专业 NVH API 与通用 AI API 网关严格拆分

本页只做公开介绍和申请入口规划，不承载任何后端逻辑、密钥、支付或数据库配置。专业 API 面向工程研究，AI API 网关参考 Sub2API 类能力但独立运行。

专业 NVH API

`api.nvhtest.cn`：数据上传、分析任务、报告生成、定制 Skill、MCP 服务。

AI API 网关

`ai-api.nvhtest.cn`：模型路由、API Key、额度、用量、限流、审计。

隔离原则

两套服务不共用 Key、额度、日志和计费数据库，避免成本与风险互相影响。

申请入口

免费阶段先展示规划；正式阶段增加申请表单、文档和服务状态。
