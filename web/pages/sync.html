Githubfeishu / VitePress

把 NVH 百宝箱作为内容同步源

当前 `nvhtest.cn` 已经是 VitePress 文档站，适合继续承载飞书/Markdown 同步内容。新的 `web/` 站群门户不替代它，而是把它作为博客、文档和频道内容的上游来源之一。

现有站点

NVH百宝箱

适合持续发布教程、指南、更新日志、导航页和可搜索文档。

仓库结构

Githubfeishu

仓库使用 `docs/` + VitePress，脚本包含 `docs:dev`、`docs:build`、`docs:preview`。

同步定位

内容源

飞书或 Markdown 内容先进入 VitePress，再由 `web` 做精选入口和站群导航。

边界

不混后端

同步内容不携带 API 密钥、付费配置、论坛用户或客户私密数据。

Recommended Flow

推荐同步流程

1. 内容编辑继续在飞书或 Markdown 中维护 NVH 教程、工程笔记、工具说明。内容源
2. VitePress 构建通过 Githubfeishu 仓库的 `pnpm run docs:build` 生成文档站。构建
3. 主站精选`web/pages/blog.html`、`channel.html` 只收录精选入口、摘要、标签和跳转。聚合
4. 论坛沉淀高价值讨论进入 Discourse；精选结论再回流到 VitePress/频道。闭环
建议长期保留两个前台层：`www.nvhtest.cn` 做站群门户，`docs.nvhtest.cn` 或当前 VitePress 站做可搜索知识库。现在本地静态站先记录这个关系，暂不迁移现有 VitePress 内容。
