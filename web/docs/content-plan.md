# Web Content Plan

## Goal

Make `web/` a credible first-stage public entry for NVH Test before paid API and forum services are launched.

## Page System

| Page | Purpose | Content Direction |
|---|---|---|
| `index.html` | Station-group portal | Brand, service matrix, subdomain map, current/planned split |
| `pages/blog.html` | Blog directory | Research notes, engineering cases, testing methods, tool updates |
| `pages/docs.html` | Docs directory | Deployment, architecture, content plan, forum deployment, future API docs |
| `pages/channel.html` | Channel hub | All, NVH Testing, Signal Processing, CAE, API/MCP/Skill, Papers, Featured |
| `pages/api.html` | API overview | Separate professional API and AI API gateway |
| `pages/forum.html` | Forum guide | Positioning, categories, future Discourse link |
