# 博客文章

这里是 NVH 工程研究博客，文章涵盖研究笔记、工程案例和测试方法。

## 理论基础

- [声功率测量：半球包络法与K1/K2修正](theory/acoustics-basics/sound-power-measurement.html) — 从定义出发五步推导半球法公式 Lw=Lp+10lg(S/S0)：声强积分、I=p^2/(rho*c)、参考值自洽拆分；0.02 W 打印机在 r=1/2/4 m 半球面上 Lp 从 95 降至 83 dB 而 Lw 恒为 103 dB 的不变性数值验证；能量平均与算术平均差 1.31 dB 的原因（Jensen 不等式）；K1=-10lg(1-10^(-D/10)) 能量域减法推导与 ISO 3744 判据（D>=15 dB 免修正、D<6 dB 超范围）；K2 以标准声源标定场地反射增量，逐倍频程带操作

- [FIR 滤波器设计三路线：单窗、频域抽样与 Remez 交换](theory/signal-processing/fir-design-three-ways.html) — 理想频响的冲激响应无限长，截断引发吉布斯振铃，三条设计路线是对同一矛盾的三种处理方式：单窗法用窗函数控制傅里叶级数收敛（汉宁/凯塞/切比雪夫，指标不能分开设）；频域抽样把频响钉在 DFT 格点上逆变换出系数，窄带选频最强但格点间靠插值、朴素设定阻带只有 -24 dB（汉宁窗单窗法 -55 dB，加一个 0.5 过渡点 -32 dB）；Remez 交换算法让加权误差最大值在通带阻带等幅最小，唯一能同时约束三项指标、同指标阶次最低。线性相位要求 h(n)=h(N-1-n)、延迟锁定 (N-1)/2；格点值漏乘相位因子冲激响应即不对称、阻带衰减退化到约 -3 dB 的 numpy 实证
- [声振模态分析：车身结构与车内声腔的耦合动力学](theory/modal-analysis/vibro-acoustic-modal-analysis.html) — 车内轰鸣峰既不在结构模态表也不在声腔模态表上：乘员舱空气是个有模态的"结构"，板振动推拉腔内空气、声压反施板面载荷，耦合后模态裂变。手册 15.2.5 节的拼装路线——结构方程加 G·p 声压载荷项、声学方程用体积加速度源的非直接形式、左下角 -G^T 挂质量块右上角 +G 挂刚度块，天然不对称的物理解释（两域因果链求导阶数错位：声压对板是刚度项、板加速度对空气是体积源）；互易性跨域成立支撑 Q-source 一次测量获得全部 ATF，代价是结构/声激励留数标尺差 λ²（45 Hz 与 50 Hz 模态相差约 23%，逐模态换算不可省略）；参数估计全套复用 LSCE/FDPI/MLMM 多参考整体方法；numpy 最小耦合模型演示裂变行为：45/50 Hz 两模态 g=50 时排斥到 43.82/51.35 Hz

- [均值、中值与偏斜度：数据中心不只一个](theory/signal-processing/mean-median-skewness.html) — 手册明说均值不是唯一的中心：正偏斜时均值被长尾拖走（95% 点在 0.1g、5% 冲到 3g 的信号均值 0.245g、中值 0.101g），偏斜度三次标准化矩三步推导（中心化→σ³ 标准化→符号保留），γ₁=Σ((x−x̄)/σ)³/N 正尾正、负尾负、对称归零；均值−中值差是不对称的快速诊断，√(6/N) 是可信门限、超几倍才算真偏；|γ₁|<1 用均值、超出换中值/百分点，路噪载荷谱、怠速抖动、主观评分三场景 + 数据质检先查偏斜再谈分析
- [重采样：降采样的频率折叠、升采样的镜像与任意比率的实现代价](theory/signal-processing/resampling-decimation-interpolation.html) — 变换采样率并非简单插值取点：降采样不做抗混叠滤波，手册算例中 325 Hz 按 |325-2×200|=75 Hz 折叠成虚假谱峰且幅值不减；升采样插零的谱为原谱压缩 n 倍后周期重复，8 Hz 映出 992 Hz 镜像，由后置低通滤除；分数比率固定先升后降——先降后升时 200~300 Hz 频带直接丢失；任意比率（8192→8000 Hz）采用因子 15 插值前升采样+线性插值，SDR=10lg(80R/(π·fc%)) 量化精度与计算量的权衡；自适应重采样按转速曲线变换到角度轴，Δα 按全程最低转速确定（500 rpm/2000 Hz 时阈值 1.5°）；numpy 实验数值验证折叠与镜像
- [结构动力学设计的三项工具：灵敏度分析、修改预测与强迫响应](theory/modal-analysis/modal-design-toolbox.html) — 模态模型不止用来写报告：灵敏度 dw/dm=-w*psi^2/2、dw/dk=(psi_a-psi_b)^2/2w 把"在哪儿改"变查表题（质量跟振型腹点走、刚度跟相对运动大的位置走，数值例：同 1 N/m 接地刚度收益是同相位两点间弹簧的 13.6 倍）；互易性 r_mn=r_mj*r_nj/r_jj 说明驱动点留数是整套设计的标尺地基；修改预测走模态空间子结构综合五步重解特征值（+100 N/m 外推误差 0.003 Hz，+800 N/m 偏 0.157 Hz 必须重解，MAC 同步掉到 0.98）；强迫响应逐模态贡献量分解指出未被激励的模态不出面；频带包不住修改后新模态、驱动点缺测是两条硬性限制
- [IIR 原型滤波器选型：贝塞尔、巴特沃斯、切比雪夫与椭圆的特性对比](theory/signal-processing/iir-prototype-filters.html) — 同一组指标（1 dB 波纹/40 dB 衰减/一个倍频程过渡带）下巴特沃斯 8 阶、切比雪夫 5 阶、椭圆 4 阶：原型选择本质是用通带平坦度、阻带形状和群延时换阶次。从 |H|²=1/(1+w^2n) 推出截止处 -3.01 dB 与 6n dB/倍频程滚降、切比雪夫多项式 ±1 振荡给等波纹、椭圆积分给最低阶次；贝塞尔用最差衰减换最平群延时所以保波形、阶次自动估计对它失效；双线性变换的频率翘曲（200 Hz@1 kHz 采样偏到 231 Hz）要求预畸变，带通变换阶次翻倍需提前核算
- [调谐式动力吸振器：用模态模型直接算出质量、刚度与阻尼](theory/vibration-basics/tuned-absorber-design.html) — 悬置架、排气吊钩的共振错不开频就压峰：附加单自由度质量-弹簧-阻尼系统，5% 质量比把 42 Hz 峰压低 13 dB。从消振器运动方程（式 20-72）推起，附着点反作用力化为频率相关的等效质量（式 20-77），分母归零处即调谐的本质；最佳调谐频率 f_a=f_n/(1+mu) 调低使裂变双峰等高、最佳阻尼比为 minimax 解；等效质量由驱动点留数反算 m_eq=-1/(2*wd*Im(A_jj))，无驱动点测量则无标尺；numpy 复现设计-验证全流程，调错 2 Hz 回升 2.1 dB、质量比减半收益减半
- [声音的掩蔽效应：临界带、响度计算与 AVAS 设计判据](theory/acoustics-basics/masking-effect.html) — 50 dB、4 kHz 纯音在 90 dB 窄带背景中仍可闻、背景升至 100 dB 即不可闻：掩蔽在临界带（Critical Band）内结算，Bark 差小于 1 的分量按同带合成处理。临界带带宽 500 Hz 以下约 110 Hz、高频段约 23% 恒百分比，掩蔽区向高频侧扩展更宽；Stevens Mark VI 的 F 因子（1/1 倍频程取 0.3、1/3 取 0.15）介于各带独立求和与仅占优带两个极限之间，Zwicker 法以局部响度曲线下面积合成总响度、被压平段即对总响度无贡献；AVAS 提示音置于 1～3 kHz 窄带并留出约 20 ms 后掩蔽窗，电动平台取消发动机后掩蔽格局需整体重算
- [MLMM 最大似然模态模型：从最小二乘到迭代优化](theory/modal-analysis/mlmm-modal-estimation.html) — Polymax 合成 FRF 与实测仍存偏差：去分母线性化使噪声被乘上分母模值，共振区被降权、反共振区被放大。从复高斯概率密度出发分步推导 ML 代价函数（连乘取负对数，方差大的谱线自动小权重），高斯-牛顿迭代每轮仍解线性 LS，协方差矩阵接近 CRLB，是手册路线中唯一能给出置信区间的方法；numpy 实测重加权将反共振区误差从 25.3% 降至 3.2%、GN 迭代三轮收敛至 35.154 Hz/11.84%；Testlab 中 26 tokens 插件、锁频率与 70% 阻尼上限剔除多余模态两类约束
- [圆拟合法：复平面上的SDOF模态参数估计](theory/modal-analysis/modal-circle-fit.html) — 复平面里共振区数据排成圆弧不是巧合：单模态分式推导给出过原点的圆方程，直径 d=|A|/σ 把留数锁在圆的大小上。频率用最大角度间距法定位，绕开谱线离散化限制（数值实验：峰值法偏 0.3 Hz、圆拟合精确命中 30.200 Hz）；阻尼用张角半角公式 tan(θ/2)=|ω-ωd|/σ，不依赖半功率点存在性。留数反号的密频双模态把圆拉歪到残差 12.9% 半径（同号仅 2.2%），SDOF 前提不成立时转 CMIF 增强 FRF 再圆拟合；方法选型表对齐手册：强阻尼内饰车选 FDPI、标准场景 LSCE、快速筛查与试验设置检查用圆拟合

- [模态指示函数 MIF：FRF 矩阵逐谱线特征值分析与重根判据](theory/modal-analysis/modal-indicator-function.html) — 幅值谱逐峰计数存在两个系统性缺陷：单条 FRF 丢失节点模态、密频对融成单个包络。MIF 逐谱线对 FRF 实部虚部矩阵解广义特征值问题，共振处响应滞后 90 度、实部趋零，特征值曲线呈局域极小；第 n 条 MIF 与前面各条同时凹陷指示 n 重根，可算条数等于参考点数。numpy 仿真 3 测点 2 输入：密频对处 MIF1 谷底 0.0005 而 MIF2 仅降至 0.40，二重根两线同陷 0.0003 与 0.0046，仅留一个输入时第二 MIF 不复存在；判重根前先核对参考点数

- [动刚度、柔度与导纳：一族 FRF 的换算关系](theory/modal-analysis/dynamic-stiffness-compliance-mobility.html) — 锤击测的 g/N、供应商要的 N/m、声学用的 (m/s)/N 是同一个复函数的六种面孔：位移/速度/加速度配合正反演，频域互推只需乘除 jw 和取倒数。从 SDOF 运动方程分步推导柔度-导纳-加速度导纳链，刚度线读 k、质量线读 m 的判读法；反演形式共振变深谷不是反共振；悬置安装点 10 倍刚度法则的串联弹簧变形分配解释（1 倍时悬置只担 50% 变形、10 倍 90.9%、100 倍 99%），通用机械安装参考 1e7 N/m 量级；Testlab 右键 Y 轴 Processing 直接积分微分切换
- [FRF 互易性：换激励点与响应点，结果为什么不变](theory/modal-analysis/frf-reciprocity.html) — 留数三因子拆解 A=Qψ(i)ψ(j) 直接给出 H(ij)=H(ji)：互易性是乘法交换律在动力学矩阵对称结构上的投影。锤击试验只测一行或一列的组织方式、移动锤子必须每点敲满三方向否则振型残缺、留数综合式 A(mn)=A(mj)A(nj)/A(jj) 让少数参考点数据补算全部自由度对（驱动点留数是标尺）、多参考下振型与参预因子成正比是常规质检、Q-source 反测把 12 条 ATF 路径并成 1 次测量（P/F 与 A/Q 量纲同约化为 1/m2）；numpy 两自由度模型 H12 与 H21 差在 1e-19 机器精度、K12 破坏 1.5 倍后比值 1.499 立刻失衡；陀螺耦合与声振耦合是真失效（反对称项），非比例阻尼只要阻尼阵对称并不破坏互易性，测量不一致是假失效，RSF 最小二乘可强制对称

- [Vold-Kalman 阶次跟踪滤波器：用加权最小二乘从噪声中提取阶次波形](theory/rotating-machinery/vold-kalman-order-tracking.html) — 谱线切取法受 1/平均循环数分辨率限制且瞬变幅值被平均抹平时，VKF 改用求解思路：正弦二阶差分 x(n)-c(n)x(n-1)+x(n-2)=eps(n) 当结构约束、测量方程当数据约束，叠成超定方程组加权最小二乘一次解出阶次时域波形，幅值相位均为副产品且无相位失真；HC 因子决定带宽：λ=3000 时 55 Hz 邻频增益压到 0.10、幅值阶跃收敛延至 19 ms，λ=30 时邻频 0.92 原样通过但 6 ms 跟上；矩阵形式一行解出 x=(I+λL'L)^-1y 的 numpy 复现；邻阶密集取高 HC、瞬变工况取低 HC、带宽按阶次而非频率定义

- [时频分析方法选择：STFT、小波变换与 Wigner-Ville 分布](theory/signal-processing/time-frequency-analysis.html) — 非平稳信号一帧 FFT 全糊掉：时频分布 P(t,ω) 要过边缘方程（沿频率积分=即时功率、沿时间积分=能量密度谱）才算能量自洽。STFT 一把固定窗量全程，Δf=1/T 锁死时间/频率分辨率的折中，恒带宽带通滤波器组分格均匀；小波用尺度 a=ω₀/ω 伸缩基函数，Δf/f=Const 恒百分比带宽、高频窄窗低频宽窗，与听觉倍频程同构；Wigner-Ville 双线性翻折相乘满足最多数学性质，但多分量信号在分量中间织出振荡干涉项、噪声沿时间轴扩散——工程判读优先谱图/尺度图，要用 WVD 选带平滑核的 SPWD/CWD；numpy 实测长窗把 20 ms 猝发读宽 6 倍、短窗定位准但分辨率掉到 50 Hz

- [驱动点测量：激励点选在节点上会丢模态](theory/modal-analysis/driving-point-survey.html) — 同一结构换三个敲击点，FRF 峰数就从 3 变 2：激励点落在振型节点上留数归零、该阶模态整个消失。从留数三步推导（模态解耦→频域回收→部分分式）给出 A=Qψ(i)ψ(j)，驱动点平方恒正所以峰谷交替；平板 15 节点 5 候选点实测只有角点 plate:15 激全 8 阶，中心线上的点全丢扭转模态；numpy 复算悬臂梁振型精确复现 x=0.50 丢三阶、x=0.78 丢二阶（留数比自由端低近 4 个量级）；驱动点数据还是模态质量定标与互易性校验的唯一来源
- [雨流计数：从随机载荷历程提取等幅循环的方法](theory/signal-processing/rainflow-counting.html) — S-N 曲线对应等幅对称循环，实测载荷谱是大小循环叠加、均值漂移的复杂历程：雨流计数把历程分解为一系列带值域与均值的等幅循环，结果直接代入 Miner 准则预估寿命。四点法判据 |s3-s2| 不大于两端值域即闭合小循环、剔除后回扫的完整算法；残数（含全程最大值域）按半循环计数；值域滤波门坎不敏感（R0 到 3R0 才影响矩阵）、量程与测段长度才是关键变量；numpy 从 66350 个峰谷的模拟信号跑通全流程，k=8 下预期寿命 802 块、大循环主导损伤

- [重叠处理：50% 重叠的数学与统计依据](theory/signal-processing/overlap-processing.html) — 频谱平均中重叠设置的三个依据：汉宁窗两端各 20% 数据权重接近零（手册判据：至少 30% 重叠可恢复数据利用率）、50% 步距满足 COLA 恒等式 w(n)+w(n+N/2)=1 使数据权重严格均匀（66.7%/75% 同样满足，叠加和 1.5/2.0）、相邻块功率谱相关仅 ρ²=1/36 平均效果接近独立（Monte Carlo 实测方差比 1.06 对应理论 1.056）；重叠换块数的收益在 50% 后快速衰减（75% 时 ρ²=0.434），正弦/瞬态信号重叠平均只虚增平均次数

- [倍频程滤波与实时频谱：声级计 1/1、1/3 倍频程带是怎么算出来的](theory/acoustics-basics/octave-filters.html) — 倍频程柱状谱不是 FFT 分组求和：ANSI S1.11/IEC 61260 时域滤波器组各管一带、RMS 检波出带级；中心频率按 1000·2^(i·x) 对数轴生成的分步推导——上下限几何平均、带宽恒为 fc 的 70.7%（1/1）或 23.1%（1/3），1000 Hz 带真实上限 1122.5 Hz 而非标称差 250 Hz；自然频率算数、标称频率标注，跨软件对数据先核对口径；Testlab 需勾 ANSI-IEC Octave Filtering 插件（23 token），Fast 0.125s/Slow 1s/Impulse 0.035s 时间计权决定读数跟随性，RTO 后缀功能走同一滤波法
- [声级计读数里的时间：时间计权与等效声压级](theory/acoustics-basics/spl-time-weighting-leq.html) — 声级计三挡读数与 Leq 各答各的问题：时间计权是 e^(-dt/tau) 指数折扣记忆历史的均方估计器，Impulse 35 ms/Fast 125 ms/Slow 1 s 三挡，配上信号递减时 1500 ms 长衰减构成快上慢下的不对称响应（上升跟得上、回落给表针留读数时间）；100 ms 脉冲实测三挡读数差 10 dB（-0.26/-2.59/-10.22），Slow 看关门声必亏；Leq 按式 7-1 在平方域做线性能量平均再取 10lg，分贝不能直接平均（80/70 各半得 77.4 不是 75），85 dB 关门声摊进 60 s 只剩 57.2；积分时长与计权方式必须随数标注，Impulse 值禁止与 Leq 比大小

- [自由场与扩散场：近场远场的工程划分](theory/acoustics-basics/sound-fields.html) — 声场类型决定数据怎么解读：近场/远场以 2 倍波长为界，63 Hz 要离源 10.9 m 才进远场，低频布点 0.5 m 处测的是环流污染数据；自由场零反射、每倍距离降 6 dB 可外推，扩散场各处声级一致但净声强为零——声强法在强混响环境失灵是物理不是仪器问题

- [噪声认证标准怎么选：从指令到测法的决策链](theory/acoustics-basics/noise-certification-standards.html) — 指令定类别、C 类标准定工况、基础标准定测法三层决策链：声压法要特定声学环境但认证主流，声强法任意声场可测但频带受限；K1/K2 是限值内的补救而非透支，背景级差 15 dB 修正量仅 0.14 dB 这条判据的物理依据

- [扭转振动：旋转机械角速度波动的基本概念、测量判据与阶次诊断](theory/rotating-machinery/torsional-vibration.html) — 角速度围绕稳态转速的交变波动：1 PPR 测不到它，PPR 至少取最高关心阶次 2 倍（欠采样折叠出假阶次而非消失）；点火阶次主导、低转速扭振更大，扭振阶次与 DRE 噪声阶次叠图对峰即可锁定曲轴共振
- [动平衡：静平衡、耦合平衡与动平衡](theory/rotating-machinery/balancing-static-dynamic.html) — 质量轴与旋转轴的三种错位关系定校正平面数：平行错开是静不平衡单面可解，相交是耦合不平衡必须双面，既不平行又不相交是最常见的动不平衡；离心力 F=U·ω² 转速翻倍力翻四倍，12000 rpm 下 10 gm·cm 偏置的离心力达自重 1600 倍，平衡机两面配重"不同相不反相"是静+耦合分量矢量叠加的正常数据

- [调制阶次与边带：彩色图谱对称伴线的成因与判读方法](theory/rotating-machinery/modulated-order-sidebands.html) — 62 阶两侧对称出现 60/64 阶伴线不是三个独立激励源而是一个：偏心椭圆齿轮每转推拉两次，啮合能量被调幅分解为载波+两侧 m/2 边带（积化和差推导，并给出任意 N±k 一般式与调制深度反算）；边带间距 k 即调制源每转作用次数——间距 2 指向椭圆偏心、间距 1 指向安装偏心，在阶次域量不在频率域量；受控偏心把能量分散到宽频带、降低峰值响应，是齿轮制造商主动采用的降噪手段
- [阶次：旋转机械响应的每转事件数表征](theory/rotating-machinery/whats-an-order.html) — 每转事件数相对参考轴之比：皮带速比 3 即 3 阶、86 齿啮合即 86 阶、六缸四冲程燃烧恒为 3 阶（缸数/2，与转速无关）；频率=阶次×rpm/60，colormap 上斜线是阶次、竖线是共振，交点即问题转速

- [H1、H2、Hv：频响函数的三种估计子及其适用条件](theory/modal-analysis/frf-estimators.html) — FRF 是估出来的不是测出来的：H1=Syx/Sxx 认噪声在输出端、H2=Syy/Syx 认噪声在输入端、Hv 谱矩阵最小特征向量两头认账，|H1|=γ²·|H2| 锁死三者关系；共振峰谁都准（偏差<1.5%），反共振谷 H2 虚高 6 倍同时相干跌到 0.159 是同一噪声的两种症状；锤击用 H1、激振器随机用 Hv、MIMO 先做主分量鉴别再估计
- [伪随机激励：将激振能量对齐傅里叶网格的模态测试信号](theory/modal-analysis/pseudo-random-excitation.html) — 伪随机=多正弦叠加且频率全落傅里叶网格：矩形窗零泄漏、谱线幅度可逐根设定信噪比高；Schroeder 相位 φk=πk(k-1)/K 把 50 分量合成波的波峰因子从 3.06 压到 1.89，同等功放电压上限下多出 60% 有效激励；配合延迟块后的周期平均（时域）压不相关噪声，飞机驱动点 FRF 相干全面压过猝发随机

- [传递路径分析TPA入门：把整车噪声拆成一条条可量化的传递路径](theory/vibration-basics/transfer-path-analysis-intro.html) — 源-路径-目标拆解模型：切口划在能改的接口上，12/15/5 条路径三种切法各有适用；贡献量是复数，反相路径抵消时拆掉"最大贡献"反而升 1.2 dB 的 numpy 复现；软悬置用刚度法 F=kx、硬连接用矩阵求逆法，反共振点单 FRF 相除噪声放大近 9 N、两指示点最小二乘全频段误差 2.4%

- [峭度：表征信号冲击特性的统计量](theory/signal-processing/kurtosis-signal-statistics.html) — RMS 只反映能量平均、峰值易被毛刺带偏，冲击信息集中在幅值分布尾部：峭度以四次方矩放大尾部贡献，方波 1/正弦 1.5/高斯 3（不减 3 口径），Testlab 吞吐处理算"减 3"版而振动控制用"不减 3"版；滑动帧峭度超值定位咔哒异响（同峰值短/长点击差近一个数量级），Kurtosis Control 3~12 复现路谱峰值分布、Sigma Clipping 限制峰值/RMS 保护试件
- [角度域：把时间轴换成转轴看信号](theory/rotating-machinery/angle-domain.html) — 变转速把阶次拖成时域宽峰，换横轴为转角后阶次原地锁定：一整套对偶关系（频率对阶次、fs 对每转点数、谱平均对循环平均），阶次分辨率=1/平均循环数，最大阶次=每转点数/2，循环平均对非整数阶的衰减公式；转速通道质量、四冲程 720 度循环定义两大坑；numpy 演示 4 秒匀加速数据时域 FFT 散布 95 Hz、角域 1.00/4.00 阶精准落位，103 循环平均把 2.3 阶泄漏压到 0.003
- [阶次跟踪两种采样：定采样 vs 同步采样](theory/rotating-machinery/order-tracking-sampling.html) — 变速工况下阶次幅值准不准，先看采样栅格是等时间还是等角度：定采样靠 tacho 曲线插值重采样进角度域（SDR 刻画插值失真），同步采样用编码器直采每转点数恒定；最大阶次=PPR/2 且无混叠保护，测 60 阶扭振至少 120 PPR、实用留 10 倍余量；角度分辨率按全程最低转速设计，numpy 演示变速信号重采样后 3 阶幅值解调恢复 0.997
- [模态置信判据MAC：评估振型一致性的定量指标](theory/modal-analysis/modal-assurance-criterion.html) — 振型是多维向量，MAC 是共线程度度量：对复数缩放免疫、几何上是夹角余弦平方；对角线看一致性、非对角看独立性；MSF 只在 MAC 高时有意义；关键约束是空间混叠——同样 8 个测点铺满全跨 MAC=0、挤半跨升至 0.69，CMIF 交叉点两侧 MAC 矩阵（幺矩阵/反对角阵）区分共振峰与交叉点；附 numpy 演示与实测输出
- [模态振型验证三指标：MPC、MPD 与 MOV](theory/modal-analysis/modal-validation-mpc-mpd-mov.html) — 稳定图锁定极点后振型还需量化验证：MPC 检验复平面实虚部是否共线（正则模态应近 100%）、MPD 给出相位散布角度（健康值近 0°，20° 以上动画出现可见错动）、MOV 以附加质量必降频的理论特性统计灵敏度为负的测点占比（物理模态应近 100%，识别计算模态）；单一输入点全模态 MOV 集体偏低先查激振力方向符号，改正负号即可修正；倍角圆均值消除 0°/180° 二义后 numpy 实测复模态 MPC 降至 44.3%、MPD 升至 20.7° 而 MOV 不变——相位形态与灵敏度符号是两个独立问题

- [刚体属性提取：用FRF质量线反算质量、质心与转动惯量](theory/modal-analysis/rigid-body-properties.html) — 自由悬挂下低于第一阶弹性模态的平直质量线是实测惯量属性的免费来源：刚体段 FRF 读出惯性制约力，经运动学约束方程逐谱线最小二乘先解质心、再解惯量张量六分量，特征值分解得主转动惯量与主轴。numpy 数值算例：62 kg 动力总成 1% 力测量噪声下质心误差在 1 mm 量级，角加速度方向多样时方程组条件数约 1.5、趋于共线时升至约 16.5；惯量矩阵换参考点时 Iyy 由 4.992 增至 7.472 kg·m²，增量恰为平行轴项；2 点 6 向激励加 12 响应是工程配置底线，测点共线则该轴惯量无解，报告惯量必须注明参考点

- [音高与虚拟音高：滤掉基频为什么还能听出那个调](theory/acoustics-basics/pitch-virtual-pitch.html) — 音高是听觉属性不是物理量：低频近似线性、8 kHz 的半音高只有 1300 Hz（比值 0.163），mel 标尺 2100 对 1050 恰好减半；复合音的音高感走虚拟音高通道——谐波族间距携带基频信息，滤掉基频谱线听觉照常反演，多解候选靠低次谐波偏好裁决（Terhardt 谱音高/虚拟音高带权框架，真实 vs 标称音高分口径）；工程含义：去啸叫调感要打谐波族间距结构而非摘一根谱线，AVAS 提示音按 mel 差设计，对标报告注明口径

- [扭振阶次实操三招：通道组、纵轴量纲与三维动画](practice/test-setup/torsional-orders-tips.html) — tacho 通道组改 Vibration 一份信号两种身份免分线；RPM 波动除以 2*pi*O*f_rot 换角度（±25 RPM @ 2 阶 2600 RPM 折合约 0.275 度峰值），积分前先洗净转速信号；RMS/峰值/峰峰值差 1.414 到 2.828 倍报告必须写明口径；Torsional Node 圆盘动画把扭转 ODS 直观呈现

- [留数与残差：模态理论里最易混的一对术语](theory/signal-processing/residues-vs-residuals.html) — Residue 与 Residual 只差两个字母却是两码事：留数是部分分式极点前的复系数、三因子式（标尺×响应点振型×参考点振型）给出的带标尺振型，模态参数组成员，实模态下纯虚、峰拾取按 |A|=sigma*|ImH(wd)| 直接换算（与圆拟合直径 d=|A|/sigma 同源）；残余项是带外模态在窄带内的渐近贡献——高频退化成常数（残余刚度 UR）、低频退化成 1/w^2（残余质量 LR），渐近系数由 Im(A) 给出，没有频率阻尼、不进振型动画。numpy 双演示：对称化特征分解+峰拾取留数列归一化后还原振型至 1e-4~1e-3（附 eigh 误用非对称阵的陷阱说明），窄带拟合加上下残余项把 20.46% 误差压到 1.97%、LR 渐近理论值与拟合值同量级印证其补偿项本质；Testlab 面板 Residue type 与 Upper/Lower residuals 勾选框的对应关系（手册 15.2.1/15.3.2/15.3.6/18.3 节）
