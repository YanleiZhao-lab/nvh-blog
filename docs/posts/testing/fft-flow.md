# FFT 基础流程：从采样率到谱线解释

> FFT 是 NVH 频域分析的基础工具，但从采集到得到一条可解释的频谱，中间有多个参数会直接影响结果。本文按信号链顺序梳理采样率、抗混叠滤波、加窗、平均、频率分辨率和谱线判读，给出参数选择依据和常见误区。

## 一、信号链总览

```text
物理信号 → 传感器 → 抗混叠滤波器 → ADC 采样 → 加窗 → FFT → 平均 → 频谱
            ↑                       ↑              ↑          ↑
         选型/灵敏度            采样率 fs       窗类型      平均方式
```

每个环节的选择都会影响最终频谱的频率范围、分辨率、幅值精度和噪声水平。

## 二、采样率与奈奎斯特

### 2.1 奈奎斯特定理

要无失真地恢复一个频率为 f 的信号，采样率必须满足：

```text
fs ≥ 2 × f_max
```

工程中**不会**取 fs = 2 f_max，而是留足余量。

::: warning 抗混叠
高于 fs/2 的频率成分会"折叠"回基带，产生**混叠**，混叠后的信号无法用软件去除。必须在 ADC 前用模拟抗混叠滤波器（低通）把高频成分压下去。
:::

### 2.2 实际采样率选择

| 关注频段 (Hz) | 推荐 fs (Hz) | 理由 |
| --- | --- | --- |
| 0–200 | 1024 | 留 2.5 倍余量，抗混叠滤波器有过渡带 |
| 0–2000 | 8192 | 常用声学范围 |
| 0–8000 | 32768 | 高频啸叫 / 啁啾分析 |
| 0–20000 | 65536 | 人耳全频段 |

::: tip 经验法则
采样率取分析上限频率的 **2.5–4 倍**。便宜一点的方案取 2.56 倍，现代采集系统常取 4 倍给抗混叠滤波器留更陡的过渡带。
:::

## 三、抗混叠滤波器

抗混叠滤波器（Anti-Aliasing Filter, AAF）是模拟低通滤波器，放在 ADC 之前。

```python
# 概念示意：理解为什么需要留余量
import numpy as np

fs = 8192                  # 采样率
f_nyquist = fs / 2         # 4096 Hz —— 奈奎斯特频率
f_analysis = 3200          # 想分析的频率上限
# 抗混叠滤波器的截止通常设在 0.4 ~ 0.5 × fs
# 留出 3200–4096 Hz 作为滤波器过渡带
print(f"分析上限 / 奈奎斯特 = {f_analysis / f_nyquist:.2f}")
# 若分析上限 = 0.8 × f_nyquist，滤波器衰减不足，会残留混叠
```

::: warning 数字滤波器不能替代模拟 AAF
一旦信号被采样，混叠就已经发生了。后端的数字低通滤波器无法恢复被混叠的信号。抗混叠必须在 ADC 之前完成。
:::

## 四、频率分辨率

频率分辨率由采样时长决定：

```text
Δf = fs / N = 1 / T
```

其中 N 是 FFT 点数，T 是单帧采样时长。要分辨更近的两个频率，必须**增加采样时长**。

| 目标 Δf (Hz) | 所需 T (s) | 在 fs=8192 时 N |
| --- | --- | --- |
| 1 | 1.0 | 8192 |
| 0.5 | 2.0 | 16384 |
| 0.25 | 4.0 | 32768 |

::: tip 分辨率 vs 窗函数
有效分辨率还会受窗函数主瓣宽度影响。Hann 窗下能真正分辨的两个等幅频率约为 `4 × Δf`。若 Δf=1 Hz，实际可分辨间隔约 4 Hz。
:::

## 五、窗函数

非整周期截断会产生泄漏，必须加窗。窗函数的选择详见[FFT 窗函数选择](./fft-window-functions.html)一文。

```python
import numpy as np
from scipy import signal
from scipy.fft import fft, fftfreq

fs = 8192
T_frame = 0.5
N = int(fs * T_frame)
t = np.linspace(0, T_frame, N, endpoint=False)
x = 3 * np.sin(2 * np.pi * 120 * t) + 0.5 * np.random.randn(N)

# 加 Hann 窗后做 FFT
win = signal.get_window('hann', N)
X = fft(x * win)
freqs = fftfreq(N, 1 / fs)[:N // 2]
mag = (2.0 / np.sum(win)) * np.abs(X[:N // 2])
```

::: warning 幅值修正不可省
加窗后必须乘补偿系数 `N / sum(window)`，否则幅值偏小。不同窗的补偿系数不同（Hann=2.0，Flat Top≈4.18）。
:::

## 六、平均方法

实测信号含噪声，单帧 FFT 谱波动大，需要多帧平均。平均方式直接影响谱的统计特性。

| 平均方式 | 计算方法 | 特点 |
| --- | --- | --- |
| **线性平均（功率谱）** | 对 |X(f)|² 做 N 帧算术平均 | 稳态信号最常用，结果稳定 |
| **RMS 平均** | 对 √(|X(f)|²/N) 平均 | 对应有效值，物理含义直观 |
| **指数平均** | 新帧按权重递减，强调最近数据 | 缓变信号 / 实时监测 |
| **峰值保持** | 取每帧最大值 | 捕捉瞬态/扫频峰值 |
| **无平均（单帧）** | 仅 1 帧 | 瞬态/冲击信号 |

```python
# 线性功率谱平均示意
n_frames = 16
psd_acc = np.zeros(N // 2)
for i in range(n_frames):
    frame = acquire_one_frame()               # 获取一帧
    win = signal.get_window('hann', N)
    X = fft(frame * win)
    psd_acc += np.abs(X[:N // 2]) ** 2
psd_avg = psd_acc / n_frames                  # 平均功率谱
```

::: warning 平均方式不匹配信号类型
- **稳态信号**用线性平均——帧越多越稳定。
- **缓变信号**（如发动机暖机）用指数平均——否则早期数据会"污染"当前谱。
- **瞬态信号**不能用功率平均——会抹掉能量，应单帧或峰值保持。
:::

## 七、重叠处理

加窗后帧两端信号被衰减，若帧间不重叠会丢信息。常用 **50% 重叠**（Hann 窗），既补偿能量损失又不过度增加计算量。

```text
无重叠:  |---帧1---|---帧2---|---帧3---|   ← 窗两端信号弱
50%重叠: |---帧1---|
              |---帧2---|                    ← 弱区被下一帧中心覆盖
                   |---帧3---|
```

| 窗类型 | 建议重叠率 |
| --- | --- |
| 矩形 | 0%（整周期时） |
| Hann | 50%（常用）或 66.7% |
| Flat Top | 66.7%–75% |

## 八、谱线解释

得到频谱后，如何判读是 NVH 工程的核心能力：

- **离散峰值** → 多为周期性来源（转速阶次、电源频率、齿轮啮合）
- **宽带隆起** → 流体噪声、摩擦、随机振动
- **低频隆起 (<100 Hz)** → 结构共振 / 轰鸣
- **50/100 Hz 尖峰** → 工频干扰（检查接地和屏蔽）
- **随转速移动的峰** → 阶次成分，需做阶次分析

::: tip 判读三问
拿到一条谱，先问三个问题：
1. 这个峰的频率对应的**物理来源**是什么？
2. 这个峰的幅值是否**超过目标值/背景**？
3. 这个峰是**稳态**还是**瞬态**？（决定是否需要时频分析）
:::

## 九、参数速查

::: warning 参数联动
采样率、采样时长、窗函数、平均次数是**联动**的，不能孤立设置。典型配置示例：
- 通用声学频谱：fs=8192, T=1s, Hann, 线性 32 平均 → Δf=1 Hz
- 阶次分析：fs=随转速重采样, Hann, 50% 重叠
- 模态 FRF：fs=2048, T=4s, Hann → Δf=0.25 Hz
:::
