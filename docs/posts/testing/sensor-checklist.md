# 传感器与采样配置检查

> NVH 测试的数据质量首先取决于传感器选型与采样配置。本文按现场执行顺序整理一份测试前检查清单，涵盖麦克风、加速度计、采样率与抗混叠、量程、同步与转速信号，关键判据与数值依据 Simcenter Testing Knowledge Base 相关条目整理，供测试前逐项确认。

## 一、声学传感器（麦克风）

### 1.1 选型检查

- [ ] 根据测试场景选择麦克风类型（自由场 free-field / 随机入射 random incidence / 压力型 pressure）
- [ ] 麦克风动态范围覆盖预期声压级，并留约 10 dB 余量
- [ ] 频率响应范围覆盖关注频段（低频 < 20 Hz 或高频 > 20 kHz 需与厂家数据表确认）
- [ ] 灵敏度（mV/Pa）已校准并记录在通道设置中
- [ ] ICP（恒流源）或外部极化供电方式与采集前端匹配

::: tip 麦克风类型与声场对应关系
- **自由场（free field）**：无反射环境，如消声室、半消声室、开阔空间
- **随机入射（random incidence，扩散场）**：混响环境，如混响室、车内、舱室
- **压力型（pressure）**：管道、耦合腔、近场与壁面测量

声场类型难以目视判断时，可用测量验证：自由场远场中，与声源距离加倍声压级下降约 6 dB（平方反比定律）；扩散场中各测点位置声压级近似相等。部分厂家为同一支麦克风提供自由场/扩散场修正曲线，可按声场条件换算测得声级。
:::

### 1.2 现场校准

- [ ] 使用声校准器（活塞发声器 pistonphone 或声级校准器）进行现场校准
- [ ] 校准频率和声压级已记录（常见 1 kHz / 94 dB 或 250 Hz / 114 dB）
- [ ] 各通道校准后灵敏度偏差 < 0.5 dB

校准音多取 1 kHz 的原因：A 计权曲线在 1 kHz 处增益为 0 dB，校准结果不受通道计权开关状态影响。通道偏差按下式复核：

$$L_{\text{dev}} = L_{\text{meas}} - L_{\text{ref}}$$

其中 $L_{\text{meas}}$ 为校准时的读数声压级（dB），$L_{\text{ref}}$ 为校准器标称声压级（dB），$L_{\text{dev}}$ 即各通道一致性检查所用偏差值。

## 二、振动传感器（加速度计）

### 2.1 选型与安装

- [ ] 加速度计频响范围覆盖测试频段
- [ ] 传感器质量足够小，控制质量负载效应（mass loading），遵循质量比 > 10:1 原则
- [ ] 安装方式确定，刚度排序：螺柱 stud > 蜂蜡 > 磁座 > 手持探针
- [ ] 安装面平整、清洁，确认无松动
- [ ] 三轴（tri-axial）加速度计的 X/Y/Z 方向定义与测试坐标系一致并现场记录
- [ ] 电缆固定，避免电缆抖动引入摩擦电噪声（triboelectric noise），三轴细缆尤其注意

质量负载效应可由安装点等效动质量 $M$ 与传感器质量 $m$ 估算，被测结构固有频率的偏移为

$$\frac{f'}{f} = \sqrt{\frac{M}{M+m}}$$

物理意义：附加质量使安装点等效质量增大，固有频率下移。取 $m = M/10$（即 10:1 原则）时 $f'/f \approx 0.95$，固有频率偏移约 5%，为工程可接受的上限。

::: warning 安装谐振频率
不同安装方式改变加速度计的安装谐振频率（mounted resonance），典型量级如下（具体值以传感器手册与安装面状态为准）：

| 安装方式 | 典型安装谐振频率 |
| --- | --- |
| 螺柱安装 | ~30 kHz |
| 蜂蜡 | ~10 kHz |
| 磁座 | ~3 kHz |
| 手持探针 | ~1 kHz |

可信测量频段上限应显著低于安装谐振频率（工程上常取其 1/3 以下）；安装谐振落入分析带宽内时，谐振附近数据失真。
:::

## 三、采样配置

### 3.1 采样率与抗混叠

::: danger 奈奎斯特采样定理
采样率必须至少为最高关心频率的 2 倍：

$$f_s \ge 2 f_{\max}$$

其中 $f_s$ 为采样率（Hz），$f_{\max}$ 为最高关心频率（Hz）。不满足时，高于带宽 $f_s/2$ 的频率成分以带宽为轴镜像折叠到低频：

$$f_{\text{alias}} = f_s - f$$

即超出带宽 X Hz 的成分出现在带宽以下 X Hz 处。混叠一旦发生无法用软件恢复，必须在 ADC 之前由模拟抗混叠滤波器（anti-aliasing filter）抑制。
:::

实际抗混叠滤波器不是理想砖墙：Simcenter SCADAS 的滤波器在带宽处为 -3 dB 衰减点，在带宽外 20% 处衰减到零。因此无混叠的可信区间（span，频率跨度）为带宽的 80%：

$$\text{Span} = 0.8 \times \frac{f_s}{2} \quad \Rightarrow \quad f_s \ge 2.5\, f_{\text{span}}$$

即工程上采样率至少取最高关心频率的 2.5 倍（常用 2.56 倍取整配置）；若需在时域正确判读波形峰值幅值，Simcenter 手册建议采样率取 10 倍以上。例：带宽 1000 Hz 时 span = 800 Hz，800 Hz 以上幅值已被滤波器压低。

![带宽 1000 Hz 时，1300 Hz 成分镜像折叠到 700 Hz：超出带宽的频率以带宽为轴反射](/images/sensor-checklist/aliasing-mirror.png)

*（图源：Simcenter Testing Knowledge Base）*

![实际抗混叠滤波器在带宽处为 -3 dB 点、带宽外 20% 处衰减为零，无混叠区间为带宽的 80%（span）](/images/sensor-checklist/antialiasing-filter.png)

*（图源：Simcenter Testing Knowledge Base）*

- [ ] 采样率设置确认（常见 2048 / 4096 / 8192 / 51200 Hz）
- [ ] 抗混叠模拟滤波器已启用（SCADAS 内置，随带宽自动设置）
- [ ] 采样率 / 分析带宽（bandwidth）/ 频率跨度（span）关系明确

| 采样率 (Hz) | 带宽 fs/2 (Hz) | 建议分析上限 span (Hz) |
| --- | --- | --- |
| 2048 | 1024 | 800 |
| 4096 | 2048 | 1600 |
| 8192 | 4096 | 3200 |
| 51200 | 25600 | 20000 |

Simcenter Testlab 中可将频率显示切换为 span（Tools → Options → General → Frequency: Span），保证显示范围为无混叠区间。

### 3.2 采样精度与量程

量化将连续电压划分为离散电平，相邻电平间隔由量程与 ADC 位数决定：

$$\Delta V = \frac{V_{\text{range}}}{2^b}$$

其中 $V_{\text{range}}$ 为输入电压量程（V），$b$ 为 ADC 位数。16 bit 系统满量程 10 V 时有 65,536 个离散电平，$\Delta V \approx 0.153$ mV；24 bit 系统（现款 SCADAS 前端）有 16,777,216 个电平。信号电压远小于量程时，可用电平数急剧减少，量化误差（quantization error）增大。

理想 ADC 在满量程正弦信号下的最大信噪比（量化噪声下限）为

$$\text{SNR}_{\max} \approx 6.02\, b + 1.76 \ \mathrm{dB}$$

即每增加 1 bit 信噪比上限提升约 6 dB，可用于核算系统对小信号的测量能力。

- [ ] ADC 分辨率确认（现代前端多为 24 bit）
- [ ] 输入量程与信号匹配，无过载/削波（overload / clipping）
- [ ] 系统信噪比（SNR）满足最小信号测量要求

![可用量化电平数随信号电压占量程比例变化：小信号对应的电平数急剧减少](/images/sensor-checklist/quantization-bins.png)

*（图源：Simcenter Testing Knowledge Base）*

::: tip 量程设置与指示条
Simcenter Testlab 采集设置界面左下角的量程指示条（range indicator）给出直接判据：**白色** = 量程过大（量化误差风险），**绿色** = 量程合适，**橙色** = 接近量程上限，**红色** = 已过载。自动量程操作顺序：start ranging → hold level → set ranges，并建议勾选 Use full range when auto-ranging——未用满量程时，过载后增益每次仅下调一档，可能连续过载。

![Simcenter Testlab 量程指示条：白色量程过大、绿色合适、橙色接近上限、红色过载](/images/sensor-checklist/range-indicator.png)

*（图源：Simcenter Testing Knowledge Base）*
:::

## 四、触发与同步

### 4.1 触发配置

- [ ] 触发方式确认（自由运行 free-run / 边沿触发 / 转速触发）
- [ ] 触发电平和斜率设置正确
- [ ] 预触发（pre-trigger）数据保留足够（建议 ≥ 0.5 s）

### 4.2 多通道同步

- [ ] 所有通道共享同一时钟源（共用采样时钟）
- [ ] 转速通道（tacho）与声振通道同步采集
- [ ] 通道间相位偏差已确认（相位敏感分析必需）

::: warning 多前端同步
使用多台采集设备时，必须确认硬件同步方式：

<details>
<summary>常见同步方案</summary>

- **菊花链同步（daisy-chain）**：一台主设备提供时钟，从设备串联
- **GPS 同步**：户外或分布式测量，精度 ~1 μs
- **IEEE 1588 (PTP)**：网络化采集系统，精度 ~1 μs
- **专用同步线缆**：厂商专用协议

</details>
:::

## 五、转速信号（阶次分析必备）

- [ ] 转速传感器类型确认（光电 / 磁电 / 编码器 / 反射条纹带 zebra tape）
- [ ] 每转脉冲数（pulses per revolution, PPR）已记录
- [ ] 转速信号无丢脉冲现象（高速段重点检查）

阶次分析对转速信号的约束与采样定理同构：每转脉冲数相当于转角域的采样率，可分析的最高阶次为

$$O_{\max} = \frac{\mathrm{PPR}}{2}$$

其中 PPR 为每转脉冲数。由于转速通道没有抗混叠保护，Simcenter 手册要求最低 PPR 为关心阶次的 2 倍（如测 60 阶扭转振动至少 120 PPR），工程配置常直接取 PPR 为最高关心阶次的 10 倍作为安全系数。

![PPR 限制最高可分析阶次：120 PPR 采样时，60 阶以上无阶次信息](/images/sensor-checklist/ppr-order-limit.png)

*（图源：Simcenter Testing Knowledge Base）*

::: danger 转速信号质量与阶次结果
阶次分析精度直接取决于转速信号质量：

- PPR 越高，阶次分辨力越高
- 丢脉冲导致阶次计算错误，该段数据的阶次结果不可用
- 低 PPR 叠加高加减速工况时，阶次在谱图上涂抹（smearing）

**建议**：PPR ≥ 2 × 最高关心阶次（最低要求），工程配置常取 10 × 最高关心阶次。
:::

## 六、测试前最终确认

### 6.1 系统检查

- [ ] 所有通道信号正常，无异常噪声与 50 Hz 工频干扰（mains hum）
- [ ] 接地环路（ground loop）已排查（表现为约 50/60 Hz 哼声）
- [ ] 环境温度、湿度记录（麦克风与加速度计灵敏度均受温度影响）
- [ ] 备用电池 / 电源充足
- [ ] 存储空间足够（高采样率长时间采集数据量大）

### 6.2 环境记录

- [ ] 测试对象状态（工况、转速、负载）记录
- [ ] 背景噪声水平测量并记录
- [ ] 现场照片 / 安装位置图留存

## 七、数据质量快速验证

::: tip 验证三步法
采集后立即进行以下检查：

1. **时域检查**：信号是否削波？是否有周期性干扰？DC 偏置是否正常？
2. **频域检查**：频谱是否有异常尖峰（如 50 Hz 工频及其谐波）？信噪比是否合理？
3. **通道一致性**：同类传感器信号是否合理一致？相关通道相位是否符合预期？
:::
