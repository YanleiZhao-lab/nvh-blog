# 锤击法模态测试实战指南

> 锤击法（Impact Testing）是试验模态分析中最常用的激励方式：一把力锤、若干加速度计，就能得到结构的频响函数。设备门槛低，但实测中锤头选择、双击、加窗、附加质量这些细节，直接决定 FRF 质量。本文从工程实操角度梳理锤击法的关键环节和常见坑。

## 一、锤击法的原理与适用场景

锤击法的核心是用力锤对结构施加脉冲激励。锤头内置力传感器记录输入力，加速度计记录结构响应，两者相除得到频响函数（FRF），再经模态拟合提取频率、阻尼和振型。

![锤击法测试设备组成：力锤、加速度计、SCADAS 采集前端与运行 Simcenter Testlab 的计算机](/images/impact-testing/equipment-impact-test.png)

*锤击法最小设备配置（图源：Siemens Simcenter Testlab 官方知识库）*

脉冲激励的频谱能量分布取决于冲击持续时间——脉宽越窄，激励频带越宽。这带来锤击法天然的优缺点：

| 特性 | 说明 |
| --- | --- |
| 激励点可移动 | 一把锤子敲遍所有测点，适合移动激励（Roving Hammer）方案 |
| 无附加质量 | 不与结构连接，不引入激振器柔性杆带来的附加质量和刚度 |
| 能量有限 | 单次冲击能量有限，大阻尼、大质量结构激励起来吃力 |
| 敲击一致性 | 依赖操作者手感，力度、方向、点位的一致性需要练习 |
| 双击风险 | 弹性结构回弹容易造成连击，污染力谱 |

与激振器方案对比：激振器激励力可控、峰值因数低、容易获得高相干，适合密集模态和需要 MIMO 多参考的场合；但必须用柔性杆连接结构，附加质量和刚度对轻质结构、对称结构的模态影响不可忽视。北京东方所与铁科院对动车组轮对的对比试验表明，两种激励方式得到的模态频率基本一致，但参考点数量和激励位置对密集模态的识别质量影响明显——力锤方案设了八个激励参考点，在四阶密集模态处的指示比两参考点的激振器方案更清晰。

::: info 选型经验
实验室里的小型部件（支架、制动盘、电机端盖）优先锤击法；整车车身、大型焊接结构、需要纯随机激励识别非线性的场合用激振器。两者不是替代关系，很多试验规范里先用锤击做预试验定位模态，再用激振器做精细测量。
:::

## 二、锤子与锤头的选择

### 2.1 锤子规格按结构尺度选

力锤不是一把通用的。以 Endevco 产品线为例，从 2 克锤头的 2301（电路板、小型涡轮叶片）到 5.4 公斤的 2305（重型基础、船舶、建筑结构），测力范围从 220 N 到 22 kN。基本原则：

- **小而硬的结构**（电路板、传感器部件）：小锤 + 硬头，脉宽窄、频带宽
- **中等结构**（机器零件、汽车部件、电机）：100 克级锤头，测力范围按预期冲击力选
- **大型结构**（车架、泵、基础）：大锤 + 软头，能量集中在低频

### 2.2 锤头软硬决定激励频带

锤头刚度决定冲击持续时间，进而决定激励频谱的平坦范围：

| 锤头材质 | 典型激励频带 | 适用场景 |
| --- | --- | --- |
| 软橡胶 | 0 – 数百 Hz | 大型低频结构、整车车身 |
| 中等硬度 | 数百 Hz – 2 kHz 量级 | 一般机械部件 |
| 硬塑料 | 至 5 kHz 量级 | 小型刚性部件 |
| 金属（钢/铝） | 8 kHz 以上 | 局部结构、板类高频模态 |

![Impact Setup 的 Bandwidth 子表：检查力谱平坦度](/images/impact-testing/bandwidth-worksheet.png)

*Bandwidth 子工作表——锤头软硬直接体现在力谱的平坦范围上（图源：Siemens）*

Simcenter 官方指南给出的验收标准：力谱在关注频段内应平坦，跌落不超过 3–10 dB（频谱顶部约 20% 的滚降来自采集前端抗混叠滤波器，属正常现象）。如果力谱在分析带宽内提前滚落，说明锤头太软——换硬头；反之若高频能量充足但低频激励不够、响应信噪比差，换软头把能量压回低频段。

::: warning 常见误区
硬头敲轻结构，力谱很宽很漂亮，但能量摊在整个频段上，单频能量密度低，共振峰可能根本激励不起来。这时该做的是换软头集中能量，或者加大锤的质量（加装配重头），而不是抡得更重——抡重容易过载力传感器（IEPE 力传感器的饱和不像加速度计那样总能从时域一眼看出来，过载会让力谱失真）。
:::

### 2.3 一个容易忽视的因素：结构刚度也影响脉宽

同样的锤头，敲薄板和敲厚锻件，冲击持续时间不同。锤头-结构接触本质上是两个弹簧串联，最终脉宽由较软的一方主导。所以换锤头后必须实测力谱确认带宽，不能凭说明书照搬。

## 三、测点布置与两种移动方案

### 3.1 移动锤 vs 移动加速度计

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| 移动锤（固定加速度计） | 传感器不动，无质量转移问题；单轴加速度计即可 | 每个测点都要敲，操作量大 |
| 移动加速度计（固定敲击点） | 敲击次数少（一次激励测多点） | 传感器移来移去改变结构质量分布，振型有质量加载偏差 |

移动锤方案是目前的主流做法——传感器固定在一处（选刚度大、非节点、各阶模态都有响应的位置），锤子逐点敲。Simcenter 官方也明确指出：移动锤不产生质量加载（mass loading）问题；而移动加速度计引入的质量影响，可以在后处理用质量补偿（如 Testlab 的 Modification Prediction）部分修正，或者用极轻的加速度计把影响降到可忽略。

### 3.2 参考点和测点数量

- 敲击点（或响应参考点）不能落在关心模态的节点上，否则该阶模态在 FRF 里消失
- 对称结构要小心对称/反对称模态成对出现，参考点至少两个非对称位置
- 测点密度决定振型的空间分辨率：板类结构想看清第 3、4 阶弯曲振型，一个波长内至少 4–6 个测点

## 四、采集参数设置

### 4.1 触发与预触发

力通道做触发源，设置触发电平捕捉冲击开始时刻，同时配置预触发（pre-trigger）保留完整的力脉冲上升沿。

![Trigger 子表：触发电平与预触发设置](/images/impact-testing/trigger-setup.png)

*Trigger 子工作表，预触发不足会切掉力脉冲前沿（图源：Siemens）*预触发时间不足，力脉冲前沿被切掉，FRF 幅值系统性偏低。

### 4.2 分析带宽与采样

分析带宽由关心模态的最高频率决定。锤击信号是窄脉冲，需要较高的采样率保证力脉冲不失真。Simcenter 建议确认力谱平坦段覆盖整个分析带宽，抗混叠滚落只应出现在带宽顶部 20% 以内。

### 4.3 窗函数：能不加就不加

这是锤击法设置里最容易被"惯性"处理错的一环：

- **力信号：力窗（Force Window）**。脉冲后的噪声用窗置零，提高力信噪比。注意窗边界不要切到脉冲本体或采样率不足造成的振铃。
- **响应信号：理想情况不加窗**。如果测量时间足够长，响应自然衰减到零，无泄漏。Simcenter 官方的态度很明确：与其加指数窗，不如延长测量时间——指数窗会引入附加阻尼，必须事后修正，修正是潜在的误差源。
- **响应衰减不完时：指数窗（Exponential Window）** + 阻尼修正。结构阻尼大、测量时间受限制时才用。

![指数窗示意](/images/impact-testing/exponential-window.png)

*指数窗（图源：Siemens）*

::: info 判断标准
时域看响应末端：已经衰减到接近零线（幅值不足首峰的 1% 量级），不加窗；还在明显振荡，优先延长记录时间；确实延长不了，再加指数窗并记录窗参数做阻尼修正。
:::

### 4.4 平均次数

每次敲击的力度和角度总有差异，工程上每测点敲 3–5 次取平均，同时观察每次的 FRF 是否一致。Simcenter 的 Impact Setup 会自动剔除双击和过载的敲击（可设拒绝门限），但不要依赖自动剔除——双击多说明敲击手法或结构弹性有问题，先解决根源。

## 五、相干函数：数据质量的底线

FRF 测完先看相干（Coherence），再看幅值和相位：

![FRF（下）与相干函数（上）：反共振处相干下降属正常](/images/impact-testing/frf-coherence.png)

*相干函数大部分频段接近 1，仅在反共振（响应低、噪声占比高）处下降（图源：Siemens）*

- 关注频段内相干应接近 1
- 反共振点处响应幅值低、信噪比差，相干下降属正常（Simcenter 官方文档明确了这一点）
- 共振峰处相干也低，说明激励不足、双击、过载或非线性，必须重测

共振峰相干低的三种典型原因排查顺序：先看力谱是否平坦（锤头/力度问题）→ 再看时域力脉冲是否双击（手法问题）→ 最后考虑结构连接状态和非线性（预紧力不足、松动、裂纹）。

## 六、常见坑清单

1. **双击**。弹性结构回弹二次接触，力谱出现周期性深谷。对策：敲击后迅速撤离锤头（手腕"弹"出去而不是"压"上去）；刚性大的结构戴薄手套增加阻尼；软件端启用双击自动拒绝。
2. **力传感器过载**。换硬头或抡重后没重新检查量程，IEPE 力传感器饱和导致力谱失真。对策：每次改锤头/力度后重看时域力和力谱。
3. **加速度计质量加载**。小试件上贴大传感器，模态频率整体下移。对策：小试件用微型加速度计（亚克级）；必要时做质量修正或多组质量外推。
4. **敲在节点上**。某阶模态在所有 FRF 里缺席。对策：预试验阶段多敲几个位置确认参考点不在节点上。
5. **指数窗滥用**。测量时间设置随意，全靠指数窗"救"数据，附加阻尼修正不准，模态阻尼系统性偏大。对策：先加长记录时间。
6. **电缆和安装**。锤击瞬间电缆抖动产生低频噪声；加速度计安装松动（磁座吸在薄板上最典型）让高频响应失真。对策：电缆固定走线，高频测量用蜂蜡/胶栓安装。
7. **分析带宽顶部数据不可用**。力谱滚落进入顶部 20% 区域后，该段 FRF 不可信，模态拟合时直接排除。

## 七、小结

锤击法设备简单、无附加质量、激励点灵活，是 NVH 工程师日常最顺手的模态工具。它的质量下限也低——锤头不对、双击频发、指数窗乱加，得到的是一套看着像模态的废数据。实测前花十分钟确认力谱平坦度和响应衰减情况，比事后在拟合阶段纠结半天更值得。相干函数是最诚实的裁判，共振峰上的相干不过关，模态参数就没有可信度可言。
