# 锤击法模态测试实战指南

> 锤击法（Impact Testing）是试验模态分析中最常用的激励方式：一把力锤、若干加速度计，即可获得结构的频响函数。设备门槛低，但实测中锤头选择、双击、加窗、附加质量这些细节，直接决定 FRF 的质量。本文从工程实施角度梳理锤击法的关键环节和常见问题。

## 一、锤击法的原理与适用场景

锤击法的核心是用力锤对结构施加脉冲激励。锤头内置力传感器记录输入力，加速度计记录结构响应，两者在频域之比即频响函数（Frequency Response Function, FRF），再经模态拟合提取频率、阻尼和振型。

![锤击法测试设备组成：力锤、加速度计、SCADAS 采集前端与运行 Simcenter Testlab 的计算机](/images/impact-testing/equipment-impact-test.png)

*锤击法最小设备配置（图源：Siemens Simcenter Testlab 官方知识库）*

按《LMS 振动/噪声测试与分析系统 Theory and Background》理论手册的定义，一个 FRF 总是涉及两个自由度（DOF）——响应 DOF（分子）与参考 DOF（分母）：

$$
H_{ij}(f) = \frac{X_i(f)}{F_j(f)}
$$

物理意义：$H_{ij}$ 是在 $j$ 点单位激励下 $i$ 点响应的复数比值，同时包含幅值与相位信息。

实测中 FRF 并非由两帧谱直接相除得到，而是经由谱估计分三步构造：

第一步，理想情形下线性时不变系统满足 $Y(f) = H(f)\,X(f)$，两谱相除即得 $H$——前提是输入、输出谱完全无噪声，实测并不成立。

第二步，引入统计平均，用平均互功率谱与平均自功率谱之比构造 H1 估计（手册式 3-22）：

$$
\hat{H}_1(f) = \frac{S_{yx}(f)}{S_{xx}(f)}
$$

物理意义：输出端的噪声与输入不相关，多次平均后从互谱 $S_{yx}$ 中趋于消失，而分母 $S_{xx}$ 全部来自真实激励功率——H1 对输出端噪声不敏感。

第三步，确认锤击场景的适配性：力窗把脉冲之外的输入噪声置零后，输入端信噪比高，与 H1 "输入无噪声"的假设一致，因此锤击测试默认采用 H1（H1/H2/Hv 三种估计子的对比见站内《H1、H2、Hv：频响函数的三种估计子及其适用条件》一文）。

脉冲激励的频谱能量分布取决于冲击持续时间——脉宽越窄，激励频带越宽。这带来锤击法固有的优缺点：

| 特性 | 说明 |
| --- | --- |
| 激励点可移动 | 一把力锤即可逐点激励所有测点，适合移动激励方案 |
| 无附加质量 | 不与结构连接，不引入激振器柔性杆带来的附加质量和刚度 |
| 能量有限 | 单次冲击能量有限，大阻尼、大质量结构难以有效激励 |
| 敲击一致性 | 依赖操作者手法，力度、方向、点位的一致性需要练习 |
| 双击风险 | 弹性结构回弹容易造成连击，污染力谱 |

与激振器方案对比：激振器激励力可控、峰值因数（Crest Factor）低、容易获得高相干，适合密集模态和需要 MIMO 多参考的场合；但必须用柔性杆连接结构，附加质量和刚度对轻质结构、对称结构的模态影响不可忽视。北京东方所与铁科院对动车组轮对的对比试验表明，两种激励方式得到的模态频率基本一致，但参考点数量和激励位置对密集模态的识别质量影响明显——力锤方案设了八个激励参考点，在四阶密集模态处的指示比两参考点的激振器方案更清晰。

::: info 选型经验
实验室里的小型部件（支架、制动盘、电机端盖）优先锤击法；整车车身、大型焊接结构、需要纯随机激励识别非线性的场合用激振器。两者不是替代关系，很多试验规范里先用锤击做预试验定位模态，再用激振器做精细测量。
:::

## 二、锤子与锤头的选择

### 2.1 锤子规格按结构尺度选

力锤并非一把通用工具。以 Endevco 产品线为例，从 2 克锤头的 2301（电路板、小型涡轮叶片）到 5.4 公斤的 2305（重型基础、船舶、建筑结构），测力范围从 220 N 到 22 kN。基本原则：

- **小而硬的结构**（电路板、传感器部件）：小锤 + 硬头，脉宽窄、频带宽
- **中等结构**（机器零件、汽车部件、电机）：100 克级锤头，测力范围按预期冲击力选
- **大型结构**（车架、泵、基础）：大锤 + 软头，能量集中在低频

### 2.2 锤头软硬决定激励频带

锤头刚度决定冲击持续时间，进而决定激励频谱的平坦范围：

| 锤头材质 | 典型激励频带 | 适用场景 |
| --- | --- | --- |
| 软橡胶 | 0 – 数百 Hz | 大型低频结构、整车车身 |
| 中等硬度 | 数百 Hz – 2 kHz 量级 | 一般机械部件 |
| 硬塑料 | 至 5 kHz 量级 | 小型刚性部件 |
| 金属（钢/铝） | 8 kHz 以上 | 局部结构、板类高频模态 |

![Impact Setup 的 Bandwidth 子表：检查力谱平坦度](/images/impact-testing/bandwidth-worksheet.png)

*Bandwidth 子工作表——锤头软硬直接体现在力谱的平坦范围上（图源：Siemens）*

Simcenter 官方指南给出的验收标准：力谱在关注频段内应平坦，跌落不超过 3–10 dB（频谱顶部约 20% 的滚降来自采集前端抗混叠滤波器（Anti-aliasing Filter），属正常现象）。如果力谱在分析带宽内提前滚落，说明锤头太软——换硬头；反之若高频能量充足但低频激励不够、响应信噪比差，换软头把能量压回低频段。

::: warning 常见误区
硬头敲轻结构，力谱很宽、表面看符合要求，但能量摊在整个频段上，单频能量密度低，共振峰可能根本激励不起来。这时该做的是换软头集中能量，或者加大锤的质量（加装配重头），而不是加大挥锤力度——力度过大容易过载力传感器（IEPE 力传感器的饱和不像加速度计那样总能从时域一眼看出，过载会让力谱失真）。
:::

### 2.3 一个容易忽视的因素：结构刚度也影响脉宽

同样的锤头，敲薄板和敲厚锻件，冲击持续时间不同。锤头-结构接触本质上是两个弹簧串联，最终脉宽由较软的一方主导。所以换锤头后必须实测力谱确认带宽，不能凭说明书照搬。

## 三、测点布置与两种移动方案

### 3.1 移动锤 vs 移动加速度计

手册把锤击试验的实施方式分为两种：游动锤击（Roving Hammer，固定测点测响应、力锤逐点施加激励）与定点锤击（Fixed Hammer，固定点施加锤击、其余测点测量响应）：

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| 游动锤击（固定加速度计） | 传感器不动，无质量转移问题；单轴加速度计即可 | 每个测点都要敲，操作量大 |
| 定点锤击（移动加速度计） | 敲击次数少（一次激励测多点） | 传感器逐点移动改变结构质量分布，振型有质量加载偏差 |

游动锤击是目前的主流做法——传感器固定在一处（选刚度大、非节点、各阶模态都有响应的位置），锤子逐点敲。Simcenter 官方也明确指出：游动锤击不产生质量加载（mass loading）问题；而移动加速度计引入的质量影响，可以在后处理用质量补偿（如 Testlab 的 Modification Prediction）部分修正，或者用极轻的加速度计把影响降到可忽略。

两种方案在数学上等价的依据是 FRF 的互易性（Reciprocity）：

$$
H_{ij}(f) = H_{ji}(f)
$$

物理意义：在 $j$ 点激励、$i$ 点响应测得的 FRF，与对调激励与响应位置测得的结果相同，FRF 矩阵为对称阵。手册 18.4 节明确指出，这一性质是实施锤击法模态试验时测量 FRF 的前提假定（站内《FRF 互易性》一文有专门讨论）。

### 3.2 参考点和测点数量

- 敲击点（或响应参考点）不能落在关心模态的节点上，否则该阶模态在 FRF 里消失
- 对称结构要小心对称/反对称模态成对出现，参考点至少两个非对称位置
- 测点密度决定振型的空间分辨率：板类结构想看清第 3、4 阶弯曲振型，一个波长内至少 4–6 个测点

## 四、采集参数设置

### 4.1 触发与预触发

力通道做触发源，设置触发电平捕捉冲击开始时刻，同时配置预触发（Pre-trigger）保留完整的力脉冲上升沿。

![Trigger 子表：触发电平与预触发设置](/images/impact-testing/trigger-setup.png)

*Trigger 子工作表，预触发不足会切掉力脉冲前沿（图源：Siemens）*

预触发时间不足，力脉冲前沿被切掉，FRF 幅值系统性偏低。

### 4.2 分析带宽与采样

分析带宽由关心模态的最高频率决定。锤击信号是窄脉冲，需要较高的采样率保证力脉冲不失真。Simcenter 建议确认力谱平坦段覆盖整个分析带宽，抗混叠滚落只应出现在带宽顶部 20% 以内。

### 4.3 窗函数：能不加就不加

这是锤击法设置里最容易凭习惯处理错的一环。手册对系统分析（FRF 测量）的窗选择有明确清单：**力窗用于锤击法的激励（参考）信号，指数窗用于锤击激励小阻尼系统的响应信号**。

- **力信号：力窗（Force Window）**。按手册定义，力窗专用于削减激励通道的杂散噪声，在脉冲作用期间取值为 1，其余时间取值为 0：

$$
w(t) =
\begin{cases}
1, & \text{脉冲作用期间} \\
0, & \text{其余时间}
\end{cases}
$$

物理意义：力信号在脉冲结束后理论上为零，剩余部分均为测量链噪声；时域置零即频域置零，FRF 分母中的输入噪声被压掉，而脉冲本身在窗内保持原样、不引入畸变。注意窗边界不要切到脉冲本体或采样率不足造成的振铃。

![力窗定义：脉冲作用期间取 1，其余时间取 0](/images/impact-testing-guide/force-window-def.png)

*力窗的定义与作用（图源：《Theory and Background》理论手册第 23 页）*

- **响应信号：理想情况不加窗**。如果测量时间足够长，响应自然衰减到零，帧首尾无缝衔接、无泄漏，手册把这类完全衰减的瞬态信号归入矩形窗（Uniform）的适用场景。Simcenter 官方的态度很明确：与其加指数窗，不如延长测量时间——指数窗会引入附加阻尼，必须事后修正，修正是潜在的误差源。

- **响应衰减不完时：指数窗（Exponential Window）** + 阻尼修正。按手册定义，指数窗的目标是使信号在采样周期终点衰减到接近零，数学表示式为：

$$
w(t) = e^{-\beta t}
$$

物理意义：窗从 1 起按指数衰减，由衰减指数 $\beta$ 确定记录终点信号被压低到的百分率；结构阻尼大、测量时间受限制时才使用。加指数窗会在测量数据中附加人为的阻尼，随后的模态分析处理必须计入其影响（人工阻尼的定量推导见站内《锤击测试实操：力窗、指数窗与双击处理》）。

![指数窗应用于锤击响应：加窗后信号在记录末端衰减到零，避免泄漏](/images/impact-testing-guide/exp-window-applied.png)

*锤击响应信号乘以指数窗，加窗后信号在记录时间内完全衰减（图源：Siemens）*

::: info 判断标准
时域看响应末端：已经衰减到接近零线（幅值不足首峰的 1% 量级），不加窗；还在明显振荡，优先延长记录时间；确实延长不了，再加指数窗并记录窗参数做阻尼修正。
:::

### 4.4 平均次数

每次敲击的力度和角度总有差异，工程上每测点敲 3–5 次取平均，同时观察每次的 FRF 是否一致。Simcenter 的 Impact Setup 会自动剔除双击和过载的敲击（可设拒绝门限），但不要依赖自动剔除——双击多说明敲击手法或结构弹性有问题，先解决根源。

## 五、相干函数：数据质量的底线

FRF 测完先看相干（Coherence），再看幅值和相位。手册定义信号 $x$ 与 $y$ 之间的常相干（ordinary coherence）为（式 3-16）：

$$
\gamma_{xy}^2(f) = \frac{\left|S_{xy}(f)\right|^2}{S_{xx}(f)\,S_{yy}(f)}
$$

分两步理解这个定义：

第一步，看分子：$|S_{xy}|^2$ 是输入输出之间线性相关部分的功率——输出端与输入不相关的噪声在互谱平均中趋于零，进不了分子。

第二步，看分母：$S_{xx}\,S_{yy}$ 是两端总功率的乘积，规约了量纲。相干因此表示输出能量中由输入线性引起的比例，取值范围 $[0, 1]$：接近 1 表明输出几乎完全由输入引起，FRF 测量结果可信；接近 0 表明存在未测量的其它输入、严重噪声、明显非线性或时延。

![FRF（下）与相干函数（上）：反共振处相干下降属正常](/images/impact-testing/frf-coherence.png)

*相干函数大部分频段接近 1，仅在反共振（响应低、噪声占比高）处下降（图源：Siemens）*

- 关注频段内相干应接近 1
- 反共振点处响应幅值低、信噪比差，相干下降属正常（Simcenter 官方文档明确了这一点）
- 共振峰处相干也低，说明激励不足、双击、过载或非线性，必须重测

共振峰相干低的三种典型原因排查顺序：先看力谱是否平坦（锤头/力度问题）→ 再看时域力脉冲是否双击（手法问题）→ 最后考虑结构连接状态和非线性（预紧力不足、松动、裂纹）。

## 六、常见问题清单

1. **双击**。弹性结构回弹二次接触，力谱出现周期性深谷。对策：敲击后迅速回撤锤头（短促敲击而非按压）；刚性大的结构戴薄手套增加阻尼；软件端启用双击自动拒绝。
2. **力传感器过载**。换硬头或加大力度后没重新检查量程，IEPE 力传感器饱和导致力谱失真。对策：每次改锤头/力度后重看时域力和力谱。
3. **加速度计质量加载**。小试件上贴大传感器，模态频率整体下移。对策：小试件用微型加速度计（亚克级）；必要时做质量修正或多组质量外推。
4. **敲在节点上**。某阶模态在所有 FRF 里缺席。对策：预试验阶段多敲几个位置确认参考点不在节点上。
5. **指数窗滥用**。测量时间设置随意，依赖指数窗补偿数据，附加阻尼修正不准，模态阻尼系统性偏大。对策：先加长记录时间。
6. **电缆和安装**。锤击瞬间电缆抖动产生低频噪声；加速度计安装松动（磁座吸在薄板上最典型）让高频响应失真。对策：电缆固定走线，高频测量用蜂蜡/胶栓安装。
7. **分析带宽顶部数据不可用**。力谱滚落进入顶部 20% 区域后，该段 FRF 不可信，模态拟合时直接排除。

## 七、小结

锤击法设备简单、无附加质量、激励点灵活，是 NVH 工程师常用的模态测试手段；其数据质量也高度依赖操作细节——锤头不对、双击频发、指数窗使用不当，得到的就是一套无效数据。实测前花十分钟确认力谱平坦度和响应衰减情况，收益高于事后在拟合阶段的反复调整。相干函数是 FRF 数据质量最直接的定量指标：共振峰上的相干不达标，模态参数即不可信。
