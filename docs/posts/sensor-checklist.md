# 传感器与采样配置检查

> NVH 测试的数据质量取决于传感器选型和采样配置。本文整理一份完整的现场检查清单，涵盖麦克风、加速度计、采样率和抗混叠滤波，供测试前逐项确认。

## 一、声学传感器（麦克风）

### 1.1 选型检查

- [ ] 根据测试场景选择麦克风类型（自由场 / 随机入射 / 压力型）
- [ ] 麦克风动态范围覆盖预期声压级（留 10 dB 余量）
- [ ] 频率响应范围覆盖关注频段（低频 < 20 Hz 或高频 > 20 kHz 需确认）
- [ ] 灵敏度（mV/Pa）已校准并在数据表中记录
- [ ] ICP/外部极化供电方式与采集前端匹配

::: tip 麦克风类型速选
- **自由场**：消声室、半消声室、开阔空间测量
- **随机入射**：车内、舱室等混响环境
- **压力型**：管道、耦合腔、近场测量
:::

### 1.2 现场校准

- [ ] 使用声校准器（活塞发声器 / 声级校准器）进行现场校准
- [ ] 校准频率和声压级已记录（如 1 kHz / 94 dB 或 250 Hz / 114 dB）
- [ ] 各通道灵敏度偏差 < 0.5 dB

## 二、振动传感器（加速度计）

### 2.1 选型与安装

- [ ] 加速度计频响范围覆盖测试频段
- [ ] 重量足够轻，避免负载效应（质量比 > 10:1 原则）
- [ ] 安装方式确定（螺柱 > 蜂蜡 > 磁座 > 手持）
- [ ] 安装面平整、清洁，确认无松动

::: warning 安装谐振频率
不同安装方式会改变加速度计的有效谐振频率：

| 安装方式 | 典型谐振频率 |
| --- | --- |
| 螺柱安装 | ~30 kHz |
| 蜂蜡 | ~10 kHz |
| 磁座 | ~3 kHz |
| 手持探针 | ~1 kHz |

安装谐振频率必须远高于测试频段上限，否则数据失真。
:::

- [ ] 确认三轴加速度计的 X/Y/Z 方向定义与测试坐标系一致
- [ ] 电缆固定，避免电缆抖动引入摩擦电噪声（tri-axial 线缆尤其注意）

## 三、采样配置

### 3.1 采样率

::: danger 奈奎斯特定理
采样率必须 **≥ 2 倍** 关注的最高频率。实际工程中建议采样率 ≥ 2.56× 分析上限频率，为抗混叠滤波器留过渡带。
:::

- [ ] 采样率设置确认（常见 2048 / 4096 / 8192 / 51200 Hz）
- [ ] 抗混叠模拟滤波器已启用
- [ ] 采样率/分析带宽（analysis bandwidth）关系明确

| 采样率 (Hz) | 理论上限 (Hz) | 建议分析上限 (Hz) |
| --- | --- | --- |
| 2048 | 1024 | 800 |
| 4096 | 2048 | 1600 |
| 8192 | 4096 | 3200 |
| 51200 | 25600 | 20000 |

### 3.2 采样精度与量程

- [ ] ADC 分辨率 ≥ 16 bit（高精度场景建议 24 bit）
- [ ] 输入量程设置合理，避免削波（clipping）
- [ ] 信噪比 SNR 已确认（参考传感器和前端指标）

::: tip 量程设置
信号峰值应占满量程的 **60%–90%**。过低会浪费分辨率，过高有削波风险。带间隙的测试建议用自动量程或分段录制。
:::

## 四、触发与同步

### 4.1 触发配置

- [ ] 触发方式确认（自由运行 / 边沿触发 / 转速触发）
- [ ] 触发电平和斜率设置正确
- [ ] 触发前数据（pre-trigger）保留足够（建议 ≥ 0.5 s）

### 4.2 多通道同步

- [ ] 所有通道共享同一时钟源（共用采样时钟）
- [ ] 转速通道（tacho）与声振通道同步采集
- [ ] 通道间相位偏差已确认（相位敏感分析必需）

::: warning 多前端同步
使用多台采集设备时，必须确认硬件同步方式：

<details>
<summary>常见同步方案</summary>

- **菊花链同步（Daisy-chain）**：一台主设备提供时钟，从设备串联
- **GPS 同步**：户外或分布式测量，精度 ~1 μs
- **IEEE 1588 (PTP)**：网络化采集系统，精度 ~1 μs
- **专用同步线缆**：厂商专用协议（如 HBK / HEAD / NI）

</details>
:::

## 五、转速信号（阶次分析必备）

- [ ] 转速传感器类型确认（光电 / 磁电 / 编码器 / 反射贴片）
- [ ] 每转脉冲数（PPR）记录，用于阶次分析精度
- [ ] 转速信号无丢脉冲现象（高速时尤其检查）

::: danger 阶次分析基础
阶次分析精度严重依赖转速信号质量：

- PPR 越高 → 阶次分辨力越高
- 丢脉冲 → 阶次计算错误，整段数据报废
- 低 PPR + 高加减速 → 阶次严重涂抹

**建议**：每转至少 10 个脉冲（PPR ≥ 10），高精度阶次分析建议 PPR ≥ 60。
:::

## 六、测试前最终确认

### 6.1 系统检查

- [ ] 所有通道信号正常，无异常噪声 / 50 Hz 工频干扰
- [ ] 接地回路已排查（接地环路哼声 ~50/60 Hz）
- [ ] 室温、湿度记录（传感器灵敏度受温度影响）
- [ ] 备用电池 / 电源充足
- [ ] 存储空间足够（高速采样数据量大）

### 6.2 环境记录

- [ ] 测试对象状态（工况、转速、负载）记录
- [ ] 背景噪声水平测量并记录
- [ ] 现场照片 / 安装位置图留存

## 七、数据质量快速验证

::: tip 验证三步法
采集后立即进行以下检查：

1. **时域检查**：信号是否削波？是否有周期性干扰？DC 偏置是否正常？
2. **频域检查**：频谱是否有异常尖峰（如 50 Hz 工频）？信噪比是否合理？
3. **通道一致性**：同类传感器信号是否合理一致？相关通道相位是否符合预期？
:::
