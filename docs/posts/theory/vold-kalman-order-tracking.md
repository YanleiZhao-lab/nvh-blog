# Vold-Kalman 阶次提取：用正弦约束从噪声里拎出阶次

> 变速箱台架升速扫频，colormap 上 21.5 阶那条线又细又亮，可旁边还挤着 22 阶和调制边带，阶次切线一拉，三条线糊成一团。Vold-Kalman 滤波器不做"切谱线"这件事，它反过来：假设待提取的阶次在每一段短时间里就是一根干净正弦，把这个结构当约束、跟测量数据做加权最小二乘，直接解出阶次的时域波形，幅值和相位都是副产品。这篇从正弦的二阶差分方程推起，讲清结构方程与数据方程怎么博弈、谐波置信因子 HC 怎么定带宽，用 numpy 复现整套求解，最后给工程上的参数选择判据。

## 一、为什么切谱线不够，要"解"出阶次

阶次分析的传统路子是重采样加 FFT：把时域信号按转角重采样，阶次就变成离散谱线，再从谱上把目标阶次的谱线切出来。这套流程在转速平稳、阶次间隔宽时很好用，但有两个天然短板。

一是分辨率受观察时间限制。阶次分辨率等于平均循环数的倒数，想把间隔 0.5 阶的两根线分开，平均循环数得堆到 2 个以上，转速快速变化时根本没这么多循环可平均。二是切谱线拿到的是"某段平均时间内"的幅值，阶次幅值在转速瞬变过程中的起伏细节全被抹平。

卡尔曼式阶次跟踪换了思路：既然目标阶次在任意短的时间段内都近似一根正弦波，那就**为每个采样时刻解一个方程**，让解出来的时域序列 $x(n)$ 既像一根正弦（结构约束），又尽量贴近测量数据 $y(n)$（数据约束）。两个约束各让一步，加权取平衡。这样得到的是阶次的完整时域波形，分辨率不再受观察时间制约。手册给出的能力清单包括：从恒采样率信号中以任意分数阶次分辨率跟踪、少量采样点即可得到良好阶次谱分辨率、旋转速率实际上不受限制、每个采样点都产生阶次值、无相位失真。

::: info 核心概念
- **结构方程（Structural Equation）**：规定待跟踪波形形态的约束，正弦波对应二阶差分方程 $x(n) - c \cdot x(n-1) + x(n-2) = \varepsilon(n)$，其中 $c = 2\cos(2\pi f/f_s)$
- **数据方程（Data Equation）**：测量信号 $y(n) = x(n) + \eta(n)$，$\eta$ 包含噪声和其它频率的周期分量
- **谐波置信因子 HC（Harmonic Confidence）**：结构方程与数据方程的置信度之比，HC 高则带宽窄、分辨率高，HC 低则带宽宽、幅值收敛快
- **Vold-Kalman 滤波器（VKF）**：把两组方程叠成超定方程组、加权最小二乘求解的阶次提取方法，对非平稳转速自适应
:::

## 二、推导：从正弦的差分方程到最小二乘

### 第一步：正弦波满足什么方程

设目标阶次的瞬时频率为 $f$（随转速变化，由 tacho 通道逐点给出），采样率 $f_s$。一段纯净正弦 $x(t) = A\sin(2\pi f t + \varphi)$ 以间隔 $\Delta t = 1/f_s$ 采样后，相邻三个点之间有一个精确的递推关系。用三角恒等式：$x(n)$ 与 $x(n-2)$ 都是 $x(n-1)$ 的"隔一步回声"，三者线性组合可以消去幅值 $A$ 和初相 $\varphi$，得到

$$x(n) - c \cdot x(n-1) + x(n-2) = 0, \quad c = 2\cos(2\pi f/f_s)$$

物理意义：知道一根正弦最近两个采样点，第三个点就被完全锁定，不需要知道幅值和相位。这正是"结构"二字的含义：不管这根正弦多大多小、相位如何，只要频率是 $f$，这个三点头递推就严格成立。频率 $f$ 逐点可变（跟着 rpm 走），所以系数也是逐点的 $c(n)$。

### 第二步：松开一口，加非齐次项

实测信号的频率、幅值、相位都会缓慢漂移，严格等式太硬。引入一个确定但未知的偏离项 $\varepsilon(n)$，方程变成 $x(n) - c(n)x(n-1) + x(n-2) = \varepsilon(n)$，它的标准差 $S_\varepsilon$ 刻画"允许波形偏离理想正弦多远"。同时测量端写成 $y(n) = x(n) + \eta(n)$，$\eta$ 是噪声加别的周期分量，标准差 $S_\eta$。

### 第三步：叠起来，加权求解

对每个时刻 $n$，两个方程都只涉及 $x(n)$、$x(n-1)$、$x(n-2)$ 三个未知数。把全部时刻的方程竖着摞起来，得到一个超定方程组：结构方程管"波形得像正弦"，数据方程管"数值得贴近测量"。两组误差不能直接相加，量纲和置信度都不同，于是用标准差之比定义计权因子 $r(n) = S_\varepsilon / S_\eta$，方程统一成加权形式。对所有时间观察点列出方程后，用标准最小二乘求解。

![结构方程与数据方程叠加为超定方程组的最小二乘公式](/images/vold-kalman-order-tracking/least-squares-eq.png)

*（图源：Simcenter Testing Knowledge Base）*

![计权因子 r(n) 的定义：结构方程与数据方程置信度之比](/images/vold-kalman-order-tracking/weighting-eq.png)

*（图源：Simcenter Testing Knowledge Base）*

写成矩阵形式更直观。设 $L$ 为二阶差分算子矩阵（每行只有三个非零元素 1、$-c(n)$、1），则整个问题等价于最小化

$$J = HC \cdot \|Lx\|^2 + \|x - y\|^2$$

对 $x$ 求导置零，解出

$$x = (I + HC \cdot L^T L)^{-1} y$$

一行线性代数，阶次的时域波形就出来了。幅值包络用滑动 RMS 或 Hilbert 变换从 $x$ 里取，相位就是 $x$ 的瞬时相位。这就是"无相位失真"的来源：解的是波形本身，不是谱线幅值。

::: warning 两个前提别丢
- 被跟踪信号的结构必须精确已知：频率对应阶次、采样率恒定，rpm 时迹必须准。tacho 不准，$c(n)$ 就是错的，滤波器会"忠实地"跟踪错的目标。手册强调转速通道要与振动通道同采样率记录，必要时先做重采样平滑
- 结构方程假定频率在三个连续采样点内近似不变。转速变化只要小于滤波器带宽就没问题；带宽下限是观察时间 $T$ 的倒数，旋转速率上限为 $F_s/2T$。按手册算例，75 Hz/s 变率的燃气涡轮 5 秒降速只需 750 Hz 采样率，实际完全不构成限制
:::

## 三、HC 怎么拧：带宽与收敛的跷跷板

计权因子 $r(n)$ 的倒数就是谐波置信因子 HC。HC 高，等于宣称"我信结构方程、测量数据噪声大"，滤波器带宽变窄、频率分辨力变高，代价是幅值估计收敛变慢；HC 低则相反，带宽宽、收敛快、但挨得近的阶次会互相渗透。

![三种谐波置信因子下的滤波器带宽特性对比](/images/vold-kalman-order-tracking/hc-bandwidth.png)

*（图源：Simcenter Testing Knowledge Base）*

还有一个容易被忽略的细节：计权因子逐点可变，意味着**带宽可以定义为频率或阶次的函数**。如果按频率定义带宽，低转速时同一 Hz 带宽会罩住好几个阶次；按阶次定义带宽，各转速下的滤波范围相对阶次轴恒定。手册的带宽特性图直观展示了两种定义的差别。

![滤波带宽定义为频率/幅值函数时的行为差异](/images/vold-kalman-order-tracking/bandwidth-vs-order.png)

*（图源：Simcenter Testing Knowledge Base）*

用 numpy 把这套求解复现一遍，看 HC 对带宽和收敛的实际影响。40 Hz 目标正弦，干扰是 55 Hz 邻频。先看带宽：对每个候选频率的复指数求滤波器增益，相当于扫频测滤波器的频响。

```python
import numpy as np

fs, N = 1000.0, 4000                    # 采样率与数据长度
f0 = 40.0                               # 目标频率（对应某阶次）
c = 2*np.cos(2*np.pi*f0/fs)             # 结构方程系数
L = np.zeros((N-2, N))                  # 二阶差分算子：每行 1, -c, 1
L[:, 2:]  += np.eye(N-2)
L[:, 1:-1] -= c*np.eye(N-2)
L[:, :-2] += np.eye(N-2)
A = L.T @ L

for hc in [30, 300, 3000]:
    M = np.linalg.inv(np.eye(N) + hc*A) # 滤波器矩阵 (I + HC*L'L)^-1
    gains = []
    for f in [40, 45, 50, 55]:          # 扫频：看邻频被压到多低
        n = np.arange(N)
        y = np.exp(2j*np.pi*f*n/fs)     # 复指数激励
        g = np.abs(M @ y)[N//2:].mean() # 稳态增益
        gains.append(f"{f}Hz:{g:.2f}")
    print(f"HC={hc:5d}  增益 " + "  ".join(gains))
```

运行结果要点：HC=30 时 55 Hz 增益 0.92，邻频几乎原样通过；HC=300 降到 0.52；HC=3000 压到 0.10。带宽随 HC 收窄的效果一目了然，HC 每放大一个量级，阻带抑制跟着上一个台阶。

再看收敛速度。目标正弦幅值在 3 秒处从 1.0 阶跃到 0.2，看提取出的包络多久跟上。

```python
import numpy as np

fs, N = 1000.0, 6000
f0 = 40.0
c = 2*np.cos(2*np.pi*f0/fs)
L = np.zeros((N-2, N))
L[:, 2:]  += np.eye(N-2)
L[:, 1:-1] -= c*np.eye(N-2)
L[:, :-2] += np.eye(N-2)
A = L.T @ L

n = np.arange(N)/fs
amp = np.where(n < 3.0, 1.0, 0.2)               # 幅值阶跃
target = amp*np.sin(2*np.pi*f0*n)
y = target + 0.05*np.random.default_rng(3).standard_normal(N)

for hc in [30, 300, 3000]:
    x = np.linalg.solve(np.eye(N) + hc*A, y)    # VKF 求解
    e = np.convolve(np.abs(x), np.ones(20)/20, 'same')  # 20ms 包络
    idx = np.where((n > 3.0)*(np.abs(e-0.2) < 0.04))[0]
    print(f"HC={hc:5d}  包络收敛耗时 {(idx[0]/fs-3.0)*1000:.0f} ms")
```

运行结果要点：HC=30 收敛 6 ms，HC=300 收敛 7 ms，HC=3000 拖到 19 ms。带宽窄了，阶跃响应就钝，这正是手册说的"高 HC 以幅值收敛时间为代价"。

两个演示合成一张决策表：

| 场景 | HC 取向 | 带宽 | 理由 |
| --- | --- | --- | --- |
| **邻阶密集**（变速箱多对齿轮啮合阶次挤在一起） | 高 | 窄 | 先保证把邻阶分开，收敛慢点无所谓，稳态工况幅值总会到位 |
| **转速快变**（电机快速升降速、tip-in 冲击） | 中低 | 宽 | 阶次幅值本身瞬变，滤波器跟不上会把真实起伏抹平 |
| **阶次幅值突变**（离合器结合瞬间的冲击） | 低 | 宽 | 要的是事件发生时刻的幅值，宁可渗点邻频也要跟得上 |
| **稳态精测**（定转速对标 CAE 幅值） | 高 | 窄 | 时间充足，分辨率优先，把邻频泄漏压到最低再读数 |

::: tip 参数怎么起步
- HC 先按"目标阶次与最近邻阶的间隔"反推带宽：手册指出对两个间隔密集正弦波的分辨能力与总观察时间成反比，观察时间应取最小频率间隔的倒数
- 拿不准时先跑一版 HC 中等的，看提取波形与原始数据的残差：残差里若还能看到目标阶次的影子，说明带宽太窄锁死了结构；残差里若邻频还很浓，说明带宽太宽
- 带宽定义优先按阶次而非频率，保证全转速范围滤波行为一致
:::

## 四、和重采样法怎么选

Vold-Kalman 与角域重采样 FFT 不是替代关系，是分工。

| 维度 | 重采样 + FFT | Vold-Kalman |
| --- | --- | --- |
| **输出** | 阶次谱、切线（平均结果） | 阶次时域波形（逐点） |
| **分辨率** | 1/平均循环数 | 不受观察时间限制，可达分数阶次 |
| **瞬变跟踪** | 快速升降速会拖影 | 逐点自适应，无相位失真 |
| **计算代价** | 低，一遍重采样加 FFT | 高，逐阶次解大型方程组 |
| **多阶次** | 一次得到全部阶次 | 一次解一个阶次，要几条线解几次 |
| **前提** | tacho 质量决定一切 | 同样依赖 tacho，且要求频率模型精确 |

规律很简单：要全谱概览、要 colormap、要看几十条阶次线，用重采样 FFT；只要其中一两条关键阶次、要看它在瞬态过程中的幅值相位细节，上 Vold-Kalman。实际项目里常见的组合是 colormap 用重采样法定位问题阶次，锁定后再用 VKF 把这条阶次"解"出来做幅值定量和源识别，配合声阵列做阶次域 beamforming 也是它的常见去处。

## 五、小结

阶次提取的本质，是在"波形该长什么样"和"测到了什么"之间做加权妥协。结构方程把正弦形态写成三点头递推，数据方程拉住解不让它离测量太远，HC 决定谁的话语权大。工程判断三条：邻阶间隔决定带宽下限，幅值瞬变剧烈程度决定带宽上限，两者打架时先保分辨。幅值收敛慢可以等，邻阶渗进去，读出来的数就是错的。
