# 圆拟合法：为什么最老的SDOF模态估计至今仍是精度标杆

> 模态测试做完，FRF 共振峰上量阻尼——多数人只会 3dB 带宽法，很少有人还记得复平面里那个圆。1947 年 Kennedy 和 Pancu 提出的圆拟合法（Circle Fit）是所有 SDOF 参数估计里精度最高的一种（LMS 理论手册原话："在所有单自由度技术中，圆拟合法给出最精确的估计"）。这篇从单模态 FRF 的复平面轨迹推导出"为什么是圆"，给出频率、阻尼、留数三个参数全部从圆上读出来的完整链条，并用数值实验展示它把峰值法偏掉 0.3 Hz 的频率精确拉回真值。

## 一、从一条 FRF 到复平面上一个圆

锤击或激振器扫频得到频响函数（FRF）后，每个频率点 $f_i$ 对应一个复数 $H(i\omega_i)$。常规做法看幅频曲线的峰，圆拟合法换一个视角：把所有点画在复平面上（横轴实部、纵轴虚部），共振区附近的点会规整地排成一个圆弧。

这不是巧合，是数学结构决定的。单自由度（SDOF）假设下，共振区附近的 FRF 可写成（LMS 理论手册式 15-37）：

$$H(i\omega) \approx \frac{A}{i\omega - \lambda} + C$$

其中 $A$ 是该阶模态的**复留数**（含幅值和相位），$\lambda = -\sigma + i\omega_d$ 是极点（$\sigma$ 为阻尼因子，$\omega_d$ 为有阻尼固有频率），$C$ 是复常数——它把分析频带外的高阶、低阶模态影响近似成一个不变的背景，手册里对应上残余项（残余刚度）与下残余项（残余质量）之和。

推导的关键一步是分式变形。令 $s = i\omega - \lambda$ 的实部为 $u = \sigma$（固定），虚部 $v = \omega + \omega_d$（随频率扫过共振点由负变正），则：

$$\frac{A}{i\omega-\lambda} = \frac{A}{u + iv} = \frac{A(u - iv)}{u^2 + v^2}$$

把它拆成实部和虚部之后有一个经典结论：$(H_\mathrm{re})^2 + (H_\mathrm{im} - \frac{|A|}{4\sigma})^2 = (\frac{|A|}{4\sigma})^2$ ——这是以 $(0, \frac{|A|}{4\sigma})$ 为圆心、$\frac{|A|}{4\sigma}$ 为半径的圆方程（$C$ 只是把整个圆在复平面里平移旋转）。所以圆的**直径 $d = \frac{|A|}{2\sigma}$**，留数的模直接锁在圆的大小上，阻尼因子锁在圆被"扫过的速度"上。

::: info 核心概念
- **圆拟合法（Circle Fit）**：在复平面上对共振区数据点拟合圆，从圆的几何参数反推模态频率、阻尼、留数的 SDOF 估计方法
- **留数（Residue）$A$**：部分分式里每个极点前的复系数，等于模态振型系数乘积再乘比例常数，是有量纲的绝对幅值
- **残余项 $C$**：带外模态在窄带内的近似贡献，圆拟合里体现为复平面上的平移，不影响圆的半径
:::

## 二、三个模态参数全部从圆上读出来

圆拟出来之后，频率、阻尼、留数各有各的读法，每一步都有明确的几何—物理对应。

**频率：最大角度间距法。** 把相邻两个频率点的数据点连到圆心，得到一段圆心角。扫频经过共振点时，频率走一小步、复平面上的点却沿着圆跑一大截——圆心角变化率最大的那对点，中间夹的就是固有频率。这比在幅频谱上找最高谱线精细得多：谱线是离散的，真实峰很可能落在两条谱线之间，而圆心角间距用的是整段圆弧的形状信息，天然带插值能力。

**阻尼：圆心角半角公式。** 在圆上取共振点两侧对称的两个点，它们对圆心的张角为 $\theta_1$、$\theta_2$。从单模态分式的虚实部关系可以推出几何关系：

$$\tan\frac{\theta_1}{2} = \frac{\omega - \omega_d}{\sigma}, \qquad \tan\frac{\theta_2}{2} = \frac{\omega_d - \omega}{\sigma}$$

物理意义很直观：张角一半的正切，等于该点偏离共振的频率量除以阻尼因子。阻尼越小圆被"匀速扫过"得越慢（同样带宽内张角越小），阻尼大则频率稍微偏一点、点就在圆上跑很远。两式相加消去 $\omega_d$：

$$\sigma = \frac{\omega_2 - \omega_1}{\tan(\theta_1/2) + \tan(\theta_2/2)}$$

于是 $\zeta = \sigma / \omega_n$。注意这里用的 $\omega_1$、$\omega_2$ 是两个数据点自身的频率，不需要它们恰好落在半功率点上——3dB 法必须找到幅值恰降 3 dB 的位置，谱线离散时这个位置根本不存在；圆拟合随便取两个对称点，公式自带精确换算。

**留数：直径乘阻尼因子。** $|A| = d \cdot \sigma$，$d$ 是拟合圆直径，$\sigma$ 是刚算出的阻尼因子。留数的相位角对应圆在复平面里的朝向。有了每个测点的留数，除以比例常数后就是模态振型系数——一整套模态模型齐了。

::: warning 工程注意
圆拟合法的两个失效前提都写在 SDOF 假设里：
- **振型节点附近**：留数趋零，圆缩成一个点，手册明确指出此时"仍可能产生大的误差"，这是原理性盲区不是操作失误
- **模态耦合**：分析频带内两阶模态分不开时，复平面轨迹是两个圆的叠加而非一个圆，拟合残差会明显增大——先看轨迹像不像圆再谈拟合
:::

## 三、Python 演示：36 条谱线，圆拟合把 0.3 Hz 的偏差拉回来

造一组教科书式的单模态窄带 FRF：固有频率 30.2 Hz、阻尼比 2.5%、留数带相位（0.8-0.6j）、残余项带相位（0.15+0.10j），36 条谱线覆盖 28.5~32 Hz。用代数法拟合圆（$x^2+y^2 = ax + by + c$ 线性最小二乘），再按上面三步读参数：

```python
import numpy as np

fn, zt = 30.2, 0.025                       # 真值：固有频率 Hz、阻尼比
wn = 2*np.pi*fn
lam = -zt*wn + 1j*wn*np.sqrt(1-zt**2)      # 极点 λ = -σ + jωd
A, C = 0.8-0.6j, 0.15+0.10j                # 复留数、带外残余项（复常数）
f = np.linspace(28.5, 32.0, 36)            # 窄带内 36 条谱线
H = A/(2j*np.pi*f - lam) + C               # 手册式(15-37)

print(f"幅值谱峰点频率 = {f[np.abs(H).argmax()]:.2f} Hz（真值 {fn}）")

# 代数圆拟合：x²+y² = a·x + b·y + c 线性最小二乘
x, y = H.real, H.imag
M = np.c_[x, y, np.ones_like(x)]
a, b, c = np.linalg.lstsq(M, x**2+y**2, rcond=None)[0]
cx, cy = a/2, b/2                          # 圆心 (a/2, b/2)
R = np.sqrt(c + cx**2 + cy**2)             # 半径

# 频率：相邻谱线对圆心的张角最大处
th = np.arctan2(y-cy, x-cx)
dth = np.abs(np.diff(np.unwrap(th)))
k = dth.argmax() + 1
print(f"最大角度间距 fn = {f[k]:.3f} Hz")

# 阻尼：两点法 tan(θ/2)=|ω-ωd|/σ，两式相加消去 ωd
i1, i2 = k-12, k+12
t1, t2 = abs(th[i1]-th[k]), abs(th[k]-th[i2])
sig = 2*np.pi*(f[i2]-f[i1]) / (np.tan(t1/2)+np.tan(t2/2))
print(f"圆拟合 ζ = {sig/wn:.4f}（真值 {zt}）")

# 留数幅值 = 直径×阻尼因子
print(f"留数 |A| = {2*R*sig:.3f}（真值 {abs(A):.3f}）")
```

实测输出：

```
幅值谱峰点频率 = 29.90 Hz（真值 30.2）
最大角度间距 fn = 30.200 Hz
圆拟合 ζ = 0.0250（真值 0.025）
留数 |A| = 1.000（真值 1.000）
```

最值得看的数字是第一行和第二行的对比：幅值谱最高谱线在 29.90 Hz，偏离真值 0.3 Hz——因为真实峰恰好落在两条谱线之间；而最大角度间距法给出 **30.200 Hz**，四位数全对。阻尼 0.0250、留数 1.000 同样精确命中。这就是手册敢说它"最精确"的底气：峰值法受谱线离散化限制，圆拟合利用的是整段圆弧的几何信息。

## 四、什么时候圆会断：密频模态的数值实验

圆拟合法的软肋是 SDOF 假设本身。在窄带里再叠一阶模态，复平面轨迹立刻变形——变形程度取决于两阶模态留数的相对符号和频率间隔。用同样的拟合代码量化一下：

```python
import numpy as np

# 密频双模态：间隔小于一个半功率带宽（1.50 Hz）
fn1, zt = 30.0, 0.025
w1 = 2*np.pi*fn1; BW = 2*zt*w1             # 半功率带宽（rad/s）
for A2 in (0.7, -0.7):
    for df in (0.54, 0.30):
        fn2 = fn1 + df
        w2 = 2*np.pi*fn2
        f = np.linspace(fn1-0.8, fn2+0.8, 35)
        w = 2*np.pi*f
        lam1 = -zt*w1 + 1j*w1; lam2 = -zt*w2 + 1j*w2
        H = 1.0/(1j*w-lam1) + A2/(1j*w-lam2)   # 双模态叠加

        x, y = H.real, H.imag
        a, b, c = np.linalg.lstsq(
            np.c_[x, y, np.ones_like(x)], x**2+y**2, rcond=None)[0]
        cx, cy = a/2, b/2
        R = np.sqrt(c + cx**2 + cy**2)
        resid = np.abs(np.hypot(x-cx, y-cy) - R).max()
        print(f"A2={A2:+.1f} 间隔{df:.2f}Hz"
              f"({df/(BW/2/np.pi):.2f}倍带宽): "
              f"径向残差 {100*resid/R:5.1f}% 半径")
```

实测输出：

```
A2=+0.7 间隔0.54Hz(0.36倍带宽): 径向残差   2.2% 半径
A2=+0.7 间隔0.30Hz(0.20倍带宽): 径向残差   0.6% 半径
A2=-0.7 间隔0.54Hz(0.36倍带宽): 径向残差  12.9% 半径
A2=-0.7 间隔0.30Hz(0.20倍带宽): 径向残差  10.3% 半径
```

两个数字对比出一条实用判据：留数同号（对应同一测点上两阶模态同相参与，如车身边梁的两阶同向弯曲）时，即使模态间隔只有 0.36 倍带宽，残差也不过 2.2%，圆拟合仍然可信；留数反号（节点两侧测点常见）时残差直接跳到 12.9%，圆已经明显变形，硬拟出来的频率和阻尼都不可信。整车车身的一阶扭转与一阶弯曲有时只差几 Hz，测点布在它们的振型反相区就会踩中这个坑。

顺带说 CMIF（复模态指示函数）在这里的救场角色：它对每条谱线的 FRF 矩阵做奇异值分解，密频模态在 CMIF 曲线上会分开成两个峰。手册给出一条成熟的组合拳——先用 CMIF 定模态个数和频率，对每个模态生成解耦的**增强 FRF**（Enhanced FRF），再对增强 FRF 做圆拟合拿精确的频率、阻尼和比例因子。老方法不是被淘汰了，是被嫁接到新框架里继续当精度担当。

## 五、方法选型：圆拟合在参数估计家族里的位置

LMS 理论手册把参数估计方法按"自由度数—域—估计策略—输入数"四个维度分类，圆拟合的定位是频域、局部、单输入。对照着看：

| 方法 | 可识别参数 | 自由度 | 域 | 估计策略 | 输入 |
| --- | --- | --- | --- | --- | --- |
| **峰检索** | 频率、阻尼 | 单 | 频域 | 局部 | 单 |
| **模态检出** | 模态振型 | 单 | 频域 | 局部 | 单 |
| **圆拟合法** | 频率、阻尼、模态振型 | 单 | 频域 | 局部 | 单 |
| **CMIF** | 频率、阻尼、模态振型 | 多 | 频域 | 整体 | 单或多 |
| **LSCE** | 频率、阻尼、模态参预因子 | 多 | 时域 | 整体 | 单或多 |
| **FDPI** | 频率、阻尼、模态参预因子 | 多 | 频域 | 整体 | 单或多 |

时域 MDOF 法（LSCE 一族）是当前模态分析的标准工具，但手册同时点明它的边界：强阻尼系统（阻尼比大于 5%，如全内饰车）不太适合；频域 MDOF 法（FDPI）恰好互补，弱阻尼（低于 3%）反而是它的弱项。SDOF 家族的圆拟合胜在快、直观、精度高，是检查试验设置（传感器标定、节点标记、测点布置）的第一道工具。

::: tip 选择原则
- **首轮筛查 / 单篇 FRF 快速读参数**：圆拟合，速度快精度高，且一次拿全频率、阻尼、振型三个参数
- **密频、耦合模态**：CMIF 定频率 → 增强 FRF → 圆拟合精修；直接对原始 FRF 硬拟会踩残差 10% 级别的坑
- **强阻尼系统（ζ > 5%，内饰车身）**：时域 MDOF 法让位，选频域直接识别（FDPI）
- **测点落在振型节点附近**：换测点或换方法，圆缩点后任何 SDOF 方法都无能为力
:::

## 六、小结

圆拟合法七十余年不倒，靠的不是情怀，是三件实事：频率用最大角度间距定位，绕开了谱线离散化对峰值法的硬限制（数值实验里 0.3 Hz 的偏差被精确修正）；阻尼用张角半角公式，不依赖半功率点的存在性；留数直接等于直径乘阻尼因子，几何量与物理量一一对应。用之前先看复平面轨迹像不像一段圆弧——像，它就是手头最准的 SDOF 工具；不像，说明 SDOF 前提已破，转 CMIF 增强 FRF 或 MDOF 整体估计。
