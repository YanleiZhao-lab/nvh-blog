# 模态振型验证三指标：MPC、MPD 与 MOV

> 稳定图上锁定的极点，频率与阻尼均在容差带内，仍不足以确认振型的物理真实性——测点相位散乱、节线模糊的"振型"在工程数据中并不少见。判断一条振型是否为物理模态，除目视检查动画外，Simcenter Testing 理论手册第十八章给出一组量化指标：MPC（模态相位共线性）检验振型系数实部与虚部是否共线，MPD（平均相位偏差）给出相位散布的角度值，MOV（模态超复性值）以"附加质量必使固有频率下降"这一理论特性对振型评分。三个指标各度量振型的一个侧面，合起来构成振型的验证依据。

## 一、为什么"正则模态"是评判的起点

弱阻尼结构或比例阻尼结构的模态振型理论上是完全"正则"（normal）的：同一阶模态里，各个测点的复数振型系数之间要么同相（相位差 0°），要么反相（相位差 180° 或 −180°）。以白车身一阶扭转为例，前部横梁与后部横梁摆动方向相反，中间横穿一条节线——所有测点的相位只落在两个方向上。

这个性质可以由运动方程推出，不是经验规律。比例阻尼下运动方程可在模态坐标解耦，特征向量是实数向量（正则模态）；实测频响函数（FRF，Frequency Response Function）拟合出的复留数与实振型系数之间只差一个纯虚的比例因子（共振处留数为纯虚数），因此各测点留数的相位只能落在 0° 或 180° 两个方向上。一旦阻尼不再成比例（结构上存在阻尼片、局部大阻尼连接），或者测量与拟合环节引入误差，振型系数就会在复平面内偏离这条直线——复模态出现。

MPC 和 MPD 度量的正是这种偏离的程度。MOV 则从另一个角度切入：不检查相位形态，只检验一条理论特性——在测点上附加质量，这一阶模态的有阻尼固有频率是否降低。

::: info 核心概念
- **正则模态（Normal Mode）**：比例阻尼结构的实数振型，各测点相位非同相即反相
- **复模态（Complex Mode）**：振型系数相位偏离 0°/180° 的模态，源于非比例阻尼或估计误差
- **模态超复性（Overcomplexity）**：振型系数相位角超越合理界限的现象，MOV 指数的命名由来
:::

## 二、MPC：振型系数实部与虚部是否共线

**模态相位共线性（Modal Phase Collinearity，MPC）**度量无标尺振型向量各元素的实部与虚部之间的线性关系。把每个测点的复振型系数画在复平面上——横轴实部、纵轴虚部——正则模态的所有点应排成一条过原点的直线：同相的点位于正实轴方向，反相的点位于负方向。

MPC 的常用算法对这组（实部，虚部）点做主轴拟合。记

$$S_{xx}=\sum_{i} \mathrm{Re}^2(\psi_i), \qquad S_{yy}=\sum_{i} \mathrm{Im}^2(\psi_i), \qquad S_{xy}=\sum_{i} \mathrm{Re}(\psi_i)\,\mathrm{Im}(\psi_i)$$

三个统计量分别累积实部能量、虚部能量与实虚部交叉项，则

$$\mathrm{MPC} = \frac{\left(S_{xx}-S_{yy}\right)^{2} + 4\,S_{xy}^{2}}{\left(S_{xx}+S_{yy}\right)^{2}} \times 100\%$$

分子是数据在复平面主轴方向投影能量的平方形式，分母是总能量。当实部与虚部严格成比例（所有点共线）时，比值取到上界 100%；当数据在两个方向上的分布"圆化"（如相位均匀散布）时，比值趋于 0。该式对整条直线过不过原点、斜率多大均不敏感——它只回答"这些点是否排成一条直线"。

对实正则模态，**MPC 应接近 100%**；数值低，说明振型在某种程度上是复模态——要么结构上确实存在局部阻尼元件，要么测量或分析处理存在不良环节（手册 18.7 节）。物理上可以这样理解：共振处结构响应落后激振力 90°，拟合出的留数理应纯虚；实部里残存的分量，正是噪声、泄漏、带宽外模态残留的痕迹。MPC 高，说明这些干扰被压制住了；MPC 低，这条振型暂不应采信。

## 三、MPD：相位散布了多少度

MPC 是 0 到 100% 的相对指标，回答"像不像一条直线"；**平均相位偏差（Mean Phase Deviation，MPD）直接给出角度**——各振型系数的相位角对其加权平均值的统计偏差，指示振型在相位上的分散程度（手册 18.7 节）。

由于正则模态的相位本来就允许 0° 与 180° 两种取值，平均相位不能直接对相位角取算术平均——一条完美的正则振型会因为 0°/180° 二义性得到虚假的均值。工程上采用倍角处理：将每个系数的相位角加倍后取复数加权平均，再折半回来，即可把 0° 与 180° 视为同一方向。记加权因子 $w_i = |\psi_i| / \sum_j |\psi_j|$（按振型系数幅值归一），平均相位取为

$$\bar{\theta} = \frac{1}{2}\,\arg\!\left(\sum_{i} w_i\, e^{\,j\,2\theta_i}\right)$$

其中 $\theta_i = \arg(\psi_i)$ 为第 $i$ 个测点振型系数的相位角。各测点相对平均相位的偏差（折算回单角）为

$$\Delta\theta_i = \frac{1}{2}\left|\arg\!\left(e^{\,j\,(2\theta_i - 2\bar{\theta})}\right)\right| \in [0^{\circ},\, 90^{\circ}]$$

MPD 即偏差的加权平均：

$$\mathrm{MPD} = \sum_{i} w_i\, \Delta\theta_i \quad (\text{deg})$$

对实正则模态，**MPD 应接近 0°**。读数的工程参考：MPD 在 5° 以内，动画里节线清晰；20° 以上，动画播放时本应同时过零的测点出现可见的先后错动；到 45° 量级，这条"振型"多数已不是物理模态，或者结构上存在显著的非比例阻尼。

两个指标配合使用：MPC 低而 MPD 只有几度，多数是少数远端测点噪声拉低的结果，可定位到具体测点检查安装；MPC 与 MPD 同时变差，整条振型的相位结构有问题，应检查拟合带宽、极点选择或阻尼模型。

## 四、MOV：附加质量必使固有频率降低

前两个指标检查相位，MOV（Modal Overcomplexity Value，模态超复性值）换了一个完全不同的角度——用**质量的物理效应**做判据。

理论特性：在某一测点给结构附加质量，会降低所有模态的有阻尼固有频率（手册 18.6 节）。这一特性对单自由度系统一目了然——固有频率等于刚度除以质量的平方根，质量增大、频率必然下降。对某阶模态，逐测点计算固有频率对该测点质量增加的灵敏度 $\partial f_k / \partial m_i$，物理模态在所有测点上该灵敏度均应为负。MOV 定义为灵敏度为负的测点所占的加权百分比（Eqn 18-13）：

$$\mathrm{MOV}_{k} = \frac{\sum_{i} \gamma_{ik}\, \delta_{ik}}{\sum_{i} \gamma_{ik}} \times 100\%$$

其中 $\gamma_{ik}$ 为加权因子，取 $\gamma_{ik}=1$（不加权）或 $\gamma_{ik}=\left|\psi_{ik}\right|$（按振型系数幅值加权）；指示函数

$$\delta_{ik} = \begin{cases} 1, & \text{若第 } k \text{ 阶模态在测点 } i \text{ 附加质量的固有频率灵敏度为负} \\ 0, & \text{否则} \end{cases}$$

![MOV 定义：附加质量后频率确实降低的测点所占加权百分比](/images/modal-validation-mpc-mpd-mov/mov-sensitivity.png)

*（图示：物理模态各测点的频率-质量灵敏度全部为负，12/12 个测点满足条件，MOV = 100%。按第五节算例复模态数据绘制）*

**高质量的模态，MOV 指数应有高值（接近 100%）**。数值偏低，该模态要么是计算模态（从噪声中拟合出的非物理极点），要么是有缺陷的估计。之所以称为"超复性"（Overcomplexity），是因为它对应某些振型系数的相位角超越了一个合理的界限——"复得过头"的振型，其质量灵敏度会集体失去负号。

MOV 的一个典型应用是定位测量符号错误：**如果对某一个特定输入点，所有模态的 MOV 都很低（手册示例低于 10%），很可能是测量该输入点 FRF 时激振力方向输反了**。修正方法是将所有模态对该输入的模态参预因子整体改变正负号。

::: warning 工程注意
MOV 低不一定意味着振型不可用，按顺序先查三件事：激振力方向符号（单一输入点全模态集体偏低）、测点灵敏度标定（个别通道异常），再评估振型本身的质量问题。检查顺序颠倒，容易把好振型误判为坏振型。
:::

## 五、Python 演示：给三条振型做验证

下面用 numpy 构造三条振型——一条干净的正则振型、一条被非比例阻尼"拧歪"的复模态、一条方向标反的——分别计算 MPC（复平面直线拟合）、MPD（相位对加权平均的偏差）和 MOV（质量灵敏度负号占比），看指标如何读。

```python
import numpy as np

n = 12                                # 测点数
# 1) 干净的正则振型：系数全实数，相位非 0 即 180 度
psi_normal = np.cos(np.pi * np.arange(n) / 3)

# 2) 复模态：相位逐点拧歪（模拟非比例阻尼/估计误差）
twist = np.deg2rad(35) * np.sin(2 * np.pi * np.arange(n) / n)
psi_complex = psi_normal * np.exp(1j * twist)

# 3) 力方向标反的振型：整体差一个负号（仍是正则模型）
psi_flipped = -psi_normal

def check(name, psi):
    # MPC：实部-虚部在复平面的共线性（主轴拟合优度）
    re, im = psi.real, psi.imag
    sxx, syy, sxy = np.sum(re*re), np.sum(im*im), np.sum(re*im)
    mpc = ((sxx - syy)**2 + 4*sxy*sxy) / (sxx + syy)**2
    # MPD：相位对加权倍角圆均值的偏差（倍角消除 0/180 度二义）
    w = np.abs(psi); w = w / w.sum()
    ang2 = 2 * np.angle(psi)
    mean2 = np.angle(np.sum(w * np.exp(1j*ang2)))
    dev = np.abs(np.angle(np.exp(1j*(ang2 - mean2)))) / 2
    mpd = np.rad2deg(np.average(dev, weights=w))
    # MOV：df/dm < 0 的测点占比（灵敏度正比于 -psi_i 的平方）
    dfdm = -np.abs(psi)**2
    mov = np.mean(dfdm < 0) * 100
    print(f"{name:8s} MPC={mpc*100:5.1f}%  MPD={mpd:5.1f} deg  MOV={mov:5.1f}%")

check("normal",  psi_normal)
check("complex", psi_complex)
check("flipped", psi_flipped)
```

![三条振型的 MPC、MPD、MOV 计算结果对比](/images/modal-validation-mpc-mpd-mov/metrics-comparison.png)

*（图示：三种振型的指标计算结果对比，按上述代码输出绘制）*

运行结果要点：

- 正则振型 MPC = 100%、MPD = 0°、MOV = 100%，三项全部健康；
- 复模态 MPC 降至 44.3%、MPD 升至 20.7°，MOV 仍为 100%——相位形态变差但质量灵敏度符号未反，对应结构上确实存在非比例阻尼的"真复模态"；
- 方向标反的振型三项读数与正则振型完全相同——这正是单看一条振型的 MOV 抓不到符号错误的原因：符号问题要靠"同一输入点全模态 MOV 集体偏低"这一群体特征来暴露。

## 六、三指标与 MAC 的分工

验证模态模型的工具箱里，MAC 回答"两条振型像不像"，MPC/MPD/MOV 回答"这一条振型本身正不正"，互不替代：

| 指标 | 回答的问题 | 健康值 | 典型病征 |
| --- | --- | --- | --- |
| **MPC** | 实部虚部是否共线 | 接近 100% | 局部阻尼元件、测量/拟合不良 |
| **MPD** | 相位散布多大 | 接近 0° | 同上，直接给出角度刻度 |
| **MOV** | 附加质量降频特性是否成立 | 接近 100% | 计算模态、病态估计、力方向标反 |
| **MAC**（另文） | 两条振型是否一致 | 视对象而定 | 测点布置不当、漏测自由度 |

比较从同一数据组、用不同参数估计技术得到的两组模态时，手册 18.8 节建议同时检查有阻尼固有频率、阻尼比、MPC 和 MAC 四项——频率阻尼一致而 MPC 一高一低，两条"同一个"模态里至少有一条振型可疑。

::: tip 判读顺序
- 先看 MOV 抓群体性错误（输入点方向、标定），再看 MPC/MPD 定位个别测点
- 指标全部健康但动画仍然异常时，回到 FRF 累加（FRF accretion）与综合对比，检查是否丢失模态或存在带外模态污染
- 三指标都合格的振型，才值得进入 MAC 与 CAE 或历史数据对比
:::

## 七、小结

频率阻尼依靠稳定图锁定，振型依靠指标验证：MPC 检查共线性、MPD 给出相位散布角、MOV 用质量灵敏度符号识别计算模态。读数时记住三条：MOV 接近 100% 是物理模态的底线；单一输入点全模态 MOV 集体偏低时先查激振力方向符号；MPC 低而 MPD 小，是局部测点问题而非整条振型问题。验证未通过的振型，不应进入后续的灵敏度分析和修改预测——误差会沿模态模型传递放大。
