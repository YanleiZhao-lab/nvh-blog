# 运行模态分析 OMA：不测力也能识别模态参数

> 整车路试、动力总成台架、风机叶片在转——这些工况下输入力根本没法测，传统 FRF 模态分析直接歇菜。运行模态分析（OMA, Operational Modal Analysis）只用响应数据就能识别固有频率、阻尼和振型，靠的是"白噪声输入下响应互相关函数 = 衰减正弦之和"这一物理内核。本文从这条核心定理出发推导参数辨识链，再给 Testlab 实操中参考点、时滞数、指数窗三个关键设置的判断标准。

## 一、工程问题：想测模态，但力测不了

模态参数（固有频率、阻尼比、振型）是结构动力学设计的通用语言。经典试验模态分析（EMA）的路数是：锤击或激振器激励，同时测输入力与响应，算频响函数 H(ω)=X(ω)/F(ω)，再曲线拟合出极点与振型。这条路在实验室里走得通，到了现场常常撞墙：

- **力不可测**：轮胎接地的路面输入、气动载荷、管道流激、桥梁上的车流——没有哪个性价比合理的传感器能量出这些分布式随机激励；
- **工作点对不上**：实验室激振器推力有限，而实际工况载荷叠加预应力、转速离心刚化、气动弹性效应后，结构动态特性随载荷状态漂移。手册（LMS 模态分析理论第 16 章）明确指出：真实载荷作用下得到的模型，是在典型工作点作线性化处理的结果——环境对系统特性的影响（支承预应力、载荷使刚度增加等）将被计入；
- **数据已经在手里**：耐久路试、台架标定积累了海量运行数据，只做谱峰检索太浪费。

手册把适用场景归纳为：海洋平台受微扰动、建筑受车流与风力、车辆受道路不平输入、旋转机械受内部激励等。共同特征——**输入力不可测量，只有响应可用**。

### 与 ODS 的分界线

对运行数据做自谱/互谱峰检索，取峰处各测点的幅相得到"工作变形"（ODS），是工程界多年的老办法。手册对它的局限说得很直白：挑峰靠人工经验，工程技巧要求高；**得不到阻尼**；密集模态下 ODS 是多阶模态的叠加，分解不出"干净"的振型。OMA 的目标就是把这三个短板补上——直接对运行数据做曲线拟合，萃取真正的模态参数。

::: info 核心概念
- **OMA（运行模态分析）**：仅用运行状态下响应数据（response-only）识别模态参数的技术总称
- **NExT（自然激励技术）**：白噪声激励下响应间相关函数可表示为衰减正弦之和，从而复用 LSCE、ERA 等经典时域识别算法
- **随机子空间法（SSI, Stochastic Subspace Identification）**：由输出相关函数构造 Hankel 矩阵，经奇异值分解识别状态空间模型；BR（均衡实现）与 CVA（正则变量分析）是两种典型加权方案
- **PolyMAX**：Simcenter 的频域多参考点模态估计器，稳定图清晰；Testlab OMA 中其拟合对象是互功率谱
:::

## 二、物理本质：随机激励下的互相关函数就是"自由衰减"

OMA 的全部合法性建立在一个漂亮的结果上：平稳白噪声激励下，两个响应之间的互相关函数与脉冲响应具有相同的数学形式——衰减正弦之和。这一节把这条链推导清楚。

### 从运动方程到"看不到刻度的 FRF"

n 自由度粘性阻尼系统在随机力向量作用下，两边取傅里叶变换，响应谱与激励谱通过 FRF 矩阵联系：

$$
\{X(\omega)\} = [H(\omega)]\{F(\omega)\}
\quad\Rightarrow\quad
[S_{xy}(\omega)] = [H(\omega)]\,[S_{ff}(\omega)]\,[H(\omega)]^{H}
$$

其中上标 H 表示共轭转置，S_ff 为输入谱矩阵。若输入为理想白噪声，S_ff(ω)=C 为常数，则输出互谱正比于频响：

$$
S_{xy}(\omega) = C\,H(\omega)
$$

**物理意义**：运行数据的互谱就是"看不到刻度的 FRF"——形状与 FRF 一致，只差一个未知常数倍数。模态拟合要的峰位、峰宽、相对幅相全都在，只是绝对标定没了。这直接解释了 OMA 振型只能得到归一化形状、不能标定留数的原因。

### 相关函数 = 衰减正弦之和（NExT 定理）

对平稳过程，互谱与互相关是一对傅里叶变换（Wiener-Khinchin 关系）：

$$
R_{xy}(\tau) = \int_{-\infty}^{\infty} S_{xy}(\omega)\,e^{j\omega\tau}\,d\omega
= C \int_{-\infty}^{\infty} H(\omega)\,e^{j\omega\tau}\,d\omega
= C\,h(\tau)
$$

第二步把白噪声常数 C 提出积分号，剩下的积分正是脉冲响应 h(τ)（FRF 的逆变换）。**物理图像**：白噪声在统计平均意义下等效于一串随机脉冲；对两个响应做相关运算，等效于把每个随机脉冲的"余响"沿时间轴对齐叠加——输入的随机性被平均掉，剩下的就是系统的自由衰减信息。

对第 r 阶模态，单自由度脉冲响应是指数包络正弦，按模态叠加展开（对应手册多参考 LSCE 分解式）：

$$
R_{xy}(\tau) = \sum_{r=1}^{N_m} A_r\, e^{-\sigma_r \tau}\sin(\omega_{dr}\tau + \varphi_r)
\qquad
\mu_r = -\sigma_r + j\omega_{dr}\,,\quad \sigma_r = \zeta_r \omega_r
$$

每个衰减正弦分量对应一阶模态——**互相关函数就是一组"合成脉冲响应"，LSCE、ERA、SSI 这些现成的时域工具可以直接搬过来用**。这就是 NExT（Natural Excitation Technique）的核心思想：不需要真脉冲，随机输入的相关运算天然造出一个。

::: warning 前提条件别忘
- **白噪声假设**：输入谱必须平坦。路面输入接近宽带随机，没问题；但阶次鲜明的窄带激励（如发动机点火阶次族）违反假设——正弦成分会伪装成阻尼极小的"假模态"，稳定图上表现为极稳但物理上可疑的杆件，需人工剔除或用谐波去除工具预处理。
- **时不变与平稳**：转速恒定是前提，工况漂移会污染相关函数。
- **可激励性**：没被激励起来的模态，再好的算法也变不出来。
:::

### 随机子空间法：从相关函数到状态空间

NExT 把相关函数当脉冲响应用，SSI（随机子空间法）则更进一步，直接用相关函数构造矩阵做整体识别。思路：把连续状态空间模型离散化为 x(k+1)=A·x(k)+w(k)、y(k)=C·x(k)+v(k)，其中 w、v 是过程噪声与测量噪声。由输出相关函数块按"过去/未来"分块排列构成 Hankel 矩阵，其秩等于系统阶次 2Nm（Nm 为模态数）。对加权后的 Hankel 矩阵做奇异值分解并截断小奇异值，得到能观测矩阵 [O_p] 的近似：

$$
[O_p] \approx U_1 S_1^{1/2}
$$

U_1、S_1 是保留的大奇异值块。状态矩阵由移位关系求出——从 [O_p] 删掉最后一个子块行、对剩余部分解最小二乘：

$$
[A] \approx [O_p^{\uparrow}]\,[O_p^{-1}]
$$

最后对 [A] 做特征值分解，离散特征值转为连续极点并给出模态参数（手册式 16-3、16-4）：

$$
\lambda_r = e^{\mu_r \Delta t} \;\Rightarrow\; \mu_r = \frac{\ln \lambda_r}{\Delta t} = -\sigma_r + j\omega_{dr}
\;\Rightarrow\;
\zeta_r = \frac{-\mathrm{Re}(\mu_r)}{|\mu_r|}
$$

每一步的物理意义：**Hankel 矩阵把"过去输出"与"未来输出"通过相关函数搭桥，SVD 截断滤掉噪声子空间，剩下的结构子空间直接给出系统矩阵**。选择不同的权矩阵衍生不同方法：不加权（两个权都取单位阵）就是 BR（均衡实现）法；CVA 加权让各阶模态在能量上均衡——那些在工作状态下没被充分激励的模态，用这种方法仍可能识别得较好，这正是手册强调的 CVA 实用价值。

## 三、三十行代码看懂 OMA 的底气

推导归推导，"白噪声下互相关函数携带完整模态信息"这件事，一段 numpy 就能亲眼验证：造一个 30 Hz、阻尼比 4% 的单模态系统，让白噪声穿过它得到两路"测点响应"，只用这两路响应算互相关，再从互相关里把频率和阻尼抠出来。

```python
import numpy as np

rng = np.random.default_rng(1)
fs, T = 2048.0, 40.0                    # 采样率与总时长
t = np.arange(int(fs*T)) / fs
f0, zeta = 30.0, 0.04                   # 模态设定：30 Hz，阻尼比 4%
wn = 2*np.pi*f0; sigma = zeta*wn        # 阻尼因子 sigma = zeta*wn
h = np.exp(-sigma*t) * np.sin(wn*t)     # 脉冲响应（衰减正弦）
F = rng.standard_normal(t.size)         # 白噪声"路面输入"（不可测）
N = t.size; nfft = 1 << (2*N - 1).bit_length()
HF = np.fft.rfft(h, nfft); FF = np.fft.rfft(F, nfft)
y1 = np.fft.irfft(FF*HF, nfft)[:N]      # 测点1响应（频域法快速卷积）
y2 = np.fft.irfft(FF*0.7*HF, nfft)[:N]  # 测点2（振型分量0.7）
S = np.conj(np.fft.rfft(y1, nfft)) * np.fft.rfft(y2, nfft)
r = np.fft.irfft(S, nfft)[:N] / N       # 互相关（互谱逆FFT，同Testlab思路）
tau = np.arange(int(0.5*fs)) / fs       # 只取前0.5s，信噪比高
seg = r[:tau.size]
pk = [i for i in range(1, seg.size-1)   # 正峰序列拟合包络
      if seg[i] > seg[i-1] and seg[i] >= seg[i+1] and seg[i] > 0]
k = np.polyfit(tau[pk], np.log(seg[pk]), 1)[0]
z = np.where(np.diff(np.sign(seg)) > 0)[0]
print(f"互相关振荡频率 = {1/np.mean(np.diff(z))*fs:.1f} Hz（模态设定 30 Hz）")
print(f"包络衰减率 = {-k:.2f} rad/s（理论 sigma = {sigma:.2f}）")
print(f"反推阻尼比 = {-k/wn*100:.2f}%（设定 4.00%）")
```

运行结果：频率恢复 30.0 Hz，阻尼比 4.37%（设定 4.00%）。输入的随机性在相关运算中被平均掉，互相关确实就是一条"合成脉冲响应"。值得盯住的数字是阻尼的散布——换个随机种子，阻尼估计会在 3.6% 到 5.7% 之间波动，这就是 OMA 阻尼估计天然带统计散差的直观来源：相关函数尾部信噪比有限，工程上靠多段平均、多工况交叉验证收敛。

## 四、Testlab 实操：三个关键设置

软件流程 Op. Data Collection → Op. Data Selection → Op. PolyMAX，曲线拟合环节与 EMA 几乎同构（稳定图选极点那套原样适用），差别集中在前处理：互功率谱代替 FRF 成为拟合对象。

### 参考点：没有力信号，就造一个"虚拟激励点"

选一个或几个响应通道作参考（reference），对所有通道算互功率谱，参考列就是拟合用的"输入列"。工程原则：**大结构分区布置参考点，让每个测点都离某个参考不太远**——保证响应与参考之间的关系主要由结构模态承载，而不是噪声。社区文章的滑雪板案例在板头右侧 +Z、板尾左侧 +Z 各布一个参考，前/后/左/右全覆盖。

参考不是越多越好：超出结构模态数后新增参考几乎不带来新信息，只会拖慢计算。手册的说法更直接——选择输出参考通道，类似于传统模态试验选择输入激励点，应当选取那些包含所有有关模态信息的输出。

### 时滞数：分辨率与光顺度的平衡

时滞数（Number of time lags）决定相关函数长度，也决定互功率谱的分辨率，作用完全类比传统 FFT 的采集时间：

$$
\Delta f = \frac{f_s}{N} = \frac{\text{带宽}}{N/2}
$$

案例参数：fs=256 Hz（带宽 128 Hz），512 时滞，代入得分辨率 0.5 Hz。

| | 时滞数太少 | 时滞数适中 | 时滞数太多 |
| --- | --- | --- | --- |
| **分辨率** | 粗（128时滞到1.0 Hz） | 0.5 Hz 量级 | 细（2048时滞到0.125 Hz） |
| **相关函数形态** | 高时滞截断，泄漏 | 尾部已衰减干净 | 尾部方差大，尖刺毛糙 |
| **密集模态** | 间距小于分辨率的粘成一团漏检 | 可分开 | 可分开 |
| **拟合效果** | 物理模态缺失 | 稳定图干净 | 噪声杆件增多 |

![不同时滞数对互功率谱的影响](/images/operational-modal-analysis/oma-time-lags.png)

*（图源：Simcenter Testing Knowledge Base）*

两头都有坑：太少把密集模态漏检，太多让尖刺干扰拟合。Quick Function 窗口可以对选定的响应/参考对预览互功率谱和互相关（加窗/不加窗对照），是调参的主要手段。案例试算后把设置写进 Run 名（如 Oper Pre-Processing 0_5Hz_1%），几组设置各算一遍、看哪组稳定图最干净，是常规操作。

### 指数窗：泄漏与阻尼补偿的账

相关函数尾部若在时窗末端不为零，FFT 到频域同样泄漏。处理办法与锤击试验同源：加指数窗强制尾部归零。设置项是百分比，含义是**窗末幅值保留为原始值的百分之几**——100% 等于不加窗，1% 表示窗末幅值只剩 1%，案例用的就是 1%。

数学账很简单：乘以指数窗等效于把极点实部平移。设窗末保留比例为 p、相关函数长 T=N/fs，窗衰减率为：

$$
\sigma_w = \frac{\ln(1/p)}{T}
\quad\xrightarrow{p=1\%}\quad
\sigma_w = \frac{\ln 100}{T} \approx \frac{4.6}{T}
$$

于是实测衰减率变成真实值加窗贡献：sigma_meas = sigma + sigma_w，阻尼比被系统性抬高。软件在后续识别中会自动补偿这份附加阻尼（与锤击试验的指数窗补偿同一个机制）；但如果在软件外手工处理相关函数又忘了扣，阻尼就直接虚高。

```python
import numpy as np

fs, N_lags = 256.0, 512                 # 采样率与时滞数
T = N_lags / fs                          # 相关函数长 2.0 s
sigma_w = np.log(100) / T                # 1% 指数窗的附加衰减率
print(f"相关函数长 {T:.1f} s，互功率谱分辨率 = {fs/N_lags:.2f} Hz")
print(f"1% 指数窗附加衰减 sigma_w = {sigma_w:.2f} rad/s")

f0, zeta = 30.0, 0.02                    # 假设一阶 30 Hz / 阻尼比 2% 的模态
sigma = zeta * 2*np.pi*f0                # 真实阻尼因子
print(f"30Hz/2% 模态真实阻尼因子 = {sigma:.2f} rad/s")
print(f"若不补偿，阻尼比虚读为 {(sigma+sigma_w)/(2*np.pi*f0)*100:.2f}%")
```

运行结果要点：相关函数长 2.0 s、分辨率 0.50 Hz；1% 指数窗的附加衰减 2.30 rad/s，而 30 Hz、2% 阻尼模态的真实阻尼因子只有 3.77 rad/s——不补偿的话阻尼比直接从 2.00% 虚读成 3.22%，多出一半还多。指数窗的百分比拧得越小，这份账越重，软件补偿机制必须确认在位。

::: tip 调参路线
- 时滞数从 0.5 Hz 分辨率量级起步，稳定图上密集模态分不开再加倍
- 指数窗从 1% 起步，Quick Function 对照加窗前后互相关，尾部归零即可
- 几组设置各算一套互功率谱（把参数写进 Run 名），哪组稳定图最干净用哪组
:::

## 五、验证：振型会讲物理故事

滑雪板案例的四阶模态识别结果本身就是一堂解读课。运行状态下滑雪者站在板中间，体重把中段压住——四个振型里**中间段几乎都不参与**，这与自由边界下的滑雪板振型完全不同。18.8 Hz 前段主导弯曲、25.4 Hz 后段主导弯曲、54.3 Hz 前后同相扭转、55.8 Hz 前后反相扭转。

振型之外，EMA 的验证工具链在 OMA 里原样可用：用识别出的模态模型合成互功率谱，与实测互功率谱叠画对比——合成曲线（红）抓住了实测曲线（绿）的全部主要动力学特征，说明主要模态没有漏掉，模型可信。

一个常见疑问：PolyMAX 识别出的振型数值普遍偏小，是不是归一化了？Simcenter 工程师在文章评论区的回复是：模态振型可以任意缩放而不改变形状，默认输出未缩放未归一化，需要改标定可在模态验证工作表里操作，保存为新处理。

## 六、小结

OMA 与 EMA 的选择，先看输入力能不能测：

| | **EMA（试验模态）** | **OMA（运行模态）** |
| --- | --- | --- |
| **输入** | 已知激励（锤/激振器） | 不可测随机激励 |
| **拟合对象** | FRF | 互功率谱/相关函数 |
| **频率** | 直接可得 | 直接可得 |
| **阻尼** | 直接可得 | 可得，带统计散差，需多段平均 |
| **振型** | 可标定质量归一化 | 只能得相对形状，不可标定 |
| **典型场景** | 部件级实验室测试 | 整车路试、在役结构、大柔性结构 |
