# H1、H2、Hv：频响函数的三种估计子及其适用条件

> 模态测试得到的频响函数（Frequency Response Function, FRF）不是直接"测"出来的，而是由含噪声的自功率谱与互功率谱经统计平均"估"出来的。H1、H2、Hv 是三种常用估计子（estimator）：H1 假设噪声仅在输出端，反共振区估计精度较高；H2 假设噪声仅在输入端，共振区估计精度较高；Hv 对输入输出两端噪声同时最小化，是全频带的总体最优估计。估计子选择不当时，反共振谷幅值偏差可达 6 倍（本文数值演示结果），此类数据用于模态参数拟合会导致极点偏移。

## 一、FRF 为什么需要"估计子"

理想线性时不变系统（Linear Time-Invariant, LTI）中，输出谱等于输入谱乘频响函数矩阵（LMS 理论基础手册式 3-21）：

$$
\{Y(k)\} = [H(k)]\,\{X(k)\}
$$

单输入单输出情形下即 $Y(f) = H(f)\,X(f)$，其中 $X$ 为输入谱（力锤测试中为力信号，单位 N）、$Y$ 为输出谱（如加速度，单位 m/s^2）、$H$ 为频响函数（加速度导纳情形下单位为 (m/s^2)/N）、$f$ 为频率（Hz）。若谱无噪声，两边相除即得 $H$。

![理想线性系统的频域输入输出关系：输出谱等于输入谱乘以频响函数矩阵](/images/frf-estimators/lms-theory-p41-frf-definition.png)

*（图源：LMS 振动/噪声测试与分析系统《Theory and Background》理论手册，第 41 页）*

问题在于实测的 $x(t)$、$y(t)$ 总混有噪声：力锤测到的力除真实激励外还含压电传感器的电噪声；加速度信号除结构响应外还含背景振动。直接拿两帧含噪谱相除，得到的不是 $H$，而是被噪声污染的混合量。三种估计子的差别，就在于对噪声位置采用哪种假设：

- **H1 估计**：假设输入无噪声、噪声全在输出端，在最小二乘意义上使输出噪声影响最小化，$H_1 = S_{yx}/S_{xx}$；
- **H2 估计**：假设输出无噪声、噪声全在输入端，在最小二乘意义上使输入噪声影响最小化，$H_2 = S_{yy}/S_{yx}$；
- **Hv 估计**：对输入、输出端噪声同时建模，按总体最小二乘（Total Least Squares, TLS）求解。

::: info 核心概念
- **频响函数（FRF）**：输出谱与输入谱之比，一个响应自由度（DOF，分子）对一个参考自由度（分母），复数，含幅值与相位
- **H1 估计**：$H_1 = S_{yx}/S_{xx}$，噪声模型在输出端；若噪声实际在输入端，得到 FRF 的欠估计（underestimate，幅值偏低）
- **H2 估计**：$H_2 = S_{yy}/S_{yx}$，噪声模型在输入端；若噪声实际在输出端，得到 FRF 的过估计（overestimate，幅值偏高）
- **Hv 估计**：取谱矩阵 $[S_{xx}\ S_{xy};\ S_{yx}\ S_{yy}]$ 最小特征值对应特征向量为解，共振区接近 H2、反共振区接近 H1
- **相干函数（coherence function）**：$\gamma^2 = |S_{yx}|^2/(S_{xx}\,S_{yy})$，无量纲，取值范围 [0, 1]，恰好等于 $|H_1|/|H_2|$，是输入输出两端噪声总量的统计指标
- **反共振（antiresonance）谷**：两阶模态相消处结构几乎不响应，输出信号极小、输出端噪声占比显著上升
:::

## 二、欠估计与过估计的定量表达

H1 假设噪声全在输出端，按 $S_{yx}/S_{xx}$ 计算：分子 $S_{yx}$ 中输出噪声与输入不相关，多帧平均后趋于零；分母 $S_{xx}$ 全部为真实激励功率——因此 H1 对输出噪声不敏感（无偏）。但若噪声混在输入端（力传感器漂移、锤头接触不良、双击），设输入端混入的不相关噪声功率为 $S_{nn}$，则估计的期望值为

$$
E[\hat{H}_1] = H\cdot\frac{S_{xx}}{S_{xx}+S_{nn}}
$$

分母被噪声功率抬高，H1 被系统性压低，这就是**欠估计**。

H2 反过来，假设输出无噪、噪声全在输入端，按 $S_{yy}/S_{yx}$ 计算。若输出端实际混入不相关噪声功率 $S_{mm}$，记无噪输出自功率谱为 $S_{yy}$，则

$$
E[\hat{H}_2] = H\cdot\left(1+\frac{S_{mm}}{S_{yy}}\right)
$$

分子把输出端全部能量（含未被力通道观测的部分）计入，$S_{mm}/S_{yy}$ 越大抬高越多，这就是**过估计**。注意 H2 仅在单输出情形可直接计算，多输入多输出（Multiple-Input Multiple-Output, MIMO）需用 Moore-Penrose 广义逆。

![H1 估计的噪声模型：噪声 N 仅叠加在输出端，Y(k) = H(k)X(k) + N(k)](/images/frf-estimators/lms-theory-p42-h1-model.png)

*（图源：LMS 振动/噪声测试与分析系统《Theory and Background》理论手册，第 42 页）*

![H2 估计的噪声模型：噪声 M 仅混在输入端，Y = H(X - M)](/images/frf-estimators/lms-theory-p43-h2-model.png)

*（图源：LMS 振动/噪声测试与分析系统《Theory and Background》理论手册，第 43 页）*

![Hv 估计的噪声模型：输入输出两端同时含噪，Y - N = H(X - M)](/images/frf-estimators/lms-theory-p43-hv-model.png)

*（图源：LMS 振动/噪声测试与分析系统《Theory and Background》理论手册，第 43 页）*

一条恒等式将三者联系起来：

$$
\frac{|\hat{H}_1|}{|\hat{H}_2|} = \frac{|S_{yx}|^2}{S_{xx}\,S_{yy}} = \gamma_{xy}^2
$$

相干低的地方，H1 与 H2 幅值差异按 $\gamma^2$ 拉大；相干接近 1 的地方，三种估计子几乎重合。

### 共振区与反共振区的估计子选择

共振峰处，结构把激励放大几十倍，输出端电噪声相对可忽略，主要误差源转为输入端（力通道信噪比低），应采用 H2。反共振谷处正相反：结构几乎不响应，加速度信号量级接近背景振动，噪声格局转为以输出端为主，应采用 H1。Hv 在共振区贴近 H2、反共振区贴近 H1，全频带表现均衡，代价是每个频率点都要做谱矩阵特征分解，计算时间比 H1/H2 长。手册对此的表述为：H1 在反共振区的估计优于共振区，H2 对共振区的估计优于反共振区，Hv 得到 FRF 的最佳总体估计。

| 场景 | 噪声格局 | 推荐估计子 | 选错的代价 |
| --- | --- | --- | --- |
| **共振峰** | 输出被结构放大，噪声占比自动下降；输入端是主要误差源 | **H2**（或 Hv） | 用 H1，峰值按 $\gamma^2$ 因子压低，拟合阻尼偏大 |
| **反共振谷** | 输出几乎为零，输出端噪声占比上升 | **H1**（或 Hv） | 用 H2，谷被填平甚至出现虚假峰 |
| **频带整体判读** | 两端都有噪声 | **Hv** | 只用 H1，全带幅值系统性偏低 |
| **MIMO 多输入** | 输入间相关时 $S_{xx}$ 病态 | Hv，或 H1 加主分量鉴别 | 直接对 $S_{xx}$ 求逆，矩阵接近奇异、FRF 出现大量毛刺 |
| **锤击测试** | 力窗抑制输入噪声，两次敲击之间输出端全是背景 | **H1** | 用 H2，反共振区虚高数倍（见下文演示） |
| **激振器随机激励** | 力谱平坦，两端信噪比都不差 | **Hv** | — |

## 三、数值演示：同一组数据，三个估计子在峰谷处各偏多少

双自由度系统（约 16 Hz 与 27.5 Hz 两阶模态、22.5 Hz 反共振），均匀谱随机激励、30 帧平均，输入输出两端各加 5% 噪声：

```python
import numpy as np

np.random.seed(7)
fs, T, nb = 200, 4.0, 30                          # 采样率/帧长/平均帧数
N = int(fs*T); f = np.fft.rfftfreq(N, 1/fs)
M = np.eye(2); K = np.array([[2e4,-1e4],[-1e4,2e4]]); C = 1.5e-4*K
H = np.array([0j] + [np.linalg.solve(K + 2j*np.pi*fi*C - (2*np.pi*fi)**2*M,
                                     np.eye(2))[0,0] for fi in f[1:]])
H = H/np.abs(H).max()                             # 真值 FRF，归一化便于读数
Sxx = np.zeros(len(f)); Syy = np.zeros(len(f)); Sxy = np.zeros(len(f), complex)
for _ in range(nb):                               # 30 帧谱平均
    XF = np.random.randn(len(f))                  # 均匀谱随机激励
    x = np.fft.irfft(XF); y = np.fft.irfft(H*XF)
    xm = np.fft.rfft(x + 0.05*x.std()*np.random.randn(N))   # 输入端 5% 噪声
    ym = np.fft.rfft(y + 0.05*y.std()*np.random.randn(N))   # 输出端 5% 噪声
    Sxx += abs(xm)**2; Syy += abs(ym)**2; Sxy += xm*np.conj(ym)
Sxx /= nb; Syy /= nb; Sxy /= nb
H1 = np.conj(Sxy)/Sxx                             # H1 = Syx/Sxx
H2 = Syy/np.conj(Sxy)                             # H2 = Syy/Syx（Syx 为 Sxy 的共轭）
gam = abs(Sxy)**2/(Sxx*Syy)                       # 相干 = |H1|/|H2|
Hv = np.zeros(len(f), complex)
for i in range(len(f)):                           # Hv：谱矩阵最小特征向量
    _, V = np.linalg.eigh([[Sxx[i], Sxy[i]], [np.conj(Sxy[i]), Syy[i]]])
    Hv[i] = -np.conj(V[0,0]/V[1,0])
mag = np.abs(H)
pk = sorted((i for i in range(1, len(f)-1) if mag[i-1] < mag[i] > mag[i+1]),
            key=lambda i: -mag[i])[:2]
lo, hi = sorted(pk); anti = lo + int(np.argmin(mag[lo:hi]))   # 定位两峰一谷
print("位置      频率Hz   真值    H1     H2     Hv    相干")
for tag, i in [("共振峰1", lo), ("反共振谷", anti), ("共振峰2", hi)]:
    print(f"{tag}  {f[i]:5.1f}  {mag[i]:.3f}  {np.abs(H1[i]):.3f}  "
          f"{np.abs(H2[i]):.3f}  {np.abs(Hv[i]):.3f}  {gam[i]:.3f}")
```

运行结果（实测输出）：

```
位置        频率Hz   真值    H1     H2     Hv    相干
共振峰1      16.0   1.000  0.985  0.988  0.987  0.997
反共振谷     22.5   0.002  0.002  0.010  0.002  0.159
共振峰2      27.5   0.233  0.231  0.232  0.231  0.997
```

共振峰上三个估计子几乎重合（相对真值 1.000，三者 0.985/0.988/0.987，偏差均在 1.5% 以内），相干 0.997——峰顶不需要挑选估计子。分界在反共振谷：真值 0.002（精确值 0.0016），H1 与 Hv 保持 0.002，H2 报 0.010（精确值 0.0098），虚高约 6.2 倍，同一频率的相干跌到 0.159。低相干与 H2 虚高是同一噪声的两种表现：谷越深、输出信噪比越差，H2 抬得越高（过估计因子 $1+S_{mm}/S_{yy}$）。要保住谷形，要么改用 H1/Hv，要么在谷区提高激励量级以改善输出信噪比。

## 四、MIMO 情况：H1 不只是除法

多台激振器同时激励时，H1 的矩阵形式 $[\hat{H}_1] = [S_{yx}]\,[S_{xx}]^{-1}$ 要对输入谱矩阵求逆——输入信号彼此相关（例如由同一随机源移相生成）时 $[S_{xx}]$ 接近奇异，求逆会把噪声放大，FRF 全频带出现毛刺。手册给出的处理方法是主分量分析（Principal Component Analysis）：

$$
\{X'(k)\} = [U]^H\,\{X(k)\}, \qquad [S'_{xx}] = [U]^H\,[S_{xx}]\,[U]
$$

其中 $[U]$ 为酉矩阵，$[S'_{xx}]$ 为以主分量自功率谱为对角元素的对角阵（手册式 3-20）。不相关主分量的个数就是真正独立的激励源数，应先鉴别出独立源数目再估计。手册明确指出"主分量谱的主要应用是确定信号组中不相关机械源的数目"，MIMO 频响估计中它是前置步骤而非可选项。另据手册，H1 在各输入信号互不相关时得到最佳结果。

::: warning 工程注意
锤击测试使用 H2 有一个系统性风险：力窗把窗外的输入噪声衰减掉，输入通道显得"干净"，但反共振谷里观测到的响应主要来自输出端背景振动；H2 假设噪声仅在输入端，会把这部分输出噪声全部归因于输入，使谷底出现虚假抬升——锤击测试默认采用 H1，与其噪声假设一致。另一个常见问题是对激振器测试只看 H1：当输入端存在噪声时，共振峰幅值按 $\gamma^2$ 因子相对无偏值缩低（偏低比例为 $1-\gamma^2$），对小阻尼结构，峰幅偏低通常使曲线拟合得到的阻尼比偏大。判断依据始终是相干函数：共振区 $\gamma^2$ 无法接近 1，应优先排查输入通道；反共振区 $\gamma^2$ 下降是输出信噪比物理下降的必然结果，不应据此直接舍弃数据。
:::

## 五、小结

拿到 FRF 先叠加相干曲线：共振峰 $\gamma^2 > 0.95$ 数据才可用于模态拟合；反共振谷 $\gamma^2$ 允许下降，但 H1 与 Hv 应保持谷形。估计子选择的三条判断标准：锤击用 H1（噪声偏输出端），激振器随机激励用 Hv（两端噪声同时建模），只关心共振区极点且输入信噪比可疑时补算 H2 交叉验证。$|H_1|/|H_2| = \gamma^2$，一条曲线同时给出噪声总量与估计子分离程度，是评估 FRF 数据质量的常规手段。
