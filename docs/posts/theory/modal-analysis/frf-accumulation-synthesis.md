# FRF 累加与综合：模态模型的两条使用路径

> 模态拟合跑完，稳定图很干净、极点一列排开，怎么知道这张模态表到底对不对？Simcenter Testlab 理论手册第 18 章给出两条配套的检验与使用路径：FRF 累加（FRF Accumulation）把所有测点 FRF 的实部、虚部分别取绝对值求和，用全体数据共同增强共振峰，再与拟合频率对照着数峰；FRF 综合（FRF Synthesis）反过来，由模态模型（极点加带标尺振型加模态参预因子）把 FRF 曲线重新算出来，与实测曲线逐谱线计算相关性与误差。本文按手册 18.10/18.11 节展开：累加怎么把丢失模态、错频率、附加质量频移晒出来，综合凭什么能算出你没测过的那条 FRF，以及 correlation 与 error 两个数各在替你把什么关。

模态试验报告评审会上常出现这样一幕：两组工程师用同一批数据各跑了一版拟合，A 版报 9 阶模态、B 版报 7 阶，频率都贴着谱峰走，阻尼差 10% 到 15%，评审主持人问到底信哪版，两边都拿不出独立于拟合器之外的证据。其实证据一直躺在数据里：把全部测点的 FRF 做一次累加，共振峰会由所有测点共同投票增强——某阶模态如果真被激励起来，它必然在多数测点上留下峰；拟合表里多出来的那一阶若在累加曲线上没有对应的峰，多半是噪声拟出来的计算模态。反过来，把 B 版的 7 阶模型综合回 FRF 曲线叠到实测上，33 Hz 附近实测有峰、综合曲线光滑无峰，缺的那一阶当场现形。检验不需要重新敲一次锤子，需要的只是把已有数据从两个方向再读一遍。

本文的贯穿类比是验钞机与复印机：FRF 累加像一台验钞机——不产生新信息，只是把散落在几十条 FRF 里的共振峰证据集中到一条曲线上，对着灯照出哪些钞票（拟合频率）没有真材实料的对应峰；FRF 综合像一台复印机——模态模型是底片，综合就是按底片把 FRF 曲线重新印出来，复印件（综合 FRF）与原件（实测 FRF）并排一比，底片丢了一阶模态、或者频率差了半赫兹，复印件上立刻露馅。验钞管多报的，复印管漏报的与印歪的，两条路径合起来，正好把模态模型的两类错误都兜住。

## 一、为什么拟合完还需要再检验

先看工程现场。内饰白车身锤击模态试验，120 个测点、3 个参考点，Polymax 稳定图跑完，35 Hz 附近两阶密频模态的极点杆断断续续，分析员圈了其中一阶、放掉了另一阶；42 Hz 附近的极点在两个参考点下频率差了 0.6 Hz，最后取了平均值。这些决策当时都有理由，但决策质量没有任何独立指标来复核。更隐蔽的是传感器附加质量：结构轻、测点多，装满加速度计后结构的固有频率整体下移，靠单条 FRF 根本看不出移了多少、哪些阶移得多——附件装在振型腹点上的那阶移得多，装在节点附近的几乎不移，这正是判断质量影响是否可忽略的依据。

这两类问题的共同点是：答案不在拟合器里，而在原始数据与拟合结果的对照里。手册第 18 章（模态验证）把 MAC、MPC、互易性、MIF、FRF 累加、FRF 综合排成一列验证工具，前几件检验振型与极点本身，最后两件把检验搬回频域曲线的世界：累加回答拟合频率与实测共振峰对得上吗，综合回答这张模态模型重建出来的曲线与实测曲线贴得拢吗。一件对着原始数据查多报，一件对着重建曲线查漏报，配合使用。

先给三个具体数字建立手感，再进入定义：

- 一阶 32 Hz、阻尼比 2% 的模态，半功率带宽约 1.28 Hz——谱线间隔 0.5 Hz 时峰内只有两三根谱线，目测数峰很容易把密频对数成一个；
- 综合模型丢掉密频对中的一阶（32.0 与 33.2 Hz），综合曲线与实测的 LS 误差从约 3% 跳到约 67%——缺一阶不是差一点，是残差翻二十倍；
- 拟合频率整体偏 0.5 Hz（相当于附加质量引起的频移量级），LS 误差约 35%——误差指标对频率错位同样敏感。

::: info 核心概念
- <strong>FRF 累加（FRF Accumulation）</strong>：对全部测点 FRF 的实部和虚部分别取绝对值求和，再合成一条累加 FRF；共振峰被全体数据共同增强，用于与估计频率对照（手册 18.10 节）
- <strong>FRF 综合（FRF Synthesis）</strong>：由模态模型（极点、带标尺振型、模态参预因子）反算 FRF 曲线，可计算任意响应自由度与参考自由度之间的 FRF（手册 18.11 节）
- <strong>带标尺振型（scaled mode shape）</strong>：具有绝对量纲约定（如质量归一）的振型；综合出有物理单位的 FRF 的前提
- <strong>模态参预因子（modal participation factor）</strong>：多参考拟合中描述每阶模态被各参考输入激发程度的系数向量，正比于参考点的振型系数
- **correlation / LS error**：综合 FRF 与实测 FRF 的形状相关度与幅值误差，理想值分别为 100% 与 0%
:::

## 二、FRF 累加：让所有测点一起投票

固有频率估计精度的一个重要迹象，是它们是否与测量的 FRF 共振峰相吻合。但单看某一条 FRF：节点测点上某阶模态的峰几乎消失，密频对融成一个包络，噪声毛刺与真峰难分。累加的想法朴素：一条 FRF 上的峰可能漏，几十条 FRF 同时在同一频率起峰，就不可能是巧合。

手册 18.10 节的做法用公式写出来只有一行。这个公式回答的问题是：怎样把所有测点都在此频率起峰这件事合成一条曲线？其中 $|\mathrm{Re}\,H_i(k)|$ 对应物理里第 $i$ 个测点 FRF 实部在该谱线上的贡献，绝对值保证不同测点反相的峰不互相抵消——共振处各测点相位本就有的 0 度与 180 度之别，取绝对值后全部变成投票权：

$$
H_{\mathrm{acc}}(k) = \sum_{i=1}^{N_{p}} \left( \left|\mathrm{Re}\,H_i(k)\right| + \left|\mathrm{Im}\,H_i(k)\right| \right)
$$

其中 $H_i(k)$ 为第 $i$ 个测点的 FRF 在谱线 $k$ 的复数值，$N_p$ 为参与累加的测点（或 FRF 条数）。实部与虚部分别取绝对值后求和，再合成累加的 FRF——这正是手册所说"对各个 FRF 的实部和虚部的绝对值分别求和，再合成累加的 FRF"。

为什么取绝对值是关键设计？如果直接把各测点 FRF 代数相加，振型系数有正有负，节点两侧的峰互相抵消，累加曲线会平得像没有模态。取绝对值相当于只统计参与程度、不问方向：某阶模态在测点 A 是正向峰、在测点 B 是反向峰，两边都为累加曲线垫高同一频率的台地。代价是累加曲线不再有相位与正负号信息——它只回答哪里有峰、峰有多强，不回答谁在动、往哪动，那是振型的任务。

利用显示模块，可以用图形方式把 FRF 累加的共振频率与估计出的各个固有频率相互比较。三类典型问题靠它暴露：

- **丢失模态**：稳定图上被放掉的极点，在累加曲线上仍有清晰台地——多数测点都看到了这阶，拟合表里却没有它；
- **有毛病的频率估计**：拟合频率落在累加峰的肩部而非峰顶，两版拟合打架时，累加峰顶是仲裁者；
- **传感器附加质量引起的共振频率偏移**：加装满测点传感器后重测的累加曲线与空载状态对比，腹点方向的那几阶整体下移，节点方向的那几阶几乎不动。

一个数字实验把这几件事同时演一遍（完整代码见第五节）：密频对 32.0/33.2 Hz、阻尼 2%/2.5%，累加曲线上两阶融成一个 31.6 Hz 的单峰包络——这正解释了谱线间隔不够细、密频对数成一阶的常见事故；用累加峰位去仲裁两个拟合版本，偏差半赫兹的一版立刻出局。

## 三、FRF 综合：从模态模型把 FRF 印回来

累加检验的是频率，综合检验的是整张模态模型。手册 18.11 节：由得到的模态模型可有多种途径综合出 FRF。综合的原料是三样——极点（频率与阻尼）、带标尺的模态振型、模态参预因子；产品是任意一对自由度之间的 FRF 曲线，包括你没有测过的那一对。

综合的第一个公式就是模态叠加展开式。这个公式回答的问题是：知道了一组极点和留数，任意两个自由度之间的 FRF 曲线长什么样？其中 $A_{r,ij}$ 对应物理里第 $r$ 阶模态在 i、j 两个自由度之间传递能量的强度（留数），$p_r$ 对应物理里该阶模态的极点（频率与阻尼打包在一起）：

$$
H_{ij}(\omega) = \sum_{r=1}^{N_m} \left[ \frac{A_{r,ij}}{j\omega - p_r} + \frac{A^{*}_{r,ij}}{j\omega - p^{*}_{r}} \right]
$$

每一阶模态贡献一对共轭极点的分式项，全部叠加就是综合 FRF。工程里常见的 Synthesis 页签画的曲线就是它：把拟合出的极点、留数代回去，曲线一条条重新印出来，与实测叠在一幅图里。

综合的第二个公式回答留数从哪来。必须有对应至少一个输入自由度的带标尺的模态振型（即模态振型及模态参预因子），且其中还必须有输入自由度的模态振型系数。这个公式回答的问题是：振型系数怎么折算成任意 i、j 对之间的留数？其中 $\psi_i$、$\psi_j$ 对应物理里两个测点在该阶振型上的系数，$Q_r$ 是把振型换算成有量纲留数的模态比例因子（比例阻尼下为纯虚数）：

$$
A_{r,ij} = Q_r\,\psi_i\,\psi_j
\qquad\Longleftrightarrow\qquad
A_{r,mn} = \frac{A_{r,mj}\,A_{r,nj}}{A_{r,jj}}
$$

右边的等价形式是互易性的直接推论（手册 18.4 节，Maxwell-Betti 互易原理）：留数三因子相乘结构下，同一参考点 $j$ 的行数据即可换算出任意 $m$、$n$ 对之间的留数——这正是综合能算出没测过的 FRF 的数学依据。数值验证毫不客气：三点模型中 $H_{23}$ 直接计算与 $H_{21}H_{31}/H_{11}$ 综合的最大偏差在机器精度量级（约 2e-16），因为对单阶模态这是恒等式；多阶叠加时只要互易性成立，恒等式逐阶成立。反过来它也是质检工具：综合值与补测值对不上，说明参考点 $j$ 附近的互易性被测量问题破坏（力传感器标定、锤击滑移、附加质量不一致），排查方向立刻收窄。

前提条件要记牢：若互易性不满足，实际上只有测量的响应自由度和参考自由度之间的传递函数可以正确地综合出来——想强行综合未测对，先过互易性检查（RSF 比例因子接近常数）这一关。

综合曲线与实测曲线怎么定量比较？手册给出相关与误差两个指标。这个公式回答的问题是：两条复数曲线的形状贴得多拢？其中分子 $\sum_i H^{*}_{s}(i)H_{m}(i)$ 对应物理里综合与实测逐谱线复共轭配对乘积之和（相位对齐的谱线同向累加、错位的互相抵消），分母把两条曲线各自的模长归一掉——与 MAC 同构，只对形状敏感、对整体缩放免疫：

$$
\mathrm{corr} = \frac{\left| \sum_i H^{*}_{s}(i)\,H_{m}(i) \right|^{2}}{\left( \sum_i \left|H_{s}(i)\right|^{2} \right)\left( \sum_i \left|H_{m}(i)\right|^{2} \right)}
$$

其中 $H_s(i)$ 为综合的 FRF 在谱线 $i$ 的复值，$H_m(i)$ 为测量的 FRF 在谱线 $i$ 的复值。以 LS error 表示对综合值规一化的误差，则：

![FRF 综合的相关与误差计算式：相关是复共轭乘积的规一化，LS error 是对综合值规一化的偏差](/images/frf-accumulation-synthesis/correlation-error-eqs.png)

*（图源：网络 侵删）*

$$
\mathrm{LS\ error} = \sqrt{ \frac{\sum_i \left| H_{m}(i) - H_{s}(i) \right|^{2}}{\sum_i \left| H_{s}(i) \right|^{2}} }
$$

对各个 FRF，列出相关低于某规定百分比的 FRF、误差高于某规定百分比的 FRF，对评价综合 FRF 的质量能提供有效的信息——Testlab 的 Modal Synthesis 页上这两列数就是按谱线集逐条 FRF 给出的。

两个数各管一件事，别混着读：correlation 高、error 高，说明曲线形状对但幅值整体偏——查标尺链路（驱动点测量、传感器标定、单位约定）；correlation 低，说明形状就错位——查丢模态、错频率、密频对拆分失败。数值实验里四种损伤模式给出四个指纹：完整模型 corr 0.999 / error 3.1%；丢掉 33.2 Hz 那阶 corr 掉到 0.916 / error 67.4%；频率整体加 0.5 Hz 时 corr 0.938 / error 35.3%；阻尼 2% 虚标成 3% 时 corr 0.978 / error 22.8%。丢模态伤 error 最狠，频率错位伤 correlation 最狠——两个数一对照，损伤类型先分了类。

## 四、Testlab 中的位置与工作流

两件工具在软件里的入口都围绕模态拟合结果页：

- **FRF 累加对照**：模态分析工作表中，将全部测点 FRF 的显示切换为累加模式（Display 模块对 FRF 实部/虚部绝对值求和），把拟合得到的各阶固有频率以光标或标记形式叠到累加曲线上逐一对峰；丢模态、错频率、附加质量频移三类问题在这一屏上排查（手册"利用显示模块"的图形比对流程）。
- **FRF 综合与 correlation/error 检查**：拟合完成后到 Modal Synthesis 页，把综合 FRF 叠加到实测 FRF 上，界面逐条给出 correlation（理想 100%）与 error（理想 0%）两列指标；相关低于阈值、误差高于阈值的 FRF 单独列出，定位到具体测点与频带（与 MLMM 工作流的 Synthesis 检查页同源）。
- **未测对的综合**：模态模型满足互易性检查后，利用驱动点行数据按 $A_{mn}=A_{mj}A_{nj}/A_{jj}$ 综合任意测点对的 FRF，用于补全 TPA 或 FBS 需要而未实测的传递函数（前提：驱动点留数非零、参考点不在该阶节点上）。

工作流上两件工具的顺序建议：先累加数峰定有几阶、在哪，再稳定图选极点，最后综合复核模态表重建曲线贴不贴——验钞在前、复印在后，多报漏报两头堵。

## 五、数值演示：累加数峰、综合验损、互易补全

一次演示走完三条路径：密频对的累加包络、四种模型损伤的 correlation/error 指纹、互易性综合未测对。自包含，可直接运行：

```python
import numpy as np

fs, N = 512.0, 4096
f = np.fft.rfftfreq(N, 1/fs)
rng = np.random.default_rng(7)

def sdoi(f, fn, z):                      # 单模态 FRF
    w, wn = 2*np.pi*f, 2*np.pi*fn
    return 1.0/(wn**2 - w**2 + 2j*z*wn*w)

# 密频对真值 + 3% 乘性噪声的测量 FRF
H = 1.0*sdoi(f, 32.0, 0.02) + 0.8*sdoi(f, 33.2, 0.025)
Hmeas = H*(1 + 0.03*rng.standard_normal(f.size))

# 实验1: FRF 累加——实部虚部分别取绝对值再合成（多测点时逐条求和）
acc = np.abs(Hmeas.real) + np.abs(Hmeas.imag)
band = (f > 20) & (f < 45)
k = int(np.argmax(acc*band))
print(f"累加曲线峰位 {f[k]:.2f} Hz（真值 32.0/33.2 Hz，密频对融成单峰包络）")

# 实验2: 综合四种损伤的 correlation / LS error 指纹
def corr_err(Hm, Hs):
    num = np.abs(np.vdot(Hs, Hm))**2          # 复共轭配对乘积
    den = np.vdot(Hs, Hs).real*np.vdot(Hm, Hm).real
    ls = np.sqrt(np.sum(np.abs(Hm-Hs)**2)/np.sum(np.abs(Hs)**2))
    return num/den, ls

cases = {
    "完整模型":    sdoi(f,32.0,.02) + 0.8*sdoi(f,33.2,.025),
    "丢33.2Hz阶":  sdoi(f,32.0,.02),
    "频率+0.5Hz":  sdoi(f,32.5,.02) + 0.8*sdoi(f,33.7,.025),
    "阻尼虚标1.5倍": sdoi(f,32.0,.03) + 0.8*sdoi(f,33.2,.0375),
}
for name, Hs in cases.items():
    c, e = corr_err(Hmeas, Hs)
    print(f"{name:10s} corr {c:.4f}   LS error {e*100:5.1f}%")

# 实验3: 互易综合——由参考行 H21,H31,H11 补算未测的 H23
psi = {1: 1.0, 2: 0.6, 3: -0.4}             # 振型系数
Hij = lambda i, j: psi[i]*psi[j]*sdoi(f, 32.0, 0.02)
H23_direct = Hij(2, 3)
H23_synth  = Hij(2, 1)*Hij(3, 1)/Hij(1, 1)  # A23 = A21*A31/A11
dev = np.max(np.abs(H23_direct-H23_synth))/np.max(np.abs(H23_direct))
print(f"综合 H23 与直接计算最大偏差 {dev:.1e}（机器精度）")
```

实测输出（rng 种子 7）：

```text
累加曲线峰位 31.62 Hz（真值 32.0/33.2 Hz，密频对融成单峰包络）
完整模型     corr 0.9991   LS error   3.1%
丢33.2Hz阶  corr 0.9159   LS error  67.4%
频率+0.5Hz   corr 0.9378   LS error  35.3%
阻尼虚标1.5倍 corr 0.9781   LS error  22.8%
综合 H23 与直接计算最大偏差 2.0e-16（机器精度）
```

三个实验分别对应三条结论：密频对在累加曲线上融成单峰，数峰前先核对谱线分辨率与阻尼带宽的关系；丢模态把 LS error 推高一个数量级、频率错位主要压低 correlation——两个指标分工诊断；互易综合未测对在模型干净时是恒等式，工程中偏差主要来自测量端互易性破坏而非公式近似。

## 六、小结

FRF 累加与综合是模态模型的验收工序，不是可选项。累加把全体测点的共振证据合成一条曲线，对着拟合频率数峰——多报的计算模态没有对应台地，漏报的真模态留有清晰峰；综合把模态模型当底片重新印出 FRF，与实测逐谱线比形状（correlation）与幅值（error）——形状错位查丢模态与错频率，幅值整体偏查标尺链路。综合还能向前多走一步：互易性成立时由一个参考行的数据补算任意未测对的 FRF，为 TPA 与 FBS 供数。两件工具都只消费已有数据，成本以分钟计，却是模态表出门前的最后一道质检。

## 一句话记住

FRF 累加是验钞机——把几十条 FRF 的峰叠成一张对账单，拟合频率逐峰对号，多报的无峰、漏报的有峰；FRF 综合是复印机——用模态模型把曲线印回来与原件对比，corr 查形状、error 查幅值，互易恒等式还能补印没测过的那条 FRF。
