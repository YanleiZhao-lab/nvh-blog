# 驱动点测量：激励点选在节点上会丢模态

> 模态试验正式测量前应先做驱动点勘察（Driving Point Survey）——同一结构更换三个敲击位置，FRF 中有的出现三个共振峰、有的只剩两个；减少的峰并非该阶模态不存在，而是激励点位置使其无法被激发。本文从留数展开式出发，推导"激励点落在振型节点上、留数归零、共振峰消失"的因果链，并给出驱动点勘察的操作流程与激励点选择判据。

## 一、什么是驱动点测量

驱动点测量（Driving Point Measurement）指激励与响应在结构**同一点、同一方向**上测得的频响函数（FRF, Frequency Response Function）：力锤敲在哪、加速度计就贴在哪，且两者轴线共线。悬臂梁上一个典型的驱动点测量如下图。

![悬臂梁上的驱动点测量：力与响应同点同向（-Z）](/images/driving-point-survey/beam-driving-point.png)

*（图源：Simcenter Testing Knowledge Base）*

实际结构经常做不到严格共点。比如油箱这类封闭容器内表面够不着，只能把加速度计贴在敲击点旁边——此时要尽量靠近，且不能让锤头击到传感器上，否则 FRF 失真、加速度计通道直接过载。方向极性可以不一致（锤击测 -Z、加速度计测 +Z 不影响有效性），只要两者沿同一根轴线。

::: info 核心概念
- **驱动点 FRF**：激励点与响应点重合的对角线测量，$H_{pp}(\omega)$
- **跨点 FRF（Cross FRF）**：激励点与响应点不同的非对角线测量，$H_{ij}(\omega)$
- **节点（Node / Nodal Point）**：某阶振型中位移恒为零的位置；二维结构上节点连成**节线（Nodal Line）**
- **驱动点勘察（Driving Point Survey）**：在结构多个位置各做一次驱动点测量、对比 FRF 峰的数量，确定最佳激励位置
:::

## 二、为什么激励点选在节点上会丢模态

### 从留数展开式看起

多自由度结构的 FRF 可以写成各阶模态部分分式之和（LMS 模态理论手册第 15 章）：

$$
H_{ij}(\omega) = \sum_{k=1}^{N} \left[ \frac{A_{k,ij}}{j\omega - \lambda_k} + \frac{A^{*}_{k,ij}}{j\omega - \lambda_k^{*}} \right]
$$

其中极点 $\lambda_k = -\sigma_k + j\omega_{d,k}$（$\sigma_k$ 为第 k 阶阻尼因子，$\omega_{d,k}$ 为有阻尼固有频率，二者量纲均为时间的倒数，常以 Hz 计），$A_{k,ij}$ 是第 k 阶留数（Residue），"*"表示复共轭。推导的关键在留数上，分三步：

**第一步：模态坐标解耦。** 对运动方程 $M\ddot{x} + C\dot{x} + Kx = f$ 作模态变换 $x = \Phi q$（$\Phi$ 为振型矩阵），利用振型正交性把耦合的物理坐标方程拆成一组单自由度模态坐标方程，第 k 阶为

$$
m_k \ddot{q}_k + c_k \dot{q}_k + k_k q_k = \varphi_k^{\mathrm{T}} f
$$

物理意义：任意位置的响应都能拆成若干阶独立"摆动方式"的叠加，每阶方式有自己独立的模态质量 $m_k$（kg）、模态刚度 $k_k$（N/m）与模态阻尼 $c_k$。

**第二步：频域求解并回收物理坐标。** 只在 j 点施加力 $F_j$ 时，模态坐标频域解为 $Q_k(\omega) = \varphi_k(j) F_j(\omega) / \left[ m_k(\omega_k^2 - \omega^2 + j\,2\zeta_k \omega_k \omega) \right]$，i 点响应是各阶振型系数加权和：

$$
X_i(\omega) = \sum_k \varphi_k(i)\, Q_k(\omega) = \sum_k \frac{\varphi_k(i)\,\varphi_k(j)}{m_k(\omega_k^2 - \omega^2 + j\,2\zeta_k \omega_k \omega)} F_j(\omega)
$$

物理意义：第 k 阶模态对 FRF 的贡献被**两个因子连乘**——响应点看得到多少（$\varphi_k(i)$）、激励点激得起多少（$\varphi_k(j)$）。二者任一为零，这阶模态在该 FRF 中就不出现。

**第三步：部分分式分解得留数。** 把上式分母在极点处展开成 $\frac{A_{k,ij}}{j\omega-\lambda_k} + \frac{A^{*}_{k,ij}}{j\omega-\lambda_k^{*}}$ 的形式，对比系数得（实模态情形）

$$
A_{k,ij} = Q_k \cdot \varphi_k(i) \cdot \varphi_k(j), \qquad Q_k = \frac{1}{2j\, m_k \omega_{d,k}}
$$

这正是手册强调的形式（式 15-5）：**留数 = 响应点振型系数、激励点振型系数、比例常数三者的积**。手册同时给出单位说明：模态振型系数本身无量纲，留数的量纲由比例常数赋予，与测量数据同量纲（加速度型 FRF 时为 $\mathrm{(m/s^2)/N}$）。

### 驱动点的特殊性质

驱动点测量 $i = j$，留数变成

$$
A_{k,pp} = Q_k \cdot \varphi_k^2(p)
$$

平方恒非负——驱动点留数永远同号，这带来两个直接推论：

1. **峰谷交替**。各阶留数同号叠加，驱动点 FRF 呈现典型的"共振峰—反共振谷—共振峰"交替结构，相位在每个共振穿越后、每个反共振再穿回来。跨点 FRF 留数可正可负（乘积 $\varphi_k(i)\varphi_k(j)$ 带符号），常常看不到明显的反共振谷。反过来，一条"只有峰没有谷"的驱动点 FRF，本身就是测量存在问题的信号。
2. **节点即盲区**。若激励点 p 恰在第 k 阶振型的节点上，$\varphi_k(p) = 0$，则 $A_{k,pp} = 0$——这阶模态在 FRF 里不会出现共振峰，与激励力大小、平均次数无关。

下面这组悬臂梁驱动点 FRF 是直接例证：蓝色 FRF 三个峰齐全，红色和绿色各少一个。

![同一悬臂梁三个不同驱动点的 FRF：蓝色三个峰，红绿各只有两个](/images/driving-point-survey/frf-three.png)

*（图源：Simcenter Testing Knowledge Base）*

原因在于振型。悬臂梁第一阶各点都在动，但第二、三阶出现了不动的点——节点：

![悬臂梁前三阶振型：二、三阶振型出现了不参与的节点](/images/driving-point-survey/beam-mode-shapes.png)

*（图源：Simcenter Testing Knowledge Base）*

将振型叠回梁上即可定位：红色敲击点正落在第三阶的节点上，绿色点落在第二阶的节点上，于是红 FRF 丢第三阶、绿 FRF 丢第二阶。

![红色激励点位于第三阶节点，绿色激励点位于第二阶节点](/images/driving-point-survey/beam-nodes.png)

*（图源：Simcenter Testing Knowledge Base）*

真实结构是二维三维的，节点连成节线。下图圆盘模态有两条节线，落在节线上的所有点都激不出这阶模态——平板上的扭转模态节线常与中心对称线重合，这正是"激励点不应选在结构中心线上"的根源。

![圆盘模态的两条节线：节线上的点均不参与该阶振型](/images/driving-point-survey/disc-nodal-lines.png)

*（图源：Simcenter Testing Knowledge Base）*

::: warning 工程注意
锤击法移动的是锤（或加速度计），每换一个激励点就等于换一组 $\varphi_k(j)$。漏掉的模态不会在后续任何处理里补回来——稳定图上不出现的极点，PolyMAX 也估计不出来。跳过驱动点勘察直接固定激励点，丢失的模态无法通过后续数据处理弥补。
:::

## 三、驱动点勘察怎么做

流程分四步：建模、选点、逐点测驱动点 FRF、汇总比峰。

以一块 15 节点平板、关注前 8 阶模态为例，先在结构上选 5 个候选点（plate:2、4、7、8、15），每个点敲一组平均，得到 5 条驱动点 FRF：

![五个候选驱动点的 FRF 叠加对比：不同位置激发出的峰数量明显不同](/images/driving-point-survey/five-frfs.png)

*（图源：Simcenter Testing Knowledge Base）*

把每条 FRF 的共振峰列成表，统计各点激发出的模态数：

| 候选点 | 激发模态数（共 8 阶） | 丢的模态 | 原因 |
| --- | --- | --- | --- |
| **plate:2** | 6 | 弯扭等 2 阶 | 位于对称中心线上 |
| **plate:4** | 8（弱激发 1 阶） | 无 | 角点附近，避开中心线 |
| **plate:7** | 6 | 2 阶 | 位于中心线上 |
| **plate:8** | 7 | 1 阶 | 位于中心线上 |
| **plate:15** | **8** | **无** | 角点，远离所有节线 |

对比结果明确：只有 plate:15 把 8 阶全部激发出来。丢模态的原因也能从节线位置反推——第 2 阶扭转模态的两条节线与平板中心对称线重合，凡是落在中心线上的点（plate:2、7、8）都参加不了这阶扭转。

![扭转模态的节线与平板中心线重合：中心线上的点激不出扭转模态](/images/driving-point-survey/plate-centerline.png)

*（图源：Simcenter Testing Knowledge Base）*

Testlab 的 Impact Setup 工作表里有专门的 Driving Points 页，布局就是为这个流程设计的：力通道与响应通道的时域波形+自功率谱（检查敲击质量）、当前 FRF 幅相、平均后 FRF 幅相、相干函数同屏显示，边敲边看。

![Testlab Impact Setup 的 Driving Points 工作表：波形、FRF、相干同屏](/images/driving-point-survey/worksheet.png)

*（图源：Simcenter Testing Knowledge Base）*

一个提高效率的做法：把 Geometry 工作表拖到 Channel Setup 前面，先建几何再命名通道，Point ID 直接从几何插入到力/加速度两个通道，换点时不容易出错。

::: tip 激励点选择原则
- **默认选角点、边缘、端部**，避开结构中心线与对称轴——前几阶模态的节线大多与对称线重合
- 对陌生结构，应先做一轮驱动点勘察，5 个点左右即可锁定
- 正式测完模态后可用留数检验（LMS 手册第 18.3 节"模态参预"）：对某一阶模态，将各候选参考点对应的留数分别求和并比较，**留数求和值最大的参考点即该阶模态的最佳激励点**；再对所有模态的留数求和作比较，其值最大的点即总体意义下的最佳参考点
- 激励方向同样适用：敲击方向若垂直于某阶模态的主振动平面，该模态同样激不出来
:::

## 四、Python 演示：算出悬臂梁的节点

悬臂梁前几阶振型有解析解，特征根 $\beta_k L$ = 1.8751、4.6941、7.8548，振型函数 $\varphi_k(x) = \cosh\beta x - \cos\beta x - \alpha_k(\sinh\beta x - \sin\beta x)$，其中振型常数 $\alpha_k$ = 0.7341、1.0185、0.9992。把它离散后直接算候选激励点的振型系数——系数接近零的位置就是节点，敲在那里必丢模态。

```python
import numpy as np

# 悬臂梁前3阶振型系数（长度归一 L=1，教材特征值）
beta = [1.8751, 4.6941, 7.8548]     # 特征根 beta_k*L
alpha = [0.7341, 1.0185, 0.9992]    # 振型常数 alpha_k
x = np.linspace(0, 1, 2001)

def psi(k, x):
    """第 k 阶振型系数 phi_k(x)"""
    b = beta[k]
    return np.cosh(b*x) - np.cos(b*x) - alpha[k]*(np.sinh(b*x) - np.sin(b*x))

# 候选激励点（相对夹持端位置）
pts = [("x=0.25 近根部", .25), ("x=0.50 梁中点", .50), ("x=0.78", .78), ("x=1.00 自由端", 1.0)]
print(f"{'激励点':<14}{'phi1':>7}{'phi2':>7}{'phi3':>7}   驱动点留数正比 phi^2（|phi|<0.05 判节点）")
for name, xp in pts:
    v = [psi(k, x)[np.argmin(abs(x - xp))] / abs(psi(k, 1.0)) for k in range(3)]
    tag = "  ".join(f"模态{k+1}:节点" if abs(a) < 0.05 else "" for k, a in enumerate(v))
    print(f"{name:<14}" + "".join(f"{a:7.3f}" for a in v) + f"   {tag}")
```

输出（实测运行结果）：

```
激励点                phi1    phi2    phi3   驱动点留数正比 phi^2（|phi|<0.05 判节点）
x=0.25 近根部      0.097  0.417  0.713   
x=0.50 梁中点      0.340  0.713  0.020       模态3:节点  
x=0.78          0.698  0.014 -0.472     模态2:节点  
x=1.00 自由端      1.000 -1.000  1.000   
```

其中两个数值最关键：x=0.50 处 $\varphi_3 = 0.020$、x=0.78 处 $\varphi_2 = 0.014$——正是第三阶和第二阶的节点位置，留数正比于振型系数平方（约 $4\times10^{-4}$、$2\times10^{-4}$），峰值能量比自由端低近四个数量级，在 FRF 上表现为基本消失的共振峰。另外注意自由端 $\varphi_2 = -1.000$：跨点测量留数带符号可正可负，而驱动点平方后恒正，这就是驱动点 FRF 峰谷交替、跨点 FRF 常常没有反共振谷的数学根源。

## 五、除了选点，驱动点测量还干什么用

驱动点测量的价值不止于开测前的勘察。锤击法要复原完整振型，必须测满 FRF 矩阵的一整行或一整列，驱动点测量就是矩阵对角线上的那些元素，必不可少。

更关键的是**定标尺**。振型系数本身无量纲、可以任意缩放，想把振型换成带物理单位的绝对量，必须依靠驱动点数据：由 $A_{k,pp} = \varphi_k^2(p)/(2j\, m_k \omega_{d,k})$ 反解出模态质量 $m_k$（kg），再得模态刚度 $k_k = \omega_k^2 m_k$（N/m）。没有驱动点测量，模态模型只有频率、阻尼和相对振型，做不了响应仿真、载荷识别这一类需要绝对量纲的工作。互易性校验（Maxwell-Betti 互易，$H_{ij} = H_{ji}$）也依赖驱动点数据参与确定比例因子——LMS 手册第 18.4 节给出计算互易性比例因子（RSF）的三种方案，首选方案正是取"对应模态驱动点留数值最大"的那个驱动点。

所以判断标准很直接：只要试验目的不止于"看看固有频率"，驱动点测量就是必选项；只要激励点还没定，驱动点勘察就是第一步。判据就是峰的数量——哪条 FRF 峰最全，激励点就选在哪里。
