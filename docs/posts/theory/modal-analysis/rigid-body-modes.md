# 刚体模态分析：自由悬挂下刚体/弹性模态分离

> 自由悬挂模态试验的拟合结果里，低频段总混着几个"不像弹性模态"的模态：频率只有几 Hz，振型看不到弯曲扭转，只有整体平移与绕轴转动——它们是刚体模态，频率不由结构刚度而由吊绳与气囊的支承刚度决定。本文讲清楚两件事：怎么把刚体模态从测量结果里分离出来（分解为六个刚体运动模式的最小二乘问题，测点共线则该轴无解），以及怎么反过来用质量、质心与主轴惯量把刚体模态综合出来（留数由总质量、转动惯量与自由度到主轴的距离决定）。分离出的刚体成分顺带提供三项免费服务：查测点标示错、补稀疏测点、平滑测量噪声。

一台新能源车的电驱全套齿轮机在自由悬挂状态下做完模态试验，拟合报告里却出现了六个频率极低、阻尼模糊的“低价模态”，而且其中两个的振型动画明显不像弹性振型——转子整体平移、扭转，没有内部变形。与此同时，另一个团队正在为这台齿轮机做悬置解耦分析，需要刚体模态的频率与振型作输入。两件事其实是一件事：那六个“不像弹性模态”的模态就是刚体模态，它们的频率不由齿轮机自身刚度决定，而由软吊绳、气囊这些支承元件的刚度与阻尼决定。如何把刚体模态从测量结果里分离出来、分离之后又能干什么，是本文要回答的问题。

## 一、为什么自由悬挂试验里总有六个"多余"的模态

模态试验的第一步往往是把试件用软绳吊起来或搁在气囊上，让边界条件尽量接近自由-自由（Free-Free）状态。做完曲线拟合，低于第一阶弹性模态的地方总会冒出几个频率很低的模态：频率可能只有几 Hz，阻尼比飘忽，振型动画里看不到弯曲、扭转，只看到整体平移或绕某根轴转动。刚接触模态试验的工程师容易把它们当成拟合噪声删掉了事——这一删，删掉的恰是悬挂系统信息、试件质量分布信息最集中的频段。

刚体模态（Rigid Body Mode）指结构不发生内部变形、作为整体平移或转动的运动形式。它们的模态参数不由结构自身动力特性决定，而由边界条件——支承刚度与阻尼——决定：软绳越软，刚体模态频率越低；试件质量越大，同样支承下频率也越低。一个自由-自由状态的结构有且仅有六个刚体模态：沿 x、y、z 三个坐标轴的平动模态，以及绕这三个轴的转动模态。任何测量得到的刚体段振型，都是这六个模态的线性组合。

::: info 核心概念
- <strong>刚体模态（Rigid Body Mode）</strong>：结构无内部变形、整体平移或转动的运动形式，自由-自由状态下有 6 个，频率由支承刚度与阻尼决定而非结构本身
- <strong>刚体段（Rigid Body Range）</strong>：从最低刚体模态到第一阶弹性模态之间的频段，此段内结构近似作刚体运动，是刚体模态分离与质量线法的工作区间
- <strong>弹性模态（Flexible/Elastic Mode）</strong>：结构发生内部变形的振动模态，频率与振型由结构自身质量、刚度分布决定
:::

这六个模态并非干扰，而是三类工程任务的直接输入：其一，检验测量设置——刚体段振型动画里若出现个别测点"乱动"，多半是响应点标示、方向定义或传感器标定出了错；其二，补充非测量自由度——刚体运动由几何约束完全确定，据此可把稀疏测量插值成完整的几何骨架动画；其三，为悬置解耦、子结构耦合等分析提供低频边界的模态模型。相关技术手册把它们统称为"刚体模态分析"的两条路径：从测量模态中分离，或基于几何数据综合。

贯穿全文的比方：把自由悬挂的结构想象成一块刚纯的木头，用几根弹簧绳吊在半空。推它一把，木头块本身不变形，只会整体平移或绕某个方向摆动——这就是六个刚体模态：三个平移、三个转动；弹簧绳的长短与阻尼决定摆动快慢，木头自身的质量分布决定哪个方向摇得厉害。频率升高到某个程度，木头内部开始发生弯曲振型，刚体运动与弹性变形混在一起——这正是后文“分离刚体模态要选频带、刚体运动可分解为六个模式的线性组合”的直观图景。

## 二、路径一：从测量模态中分离刚体模态

分离的做法直截了当，共三步：

1. 用几何数据构建结构的 6 种刚体运动模式（三个平移、三个转动）；
2. 把给定的模态振型分解为这 6 种模式的刚体运动，即求解一组线性方程，得到 6 个计权系数；
3. 基于几何数据和 6 个计权系数，计算所关心各自由度的模态振型系数。

其中第 2 步是核心。设振型向量在第 $k$ 个测点三个方向上的分量为 $\phi_{kx}, \phi_{ky}, \phi_{kz}$，测点坐标为 $(x_k, y_k, z_k)$，刚体运动的分解可写为：

这个分解回答的问题是：任何一个测量振型怎么拆成六个刚体运动——振型向量被写成六个刚体运动模式的线性组合，平移模式直接给出三向分量，转动模式按坐标叉乘贡献分量；求解六个计权系数即得刚体成分。

$$
\begin{aligned}
\phi_{kx} &= T_x + R_y\, z_k - R_z\, y_k \\
\phi_{ky} &= T_y + R_z\, x_k - R_x\, z_k \\
\phi_{kz} &= T_z + R_x\, y_k - R_y\, x_k
\end{aligned}
$$

其中 $T_x, T_y, T_z$ 为三个平移系数，$R_x, R_y, R_z$ 为绕三个轴的转动系数。测点多于两个时方程过定，用最小二乘求解。方程组能解的前提是系数矩阵线性独立，这要求至少 6 个线性独立的测量自由度。

这条约束回答的问题是：什么样的测点配置汇总不出六个刚体运动——例如 z 轴上两个测点各测三向，关于绕 z 轴转动的方程失去独立性，该轴转动惯量无解；测点布局必须避免共线。

手册给出的具体判例：把两个测点都放在 z 轴上，即使各自都有三个自由度的测量，也根本不可能从这两点的数据中求出刚体绕 z 轴旋转的成分——所有测点的运动都绕着这根轴对称分布，转动与平移在方程里长成了同一个模样。

频带选取同样有讲究：刚体属性与刚体运动的计权系数都在一个规定频带内按总体最小二乘求出，该频带应选在最高刚体模态与最低变形模态之间的中间区段（见上图）。频带偏低则吊挂共振的阻尼不确定性渗入结果，偏高则第一阶弹性模态的贡献开始污染"纯刚体"假设。

分离出的刚体成分有三项直接用途：

**检验测量设置。** 用最简单的峰检索法拟合出刚体段模态并播放动画，任何"不合理运动"都会现形：某些结点没有测量（完全无运动）、响应点标示出错（运动偏离合理方向）、响应指向出错（往相反方向动）、传感器故障或标定值出错（幅值不对）。前四类失误靠刚体模态的曲线拟合检查一目了然。

**补充非测量自由度。** 从测量数据求出六个刚体运动的计权系数后，把同样的权加到非测点自由度的刚体运动上，即得该自由度的振型系数——几何约束保证了刚体运动的可插值性。这可用于补齐稀疏测量、改善骨架线模型的动画显示。

**校正测量误差。** 用同一组计权系数重算已测自由度的振型系数，重算值与实测值之差即测量噪声与失误的量化指标；必要时可用计算值替换实测值，平滑出干净的刚体运动。

局限性也要说清：部件作为单件做刚体运动有时为难——飞机尾翼试验时可以绕通过翼中的水平轴旋转，装到机身上以后这个刚体运动就被连接约束住了；车辆发动机同理，刚体试验可能要求把它从悬置上拆下来。分离出的刚体模态描述的是"试件当前边界"下的运动，换边界要重测或重新综合。

## 三、路径二：基于几何数据综合刚体模态

第二条路径不需要新的测量：只要知道结构的刚体属性——总质量、质心位置、通过质心的三个惯量主轴方位、以及相对这些主轴的主转动惯量——就可以直接"算出"六个刚体模态。频率与阻尼由用户按支承状态给定（自由-自由综合时频率取 0 或极小值），留数由刚体属性导出：

这组公式回答的问题是：刚体模态的留数长什么样——平动刚体模态的留数只含总质量一个参数，频率完全由用户给定的支承固有频率决定；转动刚体模态的留数由对应主轴的转动惯量与两个自由度到该主轴的垂直距离共同决定。

$$
R^{\text{平动}} = \frac{1}{\omega^2 m}, \qquad
R^{\text{转动}} = \frac{x_r\, f_r}{\omega^2 I}
$$

其中 $m$ 为总质量，$\omega$ 为用户给定的有阻尼固有频率，$f_r$ 为参考自由度到相关惯量主轴的垂直距离，$x_r$ 为响应自由度到该主轴的垂直距离，$I$ 为刚体对相关惯量主轴的转动惯量。

综合出来的刚体模态与实测弹性模态拼在一起，构成完整的低频模态模型。它的典型用途有两个：一是结构修改预测——在弹性模态模型前面补上刚体段，低频强迫响应才不会缺"质量项"；二是子结构耦合——两个分别做过模态试验的子结构，各自补上刚体模态后才能在连接自由度上正确耦合。刚体属性本身可以来自上一节的质量线反算（参见本站《刚体属性提取：用 FRF 质量线反算质量、质心与转动惯量》），也可以来自称重与摆动试验，CAD 惯量报表因缺少油液、线束与装配偏差，只宜作初值。

## 四、numpy 演示：把一个测量振型分解为六个刚体运动

下面用 numpy 复现 19.2.1 节"分解为六种刚体运动"的核心步骤：构造三个平移、三个转动的刚体运动模式，将一个带噪声的测量振型按最小二乘分解，再用计权系数重建非测点自由度的振型系数。

```python
import numpy as np

np.random.seed(0)
# 6 个测点坐标（m）：故意不放在同一轴线附近，保证六个方程线性独立
XYZ = np.array([[0.30, 0.00, 0.10],
                [0.00, 0.25, 0.05],
                [-0.28, 0.00, 0.12],
                [0.00, -0.22, 0.08],
                [0.05, 0.03, -0.20],
                [-0.04, -0.02, 0.22]])

def rigid_modes(xyz):
    # 返回 6x3N 矩阵：每行一个刚体运动模式对各测点三向的映射
    n = xyz.shape[0]
    T = np.zeros((6, 3 * n))
    for k in range(n):
        x, y, z = xyz[k]
        cols = slice(3 * k, 3 * k + 3)
        T[0, cols] = [1, 0, 0]              # 平移 x
        T[1, cols] = [0, 1, 0]              # 平移 y
        T[2, cols] = [0, 0, 1]              # 平移 z
        T[3, cols] = [0, -z, y]             # 绕 x 转动
        T[4, cols] = [z, 0, -x]             # 绕 y 转动
        T[5, cols] = [-y, x, 0]             # 绕 z 转动
    return T

T = rigid_modes(XYZ)
w_true = np.array([0.8, 0.2, 0.1, 0.05, -0.03, 0.02])   # 真实刚体组合系数
phi_true = w_true @ T
phi_meas = phi_true + 0.02 * np.random.randn(*phi_true.shape)  # 加测量噪声

w, res, rank, sv = np.linalg.lstsq(T.T, phi_meas, rcond=None)
phi_fit = w @ T
print("系数误差:", np.round(w - w_true, 4))       # 各分量 1e-2 量级
print("振型残差 RMS:", round(np.sqrt(np.mean((phi_fit - phi_meas)**2)), 4))
print("矩阵秩:", rank, "/ 6 —— 测点不共线时满秩，六个刚体运动均可辨识")
```

运行结果显示：测点不共线时组合矩阵满秩（秩 6），最小二乘解把噪声平均掉之后，六个计权系数的误差在 1e-3 量级，重建振型与测量值的残差 RMS 与所加噪声水平一致。若把六个测点全部摆到同一根 z 轴线上再重跑，矩阵秩会立即跌到 4——绕 z 轴的转动与两个水平平移再也分不开，这正是手册强调"至少 6 个线性独立测量自由度"的数值注脚。

## 五、Testlab 落点

- **Modal Analysis → 曲线拟合**：对刚体段用最简单的峰检索法即可拟合出刚体模态，先播放动画检查测量设置，再进入弹性模态的精细拟合；
- **Testlab Modal Analysis 的 Rigid Body Properties / 结构修改**：由 FRF 质量线反算质量、质心与惯量张量（对应手册 19.1 节），或由几何数据综合刚体模态（19.2.2 节），两条路径在同一工作流里衔接；
- **振型动画检查清单**：刚体段动画中逐点核对——没测的点显示零运动是否合理？各点运动方向是否与坐标定义一致？幅值比例是否突然异常？三个问题分别对应漏测、指向错、标定错三类常见失误。

工程上还有一条经验判据：自由悬挂是否"足够软"，看最高刚体模态频率与第一阶弹性模态频率的比值——相关技术手册建议两者至少拉开一个数量级，否则刚体段与弹性段在频域上重叠，质量线读数与刚体模态分离都会失真。

## 六、小结

刚体模态不是模态试验的副产品，而是低频动力学的一等公民：分离路径把测量振型投影到六个刚体运动模式上，用几何约束完成测点检查、稀疏插值与噪声校正；综合路径把质量、质心与主轴惯量翻译成六个带留数的模态，补全结构修改与子结构耦合所需的低频模型。两条路径共用同一组刚体属性，也共用同一条铁律——测点几何必须线性独立，频带必须落在刚体段与弹性段之间。

## 一句话记住

刚体模态是悬挂系统的六个免费模态：频率看支承，振型看惯量；把振型分解成六个刚体运动的组合，可查测点、补稀疏、平滑噪声；测点共线则该轴无解，分离频带要选在最高刚体模态与最低弹性模态之间。
