# 从FRF提取阻尼：3dB带宽法的原理、误差来源与Testlab游标

> 频响函数（FRF, Frequency Response Function）的共振峰宽度与结构阻尼直接相关，工程中最常用的提取方法是 3dB 带宽法（半功率法, half-power method）：从峰顶 $f_0$ 往下 3dB 量取带宽。方法本身简单，但频率分辨率、指数窗、相邻模态耦合三个误差源可使阻尼读数偏离 30%~75%。本文给出方法推导、数值实验验证与 Simcenter Testlab 阻尼游标的操作步骤，并逐项给出各误差源的定量判据。

## 一、阻尼的度量与 FRF 共振峰的关系

阻尼（damping）是结构在交变应力下耗散能量的能力。无阻尼系统一旦被激励便持续等幅振动；阻尼越大，自由振动衰减越快，FRF 上的共振峰越宽。因此共振峰的宽度是阻尼的定量表征——窄而尖对应轻阻尼，宽而缓对应重阻尼。

工程中描述阻尼的量值有四种：损耗因子 $\eta$（loss factor）、阻尼比 $\zeta$（damping ratio，即临界阻尼的百分比）、品质因子 $Q$（quality factor）与百分临界阻尼。它们在数值上可以互相换算，并存的原因是不同场合的读数便利：两个结构分别测得 0.0123% 与 0.0032% 的临界阻尼时，百分数差异不易直观分辨；换算为 $Q$ 则是 4065 对 15625，相差约 3.8 倍。

各量值与小阻尼近似（$\zeta \ll 1$）下的换算关系：

$$\eta = \frac{1}{Q}, \qquad \zeta = \frac{1}{2Q}, \qquad \eta \approx 2\zeta$$

::: info 核心概念
- **品质因子 $Q$（quality factor）**：共振峰尖锐程度的度量，$Q = f_0/(f_2-f_1)$。Simcenter 官方知识库将 quality factor 与 damping factor 视为同一量，本文遵循此约定
- **阻尼比 $\zeta$（damping ratio）**：临界阻尼的百分比，$\zeta = 1/(2Q)$
- **损耗因子 $\eta$（loss factor）**：$\eta = 1/Q$，小阻尼下 $\eta \approx 2\zeta$
- **方向性**：$Q$ 增大表示阻尼减小；$\zeta$ 与 $\eta$ 增大表示阻尼增大——汇报数据前先确认对方采用哪种量值
:::

注意符号方向：$Q$ 增加、$\zeta$ 减小才表示阻尼变小。审阅报告时应先确认纵轴是哪个量，再判断阻尼是升是降。

| 阻尼表示 | 阻尼增大时 | 与 Q 的关系 | 数值示例 |
| --- | --- | --- | --- |
| **品质因子 $Q$** | 变小 | — | 4065 对 15625，差异显著 |
| **阻尼比 $\zeta$** | 变大 | $\zeta = 1/(2Q)$ | 2% 对应 Q = 25 |
| **损耗因子 $\eta$** | 变大 | $\eta = 1/Q$ | 小阻尼下约为 $\zeta$ 的 2 倍 |
| **百分临界阻尼** | 变大 | $100\zeta$ | 0.0123% 对 0.0032%，差异不直观 |

::: tip 换算速记
- 已知 $Q$ 求 $\zeta$：Q = 25 对应 $\zeta = 2\%$；反之亦然
- 模态软件中极点（pole）实部即阻尼因子 $\sigma$（damping factor，单位 Hz），轻阻尼下 $\zeta \approx \sigma/\omega_d$（$\omega_d$ 为有阻尼固有角频率）。理论手册给出的精确形式为 $\zeta_r = -\sigma_r/\sqrt{\sigma_r^2 + \omega_{d,r}^2}$（式 16-5），轻阻尼时退化为上述近似
- 手册特别说明：频率和阻尼因子的量纲都是时间量纲的倒数，因此二者都以 Hz 为单位——阻尼因子带 Hz 单位是正常的
:::

## 二、3dB 带宽法：定义与推导

FRF 中共振峰的带宽与阻尼成正比。从峰顶频率 $f_0$ 往下 3dB（幅值降为峰值的 $1/\sqrt{2} \approx 0.707$，即 $20\lg(1/\sqrt{2}) \approx -3.01$ dB），在峰两侧找到 $f_1$、$f_2$ 两个穿越点，则：

$$Q = \frac{f_0}{f_2 - f_1}, \qquad \zeta = \frac{f_2 - f_1}{2f_0} = \frac{1}{2Q}$$

其中 $f_0$、$f_1$、$f_2$ 单位均为 Hz。物理上 $f_1$、$f_2$ 称为半功率点（half-power point）：幅值下降 3dB 恰好对应信号功率下降一半。

![阻尼比估计的半功率(3dB)带宽法:在FRF幅频峰两侧找到-3dB穿越点f1、f2, Q=f0/(f2-f1)](/images/damping-from-frf/half-power-bandwidth.png)

*（图源：Simcenter Testing Knowledge Base，理论手册图 15-5）*

推导链从小阻尼单自由度（SDOF）系统的位移导纳（receptance，单位 m/N）出发：

$$H(\omega) = \frac{X(\omega)}{F(\omega)} = \frac{1}{k - m\omega^2 + \mathrm{j}c\omega}$$

其中 $m$（kg）、$k$（N/m）、$c$（N·s/m）分别为质量、刚度、阻尼系数，$\omega$ 为激励角频率（rad/s）。在共振处惯性项与刚度项相消，幅值由阻尼项决定：

$$|H|_{\max} \approx \frac{1}{2\zeta k}$$

即共振峰值反比于阻尼比——阻尼越大峰越矮。解 $|H(\omega)| = |H|_{\max}/\sqrt{2}$ 可得两个半功率点满足 $\omega_2 - \omega_1 = 2\zeta\omega_n$，即半功率带宽正比于阻尼比。代入 $Q$ 的定义即得 $Q = \omega_n/(\omega_2-\omega_1) = f_0/(f_2-f_1)$。

理论手册 15.3.1 节（峰检索，peak picking）即采用此法（式 15-33、图 15-5），并明确其适用条件：

- 对小阻尼单自由度系统，公式是严格的；对实际结构的多自由度 FRF，它是共振峰附近的局部近似，只在峰两侧能找到干净的 -3dB 穿越点时成立
- 峰检索属于 SDOF 方法，只适合模态之间分隔很疏散的情况
- 当某阶模态频率与相邻模态非常靠近，或模态频率靠近测量频带两端时，半功率点之一可能找不到——此时该方法不适用（见第四节）

幅值轴显示为线性还是 dB 无影响，Testlab 的阻尼游标按正确的刻度换算寻找穿越点，不要求先把 FRF 换成 dB 显示。

## 三、数值实验：频率分辨率不足使 Q 读数显著偏低

用一个单自由度系统（100 Hz、阻尼比 2%，即 Q = 25）生成解析 FRF，考察 3dB 法在三种频率分辨率下的表现。重点看谱线直读一列——不插值、直接取第一条低于 -3dB 的谱线，对应手动放置游标时的真实操作。

```python
import numpy as np

# 单自由度FRF + 3dB带宽法：Q = f0/(f2-f1), zeta = 1/(2Q)
f0, zeta = 100.0, 0.02          # 真值：共振100Hz，阻尼比2%
wn = 2*np.pi*f0
k, m, c = wn**2, 1.0, 2*zeta*wn # SDOF参数（m=1kg）

def frf(f):
    w = 2*np.pi*f
    return 1.0/(k - m*w**2 + 1j*c*w)

for df in (2.0, 1.0, 0.25):
    f = np.arange(60, 140+df, df)
    amp = np.abs(frf(f))
    pk = np.argmax(amp)
    a0, f0h = amp[pk], f[pk]
    tgt = a0/np.sqrt(2)                               # -3dB即幅值1/sqrt(2)
    f1 = np.interp(tgt, amp[:pk+1], f[:pk+1])         # 左翼插值
    f2 = np.interp(tgt, amp[pk:][::-1], f[pk:][::-1]) # 右翼插值
    Q = f0h/(f2-f1)
    # 对照：不插值，取第一条低于-3dB的谱线（手动放游标的真实操作）
    i1 = pk - np.argmax(amp[:pk+1][::-1] < tgt)
    i2 = pk + np.argmax(amp[pk:] < tgt)
    Qn = f0h/(f[i2]-f[i1])
    print(f"df={df:4.2f}Hz  插值 Q={Q:5.1f} zeta={100/(2*Q):5.2f}% | 谱线直读 Q={Qn:5.1f} 误差{abs(Qn-25)/25*100:4.0f}%")

print("真值: Q=25.0, zeta=2.00%")
```

实际运行结果（本站复现）：

| 频率分辨率 df | 插值法 Q | 谱线直读 Q | 谱线直读误差 |
| --- | --- | --- | --- |
| 2.00 Hz | 24.9 | 16.7 | -33% |
| 1.00 Hz | 24.9 | 20.0 | -20% |
| 0.25 Hz | 25.0 | 23.5 | -6% |

结论：插值法在三种分辨率下均稳定给出 Q 约 24.9~25.0；谱线直读在 df = 2 Hz 时 Q 仅 16.7，偏低 33%——带宽被量化为整数条谱线，粗分辨率下 $f_2 - f_1$ 被系统性放大。Q = 25 时半功率带宽本身只有 4 Hz，覆盖它的谱线不到三条。理论手册对此的说明一致：若 FRF 频率分辨率低到真实峰落在两条谱线之间，共振频率和阻尼比估计都会产生大误差；手册建议的补偿办法是对峰值谱线两边的 FRF 曲线斜率作外推，即本文插值做法的依据。

## 四、主要误差来源：频率分辨率、指数窗与密集模态

**误差来源一：频率分辨率。** 第三节数值实验已给出定量结果。经验判据：让半功率带宽内至少落 5~10 条谱线，即 $\mathrm{d}f \le (f_2-f_1)/5$。对 Q 上百的轻阻尼结构，这意味着要么延长采样时间，要么承认 3dB 法在此精度极限附近失效。

**误差来源二：指数窗（exponential window）。** 锤击小阻尼结构时，响应在采样窗内衰减不完，泄漏会把峰压矮拉宽，因此通常对响应加指数窗强制其衰减到零：

![锤击测试的加速度响应(左上)乘以指数窗(中)后完全衰减到零(右下),以避免泄漏](/images/damping-from-frf/exponential-window-signal.png)

*（图源：Simcenter Testing Knowledge Base）*

Simcenter Testlab 的指数窗以衰减参数定义：窗从 1.0 开始，衰减参数（0%~100%）指定测量结束时窗值衰减到初值的百分比；衰减参数 100% 等效于不加窗（矩形窗）——信号能在采样时间内自然衰减到零时应优先采用 100%：

![不同衰减参数下指数窗的形状对比](/images/damping-from-frf/exponential-window-decay-params.png)

*（图源：Simcenter Testing Knowledge Base）*

但指数窗给信号叠加了人为衰减，使响应看起来衰减得更快，相当于附加了阻尼，FRF 峰变宽，3dB 法读出的阻尼偏高。理论手册明确提示：加指数窗会在测量数据中附加人为的阻尼，在随后的模态分析处理中应仔细计入其影响。

附加阻尼可以定量表示。设指数窗为 $\mathrm{e}^{-t/\tau}$（$\tau$ 为窗时间常数，单位 s），真实响应包络为 $\mathrm{e}^{-2\pi\zeta f_0 t}$，加窗后包络变为 $\mathrm{e}^{-(2\pi\zeta f_0 + 1/\tau)t}$，即衰减率直接叠加。等效阻尼比为：

$$\zeta_{\mathrm{eq}} = \zeta + \frac{1}{2\pi f_0 \tau}$$

可见加窗后的读数是"结构阻尼 + 窗阻尼"之和，窗越激进（$\tau$ 越小）、模态频率越低，虚增越大。

```python
import numpy as np

# 指数窗如何虚增阻尼：衰减率变成"结构+窗"的叠加
fs, T = 4096, 4.0
t = np.arange(0, T, 1/fs)
f0, zeta = 100.0, 0.02
env = np.exp(-zeta*2*np.pi*f0*t)*np.cos(2*np.pi*f0*t)  # 真实响应

for tau in (np.inf, 0.4, 0.1):   # 窗时间常数：无窗/温和/激进
    win = 1.0 if tau == np.inf else np.exp(-t/tau)
    y = env*win
    # 对信号平方做指数拟合 -> 等效衰减率 -> 等效阻尼比
    sq = y**2
    mask = sq > 1e-12
    slope = np.polyfit(t[mask], np.log(sq[mask]), 1)[0]
    zeta_eq = -slope/(4*np.pi*f0)
    print(f"tau={tau:5.1f}s -> 等效阻尼比 {zeta_eq*100:6.2f}% (真实 2.00%)")
```

实际运行结果（本站复现）：$\tau = \infty$（无窗）读出 1.96%；$\tau = 0.4$ s 读出 2.35%；$\tau = 0.1$ s 的激进指数窗把 2.00% 读成 3.51%，虚增 75%。后两组与上式解析值（2.40%、3.59%）一致——数值拟合略低是因为余弦平方项的求平均区间有限。

![对信号施加指数窗使其看起来衰减更快,等效于附加阻尼](/images/damping-from-frf/exponential-window-added-damping.png)

*（图源：Simcenter Testing Knowledge Base）*

两条处理出路：其一，让模态曲线拟合器自动扣除窗效应——Simcenter Testlab 的模态拟合器会利用记录在数据中的指数窗衰减参数，自动移除其影响并报告正确的模态阻尼；其二，用 R18 及以上版本的阻尼游标，其读数已自动修正指数窗影响。手动 3dB 法读到的始终是结构与窗的合计值。

**误差来源三：密集模态。** 两个模态频率靠近时峰互相重叠，3dB 法量到的带宽包含两阶模态的贡献，单峰阻尼无法读出。判据与手册一致：峰两侧找不到干净的 -3dB 穿越点，或峰形明显不对称。此时应改用模态曲线拟合（modal curve fitting）——它能把两阶模态拆开分别给出阻尼，还能联合多张 FRF 一起估计，比单张 FRF 的 3dB 法稳健得多。

::: warning 工程注意
- 3dB 法读的是单张 FRF 的单个峰，密集模态下直接失效，不应强行读数
- 指数窗下的手动 3dB 读数阻尼偏高，比较不同试件时必须保证窗设置一致
- 汇报 Q 还是 $\zeta$ 需事先确认；$\eta$ 与 $\zeta$ 相差的因子 2 是报告评审中的常见错误
:::

## 五、Testlab 操作：阻尼游标两步读数

FRF 显示出来后：

1. 右键选 **Automatic -> Peak Cursor**（自动峰游标），让游标自动定位到峰顶；对峰位有把握时也可以用普通 SingleX 游标。
2. 游标上右键选 **Calculations -> Q** 或 **Calculations -> Damping Ratio**，读数直接显示在游标旁。

幅值轴不必切换为 dB——游标内部按刻度正确换算。R18 起阻尼游标自动补偿指数窗的虚增效应，锤击数据也可直接读取。

## 六、小结

Q = 25 的共振峰半功率带宽只有 4 Hz，df = 2 Hz 的谱线直读误差可达 33%——应先确认频率分辨率满足 $\mathrm{d}f \le (f_2-f_1)/5$ 再使用 3dB 法。指数窗与密集模态是两个系统性偏差源：前者可交给 Testlab 拟合的自动补偿或 R18 游标修正，定量关系为 $\zeta_{\mathrm{eq}} = \zeta + 1/(2\pi f_0 \tau)$；后者必须放弃 3dB 法改用曲线拟合。快速车间诊断，自动峰游标加 Q 读数即可；正式模态报告，以曲线拟合结果为准。
