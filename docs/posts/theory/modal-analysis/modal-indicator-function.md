# 模态指示函数 MIF：FRF 矩阵逐谱线特征值分析与重根判据

> 模态试验完成后，屏幕上是整组频响函数曲线：哪些峰对应真实模态？两个相邻的峰是密频还是重根？仅凭幅值谱逐峰计数无法回答这些问题——密频对只呈现一个包络，重根模态则只表现为一个峰。模态指示函数（Mode Indicator Function, MIF）将整个 FRF 矩阵压缩为一列随频率变化的特征值曲线：共振区曲线出现局域极小（凹陷），第几条曲线同时出现凹陷，就指示该频率上至少存在几阶模态。本文从"共振处响应虚部主导"的物理事实出发，推导 MIF 的特征值问题，说明第一、第二 MIF 的分工与重根判据的适用条件，最后用数值算例演示含密频对与二重根结构的判读过程。

## 一、为什么幅值谱数峰不可靠

锤击或激振器试验得到的是一组频响函数（Frequency Response Function, FRF）：$N_o$ 个响应测点 × $N_i$ 个参考输入，组成 FRF 矩阵 $H(\omega)$，每个元素都是从某点激励、另一点响应的传递函数。常见做法是将若干条 FRF 幅值曲线叠合在一张图上逐峰计数。这个做法存在两个系统性缺陷。

第一，单条 FRF 会丢失模态。激励点或响应点落在某阶振型的节点附近时，该阶留数（Residue）趋零，这条曲线上不会出现峰——这是驱动点测量一篇讨论过的问题。第二，幅值谱将多阶模态的能量叠加成一个包络。两阶模态频率相差小于一个共振带宽时，幅值上仅表现为单个峰；频率完全重合的重根模态则只可能出现一个峰。逐峰计数得到的模态个数既可能偏多（噪声与泄漏引起的虚假峰），也可能偏少（密频、重根、节点丢失），不能作为确定模态数量的依据。

MIF 不依赖单条曲线，而是考察整个矩阵。它逐谱线计算：该频率上 FRF 矩阵实部能量占响应总能量的比重是多少？结果表示为一组取值介于 0 与 1 之间的特征值曲线，共振信息全部体现在这些曲线的局域凹陷中。

::: info 核心概念
- **模态指示函数（Mode Indicator Function, MIF）**：逐谱线求解特征值问题得到的频域函数，在固有频率处呈局域极小（凹陷）；可算出的 MIF 条数等于输入（参考）自由度数
- **重根（Repeated Root）**：两阶或多阶模态具有相同的固有频率（如对称结构的一弯一扭），靠单条 FRF 无法分辨
- **密频对（Closely Spaced Modes）**：频率间隔小于共振带宽的两阶模态，幅值谱上融成一个峰，但物理上是两颗独立的极点
- **FRF 矩阵 $H(\omega)$**：$N_o \times N_i$ 的复数矩阵，第 $ij$ 元素为 j 点激励、i 点响应的频响函数
:::

## 二、推导：从"共振处响应虚部主导"到特征值问题

### 第一步：共振处响应相位偏转 90 度

单自由度系统位移导纳的频响函数，分母是 $k - \omega^2 m + j\omega c$（$k$ 为刚度，N/m；$m$ 为质量，kg；$c$ 为阻尼系数，N·s/m；$\omega$ 为激励圆频率，rad/s）。写成正则形式：

$$H(\omega) = \frac{1/k}{1 - \lambda^2 + 2j\zeta\lambda}, \quad \lambda = \omega/\omega_n$$

其中 $\omega_n$ 为固有圆频率（rad/s），$\zeta$ 为阻尼比（无量纲）。实部和虚部分别为

$$\mathrm{Re}\,H = \frac{1}{k}\cdot\frac{1-\lambda^2}{(1-\lambda^2)^2 + (2\zeta\lambda)^2}, \qquad \mathrm{Im}\,H = -\frac{1}{k}\cdot\frac{2\zeta\lambda}{(1-\lambda^2)^2 + (2\zeta\lambda)^2}$$

在共振处 $\lambda = 1$：实部分子 $1-\lambda^2 = 0$，虚部达到极值。其物理意义是：实模态、弱阻尼条件下，结构响应在共振处恰好落后激励力 90°，能量全部集中在虚部；实部只在共振两侧变号过零。"共振处实部趋于零、虚部达到极值"这一特性，就是 MIF 的出发点。

多自由度、多输入的情形，将每个测点的响应排成向量。给定一组参考输入力向量 $F$，响应为 $X = [H]F$。激励力向量可以任意缩放，MIF 要找的是：**在所有可能的激励组合里，响应向量实部的"总长度"占响应总长度的最小比例**。

### 第二步：比值的最小化问题

将这个比例写成二次型比值。响应实部能量为 $F^T[H_R]^T[H_R]F$，响应总能量为 $F^T([H_R]^T[H_R] + [H_I]^T[H_I])F$，其中 $[H_R]$、$[H_I]$ 是 FRF 矩阵的实部和虚部。要最小化的目标函数：

$$D^2 = \frac{F^T[H_R]^T[H_R]F}{F^T\left([H_R]^T[H_R] + [H_I]^T[H_I]\right)F} \to \min$$

$D^2 = 0$ 意味着存在一种激励组合，使响应的实部完全消失——这正是"激励找准了某阶实模态"的数学表述（手册原文：当结构上的激励找准某一模态时，响应向量实部的总长度必定变得极小）。

### 第三步：瑞利商变特征值

分母归一的二次型比值是标准的瑞利商（Rayleigh Quotient）结构，最小值在广义特征值问题的最小特征值处取得：

$$[H_R]^T[H_R]\,F = \mu\left([H_R]^T[H_R] + [H_I]^T[H_I]\right)F$$

对每一条谱线解一次这个特征值问题，把特征值按从小到大排序：

- **第一 MIF** = 每条谱线的最小特征值 $\mu_1(f)$。某个频率存在实的纯模态时，$\mu_1$ 出现明显的局域极小——曲线出现凹陷。
- **第二 MIF** = 每条谱线的第二小特征值 $\mu_2(f)$。仅当结构存在**重根模态**时，它才呈现明显的局域极小。
- 更高阶 MIF 同理：第 $n$ 条 MIF 凹陷，意味着该频率上至少有 $n$ 颗模态重合。

可组成的 MIF 阶数等于特征值个数，也等于输入（参考）自由度数。这就是手册结论的来历：**第一、第二 MIF 在同一频率同时出现深度接近零的凹陷，才能判定二重根；四重根需要四条 MIF 同时凹陷，也就要求至少四个独立参考输入**。

::: warning 两个适用性限制
- MIF 的判读前提是实模态。结构存在强阻尼连接、局部大阻尼元件时模态呈复模态特性，响应相位不再保持 90° 滞后关系，实部谷底无法完全归零，MIF 数值偏高、凹陷变浅，判读结果不可靠（手册 18.7 节：振型相位偏离 0°/180° 即指示复模态，原因或是结构上存在局部阻尼元件，或是测量与数据处理不良）。此时应改用 CMIF（复模态指示函数，Complex Mode Indicator Function）：对 FRF 矩阵逐谱线做奇异值分解（Singular Value Decomposition, SVD），奇异值曲线的**峰**指示模态，对复模态系统同样适用。
- 特征值问题维数等于参考点数。两个参考点最多算出第一、第二 MIF，遇到三重根结构（轮胎的多重对称模态是典型情形）将无法判别。参考点数量和位置要按预期的模态重数规划。
:::

## 三、MIF 家族与 FRF 累加：同族指示工具

MIF 并非孤立工具。围绕"数峰、定频、验频"这件事，工程软件中常备一组同族工具，峰谷方向和分工各不相同：

| 工具 | 数学操作 | 指示形态 | 主要用途 |
| --- | --- | --- | --- |
| **第一 MIF（MvMIF）** | $[H_R]^T[H_R]$ 的最小特征值 | 共振处**凹陷** | 找出所有被当前参考组激励到的模态频率 |
| **第 n MIF** | 同一特征值问题的第 n 小特征值 | 与前 n−1 条**同时凹陷** | 判定 n 重根，需要的独立参考数 ≥ n |
| **CMIF** | FRF 矩阵逐谱线 SVD 的奇异值 | 共振处**起峰** | 复模态也适用；密频对表现为两条奇异值曲线同时起峰 |
| **FRF 累加** | 各 FRF 的实部、虚部分别取绝对值求和 | 共振处**起峰** | 增强全部数据的共振峰，与估计频率比对 |
| **稳定图（Stabilization Diagram）** | 递增模型阶数反复拟合极点 | 物理模态连成**竖直线列** | 区分物理模态与计算模态（见模态拟合入门篇） |

FRF 累加值得单独说明，它是固有频率估计精度的快速检验手段：把所有测点 FRF 的实部和虚部分别取绝对值后逐线求和，共振峰被全体数据共同增强。拿累加曲线的峰位对照拟合出的各阶固有频率，丢失模态、有偏差的频率估计、传感器附加质量导致的共振频率偏移，都可以直观发现。

::: tip 选用建议
- 锤击单参考试验：先 FRF 累加数峰 + 第一 MIF 定频，稳定图选极点，两套独立证据交叉验证
- 密频疑似区（两个峰肩并肩、峰间还有反号）：采用 CMIF，两条奇异值曲线是否同时起峰是密频对的直接证据
- 对称结构疑似重根：确认参考点数 ≥ 疑似重数，再看第 n MIF 是否与前 n−1 条一起凹陷
:::

## 四、Python 演示：数值算例判读模态

构造一个 3 测点 × 2 参考输入的仿真数据集：30.1/30.6 Hz 一对密频模态，45.0 Hz 一组二重根（两阶正交振型分别只被两个参考激励到）。逐谱线解特征值问题，观察第一、第二 MIF 的分工。

```python
import numpy as np

f = np.linspace(20, 55, 1401)                # 谱线
w = 2*np.pi*f
# (固有频率Hz, 阻尼比, 实振型(3测点), 参与系数(2输入))
modes = [(30.1, .01, np.array([1.0, .8, .3]), np.array([1.0, .6])),
         (30.6, .01, np.array([.4, -.9, 1.0]), np.array([.5, 1.0])),
         (45.0, .01, np.array([1.0, 0.0, -1.0]), np.array([1.0, 0.0])),   # 重根A: 输入1专激
         (45.0, .01, np.array([0.0, 1.0, 0.0]), np.array([0.0, 1.0]))]    # 重根B: 输入2专激
mif = np.zeros((len(f), 2))
for k, wi in enumerate(w):
    H = np.zeros((3, 2), dtype=complex)
    for fk, zk, psi, L in modes:             # 实模态叠加 -> FRF 矩阵
        wk = 2*np.pi*fk
        H += np.outer(psi, L) / (wk**2 - wi**2 + 2j*zk*wk*wi)
    HR, HI = H.real, H.imag
    A = HR.T @ HR                            # 实部能量矩阵
    ev = np.sort(np.linalg.eigvals(
        np.linalg.solve(A + HI.T @ HI, A)).real)   # 逐线特征值分解
    mif[k] = ev[:2]                          # 最小两个特征值 -> 第一/第二 MIF
for f0, name in [(30.35, "30.1/30.6 Hz 密频对"), (45.0, "45.0 Hz 二重根")]:
    sel = np.abs(f - f0) < 1.5
    print(f"{name}: MIF1 谷底 {mif[sel,0].min():.4f}, MIF2 谷底 {mif[sel,1].min():.4f}")
print(f"非共振区基线: MIF1 中位数 {np.median(mif[:,0]):.2f}, MIF2 中位数 {np.median(mif[:,1]):.2f}")
```

运行结果要点：密频对处 MIF1 塌到 0.0005 而 MIF2 只降到 0.40——两颗极点频率不同，各自能被"单独瞄准"，但无法同时消掉两组实部，第二特征值降不下去；45 Hz 二重根处两条 MIF 一起塌到 0.0003/0.0046——两个独立参考输入把两阶正交振型分别激励起来，两组实部可以同时清零。基线 0.99 对谷底 0.0005，凹陷深度与基线相差约三个数量级，判读依据明确。

## 五、参考点数与输入布局：MIF 的适用边界

在演示数据上再做一组对照：去掉输入 2，只用输入 1 重新计算。45 Hz 处 MIF1 照样凹陷（谷底 0.0015），但特征值问题退化成 1×1，**第二 MIF 根本不存在**——重根 B 没被激励到，FRF 矩阵中不包含其信息，无从判读。这不是算法缺陷，而是数据信息量的限制：$N_i$ 个参考最多支撑 $N_i$ 条 MIF，也最多"看见" $N_i$ 重复根。

工程上的推论很直接。整车车身对称模态、轮胎/制动盘的多节径模态、航空壁板的对称/反对称对，重数常见为 2 甚至 3。试验规划阶段就要把参考点布置充分：数量上，参考点数 ≥ 疑似最大重数；位置上，各参考点在疑似重根振型上的投影要相互独立（对称结构的对称点和反对称点各取一个，应避免将全部参考点布置在对称面上）。参考点布置满足要求后，MIF 的重根判读结果才有效；反过来，若第二 MIF 全程不凹陷、只在个别谱线抖动，应先检查参考点是否布置在振型节点上，再下"无重根"的结论。

## 六、小结

- MIF 是逐谱线特征值分解的产物：$[H_R]^T[H_R]$ 对 $[H_R]^T[H_R]+[H_I]^T[H_I]$ 的广义特征值，从小到大排成第一、第二…条曲线
- 共振处曲线出现局域极小；第 n 条 MIF 与前 n−1 条同时凹陷，指示该频率上至少 n 颗模态；判重根前先确认参考点数 ≥ n
- 密频对与重根的区分：MIF1 在两个相邻频率分别凹陷而 MIF2 不凹陷，指示密频对（每颗极点可被单独瞄准）；MIF1 与 MIF2 在同一频率同时凹陷，才指示重根；复模态场景改用 CMIF
- FRF 累加以全体数据共同增强共振峰，与拟合频率对照，可快速发现丢模态、错频率、附加质量频移
