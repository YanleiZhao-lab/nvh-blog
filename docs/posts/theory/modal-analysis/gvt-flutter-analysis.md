# 地面共振试验 GVT 与颤振分析：首飞前给全机做模态

> 一架新飞机首飞前必须回答一个问题：它在多快、多高的时候还安全？回答靠的不是胆量，是两张图纸的相互印证——风洞里的缩比模型验证气动模型，地面上对全机做模态试验（GVT）验证结构模型，两者合起来才能算出颤振边界。可是 GVT 的测点动辄数百、激振器好几台、外挂与油量配置一种接一种，几天到几周的窗口期压着首飞日程。更微妙的是：对颤振最关键的那几阶模态，工程师偏偏不用 FRF 曲线拟合，而是回到"调模态"的老手艺——把各台激振器的力调到让结构单一振型纯起来，再看 Lissajous 图转成一个圆。本文讲清 GVT 与颤振的因果链、正弦类激励与随机类激励的取舍、Normal Modes 调谐为什么弃 FRF 而直接取振型、阻尼为什么要单独补测，以及测试模态与有限元模型的 MAC 对账。

## 一、为什么首飞之前必须"在地上把全机敲一遍"

一架客机以巡航速度飞行时，机翼在气动力作用下持续变形、振动。正常情况下结构振动被阻尼耗散掉；但当速度升高，气动力与结构变形之间可能形成**正反馈**——变形越大、气动力越"推波助澜"，能量不断灌入某几阶模态，振动幅度在几秒内失控发散。这就是**颤振（Flutter）**：一种弹性结构在流体流动中的动不稳定，可导致全机解体，没有补救机会。

颤振的机理常用 **Collar 图（Collar Diagram）** 概括：弹性力、惯性力与气动力三种力两两交互，分别对应静气动弹性、动力响应与气动弹性稳定性问题；颤振是三力交汇的中心议题。三力交汇的一个典型后果是**模态聚合（modal coalescence）**：气动载荷随速压改变结构的有效刚度与阻尼，使原本频率错开的两阶模态（如机翼一阶弯曲与一阶扭转）互相靠近，某一速度下阻尼之一先降到零——该速度即颤振速度。

![Collar 图：弹性力、惯性力与气动力三力交互，交汇中心即颤振问题](/images/gvt-flutter-analysis/fig1.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

颤振不能靠试飞"摸着石头过河"——那是在拿飞机赌命。工程路线分三步：

1. **分析预测**：结构有限元模型 + 气动力模型（工程颤振分析常基于模态方法，取结构前若干阶模态作为广义自由度），算出各高度、速度下的模态频率与阻尼曲线，阻尼过零处即预测颤振边界；
2. **地面验证**：风洞试验验证气动模型，**GVT 验证结构模型**——在全机处于地面状态时做完整模态试验，测出共振频率、振型与阻尼，与有限元预测对账；
3. **颤振试飞**：模型对得上，才进入实际飞行验证。试飞员在指定的"飞行数据点"上逐点小心地扩展包线，实时监控模态阻尼，绝不一步跳到预测边界外。

![颤振试飞按飞行数据点逐点扩展包线（右图为数据点分布）](/images/gvt-flutter-analysis/fig2.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

只有 GVT 与颤振试飞都成功完成，适航当局（如 FAA）才为该构型签发型号合格证——而且每出一个新的结构改型（换发动机、加外挂、改油量布局），这套验证流程就要重来一遍。

由此可见 GVT 在整个链条中的定位：它是结构动力学模型的**地面实弹校准**。下一节先看这场试验的规模与组织，再看激励信号怎么选。

## 二、试验组织：V 模型右端的顶点

GVT 不是工程师兴之所至的敲击，它是产品研制"V 字模型"右端的收口动作：从左到右，零件级、部件级的建模与试验验证逐级上升，到全机 GVT 汇总；GVT 通过之后才谈颤振包线核查（Flutter Envelope Clearance, FEC）、颤振试飞与最终取证。换言之，全机 GVT 之前，各部件的动力学特性应当已被逐级验证过——GVT 测的是它们**装配成整体并带真实质量属性**之后的模态。

![V 模型：GVT 位于产品研制流程右端的收口位置](/images/gvt-flutter-analysis/fig3.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

GVT 的持续时间从几天到几周不等，取决于机体大小、通道数量、以及**构型数量**。构型是最大的变量：外挂、副油箱、任务载荷的种类与油量状态组合，凡是对结构质量分布影响大到可能改变颤振特性的，都得单独测一遍。一架战斗机的外挂与燃油构型可能有十余种组合——构型每加一种，试验周期就延长一截，首飞日程的风险就多一分。

![不同外挂与燃油构型可能都需要单独 GVT](/images/gvt-flutter-analysis/fig4.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

正因窗口期金贵，**试验前规划**（pretest planning）至关重要：若有限元模型已就绪，可用它预先优化激振器与加速度计的数量、位置，并核验边界条件模拟方案，把机上时间压到最短。GVT 的"边界条件"是专门课题：飞机用起落架支撑、气囊支撑或软悬挂等方式接地，支撑体系自身的刚体模态必须与弹性模态充分分离，不干扰目标频带——试验规程中通常把这一项列为开工前的必检项。

## 三、激励与测点：多台激振器、数百只加速度计

先给几个数感受规模：一次 GVT 动用**多台激振器与数百只加速度计**并不罕见。机体大而柔的飞机（大展弦比机翼、宽机身）需要更多激振器才能把能量送进各个部位；机体小而硬的飞机则可以少配。发动机是典型的重点部位——质量集中、局部模态丰富，常在发动机短舱上同时布置侧向与垂向两台激振器。

![发动机上的侧向（左）与垂向（下方）激振器](/images/gvt-flutter-analysis/fig5.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

无论配置如何，共同的要求是：**激励能量必须在全频段、全结构上足够**，各测点响应的信噪比才撑得起模态识别。可选的激励信号覆盖两大类：

![GVT 可选激励信号：正弦类与随机类](/images/gvt-flutter-analysis/fig6.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

- **随机类**：猝发随机（burst random）等，测 FRF 后曲线拟合，速度快；
- **正弦类**：扫频正弦（swept sine）、步进正弦（stepped sine）与 Normal Modes 调谐，能量集中、信噪比高、可控激励幅值。

工程惯例是混合使用：先用猝发随机或扫频正弦把全机模态全景扫出来；对颤振预测最关键的少数几阶模态（通常 2～3 阶），再用正弦类方法精调。

::: info 核心概念
- **GVT（Ground Vibration Test，地面共振试验）**：首飞前对全机做的完整模态试验，测共振频率、振型与阻尼，用于验证颤振分析所用结构有限元模型
- **颤振（Flutter）**：弹性结构与气流之间的正反馈动不稳定，模态聚合导致阻尼归零、振动发散，可致全机解体
- **颤振包线（Flight Envelope）**：以高度与速度为坐标的安全飞行边界，由颤振分析预测、颤振试飞逐点验证
- **Normal Modes（模态调谐试验）**：多台激振器按响应反馈调幅调相，把某一阶模态隔离成单自由度响应的经典正弦试验方法
- **MAC（Modal Assurance Criterion，模态置信判据）**：两组振型（试验对分析）逐对相关程度的度量，1 为完全一致
:::

## 四、正弦类方法：步进正弦与 Normal Modes 调谐

### 步进正弦（Stepped Sine）

步进正弦在每条谱线上短暂驻留，测稳态响应后再跳到下一条；多台激振器时按激振器数把整个频率范围重复扫描若干遍。它牺牲速度换取单频纯度：每一频率点的激励能量全部集中在一根谱线上，响应信噪比远高于宽带随机。

### Normal Modes：把一阶模态"调"纯

Normal Modes 测试的目标更进一步：**把某一特定模态隔离成单自由度（SDOF）响应**。手段是同时管理所有激振器力的幅值与相位——以各驱动点或控制点的加速度响应为反馈，调整各力之间的相位关系，使结构只按目标振型振动。这本质上是用人为的激励分布去"抵消"其他模态的参与。

判断调谐到位的经典工具是**李萨如图（Lissajous）**：在驱动点处把力信号与加速度响应画成 XY 图。共振时响应滞后激励 90 度，图形恰为一个圆；偏离共振则为斜线。看圆不圆，一眼判断是否锁定共振。

![李萨如图：共振时为圆（上，绿），非共振时为斜线（下，红）](/images/gvt-flutter-analysis/fig7.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

多激振器场合，各响应之间的相位必须同时统筹——激振器与响应之间是耦合的，激励相位矩阵要整体评估。早年这靠试验操作员盯着控制台上的一排李萨如图手工调，如今软件已能自动完成调谐，并把李萨如图、振型动画、幅值相位等信息同屏呈现。

![Normal Modes 软件界面：下方为各驱动点的李萨如图显示](/images/gvt-flutter-analysis/fig8.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

正因为此类测试耗时，通常只对颤振预测最关键的 2～3 阶模态使用。另一个必做的动作是**改变激励幅值**：同一模态在若干幅值下重复调谐，看模态参数是否漂移——这是在线性范围内取参数的直接证据。颤振预测对阻尼极其敏感，线性范围内阻尼识别不准，预测边界就不可信。

### Normal Modes 的一个特点：阻尼须单独补测

注意 Normal Modes 调谐**不采集 FRF**：振型直接从各测点响应算出，无需参数估计流程。代价是模态阻尼不在其结果里，必须用附加的阻尼试验补上——最直接的方式是调谐到位后突然关断激励，记录各测点的**自由衰减**，从指数包络算阻尼。

![由指数衰减曲线计算模态阻尼](/images/gvt-flutter-analysis/fig9.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

这个衰减信号正是对数减幅率（log-decrement）的舞台。下面的公式回答的问题是：一段衰减振荡里，阻尼比藏在哪？其中 $x_n$ 对应物理里衰减波形的第 $n$ 个峰值，对数相邻峰之比 $\delta_{\log}$ 每周期消掉多少幅度，只取决于系统阻尼：

$$
\delta_{\log} = \ln\frac{x_n}{x_{n+1}} = \frac{2\pi\zeta}{\sqrt{1-\zeta^2}} \approx 2\pi\zeta \quad (\zeta \ll 1)
$$

其中 $\zeta$ 为阻尼比。衰减曲线经希尔伯特变换取包络后，逐峰取对数做线性回归，斜率即 $\delta_{\log}$——这正是 Testlab 中"对数减幅率（希尔伯特变换）"选项的算法原型。除它之外，Testlab 还有复功率（Complex Power）、力正交（Force Quadrature）、SDOF 圆拟合等阻尼提取途径，适用于不同的激励与响应组合。

## 五、伪随机与多正弦：速度与精度的折中

在随机类的速度与正弦类的精度之间，还有一类**多正弦（Multi-sines）**信号。经典伪随机（Pseudo-Random）的各分量相位随机，叠加后时域波形峰谷悬殊，容易触发功放过载；若改用 **Schroeder 相位**编排各正弦分量，波峰因子显著降低——同等功放电压上限下有效激励能量更大，同时保留正弦类的高信噪比与随机类的多线同测速度。该技术的机理与工程细节展开见[《伪随机激励：将激振能量对齐傅里叶网格的模态测试信号》](./pseudo-random-excitation.html)。

对 GVT 而言，伪随机/多正弦是"关键模态正弦精调"与"全景随机扫查"之间的中间档：多数模态用它一遍扫完，最关键的几阶再上 Normal Modes。

## 六、数据处理：曲线拟合、与有限元对账

用宽带随机、正弦类或步进正弦得到的 FRF，经**曲线拟合参数估计器**统一提取模态模型——共振频率、振型、阻尼。曲线拟合的原理与选型（LSCE、Polymax、整体拟合等）见[《模态拟合入门：稳定图与极点选择》](../../practice/test-setup/modal-curvefitting-start.html)。Normal Modes 方案的振型则由调谐直接给出，不走拟合。

![由 GVT 采集的 FRF 计算得到的 F-16 模态振型](/images/gvt-flutter-analysis/fig10.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

GVT 的特殊之处在于**数据要在现场立刻消化**：拆台之前，试验模态必须与有限元预测当场比对，确认没有明显出入，设备才能撤。比对的两件工具：

- **直接叠加显示**：将 NASTRAN 或 ANSYS 的有限元结果直接导入 Simcenter Testlab，FRF 曲线与振型动画同屏叠加（相关操作见社区文章 Viewing Nastran results in Simcenter Testlab）；
- **MAC 矩阵**：对试验与分析两组振型逐对算相关度，量化"像不像"。下图是一组 GVT 后的 MAC 矩阵——前几阶重要模态对角线接近 1，说明试验与模型高度一致；MAC 的定义、性质与陷阱见[《模态置信判据 MAC：评估振型一致性的定量指标》](./modal-assurance-criterion.html)。

![试验模态与分析模态之间的 MAC 矩阵，对角线接近 1 表示一致](/images/gvt-flutter-analysis/fig11.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

对账不过关就进入**模型修正迭代**：以试验为准更新有限元模型（质量、刚度、连接刚度），直至模态对齐。对账通过前还有一个前提要自查：试验状态必须真实代表分析模型的构型——质量属性（载荷、油量）与边界条件（支撑方式）一致，且刚体模态不侵入弹性模态频带。

若希望试验模态模型本身更"干净"，可用 **MLMM（最大似然模态模型）** 扩展：它以"实模态"（比例阻尼）为约束迭代优化模态参数，同时改善合成 FRF 的拟合度——与直接用于颤振分析的 FE 模型天然更兼容。MLMM 的推导与 Testlab 用法见[《MLMM 最大似然模态模型：从最小二乘到迭代优化》](./mlmm-modal-estimation.html)。振型的直观呈现还可用 **振型扩展（Modeshape Expansion）**：以 CAD 模型为基准把测点振型扩展到全结构，便于理解各阶模态的全机行为。

## 七、numpy 演示：模态聚合与颤振边界的最小模型

颤振的"频率聚合、阻尼归零"用一个二自由度机翼段的简化模型即可复现。取弯沉 $h$ 与俯仰角 $\alpha$ 两个自由度，准定常气动力随速压 $q = \tfrac12 \rho_{\mathrm{air}} V^2$ 增长，作用等效为随 $q$ 线性放大的刚度与阻尼修正项。下面的公式回答的问题是：为什么速度升高时两阶模态会互相靠近、其中一阶的阻尼先归零？其中 $\mathbf{K}_a$ 对应物理里气动变形反馈力的等效刚度（扭转分量显著为负——气动力矩"替"扭转弹簧卸载，频率随速度下坠），$\mathbf{C}_a$ 是气动阻尼矩阵（对角一正一负——能量从一阶模态搬到另一阶）：

$$
\mathbf{M}\ddot{\mathbf{x}} + \left(\mathbf{C}_s + q\,\mathbf{C}_a\right)\dot{\mathbf{x}} + \left(\mathbf{K}_s + q\,\mathbf{K}_a\right)\mathbf{x} = 0, \qquad q = \tfrac12 \rho_{\mathrm{air}} V^2
$$

其中 $\mathbf{x} = [h,\alpha]^T$，$\mathbf{M}$、$\mathbf{C}_s$、$\mathbf{K}_s$ 为结构的模态质量、阻尼、刚度矩阵。把方程写成状态空间形式解复特征值：虚部是模态频率，实部是衰减率——某一支实部由负转正的速度，就是颤振速度。

```python
import numpy as np

# 二自由度机翼段：弯沉 h 与俯仰 alpha，准定常气动项随速压 q 线性放大
m1, m2 = 1.0, 1.0
k1, k2 = (2*np.pi*6.0)**2, (2*np.pi*12.0)**2   # 6 Hz 弯曲 / 12 Hz 扭转
c1, c2 = 0.05, 0.05                             # 结构阻尼
M  = np.diag([m1, m2])
Ks = np.array([[k1, 0.0], [0.0, k2]])
Ka = 0.035  * np.array([[0.3, 1.0], [1.0, -8.0]])   # 气动刚度(扭转强软化)
Ca = 1.2e-5 * np.array([[1.0, -0.5], [-0.5, -1.0]]) # 气动阻尼(一进一出)
rho = 1.225

for V in [0.0, 60.0, 80.0, 90.0, 100.0, 120.0, 140.0]:
    q  = 0.5*rho*V**2
    K = Ks + q*Ka
    C = np.diag([c1, c2]) + q*Ca
    A = np.block([[np.zeros((2, 2)), np.eye(2)],
                  [-np.linalg.solve(M, K), -np.linalg.solve(M, C)]])
    ev = np.linalg.eigvals(A)
    ev = ev[ev.imag > 0]                 # 每对共轭特征值取其一
    f, s = ev.imag/(2*np.pi), ev.real    # 频率 / 衰减率(s>0 即发散)
    o = np.argsort(f)
    print(f"V={V:6.1f} m/s  f={f[o][0]:6.2f}/{f[o][1]:6.2f} Hz"
          f"  sigma={s[o][0]:+7.3f}/{s[o][1]:+7.3f} 1/s"
          f"  {'FLUTTER' if (s > 0).any() else 'stable'}")
```

```text
V= 100.0 m/s  f= 6.10/10.05 Hz  sigma=-0.064/+0.014 1/s  FLUTTER
V= 120.0 m/s  f= 6.08/ 9.10 Hz  sigma=-0.084/+0.034 1/s  FLUTTER
V= 140.0 m/s  f= 5.88/ 7.97 Hz  sigma=-0.100/+0.050 1/s  FLUTTER
```

三条规律与真实颤振一致：其一，速压升高时两阶频率**互相靠拢**（扭转支 12.00 → 7.97 Hz 向弯曲支贴近——准定常气动力矩给扭转弹簧"卸载"）；其二，扭转支的衰减率在 80～90 m/s 之间越过零线，该点即颤振速度——注意它发生在频率完全合拢**之前**，工程上从不敢等"频率重合"才认定颤振；其三，两支衰减率一负一正、对称地分道扬镳——气动力做的功从弯曲支"输血"给扭转支，这正是能量搬运型不稳定的标志。对 GVT 的含义很直白：**弯曲与扭转这两阶模态的频率和阻尼，是颤振预测的命门参数**——GVT 报告里它们必须最准，这也解释了为什么对这几阶要不惜成本地上 Normal Modes 精调与专门的阻尼测试。

## 八、Testlab 落点

- **GVT 数据采集**：Simcenter Testlab Signature 等模块支持猝发随机、扫频/步进正弦与多正弦激励；步进正弦允许谱线不等间隔布点，可在共振区加密
- **Normal Modes 调谐**：多激振器幅相在线调整、李萨如图与振型同屏监视，自动完成相位矩阵评估
- **阻尼提取**：对数减幅率（希尔伯特变换）、复功率、力正交、SDOF 圆拟合等多种方法可选
- **与 FE 对账**：直接导入 NASTRAN/ANSYS 结果叠加显示；MAC 矩阵量化振型一致性；MLMM 以实模态约束优化试验模态模型
- **振型呈现**：振型扩展（Modeshape Expansion）以 CAD 几何为基准放大测点振型

## 九、小结

- 颤振 = 弹性力、惯性力、气动力正反馈引起的动不稳定（Collar 图三力交汇），防颤振靠"预测 + 地面验证 + 试飞逐点扩包线"三步闭环；FAA 取证以 GVT 与颤振试飞双通过为前提，每个结构改型重走一遍
- GVT 是全机级模态试验：V 模型右端收口，多台激振器、数百加速度计、按外挂/油量构型逐个测；有限元前规划激振点与测点，支撑边界条件的刚体模态须与弹性模态分离
- 激励分速度与精度两档：随机类扫全景，正弦类（步进正弦、Normal Modes）精调对颤振最关键的 2～3 阶；伪随机/Schroeder 多正弦是折中档
- Normal Modes 调谐以响应反馈管理多台激振器幅相，把模态隔离成 SDOF 响应，李萨如图成圆判共振；不采集 FRF，阻尼须由关断激励后的指数衰减（对数减幅率）等专门方法补测
- 数据现场消化：试验模态与 FE 模型当场叠加比对 + MAC 对账，不过关则模型修正迭代；MLMM 可把试验模态模型约束为实模态以匹配颤振分析

## 一句话记住

颤振边界 = 结构模型 × 气动模型：GVT 用全机模态试验把结构模型钉在地上——随机扫全景、正弦精调关键模态、衰减补阻尼、MAC 对账 FE；弯扭两阶聚合的频率与阻尼就是命门，测准了，颤振试飞才敢逐点扩包线。
