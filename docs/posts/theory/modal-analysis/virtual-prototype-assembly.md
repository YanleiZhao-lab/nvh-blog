# 虚拟样机装配 VPA：把各部件的试验模态装配成整机

> 动力总成装上车身之后怠速轰鸣会不会超标——这个问题在只有动力总成样件、车身还在图纸阶段时能回答吗？能。虚拟样机装配（Virtual Prototype Assembly, VPA）的做法是：各部件分别做模态试验得到各自的模态模型，再把螺栓、悬置、衬套这些连接件当成弹簧和阻尼器"拧"上去，在模态空间里直接解出整机的模态参数。就像乐高积木：每块积木（子结构）的形状是各自量好的，拼插口（连接件）的松紧是独立给定的，拼起来之前就能算出整个造型。本文从拉普拉斯域运动方程出发拆解模态域装配的完整推导，用 numpy 把"物理域直接组装"与"模态域装配"两条路线算到同一组数字上，并演示模态截断会带来多大偏差。

## 一、为什么需要虚拟装配：等不来的整机样件

整机模态测试有个尴尬的先后依赖：想知道动力总成装上车后整车轰鸣频率会不会撞上怠速激励，就得先有一台装好的整车；可整车还没造出来——发动机台架、白车身分处两个供应商，拼装要等模具、等物流、等排产。等整机到位再测出问题，改动窗口已经关了一半。

传统出路有两条，各有代价。一条是有限元整机建模：每个部件都建网格，连接刚度靠估，螺栓预紧力、衬套老化这类连接特性恰好是有限元最不准的部分。另一条是等样件做整机试验：数据最真，但时间最晚。

第三条路是虚拟样机装配（Virtual Prototype Assembly, VPA）。它的洞察在于：难建的连接件在试验里反而好测——一根悬置的动刚度上台架半小时就能拿到；而部件本身的动态特性，试验模态比有限元准得多。于是把两者分工：部件动力学用试验模态模型（极点 + 带标尺振型），连接件用弹簧阻尼参数，整机模态在模态空间里装配求解。这与乐高积木同理：每块积木的形状（部件模态）是逐块量出来的，拼插口（连接件）的松紧独立标定，拼装之前就能算出整体造型——而且换一副拼插口（换一组悬置）重算只需几秒，不用重测任何积木。

回看开头的问题：动力总成台架试验给出它的模态模型，车身哪怕只有有限元模型也可以先转成模态模型参与装配，悬置参数来自供应商数据——整机怠速轰鸣频率的预测不必等整机。LMS 理论手册第二十章把这套方法称为子结构集成与结构修改，Simcenter Testlab 中的对应功能即 Virtual Prototype Assembly。

::: info 核心概念
- **虚拟样机装配（Virtual Prototype Assembly, VPA）**：将各部件的模态模型与连接件（弹簧/阻尼器）参数在模态空间装配，解出集成结构模态参数的预测方法
- **子结构（substructure）**：参与装配的部件，每个子结构有自己的模态模型（极点、带标尺振型），装配前彼此动力独立
- **连接矩阵（connection matrix）**：把连接件两端物理位移写成系统位移向量线性组合的矩阵，弹簧与阻尼器的贡献经由它进入系统矩阵（手册式 20-40）
- **带标尺振型（scaled mode shape）**：经质量归一或驱动点留数定标、具有物理量纲的振型，无标尺振型无法参与装配运算
- **模态截断（modal truncation）**：每个子结构只保留有限阶模态，带外模态的影响以残余项补偿（手册 15.5 节静态补偿）
:::

## 二、从物理域到模态域：装配公式的三步推导

先看每个部件手里的积木长什么样。子结构 i 在拉普拉斯域的运动方程为（手册式 20-28）：

$$
[B_i(s)]\,\{y_i(s)\} = \{f_i(s)\}, \qquad [B_i(s)] = s^2[M_i] + s[C_i] + [K_i]
$$

这个公式回答的问题是：一个部件在复频域里力和位移是什么关系？其中 $[B_i(s)]$ 对应物理里的动刚度矩阵——质量、阻尼、刚度三项按 $s$ 的幂次加权求和，$s$ 是拉普拉斯复频率。

![两个子结构的拉普拉斯域运动方程](/images/virtual-prototype-assembly/fig-two-substructure-eq.png)

*（图源：LMS 振动/噪声测试与分析系统《Theory and Background》理论手册，第 253 页）*

第一步，各自解耦。对每个子结构解特征值问题，得到极点对与振型矩阵，物理坐标经 $y = Vq$ 变换到模态坐标——手册强调，模态空间内两个子结构的运动方程是无耦合的：作用在一个子结构上任意点的任何力都不会引起另一结构的任何运动。这正是积木各自量好的数学表达。

第二步，连接件进场。两个子结构通过弹簧和阻尼器柔性连接，引入连接矩阵后，系统矩阵在块对角基础上叠加连接项（手册式 20-40）。这个公式回答的问题是：拼上连接件之后整机矩阵怎么写？其中连接刚度与连接阻尼对应物理里全部弹簧和阻尼器的贡献——它们破坏了块对角结构，两个子结构从此动力耦合。

![柔性连接：连接矩阵引入后的集成运动方程](/images/virtual-prototype-assembly/fig-flexible-coupling-eq.png)

*（图源：LMS 振动/噪声测试与分析系统《Theory and Background》理论手册，第 255 页）*

第三步，回到模态空间求解。手册 20.3.4 节给出七步流程：调出各子结构模态模型构建对角极点阵与带标尺振型阵、合并为总成矩阵、给定连接件产生连接矩阵、给定修改矩阵、用模态矩阵 V 把连接与修改转换到模态空间、叠加对角阵、最后特征值分解。核心一步的坐标变换为：

$$
\{y\} = [V]\{q\}, \qquad [K]_{mod} = [V]^T\,[K]_{conn}\,[V]
$$

这组公式回答的问题是：连接件的刚度如何投影到模态坐标？其中 $[V]$ 对应物理里积木拼装的变换——块对角振型矩阵，投影结果的非对角元素就是连接件在各部件模态之间搭起的桥。特征值分解的产出就是整机的复数极点（含固有频率与阻尼因子）和振型。

## 三、数值演示：两条路线算出同一组数字

把上述流程搬进 numpy。构造一个最小装配体：动力总成 A（2 自由度，单独固有频率 19.49 / 39.79 Hz）、车身 B（2 自由度，单独 12.99 / 25.99 Hz），一根悬置连接 A 的第 2 自由度与 B 的第 1 自由度，刚度 1.2e5 N/m、阻尼 300 N·s/m。路线 1 在物理域直接组装 4×4 矩阵求特征值（真值对照）；路线 2 模拟 VPA——各子结构先各自解出质量归一化模态模型，再把悬置投影进模态空间求解：

```python
import numpy as np
np.random.seed(3)
# ---------- 子结构：动力总成 A (2 DOF)、车身 B (2 DOF)、悬置连接 A2-B1 ----------
mA = np.diag([20.0, 8.0]); kA = np.array([[8e5,-3e5],[-3e5,3e5]]); cA = 1e-4*kA
mB = np.diag([120.0, 60.0]); kB = np.array([[2.4e6,-8e5],[-8e5,8e5]]); cB = 8e-5*kB
km, cm = 1.2e5, 300.0
L = np.zeros((4,4)); L[1,1] = 1.0; L[2,2] = -1.0        # 连接矩阵（式 20-40）

# ---------- 路线 1：物理域直接组装（真值对照） ----------
M = np.zeros((4,4)); M[:2,:2]=mA; M[2:,2:]=mB
K = np.zeros((4,4)); K[:2,:2]=kA; K[2:,2:]=kB; K += km*(L.T@L)
C = np.zeros((4,4)); C[:2,:2]=cA; C[2:,2:]=cB; C += cm*(L.T@L)

def eig_nc(M, C, K):
    n=len(M); Z=np.zeros((n,n)); I=np.eye(n)
    A = np.vstack([np.hstack([Z,I]), np.hstack([-np.linalg.solve(M,K), -np.linalg.solve(M,C)])])
    lam,_ = np.linalg.eig(A); o=np.argsort(np.abs(lam)); lam=lam[o]
    return lam[0::2]                                    # 共轭对取一支

l1 = eig_nc(M, C, K)
print("真值  物理域组装: f =", np.round(np.abs(l1)/2/np.pi,2),
      "Hz  zeta =", np.round(-l1.real/np.abs(l1)*100,2), "%")

# ---------- 路线 2：VPA——子结构各自模态化，模态域组装 ----------
def modal_shapes(m, c, k):
    """返回质量归一化实振型（模拟试验得到的带标尺模态模型）"""
    n=len(m); Z=np.zeros((n,n)); I=np.eye(n)
    A = np.vstack([np.hstack([Z,I]), np.hstack([-np.linalg.solve(m,k), -np.linalg.solve(m,c)])])
    lam, V = np.linalg.eig(A); o=np.argsort(np.abs(lam)); lam,V = lam[o],V[:,o]
    Phi = np.real(V[:n][:,0::2] + V[:n][:,1::2])        # 共轭对合成实振型
    Phi = Phi @ np.diag(1/np.sqrt(np.diag(Phi.T@m@Phi))) # 质量归一
    return Phi

PhiA, PhiB = modal_shapes(mA,cA,kA), modal_shapes(mB,cB,kB)
Phi = np.zeros((4,4)); Phi[:2,:2]=PhiA; Phi[2:,2:]=PhiB  # 集成变换（式 20-46 的 V）
Mm = Phi.T@M@Phi                                         # 模态质量（单位阵）
Km, Cm = Phi.T@K@Phi, Phi.T@C@Phi                        # 连接件投影进模态空间
l2 = eig_nc(np.eye(4), Cm, Km)
print("VPA   模态域组装: f =", np.round(np.abs(l2)/2/np.pi,2),
      "Hz  zeta =", np.round(-l2.real/np.abs(l2)*100,2), "%")

# ---------- 路线 3：模态截断——每个子结构只保留第 1 阶 ----------
Phit = np.zeros((4,2)); Phit[:2,0]=PhiA[:,0]; Phit[2:,1]=PhiB[:,0]
lt = eig_nc(Phit.T@M@Phit, Phit.T@C@Phit, Phit.T@K@Phit)
print("截断  各留 1 阶:  f =", np.round(np.abs(lt)/2/np.pi,2),
      "Hz  zeta =", np.round(-lt.real/np.abs(lt)*100,2), "%")
```

运行结果（实测输出）：

```
真值  物理域组装: f = [13.31 23.53 26.32 42.21] Hz  zeta = [0.79 5.29 1.17 5.58] %
VPA   模态域组装: f = [13.31 23.53 26.32 42.21] Hz  zeta = [0.79 5.29 1.17 5.58] %
截断  各留 1 阶:  f = [13.32 24.08] Hz  zeta = [0.82 7.02] %
```

三个层次的读数值得逐一咀嚼。其一，全模态基下路线 1 与路线 2 四阶频率、阻尼逐位一致——模态域装配在数学上与物理域组装严格等价，VPA 不是近似方案，而是同一问题的另一种坐标写法。其二，装配效应本身很有信息量：车身单独第一阶 12.99 Hz，装上动力总成后系统第一阶 13.31 Hz，第二阶从 25.99 Hz 压到 23.53 Hz——悬置把动力总成的质量挂上车身，整机的低阶模态既不是车身模态也不是动力总成模态，而是两者的混合。其三，截断的代价集中在第二阶：各留 1 阶时第一阶 13.32 Hz 仍准（0.04% 偏差），第二阶 24.08 Hz 偏了 0.55 Hz、阻尼从 5.29% 偏到 7.02%——被截掉的第二阶模态通过悬置参与了耦合，丢掉它就丢掉了这条耦合路径。

最后这个数字直接对应手册 15.5 节的告诫：模态综合法中每个子结构的模态模型截断误差会带入组合结果，改善办法是引进静态补偿项与动态补偿项——由子结构连接点 FRF 矩阵拟合出上残余项，经奇异值分解转换为补偿模态，补偿模态的频率须大大高于装配计算频带（上残余频率一般取计算频带上限的 10 倍）。

## 四、Testlab 中的操作与工程要点

Simcenter Testlab 中 VPA 的入口在 Modification Prediction（修改预测）——手册第二十章的整套理论（子结构集成、连接件、结构修改）在软件里对应同一条工具链：装配所需的各子结构模态模型来自各自的模态试验（Curve Fitting 得到极点与留数，留数经驱动点数据定标成为带标尺振型），连接件以弹簧-阻尼器单元给定，修改件可以是质量、弹簧、阻尼器、梁单元、板单元乃至整个子结构。手册给出的梁单元应用例子最能说明流程：均质平板上加装加强肋，肋离散为 4 个梁单元、在 5 个结点与平板连接，结点位置与试验测点一一对应，梁的截面参数（面积、弯曲惯性矩、扭转惯性矩、弹性模量）由图纸直接给定。

![平板加装加强肋：梁单元离散与连接结点](/images/virtual-prototype-assembly/fig-plate-rib-example.png)

*（图源：LMS 振动/噪声测试与分析系统《Theory and Background》理论手册，第 268 页）*

工程上有三个高频陷阱。第一，振型标尺：装配公式里的 $[V]$ 必须是带标尺振型，没有驱动点测量就没有绝对量纲，两个子结构的振型各自任意缩放时，连接件投影 $[V]^T[K]_{conn}[V]$ 的数值随缩放比例漂移——这是手册把驱动点系数列为模态综合先决条件的原因。第二，连接自由度覆盖：只需得到对结构改变有影响的自由度的振型系数，但连接件所在自由度必须包含在内，漏掉一个连接点的振型系数，该连接件在模态空间就变成悬空。第三，数值条件：手册指出两种情况会让特征值问题病态——不均衡的结构修改（大刚度仿真定位、局部强阻尼）和固有频率范围太宽（自由-自由子结构的刚体模态接近 0 Hz 与高频弹性模态混在一起，最高最低频率比过大）；对策是子结构试验时用合理约束消除纯刚体模态，或在装配前先做子结构的刚体属性提取（质量线法）分离刚体与弹性自由度。

::: warning 工程注意
连接件参数本身是频率依赖的：悬置动刚度在 30 Hz 与 300 Hz 可差数倍，橡胶件还有明显的幅值非线性。用单组弹簧阻尼参数做全频带装配时，预测结果只在参数标定频带内可信；跨频带评估应分段给参数或直接用复刚度 FRF 数据。此外，两个子结构的模态模型如果分别来自试验与有限元，单位制与结点自由度编号必须先对齐——坐标转换错误不会报错，只会给出一组貌似合理的错误极点。
:::

## 五、小结

VPA 的价值链条是：部件级试验模态（准）+ 连接件台架参数（好测）+ 模态空间装配（快）= 整机模态预测（早）。数值演示证实全模态基下它与物理域组装严格等价，截断引入的误差集中在通过连接件强耦合的模态上，静态补偿项是手册给出的标准补救。换悬置、加肋、改衬套在装配模型上都是参数级改动，重解特征值几秒完成——这把"改结构再测一遍"的循环，压缩成了"改参数再算一遍"。

## 一句话记住

VPA 是模态空间的积木拼装：部件模态模型是量好形状的积木，连接件是标定过的拼插口，拼装前就能算出整机模态；全模态基下与物理域严格等价，截断误差靠静态补偿项兜底。
