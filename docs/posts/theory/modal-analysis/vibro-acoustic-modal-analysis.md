# 声振模态分析：车身结构与车内声腔的耦合动力学

> 车内轰鸣问题的诊断中常遇到同一现象：声压级峰对应的既不是结构模态也不是声腔模态，而是两者的耦合模态。LMS 理论手册 15.2.5 节给出的声振模态分析（Vibro-Acoustic Modal Analysis）将结构运动方程与声学方程联立为一个耦合二阶系统——矩阵不对称、激励可以来自结构侧也可以来自声学侧、模态振型一半是节点位移一半是声压。本文从两个域的运动方程出发逐步建立耦合模型，说明不对称性的来源、互易性依然成立的原因、声激励与结构激励之间按特征值平方换算比例因子的依据，最后用 numpy 求解一个"车身板+声腔"最小耦合模型，展示耦合如何使两个独立模态发生频率分裂。

## 一、纯结构模态分析在车内轰鸣问题上的局限

车身模态试验的标准流程为：力锤或激振器扫频激励、拟合 FRF、估计频率、阻尼与振型。将同一流程用于车内声学问题时，会出现数据不一致：驾驶员耳侧声压的峰值频率，在结构模态表中查不到对应峰；而声腔估算的第一阶纵向声腔模态频率，与实测峰值之间又存在数赫兹偏差。

其原因在于：乘员舱是一个封闭空腔，空气具有质量与弹性，本身即构成一个动力学系统，具有自身的模态（声腔模态，Cavity Modes）。地板、顶棚、行李厢隔板等大面积钣金振动时周期性压缩腔内空气，声压反过来对板面施加分布载荷。两个动力学系统互相施加载荷，即构成耦合系统。耦合后系统的模态既不属于板也不属于腔，而是两者的混合形态：频率发生分裂，振型同时包含结构与声腔成分。仅分析结构侧或仅分析声学侧，均无法反映系统完整的动力学特性。

声振模态分析即针对该场景：同时布置加速度计（结构侧）与传声器（声学侧），激励可选用结构激励（激振器、力锤）或声激励（体积加速度源 Q-source），一次性识别耦合系统的模态参数。手册 15.2.5 节指出：以声激励或结构激励情况下的声振测量为基础，可以实施混合的声振分析——两种激励得到的模态模型是一致的。

::: info 核心概念
- **声腔模态（Cavity Mode）**：封闭空腔内空气的固有振动模式，乘员舱第一阶纵向声腔模态通常在 50~60 Hz 量级，恰好覆盖怠速与低档位轰鸣频段
- **声振耦合（Vibro-Acoustic Coupling）**：结构振动激励声压、声压反作用于结构的双向载荷关系，耦合后的模态是结构与声腔的混合形态
- **声振模态分析**：对结构-声腔耦合系统做模态试验与参数估计，输入输出可以混合结构量（力、加速度）与声学量（体积加速度、声压）
- **Q-source**：输出已知体积加速度 Q（m³/s²）的声源，声学域里与"力"对等的激励设备
:::

## 二、耦合方程的建立：从两个域的运动方程出发

### 2.1 结构侧：引入声压载荷项

结构有限元运动方程为标准二阶形式：

$$M_s \ddot{u} + C_s \dot{u} + K_s u = F_s$$

其中 $M_s$、$C_s$、$K_s$ 为结构的质量、阻尼、刚度矩阵，$F_s$ 为系统外部作用力向量（单位 N）。声振耦合引入附加项：与腔内空气接触的板面受声压 $p$（单位 Pa）作用，声压对板面的分布载荷积分后写成矩阵形式 $G\, p$——$G$ 为结构-声耦合矩阵（几何耦合矩阵），将声压场映射为节点力。结构方程变为：

$$M_s \ddot{u} + C_s \dot{u} + K_s u + G\, p = F_s$$

![声振耦合系统的结构侧运动方程（手册 15.2.5 节）](/images/vibro-acoustic-modal-analysis/eq-structure.png)

*（图源：Simcenter Testing Knowledge Base）*

### 2.2 声学侧：非直接形式的声学方程

流体侧不直接采用声压的二阶波动方程，手册采用"非直接的声学方程"——以声压 $p$ 为未知量、右端项是体积加速度 Q 的形式：

$$M_f \ddot{p} + C_f \dot{p} + K_f p = F_q$$

$M_f$、$C_f$、$K_f$ 为声腔的质量、阻尼、刚度矩阵（由波动方程的有限元离散得到），$F_q$ 为声压载荷向量——描述声压-体积加速度关系的矩阵乘以体积加速度源。板的振动排开腔内空气，等效于分布的体积源，该项通过耦合矩阵的转置与结构运动关联：

$$M_f \ddot{p} + C_f \dot{p} + K_f p - G^T \ddot{u} = F_q$$

注意耦合项 $G^T$——转置出现在此处，且作用于 $\ddot{u}$（结构加速度）。板面加速度对空气而言是体积加速度源，因此该项对时间求了两阶导数。

![声学域的非直接声学方程与声压-体积加速度矩阵（手册 15.2.5 节）](/images/vibro-acoustic-modal-analysis/eq-fluid.png)

*（图源：Simcenter Testing Knowledge Base）*

### 2.3 联立：不对称的二阶系统

两个方程联立，未知量合并为一个向量，得到手册所述"描述声振耦合系统特性的方程"：

$$\begin{bmatrix} M_s & 0 \\ -G^T & M_f \end{bmatrix} \begin{bmatrix} \ddot{u} \\ \ddot{p} \end{bmatrix} + \begin{bmatrix} C_s & 0 \\ 0 & C_f \end{bmatrix} \begin{bmatrix} \dot{u} \\ \dot{p} \end{bmatrix} + \begin{bmatrix} K_s & G \\ 0 & K_f \end{bmatrix} \begin{bmatrix} u \\ p \end{bmatrix} = \begin{bmatrix} F_s \\ F_q \end{bmatrix}$$

![声振耦合系统的完整二阶模型（手册 15.2.5 节）](/images/vibro-acoustic-modal-analysis/eq-coupled-full.png)

*（图源：Simcenter Testing Knowledge Base）*

考察质量块与刚度块的构成：$G$ 出现在右上角，$-G^T$ 出现在左下角。两者互为转置且差一个负号——**耦合项一个作用于位移（刚度块位置）、一个作用于加速度（质量块位置），矩阵结构天然不对称**。这就是手册所述"描述声振特性的二阶模型，它明显地有不对称性"。

物理上，这一不对称源于两个域耦合项的求导阶数不一致：声压对结构的作用项 $G\,p$ 与位移向量同列，位于刚度块；结构加速度对流体的作用项 $-G^T\ddot{u}$ 与加速度向量同列，位于质量块。不对称是方程组的结构性属性，不是数值误差。

::: warning 工程注意
不对称不等于病态。手册明确指出：多数多输入-多输出模态参数估计算法并不要求对称性，非对称的基本方程组对识别有效的模态频率、阻尼因子和模态振型没有任何问题。若因求解器或估计程序给出"非对称矩阵"警告而人为强制对称化，反而会偏离物理模型。
:::

## 三、不对称系统的互易性：激励域互换与特征值平方比例因子

### 3.1 互易原理在声振系统里的形式

纯结构系统里，Maxwell-Betti 互易原理说 $H_{ij} = H_{ji}$，FRF 矩阵对称。耦合系统不对称，互易性是否随之失效？并未失效，但表现形式改变。手册给出声振互易的表述：结构自由度与声学自由度之间的互易关系依然成立，只是互易的两个"方向"跨越了物理域——**在结构点激励、声学点测响应，与在声学点激励、结构点测响应，两条传递函数由互易关系联系起来**。

![声振作用的互易原理（手册 15.2.5 节）](/images/vibro-acoustic-modal-analysis/eq-reciprocity.png)

*（图源：Simcenter Testing Knowledge Base）*

这是 Q-source 声学传递函数测量的理论依据。传统 ATF（声学传递函数，Acoustic Transfer Function）测量在悬置点用力锤逐点激励、耳侧放置传声器，每条路径需激励一次；改用 Q-source 放置在耳侧、悬置点布置加速度计的方式，一次测量即可获得全部路径——$P/F$ 与 $A/Q$ 量纲都约化为 $1/\text{m}^2$，两者等价。

### 3.2 比例因子：相差一个特征值的平方

手册同时指出：**结构激励可以用声激励来代替，两种激励得到的模态模型是一致的，但每一模态的比例因子不相同**；从结构方程过渡到声学方程，要求比例因子为相应模态特征值的平方。

具体而言，模态模型的留数具有绝对标尺，标尺由激励方式决定。用激振器在结构点激励，得到"力到位移/加速度"意义下的留数；用 Q-source 在声学点激励，得到"体积加速度到声压"意义下的留数。两者描述的是同一阶耦合模态（频率、阻尼、振型形状完全一样），但两套留数之间相差换算系数——第 $k$ 阶模态相差 $\lambda_k^2$（该阶特征值的平方）。

工程上的含义：声激励数据与结构激励数据混用、或与有限元模型对标时，**不能直接比较留数幅值**，须先对齐比例因子换算。归一化后的振型形状可以直接比较；绝对标尺的比较必须先确认数据来自哪个激励域。

## 四、参数估计：现有方法的直接适用

声振耦合系统的模态参数估计不需要新算法。手册将声振分析列为"模态参数估计的特殊情况"——耦合方程虽然不对称，但仍然是标准的二阶线性系统，15.3 节的方法全部适用。

![模态参数的获取流程（手册图 15-1）](/images/vibro-acoustic-modal-analysis/fig15-1-modal-model.png)

*（图源：Simcenter Testing Knowledge Base）*

实测数据的组织上有一个天然优势：声振试验天然是多参考的。结构激励点、声学激励点（如果有多个 Q-source 位置）构成参考自由度组；响应侧加速度计与传声器混布。多输入整体估计方法（LSCE、FDPI、CMIF 等）适用于这样的数据结构——密频耦合模态的解耦，依靠的是模态参与因子在多个参考点之间的独立变化。

| 维度 | 纯结构模态试验 | 声振模态试验 |
| --- | --- | --- |
| **激励设备** | 力锤、激振器 | 力锤/激振器 或 Q-source（二选一或混用） |
| **响应传感器** | 加速度计 | 加速度计 + 传声器混布 |
| **激励-响应配对** | $a/F$ | $a/F$、$P/F$、$P/Q$、$A/Q$ 混合 |
| **方程组结构** | 对称（互易结构） | 不对称二阶系统 |
| **留数标尺** | 力域统一 | 结构域与声域差 $\lambda_k^2$，逐模态换算 |
| **典型算法** | LSCE、FDPI、MLMM | 同左，多参考整体估计适用 |
| **典型场景** | 白车身、悬架部件 | 整车/内饰车身轰鸣、进排气声腔 |

## 五、Python 演示：板-声腔耦合模型的频率分裂

为直观考察耦合的作用，下面求解一个最小耦合模型：单自由度"板"（质量-弹簧）与单自由度"声腔"（声压自由度，腔内空气的等效质量与弹性）耦合，扫描耦合强度系数 $g$，观察两个固有频率如何从相互独立变为频率分裂。

```python
import numpy as np

# 结构侧：板的模态质量 2 kg，固有 45 Hz（典型车身板件一阶）
ms, fs = 2.0, 45.0
ks = ms * (2*np.pi*fs)**2
# 声学侧：声腔等效模态质量 1 kg，固有 50 Hz（乘员舱一阶纵向声腔量级）
mf, fc = 1.0, 50.0
kf = mf * (2*np.pi*fc)**2

def coupled_modes(g):
    # 组装不对称耦合矩阵（手册 15.2.5 形式的无阻尼版本）
    M = np.array([[ms, 0], [-g, mf]])      # 左下角 -G^T 位于质量块
    K = np.array([[ks, g], [0, kf]])       # 右上角 +G 位于刚度块
    lam = np.linalg.eigvals(np.linalg.solve(M, -K))  # M x'' = -K x
    w = np.sqrt(-lam.real)                 # 取共轭对的正频率部分
    return np.sort(w) / 2 / np.pi

print("耦合强度g   低频模态Hz   高频模态Hz")
for g in [0.0, 20.0, 50.0, 100.0, 150.0]:
    f1, f2 = coupled_modes(g)
    print(f"{g:8.0f}      {f1:7.2f}      {f2:7.2f}")
```

输出中的关键数值：$g=0$ 时两阶模态为 45.00 与 50.00 Hz，相互独立；$g=50$ 时分裂为 43.82 与 51.35 Hz——**低频模态频率下降、高频模态频率上升，间距从 5.00 Hz 增大到 7.53 Hz**。这是耦合模态的频率回避（veering）行为：耦合增强到 $g=150$ 时，间距达到 17.61 Hz。实测轰鸣峰与任何一侧的"理论模态"都不对应时，其频率往往就是分裂后的耦合频率。

再补充激励域换算的数值示例——结构激励与声激励的留数标尺差 $\lambda^2$：

```python
import numpy as np

for name, f in [("板侧模态", 45.0), ("腔侧模态", 50.0)]:
    lam2 = (2*np.pi*f)**2                  # 特征值平方 = (2*pi*f)^2
    print(f"{name} {f:.0f} Hz: 结构-声学留数换算系数 = {lam2:.3e}")
```

输出要点：45 Hz 模态的换算系数约 7.99e4，50 Hz 模态约 9.87e4——同为"特征值平方"，不同模态的系数相差约 23%。混用两种激励域的数据对标留数幅值时，逐模态换算不可省略；若按统一比例因子处理，两阶模态的标尺偏差将超过 20%。

::: tip 试验组织建议
- 激励方式按可行性选择：台架或部件级试验用激振器直接结构激励最直接；整车状态下 Q-source 放耳侧做互易测量，一次测量获得全部 ATF 路径，效率与一致性好
- 响应侧加速度计与传声器混布是声振试验的常态；只测结构侧将丢失声学响应，即丢失耦合信息的一半
- 识别算法选多参考整体估计（LSCE/FDPI 起步，重阻尼内饰上 MLMM），密频耦合模态依靠模态参与因子解耦
- 结构激励与声激励数据混用时，逐模态乘 $\lambda_k^2$ 对齐标尺后再比较留数
:::

## 六、小结

声振模态分析不是新的学科分支，而是模态分析在混合物理域上的自然延伸：结构方程引入声压载荷项、声学方程采用体积加速度源形式，联立为天然不对称的二阶系统——不对称来自两个域耦合项求导阶数的差异，是方程组的结构属性而非缺陷；互易性跨域成立，代价是留数标尺相差特征值平方；参数估计全部沿用多参考整体方法。车内轰鸣频率对不上纯结构或纯声腔模态表时，应首先考虑耦合引起的频率分裂：两个频率接近的模态频率相互分离，实测频率落在两者外侧正是耦合系统的特征。将其作为普通多自由度系统进行试验与拟合，现有工具链可直接沿用。
