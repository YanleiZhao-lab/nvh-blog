# 圆拟合法：复平面上的SDOF模态参数估计

> 从 FRF 共振峰估计模态参数，工程上常用的是半功率（3 dB）带宽法；而在复平面上对共振区数据拟合圆，可以一次得到频率、阻尼和留数三个参数。圆拟合法（Circle Fit）由 Kennedy 和 Pancu 于 1947 年提出，LMS 理论手册对其评价是："在所有单自由度技术中，圆拟合法给出最精确的估计"。本文从单模态 FRF 的复平面轨迹出发推导圆方程，给出频率（最大角度间距法）、阻尼（张角半角公式）、留数（直径乘阻尼因子）三个参数的完整估计链条，并用数值实验展示峰值法 0.3 Hz 的频率偏差如何被圆拟合修正回真值。

## 一、从一条 FRF 到复平面上一个圆

锤击或激振器扫频得到频响函数（FRF, Frequency Response Function）后，每个频率点 $f_i$ 对应一个复数 $H(i\omega_i)$。常规做法看幅频曲线的峰，圆拟合法换一个视角：把所有点画在复平面上（横轴实部、纵轴虚部），共振区附近的点会规整地排成一个圆弧。

这不是巧合，而是单模态分式的数学结构决定的。单自由度（SDOF）假设下，共振区附近的 FRF 可写成（LMS 理论手册式 15-37）：

$$H(i\omega) \approx \frac{A}{i\omega - \lambda} + C$$

其中 $A$ 是该阶模态的**复留数**（含幅值和相位），$\lambda = -\sigma + i\omega_d$ 是极点（$\sigma$ 为阻尼因子，$\omega_d$ 为有阻尼固有频率），$C$ 是复常数——它把分析频带外的高阶、低阶模态影响近似成一个不变的背景，手册里对应上残余项（残余刚度）与下残余项（残余质量）之和。

推导的关键一步是分式变形。$i\omega - \lambda = \sigma + i(\omega - \omega_d)$：实部 $u = \sigma$ 固定，虚部 $v = \omega - \omega_d$ 随频率扫过共振点由负变正。先看 $A$ 为实数的情形（复留数的情形见本段末），有：

$$\frac{A}{i\omega-\lambda} = \frac{A}{u + iv} = \frac{A(u - iv)}{u^2 + v^2}$$

它的实部与虚部恒满足 $H_\mathrm{re}^2 + H_\mathrm{im}^2 = \frac{A}{\sigma} H_\mathrm{re}$，配方后得到圆方程：

$$\left(H_\mathrm{re} - \frac{A}{2\sigma}\right)^2 + H_\mathrm{im}^2 = \left(\frac{A}{2\sigma}\right)^2$$

这是以复数 $A/(2\sigma)$ 为圆心、$|A|/(2\sigma)$ 为半径、且**经过原点**的圆：共振点 $\omega = \omega_d$ 处 $H = A/\sigma$，恰为原点关于圆心的对称点，因此圆的**直径 $d = |A|/\sigma$**（与 FRF 同量纲，位移导纳时单位为 m/N）。复留数的相位 $\arg A$ 只把整个圆绕原点旋转，复常数 $C$ 只把圆平移——两者都不改变半径。于是留数的模直接由圆的大小确定，阻尼因子由数据点沿圆移动的速度确定。

::: info 核心概念
- **圆拟合法（Circle Fit）**：在复平面上对共振区数据点拟合圆，从圆的几何参数反推模态频率、阻尼、留数的 SDOF 估计方法
- **留数（Residue）$A$**：部分分式里每个极点前的复系数，等于模态振型系数乘积再乘比例常数，是有量纲的绝对幅值
- **残余项 $C$**：带外模态在窄带内的近似贡献，圆拟合里体现为复平面上的平移，不影响圆的半径
:::

## 二、三个模态参数全部从圆上读出来

圆拟出来之后，频率、阻尼、留数的读法均有明确的几何与物理对应（手册 15.3.3 节）。

**频率：最大角度间距法。** 把相邻两个频率点的数据点连到圆心，得到一段圆心角。扫频经过共振点时，频率走一小步、复平面上的点却沿圆移动一大段——圆心角变化率最大的那对点，中间夹的就是固有频率。这比在幅频谱上找最高谱线精细：谱线是离散的，真实峰很可能落在两条谱线之间，而圆心角间距用的是整段圆弧的形状信息，对峰的位置具有插值能力。

**阻尼：张角半角公式。** 在共振点两侧各取一个数据点，频率为 $\omega_1$、$\omega_2$，它们与共振点的圆心角分别为 $\theta_1$、$\theta_2$。由上节的圆方程可推出，数据点相对圆心的幅角（以共振点为零位）为 $-2\arctan\frac{\omega-\omega_d}{\sigma}$，于是半角关系为：

$$\tan\frac{\theta_1}{2} = \frac{\omega_d - \omega_1}{\sigma}, \qquad \tan\frac{\theta_2}{2} = \frac{\omega_2 - \omega_d}{\sigma}$$

物理意义：张角一半的正切，等于该点偏离共振的频率量与阻尼因子之比。阻尼因子 $\sigma$ 越小（弱阻尼），同样的频率偏移对应的张角越大，整段圆弧在很窄的频带内就被扫完——这正是弱阻尼系统共振峰尖锐在复平面上的体现。两式相加消去 $\omega_d$：

$$\sigma = \frac{\omega_2 - \omega_1}{\tan(\theta_1/2) + \tan(\theta_2/2)}$$

于是 $\zeta = \sigma / \omega_n$（$\omega_n$ 为无阻尼固有频率，弱阻尼时 $\omega_n \approx \omega_d$）。注意这里的 $\omega_1$、$\omega_2$ 只是两个数据点自身的频率，既不要求两点对称，也不要求落在半功率点（half-power point）上——3 dB 法必须找到幅值恰降 3 dB 的位置，谱线离散时该位置可能不存在；圆拟合任取共振点两侧各一点，公式本身完成精确换算。

**留数：直径乘阻尼因子。** $|A| = d \cdot \sigma$，$d$ 是拟合圆直径，$\sigma$ 是刚算出的阻尼因子；留数的相位 $\arg A$ 对应圆在复平面里的方位（图 15-6）。有了每个测点的留数，除以比例常数后就是模态振型系数——频率、阻尼、振型三要素齐了，一整套模态模型齐了。

::: warning 工程注意
圆拟合法的两个失效前提都写在 SDOF 假设里：
- **振型节点附近**：留数趋零，圆缩成一个点，手册明确指出此时"仍可能产生大的误差"，这是方法原理决定的限制，不是操作失误
- **模态耦合**：分析频带内两阶模态分不开时，复平面轨迹是两个圆的叠加而非一个圆，拟合残差会明显增大——应先检查轨迹是否接近圆弧，再决定是否拟合
:::

## 三、数值验证：36 条谱线下峰值法与圆拟合的对比

构造一组单模态窄带 FRF 仿真数据：固有频率 30.2 Hz、阻尼比 2.5%、留数带相位（0.8-0.6j）、残余项带相位（0.15+0.10j），36 条谱线覆盖 28.5~32 Hz。用代数法拟合圆（$x^2+y^2 = ax + by + c$ 线性最小二乘），再按上面三步读参数：

```python
import numpy as np

fn, zt = 30.2, 0.025                       # 真值：固有频率 Hz、阻尼比
wn = 2*np.pi*fn
lam = -zt*wn + 1j*wn*np.sqrt(1-zt**2)      # 极点 λ = -σ + jωd
A, C = 0.8-0.6j, 0.15+0.10j                # 复留数、带外残余项（复常数）
f = np.linspace(28.5, 32.0, 36)            # 窄带内 36 条谱线
H = A/(2j*np.pi*f - lam) + C               # 手册式(15-37)

print(f"幅值谱峰点频率 = {f[np.abs(H).argmax()]:.2f} Hz（真值 {fn}）")

# 代数圆拟合：x²+y² = a·x + b·y + c 线性最小二乘
x, y = H.real, H.imag
M = np.c_[x, y, np.ones_like(x)]
a, b, c = np.linalg.lstsq(M, x**2+y**2, rcond=None)[0]
cx, cy = a/2, b/2                          # 圆心 (a/2, b/2)
R = np.sqrt(c + cx**2 + cy**2)             # 半径

# 频率：相邻谱线对圆心的张角最大处
th = np.arctan2(y-cy, x-cx)
dth = np.abs(np.diff(np.unwrap(th)))
k = dth.argmax() + 1
print(f"最大角度间距 fn = {f[k]:.3f} Hz")

# 阻尼：两点法 tan(θ/2)=|ω-ωd|/σ，两式相加消去 ωd
i1, i2 = k-12, k+12
t1, t2 = abs(th[i1]-th[k]), abs(th[k]-th[i2])
sig = 2*np.pi*(f[i2]-f[i1]) / (np.tan(t1/2)+np.tan(t2/2))
print(f"圆拟合 ζ = {sig/wn:.4f}（真值 {zt}）")

# 留数幅值 = 直径×阻尼因子
print(f"留数 |A| = {2*R*sig:.3f}（真值 {abs(A):.3f}）")
```

运行输出：

```
幅值谱峰点频率 = 29.90 Hz（真值 30.2）
最大角度间距 fn = 30.200 Hz
圆拟合 ζ = 0.0250（真值 0.025）
留数 |A| = 1.000（真值 1.000）
```

最值得看的数字是第一行和第二行的对比：幅值谱最高谱线在 29.90 Hz，偏离真值 0.3 Hz——因为真实峰恰好落在两条谱线之间；而最大角度间距法给出 30.200 Hz，与真值一致。阻尼 0.0250、留数 1.000 同样命中真值。手册"圆拟合法给出最精确的估计"的结论在此得到验证：峰值法受谱线离散化限制，圆拟合利用的是整段圆弧的几何信息，不受单条谱线位置的约束。

## 四、适用边界：密频模态的数值实验

圆拟合法的局限来自 SDOF 假设本身。在窄带里再叠一阶模态，复平面轨迹随即变形——变形程度取决于两阶模态留数的相对符号和频率间隔。用同样的拟合代码量化一下：

```python
import numpy as np

# 密频双模态：间隔小于一个半功率带宽（1.50 Hz）
fn1, zt = 30.0, 0.025
w1 = 2*np.pi*fn1; BW = 2*zt*w1             # 半功率带宽（rad/s）
for A2 in (0.7, -0.7):
    for df in (0.54, 0.30):
        fn2 = fn1 + df
        w2 = 2*np.pi*fn2
        f = np.linspace(fn1-0.8, fn2+0.8, 35)
        w = 2*np.pi*f
        lam1 = -zt*w1 + 1j*w1; lam2 = -zt*w2 + 1j*w2
        H = 1.0/(1j*w-lam1) + A2/(1j*w-lam2)   # 双模态叠加

        x, y = H.real, H.imag
        a, b, c = np.linalg.lstsq(
            np.c_[x, y, np.ones_like(x)], x**2+y**2, rcond=None)[0]
        cx, cy = a/2, b/2
        R = np.sqrt(c + cx**2 + cy**2)
        resid = np.abs(np.hypot(x-cx, y-cy) - R).max()
        print(f"A2={A2:+.1f} 间隔{df:.2f}Hz"
              f"({df/(BW/2/np.pi):.2f}倍带宽): "
              f"径向残差 {100*resid/R:5.1f}% 半径")
```

运行输出：

```
A2=+0.7 间隔0.54Hz(0.36倍带宽): 径向残差   2.2% 半径
A2=+0.7 间隔0.30Hz(0.20倍带宽): 径向残差   0.6% 半径
A2=-0.7 间隔0.54Hz(0.36倍带宽): 径向残差  12.9% 半径
A2=-0.7 间隔0.30Hz(0.20倍带宽): 径向残差  10.3% 半径
```

两个数字对比出一条实用判据：留数同号（对应同一测点上两阶模态同相参与，如车身边梁的两阶同向弯曲）时，即使模态间隔只有 0.36 倍带宽，残差也不过 2.2%，圆拟合仍然可信；留数反号（节点两侧测点常见）时残差直接跳到 12.9%，圆已明显变形，继续拟合得到的频率和阻尼误差会显著增大。整车车身的一阶扭转与一阶弯曲有时只差几 Hz，若测点位于两阶振型的反相区，就会遇到这种工况。

CMIF（复模态指示函数，Complex Mode Indicator Function）可在此发挥作用：它对每条谱线的 FRF 矩阵做奇异值分解，密频模态在 CMIF 曲线上会分开成两个峰。手册给出的处理流程是——先用 CMIF 确定模态个数和频率，对每个模态生成解耦的**增强 FRF**（Enhanced FRF），再对增强 FRF 做圆拟合拿精确的频率、阻尼和比例因子。圆拟合法并未被 MDOF 方法取代，而是作为 CMIF 之后的精修步骤继续使用。

## 五、方法选型：圆拟合在参数估计家族里的位置

LMS 理论手册把参数估计方法按"自由度数—域—估计策略—输入数"四个维度分类，圆拟合的定位是频域、局部、单输入。对照着看：

| 方法 | 可识别参数 | 自由度 | 域 | 估计策略 | 输入 |
| --- | --- | --- | --- | --- | --- |
| **峰检索** | 频率、阻尼 | 单 | 频域 | 局部 | 单 |
| **模态检出** | 模态振型 | 单 | 频域 | 局部 | 单 |
| **圆拟合法** | 频率、阻尼、模态振型 | 单 | 频域 | 局部 | 单 |
| **CMIF** | 频率、阻尼、模态振型 | 多 | 频域 | 整体 | 单或多 |
| **LSCE** | 频率、阻尼、模态参预因子 | 多 | 时域 | 整体 | 单或多 |
| **LSFD** | 模态振型 | 多 | 频域 | 整体 | 单或多 |
| **FDPI** | 频率、阻尼、模态参预因子 | 多 | 频域 | 整体 | 单或多 |

时域 MDOF 法（LSCE 一族）是最常用的参数估计技术，手册认为它很可能成为模态分析的标准工具；但其适用边界手册同样明确：不适合阻尼比大于 5% 的强阻尼系统（如全内饰车身）。频域 MDOF 法（FDPI）与之互补：特别适合强阻尼系统，而阻尼比低于 3% 的轻阻尼系统是它的弱项。SDOF 家族中的圆拟合法计算量小、结果直观、精度最高，手册建议将其用于检查试验设置——传感器是否都正常工作并正确标定、加速度计安装的结点和方位是否正确标记、结点处是否都安装了测量装置。

::: tip 选择原则
- **首轮筛查 / 单条 FRF 快速估计**：圆拟合法，速度快、精度高，一次得到频率、阻尼、振型三个参数
- **密频、耦合模态**：CMIF 定频率 → 增强 FRF → 圆拟合精修；直接对原始 FRF 拟合，残差可达 10% 量级
- **强阻尼系统（ζ > 5%，内饰车身）**：不宜用时域 MDOF 法，选频域直接识别（FDPI）
- **测点落在振型节点附近**：更换测点或改用其他方法，留数趋于零后任何 SDOF 方法误差都会增大
:::

## 六、小结

圆拟合法的工程价值建立在三点事实上：频率用最大角度间距法定位，绕开了谱线离散化对峰值法的限制（数值实验中 0.3 Hz 的偏差被修正到真值）；阻尼用张角半角公式，不依赖半功率点的存在性；留数等于直径乘阻尼因子，几何量与物理量一一对应。使用前应先检查复平面轨迹是否接近一段圆弧：接近，它就是精度最高的 SDOF 估计工具（手册结论）；明显偏离，说明 SDOF 前提不再成立，应改用 CMIF 增强 FRF 或 MDOF 整体估计。
