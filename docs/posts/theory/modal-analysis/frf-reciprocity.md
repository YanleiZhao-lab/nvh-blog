# FRF 互易性：换激励点与响应点，结果为什么不变

> 锤击法做模态试验时，"激励固定、加速度计移动"和"加速度计固定、锤子移动"测到的 FRF 是同一批函数——这不是巧合，而是 Maxwell-Betti 互易原理的直接推论。互易性决定了锤击试验的测点布局逻辑，也是声学传递路径测量里 Q-source 一次测完 12 条路径的底气。它什么时候成立、什么时候失效、失效了怎么补救，这篇从留数矩阵推起。

## 一、从一条 FRF 到一个 FRF 矩阵

单输入单输出测量的频响函数（FRF，Frequency Response Function）写成 $H_{ij}(\omega) = X_i / F_j$：在 $j$ 点激励、$i$ 点测响应。但如果结构上有 $N$ 个测点，任意两点之间都存在一条传递函数，全部写出来就是一个 $N \times N$ 的 FRF 矩阵，对角线上的元素是驱动点（Driving Point）FRF。

矩阵里 $N^2$ 个元素不独立。对满足 Maxwell-Betti 互易原理的线性结构，矩阵是对称的：

$$H_{ij}(\omega) = H_{ji}(\omega)$$

物理含义一句话：**在 $j$ 点敲、$i$ 点测，与在 $i$ 点敲、$j$ 点测，得到的是同一条曲线**。激励点和响应点的角色可以互换。

这个性质太有用了。9 个测点的试验，理论上要测的 $9\times 9 = 81$ 条传递函数（每个测点三个方向则是 $27\times 27$），利用对称性实际只需要测一行或一列。这就是锤击法模态试验的整体组织方式。

## 二、推导：留数矩阵为什么天然对称

结论不是天上掉下来的，从模态模型出发走三步。

**第一步，写出 FRF 的模态叠加表达式。** 多自由度线性结构的频响函数可以表示为各阶模态留数（Residue）之和：

$$H_{ij}(\omega) = \sum_{k=1}^{n} \left[ \frac{A_{k,ij}}{j\omega - p_k} + \frac{A^*_{k,ij}}{j\omega - p^*_k} \right]$$

其中 $p_k$ 是第 $k$ 阶极点（含频率和阻尼信息），$A_{k,ij}$ 是第 $k$ 阶模态中连接 $i$、$j$ 两点的留数。

**第二步，拆留数。** 留数可以分解为一个与测点无关的比例因子和两个模态振型系数的乘积：

$$A_{k,ij} = Q_k \, \psi_i(k) \, \psi_j(k)$$

$\psi_i(k)$、$\psi_j(k)$ 分别是第 $k$ 阶振型在 $i$、$j$ 自由度上的系数，$Q_k$ 是比例常数（比例阻尼时为纯虚数，与归一化方式有关）。这一步的物理意义：每阶模态对任意两点间传递的贡献，等于响应点振型分量、激励点振型分量与模态强度三者的乘积。

**第三步，交换 $i$ 和 $j$。** 乘法满足交换律：

$$A_{k,ji} = Q_k \, \psi_j(k) \, \psi_i(k) = A_{k,ij}$$

每一阶模态的留数都对称，求和之后整个 FRF 矩阵自然对称。这就是 lms-theory 手册 18.4 节给出的互易性数学表述——"测量在 j 自由度激励下 i 自由度响应得到的 FRF，与测量在 i 自由度激励下 j 自由度的响应得到的 FRF 是一样的"。

倒过来看更有工程味：留数的可分解性意味着**模态振型向量和模态参预因子（Modal Participation Factor）扮演的角色可以互换**。对满足互易性的结构，模态参预因子应正比于参考点（激励点）处的振型系数——这给了一条用多参考数据检验互易性是否成立的途径。

::: info 核心概念
- **互易性（Reciprocity）**：$H_{ij} = H_{ji}$，激励与响应角色互换、传递函数不变
- **留数（Residue）**：模态模型中每阶模态的强度系数，可分解为 $Q_k\psi_i\psi_j$
- **模态参预因子**：多参考模态试验中描述各输入点对每阶模态激励有效性的量
- **驱动点 FRF**：激励与响应同一点的 $H_{jj}$，互易性校验和模态质量定标的唯一数据来源
:::

## 三、互易性的三个工程红利

### 红利一：锤击试验只需测一行或一列

9 测点、每点三方向的试验共有 27 个可能输入和 27 个可能输出。要得到相位一致的完整振型，所有测量必须共享同一个参考——对应到 FRF 矩阵上，就是**测满完整的一行或完整的一列**。

![27 个输入对 27 个输出的完整测量表](/images/frf-reciprocity/io-table.png)

*（图源：Simcenter Testing Knowledge Base）*

- **移加速度计**（锤固定敲 $F_{1z}$）：三向加速度计每挪一个点，就同时填满该点在行中的三个元素。9 个点测完，一行齐了，只需 9 次测量。
- **移动锤子**（加速度计固定）：锤单向敲击每敲一个点只填一列中的一个元素。要凑齐完整列，必须在每个测点沿 x、y、z 三个方向都敲——平板中间做不到垂直面内敲击，这正是社区文章里"roving hammer 得不到完整振型"的坑。

![互易性保证：完整一行或一列即可](/images/frf-reciprocity/row-or-column.png)

*（图源：Simcenter Testing Knowledge Base）*

![移加速度计：9 次测量填满一行](/images/frf-reciprocity/roving-accel-complete.png)

*（图源：Simcenter Testing Knowledge Base）*

互易性的价值在这里显形：因为 $H_{ij}=H_{ji}$，这"一行"同时就是矩阵的一列，两种方案在数学上等价，工程上选省事的那种——但前提是别把单方向锤击当成了完整测量。

![移动锤子单向敲击：凑不出完整行或列](/images/frf-reciprocity/roving-hammer-incomplete.png)

*（图源：Simcenter Testing Knowledge Base）*

### 红利二：互易性校验是模态数据质量的免费体检

多参考试验中，把不同参考下提取的同一阶振型与参预因子对比：互易性成立时两者成正比，比例关系散乱则说明数据有问题——锤击位置不准、传感器质量载荷改变了结构、或结构本身非线性。不用额外测量，拟合完顺手就能查。

### 红利三：声学路径测量一次顶十二次

整车声学传递函数（ATF）测量中，传统做法是用锤子在 4 个悬置点沿 3 个方向逐个激励、驾驶员耳侧测声压，得到 12 条 $P/F$ 传递函数，做 12 次测量。利用互易性换一套测法：把已知体积加速度源（Q-source）放在耳侧声学响应点，4 个悬置点上贴加速度计，**一次测量同时得到全部 12 条路径**。道理在量纲：$P/F$ 与 $A/Q$ 的单位都约化为 $1/\text{m}^2$，两者等价——这正是互易原理在结构-声耦合系统上的体现。

## 四、Python 演示：对称矩阵的 FRF 天生互易

```python
import numpy as np

m1, m2 = 2.0, 3.0                  # 两质量 (kg)
k1, k2, k3 = 4000., 6000., 5000.   # 三弹簧刚度 (N/m)
zeta = 0.02                        # 目标模态阻尼比

M = np.diag([m1, m2])
K = np.array([[k1+k2, -k2], [-k2, k2+k3]])

# 比例阻尼 C = beta*K, beta 按两阶固有频率凑出 zeta
w2 = np.linalg.eigvalsh(np.linalg.solve(M, K))
beta = 2*zeta/np.sqrt(w2).mean()
C = beta*K

print("固有频率:", np.round(np.sqrt(w2)/2/np.pi, 2), "Hz")
for f in [8.0, 12.5, 20.0]:
    w = 2*np.pi*f
    H = np.linalg.inv(-w**2*M + 1j*w*C + K)   # FRF 矩阵
    print(f"f={f:5.1f} Hz | H12={abs(H[0,1]):.4e} | H21={abs(H[1,0]):.4e} | 差={abs(H[0,1]-H[1,0]):.1e}")

# 破坏 K 对称(如旋转结构陀螺耦合), 互易性即失效
Kb = K.copy(); Kb[0,1] *= 1.5
w = 2*np.pi*12.5
H = np.linalg.inv(-w**2*M + 1j*w*C + Kb)
print(f"非对称K f=12.5Hz: |H12|={abs(H[0,1]):.4e} | H21={abs(H[1,0]):.4e} 比={abs(H[0,1])/abs(H[1,0]):.3f}")
```

运行结果要点：对称 $K$ 下三个频率点 $H_{12}$ 与 $H_{21}$ 的差都在 $10^{-19}$ 量级（机器精度，完全互易）；把 $K_{12}$ 破坏 1.5 倍后比值立刻变成 1.499——互易性随矩阵对称性一起死掉。留数表达式 $Q_k\psi_i\psi_j$ 里乘法可交换，但前提是动力学矩阵本身对称。

## 五、互易性什么时候失效

互易性是对线性、定常、且动力学矩阵对称的结构的奖赏。常见失效源：

| 失效源 | 机理 | 典型场景 |
| --- | --- | --- |
| **陀螺耦合** | 旋转引入反对称陀螺项 $G$，$K+G$ 不再对称 | 陀螺飞轮、涡轮轴、离心压气机叶轮 |
| **非比例阻尼/主动控制** | 阻尼矩阵破坏模态解耦的对称结构 | 带主动悬置、半主动悬架控制的整车 |
| **结构非线性** | 预载、间隙、摩擦使传递函数依赖激励水平 | 松动的螺栓连接、橡胶悬置大变形 |
| **测量系统不一致** | 不是结构失效，而是标定/方向/位置错 | 通道灵敏度录错、锤击点偏移 |

表里最后一行是假失效。互易性校验查出问题，第一反应应该是查测量本身：两个通道的灵敏度、方向定义、几何坐标是否一致。手册为此给出了强制互易的处理办法：若数据不满足互易性，可用互易性比例因子（RSF）对所有驱动点数据做最小二乘平均，把模型"扳"回对称。

::: warning 工程注意
多参考锤击试验中，如果不同参考下提取的模态参预因子与振型系数不成比例，先别怀疑结构——九成是某个参考点的锤击位置敲偏了或方向录错了。互易性校验的价值正在于把测量错误从结构属性里剥离出来。
:::

## 六、小结

判断清单直接给：

- 锤击模态试验，测满 FRF 矩阵的**一行或一列**即可，行/列选择靠互易性背书；移动锤子时务必每个点敲满三个方向，否则振型不完整
- 拟合完做一次**互易性校验**（振型 vs 参预因子成正比），免费的质保手段
- 声学路径用 **Q-source 反着测**（源放响应点、加速度计放激励点），12 次并成 1 次
- 旋转结构、含主动控制的系统、明显非线性的连接，互易性可能失效，别拿互易性去要求这些数据
- 互易性不满足时，先查通道灵敏度、方向、坐标一致性，再考虑 RSF 强制对称
