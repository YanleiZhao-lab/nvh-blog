# 刚体属性提取：用FRF质量线反算质量、质心与转动惯量

> 动力总成悬置设计、路噪传递分析、碰撞模型标定，第一步都绕不开同一组数：质量、质心、转动惯量。CAD 模型给的惯量往往缺油液、缺附件、缺线束，算出来的悬置模态能差出好几赫兹。锤击模态试验里那一排"没峰的平直段"其实是宝贝——刚体段 FRF 的质量线，逐谱线读出的就是惯性制约力，把它代入运动学方程组最小二乘求解，能直接反算出实测状态下的质心坐标和惯量张量。这篇从 $F = ma$ 的刚体段物理出发，推导质量线反算惯量的完整链条，讲清测点布置的最低配置、频带选取的三种工况，最后用 numpy 造一台"假发动机"把质心、绕轴惯量、主轴方位全部算出来。

## 一、为什么 CAD 惯量撑不起悬置设计

六自由度刚体模态解耦是悬置设计的经典目标：沿三个方向的平动、绕三个轴的转动，各自的频率和能量分布由悬置三向刚度和动力总成惯量属性共同决定。设计输入里那组 $m$、质心坐标、$I_{xx}/I_{yy}/I_{zz}/I_{xy}/I_{yz}/I_{xz}$，任何一项偏差都会顺着能量解耦率传导到模态频率上。

问题在于这组数很难拿准。数字样机里没有油液、没有冷却工质、没有装配偏差，进排气歧管和线束的密度估算更是随意；台架上拆装过的试验件，跟图纸状态早就不是一回事。悬置刚度的匹配裕度通常只有百分之几，惯量差 10% 就足以让滚转模态撞上怠速激励频率。

模态试验给了另一条路。自由悬挂（软吊或气囊）状态下测得的一组 FRF，在低于第一阶弹性模态的频段内，整个结构近似作刚体运动——这段 FRF 里藏着实测惯量。

::: info 核心概念
- **刚体模态（Rigid Body Mode）**：结构无内部变形、整体平移或转动的运动形式，自由-自由状态下有 6 个，频率由支承刚度而非结构本身决定
- **质量线（Mass Line）**：高于刚体模态、低于第一阶弹性模态的频段内，加速度导纳趋近常数 $1/m$ 的平直线段，反映惯性制约力
- **惯量张量（Inertia Tensor）**：3×3 对称阵，对角线为轴转动惯量，非对角为惯量积，完整描述刚体绕参考点的转动惯性
:::

## 二、质量线为什么能反算惯量：从 F = ma 到最小二乘

### 2.1 刚体段的加速度导纳

单自由度系统加速度导纳（Accelerance，$A(\omega) = a/F$）的高频渐近行为，上一篇《动刚度、导纳与机械阻抗》里推过：分子分母同时被 $\omega^2$ 主导，极限为 $1/m$。把视角换成刚体动力学更直接——频段内所有弹性变形模态都没被激起，结构响应完全由刚体运动方程决定：

$$F_i(\omega) = m \cdot a_{cog,i}(\omega), \qquad M_o(\omega) = I\,\alpha(\omega)$$

前者是平动：任意测点 $p$ 的响应通过刚体运动学约束 $a_p = a_{ref} + \alpha \times r_p$ 关联到参考点；后者是转动：力矩除以角加速度就是惯量。质量线读出的不是单一质量，而是一组过约束的惯性方程。

### 2.2 运动学约束：测点响应拼出参考加速度

设参考点加速度 $\{a_r\}$（3 分量）和角加速度 $\{\alpha\}$（3 分量）共 6 个未知量。任意测点 $p$（位置 $r_p$，总体坐标）的测量加速度满足：

$$\begin{Bmatrix} a_p \end{Bmatrix} = \begin{Bmatrix} a_r \end{Bmatrix} - [\tilde r_p]\{\alpha\}$$

其中 $[\tilde r_p]$ 是位置矢量 $r_p$ 的反对称叉乘矩阵。对选定频带内**所有谱线、所有测点、所有输入**列方程，得到超定方程组，逐谱线最小二乘解出参考加速度矩阵——这是流程第一步。

*（图源：Simcenter Testing Knowledge Base）*

### 2.3 动力学方程：两步解出质心与惯量

力这一侧做同样的坐标变换。第 $i$ 个输入在作用点 $r_i$ 施力 $F_i$，等价到参考点是一个力加一个力矩 $M = r_i \times F_i$：

![参考力矩阵：输入力向参考点简化为力与力矩](/images/rigid-body-properties/force-eq.png)

*（图源：Simcenter Testing Knowledge Base）*

把牛顿-欧拉方程按总体坐标展开。合力等于质量乘质心加速度：

$$\sum F_i = m\,a_{cog} = m\left(a_r + \alpha \times r_{cog}\right)$$

两边除以 $m$，把叉乘展开成 $[\tilde\alpha]\,r_{cog}$ 移项，得到**前三个方程**——未知量只有质心坐标 $X_{cog}, Y_{cog}, Z_{cog}$，每条谱线每个输入各贡献 3 个方程，最小二乘直接解出质心。这是第一步。

合力矩等于动量矩变化率，对参考点取矩、代入已解出的 $r_{cog}$，展开后得到**后六个方程**——未知量是 3 个轴转动惯量加 3 个惯量积。第二步接着最小二乘。

![两步求解方程组：前三个方程解质心，代入后六个方程解转动惯量与惯量积](/images/rigid-body-properties/two-step-eq.png)

*（图源：Simcenter Testing Knowledge Base）*

::: info 方程组结构
- **第一步（质心）**：$\sum F_i / m - a_r = [\tilde\alpha]\{r_{cog}\}$，线性于质心坐标，无需先知质量
- **第二步（惯量）**：$\sum r_i \times F_i - m\,(a_r \times r_{cog}) = [I]\{\alpha\} + m\,[\tilde r_{cog}](\alpha \times r_{cog})$，惯量张量 6 个独立分量线性出现
- **主轴（可选）**：对 $[I]$ 解特征值问题 $[I]\{u\} = I_p\{u\}$，特征值为主转动惯量，特征向量为惯量主轴方向余弦
:::

## 三、试验怎么做才够格：测点、频带、三种质量线取法

### 3.1 最低配置与工程配置

理论上 2 个激励、6 个响应即可凑满方程；手册基于实践给出的配置门槛要高得多——**至少 6 个激励（2 个点 × 3 方向）、12 个响应**。原因很朴素：方程组要的是几何多样性。所有测点都布在一条 z 轴线上时，绕 z 转动的方程全部退化，$I_{zz}$ 永远解不出来；这就是运动学约束线性相关的典型坑。

![图19-1 刚体模态：六个刚体自由度与分析频带的选取区间](/images/rigid-body-properties/fig19-1-rigid-body-modes.png)

*（图源：Simcenter Testing Knowledge Base）*

### 3.2 频带：夹在刚体模态与第一弹性模态之间

分析频带在**最高刚体模态与最低弹性模态的中间区段**选取，按总体最小二乘意义求解。频带太低，悬置弹簧力还没退场，质量线被支承刚度污染；频带太高，弹性模态的影子已经压过来。

质量线取值按手册分三种情形，从优到劣：

| 情形 | 刚体-弹性频率间距 | 质量线取法 | 附加处理 |
| --- | --- | --- | --- |
| **理想** | 足够大 | 直接用实测 FRF 实部（带符号） | 无需修正 |
| **偏紧** | 间距不够 | 用修正后的 FRF 实部 | 先从实测 FRF 中扣除弹性模态贡献（可用综合 FRF） |
| **困难** | 刚体段无法精确测量 | 用模态分析的下残余项 | 下残余项物理上就代表低于弹性模态的刚体影响 |

::: warning 三个高频翻车点
- **单位**：输入数据必须是力→加速度（m/s²/N 或 g/N），且要带绝对标尺；转角参数、无量纲量不能进方程
- **坐标一致性**：测点局部坐标、参考坐标、总体坐标三套系统不统一时，先做转移矩阵变换再列方程，否则质心坐标系统错位
- **质心已知时**：可直接跳过第一步，把给定质心代入第二步只解惯量——但质心错了惯量跟着错，慎用
:::

### 3.3 这组数还有什么用

刚体模态的价值不止于出惯量报表。检验测量设置：刚体模态动画里某测点运动"不合理"，直接暴露漏测、方向标反、灵敏度标错；补充稀疏测量：用六个刚体运动的计权系数外推非测量自由度，改善动画骨架线；校正误差：重算系数与实测对比量化噪声；子结构耦合：基于质量、惯量、主轴和用户给定阻尼频率，按 $R = \omega^2 m$（平动）/ $R = \omega^2 I/(x_r f_r)$（转动）综合出刚体模态，接入整体模态模型做修改预测。

## 四、Python 演示：造一台"假发动机"反算全套刚体属性

### 4.1 质心：三组激励的过约束最小二乘

设一台 62 kg 的动力总成，真实质心在总体坐标 $(0.15, -0.06, 0.08)$ m。三个方向不同的角加速度工况下测得合力，合力除以 $m$ 与角加速度叉乘质心的关系给出 9 个方程解 3 个未知量——给测量加 1% 噪声看鲁棒性：

```python
import numpy as np

rng = np.random.default_rng(3)

def skew(v):
    # 反对称叉乘矩阵：skew(a) @ b = a x b
    return np.array([[0, -v[2], v[1]],
                     [v[2], 0, -v[0]],
                     [-v[1], v[0], 0]])

m = 62.0                                   # 总质量 kg
cog_true = np.array([0.15, -0.06, 0.08])   # 真实质心 m
alphas = np.array([[1.2, -0.8, 0.5],       # 三个工况的角加速度 rad/s^2
                   [2.5,  0.4, -1.6],
                   [-0.7, 1.9, 0.9]])

rows, rhs = [], []
for al in alphas:
    # 刚体合力 F = m*a_cog = m*(alpha x r_cog)，加 1% 噪声模拟测量
    F = m * np.cross(al, cog_true) * (1 + rng.normal(0, 0.01, 3))
    rows.append(skew(al))                  # 每工况 3 行： [~alpha] r_cog = F/m
    rhs.append(F / m)

cog_hat, res, *_ = np.linalg.lstsq(np.vstack(rows), np.hstack(rhs), rcond=None)
print("真值质心   :", cog_true)
print("反算质心   :", np.round(cog_hat, 4))
print("误差 (mm)  :", np.round((cog_hat - cog_true) * 1e3, 2))
```

运行结果要点：1% 力测量噪声下，质心三个分量的误差都在 ±2 mm 以内——三个不共线方向的激励工况足够把质心钉死；工况角加速度方向越接近共线，这个数字恶化得越快。

### 4.2 绕轴惯量：力偶激励下的刚体段读数

刚体段频带内对 $y$ 轴打一对力偶（力偶矩 $T$ 作用在 $xz$ 平面内），测角加速度 $\alpha_y = T / I_y^{(O)}$，其中 $I_y^{(O)}$ 是对参考原点的表观惯量。改变参考点位置重复测量，平行轴定理把"表观惯量"和"质心惯量"拆开：

```python
import numpy as np

m, Iyy_cog, d = 62.0, 3.20, 0.15      # 质量、质心处 Iyy、质心偏离原点 x 距离

I_origin = Iyy_cog + m * d**2         # 平行轴：对原点的表观惯量
for lever, T in [(0.40, 120.0),       # 力偶作用在 x=0.40，力偶矩 120 N·m
                 (0.55, 150.0)]:
    alpha = T / I_origin              # 刚体段读数：角加速度只认对原点的惯量
    print(f"杠杆 {lever:.2f} m | 力偶矩 {T:.0f} N·m -> "
          f"alpha = {alpha:.4f} rad/s², 反算 I(O) = {T/alpha:.3f} kg·m²")

I_at_040 = Iyy_cog + m * 0.25**2      # 把参考点挪到 x=0.40（距质心 0.25 m）
print(f"对原点 I = {I_origin:.3f}，对 x=0.40 I = {I_at_040:.3f}，"
      f"平移量 m*d² = {I_at_040 - I_origin:.3f}")
```

运行结果要点：两处不同参考点反算的 $I(O)$ 都是 4.595 kg·m²——刚体段测量只认参考点表观惯量；从原点挪到 x=0.40 m，表观惯量从 4.595 涨到 7.075，多出的 2.480 恰是 $m d^2$ 项。不知道质心位置就想直接报"转动惯量"，报的其实是平行轴污染后的数字。

### 4.3 惯量张量对角化：主值与主轴一步到位

第二步方程组解出的 3×3 惯量矩阵（对称、非对角为惯量积）做特征值分解，就是手册里的主转动惯量特征值问题：

```python
import numpy as np

# 第二步最小二乘解出的惯量矩阵（kg·m²）：对角=轴惯量，非对角=惯量积
I = np.array([[2.80,  0.30, -0.20],
              [0.30,  3.20,  0.25],
              [-0.20, 0.25,  1.10]])

I_prin, axes = np.linalg.eigh(I)      # 对称阵特征值问题 = 主惯量/主轴
print("主转动惯量 (kg·m²):", np.round(I_prin, 3))
print("主轴方向余弦 (按列):\n", np.round(axes, 3))
print("惯量积非零的代价: 主轴偏离总体坐标最大",
      round(np.degrees(np.arccos(abs(axes).max(axis=0)).max()), 1), "度")
```

运行结果要点：主值 1.039 / 2.693 / 3.368 kg·m² 没有一个等于对角线元素——0.30 和 -0.20 的惯量积把主轴拧偏了 8 度上下；eigh 自动给出升序主值和正交主轴，且对称惯量阵的主值恒为正，物理上天然成立。

## 五、小结

刚体属性提取的本质是把模态试验里最不起眼的一段数据——没有共振峰的平直质量线——变成一台免费的惯性天平。执行层面记三条：测点布置保几何多样性，2 点 6 向激励 + 12 响应是工程底线，所有测点共线则相应转轴惯量无解；频带卡在最高刚体模态与最低弹性模态正中间，间距不足时先扣弹性模态贡献或改用下残余项；反算流程两步走——先解质心再解惯量，质心给定的捷径只在数据来源可靠时走。报出的惯量值必须同时注明参考点，没注明参考点的"转动惯量"在悬置解耦计算里就是定时炸弹。
