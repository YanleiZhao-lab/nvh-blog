# 刚体属性提取：用FRF质量线反算质量、质心与转动惯量

> 动力总成悬置设计、路噪传递路径分析与碰撞模型标定共用同一组惯性参数输入：质量、质心与转动惯量。CAD 模型通常缺少油液、冷却工质、附件与线束，据此导出的惯量数据与实测状态存在系统偏差，而悬置刚度匹配的裕度通常只有百分之几。自由悬挂模态试验提供了另一条途径：低于第一阶弹性模态的频段内结构近似作刚体运动，该频段 FRF 的质量线（Mass Line）反映惯性制约力，将逐谱线读出的质量线代入一组运动学方程与动力学方程，按总体最小二乘求解，即可反算实测状态下的质心坐标与惯量张量。本文从刚体动力学出发推导该方法的完整流程，给出测点配置的最低要求与频带选取的三种情形，并用 numpy 数值算例检验质心、绕轴惯量与主轴方位的求解精度。

## 一、CAD 惯量数据的局限与试验反算思路

六自由度刚体模态解耦是悬置设计的经典目标：沿三个坐标轴的平动模态与绕这三个轴的转动模态，其频率与能量分布由悬置三向刚度和动力总成惯量属性共同决定。设计输入中的质量 $m$（kg）、质心坐标（m）与惯量张量六个独立分量 $I_{xx}/I_{yy}/I_{zz}/I_{xy}/I_{yz}/I_{xz}$（kg·m²），任一项偏差都会经能量解耦率传递到模态频率。

这组数据难以从数字样机直接获得：模型中没有油液与冷却工质，不考虑装配偏差，进排气歧管与线束的密度只能估算；台架上拆装过的试验件与图纸状态也存在差异。悬置刚度匹配裕度通常只有百分之几，惯量偏差 10% 即可能使滚转模态频率进入怠速激励频段。

模态试验给出另一条路径。自由悬挂（软吊或气囊支承）状态下测得的 FRF，在低于第一阶弹性模态的频段内，结构近似作整体刚体运动，该频段的 FRF 即包含实测惯量信息。

::: info 核心概念
- **刚体模态（Rigid Body Mode）**：结构无内部变形、整体平移或转动的运动形式，自由-自由（Free-Free）状态下有 6 个，频率由支承刚度与阻尼而非结构本身决定
- **质量线（Mass Line）**：高于刚体模态、低于第一阶弹性模态的频段内，加速度导纳趋近常数 $1/m$ 的平直线段，反映结构的惯性制约力
- **惯量张量（Inertia Tensor）**：3×3 对称矩阵，对角线为轴转动惯量，非对角线为惯量张量分量，完整描述刚体绕参考点的转动惯性
:::

## 二、质量线反算惯量的原理：从 F = ma 到总体最小二乘

### 2.1 刚体段的加速度导纳

单自由度系统加速度导纳（Accelerance，$A(\omega) = a/F$）的高频渐近行为在上一篇《动刚度、柔度与导纳：一族 FRF 的换算关系》中已推导：分子分母同时被 $\omega^2$ 主导，极限为 $1/m$。从刚体动力学角度看更直接——该频段内所有弹性变形模态均未被激起，结构响应完全由刚体运动方程决定：

$$\{F\} = m\,\{a_{cog}\}, \qquad \{M_{cog}\} = [I_{cog}]\,\{\alpha\}$$

前者为平动方程：合力等于质量乘质心加速度；后者为转动方程：关于质心的合力矩等于质心惯量矩阵乘角加速度。任意测点的响应通过刚体运动学约束关联到参考点，因此质量线读出的不是单一质量，而是一组过约束的惯性方程。

### 2.2 运动学方程：由测点响应解参考加速度

设参考点加速度 $\{a_r\}$（3 分量）与角加速度 $\{\alpha\}$（3 分量）共 6 个未知量。任意测点 $p$（总体坐标位置 $r_p$，m）的测量加速度满足刚体运动学约束：

$$\{a_p\} = \{a_r\} - [\tilde r_p]\,\{\alpha\}$$

其中 $[\tilde r_p]$ 为位置矢量 $r_p$ 的反对称（Skew-symmetric）叉乘矩阵，$[\tilde r_p]\{\alpha\} = r_p \times \alpha$。对选定频带内所有谱线、所有测点、所有输入列方程，得到超定方程组；逐谱线以最小二乘求解参考加速度矩阵，再求涵盖全部频带、全部输出与全部谱线的总体最小二乘（Global Least Squares）综合解——这是流程的第一步。

*（图源：Simcenter Testing Knowledge Base）*

### 2.3 动力学方程：两步解出质心与惯量

力这一侧作同样的坐标变换。第 $j$ 个输入在作用点 $r_j$ 施加力 $F_j$（N），向参考点简化为一个力与一个力矩 $M_j = r_j \times F_j$（N·m）：

![参考力矩阵：输入力向参考点简化为力与力矩](/images/rigid-body-properties/force-eq.png)

*（图源：Simcenter Testing Knowledge Base）*

平动质量线的水平值给出 $1/m$，即得总质量 $m$。将牛顿方程按总体坐标展开，合力等于质量乘质心加速度 $a_{cog} = a_r + \alpha \times r_{cog}$：

$$\{F_j\} = m\left(\{a_{r,j}\} + \{\alpha_j\} \times \{r_{cog}\}\right)$$

两边除以 $m$，把叉乘改写为 $[\tilde\alpha]\{r_{cog}\}$ 并移项，得到**前三个方程**——未知量仅为质心坐标 $X_{cog}, Y_{cog}, Z_{cog}$（m）：

$$\frac{\{F_j\}}{m} - \{a_{r,j}\} = [\tilde\alpha_j]\,\{r_{cog}\}$$

每个输入、每条谱线各贡献 3 个方程，总体最小二乘直接解出质心，这是第一步。

转动方程对参考点取矩（欧拉方程），代入已解出的 $r_{cog}$，得到**后六个方程**——未知量为关于参考点的 3 个轴转动惯量与 3 个惯量张量分量（kg·m²）：

$$\{r_j\} \times \{F_j\} - m\left(\{r_{cog}\} \times \{a_{r,j}\}\right) = [I_{ref}]\,\{\alpha_j\}$$

惯量矩阵 $[I_{ref}]$ 的 6 个独立分量在方程中线性出现，每个输入、每条谱线贡献 3 个方程，第二步继续总体最小二乘。

![两步求解方程组：前三个方程解质心，代入后六个方程解转动惯量与惯量张量分量](/images/rigid-body-properties/two-step-eq.png)

*（图源：Simcenter Testing Knowledge Base）*

::: info 方程组结构
- **第一步（质心）**：$\{F_j\}/m - \{a_{r,j}\} = [\tilde\alpha_j]\{r_{cog}\}$，对质心坐标线性；总质量 $m$ 由平动质量线水平值 $1/m$ 直接给出
- **第二步（惯量）**：$\{r_j\} \times \{F_j\} - m(\{r_{cog}\} \times \{a_{r,j}\}) = [I_{ref}]\{\alpha_j\}$，惯量矩阵 6 个独立分量线性出现；关于参考点的惯量与关于质心的惯量之间由平行轴定理（Parallel-axis Theorem）换算：$[I_{ref}] = [I_{cog}] + m\left[(r_{cog} \cdot r_{cog})E - r_{cog}r_{cog}^{T}\right]$，其中 $E$ 为单位矩阵
- **主轴（可选）**：对 $[I]$ 解特征值问题 $[I]\{u\} = I_p\{u\}$，特征值为主转动惯量（Principal Moments of Inertia），特征向量为惯量主轴（Principal Axes of Inertia）方向余弦
:::

## 三、试验配置要求：测点、频带与质量线取法

### 3.1 最低配置与工程配置

理论上 2 个激励、6 个响应即可满足方程数要求；手册基于实践给出的配置门槛更高——**至少 6 个激励（2 个点各三个方向）、12 个响应**。原因在于方程组需要几何多样性：所有测点都布置在同一条 z 轴线上时，绕 z 轴转动的方程全部线性相关，$I_{zz}$ 无法解出，这是运动学约束线性相关的典型情形。

![图19-1 刚体模态：六个刚体自由度与分析频带的选取区间](/images/rigid-body-properties/fig19-1-rigid-body-modes.png)

*（图源：Simcenter Testing Knowledge Base）*

### 3.2 频带选取与质量线取值

分析频带应在**最高刚体模态与最低弹性模态的中间区段**选取，刚体属性按总体最小二乘意义求出（参看图19-1）。频带过低，支承弹簧力尚未退出，质量线中混入支承刚度的影响；频带过高，弹性模态的贡献已经进入。

质量线取值按手册分三种情形（按优先顺序）：

| 情形 | 刚体-弹性频率间距 | 质量线取法 | 附加处理 |
| --- | --- | --- | --- |
| **一** | 足够大 | 直接用实测 FRF 的实部（带正负号） | 无需修正 |
| **二** | 间距不够 | 用修正后 FRF 的实部 | 先从实测 FRF 中扣除弹性模态的贡献（可用综合 FRF） |
| **三** | 刚体段无法精确测量 | 用模态分析的下残余项（Lower Residual） | 下残余项代表低于变形模态的那些模态的影响，物理上即刚体模态的贡献 |

::: warning 三个常见错误来源
- **单位**：输入数据必须是力→加速度（(m/s²)/N 或 g/N），且要带绝对标尺；转角参数与其它无标尺参数不能参与刚体属性计算
- **坐标一致性**：测点局部坐标、参考坐标、总体坐标三套系统不统一时，必须先作转移矩阵变换再列方程，否则质心坐标整体错位
- **质心给定的捷径**：质心已知时可跳过第一步、直接解第二步惯量方程；但质心偏差会直接传递到惯量结果，仅在质心数据来源可靠时使用
:::

### 3.3 刚体模态分析的其他应用

刚体属性与刚体模态的用途不止于惯量报表：

1. **检验测量设置**：当测量频段涵盖刚体运动频率时，峰检索与模态动画可直接暴露四类失误——测点漏测（该点完全无运动）、响应点标示出错（运动偏离合理位置）、响应方向标反（往相反方向运动）、传感器故障或标定值出错（幅值异常），前四类均可通过刚体模态的曲线拟合检查出来
2. **补充非测量自由度**：从测量数据求出结构六种刚体运动的计权系数，将同样的权加到非测量自由度的运动上，在维持刚体运动几何约束的前提下外推稀疏测点，改善骨架线动画
3. **校正测量误差**：用同样的计权系数重算已测自由度的振型系数，与实测值对比可量化各类失误与测量噪声，也可以计算值替换测量数据以平滑振型
4. **基于几何数据的模态综合**：以质量、转动惯量、惯量主轴方位及用户给定的频率和阻尼为基础综合刚体模态，留数按下式计算（左为平动、右为转动）：

$$R = \frac{1}{\omega^2 m}, \qquad R = \frac{x_r f_r}{\omega^2 I}$$

其中 $m$ 为总质量（kg），$\omega$ 为用户给定的有阻尼固有频率（rad/s），$f_r$ 与 $x_r$ 分别为参考自由度与响应自由度到相关惯量主轴的垂直距离（m），$I$ 为刚体对该主轴的转动惯量（kg·m²）。综合出的刚体模态可用于完善模态模型、实施结构修改预测，或将两个分别识别的子结构模态模型耦合。

## 四、Python 数值算例

### 4.1 质心：多样工况的过约束最小二乘

设一台 62 kg 的动力总成，真实质心位于总体坐标 $(0.15, -0.06, 0.08)$ m。6 个工况的参考点加速度与角加速度方向多样，按第一步方程组解质心，每个力分量施加 1% 噪声模拟测量误差：

```python
import numpy as np

rng = np.random.default_rng(3)

def skew(v):
    # 反对称叉乘矩阵：skew(a) @ b = a x b
    return np.array([[0, -v[2], v[1]],
                     [v[2], 0, -v[0]],
                     [-v[1], v[0], 0]])

m = 62.0                                    # 总质量 kg
cog_true = np.array([0.15, -0.06, 0.08])    # 真实质心 m

rows, rhs = [], []
for _ in range(6):
    a_r = rng.normal(0, 0.3, 3)             # 参考点加速度 m/s²（第一步已解出，视为已知）
    al  = rng.normal(0, 2.5, 3)             # 角加速度 rad/s²，方向多样
    # 刚体合力 F = m (a_r + alpha x r_cog)，各分量施加 1% 噪声模拟测量
    F = m * (a_r + np.cross(al, cog_true)) * (1 + rng.normal(0, 0.01, 3))
    rows.append(skew(al))                   # 每工况 3 行：[~alpha] r_cog = F/m - a_r
    rhs.append(F / m - a_r)

cog_hat = np.linalg.lstsq(np.vstack(rows), np.hstack(rhs), rcond=None)[0]
print("真值质心   :", cog_true)
print("反算质心   :", np.round(cog_hat, 4))
print("误差 (mm)  :", np.round((cog_hat - cog_true) * 1e3, 2))

# 工况方向多样性的影响：条件数对比
rng = np.random.default_rng(7)
diverse = rng.normal(0, 2.5, (6, 3))                          # 方向多样
rng = np.random.default_rng(7)
collinear = np.array([2.5, 0.15, 0.1]) + rng.normal(0, 0.15, (6, 3))  # 趋于共线
print("方程组条件数（方向多样）  :",
      round(np.linalg.cond(np.vstack([skew(a) for a in diverse])), 2))
print("方程组条件数（趋于共线）:",
      round(np.linalg.cond(np.vstack([skew(a) for a in collinear])), 2))
```

运行结果：真值 $(0.15, -0.06, 0.08)$，反算 $(0.150, -0.061, 0.080)$，三分量误差 $-0.04 / -0.98 / -0.28$ mm——1% 力测量噪声下质心误差在 1 mm 量级。条件数（Condition Number）对比显示工况设计的影响：角加速度方向多样时方程组条件数约 1.5，趋于共线时升至约 16.5，同等噪声水平下误差随之放大。这与 3.1 节的结论一致：激励方向与测点位置都需要几何多样性。

### 4.2 绕轴惯量：刚体段读数与参考点换算

刚体段频带内，过质心的简谐力只激起平动，加速度导纳趋于 $1/m$；绕 y 轴的纯力偶（力偶矩 $T$，N·m）只激起绕 y 轴转动，读数为 $1/I_{yy}^{(cog)}$。第二步解出的惯量矩阵默认关于参考点，换算参考点用平行轴定理：

```python
import numpy as np

m = 62.0                                  # 总质量 kg
r_cog = np.array([0.15, -0.06, 0.08])     # 质心 m
I_cog = np.diag([2.8, 3.2, 1.1])          # 关于质心的惯量矩阵 kg·m²

# (a) 刚体段质量线读数：过质心的力与绕质心的纯力偶
print("平动质量线 1/m   = %.5f (m/s²)/N = %.6f g/N" % (1/m, 1/m/9.81))
T = 120.0                                 # 绕 y 轴纯力偶 N·m
print("转动质量线 1/Iyy = %.4f -> alpha = %.1f rad/s²" % (1/3.2, T/3.2))

# (b) 解出的惯量矩阵换算参考点：平行轴定理
def I_about(p):
    r = r_cog - np.asarray(p, float)      # 参考点相对质心的位置
    return I_cog + m * ((r @ r) * np.eye(3) - np.outer(r, r))

I1 = I_about((0, 0, 0))                   # 对参考原点（求解时默认参考点）
I2 = I_about((0.40, 0, 0))                # 参考点移到 x = 0.40 m
print("I(参考原点) =")
print(np.round(I1, 3))
print("I(x=0.40) =")
print(np.round(I2, 3))
print("Iyy: %.3f -> %.3f, 差值 m(0.25²-0.15²) = %.2f"
      % (I1[1, 1], I2[1, 1], m * (0.25**2 - 0.15**2)))
```

运行结果要点：

- 平动质量线 $1/m = 0.01613$ (m/s²)/N（0.001644 g/N），即 $m = 62$ kg
- 力偶矩 120 N·m 下角加速度 37.5 rad/s²，转动质量线 $1/I_{yy} = 0.3125$，即 $I_{yy}^{(cog)} = 3.2$ kg·m²
- 同一惯量矩阵关于参考原点时 $I_{yy} = 4.992$ kg·m²；参考点移到 $x = 0.40$ m（质心 x 坐标 0.15 m，参考点相对质心移动 0.25 m）后变为 7.472 kg·m²，增量 2.48 kg·m² 恰为平行轴项 $m(0.25^2 - 0.15^2)$

同一物理刚体，参考点不同则惯量矩阵不同。报告转动惯量必须同时注明参考点，未注明参考点的数值无法直接用于悬置解耦计算。

### 4.3 惯量矩阵对角化：主值与主轴

对第二步解出的 3×3 对称惯量矩阵作特征值分解，即手册中的主转动惯量特征值问题：

```python
import numpy as np

# 第二步最小二乘解出的对称惯量矩阵（kg·m²）
# 对角线 = 轴转动惯量，非对角 = 惯量张量分量（含符号）
I = np.array([[2.80,  0.30, -0.20],
              [0.30,  3.20,  0.25],
              [-0.20, 0.25,  1.10]])

I_prin, axes = np.linalg.eigh(I)          # 对称矩阵特征值问题
print("主转动惯量 (kg·m²):", np.round(I_prin, 3))
print("主轴方向余弦（按列）:")
print(np.round(axes, 3))
print("主轴与总体坐标轴最大偏角 (°):",
      round(np.degrees(np.arccos(abs(axes).max(axis=0)).max()), 1))
```

运行结果要点：主值 1.039 / 2.693 / 3.368 kg·m²，没有一个等于矩阵的对角线元素 2.80 / 3.20 / 1.10；0.30 与 -0.20 量级的非对角分量使主轴偏离总体坐标轴最大 28.0°。eigh 给出升序主值与正交主轴，且对称惯量矩阵的主值恒为正，与物理一致。

## 五、小结

刚体属性提取利用的是模态试验中没有共振峰的平直频段：质量线反映惯性制约力，经两步总体最小二乘——先解质心、再解惯量矩阵六分量——得到实测状态下的完整惯性属性。执行要点三条：

1. **测点与工况保几何多样性**：工程配置至少 6 个激励（2 点 × 3 方向）加 12 个响应；激励方向趋于共线或测点共线都会使相应转轴的方程退化、条件数上升
2. **频带选在最高刚体模态与最低弹性模态的中间区段**：间距不足时先扣除弹性模态的贡献，刚体段无法精确测量时改用模态分析的下残余项
3. **报告数值必须注明参考点**：不同参考点的惯量矩阵之间由平行轴定理换算；质心已知时可直接解第二步，但质心偏差会全部传递到惯量结果
