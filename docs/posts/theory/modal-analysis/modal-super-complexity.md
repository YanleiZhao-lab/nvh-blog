# 模态超复性与相位共线性：复模态的两个判据

> 同一条振型，两台机器拟合出的频率阻尼完全一致，动画播放时一台的节线纹丝不动、另一台的节线却在缓慢"爬行"——为什么？区别在于后者的振型系数相位不再是非 0° 即 180°，而是逐点偏转了一个角度。就像一排人齐步走（正则模态，所有人同起同落）与一排人玩"人浪"（复模态，起落有先后），乍看都是"在振动"，物理结构却已不同。本文从"人浪"这个相位滞后现象切入，说明复模态从哪里来、MPC（模态相位共线性）如何用一条直线检验它、MOV（模态超复性值）如何用"附加质量必降频"这一物理特性给振型打分，并给出两者联合判读的工程流程。

## 一、为什么动画里的节线会"爬行"

模态试验交付评审时最常被追问的一幕：振型动画播放到一阶扭转模态，观众席里有人指出"节线在动"。按理说，一阶扭转的节线应当是一条固定不动的线，两侧的测点反相摆动、同时过零。可屏幕上，本应同时过零的几个测点出现了肉眼可辨的先后错动，节线位置随时间在一个小范围内来回挪动。

这不是动画软件的渲染问题，而是数据本身在说话：**这条振型的相位结构已经不是"正则模态"了**。正则模态（normal mode）下，同一阶振型里每个测点的运动只有两种相位——0°（与参考同相）或 180°（反相），如同齐步走的队伍，所有人同起同落，节线天然固定。而实测数据里，各测点的相位常常是 0°、−17°、−35°、−52°……逐点往后拖，像体育场里的"人浪"：每个观众只比邻座晚一点点，单独看谁都没乱动，整体上却形成一个不断移动的波峰。

数学上，这对应振型系数从实数变成了复数：每个测点的系数不再只是"正负多少"，而是"幅值多少、相位几度"。这种振型称为<strong>复模态（complex mode）</strong>。它从哪里来？当结构阻尼不再成比例——比如车身上局部贴了阻尼片、某处连接阻尼特别大——运动方程无法在模态坐标下解耦，特征向量本身就是复数；此外，测量噪声、带宽外的模态残留、拟合算法的病态解，也会把一条本来正则的振型"拟合"出相位散乱来。前者是真复模态（结构固有的），后者是假象（估计出来的），**工程上必须区分这两者，因为对待方式完全不同**：真复模态要如实保留复数振型参与后续分析，假象则要从稳定图上剔除重估。

本文讨论 Simcenter LMS 模态理论手册 18.6–18.7 节给出的两个判据：MPC 检验"复得有多厉害"（相位形态），MOV 检验"是不是物理模态"（质量灵敏度）。两者一个看形、一个验骨，配合使用。

::: info 核心概念
- <strong>正则模态（Normal Mode）</strong>：比例阻尼结构的实数振型，各测点相位非 0° 即 180°，如齐步走
- <strong>复模态（Complex Mode）</strong>：振型系数相位逐点偏转的模态，如"人浪"，源于非比例阻尼或估计误差
- <strong>模态超复性（Overcomplexity）</strong>：振型系数相位角"复得过头"、超越合理界限的现象，MOV 指数的命名由来
- <strong>MPC（Modal Phase Collinearity）</strong>：模态相位共线性，检验复平面内振型系数是否排成一条直线
- <strong>MOV（Modal Overcomplexity Value）</strong>：模态超复性值，用"附加质量必使固有频率下降"给振型打分
:::

## 二、复模态的物理：从"齐步走"到"人浪"

先把"人浪"定量化。设想一条 8 个测点的梁，比例阻尼下其一阶弯曲振型为 $\psi = [1.0,\ 0.87,\ 0.5,\ 0.25,\ -0.25,\ -0.7,\ -0.87,\ -1.0]$——纯实数，前四个点同相（系数为正），后四个点反相（系数为负），中间过节线。这是齐步走：任取两个测点，相位差要么 0° 要么 180°。

现在在梁中段贴一大块阻尼片。阻尼力不再与"质量×刚度"的分布成比例，运动方程解耦失败，振型系数获得各不相同的相位角：$\psi_i$ 变成 $|\psi_i|\,e^{j\theta_i}$，其中 $\theta_i$ 在原有 0°/180° 的符号结构上叠加了从 0° 逐点滞后到约 −50° 的附加相位。观察任意时刻各测点的位移：$|\psi_i|\cos(\omega t + \theta_i)$——相位滞后意味着峰值时刻推迟，于是波峰像人浪一样从测点 1 "走"向测点 8。节线不再固定：不同时刻位移过零的位置在梁上缓慢移动，这就是动画里"爬行的节线"。

*（图示：复模态示意——8 个测点的摆动相位从 0° 逐点滞后到 −50°，波峰自左向右移动，节线随之漂移）*

::: tip 先看一个数字
一条 12 测点的振型，若各测点相位在 0°/180° 符号结构上叠加 0°→−50° 的均匀滞后（相邻约 −4.5°/点），这些系数画在复平面上将不再落在实轴上，按第三节公式算得其 MPC 约 69%——"像不像一条直线"是可以用一个数回答的，且这个数对滞后量相当敏感：滞后范围增至 −60° 时 MPC 降到 57%。
:::

需要注意的是区分两种来源。结构真有局部大阻尼（阻尼片、橡胶连接、约束层结构）时，复模态是结构固有属性，拟合结果是"真"的；而带宽选错、信噪比差、极点定偏时，拟合算法会把噪声组织成一条"相位散乱的振型"，这是"假"的。真复模态的相位滞后沿结构空间有序分布（哪里阻尼大哪里滞后多），假象的相位散乱则无空间规律——这正是后续判读的抓手。

## 三、MPC：复平面上的一条直线

MPC（Modal Phase Collinearity，模态相位共线性）回答的问题是：<strong>这组复振型系数在复平面上到底有多像一条直线？</strong>

理解它只需要一个图像：把每个测点的振型系数 $\psi_i$ 画到复平面上（横轴实部、纵轴虚部）。正则模态的所有点严格落在实轴上——同相的点在正方向、反相的点在负方向，构成一条过原点的直线。复模态的点则偏离这条直线，相位拧得越厉害，散得越开。MPC 就是"这串点共线程度"的量化，取值 0–100%。

先给直觉再给公式：想象把一把筷子撒在桌面上，MPC 度量的就是这些筷子"抱团成一把"的程度——全部排成一条线是 100%，向四面八方散开趋向 0%。实现上，MPC 对（实部，虚部）点做主轴拟合：把数据绕原点旋转一个角度，找总投影能量最大的那根"主轴"，主轴能量占总能量的比例即共线性。具体地，先累积三个统计量

$$S_{xx}=\sum_{i} \mathrm{Re}^2(\psi_i), \qquad S_{yy}=\sum_{i} \mathrm{Im}^2(\psi_i), \qquad S_{xy}=\sum_{i} \mathrm{Re}(\psi_i)\,\mathrm{Im}(\psi_i)$$

这三个求和公式回答的问题是：数据在实轴、虚轴方向各自累积了多少"能量"，以及两个方向之间关联多强？其中 $S_{xx}$、$S_{yy}$ 对应实部与虚部的平方和（各自方向的"长度"信息），$S_{xy}$ 对应实虚部的交叉项（共线的"方向"信息）。有了它们，共线性闭式解为

$$\mathrm{MPC} = \frac{\left(S_{xx}-S_{yy}\right)^{2} + 4\,S_{xy}^{2}}{\left(S_{xx}+S_{yy}\right)^{2}} \times 100\%$$

这个公式回答的问题是：数据在最优直线方向上的投影能量占总能量的比例是多少？其中分子是数据沿复平面主轴的"线性能量"（共线时取到最大），分母是总能量 $\left(S_{xx}+S_{yy}\right)^2$，比值即为"直的程度"。

![复平面上的振型系数：正则模态所有点排成一条过原点的直线，复模态相位逐点偏转、散离开直线](/images/modal-super-complexity/complex-plane.png)
*（图示：按第二节算例数据绘制——左图为正则振型，MPC = 100%；右图为 0°/180° 符号结构上叠加 0°→−50° 逐点滞后的复模态，MPC ≈ 56%）*

判读标准：<strong>正则模态 MPC 接近 100%</strong>。数值低说明振型在某种程度上是复模态——要么结构上确有局部阻尼元件（真复模态），要么测量或拟合环节不良（假象）。物理根源可以追溯到共振特性：正则模态下结构响应落后激振力 90°，拟合出的留数应为纯虚数；实部里残存的分量正是噪声、泄漏、带外模态污染的痕迹。MPC 高，说明这些干扰被压制住了。

## 四、MOV：附加质量必使固有频率下降

MPC 检查"形"，MOV（Modal Overcomplexity Value，模态超复性值）检查"骨"——它不看点在复平面上的排布，而是用一条**无法伪造的物理特性**给振型打分：**在结构任一测点上附加质量，所有模态的有阻尼固有频率必然下降**。

这条特性对单自由度系统一目了然——固有频率 $f=\sqrt{k/m}/2\pi$，质量增大、频率必然降低。多自由度结构同样成立，只是"降多少"因测点而异：在振型幅值大的测点（腹点）加质量，该阶频率降得多；在节线附近加，几乎不降。对第 $k$ 阶模态，逐测点计算固有频率对该测点质量增加的灵敏度 $\partial f_k/\partial m_i$，物理模态在**所有**测点上该灵敏度均应为负。

MOV 定义为"灵敏度为负的测点"所占的加权百分比：

$$\mathrm{MOV}_{k} = \frac{\sum_{i} \gamma_{ik}\,\delta_{ik}}{\sum_{i} \gamma_{ik}} \times 100\%$$

这个公式回答的问题是：附加质量的降频特性在这条振型的多少比例测点上成立？其中 $\gamma_{ik}$ 是加权因子（取 1 不加权，或取振型系数幅值 $|\psi_{ik}|$，让腹点更有话语权），$\delta_{ik}$ 是指示函数——第 $k$ 阶模态在测点 $i$ 的频率-质量灵敏度为负时取 1，否则取 0。

对高质量振型，<strong>MOV 应接近 100%</strong>。数值偏低有两种典型情形：该"模态"只是计算模态（从噪声中拟合出的非物理极点，不描述真实振动，物理特性自然对不上），或拟合有缺陷。它叫"超复性"（over-complexity，直译"复得过头"），是因为这种病的根源正是相位角超越了合理界限——上一节人浪的比喻里，浪"走"得太远、相位滞后超过物理允许的范围，质量灵敏度就会集体失去负号。

MOV 最实用的一个应用是**抓激振力方向输反**：如果对某一个特定输入点，所有模态的 MOV 都很低（手册示例低于 10%），多半是测量该输入点 FRF 时激振力方向设错了。这种系统性错误只影响一个输入点对应的整列振型系数，修正方法是把所有模态对该输入点的模态参预因子整体改号后复算——不必重测。

## 五、联合判读：先排错误，再定性质

两个指标分工明确：MOV 用物理定律筛"真伪"，MPC 用几何形态量"复简"。工程判读按固定顺序进行，先排除测量错误，再下模态性质的结论：

1. <strong>先看 MOV 的群体特征。</strong> 同一输入点全部模态 MOV 集体偏低 → 激振力方向输反，改号复算即可；个别模态 MOV 低 → 从稳定图剔除或重新拟合，多数是计算模态。
2. <strong>再看 MPC/MPD。</strong> MOV 正常而 MPC 低 → 振型相位已"复"，结合结构上是否存在真实的局部阻尼（阻尼片、橡胶连接）判断真伪：有物理来源且相位滞后沿空间有序分布，是真复模态，如实保留；无物理来源、相位散乱无规律，回查拟合带宽与极点。
3. <strong>辅以 MPD（Mean Phase Deviation，平均相位偏差）</strong>：各振型系数相位角对加权平均值的统计偏差，直接给"度数"。经验读数：5° 以内动画节线稳定；20° 以上肉眼可见节线爬行；45° 量级多数已非物理模态。

*（图示：判读决策流程，按本文第五节整理）*

下面用 numpy 把"人浪"数字化，亲眼看两个指标如何区分三类振型：干净的齐步走（正则）、拧歪的人浪（复模态）、以及一条从噪声里拟出来的"假振型"。

```python
import numpy as np

n = 12                                   # 测点数
x = np.arange(n)
# 1) 正则振型：齐步走，相位非 0 即 180 度
psi_normal = np.cos(np.pi * x / 5)
# 2) 复模态：人浪，在 0/180 符号上叠加逐点滞后 0 -> -50 度
sign = np.where(psi_normal < 0, 180, 0)
psi_wave = np.abs(psi_normal) * np.exp(1j * np.deg2rad(sign - 50 * x / (n - 1)))
# 3) 假振型：随机相位（模拟噪声拟合产物）
rng = np.random.default_rng(3)
psi_fake = np.abs(psi_normal) * np.exp(1j * rng.uniform(-180, 180, n))

def mpc(psi):
    re, im = psi.real, psi.imag
    sxx, syy, sxy = np.sum(re*re), np.sum(im*im), np.sum(re*im)
    return ((sxx - syy)**2 + 4*sxy*sxy) / (sxx + syy)**2 * 100

def mov(psi):
    # 频率-质量灵敏度符号正比于 -|psi_i|^2（腹点加质量降频最多）
    return np.mean(-np.abs(psi)**2 < 0) * 100

for name, psi in [("normal", psi_normal), ("wave   ", psi_wave), ("fake   ", psi_fake)]:
    print(f"{name}  MPC = {mpc(psi):5.1f}%   MOV = {mov(psi):5.1f}%")
```

运行输出（幅度分布相同时）：

```text
normal  MPC = 100.0%   MOV = 100.0%
wave     MPC =  68.5%   MOV = 100.0%
fake     MPC =  22.5%   MOV = 100.0%
```

三个读数各说了一件事：齐步走（正则振型）两项全满分；人浪（真复模态）MPC 降到 68.5%——相位确实拧了、但滞后沿梁有序分布、幅度结构物理合理；假振型 MPC 崩到 22.5%——相位完全随机、复平面上散成一盘沙。注意 MOV 在简化模型里全为 100%：本例把灵敏度写成 $-|\psi_i|^2$ 的符号，只反映幅度结构；真实 MOV 用的是估计极点对质量扰动的灵敏度，还会暴露计算模态与力方向错误，这也是它被排在判读第一步的原因。

## 六、Testlab 里的对应位置

Simcenter Testlab 模态参数拟合（PolyMAX / MLMM 等）的结果表单中，每阶模态一行，MPC、MPD、MOV 作为标准列直接给出，无需手工计算：

- **Mono-reference / Multi-reference 拟合工作表**：结果网格中调出 MPC、MPD、MOV 列，与频率、阻尼比并排显示
- <strong>稳定图（Stabilization Diagram）</strong>：筛选极点时按 MOV 阈值过滤，直接把计算模态挡在门外
- **振型动画**：MPC/MPD 读数存疑时，回动画确认节线是否爬行——两个证据互相印证

::: warning 判读注意
MOV 低不一定说明振型不可用：先查激振力方向符号（单一输入点全模态集体偏低），再查通道标定，最后才怀疑振型本身。顺序颠倒，容易把好振型误判为坏振型。
:::

## 七、小结

- 复模态的本质是相位滞后沿结构逐点累积——齐步走变成了人浪，节线从固定变为爬行
- 两种来源必须区分：非比例阻尼造成的真复模态要保留，估计误差造成的假象要剔除
- MPC 用复平面共线性量"复的程度"：正则 100%，随机相位坍缩到接近 0%
- MOV 用"附加质量必降频"验"物理真伪"：群体偏低抓力方向输反，个别偏低抓计算模态
- 判读顺序固定：MOV 先排错误，MPC/MPD 再定性质，动画作最终印证

## 一句话记住

正则模态是齐步走（相位非 0° 即 180°），复模态是人浪（相位逐点滞后、节线爬行）；MPC 看形——复平面里像不像一条直线，MOV 验骨——附加质量降频是否处处成立；先 MOV 排错误，再 MPC 定真假。
