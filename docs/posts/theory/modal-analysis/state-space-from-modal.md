# 从模态试验到状态空间模型：给控制器设计搭桥

> 一份锤击试验报告交给控制组，对方回复"我们要的不是一张模态表，是 A、B、C、D 四个矩阵"——为什么控制器设计不吃模态参数这套语言？本文用一个贯穿全文的"菜谱与厨房"类比回答：模态模型像一张写清食材配比的菜谱（每阶模态的频率、阻尼、振型），状态空间模型则像一间照菜谱布置好的厨房（矩阵化的动力学方程，输入一搅、状态就演化、输出就出炉）。文章从二阶运动方程出发，推导模态模型到状态空间实现的转换公式，给出连续系统离散化与极点/阻尼的对应关系，最后用 numpy 在 2 自由度系统上验证：物理坐标与模态坐标两种实现仿真偏差在 1e-14 量级——同一台机器，两种说法，分毫不差。

## 一、为什么控制组不收模态表

NVH 工程师与控制工程师的交付矛盾几乎每家公司都上演过：模态试验做完，固有频率、阻尼比、振型一应俱全，报告发过去，控制组退回来一句——"请给我们可仿真的模型"。具体一点：他们要在计算机里复现这台结构，任意给定作动器输入力的时间历程，模型输出任意测点的加速度响应；控制器设计软件（极点配置、LQG、卡尔曼滤波、观测器）的输入接口清一色是四个状态空间矩阵，而不是一列模态频率加振型动画。

为什么控制领域偏爱这套语言？打一个贯穿全文的比方：**模态模型是一张菜谱，状态空间模型是一间厨房**。菜谱（模态表）告诉你这道菜由哪几味主料构成、各占多少、口感如何——5.033 Hz、阻尼比 3.2%、一阶弯曲振型，好比"主料是弹簧质量系统、配比 1:1、入口回甜 3 秒"。但光有菜谱做不出菜：厨房（状态空间实现）把灶台、锅、水管按菜谱布置好，你倒进任意输入（食材），它就按物理规律自动演化（烹饪），端出任意想要的输出（成品）。控制器设计是在厨房里装机械臂与温度探头——机械臂必须接在"厨房"的接口上，接不到"菜谱"上。

::: info 核心概念
- **模态模型（Modal Model）**：由试验拟合得到的固有频率、阻尼比、模态振型与留数，描述结构"由哪些固有运动构成"
- **状态空间模型（State-space Model）**：以一阶矩阵微分方程"状态导数=系统矩阵×状态+输入矩阵×输入、输出=输出矩阵×状态+直通矩阵×输入"描述的系统模型，状态向量浓缩了系统当前的全部历史，是控制器设计的标准接口
- **实现（Realization）**：由传递函数/模态参数构造一组 A、B、C、D 的过程——同一模型可以有无数种实现，它们的输入输出关系完全等价
- **模态叠加（Modal Superposition）**：把响应写成各阶模态贡献之和，物理坐标响应 = 振型矩阵 × 模态坐标响应
:::

两条技术路线由此分工：模态试验给出"这台结构是什么"（菜谱），状态空间实现把它变成"这台结构怎么算"（厨房）。本文讲的就是中间这座桥怎么搭。

## 二、从二阶方程到状态空间：先换一种写法

结构动力学的基本语言是二阶运动方程。对 $n$ 个测量自由度的结构：

$$M\ddot{q}(t) + C\dot{q}(t) + Kq(t) = f(t)$$

这个公式回答的问题是：力作用下结构怎么运动？其中 $M$、$C$、$K$ 分别为质量、阻尼、刚度矩阵（$n \times n$），$q$ 为物理位移向量，$f$ 为外力向量。NVH 工程师熟悉它的频域形式——FRF 正是由它导出。

状态空间形式做的事情，是把这个二阶方程**降为一阶**：引入状态向量 $x = [q;\ \dot{q}]$（位移与速度摞在一起，长度 $2n$），二阶方程就拆成两条一阶方程：

$$\dot{x} = Ax + Bu, \qquad y = Cx + Du$$

这个公式回答的问题是：给定当前状态与当前输入，下一瞬间状态与输出各是多少？其中 $A$（系统矩阵）描述状态自身的演化，$B$（输入矩阵）描述外力如何进入系统，$C$（输出矩阵）描述从状态读到什么（位移、加速度或其组合），$D$（直通矩阵）描述输入到输出的直接通路。对上式展开：

$$A=\begin{bmatrix}0&I\\-M^{-1}K&-M^{-1}C\end{bmatrix},\quad B=\begin{bmatrix}0\\M^{-1}\end{bmatrix},\quad C=\begin{bmatrix}I&0\end{bmatrix}$$

即取位移为输出、无直通项的标准实现。要输出加速度，把 $C$ 换成 $[-M^{-1}K\ \ -M^{-1}C]$、$D$ 加上输入方向的直通项即可——同一结构，看你要什么输出，$C$、$D$ 随之变化，$A$、$B$ 不动。

## 三、模态模型进来：振型矩阵就是那座桥

### 3.1 模态叠加原理

试验模态分析不直接给出 $M$、$C$、$K$（试验测不了矩阵），它给出的是特征值与特征向量。对无阻尼自由振动 $M\ddot{q}+Kq=0$ 解特征值问题：

$$K\psi_r = \omega_r^2 M\psi_r$$

这个公式回答的问题是：结构有哪些"天生就会"的振动形状与频率？其中 $\psi_r$ 为第 $r$ 阶振型（各测点振幅的比例关系），$\omega_r$ 为对应固有频率。振型满足质量归一化条件 $\psi_r^T M \psi_s = \delta_{rs}$。

模态叠加假设物理坐标响应是各阶模态的加权和，$q = \Phi \eta$（$\Phi=[\psi_1,\dots,\psi_m]$ 为振型矩阵，$\eta$ 为模态坐标）。代入运动方程并左乘 $\Phi^T$：

$$\ddot{\eta}_r + 2\zeta_r\omega_r\dot{\eta}_r + \omega_r^2\eta_r = \psi_r^T f(t)$$

这个公式回答的问题是：每一阶模态自己是一个怎样的单自由度系统？质量归一化后各阶解耦，第 $r$ 阶的"模态力"就是外力在振型上的投影 $\psi_r^T f$。$m$ 阶模态 = $m$ 个互不干扰的单自由度振子——这正是模态试验送来的那张"菜谱"。

### 3.2 拼装模态坐标状态空间

对每阶模态写状态方程（状态 $[\eta_r;\dot{\eta}_r]$），摞起来即得**模态坐标状态空间实现**：

$$A_m=\begin{bmatrix}0&I\\-\Omega^2&-2Z\Omega\end{bmatrix},\quad B_m=\begin{bmatrix}0\\\Phi^T L\end{bmatrix},\quad C_m=\begin{bmatrix}L^T\Phi & 0\end{bmatrix}$$

这个公式回答的问题是：把菜谱直接布置成厨房，矩阵长什么样？其中 $\Omega=\mathrm{diag}(\omega_r)$、$Z=\mathrm{diag}(\zeta_r)$ 由拟合的频率阻尼直接填入，$L$ 为输入位置矩阵（把作动器力分配到物理自由度），$L^T\Phi$ 正是"输入力在各振型上的投影"。输出端再乘振型矩阵把模态坐标变回物理坐标。

注意与第二章物理坐标实现的区别：$A$ 矩阵的左下块从 $-M^{-1}K$（物理坐标，需要质量刚度矩阵）换成了 $-\Omega^2$（模态坐标，对角阵，直接来自试验拟合）。**试验给不出 $M$、$K$，但给得出 $\omega_r$、$\zeta_r$、$\psi_r$——模态坐标实现绕开了试验测不了的量，这正是这座桥的价值。**

### 3.3 两条路拼出同一台机器

物理坐标实现与模态坐标实现是同一系统的两种"实现"：状态向量之间差一个线性变换 $x_p = T x_m$（$T$ 由振型矩阵与单位阵拼成）。理论上 $A_p = T A_m T^{-1}$，两者特征值相同、输入输出传递函数相同——同一台厨房换个布置，菜的口味不变。第五节的数值验证将给出定量证据：2 自由度系统两种实现的仿真曲线最大相对偏差 $9.1\times10^{-14}$。

## 四、极点、离散化与试验模型的边界

### 4.1 A 矩阵特征值 = 模态极点

实现拼好后，控制软件读的第一样东西就是 $A$ 的特征值。连续系统特征值与模态参数的对应：

$$\lambda_r,\lambda_r^* = -\zeta_r\omega_r \pm j\omega_r\sqrt{1-\zeta_r^2}$$

这个公式回答的问题是：控制器看到的"极点"与模态表里的频率阻尼如何互译？特征值到虚轴的距离 $-\mathrm{Re}(\lambda)=\zeta\omega$ 决定衰减快慢，虚部为有阻尼固有频率。反过来验证实现正确与否，就是算一遍 $A$ 的特征值、折回频率阻尼，与拟合表逐条对照（第五节演示）。

### 4.2 连续变离散：采样是绕不开的一步

控制器在数字处理器上运行，模型必须离散化。采样周期 $T_s$ 下最常用的是零阶保持（ZoH）精确离散化：

$$A_d=e^{AT_s},\qquad B_d=A^{-1}(A_d-I)B$$

这个公式回答的问题是：连续厨房每隔 $T_s$ 秒看一眼输入，怎么等价成一台"每拍走一步"的数字厨房？$A_d$ 的模即每拍状态放缩率——$|e^{\lambda T_s}|=e^{-\zeta\omega T_s}<1$ 恒成立，故稳定的连续系统离散后仍稳定。工程软件里这一步由积分器选项自动完成；自写代码时梯形（双线性）离散化即可满足演示精度。

### 4.3 试验模型的三个边界

把试验模态模型交给控制组之前，三件事必须交代清楚：

- **频带边界**：拟合频带外的动态不在模型里。低频缺刚体模态、高频缺弹性模态时，需分别用残余项（下残余代表低频刚体、上残余代表高频质量线）补上，或直接说明模型有效频带；
- **截断误差**：模态叠加只保留 $m$ 阶，被截断的高阶模态在频带内的影响即截断误差——带宽定多宽、留几阶，直接决定模型可信区间；
- **线性假设**：模态模型是典型工作点邻域的线性化结果。振幅一大、装配预紧一变，$\omega_r$、$\zeta_r$ 随之漂移，控制器设计按线性模型配好的增益就可能失配。

::: warning 工程注意
带残余项的拟合结果转状态空间时，上下残余项不能当"模态"拼进 $A$——它们没有极点，只能以 $D$ 矩阵（上残余）与低频二阶项（下残余）的形式进入实现，否则模型在高频段会凭空多出能量。
:::

## 五、numpy 演示：两种实现，一台机器

2 自由度链式系统（$m_1=m_2=1$ kg，$k=1000$ N/m，$c=2$ N·s/m），力作用在自由度 1，输出两个位移。先按物理坐标建 $A_p$、$B_p$，再经振型矩阵变换建模态坐标实现，最后对照 $A$ 特征值折回的频率阻尼。自包含，可直接运行：

```python
import numpy as np

m, k, c = 1.0, 1000.0, 2.0
M, C = np.eye(2)*m, np.eye(2)*c
K = np.array([[2*k, -k], [-k, 2*k]])

# 模态参数：特征分解（质量归一振型）
w2, V = np.linalg.eigh(K)          # V 列为振型
print("固有频率 Hz:", np.sqrt(w2)/(2*np.pi))   # -> [5.033, 8.717]

# 物理坐标状态空间: x=[q; qdot]
Minv = np.linalg.inv(M)
Ap = np.block([[np.zeros((2, 2)), np.eye(2)],
               [-Minv@K, -Minv@C]])
Bp = np.vstack([np.zeros((2, 1)), Minv@np.array([[1.0], [0.0]])])

# A 特征值折回频率/阻尼，与模态表对照
for lam in np.linalg.eigvals(Ap):
    if lam.imag > 0:
        print(f"{abs(lam)/(2*np.pi):.3f} Hz, zeta={-lam.real/abs(lam):.4f}")

# 模态坐标实现: Kr=V'KV 对角, Cr=V'CV, 模态力=V'f
Am = np.block([[np.zeros((2, 2)), np.eye(2)],
               [-V.T@K@V, -V.T@C@V]])
Bm = np.vstack([np.zeros((2, 1)), (V.T@np.array([[1.0], [0.0]]))])

# 同一随机输入下分别仿真（梯形离散化），输出变回物理坐标
fs, T = 2000.0, 2.0
u = 0.5*np.random.default_rng(3).standard_normal(int(fs*T))
def sim(A, B, u):                  # 梯形离散化逐步推进
    n, h = A.shape[0], 1/fs
    I = np.eye(n)
    Ad = np.linalg.solve(I-0.5*h*A, I+0.5*h*A)
    Bd = np.linalg.solve(I-0.5*h*A, B*h).ravel()
    x = np.zeros((n, len(u))); xi = np.zeros(n)
    for i, ui in enumerate(u):
        x[:, i] = xi; xi = Ad@xi + Bd*ui
    return x
yp = sim(Ap, Bp, u)[:2]            # 物理坐标位移
ym = V@sim(Am, Bm, u)[:2]          # 模态坐标 -> 变换回物理坐标
print("两种实现最大相对偏差:", np.max(np.abs(yp-ym))/np.max(np.abs(yp)))
```

运行输出：固有频率 5.033 Hz 与 8.717 Hz；特征值折回 8.717 Hz（$\zeta$=0.0183）与 5.033 Hz（$\zeta$=0.0316）——两阶模态的阻尼比不同，因为比例阻尼下各阶模态阻尼比 $\zeta_r = \psi_r^T C \psi_r/(2\omega_r)$ 随频率升高而递减；两种实现的仿真曲线最大相对偏差 $9.1\times10^{-14}$，即机器精度的等价。**这一行输出就是"菜谱拼成厨房"的验收标准：转换过程不引入任何动力学差异。**

## 六、Testlab 中的位置与交接清单

在 Testlab 的模态分析工作流里，这条转换路径有两处入口：其一是模态拟合完成后，模态模型（极点 + 带标尺振型）可导出为通用格式（如 UniRAF/UFF 的模态数据集、或直接与 MATLAB/Python 流程对接的文本矩阵），控制组拿到 $\omega_r$、$\zeta_r$、$\psi_r$、留数即可按第三节公式拼装；其二是对需要直接仿真的场景，Testlab 的模态综合（Modal Synthesis）页可由模态模型重建任意输入输出对的 FRF，频域上先验证模型复现能力，再交状态空间转换。交接时建议附上三件东西：拟合频带与采样参数、残余项处理方式、驱动点 FRF 的互易性检查结果——控制组据此判断模型有效区间。

交接前自查清单（按本文脉络）：

| 检查项 | 方法 | 不通过的后果 |
| --- | --- | --- |
| 拟合频率阻尼 vs $A$ 特征值折回值 | 特征值折回逐条对照 | 极点错位，控制器配错增益 |
| 实现等价性 | 同一输入下两种实现仿真对比 | 转换过程引入假动态 |
| 残余项处理 | 上残余进 $D$、下残余按低频项处理 | 高频段凭空多能量 |
| 有效频带声明 | 频带外响应不外推 | 带外"模型预测"变成编造 |

## 七、小结

模态试验与控制器设计之间隔着一层语言差异：前者交付"结构由哪些固有运动构成"，后者消费"状态如何随输入演化"。状态空间实现是标准译法——振型矩阵做坐标变换，拟合的频率阻尼直接填进 $A$，输入投影与输出变换由 $\Phi^T L$ 与 $L^T\Phi$ 承担，连续转离散交给矩阵指数。验收标准只有一条：转换前后输入输出关系分毫不差（数值上即两种实现仿真偏差到机器精度）。试验模型的边界——频带、截断、线性化工作点——必须随矩阵一起交接，否则控制组拿到的是一台只在特定频段、特定振幅下成立的"机器"。

## 一句话记住

模态模型是菜谱、状态空间是厨房：振型矩阵搭桥做坐标变换，拟合的 $\omega_r$、$\zeta_r$ 填进 $A$ 矩阵，输入投影 $\Phi^T L$ 进 $B$、输出变换 $L^T\Phi$ 进 $C$；转换合格的唯一标准是两种实现仿真偏差到机器精度，且频带边界必须随件移交。
