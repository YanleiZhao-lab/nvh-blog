# 基于 FRF 的子结构耦合 FBS：不装起来就能预测装配体的频响

> 副车架在德国、白车身在中国，两家工厂各测了各部件的 FRF，装车之后的怠速振动能不能提前算出来？能——而且不需要把任何一个部件寄过海关。基于 FRF 的子结构耦合（FRF Based Substructuring, FBS）在频域直接做这件事：把 A、B 两个系统的 FRF 各自测好，再按连接条件"缝"在一起，装配体 AB 的 FRF 就算出来了。就像两段供水管在法兰对接前各自标定好接口特性：每段管子"进水口加单位水压、出水口出多少流量"的水表读数（各连接点的 FRF）事先在实验台上量好，对接面两侧水压相等、流量一进一出相等相反这两条连续条件一联立，整条管线的特性就解出来了，不必真通水试漏。本文按 Simcenter 官方知识库的推导路线，从子系统方程一步步推出 Lagrange 乘子 FBS 公式，用 numpy 把两个子结构的 FRF 拆开再合上、逐频率核对到机器精度，并给出连接点测量质量与 Testlab 操作入口这两件工程上真正决定成败的事。

## 一、为什么需要 FBS：装配体测不到，部件测得到

NVH 开发里有一类问题很憋屈：想知道"装上以后"的行为，却测不到"装上以后"的东西。副车架要装的新车身还在图纸阶段；动力总成在供应商台架上、整车在主机厂，两地相隔一个海运周期；声学与结构两个团队各自负责腔体和面板，联合装配试验排期排到下个季度。等到物理装配完成再测 FRF，发现问题再改，模具已经开完——改动窗口所剩无几。

反过来看，"没装起来"的部件反而好测：副车架吊起来自由悬挂，锤击或 Qsource 激励，连接点、输入点、输出点的 FRF 一个下午就能测完；车身哪怕只有有限元模型，也能仿真出同格式的 FRF。FBS 的洞察就在这里：**装配体的频响信息，其实已经全部藏在各部件的 FRF 里**——两个系统各自受连接点力作用的响应方程、加上"刚性连接处位移相等、内力相等相反"这两条装配条件，代数上足以把装配体的 FRF 解出来。Simcenter 官方知识库把这套方法称为 Lagrange Multiplier FBS（拉格朗日乘子 FBS），并明确说明：文章以刚性连接为例推导，方法同样适用于弹簧/柔性连接；部件可以来自试验，也可以来自仿真，还可以一个试验一个仿真混合装配——物理副车架配上仿真车身，正是官方给出的典型用例。

本文的贯穿类比就是开头那段**供水管**：把 A、B 两个系统想成两段各自装好水表的管段，每段管子的接口特性（单位水压进、多少流量出的"压强—流量"传函）可以单独标定；法兰对接时，对接面两侧水压相等（位移协调）、流量一进一出相等相反（力平衡），两张接口特性表联立就能解出整条管线的特性。FBS 做的是同一件事，只不过"水压"换成力、"流量"换成位移响应，且力与响应都是随频率变化的复数——每条 FRF 曲线的一根谱线，就是该频率下接口特性的一个复数读数。

具体到工程数字：一副副车架与车身通常有 4 个连接点，每点 3 个方向，接口共 12 个自由度；要预测"底盘激励点传到驾驶员座椅导轨"的装配体 FRF，需要的是 A 系统输入点到连接点的 FRF（12 条）、A 连接点驱动点及互 FRF（12×12 矩阵）、B 系统连接点到输出的 FRF（12 条）——三组 FRF 齐了之后，装配体 FRF 在每个频率点上都是一次矩阵求逆加两次矩阵乘。这也是 FBS 与模态域装配的分工：VPA（虚拟样机装配）把部件浓缩成"极点+带标尺振型"的模态模型，适合预测装配体模态参数；FBS 直接在 FRF 曲线上操作，保留每根谱线的原始信息，是传递路径分析中 Component-based TPA 的数学发动机——后文 2.5 节会看到，把装配公式换个方向用，还能做阻塞力与接触力的换算。

::: info 核心概念
- **FBS（FRF Based Substructuring，基于 FRF 的子结构耦合）**：用各子系统分别测得（或仿真得到）的 FRF，按连接条件代数求解装配体 FRF 的方法，也称 Frequency Based Substructuring 或 Lagrange Multiplier FBS
- **耦合 FRF（coupling FRF）**：子系统连接点上的 FRF，包括连接点之间的互 FRF 与力响应同点的驱动点 FRF，构成连接接口的 FRF 矩阵
- **跨系统 FRF（cross FRF）**：横跨一个子系统的 FRF，如从系统 B 的连接点到输出点的 FRF
- **自由-自由边界（free-free boundary）**：FBS 要求子系统 FRF 在自由-自由条件下获取，即部件悬空、不加接地约束
- **阻塞力（blocked force）与接触力（contact force）**：源部件接口"焊死"时输出的力与装配后接口处实际传递的力，FBS 可在两者间换算
:::

## 二、从子系统方程到装配公式：五步推导

### 2.1 每个部件各自的家底：位移响应方程

FRF 的本义就是"单位力下的响应"。对系统 A，同时考虑作用在输入点和连接点上的力，连接点处的位移响应是两个激励各自贡献之和（Simcenter 文章第 3 节，图 9）：

$$x^A_{c} = H^A_{c i}\,F^A_{i} + H^A_{c c}\,F^A_{c}$$

这个公式回答的问题是：**部件 A 的连接点在多方激励下怎么动？**其中驱动点项 $H^A_{c c}$ 对应物理里"在自己连接点上敲、在自己连接点上测"的 FRF，$H^A_{c i}$ 是输入点到连接点的跨系统 FRF——每一项都是一条随频率变化的复数曲线，不是常数。系统 B 同理，且要同时写两条：连接点一条、输出点一条（图 10）。

$$x^B_{c} = H^B_{c c}\,F^B_{c} + H^B_{c o}\,F^B_{o}, \qquad x^B_{o} = H^B_{o c}\,F^B_{c} + H^B_{o o}\,F^B_{o}$$

这两条方程回答的问题是：**部件 B 在接口力和输出端外力共同作用下，接口和输出各自怎么动？**其中下标 $o$ 对应物理里的输出自由度——FBS 最终要的就是 $x^B_o$ 这个量。

### 2.2 装配条件：刚性连接的两条守恒律

把 A、B 刚性连接后，接口必须满足两条物理条件（Simcenter 文章第 4 节，图 11、图 12）：

**位移协调**——连接点两侧位移相等：$x^A_{c} = x^B_{c}$。法兰盘拧在一起，两侧不可能各自运动。

**力平衡**——接口内力相等相反：$F^A_{c} = -F^B_{c}$。这是牛顿第三定律在接口上的直接投影：A 通过螺栓拉 B 多少，B 就反拉 A 多少，装配体方程里可以互相代入消掉。

### 2.3 输出端无外力：多数场景的合理简化

若装配体的输出端没有外力（比如输出是人耳位置或座椅导轨这样的"纯观测点"，Simcenter 文章第 5 节），$F^B_{o}=0$，方程组进一步简化。官方原文的玩笑很形象：除非操作员正在大声说话（或者在座椅上蹦跳），这个假设都是成立的。

### 2.4 消元求解：装配体 FRF 浮出水面

把位移协调条件代入 A 的连接点方程、力平衡条件代入消去接口内力，整理后每个频率点上解一个线性方程组——Simcenter 文章第 6 节给出两步代入与重排，最终形式（图 16）：

$$H^{AB}_{o i} = H^B_{o c}\left(H^A_{c c} + H^B_{c c}\right)^{-1} H^A_{c i}$$

这个公式回答的问题是：**装配体"输入点激励—输出点响应"的 FRF 由哪些部件 FRF 拼成？**其中 $H^A_{c i}$ 对应物理里"激励经 A 传到接口"的管段特性，$H^B_{o c}$ 对应"接口经 B 传到输出"的管段特性，中间的逆矩阵是两侧接口 FRF 矩阵之和的逆——供水管类比里"对接阻抗串联叠加后求逆"的那一步。分母里两个子系统接口 FRF **相加**是整条公式的物理心脏：刚性连接把两个接口变成一个节点，该节点的柔顺程度由两侧串联决定。

需要的三组 FRF 也随之明确（Simcenter 文章第 6 节的观察）：

1. **耦合 FRF**：A、B 各自连接点上的驱动点及互 FRF（$H^A_{c c}$、$H^B_{c c}$）
2. **输入到连接**：A 系统输入点到其连接点的 FRF（$H^A_{c i}$）
3. **连接到输出**：B 系统连接点到其输出点的 FRF（$H^B_{o c}$）

### 2.5 力变换：同一套代数的另一个方向

把 FBS 公式反着用，还能做力变换（Simcenter 文章第 7 节）：A 系统输出端的阻塞力可以换算成装配后进入 B 系统的接触力（图 17）。

这个公式回答的问题是：**源部件"独自运行时"输出的力，怎么折算成它装上目标部件后真正传过去的力？**其中阻塞力对应物理里源部件接口"焊死"状态下输出的力，接触力对应装配状态下接口实际传递的力。这一变换只需要**接口处的 FRF**——不需要横跨系统的 FRF，而跨系统 FRF 在某些结构上物理上就很难测（比如从悬置安装点到底盘远端的锤击通道被油箱、线束挡死）。Component TPA 正是用它把"源部件台架上测得的阻塞力"翻译成"装车后进入车身的力"，再对各传递路径做贡献量分析。

![FBS 力变换：阻塞力与接触力](/images/frf-based-substructuring/fig17_forces.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

回看供水管类比：知道每段管子的接口特性，不但能预测整条管线的流量（FRF 装配），还能把"水泵单独堵口运行时的压力脉动"换算成"接上管路后实际注入管路的水量"（力变换）——同一张接口特性表，正着用反着用都是它。

## 三、numpy 演示：拆开再合上，逐频率对账

公式的正确性最好用"先有真值、再走 FBS 路线"来验证：构造一个 3 自由度装配体（A 系统 2 自由度、B 系统 1 自由度，刚性连接 A2-B3），先在物理域直接组装成 3 自由度装配体求出真值 FRF；然后假装不认识装配体——只取 A、B 各自自由悬挂的 FRF 分块，按 FBS 公式重新拼装，看两条曲线是否逐频率重合。

```python
import numpy as np
f = np.linspace(5, 200, 400); w = 2*np.pi*f; s = 1j*w
# ---------- A: 2 自由度自由-自由, B: 2 自由度自由-自由, 刚性连接 A2-B1 ----------
mA = np.diag([2.0, 1.0]); kA = np.array([[4e5,-4e5],[-4e5,4e5]]); cA = 2e-5*kA
mB = np.diag([0.6, 0.4]); kB = np.array([[3e5,-3e5],[-3e5,3e5]]); cB = 2e-5*kB
# ---------- 路线 1：物理域直接组装 3x3（真值对照, A2 与 B1 焊死） ----------
M = np.diag([2.0, 1.6, 0.4])
K = np.array([[4e5,-4e5,0],[-4e5,4e5+3e5,-3e5],[0,-3e5,3e5]])
C = 2e-5*K
Z = M*s[:,None,None]**2 + C*s[:,None,None] + K
H_true = np.linalg.inv(Z)[:, 0, 2]      # 真值: 输入 A1 -> 输出 B2
# ---------- 路线 2：FBS——只用 A、B 各自的自由-自由 FRF ----------
ZA = mA*s[:,None,None]**2 + cA*s[:,None,None] + kA
ZB = mB*s[:,None,None]**2 + cB*s[:,None,None] + kB
HA, HB = np.linalg.inv(ZA), np.linalg.inv(ZB)
H_Aci = HA[:, 1, 0]     # A: 输入点1 -> 连接点2
H_Acc = HA[:, 1, 1]     # A: 连接点2 驱动点
H_Bcc = HB[:, 0, 0]     # B: 连接点1 驱动点
H_Boc = HB[:, 1, 0]     # B: 连接点1 -> 输出点2
H_fbs  = H_Boc*(H_Acc+H_Bcc)**-1*H_Aci    # LM-FBS 装配公式
rel = np.abs(H_fbs-H_true)
print("最大绝对偏差/真值峰值:", f"{rel.max()/np.abs(H_true).max():.2e}")
i = 30 + np.argmax(np.abs(H_true)[30:])
print(f"主峰 {f[i]:.1f} Hz: 真值 |H|={abs(H_true[i]):.3e}, FBS |H|={abs(H_fbs[i]):.3e}")
# ---------- 装配改变了什么：A 连接点驱动点 FRF 前后对比 ----------
H_int_asm = np.linalg.inv(Z)[:, 1, 1]
pk = lambda H: f[30+np.argmax(np.abs(H)[30:])]
print(f"A 单独接口驱动点弹性峰 {pk(H_Acc):.1f} Hz -> 装配后 {pk(H_int_asm):.1f} Hz")
```

运行结果（实测输出）：

```
最大绝对偏差/真值峰值: 9.81e-15
主峰 96.4 Hz: 真值 |H|=8.603e-05, FBS |H|=8.603e-05
A 单独接口驱动点弹性峰 123.3 Hz -> 装配后 96.4 Hz
```

两个读数值得咀嚼。其一，最大绝对偏差与真值峰值之比 9.81e-15——机器精度量级，FBS 装配公式在数学上是恒等式：只要子系统 FRF 准确、连接条件写得对，装配体 FRF 就不是"近似预测"而是"精确重构"。其二，装配的物理效应清晰可见：B 的质量挂上 A 的连接点之后，接口节点的驱动点 FRF 共振峰整体下移——这正是"装配体动态既不属于 A 也不属于 B、而属于耦合"的直观数字体现。真值与 FBS 在同一张图上逐频率重合这件事，就是供水管类比里"两张接口特性表联立解出整条管线"的数值版本。

## 四、测量质量：FBS 的真正软肋

公式是恒等式，工程上 FBS 的误差几乎全部来自测量——Simcenter 文章第 8 节开宗明义：**FRF 在 FBS 过程中要求逆，测量的微小误差会被放大**，接口 FRF 矩阵必须良态（well conditioned）。两条官方建议对应两种对策。

**其一，模态曲线拟合去噪。**对实测 FRF 做模态曲线拟合，用合成 FRF（synthesized FRF）代替含噪原始数据进入 FBS 运算：拟合准确时，合成 FRF 保留全部系统动态而不含测量噪声（图 18）。

![实测含噪 FRF 与模态拟合合成 FRF](/images/frf-based-substructuring/fig18_curvefit.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

**其二，Qsource 激励器保证连接点 FRF 质量。**连接点常藏在结构缝隙里，力锤既伸不进去、也保证不了敲击角度与频带能量；Qsource 结构激励器体积小、可固定安装，提供准确的激励位置与角度、更好的重复性与信噪比，以及关注频带内的足够能量（图 19）。

![Qsource 结构激励器用于狭小空间连接点激励](/images/frf-based-substructuring/fig19_qsource.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

为什么求逆这么怕噪声？供水管类比再次适用：对接面的流量解出来自两张特性表的"差值平衡"，若两张表在某个频率上读数都很小（接口接近反共振、FRF 模值低），微小的测量噪声就会在求逆时被除法放大成主导项——接口 FRF 矩阵在这个频点附近接近奇异。工程上的对应做法：检查接口驱动点 FRF 的反共振深度、必要时增加连接点冗余测量自由度，让矩阵保持良态。

另一个测量层面的硬性要求是**自由-自由边界**：子系统 FRF 必须在不加接地约束的状态下获取（部件悬吊或软支撑）。原因藏在装配条件里——FBS 假定接口力是两个系统之间唯一的相互作用，如果部件试验时装了地脚螺栓，约束力就成了方程外的"第三只手"，装配条件不再完备。

## 五、响应格式与 Testlab 入口

**响应格式**：FBS 推导中的响应是位移，实测常用加速度——两者（以及速度）只是积分/微分关系，即乘或除 $j\omega$（Simcenter 文章第 9 节）。装配运算前把所有 FRF 统一到同一种响应格式即可。

**Testlab 入口**：FBS 在 Simcenter Testlab 中是 Component TPA（Component-based TPA）的功能模块，经 **Tools -> Add-ins** 打开，占用 50 tokens；装配体的管理在 Virtual Prototype Assembly 界面。这与 VPA 的 Modification Prediction 工具链互为补充：一个在 FRF 域拼曲线，一个在模态域拼极点。

::: warning 工程注意
接口 12 自由度（4 点 × 3 向）意味着接口 FRF 矩阵是 12×12、含 78 条独立 FRF 曲线——连接点数量是 FBS 试验成本的第一驱动因素。方案阶段就要问：连接点能不能合并？方向数能不能裁剪？接口矩阵的良态与试验成本之间需要显式权衡。此外，混合装配（试验部件 + 仿真部件）时，两边 FRF 的频率分辨率、单位制与结点位置必须严格对齐，错位不会报错，只会给出貌似合理的错误装配结果。
:::

## 六、小结

FBS 的逻辑链条：部件 FRF 各自测好（自由-自由）+ 两条装配条件（位移协调、力平衡）+ 线性代数消元 = 装配体 FRF，每一步都发生在频域、逐谱线进行，不需要模态参数作为中间产品。numpy 演示验证了它是恒等式而非近似；工程误差的来源几乎全在测量侧——接口 FRF 的噪声与条件数，对策是模态拟合去噪与 Qsource 激励。把公式反方向使用就是力变换，支撑 Component TPA 把源部件的阻塞力翻译成装配后的接触力。

## 一句话记住

FBS 是频域的法兰对接：两段管子各自的接口特性表（部件 FRF，自由-自由测得）加上"对接面水压相等、流量相等相反"两条装配条件，不真接起来也能算出整条管线的频响；误差不在公式在测量——接口 FRF 一旦含噪，求逆就把它放大。
