# 静态补偿模态：上/下残留项的物理意义

> 一根车身纵梁敲了 0～2000 Hz 的 FRF，模态拟合只圈定 180～500 Hz 的四阶模态，拟合残差却总在曲线两端"翘尾巴"——低频端整体抬不起来，高频端又压不下去。有人把频带一扩了事，可带外模态一进来，拟合器开始把 700 Hz 附近的峰也往模型里塞，四阶变七阶，振型全乱了。问题不在测量也不在拟合器，而在模态截断：你只给了带内四阶模态，带外那些模态的贡献没有户口。本文介绍残留项（Residual Terms）——上残余项（残余刚度）与下残余项（残余质量）——如何用两个常数把带外所有模态的影响打包记账，以及把上残余项经奇异值分解升级成"静态补偿模态"、用于子结构综合的完整推导。像搬家时整理行李：带内模态是随身带的箱子，上、下残余项是门口那两个"杂物袋"——不打开看，但必须知道有多重；静态补偿模态则是把杂物袋里的东西按重量压成两块标准砖，砌回新房子（组合结构）时不塌角。

## 一、为什么拟合频带的两端总是对不上

先看工程现场最常见的一幕。锤击法测一根自由-自由悬挂的子结构，分析频带定在 180～500 Hz——这里面有四阶清晰的模态。曲线拟合跑完，稳定图很干净，四阶极点一列排开。可是把拟合曲线叠到实测 FRF 上，残差（实测减拟合）在频带两端不是白噪，而是系统性的弯曲：低频端残差随频率上升而下降，高频端残差随频率上升而上升。加大拟合阶数没用——带外没有峰，拟合器分不出新极点，只会把噪声拟成假模态。

这个现象的根源写在模态叠加展开式里：结构的 FRF 是**所有**模态的贡献之和，而拟合模型只包含分析频带内的 N 阶。带外模态并没有消失，它们在带内每根谱线上都贡献了一份"背景"。这份背景在窄频带内变化缓慢，可以近似成两个常数项——这正是上、下残余项的位置。

打个生活比方：装修队给一面墙报总价。。你只统计了主卧、次卧、客厅三个房间（带内模态），但走廊和卫生间的面积（带外模态）不会因为你不统计就消失。聪明的做法不是把三个房间的单价抬高去凑总价，而是在报价单末尾加两行"其他区域"的打包价。低频端好比按总面积摊的底价（随面积走，对应质量型项），高频端好比固定上门服务费（不怎么随面积变，对应刚度型项）——两行打包价一加，报价单两端就对上了。

## 二、上、下残余项：两个常数怎么记账

### 先用数字建立直觉

先用纯数字把直觉立起来，再上符号。三个数字先行：30、100、300——这是一根自由-自由梁前三阶模态的频率（单位 Hz）；分析频带 80～120 只圈住中间那阶；两端各站着一阶"编外"模态。我们要回答的问题只有一个：编外模态在 100 Hz 这根谱线上贡献多大、长什么形状。

考虑一个无阻尼三自由度系统的驱动点导纳（速度/力口径），三阶模态频率分别在 30、100、300 Hz。若分析频带只圈 80～120 Hz（只含第二阶），那么第一阶（30 Hz，在带下方）与第三阶（300 Hz，在带上方）的贡献是多少？在 100 Hz 这根谱线上：

- 30 Hz 模态的贡献与 $1/(s^2+\omega_1^2)$ 成正比——代入 $s=j\omega$，$\omega$ 远大于 $\omega_1$ 时，这个分母近似为 $-\omega^2$，贡献近似一个**负常数除以 $\omega^2$**；
- 300 Hz 模态的贡献分母近似为 $\omega_3^2$（$\omega$ 远小于 $\omega_3$），贡献近似一个**正常数**。

也就是说：带外的低频模态在带内表现为一项 $-LR/\omega^2$ 形状的"质量型"背景，带外的高频模态表现为一项 $UR$ 形状的"刚度型"背景。两项在窄带内都是慢变函数，各用一个常数近似，就是上、下残余项。

### 带残余项的 SDOF 模型

**导读**：这个公式回答的问题是"分析频带内只留一阶模态时，带外所有模态的背景贡献怎么补"——其中 $UR_{ij}$ 对应物理里"频率高于分析频带的所有模态打包成的残余刚度项"，$LR_{ij}$ 对应物理里"频率低于分析频带的所有模态打包成的残余质量项"；两项就是手册式 15-8 里的上、下残余项。

**导读**：这个公式回答的问题是"分析频带内只留一阶模态时，这阶模态自己的 FRF 长什么样"——其中 $\lambda$ 对应物理里"该阶模态的极点（含频率与阻尼）"，$\Re_{ij}$ 对应物理里"该阶模态在 i、j 两个自由度之间传递能量的强度（留数）"，两项复共轭合成一条完整的共振峰。

按 LMS 理论手册 15.2.1 节（式 15-7、15-8），单自由度（SDOF）假定下的 FRF 基础模型为（$\Re_{ij}$ 为留数、$\lambda$ 为极点）：

$$
H_{ij}(\omega) = \frac{\Re_{ij}}{i\omega - \lambda} + \frac{\Re_{ij}^{*}}{i\omega - \lambda^{*}}
$$

通过在式中引进所谓上、下残余项，可补偿分析频带以外的邻近模态对 FRF 数据的影响：

$$
H_{ij}(\omega) = \frac{\Re_{ij}}{i\omega - \lambda} + \frac{\Re_{ij}^{*}}{i\omega - \lambda^{*}} + \frac{UR_{ij}}{i\omega} + \frac{LR_{ij}}{(i\omega)^{3}}
$$

其中：

- $UR_{ij}$ **上残余项（Upper Residual，残余刚度）**：近似反映频率**高于** $\omega_{\max}$ 的模态影响；
- $LR_{ij}$ **下残余项（Lower Residual，残余质量）**：近似反映频率**低于** $\omega_{\min}$ 的模态影响。

::: info 核心概念
- **上残余项（Upper Residual / 残余刚度）**：补偿分析频带上方所有模态的常数项，位移/力口径下量纲同柔度（刚度倒数），在 FRF 表达式中为常数型项
- **下残余项（Lower Residual / 残余质量）**：补偿分析频带下方所有模态的项，随 $1/\omega^2$ 衰减，量纲同质量的倒数
- **截断误差（Truncation Error）**：模态叠加只取有限阶（带内 N 阶）时，带外模态贡献被丢弃造成的系统误差——残余项是它的一阶近似补偿
:::

上、下残余项的意义可参看图 15-3：低频模态的共振峰远在分析频带左侧，它在带内的"尾巴"随频率升高单调下降，形状像 $1/\omega^2$；高频模态的共振峰远在右侧，带内尾巴近似水平线。两者叠加，正好解释了拟合残差在两端翘起的方向。

![图15-3：上、下残余项示意——带外低频模态在带内呈 1/ω² 形状的残余质量尾巴，带外高频模态呈近似常数的残余刚度台地](/images/residual-compensation-modes/fig15-3-residual-terms.png)

*(图源：Siemens Simcenter Testing Knowledge Base 中文理论手册)*

物理上再啰嗦一句帮助记忆：低频模态"沉"——频率趋零时它的位移响应趋于静态，贡献大，所以带内看它随 $\omega$ 增大而衰减，像质量的懒（惯性项主导）；高频模态"轻快"——带内频率远低于其固有频率，它几乎不动，只贡献一个近似刚性的传递路径，所以像弹簧。**下残余对应质量、上残余对应刚度**，与"低频看质量、高频看刚度"的直觉完全一致。

这个数字实验值得动手复算一遍（完整代码见第五节）：两阶带外模态混出来的残余矩阵，SVD 之后奇异值为 2.559、0.571、0——第三个塌到零，说明三条连接自由度里只有两个独立"方向"在承载带外刚度；参与因子除以残余频率的平方后只有 1e-7 量级，但乘回去还原矩阵的误差是机器精度。也就是说，补偿模态在带内贡献虽小，缺了它连接点刚度就是实实在在地少一块。

### 在拟合器里的位置

Simcenter Testlab 模态拟合（如 Polymax / LSCE 系列）的求解设置里，每一条 FRF 都可以独立开关 Upper Residual 与 Lower Residual：当分析频带两侧确实存在邻近模态时打开它们，拟合器会把 $UR_{ij}$、$LR_{ij}$ 当作普通参数与留数一起最小二乘估计；对带外干净（两侧远离共振）的窄带拟合则可以关闭，减少两个待估参数。这也是"扩带 + 残余项"与"窄带 + 无残余"两条路线的取舍：前者诚实记账，后者强行截断。

## 三、从频带说到子结构：截断误差的真正战场

单条 FRF 的拟合里，残余项只是让曲线两端对齐的"补丁"。但在**模态综合法**（component mode synthesis）里，截断误差会实打实地改变组合结构的预测频率——每个子结构只保留有限阶模态，带外模态在连接点上丢失的刚度与质量，直接进到装配体的动力学里。

手册第 15.2.4 节对时域方法的一条警告值得引用：如果分析频带的数据受到带外模态的严重影响（残余效应）时，时域技术估计的模态参数可能会有问题——因为时域模型（式 15-24）在数学上不可能识别出分析频带之外的极点；而频域技术直接估计的参数里可以容纳残余项。所以**残余效应严重的窄频带数据，频域法有时比时域法更可靠**。

![图15-4：分析频带与测量频带示意——分析带只含三个模态而测量带内有五个](/images/residual-compensation-modes/fig15-4-analysis-band.png)

*(图源：Siemens Simcenter Testing Knowledge Base 中文理论手册)*

回到子结构组合的场景：两个子结构各自做了模态试验，各自保留 0～500 Hz 的模态模型，然后装配。手册 15.5 节的做法是给每个子结构模型追加一个静态补偿项和一个动态补偿项：

$$
H(\omega) \cong \underbrace{\sum_{k=1}^{N} \frac{\Re_{k}}{i\omega - \lambda_{k}} + \frac{\Re_{k}^{*}}{i\omega - \lambda_{k}^{*}}}_{\text{模态 FRF（带内）}} + \underbrace{H_{\text{static}}(\omega)}_{\text{静态补偿项}} + \underbrace{H_{\text{dyn}}(\omega)}_{\text{动态补偿项}}
$$

**导读**：这个公式回答的问题是"有限阶模态模型在装配后精度不够，怎么把截断误差补回来"——其中静态补偿项对应物理里"所有带外模态的准静态刚度贡献"，动态补偿项对应"带外模态的惯性/动态部分"，手册指出截断误差可用台劳展开的二次式函数近似，实测与二次式估计之间有良好一致性。

## 四、静态补偿模态：把上残余项升级成"虚拟模态"

### 为什么不直接用常数

补丁式残余项解决单条 FRF 的拟合问题够用，但子结构综合需要的是**一套模态参数**（振型 + 参与因子）——装配方程在模态空间里组装，一个常数塞不进模态基。所以 15.5 节的核心动作是：把上残余项矩阵经奇异值分解（SVD）转换为规一化的模态振型和模态参与因子，构造出"静态补偿模态"（static compensation modes），日后作为模态子结构集成到两个子结构的规一化模态中。

### 残余频率：把补偿模态放在哪

静态补偿模态的频率 $\omega_{\text{上残余}}$ 必须大大高于子结构组合中所有计算模态牵涉的频带。模态子结构的频带上限被定义为上残余频率，一般取：

$$
\omega_{\text{上残余}} = 10\,\omega_{0}
$$

**导读**：这个公式回答的问题是"补偿模态的固有频率该设多高才不干扰带内模态"——其中 $\omega_0$ 对应物理里"子结构参与综合的最高计算模态频率"，放大 10 倍是为了让补偿模态自身远在分析带外，只以准静态刚度身份工作，不在带内添新峰。

### SVD 分解

**导读**：这个公式回答的问题是"一堆上残余项矩阵里藏着几条独立的补偿模态"——其中 $[U]$ 的列向量对应物理里"各条静态补偿模态在连接自由度上的规一化振型"，$\Sigma$ 的非零奇异值对应"每条补偿模态的强度（参与因子的原料）"。

为了求出静态补偿项，需要对上残余项矩阵作奇异值分解。将所有的上残余项一起放在一个大矩阵内：

$$
[R_{\text{上残余}}] = [U]\,[\Sigma]\,[V]^{T}
$$

静态补偿模态的模态振型值取决于左奇异值向量 $[U]$、特征值 $\Sigma$ 以及频率 $\omega_{\text{上残余}}$；模态参与因子的值可由模态振型值进一步求出。手册给出的关系链是：

$$
[\Phi_{\text{comp}}] = [U] \quad\text{（规一化振型取左奇异向量）}
$$

$$
[L_{r}] = \frac{\sigma_{r}}{\omega_{\text{上残余}}^{2}} \quad\text{（参与因子由奇异值缩放而来）}
$$

由此，带外全部模态在连接点上的准静态刚度，被压缩成少数几条"虚拟的、频率极高的模态"——奇异值断崖的位置就是需要的补偿模态数目。

用搬家比喻回收一下：补丁式残余项是"杂物袋"，拎得动但没法砌墙；SVD 做的事是把所有杂物按"承重方向"（左奇异向量）重新码放、压成几块标准砖（静态补偿模态），砖的重量（参与因子）由奇异值决定。砌进新房子后，这些砖只提供静刚度、不产生新共振（频率放在 10 倍带外），正是"补偿"二字的含义。

## 五、numpy 演示：SVD 压缩补偿模态

```python
import numpy as np

# 两个"带外模态"在连接点上的振型（真实结构中未知，这里用于生成数据）
psi1 = np.array([1.0, 0.8, 0.3])
psi2 = np.array([0.2, 0.6, 1.0])
R_up = np.outer(psi1, psi1) + np.outer(psi2, psi2)   # 上残余项矩阵（秩2）

# SVD：奇异值断崖给出补偿模态数目
U, s, Vt = np.linalg.svd(R_up)
print("奇异值:", np.round(s, 3))          # [2.559, 0.571, 0.] -> 2 条补偿模态

# 残余频率取分析带上限(500 Hz)的 10 倍，参与因子 = sigma / w_up^2
w_up = 2*np.pi*10*500.0
L = s[:2] / w_up**2
print("参与因子:", np.round(L, 12))

# 校验：补偿模态的准静态刚度应还原上残余矩阵（重构误差~1e-16）
R_check = sum(L[r]*w_up**2*np.outer(U[:, r], U[:, r]) for r in range(2))
print("重构误差:", np.abs(R_check - R_up).max())

# 带内边缘(500 Hz)：补偿模态的动态项 = 静态项 x w^2/(w_up^2-w^2)，十倍频距 -> 约 1% 起伏
w = 2*np.pi*500.0
dyn_frac = w**2/(w_up**2 - w**2)
print("带边动态/静态比值:", np.round(dyn_frac, 4), "理论 1/99 =", np.round(1/99, 4))
```

三个输出对应三件事：奇异值 `[2.559, 0.571, 0.]` 第三个塌到零——两个带外模态只需两条补偿模态，断崖即数目；重构误差 1e-16 量级说明 $L_r\omega_{\text{上残余}}^2 u_r u_r^{\mathrm{T}}$ 的组合**精确还原**上残余矩阵（SVD 的定义使然，不是巧合）；带边比值 0.0101 恰等于 $1/(10^2-1)$——残余频率放在十倍频距之外，带外模态的动态起伏只占其静态贡献的约 1%，这正是"十倍"这条经验规则的数量级依据；但若把带外模态整个扔掉，丢掉的是 100% 的静态部分，组合结构的连接点会偏"软"。

## 六、Testlab 中的对应位置

- **残余项开关**：模态拟合工作表（Polymax/LSCE）求解参数里，FRF 组级别可勾选 Upper/Lower Residual，与留数一同估计
- **残余项的应用出口**：拟合得到的残余项随模态模型存储，供 FRF 综合显示、子结构类应用（FBS/VPA 的补偿输入）使用
- **静态补偿模态**：属于模态综合/虚拟样机装配流程的内部步骤（由上残余项 SVD 自动生成），操作层面体现为综合设置里的补偿项选项
- **验证技巧**：打开残余项重拟合后，观察残差曲线两端是否回平——这是判断"翘尾巴"确实来自截断误差的最直接证据

## 一句话记住

模态拟合只带带内模态上路，带外模态的贡献不消失而是变成两笔背景账：低频侧记成残余质量（随 1/ω² 衰减）、高频侧记成残余刚度（近似常数）；子结构综合时再把上残余项经 SVD 压成频率放在 10 倍带外的静态补偿模态——户口补上，装配体刚度才不缺斤短两。
