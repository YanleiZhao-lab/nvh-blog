# 结构动力学设计三板斧：灵敏度分析、修改预测与强迫响应

> 模态试验拟合出频率、阻尼、振型之后，下一步不是写报告，是改结构。车身上哪儿加筋、动力总成悬置架加多大刚度、地板加多少阻尼材料能把 40 Hz 轰鸣压下去——LMS 理论手册第二十章给了一套完整的设计闭环：灵敏度分析告诉你"在哪儿改最有效"，修改预测告诉你"改完之后模态会变成什么样"，强迫响应告诉你"改完之后工况下响应剩多少"。这篇从留数和动刚度矩阵出发推导灵敏度公式，拆解模态空间里的子结构综合，最后用 numpy 把三板斧在一个三自由度模型上全部跑通。

## 一、模态模型的第二人生：从描述到设计

试验模态分析的直接产物是一组极点和留数：每个模态 k 一个极点（含固有频率与阻尼因子），每对自由度 i、j 一个留数。多数工程师到这一步就停了——出振型动画、对仿真模型、写试验报告。但手册第二十章的立场是：这组参数本身就是一台"设计计算机"，结构改动的效果可以在上面虚拟演算，不必每次都开样件、改模具、重新测试。

要理解为什么能这么干，先看一个根本性的关系。对服从 Maxwell-Betti 互易原理的线性结构，FRF 矩阵是对称阵：H(i,j) = H(ji)。由此，任意两个自由度 m、n 之间的留数，可以从它们对参考点 j 的已知留数重建（手册式 20-4）：

$$r_{mnk} = \frac{r_{mjk}\, r_{njk}}{r_{jjk}}$$

推导只用到留数的因子分解 r = Q·psi(i)·psi(j)（模态比例因子乘两个振型系数）：分子 Q²·psi(m)·psi(j)·psi(n)·psi(j) 除以分母 Q·psi(j)²，恰好剩 Q·psi(m)·psi(n)。**物理意义：一个参考点的一列留数（含驱动点留数），加上互易性，就锁住了整个模态的振型标尺。** 这正是后两板斧的输入接口——它们要求"带标尺的模态振型"，而来路就是驱动点测量。

::: info 核心概念
- **灵敏度分析（Sensitivity Analysis）**：计算固有频率、振型对质量/刚度/阻尼改动的一阶导数，虚拟改动、不实际实施，回答"在哪儿改最有效"
- **修改预测（Modification Prediction）**：把改动（质量、弹簧、阻尼器、梁板单元、整个子结构）叠加进模态模型，重解特征值得到改动后的模态参数
- **强迫响应（Forced Response）**：用模态模型预测结构在给定力谱下的工作响应，并分解每个模态的贡献量
- **带标尺振型**：具有物理单位对应关系（留数可比）的振型，由驱动点留数定标，无标尺振型只能看形状不能算数
:::

## 二、灵敏度：固有频率对改动的导数

### 从动刚度矩阵出发的推导

数学上，灵敏度就是矩阵特征值对物理参数的偏导数。出发点是模态参数与 FRF 的关系式（手册式 20-12）：FRF 是动刚度矩阵逆阵的元素，而动刚度矩阵

$$Q(s) = s^2 M + s C + K$$

其中 s 为拉普拉斯变量。把式 20-12 对物理参数 P 取偏导（式 20-13），P 可以是某个自由度上的质量、某对自由度之间的刚度或阻尼。经过伴随矩阵关系和部分分式分解（手册式 20-14 至 20-16），频率与振型的灵敏度分离成式 20-17 和 20-18 两个闭式。

对无阻尼实模态、质量归一振型（振型对质量矩阵的广义质量为 1），公式退化成教科书形式，且能徒手推出。以**质量灵敏度**为例：特征值问题 K·psi = ω²·M·psi 两边对自由度 a 上的质量 m_a 求导，左乘振型转置并利用正交性消去振型导数项，得

$$\frac{\partial \omega_k}{\partial m_a} = -\frac{\omega_k}{2}\,\psi_{ak}^2$$

物理意义一目了然：**频率对某点质量的敏感度正比于该点振型系数的平方**。振型节点处（psi_a = 0）加配重，频率纹丝不动；振型腹点处加同样的配重，频率掉得最多。刚度灵敏度同理可推：

$$\frac{\partial \omega_k}{\partial k_{ab}} = \frac{(\psi_{ak} - \psi_{bk})^2}{2\,\omega_k}$$

其中 k_ab 是自由度 a、b 之间的弹簧刚度，接地时 b 端振型系数取零。注意分母是 ω_k 的一次方——同一根弹簧装在高阶模态上（ω 大）单位刚度收益反而小，这解释了为什么低频车身模态对局部刚度改动更敏感。

手册还给出阻尼的对应公式，并明确判读方法：式 20-19、20-21、20-23 的**虚部代表有阻尼固有频率的灵敏度，实部代表阻尼因子（指数衰减率）的灵敏度**——极点在复平面上的移动方向，虚向是错频、实向是调衰减。

### 灵敏度的三个工程读法

**读法一：找改动位置。** 把振型系数平方排出来就是质量灵敏度排名，车身顶棚 45 Hz 轰鸣模态的腹点在中部，在那儿加 1 kg 比在边缘加 3 kg 都管用。刚度灵敏度看振型差——连接两个同相位点的弹簧几乎不改变频率，想错频就要把刚度加在相对运动大的位置。

**读法二：估改动量。** 一阶外推 Δω ≈ (∂ω/∂P)·ΔP 对小改动精度很高（后文数值验证：+100 N/m 时误差 0.003 Hz），方案筛选阶段连特征值都不用重解。

**读法三：查驱动点。** 手册特别指出：计算灵敏度需要受改动影响自由度的留数，缺的留数用互易原理补算——而这条路必须有驱动点留数做分母。单参考点试验若参考点恰好落在某些模态的节点上，这些模态"测不出来"但也"设计不了"，模态模型描述所测 FRF 够用、描述结构动力学不够用。

## 三、修改预测：模态空间里的子结构综合

灵敏度是一阶近似，改动一大就失真。修改预测直接把改动揉进模型重解特征值，理论框架是子结构综合。

### 五步流程的数学骨架

考虑两个子结构，各自有模态模型。关键一步是**坐标变换到模态空间**：物理坐标运动方程经 y = V·q 变换（V 为特征向量矩阵）后，未连接时系统矩阵在模态空间是对角的——两个子结构各振各的，一个上面施力另一个纹丝不动。

现在让它们通过弹簧和阻尼器连接。连接刚度与阻尼进入系统矩阵，破坏了对角性（手册式 20-40）；再叠加各子结构自身的修改（质量、弹簧、阻尼器，式 20-42），得到最终的物理坐标方程。求解流程：

1. 调出各子结构模态模型，构建对角极点阵与带标尺振型阵；
2. 合成未连接的总成矩阵；
3. 给定连接件（弹簧、阻尼器），产生连接矩阵；
4. 给定修改项，产生修改矩阵；
5. 用模态矩阵 V 把连接与修改变换到模态空间，叠加对角项后解特征值问题——特征值的虚部、实部分别给出新模态的固有频率与阻尼因子，特征向量给出新振型。

物理图像：**改动在物理空间是局部的，变换到模态空间后是一张稠密的耦合矩阵**——任何一处局部刚度都会让所有模态互相牵手，这就是为什么装一个排气吊钩吸振器能把峰裂成两个（见本博客吸振器设计一文），也是为什么修改预测必须整队模态一起重算。
### 可以"挂"上去的修改类型

| 修改类型 | 需给定参数 | 工程对应 |
| --- | --- | --- |
| **点质量** | 结点、质量值 | 配重块、电池包附加质量 |
| **弹簧刚度** | 两自由度、刚度值 | 悬置、衬套、加强筋等效 |
| **粘性阻尼** | 两自由度、阻尼系数 | 阻尼器、约束阻尼层等效 |
| **桁架/杆元件** | 两结点、截面积/模量/密度 | 拉杆、加强杆（铰接、不传弯矩） |
| **梁元件** | 两结点加参考结点、截面与材料参数 | 加强肋、梁截面补强（传弯矩扭矩） |

::: warning 数值与建模的坑
- **不均衡修改会病态**：用大刚度模拟固支、局部强阻尼，会让特征值问题数值病态；自由-自由边界带入近 0 Hz 刚体模态与高频弹性模态混在一起时尤其如此，相关因素是最高与最低频率之比
- **频带必须包住修改后的新模态**：有限频带模型做大改动，新固有频率可能跑到带外——模型在那里无效，预测不可信。手册要求至少包含感兴趣频带上下各一个模态，残余项补偿不了振型标尺
- **新出现的带外模态一律存疑**：预测出的频率超出原试验频带的模态，不要写进结论
:::

## 四、强迫响应：模态贡献量分解

前两板斧改的是模态参数，但客户抱怨的是"工况下的振动噪声"。强迫响应把模态模型变回物理响应：频域运动方程 X(w) = H(w) * F(w)，其中 FRF 由模态模型按部分分式合成（式 20-89），或直接用带标尺振型（留数）表示（式 20-91）。

真正的价值不在合成响应本身，而在**逐模态贡献量分解**（式 20-92、20-93）：每个自由度的响应写成各模态贡献的线性组合，每个模态的贡献是"单自由度分母乘振型"——分母是 w_r^2 - w^2 + 2j*zeta_r*w_r*w，分子是振型对力向量的投影乘振型本身。两个因子各有工程含义：

- 投影小，该模态没被激励起来。激励点落在振型节点上，再大的模态也不出面；
- 分母大，激励频率离该模态远。共振只在激励频率贴着固有频率的窗口内有效。

手册的原话点破了常见误区：固有频率看似模态模型最重要的参数，**但某模态未获充分激励时，响应中该频率分量不会占优**——对轰鸣问题，先查激励谱与振型投影，别急着对每个峰下药。

## 五、Python 演示：三板斧跑通一个三自由度支架

模型：三个质量的悬臂式支架链（节点 1、2、3 依次相连再接地），质量 2/1/1.5 kg，连接刚度 2000/1500 N/m，接地刚度 1000 N/m。三阶模态 1.96 / 6.04 / 10.77 Hz。全部计算只用 numpy 的特征值分解。

### 第一板斧：灵敏度——改哪里、改多少

```python
import numpy as np

m = np.array([2.0, 1.0, 1.5])                     # 三自由度质量 kg
K = np.array([[2000.,-2000.,0.],                  # 刚度矩阵 N/m
              [-2000.,3500.,-1500.],
              [0.,-1500.,2500.]])
iM = np.diag(1/np.sqrt(m))                        # 质量对角缩放
w2, Y = np.linalg.eigh(iM @ K @ iM)               # 对称特征值问题
w, psi = np.sqrt(w2), iM @ Y                      # 圆频率与质量归一振型
sens_m = -w[0]*psi[:,0]**2/2                      # dw/dm_a = -w*psi_a^2/2
sens_k12 = (psi[0,0]-psi[1,0])**2/(2*w[0])        # dw/dk_ab = (psi_a-psi_b)^2/2w
sens_k3g = psi[2,0]**2/(2*w[0])                   # 接地弹簧: b 端振型取 0
print(f"一阶模态 {w[0]/2/np.pi:.3f} Hz, 振型 {np.round(psi[:,0],3)}")
print(f"dw/dm: {np.round(sens_m,3)} rad/s per kg")
print(f"dw/dk12 = {sens_k12:.2e}, dw/dk3g = {sens_k3g:.2e} rad/s per N/m")
print(f"单位刚度收益比 k3g/k12 = {sens_k3g/sens_k12:.1f} 倍")
Md = np.diag(m*[1.01, 1, 1])                      # 差分验证: 节点1质量 +1%
iMd = np.diag(1/np.sqrt(Md.diagonal()))
wd = np.sqrt(np.linalg.eigvalsh(iMd @ K @ iMd))[0]
print(f"节点1质量+1%: 预测 {sens_m[0]*0.01*m[0]:.4f}, 实际 {wd-w[0]:.4f} rad/s")
```

运行结果要点：质量灵敏度 [-1.93, -1.39, -0.61] rad/s/kg——节点 1 的配重收益是节点 3 的 3.2 倍，因为一阶振型（0.56/0.475/0.314）腹点在自由端；同样 1 N/m 的刚度，加在节点 3 接地处（3.99e-3）收益是加在 1-2 连接上（2.93e-4）的 **13.6 倍**，因为 1、2 两点一阶振型几乎同相位，弹簧夹在同相位点之间形变不出力。差分验证预测 -0.0386 对实际 -0.0385 rad/s，一阶公式在小改动下精度足够。

### 第二板斧：修改预测——小改动外推，大改动重解

```python
import numpy as np

m = np.array([2.0, 1.0, 1.5])
K0 = np.array([[2000.,-2000.,0.],[-2000.,3500.,-1500.],[0.,-1500.,2500.]])
iM = np.diag(1/np.sqrt(m))
def modes(K):
    w2, Y = np.linalg.eigh(iM @ K @ iM)
    return np.sqrt(w2), iM @ Y
w0, psi0 = modes(K0)
sens = psi0[2,0]**2/(2*w0[0])                      # dw/dk3g 接地刚度灵敏度
mac = lambda a, b: abs(a @ b)**2/((a @ a)*(b @ b))
for dk in [100.0, 800.0]:                          # 节点3加接地弹簧
    Kd = K0.copy(); Kd[2,2] += dk
    wd, psid = modes(Kd)                           # 特征值重解
    pred = w0[0] + sens*dk                         # 灵敏度一阶外推
    print(f"+{dk:.0f} N/m: 外推 {pred/2/np.pi:.3f} Hz, 重解 {wd[0]/2/np.pi:.3f} Hz")
    print(f"   MAC(前3阶) = {np.round([mac(psi0[:,i], psid[:,i]) for i in range(3)],3)}")
```

运行结果要点：+100 N/m 时外推 2.024 Hz 对重解 2.021 Hz，误差 0.003 Hz，一阶外推完全够用；+800 N/m 时外推 2.469 Hz 而重解 2.312 Hz，**偏差 0.157 Hz**——改动量达到原接地刚度的 80%，二阶项开始说话，此时必须走特征值重解。同时 MAC 从全 1.000 掉到 0.989/0.981，振型也在动。这正是灵敏度（小改动）与修改预测（大改动）的分工边界。

### 第三板斧：强迫响应——每个峰是谁贡献的

```python
import numpy as np

m = np.array([2.0, 1.0, 1.5])
K = np.array([[2000.,-2000.,0.],[-2000.,3500.,-1500.],[0.,-1500.,2500.]])
M = np.diag(m); beta = 0.25; C = beta*M           # C = beta*M 保证模态解耦
iM = np.diag(1/np.sqrt(m)); w2, Y = np.linalg.eigh(iM@K@iM)
w, psi = np.sqrt(w2), iM @ Y
F = np.array([0., 1.0, 0.])                       # 节点2 受 1 N
for f in [2.0, 4.0, 10.0]:
    ww = 2*np.pi*f
    H = np.linalg.solve(K - ww**2*M + 1j*ww*C, F) # 直接解 [K-w^2*M+jwC]x=F
    parts = []
    for r in range(3):                            # 模态叠加: 每阶一个 SDOF 分母
        q = (psi[:,r] @ F)/(w[r]**2 - ww**2 + 1j*beta*ww)
        parts.append(q*psi[:,r])
    x = np.sum(parts, axis=0)
    print(f"f={f:4.1f} Hz 节点2 |x|: 直接 {abs(H[1]):.3e} / 叠加 {abs(x[1]):.3e} m/N")
    print("        各模态贡献:", " ".join(f"{abs(p[1]):.2e}" for p in parts))
```

运行结果要点：直接解与模态叠加在三个频率上都严格一致（C 为质量矩阵的倍数时模态解耦精确成立），验证实现无误；贡献量分解才是看点——2 Hz 激励（贴着一阶共振）节点 2 响应里一阶模态贡献 3.29e-2，比二、三阶大三个数量级；4 Hz 激励（一、二阶之间）响应只剩 2.49e-4；10 Hz 激励贴着三阶共振，三阶贡献 1.19e-3 独大、一阶掉到 5.94e-5。**同样大小的力，作用频率决定哪个模态出面**——贡献量表就是整改优先级表。

## 六、三板斧的工程组织

| 环节 | 输入 | 输出 | 可信边界 |
| --- | --- | --- | --- |
| **灵敏度分析** | 带标尺振型、极点 | 各点质量/刚度/阻尼的一阶导数 | 小改动（约 10% 以内的局部参数变化） |
| **修改预测** | 模态模型 + 修改定义 | 新模态频率/阻尼/振型、MAC 对比 | 新模态在原频带内 |
| **强迫响应** | 模态模型 + 力谱 | 工况响应、逐模态贡献量 | 线性时不变假设 |

三步的依赖关系是一条链：强迫响应的精度取决于模态模型，模态模型的可用性取决于修改后的模态是否仍在频带内，而频带够不够宽在试验设计阶段就定了。驱动点测量是整条链的地基——没有驱动点留数，振型无标尺，灵敏度算不出绝对值，吸振器等效质量、子结构连接力全都悬空。

::: tip 实用建议
- 改动方案筛选先用灵敏度外推排队，入围方案一律用修改预测重解确认，别拿一阶外推写整改承诺
- 预测前后各阶振型做 MAC：掉得厉害的阶说明模态参与重组大，试验验证计划要跟上
- 贡献量分解放在整改最前面：激励谱不覆盖的模态不必投入，先确认"是谁在响"再动结构
- 模态试验频带按修改后可能到达的频率规划，别按当前问题频率规划——带外新模态不可信是手册反复强调的红线
:::

## 七、小结

模态模型的价值不止于描述现状。灵敏度公式把"在哪儿改"变成查表题：质量跟振型腹点走，刚度跟相对运动大的位置走；小改动外推、大改动重解、结果用 MAC 验证；最后用强迫响应的贡献量分解确认改完之后工况响应真的降了。驱动点测量和频带宽度是这套流程的两个先决条件，都在试验阶段锁定，后处理阶段无法补救。
