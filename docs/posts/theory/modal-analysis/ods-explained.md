# ODS工作变形：不测激励力的运行状态变形分析

> 整车怠速轰鸣、变速箱啸叫等排查工作，常因试验设备成本、样机占用时间或无法隔离其它作用力，不具备实施完整模态试验的条件。ODS（Operational Deflection Shape，工作变形，亦称运行模态 Running Mode）只测响应、不测激励力，直接给出“运行状态下结构各测点之间的相对运动形态”。它与模态振型的动画显示方式相似，但属于两个不同的概念——若不加区分，共振判断与噪声传递路径分析的结论都会出现偏差。

## 一、ODS 的定义与数学本质

结构运行时，每个测点都在振动。把同一频率下所有测点响应的幅值和相位集合成一个向量，在几何骨架线模型上循环动画显示出来，就是一幅 ODS——各测点之间相对运动的往复形态。

它的数学本质是强迫响应。以位移 ODS 为例，基于位移/力频响函数 $H$（单位 m/N）和激振力线性谱 $F$（单位 N），特定角频率 $\omega_p$（单位 rad/s）处各测点的响应向量为：

$$
\{X(\omega_p)\} = [H(\omega_p)]\{F(\omega_p)\} \quad \text{(Eqn 17-1)}
$$

即各测点响应等于 FRF 矩阵与力线性谱向量之积——响应由结构传递特性与激励共同决定。将 FRF 写成模态叠加形式，可展开为：

$$
X_i(\omega_p) = \sum_{k=1}^{n} V_{ik}\quad H_k(\omega_p) \sum_{j=1}^{m} V_{jk}\quad F_j(\omega_p) \quad \text{(Eqn 17-2)}
$$

其中 $i$ 为响应测点序号，$V_{ik}$ 为第 $k$ 阶振型在测点 $i$ 处的系数（无量纲，归一化后），$H_k(\omega_p)$ 为第 $k$ 阶模态频响（m/N），$V_{jk}$ 为第 $k$ 阶振型在力作用点 $j$ 处的取值，$F_j(\omega_p)$ 为作用在 $j$ 自由度上的力线性谱（N），$m$ 为激振力总数，$n$ 为模态阶数。该式表明：每一阶模态对 ODS 的贡献 = 振型 × 模态频响 × 该阶振型在力作用点的取值 × 力幅。

由式 17-1、17-2 可以直接得出 ODS 的下列性质：

::: info 核心概念
- **任意测量频率都有 ODS**：模态振型只属于确定的固有频率（由结构质量、几何尺寸、弹性模量等决定）；ODS 在任何测量频率处都能提取——1024 点数据块有 512 条谱线，理论上就有 512 个 ODS，通过谱线间插值甚至更多
- **ODS 依赖激励**：与作用力的量级、属性均有关；若某力 $F_j(\omega)$ 在 $\omega_p$ 处取值为零，则该力对 $\{X(\omega_p)\}$ 没有任何贡献。模态振型则只由结构自身决定
- **共振点与激励谱峰点 ODS 占优**：在结构共振点（$\omega_p \approx \lambda_K$，$\lambda_K$ 为第 K 阶固有频率）附近，以及作用力的谱峰频率点，ODS 幅值显著突出，是重点观察对象
- **无阻尼信息**：ODS 分析不可能给出阻尼值，也不能给出留数、模态参与因子等其它模态参数
:::

为什么说 ODS “不测激励力”？因为发动机运转、路面激励、齿轮啸合等工况激励本身就在持续激励结构，只要工况稳定，测响应谱即可构造 ODS。代价是：得到的是“这台设备此工况下的真实变形”，不是结构固有属性——换一个工况（转速、负载），ODS 随之改变。

什么时候 ODS 接近某阶模态振型？两种情况：频率落在结构共振点附近且该阶模态被显著激发；或激励力谱在该频率有峰且以某一模态贡献为主。频率落在两阶模态之间、或多阶模态混叠时，ODS 是几阶振型的线性组合，直接当作“第 N 阶振型”解读会得出错误结论。

## 二、测量方案：传导函数与互功率谱

ODS 测量的理想条件是：结构作简谐振动、短时间内工况保持不变、信噪比高到无需平均处理。实际通道数不足时要分批测量，加上工况漂移，必须设一个**参考自由度**——所有测点都相对它测量。从一批到另一批，工况变化对参考点和响应点的影响相同，相对关系（幅值比与相位差）基本被保留；同时参考信号的相位成为所有信号的相位参考，确保了各响应信号之间固定的相位关系。

工程上常用的测量函数有三种：

| 测量函数 | 计算方式 | 特点 | 适用场景 |
| --- | --- | --- | --- |
| **传导函数（Transmissibility）** | 响应谱 ÷ 参考点谱（复数比） | 无量纲；共振峰在分子分母间约分抵消，峰值不明显；反共振点分母趋零会产生假峰 | 分批测量、工况有漂移 |
| **互功率谱（Cross Spectrum）** | 响应谱 × 参考点谱的复共轭 | 峰值明确标示高响应频率；需要所有通道同时测量 | 多通道系统一次性测完 |
| **相位参考谱（Phase Referenced Spectrum）** | 每帧把参考通道相位归零、同相减所有通道 | 既有正确幅值又有正确相位，可安全平均 | 噪声大需要平均的场合 |

**传导函数**（式 17-3）：各测点响应线性谱除以参考测点线性谱，

$$
T_{ij}(\omega) = \frac{X_i(\omega)}{X_j(\omega)}
$$

其中 $j$ 为参考测点序号。若允许平均处理，也可由测量的互功率谱与自功率谱求出（式 17-4）：

$$
T_{ij}(\omega) = \frac{S_{ij}(\omega)}{S_{jj}(\omega)}
$$

传导函数代表两个谱之间的复数（含幅值和相位）比。它的峰可能来自分子互功率谱有峰（结构共振或激励谱在该频率有峰），也可能来自分母自功率谱存在零点（反共振）。对于共振峰，互功率谱和自功率谱在同一频率处都有峰，分子分母约分抵消，$T_{ij}$ 的值反而并不很大；而参考点处于反共振时，分母接近零，会出现一个与高响应无关的尖峰——读传导函数的峰必须先排查参考点反共振。

对 FRF 的不同估计方法（$H_1$、$H_2$ 和 $H_v$ 估计）同样适用于传导函数估计；当相干函数值接近 100% 时，不同估计得到的 $T_{ij}(\omega)$ 差别很小。用式 17-4 估计时，可同时计算两响应信号之间的相干函数：

$$
\gamma^2(\omega) = \frac{|S_{ij}(\omega)|^2}{S_{ii}(\omega)\quad S_{jj}(\omega)}
$$

两个响应由同一激励源引起，相干函数理应有高值；若偏低，原因与 FRF 测量相同——一个或两个信号信噪比低、信号调理性能不良，或平均过程中工况变化改变了加权因子。某频段内相干函数持续高值，是测量品质与工况稳定并存的标志。

**绝对标尺**：ODS 系数的绝对标尺可通过传导函数乘以参考自功率谱的有效值（RMS）求得（式 17-6）：

$$
X_i = T_{ij} \cdot \sqrt{S_{jj}}
$$

当测量的自功率谱具有位移平方的量纲时，ODS 标尺与位移同单位（m）；传导函数本身无量纲。位移、速度、加速度 ODS 之间可在频域按单系数换算（式 17-7 至 17-9）：在确定频率 $\omega_0$ 处，

$$
\{V\} = j\omega_0 \{X\}, \qquad \{A\} = (j\omega_0)^2 \{X\} = -\omega_0^2 \{X\}
$$

注意这是频域内一条谱线一个系数的乘法换算（相当于一次/二次微分），不是时域积分。

**互功率谱**（手册 17.2.2 节）：若能确认所有响应信号在工况不变的条件下测得，可只测每个响应自由度 $i$ 与参考自由度 $j$ 之间的互功率谱：

$$
S_{ij}(\omega) = X_i(\omega)\quad X_j^*(\omega)
$$

其中 $*$ 表示复共轭。与传导函数相比，互功率谱的峰更明确地标示高响应级的频率（仍可能来自结构共振或力谱峰），特别适合多通道测量系统一次测完所有响应的情况。带绝对标尺的 ODS 由参考自功率谱定标（式 17-11）：

$$
X_i = \frac{S_{ij}(\omega)}{\sqrt{S_{jj}(\omega)}}
$$

若测量的是位移，ODS 系数具有位移量纲。

普通 Spectrum（线性谱）函数在多帧平均时相位逐帧随机，幅值会随平均次数增加而不断衰减，得不到正确的幅值：

![同一宽带随机信号经 10、25、100 次平均后的 Spectrum 幅值：平均次数越多幅值越低](/images/ods-explained/dsp-spectrum-averaging-decay.png)

*（图源：Simcenter Testing Knowledge Base）*

需要“正确幅值 + 正确相位 + 平均”三者的场合（ODS 正是典型），应使用**相位参考谱**：指定一个参考通道，每帧、每条谱线先把参考通道的相位归零，再把同样大小的相位从其它所有通道中减去。它利用了振动结构不同测点之间固定的相位关系，使各帧数据相位一致后再平均。下图给出生效机理——同一结构上 plate:1:Z 与 plate:13:Z 同相、plate:15:Z 与 plate:13:Z 反相：

*（图源：Simcenter Testing Knowledge Base）*

每次采集起始时刻不同，导致各帧之间绝对相位不一致，直接平均会丢失正确幅值：

![三次采集因起始时刻不同产生不一致的相位，使幅值无法直接平均](/images/ods-explained/dsp-phase-ref-inconsistent.png)

相位参考谱按参考通道把各帧数据旋转到一致的相位后再平均，幅值得以保留：

::: warning 工程注意
- **ODS 无阻尼**：需要阻尼比必须回到模态分析；密集模态下 ODS 更难解读，几阶振型混在一幅变形里
- **滤波器会破坏动画**：如果对部分通道加了滤波（如去趋势、带通）而其他通道没加，滤波引入的相位延迟会改变通道间固定相位关系，动画失真
- **普通 Spectrum 平均会损失幅值**：多帧平均时相位随机、幅值递减；需要平均又要相位，用相位参考谱
- **参考点避开节点**：参考点若位于关心模态的节点（响应趋零），传导函数分母失控，全部结果失真
- **相似可能纯属巧合**：一个 56 Hz 的 ODS 与一个固有频率 200 Hz 的模态振型不存在任何关联，尽管二者有可能看起来很相近——判断关联以频率对应关系为前提
:::

## 三、ODS 与模态振型：一张表分清

| 对比项 | **ODS（工作变形）** | **模态振型** |
| --- | --- | --- |
| **所属频率** | 任意测量频率 | 固有频率（结构属性） |
| **是否依赖激励** | 是（力的量级、频率成分、作用点） | 否 |
| **物理单位** | 可定绝对标尺（m、mm/s、g） | 常归一化，无量纲 |
| **阻尼信息** | 无 | 有（模态阻尼比） |
| **获得方式** | 运行状态测响应谱即可 | 需可控激励 + FRF + 曲线拟合 |
| **典型用途** | 工况下变形定位、噪声源排查、验证 CAE | 结构动态特性描述、修改预测 |

判断一幅 ODS 是否“某一阶振型占主导”，标准工具是 MAC（Modal Assurance Criterion，模态置信判据）与 MSF（Modal Scale Factor，模态比例因子）。以 $[V]$ 表示一组模态振型（或 ODS）构成的矩阵，$\{V_{jk}\}$、$\{V_{lk}\}$ 为其中第 $j$、$l$ 列向量，上标 $H$ 表示共轭转置，则（式 17-12、17-13）：

$$
MSF_{jlk} = \frac{V_{jk}^{H} V_{lk}}{V_{jk}^{H} V_{jk}}
$$

$$
MAC_{jlk} = \frac{\left| V_{jk}^{H} V_{lk} \right|^{2}}{\left( V_{jk}^{H} V_{jk} \right) \left( V_{lk}^{H} V_{lk} \right)}
$$

两个向量线性相关（一幅是另一幅的常数倍）时 MAC 接近 1（100%），MSF 即二者之间的比例常数；彼此无关时 MAC 接近零，MSF 无意义。把实测 ODS 与各阶计算/试验模态振型逐一计算 MAC，值接近 100% 的那阶即主导模态。按 LMS 手册的判据：ODS 与模态振型彼此对应时，MAC 应接近 100%，MSF 应接近于整数。

更进一步可做**模态分解（Modal Decomposition）**：若模态模型与 ODS 自由度数相同，把每一个 ODS 展开为模态振型（模态“基”群）的线性组合，即可追踪共振现象主要源于哪一阶模态的贡献，并给出相对误差（Rest）。

## 四、Python 演示：同一根梁，三个频率三幅形

用一根简支梁的 9 个测点演示 ODS 与模态振型的关系：两阶模态（12 Hz、47 Hz），力作用在第 4 个测点。分别提取 12 Hz（第一阶共振）、30 Hz（两阶之间）、47 Hz（第二阶共振）三个频率的 ODS，与两阶解析振型计算 MAC。

```python
import numpy as np

# 简支梁示意：9 个测点，两阶模态，模态叠加法生成各点响应
x = np.linspace(0, 1, 9)
phi1 = np.sin(np.pi * x)            # 一阶振型
phi2 = np.sin(2 * np.pi * x)        # 二阶振型
f1, f2, zeta = 12.0, 47.0, 0.02     # 固有频率与阻尼比
fp, F0 = 3, 10.0                    # 激振力作用在第 4 个测点，10 N

def ods(f):                          # 模态叠加：X(f) = Σ phi_k · H_k(f) · phi_k(fp) · F0
    w, w1, w2 = 2*np.pi*f, 2*np.pi*f1, 2*np.pi*f2
    h1 = 1 / (w1**2 - w**2 + 2j*zeta*w1*w)
    h2 = 1 / (w2**2 - w**2 + 2j*zeta*w2*w)
    return F0 * (phi1*h1*phi1[fp] + phi2*h2*phi2[fp])

def mac(a, b):                        # 模态置信判据 MAC（0~1）
    return abs(np.vdot(a, b))**2 / (np.vdot(a, a).real * np.vdot(b, b).real)

print("频率      幅值@测点2/4/6 (um)        MAC-一阶  MAC-二阶")
for f in [f1, 30.0, f2]:
    v = np.abs(ods(f)) * 1e6         # 换算成微米
    print(f"{f:5.1f} Hz   {v[2]:7.1f} / {v[4]:6.1f} / {v[6]:7.1f}"
          f"    {mac(ods(f), phi1):.3f}    {mac(ods(f), phi2):.3f}")
```

运行结果（实测输出）：

```text
频率      幅值@测点2/4/6 (um)        MAC-一阶  MAC-二阶
 12.0 Hz    28729.9 /  40628.7 /  28728.0    1.000    0.000
 30.0 Hz       82.8 /    309.5 /    355.4    0.837    0.163
 47.0 Hz     2029.5 /    113.3 /   2027.8    0.003    0.997
```

结果要点：12 Hz 共振处 MAC-一阶 = 1.000，ODS 与振型一致；47 Hz 时测点 4 幅值只有 113 μm，两侧测点是它的约 18 倍（17.9 倍）——测点 4 正是二阶振型的节点，节点不动是识别振型的依据；30 Hz 落在两阶之间，MAC 0.837/0.163，两阶混叠、谁都不主导，这正是 ODS 最容易误读的频区。

## 五、小结

ODS 是工况下的真实变形，不是结构属性。工程判断顺序：先看动画定位“哪里动得大、节点在哪”，再用 MAC 对照模态振型确认主导模态，需要阻尼和修改预测时回到模态分析。通道不够分批测时，参考点选响应大且稳定的非节点位置；传导函数的峰先排查参考点反共振再下结论；既要平均又要相位时用相位参考谱。
