# 声场指数与动态性能指数：声强法测量的质量判据

> 声强法可以在现场直接测定声源的声功率级，但数据是否可用须依据 ISO 9614-1 规定的指标体系逐项核验：声压残余声强指数由探头两通道的相位失配决定，给出测量下限；扣除偏差因子后得到动态性能指数；声场指数 F1 到 F4 分别量化声场的时间稳定性、声压与声强的偏差、外噪声源贡献与空间不均匀性。两条判据，$L_d - F_2 > 0$（测量链精度）与 $N > C F_4^2$（网格充分性），须逐频带执行。本文从定义出发推导上述各量，说明每条判据不满足时的处理措施，并附 Python 数值演示。

## 一、测量下限的来源：残余声强与声压残余声强指数

声强探头由两只间距为 $d$（m）的传声器组成。声强的法向分量 $I_n$（$\mathrm{W/m^2}$）由两路信号的互谱虚部计算：

$$
I_n = \frac{\mathrm{Im}\{S_{21}\}}{2\pi f \rho d}
$$

其中 $S_{21}$ 为两传声器信号的双边互功率谱，$f$ 为频率（Hz），$\rho$ 为空气密度（$\mathrm{kg/m^3}$）。推导路线是欧拉方程：质点速度等于声压梯度的时间积分；间距 $d$ 足够小时，梯度用有限差分近似，得 $u \approx \frac{p_2 - p_1}{\mathrm{j}\omega \rho d}$；与平均声压 $\frac{p_1 + p_2}{2}$ 相乘取时间平均（频域对应取互谱虚部），即得上式。

理论上，将探头置于**声压处处均匀**的声场（如耦合腔）中，两路信号完全相同，压力梯度为零，声强读数应为零。实际上，两只传声器与两路前置放大电路不可能完全一致：即使声压相同，两通道之间仍存在残余**相位失配** $\phi_e$（rad）。该失配经互谱虚部计算表现为一个表观声强，即**残余声强（Residual Intensity, RI）**：

$$
L_{RI} = L_p - \delta_{pIo} \quad \text{(dB)}
$$

其中 $L_p$ 为测量声压级，$\delta_{pIo}$ 为声压残余声强指数。残余声强级给出了给定声压级下测量系统可检测的最低声强级，低于该值的读数被通道相位失配淹没。

残余声强级随声压级浮动，不是固定值；固定不变的特征参数是**声压残余声强指数（Pressure-Residual Intensity Index）** $\delta_{pIo}$，即同一信号同时馈入两个测量通道时的声压级与声强级之差：

$$
\delta_{pIo} = L_p - L_{I_n} \quad \text{(dB)}
$$

它与声压级无关，由两通道的相位失配决定，是探头标定状态的固有参数。

$\delta_{pIo}$ 与相位失配的定量关系可由平面行波导出。平面波沿探头轴向传播时，两传声器间的相位传播差为 $k d$（$k = \omega / c$ 为波数，$\omega$ 为角频率，$c$ 为声速）；通道相位失配 $\phi_e$ 产生的残余声强为 $I_{RI} \approx \frac{p^2 \phi_e}{\omega \rho d}$（$\phi_e$ 为小量），而平面行波声强为 $I = \frac{p^2}{\rho c}$。两者之比取对数：

$$
\delta_{pIo} = 10 \lg \frac{k d}{\phi_e} \quad \text{(dB)}
$$

该式说明两点。其一，频率降低时 $k$ 减小、$k d$ 变小，$\delta_{pIo}$ 随之下降，探头的可用动态范围在低频变窄。其二，加大间距 $d$ 可提高低频 $\delta_{pIo}$，但 $d$ 过大会使有限差分近似在高频失效，选配隔离垫时须在低频动态范围与高频上限之间权衡。

由此，声强测量的有效范围为：

$$
L_p - \delta_{pIo} < L_I < L_p
$$

下限为残余声强级；上限为声压级。自由场中沿传播方向测量时声强级等于声压级，其他声场中声波斜入射或存在反射时，法向声强是矢量投影，声强级低于声压级。

::: info 核心概念
- **残余声强（Residual Intensity, RI）**：通道相位失配产生的表观声强，给出给定声压级下的可测声强下限，随声压级变化
- **声压残余声强指数 $\delta_{pIo}$**：同一信号馈入两通道时的 $L_p - L_{I_n}$，与声压级无关，取决于相位失配 $\phi_e$，$\delta_{pIo} = 10 \lg (kd/\phi_e)$
- **动态性能指数 $L_d$**：$\delta_{pIo} - \chi$，扣除精度安全余量后探头的可用工作范围
:::

## 二、动态性能指数：按精度等级扣除安全余量

直接以 $\delta_{pIo}$ 对应的残余声强级作为工作下限，测量值将贴近测量下限，精度无法保证。为此 ISO 引入**偏差因子（bias factor）** $\chi$，提高测量下限：

$$
L_p - \delta_{pIo} + \chi < L_I < L_p
$$

等效地下限为 $L_p - (\delta_{pIo} - \chi)$。声压残余声强指数与偏差因子之差定义**动态性能指数（Dynamic Capability Index）** $L_d$：

$$
L_d = \delta_{pIo} - \chi \quad \text{(dB)}
$$

探头在 $L_p - L_d < L_I < L_p$ 范围内工作，声强读数的精度等级才有依据。

![图5-1 动态性能指数：残余声强指数扣掉偏差因子后的可用工作范围](/images/sound-field-indicators/fig5-1-dynamic-capability.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册）*

偏差因子按精度等级选取，手册表 5-1 的取值：

| 精度等级 | 偏差因子 $\chi$ (dB) |
| --- | --- |
| **精密级（1 级）** | 10 |
| **工程级（2 级）** | 10 |
| **观察级（3 级）** | 7 |

![表5-1 偏差因子取值](/images/sound-field-indicators/table5-1-chi.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册）*

精密级与工程级的 $\chi$ 均取 10 dB，观察级取 7 dB。观察级扣减较少，$L_d$ 相应较大，允许声强级更接近残余声强下限，对应较低的精度要求；精密级与工程级扣减 10 dB，测量下限提高、工作范围收窄，以换取精度保证。$\chi$ 的取值体现精度与量程之间的权衡。

::: warning 工程注意
$\delta_{pIo}$ 是每一对传声器通道的属性。探头受到机械冲击、更换隔离垫、更换前置放大器或改变通道分配后，必须重新标定。长期在台架上使用的探头，拆除后应先在耦合腔中复核残余声强指数，再决定数据是否可用。
:::

## 三、声场指数 F1 到 F4：表征声场的时间与空间特性

测量链达标只是前提，声场本身的状况也须量化。ISO 9614-1 定义了一组**声场指数（Field Indicators）**，各自表征声场的一个侧面。

![图5-2 声源、声测量网格与结点](/images/sound-field-indicators/measure-surface.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册）*

**F1：声场瞬变指数（temporal variability index）**，量化声场随时间的波动。取 $M$ 个短时平均声强 $I_{nk}$ 与总平均 $\bar{I}_n$ 的相对标准差：

$$
F_1 = \frac{1}{\bar{I}_n}\sqrt{\frac{1}{M-1}\sum_{k=1}^{M}\left(I_{nk} - \bar{I}_n\right)^2}
$$

其中 $\bar{I}_n = \frac{1}{M}\sum_{k=1}^{M} I_{nk}$。稳态工况下 F1 接近零；风扇负载周期性波动、间歇性漏气等时变干扰会使 F1 增大。

**F2：测量面声压与声强指数（surface pressure-intensity index）**。自由场中单一声源辐射时 $L_p = L_I$；混响场或扩散场中，声压是各方向能量的标量叠加，声强是矢量投影，$L_I$ 低于 $L_p$；声波斜入射到探头也产生同样效果。F2 定义为：

$$
F_2 = L_p - L_{I_n} \quad \text{(dB)}
$$

其中声压级与声强级均按测量面 $N$ 个分块做能量平均：

$$
L_p = 10\lg\left(\frac{1}{N}\sum_{i=1}^{N}10^{L_{p,i}/10}\right), \qquad
L_{I_n} = 10\lg\left(\frac{1}{N}\sum_{i=1}^{N}10^{L_{I_{n,i}}/10}\right)
$$

F2 中的法向声强取**绝对值**（不带正负号）。F2 越大，声场的反应性越强，被测声源的能量被反射、斜入射稀释得越严重，声强测量的系统误差越大。手册提示：声压级与声强级相差过大时，可能是探头没有对正声源，或探头处于扩散场中。计算 F2 需要在网格所有结点同时测量声强与声压自功率谱。

**F3：局部负功率指数（local negative power index）**，与 F2 使用同一组数据，但声强**带正负号**平均：

$$
F_3 = L_p - L_{I_n}(\text{带符号}) \quad \text{(dB)}
$$

封闭测量面上部分分块声强为正（被测声源能量流出），部分为负（外噪声源输入）。带符号平均时负贡献抵消正贡献，$L_{I_n}$ 减小，因此 F3 大于等于 F2。手册另有一条警示：若带符号的平均声强为负值，说明外噪声源贡献已占主导，测量不满足 ISO 标准的要求。计算 F3 同样需要声强与声压自功率谱。

**F4：不均匀指数（non-uniformity index）**，量化声强沿测量面分布的空间不均匀性，等于统计标准差与平均值之比：

$$
F_4 = \frac{1}{\bar{I}_n}\sqrt{\frac{1}{N-1}\sum_{i=1}^{N}\left(I_{ni} - \bar{I}_n\right)^2}
$$

其中 $\bar{I}_n = \frac{1}{N}\sum_{i=1}^{N} I_{ni}$。F4 大，说明声源辐射在测量面上分布不均匀（如强指向性排气口），网格不够密时会遗漏空间细节。计算 F4 只需声强数据。

| 指数 | 表征内容 | 所需数据 | 偏大的含义 |
| --- | --- | --- | --- |
| **F1** | 时间稳定性 | 声强（多段短时平均） | 工况不稳、间歇性干扰 |
| **F2** | 声压与声强的偏差 | 声强 + 声压自功率谱 | 扩散场、斜入射、探头未对正声源 |
| **F3** | 外噪声源贡献（带符号） | 声强 + 声压自功率谱 | F3 与 F2 之差大于 3 dB：近处存在强定向外噪声源 |
| **F4** | 空间不均匀性 | 仅声强 | 网格过稀、声源指向性强 |

## 四、两条判据及不满足时的处理措施

声场指数算出后须对照判据做决策。ISO 9614-1 规定两条判据（准则之一、之二），另有一条外噪声源核验项。

**判据一（测量链精度）：每一分析频带内 $L_d - F_2 > 0$。**

动态性能指数必须大于测量面声压与声强指数：F2 把声强级压低多少 dB，探头就必须有比这更宽的干净动态范围去接收。不满足时说明被测声级相对测量链太低，手册给出的处理措施是**缩短测量面到声源的距离**，离源越近，直达声占比越高，F2 越小。该判据逐频带检查；由 $\delta_{pIo} = 10 \lg (kd/\phi_e)$，低频 $kd$ 减小使 $L_d$ 下降，因此低频段最先不满足，对应的措施是缩短测量距离或换用更长间距的隔离垫。

**判据二（测量网格充分性）：$N > C \cdot F_4^2$。**

F4 为线性量，平方后乘以与精度等级和频带对应的因子 C，即为所需的最少测点数 N：分布越不均匀（F4 越大），所需测点数按平方增长。同一网格用于多个频带测量时，取 $C \cdot F_4^2$ 的最大值作为判据。

**外噪声源核验：$F_3 - F_2 > 3\ \text{dB}$。**

F3 与 F2 之差超过 3 dB，表明被测声源近处存在很强的定向外噪声源。手册给出的处理措施：缩短测量面到声源的平均距离、隔离被测声源与外噪声源、或减少射向被测声源的反射声。此项不满足时应先处理外噪声源再复测，否则其余判据的结论不可靠。

![表5-3 不同精度等级与频带下的 C 因子取值](/images/sound-field-indicators/table5-3-C.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册）*

C 因子按手册表 5-3 选取：

| 中心频率（倍频程带，Hz） | 中心频率（1/3 倍频程带，Hz） | C（精密级 1 级） | C（工程级 2 级） | C（观察级 3 级） |
| --- | --- | --- | --- | --- |
| **63-125** | 50-160 | 19 | 11 | - |
| **250-500** | 200-630 | 9 | 19 | - |
| **1000-4000** | 800-5000 | 57 | 29 | - |
| - | 6300 | 19 | 14 | - |
| **A 计权（63-4k 或 50-6.3k Hz）** | - | - | - | 8 |

表中两点值得注意（工程上的通常解释）：一是 1-4 kHz 频带精密级的 C 高达 57，明显高于低频带，高频声源辐射指向性增强，声强在测量面上分布更不均匀，需要更多测点采样；二是工程级在 250-500 Hz 的 C（19）大于精密级（9），两档允许的空间采样误差分量不同，工程级需以更密的网格补偿测量链其余环节。观察级仅对 A 计权声功率级给出 C = 8，用于精度要求不高的验收性测量。

::: tip 判据的检查顺序
- 先核验 $F_3 - F_2$：超过 3 dB 说明存在强定向外噪声源，先缩短距离、隔离外源或减少反射，再复测
- 再核验 $L_d - F_2$：不满足时缩短测量面到声源的距离；仅低频不满足时换用更长间距的隔离垫
- 最后核验 $N > C F_4^2$：不满足时加密网格，优先补强指向性声源正对的分块
:::

## 五、Python 演示

**演示一：动态性能指数与判据一的逐频带检查。** 设探头 $\delta_{pIo}$ 随频率变化（低频 $kd$ 减小，$\delta_{pIo}$ 降低），对比某测量面的 F2 谱：

```python
import numpy as np

# 某探头残余声强指数谱（低频 kd 减小、指数降低）与测量面 F2 谱（低频扩散贡献大）
freq      = np.array([63, 125, 250, 500, 1000, 2000, 4000])
delta_pIo = np.array([14.0, 18.0, 21.0, 23.0, 24.0, 24.0, 23.0])  # dB
F2        = np.array([11.5, 12.0, 10.0,  7.0,  5.0,  4.0,  3.5])  # dB
chi       = 10            # 工程级偏差因子 (dB)

Ld = delta_pIo - chi     # 动态性能指数
margin = Ld - F2         # 判据一余量，必须 > 0

print(f"{'f(Hz)':>6} {'d_pIo':>6} {'Ld':>5} {'F2':>5} {'margin':>7}  判定")
for f, d, l, f2, m in zip(freq, delta_pIo, Ld, F2, margin):
    verdict = "OK" if m > 0 else "FAIL->缩短距离"
    print(f"{f:>6} {d:>6.1f} {l:>5.1f} {f2:>5.1f} {m:>7.1f}  {verdict}")
```

输出显示问题集中在低频：63 Hz 和 125 Hz 频带余量分别为 -7.5 dB 和 -4.0 dB，判据一不满足，低频段需将测量面移近声源，或在报告中注明该频带不满足工程级要求；1 kHz 以上余量不低于 9 dB，数据可用。

**演示二：F4 不均匀指数与测点数估算。** 测量面 12 个分块的法向声强，分布越分散，需要的测点越多：

```python
import numpy as np

# 某测量面 12 个分块的法向声强 (W/m^2)，第 6 块正对排气口明显偏强
I = np.array([0.8, 1.2, 0.9, 1.1, 1.0, 9.0, 4.0, 1.3, 0.9, 1.0, 1.2, 0.8]) * 1e-3

F4 = np.std(I, ddof=1) / np.mean(I)      # 不均匀指数（标准差/均值，N-1）
print(f"平均法向声强  = {np.mean(I)*1e3:.2f} mW/m^2")
print(f"F4 不均匀指数 = {F4:.2f}")

for band, C in [("1-4k 倍频程带(精密级)", 57), ("250-500 倍频程带(精密级)", 9)]:
    N_need = C * F4**2
    ok = "够" if 12 > N_need else "不够,需加密"
    print(f"{band:<26} C={C:>2} -> 最少测点 N = {N_need:.0f} (现有 12 点: {ok})")
```

正对排气口的 9.0 mW/m^2 分块使 F4 达到 1.24：按精密级，1-4 kHz 频带需要约 87 个测点、250-500 Hz 频带需要约 14 个，现有 12 点均不足；按工程级（C = 29 与 19）也分别需要约 45 与 29 个测点。整改方向不是全测量面均匀加密，而是向排气口正对的分块局部加密，F4 大是局部现象，测点也应补在局部。

## 六、小结

- 声强数据是否可用须经过三道核验：探头标定参数（$\delta_{pIo}$）、声场指数（F1 到 F4）、判据对照（$L_d - F_2 > 0$ 与 $N > C F_4^2$），逐频带执行，低频最先不满足
- 声压残余声强指数是每一对传声器通道的固有参数，$\delta_{pIo} = 10 \lg (kd/\phi_e)$，低频 $kd$ 减小使其下降；探头受冲击、换垫、换通道后必须重新标定；动态性能指数 $L_d = \delta_{pIo} - \chi$，精密级与工程级 $\chi$ 取 10 dB，观察级取 7 dB
- F2 大说明声场反应性强（扩散场、斜入射），F3 与 F2 之差超过 3 dB 说明存在强定向外噪声源，须先处理再复测；两个声压与声强指数的差别在于法向声强是否带符号平均
- 高频带 C 因子最大（1-4 kHz 精密级达 57），指向性强的声源所需测点数按 $C F_4^2$ 平方增长，网格加密应优先补强辐射正对的分块
- 报告中应逐频带列出各判据的通过情况，仅给出声功率级单值不足以支撑数据有效性
