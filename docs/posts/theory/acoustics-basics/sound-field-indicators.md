# 声场指数与动态性能指数：声强法测量的质量判据

> 声强法宣称"现场测声功率、背景噪声高 10 dB 也不怕"，但报告交出去之前得先回答：这台设备、这个声场、这张网格，测出来的数到底算不算数？ISO 9614-1 给出了一套完整的体检指标——残余声强、声压残余声强指数、动态性能指数，加上 F1 到 F4 四个声场指数和两条判据。这篇把这些公式从定义出发推导一遍，说清每条判据不满足时该往哪儿动手。

## 一、先算仪器底噪：残余声强从哪来

声强探头的核心是两路传声器信号的互谱虚部（$I_n = \frac{\mathrm{Im}\{S_{21}\}}{2\pi f \rho d}$）。推导路线是欧拉方程：质点速度等于声压梯度的积分，两路传声器间距 $d$ 足够小时，梯度用有限差分近似，速度 $u \approx \frac{p_2 - p_1}{j\omega\rho d}$，与平均声压 $\frac{p_1+p_2}{2}$ 相乘取实部，互谱的虚部就这样进了公式。

理论上，把探头放进一个**声压处处均匀**的声场（比如耦合腔），两个传声器收到完全相同的信号，梯度为零，声强读数应该是零。实际不然：两路传声器、两路前置放大电路不可能完全一致，哪怕信号相同，两通道之间也残留一点**相位失配** $\phi_e$。这点失配经过互谱虚部一算，就变成一个表观声强——这就是**残余声强（Residual Intensity, RI）**。

把残余声强换算成级，与当时当地的声压级相减：

$$L_{RI} = L_p - \delta_{pIo} \quad \text{(dB)}$$

这个差值 $\delta_{pIo}$ 叫**声压残余声强指数**。关键在于：单独看残余声强，它随声压级水涨船高，似乎没有不变的"底噪"；但把同一信号同时馈入两通道，$L_p - L_{I_n}$ 这个差是固定的——它就是这套探头的指纹。手册给出的完整测量区间写法：

$$L_p - \delta_{pIo} < L_I < L_p$$

下限是残余声强（再低就被仪器自身的相位失配淹没），上限是声压级（自由场中声强级等于声压级，其他声场里声强级只会更低——声波斜入射或有反射时，法向声强是矢量投影，必然打折）。

::: info 核心概念
- **残余声强（RI）**：通道相位失配造成的表观声强，是声强测量的"噪声地板"，随声压级浮动
- **声压残余声强指数 $\delta_{pIo}$**：$L_p - L_{I_n}$ 的固定差值，探头出厂指纹，与声压级无关
- **动态性能指数 $L_d$**：$\delta_{pIo} - \chi$，扣掉精度安全余量后探头真正可用的工作范围
:::

## 二、动态性能指数：给精度等级留出安全余量

直接拿 $\delta_{pIo}$ 当工作下限，测出来的数刚好压在噪声地板上，误差没保证。ISO 的办法是再往下扣一笔**偏差因子** $\chi$：

$$L_p - (\delta_{pIo} - \chi) < L_I < L_p$$

$$L_d = \delta_{pIo} - \chi \quad \text{(dB)}$$


$\delta_{pIo}$ 与 $\chi$ 的差就是**动态性能指数** $L_d$——探头在这个范围内工作，声强读数的精度才有依据。

![图5-1 动态性能指数：残余声强指数扣掉偏差因子后的可用工作范围](/images/sound-field-indicators/fig5-1-dynamic-capability.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册）*

偏差因子按精度等级选取，手册表 5-1 的取值：

| 精度等级 | 偏差因子 $\chi$ (dB) |
| --- | --- |
| **精密级（1 级）** | 10 |
| **工程级（2 级）** | 10 |
| **观察级（3 级）** | 7 |

![表5-1 偏差因子取值](/images/sound-field-indicators/table5-1-chi.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册）*


注意一个反直觉的细节：精密级和工程级的 $\chi$ 都是 10 dB，观察级反而只扣 7 dB。等级越低留的余量越少，不是要求更松，而是观察级本来就不承诺精度，只求"能读出个数"。$\chi$ 扣得越多，$L_d$ 越小，工作范围越窄——精度和量程做的是同一笔交易。

::: warning 工程注意
$\delta_{pIo}$ 是**每对传声器**的属性，探头摔过、隔离垫换过、前置放大器换通道，都得重新标定。台架上传了三个月的探头，下台前先回耦合腔里验一次残余声强指数，再决定数据能不能用。
:::

## 三、声场指数 F1 到 F4：给声场做体检

仪器过关只是第一步，声场本身也得合格。ISO 9614-1 定义了一组声场指数（Field Indicators），每个盯一个侧面。

![图5-2 声源、声测量网格与结点](/images/sound-field-indicators/measure-surface.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册）*

**F2：测量面声压—声强指数**，最核心的一条。自由场中单一声源辐射时 $L_p = L_I$；混响场、扩散场里，声压是各方向能量的标量叠加，声强是矢量投影，$L_I$ 会被稀释。定义：

$$F_2 = L_p - L_{I_n} \quad \text{(dB)}$$

其中声压级和声强级都按测量面 $N$ 个分块做能量平均（$L_p = 10\lg\frac{1}{N}\sum_i 10^{L_{p,i}/10}$，$L_{I_n}$ 用**不带正负号**的法向声强绝对值）。F2 越大，说明声场越"浑"——被测声源的能量被反射、被斜入射稀释得越厉害，测出的声强离真值越远。手册的提醒：F2 偏大时，可能是探头没有对正声源，或者探头已经泡在扩散场里。

**F3：局部负功率指数**，和 F2 用同一组数据，但声强**带正负号**平均：

$$F_3 = L_p - L_{I_n}(\text{带符号})$$


封闭面上有的面元声强为正（能量流出），有的为负（外噪声源灌进来）。带符号一平均，负贡献把总值往下拽，$L_{I_n}$ 变小，F3 就比 F2 大。两者的差值有明确含义：

$$F_3 - F_2 > 3 \ \text{dB} \Rightarrow \text{近处存在强定向的外噪声源}$$

差值超过 3 dB，别急着改探头，先看看是不是旁边那台液压泵在往你的测量面里灌能量。

**F1：声场瞬变指数**，量化声场随时间的波动，取 M 个短时均值 $I_{nk}$ 与总平均 $\bar{I}_n$ 的相对偏差：

$$F_1 = \frac{1}{\bar{I}_n}\sqrt{\frac{1}{M}\sum_{k=1}^{M}(I_{nk} - \bar{I}_n)^2}$$

稳态工况 F1 应该很小；风扇负载周期波动、间歇性漏气这类时变干扰会把它顶起来。

**F4：不均匀指数**，量化声强在测量面上分布的空间不均匀性——标准差与均值之比：

$$F_4 = \frac{1}{\bar{I}_n}\sqrt{\frac{1}{N-1}\sum_{i=1}^{N}(I_{ni} - \bar{I}_n)^2}$$

F4 大，说明声源辐射在面上分布很不均匀（比如一个强指向性的排气口），网格不够密就会漏掉空间细节。它只要求测声强，不需要声压数据。

| 指数 | 盯什么 | 需要的数据 | 偏大时意味着 |
| --- | --- | --- | --- |
| **F1** | 时间稳定性 | 声强（多次短时平均） | 工况不稳、间歇干扰 |
| **F2** | 声场浑浊度 | 声强 + 声压自谱 | 扩散场、斜入射、探头没对正 |
| **F3** | 外源污染（带符号） | 声强 + 声压自谱 | F3-F2 大于 3 dB：近处有强定向干扰源 |
| **F4** | 空间不均匀性 | 仅声强 | 网格太稀、声源指向性强 |

## 四、两条判据：不满足时往哪动手

指数算出来不是看的，是用来对照判据做决策的。ISO 9614-1 给了两条。

**判据一：$L_d - F_2 > 0$，测量链精度够不够。**

每个分析频带里，探头的动态性能指数必须大于测量面的声压—声强指数。物理含义很直白：F2 把声强级往下压了多少 dB，探头就得有比这更宽的干净量程去接住它。不满足时手册给的处方是**缩短测量面到声源的距离**——离源越近，直达声占比越高，F2 越小。注意这条判据逐频带检查：低频段跨垫相位小、$\delta_{pIo}$ 缩水，往往先在低频翻车。

**判据二：$N > C \cdot F_4^2$，测量网格够不够密。**

F4 是标准差与均值的比值（线性量），平方后与频带、精度等级对应的因子 C 相乘，就是需要的最少测点数 N。直观理解：分布越不均匀（F4 大），要采样的点数按平方增长；同一张网格服务多个频带时，取 $C \cdot F_4^2$ 的最大值。


![表5-3 不同精度等级与频带下的 C 因子取值](/images/sound-field-indicators/table5-3-C.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册）*

C 的取值按手册表 5-3 整理：

| 中心频率（倍频程带） | 中心频率（1/3 倍频程带） | C（精密级 1 级） | C（工程级 2 级） |
| --- | --- | --- | --- |
| **63-125 Hz** | 50-160 Hz | 19 | 11 |
| **250-500 Hz** | 200-630 Hz | 9 | 19 |
| **1000-4000 Hz** | 800-5000 Hz | 57 | 29 |
| — | 6300 Hz | 19 | 14 |
| **A 计权（63-4k 或 50-6.3k Hz）** | — | — | 8 |

值得看两处：一是 1-4 kHz 频带的 C 高达 57，比低频带大好几倍——高频声源尺寸相对波长变小、辐射指向性变强，面上分布更不均匀，需要更多测点去采样；二是工程级在 250-500 Hz 的 C（19）反而比精密级（9）大，这不是标准写反了，而是两档允许的空间采样误差不同，工程级要用更密的网格弥补分析链路其余环节的损失。A 计权总值对应 C=8，做单次验收扫描时经常用这条兜底。

::: tip 三条判据的处理顺序
- 先看 $F_3 - F_2$：超 3 dB 说明有外源捣乱，隔离或关掉干扰源，否则后面都白测
- 再看 $L_d - F_2$：不过关就缩短测量距离；低频翻车换更长的隔离垫
- 最后看 $N > C F_4^2$：不过关就加密网格，重点补强指向性声源正对的那个面
:::

## 五、Python 演示

**演示一：动态性能指数与判据一的逐频带检查。** 设探头 $\delta_{pIo}$ 随频率变化（低频跨垫相位小、指数缩水），对比某测量面的 F2 谱：

```python
import numpy as np

# 某探头残余声强指数谱（低频缩水）与测量面 F2 谱（低频声场浑浊）
freq      = np.array([63, 125, 250, 500, 1000, 2000, 4000])
delta_pIo = np.array([14.0, 18.0, 21.0, 23.0, 24.0, 24.0, 23.0])  # dB
F2        = np.array([11.5, 12.0, 10.0,  7.0,  5.0,  4.0,  3.5])  # dB
chi       = 10            # 工程级偏差因子 (dB)

Ld = delta_pIo - chi     # 动态性能指数
margin = Ld - F2         # 判据一余量，必须 > 0

print(f"{'f(Hz)':>6} {'d_pIo':>6} {'Ld':>5} {'F2':>5} {'margin':>7}  判定")
for f, d, l, f2, m in zip(freq, delta_pIo, Ld, F2, margin):
    verdict = "OK" if m > 0 else "FAIL->缩短距离"
    print(f"{f:>6} {d:>6.1f} {l:>5.1f} {f2:>5.1f} {m:>7.1f}  {verdict}")
```

跑一遍就能看到问题出在低频：63 Hz 和 125 Hz 频带余量为 -7.5 dB 和 -4.0 dB，判据一翻车——低频段要么把测量面往声源贴，要么在报告里注明该频带不满足工程级要求。1 kHz 以上余量都在 9 dB 以上，数据干净。

**演示二：F4 不均匀指数与测点数估算。** 测量面 12 个分块的法向声强，分布越散，需要的测点越多：

```python
import numpy as np

# 某测量面 12 个分块的法向声强 (W/m2)，第 6 块正对排气口明显偏强
I = np.array([0.8, 1.2, 0.9, 1.1, 1.0, 9.0, 4.0, 1.3, 0.9, 1.0, 1.2, 0.8]) * 1e-3

F4 = np.std(I, ddof=1) / np.mean(I)      # 不均匀指数（标准差/均值）
print(f"平均法向声强  = {np.mean(I)*1e3:.2f} mW/m2")
print(f"F4 不均匀指数 = {F4:.2f}")

for band, C in [("1-4k 倍频程带", 57), ("250-500 倍频程带", 9)]:
    N_need = C * F4**2
    ok = "够" if 12 > N_need else "不够,需加密"
    print(f"{band:<18} C={C:>2} -> 最少测点 N = {N_need:.0f} (现有 12 点: {ok})")
```

排气口那一块的 9.0 mW/m2 把 F4 顶到 1.24：1-4 kHz 频带需要约 87 个测点，现有 12 点远远不够；250-500 Hz 频带要 14 点，也差一点。整改方向不是全测量面均匀加密，而是把网格往排气口正对的面上局部加密——F4 大是局部现象，补点也该补在局部。

## 六、小结

- 声强法的数据能不能用，走三道门：探头指纹（$\delta_{pIo}$ 标定）、声场体检（F1 到 F4）、判据对照（$L_d - F_2 > 0$ 与 $N > C F_4^2$），逐频带检查，低频最先出事
- 残余声强指数是探头级属性，摔碰、换垫、换通道后必须重标；动态性能指数等于 $\delta_{pIo}$ 减 $\chi$，工程级 $\chi$ 取 10 dB，观察级取 7 dB
- F2 大说明声场浑（扩散场、斜入射），F3 与 F2 的差大于 3 dB 说明有强定向外源要先处理；两个"声压—声强"指数一个不带符号、一个带符号，差值就是外源污染的账单
- 高频带 C 因子最大（1-4 kHz 达 57），指向性强的源按 $C F_4^2$ 的平方律吃测点数，网格加密优先补强辐射面正对的区域
- 报告里把这几条判据的通过情况列出来，比单写一个声功率级数字有说服力得多——审稿人第一个问题永远是"这个数怎么保证的"
