# 隔声量测量：传声损失TL的实验室方法

> 发动机舱噪声穿过前壁板进了驾驶室、排气噪声穿过消声器壳体漏了出去——这类"隔声"问题都绕不开传声损失（Sound Transmission Loss，STL）。这篇讲清 STL 的定义与频率特性、覆盖率和开孔如何毁掉隔声量，以及阻抗管法与双室法两条实验室测量路线的适用边界。

## 一、声遇到屏障的三种去向与TL定义

声波到达屏障时只有三种命运：被**吸收**（转化为热）、被**反射**回声源侧、**透射**过去。隔声设计追求的就是把透射份额压到最低。

![声波到达屏障后被吸收、透射或反射](/images/sound-transmission-loss/fig1-barrier-fate.png)

*（图源：Simcenter Testing Knowledge Base）*

传声损失定义为入射声能与透射声能之比，取对数表达：

**TL = 10·lg(Wi / Wt) dB**

其中 Wi 是入射声功率，Wt 是透射声功率。TL 越大，隔声越好。比如 TL = 30 dB，意味着只有千分之一的声能穿过了屏障。

::: info 核心概念
- **传声损失（STL/TL）**：入射与透射声功率之比的分贝值，衡量声学处理阻止声音透过的能力
- **入射声功率 Wi**：打到材料表面的总声能
- **透射声功率 Wt**：穿过材料到达另一侧的声能
- **频率依赖性**：TL 是频率的函数，任何材料在不同频段的隔声表现差异巨大
:::

STL 是频率的函数，这一点怎么强调都不过分。同一只消声器，在 2050 Hz 处能把入射声能衰减 10 dB，到了 3500 Hz 却几乎不衰减——单看一个"总隔声量"数字选材料，很可能在关键频段翻车。

![传声损失随频率变化，同一消声器在2050Hz衰减10dB而3500Hz几乎不衰减](/images/sound-transmission-loss/fig2-tl-vs-freq.png)

*（图源：Simcenter Testing Knowledge Base）*

## 二、覆盖率与开孔：隔声量毁于"第一个洞"

工程上降低透射声的常见做法是给板件贴一层声学材料。但两层物理机制决定了实际效果往往远低于材料样品的标称 TL：

**覆盖率不足。** 声学材料没有完全盖住板件时，裸露区域直接放行声能。实验表明，方板裸露 3% 面积，TL 就会显著下降；裸露扩大到 25%，下降幅度反而不成比例地增加——从全覆盖到出现第一个裸露区的损失，远大于裸露区继续扩大带来的损失。

![材料覆盖率对传声损失的影响，3%裸露即显著降低TL](/images/sound-transmission-loss/fig3-coverage.png)

*（图源：Simcenter Testing Knowledge Base）*

**开孔泄漏。** 在声学处理上开孔同样降低有效 TL，高频段尤其明显。1% 的小孔就能造成可观损失，孔扩大到 5% 时，额外损失不如第一个孔带来的冲击大。

![开孔泄漏对传声损失的影响，高频段损失尤为明显](/images/sound-transmission-loss/fig4-holes.png)

*（图源：Simcenter Testing Knowledge Base）*

::: warning 工程注意
"第一个洞最贵"是隔声工程的铁律：从全覆盖到出现第一个泄漏孔，TL 的跌幅远大于孔继续扩大的增量损失，且高频段受害最深。整车隔声排查时，优先封堵线束过孔、踏板孔、风窗下沿等首发泄漏点，比额外加贴吸音垫的收益高得多。材料样品的 TL 曲线是"理想满覆盖"值，装车状态必打折扣，别拿样品数据直接承诺整车隔声指标。
:::

## 三、两条实验室测量路线

STL 与声源无关，可以用扬声器等实验室声源测量，不必在实车现场测。两大主流方法各有领地：

| 方法 | 声场条件 | 适用对象 | 结果产出 |
| --- | --- | --- | --- |
| **阻抗管法** | 管中平面波，垂直入射 | 消声器、管道系统、小样件 | TL-频率曲线 |
| **双室声强法** | 混响室 + 消声室 | 仪表板、车门、前壁板等大件 | TL 曲线 + 透射强度云图 |
| **双混响室声压法** | 混响室 + 混响室 | 建筑隔墙、门窗、大样件 | TL 曲线（倍频程呈现） |

### 阻抗管法：小件与声学元件

阻抗管是一根厚壁钢管，一端接宽带声源，被测件装夹在管中间，声波以平面波形式垂直入射到样件上。管上布置四个传声器拾取入射与透射声场。

![阻抗管示意，样件安装于管中间](/images/sound-transmission-loss/fig5-impedance-tube.png)

*（图源：Simcenter Testing Knowledge Base）*

Simcenter Testlab 用**四传声器传递矩阵法**求解 STL：测得样件两侧的声压 p1、p2 与质点振速 v1、v2，代入传递矩阵方程组。矩阵四个系数 T11~T22 是未知数，而一组工况只提供两个方程，所以必须做**两种负载工况**——典型组合是刚性末端加无反射（消声）末端，凑齐四个方程解出矩阵，进而算出 TL。

::: tip 两负载法优于两声源法
- 换末端负载（比如换一段管子）简单快捷，声源与传声器电缆全都不用动
- 移动的是便宜的管件，而不是昂贵易损的声源
- 两种末端：一端刚性封死，一端消声末端
:::

::: warning 工程注意
样件与管壁之间必须密封贴合。测消声器时，入口管与阻抗管出口、出口管与第二段管都要对接紧密，任何缝隙都会让 TL 测值失真。当样件进出口直径与管径不一致时，需要锥形转接件，Simcenter Testlab 提供锥度修正功能把转接影响扣除。
:::

### 双室声强法：大件与泄漏定位

混响室里用全向声源营造扩散声场，样件安装在混响室与消声室之间的开口中；消声室侧用声强探头（或 Simcenter Soundbrush）扫描样件表面。此时 STL 按入射声压级与透射声强级计算，平样件入射面积与透射面积相等，公式简化后只含入射声压、透射声强与一个综合常数 6.18（涵盖空气密度、声速等物理量）。

![混响室与消声室布置，样件装于两室之间](/images/sound-transmission-loss/fig9-two-room-intensity.png)

*（图源：Simcenter Testing Knowledge Base）*

这套方法最大的附加价值是**强度云图**：扫描得到样件表面的透射声强分布，哪里漏声一目了然。整车前壁板隔声排查时，云图能直接指出过孔、缝隙等透射通道的位置，配合 TL-频率曲线一起用。

![前壁板透射声强云图，直接定位漏声位置](/images/sound-transmission-loss/fig11-intensity-map.png)

*（图源：Simcenter Testing Knowledge Base）*

### 双混响室声压法：建筑与部件规范测量

发送室与接收室都是混响室，样件装在连通两室的开口里。两侧各用旋转传声器架或多点传声器测平均声压级，TL 等于两室平均声压级之差，再对接收室做修正：TL = L1 - L2 + 10·lg(S/A)，其中 S 是样件面积，A 是接收室等效吸声量（A = 0.16·V/T，V 为接收室容积，T 为混响时间）。

![双混响室法布置，两侧各测平均声压级](/images/sound-transmission-loss/fig13-two-room-pressure.png)

*（图源：Simcenter Testing Knowledge Base）*

::: tip 方法选择原则
- 消声器、进排气管道、小材料样品：**阻抗管法**，样件小、频率分辨率高
- 前壁板、车门、仪表板等整车部件，且想知道"哪里漏"：**双室声强法**
- 建筑隔墙、门窗类规范件：**双混响室声压法**，结果常按倍频程给出
- 三者测的都是材料或部件的固有属性，不依赖实际声源
:::

## 四、Python演示：从能量比到分贝

```python
import numpy as np

# TL 定义演示：能量比 -> 分贝
for wi_wt in [1, 0.5, 0.1, 0.01, 0.001]:
    tl = 10 * np.log10(wi_wt)          # 能量透射比取对数
    print(f"透射声能占比 {wi_wt*100:6.1f}%  ->  TL = {tl:6.1f} dB")

print()
# 覆盖率/开孔效果演示：复合结构等效 TL
tl_panel = 30.0        # 材料满覆盖时 TL(dB)
area = 1.0             # 板件总面积
for leak in [0.0, 0.01, 0.03, 0.05, 0.25]:
    a_ok, a_leak = area * (1 - leak), area * leak
    # 覆盖区透射能量按 10^(TL/10) 衰减，泄漏区直通
    wt = a_ok * 10**(-tl_panel / 10) + a_leak * 1.0
    tl_eff = 10 * np.log10(area / wt)
    print(f"泄漏面积 {leak*100:4.0f}%  ->  等效 TL = {tl_eff:5.1f} dB")
```

运行结果要点：能量占比每降一个数量级，TL 涨 10 dB；第二组数字更扎心——TL 30 dB 的材料只要留 1% 的泄漏孔，等效 TL 直接掉到 19.6 dB，留 5% 就只剩 12.9 dB，"第一个洞最贵"在数字上看得明明白白。

## 五、小结

选隔声材料看 TL-频率曲线，别看单值；排查整车隔声先封首发泄漏孔，高频段最受益；消声器与管道件走阻抗管两负载法，前壁板、车门、仪表板走双室声强法顺带拿泄漏云图，建筑类规范件走双混响室声压法。
