# 声吸收：吸声系数与混响室法

> 声波打到界面上只有三条路：被吸收、被透射、被反射。吸声系数 α 定量描述第一条路，但它随频率、厚度、安装方式剧烈变化——50 mm 的吸声棉在 1000 Hz 是好手，到 125 Hz 几乎失效。本文从摩擦耗能的物理本质讲到四分之一波长法则，再对比阻抗管与混响室两种测量方法及其中的坑。

## 一、声波的三种归宿与吸声系数

声波到达屏障时，能量被分成三份：一部分被材料吸收并耗散为热量（Absorption），一部分穿透屏障继续传播（Transmission），一部分被反射回来（Reflection）。三者的比例逐频率不同——高频波长短，薄薄一层多孔材料就能吃掉；低频波长动辄几米，同样这块材料基本无能为力。

工程上从来不说某个材料"α = 0.8"，而是给一条随频率变化的吸收曲线。材料的吸声数据必须逐频带看，只报一个单值的基本可以退回重写。

::: info 核心概念
- **吸声系数 α**：被吸收声能与入射声能之比，0 到 1，随频率变化
- **吸收（Absorption）**：声能经材料内摩擦转化为热
- **透射（Transmission）**：声能穿过屏障到另一侧，对应隔声量 TL 的研究对象
- **反射（Reflection）**：声能被界面弹回，形成混响场
:::

规律很朴素：越软越多孔，吸收越强；越密越硬，反射越强。织物、泡沫、玻璃棉、吸声天花板属于前一类；混凝土、砌块、玻璃属于后一类。做动力总成声学包裹时选多孔吸声材料，做前壁板隔声时选高面密度阻隔层——吸声和隔声是两回事，一个对付混响场内的反射声，一个对付透射声，混用是常见的设计错误。
## 二、吸声性能由什么决定

四个主要变量：材料成分、湿度、厚度、安装位置。

**成分**决定基础盘。多孔材料（泡沫、玻璃棉、毛毡）内部纤维和颗粒表面积巨大，声波驱动空气分子在孔隙中往复运动，摩擦生热耗散声能。这是"吸声"的物理本质——不是声音"消失"了，是变成了微不可察的热量。

**湿度**容易被人忽略。空气湿度上升，声速上升，材料吸收随之变化。手册明确要求：做吸声测试前，样品应在湿度受控的房间里存放数天，让它达到测试目标湿度状态。刚从仓库拿出来的样品直接上管，数据不可信。

**厚度**控制低频下限。同等条件下加厚材料，吸收曲线向低频延伸。实验规律：当材料厚度约为目标频率波长的四分之一时，该频率的吸收达到峰值。

**入射角与安装方式**也影响结果。声波斜入射与垂直入射的吸收不同，工程设计中常用"角度平均"值。吸声材料贴墙安装与离墙留空腔，系数也不一样——这引出下文的四分之一波长法则。

::: warning 工程注意
样品状态调节不是走过场。湿度没平衡、切样时边缘被压实的样品，测出来的吸收曲线既复现不了也对标不上。供应商报告和自测数据对不上的第一嫌疑，往往就是样品状态和安装条件不同。
:::

## 三、四分之一波长法则：吸声材料放在哪最有效

吸声靠摩擦，摩擦耗能取决于空气质点速度——质点速度越大，与材料纤维的摩擦越烈，吸收越多。那么驻波场里质点速度最大在哪？

声波在刚性壁面反射形成驻波。壁面处空气分子被墙"顶住"，速度为零而声压最大，这是**波节（node）**——高压低速位置；离壁面四分之一波长处，压力最小而分子速度最大，这是**波腹（anti-node）**——低压高速位置。声压与质点速度在空间上呈反相关系。

![声压与质点速度的反相关系](/images/sound-absorption/pressure-velocity.png)
*（图源：Simcenter Testing Knowledge Base）*

所以把吸声材料贴在墙上，它恰好待在质点速度为零的地方，摩擦最少、吸收最差；把材料架空，让它坐在离壁 λ/4 处，那里分子跑得最欢，吸收在该频率达到峰值。这就是**四分之一波长法则（Quarter Wavelength Rule）**。

![吸声材料置于离壁四分之一波长处使吸收最大化](/images/sound-absorption/quarter-wavelength.png)
*（图源：Simcenter Testing Knowledge Base）*

空气间隙的效果等价于增加材料厚度——这就是为什么薄薄的吸声毯离壁留空腔后低频吸收明显改善。但注意：λ/4 定位只对单一频率最优。想宽频吸收，要么用足够厚的材料让"各个频率的 λ/4 位置"都落在材料内部，要么分层设计。材料成本与目标频带之间永远是权衡。

```python
import numpy as np

c = 343.0  # 空气中声速 m/s
freqs = np.array([63, 125, 250, 500, 1000, 2000, 4000])  # 倍频程中心频率 Hz

lam = c / freqs        # 各中心频率对应波长
quarter = lam / 4      # 四分之一波长：最优吸声距离或厚度

print(f"{'频率(Hz)':>8} {'波长(m)':>9} {'q(m)':>7} {'q(mm)':>8}")
for f, l, q in zip(freqs, lam, quarter):
    print(f"{f:>8} {l:>9.2f} {q:>7.3f} {q*1000:>8.0f}")
```

运行结果要点：1000 Hz 只需离壁 86 mm 就到最优位置，而 63 Hz 的 λ/4 长达 1.36 m——想在车内用吸声材料真正压住 63 Hz 的轰鸣声，物理上就不现实，那个频段要靠隔声、阻尼和结构修改。

::: tip 应用建议
- 追求单一频段（如胎腔共鸣、进气谐振）：按 λ/4 定位吸声材料或空腔深度，性价比最高
- 宽频吸声：用厚材料覆盖多个频段的 λ/4 位置，薄贴墙方案只对高频有效
- 低频优先：别指望吸声，转向隔声与结构路径处理
:::

## 四、两种测量方法：阻抗管 vs 混响室

材料吸收怎么测？两种主流方法，入射条件根本不同，测出的系数不能直接互换。

| 对比项 | **阻抗管法（Impedance Tube）** | **混响室法（Reverberation Room）** |
| --- | --- | --- |
| 入射条件 | 垂直入射（direct incidence） | 随机入射（random incidence） |
| 声场 | 管内平面波 | 扩散场，各角度入射 |
| 试样尺寸 | 管径大小（小圆片） | 约 1 m x 1 m 大样品 |
| 结果 | α-频率曲线 | α-频率曲线或等效吸声面积 |
| 代表场景 | 材料研发、快速筛选 | 车内/室内实际声学环境评价 |
| 依据 | 管内双麦克风传递函数 | ISO 354:2003 |

阻抗管是一根厚壁钢管：一端接宽带声源，另一端刚性封闭，样品装在管内末端，两只麦克风布置在样品前方。声波全部以同一角度（法向）打到样品上，多次平均压掉随机噪声后直接得到 α-频率曲线。

真实世界里的声场很少是纯垂直入射——车内声场经过顶棚、地板、座椅的多重反射，接近随机入射。阻抗管的垂直入射结果偏"理想化"，评价真实装车效果要靠混响室法。

::: warning 切样的坑
阻抗管样品必须与管径严丝合缝：切大了塞进去边缘被压缩，孔隙率变了；切小了管壁与样品留缝，声能从缝里泄漏。专用切样刀在切割时会轻微压缩样品边缘、改变吸收特性，水刀切割是更可靠的方案。两毫米的缝隙就能让一组数据作废。
:::

## 五、混响室法的两步测量

混响室刻意做成"最不吸声的房间"：墙面坚硬且互不平行（斜置），大墙面上加半球凸起增强衍射，让声波被反射最多次数、形成尽量均匀的扩散场。

![混响室的斜置墙面设计](/images/sound-absorption/reverberation-room.png)
*（图源：Simcenter Testing Knowledge Base）*

测量的物理桥梁是**混响时间（reverberation time）与吸声量的关系**。声源停止后声压级衰减 60 dB 所需的时间记为 T60，它与房间等效吸声量 A 通过 Sabine 关系联系：A = 0.16V/T，其中 V 是房间容积。房间吸声越多，声音死得越快，T 越短。

实际测量中不一定打得够响、凑足 60 dB 的衰减窗口，所以常用 T20/T30——只测 20 dB 或 30 dB 的衰减段再外推到 60 dB，报告时仍按 T60 口径给出。衰减曲线的起始点也有讲究：声源停止后先等 5 dB 的衰减再开始计时，避开声源关断瞬间的非稳态。

![Simcenter Testlab 中的 T20/T30/T60 混响时间计算](/images/sound-absorption/testlab-t60.png)
*（图源：Simcenter Testing Knowledge Base）*

整个测试就两步：

1. **空室测量**：测空混响室各倍频程的混响时间，算出空室吸声量
2. **放样测量**：放入样品（典型 1 m x 1 m，也可以是声学板甚至整件家具），再测一轮混响时间

样品的吸声量 = 放样后房间吸声量 − 空室吸声量，除以样品面积即得吸声系数。两种条件都应多次测量取平均，滤除不相关噪声的影响。放样后的混响时间理应更短——如果测出来反而变长，先查数据再看样品是不是装了反射面朝外。

```python
import numpy as np

V = 200.0    # 混响室容积 m3
S = 1.0      # 样品面积 m2（约 1m x 1m）
freqs = np.array([250, 500, 1000, 2000])       # 倍频程中心频率 Hz
T_empty  = np.array([7.2, 6.8, 6.1, 5.5])      # 空室混响时间 s
T_sample = np.array([7.0, 6.0, 5.4, 4.8])      # 放样后混响时间 s

A_empty = 0.16 * V / T_empty     # 空室等效吸声量 m2（Sabine: A = 0.16V/T）
A_with  = 0.16 * V / T_sample    # 放样后房间吸声量 m2
alpha = (A_with - A_empty) / S   # 样品吸声系数

print(f"{'f(Hz)':>6} {'T_empty':>8} {'T_samp':>7} {'dA(m2)':>8} {'alpha':>6}")
for f, t0, t1, da, a in zip(freqs, T_empty, T_sample, A_with - A_empty, alpha):
    print(f"{f:>6} {t0:>8.1f} {t1:>7.1f} {da:>8.2f} {a:>6.2f}")
```

运行结果要点：1 m² 的样品只让 200 m³ 混响室的 T60 缩短 0.2 到 0.7 s，混响时间的变化信号本就微弱——这正是标准测试要求足够大试件面积、并做多次平均的原因；同时 α 从 250 Hz 的 0.13 爬到 2000 Hz 的 0.84，多孔材料"高频好用、低频乏力"的形态一眼可见。

## 六、小结

拿到一份吸声材料数据，按四条判断：

- **先看频率轴**：单值 α 无意义，125 到 4000 Hz 倍频程曲线才是完整信息；低频差是材料物理属性，不是供应商偷工
- **再看测试方法**：阻抗管是垂直入射、混响室是随机入射，两套数据不能直接对比，选型以接近实际声场的方法为准
- **核对安装条件**：贴墙还是空腔、空腔多深，直接改写低频段曲线；应用场景的安装方式要和数据的测试条件对齐
- **用 λ/4 估算低频下限**：材料厚度（含等效空腔）达到 λ/4 的频率以下，吸收快速失效；63 Hz 意味着 1.36 m，车内别对吸声抱幻想
