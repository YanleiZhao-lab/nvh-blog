# 声吸收：吸声系数与混响室法

> 声波入射到界面上，能量只有三个去向：吸收、透射、反射。吸声系数（absorption coefficient）α 定量描述其中被吸收的份额，但它随频率、厚度与安装方式显著变化——按四分之一波长法则估算，50 mm 厚吸声层的峰值吸收频率约为 1.7 kHz，而对 125 Hz（λ/4 ≈ 0.69 m）的吸收接近于零。本文从多孔材料摩擦耗能的物理机理出发，推导四分之一波长法则，并对比阻抗管法与混响室法两种测量方法的原理、适用条件与工程注意事项。

## 一、声波在界面处的能量分配与吸声系数

声波到达屏障时，入射声能 $E_{\mathrm{inc}}$ 被分成三部分：一部分被材料吸收并耗散为热量（absorption），一部分穿透屏障继续传播（transmission），一部分被界面反射（reflection）：

$$
E_{\mathrm{inc}} = E_{\mathrm{abs}} + E_{\mathrm{trans}} + E_{\mathrm{refl}}
$$

三项之和等于入射能量，满足能量守恒。将各项除以 $E_{\mathrm{inc}}$，得到三个无量纲系数：

$$
\alpha = \frac{E_{\mathrm{abs}}}{E_{\mathrm{inc}}}, \qquad
\tau = \frac{E_{\mathrm{trans}}}{E_{\mathrm{inc}}}, \qquad
r = \frac{E_{\mathrm{refl}}}{E_{\mathrm{inc}}}, \qquad
\alpha + \tau + r = 1
$$

其中 α 为吸声系数，取值范围 $0 \le \alpha \le 1$：α = 1 表示入射声能全部被吸收，α = 0 表示全部被反射。

三者的比例逐频率不同：高频声波波长短，薄层多孔材料即可有效吸收；低频声波波长长（125 Hz 约 2.7 m，63 Hz 约 5.4 m），同样厚度的材料吸收能力显著下降。因此工程上不以单值表征材料的吸声性能，而是给出吸声系数随频率变化的曲线（通常按倍频程或 1/3 倍频程给出）；仅报告单一 α 值的数据信息不完整，不能用于选型。

::: info 核心概念
- **吸声系数 α（absorption coefficient）**：被吸收声能与入射声能之比，取值 0 到 1，随频率变化
- **吸收（absorption）**：声能经材料内摩擦转化为热
- **透射（transmission）**：声能穿过屏障到另一侧，对应隔声量（Sound Transmission Loss, STL）的研究对象
- **反射（reflection）**：声能被界面反射，构成混响场
:::

材料成分决定吸收能力的基础水平：越软、越多孔的材料吸收越强；越密、越硬的材料反射越强。织物、泡沫、玻璃棉、吸声天花板属于多孔吸声材料，混凝土、砌块、玻璃等致密材料以反射为主。动力总成声学包裹选用多孔吸声材料处理腔内反射声，前壁板隔声选用高面密度阻隔层抑制透射声——吸声处理的对象是反射声，隔声处理的对象是透射声，二者机理不同，混用是常见的设计错误。

## 二、影响吸声性能的四个因素

手册归纳了影响吸声性能的四个主要变量：材料成分、湿度、材料厚度与安装位置。

**材料成分（composition）**决定基础吸收能力。多孔材料（porous materials，如泡沫、玻璃棉、毛毡）内部纤维与颗粒的表面积大，声波驱动孔隙内的空气往复运动，经摩擦将声能耗散为热——声能并未消失，而是转化为热量。致密材料缺乏孔隙通道，入射声以反射为主。

**湿度（humidity）**影响空气中的声速：湿度升高，声速增大，材料吸收随之增大。手册因此要求：吸声测试前，样品应在湿度受控的房间内存放数天，使其达到测试目标湿度状态。未经状态调节的样品，测试数据不可靠。

**厚度（thickness）**控制低频下限。同等条件下增加材料厚度，吸收曲线向低频延伸。实验规律：当材料厚度约为目标频率波长的四分之一时，该频率的吸收达到峰值。

**安装位置（position）**包括入射角与离墙距离两个方面。吸声系数随入射平面波的入射角（angle of incidence）变化，工程设计中常采用角度平均（angle-averaged）值。吸声材料贴墙安装与离墙留空腔，吸声系数也不同——这引出第三章的四分之一波长法则。

::: warning 工程注意
样品状态调节直接影响数据有效性。湿度未平衡、切样边缘被压实的样品，其吸收曲线既不可复现，也无法与参考数据对标。供应商报告与自测数据不一致时，应首先核对两者的样品状态与安装条件是否一致。
:::

## 三、四分之一波长法则：吸声材料的布置位置

吸声的机理是摩擦耗能，耗散的声能取决于空气质点速度：质点速度越大，空气与材料纤维之间的摩擦越强，吸收越多。由此问题转化为：驻波场中质点速度的最大值出现在何处？

声波在刚性壁面（$x = 0$）反射形成驻波。刚性壁面处空气质点的法向速度必须为零，入射波与反射波的声压同相叠加达到最大。叠加后声压与质点速度的幅值沿离壁距离 $x$ 的分布为：

$$
\left|\tilde{p}(x)\right| = 2\tilde{p}_{i}\left|\cos(kx)\right|, \qquad
\rho_0 c\,\left|\tilde{v}(x)\right| = 2\tilde{p}_{i}\left|\sin(kx)\right|, \qquad
k = \frac{2\pi}{\lambda}
$$

其中 $\tilde{p}_i$ 为入射波声压幅值（Pa），$\rho_0 c$ 为空气特性阻抗（20 °C 时约 413 Pa·/m），$k$ 为波数（rad/m）。声压按余弦分布、质点速度按正弦分布，两者在空间上反相：

- 壁面处（$x = 0$）：声压最大而质点速度为零，称为**波节（node）**，即高压低速位置；
- 离壁 $\lambda/4$ 处（$kx = \pi/2$）：声压最小而质点速度最大，称为**波腹（anti-node）**，即低压高速位置。

![声压与质点速度的反相关系](/images/sound-absorption/pressure-velocity.png)
*（图源：Simcenter Testing Knowledge Base）*

将吸声材料贴墙安装，材料恰处于质点速度为零的位置，摩擦耗能最小、吸收最差；将材料架空，使其位于离壁 $\lambda/4$ 处，则材料处于质点速度最大的位置，该频率的吸收达到峰值。这就是**四分之一波长法则（Quarter Wavelength Rule）**，最优距离由波长 $\lambda = c/f$ 直接给出：

$$
d_{\mathrm{opt}} = \frac{\lambda}{4} = \frac{c}{4f}
$$

其中 $c$ 为空气中声速（20 °C 时约 343 m/s），$f$ 为目标频率（Hz）。

![吸声材料置于离壁四分之一波长处使吸收最大化](/images/sound-absorption/quarter-wavelength.png)
*（图源：Simcenter Testing Knowledge Base）*

离墙留空气间隙的效果与增加材料厚度相当——这就是薄层吸声材料离墙留空腔后低频吸收明显改善的原因。但 λ/4 定位仅对单一频率最优：要实现宽频吸收，需使用足够厚的材料，使多个目标频率的 λ/4 位置都落在材料内部，或做分层设计；材料成本与目标频带宽度之间存在权衡。

```python
import numpy as np

c = 343.0  # 空气中声速 m/s
freqs = np.array([63, 125, 250, 500, 1000, 2000, 4000])  # 倍频程中心频率 Hz

lam = c / freqs        # 各中心频率对应波长
quarter = lam / 4      # 四分之一波长：最优吸声距离或厚度

print(f"{'频率(Hz)':>8} {'波长(m)':>9} {'q(m)':>7} {'q(mm)':>8}")
for f, l, q in zip(freqs, lam, quarter):
    print(f"{f:>8} {l:>9.2f} {q:>7.3f} {q*1000:>8.0f}")
```

计算结果显示：1000 Hz 的最优位置在离壁 86 mm 处，而 63 Hz 的 λ/4 长达 1.36 m。在车内用吸声材料处理 63 Hz 的低频轰鸣在物理上不可行，该频段应转向隔声、阻尼与结构路径修改。

::: tip 应用建议
- 单一频段问题（如胎腔共鸣、进气谐振）：按 λ/4 定位吸声材料或设定空腔深度，效率最高
- 宽频吸声：用厚材料覆盖多个频段的 λ/4 位置，薄层贴墙方案仅对高频有效
- 低频问题：优先考虑隔声与结构路径处理，而非单纯加厚吸声材料
:::

## 四、两种测量方法：阻抗管与混响室

材料吸声系数的两种主流测量方法，入射条件不同，测得的系数不能直接互换。

| 对比项 | **阻抗管法（impedance tube）** | **混响室法（reverberation room）** |
| --- | --- | --- |
| 入射条件 | 垂直入射（direct incidence） | 随机入射（random incidence） |
| 声场 | 管内平面波 | 扩散场（diffuse field），各角度入射 |
| 试样尺寸 | 管径大小的圆片 | 约 1 m × 1 m，也可以是声学板或家具 |
| 结果 | α-频率曲线 | α-频率曲线或等效吸声面积 |
| 适用场景 | 材料研发、快速筛选 | 车内/室内实际声学环境评价 |
| 依据 | 管内双麦克风法 | ISO 354:2003 |

阻抗管通常由厚壁钢管制成：一端接输出宽带信号的声源，另一端为刚性封闭端，样品安装在管内末端，两只麦克风布置在样品前方。声波全部以同一角度（法向）入射到样品表面，经多次平均抑制随机噪声后，直接得到 α-频率曲线。

实际声场很少是纯垂直入射：车内声场经顶棚、地板、座椅的多重反射，接近随机入射。阻抗管的垂直入射结果偏于理想化，评价真实装车效果应以混响室法的随机入射数据为准。

::: warning 样品制备
阻抗管样品的边界条件直接决定测量有效性。样品切大了装入后被边缘压缩，孔隙率改变；切小了则样品与管壁之间留缝，声能从缝隙泄漏。专用切样刀在切割时会轻微压缩样品边缘、改变吸收特性，水刀切割是更可靠的方案。
:::

## 五、混响室法：两步测量与 Sabine 公式

混响室的设计目标是形成尽量均匀的扩散场：墙面坚硬且互不平行（斜置），大墙面上附加半球凸起以增强衍射（diffraction），使声波在房间内被反射的次数最大化。

![混响室的斜置墙面设计](/images/sound-absorption/reverberation-room.png)
*（图源：Simcenter Testing Knowledge Base）*

测量的物理桥梁是混响时间（reverberation time）与房间吸声量之间的 Sabine 关系。声源停止后声压级衰减 60 dB 所需的时间记为 $T_{60}$（s），房间等效吸声量（equivalent absorption area）$A$（m²）与房间容积 $V$（m³）满足：

$$
T_{60} = \frac{0.16\,V}{A} \qquad \Longleftrightarrow \qquad A = \frac{0.16\,V}{T_{60}}
$$

物理意义：房间吸声量越大，声能衰减越快，混响时间越短。混响时间随频率变化，因此需逐倍频程测量与计算（具体公式与规范见 ISO 354:2003）。

实际测量中，声源不一定能提供足够高的声压级以覆盖完整的 60 dB 衰减范围，因此常用 T20/T30：只测量 20 dB 或 30 dB 的衰减段，再外推到 60 dB，报告时仍按 T60 口径给出。衰减计时的起点也有规定：声源停止后先等待 5 dB 的衰减再开始计时，以避开声源关断瞬间的非稳态过程。

![Simcenter Testlab 中的 T20/T30/T60 混响时间计算](/images/sound-absorption/testlab-t60.png)
*（图源：Simcenter Testing Knowledge Base）*

测试分两个测量条件：

1. **空室测量**：测量空混响室各倍频程的混响时间 $T_1$，由 Sabine 公式计算空室吸声量 $A_1$
2. **放样测量**：放入样品（典型 1 m × 1 m），再测一轮混响时间 $T_2$，计算放样后的房间吸声量 $A_2$

样品的吸声系数由两个条件的吸声量之差除以样品面积 $S$（m²）得到。推导分两步：先由 Sabine 公式分别写出两个条件的吸声量 $A_1 = 0.16V/T_1$ 与 $A_2 = 0.16V/T_2$；放样前后吸声量之差即样品贡献的吸声量 $\Delta A = A_2 - A_1$，再除以样品面积得无量纲系数：

$$
\alpha(f) = \frac{A_2 - A_1}{S} = \frac{0.16\,V}{S}\left(\frac{1}{T_2} - \frac{1}{T_1}\right)
$$

两个条件均应多次测量取平均，以抑制不相关噪声的影响。放样后的混响时间应短于空室——样品增加了房间吸声量；若测得相反的结果，应检查测量数据与样品安装状态。

```python
import numpy as np

V = 200.0    # 混响室容积 m3
S = 1.0      # 样品面积 m2（约 1m x 1m）
freqs = np.array([250, 500, 1000, 2000])       # 倍频程中心频率 Hz
T_empty  = np.array([7.2, 6.8, 6.1, 5.5])      # 空室混响时间 s
T_sample = np.array([7.0, 6.0, 5.4, 4.8])      # 放样后混响时间 s

A_empty = 0.16 * V / T_empty     # 空室等效吸声量 m2（Sabine: A = 0.16V/T）
A_with  = 0.16 * V / T_sample    # 放样后房间吸声量 m2
alpha = (A_with - A_empty) / S   # 样品吸声系数

print(f"{'f(Hz)':>6} {'T_empty':>8} {'T_samp':>7} {'dA(m2)':>8} {'alpha':>6}")
for f, t0, t1, da, a in zip(freqs, T_empty, T_sample, A_with - A_empty, alpha):
    print(f"{f:>6} {t0:>8.1f} {t1:>7.1f} {da:>8.2f} {a:>6.2f}")
```

计算结果显示两点：其一，1 m² 样品仅使 200 m³ 混响室的 T60 缩短 0.2～0.8 s，混响时间的变化量本身较小——这正是标准测试要求足够大的试件面积并做多次平均的原因；其二，α 从 250 Hz 的 0.13 增至 2000 Hz 的 0.85，符合多孔材料高频吸收强、低频受 λ/4 限制的典型特征。

## 六、小结

拿到一份吸声材料数据，按四条判据核查：

- **先看频率轴**：单值 α 无意义，125～4000 Hz 倍频程曲线才是完整信息；低频吸收不足是 λ/4 法则决定的物理属性，不是数据异常
- **再看测试方法**：阻抗管为垂直入射、混响室为随机入射，两套数据不能直接对比，选型以接近实际声场的方法为准
- **核对安装条件**：贴墙还是空腔、空腔多深，直接改写低频段曲线；应用场景的安装方式应与数据的测试条件对齐
- **用 λ/4 估算低频下限**：材料厚度（含等效空腔）达到 λ/4 的频率以下，吸收快速下降；63 Hz 对应 1.36 m，车内低频问题应转向隔声与结构路径处理
