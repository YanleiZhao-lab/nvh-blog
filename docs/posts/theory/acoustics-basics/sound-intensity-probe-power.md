# 声强法测声功率：双传声器探头与 ISO 9614 扫描

> 声压法测声功率的前提是已知声场条件——消声室、混响室或经过修正的自由场。但动力总成台架上的发动机、车间里整线运行的设备根本搬不进这些房间。声强法用一对间距几十毫米的传声器在现场直接测出声功率，稳态背景噪声甚至比被测对象高 10 dB 都不影响结果。这篇讲清双传声器探头的测量原理、隔离垫选型逻辑，以及 ISO 9614 离散点法与扫描法的取舍。

## 一、声压法的死穴：它测的是"果"，不是"因"

声压是声源辐射功率在某个位置产生的**效果**，它随距离衰减、受环境反射调制。同一台电机，装在消声室里测和装在水泥车间里测，同一测点的声压级能差出好几个 dB。想用声压反推声功率，就必须对声场做假设——ISO 3744/3745 那套方法因此离不开消声室、半消声室或混响室。

声强（Sound Intensity）绕开了这个死结。它是单位面积上流过的声功率，单位 W/m2，本质是**能量流密度**，天生是个矢量：有大小，有方向。把声强对包围声源的封闭面积分，就直接得到辐射声功率，不需要任何声场假设：

$$W = \sum_i I_{n,i} \cdot S_i$$

其中 $I_{n,i}$ 是第 $i$ 个面元的法向声强，$S_i$ 是其面积。这个关系对任何声场都成立——这是声强法全部优势的根源。

**稳态背景噪声为什么测不出来？** 想象封闭面外还有一台机器在响。它的声能从箱体的一面流进来，必然从别的面流出去。法向声强有正有负，流入为负、流出为正，时间平均后整个封闭面的净流量为零——外面的稳态源对积分结果没有贡献。工程上的经验值：背景噪声比被测源高 10 dB 时，声强法仍能把声功率测到 1 dB 精度以内。碰到这种情况，把测量面适当缩小、贴近被测源，信噪比还会更好。

::: info 核心概念
- **声强**：单位面积流过的声功率（W/m2），矢量；稳态场下对封闭面的净积分只剩面内声源的贡献
- **法向分量**：双传声器探头只测沿探头轴的分量，测量时探头轴要垂直于测量面
- **有功/无功声场**：有功场中声压与质点速度同相位，能量单向流动；无功场（驻波、近场）两者相差 90 度，能量来回摆动，净声强为零
:::

::: warning 工程注意
背景噪声"抵消"的前提是**稳态**。车间天窗有节奏地开关、风扇负载周期变化，都会让流入流出的能量不再对称。另外封闭面内不能有吸声体——操作员站在测量面里举着探头，自己就是一块移动吸声板，会破坏流入流出的能量平衡。
:::

## 二、双传声器探头：从欧拉方程到声强

单支传声器测声压不难，难的是质点速度（Particle Velocity）——空气分子来回振动的速度，没人能直接测。声强的定义是：

$$I = \overline{p(t) \cdot v(t)}$$

横杠表示时间平均。压力是标量，速度是矢量，乘出来自然是矢量。

**欧拉方程（Euler Equation）**给出了突破口。它就是牛顿第二定律作用于流体：压力梯度把力施加给密度为 $\rho$ 的空气微元，产生加速度：

$$-\frac{\partial p}{\partial r} = \rho \frac{\partial v}{\partial t}$$

物理图像很直白：哪里的压力随位置变化得越陡，那里的空气就被加速得越狠。对时间积分就得到质点速度：

$$v = -\frac{1}{\rho} \int \frac{\partial p}{\partial r} \, dt$$

**有限差分近似（Finite Difference Approximation）**：压力梯度是连续函数，但用两支间距 $\Delta r$ 的传声器，可以用差商近似微商：

$$\frac{\partial p}{\partial r} \approx \frac{p_B - p_A}{\Delta r}$$

相当于用割线斜率代替切线斜率。声压取两支传声器的平均 $\bar{p} = (p_A + p_B)/2$，位置都归到两传声器中间的声学中心。于是时域声强估计为：

$$I \approx \overline{\bar{p} \cdot v} = -\frac{1}{2\rho \Delta r} \, \overline{(p_A + p_B) \int (p_B - p_A) \, dt}$$

频域里这个乘积的时间平均对应互谱的虚部（同相分量积分为零，只有 90 度相移的分量留下净流量），即经典的互谱法（Fahy 1977 / Chung 1978）：

$$I(\omega) = -\frac{1}{\omega \rho \Delta r} \, \mathrm{Im}\{G_{AB}(\omega)\}$$

这就是分析仪内部做的事：探头只负责采两路压力，积分、互谱、取虚部都在分析端完成。

![双传声器面对面布置，中间用实体隔离垫分隔，三种垫长覆盖不同频段](/images/sound-intensity-probe-power/probe-spacers.png)

*（图源：Bruel and Kjaer, The Fundamentals of Sound Intensity Measurement）*

**指向性是"8 字"。** 声波沿探头轴入射时两传声器压差最大；垂直入射（90 度）时两路信号完全一样，压差为零，声强读数为零。任意入射角 $\theta$ 下测到的是轴向分量，自动乘上 $\cos\theta$——探头和计算合起来构成余弦指向性，极坐标图是个 8 字。反过来的用途是**零点搜索法（Null Search）**：让探头轴平行扫过疑似声源所在平面，显示值在正负之间快速跳变的位置，声波必然沿 90 度入射——那就是声源方位。85 度入射读数为正、95 度为负，指向突变极其灵敏，现场定位一台机器的主辐射面很快。

## 三、隔离垫选型：高频误差与低频失配的拉锯

有限差分用割线代替切线，误差随频率升高急剧恶化——波长越短，同样 $\Delta r$ 跨过的相位角越大。对平面波做误差分析，估计声强与真实声强之比为：

$$\frac{I_{est}}{I_{true}} = \left[ \frac{\sin(k\Delta r/2)}{k\Delta r/2} \right]^2, \quad k = \frac{2\pi f}{c}$$

分子里的正弦来自"取两点平均"引入的相位滞后，分母是理想微分应有的线性项。$k\Delta r/2 \to 0$ 时比值趋于 1；工程准则：**波长大于 6 倍隔离垫长度**时误差可压在 1 dB 以内。

低频端是另一头的问题。跨隔离垫的相位变化 $\phi = k\Delta r$ 随频率降低而缩小：12 mm 垫在 5 kHz 时相位变化 65 度，到 50 Hz 只剩 0.65 度。而两路测量通道自身存在相位失配（传声器、电路不可能完全一致）。判据是：**跨垫相位变化应大于通道相位失配的 5 倍**，误差才能控制在 1 dB 内。频率低到跨垫相位只剩零点几度时，失配把信号完全淹没——这就是低频下限。

| **隔离垫长度** | 高频上限（1 dB 准则） | 典型用途 |
| --- | --- | --- |
| **50 mm** | 1.25 kHz | 低频为主的动力总成、大型结构 |
| **12 mm** | 5 kHz | 通用测量，NVH 常备 |
| **6 mm** | 10 kHz | 高频异响、啸叫 |

::: tip 选择原则
- 覆盖常规 NVH 频段的通用测试：**12 mm 垫**是默认选择，配合垫长等于传声器直径的共振补偿，实际上限还能再高一个倍频程
- 关心低频端的结构辐射或进排气轰鸣：换 50 mm 垫，跨垫相位更大，低频端更稳
- 宽频测量一次搞不定：长短两个垫各测一遍，在中间频段拼接
:::

## 四、ISO 9614：定好面，再谈点怎么布

测声功率的第一步是定义包围被测对象的封闭面。面内只能有被测源，不能有其他声源或吸声体；地面默认全反射，不必计入测量面。常用的两种形状：

![箱体面与半球面两种典型测量面](/images/sound-intensity-probe-power/box-hemisphere-surfaces.png)

*（图源：Bruel and Kjaer, The Fundamentals of Sound Intensity Measurement）*

- **箱体面**：平面好划分、好平均，各面部分声功率直接相加
- **半球面**：对全向声源在自由场中面上声强近似均匀，需要的测点最少

空间平均怎么做，ISO 9614 分了三个部分：Part 1 离散点法，Part 2 扫描法，Part 3 是实验室环境的加强版要求。

![离散点法：测量面划分网格，每个面元中心测一点](/images/sound-intensity-probe-power/discrete-points.png)

*（图源：Bruel and Kjaer, The Fundamentals of Sound Intensity Measurement）*

![扫描法：探头以恒定速度均匀刷过整个测量面](/images/sound-intensity-probe-power/swept-scan.png)

*（图源：Bruel and Kjaer, The Fundamentals of Sound Intensity Measurement）*

| **维度** | 离散点法（ISO 9614-1） | 扫描法（ISO 9614-2） |
| --- | --- | --- |
| **原理** | 面元离散求和 $\sum I_{n,i} S_i$ | 连续路径的空间积分近似 |
| **准确度** | 受网格密度限制 | 数学上更优，通常更准 |
| **重复性** | 高，测点可复现 | 依赖操作者手法 |
| **操作要点** | 网格布点（线框、卷尺定位） | 匀速、等覆盖，像"刷漆" |
| **自动化** | 易于机器人复现 | 可自动化后准确度进一步提升 |

扫描法效率高，动力总成的整机声功率排查基本都用它；离散点法胜在可重复，适合认证测试和仲裁复测。

**声强图谱是副产品，往往比声功率本身更值钱。** 网格化测完后插值画等声强线（Contour Plot），或者像 Simcenter Soundbrush 那样四传声器四面体布置直接刷出彩色图，泄漏点、辐射热点一目了然——仪表板隔声、油底壳辐射这类问题，一张图顶半天排查。

## 五、Python 演示

**演示一：隔离垫的有限差分误差曲线。** 用上面的误差公式复算手册频限——50 mm 垫在 1.25 kHz、12 mm 垫在 5 kHz 应恰好落在 1 dB 准则内：

```python
import numpy as np

c = 343.0  # 空气中声速 m/s

def fd_error_db(f, d):
    # 有限差分误差：估计声强 / 真实声强（平面波假设）
    k = 2 * np.pi * f / c        # 波数 rad/m
    x = k * d / 2
    return 10 * np.log10((np.sin(x) / x) ** 2)

freqs = np.array([125, 500, 1250, 2500, 5000])
for d, name in [(0.050, "50 mm"), (0.012, "12 mm")]:
    errs = fd_error_db(freqs, d)
    line = "  ".join(f"{f/1000:g}kHz:{e:+.1f}dB" for f, e in zip(freqs, errs))
    print(f"隔离垫 {name}: {line}")
```

跑一遍就能看到：50 mm 垫在 1.25 kHz 处误差 -0.5 dB，还在 1 dB 准则内；到 5 kHz 跌到 -9.7 dB，读数完全不可信。12 mm 垫在 5 kHz 只有 -0.4 dB——这就是"高频换短垫"的定量依据。

**演示二：封闭面声功率计算。** 各面法向声强有正有负，正负抵消正是背景噪声免疫的来源：

```python
import numpy as np

# 某箱体测量面 5 个面的平均法向声强 (W/m2) 与面积 (m2)
# 背面出现负值：环境噪声从该面流入（能量流进封闭面）
I = np.array([0.020, -0.005, 0.008, 0.001, 0.004])
S = np.array([1.2, 1.5, 1.5, 1.0, 1.0])

W = np.sum(I * S)                # 净流出功率 = 辐射声功率
Lw = 10 * np.log10(W / 1e-12)    # 声功率级，参考 1 pW
print(f"净辐射声功率  W  = {W*1e3:.1f} mW")
print(f"声功率级      Lw = {Lw:.1f} dB re 1 pW")
```

负面元贡献 -7.5 mW 被其他面的正面声强抵掉，净辐射功率 33.5 mW，对应声功率级 105.3 dB。做验收汇报时记得：各面分项一起给，负面值不是错误，是背景噪声能量在"还账"。

## 六、小结

- 声强法的不可替代之处：**现场、稳态干扰环境、近场**三个条件下依然能给出可信的声功率，这是声压法做不到的
- 双传声器探头的本质是用有限差分从两路声压恢复质点速度（欧拉方程），分析仪里跑的是互谱虚部
- 隔离垫选型一句话：高频上限由有限差分误差决定（50 mm 对应 1.25 kHz、12 mm 对应 5 kHz、6 mm 对应 10 kHz），低频下限由通道相位失配决定，两头顶不住就长短垫各测一遍拼接
- ISO 9614-2 扫描法快且准，是动力总成整机排查的默认选项；要可重复、要仲裁，回 9614-1 离散点
- 声功率之外，顺手得到的声强图谱往往才是解决问题的那张图
