# 倍频程滤波与实时频谱：声级计 1/1、1/3 倍频程带是怎么算出来的

> 倍频程谱上那排柱子不是 FFT 分组算出来的，而是一组时域带通滤波器各覆盖一段频带、对各自输出做能量（均方）平均的结果。本文从中心频率的 2 的分数次幂定义出发，推导自然频率与标称频率为什么对不上、带内能量积分怎么落到离散谱线求和，最后说明 Testlab 里 ANSI-IEC Octave Filtering 插件、RTO 处理和 Fast/Slow 时间计权这些实测设置。

## 一、一个倍频程带到底是哪一段频率

音乐里 1 个八度（octave）是频率翻倍：A4 是 440 Hz，A5 就是 880 Hz。倍频程分析沿用了同一个规则——**后一个带的中心频率是前一个带的 2 倍**。人耳听觉范围 20 Hz 到 20 kHz 按 1/1 倍频程划分，正好得到 11 个带；把每个 1/1 带再三分，就是 1/3 倍频程，与人耳的频率分辨能力更接近。

![1/1倍频程带的下限、中心与上限频率](/images/octave-filters/fig3-1-1-octave-bands.png)

*（图源：Simcenter Testing Knowledge Base）*

1/3 带切得更细，随之带来一个需要留意的后果：**带宽不再等宽，而是逐带变宽**。100 Hz 带宽约 23 Hz，1000 Hz 带宽约 232 Hz——同样是"一个带"，高频带覆盖的频率范围是低频带的十倍。

![1/3倍频程带的上下限与中心频率](/images/octave-filters/fig4-1-3-octave-bands.png)

*（图源：Simcenter Testing Knowledge Base）*

::: info 核心概念
- **倍频程（Octave）**：中心频率按 2 的整数或分数次幂递进的频带划分
- **1/3 倍频程**：把一个 1/1 带按 2 的 1/3 次幂比例再切成三段
- **恒定百分比带宽（constant percentage bandwidth）**：带宽与中心频率之比对所有带恒定（1/1 带约 70.7%，1/3 带约 23.1%）
:::

## 二、中心频率推导：为什么 1000 Hz 带的上限是 1122 Hz 而不是 1150 Hz

先从定义出发。相邻带中心频率之比固定为 2 的 x 次幂；LMS 倍频程分析支持 x = 1、1/2、1/3、1/12、1/24（LMS 理论手册 4.3 节）：

$$f_{c,\,i+1} = f_{c,\,i} \cdot 2^{x}$$

以 1000 Hz 为锚点往两边生成整条频率轴，第 i 个带的中心频率（单位 Hz）就是：

$$f_{c,\,i} = 1000 \cdot 2^{i \cdot x}$$

物理意义：带中心在**对数频率轴上等间距**，间距为 x 个倍频程。人耳近似按对数规律感知音高，所以这套划分与听觉一致。

带宽按中心频率两侧各取 x/2 个倍频程定义上下限：

$$f_{lower} = f_c \cdot 2^{-x/2}, \qquad f_{upper} = f_c \cdot 2^{+x/2}$$

推导带宽与中心频率之比：上下限相除得 $f_{upper}/f_{lower} = 2^{x}$；相乘得 $f_{lower} \cdot f_{upper} = f_c^2$，即中心频率恒等于上下限的**几何平均**，这正是"对数轴中点"的含义。带宽：

$$BW = f_c\,(2^{x/2} - 2^{-x/2})$$

代入 x=1：$2^{0.5}-2^{-0.5} \approx 0.707$，即 1/1 带宽恒为中心频率的 70.7%；x=1/3 时算出 23.1%。带宽与频率同单位（Hz），该比值为无量纲常数。

按这套公式算出的频率叫**自然频率（natural frequency）**。1/3 带相邻中心频率比是 $2^{1/3} = 1.2599$，1000 Hz 的下一个带是 1259.9 Hz，再下一个是 1587.4 Hz。工程报告通常不直接使用 1259.9 Hz 这类数值，标准将中心频率取整为 100、125、160、200、250、315、400、500、630、800、1000 等（LMS 理论手册 表 4.1，标准化中心频率引自 ISO 150266），这套**标称频率（nominal frequency）**用于标注，自然频率用于计算。

对 1000 Hz 的 1/3 带实际算一下：$f_{upper} = 1000 \times 2^{1/6} = 1122.5$ Hz，$f_{lower} = 1000 / 2^{1/6} = 890.9$ Hz。上限不是 1000+232/2=1116 的算术切法，也不是"125 减 100 等于 25 Hz 宽"——25 Hz 是**标称频率之差**，1122 减 891 等于 232 Hz 才是该带实际的滤波器带宽。

::: warning 工程注意
自然频率用于计算，标称频率用于标注，两者数值有出入：1000 Hz 的 1/3 带，自然边界为 890.9 / 1122.5 Hz，相邻自然中心频率为 1000、1259.9、1587.4 Hz，而标称中心频率序列为 800、1000、1250、1600 Hz。做带级对比、滤波器设计或跨软件交换数据时，务必确认双方使用的是自然频率还是标称频率，否则带边界错位、能量归属出错。
:::

## 三、倍频程谱不是 FFT 分组：滤波器组加均方根检波

Simcenter Testlab 的倍频程由**一组并行时域带通滤波器**实现，滤波器形状符合 ANSI S1.11-2011 与 IEC 61260:2014 标准。时域数据流进滤波器组，每个滤波器放行一个带的频率范围，输出各自滤波后的时间信号，再对每路输出做均方根（RMS）检波与能量平均，得到该带的声压级。

![时域数据流过带通滤波器组，每路输出按带计算总级](/images/octave-filters/fig7-filter-bank.png)

*（图源：Simcenter Testing Knowledge Base）*

这条路叫滤波法（filter-based），与 FFT 法有本质差别：

| 对比项 | **滤波法（ANSI/IEC）** | **FFT 法（谱线分组求和）** |
| --- | --- | --- |
| **实现** | 时域带通滤波器组 + RMS 检波 | FFT 谱线按频率区间累加 |
| **频率边界** | 滤波器标准形状，边界固定 | 谱线格点决定，随分辨率变 |
| **时间跟踪** | 逐帧输出，可跟踪瞬态 | 帧长内平均，瞬态被摊薄 |
| **边界能量归属** | 滤波器过渡带连续滚降，无半值争议 | 落在边界上的谱线需半值规则 |
| **瞬态事件峰值** | Fast 计权 125 ms 窗，峰值保留度高 | FFT 帧长把冲击摊到全帧，峰值低估 |
| **频率分辨率低频端** | 滤波器按对数轴恒百分比带宽，低频带窄而准确 | 1 Hz 线在整个频段等宽，20 Hz 带内只有几根线 |
| **标准符合性** | 声级计、认证测试指定 | 非标准算法，仅供工程参考 |
| **代价** | 每带一个滤波器，计算量大 | 一次 FFT 全带宽到手 |

滤波器组视图也解释了倍频程显示的两种画法：把 x 轴标成"倍频程格式"（对数频率、各带等宽显示），高频带和低频带看起来一样宽；换回线性频率轴，差异立即显现——白噪声的窄带谱全线持平，而倍频程柱随频率升高越来越高。定量解释：白噪声的单位带宽能量密度恒定，带能量正比于带宽，而相邻 1/1 带的带宽之比恒为 2，于是带级逐带抬升：

$$\Delta L = 10\,\lg\frac{BW_{i+1}}{BW_i} = 10\,\lg 2 \approx 3.0\ \mathrm{dB}$$

物理意义：每上一个带，带宽翻倍、收录的能量翻倍，级值提高约 3 dB——这就是"高频端倍频程柱更高"的来源。

## 四、时域滤波器组怎么实现

滤波法的核心是一组符合 ANSI S1.11-2011 / IEC 61260:2014 的带通滤波器。标准不规定具体电路或算法，只规定**滤波器在频域里允许的形状包络**——通带内纹波上限、阻带最小衰减、过渡带位置，全部画成一张容差图，任何实现（模拟电路、数字 IIR）只要形状落进容差区就算合规。

**基础滤波器原型是 Butterworth（最平坦）**。以 1/1 倍频程为例，工程实现常用每倍频程衰减特性逼近标准包络：通带取 $[f_c/\sqrt{2}, f_c\sqrt{2}]$ 附近，过渡带按对数频率轴对称展开，阻带端衰减量随阶数增加而加深。Testlab 的实现细节不公开，但 ANSI S1.11 的容差图决定了它必须是高阶窄过渡带设计。

**精度分等级：Class 0 / Class 1 / Class 2**。等级越高，容差区越窄：

| 等级 | 容差 | 定位 |
| --- | --- | --- |
| **Class 0** | 最严 | 计量级实验室、标准器校准 |
| **Class 1** | 严 | 工程与认证测试（Testlab 默认对标） |
| **Class 2** | 宽 | 现场普查、普查性监测 |

**数字实现的关键参数**：采样率远高于带宽上限（抗混叠前置）、滤波器阶数决定过渡带陡度与纹波的折中、级联形式（若干二阶节串联）保证数值稳定。时域实现还有个天然优势：输出是**连续的滤波后时间信号**，可以直接接指数平均或 Fast/Slow 计权，声级计读数就是这样来的；FFT 法只能对整帧频谱做后处理，没有"滤波后波形"这个中间产物。

## 五、带级怎么算：从能量积分到谱线求和

声学量在任何频带内的值，本质是该带内频率分量的能量积分（LMS 理论手册 式 5-14）：

$$a = \int_{f_1}^{f_2} a(f)\, df$$

物理意义：频域函数 $a(f)$ 在带内围出的面积。这个"面积"对应的不是幅值相加，而是**能量（均方）相加**——两个不同频率的声压叠加，总均方声压等于各自均方声压之和，因为交叉项在整周期上积分为零。所以由带内谱线级值 $L_i$ 合成带级时，必须先回到线性能量域求和再取对数：

$$L_{\mathrm{band}} = 10\,\lg\left(\sum_{i\,\in\,\mathrm{band}} 10^{L_i/10}\right)\ \mathrm{dB}$$

物理意义：dB 值不可直接相加，$10^{L_i/10}$ 把每根谱线的级值还原成能量占比，求和后统一回到分贝。

实测数据是离散谱线，连续积分退化为求和（式 5-15）：带内谱线取全值，恰落在上、下限频率上的谱线取半值：

$$a = \frac{a_{f_1}}{2} + \sum_{i} a_i + \frac{a_{f_2}}{2}$$

半值规则不是数学修饰：边界谱线的能量分属相邻两个带，各记一半，带边界两侧的总能量才守恒。对滤波法倍频程不存在这个问题——滤波器形状本身决定了边界过渡带的能量归属，这也是认证测试只认滤波法的原因之一。

## 六、Testlab 实测设置：插件、RTO 与时间计权

倍频程在 Testlab 里不是默认功能。路径：**Tools → Add-ins 里勾选 ANSI-IEC Octave Filtering**（该插件需 23 个 token），然后在 Time Data Processing 里做滤波法倍频程。

两个必设参数：

**平均方式（averaging method）**。指数平均（exponential）对时间上靠后的帧加权更重，读数跟随变化快、回稳慢；线性平均（linear）对所有帧算术平均，读数更稳。稳态工况选线性，工况有漂移或要做声级计式监视选指数。

**时间计权（Sound Level Type）**。这是滤波法倍频程中容易设置不当的一项：

| 时间计权 | 平均帧长 | 读数行为 | 适用场景 |
| --- | --- | --- | --- |
| **Fast** | 0.125 s | 跟随快、抖动大 | 快速扫工况、瞬态监视 |
| **Slow** | 1.000 s | 平滑、滞后 | 稳态读数、报告值 |
| **Impulse** | 0.035 s | 峰值抓取 | 脉冲声、咔哒声 |
| **User** | 自定 | — | 特殊帧长需求 |

帧长（averaging frame）即每个增量步计算一次平均所用的时间窗：Fast 用 125 ms 内的能量平均，电动窗上升这类 200 ms 级事件能看到明显的级差起伏；Slow 把 1 s 的能量摊开，同一事件读数平滑但峰值被低估。

带 RTO（Real Time Octaves）后缀的功能（如 Psychoacoustic Metrics RTO）同样走滤波法路线，用时间域滤波直接算声品质指标，适合非平稳信号。

倍频程结果有两种输出形式：**倍频程图（octave map）**把各带总能量级画成柱状谱；**倍频程切片（octave section）**固定一个中心频率（如 315 Hz、500 Hz），跟踪该带随时间或转速等跟踪参数的变化，直接定位"哪个频段在什么工况下超标"。在 Time Data Processing 的 Section 设置中，分别在 Octave Maps 页签勾选带类型、在 Octave Sections 页签输入中心频率。

## 七、Python 演示：时域滤波法 vs FFT 法同台对比

同一帧信号，两条路线各算一遍 1/1 倍频程谱，差值一目了然。时域侧用 Butterworth 带通滤波器组（scipy.signal.butter + sosfilt，级联二阶节保证稳定），FFT 侧用矩形窗谱线按带边界能量求和（含半值规则）：

```python
import numpy as np
from scipy import signal

fs = 48000
t = np.arange(0, 3.0, 1/fs)
# 信号：白噪声 + 3 个纯音（31.5/250/2000 Hz），模拟"宽带底噪+窄带尖峰"
rng = np.random.default_rng(42)
x = rng.normal(0, 0.05, len(t)) \
    + 0.5*np.sin(2*np.pi*31.5*t) + 0.4*np.sin(2*np.pi*250*t) + 0.3*np.sin(2*np.pi*2000*t)

bands = [31.5, 63, 125, 250, 500, 1000, 2000, 4000, 8000]  # 1/1 倍频程标称 fc

def band_edges(fc, frac=1):
    """1/1 倍频程带边界"""
    return fc*2**(-frac/2), fc*2**(+frac/2)

# ---- 方法一：时域滤波器组（Butterworth 4 阶带通 + RMS 检波）----
print(f"{'fc':>6} {'滤波法':>9} {'FFT法':>9} {'差值':>7}")
levels_filter, levels_fft = [], []
for fc in bands:
    lo, hi = band_edges(fc)
    sos = signal.butter(4, [lo/(fs/2), hi/(fs/2)], btype='band', output='sos')
    y = signal.sosfilt(sos, x)
    # RMS 检波：稳态后 1 秒（避开滤波器启动暂态）
    seg = y[-fs:]
    p_rms = np.sqrt(np.mean(seg**2))
    L_f = 20*np.log10(p_rms/2e-5)
    levels_filter.append(L_f)

    # ---- 方法二：FFT 谱线分组（同一秒数据，半值规则）----
    xs = x[-fs:]
    N = len(xs)
    spec = np.abs(np.fft.rfft(xs)) / N * 2      # 幅值谱
    freqs = np.fft.rfftfreq(N, 1/fs)
    power = (spec/np.sqrt(2))**2                 # 各谱线均方值
    m = (freqs >= lo) & (freqs <= hi)
    pw = power[m].sum()
    # 边界谱线半值（近似处理）
    for edge in (lo, hi):
        idx = np.argmin(np.abs(freqs - edge))
        if abs(freqs[idx]-edge) < fs/N and idx in np.where(m)[0]:
            pw -= power[idx]/2
    p_f = np.sqrt(pw)
    L_s = 20*np.log10(p_f/2e-5)
    levels_fft.append(L_s)

    print(f"{fc:>6.0f} {L_f:>8.1f}dB {L_s:>8.1f}dB {L_f-L_s:>+6.1f}")

print(f"\n总级 滤波法: {20*np.log10(np.sqrt(sum(10**(L/10) for L in levels_filter))/2e-5):.1f} dB")
```

实测输出（固定随机种子 42，可复现）：

```
    fc        滤波法       FFT法      差值
    32      85.0dB      84.9dB   +0.1
    63      58.9dB      59.9dB   -1.0
   125      57.1dB      49.3dB   +7.8
   250      83.0dB      83.0dB   -0.0
   500      57.7dB      49.9dB   +7.8
  1000      56.6dB      52.7dB   +3.9
  2000      80.5dB      80.5dB   -0.0
  4000      60.3dB      58.8dB   +1.5
  8000      61.8dB      61.7dB   +0.1
```

三个规律值得细看：

- **纯音正对中心频率的带（250、2000 Hz）两法完全一致**（±0.0 dB）——信号能量集中在带内、远离边界时，两条路线殊途同归。
- **白噪声主导、不含强纯音的带（125、500 Hz）FFT 法偏低可达 7.8 dB**。原因有两层：矩形窗对非整周期白噪声的谱泄漏把能量摊到全带宽，带内截断就丢了摊出去的部分；半值规则只是对边界谱线的粗补偿。滤波法没有这个问题——滤波器在时域连续作用，过渡带的能量归属由滚降形状决定。
- **31.5 Hz 带两法接近但都有偏差来源**：时域侧滤波器低频暂态长（3 秒信号只取最后 1 秒基本收敛）；FFT 侧 1 秒窗在 31.5 Hz 带内只有约 2 根谱线，统计涨落大。

把 `butter` 阶数从 4 改到 8 观察：纯音带的读数几乎不动，白噪声带的滤波法读数轻微变化——阶数改变的是过渡带宽度，即带边界能量归属，这正是 ANSI S1.11 容差图要约束的东西。

**时域法的隐藏成本**：每个带一个滤波器（9 带就是 9 次 sosfilt 全长滤波），FFT 法只做一次变换；但时域输出的是连续波形，天然支持逐帧 Fast/Slow 跟踪——两法的适用场景由这个结构差异决定。

## 八、小结

判读倍频程数据先问三个问题：滤波法还是 FFT 法（认证与声级计对标只认前者）；自然频率还是标称频率（计算用前者、标注用后者，混用会带边界错位）；Fast 还是 Slow（0.125 s 抓瞬态、1 s 出稳态读数，报告值默认 Slow）。1/3 带与人耳分辨对齐、带宽恒为中心频率的 23.1%，这套"恒定百分比带宽"体系全部来自 $f_c = 1000 \cdot 2^{i \cdot x}$ 这一条对数轴——记住锚点和指数，任何分数倍频程的边界都能手算。
