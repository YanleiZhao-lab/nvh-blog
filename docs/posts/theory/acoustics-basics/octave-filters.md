# 倍频程滤波与实时频谱：声级计 1/1、1/3 倍频程带是怎么算出来的

> 倍频程谱上那排柱子不是 FFT 算出来的，是一整组时域带通滤波器各管一段、各自输出能量平方平均的结果。这篇从中心频率的 2 的分数次幂定义出发，推导自然频率与 ISO 标称频率为什么对不上、带内能量积分怎么落到离散谱线求和，最后说清 Testlab 里 ANSI-IEC Octave Filtering 插件、RTO 处理和 Fast/Slow 时间计权这些实测设置。

## 一、一个倍频程带到底是哪一段频率

音乐里 1 个八度（octave）是频率翻倍：A4 是 440 Hz，A5 就是 880 Hz。倍频程分析借用了同一个规则——**后一个带的中心频率是前一个带的 2 倍**。人耳听觉范围 20 Hz 到 20 kHz 按 1/1 倍频程切，正好切成 11 个带；把每个 1/1 带再三分，就是 1/3 倍频程，与人耳的频率分辨能力更贴近。

![1/1倍频程带的下限、中心与上限频率](/images/octave-filters/fig3-1-1-octave-bands.png)

*（图源：Simcenter Testing Knowledge Base）*

1/3 带看起来只是切得更细，但有一个常被忽略的后果：**带宽不再等宽，而是逐带变宽**。100 Hz 带宽约 23 Hz，1000 Hz 带宽约 232 Hz——同样是"一个带"，高频带装进的频率范围是低频带的十倍。

![1/3倍频程带的上下限与中心频率](/images/octave-filters/fig4-1-3-octave-bands.png)

*（图源：Simcenter Testing Knowledge Base）*

::: info 核心概念
- **倍频程（Octave）**：中心频率按 2 的整数或分数次幂递进的频带划分
- **1/3 倍频程**：把一个 1/1 带按 2 的 1/3 次幂比例再切成三段
- **带宽恒分数**：带宽与中心频率的比值对所有带恒定（1/1 带约 70.7%，1/3 带约 23.1%）
:::

## 二、中心频率推导：为什么 1000 Hz 带的上限是 1122 Hz 而不是 1150 Hz

先从定义出发。相邻带中心频率之比固定为 2 的 x 次幂（x = 1、1/3、1/12、1/24 等）：

$$f_{c,\,i+1} = f_{c,\,i} \cdot 2^{x}$$

以 1000 Hz 为锚点往两边生成整条频率轴，第 i 个带的中心频率就是：

$$f_{c,\,i} = 1000 \cdot 2^{i \cdot x}$$

物理意义：带中心在**对数频率轴上等间距**，间距为 x 个倍频程。人耳恰近似按对数感知音高，所以这套划分与听觉一致。

带宽怎么定？一个带的上、下限频率取中心频率两侧各 x/2 个倍频程：

$$f_{lower} = f_c \cdot 2^{-x/2}, \qquad f_{upper} = f_c \cdot 2^{+x/2}$$

推导带宽与中心频率之比：上下限相除得 $f_{upper}/f_{lower} = 2^{x}$，相乘得 $f_{lower} \cdot f_{upper} = f_c^2$——中心频率恒等于上下限的**几何平均**，这正是"对数轴中点"的含义。带宽：

$$BW = f_c\,(2^{x/2} - 2^{-x/2})$$

代入 x=1：$2^{0.5}-2^{-0.5} \approx 0.707$，即 1/1 带宽恒为中心频率的 70.7%；x=1/3 时算出 23.1%。

按这套公式算出的频率叫**自然频率（natural frequency）**。1/3 带相邻中心频率比是 $2^{1/3} = 1.2599$，1000 Hz 的下一个带是 1259.9 Hz，再下一个是 1587.4 Hz。工程上没人愿意报"1259.9 Hz"，ISO 标准把中心频率取整为 100、125、160、200、250、315、400、500、630、800、1000 等，这套**标称频率（nominal frequency）**用于标注，自然频率用于计算。

对 1000 Hz 的 1/3 带实际算一下：$f_{upper} = 1000 \times 2^{1/6} = 1122.5$ Hz，$f_{lower} = 1000 / 2^{1/6} = 890.9$ Hz。上限不是 1000+232/2=1116 那种算术切法，更不是"125 减 100 等于 25 Hz 宽"——25 Hz 是**标称频率之差**，1122 减 891 等于 232 Hz 才是真实的滤波器带宽。

::: warning 工程注意
自然频率用于计算，标称频率用于标注，两者数值有出入（如 1/3 带自然序列 891、1000、1122、1260、1413、1587，标称序列 800、1000、1250、1600）。做带级对比、滤波器设计或跨软件对数据时，务必确认双方用的是自然频率还是标称频率，否则边界对不上、能量归属出错。
:::

## 三、倍频程谱不是 FFT 分组：滤波器组加均方根检波

Simcenter Testlab 的倍频程由**一组并行时域带通滤波器**实现，滤波器形状符合 ANSI S1.11-2011 与 IEC 61260（2014）标准。时域数据流进滤波器组，每个滤波器放行一个带的频率范围，输出各自滤波后的时间信号，再对每路输出做能量（均方）平均，得到该带的声压级。

![时域数据流过带通滤波器组，每路输出按带计算总级](/images/octave-filters/fig7-filter-bank.png)

*（图源：Simcenter Testing Knowledge Base）*

这条路叫滤波法（filter-based），与 FFT 法有本质差别：

| 对比项 | **滤波法（ANSI/IEC）** | **FFT 法（谱线分组求和）** |
| --- | --- | --- |
| **实现** | 时域带通滤波器组 + RMS 检波 | FFT 谱线按频率区间累加 |
| **频率边界** | 滤波器标准形状，边界固定 | 谱线格点决定，随分辨率变 |
| **时间跟踪** | 逐帧输出，可跟踪瞬态 | 帧长内平均，瞬态被摊薄 |
| **标准符合性** | 声级计、认证测试指定 | 非标准算法，仅供工程参考 |
| **代价** | 每带一个滤波器，计算量大 | 一次 FFT 全带宽到手 |

滤波器组视图也解释了倍频程显示的两种画法：把 x 轴标成"倍频程格式"（对数频率、各带等宽显示），高频带和低频带看起来一样宽；换回线性频率轴，同一组数据立刻现形——白噪声的窄带谱全线持平，而倍频程柱随频率越来越高（带宽逐带变宽，装进的能量越多，白噪声每个 1/1 带比前一带高 3 dB）。

![倍频程格式 x 轴下白噪声的窄带谱与倍频程谱](/images/octave-filters/fig5-octave-format.png)

*（图源：Simcenter Testing Knowledge Base）*

![线性频率轴下同一组数据：高频倍频程带覆盖的频率范围越来越大](/images/octave-filters/fig6-linear-format.png)

- 报告给人看、对标法规或声级计读数：滤波法 1/3 倍频程

## 四、带级怎么算：从能量积分到谱线求和

声学量在任何频带内的值，本质是该带内频率分量的能量积分（LMS 理论手册 式 5-14）：

$$a = \int_{f_1}^{f_2} a(f)\, df$$

物理意义：频域函数 $a(f)$ 在带内的面积。这个"面积"对应的不是幅值相加，而是**能量（均方）相加**——两个不同频率的声压叠加，总均方声压等于各自均方声压之和，因为交叉项在整周期上积分为零。这就是为什么带级用 $10\lg$ 对能量求和，而不是把 dB 值直接相加。

实测数据是离散谱线，积分退化为求和（式 5-15）：带内谱线取全值，恰落在上下限频率上的谱线取半值。

半值规则不是数学美化：边界谱线的能量分属相邻两个带，各记一半，带边界两侧的总能量才守恒。对滤波法倍频程不存在这个问题——滤波器形状本身决定了边界过渡带的能量归属，这也是认证测试只认滤波法的原因之一。

## 五、Testlab 实测设置：插件、RTO 与时间计权

倍频程在 Testlab 里不是默认功能。路径：**Tools、Add-ins 里勾选 ANSI-IEC Octave Filtering**（该插件需 23 个 token），然后在 Time Data Processing 里做滤波法倍频程。

两个必设参数：

**平均方式**。指数平均对最近的帧加权更重，读数跟随变化快、回稳慢；线性平均对所有帧算术平均，读数更稳。稳态工况选线性，工况有漂移或要做声级计式监视选指数。

**时间计权（Sound Level Type）**。这是滤波法倍频程最容易被设错的一项：

| 时间计权 | 平均帧长 | 读数行为 | 适用场景 |
| --- | --- | --- | --- |
| **Fast** | 0.125 s | 跟随快、抖动大 | 快速扫工况、瞬态监视 |
| **Slow** | 1.000 s | 平滑、滞后 | 稳态读数、报告值 |
| **Impulse** | 0.035 s | 峰值抓取 | 脉冲声、咔哒声 |
| **User** | 自定 | — | 特殊帧长需求 |

帧长就是每一步增量计算所用的时间窗：Fast 用 125 ms 内的能量平均，电动窗上升这类 200 ms 级事件能看到明显的级差起伏；Slow 把 1 秒的能量摊开，同一事件读数平滑但峰值被低估。

带 RTO（Real Time Octaves）后缀的功能（如 Psychoacoustic Metrics RTO）同样走滤波法路线，用时间域滤波直接算声品质指标，适合非平稳信号。

单带跟踪是倍频程分析的另一用法：固定一个中心频率（如 315 Hz、500 Hz），看它随时间或转速的变化，直接定位"哪个频段在什么工况下超标"。

## 六、Python 演示

```python
import numpy as np

# 1/3 倍频程带的自然频率与带宽
x = 1/3
print("1/3 倍频程 1000 Hz 相邻三带 (自然频率):")
for k in (-1, 0, 1):
    fc = 1000 * 2**(k * x)              # 自然中心频率, 用于计算
    lo = fc * 2**(-x/2)                 # 带下限
    hi = fc * 2**(+x/2)                 # 带上限
    print(f"  fc={fc:8.1f} Hz  带宽 [{lo:7.1f}, {hi:7.1f}] Hz  BW={hi-lo:6.1f} Hz ({(hi-lo)/fc*100:.1f}%)")

# ISO 标称中心频率 (R10 优先数序列) 用于标注
nom = np.array([1.0, 1.25, 1.6, 2.0, 2.5, 3.15, 4.0, 5.0, 6.3, 8.0])
fc_nom = np.sort(np.outer(10.0**np.arange(1, 4), nom).ravel())
fc_nom = fc_nom[(fc_nom >= 20) & (fc_nom <= 20000)]
print(f"\nISO 标称序列(部分): {fc_nom[10:17]}")

print(f"\n标称 1000 Hz 带的自然边界: [{1000*2**(-1/6):.1f}, {1000*2**(+1/6):.1f}] Hz")
print(f"带宽/中心频率 恒为 {2**(x/2)-2**(-x/2):.3f} (所有 1/3 带相同)")
print(f"白噪声 1/1 带级差: {10*np.log10(2):.1f} dB/带")
```

输出里最值得看的三个数：1000 Hz 的 1/3 带真实带宽是 232 Hz 而不是标称差 250 Hz；带宽与中心频率之比对所有带恒为 0.231，这就是"恒定百分比带宽"；白噪声 1/1 带每升一带涨 3.0 dB。

## 七、小结

判读倍频程数据先问三个问题：滤波法还是 FFT 法（认证与声级计对标只认前者）；自然频率还是标称频率（计算用前者、标注用后者，混用会带边界错位）；Fast 还是 Slow（0.125 s 抓瞬态、1 s 出稳态读数，报告值默认 Slow）。1/3 带与人耳分辨对齐、带宽恒为中心频率的 23.1%，这套"恒定百分比带宽"体系全部来自 $f_c = 1000 \cdot 2^{i \cdot x}$ 这一条对数轴——记住锚点和指数，任何分数倍频程的边界都能手算。
