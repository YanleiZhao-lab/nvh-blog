# 音高与虚拟音高：滤掉基频为什么还能听出那个调

> 变速箱台架上一族间距 565 Hz 的窄带啸叫，将 565 Hz 基频谱线滤除后，音调感（tonality）几乎不变。这不是测量误差：人耳对复合音的音高判断本就不依赖基频谱线本身，而是由高次谐波之间的间距推断出来的，这就是残差音高（residue pitch），也称虚拟音高（virtual pitch）。本文从纯音音高随频率与声压级的非线性关系讲起，经半音高实验与 mel 标尺，过渡到 Terhardt 的谱音高/虚拟音高计算框架，最后给出电驱啸叫"去音调感"整改的工程判据。

## 一、音高不是频率的另一个名字

谱上一根 1 kHz 纯音，称其"音高 1 kHz"并不严谨，这个等价关系只在很窄的条件下成立。手册的表述为：**纯音的音高随频率和声压级二者变化，而这一关系本身又与音的频率有关**。

这一表述包含三层含义。第一，音高（pitch）是听觉属性，频率是物理量，二者只在低频段近似一一对应。第二，同一频率的纯音，声压级改变时感觉到的音高也会漂移，且纯音音高随声压级的漂移在高频段更明显。第三，由多个谱分量组成的复合音（complex tone）可感觉出一个或多个音高，哪些音高更为突出，还受掩蔽效应（masking effect）支配。

音高感与频率呈非线性关系的根源在耳蜗。内耳等效于一组互相衔接的带通滤波器（临界带，critical band）：500 Hz 以下带宽近似恒定约 110 Hz，高频段扩展为约 23% 的恒百分比带宽，这与耳蜗的频率—位置对数特性相符（详见声品质指标一篇的临界带部分）。对数特性的"硬件"感知线性扫频的频率轴，音高感自然偏离线性。

![临界带表：耳蜗等效滤波器组的分带](/images/pitch-virtual-pitch/tab6-1-critical-bands.png)

*临界带表，以 Bark 标尺标识（图源：Simcenter Testing Knowledge Base 中文理论手册）*

要量化音高感，需要一把听觉上的标尺。心理声学实验的标准做法是**半音高测量**：先听某一频率的纯音，再调节第二个纯音的频率，直到其音高感觉为前者的一半。

实验结果：

- **低频区**：半音高对应 2:1 的频率比——音乐上八度的来源；
- **高频区**：频率比明显大于 2:1。手册给出的实测数：**8 kHz 纯音的半音高是 1300 Hz**，比值 1300/8000 = 0.163，与 0.5 相差约三倍。

即"频率减半 = 音高减半"这一音乐直觉，只是人耳在低频段的局部近似，到高频完全不成立。

### mel 标尺：音高感的定量刻度

半音高实验只给出比率，要得到绝对刻度需选定参考。标准以 125 Hz 为参考频率：125 Hz 纯音的比音高（ratio pitch）定义为 **125 mel**（mel 取自 melody）。手册给出三个锚点：

| 频率 | 比音高 | 备注 |
| --- | --- | --- |
| **125 Hz** | 125 mel | 参考点，低频段 mel 与频率数值近似相等 |
| **1300 Hz** | 1050 mel | 恰为 2100 mel 的一半 |
| **8000 Hz** | 2100 mel | 高频严重偏离线性 |

440 Hz 标准音的 mel 值与其频率数值几乎相同，中频段是过渡区。mel 标尺的用途不是日常工程计算，而是心理声学实验中报告音高差别的统一坐标——两音的 mel 差才是"听起来的音高距离"。

::: info 核心概念
- **音高（pitch）**：听觉上由低至高给音分类的属性，纯音主要依赖频率但受声压级影响
- **半音高**：音高感减半对应的频率，低频 2:1、高频远大于 2:1（8 kHz 对应 1300 Hz）
- **mel 标尺**：比音高的线性刻度，125 Hz = 125 mel 定参考，中频近似频率、高频压缩
- **谱音高（spectral pitch）**：直接由信号中真实存在的谱分量求出的音高
- **虚拟音高（virtual pitch / 残差音高 residue pitch）**：基频不在谱内、由高次谐波间距推断出的音高
:::

## 二、虚拟音高：听觉在反演基频

手册 7.7 节的现象描述只有一句，但值得展开：**考察包含基频及若干谐波组成的复合音，可感觉出相应于基频的音高，甚至将基频从信号中滤除后仍可感觉到。** 这一情况下，感觉音高不但与真实存在的信号分量有关，而且与高次谐波之间的频率差有关。

将其写成数学形式。设复合音的谐波族为 $f_k = k f_0$（$k = 1, 2, \ldots, K$），$f_0$ 为基频（Hz）。滤除基频谱线后，听觉系统面对的谱线集合为：

$$\{2f_0,\ 3f_0,\ \ldots,\ Kf_0\}$$

恢复 $f_0$ 最直接的线索是**相邻谐波间距**：$f_{k+1} - f_k = f_0$，与 $k$ 无关。$K-1$ 根谱线共有 $K-2$ 个相邻间距，对其取平均即得基频的最小二乘估计：

$$\hat{f}_0 = \frac{1}{K-2}\sum_{k=2}^{K-1}\left(f_{k+1} - f_k\right) = \frac{f_K - f_2}{K-2}$$

物理意义：谐波族在频率轴上等间距排列，间距就是被滤除的基频。间距信息编码在整族谱线的相对位置中，滤除一根谱线并不破坏它——这就是"基频不在谱内、音高仍然成立"的机理。注意该式仅对理想等间距谐波族严格成立；实际谱线受转速波动、边带调制影响存在偏离，估计精度取决于间距的规整程度。

但间距线索只解释"能恢复"，解释不了"恢复到哪个候选"。基频反演存在多解问题：谱线集 400/600/800 Hz 用 $f_0 = 200\ \mathrm{Hz}$ 可解释为 2、3、4 次谐波，用 $f_0 = 100\ \mathrm{Hz}$ 同样自洽（4、6、8 次）。听觉如何选择？Terhardt 的答案是**加权**：谐波次数越低的候选越受偏好（低次谐波的谱音高权重高），同时候选基频还须落在听觉较敏感、掩蔽较弱的区域。上例中人耳听到 200 Hz 而非 100 Hz，正是因为 200 Hz 的解释方案谐波次数整体更低。
### Terhardt 计算框架

手册指明音高计算按 Terhardt 方法执行（J. Acoust. Soc. Am. Vol 71, pp 679-688, 1982），框架要点：

1. 对谱中每根显著分量计算**谱音高**——真实分量的音高，带权；
2. 对每根谱线 $f_i$ 生成**子谐波候选** $f_i/n$（$n = 1, 2, \ldots$），统计各候选获得的**支持权重**（哪些谱线能被它解释为自己的谐波）；
3. 支持多、谐波次数低、掩蔽影响小的候选得分最高，成为**虚拟音高**；
4. 谱音高与虚拟音高均带权输出——指明各音高分量在感觉上的地位。

还有一个工程上常用的区分：计算时**计及声压级对音高的影响**，得到真实音高（true pitch）；**忽略**声压级影响，得到标称音高（nominal pitch）。报告采用哪种口径，须事先明确。

*纯音等响度曲线簇：同一频率在不同声压级下的听觉属性并不重合（图源：Simcenter Testing Knowledge Base 中文理论手册）*

::: warning 工程注意
"把啸叫的基频滤掉就没有音调感了"是误判。只处理基频、不动谐波族，虚拟音高几乎原样保留。要去掉音调感（tonality），整改对象是谐波族的**间距结构**——要么将整族能量按频带衰减（吸声/隔声分频带处理），要么打破等间距性（改变啮合参数使边带不再规则）。
:::

## 三、Python 演示：从谐波族反推虚拟音高

```python
import numpy as np

# 场景：台架啸叫谱线族 565 Hz 间距，基频 565 Hz 谱线已被滤除
peaks = np.array([1130.0, 1695.0, 2260.0, 2825.0])  # 2,3,4,5 次谐波

# Terhardt 式子谐波候选打分：候选 f0 = f_i/n，统计支持权重
def virtual_pitch(peaks, n_max=10, tol=0.02):
    scores = {}
    for f in peaks:                      # 每根谱线生成自己的子谐波候选
        for n in range(1, n_max + 1):
            f0 = round(f / n, 1)
            w = 0.0
            for p in peaks:              # 哪些谱线能被该 f0 解释为谐波
                ratio = p / f0
                if abs(ratio - round(ratio)) < tol:
                    w += 1.0 / round(ratio)   # 谐波次数低权重高
            scores[f0] = scores.get(f0, 0.0) + w
    return sorted(scores.items(), key=lambda kv: -kv[1])[:4]

for f0, w in virtual_pitch(peaks):
    harm = np.round(peaks / f0).astype(int)
    res = peaks - harm * f0
    print(f"候选 f0={f0:7.1f} Hz  权重={w:5.2f}  谐波号={harm}  残差RMS={np.sqrt((res**2).mean()):6.1f} Hz")
```

实际输出（本站环境实测）：

```text
候选 f0=  565.0 Hz  权重= 5.13  谐波号=[2 3 4 5]  残差RMS=   0.0 Hz
候选 f0= 1130.0 Hz  权重= 3.00  谐波号=[1 2 2 2]  残差RMS= 399.5 Hz
候选 f0=  282.5 Hz  权重= 2.57  谐波号=[ 4  6  8 10]  残差RMS=   0.0 Hz
候选 f0=  376.7 Hz  权重= 1.00  谐波号=[3 4 6 7]  残差RMS= 133.0 Hz
```

结果分三个层次读：**565.0 Hz 权重最高**（四根谱线全部被解释为 2/3/4/5 次低次谐波，残差为零）。次优候选 1130 Hz 残差高达 399.5 Hz——它只能解释 1130/2260 两根谱线，1695 与 2825 Hz 落在其解释之外。值得注意的是 282.5 Hz：它同样能以零残差解释全部四根谱线（4/6/8/10 次），但谐波次数整体翻倍使权重降至 2.57——这正是"低次谐波偏好"在打分中的体现，也是 565 Hz 胜出的直接原因。基频被滤除这件事，对该反演算法与对听觉系统一样，几乎不构成影响。

再给出多解性的对照（同一函数换输入）：

```python
import numpy as np

# 教科书例子：400/600/800 Hz，200 与 100 均自洽，观察权重如何选择
peaks = np.array([400.0, 600.0, 800.0])

def virtual_pitch(peaks, n_max=10, tol=0.02):
    scores = {}
    for f in peaks:
        for n in range(1, n_max + 1):
            f0 = round(f / n, 1)
            w = 0.0
            for p in peaks:
                ratio = p / f0
                if abs(ratio - round(ratio)) < tol:
                    w += 1.0 / round(ratio)
            scores[f0] = scores.get(f0, 0.0) + w
    return sorted(scores.items(), key=lambda kv: -kv[1])[:4]

for f0, w in virtual_pitch(peaks):
    print(f"候选 f0={f0:6.1f} Hz  权重={w:5.2f}")

# 半音高的非线性：低频 2:1 成立，8 kHz 的半音高只有 1300 Hz
print()
print("低频半音高(2:1): 250 Hz -> 125 Hz")
print(f"8 kHz 物理半频 4000 Hz，听觉半音高 1300 Hz，比值 {1300/8000:.3f}")
print("mel: 8000 Hz = 2100 mel, 1300 Hz = 1050 mel，恰好减半")
```

实际输出：

```text
候选 f0= 200.0 Hz  权重= 3.25
候选 f0= 400.0 Hz  权重= 3.00
候选 f0= 100.0 Hz  权重= 1.62
候选 f0= 133.3 Hz  权重= 1.00

低频半音高(2:1): 250 Hz -> 125 Hz
8 kHz 物理半频 4000 Hz，听觉半音高 1300 Hz，比值 0.163
mel: 8000 Hz = 2100 mel, 1300 Hz = 1050 mel，恰好减半
```

两段输出合起来看：200 Hz 权重（3.25）明显高于 100 Hz（1.62），低次谐波偏好使人耳在多解候选中选定 200 Hz；而 8 kHz 的半音高比值 0.163 说明，高频段"音高减半"对应的频率变化远不止减半——频率轴与听觉音高轴在高频段严重分离。

## 四、整车 NVH 中的音高问题

**电驱/齿轮啸叫的音调感**。阶次啸叫本质是谐波族，其音调感即虚拟音高。评价电驱啸叫的干扰程度，仅看 colormap 上谱线的 dB 值并不充分，还要看其音高属性——落在哪个 mel 区间、与背景噪声的掩蔽关系（参考掩蔽效应一篇）。同为 40 dB(A) 的啸叫，谱线族间距落在 1～5 kHz（听觉敏感区、掩蔽弱）比落在 200 Hz 以下（易被路噪掩蔽）干扰显著更大。

**音频提示音设计**。倒车提示、行人提示音（AVAS）都是音调设计问题。低频段音高与频率近似线性、易记忆易传唱；要使两声音高差可分辨，应按 mel 差设计而非频率差——8000 Hz 附近 500 Hz 的频率差，在听觉上几乎不可分辨。

**声音品质对标**。关门声、转向灯咔哒声这类"好声音"，音高是品牌属性的一部分。对标竞品音高应使用标称音高口径、同一套计算参数，避免一台计级一台不计。

| 场景 | 用什么音高口径 | 原因 |
| --- | --- | --- |
| **啸叫音调感评价** | 虚拟音高 + 掩蔽分析 | 基频常被滤除或掩埋，谐波族才是载体 |
| **AVAS/提示音设计** | mel 标尺（标称音高） | 低频线性区便于设计，高频防止差异不可分辨 |
| **声品质对标报告** | 标称音高 | 忽略声压级影响，口径统一才可比 |
| **心理声学实验** | 真实音高 | 级相关漂移本身是研究对象 |

::: tip 选择原则
- 判断"啸叫有无音调感"：不以基频谱线为准，对整族谱线计算虚拟音高——间距在，音调感就在
- 降噪目标设定：将谐波族整体压到背景掩蔽阈值以下，而不是只压最响的一根谱线
- 报告音高数值：注明真实/标称口径与所用算法（Terhardt 族），跨数据对比先统一口径
:::

## 五、小结

音高是听觉属性而非物理量，低频近似线性、高频严重压缩（8 kHz 的半音高是 1300 Hz，mel 标尺 2100 对 1050 恰好减半）。复合音的音高感主要经由虚拟音高通道：谐波族间距携带基频信息，基频谱线本身可有可无；多解候选由低次谐波偏好决定（Terhardt 框架）。工程含义：去音调感须处理间距结构，不是滤除一根谱线；提示音与音高对标采用 mel 与标称口径，跨报告先统一算法。
