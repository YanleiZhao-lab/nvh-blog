# 音高与虚拟音高：滤掉基频为什么还能听出那个调

> 变速箱台架上一族 565 Hz 间隔的窄带啸叫，工程师把 565 Hz 那根线滤掉准备"消掉音调感"，结果听感几乎没变——音高感还在。这不是心理作用：人耳对复合音的音高判断本来就不依赖基频那根谱线，而是从高次谐波之间的间距"解"出来的，这就是残差音高（residue pitch），也叫虚拟音高（virtual pitch）。这篇从纯音音高的非线性讲起，经 mel 标尺和半音高实验，推到 Terhardt 的谱音高/虚拟音高计算框架，最后给电驱啸叫"去音调感"整改的工程判断。

## 一、音高不是频率的另一个名字

谱上一根 1 kHz 纯音，说它"音高 1 kHz"看似没错，但这个等号只在很窄的条件下成立。手册给的表述很谨慎：**纯音的音高随频率和声压级二者变化，而这一关系本身又与音的频率有关**。

拆开读有三层意思。第一，音高（pitch）是听觉属性，频率是物理量，二者只在低频段近似一一对应。第二，同一个频率的纯音，声压级变了，感觉到的音高也会漂——纯音的音高随级漂移在高频段更明显。第三，复合音（多个谱分量）可以听出一个或多个音高，哪些音高"浮出来"还受掩蔽效应支配。

为什么音高感与频率不是线性关系？根源在耳蜗。内耳等效于一组衔接的恒百分比带宽滤波器（临界带），频率—位置换能本身是对数型的（详见声品质指标一篇的临界带部分）。对数硬件感知线性扫频的频率轴，输出自然要弯。

![临界带表：耳蜗等效滤波器组的分带](/images/pitch-virtual-pitch/tab6-1-critical-bands.png)

*临界带表，以 Bark 标尺标识（图源：Simcenter Testing Knowledge Base 中文理论手册）*

要量化"音高感"，得先有一把听觉上的尺。心理声学实验的标准做法是**半音高测量**：先听一个频率的纯音，再调第二个纯音的频率，直到它的音高感觉是前者的一半。

结果很说明问题：

- **低频区**：半音高对应 2:1 的频率比——音乐上八度的来源；
- **高频区**：频率比明显大于 2:1。手册给的实测数：**8 kHz 纯音的半音高是 1300 Hz**，比值 0.163，离 0.5 差了三倍。

也就是说"频率减半 = 音高减半"这条音乐直觉，是人耳在低频段的局部近似，到高频完全不成立。

### mel 标尺：给音高感定标

半音高实验只能给比率，要绝对刻度得选参考。标准选 125 Hz 为参考：125 Hz 纯音的比音高定义为 **125 mel**（mel 取自 melody）。手册给了三个锚点：

| 频率 | 比音高 | 备注 |
| --- | --- | --- |
| **125 Hz** | 125 mel | 参考点，低频段 mel 与频率近似相等 |
| **1300 Hz** | 1050 mel | 恰为 2100 mel 的一半 |
| **8000 Hz** | 2100 mel | 高频严重偏离线性 |

440 Hz 标准音的 mel 值与频率数值几乎相同，中频段是过渡区。mel 标尺的用途不是日常计算，而是心理声学实验里报告音高差别的公共语言——两音的 mel 差才是"听起来差多少"。

::: info 核心概念
- **音高（Pitch）**：听觉上由低到高给音分类的属性，纯音主要依赖频率但受声压级影响
- **半音高**：音高感减半对应的频率，低频 2:1、高频远大于 2:1（8 kHz 对应 1300 Hz）
- **mel 标尺**：比音高的线性刻度，125 Hz = 125 mel 定参考，中频近似频率、高频压缩
- **谱音高（Spectral pitch）**：直接由信号中真实存在的谱分量求出的音高
- **虚拟音高（Virtual pitch / 残差音高 residue pitch）**：基频不在谱里、由高次谐波间距推断出的音高
:::

## 二、虚拟音高：听觉在做基频反演

手册 7.7 节的现象描述只有一句，但值得展开：**考察包含基频及若干谐波组成的复合音，可感觉出相应于基频的音高，甚至将基频从信号中滤除后仍可感觉到。**

这一情况下，感觉音高不但与真实存在的信号分量有关，而且与高次谐波之间的频率差有关。

把这句话翻译成数学。设复合音的谐波族为 $f_1 = f_0, f_2 = 2f_0, \ldots, f_K = Kf_0$。听觉系统面对的谱线集合（滤除基频后）是：

$$\{2f_0,\ 3f_0,\ \ldots,\ Kf_0\}$$

要恢复 $f_0$，最直接的线索是**相邻谐波间距**：$f_{k+1} - f_k = f_0$。对间距做平均（最小二乘意义上的拟合），就是基频的反演：

$$\hat{f}_0 = \frac{1}{K-1}\sum_{k=2}^{K-1}\left(f_{k+1} - f_k\right)$$

物理意义：谐波族在频率轴上等间距排列，间距就是"隐藏的基频"。听觉不需要那根基频谱线——间距信息在整族谱线的相对位置里，滤掉一根线破坏不了它。

但这只解释了"能恢复"，解释不了"恢复到哪个候选"。反演有个多解问题：谱线集 400/600/800 Hz 用 $f_0 = 200$ Hz 解释为 2、3、4 次谐波，用 $f_0 = 100$ Hz 也完全自洽（4、6、8 次）。听觉怎么选？Terhardt 的答案是**加权**：谐波次数越低的候选越受偏爱（低次谐波的谱音高权重高），同时候选基频还要落在听觉最敏感、掩蔽最弱的区域。上例中人耳听到 200 Hz 而非 100 Hz，就是因为 200 Hz 的解释方案谐波次数整体更低。

### Terhardt 计算框架

手册指明音高计算按 Terhardt 方法做（J. Acoust. Soc. Am. Vol 71, pp 679-688, 1982），框架要点：

1. 对谱中每根显著分量计算**谱音高**——真实分量的音高，带权；
2. 对每根谱线 $f_i$ 生成**子谐波候选** $f_i/n$（$n = 1, 2, \ldots$），统计各候选获得的**支持权重**（哪些谱线能被它解释为自己的谐波）；
3. 支持多、谐波次数低、掩蔽影响小的候选胜出，成为**虚拟音高**；
4. 谱音高与虚拟音高都带权输出——指明各音高分量在感觉上的地位。

还有一个工程上用得着的区分：计算时**计及声压级对音高的影响**，得到真实音高（true pitch）；**忽略**级的影响，得到标称音高（nominal pitch）。报告里写哪个，先想清楚。

*纯音等响度曲线簇：同一频率在不同声压级下的听觉属性并不重合（图源：Simcenter Testing Knowledge Base 中文理论手册）*

::: warning 工程注意
"把啸叫线的基频滤掉就没有音调感了"是错觉。只处理基频、不动谐波族，虚拟音高几乎原样保留。要去掉音调感（tonality），整改对象是谐波族的**间距结构**——要么把整族能量摊平（吸声/隔声按频带做），要么打破等间距性（改变啮合参数让边带不再规则）。
:::

## 三、Python 演示：从谐波族反推虚拟音高

```python
import numpy as np

# 场景：台架啸叫谱线族 565 Hz 间隔，基频 565 Hz 那根线已被滤除
peaks = np.array([1130.0, 1695.0, 2260.0, 2825.0])  # 2,3,4,5 次谐波

# Terhardt 式子谐波候选打分：候选 f0 = f_i/n，统计支持权重
def virtual_pitch(peaks, n_max=10, tol=0.02):
    scores = {}
    for f in peaks:                      # 每根谱线都提名自己的子谐波
        for n in range(1, n_max + 1):
            f0 = round(f / n, 1)
            w = 0.0
            for p in peaks:              # 哪些谱线能被该 f0 解释为谐波
                ratio = p / f0
                if abs(ratio - round(ratio)) < tol:
                    w += 1.0 / round(ratio)   # 谐波次数低权重高
            scores[f0] = scores.get(f0, 0.0) + w
    return sorted(scores.items(), key=lambda kv: -kv[1])[:4]

for f0, w in virtual_pitch(peaks):
    harm = np.round(peaks / f0).astype(int)
    res = peaks - harm * f0
    print(f"候选 f0={f0:7.1f} Hz  权重={w:5.2f}  谐波号={harm}  残差RMS={np.sqrt((res**2).mean()):6.1f} Hz")
```

输出里最值得看的对比：**565.0 Hz 以压倒性权重胜出**（四根谱线全部被解释为低次谐波 2/3/4/5，残差为零），次优候选只能解释两根线。基频被滤除这件事，对反演算法和对你我的耳朵一样——几乎无关紧要。

再给一个多解性的对照（同一函数换输入）：

```python
import numpy as np

# 教科书例子：400/600/800 Hz，200 与 100 都自洽，看权重怎么裁决
peaks = np.array([400.0, 600.0, 800.0])

def virtual_pitch(peaks, n_max=10, tol=0.02):
    scores = {}
    for f in peaks:
        for n in range(1, n_max + 1):
            f0 = round(f / n, 1)
            w = 0.0
            for p in peaks:
                ratio = p / f0
                if abs(ratio - round(ratio)) < tol:
                    w += 1.0 / round(ratio)
            scores[f0] = scores.get(f0, 0.0) + w
    return sorted(scores.items(), key=lambda kv: -kv[1])[:4]

for f0, w in virtual_pitch(peaks):
    print(f"候选 f0={f0:6.1f} Hz  权重={w:5.2f}")

# 半音高的非线性：低频 2:1 成立，8 kHz 的半音高只有 1300 Hz
print()
print("低频半音高(2:1): 250 Hz -> 125 Hz")
print(f"8 kHz 物理半频 4000 Hz，听觉半音高 1300 Hz，比值 {1300/8000:.3f}")
print("mel: 8000 Hz = 2100 mel, 1300 Hz = 1050 mel，恰好减半")
```

两段输出合起来看：200 Hz 比 100 Hz 权重高出一截（低次谐波偏好），这就是人耳在多解候选里"选"200 Hz 的机制；而 8 kHz 的半音高比值 0.163 说明，高频段"音高减半"对应的频率变化远不止减半——频率轴和听觉音高轴在高频严重分叉。

## 四、整车 NVH 里的音高问题去哪找

**电驱/齿轮啸叫的"调感"**。阶次啸叫本质是谐波族，人耳对它的"调感"就是虚拟音高。评价一台电驱的啸叫烦不烦，光看 colormap 上那根线的 dB 值不够，要看它的音高属性——落在哪个 mel 区间、与背景噪声的掩蔽关系（参考掩蔽效应一篇）。同为 40 dB(A) 的啸叫，谱线族间距落在 1～5 kHz（听觉敏感区、掩蔽弱）比落在 200 Hz 以下（容易被路噪掩蔽）烦得多。

**音频提示音设计**。倒车提示、行人提示音（AVAS）都是音调设计问题。低频段音高与频率近似线性、易记易唱；要两声音高差"明显"，按 mel 差设计而不是按频率差——8000 Hz 附近拉 500 Hz 的频率差，听觉上纹丝不动。

**声音品质对标**。关门声、转向灯咔哒声这类"好声音"，音高是品牌属性的一部分。对标竞品的音高要用标称音高口径，同一套计算参数，别一台计级一台不计。

| 场景 | 用什么音高口径 | 原因 |
| --- | --- | --- |
| **啸叫调感评价** | 虚拟音高 + 掩蔽分析 | 基频常被滤/被埋，谐波族才是载体 |
| **AVAS/提示音设计** | mel 标尺（标称音高） | 低频线性区好设计，高频防"听不出差别" |
| **声品质对标报告** | 标称音高 | 忽略级影响，口径统一才可比 |
| **心理声学实验** | 真实音高 | 级相关漂移本身是研究对象 |

::: tip 选择原则
- 判断"这条啸叫有没有调感"：别盯基频线，对整族谱线跑虚拟音高——间距在、调感就在
- 降噪目标设定：把谐波族整体压到背景掩蔽阈值以下，而不是只压最响那根
- 报告音高数值：注明真实/标称口径与所用算法（Terhardt 族），跨数据对比先对口径
:::

## 五、小结

音高是听觉属性不是物理量，低频近似线性、高频严重压缩（8 kHz 的半音高是 1300 Hz，mel 标尺 2100 对 1050 恰好减半）。复合音的音高感主要走虚拟音高通道：谐波族间距携带基频信息，基频谱线本身可有可无；多解候选靠低次谐波偏好裁决（Terhardt 框架）。工程含义直接——去音调感要打间距结构，不是摘掉一根谱线；提示音与音高对标用 mel 和标称口径，跨报告先对齐算法。
