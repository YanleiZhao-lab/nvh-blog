# 测量麦克风基础：驻极体、预极化与 IEPE 的原理与选型

> 同一台风洞里的同一组传声器，有人接 BNC 线两芯就出数据，有人必须拖一根 7 芯 LEMO 线并额外供 200 V 直流；同一份粉红噪声，用工程测量麦克风测出的倍频程谱是平的，换一支录音棚麦克风却低频塌、中频鼓。这两件"同源不同果"的事，答案都藏在麦克风胶囊里面那片几微米厚的振膜与它的供电方式里。本文把测量麦克风拆成胶囊、前放、接头三件套，讲清电容式换能的物理、外极化与预极化（驻极体）的分野、IEPE/ICP/CCP 与采集卡的对接、自由场/扩散场/压力场三种响应类型的选用、尺寸-频率-量程的三角取舍，以及标定与保养的现场纪律——就像认识一位琴师：先看他的琴（胶囊）、再看他的扩音（前放）、最后看他的琴谱与调音（标定）。

一台设备噪声整改后复测：同一测点、同一工况，前一批数据是 61 dBA，这一批却成了 64 dBA。排查半天，发现两次用的麦克风类型不同——一次是自由场型、一次是扩散场型；而测点恰在混响较强的车间里，声波从四面八方涌向麦克风。两支麦克风都没坏、都过了校准，读数就是差了 3 dB。这引出测量麦克风的第一课：**麦克风不是"通用的耳朵"，而是带个性的仪器**——它的极化方式决定了你怎么接线，它的频响平不平决定了你敢不敢叠加 A 计权，它的场型决定了它在哪种声场里读数才准，它的振膜尺寸决定了它能测多低、多高、多响。

## 一、为什么测量麦克风长这样：三个部件的分工

测量麦克风（measurement microphone）几乎都是**电容式（condenser / capacitance microphone）**：其它原理（动圈、铝带）当然存在，但工程计量的精度要求把它们挤出了主流。一支完整的麦克风"套装"由三段组成：**胶囊（capsule）+ 前置放大器（preamplifier）+ 接头（connector）**。

![测量麦克风三段结构：胶囊、前放、接头](/images/microphone-basics/figa.png)

*（图源：网络官方公开资料）*

贯穿全文打个比方：**电容麦克风像一张绷紧的小鼓皮悬在一块带电的板上方**。鼓皮就是振膜（diaphragm），几微米厚的金属化薄膜；带电的板就是背板（backplate）。声压推着鼓皮一鼓一瘪，鼓皮与背板之间的距离随之变化——这与用手按压鼓面、鼓腔里空气被压缩是同一个物理：距离变化改变电容，电容变化被转成电压。

![胶囊剖面：保护栅网内的振膜与背板](/images/microphone-basics/fig1.png)

*（图源：网络官方公开资料）*

::: info 核心概念
- **电容式麦克风（Condenser Microphone）**：以振膜-背板构成的电容器为换能元件，声压改变极间距从而改变电容，输出与声压成比例的电压；历史上电容曾被称为 condenser，故得名
- **胶囊（Capsule）**：完成"声压到电信号"换能的最小单元，内含保护栅网、振膜与背板
- **前置放大器（Preamplifier）**：把胶囊的高阻抗电容信号转为可长距离传输的低阻抗电压信号，并做初步放大
- **驻极体（Electret）**：一种准永久带电的介电材料，"静电版的永磁体"；涂在背板上可省去外部极化电压
:::

换能的物理链条只有五步：振膜初始与背板保持固定间距；背板携带电荷；声波推动振膜运动；间距变化使电容波动；电压随之输出。前放的职责是把这份微弱的电容变化"翻译"成模拟电压——既放大信号，又用低阻抗输出把传输线上的噪声挡在门外。接头则决定供电与信号协议：BNC（用于 IEPE/ICP/CCP）、SMB（阵列麦克风常见）、7 芯 LEMO（外极化麦克风专用）。

## 二、电容换能的定量链条

先给数再给式。一支 1/2 英寸测量麦克风的静态电容约几十皮法，振膜-背板初始间距约 20 微米，间距被声压推动的变化量只有几纳米。背板上的电荷保持恒定，声压做的全部事情就是微调这个间距。

这个公式回答的问题是：**声压推动振膜后，电容到底变了多少？** 其中 $d$ 为振膜-背板间距，$\varepsilon$ 为空气介电常数，$A$ 为振膜等效面积——间距越小电容越大，且越是靠近变化越剧烈（倒数关系是微小非线性的来源）：

$$
C = \frac{\varepsilon A}{d}
$$

这个公式回答的问题是：**恒定电荷下，电容变化如何变成电压信号？** 其中 $Q_0$ 是极化电荷（由 200 V 外极化或驻极体提供），$C_0$ 为静态电容，$E_0$ 为静态偏置电压，$e$ 是输出电压变化量——电荷不变时电压与电容成反比，声压"调幅"电容，电压便随之波动：

$$
e = \frac{Q_0}{C} - E_0, \qquad E_0 = \frac{Q_0}{C_0}
$$

两式合起来读：声压 → 间距 → 电容 → 电压，每个箭头都是确定性的比例关系。这也是"电容麦克风线性好、适合计量"的物理根源——它没有动圈式那种电磁转换中的非线性环节，小信号下失真天然在千分之几的水平。

用 numpy 把这条链条走一遍（12 行自包含）：设 1 kHz 声压使间距产生峰峰值 2 纳米的微变，偏置 200 V，看输出电压与二次谐波各是多少：

```python
import numpy as np

# 电容麦克风换能链：声压 -> 间距 -> 电容 -> 电压
d0       = 20e-6                 # 初始间距 20 um
eps, A   = 8.85e-12, 0.5e-4      # 空气介电常数 / 振膜有效面积 0.5 cm^2
C0, E0   = eps*A/d0, 200.0       # 静态电容约 22 pF / 偏置 200 V
Q0       = C0*E0                 # 恒定极化电荷

t  = np.linspace(0, 2e-3, 2000)              # 2 ms，含两个 1 kHz 周期
dd = 1e-9*np.sin(2*np.pi*1000*t)             # 间距微变，峰 1 nm
e  = Q0/(eps*A/(d0 - dd)) - E0               # e = Q0/C - E0
F  = np.abs(np.fft.rfft(e))
print(f"静态电容 C0 = {C0*1e12:.1f} pF")
print(f"输出峰峰值   = {2*np.max(np.abs(e))*1e3:.2f} mV")
print(f"二次谐波占比 = {F[4]/F[2]*100:.2f} %")
```

运行输出：

```text
静态电容 C0 = 22.1 pF
输出峰峰值   = 20.00 mV
二次谐波占比 = 0.07 %
```

间距微变万分之一（1 nm 对 20 μm），换来 20 mV 峰峰输出、二次谐波不到千分之一——线性度的数量级概念就来自这里。毫伏级信号经前放放大后进采集卡，链路上每一步的增益与噪声都计入最终信噪比。

## 三、极化方式之争：200 V 外极化 vs 驻极体预极化

背板要"感觉到"振膜的运动，必须先带电。带电有两种方案：**外极化（externally polarized）**由外部电源给背板加 200 V 直流；**预极化（prepolarized）**在背板上涂一层驻极体材料，电荷被"冻结"在介电材料里，静电学上它等效于一块永磁体——磁体不需要通电就有磁场，驻极体不需要电源就有电场。

![左：外极化麦克风（需 200 V 电源），右：预极化背板（驻极体涂层）](/images/microphone-basics/fig2.png)

*（图源：网络官方公开资料）*

选型时要在这两者间掂量，差异全部从"200 V 从哪来"派生：

| 维度 | 外极化（200 V） | 预极化（驻极体，0 V） |
| --- | --- | --- |
| 布线 | 7 芯 LEMO（极化电压、信号、供电分开走） | BNC 同轴两芯即可 |
| 与加速度计混测 | 需独立信号调理 | 与 IEPE 加速度计共用同一恒流源调理，一套设置通吃 |
| 高温稳定性 | 150 ℃ 以上更稳 | 高温下驻极体电荷可能缓慢衰减 |
| 量级上限 | 更高电压的前放可把最大声级抬高 3~6 dB | 常规量级 |
| 湿度敏感性 | 200 V 下潮湿环境更易短路放电 | 更皮实 |
| 成本 | 线缆与接插件复杂、更贵 | 同轴缆 + BNC，更便宜 |

::: info 核心概念
- **IEPE（Integrated Electronic Piezo-Electric）**：恒流源供电传感器的通用名，2~20 mA 恒流经信号线同时供能与传信号；预极化麦克风即走此协议
- **ICP / CCP**：同一恒流协议的商业名称——ICP 为 PCB Piezotronics 商标，CCP（Constant Current Power）常见于 GRAS；三者对采集卡而言完全等价，都用 BNC
:::

**IEPE 的接法值得单独说透**：恒流源经同轴缆送到麦克风前放，前放内部电路"吃"掉直流偏置、送回叠加在固定偏压上的交流信号；采集卡耦合掉直流、只取交流部分。因此预极化麦克风与 IEPE 加速度计在采集卡眼里是同一类设备——同一个通道设置（Input Mode 选 ICP）即可通用。这也是"声振混测"试验（比如 TPA 或声振模态）优先选预极化的现实理由：少一类线、少一类设置、少一类出错。

外极化的地位并未消失：高温台架（发动机周边）、极高声级（喷流噪声）、计量级年检等场合，200 V 方案仍靠稳定性与量级上限守住基本盘。两类麦克风对采集硬件的要求不同，这在 SCADAS 卡件上体现得很直白。

![同一块 SCADAS VM8 卡既支持外极化麦克风也支持 IEPE 麦克风，但接线与设置不同](/images/microphone-basics/fig3.png)

*（图源：网络官方公开资料）*

在 Simcenter SCADAS 上接外极化麦克风：需在 Testlab 中经 Tools → Channel Setup Visibility 打开 "Polarization" 与 "Power Supply" 字段，分别设为 200 V 与 28 V；V24/V8 等卡接 IEPE 传感器时 Input Mode 选 ICP 即可。用 VM8 卡接 IEPE 设备还需 7 芯 LEMO 转 BNC 的转接线——卡件端是 LEMO 座，传感器端是 BNC 头，这根转接线是现场常备品。

## 四、频响曲线：工程平直 vs 录音棚"美化"

频率响应回答的问题是：**同一个物理声压，麦克风在不同频率上读出的数一样吗？** 工程测量麦克风的答案是"尽量一样"——设计目标是一条平直的频响曲线，灵敏度在全部频段一致，偏差以相对参考的增益/衰减分贝数表示，理想值为零。录音棚话筒正相反：它故意不平，低频（100 Hz 以下）与高频（15 kHz 以上）被压低、对语音最重要的 1~6 kHz 被抬高，用以滤除咔嗒声、凸显人声——那是"好听的曲线"，不是"诚实的曲线"。

![录音棚麦克风的频响：低频高频衰减、1~6 kHz 抬升](/images/microphone-basics/fig4.png)

*（图源：网络官方公开资料）*

用同一粉红噪声源对比两类麦克风，差别一目了然：粉红噪声的设计意图是各倍频程能量相同，工程麦克风测出的 1/3 倍频程谱接近一条平线；录音棚麦克风测出的谱低频塌陷、中频隆起——两份"测量结果"都不是设备故障，但只有前者可以作为工程数据入账。

![粉红噪声的 1/3 倍频程谱：工程麦克风（绿）接近平线，录音棚麦克风（蓝）起伏明显](/images/microphone-basics/fig5.png)

*（图源：网络官方公开资料）*

由此引出一条常被忽视的纪律：**A 计权只能叠加在平直频响的数据上**。A 计权曲线本身刻画了人耳对各频段的敏感度差异，前提是原始数据如实反映物理声压。工程麦克风（平）+ A 计权 = 人耳感知的合理近似；录音棚麦克风（自带起伏）+ A 计权 = 两次加权叠加，结果不可解释。此外，工程麦克风在高频段的残余偏差也不必硬扛——Testlab 提供"频率相关校准（frequency dependent calibration）"功能，可把出厂频响偏差表逐频段补偿进测量链。

## 五、声场类型与指向：自由场、扩散场、压力型

开篇 3 dB 之谜的谜底在这一节。当声波波长与麦克风尺寸相当时（一般 10 kHz 以上），麦克风本体对声场的扰动不可忽略：机身反射、绕射会让某些频率的读数虚高。厂家无法造出"对所有入射角都平直"的理想麦克风，于是按目标声场分型校准——**同一支物理振膜，装进不同标定的壳里，就是三种不同的麦克风**。

![按声场分型的三种麦克风：自由场、扩散场、压力型](/images/microphone-basics/fig6.png)

*（图源：网络官方公开资料）*

- **自由场型（Free Field）**：校准时补偿"麦克风自身存在于自由场中"带来的扰动，要求**0 度正对声源**使用——指向声源的那一面读数才准。消声室、开阔户外首选。
- **扩散场型（Diffuse Field / Random Incidence）**：对任意入射角均匀响应，声从四面八方来时读数不偏。混响室、车内舱等混响环境首选——开篇那 3 dB，正是自由场型麦克风被放进了扩散场。
- **压力型（Pressure）**：为齐平安装设计，声源方向与膜面成 90 度，用于小腔体、近场与壁面测点（如管道内壁、声学腔体内部）。

指向特性可以用**极坐标图（polar plot / pickup pattern）**量化：固定声级、绕麦克风一周改变入射角、逐频记录衰减。自由场型在 0 度方向各频率均无衰减，背向衰减最大——"始终把自由场麦克风正对声源"这条现场铁律，就是从这张图里读出来的。

![自由场麦克风的极坐标图：0 度方向各频率响应一致，侧向与背向衰减增大](/images/microphone-basics/fig7.png)

*（图源：网络官方公开资料）*

## 六、尺寸的三角取舍：灵敏度、量级上限、频率上限

振膜直径直接框定一支麦克风的三个极限，规律一句话：**膜越大越灵敏、能测越低的声级；膜越小越能扛、能测越高的频率与声级**。

![振膜尺寸与可测声级范围：大膜测低声级，小膜测高声级](/images/microphone-basics/fig8.png)

*（图源：网络官方公开资料）*

- **1 英寸**：灵敏度约 50 mV/Pa，下限低至 0 dB（20 μPa）量级、上限约 140 dB。本底热噪声（CTN，cartridge thermal noise）最低，适合"听最安静的东西"——比如验证一台待机手机是否有可闻的电子嗡声。
- **1/2 英寸**：灵敏度 50~12.5 mV/Pa，范围约 15~160 dB，覆盖 20 Hz~20 kHz 全人耳频段，是车内、机舱等常规 NVH 测量的主力尺寸。
- **1/4 英寸**：灵敏度降到 4~0.25 mV/Pa，但上限可到 187 dB、频率上限更高，喷流、爆炸、排气近场等极端场合专用。

为什么大膜反而测不了大声级？回到第二节那条链条：输出电压正比于间距相对变化，大膜灵敏（单位声压输出电压高），声级稍大输出就顶到前放的电压余量；小膜"迟钝"，同样的前放就能容忍大得多的声压。为什么小膜频率上限高？波长与麦克风尺寸相当时的扰动效应（第五节）来得更晚——10 kHz 声波长约 34 mm，对 1/4 英寸（约 6 mm）的外壳来说仍是"大波遇小物"，绕射修正小。灵敏度与热噪声的账也同源：膜大面积收集更多声压能量，等效噪声地板更低。一张三角表：灵敏度、量级上限、频率上限，尺寸就是那个同时拨动三个指针的旋钮。

## 七、特殊类型：表面、探管、声强与 MEMS

标准胶囊之外，四类特种麦克风覆盖常规构型够不着的工况。**表面麦克风（surface microphone）**齐平安装、整体高度 10 mm 上下，用于空间受限或要求不扰动流场的场合——声学风洞里贴壁测脉动压力就是典型；**探管麦克风（probe microphone）**把胶囊与前放封在护套里、以针状探管伸入测点，抗粉尘油污、耐高温（可到 800 ℃），探针细到可伸进小腔与管内，排气噪声测量常用；**声强麦克风（intensity microphone）**是相位严格配对的一对麦克风加定距隔撑，声强既看幅值也看方向，方向信息靠两麦之间的声压差反推，因此相位匹配是生命线；**MEMS 麦克风**是硅片上的微型固态器件，原理与电容式同宗（硅背板+微振膜），功耗低、体积小到可布成阵列，但无法按传统方式标定，定位在声源定位等定性任务，而非 ISO 声功率这类定量测量。

## 八、标定：每天一查，每年一检

麦克风是整条声学测量链的起点，它的灵敏度漂移直接乘进所有结果。工程惯例分两级：

- **每日检查**：温湿度与大气压天天变，振膜又极敏感，试验前后各做一次单频检查。手持声级校准器（Class 1 或更好）向耦合腔内播放 1 kHz、94 dB（1 Pa RMS）标准音，读出此刻的灵敏度。
- **年度检定**：送回厂家在受控条件下扫全频段，确认频响仍然平直——平直性是工程麦克风的立身之本，必须整条曲线查，不能只查 1 kHz 一个点。

这个公式回答的问题是：**校准器给足 1 Pa 标准声压后，这支麦克风的灵敏度是多少？** 其中 $U_{\mathrm{rms}}$ 是实测输出电压有效值、$p_{\mathrm{rms}}$ 是校准声压 1 Pa——灵敏度就是"每帕输出多少毫伏"：

$$
S = \frac{U_{\mathrm{rms}}}{p_{\mathrm{rms}}} \quad \left[\mathrm{mV/Pa}\right]
$$

注意峰与有效值的换算：示波器窗口读到的常是峰值，比如 63.6 mV 峰，乘 0.707 得 45 mV RMS，除以 1 Pa RMS 得灵敏度 45 mV/Pa。在 Testlab 中校准不必手算——在线校准功能读取校准器音并自动写入灵敏度；支持 TEDS（传感器电子数据表）的麦克风更把灵敏度、序列号、校准日期存在芯片里，一读即得。但 TEDS 不是免检金牌：芯片里的值不随环境更新，读数正常也不代表链路完好，按规程做实物校准永远是每日开工的第一件事——它同时验证了麦克风、线缆、调理与采集的整条链路。

## 九、保养纪律与 Testlab 落点

振膜是几微米厚的绷紧薄膜，测量精度与机械脆弱性同源。保养的"要"与"不要"各四条：要存放于洁净干燥处、胶囊与前放只用手拧紧、绝不触碰振膜、保护栅网常罩不摘；不要留在试验间等脏环境、不要跌落、不要用车间压缩空气吹、不要用钳子上紧。胶囊与前放的连接螺纹用钳子"加固"一次，可能就毁掉一支 capsules——力矩失控会让栅网变形压迫振膜。

在 Simcenter Testlab / SCADAS 里配一支麦克风的关键落点：

1. **通道设置（Channel Setup）**：预极化（IEPE/ICP/CCP）麦克风 Input Mode 选 ICP，Measured Quantity 选 Pressure，灵敏度填入当日校准值（mV/Pa）
2. **外极化麦克风**：经 Tools → Channel Setup Visibility 勾出 "Polarization" 与 "Power Supply" 字段，分别设 200 V 与 28 V（VM8 卡）
3. **频响补偿**：对高频段残余偏差启用 frequency dependent calibration，按出厂频响表逐频段修正
4. **TEDS**：支持 TEDS 的麦克风插上即读出灵敏度与身份信息，仍建议每日实物校准做端到端确认
5. **校准**：Testlab 在线校准功能配合 1 kHz/94 dB 声级校准器，自动更新通道灵敏度

## 十、小结

- 电容麦克风三件套：胶囊（振膜+背板换能）、前放（阻抗变换+放大）、接头（BNC/SMB/LEMO，对应不同供电协议）
- 换能链条"声压→间距→电容→电压"每步均为比例关系，小信号下二次谐波仅万分之几，线性是电容式成为计量主流的物理根基
- 外极化（200 V，7 芯 LEMO）胜在高温稳定与量级上限；预极化（驻极体，BNC 两芯）胜在布线简、成本低、与 IEPE 加速度计同调理——声振混测优先
- 工程麦克风频响平直，A 计权只允许叠加在平直数据上；录音棚话筒的起伏是"好听"不是"准确"
- 场型三选：自由场正对声源、扩散场用于混响环境、压力型齐平安装；尺寸三角：1" 测安静、1/2" 全能主力、1/4" 扛极端声级与高频
- 标定两级：每日 1 kHz/94 dB 单频检查 + 年度全频段检定；TEDS 便利但不免检

## 一句话记住

麦克风是一张带电的鼓皮：驻极体把电"冻"在背板上省掉 200 V，平直频响是诚实记账的前提，场型与振膜尺寸分别决定"在哪测得准"和"能测多低多高多响"——每天用 94 dB 校一下，这张鼓皮才靠得住。
