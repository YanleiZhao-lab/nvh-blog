# 声学测量表面：包络面选择与测点布置

> 同一台空压机，第一次测出声功率 92 dB，复测 95 dB——传声器、工况、场地都没换，只是第二次把测量面从 1 m 加大到 2 m、测点从 10 个减到 6 个。数字差 3 dB，哪个算数？答案往往不在仪器上，而在那个看不见的"袋子"上：声学测量从不把传声器贴在被测物上，而是把声源整个装进一个假想的封闭面里，沿面取数、按面积分。袋子的大小、形状、开孔疏密，直接决定结果算不算数。本文按 Simcenter Testing 理论手册 5.3 节的脉络，讲清测量面怎么选、结点怎么布、ISO 三个标准各对应哪种面，以及"点数够不够"的可量化判据。

一台齿轮箱要做出厂声功率验收，两位工程师各自拉了一版测点方案：一位按 ISO 3744 摆了 9 点的矩形六面体网格，离机子 1 m；另一位图省事，用半径 2 m 的半球摆了 10 点。两版方案测出的声功率级差了近 2 dB，供应商和主机厂各执一词。两版方案用的仪器、场地、工况完全一致，分歧只有一个来源：**测量面与测点布置本身**。声学测量和振动测量的根本不同在此：振动传感器贴在结构上，测的是"那一点"的响应；声学测量必须与被测物保持距离，测的是"包络一圈"后的积分量。面怎么选、点怎么布，不是操作细节，而是测量定义的一部分——ISO 把它写进了标准正文。

## 一、为什么声学测量需要"一个面"而不是"一个点"

先打一个贯穿全文的比方：**测声功率像给一条河流测算总流量**。你站在河边某处用流速仪测一个数，那是"声压"——依赖你站的位置、离岸的距离；要报"这条河到底有多少水"，必须在整条河的断面上布若干条测线，把各测线的流速乘以各自分管的过流面积再求和——那个你假想出来、横跨河道的断面，就是"测量表面"。断面选在哪、测线布几条，直接决定总流量算得准不准：断面离水坝太近，流速分布还没稳定（相当于离声源太近，近场起伏大）；测线太稀，主流道从缝里漏掉（相当于测点太疏，漏掉指向性波瓣）；把断面选在支流汇入口下游，别的河的水也算进来了（相当于旁侧干扰声源被包进面里）。后文每一个结论——面离声源多远、三种面型怎么挑、点数怎么验——都可以回到这条河上来对照。

道理回到物理量上。声功率（Sound Power，W）是声源单位时间辐射的总声能，是声源的固有属性；但没有任何仪器能直接测"总声能"，能测的只有声压（标量，Pa）或声强（向量，W/m²，可由双传声器互谱求出）。**把"一圈点上的局部量"换算成"声源的总功率"，中间的桥梁就是测量表面**：总功率等于声强向量沿闭合面的面积分（法向分量乘以各自分块的面积，再对全表面积累）。手册据此给出两条路线，各自的"面"承担不同角色：

- **声压路线**：在规定形状的测量面上布若干传声器，测各点声压级，能量平均后按标准公式换算声功率（ISO 3744/3745）。面在这里是**换算的载体**——公式的形状修正项直接由面的面积决定。
- **声强路线**：把声强探头沿测量面逐点（ISO 9614-1 离散点法）或连续扫描（ISO 9614-2 扫描法），法向声强乘分块面积求和。面在这里是**积分的区间**——包得不严、点布得不匀，积分就漏。

两条路线对面有共同的要求：面必须封闭地包住声源、与声源保持规定距离、法向明确。手册 5.3 节开头一句话点题：测量点称为**结点（node）**，分布在假想的封闭测量面上，测量与结点的有机集合称为**测量网格（measurement grid）**——声学测量布置的产出物，不是一份通道清单，而是一张网格。

## 二、面型怎么选：六面体、圆柱还是球

手册给出三种可选面型：**平行六面体（矩形箱面）、圆柱面、球面**。选择的第一依据是声源自身的形状与辐射指向性，第二依据是使用的标准。判别逻辑很直白：面与声源各部分的距离越均匀，各结点上采到的声压级分布越集中，能量平均的代表性越好。因此：

- **箱式机组、电气柜、制冷机组**——本身近似长方体，选**平行六面体**面：取包住声源的最小矩形箱（参考表面），再向外偏置规定距离（常见 1 m）得到测量面，结点分布在箱的五个面（落地机组不含底面）上。ISO 3744 的工程法默认这种面。
- **轴对称设备、风扇管道、圆柱形罐体**——选**圆柱面**，结点沿周向与高度两个方向布。
- **尺寸紧凑、接近点源的设备（小家电、电动工具）**——选（半）**球面**，在消声室或半消声室精密法（ISO 3745）里典型：以声源中心为球心、规定半径的球面（地面反射时为半球），结点按标准规定的方位坐标布点。

![固定传声器阵列的声压法声功率测量](/images/acoustic-measurement-surface/fig1_iso_mic_array.png)

*声压法：传声器按固定阵列布置在被测物周围，测量面为规定的（半）球面或六面体（图源：Siemens Simcenter Testing Knowledge Base）*

手册强调一个容易被忽略的细节：**结点取向**。通常采用笛卡儿坐标系，把测量坐标系的 +z 方向规定为测量方向。这不是文档洁癖——声强探头的双传声器有前后之分，法向声强的正负号（声能流出为正、流入为负）全靠取向定义；取向一乱，后面 F3 局部负功率指数里"正负声强对消"的判断就失去意义。

### 测量面到声源的距离由什么定

面不是越近越好。手册在声场指数一节给出了可量化的约束：测量面离声源越近，面上声压—声强指数 $F_2$ 越小（声场越接近自由场、法向声强越"实"），对声强法越有利；但离得太近又撞上另一条红线——探头动态性能指数 $L_d$ 必须大于 $F_2$（ISO 9614-1 准则一：$L_d - F_2 > 0$），不满足时的整改措施恰恰是**缩短测量面到声源的距离**。反过来，离得太远，面外旁侧声源（旁边的风机、管路）的影响权重上升，$F_3$ 与 $F_2$ 之差超过 3 dB 时标准判定存在强定向外界声源，需要缩距、隔离或加吸声处理。距离就是在"近一点保法向声强"与"别把邻居包进来"之间取平衡，而两条判据把平衡点变成了可计算的数。

## 三、点数够不够：一个可计算的判据

"10 个点够吗？"——多数争论止于经验。ISO 9614-1 把它变成算术：**测点数 N 必须满足 $N > C \cdot F_4^2$**（准则二），其中 $F_4$ 是不均匀指数——面上各结点法向声强的统计标准偏差与平均法向声强之比（无量纲），直接度量声强沿面分布的空间起伏；$C$ 是与精度等级和分析频带有关的因子，由标准表格选取。

$$F_4 = \frac{1}{\bar{I}_n}\sqrt{\frac{1}{N-1}\sum_{i=1}^{N}\left(I_{ni} - \bar{I}_n\right)^2}$$

这个公式回答的问题是：面上的声强到底有多"不均匀"？其中 $I_{ni}$ 是第 i 个面分块的法向声强，$\bar{I}_n$ 是全部 N 个分块的平均法向声强。它就是统计学里的变异系数（标准差除以均值）：自由场里的全向声源沿球面分布均匀，$F_4$ 接近 0；指向性强或旁侧声源干扰时起伏加大，$F_4$ 抬升。$F_4$ 以平方进入点数判据——**起伏翻倍、点数翻四倍**，这是"先整声场、再补测点"的数学根据。$C$ 则是"每个点能扛多少起伏"的折算系数，精度要求越高（精密级 1 级/工程级 2 级/观察级 3 级）、频带越宽，$C$ 越大。为计算 $F_4$ 只需测量声强，是四项指数里数据要求最省的一项。

$$F_2 = L_p - L_{I_n}$$

这个公式回答的问题是：面上"测到的声压"比"真正穿面流出的声强"大多少？其中 $L_p$ 是全部结点声压级的能量平均级，$L_{I_n}$ 是全部结点法向声强绝对值的平均级。自由场单一声源时两者相等（$F_2=0$）；混响场或斜入射时声压依旧而法向声强缩水，$F_2$ 为正。手册特别提醒：若 $L_p$ 与 $L_{I_n}$ 相差很大，要么探头没对正声源，要么探头工作在扩散场里。

手册表 5-3 给出 C 因子取值（见下图）：行按频带分组（同一行左列为倍频程带、右列为 1/3 倍频程带的中心频率范围），列按精度等级（精密级 1 级/工程级 2 级/观察级 3 级）。

![表 5-3 不同精度要求下测量网格 C 因子的取值](/images/acoustic-measurement-surface/fig5_table_C_factor.png)

*测量网格充分性判据 N > C·F4² 中的 C 因子：按频带与精度等级三档选取（图源：Simcenter Testing Knowledge Base 中文理论手册 表5-3）*

用一组典型数算一遍（工程级 2 级，倍频程带）：63~125 Hz 带 C=19、250~500 Hz 带 C=9、1~4 kHz 带 C=57、6.3 kHz 带 C=19、A 计权总值 C=8。某机组 A 计权实测 $F_4 = 0.3$（分布较均匀），则 $N > 8 \times 0.09 \approx 1$，少点即满足；长侧面有辅助风机运转时 $F_4$ 升到 1.2，$N > 8 \times 1.44 \approx 12$ 点；换到 1~4 kHz 带（C=57）且 $F_4 = 1$ 时需 $N > 57$ 点。**同一个 C，$F_4$ 从 0.5 恶化到 1.0，所需点数翻四倍**——点数对声场质量的敏感度是平方关系，这正是"先把场地和距离整好，再谈加点"的数学理由。同一网格用于多个频带测量时，以 $C \cdot F_4^2$ 的最大值作为评价准则（取最苛刻频带的点数）。

$$L_d = \delta_{pIo} - \chi\ (\mathrm{dB})$$

这个公式回答的问题是：这套探头在当前相位精度下，最多能"看穿"多大的压强—声强差？其中 $\delta_{pIo}$ 是残余声压—声强指数（由探头残余相位标定得出），$\chi$ 是偏差因子（按精度等级从表 5-1 选取）。$L_d$ 是探头的工作范围上限，准则一 $L_d - F_2 > 0$ 即"任务难度不得超出装备能力"。

![声强法声功率测量](/images/acoustic-measurement-surface/fig3_intensity_scan.png)

*声强法：背景噪声对声强的稳态贡献为零，可在现场其他设备运转时测量（图源：Siemens Simcenter Testing Knowledge Base）*

声强法还有一条声压法没有的保险：**局部负功率指数 $F_3$**，它计及声强方向（带符号），等于面平均声压级与带符号法向声强级之差。若某分块声强为负——能量在往面里流——说明那里的读数是旁侧声源贡献的，对总功率是"负贡献"。手册明确：若带符号求和结果整体为负，说明无关声源影响实在太大，测量不满足 ISO 标准要求。回到开头的河流类比：$F_3$ 抓的是"支流倒灌"——断面某几条测线的流速是负的（往上游流），此时总流量怎么算都是错的，必须先修断面位置。

## 四、numpy 演示：点数与面积分的误差

把测量面简化为一个圆（圆柱面的一条周线，或球面的一条纬圈），真实的法向声强沿周向有起伏（模拟指向性），看采样点数对积分（周向求和）误差的影响：

```python
import numpy as np

# 假想一台有指向性的设备：法向声强沿周向 theta 分布
theta = np.linspace(0, 2*np.pi, 100001)
I_true = 1.0 + 0.8*np.cos(theta) + 0.3*np.sin(3*theta)   # 有主瓣有旁瓣
mean_true = I_true.mean()                                 # 积分真值（周向平均）

rng = np.random.default_rng(0)
for N in (4, 8, 12, 20):
    errs = []
    for _ in range(2000):                                 # 蒙特卡洛：随机布点 2000 次
        th = rng.uniform(0, 2*np.pi, N)
        In = 1.0 + 0.8*np.cos(th) + 0.3*np.sin(3*th)
        errs.append(abs(In.mean() - mean_true)/mean_true)
    print(f"N={N:3d} 点  平均误差 {np.mean(errs)*100:5.1f}%   95分位 {np.percentile(errs,95)*100:5.1f}%")
```

实跑输出：N=4 时平均误差 24.2%（95 分位 58.0%），N=8 降至 17.0%/41.1%，N=12 为 13.9%/34.7%，N=20 为 11.2%/26.6%。两个工程结论：其一，误差随点数下降的速度比直觉慢——随机布点下正比于 $1/\sqrt N$，点数翻四倍误差才减半（N=4→16，24.2% 才降到 12% 附近）；其二，起伏幅度越大同样点数的误差越大。上例声场本身的 $F_4$（标准差/均值）约 0.60，代入准则二（A 计权 C=8）得 $N > 8 \times 0.36 \approx 3$——注意这是对**系统化标准网格**的最低要求，而随机布点的 95 分位误差在 N=4 时仍高达 58%：**同样点数下布点方位的设计与点数本身同等重要**。ISO 标准网格用固定方位坐标（等距布点）正是为了避开最坏相位组合，把积分误差压到同点数随机布点之下；准则二约束点数下限，不豁免网格设计——点数买不回声场质量，网格设计也买不回点数，两者都要过检。

## 五、三个 ISO 标准对应的三个现场

手册 5.3 节列出的标准各管一种现场，选择逻辑按"环境控制程度"从高到低排：

| 标准 | 方法 | 环境 | 精度定位 |
| --- | --- | --- | --- |
| ISO 3745 | 声压法 | 消声室/半消声室 | 精密法 |
| ISO 3744 | 声压法 | 有一反射面的（半）自由场 | 工程法 |
| ISO 9614-1 | 声强法·离散点 | 任意声场（含现场） | 工程法/精密法 |
| ISO 9614-2 | 声强法·扫描 | 任意声场（含现场） | 工程法 |

参考表面规定为**包围声源的最小矩形箱表面**，测量网格的维数（测点数）与参考表面的特征尺寸挂钩——箱子越大越扁，需要的测点越多，ISO 3744 附录给出按尺寸查测点数与坐标的完整表格。

声压路线对环境挑剔（认证试验通常在声学房间内做固定阵列，见上图），声强路线换来现场自由：稳态背景噪声不贡献净声强，可以在其他设备运转的车间里测单台机器。代价是每点要同时采声压与声压梯度（双传声器探头），且要过 F1（瞬变）、F2、F3、F4（不均匀）四道指数检查——手册 5.5 节的声场指数体系，本质上是给"这张网格测出的数敢不敢用"开出的体检单。

在 Simcenter Testlab 中，这一整套流程落在 Sound Power Testing（声功率测试）系列功能里：按 ISO 3744/3745 建标准网格（半球、六面体模板与测点坐标自动生成）、按 ISO 9614-1/2 做声强网格与扫描；声场指数 F1–F4 与准则检查在分析结果中逐项给出，不满足时会直接标红提示整改方向（缩距、隔离、加点）。

## 六、小结

声学测量的测量面不是一个容器概念，而是换算公式的组成部分：面积进公式（声压法）、积分靠它闭合（声强法）、点数由面上的不均匀指数决定（准则二）、可信度由四道声场指数体检（F1–F4 与两条准则）。开头的 2 dB 分歧，按这套框架复盘就能定位：六面体 1 m 面离声源近、面积小，各点声压分布集中；2 m 半球面积大，旁侧反射计入更多，两种面不在同一修正体系里，本就不该直接对数——**换面即换定义，报声功率必须连测量面一起报**。

## 一句话记住

测声功率先搭面：面型贴形状、距离保 F2 小于探头 Ld、点数按 N > C·F4² 核算、可信度过 F1–F4 体检——测量面是定义的一部分，换面即换定义，报数必须连面一起报。
