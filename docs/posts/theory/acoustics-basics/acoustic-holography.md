# 声全息：用空间傅里叶变换定位噪声源

> 变速箱台架声功率测试达标，客户仍投诉啸叫——问题不在总量，而在具体是哪个面、哪块区域在辐射。声强扫描能给出能量流分布，但分辨率受探头间距与波长限制，量级约为一个波长。声全息（Acoustic Holography）提供了另一条路径：在靠近声源的平面上测量复声压（幅值+相位），用空间傅里叶变换把声场分解为平面波分量，再反演得到任意平行平面上的声压、质点速度与声强分布。本文从波数定义与色散关系出发，说明扩散波与损耗波的分野、损耗波对亚波长分辨率的贡献及其代价，并给出维纳滤波 $S/N$ 参数的选择依据。

## 一、噪声源定位的困境：声强测的是"到达"，不是"来源"

动力总成半消声室内的常见场景：变速箱后端面附近啸叫明显，声强扫描完成后，等值线图显示该区域声强级最高。但装车后确认，贡献最大的其实是离合器壳体一角——常规声强测量给出的是测点当地的能量流密度，探头间距通常为 12～50 mm，物理分辨率大致被限制在与波长同量级。1 kHz 声波波长 343 mm，要分辨 100 mm 量级的两个辐射区，声强法难以胜任。

声全息给出的是另一套信息：不只是测量平面上的分布，而是**测量平面之外（近场和远场）任意平行平面上的声学量分布**，空间分辨率高于一般声腔测量。典型产出有三项：

- 各平行平面上的声压、质点速度、声强彩色分布图
- 被测物体辐射的声功率与声谱评估
- 多个声源之间的贡献量分析——某个源关掉后总量下降多少

::: info 核心概念
- **复声压（Complex Pressure）**：含幅值与相位的声压频谱分量。声全息的原始数据不是 RMS 声压级，而是每个测点、每个频率线上的复数声压。
- **互功率谱（Cross Spectrum）**：参考传声器与阵列各传声器之间的互谱，是提取复声压相位的载体，也是稳态过程与瞬态过程声全息的共同基础。
- **测量前提**：自由场环境，测量面充分靠近声源——这两条是方法成立的必要条件，后文展开。
:::

## 二、从时域到空间域：波数与空间傅里叶变换

时域分析中，传感器位置固定，声压 $p(t)$ 随时间变化，傅里叶变换把它分解成不同角频率 $\omega$ 的分量：

$$F(\omega) = \int_{-\infty}^{+\infty} f(t)\, e^{-j\omega t}\, dt$$

声全息把同一套变换推广到空间域：固定一个分析频率，考察声压随**位置**的变化。此时"频率"的角色由**波数（wavenumber）$k_0$** 承担，其定义从波长出发：

$$k_0 = \frac{\omega}{c} = \frac{2\pi f}{c} = \frac{2\pi}{\lambda}$$

物理意义：$k_0$ 是声波在空间中每米转过的相位角，单位 rad/m。$f$ 固定时波长 $\lambda$ 固定，于是"声压作为空间坐标的函数"——手册中称为给定频率的**声压映象（pressure image）**——是一个确定的空间图案。

| | 时域分析 | 空间域分析（声全息） |
| --- | --- | --- |
| **自变量** | 时间 $t$（s） | 空间坐标 $x, y$（m） |
| **变换** | FFT：$t \to \omega$ | 二维空间 FFT：$(x,y) \to (k_x, k_y)$ |
| **频率轴** | 角频率 $\omega$（rad/s） | 波数 $k_x, k_y$（rad/m） |
| **采样** | 采样率 $f_s$，$\Delta t = 1/f_s$ | 阵列传声器间距 $\Delta$ |
| **混叠条件** | $f > f_s/2$ 混叠 | 空间周期 $< 2\Delta$ 空间混叠 |
| **变换对象** | 时域波形 | 单一频率的复声压映象 |

对测量平面上的声压映象 $p(x,y)$ 做二维傅里叶变换：

$$S(k_x, k_y) = \iint p(x, y)\, e^{-j(k_x x + k_y y)}\, dx\, dy$$

得到的 $S(k_x,k_y)$ 是二维全息压力场在波数域的表述。这一步的物理意义：**空间傅里叶变换就是把测到的压力场分解成一组空间正弦函数之和**，而每个空间正弦函数，恰好是某一列平面波的波阵面被测量平面剖切出来的结果——正弦函数的波节与平面波波阵面一一对应。于是"分解为正弦函数之和"等价于"分解为平面波之和"，这是整个方法的核心一步。

![波数向量在测量平面上的投影](/images/acoustic-holography/k-vector.png)

*（图源：Simcenter Testing Knowledge Base）*

一个频率确定的声波可以朝多个方向传播，所以波数向量 $\vec{k}$ 有多个分量。声全息要做的，就是从测量平面上的二维分量 $k_x, k_y$ 出发，恢复完整的传播方向信息。

## 三、扩散波与损耗波：近场里被指数衰减的细节

平面波 $p = P\,e^{-j(k_x x + k_y y + k_z z)}$ 必须满足亥姆霍兹方程 $\nabla^2 p + k_0^2 p = 0$。把平面波表达式代入，每个方向的二阶偏导各贡献一个负的波数平方项：

$$\frac{\partial^2 p}{\partial x^2} = -k_x^2 p, \quad \frac{\partial^2 p}{\partial y^2} = -k_y^2 p, \quad \frac{\partial^2 p}{\partial z^2} = -k_z^2 p$$

三项相加代回亥姆霍兹方程，得到**色散关系（dispersion relation）**：

$$k_0^2 = k_x^2 + k_y^2 + k_z^2 \quad\Longrightarrow\quad k_z = \sqrt{k_0^2 - k_x^2 - k_y^2}$$

物理意义：总波数 $k_0$ 由频率决定，不可更改；测量平面上的空间频率 $k_x, k_y$ 越大（空间周期越短），留给法向的 $k_z$ 就越少。由此区分出两类性质不同的波：

![扩散波与损耗波](/images/acoustic-holography/waves-two-types.png)

*（图源：Simcenter Testing Knowledge Base）*

**情形一：$k_x^2 + k_y^2 < k_0^2$**，$k_z$ 是实数，波沿法向正常传播——这就是**扩散波（propagating wave）**，把能量从近场输运到远场的部分。

**情形二：$k_x^2 + k_y^2 > k_0^2$**，根号内为负，$k_z$ 为纯虚数。在 $\pm j$ 两个虚根中取 $k_z = -j\,|k_z|$（其中 $|k_z| = \sqrt{k_x^2 + k_y^2 - k_0^2}$）——这是幅值沿 $+z$ 方向（远离声源）衰减的物理分支。代入传播因子：

$$e^{-j k_z z} = e^{-j(-j|k_z|)\,z} = e^{-|k_z|\,z}$$

相位项消失，只剩指数衰减——这就是**损耗波（evanescent wave）**，它表征声源近场的复数声场，不向外辐射能量。

为什么空间周期比波长还短的正弦成分只能是损耗波？因为对扩散波而言，无论入射角多陡，波阵面投影到测量平面上的空间周期必定**大于**波长 $\lambda$——斜入射只会把投影拉长，不会缩短。所以空间周期短于 $\lambda$ 的成分，物理上只能来自损耗波。

| | **扩散波** | **损耗波** |
| --- | --- | --- |
| **波数域位置** | "辐射圆"内：$k_x^2+k_y^2 < (\omega/c)^2$ | "辐射圆"外：$k_x^2+k_y^2 > (\omega/c)^2$ |
| **$k_z$** | 实数 | 纯虚数（$-j\|k_z\|$） |
| **空间传播行为** | 正常传播，携带能量到远场 | $e^{-\|k_z\| z}$ 指数衰减，只在近场存在 |
| **携带的信息** | 声源的位置与强度（受波长限制的分辨率） | 亚波长尺度的源细节 |
| **对分辨率的意义** | 分辨率量级 $\approx \lambda$，与声强测量相当 | 突破波长限制的唯一通道 |

![波数域中以 ω/c 为半径的辐射圆](/images/acoustic-holography/radiation-circle.png)

*（图源：Simcenter Testing Knowledge Base）*

在波数域里画一个以 $\omega/c$ 为半径的圆——**辐射圆**。圆内是扩散波，圆外是损耗波。这张图概括了声全息的分辨率来源：圆外的损耗波成分在测量面上仍携带源表面的细微结构，前提是测量面与声源的距离足够小。

```python
import numpy as np

c = 343.0                 # 声速 m/s
f = 1000.0                # 分析频率 Hz
k0 = 2*np.pi*f/c          # 总波数 rad/m
lam = c/f                 # 波长

print(f"f = {f:.0f} Hz, 波长 = {lam:.3f} m, k0 = {k0:.1f} rad/m")
for s in [0.50, 0.343, 0.20, 0.10]:      # 声压映象上的空间周期 m
    kx = 2*np.pi/s
    kz2 = k0**2 - kx**2
    if kz2 >= 0:                          # 辐射圆内：扩散波
        print(f"空间周期 {s:.3f} m -> 扩散波, kz = {np.sqrt(kz2):5.1f} rad/m")
    else:                                 # 辐射圆外：损耗波
        kz = np.sqrt(-kz2)
        print(f"空间周期 {s:.3f} m -> 损耗波, 5 cm 外幅值剩 {np.exp(-kz*0.05):.3f}")
```

运行结果要点：空间周期 0.343 m 恰好等于波长时 $k_z=0$（波贴着测量平面掠射），这是辐射圆的边界；周期缩到 0.10 m——只有三分之一波长——的损耗波传播 5 cm 后幅值只剩约 5%。

::: warning 空间混叠
阵列间距 $\Delta$ 就是空间采样间隔。要无混叠捕捉最高分析频率 $f_{max}$ 的扩散波，需要 $\Delta \le \lambda_{min}/2 = c/(2 f_{max})$：间距 50 mm 的阵列，无混叠上限约 3430 Hz。若还要利用损耗波中的亚波长细节，间距需按目标细节尺度的一半进一步收紧——这也是声全息阵列通常配置数十至上百个通道的原因。
:::

## 四、反演传播：向源传播是放大，离源传播是模糊

知道了每个 $(k_x,k_y)$ 分量怎么传播，就能反演到任何平行平面。手册给出的工具是带 Dirichlet 边界条件的瑞利（Rayleigh）积分：

$$p(\vec r) = \iint G_d(\vec r, \vec r\,')\, p(\vec r\,')\, dx\, dy$$

其中格林函数 $G_d$ 起传递函数的作用，把声场从一个平面搬运到另一个平面，其实际计算式核心是波数域的传播因子 $g_d = e^{-j k_z (z - z')}$：$k_z$ 由色散关系给出，$z'$ 是测量平面位置、$z$ 是目标平面位置。

这里出现了声全息最关键的不对称性。**向远离声源方向传播**（预测远场）：损耗波 $e^{-|k_z|\Delta z}$ 迅速衰减到零，等于自动被滤除，图像越来越模糊——远场图里只剩扩散波。**向声源方向反演**：传播因子变成 $e^{+|k_z|\Delta z}$，是放大。损耗波的空间周期越短、$|k_z|$ 越大，放大越剧烈。这一放大具有两面性：

- 收益：源表面上那些亚波长细节在测量面上虽已被指数衰减到很小，反演时按衰减规律补回，**空间分辨率因此突破波长限制**——这是损耗波对声全息独有的贡献；
- 代价：信号被放大的同时，测量噪声、相位误差也被同倍率放大。离源越远反演，误差放大越严重，到某一处"传播的只是一些杂音"（手册原文），图像完全失真。

```python
import numpy as np

c, f = 343.0, 1000.0
k0 = 2*np.pi*f/c

# 同一个源面细节（空间周期 s），测量面离源不同距离时还剩多少幅值
for s in [0.30, 0.20, 0.15]:
    kz = np.sqrt((2*np.pi/s)**2 - k0**2)     # 损耗波衰减系数
    line = f"细节尺度 {s:.2f} m:"
    for d in [0.02, 0.05, 0.10]:
        line += f"  距源{int(d*100):>2d}cm 剩{np.exp(-kz*d):.3f}"
    print(line)
```

运行结果要点：0.15 m 的细节（不到半个波长）距源 10 cm 测量时幅值只剩约 2%——再叠加测量噪声，基本淹没。**测量面离源越近，可恢复的细节越多**，这就是"测量面要求充分靠近声源"的定量含义。

控制放大失控的标准手段是**维纳（Wiener）滤波**，其可调参数是信噪比 $S/N$。手册给出的经验界限：

| $S/N$ 取值 | 反演行为 |
| --- | --- |
| **> 15 dB** | 计入过多损耗波，放大量随损耗波数量增多而**不稳定**，图像出现伪影 |
| **≈ 5 dB** | 损耗波虽被计入，但衰减太快，对分辨率**几乎没有改善** |
| **略低于 15 dB** | 分辨率与幅值精度的**最佳折衷** |

::: tip 参数选择
$S/N$ 参数的作用是为反演放大倍率设置上限：设定越高，越多短周期损耗波被全额放大，分辨率提高、幅值可信度下降；设定低则行为保守。默认取略低于 15 dB，除非只关心源的位置形态而不在乎幅值精度——那时可以适当调高。
:::

与时间信号 FFT 的截断误差完全类比，空间截断也会出问题：声压映象在被观察的全息图内必须近似"周期"，否则边缘突变会在二维变换中产生误差，表现为观察面边缘出现声源的**"鬼影"（ghost image）**。对策是给声压映象乘二维窗。手册列了两种：

- **矩形窗**：不作任何修改，计算只计及扩散波，得到的分辨率等同于声强测量；
- **AdHoc 窗**：本质上是一维余弦窗沿 $x$、$y$ 两个方向构成的**二维汉宁窗**——平坦段保持幅值、两端渐缩，用于抑制两个方向变换分析时的突变与鬼影。

## 五、从声压到质点速度与声强：p 与 v 的乘积

声全息的产出不止声压。声学量应视为一定频带内频率分量的积分，而一旦平面波场被完整恢复，**任何平行平面上的声压场都能演算**——前提是所有声源都位于测量平面和演算平面的同一侧，这是反演成立的几何条件。

有了 $p(x,y,z)$，质点速度由声压的空间差分得到，依据是欧拉方程 $\rho_0\,\partial v/\partial t = -\nabla p$。对简谐声场（时间因子 $e^{j\omega t}$），时间求导化为乘 $j\omega$，于是：

$$v = \frac{j}{\omega \rho_0}\, \nabla p$$

物理意义：压力梯度驱动质点加速度，速度幅值与频率成反比——频率越高，同样的压力梯度产生的速度幅值越小。式中 $\rho_0$ 为介质密度（空气约 1.2 kg/m³）。声全息测量/反演过程中，$\vec r$ 与 $\vec r + \delta\vec r$ 两个位置的声压都可得，其差分对应压力梯度，代入上式即得质点速度。声压与质点速度一旦都知道，**时间平均的有功声强立即由二者的乘积求出**：

$$I = \frac{1}{2}\, \mathrm{Re}\{p \cdot v^*\}$$

其中 $p$ 为复声压（Pa），$v$ 为复质点速度（m/s），$v^*$ 为其共轭，$I$ 为声强（W/m²），方向沿能量流方向。

![由声压与质点速度得到声强](/images/acoustic-holography/intensity-pv.png)

*（图源：Simcenter Testing Knowledge Base）*

于是同一组测量数据经过不同平面、不同声学量的反演，直接支撑噪声源定位、贡献量排序和声功率评估。对整车或动力总成这类多源耦合的对象，把反演平面取在壳体表面附近查看声强分布，信息量远高于远场单点声压扫描。

## 六、测量实施：阵列、参考传声器与三类常见问题

测量链路的骨架：一组**参考传感器**固定在声源附近（每条主要谱线附近至少一个参考点），**阵列传声器**在测量平面上扫描或整阵布设，分析的是参考-阵列互功率谱。稳态工况（发动机稳态运行）与瞬态工况（例如 pass-by 类事件）都有对应的互谱处理方式，但复声压相位信息一律来自互谱——这是所有声全息实现的公共基础。

::: warning 工程上的三类常见问题
- **环境不是自由场**：普通车间里地面、墙面的反射会污染互谱相位，反演时被放大成假源。半消声室、或至少在声源与阵列之间维持干净的自由场路径，是数据可用的底线。
- **阵列离源太远**：距离每增加一点，可用的损耗波成分就指数衰减一分。距源半米的阵列无法给出亚波长分辨率，这在物理上不成立。
- **$S/N$ 与窗的联动**：$S/N$ 设置过高会放大噪声产生伪影，同时若不加 AdHoc 窗，边缘鬼影会与伪影叠加，使真实声源的判别变得困难。
:::

::: tip 实用路线
先用矩形窗 + 保守 $S/N$ 出一版稳定结果，确认主要声源区域；再针对感兴趣的频率线逐步收紧窗、提高 $S/N$，观察细节是否稳定复现——随参数变化剧烈的细节多半是噪声放大，不是真实声源。
:::

## 七、小结

判断是否采用声全息，看三条：需要**空间分布**信息而不只是总级；关心的**细节尺度**小于该频段波长，常规声强分辨率不够；具备**近场布阵列**的自由场条件。方法本身的链条很清晰——空间 FFT 把声场拆成平面波，色散关系决定每个波数分量是传播还是衰减，向源反演时损耗波按指数补回、换来分辨率，维纳滤波的 $S/N$（略低于 15 dB 起步）决定补到什么程度收手。阵列间距取 $\lambda_{min}/2$，测量距离按想分辨的细节尺度反推，环境必须自由场。满足这些条件时，声全息反演得到的声场分布才可作为整改依据。
