# 阻抗管法测隔声：驻波管里的传递损失

> 隔声材料样件卡进一根厚壁钢管，扬声器在一端发宽带声，四个传声器分立样件两侧——这就是阻抗管法测传递损失（Transmission Loss, TL）的全部硬件。本文从驻波与平面波假设讲起，推导四传声器传递矩阵法如何用两种负载工况解出二端口矩阵，再落到 TL 的计算式、频率范围边界与 Testlab 实操要点：样件密封、锥形转接修正、两负载法为什么优于两声源法。

## 一、为什么用一根管子测隔声

评价隔声性能的基本量是传递损失，定义为入射声功率与透射声功率之比的对数：

$$
\mathrm{TL} = 10\,\lg\frac{W_i}{W_t} \quad \mathrm{dB}
$$

其中 $W_i$ 为入射到样件的声功率（W），$W_t$ 为穿透样件的声功率（W）。TL 强依赖频率，一条 TL 曲线才能完整描述一个件，单值没有意义。

测 TL 的两大主流方法：**阻抗管法**（impedance tube method）与**双室法**（two-room method）。阻抗管法适合消声器、管道系统、小尺寸材料样件；双室法适合仪表板、车门、前壁板这类大件。两者的核心差别在于声场：阻抗管里声波以平面波形式**垂直入射**（normal incidence）到样件表面，双室法混响室里是**随机入射**（random incidence）——同一材料垂直入射 TL 与随机入射 TL 数值不同，两套数据不能互换。

阻抗管通常是一根厚壁钢管（厚钢壁防止管壁振动透声污染管内声场）。一端接声源，输出宽带声波；被测件装夹在管的**中间**，两侧各布置传声器。声波在管内以平面波传播，直达样件表面。

上图下半部分是管子的剖面：样件装在管中间，入射侧与透射侧各有一段等截面直管。声源端发出的宽带声在管内只剩轴向传播的平面波成分，高阶模式（横向驻波）被管的几何尺寸截止在低频段之外——这正是“驻波管”名称的由来：管内声场本质上是入射波与反射波叠加形成的轴向驻波场。

::: info 核心概念
- **传递损失（Transmission Loss, TL）**：入射声功率与透射声功率之比的分贝值，隔声性能的本征量，与声源无关
- **阻抗管（Impedance Tube）**：厚壁钢管内建立平面波声场、用于测量材料声学参数的装置，又称驻波管
- **平面波假设（Plane Wave Assumption）**：管内声压与质点振速只沿管轴变化，横截面内均匀——一切推导的前提
- **垂直入射（Normal Incidence）**：声波传播方向与样件表面法线重合，区别于混响室中的随机入射
:::

::: warning 工程注意
阻抗管测的是垂直入射条件下的 TL。混响室随机入射 TL 通常比垂直入射 TL 低（斜入射分量在部分角度发生吻合效应与全透射），工程选型若拿垂直入射数据当隔声指标用，会高估现场性能。报告数据必须注明入射条件。
:::

## 二、管内声场：入射波、反射波与驻波

平面波假设下，管中某位置的声压是沿 $+x$ 方向的入射波与沿 $-x$ 方向的反射波之和。设入射波声压幅值 $A$、反射波幅值 $B$，位置 $x$ 处：

$$
p(x) = A\,e^{j(\omega t - kx)} + B\,e^{j(\omega t + kx)}
$$

其中 $\omega$ 为角频率（rad/s），$k = \omega/c$ 为波数（rad/m），$c$ 为声速（m/s）。质点振速由欧拉方程（Euler's equation，牛顿第二定律在流体微元上的形式）给出 $v = -\frac{1}{j\omega\rho}\frac{\partial p}{\partial x}$，对上式两项分别求导：

$$
v(x) = \frac{1}{\rho c}\left(A\,e^{j(\omega t - kx)} - B\,e^{j(\omega t + kx)}\right)
$$

若管末端完全刚性（反射系数 $R = B/A = 1$），两波等幅叠加形成纯驻波：管内出现声压波腹（pressure antinode，$|p|$ 最大、$v$ 为零）与波节（pressure node，$p$ 为零、$|v|$ 最大），相邻波腹波节间距四分之一波长。这就是经典“驻波比法”测吸声系数的物理基础：波腹与波节声压比 $\mathrm{SWR} = (1+|R|)/(1-|R|)$，反射系数模值立刻可得。

四传声器法则更进一步：不测驻波比，而是同时解出入射、反射、透射各分量。以样件为界，把管分为上游（声源侧）与下游（负载侧）两段。上游声压为入射波加反射波；下游声压为透射波加负载反射波。四个已知位置（上游两个、下游两个）的传声器测得复声压（幅值与相位，由互谱得到），每侧两个测点联立即可解出该侧行波幅值。以上游为例，设间距 $s_a$ 的两传声器测得传递函数 $H_{12} = p_2/p_1$：

$$
\frac{B}{A} = \frac{H_{12}\,e^{jks_a} - e^{-jks_a}}{e^{jks_a} - H_{12}\,e^{-jks_a}}
$$

解出 $A$、$B$ 与下游的透射波幅值 $C$ 后，样件表面的入射声功率 $W_i = |A|^2 S/(2\rho c)$、透射声功率 $W_t = |C|^2 S/(2\rho c)$（$S$ 为管截面积），TL 直接得

$$
\mathrm{TL} = 10\,\lg\frac{|A|^2}{|C|^2} = 20\,\lg\left|\frac{A}{C}\right| \quad \mathrm{dB}
$$

注意分子只含入射波、分母只含透射波——反射波 $B$ 与负载反射波都不出现在结果里，这正是 TL“与负载无关、只由样件自身决定”的物理保证，也是它区别于插入损失（insertion loss，依赖整个系统）的根本所在。

## 三、传递矩阵法：四个未知数与两种负载

Simcenter Testlab 采用**四传声器传递矩阵法**（four-microphone transfer matrix method）求解。思路是把被测件看成一个**二端口声学元件**（two-port element）：不管内部结构多复杂——穿孔管、共振腔、吸声棉——对外只表现出两侧的状态量关系。样件上游面（状态 1）与下游面（状态 2）的声压、质点振速由一个 2x2 传递矩阵联系：

$$
\begin{bmatrix} p_1 \\ v_1 \end{bmatrix} =
\begin{bmatrix} T_{11} & T_{12} \\ T_{21} & T_{22} \end{bmatrix}
\begin{bmatrix} p_2 \\ v_2 \end{bmatrix}
$$

$p_1$、$v_1$、$p_2$、$v_2$ 都能由四个传声器测得，未知数是矩阵系数 $T_{11}$、$T_{12}$、$T_{21}$、$T_{22}$——共四个。但一次测量只给出两个方程（声压方程与振速方程各一），四个未知数两个方程，解不动。**必须构造两种不同的负载工况**，得到四个方程解四个未知数。

![传递矩阵法方程组与求解条件](/images/tl-impedance-tube/fig4.png)

*（图源：Simcenter Testing Knowledge Base）*

上图是知识库给出的方程组示意：两组工况下的状态量各自配对，联立求逆即得传递矩阵。该模型把样件内部的声学腔视为集总参数系统（lumped parameter model）处理——频率足够低、样件尺寸远小于波长时，腔内声场可用少数状态量描述。

### 两种负载的典型组合

制造第二种工况有两条路：**两负载法**（two-load method）换末端负载再测一遍；**两声源法**（two-source method）把声源搬到管另一端再测一遍。Simcenter 推荐两负载法，理由很实际：

| 对比项 | **两负载法** | **两声源法** |
| --- | --- | --- |
| 操作内容 | 更换末端管件/负载 | 拆装声源、搬电缆 |
| 耗时 | 快（换一段管即可） | 慢（动声源与接线） |
| 风险 | 移动的是廉价管件 | 移动的是昂贵易损声源 |
| 典型组合 | 刚性末端 + 消声末端 | 声源在 A 端 + 声源在 B 端 |

典型负载组合为**刚性末端**（rigid termination，末端封死，反射系数接近 +1）与**消声末端**（anechoic termination，末端接吸声尖勒或长吸声管，反射近似为零）。两种末端的反射系数差异越大，方程组条件数越好，矩阵解越稳。

### 从传递矩阵到 TL

矩阵解出后，TL 由矩阵系数计算。样件下游接负载阻抗 $Z_L = p_2/v_2$，把 $v_2 = p_2/Z_L$ 代入矩阵方程，整理出入射波与透射波的幅值比，负载阻抗在代数上消去，得到

$$
\mathrm{TL} = 20\,\lg\left|\frac{T_{11} + T_{12}/(\rho c) + \rho c\,T_{21} + T_{22}}{2}\right| \quad \mathrm{dB}
$$

结果表达式中不含 $Z_L$——矩阵是样件自身的属性，TL 与末端条件无关。这也解释了为什么一条 TL 曲线就能代表这个消声器本身，装到什么车上、接什么管路都不改变它。

## 四、测试流程与工程细节

### 样件安装：密封是第一要务

测消声器这类管式件时，第一段管的出口与消声器入口、消声器出口与第二段管的入口，两个接口都必须对接紧密。任何缝隙等于给声波开了旁路，高频段波长只有几厘米，缝就是孔，TL 直接失真。

![工程师检查消声器与阻抗管两端的紧密对接](/images/tl-impedance-tube/fig3.png)

*（图源：Simcenter Testing Knowledge Base）*

材料样件（如隔声毡、多孔棉）的切割同样讲究：样件直径必须与管内径一致——切大了装进去边缘受压、密度改变、吸声性能跟着变；切小了留缝、声波旁通。理想样件与管壁既不压缩也无缝隙。有些阻抗管配专用样件切刀，但切刀切割时会轻微压缩样件边缘，水刀切割（waterjet）的样件精度与一致性更好。

### 直径不一致：锥形转接与修正

被测件进出口直径与阻抗管内径不一致是常态——大消声器接小管径试验台。此时用**锥形转接件**（conical adaptor）过渡，锥段不再是等截面，平面波在锥段内传播规律改变，直接拼数据会引入系统误差。Simcenter Testlab 提供锥度修正（cone correction）功能，把转接件的影响从结果中扣除。

![Simcenter Testlab 锥形修正设置界面](/images/tl-impedance-tube/fig6.png)

*（图源：Simcenter Testing Knowledge Base）*

### 测试与结果

测试流程：声源输出宽带信号，四个传声器同步采集，多次平均压低随机噪声——每侧两个传声器的复声压传递函数 $H_{12}$ 经平均后代入第二节公式解行波幅值。第一种负载测完，换末端，第二种负载复测，联立解矩阵、算 TL。Simcenter Testlab 提供 Single Page Workbook 一页式流程（Sound Transmission Loss Measurement Using Impedance Tube 软件），从采集到出曲线一气呃成。

![Testlab 阻抗管 TL 测试结果：TL-频率曲线](/images/tl-impedance-tube/fig5.png)

*（图源：Simcenter Testing Knowledge Base）*

结果就是一条 TL 随频率变化的曲线（上图）。判读要点：低频段 TL 低（波长长、样件厚度相对薄），随频率上升 TL 总体抬升；出现低谷意味着发生了共振穿透（结构共振或声学共振，如穿孔板空腔共振），这些低谷频段就是该件在实际系统中的“漏音窗口”。

::: tip 实用建议
- 消声器、管路件、小材料样件选阻抗管法；仪表板、车门、前壁板选双室法
- 报告数据注明垂直入射条件，与混响室随机入射数据严格区分
- 两种负载的反射系数差异要大（刚性 + 消声是标准组合），改善方程组条件数
- 接口密封、样件配合、锥度修正三件事做到位，数据才可信
:::

## 五、频率范围的边界：平面波的上限

阻抗管的一切推导都建立在平面波假设上，而管内只传播平面波是有频率上限的。圆形直管中，第一个高阶模式（横向驻波，Bessel 模式）的截止频率为

$$
f_{\mathrm{upper}} \approx 0.586\,\frac{c}{D}
$$

其中 $D$ 为管内径（m）。高于这个频率，横向模式被激发，横截面内声压不再均匀，“一个截面两个状态量”的描述失效，传递矩阵法的前提崩塌。以常温空气 $c = 343\ \mathrm{m/s}$ 计：内径 100 mm 的管上限约 2011 Hz，内径 30 mm 的管上限约 6704 Hz——**管越细，可用频率越高**，所以试验室常配大、小两根管分别覆盖低频段与高频段。

下限则受传声器间距约束：两传声器法解行波幅值依赖 $H_{12}$ 中含 $k s_a$ 的相位信息，当 $k s_a$ 远小于 1（频率低、间距小）时两传声器信号几乎同幅同相，$H_{12}$ 趋近 1，方程病态。工程经验要求两传声器相位差落在约 30 到 160 度区间，间距 50 mm 的传声器对，可靠下限约在 100 到 200 Hz。

| 管内径 | 平面波上限（c=343 m/s） | 适用场景 |
| --- | --- | --- |
| **100 mm** | 约 2011 Hz | 材料样件低中频段 |
| **63 mm** | 约 3189 Hz | 通用管径 |
| **30 mm** | 约 6704 Hz | 高频段材料测试 |

（上限系数 0.586 为圆管首阶横向模式截止频率的经典结果 $1.841\,c/(\pi D)$，源自波动方程在圆形截面上的 Bessel 函数解。）

## 六、Python 演示：从传递矩阵反算 TL

设一个已知传递矩阵的简单声学元件（一段长 $L$ 的直管，其传递矩阵有解析形式：$T_{11} = \cos kL$、$T_{12} = j\rho c \sin kL$、$T_{21} = j\sin kL/(\rho c)$、$T_{22} = \cos kL$），用第三节的 TL 公式反算，验证一段无损直管的 TL 应为 0 dB——声波无损穿过，没有任何衰减。再人为加入损耗（给波数加虚部模拟管壁粘热损失），观察 TL 随频率与损耗的增长。

```python
import numpy as np

c = 343.0        # 声速 m/s
rho = 1.21       # 空气密度 kg/m3
L = 0.30         # 直管长度 m
freqs = [100, 500, 1000, 2000]  # Hz

for f in freqs:
    # 无损情形：波数纯实数
    k = 2*np.pi*f/c
    T11, T22 = np.cos(k*L), np.cos(k*L)
    T12 = 1j*rho*c*np.sin(k*L)
    T21 = 1j*np.sin(k*L)/(rho*c)
    tl0 = 20*np.log10(abs((T11 + T12/(rho*c) + rho*c*T21 + T22)/2))
    # 有损情形：波数加虚部（管壁粘热损耗，幅值示意）
    k = 2*np.pi*f/c*(1 - 0.02j)
    T11, T22 = np.cos(k*L), np.cos(k*L)
    T12 = 1j*rho*c*np.sin(k*L)
    T21 = 1j*np.sin(k*L)/(rho*c)
    tl1 = 20*np.log10(abs((T11 + T12/(rho*c) + rho*c*T21 + T22)/2))
    print(f"f={f:5d} Hz  无损 TL={tl0:6.3f} dB  有损 TL={tl1:6.3f} dB")
```

运行结果要点：无损直管四个频率的 TL 全部为 0.000 dB（浮点误差量级）——公式自洽性验证通过；加入 2% 等效损耗后，100 Hz 处 TL 仍接近 0（波长 3.43 m 远长于管长，损耗来不及积累），2000 Hz 处 TL 升至约 1.9 dB——衰减随频率与长度积累，这正是消声器用长管加吸声材料提高 TL 的原理。

## 七、小结

阻抗管法测 TL 的技术路线：厚壁钢管内建立平面波声场，四个传声器分立样件两侧解出入射与透射行波幅值，两种负载工况联立解出二端口传递矩阵，由矩阵系数算得与负载无关的 TL 曲线。判据与数字：两负载法优于两声源法（换廉价管件不动声源）；典型负载为刚性末端加消声末端；平面波上限约为 0.586c/D，内径 100 mm 管约 2000 Hz、30 mm 管约 6700 Hz，大小管分工覆盖宽频；数据判读盯共振低谷，那是漏音窗口；垂直入射 TL 与随机入射数据不可混用，对外报告必须注明入射条件。
