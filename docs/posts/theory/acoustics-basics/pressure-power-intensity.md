# 声压、声功率、声强：定义、分贝换算与选用判据

> 声学报告里这三个量都以分贝（dB）表示，参考值却各不相同——把声压级当声功率级报出去，是噪声验收中常见的错误之一。本文借助 Simcenter 知识库的暖气类比说明三个量的物理定义，给出分贝定义式与自由场换算关系，以及不同工程场合下选用哪个量的判据。

## 一、暖气类比：三个量的物理图像

把一台噪声源（例如电机）放进安静房间，与把一片暖气放进冷房间，物理过程类似。Simcenter 知识库用暖气类比说明三个量的区别：

- **温度 ↔ 声压**：房间里每个位置都有一个温度值，离暖气越近温度越高。声压（Sound Pressure）$p$ 同样是空间每点一个值，单位帕斯卡（Pa），离声源越近幅值越大。它回答的是"这个位置上声音多大"。
- **暖气功率 ↔ 声功率**：暖气单位时间发出的热量是它的固有属性，房间温度不改变这个数值。声功率（Sound Power）$W$ 是声源单位时间发出的声能量，单位瓦（W），只属于声源本身，与环境无关。
- **热流 ↔ 声强**：热量在房间里有方向地流动。声强（Sound Intensity）$I$ 描述声能量流过单位面积的速率，单位 W/m²，既有大小又有方向——三个量中唯一的矢量。

![暖气类比：温度对应声压、暖气功率对应声功率、热流对应声强](/images/pressure-power-intensity/fig2-heater-analogy.png)

*（图源：Simcenter Testing Knowledge Base）*

::: info 核心概念
- **声压 $p$**：某空间点的压力波动，标量，单位 Pa，随位置和距离变化
- **声功率 $W$**：声源单位时间发出的声能量，声源固有属性，单位 W，与测量位置无关
- **声强 $I$**：声能量流过单位面积的流量，矢量，单位 W/m²，等于声功率除以包裹面积
:::

三个量都可以写成 dB，但分贝本身不是单位，而是测量值与参考值之比的对数，因此参考值必须随物理量区分：

$$L_p = 20\lg\frac{p}{p_0}, \qquad p_0 = 20\ \mu\mathrm{Pa}$$

$$L_W = 10\lg\frac{W}{W_0}, \qquad W_0 = 1\times10^{-12}\ \mathrm{W} = 1\ \mathrm{pW}$$

$$L_I = 10\lg\frac{I}{I_0}, \qquad I_0 = 1\times10^{-12}\ \mathrm{W/m^2}$$

声压级用 $20\lg$，是因为声能量正比于声压的平方，平方提到对数前变成系数 2×10；声功率级和声强级本身就是能量类量，直接用 $10\lg$。三个分贝数值对应的物理量不同，报告中只写"89 dB"而不注明是哪个量的分贝值，容易造成误读。

![三个量各自有独立的参考值，都可以表达为分贝](/images/pressure-power-intensity/fig1-three-db.png)

## 二、工程属性对比

| 属性 | **声压** | **声功率** | **声强** |
| --- | --- | --- | --- |
| **物理含义** | 某点的压力波动 | 声源发出的总能量速率 | 单位面积的能量流 |
| **单位** | Pa | W | W/m² |
| **是否随距离变化** | 是，越远越小 | 否，固有属性 | 是，随包裹面积摊薄 |
| **是否含方向** | 否（标量） | 否（标量） | 是（矢量） |
| **dB 参考值** | 20 µPa | 1×10⁻¹² W | 1×10⁻¹² W/m² |
| **dB 定义式** | $L_p = 20\lg(p/p_0)$ | $L_W = 10\lg(W/W_0)$ | $L_I = 10\lg(I/I_0)$ |
| **测量手段** | 单个麦克风 | 由声压或声强推算 | 双麦克风声强探头等 |
| **典型应用场合** | 车内耳位噪声、通过噪声 | 法规限值、源排序 | 声源定位、隔声量测量 |

::: warning 工程注意
同一台设备，厂商给出"Lw = 73 dB"（声功率级），用户在半米处测到"Lp = 78 dB"（声压级），两个数值都可能正确——物理量不同、测点位置不同，二者不具备直接可比性。验收条款必须写明是声压级还是声功率级；若是声压级，还须写明测点位置和距离。
:::

法规限值多用声功率，原因在于它是设备的固有属性：工程机械、打印机、家电的噪声法规限值几乎都以声功率给出，更换试验场地或测量距离后限值依然成立，对供需双方都公平。

## 三、三个量之间的换算

在特定条件下，三个量可以互相推算。

### 3.1 声压与声强：乘积关系

声强的定义是声压 $p$ 与质点振速（Particle Velocity）$v$ 乘积的时间平均：

$$I = \overline{p(t)\,v(t)}$$

声压是标量、振速是矢量，因此声强是矢量。在自由场（Free Field）远场条件下 $p$ 与 $v$ 同相，上式化为

$$I = \frac{p_{\mathrm{rms}}^2}{\rho c}$$

其中 $\rho c$ 是空气的特性阻抗（Characteristic Impedance），标准大气条件下约 415 Pa·s/m，工程估算常取 400 Pa·s/m。

### 3.2 声强与声功率：面积分关系

用一个封闭面把声源包住，将面上各点的法向声强 $I_n$ 对面积积分，即得声功率：

$$W = \oint_S I_n \, \mathrm{d}S$$

这就是声强法求声功率的原理——不需要消声室，在普通车间即可进行，因为稳态背景噪声穿过封闭面的净流量为零。

反过来，已知声功率也能估算声场。知识库的打印机算例：一台声功率 0.02 W 的打印机，在 2 m 半径的半球面上测量：

- 半球表面积 $S = 2\pi r^2 = 25\ \mathrm{m^2}$
- 声强 $I = W/S = 0.02/25 \approx 8\times10^{-4}\ \mathrm{W/m^2}$
- 声强级 $L_I = 10\lg(8\times10^{-4}/10^{-12}) \approx 89\ \mathrm{dB}$

![已知声功率的打印机在 2 米半球面上测量](/images/pressure-power-intensity/fig4-hemisphere.png)

*（图源：Simcenter Testing Knowledge Base）*

自由场半球辐射条件下，距离从 $r_1$ 变到 $r_2$，声强级的变化量为

$$L_I(r_2) - L_I(r_1) = 10\lg\frac{W/(2\pi r_2^2)}{W/(2\pi r_1^2)} = -20\lg\frac{r_2}{r_1}$$

距离加倍（$r_2 = 2r_1$）时上式等于 $-20\lg 2 \approx -6\ \mathrm{dB}$——这是"距离每翻一倍声压级降 6 dB"的来源，而声功率级 $L_W$ 与距离无关。

```python
import numpy as np

W = 0.02                      # 打印机声功率，W
W0, I0 = 1e-12, 1e-12         # 声功率、声强的参考值
Lw = 10 * np.log10(W / W0)    # 声功率级
print(f"声功率级 Lw = {Lw:.1f} dB（不随距离变化）")

rhoc = 400                    # 空气特性阻抗 Pa·s/m
for r in [1.0, 2.0, 4.0]:     # 半球测量半径
    S = 2 * np.pi * r**2      # 半球表面积
    I = W / S                 # 声强 = 声功率 / 面积
    LI = 10 * np.log10(I / I0)
    p = np.sqrt(I * rhoc)     # 自由场: I = p^2/rhoc
    Lp = 20 * np.log10(p / 20e-6)
    print(f"r={r:.0f} m: 声强级={LI:.1f} dB, 声压级={Lp:.1f} dB, 声压={p*1000:.1f} mPa")
```

输出中两个关键数值：Lw 恒为 103 dB；r 从 1 m 增到 4 m，声压级从 95 dB 降到 83 dB——声功率保持不变，声压随距离每翻一倍降 6 dB。另外每个距离上 LI 与 Lp 数值相等，这不是巧合：参考值的选取恰好让 20 µPa 的声压在 400 Pa·s/m 的空气中对应 1 pW/m² 的声强，即 $I_0 = p_0^2/(\rho c) = (20\times10^{-6})^2/400 = 10^{-12}\ \mathrm{W/m^2}$。

## 四、声强比声压多出的方向信息

同一台电机，用声强图和声压图分别画云图，幅值分布的图案相同，差别在方向：

![电机周围的声强图（左，含矢量箭头）与声压图（右，仅幅值）](/images/pressure-power-intensity/fig3-intensity-vs-pressure.png)

*（图源：Simcenter Testing Knowledge Base）*

声压图只反映"哪里幅值高"，声强图的矢量箭头还反映"声音往哪流、从哪来"。排查电机啸叫时，方向信息可以直接区分噪声来自轴承辐射还是壳体结构辐射。

代价是测量复杂度：声压用一只麦克风即可，声强需要两只（或以上）麦克风按已知间距排列，利用两通道之间的声压梯度计算质点振速，Simcenter Soundbrush 用四面体布置的 4 只麦克风扫查网格。数据量和后处理量相应增加，因此常规监测用声压，溯源和声功率测定用声强。

## 五、选用判据：一个算例

两台辅助水泵并排放进机舱，A 声功率 1×10⁻⁴ W，B 是 A 的两倍，估算 0.5 m 处的声压级变化。多个不相干声源叠加时，声压级按能量相加：

$$L_{p,\Sigma} = 10\lg\left(10^{L_{p,1}/10} + 10^{L_{p,2}/10}\right)$$

```python
import numpy as np

W_A, W_B = 1e-4, 2e-4         # 两台泵的声功率，B 是 A 的两倍
rhoc = 400                    # 空气特性阻抗
r = 0.5                       # 评估点近似半球辐射
p = lambda W: np.sqrt(W / (2*np.pi*r**2) * rhoc)   # 声功率反推声压
LpA = 20*np.log10(p(W_A)/20e-6)
LpB = 20*np.log10(p(W_B)/20e-6)
LpAB = 20*np.log10(np.sqrt(p(W_A)**2 + p(W_B)**2)/20e-6)  # 能量叠加
print(f"单独开 A: {LpA:.1f} dB")
print(f"单独开 B: {LpB:.1f} dB（声功率翻倍，声压级仅升高 3 dB）")
print(f"同时开  : {LpAB:.1f} dB（叠加后仅比 B 高 1.8 dB）")
```

声功率翻倍，声压级升高 $10\lg 2 \approx 3\ \mathrm{dB}$；两台同开，总声压级也比较大的那台再高不到 2 dB——期望通过"更换一台低 3 dB 的泵"显著降低总噪声，通常因能量叠加而达不到预期。这类估算只需要声功率一个数值加一个距离假设，正是声功率作为设备固有属性指标的价值。

::: tip 场合选择
- **车内耳位、驾驶员右耳、通过噪声测点** → 声压级：与法规限值和主观感受直接对应的是这个量，须写明测点位置
- **供应商与主机厂之间的验收、不同场地数据对比** → 声功率级：不受测量环境和距离影响，对双方公平
- **声源定位、隔声量（声传递损失）测定、普通厂房里的声功率测量** → 声强：方向信息不可替代，测量成本为双麦克风以上
:::

## 六、小结

判据有三条：报告中出现 dB，先确认是哪个量的分贝值；评价设备本身（选型、验收、对标）用声功率级；评价人的感受（车内噪声、异响排查）用声压级，并在报告中写明测点距离。需要方向信息、需要在现场环境直接测定声功率时，选用声强。三个量的换算关系——声压乘质点振速得声强、声强对封闭面积分得声功率、自由场中声压平方除以特性阻抗连通声压与声强——是声学估算的基本工具。
