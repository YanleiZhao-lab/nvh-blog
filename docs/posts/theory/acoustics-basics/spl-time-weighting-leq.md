# 声级计读数里的时间：时间计权与等效声压级

> 同一段车内噪声录音，声级计 Fast 挡读数在 62～71 dB(A) 之间波动，Slow 挡稳定在 66 dB 附近，报告里给出 Leq = 67.3 dB(A)——三个数都正确，只是各自回答不同的问题。声压级并非单次计算即可确定的量：频率计权决定哪些频段计入，时间计权决定读数跟随信号变化的速度，等效声压级则把一段时间的声能量折算为单一数值。本文从指数平均的递推式出发，推导三种时间常数的物理含义、上升与衰减不对称响应的设计依据，以及 Leq 能量平均的数值特性。

## 一、读数为什么会波动：声压级定义中的时间平均

声压级的定义本身不涉及时间：

$$L_p = 20\lg\frac{p}{p_0}$$

其中 $p$ 为声压有效值（RMS），单位 Pa；参考声压 $p_0$ 取 20 µPa（1 kHz 处人耳平均听阈）。问题在于"有效值"必须对一段时间取平均才有定义：瞬时声压正负交替，其时间均值为零，直接取对数没有意义。**时间平均是声压级定义自带的步骤**，工程上需要明确的只是两件事：平均多长、按什么法则平均。

实际信号大多非平稳：车内噪声随路面激励起伏，关门声约 30 ms 即结束，怠速时风扇启停使声级缓慢漂移。平均时间太短，读数波动难以记录；太长，瞬态事件被摊薄而无法分辨。标准化做法（IEC 651、ANSI 1.4-1983）将"平均"分解为两个独立设置的参数：

**参数一：频率计权（Frequency Weighting）。** 在求总有效值之前，对声压信号的频谱倍乘一个计权函数。IEC 标准规定了 A、B、C、D 几种计权，均以实验确定的等响曲线为底本——A 计权对应 40 方等响曲线的倒置，B、C 分别对应 70 方、100 方。这一步决定"哪些频率计入"，展开见[《A计权：为什么 40 方等响曲线成了标准》](./a-weighting.html)。

**参数二：时间计权（Time Weighting）。** 对已计权的时域信号做指数平均（Exponential Averaging），得到规定的计权声压级。这一步决定"读数以多快的速度跟随信号变化"，是本文的主题。

::: info 核心概念
- **频率计权（Frequency Weighting）**：求 RMS 之前对频谱乘的计权函数（A/B/C/D），决定计入哪些频率
- **时间计权（Time Weighting）**：对计权后时域信号的指数平均，决定读数跟随变化的速度
- **有效值声压（RMS Pressure）**：一段时间内声压平方平均的开方；离开平均时长谈 RMS 没有意义
- **等效声压级（Equivalent Continuous Sound Pressure Level, Leq）**：一段时间 T 内能量平均折算的声压级，回答"这一整段平均多响"
:::

## 二、时间计权：从指数平均的递推式推起

### 为什么是指数平均，不是滑窗平均

滑窗（线性）平均对窗内每个样本赋予相同权重，窗滑动时进出样本的权重发生跳变，读数随之波动。指数平均则相反：最新的测量具有最大影响，历史测量的影响逐步递减。手册给出的计权因子为 $e^{-\Delta t/\tau}$，其中 $\Delta t$（s）为采样间隔，$\tau$（s）为时间常数。将其展开为逐样本的递推形式：

$$m(n) = a\,x^2(n) + (1-a)\,m(n-1), \qquad a = 1-e^{-\Delta t/\tau}$$

其中 $x^2(n)$ 为当前样本的瞬时均方贡献（Pa²），$m(n)$ 为到第 $n$ 个样本为止的均方值估计。推导分两步：第一步，历史估计整体乘以衰减因子 $e^{-\Delta t/\tau}$，即 $(1-a)\,m(n-1)$；第二步，权重归一——新样本权重 $a = 1-e^{-\Delta t/\tau}$ 恰好补足历史衰减让出的份额。将恒定输入 $x^2(n) = m(n-1) = c$ 代入，得 $m(n) = a\,c + (1-a)\,c = c$，稳态下读数不漂移，递推式自洽。声级读数取 $10\lg\left[m(n)/p_0^2\right]$，即时间计权声级。

对突加的稳态声，设 $x^2(t) = u_0$、初始 $m(0) = 0$，递推式的连续极限为

$$m(t) = u_0\left(1-e^{-t/\tau}\right)$$

读数按 $1-e^{-t/\tau}$ 的规律上升：一个时间常数达到稳态的 63.2%，两个达到 86.5%，三个达到 95.0%。指数平均无需记录数据段起点，适合连续刷新的表头读数；代价是读数始终滞后于真值，时间常数越大滞后越明显。

### 三挡时间常数与不对称的衰减设计

手册给出三种非约定（非标准化）时间常数取值，按信号类型选用：

| 时间计权 | 时间常数 | 适用信号类型 |
| --- | --- | --- |
| **Impulse 脉冲** | 35 ms | 含尖峰脉冲的信号，附加峰值检测 |
| **Fast 快挡** | 125 ms | 快变信号 |
| **Slow 慢挡** | 1000 ms | 慢变信号 |

先判断信号类型，再选择时间常数；信号含尖峰脉冲时归入"脉冲"类并附加峰值检测。在 Simcenter Testlab 的倍频程处理（Time Data Processing → Acquisition parameters）中，Sound Level Type 即提供 fast（0.125 s）、slow（1.000 s）、impulse（0.035 s）与 user（自定义）选项，平均方式可选 exponential 或 linear，与上述标准时间常数一一对应。

设计中特别值得注意的一点是**不对称响应**：当被平均信号强度递增时，平均可以准确跟踪其变化；当信号递减时，指数平均改用更长的时间常数，非约定取值 1500 ms，此场合下的时间常数称为衰减时间常数（Decay Time Constant）。工程含义：脉冲到来时读数须在几十毫秒内上升，与人耳对突发声的响应量级一致；脉冲过去后读数缓慢回落，使示值停留在峰值附近便于读取。上升用短时间常数保证灵敏度，回落用长时间常数保证可读性。

衰减斜率可由定义直接推出。信号突然消失后 $m(t) = m_0\,e^{-t/\tau_d}$，读数

$$L(t) = 10\lg m_0 - \frac{10}{\ln 10}\cdot\frac{t}{\tau_d}$$

即初始回落斜率为 $-4.34/\tau_d$ dB/s：Slow 挡 $\tau_d = 1$ s 时约 −4.3 dB/s，Fast 挡 $\tau_d = 125$ ms 时约 −34.7 dB/s，Impulse 衰减 $\tau_d = 1500$ ms 时约 −2.9 dB/s。工程文献中给出的三个斜率判据即来源于此。

::: warning 工程注意
Impulse 挡读数不能作为能量指标使用。上升 35 ms、回落 1500 ms 的不对称响应，使其对短暂尖峰的示值远高于等能量的稳态声——Impulse 值与 Leq 采用两种不同的平均法则，直接比较没有意义。报告中给出 Impulse 值时，必须注明衰减时间常数取值，否则复测结果无法对齐。
:::

### 三挡对同一段瞬态的读数差异

考察一段时长 $T$ 的等幅声脉冲（均方值恒为 1，稳态读数即 0 dB），从零初始状态起做指数平均，脉冲结束时刻的读数为

$$L(T) = 10\lg\left(1-e^{-T/\tau}\right)\ \text{dB}$$

即读数相对稳态的偏差只取决于比值 $T/\tau$。取 $T = 100$ ms：

| 时间计权 | 时间常数 | 100 ms 脉冲结束读数 | $T/\tau$ | 上升进度 |
| --- | --- | --- | --- | --- |
| **Impulse** | 35 ms | **−0.26 dB** | 2.86 | 94% |
| **Fast** | 125 ms | **−2.59 dB** | 0.80 | 55% |
| **Slow** | 1 s | **−10.22 dB** | 0.10 | 9.5% |

同一声事件，三挡读数相差约 10 dB，这就是读数中时间的分量。用 Slow 挡观测 100 ms 的关门声，读数尚未上升到位事件已经结束——100 ms 相对 1 s 时间常数只占十分之一，均方估计来不及积累。

## 三、Python 演示：三挡递推的数值复现

将上一节的公式用 numpy 复现。构造一段 100 ms 的声脉冲，分别以 35 ms / 125 ms / 1 s 三个时间常数运行指数平均递推，输出脉冲结束前的最大读数：

```python
import numpy as np

fs = 1000                      # 采样率 1 kHz，演示用
t = np.arange(0, 1.5, 1/fs)    # 1.5 s 时间轴
x2 = np.zeros_like(t)
seg = np.logical_and(t >= 0.2, t < 0.3)   # 0.2~0.3 s 一个 100 ms 声脉冲（均方值=1）
x2[seg] = 1.0

def expo_avg(sig, tau, fs):
    """对均方信号做指数平均，tau 为时间常数（秒）"""
    a = 1 - np.exp(-1 / (tau * fs))       # 递推系数
    out = np.zeros_like(sig)
    for n in range(1, len(sig)):          # m(n) = a*x2(n) + (1-a)*m(n-1)
        out[n] = a * sig[n] + (1 - a) * out[n - 1]
    return out

for name, tau in [("Impulse", 0.035), ("Fast", 0.125), ("Slow", 1.0)]:
    m = expo_avg(x2, tau, fs)
    print("%-9s 脉冲内最大读数 %6.2f dB（相对稳态）" % (name, 10*np.log10(m.max())))
```

输出三行：Impulse −0.26、Fast −2.59、Slow −10.22 dB，与式 $L(T) = 10\lg(1-e^{-T/\tau})$ 一致。Slow 一行最能说明问题：同一段声脉冲，时间常数从 35 ms 换到 1 s，读数降低约 10 dB。若将脉冲缩短为 50 ms（接近关门声量级），Slow 挡偏差进一步增大到 $10\lg(1-e^{-0.05}) = -13.1$ dB——这就是瞬态异响测量应改用 Impulse 挡或直接计算 Leq 的定量依据。

## 四、等效声压级 Leq：把一段能量折算成一个数

### 从能量平均推 Leq

时间计权回答"此刻多响"，法规与报告需要的是"这一整段平均多响"。ISO 1996/1-1982 与 ISO 1999/1-1990 规定了等效连续 A 计权声压级的定义，以符号 $L_{Aeq,T}$ 表示：

$$L_{Aeq,T} = 10\,\lg\left[\frac{1}{t_2-t_1}\int_{t_1}^{t_2}\frac{p_A^2(t)}{p_0^2}\,dt\right]$$

其中 $L_{Aeq,T}$ 为等效连续 A 计权声压级（dB）；$p_A(t)$ 为瞬时 A 计权声压（Pa）；$p_0 = 20\ \mu\text{Pa}$ 为参考声压；积分区间从 $t_1$ 到 $t_2$（s）。推导分两步：

第一步，均方声压是声压平方的时间平均——平均的对象是平方量，不是声压本身，更不是分贝值。物理意义：声能量与声压平方成正比，Leq 折算的是能量，因此先在平方域完成时间平均。

第二步，将均方声压代回声压级定义取对数。对抽样数据，连续积分离散化为按时间占比加权的均方值求和：

$$L_{Aeq,T} = 10\,\lg\left[\frac{1}{T}\sum_{i=1}^{N}\Delta t_i\,10^{L_i/10}\right]$$

这正是手册所述"以 dB 标度的声压级抽样值求和及平均"：每个抽样值先还原为均方值（$10^{L_i/10}$），按持续时间 $\Delta t_i$（s）加权求和，再除以总时长 $T = t_2-t_1$（s）并取对数。对同样的公式代入非计权声压 $p(t)$，得到的是 $L_{eq,T}$。

分贝不能直接算术平均，这是 Leq 使用中最常见的错误来源。两个数值例子：

$$10\,\lg\frac{10^{8}+10^{7}}{2} = 10\,\lg\left(5.5\times10^{7}\right) = 77.4\ \text{dB}$$

80 dB 与 70 dB 各占一半时间的能量平均是 77.4 dB，而非算术平均 75.0 dB；90 dB 仅占一成时间叠加在 50 dB 背景上，$10\,\lg(0.1\times10^{9}+0.9\times10^{5}) = 80.0$ dB——能量账由大声级时段主导。再看脉冲被稀释的一面：一记 85 dB、持续 0.1 s 的关门声叠加在 60 s 的 30 dB 背景上，

$$L_{eq} = 10\,\lg\frac{0.1\times10^{8.5}+59.9\times10^{3}}{60} = 57.2\ \text{dB}$$

短促强脉冲被时间稀释，但仍比背景高出约 27 dB，主导整段读数。Leq 对短脉冲的两面性——事件本身足够响、摊进长时段后被稀释——都体现在这一个算式中。

### Leq 与时间计权、SEL 的分工

声暴露级（Sound Exposure Level, SEL，符号 $L_{AE}$）将事件总能量折算到 1 s 的积分时间，便于不同时长事件之间的排序，与 Leq 的换算关系为

$$L_{AE} = L_{Aeq,T} + 10\,\lg T$$

| 量 | 平均方式 | 回答的问题 | 典型用途 |
| --- | --- | --- | --- |
| **时间计权声级** | 指数平均（不对称时间常数） | 此刻多响、峰值多大 | 表头读数、事件监测、瞬态判型 |
| **Leq 等效声压级** | 线性能量平均（式 7-1） | 整段平均多响 | 法规限值、通过噪声、工况对比 |
| **SEL 声暴露级** | 能量折算到 1 s | 单个事件总能量 | 关门声、敲击声排序 |

::: tip 报告中的选择
- 对标法规限值、跨工况对比、长时间监测：用 Leq，A 计权，标注积分时长 T
- 关门声、敲击声等单事件排序：用 SEL 或 Impulse 挡读数，注明衰减时间常数
- 稳态工况的表头读数用 Slow 挡；分析起伏、监测异常从 Fast 挡起步
- 瞬态异响判型用 Impulse 加峰值检测，不与 Leq 直接比较
:::

一台 SUV 匀速巡航，车内 A 计权声压级 Slow 挡稳定在 66 dB(A) 上下 1 dB 以内，同一路段 60 s 的 Leq 为 66.8 dB(A)，两者接近——信号平稳时，能量平均与指数平均给出基本一致的答案。换到坏路通过段，Fast 挡读数在 62～71 dB(A) 之间波动，Slow 挡收敛到 66 dB 附近，60 s 的 Leq 为 67.3 dB(A)。三个数并列写入报告：Slow 给典型值，Fast 给波动范围，Leq 给能量均值。数值来自同一段数据，差异只来自平均方式的不同。

## 五、小结

时间计权是以指数折扣记忆历史的均方估计器：Impulse 35 ms、Fast 125 ms、Slow 1 s 三挡，配合信号递减时 1500 ms 的衰减时间常数，构成上升快、回落慢的不对称响应；Leq 将线性能量平均折算为单一分贝值，积分时长与计权方式必须随数值标注。选择判据三条：观测瞬态选 Impulse，观测趋势选 Slow，能量核算用 Leq。同一段录音的三个读数各自回答不同的问题，撰写报告前应先明确要回答的是哪一个。
