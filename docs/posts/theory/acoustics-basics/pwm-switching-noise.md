# PWM 开关噪声：电机啸叫的识别、成因与整改

> 电动车 colormap（彩色图谱）上常出现一族形似阶次、但始终不穿过零频的曲线，来源是逆变器 PWM 开关频率及其边带，其振动或噪声幅值可以达到与电机本体相当的水平。本文给出两条识别判据（不穿零频、表观阶次随转速漂移），从占空比调制出发推导边带频率公式，用 numpy 复现边带结构，量化对比"提高开关基频"与"随机化开关"两条整改路线，并归纳测量环节的三项注意事项。判据与整改方向依据 Simcenter Testing Knowledge Base 相关手册条文。

一辆新能源车在高速上加速到 120 km/h，车里的人开始听见一阵细而尖的啸叫，转速再往上爬，音调却不见跟着明显上扬，反而像悬在半空；工程师拿到 colormap 一看：图谱上果然有一族斜向上行的曲线，形态像极了高阶次线，可把这族线往零转速方向外推——它压根不落在零频上。更麻烦的是，这声音的量级不输给电机本体：手册明确写着，功率电子开关产生的振动或噪声幅值可以和电机本体相当。一个电气系统的开关动作，凭什么吵到和机械结构平起平坐？如果它确是电气来源，为什么又会随转速散开和收拢？带着这两个疑问往下读：第一节给出两条识别判据，第二节从占空比调制推导出边带频率公式，第三节比较两条整改路线的取舍。

## 一、特征识别：不穿过零频的曲线族
在进入判据之前，先建立一个贯穿全文的类比：电机的"心脏"与"起搏器"要分开看。电机本体（齿轮、轴承、转子不平衡）好比心脏，每转一圈发生的事是固定的，它的振动特征与转速严格绑定——转速归零，机械特征频率必然归零；而 PWM 逆变器好比搭在心脏上的起搏器，它按自己的节拍（开关频率）独立放电，不管心脏跳多快，起搏器的节拍频率基本不动，只是放电的强弱跟着心脏的节律（电频率）起伏。colormap 上那族悬空的曲线，就是起搏器的放电纹波被心脏节律调幅后的产物：中心频率钉在开关频率上（节拍独立），边带间距跟着电频率变（强弱随节律）。记住这对关系，后文所有公式都可以用"节拍与节律"重新读一遍。


分析电机工况数据时，colormap 上可能出现一族斜向上行、随转速散开或收拢的曲线，形态接近高阶次线，但将转速外推至零，它不落在零频上。机械阶次（order）的频率等于每转事件数乘以转频：

这个公式回答的问题是：机械阶次的频率到底由什么决定。其中 O 对应物理里的每转事件数（齿数、缸数、滚珠数这类"每转一圈发生几次"的特征数），右端的 n 除以 60 把 r/min 换成 Hz——阶次线在 colormap 上的斜率由此而来，转速归零频率必归零，这就是后面判断"悬空曲线族不可能是机械阶次"的依据。



$$f_{\mathrm{order}} = O \cdot f_{\mathrm{rot}} = O \cdot \frac{n_{\mathrm{rpm}}}{60}$$

其中 $O$ 为阶次数（无量纲），$f_{\mathrm{rot}}$ 为转频（Hz），$n_{\mathrm{rpm}}$ 为转速（r/min）。转速归零时 $f_{\mathrm{order}}$ 必须为零；因此一族下端悬空的曲线不可能来自机械阶次，只能来自与转速无直接绑定关系的激励源——功率电子的开关频率。手册对该现象的表述为：**功率电子开关产生的振动或噪声幅值，可以和电机本体相当**，即此类成分不可作为"电气小事"忽略。PWM（Pulse Width Modulation，脉宽调制）逆变器以功率器件的高频通断将直流电变换为近似正弦的交流电驱动电机，开关动作在极短时间内改变电流，di/dt 与 dv/dt 经耦合路径转化为机械振动与噪声辐射。开关基频常见 2500、5000、10000 Hz，正处在人耳听觉敏感频段，这是电动车高速段"啸叫"（whine）的常见来源。

::: info 频率特征三要素
- **悬空**：曲线族以开关基频（及其倍频）为中心分布，下端不落在零频——这是与机械阶次区分的判别性特征
- **散开**：谐波族内各谱线随转速升高彼此拉开间距，转速下降又收拢（成因见第二节）
- **量级**：开关噪声可达电机本体噪声的量级，评估电驱 NVH 时须纳入分析带宽
:::

第二条判据是表观阶次（apparent order）的漂移。同一条固定频率谱线，在不同转速下按定义换算出的阶次数为：

这个公式回答的问题是：同一条固定频率的谱线，换个转速去"翻译"会得到多大的阶次数。其中 f 就是那条开关频率谱线（本例 5000 Hz），分母是转频——注意它只是换算工具，不代表谱线真的来自每转固定事件数的机械部件；算出来的表观阶次随转速连续漂移，正是电气成分的第二条识别判据。



$$O_{\mathrm{app}} = \frac{f}{f_{\mathrm{rot}}} = \frac{60\,f}{n_{\mathrm{rpm}}}$$

```python
# 表观阶次：同一条开关频率谱线在不同转速下换算出的阶次数
for rpm in [600, 3000, 6000, 12000]:
    f_rot = rpm / 60.0
    print(f"rpm={rpm:6d}  转频={f_rot:6.1f} Hz  "
          f"5000Hz 表观阶次 = {5000/f_rot:7.1f}")

# 对比：真正的机械 2 阶（四缸机燃烧阶次）随转速的行为
for rpm in [600, 3000, 6000]:
    print(f"rpm={rpm:6d}  机械2阶频率 = {2*rpm/60:6.1f} Hz")
```

600 rpm 时 5000 Hz 折算 500 阶，12000 rpm 时折算 25 阶——表观阶次随转速连续变化，说明该谱线并非"每转固定事件数"的机械源；机械 2 阶则严格等于 2 倍转频，转速归零即归零。判读流程据此固定为两步：先检查曲线族是否穿过零频，再核算表观阶次是否随转速漂移，两者均指向电气特征时，方可判定为开关噪声。

## 二、成因：开关边沿与占空比调制

PWM 的载波是固定频率的三角波或锯齿波，与正弦指令比较后输出一列方波：开关基频 $f_{\mathrm{sw}}$ 固定，占空比（duty cycle）按正弦指令摆动。输出谱因此包含两类成分：开关基频及其倍频（载波谐波族），以及调制过程搬移出来的边带（sideband）。

**第一步：占空比调制。** 正弦脉宽调制下，占空比围绕 0.5 按电机电频率（electrical frequency）$f_e$ 摆动：

这个公式回答的问题是：脉宽调制的占空比如何随时间变化。其中 m 对应物理里的调制深度（指令正弦的幅度，决定输出交流电压多高），fe 对应物理里的电机电频率（指令正弦的频率，随转速升高而增大）；占空比围绕 0.5 摆动，意味着每个开关周期里功率器件"导通的时间占比"被低频正弦连续改写——用类比的语言说，起搏器的放电强弱跟着心脏节律起伏，指的就是这条曲线。



$$d(t) = \frac{1}{2}\left[1 + m\sin\left(2\pi f_e t\right)\right]$$

其中 $m$（$0 < m < 1$）为调制深度，$f_e$ 为指令正弦的频率，即电机电频率，单位 Hz。物理意义：脉冲宽度受指令连续改写，平均输出电压按正弦规律变化。

**第二步：开关谐波被调幅。** 第 $n$ 次开关谐波（频率 $n f_{\mathrm{sw}}$）的幅度受 $d(t)$ 调制，近似为：

这个公式回答的问题是：低频的占空比摆动如何"骑"到高频开关谐波上。方括号里的 1 加 m sin 项就是上一式的占空比调制项（节律），它与频率为 n 倍开关频率的余弦载波（节拍）相乘——数学上这就是标准的幅度调制：脉冲宽度的低频摆动等效于对高频开关谐波的调幅。



$$s_n(t) = A_n\left[1 + m\sin\left(2\pi f_e t\right)\right]\cos\left(2\pi n f_{\mathrm{sw}} t\right)$$

物理意义：脉冲宽度的低频摆动等效于对高频开关谐波的幅度调制。

**第三步：和差化积得到谱线位置。** 展开上式：

这个公式回答的问题是：调幅之后的谱线究竟落在哪些频率上。展开后的三项分别是载波线本尊（n 倍开关频率）、上边带（加一个电频率）与下边带（减一个电频率）——边带成对出现在载波两侧、间距等于电频率，这就是第一节"悬空曲线族随转速散开收拢"的解析来历。



$$s_n(t) = A_n\cos\left(2\pi n f_{\mathrm{sw}} t\right) + \frac{m A_n}{2}\sin\left(2\pi (n f_{\mathrm{sw}} + f_e) t\right) - \frac{m A_n}{2}\sin\left(2\pi (n f_{\mathrm{sw}} - f_e) t\right)$$

载波线 $n f_{\mathrm{sw}}$ 两侧对称出现一对间距为 $f_e$ 的边带。计入脉宽调制的非线性后，边带扩展为一般形式：

$$f_{n,k} = n\,f_{\mathrm{sw}} \pm k\,f_e, \quad n = 1, 2, 3, \ldots,\quad k = 0, 1, 2, \ldots$$

相邻边带间距恒为 $\Delta f = f_e$。电机升速时 $f_e$ 随之增大，整族曲线在 colormap 上散开——这正是第一节观察到的悬空曲线族的物理来历，手册表述为"转速指令升高时谐波族与基频的间距拉大"。

```python
import numpy as np

fs = 200000.0                      # 采样率
t = np.arange(0, 0.02, 1/fs)       # 20 ms 数据
fsw, fe = 5000.0, 50.0             # 开关基频 5 kHz，电机电频率 50 Hz
# 正弦脉宽调制：占空比围绕 0.5 摆动正负 0.4
duty = 0.5 + 0.4*np.sin(2*np.pi*fe*t)
pwm = ((t*fsw) % 1.0 < duty).astype(float)  # 按占空比生成方波
win = 2*np.hanning(len(t)) - 1               # 手写汉宁窗压住泄漏
spec = np.abs(np.fft.rfft(pwm*win))
f = np.fft.rfftfreq(len(t), 1/fs)
band = np.logical_and(f > 4000, f < 6000)    # 只看 5 kHz 一族
idx = np.argsort(spec[band])[::-1][:6]       # 取幅值前 6 的谱线
lines = sorted(f[band][idx])
print("5 kHz 一族主要谱线 (Hz):", [int(x) for x in lines])
print("相邻谱线间距 (Hz):", [int(b-a) for a, b in zip(lines, lines[1:])])
```

运行结果中主要谱线位于 4850–5150 Hz，围绕 5000 Hz 对称分布，相邻间距精确等于电频率 50 Hz，与式 $f_{n,k} = n f_{\mathrm{sw}} \pm k f_e$ 一致。$f_e$ 升至 100 Hz（转速翻倍）时间距随之翻倍。反之，测出边带间距即可反推电频率，配合电机极对数可核对转速，构成电机数据判读中的交叉校验手段。

::: warning 工程注意
- **边带不是机械阶次**：4950/5050 Hz 的谱线对不对应任何"每转固定事件数"的机械部件，边带是调制产物，系统内不存在相应物理特征数的零件
- **倍频族须覆盖**：$2 f_{\mathrm{sw}}$、$3 f_{\mathrm{sw}}$、$4 f_{\mathrm{sw}}$（10、15、20 kHz）处各有一族边带，分析带宽须覆盖，否则整改后能量转移至倍频族的变化会漏检
- **声学敏感度**：基频 2500–5000 Hz 正处人耳敏感区，加速度级看起来不大的开关振动，声学上可能显著
:::

## 三、整改路线：提高基频与随机化开关

确认频率特征来自开关之后，手册给出两条整改方向。第一条调整**开关基频**：将 $f_{\mathrm{sw}}$ 从 2500 Hz 提高到 15000 Hz 量级、移出主要听阈，直接降低可听度——代价是开关损耗上升，电机效率受影响。第二条调整**开关方案**：以随机化 PWM 替代确定性 PWM，将集中在 $f_{\mathrm{sw}}$ 及其倍频处的能量摊到宽频段，单点峰值随之下降。

| 整改路线 | 做法 | 收益 | 代价 |
| --- | --- | --- | --- |
| **提高基频** | $f_{\mathrm{sw}}$ 从 2500 Hz 提到 15000 Hz 量级 | 峰值能量移出听阈，主观改善直接 | 开关损耗上升，效率下降 |
| **随机化开关** | 随机 PWM 替代确定性 PWM | 开关频率处峰值显著下降，电机本体的机械频率特征不受影响 | 能量摊到宽带，谱底整体抬升 |

随机化的机理：确定性 PWM 的开关时刻周期重复，谱能量在 $f_{\mathrm{sw}}$ 及其倍频上高度集中（线谱）；随机化使开关时刻抖动，载波族的相干性被破坏，能量从离散线谱扩散为连续谱底。用 numpy 对比 5 kHz 附近的峰值：

```python
import numpy as np

rng = np.random.default_rng(0)
fs, T = 400000.0, 0.02
t = np.arange(0, T, 1/fs)
fsw, fm = 5000.0, 100.0
ref = 0.5 + 0.45*np.sin(2*np.pi*fm*t)   # 正弦指令
win = 2*np.hanning(len(t)) - 1

def pwm_peak(jitter):
    # jitter=True 时给开关相位加随机抖动（随机 PWM 的简化模型）
    phase = t*fsw + (rng.random(len(t)) if jitter else 0)
    s = ((phase % 1.0) < ref).astype(float)
    spec = np.abs(np.fft.rfft(s*win))
    f = np.fft.rfftfreq(len(t), 1/fs)
    band = np.logical_and(f > 4000, f < 6000)   # 5 kHz 一族
    return spec[band].max(), spec[~band].sum()

p0, b0 = pwm_peak(False)   # 确定性 PWM
p1, b1 = pwm_peak(True)    # 随机化 PWM
print(f"确定性 PWM  5kHz 附近峰值: {p0:8.1f}")
print(f"随机化 PWM  5kHz 附近峰值: {p1:8.1f}  （降为 {100*p1/p0:.1f}%）")
print(f"5kHz 频带之外的谱能量: {b0:.0f} -> {b1:.0f}")
```

一组典型运行结果：5 kHz 邻域峰值降至确定性方案的约 5%，频带外谱能量升至约 3.8 倍——以谱底换峰值，与手册"改变开关方案可降低开关频率的幅值"的表述对应。听觉上，集中线谱的"音调感"消失，代之以更接近宽带噪声的"沙沙"声，主观上通常更易接受。手册同时强调：改变开关方案时，**电机本身的频率特征保持不变**——上图下方对比中电机频率成分未受随机化影响，这也是该路线可与电机本体诊断并行开展的原因。

## 四、测量环节的三项注意事项

**分析带宽不足，频率特征整体丢失。** 开关谐波族可延伸至 20 kHz 量级；若采样率按"关心机械阶次到 2 kHz"的习惯设置，开关族整段混叠或截断，问题在数据中不可见。电机 NVH 测量的分析带宽至少应覆盖到听觉上限。

**平均方式不当，随机化 PWM 的对比失真。** 随机 PWM 的能量本就分布在谱底上，若测量平均方式不当，本已不高的线谱进一步被抹平，整改前后的对比即失去意义。对比试验应使用同一套采集与平均设置。

**表观阶次不可当机械阶次使用。** 第一节已算过：5000 Hz 在 600–12000 rpm 区间折算 500–25 阶且随转速漂移，若据此排查齿轮、轴承，方向即错。判读流程固定为：先检查曲线族是否穿过零频，再核算表观阶次是否随转速漂移，两者均符合电气特征后，才下"开关噪声"的结论。

::: tip 判读与整改路线
- colormap 上族状曲线**下端悬空** → 电气开关频率；量取边带间距反推电频率，做交叉校验
- 主观抱怨集中在 2.5–10 kHz 的啸叫 → 优先提高基频移出听阈；效率敏感或基频不可调 → 随机化开关摊能量
- 整改验证保持采集设置一致，带宽覆盖到开关倍频族，避免能量转移至倍频族后漏检
:::

## 五、小结

PWM 开关噪声的识别锚点有二：曲线族不穿过零频，且表观阶次随转速漂移。其成因为载波谐波族的调幅边带，谱线位置由 $f_{n,k} = n f_{\mathrm{sw}} \pm k f_e$ 给出，相邻边带间距等于电频率、随转速升高而散开。整改在"提高基频移出听阈"与"随机化摊能量"之间取舍：前者以开关损耗与效率为代价，后者以谱底抬升换取峰值下降（示例中峰值约降至 5%、带外能量约升 4 倍），且电机本体频率特征不受影响。测量端保证分析带宽覆盖倍频族、保持前后采集设置一致、不将表观阶次当机械阶次使用，即可支撑此类问题的判定与整改验证。

## 一句话记住

电机的机械特征像心脏、随转速绑定并归零落地，PWM 开关像起搏器、节拍独立而强弱随电频率起伏；所以判据看两点——曲线族不穿零频、表观阶次随转速漂移；谱线位置由开关频率加减电频率倍数给出；整改要么把节拍移出听阈，要么随机化节拍摊平能量。
