# 噪声认证标准怎么选：从指令到测法的决策链

> 产品要进入欧盟市场，声功率认证是必须完成的一环：指令规定限值，C 类标准规定测试规程，基础标准规定测量方法，三层结构缺一不可。本文依据 公开技术资料 的《Guide to measuring Sound Power》，把标准选择整理成一条决策链——先确定产品归属，再确定声压法还是声强法，最后核查 K1/K2 修正能否满足测试场地的要求。


同一台发电机，第三方实验室测出声功率 92.4 dB，公司自家的半消声室测出 90.1 dB——两个数都盖了章，欧盟认证机构只认前者。复盘发现差别不在仪器：自家试验选错了 C 类标准，工况覆盖少了高温满载一条，整套数据作废重测。更常见的纠纷是反过来：产品明明更吵，换个标准测出来的数反而更低，销售拿着这份报告去投标，被竞争对手当场指出标准适用范围不符。噪声认证里"选标准"本身就是测量的一部分——指令、产品规程、基础测法三层选错任何一层，后面测得再精确也交不了差。本文把这条决策链拆开讲清楚：先看法规为什么只认声功率，再看三层标准怎么各管一段，最后看声压法与声强法两条测法路线在环境要求上的分野，以及 K1/K2 修正还能救回什么、救不回什么。


## 一、为什么认证测的是声功率

先看一组数字感受"声压为什么不能当法规量"：同一台设备，麦克风距它 1 m 测得 76 dB，退到 2 m 只剩 70 dB，再退到 4 m 变成 64 dB——距离每翻一番，读数掉 6 dB。三个数都是"真实测量值"，那法规限值该写哪一个？写 76 dB，厂商把麦克风挪远就"达标"；写 64 dB，同一台设备换个场地就"超标"。而这台设备每秒发出的声能量是恒定的，把这个量测出来，才是放之四海皆准的判据。这就是法规选声功率的底层逻辑，先把这笔账算清楚，后面的标准体系才立得住。

欧盟对户外用设备（equipment for outdoor use）设有明确的噪声限值——2000/14/EC 指令即针对此类设备。无论设备产地是否在欧盟境内，要在欧洲市场销售，就必须测出声发射声功率级（Sound Power Level，$L_W$），且低于法规限值。另一类设备没有硬性限值，但同样必须做噪声标识（noise declaration）：将“保证声功率级”（guaranteed sound power level，$L_{WA}$）印在标签上，家电能效标签右下角的 dB 数即属此类。

为什么法规口径统一选声功率而不是声压？因为声功率是声源的固有属性——单位时间内发出的声能量，单位为瓦特（W），不随测点位置、测量距离、测试场地变化。声压级 $L_p$ 换一个距离就换一个数：在声学自由场中，距离每增加一倍，声压级下降 6 dB。若法规限值针对声压级而未规定测点距离，只需把麦克风移远即可“达标”，这样的量无法写入法律条文。声功率级在修正正确的前提下与测量位置无关，因此适合作为法规限值量。

这套三层结构在生活中有个现成的对应：搬家。搬家指令层是"房东的硬性要求"——哪类租客必须认证（限养宠物、限人数），如同欧盟指令规定哪类设备必须做噪声认证、限值多少；产品规程层是"具体到这套房子的看房清单"——几点看房、带不带家具、电器开不开，如同 C 类标准规定这台设备以什么工况、什么测点布置运转；基础测法层是"水电煤怎么查表"——物业统一的抄表规程，如同 ISO 3744/9614 规定声功率怎么测、环境怎么修正。租客只盯着房东要求却拿错看房清单，房子再合适也白跑一趟——三层标准必须逐层对上，缺一层认证就作废。而这个类比里"查的是水表读数而不是水管粗细"正对应下一层关键：法规限的为什么是声功率，不是声压。

::: info 核心概念
- <strong>噪声指令（Noise Directive）</strong>：欧盟层面对特定设备类别设定的噪声限值与申报要求，如 2000/14/EC（户外用设备）
- <strong>噪声测试规程（Noise Test Code，C 类标准）</strong>：针对特定机器类别规定“怎么测”的标准，照此执行结果才可复现、才被认可
- <strong>保证声功率级（Guaranteed Sound Power Level）</strong>：厂商申报并为之负责的声功率级，印在产品标签上
:::

## 二、标准体系：三层结构

选标准之前先认清体系结构，很多混乱来自把三层混为一谈：

| 层级 | 管什么 | 例子 |
| --- | --- | --- |
| **指令/法规层** | 哪类设备要认证、限值多少、要不要标识 | 2000/14/EC 户外用设备指令 |
| <strong>产品规程层（C 类标准）</strong> | 特定产品的工况、测点布置、运转状态 | ISO 15744、ISO 7779、ISO 6393/6395 |
| **基础测法层** | 声功率怎么测：环境、阵列、修正 | ISO 3744、ISO 3745、ISO 9614-1/-2 |

C 类标准是承上启下的关键：它引用基础测法标准，又规定了产品特定的运转工况。Simcenter 知识库列出的典型 C 类标准包括：

| 标准 | 覆盖产品 |
| --- | --- |
| **ISO 15744** | 手持式非电动动力工具 |
| **ISO 7779 / ECMA-74** | 信息技术与通信设备 |
| **ISO 9296 / ECMA-109** | 计算机与办公设备噪声申报值 |
| **IEC 60704** | 家用电器 |
| **DIN 45635 系列** | 通用机械噪声测量（德标体系） |
| **ISO 6393** | 土方机械，静态工况测量 |
| **ISO 6395** | 土方机械，动态工况测量 |

注意 ISO 6393 和 6395 这对标准：同一台挖掘机，静态模拟工况和动态作业工况分属两个标准，选错类别整个认证作废。汽车产业链上的供应商更常遇到的是 ISO 7779——充电桩、服务器、通信机柜这类“信息技术设备”出口欧盟都要走它。

## 三、测法分岔：声压法还是声强法

基础测法层有两条路线，能力边界完全不同。

### 3.1 声压法

在声源周围布置固定麦克风阵列（按标准规定的半球面或包络面），测各点声压级，能量平均后加上表面积修正得到声功率。Simcenter 知识库给出的声压法基本公式为：

这个公式回答的问题是："一圈麦克风读数怎么换算成声源的声功率级？"其中 $\overline{L_p}$ 对应物理里的声场测量结果（阵列各点声压级的能量平均），$10\,\lg(S/S_0)$ 对应物理里的"把面平均声强放大成总功率"的面积贡献——包络面每大十倍，这一项就加 10 dB。

$$
L_W = \overline{L_p} + 10\,\lg\!\left(\frac{S}{S_0}\right)
$$

其中 $\overline{L_p}$ 为阵列各测点声压级的能量平均值（dB，基准 20 微帕），$S$ 为测量包络面面积（平方米），$S_0 = 1\ \mathrm{m^2}$ 为基准面积。声功率级以基准声功率 $W_0 = 1\ \mathrm{pW}$（皮瓦）为参考，用分贝表示。

![声压法声功率测量：麦克风按固定阵列布置在被测对象四周](/images/noise-certification-standards/pressure-array.png)

*（图源：网络 侵删）*

这个公式自洽于测量距离的选取：麦克风靠近声源，声压级升高，但包络面相应减小；麦克风远离声源，声压级降低，但包络面增大。两项此消彼长，声功率级保持不变——这正是声功率“与距离无关”的数学体现。

![半球阵列剖面：近距小面阵与远距大面阵给出的声功率一致](/images/noise-certification-standards/hemisphere-crosssection.png)

*（图源：网络 侵删）*

它对环境要求严格：公式假设除地面反射平面外没有其他反射和背景源，只有消声室或混响室这类特定声学环境才能直接给出可靠结果。

### 3.2 声强法

用声强探头在被测对象表面逐点（ISO 9614-1）或扫描（ISO 9614-2）测量法向声强，对封闭面做声强积分直接得到声功率：

这个公式回答的问题是："不测声压、改测每平方米流过多少瓦，怎么合成总功率？"其中 $\vec{I}$ 对应物理里穿过面元的能流密度（单位面积上的声功率），积分号对应物理里"把整个封闭面上流出的能量全部累加"——就像数清一张渔网上每个网眼流过的水量，总和即这台设备的声功率。


$$
P = \int_S \vec{I} \cdot d\vec{S}
$$

其中 $\vec{I}$ 为声强矢量（瓦每平方米），$d\vec{S}$ 为面元矢量（模等于面元面积，方向沿法线）。声强定义为声压与质点速度的乘积：

这个公式回答的问题是："声强这个矢量本身怎么测出来？"其中 $p$ 对应物理里媒质受到的压缩扰动（声压），$\vec{v}$ 对应物理里媒质质点的往复运动速度——功率=力×速度的机械类比在声学里的化身：压力提供"力"，质点速度提供"速度"，两者同相相乘才形成净能量流。

$$
\vec{I} = p\,\vec{v}
$$

其中 $p$ 为声压（帕斯卡），$\vec{v}$ 为质点速度（米每秒）。声强是矢量：幅值表示单位面积上通过的声功率，方向表示声能量流方向。

![同一电机周围的声强（左，矢量场）与声压（右，标量场）](/images/noise-certification-standards/intensity-vs-pressure.png)

*（图源：网络 侵删）*

声强法可以在任意声场测量，甚至能在其他机器正常运转的车间里测某一台设备：稳态背景噪声穿过封闭面的净声强流量为零——能量流来回抵消，时间平均为零——积分时被自动扣除。代价是可用频带受限（探头间隔决定工作频带）、测量流程耗时，且要求声源稳态（非稳态源无法做时间平均）。

知识库给出的算例：某打印机声功率为 0.02 W，在 2 m 半球面（表面积约 25 平方米）上测量，声强等于 0.02/25 = 0.0008 W/m2，换算为声强级约 89 dB——已知声功率与测量面积，反推各处声强就是这个关系。

![已知声功率的对象在 2 m 半球面上的声强测量算例](/images/noise-certification-standards/intensity-hemisphere.png)

*（图源：网络 侵删）*

### 3.3 两条路线的适用边界

| 维度 | **声压法** | **声强法** |
| --- | --- | --- |
| **代表标准** | ISO 3744、ISO 3745、2000/14/EC、ISO 6393/6395、ARI 260 | ISO 9614-1（离散点法）、ISO 9614-2（扫描法） |
| **环境要求** | 高：消声室/混响室或达标场地 | 低：现场即可，可在其他声源旁测 |
| **背景噪声** | 需 K1 修正，背景高了直接作废 | 稳态背景被积分自动抵消 |
| **频带与耗时** | 宽频带、流程成熟 | 频带受限、逐点扫描耗时 |
| **认证主流** | 绝大多数认证测量的默认路线 | 声压法环境不达标时的替代路线 |

![声功率测试的最终结果形式：A 计权倍频程谱](/images/noise-certification-standards/soundpower-spectrum.png)

*（图源：网络 侵删）*

两种测法的最终交付物相同：A 计权倍频程谱表形式的声功率级，以基准声功率 1 皮瓦为参考。

::: tip 选择原则
- 默认走声压法：认证机构认可度最高，测试规程最成熟
- 场地不达标又没预算进消声室，选声强法（ISO 9614-2 扫描法效率更高）
- 先查产品的 C 类标准，它可能直接指定了基础测法，没得选
:::

## 四、K1 与 K2：场地质量的修正

声压法公式默认理想环境，现实场地总有偏差。知识库明确说明：修正系数 K1 和 K2 用来在**一定限度内**消除背景源与多余反射的影响，且按倍频程带逐带执行。

**K1——背景噪声修正**。测试前先测一次设备不运转时的背景噪声。判据分三档：

- 背景比设备噪声高：整个测试作废；
- 背景比测量值低 15 dB 以上：修正量可忽略，不再修正；
- 介于两者之间：按能量域相减从总声功率中扣除背景贡献。

**K2——反射修正**。场地不够吸声，多余反射把声功率抬高了。用一个标准声源（Reference Sound Source，声功率已知且可复现）在场地里测一遍：某倍频程带标准源标称 90 dB，实测 91 dB，多出来的 1 dB 即场地反射的贡献，从结果中扣除。

这个公式回答的问题是："场地不理想时，上一节的声压法公式要打几折？"其中 $K_1$ 对应物理里背景噪声混进读数的份额（按能量域扣除），$K_2$ 对应物理里墙面反射"送"回来的多余声能——两者都是正值、都按倍频程带逐带算，从理想公式的结果里减掉。

$$
L_W = \overline{L_p} + 10\,\lg\!\left(\frac{S}{S_0}\right) - K_1 - K_2
$$

其中 $K_1$、$K_2$ 均为正值（分贝），按倍频程带逐带计算后从声功率级中扣减。

K1 修正在能量域进行。设某倍频程带内设备运转时测得总声压级为 $L_{p,\mathrm{tot}}$（含背景），背景声压级为 $L_{p,\mathrm{bg}}$，则声源自身贡献为：

这个公式回答的问题是："麦克风测到的总声级里，怎么把背景那份能量剥出去？"其中 $10^{L_{p,\mathrm{tot}}/10}$ 对应物理里的总能流（分贝取反对数回到线性能量域），相减发生在能量域而非分贝域——分贝是log压缩后的量，直接相减没有物理意义，这正是下一节 Python 演示要算的东西。

$$
L_{p,\mathrm{src}} = 10\,\lg\!\left(10^{L_{p,\mathrm{tot}}/10} - 10^{L_{p,\mathrm{bg}}/10}\right)
$$

推导分三步：分贝级与能量的换算关系为 $L_p = 10\,\lg(p^2/p_0^2)$，故总能量为 $p_{\mathrm{tot}}^2 = p_0^2 \cdot 10^{L_{p,\mathrm{tot}}/10}$，背景能量为 $p_{\mathrm{bg}}^2 = p_0^2 \cdot 10^{L_{p,\mathrm{bg}}/10}$；能量域相减即声源能量 $p_{\mathrm{src}}^2 = p_{\mathrm{tot}}^2 - p_{\mathrm{bg}}^2$（对不相干信号，能量叠加近似成立）；再取对数回到分贝。该式成立的前提是总级高于背景级——背景更高则整个测试作废，正是 K1 的第一条判据。

::: warning 工程注意
K1/K2 是标准限值范围内的修正手段，不是无限适用的。背景噪声贴近被测源、或场地反射修正量过大时，标准的正确动作是换场地或改用声强法——修正量超出限值硬修出来的数，认证复测时对不上，责任在测试方。
:::

## 五、Python 演示：K1 修正的计算

背景修正本质是能量域相减：总声功率减去背景声功率。dB 不能直接相减，必须回到能量域。

```python
import numpy as np

# 某倍频程带的声压级（dB），来自半球阵列能量平均
L_total = 78.0   # 设备运转时测得
L_bg    = 70.0   # 设备停机时测得（背景）

# dB 相减 = 能量相减：L_source = 10*lg(10^(L_tot/10) - 10^(L_bg/10))
L_source = 10 * np.log10(10**(L_total/10) - 10**(L_bg/10))
print(f"背景级差 dL = {L_total - L_bg:.0f} dB")
print(f"K1 修正后声源声级 = {L_source:.2f} dB")
print(f"修正量 K1 = {L_total - L_source:.2f} dB")

# 不同背景级差下的修正量对比
print()
print("背景级差 -> 修正量（不修正会高估多少）")
for d in [15, 10, 6, 4, 3]:
    lt = 80.0
    ls = 10 * np.log10(10**(lt/10) - 10**((lt-d)/10))
    print(f"  dL={d:2d} dB -> 修正 {lt-ls:.2f} dB")
```

输出里最值得核对的是：级差 15 dB 时修正量只有 0.14 dB 左右——这就是标准规定“背景低于测量值 15 dB 时不再修正”的物理依据；而级差 3 dB 时修正量已近 3 dB，背景和设备一样响，此时修正结果的不确定度已与修正量同量级，标准转而要求更换场地或改用声强法。

## 六、小结

选标准的顺序是固定的：**先查指令确定设备类别，再查 C 类标准确定工况和测法，最后由基础测法标准确定环境与修正**。产品没有对应 C 类标准时，才退到通用基础标准（ISO 3744 声压法或 ISO 9614 声强法）自定工况——但这种情况申报前应先与认证机构对齐，避免到了认证实验室才发现工况定义不被认可。场地不达标时记住两条退路：K1/K2 修正只在限值内有效，声强法是环境不满足声压法要求时的合法替代。

## 一句话记住

认证认的是声功率而非声压——它是不随测点变化的源属性；选标准走"指令→C 类规程→基础测法"三层决策链，声压法环境不达标用 K1/K2 在限值内修正、超限就换声强法兜底，能量域相减是背景修正的物理本质。
