# 噪声认证标准怎么选：从指令到测法的决策链

> 产品要卖进欧盟市场，声功率认证是绕不开的一关：指令给限值、C 类标准给规程、基础标准给测法，三层结构缺一不可。本文把 Simcenter 知识库的《Guide to measuring Sound Power》消化成一条决策链——先定产品归属，再定声压法还是声强法，最后盯住 K1/K2 修正能不能救你的测试场地。

## 一、为什么认证测的是声功率

欧盟对户外用设备（equipment for outdoor use）设有明确的噪声限值——2000/14/EC 指令管的就是这件事。不管设备产自欧盟内还是外，想在欧洲市场卖，就得测出声发射声功率级（Sound Power Level），并且低于法规限值。另一类设备没有硬性限值，但同样必须做噪声标识（noise declaration）：把"保证声功率级"印在标签上，最常见的就是家电能效标签右下角那个 dB 数。

为什么法规口径统一选声功率而不是声压？因为声功率是声源的固有属性——不随测点位置、测量距离、测试场地变化。声压级换个距离就变一个数，买卖双方各执一词；声功率级在哪里测都该是同一个数（在修正做对的前提下），这才配写进法律条文当限值。

![欧盟能效标签，右下角为声功率申报值](/images/noise-certification-standards/energy-label.png)

*（图源：Simcenter Testing Knowledge Base）*

::: info 核心概念
- **噪声指令**：欧盟层面对特定设备类别设定的噪声限值与申报要求，如 2000/14/EC（户外用设备）
- **噪声测试规程（Noise Test Code，C 类标准）**：针对特定机器类别规定"怎么测"的标准，照着做结果才可复现、才被认可
- **保证声功率级（Guaranteed Sound Power Level）**：厂商申报并为此负责的声功率级，印在产品标签上
:::

## 二、标准体系：三层结构别混

选标准之前先认清体系结构，很多混乱来自把三层混为一谈：

| 层级 | 管什么 | 例子 |
| --- | --- | --- |
| **指令/法规层** | 哪类设备要认证、限值多少、要不要标识 | 2000/14/EC 户外用设备指令 |
| **产品规程层（C 类标准）** | 特定产品的工况、测点布置、运转状态 | ISO 15744、ISO 7779、ISO 6393/6395 |
| **基础测法层** | 声功率怎么测：环境、阵列、修正 | ISO 3744、ISO 3745、ISO 9614-1/-2 |

C 类标准是承上启下的关键：它引用基础测法标准，又规定了产品特定的运转工况。Simcenter 知识库列出的典型 C 类标准包括：

| 标准 | 覆盖产品 |
| --- | --- |
| **ISO 15744** | 手持式非电动动力工具 |
| **ISO 7779 / ECMA-74** | 信息技术与通信设备 |
| **ISO 9296 / ECMA-109** | 计算机与办公设备噪声申报值 |
| **IEC 60704** | 家用电器 |
| **DIN 45635 系列** | 通用机械噪声测量（德标体系） |
| **ISO 6393** | 土方机械，静态工况测量 |
| **ISO 6395** | 土方机械，动态工况测量 |

注意 ISO 6393 和 6395 这对"孪生标准"：同一台挖掘机，静态模拟工况和动态作业工况分属两个标准，选错类别整个认证作废。汽车产业链上的供应商更常撞到的是 ISO 7779——充电桩、服务器、通信机柜这类"信息技术设备"出口欧盟都要走它。


## 三、测法分岔：声压法还是声强法

基础测法层有两条路线，能力边界完全不同。

**声压法**：在声源周围布置固定麦克风阵列（按标准规定的半球面或包络面），测各点声压级，能量平均后加上表面积修正得到声功率。它对环境要求苛刻——只有消声室或混响室这类特定声学环境才能给出可靠结果，因为公式假设除地面反射外没有其他反射和背景源。

![声压法声功率测量：麦克风按固定阵列布置在被测对象四周](/images/noise-certification-standards/pressure-array.png)

*（图源：Simcenter Testing Knowledge Base）*

**声强法**：用声强探头在被测对象表面逐点扫描，对封闭面做声强积分直接得到声功率。它可以在任意声场测，甚至能在其他机器正常运转的车间里测某一台设备——稳态背景噪声穿过封闭面的净声强流量为零，天然被积分掉。代价是可用频带受限、测量流程耗时，而且对声源特性有限制（非稳态源测不了）。

| 维度 | **声压法** | **声强法** |
| --- | --- | --- |
| **代表标准** | ISO 3744、ISO 3745、2000/14/EC、ISO 6393/6395、ARI 260 | ISO 9614-1（离散点法）、ISO 9614-2（扫描法） |
| **环境要求** | 高：消声室/混响室或达标场地 | 低：现场即可，可在其他声源旁测 |
| **背景噪声** | 需 K1 修正，背景高了直接作废 | 稳态背景被积分自动抵消 |
| **频带与耗时** | 宽频带、流程成熟 | 频带受限、逐点扫描耗时 |
| **认证主流** | 绝大多数认证测量的默认路线 | 声压法环境不达标时的替代路线 |

::: tip 选择原则
- 默认走声压法：认证机构认可度最高，测试规程最成熟
- 场地不达标又没预算进消声室，选声强法（ISO 9614-2 扫描法效率更高）
- 先查产品的 C 类标准，它可能直接指定了基础测法，没得选
:::

## 四、K1 与 K2：场地质量的补救修正

声压法公式默认理想环境，现实场地总有偏差，于是有两条修正按倍频程带逐带扣减：

**K1——背景噪声修正**。测试前先测一次设备不运转的背景噪声。判据很干脆：背景比设备噪声高，整个测试作废；背景比测量值低 15 dB 以上，不修正；夹在中间的，按公式从总声功率里扣掉背景贡献。

**K2——反射修正**。场地不够吸声，多余反射把声功率抬高了。用一个标准声源（Reference Sound Source，声功率已知且可复现）在场地里测一遍：某倍频程带标准源标称 90 dB，实测 91 dB，多出来的 1 dB 就是场地反射的贡献，从结果里扣掉。

::: warning 工程注意
K1/K2 是"一定范围内的补救"，不是无限透支的信用卡。背景噪声贴近被测源、或场地反射修正量大到离谱时，标准的正确动作是换场地或换声强法——硬修出来的数，认证复测时对不上，责任在测试方。
:::


## 五、Python 演示：K1 修正怎么做

背景修正本质是能量域相减：总声功率减去背景声功率。dB 不能直接相减，必须回到能量域。

```python
import numpy as np

# 某倍频程带的声压级（dB），来自半球阵列能量平均
L_total = 78.0   # 设备运转时测得
L_bg    = 70.0   # 设备停机时测得（背景）

# dB 相减 = 能量相减：L_source = 10*lg(10^(L_tot/10) - 10^(L_bg/10))
L_source = 10 * np.log10(10**(L_total/10) - 10**(L_bg/10))
print(f"背景级差 dL = {L_total - L_bg:.0f} dB")
print(f"K1 修正后声源声级 = {L_source:.2f} dB")
print(f"修正量 K1 = {L_total - L_source:.2f} dB")

# 不同背景级差下的修正量对比
print()
print("背景级差 -> 修正量（不修正会高估多少）")
for d in [15, 10, 6, 4, 3]:
    lt = 80.0
    ls = 10 * np.log10(10**(lt/10) - 10**((lt-d)/10))
    print(f"  dL={d:2d} dB -> 修正 {lt-ls:.2f} dB")
```

输出里最值得看的是：级差 15 dB 时修正量只有 0.14 dB 左右——这就是标准规定"背景低于测量值 15 dB 时不再修正"的物理依据；而级差 3 dB 时修正量已近 3 dB，背景和设备一样响，再修就是在猜数。能量域相减的前提是 L_total 大于 L_bg，背景更高则整个测试作废，正是 K1 的第一条判据。

## 六、小结

选标准的顺序是固定的：**先查指令定类别，再查 C 类标准定工况和测法，基础测法标准定环境与修正**。产品没有对应 C 类标准时，才退到通用基础标准（ISO 3744 声压法或 ISO 9614 声强法）自定工况——但这种情况申报前最好先和认证机构对齐，别等到了认证实验室才发现工况定义不被认可。场地不达标时记住两条退路：K1/K2 修正只在限值内有效，声强法是环境妥协的合法替代。
