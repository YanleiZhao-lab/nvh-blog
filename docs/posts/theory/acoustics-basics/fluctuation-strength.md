# 抖动强度 Fluctuation Strength：慢变调制的声品质

> 两台冷却风扇转速只差 4 rpm，声级计读数 68 dBA 稳稳不动，乘客却说"嗡——嗡——，像晕船"；把两台风扇的转速拉开，总声级一分没变，抱怨却消失了。能量没变、dBA 没变，变的只是响度包络在以每秒四次的速度慢慢起伏——就像老式日光灯的慢闪：平均亮度没变，闪起来却格外刺眼；可一旦闪得足够快，闪烁感消失，只剩稳定的亮度。人耳对声音起伏的感知同样有一条"快到看不出、慢到跟着晃"的分界线，而每秒 4 次的慢起伏恰好踩在最烦人的位置上。本文围绕"忽大忽小的声音为什么比同样响度的平稳声更烦"这个问题，讲清抖动强度（vacil）的参考定义、它与粗糙度按调制频率的分界、手册给出的近似计算式，以及车内哪些问题该用这个指标去归因。

## 一、为什么 dBA 相同，"忽大忽小"更烦

先看三个工程现场都遇到过的场景：

- **怠速驾驶室**：柴油机怠速时驾驶室轰鸣声"一涨一落"，用户形容"喘不过气"；
- **电子风扇**：降温策略让两台风扇以接近转速同转，车头传来规律的"嗡——嗡——"拍振；
- **鼓风机调速**：空调鼓风机在某一挡位附近，出风口声音明显地"晃"，换一挡就好了。

这三个场景的共同点：声级计读数完全合格，dBA 甚至不高，但主观抱怨集中而强烈。原因在手册里说得很直白——比之有同样 RMS 值的平稳声信号，**抖动的声信号显得更响、从而更加烦人**。dBA 是把整段时间能量摊平后的一个数，它天生看不见"能量的时间分布"；而人耳对 20 Hz 以下的包络起伏是逐个跟随的，每一次"变响"都是一次新的注意力事件。

拿电子风扇算一笔具体的账：风扇 2400 rpm、10 叶片，叶片通过频率 = 40 r/s × 10 = **400 Hz**；两台风速特性略有差异，一台 400 Hz、一台 404 Hz。两个等幅纯音叠加，三角函数和差化积后就是一个 402 Hz 载波被 4 Hz 包络调制的信号——听感上不是"两个音"，而是"一个音在每秒四次地变大变小"。这正是下一节要展开的调制数学。

::: info 核心概念
- <strong>幅值调制（Amplitude Modulation, AM）</strong>：信号幅值随时间周期起伏的现象，载波频率之外新增的"起伏快慢"叫调制频率
- <strong>调制频率（Modulation Frequency, $f_{\mathrm{mod}}$）</strong>：包络每秒重复的次数，单位 Hz——注意它不是声音"多高"，而是声音"多晃"
- <strong>调制深度（Modulation Depth）</strong>：包络起伏幅度与载波幅值之比，100% 调制即包络谷底触零
- <strong>抖动强度（Fluctuation Strength）</strong>：量化 20 Hz 以下慢调制"晃动感"的声品质指标，单位 vacil（vacillate 的缩写）
:::

把这条感知规律再翻译回日光灯类比：灯的闪烁频率低于约 60 Hz 时人眼看得出闪，其中慢闪（几 Hz）最刺眼；高过闪烁融合频率后，看到的是稳定但偏暗的灯。人耳这套"包络检测器"的时间分辨率也有限——**低于约 20 Hz 的起伏，听得见"变大变小"（抖动强度管辖）；高到每秒几十上百次，跟不上起伏，只剩下一种稳定但"发糙"的质地（粗糙度管辖）；再高到 150～300 Hz，包络细节彻底丢失，耳朵直接把载波和边带分辨成三个独立的音**。同一个调制现象，沿着调制频率这条轴被切成三段，归三个不同的主观维度管。

## 二、调制的数学：一根谱线怎么变成三根

抖动强度的物理载体是幅值调制。规定抖动强度锚点用的就是最干净的 AM 信号：1 kHz、60 dB 的纯音，被 4 Hz、100% 幅值调制。

这个公式回答的问题是"幅值调制的信号在时域和频域里各长什么样"——其中载波 $A\cos(2\pi f_c t)$ 对应物理里"你听到的那个音"，包络 $(1+m\sin 2\pi f_{\mathrm{mod}} t)$ 对应物理里"这个音的响度起伏"，调制深度 $m$ 从 0（平稳）到 1（谷底触零的 100% 调制）：

$$
x(t) = A\left(1 + m\sin 2\pi f_{\mathrm{mod}} t\right)\cos(2\pi f_c t)
$$

把乘积用积化和差展开，时域的"一个起伏的音"在频域里变成对称的三根谱线：

$$
x(t) = A\cos(2\pi f_c t) + \frac{mA}{2}\sin\!\left[2\pi (f_c + f_{\mathrm{mod}}) t\right] - \frac{mA}{2}\sin\!\left[2\pi (f_c - f_{\mathrm{mod}}) t\right]
$$

这个展开式回答的问题是"调制在频谱上留下什么指纹"——中间一根 $f_c$ 载波谱线，两侧各距 $f_{\mathrm{mod}}$ 处一根<strong>边带（Sideband）</strong>谱线，边带幅值是载波的 $m/2$ 倍。反过来读谱：看到等间距对称伴线，间距就是调制频率，这就是从频域反查"晃多快"的依据。

实测数据里调制长什么样，彩色图谱上最直观。下图是 Simcenter 知识库给出的经典案例：62 齿齿轮啮合本应只有一条 62 阶斜线，实测两侧对称出现 60、64 阶伴线——偏心齿轮每转推拉两次，啮合阶次被 2 次/转的幅值调制劈出边带。

这里要把"阶次域间距"换算成"时间域晃多快"，才能知道该归抖动强度还是粗糙度管：调制频率 = 边带间距（每转次数）× 转频。同样一个 2 次/转的调制，1800 rpm 时转频 30 Hz，调制频率 60 Hz——落在粗糙度区；降到 600 rpm 怠速附近，转频 10 Hz，调制频率 20 Hz——恰好压在抖动与粗糙的分界线上，轰鸣开始"一涨一落"。低速工况的调制阶次问题更容易以"晃"的形式被感知，这不是心理作用，是调制频率随转速同步下滑的结果。

## 三、20 Hz 分界线：抖动、粗糙与三个音

手册第七章把调制频率轴切成三段，三段对应三种完全不同的听感：

| 调制频率 | 听感 | 归属指标 | 敏感峰 |
| --- | --- | --- | --- |
| 低于约 15～20 Hz | 听得出音量起伏，"忽大忽小" | <strong>抖动强度（vacil）</strong> | 4 Hz 附近 |
| 约 15～300 Hz | 听不出起伏，稳定但"发糙、厌恶" | <strong>粗糙度（asper）</strong> | 70 Hz 附近 |
| 约 150～300 Hz 以上 | 载波与两边带被分辨成三个音 | 音高/音调度问题 | — |

（手册 7.5 节以 15 Hz、7.6 节以 20 Hz 表述分界，工程上按 15～20 Hz 过渡带理解即可。）

这个公式回答的问题是"包络起伏快到跟不上时，'糙'的感觉怎么定量"——其中 $f_{\mathrm{mod}}$ 对应物理里"包络起伏快慢"，$\Delta L$ 对应物理里"考虑瞬态掩蔽后听觉真正看到的响度落差"：

$$
R \cong f_{\mathrm{mod}} \cdot \Delta L \quad \text{(asper)}
$$

而抖动强度不是乘 $f_{\mathrm{mod}}$，反而是被 $f_{\mathrm{mod}}$ 压下去——调制太快跟不上、太慢起伏稀疏都不烦，只有不快不慢的每秒四次最烦。这个"中间最烦"的形状正是下一节公式的核心。

::: warning 工程注意
抖动与粗糙的分界是**调制频率**，不是载波频率。同一个电驱啸叫，包络波动 4 Hz 时是抖动问题（查拍频源、查双源转速差），波动 70 Hz 时是粗糙度问题（查啮合调制的边带结构）——整改方向完全不同。指标族的整体介绍见[声品质评价指标](./sound-quality-metrics.html)，边带的完整机理与判读见[调制阶次与边带](../rotating-machinery/modulated-order-sidebands.html)。
:::

## 四、1 vacil 锚点与近似计算式

与 sone、acum、asper 一样，vacil 也用一个可复现的锚点声定义：**1 kHz、60 dB 的纯音，受到 4 Hz、100% 幅值调制时，抖动强度为 1 vacil**。锚点选 4 Hz 不是随意的——主观实验表明人耳对每秒四次的响度起伏最敏感。

这个公式回答的问题是"晃得快慢与晃得深浅合起来，'晃'的感觉有多强"——其中 $\Delta L$ 对应物理里"**掩蔽深度**：实际感觉到的时变响度样本的最大值与最小值之差"（受瞬态掩蔽效应修正，不是信号包络的峰谷差），分母 $f_{\mathrm{mod}}/(4\,\mathrm{Hz}) + (4\,\mathrm{Hz})/f_{\mathrm{mod}}$ 对应物理里"偏离 4 Hz 敏感峰的双向惩罚"：

$$
F \approx \frac{\Delta L}{f_{\mathrm{mod}}/(4\,\mathrm{Hz}) + (4\,\mathrm{Hz})/f_{\mathrm{mod}}} \quad \text{(vacil)}
$$

分母的形状值得单独看一眼：由均值不等式，$f_{\mathrm{mod}}/4 + 4/f_{\mathrm{mod}} \ge 2$，当且仅当 $f_{\mathrm{mod}} = 4$ Hz 时取等号。于是同样的掩蔽深度 $\Delta L$，在 4 Hz 处抖动强度最大，两侧对称下降——1 Hz 和 16 Hz 的分母同为 4.25，这两处的"晃"感只相当于 4 Hz 时的一半不到。这把"4 Hz 最烦"从经验规律变成了式子里的数学性质。

用锚点声反推一下还能看出瞬态掩蔽的分量：锚点处 $F=1$，分母恰为 2，反推有效掩蔽深度 $\Delta L \approx 2$ dB。而 100% 调制的包络谷底是触零的，物理峰谷差远不止 2 dB——听觉的瞬态掩蔽把深谷"填平"了大半，耳朵实际看到的落差被大幅压缩。这正是手册强调该定量模型"计及了声音抖动造成的瞬变掩蔽效应"的原因：直接拿包络峰谷差当 $\Delta L$ 会严重高估抖动强度。

## 五、numpy 演示：合成、验包络、扫敏感曲线

```python
import numpy as np
from scipy.signal import hilbert

fs = 48000
t = np.arange(0, 2, 1/fs)
f0, fm = 1000.0, 4.0                     # 锚点声：1 kHz 载波、4 Hz 100% 调制
x = (1 + 1.0*np.sin(2*np.pi*fm*t)) * np.sin(2*np.pi*f0*t)

# 1) 包络检测：希尔伯特变换取模，包络应回到 (1+sin) 形状
env = np.abs(hilbert(x))
print("包络峰值/谷值:", env.max().round(3), env.min().round(3))   # 2.0 / ~0

# 2) 包络谱：排除 2 Hz 以下直流泄漏后，能量集中在 4 Hz 一根线上（"晃多快"的指纹）
E = np.abs(np.fft.rfft(env * np.hanning(len(env))))
freqs = np.fft.rfftfreq(len(env), 1/fs)
band = freqs >= 2.0
print("包络谱峰位置:", freqs[band][np.argmax(E[band])], "Hz")      # 4.0

# 3) 敏感曲线：同样掩蔽深度 10 dB，抖动强度随调制频率的变化
for f in [1, 2, 4, 8, 16, 70]:
    F = 10 / (f/4 + 4/f)
    tag = " ← 敏感峰" if f == 4 else ("（粗糙度区，改用 asper）" if f == 70 else "")
    print(f"f_mod={f:5.1f} Hz  F={F:5.2f} vacil{tag}")
```

运行结果里第三段循环会给出 1 Hz 时 2.35 vacil、4 Hz 时 5.00 vacil（最大）、16 Hz 时回落到 2.35 vacil、70 Hz 时只剩 0.57——敏感峰与对称下降都由分母 $f/4+4/f$ 一项决定；70 Hz 已属粗糙度区，按式 7-7 的 $R \cong f_{\mathrm{mod}} \Delta L$ 处理。

## 六、工程排查：哪些"晃"声该查 vacil

回到第一节的三个现场，抖动强度给出的是归因路线图：

- **双源拍频**（双风扇、双泵、双压缩机）：两频率差就是调制频率。包络谱上一根 4 Hz 线，等于直接告诉你要把两台设备的转速差拉开多少；
- **怠速半阶调制**：各缸燃烧不均使点火阶次响应被 0.5 次/转的包络调制，怠速 750 rpm 时调制频率约 6 Hz，正落在敏感区内——查供油/点火一致性，而不是继续加隔音；
- **鼓风机调速晃音**：某挡位气流诱发结构共振与叶频成拍，换挡即避开——在包络谱上确认调制频率后，共振频率与叶频的差值应与之一致。

**Testlab 锚点**：Simcenter Testlab 经典版通过 Tools → Add-ins 打开 Sound Quality Metrics 功能（33 token）后，在 Time Data Processing 的 Section Settings 里可勾选 Fluctuation Strength（与 Roughness、Tonality 同组），对时间记录逐帧计算；Testlab Neo 的 Process Designer → Method Library → Sound Quality 区提供同名方法，可按时间或转速出图谱跟踪。Simcenter 知识库将 Fluctuation Strength and Roughness 作为同一专题讲解——因为工程上这两个指标总是要连在一起读：先量出调制频率，再决定用哪一个。

## 七、小结

- 抖动强度量化的是 **20 Hz 以下慢调制**的"晃动感"，锚点声 1 kHz/60 dB 纯音、4 Hz、100% 调制 = 1 vacil；
- 同样 RMS 下起伏声更显响、更烦——dBA 对"能量的时间分布"天生失明，抱怨集中在"忽大忽小"时直接算 vacil；
- 近似式 $F \approx \Delta L/(f_{\mathrm{mod}}/4 + 4/f_{\mathrm{mod}})$ 的分母在 4 Hz 处最小，敏感峰是均值不等式的直接推论；$\Delta L$ 是被瞬态掩蔽压缩后的有效掩蔽深度，不是包络峰谷差；
- 调制频率 = 边带间距 × 转频：降速会把同一机械调制从"糙"拖进"晃"的区间，低速工况的调制阶次问题优先查 vacil。

## 一句话记住

dBA 称能量，vacil 称晃法：包络 20 Hz 以下听得出"忽大忽小"、4 Hz 最烦——$F \approx \Delta L/(f/4+4/f)$ 里那对倒数把敏感峰钉死在 4 Hz；看到对称边带先量间距，反算调制频率再决定归 vacil 还是 asper。
