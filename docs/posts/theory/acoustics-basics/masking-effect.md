# 声音的掩蔽效应：临界带、响度计算与 AVAS 设计判据

> 掩蔽效应（Masking Effect）指一个声分量的存在使另一个分量的听阈升高的现象：频率相近的声分量在人耳临界带（Critical Band）内合成响度，高声级分量抬高带内听阈，低于掩蔽阈的低声级分量不再贡献总响度。本文依据 Simcenter Testing Knowledge Base，说明临界带与 Bark 刻度的定义、掩蔽的三种时间形态与频率不对称性，以及掩蔽如何进入 Stevens Mark VI、Zwicker 响度与清晰度指数（AI）的计算流程，最后给出 AVAS 提示音设计与电动车掩蔽格局对标中的应用判据。

## 一、引例：频谱基本未变而听觉结论改变

电动车低速巡航时，车内某位置存在一个 4 kHz 左右的电机哨声成分，声压级 50 dB，主观评价中无人提及；将路噪隔离 5 dB 后再次评价，该成分即被明确感知。频谱的变化有限，听觉结论却完全改变，原因不在测量端，而在听觉系统的频率分析方式。

人耳不是一个全频段线性接收机。内耳的基底膜沿长度方向对不同频率产生共振，等效于一排互相衔接的带通滤波器，每个滤波器的带宽即**临界带（Critical Band）**。落在同一临界带内的声能量在响度上合并计算：强分量抬高该带的听阈基准，弱分量若不超过这一基准，则对总响度没有贡献——这就是被掩蔽。

Simcenter 手册给出了一个经典实验（图 6-3）：一个 50 dB、4 kHz 的纯音，在中心频率 1200 Hz、声压级 90 dB 的窄带背景噪声中仍可听到；背景噪声提高到 100 dB 后，该纯音不再可闻。两个分量的频率比约 3.3，在频率轴上相距很远，掩蔽仍然发生；且掩蔽声级每提高一档，受掩蔽的频带随之变宽。

![窄带噪声掩蔽效应：掩蔽声级越高，受掩蔽频带越宽](/images/masking-effect/fig6-3-masking.png)

*窄带噪声的掩蔽效应：掩蔽声把邻近及高频侧纯音的听阈推高，声级越高覆盖越宽（图源：Simcenter Testing Knowledge Base）*

::: info 核心概念
- **临界带（Critical Band）**：内耳等效滤波器组的单带带宽，以巴克（Bark）刻度标识；500 Hz 以下带宽近似恒定约 110 Hz，高频段近似 23% 恒百分比带宽
- **掩蔽（Masking）**：一个声分量的存在使另一个分量的听阈升高；同带内高声级分量抑制低声级分量对响度的贡献
- **掩蔽阈（Masking Threshold）**：被掩蔽声变得可闻所需的最低声压级，随掩蔽声级升高、随频距减小而上升
- **局部响度（Specific Loudness）**：响度沿 Bark 轴的分布，单位宋/Bark（sone/Bark）；掩蔽的直接表现是压低这条曲线
:::

## 二、掩蔽的生理声学基础：临界带是响度计算的频率单元

**频率-位置映射。** 声波经中耳传入耳蜗后，以行波（Traveling Wave）形式沿基底膜传播，行波包络的峰值位置由频率决定：高频在蜗底（入口端）达到峰值，低频需行进至蜗顶。基底膜上被强信号激励的区段，对邻近频率弱信号附加位移的响应能力下降，这是掩蔽集中于掩蔽者频率附近的物理原因。

![人耳的主要组成：外耳、中耳与耳蜗](/images/masking-effect/fig6-1-ear.png)

*声信号经外耳、中耳传入耳蜗，在基底膜上完成频率-位置映射，掩蔽发生在耳蜗的频率分析过程中（图源：Simcenter Testing Knowledge Base）*

**临界带带宽由耳蜗的频率-距离特性决定。** 基底膜的频率-距离关系是非线性的：低频段单位长度覆盖的频率范围窄，高频段覆盖的宽。等效滤波器组的带宽因此分两段近似：

$$\Delta f_c \approx 110\ \mathrm{Hz} \quad (f_c \le 500\ \mathrm{Hz})$$

$$\Delta f_c \approx 0.23\, f_c \quad (f_c > 500\ \mathrm{Hz})$$

其中 $f_c$ 为滤波器中心频率（Hz），$\Delta f_c$ 为临界带带宽（Hz）。低频段恒定带宽给出以 Hz 计的较高频率分辨能力；高频段恒百分比带宽与恒百分比带宽滤波器组的特性一致。24 个衔接的临界带覆盖约 0～16 kHz 的可听频段，对应 0～24 Bark。

频率轴到 Bark 轴的换算可采用 Zwicker 近似式：

$$z(f) = 13 \arctan\left(\frac{0.75 f}{1000\ \mathrm{Hz}}\right) + 3.5 \arctan\left[\left(\frac{f}{7500\ \mathrm{Hz}}\right)^{2}\right]$$

其中 $f$ 为频率（Hz），$z$ 为对应的 Bark 值。该式低频段主要由第一项控制（对应恒带宽特性）、高频段两项共同作用（对应恒百分比带宽特性），全频段误差在零点几 Bark 量级，满足工程判别用途。掩蔽的作用距离应以 Bark 计：同样相差 200 Hz，在 200 Hz 处已跨越近两个临界带（两分量分别结算响度），在 4 kHz 处仍属同一临界带（互相掩蔽）。

**掩蔽区向高频侧扩展更宽。** 由图 6-3 的掩蔽图案可见，听阈抬升的范围在掩蔽者高频一侧比低频一侧更宽。这一不对称性源于耳蜗行波特性与听觉神经侧抑制（Lateral Inhibition）的共同作用：被强激励的区段会抑制邻近区段的神经发放，且该抑制沿 Bark 轴向上蔓延，掩蔽声级越高蔓延越远。工程应用中可直接引用结论：**低频强声掩蔽高频信号较易，高频信号掩蔽低频声较难**。

::: warning 工程注意
不要用线性频率轴估计掩蔽。在 colormap 上量取两个分量“相隔 800 Hz”不具有判断意义：1500 Hz 与 2300 Hz 已跨越约 3 个临界带、各自独立结算响度，4500 Hz 与 5300 Hz 仍属同一临界带、按同带合成处理。掩蔽判别应换算到 Bark 域：Bark 差不小于 1 才可视为“分开”，差值小于 1 先按同带合成处理。
:::

## 三、掩蔽的时间形态与频率不对称性

### 前掩蔽、后掩蔽与同时掩蔽

稳态问题只需考虑同时掩蔽（Simultaneous Masking）；提示音、咔嗒声等瞬态信号还必须计入时间维度。手册给出的量级：

- **前掩蔽（Pre-masking）**：时间上领先于较响声音的短促声，其响度可能降低甚至被掩蔽，作用时间大致为几十 ms；
- **后掩蔽（Post-masking）**：响声去掉后约 20 ms 内（与掩蔽声级有关），短促的猝发声仍可能被掩蔽；
- **同时掩蔽**：存在连续声时，声级高于该连续声的猝发音是否变得模糊，取决于猝发音的持续时间。

20 ms 同时是“感觉响度”的时间积分尺度：猝发音存留时间短于 20 ms 时响度降低，长于 20 ms 时响度几乎与时间长短无关。这两组数字直接约束提示音设计：提示音若在一次路噪冲击（水泥路面接缝）后 20 ms 内到达，感知响度会降低；反之，把脉冲间隔拉开到大于后掩蔽窗，每个脉冲都可足额计入响度。

### 频率不对称性的整改排序含义

掩蔽的频率不对称性给出整改排序依据：低频强噪声向上掩蔽高频信号较易（1500 Hz 的轰鸣可显著压制 3 kHz 哨声的感知），反向则困难得多——高频行波在蜗底附近已达峰值并衰减，难以影响低频的共振位置。因此，车内同时存在低频轰鸣与高频哨声时，应先处理低频：它既是主要烦恼源，又在掩蔽频谱的高频段；而处理高频成分不会改变低频的掩蔽格局。

## 四、掩蔽进入声品质指标：响度与清晰度指数

### 响度的单位与基准

响度 $N$ 的单位为宋（sone），响度级 $L_N$ 的单位为方（phon），基准关系规定为 1 sone 对应 40 phon。在此基础上，响度级每增加 10 方响度增加一倍，由此得到手册式 7-2：

$$N = 2^{(L_N - 40)/10}\ \mathrm{sone}$$

推导分两步：基准点 $(L_N, N) = (40\ \mathrm{phon}, 1\ \mathrm{sone})$ 确定指数的常数项；“每 10 方响度翻倍”写成分式即 $N = 2^{(L_N-40)/10}$。该式使宋标尺对响度线性：两倍响度的声音有两倍的宋值，便于目标设定与沟通。

### Stevens Mark VI：掩蔽进入组合公式

ISO 532A-1975 与 ANSI S3.4-1980 规定的 Stevens Mark VI 法以倍频程带声压级测量为起点（该方法仅适用于混响声场中相对平稳的宽带噪声），通过一组标准曲线将每一倍频程带声压级转换为局部响度指数 $S$（sone），再按手册式 7-3 组合为总响度：

$$S_t = S_m + F\left(\sum S - S_m\right)$$

其中 $S_t$ 为总响度（sone），$S_m$ 为最大响度指数（sone），$\sum S$ 为所有频带响度指数之和（sone），$F$ 为反映掩蔽效应的分响度贡献因子，取值依赖于倍频程测量的类型：1/1 倍频程取 0.3，1/3 倍频程取 0.15。

公式的结构可从两个极限出发理解：各频带完全独立（无掩蔽）时，每个带的响度全额计入，总响度即 $\sum S$；完全掩蔽时，只有占优带起作用，总响度退化为 $S_m$。实际听觉介于两者之间：占优带（掩蔽带）的贡献 $S_m$ 全额计入，其余频带的贡献 $(\sum S - S_m)$ 按因子 $F$ 折减。$F = 1$ 对应无掩蔽极限，$F = 0$ 对应完全掩蔽极限。1/3 倍频程把频谱分得更细、邻近带更窄，落入掩蔽区被压制的份额更大，故 $F$ 取更小的 0.15；1/1 倍频程带宽较宽，带内能量合成已消化了大部分掩蔽作用，非占优带保留的份额较大，$F$ 取 0.3。

### Zwicker 响度：沿 Bark 轴的连续处理

ISO 532B 的 Zwicker 法以 1/3 倍频程声压级数据为基础，数据可源于自由声场或扩散声场，适用于复杂宽带噪声，也可用于纯音分析。该方法将频谱转换为沿 24 个 Bark 带的**局部响度** $N'(z)$（sone/Bark），总响度为局部响度曲线包围的面积：

$$N = \int_{0}^{24\ \mathrm{Bark}} N'(z)\, \mathrm{d}z$$

其中 $z$ 为 Bark 频率，$N'(z)$ 为该处的局部响度密度（sone/Bark），积分结果 $N$ 为总响度（sone）。积分的物理意义是总响度等于各临界带响度贡献的累加，而掩蔽在生成 $N'(z)$ 的过程中已经计入：占优频带（掩蔽带）暴露其影响的频率宽度，并抑制被掩蔽声对总响度的贡献，计算中还需计入每一倍频程带滤波器的斜坡边缘特性。

![Zwicker 响度计算举例：1/3 倍频程谱映射为局部响度曲线](/images/masking-effect/fig7-4-zwicker-example.png)

*Zwicker 法把 1/3 倍频程数据映射到 Bark 轴得到局部响度图线，曲线下面积即总响度；掩蔽带压低邻近区的图线（图源：Simcenter Testing Knowledge Base）*

Zwicker 分析的工程价值在于能够**区分掩蔽区与非掩蔽区**，从而判明某一局部声分量的声级是否被另一局部声分量完全掩蔽：局部响度曲线上被压平的一段，对应“该分量对总响度无贡献”，对其实施整改不会带来总响度收益。这一判别比在频谱上直接比较 dB 值更有效。

### 清晰度指数与语音私密性

掩蔽也可以被利用。清晰度指数（Articulation Index, AI）以交谈私密性观点提出，把语言频带按重要性加权，噪声对语言的掩蔽干扰由加权后的 1/3 倍频程谱算出——谱对语言信号的掩蔽越强，AI 越低。反过来，在办公室声学与电动车企划中，控制适量的掩蔽是保护交谈私密性的手段：完全私密的判据为 AI 上限 0.05，半私密（商谈非保密事务）为 AI 约 0.1。电动车缺少发动机掩蔽，车厢内轻声交谈的私密性下降，AVAS 与主动声浪设计中因此包含“补回掩蔽量”的考虑。

![AI 图算法：谱线上方计权点数占比即清晰度指数](/images/masking-effect/fig7-7-ai-chart.png)

*AI 的图形计算法：与语言相关的倍频程带用计权点数表示，谱线上方的点数除以总点数即 AI（图源：Simcenter Testing Knowledge Base）*

## 五、应用：AVAS 提示音设计与电动车掩蔽格局

电动车低速行驶时车内外噪声都较低，法规要求安装声学车辆警报系统（AVAS, Acoustic Vehicle Alerting System）提示行人。设计的主要约束即掩蔽：提示音必须在环境背景噪声之上保留可闻余量，而背景不是白噪声，是轮胎路噪、风噪与周围车流构成的谱。由掩蔽理论可直接导出三条设计规则：

**其一，频段避开路噪主能量区。** 路噪能量集中在数百 Hz 以下；提示音若置于 300～800 Hz，将落入掩蔽最密集的频段。置于 1～3 kHz 的收益有二：路噪谱已滚降、掩蔽阈较低；人耳的等响曲线在 4 kHz 附近最敏感（耳道共振所致），1～3 kHz 已处于敏感区，同样声压级的响度感知更高。

**其二，采用窄带或音调成分，不用宽带噪声。** 宽带提示音的能量分散在整个掩蔽敏感区，每个频率份额单独与背景竞争；窄带成分把能量集中到少数临界带内，带内声级可以提高，以更低的声功率穿透掩蔽阈——这是倒车蜂鸣器与电动车提示音普遍采用音调式设计的原因。

**其三，留出时间余量应对瞬态掩蔽。** 提示音的重复率应计入前/后掩蔽窗：脉冲间隔应显著大于几十 ms，保证每个脉冲不被前一个声音事件的后掩蔽压制。

对 NVH 工程师同样重要的是反向应用：电机哨声、变速箱啸叫的整改方案评审，必须先核查**竞争声场**。传统车同一位置的高频啸叫可能长期被发动机谐波掩蔽，用户无感知；改为电动平台后发动机掩蔽消失，声压级相同的啸叫从“无感知”变为被明确投诉。以传统车频谱为电动车设定声品质目标时，掩蔽格局的变化比绝对声压级的变化更需要先行核算。

::: tip 掩蔽的工程化使用
- 评审“某个纯音是否需要整改”：先计算它与最强邻近分量的 Bark 差，Bark 差小于 1 且声级差大于约 10 dB 时，多数情况已被掩蔽，整改优先级可下调
- 改进排序：优先处理低频强分量——它同时掩蔽高频段，单项整改获得双重收益
- 评审沟通用 Zwicker 局部响度曲线代替频谱：被压平的段即对总响度无贡献的频段，整改收益直观可查
- 提示音/警报音设计：窄带成分置于 1～3 kHz，重复周期大于瞬态掩蔽窗（几十 ms）
:::

| 场景 | 掩蔽的角色 | 判断/设计要点 |
| --- | --- | --- |
| **车内哨声整改** | 被低频轰鸣掩蔽 | 先查局部响度曲线是否已压平，是则下调优先级 |
| **电动车对传统车对标** | 发动机掩蔽消失 | 同级啸叫投诉突变，先重算掩蔽格局再定目标 |
| **AVAS 提示音** | 须穿透路噪掩蔽 | 窄带 + 1～3 kHz + 脉冲间隔大于几十 ms |
| **语言私密性** | 以掩蔽保护交谈 | AI 控制在 0.05 以下（完全私密） |
| **Zwicker 响度合成** | 带间贡献抑制 | 占优带抑制邻近带，曲线下面积即总响度 |

## 六、Python 示例：Bark 域的同带判别

下面的脚本用 Zwicker 近似式把三个车内声分量换算到 Bark 域，并按“Bark 差小于 1 且声级差大于 10 dB”的工程判据给出同带掩蔽的初步判断：

```python
import numpy as np

# Hz 转 Bark 的工程近似（Zwicker）：低频近似恒带宽，高频近似恒百分比带宽
def hz_to_bark(f):
    return 13.0 * np.arctan(0.75 * f / 1000.0) + 3.5 * np.arctan((f / 7500.0) ** 2)

# 车内三个声分量：(频率 Hz, 声压级 dB, 描述)
tones = [(180, 74, "路噪轰鸣"), (520, 55, "悬架嗡声"), (4200, 50, "电机哨声")]

z = [hz_to_bark(f) for f, _, _ in tones]
print(f"{'分量':<8}{'频率':>9}{'Bark':>8}{'声级':>8}")
for (f, lv, name), zi in zip(tones, z):
    print(f"{name:<8}{f:>8}Hz{zi:>8.2f}{lv:>7}dB")

# 同带判据：Bark 差小于 1 且级差大于 10 dB -> 弱者被强者掩蔽
print("\n以轰鸣(180Hz/74dB)为掩蔽源：")
for i in range(1, 3):
    dz = z[i] - z[0]
    lv_diff = tones[0][1] - tones[i][1]
    masked = dz < 1 and lv_diff > 10
    verdict = "已被掩蔽" if masked else "独立可闻"
    print(f"  {tones[i][2]}: Bark差={dz:.2f}, 级差={lv_diff}dB -> {verdict}")
```

输出中值得注意的两个数：520 Hz 悬架嗡声与 180 Hz 轰鸣在频率轴上只差 340 Hz，Bark 轴上却相距约 3 个临界带——同带掩蔽判据（Bark 差小于 1）远不满足，55 dB 的嗡声不会按同带规则被 74 dB 轰鸣掩蔽。4 kHz 附近电机哨声的 Bark 值约 17.5，与低频轰鸣分处耳蜗两端；若主观评价中该哨声不可闻，原因应在邻近的高频电驱啸叫分量中查找。一个 arctan 近似式即可把“频距多远才算分开”的判断从线性频率直觉转换到临界带刻度。

## 七、小结

掩蔽的机理是内耳临界带内的能量合成叠加神经侧抑制，判别一律在 Bark 域进行：Bark 差小于 1 的分量按同带合成，由强分量主导；跨带分量分别结算。整改排序上优先处理低频强分量，因为它同时掩蔽高频段；评审沟通采用 Zwicker 局部响度曲线，被压平的段即对总响度无贡献的频段；AVAS 提示音采用 1～3 kHz 窄带成分并留出瞬态掩蔽窗。电动平台取消发动机后掩蔽格局整体重排，原先被掩蔽的每个高频成分都需要重新评审。
