# A计权：为什么 40 方等响曲线成了标准

> 麦克风测到的声压级与人耳感知的响度级之间存在系统性差异：耳道在 4 kHz 附近存在共振，耳蜗对低频与很高频的检出能力较弱。A 计权用一条频率修正曲线对麦克风频谱逐频率修正，使读数更接近人耳感知。本文依据 Simcenter Testing Knowledge Base，说明这条 1936 年写入声级计标准的曲线的来源、定义、正确用法与适用边界。

## 一、麦克风与人耳记录的不是同一个声场

同一声场中，麦克风振膜与鼓膜处的声压可以相差数 dB。这并非仪器误差，而是两套接收系统结构不同所致。

人耳的接收特性至少有三个来源。**耳道共振（Ear Canal Resonance）**：长度约 2 cm 的耳道构成一端近似开放的四分之一波长共振管，其共振频率按

$$f_{res} = \frac{c}{4L}$$

估算。取声速 $c = 343\ \mathrm{m/s}$、耳道有效长度 $L \approx 0.0215\ \mathrm{m}$，得 $f_{res} \approx 4000\ \mathrm{Hz}$——鼓膜处声压在该频段被明显抬高。**头躯绕射**：头部、躯干与外耳对入射声场产生干扰和改变。**耳蜗特性**：耳蜗对低频与很高频声音的检出能力较弱，且随年龄增长的高频听损进一步加剧这种不平衡；耳蜗呈对数螺线形状，使人在低频区分音高的能力优于高频。

麦克风没有躯干、外耳与耳道，也没有对数形状的听觉器官。它记录的是声压的线性值；上述人耳特性全部体现在感知端。

::: info 核心概念
- **计权（Weighting）**：在频域上对各频率的测量值加/减修正量，用以模拟某种感知或物理效应的处理
- **方（phon，响度级）**：某声音与多强的 1000 Hz 纯音等响，即为多少方；40 方即与 40 dB 的 1 kHz 纯音等响
- **等响曲线（Equal Loudness Curve）**：同一响度级下各频率所需声压级连成的曲线；曲线越不平坦，说明人耳频响越不均衡
:::

## 二、一条 1936 年定型的标准修正曲线

A 计权是一条标准化曲线：在每个频率上给出衰减或放大的 dB 数，直接叠加到麦克风频谱上，使读数更接近人耳感知。

![A计权曲线：1 kHz 处为 0 dB，两侧分别下沉与微升](/images/a-weighting/aw-curve.png)

*A计权曲线：纵轴为各频率处的增益/衰减量（图源：Simcenter Testing Knowledge Base）*

这条曲线的四个关键特征（Simcenter 手册归纳）：

| 频段 | 修正量 | 原因 |
| --- | --- | --- |
| **1 kHz 以下** | 衰减，频率越低衰减越大 | 耳蜗对低频检出能力弱 |
| **1 kHz** | 0 dB | 曲线的定义锚点 |
| **1 k~6 kHz** | 放大约 1~2 dB | 耳道共振抬高鼓膜处声压 |
| **6 kHz 以上** | 转为衰减 | 高频听损与耳蜗灵敏度下降 |

A 计权源自 Fletcher-Munson 等响曲线，取其中**低声级的 40 方等响曲线**的形状。美国国家标准学会（ANSI）于 1936 年首次将其写入声级计标准。

曲线的解析定义由 IEC 61672-1 给出。设频率为 $f$（Hz），先定义 A 计权响应函数 $R_A(f)$（无量纲）：

$$R_A(f) = \frac{12194^2 \cdot f^2}{(f^2 + 20.6^2)\,\sqrt{(f^2 + 107.7^2)(f^2 + 737.9^2)}\,(f^2 + 12194^2)} \cdot f^2$$

各极点对应人耳响应的一个物理环节：20.6 Hz 极点对应对低频的衰减，107.7 Hz 与 737.9 Hz 极点构成中频段的过渡，12194 Hz 极点对应高频听感上限的下降。将 $R_A$ 取对数并加上归一化常数 +2.00 dB，使曲线在 1 kHz 处精确为 0 dB：

$$L_A(f) = 20\,\lg R_A(f) + 2.00\ \mathrm{dB}$$

按此式计算的关键频点：1000 Hz 处为 0.00 dB；100 Hz 为 -19.1 dB（手册 1/3 倍频程表取整为 -20 dB）；20 Hz 为 -50.4 dB；1 k~4 kHz 区间放大不超过 +1.2 dB。整条曲线的修正重心在低频衰减。

::: warning 工程注意
A 计权不是精确的听觉模型。为在当年实现低成本模拟电路，曲线经过大幅简化：真实人耳频响随声级变化（声级越高，听感频响越平坦），而 A 计权在任何声级下都是同一条固定曲线。用 dB(A) 外推高声级场景的响度感受时，会系统性低估低频成分的存在感。
:::

下面的代码用上述解析公式复算曲线，可核对关键频点：

```python
import numpy as np

def a_weight_db(freq):
    # IEC 61672-1 定义的 A 计权公式
    f2 = np.asarray(freq, float) ** 2
    Ra = 12194.0**2 * f2**2 / ((f2 + 20.6**2)
         * np.sqrt((f2 + 107.7**2) * (f2 + 737.9**2)) * (f2 + 12194.0**2))
    return 20 * np.log10(Ra) + 2.0

freqs = [20, 63, 100, 250, 500, 1000, 2000, 4000, 8000, 16000]
print("频率(Hz)   A计权(dB)")
for f in freqs:
    print(f"{f:>6}    {a_weight_db(f):+6.1f}")
```

运行结果要点：1000 Hz 处精确为 0.0 dB，100 Hz 约 -19 dB（手册取整 -20 dB），20 Hz 衰减 50 dB，1 k~4 kHz 区间放大不超过 1.2 dB——整条曲线的修正量集中在低频。

## 三、怎么用：频谱上的加减法，和两种必须分清的标注

用法本身很直接：**频谱的每条谱线各自加上该频率的计权量，再合成**。

手册的经典例子：100 Hz 处测得 80 dB，查曲线该频率衰减 -20 dB，结果 60 dB(A)。对数域里滤波就是加减法——

$$80\ \mathrm{dB} - 20\ \mathrm{dB} = 60\ \mathrm{dB(A)}$$

![100 Hz 处 -20 dB 衰减的查图用法](/images/a-weighting/aw-100hz.png)

*80 dB 减去 100 Hz 处的 -20 dB 计权，得 60 dB(A)（图源：Simcenter Testing Knowledge Base）*

标注必须无歧义：加 A 计权的值写 **dB(A)** 或 dBA；未计权的原始值写 **dB(L)/dBL/Linear**。报告里只写 "dB" 三个字母，会损失数据的可追溯性。

在 Simcenter Testlab 中，任何图形上右键 Y 轴 → Processing → Weighting → A 即可切换；colormap 与倍频程显示同样支持，嵌在 PowerPoint、Word、Excel 里的 Active Pictures 也可修改。

1 kHz 零点还有一个工程上的便利：**声校准器几乎都在 1000 Hz 发声**（常见 94 dB 或 114 dB 档）。由于 A 计权在 1 kHz 增益恰为 0，无论计权开关处于何种状态，校准读数不变——从标准设计层面避免了一类操作失误。

## 四、dB(A) 不一定比 dB 低：总级按能量合成

直觉上 A 计权衰减了大片频率范围，总值似乎应当更低。实际不一定——**总级在能量域合成，哪个频段占能量主导，总值走向就由它决定**。

设频谱各谱线频率为 $f_i$、未计权声压级为 $L_i$（dB），则总声压级为

$$L_p = 10\,\lg\!\left(\sum_i 10^{L_i/10}\right)\ \mathrm{dB}$$

物理意义：dB 是对数量，合成时须回到声压平方（能量）域相加。加 A 计权即对每条谱线的能量乘以计权因子 $10^{L_A(f_i)/10}$：

$$L_{pA} = 10\,\lg\!\left(\sum_i 10^{(L_i + L_A(f_i))/10}\right)\ \mathrm{dB(A)}$$

手册给出口哨的实例：口哨能量集中在约 1600 Hz，落在 A 计权的放大区（1 k~6 kHz）。未计权总级 84.2 dB，加 A 计权后为 85.1 dB(A)——总值不降反升。低于 1000 Hz 的谱线虽被大幅衰减，但其幅值本就较低，对总级的贡献小于 1600 Hz 主频的放大量。

![未计权的口哨频谱，总级 84.2 dB](/images/a-weighting/aw-whistle-lin.png)

*未计权：总级 84.2 dB（图源：Simcenter Testing Knowledge Base）*

![加 A 计权后的口哨频谱，总级 85.1 dB(A)](/images/a-weighting/aw-whistle-a.png)

*加 A 计权后：总级升到 85.1 dB(A)（图源：Simcenter Testing Knowledge Base）*

放到整车场景，这一结论的应用很普遍：排气噪声以低频为主，A 计权后总级可下降约 20 dB，看起来"轻松达标"，但 30~60 Hz 的怠速轰鸣对人的困扰依然存在——dB(A) 对低频源存在系统性低估。反过来，电驱 PWM 啸叫、齿轮啸叫落在 1 k~6 kHz，A 计权后总级不降反升，与主观上"更刺耳"的方向一致。

```python
import numpy as np

def a_weight_db(freq):
    f2 = np.asarray(freq, float) ** 2
    Ra = 12194.0**2 * f2**2 / ((f2 + 20.6**2)
         * np.sqrt((f2 + 107.7**2) * (f2 + 737.9**2)) * (f2 + 12194.0**2))
    return 20 * np.log10(Ra) + 2.0

def overall_db(freqs, levels, weighted=False):
    p2 = 10 ** (np.asarray(levels, float) / 10)      # 各谱线声压平方
    if weighted:
        p2 *= 10 ** (a_weight_db(freqs) / 10)        # 计权 = 能量域逐线缩放
    return 10 * np.log10(p2.sum())                   # 能量求和回 dB

cases = {
    "排气低频主导": ([63, 100, 160, 315], [90, 88, 80, 70]),
    "口哨啸叫型": ([100, 1600, 3200], [60, 84, 70]),
}
for name, (fs, ls) in cases.items():
    lin = overall_db(fs, ls)
    dba = overall_db(fs, ls, weighted=True)
    print(f"{name}: Linear {lin:.1f} dB -> dB(A) {dba:.1f}  ({dba-lin:+.1f})")
```

运行结果要点：低频主导的排气谱总级下降 20.1 dB（92.4 到 72.3），而啸叫型谱总级上升 1.0 dB（84.2 到 85.2，与手册实测的 85.1 一致，差 0.1 dB 来自谱线构成不同）。同一条曲线，两种相反的结果。

::: tip 判读原则
- 评审时不能只问"有没有加 A"，要先确认**能量集中在哪个频段**
- 低频问题（轰鸣、抖动、排气声）只看 dB(A) 会被明显低估，需配合 Linear 值或 C 计权值交叉判读
- 高频啸叫的 dB(A) 会比 Linear 更高，这是物理结果，不是测量事故
:::

## 五、A/B/C/D：一族四条计权曲线

A 不是唯一的计权。同一族还有 B、C、D 三条，区别在于所依据的等响曲线与低频衰减量不同。

![A，B，C，D 四种计权曲线对比](/images/a-weighting/aw-bcd.png)

*四条计权曲线：C 最平坦，D 在高频另有一段增益（图源：Simcenter Testing Knowledge Base）*

| 计权 | 出身 | 1 kHz 以下低频 | 典型用途 |
| --- | --- | --- | --- |
| **A** | 40 方等响曲线 | 衰减最重 | 法规限值、产品噪声规格的主流计权 |
| **B** | 70 方等响曲线 | 衰减较轻 | 历史标准，现已极少使用 |
| **C** | 100 方等响曲线 | 接近平坦 | 高声级与低频成分突出的场合 |
| **D** | 针对航空噪声修正 | 介于 A、C 之间 | 飞机飞越等高声压航空噪声 |

一个实用的诊断方法：同时记录 LpC 与 LpA，两者差值越大，说明频谱中低频占比越高。相比只看单一计权值，可多获得一层频谱结构信息。

## 六、工程判断

1. **报告里 dB 必须带后缀**：dB(A)、dB(L) 分别标注；裸写 dB 的数据无法追溯计权状态
2. **对标前先核对计权状态**：供应商数据与自家数据一个 dBA 一个 dBL，可能相差 15~20 dB，先对齐计权再谈偏差
3. **低频问题不用 dB(A) 单独评判**：车内轰鸣、排气声这类低频成分突出的问题，dB(A) 存在系统性低估，应补充 Linear 或 C 计权数据
4. **校准可用 1 kHz**：计权开关状态不影响校准读数，但保持固定的操作习惯仍比依赖这一设计特性可靠
5. **记住曲线的骨架**：1 kHz 为零、低频重衰减、4 kHz 附近微放大、6 kHz 以上缓降——掌握曲线形状，查表疏漏时也能发现异常
