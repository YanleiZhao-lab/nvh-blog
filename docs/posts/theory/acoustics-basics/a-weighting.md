# A计权：为什么 40 方等响曲线成了标准

> 麦克风测到的声压级和人耳听到的响度差得很远，耳道在 4 kHz 附近自带共振，耳蜗对低频近乎“失聪”。A 计权用一条频率修正曲线把麦克风的线性世界拉回人耳的听觉世界。这条 1936 年就写进声级计标准的曲线从哪来，怎么用，什么时候反而会“骗人”，一次讲透。

## 一、麦克风与人耳听到的不是同一个世界

同一场声场里，麦克风振膜和鼓膜接收到的声压可以差出好几个 dB。这不是仪器误差，是两套接收系统的物理结构完全不同。

人耳至少有三处“私货”。**耳道共振**：2 cm 出头的耳道是一根四分之一波长共振管，按 343/(4L) 估算共振频率正好落在 4000 Hz 附近，鼓膜处的声压在这个频段被明显抬高。**头躯绕射**：人的头部，躯干和外耳干扰，扭曲了到达鼓膜的声场。**耳蜗偏好**：听觉器官对低频和很高频的检出能力天生就弱，年龄带来的高频听损进一步放大这种不平衡，耳蜗呈对数螺线形状，还让人在低频区分音高的能力远强于高频。

麦克风什么都没有——没有躯干，没有耳廓耳道，没有对数形的听觉器官。它忠实记录声压，人耳忠实“歪曲”声压。

::: info 核心概念
- **计权（Weighting）**：在频域上对测量值逐频率加/减修正量的处理，模拟某种感知或物理效应
- **方（phon，响度级）**：某声音与多响的 1000 Hz 纯音等响，就是多少方，40 方即与 40 dB 的 1 kHz 纯音等响
- **等响曲线（Equal Loudness Curve）**：把同一响度级下各频率所需的声压级连成的曲线，曲线越不平，人耳频响越“偏心”
:::

## 二、一条 1936 年定型的“人耳滤镜”

A 计权是一条标准化曲线：在每个频率上给出衰减或放大的 dB 数，直接叠加到麦克风频谱上，让读数更接近人耳感知。

![A计权曲线：1 kHz 处为 0 dB，两侧分别下沉与微升](/images/a-weighting/aw-curve.png)

*A计权曲线：纵轴为各频率处的增益/衰减量（图源：Simcenter Testing Knowledge Base）*

这条曲线有四个关键特征：

| 频段 | 修正量 | 原因 |
| --- | --- | --- |
| **1 kHz 以下** | 衰减，越低越狠 | 耳蜗对低频不敏感 |
| **1 kHz** | 恰为 0 dB | 曲线的定义锚点 |
| **1 k~6 kHz** | 放大 1~2 dB | 耳道共振抬高了鼓膜处的声压 |
| **6 kHz 以上** | 转为衰减 | 高频听损 + 耳蜗灵敏度下降 |

A 计权的血统可以追溯到 Fletcher-Munson 等响曲线：它取的是**低声级的 40 方等响曲线**的形状——人耳最“偏心”的一条。美国国家标准学会（ANSI）1936 年首次把它写进声级计标准，此后近百年没有变过。

::: warning 工程注意
A 计权不是精确的听觉模型。当年为了做出低成本的模拟电路，曲线被大幅简化：真实人耳的频响会随声级变化（响声听得更“平”），A 计权在任何声级下都是同一条固定曲线。用 dB(A) 外推响度感受时，高声级场景会系统性低估低频的存在感。
:::

下面的演示直接用 IEC 61672-1 定义的解析公式复算这条曲线，看看关键频点对不对得上：

```python
import numpy as np

def a_weight_db(freq):
    # IEC 61672-1 定义的 A 计权公式
    f2 = np.asarray(freq, float) ** 2
    Ra = 12194.0**2 * f2**2 / ((f2 + 20.6**2)
         * np.sqrt((f2 + 107.7**2) * (f2 + 737.9**2)) * (f2 + 12194.0**2))
    return 20 * np.log10(Ra) + 2.0

freqs = [20, 63, 100, 250, 500, 1000, 2000, 4000, 8000, 16000]
print("频率(Hz)   A计权(dB)")
for f in freqs:
    print(f"{f:>6}    {a_weight_db(f):+6.1f}")
```

运行结果要点：1000 Hz 处精确为 0.0 dB，100 Hz 约 -19 dB（手册取整 -20 dB），20 Hz 被砍掉 50 dB：1 k~4 kHz 区间放大不过 1 dB 出头——整条曲线的“重心”全在低频的惩罚上。

## 三、怎么用：谱上的加减法，和两种必须分清的标注

用法本身极其简单：**频谱的每条谱线各自加上该频率的计权量，再合成**。

手册的经典例子：100 Hz 处测得 80 dB，查曲线该频率衰减 -20 dB，结果 60 dB(A)。对数域里滤波就是加减法，这正是 dB 体系统治声学报告的实际原因之一。

![100 Hz 处 -20 dB 衰减的查图用法](/images/a-weighting/aw-100hz.png)

*80 dB 减去 100 Hz 处的 -20 dB 计权，得 60 dB(A)（图源：Simcenter Testing Knowledge Base）*

标注上必须无歧义：加了 A 计权写 **dB(A)** 或 dBA，未计权的原始值写 **dB(L)/dBL/Linear**。报告里只写“dB”三个字母，是数据可追溯性的硬伤。

在 Simcenter Testlab 里，任何图形上右键 Y 轴 → Processing → Weighting → A 即可切换，colormap 和倍频程显示同样支持，甚至嵌在 PowerPoint，Word，Excel 里的 Active Pictures 也能改。

还有一个藏在 1 kHz 零点的巧思：**声校准器几乎都在 1000 Hz 发声**（常见 94 dB 或 114 dB 档）。因为 A 计权在 1 kHz 增益恰好为 0，操作员忘了开，或者忘了关计权开关，校准读数都纹丝不动——从标准设计层面杜绝了一类低级失误。

## 四、dB(A) 不一定比 dB 低：总级是一本能量账

直觉上 A 计权“削掉一大片”，总值应该更低。不一定——**总值在能量域合成，谁占能量大头，总值的走向就听谁的**。

手册给了个口哨的例子：口哨能量集中在约 1600 Hz，落在 A 计权的放大区。未计权总值 84.2 dB，加 A 计权后反而升到 85.1 dB(A)。

![未计权的口哨频谱，总级 84.2 dB](/images/a-weighting/aw-whistle-lin.png)

*未计权：总级 84.2 dB（图源：Simcenter Testing Knowledge Base）*

![加 A 计权后的口哨频谱，总级 85.1 dB(A)](/images/a-weighting/aw-whistle-a.png)

*加 A 计权后：总级反而升到 85.1 dB(A)（图源：Simcenter Testing Knowledge Base）*

放到整车场景，这个道理天天用得上：排气噪声以低频为主，A 计权后总级能掉 20 dB，看起来“轻松达标”，但 30~60 Hz 的怠速轰鸣该烦人还是烦人——dBA 对低频源天生偏乐观。反过来，电驱 PWM 啸叫，齿轮啸叫落在 1 k~6 kHz，A 计权不降反升，主观上也确实更刺耳，两者方向一致。

```python
import numpy as np

def a_weight_db(freq):
    f2 = np.asarray(freq, float) ** 2
    Ra = 12194.0**2 * f2**2 / ((f2 + 20.6**2)
         * np.sqrt((f2 + 107.7**2) * (f2 + 737.9**2)) * (f2 + 12194.0**2))
    return 20 * np.log10(Ra) + 2.0

def overall_db(freqs, levels, weighted=False):
    p2 = 10 ** (np.asarray(levels, float) / 10)      # 各谱线声压平方
    if weighted:
        p2 *= 10 ** (a_weight_db(freqs) / 10)        # 计权 = 能量域逐线缩放
    return 10 * np.log10(p2.sum())                   # 能量求和回 dB

cases = {
    "排气低频主导": ([63, 100, 160, 315], [90, 88, 80, 70]),
    "口哨啸叫型": ([100, 1600, 3200], [60, 84, 70]),
}
for name, (fs, ls) in cases.items():
    lin = overall_db(fs, ls)
    dba = overall_db(fs, ls, weighted=True)
    print(f"{name}: Linear {lin:.1f} dB -> dB(A) {dba:.1f}  ({dba-lin:+.1f})")
```

运行结果要点：低频主导的排气谱总级被砍掉 20.1 dB（92.4 到 72.3），而啸叫型谱总级反涨 1.0 dB（84.2 到 85.2，与手册实测的 85.1 对得上，差 0.1 dB 来自谱线构成不同）。同一根曲线，两种截然相反的结局。

::: tip 判读原则
- 评判决不能只问“有没有加 A”，要先问**能量集中在哪个频段**
- 低频问题（轰鸣，抖动，排气声）只看 dBA 会被严重低估，需配合 Linear 值或 C 计权值交叉判读
- 高频啸叫的 dBA 会比 Linear 更难看，这是物理不是测量事故
:::

## 五、A/B/C/D：一家人四条曲线

A 不是唯一的计权。同一族里还有 B，C，D 三条，区别全在“抄了哪条等响曲线，低频罚多重”。

![A，B，C，D 四种计权曲线对比](/images/a-weighting/aw-bcd.png)

*四条计权曲线：C 最平，D 在高频另有一副面孔（图源：Simcenter Testing Knowledge Base）*

| 计权 | 出身 | 1 kHz 以下低频 | 典型用途 |
| --- | --- | --- | --- |
| **A** | 40 方等响曲线 | 衰减最重 | 法规限值，产品噪声规格的绝对主力 |
| **B** | 70 方等响曲线 | 衰减较轻 | 历史遗物，如今极少使用 |
| **C** | 100 方等响曲线 | 几乎平坦 | 高声级与低频成分突出的场合 |
| **D** | 针对航空噪声修正 | 介于 A，C 之间 | 飞机飞越等高压航空噪声 |

一个实用的免费诊断：同时记录 LpC 和 LpA，两者差值越大，说明频谱里低频占比越高。比只看单一条曲线多得到一层频谱结构信息。

## 六、工程判断

1. **报告里 dB 必须带后缀**：dB(A)，dB(L) 各写各的，裸写 dB 的数据不予采信
2. **对标前先核对计权状态**：供应商数据和自家数据一个 dBA 一个 dBL，差出 15~20 dB 都有可能，先对齐再谈偏差
3. **低频抱怨别用 dBA 打太极**：车内轰鸣，排气声浪这类问题，dBA 天生看不见，补充 Linear 或 C 计权数据
4. **校准放心用 1 kHz**：计权开关状态不影响校准读数，但养成固定习惯仍比依赖这个巧合可靠
5. **记住曲线的骨架**：1 kHz 为零，低频重罚，4 kHz 区微放，6 kHz 以上缓降——能徒手画出这条曲线的形状，查表忘了也不慌
