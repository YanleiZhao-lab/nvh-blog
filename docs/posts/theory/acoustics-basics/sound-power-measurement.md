# 声功率测量：半球包络法与K1/K2修正

> 声压级读数同时依赖测点距离与方位：自由场中测点距离每加倍，声压级下降约 6 dB；同一距离、不同方位的读数也不相同。因此单点声压级不能表征声源的辐射强度。声功率（Sound Power）通过"包络面能量平均 + 测量表面积补偿"的构造，把这两个变量从测量结果中消去。本文从声功率的定义出发，分步推导半球包络法公式，说明能量平均与算术平均的差异、K1 背景修正与 K2 反射修正的能量域推导与适用判据，以及修正量超出可信范围时的处理方式。

一台空压机的验收会上双方各执一词：供方在 1 m 处测得 74 dB，判定合格；需方验收员把声级计退到 4 m，读数 62 dB，同样判定合格——可限值一旦写成“70 dB”，两家结论立刻翻脸。同一台设备、同一天、同一只声级计，只是站的位置不同，“吵不吵”就没了准数。问题出在哪？声压级这个量天生带着距离与方位两个自由度，读数属于测点而不属于声源。行业最后的解法是换一个问题：不再问“在某点听到多少”，而是问“这台设备一共发出多少”——把设备用假想曲面围起来，清点从曲面溢出的全部声能。这条路怎么走、哪些坑必须修，就是本文的内容。

## 一、声压级的两个自由度：距离与方位

用单只麦克风在声源附近读取声压级，是最直接的测量方式，但其结果受两个变量影响，不能表征声源固有的噪声发射量。

**距离**。在自由场（free field）中，测点距离每增加一倍，声压级下降约 6 dB。1 m 处测得 78 dB 的音箱，2 m 处约降至 72 dB。如果验收条款只规定"不得超过 50 dB"而未规定测点距离，则改变测点距离即可显著改变读数：声压级数据在不附距离条件时不具备可比性。

![距离不同，同一声源的声压级读数不同](/images/sound-power-measurement/mic-1m2m.png)

*（图源：网络 侵删）*

**方位**。即使测点距离固定，读数仍随方位变化：声源的声辐射通常具有方向性，音箱正面与背面测点测得的声压级不同。

![同一距离不同方位的麦克风，读数各不相同](/images/sound-power-measurement/mic-positions.png)

*（图源：网络 侵删）*

这里有一个贯穿全文的类比：声功率之于声压级，就像灯泡的瓦数之于桌面的照度。60 W 是灯泡自己的属性，不管你凑近还是退远，灯还是那盏灯；但桌面的照度随你拉开距离一路走低。关键在于这笔账能算平：灯移远一倍，落在单位面积上的光通量降为原来的四分之一，但光所摊开的球面面积扩大四倍，穿过整个球面的总光通一两不少。声功率测量数的就是那个“总光通”：声压读数好比桌面照度，随测点起落；把闭合面上穿出的能量整个收拢求和，距离与方位两笔账就自动平了。

声功率（Sound Power，单位 W）的测量目标是将这两个变量同时消去：**量化声源本身的声辐射强度，使结果与测点距离、方位无关**。因此法规认证与供应商验收条款通常以声功率级而非声压级作为限定量。

::: info 核心概念
- **声功率 W**（Sound Power）：声源单位时间辐射的总声能，单位 W，是声源的固有属性
- **声功率级 Lw**（Sound Power Level）：$L_W = 10\lg(W/W_0)$，参考功率 $W_0 = 1\ \mathrm{pW} = 10^{-12}\ \mathrm{W}$
- **测量面**（Measurement Surface）：包围被测声源的假想闭合面（半球面、箱形面等），声功率等于声强在该面上的面积分
:::

## 二、半球包络法：公式的推导

### 2.1 测量布置

工程上最常见的布置：将被测设备置于硬质反射地面上，用一组固定位置的麦克风在以设备为中心的半球面上将其包围。

![半球形麦克风阵列包络被测设备：左为测点布置图，右为实际测试系统](/images/sound-power-measurement/hemisphere-array.png)

*（图源：网络 侵删）*

这个公式回答的问题是：一圈随位置漂移的声压级读数，怎么折算成一个只属于声源、换场地也不变的量？其中 $\overline{L_P}$ 对应物理里穿过曲面的能量密度（声压平方的面平均），面积项 $10\lg(S/S_0)$ 对应这份能量摊开的窗口大小——离源近读数高但曲面小，离源远读数低但曲面大，两笔账相加，位置变量恰好对消。

半球法的核心公式（手册 Equation 1）由两部分构成：

$$L_W = \overline{L_P} + 10\lg\frac{S}{S_0}$$

- $\overline{L_P}$：全部测点声压级的**能量平均**（energy average，不是算术平均）
- $S$：测量面面积，半球面 $S = 2\pi r^2$（$r$ 为半球半径，单位 m）；参考面积 $S_0 = 1\ \mathrm{m^2}$

下面从声功率的定义出发分步推导该公式。

### 2.2 从定义出发的五步推导

<strong>第一步：声功率级的定义。</strong>

这个公式回答的问题是：给“声源一共发出多少”定一把尺。其中 $W$ 是声源每秒辐射的总声能（W），$W_0=10^{-12}\ \mathrm{W}$ 是基准刻度——就像用瓦数描述灯泡，这把尺与测点位置无关。

$$L_W = 10\lg\frac{W}{W_0}, \qquad W_0 = 10^{-12}\ \mathrm{W}$$

定义只依赖声源辐射的总功率 $W$（单位 W），与任何测点位置无关，这是整个构造的出发点。

这个公式回答的问题是：“总能量”从哪里数起？积分号对应物理里把曲面上每一小块穿过的声能都收拢求和；右边的 $\overline{I}\cdot S$ 则是离散麦克风采样后的工程近似——用面上平均声强乘以面积顶替连续积分。

<strong>第二步：总功率写成测量面上的声强积分。</strong> 声功率是声强 $I$（Sound Intensity，单位 $\mathrm{W/m^2}$）在闭合测量面上的面积分：

$$W = \oint_S I\,\mathrm{d}S \approx \overline{I}\cdot S$$

当测点在测量面上充分采样时，积分可用面上平均声强 $\overline{I}$ 乘以面积 $S$ 代替。这一步把整个面的总能量转化为"可测的平均量乘以面积"。

<strong>第三步：自由场行波中声强与声压的关系。</strong>

这个公式回答的问题是：声强看不见摸不着，拿什么测？在自由场行波里声强正比于声压的平方——其中 $p$ 就是麦克风直接测得的声压，$\rho c$ 是空气的“声学阻力”，两者一除，难测的流量就换成了好测的压强读数。

$$I = \frac{p^2}{\rho c}$$

其中 $\rho c$ 为空气的特性阻抗（characteristic impedance），常温下约取 $400\ \mathrm{Pa\cdot s/m}$。这一步把难以直接测量的声强转换为麦克风可直接测量的声压。

<strong>第四步：代入定义并整理。</strong> 将 $W = \overline{I}\,S = \overline{p^2}\,S/(\rho c)$ 代入定义式：

$$L_W = 10\lg\frac{\overline{p^2}\,S}{\rho c\,W_0}$$

<strong>第五步：拆分为声压级项与面积项。</strong> 取参考声压 $p_0 = 20\ \mathrm{\mu Pa}$。参考值的选取在数值上严格自洽：$(20\ \mathrm{\mu Pa})^2 = 4\times10^{-10}$，恰好等于 $400\times10^{-12}$（即 $\rho c\cdot W_0/\mathrm{m^2}$），于是上式恰好拆成：

$$L_W = \overline{L_P} + 10\lg\frac{S}{S_0}$$

第一项是各测点声压级的能量平均 $\overline{L_P}$，第二项为面积补偿项，只含测量面面积。参考声压、参考功率与特性阻抗的取值相互配套，是公式能够直接相加的数值基础。

![手册中声功率基本公式的构成](/images/sound-power-measurement/equation1-sound-power.png)

### 2.3 能量平均：为什么不能对 dB 值直接取算术平均

这个公式回答的问题是：$N$ 个测点各报一个 dB，怎么合成一个代表整张曲面的数？其中 $10^{L_{P,i}/10}$ 对应把每个对数读数还原成声压平方（真正的能量），求和平均后再取对数回到 dB 刻度——先回到能量域，才是“平均”的正确姿势。

声压级是对数量，平均必须在能量域进行。设 $N$ 个测点的声压级为 $L_{P,i}$，各点声压平方为 $p_i^2 = p_0^2 \cdot 10^{L_{P,i}/10}$（$p_0 = 20\ \mathrm{\mu Pa}$），则能量平均为

$$\overline{L_P} = 10\lg\left(\frac{1}{N}\sum_{i=1}^{N} 10^{L_{P,i}/10}\right)$$

推导依据是能量守恒：通过测量面的总功率等于各测点局部功率之和（等面积采样时 $W \propto \sum_i p_i^2$），而功率正比于声压平方，因此必须先将对数值还原为 $p_i^2$ 求平均，再取对数。

由对数函数的凸性（Jensen 不等式），能量平均恒大于或等于算术平均，测点间读数越分散、两者相差越大。算术平均因此引入系统性负偏差：例如 80 dB 测点的能量是 70 dB 测点的 10 倍，能量平均按此权重计入，算术平均则将其与普通测点同等对待。

### 2.4 表面积补偿：距离无关性的来源

公式第二项 $10\lg(S/S_0)$ 是结果与测点距离无关的关键。取手册算例：声功率 $W = 0.02\ \mathrm{W}$ 的打印机，声功率级 $L_W = 10\lg(0.02/10^{-12}) = 103\ \mathrm{dB}$。在三个半径的半球面上分别测量：

| 半球半径 r | 测量面面积 S = 2*3.14159*r^2 | 平均声压级 Lp | Lp + 10lg(S/S0) |
| --- | --- | --- | --- |
| 1 m | 6.28 m2 | 95.0 dB | 103.0 dB |
| 2 m | 25.13 m2 | 89.0 dB | 103.0 dB |
| 4 m | 100.53 m2 | 83.0 dB | 103.0 dB |

半径从 1 m 增至 4 m，平均声压级下降 12 dB，面积项 $10\lg(S/S_0)$ 相应增加 12 dB，两项之和保持 103 dB 不变。构造逻辑：测点离声源近则声压高但测量面小，离声源远则声压低但测量面大，声压平方与面积的乘积（即总功率）保持不变。

![半球剖面：麦克风离源近则声压高但面积小，离源远则声压低但面积大，两者乘积恒定](/images/sound-power-measurement/hemisphere-cross-section.png)

*（图源：网络 侵删）*

::: warning 工程注意
能量平均 + 表面积补偿成立的前提是：除地面反射面外无其他反射面、无其他声源。这一理想条件在 CAE 仿真中天然成立，在普通厂房中一般不成立，因此需要第三、四节的修正项。测点数量与布置必须按相应标准（如 ISO 3744）执行；随意减少测点会加大能量平均的空间采样误差，该误差直接进入最终结果。
:::

## 三、K1 背景修正：能量域扣除背景贡献

基本公式假设测量环境中只有被测设备在发声。实际厂房中存在通风系统、邻位设备等背景噪声（background noise），麦克风测得的是"设备 + 背景"的总声级。K1 修正的方法：设备停机状态下先测量背景噪声，再将背景贡献从总声级中扣除。

![背景噪声测量：设备停机状态下各倍频程带的声压级](/images/sound-power-measurement/k1-background.png)

*（图源：网络 侵删）*

能量域减法的推导：对互不相干的声源，声压平方（能量）直接相加。设某倍频程带（octave band）测得总声压平方为 $p_{tot}^2$，背景声压平方为 $p_{bg}^2$，则设备自身贡献为 $p_{src}^2 = p_{tot}^2 - p_{bg}^2$。取对数：

$$L_{src} = 10\lg\left(10^{L_{tot}/10} - 10^{L_{bg}/10}\right) = L_{tot} - K_1$$

其中修正量按 ISO 3744 约定取正值、从结果中扣除：

$$K_1 = -10\lg\left(1 - 10^{-\Delta/10}\right) \ge 0, \qquad \Delta = L_{tot} - L_{bg}\ (\mathrm{dB})$$

级差 $\Delta$ 越大，$K_1$ 越接近 0（无需修正）；级差越小，修正量越大、结果对测量波动越敏感。判据如下：

| 级差 D（总级减背景级） | K1 修正量 | 处理方式 |
| --- | --- | --- |
| D < 0 dB | 无意义 | 背景高于设备运行总级，测试无效 |
| D >= 15 dB | 0.14 dB 以内 | 修正量可忽略，不再修正（手册判据） |
| 6 <= D < 15 dB | 0.14 ~ 1.26 dB | 按公式逐倍频程带修正 |
| D < 6 dB | 大于 1.26 dB | 超出 ISO 3744 允许范围，不确定度过大 |

一个有物理意义的校核点：$\Delta = 3\ \mathrm{dB}$ 时 $p_{src}^2 = p_{bg}^2$，背景与设备能量贡献相等，$K_1 = 3.02\ \mathrm{dB}$：结果由两个近乎同量级的测量值之差决定，任何一处的测量波动都会被放大。

K1 修正按**倍频程带**逐带进行：总级差合格不代表每个带都合格。例如中频为主的设备置于高频风机旁，总级差 10 dB 可能掩盖高频带级差仅 3 dB 的事实，逐带核算才能发现。

## 四、K2 反射修正：以标准声源标定场地

基本公式的另一个隐含假设是：除地面反射面外无其他反射。普通测试间的墙面反射会使声压级整体偏高，算出的 $L_W$ 偏大。K2 修正的方法：**使用声功率已知且可复现的标准声源（Reference Sound Source）在同一场地、同一测量面上测量一遍**。

推导逻辑：设标准源某倍频程带标称声功率级为 90 dB，在该场地实测 91 dB。高出的 1 dB 来自场地反射而非标准源本身；假设被测设备与标准源受到相同的反射增量，将该增量从被测结果中扣除。计入两个修正项后，完整公式为（手册 Equation 2）：

$$L_W = \overline{L_P} + 10\lg\frac{S}{S_0} - K_1 - K_2$$

![虚拟 CAE 仿真中的声功率测试：无额外背景噪声与反射的理想环境](/images/sound-power-measurement/cae-virtual-test.png)

*（图源：网络 侵删）*

K2 与 K1 同样逐倍频程带操作。反射对低频带的影响通常大于高频带（低频波长与房间尺寸可比，驻波效应显著），各带的 K2 一般不同，不能对全频段使用单一修正值。

::: warning 工程注意
K1/K2 是有限范围内的修正手段。当背景级差不足 6 dB、或 K2 修正量明显偏大时，说明场地不满足声压法声功率测试条件，应更换消声室/半消声室，或改用声强法（ISO 9614 系列，可在普通现场实施）。超出适用范围的修正结果在认证复测中通常无法复现。
:::
## 五、Python 数值验证

### 5.1 半球法的不变性

```python
import numpy as np

W = 0.02                      # 声功率 0.02 W（手册打印机算例）
W0, p0, rho_c = 1e-12, 20e-6, 400.0   # 参考功率、参考声压、空气特性阻抗

print(f"声功率级 Lw = {10*np.log10(W/W0):.1f} dB（理论值，与距离无关）")
for r in [1.0, 2.0, 4.0]:     # 三个不同半径的半球测量面
    S = 2 * np.pi * r**2      # 半球表面积
    I = W / S                 # 面上平均声强 = 功率/面积
    Lp = 10*np.log10(I * rho_c / p0**2)   # 由 I = p^2/(rho*c) 反算声压级
    Lw = Lp + 10*np.log10(S / 1.0)        # 加回表面积项
    print(f"r={r} m: S={S:6.2f} m2  Lp={Lp:.1f} dB  Lp+10lg(S)={Lw:.1f} dB")
```

半径 1 m 处平均声压级 95.0 dB，4 m 处降至 83.0 dB，三行末列均回到 103.0 dB：距离变化被面积项精确补偿，这是声功率"与测点距离无关"的数值验证。

### 5.2 能量平均与算术平均的差异

```python
import numpy as np

p0 = 20e-6                                  # 参考声压
Lp = np.array([72, 75, 68, 80, 77, 73, 79, 71, 74, 76.])  # 10 个测点声压级

p2 = p0**2 * 10**(Lp/10)                    # dB 还原到声压平方（能量域）
Lp_energy = 10*np.log10(p2.mean() / p0**2)  # 能量平均再取对数
Lp_arith  = Lp.mean()                       # 错误做法：直接平均 dB

print(f"能量平均 Lp = {Lp_energy:.2f} dB")
print(f"算术平均 Lp = {Lp_arith:.2f} dB（偏低 {Lp_energy - Lp_arith:.2f} dB）")
```

能量平均 75.81 dB，算术平均 74.50 dB，相差 1.31 dB：80 dB 上下的高声级测点在能量求和中占主导权重，直接平均 dB 会系统性低估。在报告中注明平均方式，是结果可复核的基本要求。

### 5.3 K1 修正量数值表

```python
import numpy as np

print(f"{'级差 D(dB)':>10} {'K1(dB)':>8} {'修正量':>8}")
for d in [15, 10, 6, 4, 3]:                  # 总声级与背景级的差
    k1 = -10*np.log10(1 - 10**(-d/10))       # K1 = -10lg(1-10^(-D/10))，正值
    print(f"{d:>10} {k1:>8.2f} {k1:>7.2f} dB")
```

级差 15 dB 时 K1 仅 0.14 dB，可忽略，据此免修正；级差 6 dB 时为 1.26 dB，对应 ISO 3744 允许的下限；级差 3 dB 时达 3.02 dB，此时背景与设备能量贡献相等，结果实质上由两个大数之差决定，不确定度不可接受。

## 六、结果的表达形式与应用

声功率测试的最终交付物通常是 **A 计权（A-weighted）倍频程谱**：横轴为倍频程带，纵轴为以 1 pW 为参考的 dB 值。

![声功率测试结果：A 计权倍频程谱](/images/sound-power-measurement/octave-spectrum.png)

典型用法：

- **对标限值**：法规或验收条款逐倍频程带规定限值，任一超带即不合格；总 A 计权值只是汇总指标
- **改款评估**：同一产品降噪改款前后逐带对比谱形，信息量大于单看总值
- **跨场地可比**：K1/K2 把环境差异从结果中剥离，不同实验室的数据因此具备可比性

| 应用场景 | 采用声功率级的原因 |
| --- | --- |
| 出口认证（如欧盟指令 2000/14/EC） | 法规限值以声功率规定，与安装位置无关 |
| 供应商验收条款 | 双方场地不同，声功率是唯一可比基准 |
| 产品对标与改款评估 | 消除测量距离/方位变量，谱形可直接比较 |
| 声源排序（排查） | 多台设备的声功率可按能量相加得总贡献，声压级不能直接相加 |

手册列出的声压法声功率标准包括 2000/14/EC、ISO 3744、ISO 3745、ISO 6394、ISO 6395 与 ARI 260；声强法对应 ISO 9614-1/9614-2。

::: tip 方法选择
- 具备消声室/半消声室条件：声压法半球阵列（ISO 3744 工程级、ISO 3745 精密级），精度与认证认可度最高
- 只有普通现场：声强法（ISO 9614 系列），对稳态背景不敏感，声强云图还可用于声源定位；代价是可用带宽受限、测量耗时较长
- 测前背景噪声预查：先核算各倍频程带级差，D 不足 6 dB 的带在测试前即应预警，避免测量完成后才发现数据无效
:::

## 七、小结

声功率公式由四个要素构成（手册结论）：声压测量，即麦克风阵列加能量平均，消除方位依赖；测量面积，即补偿测点距离，消除距离依赖；K1 背景修正与 K2 反射修正，把环境变量从结果中剥离。评估一份声功率测试结果的可信度，按顺序核查三项：各倍频程带背景级差是否达到 6 dB、K2 修正量是否在合理范围、测点阵列与测量面是否符合相应标准。三项均满足，数据才具备验收与认证用途。

## 一句话记住

声压级像桌面照度、随测点起落，声功率像灯泡瓦数、只属于声源：包络面上做能量平均、再补上表面积这笔账，距离与方位自动对消；背景级差不足 6 dB 或 K2 修正压不住时，换场地比硬修更可靠。
