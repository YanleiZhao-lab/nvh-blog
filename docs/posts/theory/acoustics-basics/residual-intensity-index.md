# 残余声强与声压残余声强指数：声强测量的底噪

> 同一台设备、同一天、同一间车间，两次声强扫描测出的声功率差了 2 dB——仪表校过、探头没摔过，差在哪？答案常常不在声场里，而在测量链自己身上：两只传声器通道之间那零点几度的相位失配，会凭空"造"出一股声强来。声压表有本底噪声，声强表的本底噪声就是残余声强。本文讲清楚残余声强（RI）与声压残余声强指数（δpIo）的物理来源、标定方法、随频率与隔离垫间距的变化规律，以及工程上怎样用动态性能指数把这块"底噪"折算成可测下限。

声强测量的现场有个反常识的现象：把声强探头放进一个声压处处均匀的声场——比如耦合腔里——按理说两只传声器听到的是同一个声压，压力梯度为零，声强读数应该严格归零。可表头上的数字不是零，而且这个"假声强"还会随着腔内声压级一起涨落：腔里 90 dB 时读出一股"流"，加大到 100 dB，这股"流"也跟着大十倍。它不是环境漏进来的声，而是测量链自己的产物。理解这股伪声强从哪来、怎样标定它、它给测量划定了怎样的禁区，是声强法测声功率前必须补的一课。

## 一、为什么声强表有一个"会漂移的零点"

先看一个现场场景。车间里对一台齿轮箱做 ISO 9614 声强扫描，报告交出去三天被打回：测量面五个分块里有两种读数对不上账，复测一遍，整机声功率差出 2 dB。排查流程走了一圈：声级校准器一吹，两只传声器灵敏度都对；探头没受过冲击；扫描速度也均匀。最后把探头伸进耦合腔一测——声压处处均匀的腔体里，声强读数有 0.0001 W/m² 量级的非零值，而且方向恒定。这就是残余声强（Residual Intensity, RI）：不是声场里的能量流，而是两通道相位失配伪造出来的表观声强。

打个比方。声强测量像用两根标尺测河面上两处的水位差来推流量：水位差除以两尺间距，就是水面坡度，乘上流速系数便得流量。理想情况下两根尺子完全一样，水面平静时读数差为零、流量为零。但只要两根尺子的刻度起点差了一丝——对应两通道的相位失配——哪怕水面绝对平坦，你也会"测出"一个恒定的水位差，进而算出一股不存在的流量。这个伪流量有两个特征：其一，水面（声压）抬高一倍，伪流量（残余声强）也跟着大一倍——它随声压级浮动，不是固定值；其二，真正固定不变的是"水位差读数误差折算成流量的比例"，也就是两尺刻度差与间距的比值——对应声压级与伪声强级之差，即声压残余声强指数 δpIo。记住这两根标尺，后文所有公式都能落到它上面。

用数字建立量级感。一副典型探头：隔离垫间距 12 mm，两通道相位失配 0.3°（约 0.005 rad，工程上常见的量级）。平面波沿探头轴向传播时，声波走过 12 mm 间距累积的相位 kd 在 500 Hz 约 0.11 rad——是失配的 21 倍；到了 63 Hz，kd 只剩 0.014 rad，还不到失配的 3 倍。真实信号与伪信号的悬殊程度随频率骤降：500 Hz 时 δpIo = 10lg(0.11/0.005) ≈ 13 dB，63 Hz 时只剩 4 dB 上下。也就是说，同一个探头，中频段还能分清"真声强"与"伪声强"差一个数量级，到低频两者已经混在一起——这就是声强测量的低频困境，也是本文要定量展开的主线。

::: info 核心概念
- <strong>残余声强（Residual Intensity, RI）</strong>：两通道相位失配在均匀声压场中产生的表观声强，给定声压级下测量系统可检测的最低声强级，随声压级浮动
- <strong>声压残余声强指数（Pressure-Residual Intensity Index, δpIo）</strong>：同一信号馈入两通道时的声压级与法向声强级之差，不随声压级变化，是探头标定状态的固有参数
- <strong>相位失配（Phase Mismatch, φe）</strong>：两只传声器及前置放大通道之间的残余相位差（rad），残余声强的物理源头
- <strong>动态性能指数（Dynamic Capability Index, Ld）</strong>：δpIo 扣除按精度等级选取的偏差因子 χ 后的探头可用工作范围
:::

## 二、残余声强从哪来：互谱虚部里的相位账

声强探头由间距 d 的两只传声器 A、B 组成，法向声强由两路信号互功率谱的虚部计算（频域 p-p 法，推导见声强法测声功率一篇）。这里先把这个公式摆出来，因为它就是残余声强的发生器：

这个公式回答的问题是：两只传声器的信号怎样组合出声强？其中 $S_{12}$ 对应物理里两路声压信号的互功率谱，$d$ 是探头间距，$\rho$ 是空气密度——互谱的虚部承载着两路的相位差信息，声强全部由它算出。

$$
I_n = -\frac{1}{2\pi f \rho d}\,\mathrm{Im}\{S_{12}\}
$$

均匀声压场中两只传声器信号完全相同，互谱虚部为零，声强应为零。但两通道之间存在相位失配 φe 时，即使声压相同，第二路信号相对第一路多转了 φe 角度，互谱虚部不再为零：

$$
\mathrm{Im}\{S_{12}\} \approx -|S_{12}|\,\phi_e \quad (\phi_e \text{ 为小量})
$$

代回上式即得残余声强。它的大小与声压平方成正比——腔内声压级抬高 10 dB，残余声强同样抬高 10 dB，"水位抬高、伪流量同步变大"。因此残余声强级本身不能当指标用，要用就除掉声压级：

手册式（5-3）把残余声强定义为级差形式。这个公式回答的问题是：给定声压级之下，这套探头最低能测到多大的声强？其中 $L_p$ 对应物理里测点的声压级，$\delta_{pIo}$ 是探头的声压残余声强指数——差值就是测量下限。

$$
L_{RI} = L_p - \delta_{pIo}
$$

而 δpIo 的定义正是"同一信号同时馈入两个通道时"的声压级与声强级之差（手册式 5-5）：

$$
\delta_{pIo} = L_p - L_{I_n} \quad \text{(dB)}
$$

标定方法由此直接导出：把探头放进声压处处均匀的声场（耦合腔，或声学驱动的密闭小腔），记录声压级与"测出的"声强级，两者相减即得 δpIo。两根标尺的刻度差，就这样用一次均匀场实验称了出来。

## 三、δpIo = 10lg(kd/φe)：三个变量各自的工程含义

δpIo 与硬件参数的关系可由平面行波导出。平面波沿探头轴向传播时，两传声器间的相位传播差为 kd（k = ω/c 为波数，c 为声速）；通道失配 φe 产生的残余声强与平面波声强之比为 φe/(kd)。

这个公式回答的问题是：探头的"本征干净程度"由什么决定？其中 $kd$ 对应物理里声波走过两只传声器间距所累积的相位，$\phi_e$ 是两通道的相位失配——比值取对数，就是真实信号与伪信号的悬殊倍数。

$$
\delta_{pIo} = 10\,\lg\frac{k d}{\phi_e} \quad \text{(dB)}
$$

三个变量，三条工程线索：

<strong>频率 f（通过 k = 2πf/c）</strong>：频率减半，k 减半，δpIo 直降 6 dB。低频声强测量难，不是难在信号弱，而是难在"真伪对比度"坍塌——声波走过 12 mm 间距累积的相位太短，失配那一点角度占了上风。每倍频程 6 dB 的斜率意味着从 1 kHz 降到 63 Hz（约 4 个倍频程），δpIo 掉约 24 dB。

**间距 d**：加大隔离垫间距直接抬高 kd，低频 δpIo 线性改善。但 d 过大时有限差分近似（用割线斜率代替切线斜率）在高频失效，通常按"1 dB 准则"定高频上限：50 mm 垫约到 1.25 kHz，12 mm 垫约到 5 kHz。低频动态范围与高频测量上限是一对跷跷板，选垫就是选工作频带。

**失配 φe**：同一副探头，φe 由两只传声器与前置放大通道的配对状态决定。探头受冲击、更换隔离垫、更换前放或通道分配，φe 都会变——δpIo 必须重标。它是"每一对通道"的属性，不是"某一型号探头"的属性，二手探头接手第一件事就是进耦合腔复标。

<strong>从 δpIo 到可用下限还要再扣一道安全余量。</strong> 直接拿残余声强级当测量下限，测量值将贴着底噪走，精度没有保证。ISO 9614 引入偏差因子 χ（bias factor）：精密级与工程级取 10 dB，观察级取 7 dB。扣除后的动态性能指数（手册式 5-7）：

$$
L_d = \delta_{pIo} - \chi \quad \text{(dB)}
$$

探头的有效工作范围由此写成一道双边不等式（手册式 5-6）：

$$
L_p - \delta_{pIo} + \chi < L_I < L_p \quad\Longleftrightarrow\quad L_p - L_d < L_I < L_p
$$

上限是声压级（自由场中沿传播方向测量时声强级等于声压级，其他声场里法向声强是矢量投影、只会更低），下限是扣除安全余量后的残余声强级。声强读数必须落在这一条带里，精度等级才有依据；判据怎么逐频带核验、不满足时怎样缩短测量距离，声场指数一篇有完整展开，本文不重复。

## 四、逐频带算一遍：同一副探头在七个倍频程里的能力表

把上述公式装进 numpy，对一副具体探头（12 mm 垫、0.3° 失配）逐频带列账，并按精密级（χ = 10 dB）核验某测量面的判据一（Ld − F2 > 0，F2 为测量面声压—声强指数，此处作为给定的现场数据）：

```python
import numpy as np

rho, c, d = 1.2, 340.0, 0.012          # 空气密度/声速/12mm 隔离垫
phi_e = np.deg2rad(0.3)                # 两通道相位失配 0.3 度
f = np.array([63, 125, 250, 500, 1000, 2000, 4000])   # 倍频程中心频率
kd = 2*np.pi*f/c*d                     # 声波走过间距累积的相位
delta = 10*np.log10(kd/phi_e)          # 声压残余声强指数 δpIo
Ld = delta - 10                        # 动态性能指数（精密级 χ=10dB）
F2 = np.array([3.0, 4.5, 6.0, 8.0, 9.0, 7.5, 5.0])    # 某测量面实测 p-I 指数
print("  f(Hz)    kd    δpIo    Ld    F2   Ld-F2  判定")
for fi, kdi, di, ld, f2 in zip(f, kd, delta, Ld, F2):
    ok = "PASS" if ld - f2 > 0 else "FAIL"
    print(f"{fi:6.0f} {kdi:6.3f} {di:6.1f} {ld:6.1f} {f2:5.1f} {ld-f2:6.1f}  {ok}")
print(f"Lp=90dB 时 63Hz 残余声强级 L_RI = {90-delta[0]:.1f} dB，"
      f"该频带 Ld={Ld[0]:.1f} dB（负值：下限高于声压级，全带失效）")
```

运行结果（实测输出）：

```
  f(Hz)    kd    δpIo    Ld    F2   Ld-F2  判定
    63  0.014    4.3   -5.7   3.0   -8.7  FAIL
   125  0.028    7.2   -2.8   4.5   -7.3  FAIL
   250  0.055   10.2    0.2   6.0   -5.8  FAIL
   500  0.111   13.3    3.3   8.0   -4.7  FAIL
  1000  0.222   16.3    6.3   9.0   -2.7  FAIL
  2000  0.443   19.3    9.3   7.5    1.8  PASS
  4000  0.887   22.3   12.3   5.0    7.3  PASS
Lp=90dB 时 63Hz 残余声强级 L_RI = 85.7 dB，该频带 Ld=-5.7 dB（负值：下限高于声压级，全带失效）
```

这张表把三条工程线索全部显形。其一，δpIo 每倍频程涨约 3 dB（kd 翻倍），四个倍频程累计约 18 dB——低频判据最先失守，且失守幅度大。其二，500 Hz 处 Lp = 90 dB 的声场，残余声强级已有 76.7 dB：凡是读出的声强级低于这个数，都可能只是相位失配的"伪流量"。其三，1 kHz 以下全部 FAIL，处理方向按代价排序：缩短测量面到声源的距离（F2 随直达声占比上升而下降），或换 50 mm 长垫（kd 增大四倍多，δpIo 低频抬升约 6~14 dB，代价是高频上限跌到 1.25 kHz 附近，频带要重新规划）。

再用仿真核验一遍 δpIo = 10lg(kd/φe) 本身。构造一个纯电子的"耦合腔实验"：同一列 500 Hz 声压信号喂给两通道，仅在 B 通道加上 0.3° 相位超前，按互谱法算出表观声强，与平面波参考声强 p²/(ρc) 作比：

```python
import numpy as np

fs, T = 48000, 8.0                     # 采样率/时长
N = int(fs*T)
rho, c, d = 1.2, 340.0, 0.012
phi_e = np.deg2rad(0.3)
f0 = 500.0
t = np.arange(N)/fs
A = np.sqrt(2)*np.cos(2*np.pi*f0*t + 0.7)        # 均匀场：两通道同一声压
FA = np.fft.rfft(A)
freqs = np.fft.rfftfreq(N, 1/fs)
band = np.abs(freqs - f0) < 5                    # 500Hz 附近谱线
FB = FA.copy()
FB[band] = FA[band]*np.exp(1j*phi_e)             # B 通道相位失配
S12 = 2*np.conj(FA[band]).dot(FB[band])/N**2     # 单边互谱
SAA = 2*(np.abs(FA[band])**2).sum()/N**2         # 单边自谱
I_RI = -np.imag(S12)/(2*np.pi*f0*rho*d)          # 互谱法算出的表观声强
I_ref = SAA/(rho*c)                              # 平面波参考声强 p^2/(ρc)
print(f"残余声强 I_RI = {abs(I_RI):.3e} W/m2（纯伪流量）")
print(f"δpIo 仿真值 = {10*np.log10(I_ref/abs(I_RI)):.2f} dB，"
      f"理论 10lg(kd/φe) = {10*np.log10(2*np.pi*f0/c*d/phi_e):.2f} dB")
```

运行结果（实测输出）：

```
残余声强 I_RI = 1.157e-04 W/m2（纯伪流量）
δpIo 仿真值 = 13.26 dB，理论 10lg(kd/φe) = 13.26 dB
```

两行数字严格吻合：均匀场里"什么都没有"，互谱虚部却算出 0.000116 W/m² 的表观声强——把它折成级差，正是 10lg(kd/φe)。公式与标定实验闭环了。

## 五、工程上怎样管好这块"底噪"

| 场景 | 做法 | 依据 |
| --- | --- | --- |
| **试验前** | 探头进耦合腔（或声压处处均匀的等相场）标定 δpIo，记录随频率的谱 | δpIo 是每一对通道的属性，与上次标定无关的记忆不可靠 |
| **探头受冲击/换垫/换前放后** | 重新标定 | φe 变了，δpIo 随之变；台架上拆装过的探头尤其如此 |
| **低频段判据 FAIL** | 先缩短测量面到声源的距离；仍不行换更长隔离垫并重划频带 | F2 随直达声占比上升而下降；kd 抬升 δpIo |
| **报告数据** | 附 δpIo 谱与 Ld 谱，逐频带标注判据结果 | ISO 9614-1 的验收要求，审核复现的凭据 |
| **疑似读数贴底** | 对照 L_RI = Lp − δpIo 检查该频带声强级是否高于下限 | 低于下限的读数可能是伪流量 |

::: warning 三个易错点
- **把 δpIo 当型号参数抄说明书**：它属于"这一对通道"的当前状态，受冲击、换件后即失效，必须现场复标
- **用残余声强级当固定门槛**：L_RI 随声压级浮动，同一探头在 80 dB 声场和 100 dB 声场里的下限差 20 dB，跨工况比较必须重新折算
- **低频只换垫不核频带**：50 mm 垫把高频上限压到 1.25 kHz 附近，若测量频带原定到 5 kHz，换垫后高频段反而失效——垫与频带要一起改
:::

在 Simcenter Testlab 中，声强测量通道以"通道对"为单位组织（相邻两个通道成一对），互谱与声强计算在分析端完成；Sound Power Testing 系列（按 ISO 9614）会在结果中逐频带给出动态性能指数与判据状态，判据不满足的频带直接标红。δpIo 谱则属于探头标定数据，进耦合腔测一次即可获得，随测量数据一并归档。

## 六、小结

残余声强是两通道相位失配在均匀声压场中伪造的表观声强，随声压级浮动；固定不变的特征量是声压残余声强指数 δpIo = Lp − L_In = 10lg(kd/φe)，它由频率、隔离垫间距与通道失配三要素决定，每倍频程约涨 3 dB，低频是短板。扣除偏差因子 χ（精密级/工程级 10 dB、观察级 7 dB）得动态性能指数 Ld，声强读数落在 Lp − Ld < L_I < L_p 带内精度才有依据。探头受冲击、换垫、换前放后 δpIo 必须复标；低频判据失守时按"缩距优先、换垫其次、频带重划"的顺序处理。

## 一句话记住

声强表的底噪叫残余声强：两通道零点几度的相位失配伪造成一股随声压涨落的"假流量"；固定的是级差 δpIo = 10lg(kd/φe)，低频 kd 塌陷使它每倍频程掉 3 dB——扣掉精度安全余量 χ 才是可用下限，探头动过就得进耦合腔重标。
