# 声品质评价指标：响度、尖锐度、粗糙度

> 两台电动车车内噪声同为 38 dB(A)，一台听感安静平顺，一台的窄带呜呜声引发明显抱怨。差别不在声压级，而在声品质。响度、尖锐度、粗糙度、抖动强度这组心理声学指标（Psychoacoustic Metrics）分别定量刻画"多响、多刺、多糙、多晃"四个感受维度。本文依照 Simcenter Testing 理论手册，逐一说明各指标的物理来源、参考定义、标准算法与计算式，并给出整车 NVH 分析中以它们补充或替代 dB(A) 的适用条件。

## 一、dB(A) 够用的时候，和不够用的时候

声压级是最基础的声信号描述量，$20\,\mu\mathrm{Pa}$ 是标准化听阈——正常听力的人平均能听到的 1000 Hz 最低声音。可听声压跨越十几个数量级，人耳对声刺激的反应又近似对数规律，所以工程上普遍采用分贝标尺。

但分贝只回答"多少能量"。人耳是一台复杂的非线性接收装置：外耳的耳廓绕射和耳道共振使 1 kHz 到 10 kHz 附近灵敏度最高；内耳耳蜗的非线性使响度与声压级不成线性关系；听觉还涉及双耳，影响定位与感受。结果就是：**两个 dB(A) 相同的声音，主观感受可以完全不同**。

车辆噪声里最典型的例子：刮水器噪声、燃油泵噪声、电动机的呜呜声、仪表板的咔啦咔啦声——这些对总声压级贡献很小，却最容易引起厌烦。反过来，关车门的"砰"传递豪华感，赛车加速声传递运动感，这些"好声音"不应被一刀切地消掉。声品质分析的对象，就是这些 A 计权声级无法反映的问题。

::: info 核心概念
- **声品质（Sound Quality）**：声音的主观属性总和——舒适、厌烦、愉悦、信息含量，超出声压级所能表达的部分
- **心理声学指标（Psychoacoustic Metrics）**：对声信号做特殊处理、逼近听觉感受的定量指标，其中响度、尖锐度、粗糙度、抖动强度是四项基本指标
- **声品质三步法**：记录（高质量/双耳）→ 评价（指标计算或主观评审）→ 修改（时域/频域/阶次域改信号做对比试听）
:::

## 二、响度：方（phon）的对数标尺与宋（sone）的线性标尺

响度级（Loudness Level）以方（phon）为单位，规定某声音与多响的 1000 Hz 纯音等响即为多少方——对 1 kHz 纯音，方值就等于其声压级 dB 值。等响曲线（equal-loudness contours，自由场纯音与扩散场窄带噪声版本已并入 ISO 226）是它的物理基础。

方仍是对数标尺，"响一倍"无法直接读出。宋（sone）标尺解决这个问题：宋由方按下式导出：

$$
S = 2^{(P-40)/10} \quad \text{(sone)}
$$

其中 $P$ 为响度级（phon），$S$ 为响度（sone）。从定义出发分两步理解：

1. 代入 $P = 40$ 方，得 $S = 2^0 = 1$ 宋——40 方响度级被定义为 1 宋的锚点；
2. $P$ 每增加 10 方，指数增加 1，$S$ 翻倍——即**两倍响的声音有两倍的宋值**，宋是感觉响度的线性标尺。

工程汇报中，"响度从 4 宋降到 2 宋（主观响度减半）"比"降低 10 dB"直观得多。

宽带声不能只看总值。内耳等效于一组衔接的带通滤波器——**临界带（Critical Band）**，以巴克（Bark）标尺刻度：500 Hz 以下各带带宽近似恒定，约 110 Hz；高频段则扩展为约 23% 的恒百分比带宽，与耳蜗的频率—位置对数特性相符。响度沿 Bark 轴分布为**局部响度**（specific loudness）$N'(z)$，单位宋/Bark（sone/Bark）。这条分布曲线往往比总响度更能定位问题——据此可直接判断哪个频带对总响度贡献最大。

### 掩蔽效应：响度计算必须计及的听觉特性

同一临界带内的声能量，响度上"合在一起算"：高声级分量会把频率相近的低声级分量**掩蔽（masking）**掉。一个 50 dB、4 kHz 的纯音，在中心 1200 Hz、90 dB 的窄带背景噪声中仍可听到；背景升到 100 dB 时该纯音被完全掩蔽。掩蔽声级越高，受掩蔽的频带越宽——这就是 A 计权文章里"哨声加 A 计权反而更高"现象背后的听觉机制之一：被放大频段的响度贡献超过了低频衰减的影响。

### 两种标准算法

| 算法 | 标准 | 输入数据 | 特点 |
| --- | --- | --- | --- |
| **斯蒂文司 Mark VI** | ISO 532A（1975）/ ANSI S3.4-1980 | 1/1 倍频程声压级 | 查图得各带响度指数 S，按合成式计算总响度；只适用混响场中平稳宽带噪声 |
| **斯蒂文司 Mark VII** | 未入 ISO | 倍频程声压级 | 更新的计算图表，参考频率改 3150 Hz（32 dB 处定义为 1 宋），附加 PLdB 感觉响度级（约比方值低 8 dB） |
| **兹维克尔（Zwicker）** | ISO 532B | 1/3 倍频程声压级 | 自由场/扩散场各一套图组，显式计入掩蔽（含各带斜坡边缘滤波特性），支持时变信号跟踪；工程主流 |

斯蒂文司 Mark VI 的总响度合成式为：

$$
S_t = S_m + F\left(\sum S - S_m\right) \quad \text{(sone)}
$$

其中 $S_t$ 为总响度（sone），$S_m$ 为各频带中最大的响度指数（sone），$\sum S$ 为所有频带响度指数之和（sone），$F$ 为反映掩蔽效应的分响度贡献因子，取值依赖倍频程类型：1/1 倍频程取 0.3，1/3 倍频程取 0.15。物理意义：只有最响的频带全额计入，其余频带的响度贡献按 $F$ 折减后累加——对应高声级频带对频率相近的低声级频带的掩蔽。

::: tip 工程选择
- 稳态宽带噪声快速评估 → Stevens Mark VI 查表即可
- 含纯音、多分量的复杂声，或需要沿时间跟踪 → Zwicker（ISO 532B）
- 瞬态声（关门声、咔哒声）→ Zwicker 时变响度，注意帧长要覆盖约 20 ms 的听觉"积聚"时间——猝发音短于 20 ms 响度会降低，长于 20 ms 则几乎与时长无关
:::

## 三、尖锐度、粗糙度、抖动强度：三个补充指标的定义与计算

响度解决"多响"，其余三个指标分别刻画谱形与幅值调制带来的感受维度。

**尖锐度（Sharpness）**区分尖锐与沉闷，主要取决于谱形心的位置——高频成分占比越高越尖。参考声：中心频率 1 kHz、声压级 60 dB、带宽一个临界带的窄带噪声定义为 1 acum。计算上相当于对局部响度谱做一次矩：

$$
S'(z) = 0.11\,\frac{N'(z)\, g(z)\, z}{\displaystyle\sum_{0\,\mathrm{Bark}}^{24\,\mathrm{Bark}} N'(z)\,\Delta z}
$$

其中 $N'(z)$ 为该临界带的兹维克尔局部响度（sone/Bark），$z$ 为临界带率（Bark），$g(z)$ 为用于强化高频分量的计权函数。分母即总响度（sone），因此 $S'(z)$ 是局部响度以 $z$ 为臂长、以 $g(z)$ 为权的一阶矩——矩心频率越高，声音越尖。

总尖锐度由尖锐度分量沿 Bark 轴求和得到：

$$
S = \sum_{0\,\mathrm{Bark}}^{24\,\mathrm{Bark}} S'(z)\,\Delta z \quad \text{(acum)}
$$

计权函数分段定义（16 Bark 约对应 3 kHz）：

$$
g(z) =
\begin{cases}
1, \quad 0 \le z \le 16\ \mathrm{Bark} \\
0.066\, e^{0.171 z}, \quad z > 16\ \mathrm{Bark}
\end{cases}
$$

16 Bark 以下计权恒为 1；以上按指数规律上升（在 16 Bark 处 $0.066\,e^{0.171 \times 16} \approx 1.02$，近似连续衔接），即高频成分对尖锐感的贡献被非线性放大。限带噪声实验结果与此一致：同样带宽，中心频率越高越尖。

**粗糙度（Roughness）**针对幅值调制声。调制频率在约 15～300 Hz 区间时，人耳跟不上包络起伏，听到的是一种稳定但粗糙、令人厌烦的声音——发动机噪声里分数谐波引起的调制就是典型。调制频率低于 15 Hz，粗糙感退化为下述的抖动感；调制频率升至 150～300 Hz 附近，载波与上、下边带可被分辨为三个独立的音，粗糙感随之减弱。单位 asper：1 kHz、60 dB 纯音被 70 Hz、100% 幅值调制时定义为 1 asper。幅值调制声的粗糙度可近似表示为：

$$
R \cong f_{\mathrm{mod}} \cdot \Delta L \quad \text{(asper)}
$$

其中 $f_{\mathrm{mod}}$ 为调制频率（Hz），$\Delta L$ 为考虑瞬态掩蔽后的**掩蔽深度**（dB）——即时变响度样本最大值与最小值之差，不是信号包络的峰谷差，这一点常被忽视。按此近似，掩蔽深度相同时粗糙度随调制频率线性增长。

**抖动强度（Fluctuation Strength）**处理调制频率低于约 20 Hz 的工况，此时能直接感到音量起伏。同样 RMS 值下，起伏的声音比平稳声显得更响、更烦——电动车低速蜂鸣、鼓风机调速时的呜呜声常落在这个区间。单位 vacil：1 kHz、60 dB 纯音被 4 Hz、100% 调制时定义为 1 vacil。其近似式为：

$$
F \approx \frac{\Delta L}{f_{\mathrm{mod}}/4\,\mathrm{Hz} + 4\,\mathrm{Hz}/f_{\mathrm{mod}}} \quad \text{(vacil)}
$$

由均值不等式，分母 $f_{\mathrm{mod}}/4 + 4/f_{\mathrm{mod}} \ge 2$，当且仅当 $f_{\mathrm{mod}} = 4$ Hz 时取等号——抖动强度在 4 Hz 处最大，两侧近似对称下降，与粗糙度对 70 Hz 附近最敏感形成呼应。

| 指标 | 感觉维度 | 参考定义 | 调制频率敏感区 | 典型整车场景 |
| --- | --- | --- | --- | --- |
| **响度 N（sone）** | 多响 | 40 方 = 1 sone | — | 车内总噪声水平对标 |
| **尖锐度 S（acum）** | 多刺 | 1 kHz/60 dB 临界带窄带噪声 = 1 acum | — | 蜂鸣、啸叫、气流声评价 |
| **粗糙度 R（asper）** | 多糙 | 1 kHz/60 dB 纯音，70 Hz/100% 调制 = 1 asper | **15～300 Hz** | 发动机燃烧噪声、齿轮啮合调制 |
| **抖动强度 F（vacil）** | 多晃 | 1 kHz/60 dB 纯音，4 Hz/100% 调制 = 1 vacil | **20 Hz 以下，4 Hz 附近** | 电驱呜呜声、鼓风机调速拍振 |

![窄带噪声掩蔽效应：4 kHz 纯音被强窄带噪声淹没的过程](/images/sound-quality-metrics/fig7-3-masking-zwicker.png)

*掩蔽效应：背景从 90 dB 升到 100 dB，4 kHz 纯音从可闻变为完全被掩蔽（图源：Simcenter Testing Knowledge Base 中文理论手册）*

::: warning 工程注意
粗糙度和抖动强度的分界是**调制频率**，不是载波频率。同一个电驱阶次噪声，包络波动 4 Hz 时是抖动问题，波动 70 Hz 时是粗糙度问题——整改方向完全不同（前者查拍频/拍振源，后者查啮合调制的边带结构）。
:::

## 四、Python 演示：响度换算与两种调制感觉的分界

```python
import numpy as np

# ---- 响度：方与宋换算（S = 2^((P-40)/10)）----
phon = np.array([40, 50, 60, 70, 80])
sone = 2 ** ((phon - 40) / 10)
for p, s in zip(phon, sone):
    print(f"{p} 方 = {s:5.1f} 宋")
print(f"60 方降到 50 方，响度比值 = {2**((50-60)/10):.2f}")

# ---- 粗糙度 R 正比 f_mod；抖动强度 F 正比 1/(f/4 + 4/f) ----
# 各自按单位定义的参考调制频率归一化（R 以 70 Hz 为 1，F 以 4 Hz 为 1）
f = np.array([2, 4, 8, 15, 20, 40, 70, 150, 300])
R = f.copy()                    # 掩蔽深度相同时，粗糙度随调制频率线性上升
R = R / R[np.isclose(f, 70)]
F = 1.0 / (f/4 + 4/f)           # 抖动强度的频率形状，4 Hz 处最大
F = F / F[np.isclose(f, 4)]
print("\n f_mod(Hz)   R归一(70Hz=1)   F归一(4Hz=1)")
for fi, ri, fj in zip(f, R, F):
    print(f"{fi:8.0f}        {ri:6.3f}          {fj:6.3f}")
```

输出里最值得关注的两组数：响度从 60 方降到 50 方，宋值从 4.0 降到 2.0——主观响度恰好减半，这是宋标尺线性特性的体现；归一化后 R 曲线线性上升、F 曲线在 4 Hz 处达到最大后回落，15 Hz 往后 F 下降明显快于 R，两条曲线在 20～40 Hz 之间交叉——与听觉上"抖动"（20 Hz 以下为主）和"粗糙"（15～300 Hz）的分界带基本吻合。

## 五、Python 演示二：调制深度怎么喂给粗糙度

```python
import numpy as np

# 1 kHz 载波 + 70 Hz 幅值调制，改变调制深度 m
fs = 48000
fm = 70.0
t = np.arange(0, 0.5, 1/fs)

def env_depth_db(m):
    # 包络 = 1 + m*sin(2*pi*fm*t)，峰谷差 dB = 20*log10((1+m)/(1-m))
    env = 1 + m * np.sin(2*np.pi*fm*t)
    return 20*np.log10(env.max() / env.min())

print(" 调制深度m   包络峰谷差dB   R相对值(以m=0.5为1)")
ref = env_depth_db(0.5)
for m in [0.1, 0.25, 0.5, 0.75, 0.9]:
    dL = env_depth_db(m)
    print(f"{m:8.2f}        {dL:8.2f}            {dL/ref:6.2f}")
```

m=0.5 时峰谷差约 9.5 dB，m=0.25 时降到 4.4 dB——调制深度减半，包络峰谷差（粗糙度模型中正比于其输入量的量）的下降快于线性。另外注意 m 趋向 1 时谷值触零、dB 差发散，而实际听觉的掩蔽深度会被瞬态掩蔽效应抑制——这正是模型采用"掩蔽深度"而非"包络峰谷差"的原因。

## 六、小结

- 讲"多响"用响度：对标汇报用宋（线性、易沟通），谱定位用宋/Bark 局部响度（判断主要贡献频带）
- 讲"多刺"用尖锐度：整改高频占比，1 acum 参考声是 1 kHz/60 dB 临界带窄带噪声
- 讲"多糙/多晃"先看调制频率：15～300 Hz 归粗糙度（asper），20 Hz 以下归抖动强度（vacil），4 Hz 和 70 Hz 各自是敏感峰
- dB(A) 达标但客户抱怨"吵得烦"的项目，应直接计算 Zwicker 响度 + 尖锐度 + 粗糙度三项指标，无须继续在 A 计权框架内寻找解释
