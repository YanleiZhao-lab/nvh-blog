# 清晰度指数与语言干扰级：车里说话还听得清吗

> 两台车车内噪声一台 67 dB(A)、一台 56 dB(A)，坐在轰鸣的那台里交谈反而更轻松——因为决定"话能不能听清"的不是总声级，是 500 Hz～4 kHz 语言频带里信号压过背景多少。清晰度指数（AI）和语言干扰级（SIL/PSIL）就是专门回答这个问题的两个指标：一个按语言重要性逐带加权算"可懂度余额"，一个用三四个带级的平均数给通话环境快速分级。

## 一、dB(A) 管不了通话这件事

做整车 NVH 的都习惯用 dB(A) 汇报，但 A 计权在低频罚得狠（100 Hz 要减 19.1 dB），于是"轰鸣但高频干净"的车和"中高频沙沙作响"的车可以调出一样的总级。麻烦在于：语言能量恰恰集中在 500 Hz 到 4 kHz，辅音辨别更是依赖 2 kHz 以上——正是 A 计权放行的频段。

结果就是总级和通话质量脱钩。高速风噪主导的车，dB(A) 不高，乘客却得提高嗓门；粗糙路面低频轰鸣的车，dB(A) 很吓人，说话彼此却听得清清楚楚。评价通话、免提、语音助手唤醒率这些场景，需要只盯语言频带的指标。

::: info 核心概念
- **清晰度指数（Articulation Index，AI）**：对噪声频谱（1/3 倍频程）按各频带对语言可懂度的重要程度加权后归一求和，0～100%，回答"背景里语言信息还剩多少"
- **语言干扰级（Speech Interference Level，SIL/PSIL）**：语言频带几个倍频程带声压级的算术平均，数值越低越容易交谈
- **语言频带**：语言能量与辨别信息集中的约 500 Hz～4 kHz 区间，是这组指标与 A 计权分道扬镳的地方
:::

## 二、AI：加权谱算出的"可懂度余额"

AI 最初是为**通话私密性**提出的——办公室、开放式工位里，背景噪声把隔壁谈话掩蔽到什么程度。视角是反过来的：噪声不是干扰，而是提供掩蔽、保护私密的资源。

算法骨架出自 Beranek 1947 年的《语音通讯系统的设计》：把 1/3 倍频程声压级谱画在专用图版上，图版按各频带对语言可懂度的贡献印了数目不等的计权圆点（语言核心频带点密，带外点稀），**谱线以上的点数除以总点数就是 AI**。谱越高，盖住的点越多，被掩蔽得越狠，AI 越低。

![AI 的图形计算法：1/3 倍频程谱画在计权图版上，谱线上方的计权点数占比即 AI](/images/articulation-index/fig7-7-ai-nomogram.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册 图7-7）*

AI 与可懂度的换算有实测曲线支撑。工程上的锚点：**完全私密要求 AI 不超过 0.05；半私密（谈非保密事务）AI 取 0.1 以内**。

![句子可懂度随清晰度指数的变化曲线](/images/articulation-index/fig7-8-intelligibility.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册 图7-8）*

::: warning 两种算法结果不可直接对比
- **标准方法**（Beranek 路线）：AI 值域 0～100%
- **改良方法**（AIM 路线）：在 20～100 dB 固定 80 dB 量程上再上下浮动 30 dB，算出的 AI 可以冲到 107%～约 160%
对比两份报告前先确认算法口径，超 100% 不是数据错了，是改良法量程没封顶。
:::

顺带一提，电动车太安静反而催生了 AI 的反向应用：没有发动机掩蔽，车厢里轻声交谈一览无余，语音私密性变差——电动车的主动声浪、AVAS 提示音设计里，"把 AI 压回 0.05 以下"是掩蔽量的设计目标之一。

## 三、SIL/PSIL：三个带级的算术平均

AI 要逐带加权，工程现场有时只想要一个能快速分级的数。语言干扰级就是这么来的：取语言频带几个倍频程带声压级的算术平均，别的什么都不做。

| 版本 | 取带 | 来源 |
| --- | --- | --- |
| **SIL（原始）** | 600~1200、1200~2400、2400~4800 Hz 三带平均 | Beranek 原始定义 |
| **PSIL（优先）** | 500、1000、2000 Hz 三个倍频程带平均 | 优先倍频程带规定后的改名 |
| **ANSI-SIL** | 500、1000、2000、4000 Hz 四带平均 | ANSI S3.14-1977（R-1986），与 ISO TR3352-1974 一致 |

三个口径同源不同标尺，手册给的换算关系：**ANSI-SIL 大致比 Beranek 原始 SIL 高 1 dB，比 PSIL 低约 2.5 dB**。报数据必须写清口径，差着两三个 dB 的"语言干扰级"没有可比性。

PSIL 的经典用途是查图回答"这个噪声环境下，面对面说话得离多近"。PSIL 越高，能正常交谈的距离越短——乘员舱布置、公交车驾驶区、开放式办公室的通话评估都用这套图。

## 四、Python 演示：同 dBA，两种命运

两组典型谱形的车内噪声：高速风噪（中高频平直）与粗糙路面轰鸣（低频滚降）。1/3 倍频程带级为手工设定的典型值，A 计权用 IEC 61672 标准值。

```python
import numpy as np

# 1/3 倍频程中心频率与 A 计权（IEC 61672 标准值，dB）
fc = np.array([100,125,160,200,250,315,400,500,630,800,1000,1250,1600,2000,2500,3150,4000,5000])
Aw = np.array([-19.1,-16.1,-13.4,-10.9,-8.6,-6.6,-4.8,-3.2,-1.9,-0.8,0,0.6,1.0,1.2,1.3,1.2,1.0,0.5])
idx = {c: k for k, c in enumerate(fc)}

# 两组典型车内噪声带级（dB）：风噪中高频平直；路面轰鸣低频滚降
wind   = np.array([30,32,34,36,38,40,42,44,45,46,46,46,46,46,46,46,45,44.])
rumble = np.array([78,76,74,70,66,62,58,54,50,46,43,41,39,38,37,36,35,34.])

dBA  = lambda L: 10*np.log10(np.sum(10**((L+Aw)/10)))                                # A 计权能量合成
psil = lambda L: (L[idx[500]] + L[idx[1000]] + L[idx[2000]]) / 3                     # PSIL 三带平均
sil4 = lambda L: (L[idx[500]] + L[idx[1000]] + L[idx[2000]] + L[idx[4000]]) / 4      # ANSI 四带平均

print(f"风噪车:  dBA = {dBA(wind):5.1f}   PSIL = {psil(wind):5.1f}   ANSI-SIL = {sil4(wind):5.1f}")
print(f"轰鸣车:  dBA = {dBA(rumble):5.1f}   PSIL = {psil(rumble):5.1f}   ANSI-SIL = {sil4(rumble):5.1f}")
print(f"轰鸣车 dBA 高 {dBA(rumble)-dBA(wind):.1f} dB，PSIL 反而低 {psil(wind)-psil(rumble):.1f} dB")
```

轰鸣车总级高出 10.7 dB(A)，PSIL 却基本打平——dBA 差距全堆在 500 Hz 以下，语言频带内两车相当。汇报总级会说轰鸣车"吵得多"，评价通话两车是同一个等级。

再看 AI 的物理底牌：语言频带内的逐带信噪比。正常交谈 1 m 处的典型语言带级取示意值：

```python
import numpy as np

# 语言关键倍频程带：1 m 处正常交谈的典型带级（示意值）
band  = np.array([250, 500, 1000, 2000, 4000], float)
voice = np.array([53, 60, 58, 52, 46.])
# 上一组数据中与风噪同 dBA 口径的两种背景（取对应倍频程带）
wind_bg   = np.array([36, 44, 46, 46, 45.])
rumble_bg = np.array([70, 54, 43, 38, 35.])

snr_w, snr_r = voice - wind_bg, voice - rumble_bg
print(f"{'带 (Hz)':>8} {'250':>6} {'500':>6} {'1000':>6} {'2000':>6} {'4000':>6} {'平均':>7}")
print(f"{'风噪 SNR':>8} " + " ".join(f"{v:6.1f}" for v in snr_w) + f" {snr_w.mean():7.1f}")
print(f"{'轰鸣 SNR':>8} " + " ".join(f"{v:6.1f}" for v in snr_r) + f" {snr_r.mean():7.1f}")
```

风噪车 500 Hz 带语言信噪比只有 16 dB，2 kHz 带掉到 6 dB、4 kHz 带 1 dB；轰鸣车在 1 k～4 kHz 三个带都有 11～15 dB 余量，250 Hz 带甚至被轰鸣反超。可懂度由语言频带 SNR 逐带决定——这正是 AI 逐带加权求和的物理出发点，也是"总级不高却得喊"的直接解释。

## 五、指标选型与工程坑

| 指标 | 输入 | 输出 | 强项 | 弱点 |
| --- | --- | --- | --- | --- |
| **AI** | 1/3 倍频程谱 | 0～100%（改良法可超 100%） | 逐带计权、与可懂度有实测曲线 | 算法口径多，结果不可直接横比 |
| **PSIL** | 500/1k/2k 三带 | dB，算术平均 | 一个数快速分级，可查通话距离图 | 只覆盖中频，4 kHz 以上不管 |
| **ANSI-SIL** | 四带含 4 kHz | dB | 计入辅音辨别关键的 4 kHz | 与 PSIL 差约 2.5 dB，口径易混 |
| **dB(A)** | 全频段计权 | dB | 法规与验收通用 | 低频被压制，与可懂度脱钩 |

::: tip 选择原则
- 免提通话、语音助手唤醒率问题 → 首选 AI 或 ANSI-SIL，把 4 kHz 带纳入
- 现场快速评估"能不能交谈"、乘员舱布局 → PSIL 查图最快
- 对外验收、法规汇报 → 仍然 dB(A)，但内部诊断要配语言频带指标交叉看
:::

::: warning 三个常见的坑
- **别拿 AI 当"安静度"**：AI 高只代表语言信息传得过去，高频嘶嘶声可以把 dBA 顶得很高而 AI 几乎不动
- **口径不写清等于白测**：标准法/改良法、PSIL/ANSI-SIL、1/3 倍频程还是倍频程，任何一项不同，两个数就没有可比性
- **稳态谱指标罩不住混响和瞬态**：车内反射声、公交车到站报站的瞬态语音，都要在实际声场里复核，指标只算背景谱
:::

## 六、小结

语言类指标和 dB(A) 不是替代关系，是分工：dB(A) 回答"车里多吵"，AI 与 SIL 回答"话还能不能说"。判断标准很直接——涉及语音交互的问题，先看 500 Hz～4 kHz 语言频带的带级和逐带 SNR；轰鸣问题别被总级吓到，风噪问题别被总级骗过。报告里 AI 必须注明算法口径，SIL 必须注明取带版本，否则数字没有可比性。
