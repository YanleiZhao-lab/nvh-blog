# 倍频程：人耳的频率分辨与计权

> 频谱图上一条细密的线，为什么到了声品质报告里变成十来根柱子？因为人耳对频率的分辨不是均匀的——低频分得清、高频糊成一片。倍频程（Octave）就是按人耳的"分辨力"切分频带的工程方案，配合 A 计权构成声学评价的标准语言。这篇讲清倍频程怎么定义、怎么算、怎么用，以及窄带谱与倍频程谱各管什么。

## 一、从音乐借来的分带方式

钢琴上两个 C 音，频率恰好差一倍——"octave"这个词就是从音乐理论借来的。人耳听 500 到 1000 Hz 和 5000 到 10000 Hz，主观感受都是"高了一个八度"，虽然后者频率跨度是前者的 9 倍。**人耳对频率的感知是对数的**，这是倍频程一切规则的源头。

把人耳听觉范围 20 Hz 到 20 kHz 按"频率翻倍"切一刀，得到 11 个 1/1 倍频程频带；每个频带再三分，得到 1/3 倍频程——更贴近人耳实际的分辨粒度，也是 NVH 报告里最常见的形式。相邻 1/3 倍频程中心频率之比是 2 的立方根，约 1.26，这就是"1/3"的含义。

| 标称中心频率（Hz） | 31.5 | 63 | 125 | 250 | 500 | 1k | 2k | 4k | 8k | 16k |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **带宽（Hz）** | 22 | 44 | 89 | 178 | 355 | 707 | 1414 | 2828 | 5657 | 11314 |

看一眼带宽那一行：31.5 Hz 频带只有 22 Hz 宽，16 kHz 频带宽 11314 Hz——差了 500 多倍。同一条白噪声，低频柱子窄、高频柱子宽，能量天然往高频带里堆。

![倍频程频带的上下限与中心频率](/images/octaves-hearing/1-1-octave-bands.png)
*（图源：Simcenter Testing Knowledge Base）*

::: info 核心概念
- **倍频程频带（Octave Band）**：上/下限频率之比为 2 的频带，中心频率为上下限的几何平均（各差根号 2 倍）
- **1/3 倍频程**：把 1/1 倍频程再分三份，相邻中心频率比为 2 的立方根
- **倍频程格式（Octave Format）**：横轴按频带序号等间距排布，高频被"压缩"得与低频同宽
:::

## 二、白噪声的倍频程谱：每升一带加 3 dB

白噪声的功率谱密度处处相等——线性坐标下是一条平线。但换成倍频程柱状图，柱子一根比一根高，每个倍频程涨 3 dB。道理很简单：带宽每升一带翻一倍，密度不变，带内总能量就翻一倍，10 lg 2 = 3.01 dB。

```python
import numpy as np

rng = np.random.default_rng(7)
fs = 48000                                # 采样率
x = rng.standard_normal(fs * 4)           # 4 秒白噪声（线性单位 Pa）
X = np.abs(np.fft.rfft(x)) ** 2 / len(x)  # 能量谱
f = np.fft.rfftfreq(len(x), 1 / fs)

tot = X.sum()
print("中心频率     带内能量占比(dB)")
for k in range(-5, 5):                    # 31.5 Hz 到 16 kHz 十个带
    fc = 1000.0 * 2.0 ** k
    band = (f >= fc / np.sqrt(2)) * (f < fc * np.sqrt(2))
    share = 10 * np.log10(X[band.astype(bool)].sum() / tot)
    print(f"{fc:8.0f} Hz   {share:6.2f} dB")
```

运行结果要点：相邻频带的能量占比差稳定在 3 dB 出头（-30.4、-26.8、-24.7 直到 -3.3 dB），这就是"白噪声倍频程谱每带加 3 dB"的由来。反过来看：如果实测的倍频程谱在低频明显高出这条趋势线，说明存在低频噪声源——怠速轰鸣、排气共振都会这样"顶"出来。

## 三、倍频程不是 FFT 算出来的

这是最容易搞混的一点。倍频程柱状图长得像直方图，但它**不是把 FFT 谱按频带分组求和**，而是把时域信号送进一组并行的带通滤波器，每个滤波器的输出各自求 RMS/能量。Simcenter Testlab 的滤波器形状符合 ANSI S1.11-2011 / IEC 61260 标准的规定。

为什么必须用滤波器？两个原因。

一是**时间信息**。FFT 是帧级操作，帧长决定时间分辨率；滤波器组是连续运行的，可以逐时刻输出每个频带的声压级随时间的变化（倍频程切片，Octave Section）——关门声、怠速喘振这类非稳态事件，只有滤波法跟得上。

二是**标准符合性**。法规认证（车外加速噪声、通过噪声）指定倍频程或 1/3 倍频程结果，滤波器组的频响形状、带宽精度直接决定结果能否过认证。FFT 分组求和只能逼近，不能替代。

在 Testlab 中：Tools 菜单 Add-ins 打开 "ANSI-IEC Octave Filtering"（23 token），然后在 Time Data Processing 里选 averaging（exponential 或 linear）和 sound level type（fast 0.125 s / slow 1.0 s / impulse 0.035 s），在 Section 的 Octave Maps 页勾选频带类型即得倍频程图；Octave Sections 页可跟踪单个频带随时间或转速的行为。

## 四、A 计权：把麦克风的账换算成人耳的账

倍频程解决"频率怎么分带"，A 计权（A-weighting）解决"每个频率算几分"。麦克风振膜来什么记什么；人耳却对 1 到 6 kHz 最敏感，对低频相当迟钝——耳道在 4 kHz 附近还有共振放大。A 计权是一条标准化修正曲线：1 kHz 处 0 dB，低于 1 kHz 衰减、100 Hz 处约 -20 dB，1k 到 6k 略放大、约 6 kHz 以上再衰减。1936 年 ANSI 首次把它写进声级计标准，源头是 Fletcher-Munson 等响曲线。

```python
import numpy as np

def a_weight_db(freq):
    # IEC 61672 定义的 A 计权传递函数
    f2 = np.asarray(freq, dtype=float) ** 2
    Ra = 12194.0**2 * f2**2 / (
        (f2 + 20.6**2)
        * np.sqrt((f2 + 107.7**2) * (f2 + 737.9**2))
        * (f2 + 12194.0**2))
    return 20 * np.log10(Ra) + 2.0

# 一台动力总成在四个 1/1 倍频程带的实测声压级
fc  = np.array([63.0, 250.0, 1000.0, 2000.0])
lvl = np.array([70.0, 62.0, 55.0, 60.0])  # 低频占优的典型分布

dBA_band = lvl + a_weight_db(fc)          # 逐带修正（dB 域是加减法）
print("倍频程带   修正前(dB)   A计权后(dB)")
for c, l, w in zip(fc, lvl, dBA_band):
    print(f"{c:6.0f} Hz   {l:8.1f}     {w:8.1f}")

lin = 10 * np.log10((10 ** (lvl / 10)).sum())
dBA = 10 * np.log10((10 ** (dBA_band / 10)).sum())
print(f"\n总级: {lin:.1f} dB  ->  {dBA:.1f} dB(A)")
```

运行结果要点：63 Hz 的 70 dB 被 A 计权砍到 43.8 dB，总级从 71.1 dB 掉到 62.7 dB(A)——低频为主的动力总成噪声，A 计权后"好看"了一大截，这正是 dBA 被写进多数噪声法规的原因。但反过来要警惕：一条约 1600 Hz 的口哨音，A 计权后总值反而可能抬高（手册实测 84.2 升到 85.1 dB(A)），因为 1k 到 6k 是放大区。

![A 计权曲线：1 kHz 处 0 dB，低频大幅衰减，1k 到 6k 略放大](/images/octaves-hearing/a-weighting-curve.png)
*（图源：Simcenter Testing Knowledge Base）*

::: warning dBA 小不等于更安静
- **低频为主的源（排气、进气、怠速轰鸣）**：A 计权后大幅下降，但低频轰鸣引起的"压迫感、烦躁度"并没消失——客户抱怨"嗡嗡的难受"而 dBA 达标，是声品质工程师最常遇到的冲突。这时要补线性值、1/3 倍频程谱和声品质指标（响度 Sone、粗糙度、尖锐度）
- **高频为主的源（电机电磁啸叫、齿轮啸叫、风噪）**：能量集中在 1k 到 6 kHz 放大区，dBA 会放大问题，可能比线性值更"难看"
- **对比数据必须同计权**：dB(L) 与 dB(A) 直接比较没有意义，报告里务必写清计权状态
:::

## 五、窄带谱与倍频程谱：分工不是替代

| 维度 | 窄带 FFT 谱 | 倍频程谱（滤波法） |
| --- | --- | --- |
| **频率轴** | 线性等间距，间距为分辨率 | 对数等比间距，1/1 或 1/3 倍频程 |
| **带宽** | 全带等宽 | 低频窄、高频宽，随中心频率成比例 |
| **白噪声形态** | 平线 | 每带加 3 dB 的阶梯 |
| **频率定位** | 强：共振峰、阶次线谱一眼锁定 | 弱：只能给出频带归属 |
| **时间跟踪** | 受帧长约束 | 强：逐时刻输出频带级 |
| **与听觉对应** | 无直接对应 | 频带划分贴合人耳分辨力 |
| **典型用途** | 传递函数、模态、阶次跟踪、诊断 | 声学法规认证、声品质、隔声评价 |
| **Testlab 入口** | Spectrum / Autopower 计算 | ANSI-IEC Octave Filtering 插件 |

::: tip 怎么选
- **诊断"哪根线在响"**：窄带谱加阶次分析，倍频程帮不上忙
- **评价"人听着怎么样"、应对法规**：1/3 倍频程加 A 计权，这是行业默认语言
- **非稳态事件**（关门声、通过噪声、啸叫瞬态）：滤波法倍频程切片，看单带随时间变化
- **低频问题别只看 dBA**：同时给线性值和 1/3 倍频程谱，防"达标但难听"
:::

## 六、小结

倍频程的本质是把频率轴从"物理等间距"换成"听觉等间距"：低频带窄、高频带宽，匹配人耳的对数分辨特性。判读时记住三条基准线——白噪声倍频程谱每带加 3 dB；A 计权以 1 kHz 为零点、低频重罚、1k 到 6k 微奖；dBA 对低频源偏乐观、对高频源偏悲观。诊断用窄带谱锁频率，评价用倍频程谱对齐人耳，两把尺子各司其职，不要拿一把否定另一把。
