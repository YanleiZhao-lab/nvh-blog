# 从FRF提取阻尼：3dB带宽法的原理、坑与Testlab游标

> 频响函数（FRF）上的共振峰藏着结构的阻尼信息，工程师最常用的提取手段就是 3dB 带宽法（半功率法）：从峰顶往下 3dB 量宽度。方法一分钟就能学会，但频率分辨率、指数窗、相邻模态三个坑能让结果差出一倍。这篇把原理、数值实验和 Testlab 的阻尼游标一次讲清。

## 一、阻尼是什么，为什么非要从 FRF 上抠

阻尼是结构在交变应力下耗散能量的能力。没有阻尼的系统一旦被激励起来就永远振动下去；阻尼越大，自由衰减越快，FRF 上的共振峰就越胖。峰的胖瘦就是阻尼的指纹——窄而尖是轻阻尼，宽而缓是重阻尼。

描述阻尼的货币有好几种：损耗因子 η、阻尼比 ζ、百分临界阻尼、品质因子 Q。数值上可以互相换算，为什么并存？因为读起来方便。两个结构分别测出 0.0123% 和 0.0032% 的临界阻尼，差别听着不大；换成 Q 是 4065 对 15625，差距立刻醒目。

::: info 核心概念
- **品质因子 Q**：共振峰尖锐程度的度量，Q = f0/(f2−f1)。官方知识库把 quality factor 与 damping factor 视为同一量，本文遵循此约定
- **阻尼比 ζ**：临界阻尼的百分比，ζ = 1/(2Q)
- **损耗因子 η**：η = 1/Q，小阻尼下 η ≈ 2ζ
- **方向性**：Q 越大阻尼越小；ζ 和 η 越大阻尼越大——汇报前先确认对方要哪种
:::

注意符号方向：Q 增加、ζ 减少才是阻尼变小。审报告先看纵轴是什么量，再判断阻尼是升是降。

## 二、3dB 带宽法：一根游标量出来的阻尼

FRF 中共振峰的带宽与阻尼成正比。从峰顶 f0 往下 3dB（幅值降到峰值的 1/√2 ≈ 0.707），在峰两侧找到 f1、f2 两个穿越点，则：

**Q = f0 / (f2 − f1)**，**ζ = 1/(2Q)**

物理上这叫半功率点：−3dB 恰好是功率减半的位置。对小阻尼单自由度系统这条公式是严格的；对实际结构的多自由度 FRF，它是局部近似——够用，但有前提（见第四节）。

幅值轴显示成线性还是 dB 无所谓，Testlab 的阻尼游标会按正确的刻度找穿越点，不要求你先把 FRF 换成 dB。

| 阻尼表示 | 阻尼增大时 | 与 Q 的关系 | 数值感受 |
| --- | --- | --- | --- |
| **品质因子 Q** | 变小 | — | 4065 对 15625，差异醒目 |
| **阻尼比 ζ** | 变大 | ζ = 1/(2Q) | 2% 对应 Q = 25 |
| **损耗因子 η** | 变大 | η = 1/Q | 小阻尼下约为 ζ 的 2 倍 |
| **百分临界阻尼** | 变大 | 100ζ | 0.0123% 对 0.0032%，听着差别不大 |

::: tip 换算速记
- 已知 Q 求 ζ：25 对应 2%；反过来 2% 对应 Q = 25
- 模态软件里极点实部就是阻尼因子 σ（单位 Hz），ζ = σ/(2πf)——频率和阻尼因子的量纲都是 Hz 的一次方，别被阻尼怎么会有 Hz 单位问住
:::

## 三、Python 演示：分辨率不够，Q 直接少三分之一

用一个单自由度系统（100 Hz、阻尼比 2%，即 Q=25）生成解析 FRF，模拟 3dB 法在三种频率分辨率下的表现。重点看谱线直读那一列——不插值、直接取第一条低于 −3dB 的谱线，正是手动放游标时的真实操作。

```python
import numpy as np

# 单自由度FRF + 3dB带宽法：Q = f0/(f2-f1), zeta = 1/(2Q)
f0, zeta = 100.0, 0.02          # 真值：共振100Hz，阻尼比2%
wn = 2*np.pi*f0
k, m, c = wn**2, 1.0, 2*zeta*wn # SDOF参数（m=1kg）

def frf(f):
    w = 2*np.pi*f
    return 1.0/(k - m*w**2 + 1j*c*w)

for df in (2.0, 1.0, 0.25):
    f = np.arange(60, 140+df, df)
    amp = np.abs(frf(f))
    pk = np.argmax(amp)
    a0, f0h = amp[pk], f[pk]
    tgt = a0/np.sqrt(2)                               # -3dB即幅值1/sqrt(2)
    f1 = np.interp(tgt, amp[:pk+1], f[:pk+1])         # 左翼插值
    f2 = np.interp(tgt, amp[pk:][::-1], f[pk:][::-1]) # 右翼插值
    Q = f0h/(f2-f1)
    # 对照：不插值，取第一条低于-3dB的谱线（手动放游标的真实操作）
    i1 = pk - np.argmax(amp[:pk+1][::-1] < tgt)
    i2 = pk + np.argmax(amp[pk:] < tgt)
    Qn = f0h/(f[i2]-f[i1])
    print(f"df={df:4.2f}Hz  插值 Q={Q:5.1f} zeta={100/(2*Q):5.2f}% | 谱线直读 Q={Qn:5.1f} 误差{abs(Qn-25)/25*100:4.0f}%")

print("真值: Q=25.0, zeta=2.00%")
```

运行结果要点：插值法在三种分辨率下都稳定给出 Q 约 24.9~25.0；谱线直读在 df=2 Hz 时 Q 只有 16.7，偏低 33%——带宽被量化成整数条谱线，粗分辨率下 f2−f1 被系统性放大。Q=25 时半功率带宽本身只有 4 Hz，盖住它的谱线不到三条。

## 四、三大坑：分辨率、指数窗、模态挤在一起

**坑一：频率分辨率。** 上面的数值实验已经说明问题。经验做法：让半功率带宽内至少落 5~10 条谱线，即 df 不超过 (f2−f1)/5。对 Q 上百的轻阻尼结构，这意味着要么延长采样时间，要么承认 3dB 法在此精度极限附近失效。

**坑二：指数窗。** 锤击小阻尼结构时，响应在采样窗内衰减不完，泄漏会把峰压矮拉宽，于是给响应加指数窗强制衰完。但指数窗给信号叠加了人为衰减——FRF 峰变宽，3dB 法读出的阻尼偏高。

```python
import numpy as np

# 指数窗如何虚增阻尼：衰减率变成"结构+窗"的叠加
fs, T = 4096, 4.0
t = np.arange(0, T, 1/fs)
f0, zeta = 100.0, 0.02
env = np.exp(-zeta*2*np.pi*f0*t)*np.cos(2*np.pi*f0*t)  # 真实响应

for tau in (np.inf, 0.4, 0.1):   # 窗时间常数：无窗/温和/激进
    win = 1.0 if tau == np.inf else np.exp(-t/tau)
    y = env*win
    # 对信号平方做指数拟合 -> 等效衰减率 -> 等效阻尼比
    sq = y**2
    mask = sq > 1e-12
    slope = np.polyfit(t[mask], np.log(sq[mask]), 1)[0]
    zeta_eq = -slope/(4*np.pi*f0)
    print(f"tau={tau:5.1f}s -> 等效阻尼比 {zeta_eq*100:6.2f}% (真实 2.00%)")
```

运行结果要点：τ=0.1 s 的激进指数窗把 2.00% 读成 3.51%，虚增七成半。两条出路：让模态曲线拟合器自动扣除窗效应（Testlab 拟合时自动做）；或用 R18 及以上版本的显示阻尼游标，读数已自动修正指数窗影响。手动 3dB 法读到的是结构加窗的合计值。

**坑三：密集模态。** 两个模态频率挨得近，峰互相重叠，3dB 法量到的宽度包含两阶的贡献，单峰阻尼根本读不出来。判据很简单：峰两侧找不到干净的 −3dB 穿越点，或峰形明显不对称。此时换模态曲线拟合（curvefitting），它能把两阶模态拆开分别给出阻尼，还能联合多张 FRF 一起估计，比单张 FRF 的 3dB 法稳健得多。

::: warning 工程注意
- 3dB 法读的是单张 FRF 单个峰，密集模态下直接失效，别硬读
- 指数窗下的手动 3dB 读数偏保守（阻尼偏高），比较不同试件时务必保证窗设置一致
- 汇报 Q 还是 ζ 先问清楚，η 与 ζ 差的因子 2 是报告评审最爱抓的错误
:::

## 五、Testlab 操作：两步读出阻尼

FRF 显示出来后：

1. 右键选 **Automatic -> Peak Cursor**（自动峰游标），让游标自己坐到峰顶；对峰位有把握也可以用普通 SingleX 游标。
2. 游标上右键选 **Calculations -> Q** 或 **Calculations -> Damping Ratio**，读数直接显示在游标旁。

幅值轴不必是 dB——游标内部按刻度正确换算。R18 起阻尼游标还会自动补偿指数窗的虚增效应，锤击数据也能直接读。

## 六、小结

Q=25 的峰带宽只有 4 Hz，df=2 Hz 的谱线直读误差就能到 33%——先把分辨率做够再谈 3dB 法。指数窗与密集模态是两个系统性偏差源，前者交给 Testlab 的自动补偿或模态拟合扣除，后者必须放弃 3dB 法改用曲线拟合。快速车间诊断，自动峰游标加 Q 读数足够；出正式模态报告，以曲线拟合结果为准。
