# 阶次跟踪两种采样：定采样 vs 同步采样

> 变转速工况下想拿到准确的阶次幅值，先得回答：数据是等时间间隔采的，还是等角度间隔采的？定采样加转速重采样是当前主流，但同步采样在扭振高阶测量里仍不可替代。本文讲透两种路线的原理差异、最大阶次上限怎么算、什么工况选哪条路。

## 一、问题的根源：转一转，到底采几个点

一台发动机从 1000 rpm 升到 4000 rpm，曲轴转频从 16.7 Hz 涨到 66.7 Hz。同一个 2 阶成分，频率从 33 Hz 滑到 133 Hz，在频谱上这是一条斜线，不是一个定点。

采数据的时钟却和转速无关。ADC 按固定的采样率（比如 10 kHz）等间隔取样，一转之内采多少个点完全由当时转速决定：1000 rpm 时一转 600 个点，4000 rpm 时只剩 150 个。若想直接在「角度均匀」的栅格上分析（比如逐循环平均、角度域统计），定采样数据必须先经过一道**重采样**：从时间域换算到角度域。

同步采样把这件事反过来做：让采样时钟跟着轴转。编码器每转给出固定的脉冲数（PPR），每来一个脉冲采一个点，采样栅格天然按角度均匀。阶次在这个栅格里就是「每转周期数」，与转速解耦。

::: info 核心概念
- **定采样（fixed sampling）**：等时间间隔采集，采样率恒定；后续靠转速计曲线插值重采样到角度域
- **同步采样（synchronous sampling）**：等角度间隔采集，每转采样点数恒定；阶次即「每转周期数」
- **PPR（pulses per revolution）**：转速计或编码器每转输出的脉冲数，决定角度域栅格密度
- **重采样（resampling）**：按转速-时间曲线把定采样数据插值到等角度栅格，Simcenter 里由 Order Tracking 模块完成
:::

## 二、定采样的软肋与同步采样的硬上限

### 定采样靠重采样「补救」

重采样的原理不复杂：转速计脉冲给出转速-时间函数，积分得到转角-时间函数；在角度域按固定步长取参考点，反查出对应时刻，再用插值取出该时刻的信号值。

代价藏在插值里。Simcenter 的实现是先升采样（默认因子 15）再做线性插值、最后降采样，插值误差由**信号失真比 SDR（Signal to Distortion Ratio）**刻画，升采样因子越高、滤波器截止频率占比越低，失真越小。

另一条约束来自最低转速：角度分辨率必须按全程最低转速设计。最低转速处的「每转采样点数」最先不够用，信息损失从那里开始。

### 同步采样的上限由 PPR 决定

编码器直接采样时，角度域的 Nyquist 准则是：**最大可分析阶次 = PPR / 2**。手册里那个直白的例子：想测 60 阶扭振，至少 120 PPR。

![120 PPR 采样下，60 阶以上区域（深蓝）已无任何阶次信息](/images/order-tracking-sampling/max-order-ppr.png)

*(图源：Simcenter Testing Knowledge Base)*

而且 PPR 通道**没有抗混叠保护**，它不是靠模拟滤波器保护的 ADC 通道，阶次超出 PPR/2 的成分照样折叠进来冒充低阶。所以实际选型普遍加 10 倍安全系数：测 60 阶，用 600 PPR 的编码器或斑马带。

::: warning 工程注意
同步采样最容易被忽略的坑是低速段。每转点数固定，转速升高时等效时间采样率同步升高，高频信息只会更充裕；真正的损失在低速，若角度分辨率按最低转速设计过粗，角度域信息在低速段已经丢了，转回时间域也找不回来。选 PPR 前先算：关心的最高阶次乘 2，再乘安全系数。
:::

## 三、两条路线怎么选

| 维度 | **定采样 + 重采样** | **同步采样（编码器直采）** |
| --- | --- | --- |
| 采样栅格 | 等时间间隔 | 等角度间隔 |
| 硬件门槛 | 普通转速计（1 PPR 即可） | 高 PPR 编码器或斑马带 + tacho 通道 |
| 最大阶次 | 受采样率与插值质量限制，一般到几百阶 | PPR/2（无混叠保护，实际留 10 倍余量） |
| 幅值精度 | 依赖重采样插值，SDR 可量化 | 栅格原生对齐，无插值损失 |
| 扭振与高阶 | 可用但需高采样率支撑 | **首选**，齿轮啮合、传动系扭振标准做法 |
| 灵活性 | 一次采集，时间域角度域随意切换 | 数据天生在角度域，回时间域要再插值 |
| 适用场景 | 整车路试、通用 NVH 扫描 | 变速箱台架、扭振专项、逐循环分析 |

::: tip 选择原则
- 默认路线：定采样加 Order Tracking 重采样，硬件要求低、数据可逆，覆盖绝大多数整车与动力总成 NVH 场景
- 扭振专项、齿轮啮合高阶（大于 20 阶）专项：上同步采样，PPR 至少目标阶次乘 20
- 转速波动剧烈的工况（急加减档、瞬态），重采样插值误差被放大，优先考虑同步直采
- 已有数据想补救角度域分析：先确认转速计质量与全程最低转速，再决定角度分辨率
:::

## 四、Python 演示：重采样到底改变了什么

```python
import numpy as np

# 模拟一段变速工况：转频 1 Hz -> 3 Hz 线性上升
fs = 100.0                      # 定采样率 Hz
t = np.arange(0, 4.0, 1/fs)     # 4 秒
# 累计转角(rad) = 转频的积分，再乘 2*pi
angle = 2*np.pi*(1.0*t + 0.5*t**2)

# 振动信号 = 3 阶成分（每转 3 次）+ 少量噪声
sig = np.sin(3*angle) + 0.05*np.random.randn(len(t))

# --- 重采样到角度域：每转固定 32 个点 ---
N_ppr = 32
angle_grid = np.arange(0, angle[-1], 2*np.pi/N_ppr)
sig_angle = np.interp(angle_grid, angle, sig)

# 在角度域提取 3 阶：取 3 整转做单频相关解调
seg = sig_angle[:3*N_ppr]
k = np.arange(len(seg))
est = 2*np.sum(seg*np.exp(-1j*2*np.pi*3*k/N_ppr))/len(seg)
print("总转数: %.1f, 角度域点数: %d" % (angle[-1]/(2*np.pi), len(sig_angle)))
print("每转点数恒为 %d, 与转速无关" % N_ppr)
print("3 阶幅值: |A| = %.3f (理论值 1.000)" % abs(est))
```

运行结果要点：重采样后每转点数恒定（32），3 阶幅值 0.985（含噪声与插值误差），在角度域栅格里，变速工况下的阶次成分被「冻结」成固定频率的周期信号，这就是阶次分析偏爱角度域的原因。

## 五、小结

判断标准只有两条：一是最高关心阶次，二是转速波动烈度。阶次高、波动大、要精确幅值，就上同步采样，PPR 给足 10 倍余量；其余场景定采样加重采样足够，把省下的硬件预算花在转速计信号质量上，比什么都值。
