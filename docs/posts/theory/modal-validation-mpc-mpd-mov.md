# 模态振型体检三指标：MPC、MPD 与 MOV

> 稳定图上锁定的极点，频率看着挺稳、阻尼也在带里，动画一放却总觉得"不像个模态"——测点相位东倒西歪，凑不成干净的同相/反相节线。判断一条振型是不是物理模态，除了肉眼，LMS 检测理论手册第十八章给了一组量化指标：MPC 查相位是否共线、MPD 量相位散布多少度、MOV 用"加质量必降频"这条物理铁律给振型打分。三个数各管一件事，合起来就是振型的体检报告单。

## 一、为什么"正则模态"是评判的起点

弱阻尼结构或比例阻尼结构的模态振型理论上是完全"正则"（normal）的：同一阶模态里，各个测点的复数振型系数之间要么同相（相位差 0 度），要么反相（相位差 180 度）。白车身的一阶扭转，前部横梁向左摆时后部横梁向右摆，中间横穿一条节线——所有测点非黑即白，没有第三个方向。

这个性质是推导出来的，不是经验规律。比例阻尼下运动方程可在模态坐标解耦，特征向量是实数向量（正则模态）；实测 FRF 拟合出的复留数与实振型系数之间只差一个纯虚的比例因子（留数为纯虚数），因此各测点留数的相位只能落在 0 度或 180 度两个方向上。一旦阻尼不再比例（结构上贴了阻尼片、局部有大阻尼连接），或者测量与拟合环节引入了误差，振型系数就会在复平面里"歪"出这条直线——复模态出现了。

MPC 和 MPD 度量的正是这种歪斜的程度。而 MOV 从另一个方向切入：不管相位长什么样，只问一句——在测点上附加质量，这阶频率降不降？

::: info 核心概念
- **正则模态（Normal Mode）**：比例阻尼结构的实数振型，各测点相位非同相即反相
- **复模态（Complex Mode）**：振型系数相位偏离 0/180 度的模态，源于非比例阻尼或估计误差
- **模态超复性（Overcomplex）**：相位角越过合理界限的现象，MOV 指数的命名由来
:::

## 二、MPC：振型的实部虚部是否共线

模态相位共线性（Modal Phase Collinearity，MPC）的表达对象是**无标尺振型向量各元素的实部与虚部之间的线性关系**。把每个测点的复振型系数画在复平面上——横轴实部、纵轴虚部——正则模态的所有点应该排成一条过原点的直线：同相的点在正实轴方向，反相的在负方向。

手册给出的判据是拟合这条直线的"共线程度"：统计量由振型系数实部、虚部的平方和与交叉项构造（协方差型二次型），实部虚部严格成比例时取到上界。对实正则模态，**MPC 应接近 100%**；数值低，说明振型在某种程度上是复模态——要么结构上真有局部阻尼元件，要么测量或分析处理出了问题。

![MPC 判据：复平面内振型系数的实部与虚部构成线性关系](/images/modal-validation-mpc-mpd-mov/mpc-equation.png)

*（图源：Simcenter Testing Knowledge Base）*

物理上可以这样理解：共振处结构响应落后激振力 90 度，拟合出的留数理应纯虚；实部里残存的那点"不干净"，正是噪声、泄漏、带宽外模态残留的痕迹。MPC 高，说明这些干扰被压住了；MPC 低，先别急着信这条振型。

## 三、MPD：相位散布了多少度

MPC 是个 0 到 100% 的相对指标，回答"像不像一条直线"；**平均相位偏差（Mean Phase Deviation，MPD）直接给出角度**——各振型系数的相位角对其加权平均值的统计偏差。它指示振型在相位上的分散程度。

对实正则模态，**MPD 应接近 0 度**。读数的直观感受：MPD 5 度以内，动画里节线干净利落；20 度以上，测点开始"拖泥带水"，动画播放时能看到本该同时过零的测点有先后错动；到了 45 度量级，这条"振型"多半已经不是物理模态，或者结构上存在显著非比例阻尼。

两个指标配合用：MPC 掉下来但 MPD 只有几度，多数是少数远端测点噪声拉低的结果，可以定位到具体测点查安装；MPC 和 MPD 一起差，整条振型的相位结构有问题，该怀疑拟合带宽、极点选择或阻尼模型了。

## 四、MOV：加质量必降频的物理铁律

前两个指标盯相位，MOV（Modal Overcomplexity Value）换了个完全不同的角度——用**质量的物理效应**当试金石。

理论特性很朴素：在某一测点给结构附加质量，所有模态的有阻尼固有频率都应该**降低**，对应的频率-质量灵敏度为负。单自由度一眼看穿：固有频率等于刚度除以质量再开方，质量加大、频率必然下降。对某阶模态，逐测点计算固有频率对该测点质量增加的灵敏度，统计其中确实为负的测点所占的（加权）百分比，就是 MOV：

![MOV 定义：附加质量后频率确实降低的测点所占加权百分比](/images/modal-validation-mpc-mpd-mov/mov-equation.png)

*（图源：Simcenter Testing Knowledge Base）*

其中指示函数在测点的灵敏度为负时取 1、否则取 0，加权因子可选不加权或按振型系数加权。**高质量的模态 MOV 应接近 100%**；数值偏低，这条模态要么是计算模态（噪声里凭空拟合出来的非物理极点），要么是有毛病的估计——之所以叫"超复性"，正因为相位角越界（复得过头）的振型，其质量灵敏度会集体失去负号。

MOV 最妙的应用是抓一个很低级的错误：**如果对某一个特定输入点，所有模态的 MOV 都低（手册给的例子是低于 10%），很可能是测该输入点 FRF 时激振力方向输反了**。修正办法也直接——把所有模态对该输入的模态参预因子整体改个正负号。一个符号的事，能让整套振型的体检指标满盘翻红。

::: warning 工程注意
MOV 低不一定全是坏消息，先查三件事：激振力方向符号（单一输入点全模态集体低）、测点灵敏度标定（个别通道异常）、再谈振型本身质量问题。顺序反了，容易把好振型误杀。
:::

## 五、Python 演示：给三条振型做体检

下面用 numpy 造三条振型——一条干净的正则振型、一条被非比例阻尼"拧歪"的复模态、一条方向标反的——分别算 MPC（复平面直线拟合优度）、MPD（相位对加权平均的偏差）和 MOV（质量灵敏度负号占比），看体检单怎么读。

```python
import numpy as np

n = 12                                # 测点数
# 1) 干净的正则振型：系数全实数，相位非 0 即 180 度
psi_normal = np.cos(np.pi * np.arange(n) / 3)

# 2) 复模态：相位逐点拧歪（模拟非比例阻尼/估计误差）
twist = np.deg2rad(35) * np.sin(2 * np.pi * np.arange(n) / n)
psi_complex = psi_normal * np.exp(1j * twist)

# 3) 力方向标反的振型：整体差一个负号（仍是正则模态）
psi_flipped = -psi_normal

def check(name, psi):
    # MPC：实部-虚部在复平面的共线性（过原点直线拟合优度）
    re, im = psi.real, psi.imag
    sxx, syy, sxy = np.sum(re*re), np.sum(im*im), np.sum(re*im)
    mpc = sxy*sxy / (sxx*syy) if sxx*syy > 1e-12 else 1.0
    # MPD：相位对加权倍角圆均值的偏差（倍角消除 0/180 度二义）
    w = np.abs(psi); w = w / w.sum()
    ang2 = 2 * np.angle(psi)
    mean2 = np.angle(np.sum(w * np.exp(1j*ang2)))
    dev = np.abs(np.angle(np.exp(1j*(ang2 - mean2)))) / 2
    mpd = np.rad2deg(np.average(dev, weights=w))
    # MOV：df/dm < 0 的测点占比（灵敏度正比于 -psi_i 的平方）
    dfdm = -np.abs(psi)**2
    mov = np.mean(dfdm < 0) * 100
    print(f"{name:6s} MPC={mpc*100:5.1f}%  MPD={mpd:5.1f} deg  MOV={mov:5.1f}%")

check("zhengze", psi_normal)
check("fumo", psi_complex)
check("fanxiang", psi_flipped)
```

运行结果要点：正则振型 MPC 100%、MPD 0 度、MOV 100%，三项全绿；复模态 MPC 掉到 0、MPD 升到 20.7 度，MOV 仍是 100%——相位歪了但质量灵敏度符号没反，对应"真复模态"（结构上确有非比例阻尼）；方向标反那条三项读数与正则振型完全相同——这正是单看一条振型的 MOV 抓不到符号错误的原因，符号问题要靠"同一输入点全模态 MOV 塌方"这个群体特征来暴露。

## 六、三指标与 MAC 的分工

验证模态模型的工具箱里，MAC 负责"两条振型像不像"，MPC/MPD/MOV 负责"这一条振型本身正不正"，互不替代：

| 指标 | 回答的问题 | 健康值 | 典型病征 |
| --- | --- | --- | --- |
| **MPC** | 实部虚部是否共线 | 接近 100% | 局部阻尼元件、测量/拟合不良 |
| **MPD** | 相位散布多大 | 接近 0 度 | 同上，直接给角度刻度 |
| **MOV** | 加质量降频铁律是否成立 | 接近 100% | 计算模态、病态估计、力方向标反 |
| **MAC**（另文） | 两条振型是否一致 | 视对象而定 | 测点布置不当、漏测自由度 |

比较从同一数据组、用不同参数估计技术得到的两组模态时，手册建议同时盯有阻尼固有频率、阻尼比、MPC 和 MAC 四项——频率阻尼对上了而 MPC 一高一低，两条"同一个"模态里至少有一条振型可疑。

::: tip 判读顺序
- 先看 MOV 抓群体性错误（输入点方向、标定），再看 MPC/MPD 定位个别测点
- 指标全部健康但动画仍然古怪，回到 FRF 累加和综合对比，查是不是丢了模态或带外模态污染
- 三指标都好的振型，才值得进 MAC 去和 CAE 或历史数据对比
:::

## 七、小结

振型不是拟合出来就完事——频率阻尼靠稳定图，振型靠体检：MPC 查共线性、MPD 给相位散布角、MOV 用质量灵敏度符号一票否决计算模态。读数时记住三条：MOV 接近 100% 是物理模态的底线；单一输入点全模态 MOV 塌方先查力方向符号；MPC 低而 MPD 小，是局部测点问题而非整条振型问题。体检不过关的振型，不要让它进后续的灵敏度分析和修改预测——错误会顺着模态模型一路放大。
