# 重叠处理：50% 重叠为什么是汉宁窗的标配

> 频谱平均时相邻分析块共用一部分数据，就是重叠（Overlap）处理。它不是软件里一个可有可无的百分比：不加窗的重叠不引入新信息，加了汉宁窗之后 50% 重叠恰好让所有数据权重均等——这份巧合来自汉宁窗的数学恒等式。讲清楚重叠的统计账，也给出随机/正弦/瞬态三类信号的设置判断。

## 一、重叠是什么：相邻块共用数据

做 FFT 谱平均时，分析器每次取一段固定长度（帧长 T，N 个采样点）的时间记录做变换，然后前进、再取下一段。**重叠处理**就是每次前进的步距小于帧长：相邻两块有一部分数据是同一段波形。

![重叠处理示意：相邻 FFT 块共用部分数据](/images/overlap-processing/overlap-diagram.png)

*（图源：Simcenter Testing Knowledge Base）*

LMS 理论手册的表述很直白：历次 FFT 所取的时间记录并非彼此完全独立，而是取部分重叠。工程上重叠率用百分比表示——50% 重叠即第二块从第一块的中点开始，两块各有一半数据相同。

先算一笔时间账。设帧长 T = 2 s、平均 5 次：

| 设置 | 每块前进 | 5 块总时长 | 说明 |
| --- | --- | --- | --- |
| **无重叠 (0%)** | 2 s | 10 s | 相邻块完全独立 |
| **50% 重叠** | 1 s | 6 s | 同样 5 次平均，省 4 s |
| **66.7% 重叠** | 2/3 s | 4.67 s | 再换 1 块数据量 |
| **75% 重叠** | 0.5 s | 4 s | 3/4 数据是重复的 |

对稳态随机信号的长时监测，这笔时间账就是测试效率本身。

## 二、重叠为什么有效：汉宁窗的权重漏洞

如果数据不加窗，重叠毫无意义——手册原话：如果时域数据完全没有经过加窗，重叠处理并未计入任何新的数据，对谱估计没有任何统计上的改善。道理很简单：矩形窗下每块内所有采样点权重都是 1，相邻块重叠的那部分数据以同样的权重被重复计入，统计信息量没有增加，只是同一批数据被数了两次。

加窗之后情况完全不同。汉宁窗两端权重为零，中间权重最大：

$$w(n) = 0.5 - 0.5\cos\left(\frac{2\pi n}{N}\right), \quad n = 0, 1, \dots, N-1$$

不加重叠时，每个分析块前 20% 和后 20% 的数据被窗压到接近零——这些数据对平均几乎不做贡献，等于白采。手册配图直观展示了这个"权重漏洞"：

![汉宁窗下无重叠处理时的数据损失](/images/overlap-processing/hanning-no-overlap-loss.png)

*（图源：Simcenter Testing Knowledge Base）*

**30% 以上的重叠即可挽回这些损失**——这不是经验值，是从窗形状直接推出来的几何结论。

![施加约 30% 重叠后数据被均衡利用](/images/overlap-processing/overlap-30-percent-recover.png)

*（图源：Simcenter Testing Knowledge Base）*


### 从窗形状推出"至少 30%"的来源

汉宁窗在起点 w(0) = 0，在 20% 帧长处幅值只有：

$$w(0.2N) = 0.5 - 0.5\cos(0.4\pi) \approx 0.345$$

即块首尾 20% 的数据权重不到中心的一半，基本被丢弃。下一块从本块 70% 处开始（30% 重叠），恰好把本块尾部压低的样本用下一块中心的高权重重新利用一次。所以手册说"施加至少 30% 的重叠，即可挽回数据的损失，这不但是加快数据采集过程，也使得在统计意义上更加可信，因为所有采集数据被利用的程度更为均衡"。

但 50% 才是汉宁窗的"标配"。为什么恰好是一半？看恒定重叠相加（COLA, Constant Overlap-Add）条件。

## 三、50% 的数学必然：COLA 恒等式

把两帧错开 N/2 的汉宁窗叠加：

$$w(n) + w\left(n + \frac{N}{2}\right) = 0.5 - 0.5\cos\frac{2\pi n}{N} + 0.5 + 0.5\cos\left(\frac{2\pi n}{N} + \pi\right)$$

上式第二项展开 $\cos(\theta + \pi) = -\cos\theta$（$\theta = 2\pi n/N$），两项余弦相消：

$$w(n) + w\left(n + \frac{N}{2}\right) = 1$$

即 50% 重叠的汉宁窗逐点相加恒等于 1——每个采样点在两次加窗中的权重之和严格相等，没有任何点被系统性偏爱或亏待。这就是**恒定重叠相加（COLA）条件**，50% 是汉宁窗天然满足的步距。75% 重叠则不满足（三窗和不为常数，会在 1.0 与 1.5 之间起伏），需要更高阶窗（如 Blackman 窗 75% 满足 COLA）才能保持权重均匀。

::: info 核心概念
- **重叠率**：相邻分析块共用数据的比例，步距 = 帧长 ×（1 − 重叠率）
- **COLA 条件**：若干错位窗逐点相加为常数；汉宁窗在 50% 步距下满足，矩形窗任意步距满足（但无意义）
- **有效独立样本**：重叠块间谱值仍相关，真正决定平均效果的是独立信息量而非块数
:::

## 四、重叠的统计账：相关性与方差改善

重叠不是免费午餐。相邻块共用一半数据，两次 FFT 的谱值必然相关。衡量这个相关性的自然量是两个错位窗的内积与窗能量之比：

$$\rho = \frac{\sum_n w(n)\,w(n+H)}{\sum_n w^2(n)}, \quad H = \text{步距}$$

对随机信号，相邻块的功率谱相关系数为 $\rho^2$（幅度谱相关是 $\rho$）。代入汉宁窗可以精确算出：50% 重叠时 $\rho = 1/6$，功率谱相关 $\rho^2 = 1/36 \approx 0.028$——相邻块几乎独立，这是 50% 重叠"够用"的定量注脚。

把不同重叠率的账算全（帧长 N = 10000 点数值积分）：

| 重叠率 | 步距 | 相邻块窗相关 ρ | 功率谱相关 ρ² | 同数据量块数增益 | 方差改善 |
| --- | --- | --- | --- | --- | --- |
| **0%** | N | 0 | 0 | 1× | 基准 1/M |
| **25%** | 0.75N | 0.008 | ≈0 | 1.33× | ≈独立 |
| **50%** | 0.5N | 0.167 | 0.028 | 2× | ≈独立（微涨 6%） |
| **66.7%** | N/3 | 0.471 | 0.222 | 3× | 增益打折 |
| **75%** | 0.25N | 0.659 | 0.434 | 4× | 增益大幅打折 |

这张表是理解重叠设置的钥匙：**重叠换块数的收益在 50% 之后急剧衰减**。从 0% 到 50%，块数翻倍而块间相关仅 0.028，几乎白赚一倍平均次数；从 50% 再到 75%，块数再翻倍，但 ρ² 已达 0.434，多出来的块大半是旧数据的影子。

用 Monte Carlo 白噪声实验验证（M = 32 块汉宁窗平均，比较中心频段谱线方差）：

```python
import numpy as np

rng = np.random.default_rng(42)
N = 4096                       # 帧长（点）
M = 32                         # 平均块数
w = 0.5 - 0.5*np.cos(2*np.pi*np.arange(N)/N)   # 周期汉宁窗

def line_variance(overlap):
    # 白噪声下 M 块平均功率谱的中心频段方差
    hop = int(N*(1-overlap))   # 步距
    var = []
    for _ in range(300):
        x = rng.standard_normal(N + (M-1)*hop)
        pows = []
        for k in range(M):
            X = np.fft.rfft(x[k*hop:k*hop+N] * w)
            pows.append(np.abs(X)**2)
        var.append(np.mean(pows, axis=0)[600:1400].var())
    return np.mean(var)

v0, v50 = line_variance(0.0), line_variance(0.5)
print(f"无重叠   M={M} 方差: {v0:.0f}")
print(f"50%重叠  M={M} 方差: {v50:.0f}")
print(f"方差比: {v50/v0:.3f}  理论 (1+2*ρ²)/1 = {1+2/36:.3f}")
```

运行结果要点：方差比约 1.06，与理论值 1 + 2ρ² = 1.056 几乎重合——50% 重叠的 32 块平均与 32 块真正独立平均效果几乎相同，白赚了采样时长的一半。

但注意另一个方向：如果固定数据总长度，无重叠只能切 32 块，50% 重叠能切 63 块，后者方差降到前者的 2/3 × (1+2ρ²) ≈ 0.71——同样长的录音，重叠处理让谱线更平滑。这也是重叠在稳态随机信号处理中的真正价值。

::: warning 工程注意
重叠的方差收益只属于随机信号。正弦/阶次等确定性信号做 RMS 谱平均时，重叠块的相关性是 1 而不是 ρ²——重复数据被原样平均，块数虚高不带来任何精度提升，只会让测试报告的"平均次数"栏好看。瞬态信号（冲击、起点明确的扫频）不能用重叠：触发同步的分段方式本身保证了独立性，重叠反而会重复计入同一事件。
:::

## 五、按信号类型定设置

| 信号类型 | 推荐重叠 | 理由 |
| --- | --- | --- |
| **稳态随机**（路噪、稳态工况振动） | 50%～75% | ρ² ≤ 0.43，块数换方差依然划算；稳态数据越长越好 |
| **缓变工况**（升降速扫频） | 视帧长与转速变化率定 | 帧内转速变化要小，重叠补偿汉宁窗端部损失 |
| **正弦/阶次** | 0% 或少量 | 确定性信号无统计平均需求 |
| **瞬态/触发采集** | 0% | 触发即独立，重叠重复计入事件 |

::: tip 设置原则
- 默认 50%：汉宁窗 COLA 恒等式的天然步距，统计上近似独立，测试时间省一半
- 稳态随机要更快收敛 → 66.7%～75%，接受相关性代价
- 正弦、瞬态、触发类信号 → 老老实实 0%，别被"平均次数"迷惑
- 先想清楚要平均的量：功率类（PSD、自功率谱）才有方差账可算
:::

## 六、小结

50% 重叠的"标配"地位由三层事实叠成：汉宁窗两端各 20% 数据被压到无用，重叠至少 30% 才能挽回；50% 步距满足 COLA 恒等式 w(n) + w(n+N/2) = 1，数据权重严格均匀；功率谱块间相关仅 1/36，平均效果接近真正独立。三层里没有一层是"经验习惯"——把这个百分比调大之前，先确认自己是在用块数买平滑，还是在给报告注水。
