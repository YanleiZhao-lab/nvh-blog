# 声级计读数里的时间：时间计权与等效声压级

> 同一辆车过一遍粗糙路，声级计 Fast 挡读数在 62 到 71 dB(A) 之间跳，Slow 挡稳稳停在 66 dB，报告里写的却是 Leq = 67.3 dB(A)——三个数都对，回答的是三个不同问题。声压级从来不是一个"数出来就完"的量：频率计权决定哪些频段计入，时间计权决定读数以多快的速度跟随变化，等效声压级把一段时间的能量折成一个数。这篇从指数平均的递推式推起，讲清三挡时间常数的物理来历、上升快回落慢的不对称设计，以及 Leq 的能量平均为什么对短脉冲格外"宽容"。

## 一、读数为什么会跳：声压级里藏着一台平均机

声压级的定义本身不涉及时间：

$$L_p = 20\lg\frac{p}{p_0}$$

其中 $p$ 是声压有效值（RMS），参考声压 $p_0$ 为 20 微帕。麻烦在于"有效值"三个字——有效值必须对一段时间取平均才有意义，瞬时声压正负交替、平方前的均值为零，根本没有分贝可言。**时间上的平均是声压级定义自带的、绕不开的一步**，问题只剩：平均多长、怎么平均。

现实信号又不给面子。车内噪声随路面输入起伏，关门声 30 ms 就结束，怠速时风扇启停让声级漂上漂下。平均窗太短，读数抖得没法记录；太长，瞬态事件被摊薄到看不见。标准化的做法（IEC 651、ANSI 1.4-1983）是把"平均"拆成两个独立旋钮：

**旋钮一：频率计权。** 对声压信号的频谱先倍乘一个计权函数再求总 RMS。IEC 标准规定了 A、B、C、D 几种计权，全部以实验等响曲线为底本——A 计权相当于 40 方等响曲线的倒置，B、C 分别对应 70 方、100 方。这一步决定"哪些频率算数"，展开见[《A计权：为什么 40 方等响曲线成了标准》](./a-weighting.html)。

![标准计权曲线：A、B、C 三种计权随频率的衰减与放大](/images/spl-time-weighting-leq/fig4-2-weighting-curves.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册）*

**旋钮二：时间计权。** 对已经计权的时域信号做指数平均，得到规定的计权声压级。这一步决定"读数多快跟上变化"，是本文主角。

::: info 核心概念
- **频率计权（Frequency Weighting）**：求 RMS 之前对频谱乘的计权函数（A/B/C/D），改的是"算哪些频率"
- **时间计权（Time Weighting）**：对计权后时域信号做的指数平均，改的是"读数多快跟随"
- **有效值声压（RMS Pressure）**：一段时间内声压平方平均的开方；离开平均时长谈 RMS 没有意义
- **等效声压级（Leq）**：一段时间 T 内能量平均折算的声压级，回答"这一整段多响"
:::

## 二、时间计权：从指数平均的递推式推起

### 为什么是指数平均，不是滑窗平均

滑窗平均把窗内每个样本一视同仁，窗一挪，进出的样本权重跳变，读数跟着抖。指数平均换一种记法：**新样本全权重进来，历史读数整体打折保留**。手册给出的计权因子为 $e^{-\Delta t/\tau}$，其中 $\Delta t$ 为采样间隔，$\tau$ 为时间常数。把它展开成逐拍递推，物理图景就出来了：

$$m(n) = a\,x^2(n) + (1-a)\,m(n-1), \qquad a = 1-e^{-\Delta t/\tau}$$

推导只两步。第一步，"历史读数整体打折"即 $m(n-1)$ 乘上 $e^{-\Delta t/\tau}$；第二步，权重归一——新样本权重取 $a = 1-e^{-\Delta t/\tau}$，恰好补足打折掉的那一份，稳态输入下读数不漂移（恒定均方值代进去，$m(n)=m(n-1)=x^2$，自洽）。于是 $m(n)$ 就是"到当前时刻为止的均方值估计"，声级读数取 $10\lg m(n)$。

对突加的稳态声，读数按 $1-e^{-t/\tau}$ 的曲线爬升：一个时间常数到 63.2%，两个到 86.5%，三个到 95.0%。指数没有"记忆起点"，天然适合连续刷新的表头，不用维护滑窗；代价是读数永远滞后于真值，时间常数越大滞后越重。

### 三挡时间常数与不对称的衰减设计

手册给出三挡取值，按信号类型选用：

| 时间计权 | 时间常数 | 初始回落斜率 | 定位 |
| --- | --- | --- | --- |
| **Impulse 脉冲** | 35 ms | 2.9 dB/s（衰减用 1500 ms） | 抓尖峰，快上慢下，附加峰值检测 |
| **Fast 快挡** | 125 ms | 34.7 dB/s | 通用默认，跟得上多数车内起伏 |
| **Slow 慢挡** | 1 s | 4.3 dB/s | 稳态读数、起伏大的声源 |

先判型后选挡：含尖峰脉冲判"脉冲"类；快变、慢变信号分别配 125 ms、1000 ms。最有工程味的是**不对称设计**——信号强度递增时，平均可以准确跟踪变化；一旦信号递减，改用更长的衰减时间常数，非约定取值 1500 ms。工程逻辑：脉冲来了要在几十毫秒内把读数顶上去（人耳对突袭声的警觉就这个量级），脉冲走了读数慢慢回落，让表针停在峰值附近供人读数。上升用短时间常数保灵敏，回落用长时间常数保可读，一台平均机做出两种性格。

::: warning 工程注意
Impulse 挡读数不能当能量指标用。上升 35 ms、回落 1500 ms 的不对称响应，使它对短暂尖峰的示值远高于等能量的稳态声——拿 Impulse 值与 Leq 直接比大小，等于拿两种平均法则各记各的账。报告里写 Impulse 值，必须注明衰减挡取值，否则复测对不上。
:::

### 三挡对同一段瞬态的读数差多少

拿一段 100 ms 的等幅声脉冲(均方值恒为 1, 稳态读数即 0 dB)喂给三挡递推式, 看脉冲结束前读数能爬多高:

| 时间计权 | 时间常数 | 100 ms 脉冲内最大读数 | 爬升进度 |
| --- | --- | --- | --- |
| **Impulse** | 35 ms | **-0.26 dB** | 2.86 个时间常数, 已达 94% |
| **Fast** | 125 ms | **-2.59 dB** | 0.8 个时间常数, 只爬到 55% |
| **Slow** | 1 s | **-10.22 dB** | 0.1 个时间常数, 只爬到 9.5% |

同一个声事件, 三挡读数差出 10 dB, 这就是读数里时间的分量。Slow 挡看 100 ms 的关门声, 读数还没爬起来事件就结束了, 10 dB 就这么被时间常数吃掉。

## 三、Python 演示: 亲手喂三挡一个脉冲

把上面那张表用 numpy 复现出来。构造一段 100 ms 的声脉冲, 分别以 35 ms / 125 ms / 1 s 三个时间常数跑指数平均递推, 看读数在脉冲结束前能爬到多高:

```python
import numpy as np

fs = 1000                      # 采样率 1 kHz, 演示用
t = np.arange(0, 1.5, 1/fs)    # 1.5 s 时间轴
x2 = np.zeros_like(t)
seg = np.logical_and(t >= 0.2, t < 0.3)   # 0.2~0.3 s 一个 100 ms 声脉冲(均方值=1)
x2[seg] = 1.0

def expo_avg(sig, tau, fs):
    """对均方信号做指数平均, tau 为时间常数(秒)"""
    a = 1 - np.exp(-1 / (tau * fs))       # 递推系数
    out = np.zeros_like(sig)
    for n in range(1, len(sig)):          # m(n) = a*x2(n) + (1-a)*m(n-1)
        out[n] = a * sig[n] + (1 - a) * out[n - 1]
    return out

for name, tau in [("Impulse", 0.035), ("Fast", 0.125), ("Slow", 1.0)]:
    m = expo_avg(x2, tau, fs)
    print("%-9s 脉冲内最大读数 %6.2f dB (相对稳态)" % (name, 10*np.log10(m.max())))
```

输出三行: Impulse -0.26、Fast -2.59、Slow -10.22 dB。最值得看的是 Slow 那一行——同一段声脉冲, 只把时间常数从 35 ms 换到 1 s, 读数就被压低 10 dB; 100 ms 的事件相对 1 s 时间常数只占十分之一个时间常数, 均方估计根本没来得及积累。若把脉冲换成 50 ms 的关门声, Slow 挡亏得更多(约 -13 dB), 这就是瞬态异响必须换 Impulse 挡或直接算 Leq 的定量理由。

## 四、等效声压级 Leq: 把一段能量折成一个数

### 从能量平均推 Leq

时间计权回答现在多响, 法规和报告要的是这一整段多响。ISO 1996/1-1982 与 ISO 1999/1-1990 给出定义: 等效连续 A 计权声压级, 把区间内的均方声压做时间平均再取对数:

$$L_{Aeq,T} = 10\,\lg\left[\frac{1}{t_2-t_1}\int_{t_1}^{t_2}\frac{p_A^2(t)}{p_0^2}\,dt\right]$$

其中 $p_A(t)$ 为瞬时 A 计权声压, $p_0$ 为 20 微帕参考声压, 积分区间从 $t_1$ 到 $t_2$。推导只两步:

第一步, 能量平均的均方声压是平方的时间平均——平均的对象是平方, 不是声压本身, 更不是分贝值。这一步的物理意义: 声能量与声压平方成正比, Leq 要折算的是能量账, 所以先在平方域里把时间摊平。

第二步, 代回声压级定义取对数。连续积分离散成抽样后, 就是手册所说的以 dB 标度的声压级抽样值求和及平均: 每个抽样先还原成均方值(10 的 L/10 次幂), 按时间占比加权求和, 再取 10 倍常用对数。

关键性质随之而来: 分贝不能直接平均。对数是非线性的, 能量账里占主导的是大声级时段——两段各半的 80 dB 与 70 dB, 能量平均是 77.4 dB 而不是算术平均 75.0 dB; 90 dB 摊进只占一成时间的 50 dB 背景里, 结果 80.0 dB, 几乎由大声级时段独占。反过来看关门声: 一记 85 dB、持续 0.1 s 的关门声摊进 60 s 的 30 dB 背景, Leq 是 57.2 dB——短促强脉冲被时间稀释, 但仍比背景高出 27 dB, 主导整段读数。Leq 对短脉冲的宽容与严苛, 全在这一个例子里。

### Leq 与时间计权、SEL 的分工

| 量 | 平均方式 | 回答的问题 | 典型用途 |
| --- | --- | --- | --- |
| **时间计权声级** | 指数平均(不对称时间常数) | 此刻多响、峰值多大 | 表头读数、事件监测、瞬态判型 |
| **Leq 等效声压级** | 线性能量平均(式 7-1) | 整段平均多响 | 法规限值、通过噪声、工况对比 |
| **声暴露级 SEL** | 能量折算到 1 秒 | 单个事件总能量 | 关门声、敲击声排序 |

::: tip 报告怎么选
- 对标法规限值、跨工况对比、长时间监测, 用 Leq, A 计权, 标明积分时长 T
- 关门声、敲击声等单事件排序, 用 SEL 或 Impulse 挡读数, 写清衰减挡
- 稳态工况的表头读数用 Slow 挡; 诊断起伏、抓异常从 Fast 挡起步
- 瞬态异响判型用 Impulse 加峰值检测, 但禁止与 Leq 直接比大小
:::

一台 SUV 匀速巡航, 车内 A 计权声压级 Slow 挡稳定在 66 dB(A) 上下 1 dB 起伏, 同一路段 60 秒 Leq 算出 66.8 dB(A), 两者接近——信号平稳时, 能量平均与指数平均给出几乎一样的答案。换到坏路通过段, Fast 挡读数在 62 到 71 dB(A) 之间甩动, Slow 挡压到 66 dB 附近, 60 秒 Leq 是 67.3 dB(A)。三个数并排放进报告: Slow 给典型值, Fast 给波动范围, Leq 给能量账。数值都来自同一段数据, 差的只是那台藏在读数里的平均机。

积分时长不同, Leq 不可直接比较。60 s 与 10 min 的 Leq 差着一段能量记账的口径, 跨数据对比前先统一积分时长与计权方式; 把 Leq 与时间计权读数混进同一张表里排序, 是报告评审时最常被揪出的错误。

## 五、小结

时间计权是一台以指数折扣记忆历史的均方估计器: Impulse 35 ms、Fast 125 ms、Slow 1 s 三挡, 配上信号递减时 1500 ms 的长衰减常数, 构成快上慢下的不对称读数; Leq 把线性能量平均折成单一分贝值, 积分时长与计权方式必须随数标注。判断标准三条: 看瞬态选 Impulse, 看趋势选 Slow, 算总账用 Leq。同一段录音三个数各答各的问题, 写报告前先想清楚要回答哪一个。
