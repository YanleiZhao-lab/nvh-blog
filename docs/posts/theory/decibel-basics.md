---
title: dB 与对数刻度：为什么声学量都用分贝
---

_nvhtest.cn_ 的后台常收到一类提问："报告里写 78 dB(A)，到底是多大声音？为什么不是多少多少帕？" 这一篇就把分贝这件事从工程底层讲透：它不是单位，是比值；它存在的理由，是人耳和 NVH 信号都横跨好几个数量级；它的两个公式（10 lg 与 20 lg）背后是完全不同的物理量类别。把这篇读懂，后面所有声学报告你都能自己核算。

## 一、先回答：dB 到底是什么

很多人以为 dB 是和帕斯卡、米每秒平方并列的"单位"，画在 Y 轴上看起来也确实像个单位。但它不是——**分贝是一个无量纲的比值**，是"测量值"和"参考值"两个数取对数后的结果。

它最早来自电话行业：二十世纪初，工程师需要量化电话信号在长距离电缆中的功率损耗，于是发明了这个对数比值，取名 decibel，纪念电信先驱 Alexander Graham Bell（1 Bel 的十分之一是 1 dB，但 Bel 本身几乎没人用）。

为什么电话工程师要用对数？因为信号在电缆里是指数衰减的，线性刻度下衰减曲线很快压成一团，而对数刻度能把几个数量级的动态范围压到一张图里。这个动机，和我们今天在 NVH 里用 dB 的动机一模一样。

### 工程上的根本原因：动态范围

人耳能听到的最小声压波动约 20 µPa（1000 Hz 处的平均听阈），而一架喷气机旁边是几百帕。两者相差 **7 个数量级以上**——线性坐标根本没法画在一张图上。声压、声功率、声强、振动加速度、电压，凡是涉及"激励源强弱"的量，都有这个问题。

对数刻度的第二个好处：**人耳对响度的感知本身就接近对数**。声压翻一倍，听感并不是翻一倍；声压增加约 10 倍（20 dB），主观响度才大约翻一倍。用 dB 表达，数值变化和主观感受变化大致同步，沟通起来直观。

## 二、两个公式，对应两类物理量

这是整篇文章最核心的一张图。dB 的定义分两种形式，取决于你手上的量是"功率类"还是"幅值类"：

![功率类量与幅值类量的 dB 定义公式](/images/decibel-basics/db-equations.png)

**功率类量**（能量或功率本身）用 10 倍对数：

dB = 10 · lg(W / W_ref)

典型代表：声功率（W）、声强（W/m²）、电功率。

**幅值类量**（场量的幅值，取 RMS）用 20 倍对数：

dB = 20 · lg(p / p_ref)

典型代表：声压（Pa）、电压（V）、加速度（m/s²）。

为什么系数差一倍？直觉解释：功率正比于幅值的**平方**，对数里平方提出来就是系数 ×2，于是 10 变 20。所以"平方关系"就是这两个公式的全部区别——记住"幅值平方才是功率"，10 和 20 就不会用错。

::: warning 最常见的低级错误
拿到一个电压值直接套 10 lg。电压是幅值类量，必须用 20 lg。用错系数，结果差一倍（6 dB），报告就废了。
:::

### 参考值：dB 的一半是它

既然是比值，参考值（Reference）就决定了数值的绝对含义。声学里最常用的几个：

| 物理量 | 类型 | 参考值 | 说明 |
|---|---|---|---|
| 声压 SPL | 幅值 | 20 µPa | 1000 Hz 平均听阈 |
| 声功率 | 功率 | 1 pW（10⁻¹² W） | 声功率级 Lw |
| 声强 | 功率 | 10⁻¹² W/m² | 声强级 Li |
| 加速度（振动） | 幅值 | 视标准而定（如 1 µg、1 m/s²） | 振动 dB re |

20 µPa 这个数不是随便定的：它是平均人耳在 1000 Hz 处能察觉的最小压力波动。也就是说，**0 dB SPL 恰好是"刚好听得见"**，这个锚点让所有声学数据都有人的尺度。

::: info 没写参考值的 dB 是不完整的
"dB"本身只说明"是对数比值"，不说明大小。比较两次测试、对标杆两份报告时，第一步永远是核对参考值是否一致。Simcenter Testlab 里可以在 Configuration & Units System 编辑器中查每种量的默认参考值。
:::

## 三、声压、声功率、声强：三个都能换算成 dB，但不是一回事

NVH 报告里 dB 满天飞，经常有人混着用。这三个量虽然都表达成 dB，物理含义完全不同：

- **声压（Sound Pressure）**：某个空间位置上的压力波动，标量，单位 Pa。用一支麦克风就能测。它是"位置"的函数——离源越远越小，受环境反射影响。
- **声功率（Sound Power）**：声源单位时间发出的声能量，单位 W。它是声源本身的属性，**与环境无关**——放在消声室和混响室里测，声功率是同一个数。
- **声强（Sound Intensity）**：声能量流的密度，W/m²，是**矢量**，有方向。需要至少两支麦克风按特定间距布置（如 Simcenter Soundbrush 的四面体四麦克风阵列）才能测。

![声压、声功率、声强度虽然物理量不同，但都可以表达为分贝](/images/decibel-basics/db-three-quantities.png)

一个很好的类比是暖气片：房间里每处的温度（对应声压）随位置变化；暖气片每小时发出的热量（对应声功率）是它自己的属性；热流的密度和方向（对应声强）则描述能量怎么传播。

在自由场条件下三者可以互相换算。手册里给了一个例子：一台声功率 0.02 W 的设备，在 2 m 半径的半球面上测量，半球面积约 25 m²，声强 = 0.02/25 = 0.0008 W/m²，按功率类公式换算（参考值 10⁻¹² W/m²）约 **89 dB**。这个"功率除以包络面积"的思路就是声功率标准测试（如 ISO 3744 系列测点阵列）的底层逻辑。

::: warning "78 dB"不说明任何问题
开会时有人说"这个电机 78 dB"，一定要追问：声压还是声功率？测点距离多少？什么计权？三个答案不同，78 dB 可以是好电机也可以是不合格的电机。
:::

## 四、dB 的心算：工程师的口算表

对数刻度用多了，几个关键换算应该形成条件反射：

| 幅值变化（线性） | 对应 dB（20 lg） |
|---|---|
| ×2 | +6 dB |
| ×10 | +20 dB |
| ×100 | +40 dB |
| ×0.5 | −6 dB |
| ×0.1 | −20 dB |

功率类变化减半：功率 ×2 是 +3 dB，×10 是 +10 dB。这就是为什么"降 3 dB"在声功率意义上是砍掉一半能量——法规限值动辄要求降 3 dB，不是随便说说的数字，是一半。

滤波器规格里也有同样表述：幅值减半对应 6 dB 衰减，增益为 1（不变）对应 0 dB。看到滤波器规格书写"60 dB/倍频程滚降"，脑子里应立刻翻译成"每个倍频程幅值缩小 1000 倍"。

### 距离衰减：自由场每倍距离 −6 dB

远场自由场条件下，声传播服从平方反比律：距离翻倍，声压减半，即 **−6 dB**。这条规律在现场排查时极好用：

- 车间里测得某设备 1 m 处 85 dB，2 m 处理论上 79 dB。实测如果只降了 2 dB，说明混响场占主导（反射声淹没直达声），这时候逼近声源去定位是有效的，但"距离修正"那套算法不再适用。
- 产品要求 50 dB 的通过噪声，麦克风位置差 1 倍距离，结果就能差 6 dB——标准里规定测点距离（常见 1 m）不是形式主义。

注意 −6 dB/倍距离只在**远场**成立（距源约 2 个波长以外）。近场里声能一部分在声源表面来回"环流"（倏逝波），一部分向外传播，压力与距离没有固定关系，单麦克风测出来的数据既不可重复也不可比较——这也是声阵列技术存在的理由之一。

## 五、dB 加减的正确姿势：能量相加，不是数值相加

两个 80 dB 的声源叠加是多少 dB？不是 160，是 **83 dB**。

dB 是对数量，不能直接加减。正确做法是先换回能量域（功率/幅值平方）相加，再取对数回来。两个等幅声源叠加，能量翻倍，功率类 +3 dB（幅值相当于 ×1.414）。同理：

- 80 dB + 74 dB ≈ 81 dB——能量差 4 倍以上时，小源贡献基本被淹没；
- **背景噪声修正**：当背景噪声比总声级低 10 dB 以上时，背景贡献小于 0.5 dB，通常可不作修正；两者只差 6 dB 时修正量约 1.3 dB；差值再小，测量基本无效，得想办法先降背景。

这套"能量相加"的逻辑同样适用于振动：多激励源叠加、隔振效率计算、声学包贡献量分析，底层都是能量域的加减。

## 六、A 计权：dB 世界的"人耳滤镜"

同一条频谱，人耳听到的和麦克风录到的差别很大：耳道在 4000 Hz 附近有共振，耳蜗对低频和高频都不敏感。A 计权（A-weighting）就是一条标准化的频率修正曲线，把麦克风数据修正到"接近人耳感知"。

![A 计权曲线：1 kHz 处 0 dB，低频大幅衰减，1k–6 kHz 略有放大](/images/decibel-basics/db-a-weighting-curve.png)

曲线的几个关键点：

| 频率 | A 计权修正 |
|---|---|
| < 1000 Hz | 衰减（100 Hz 约 −20 dB，低频衰减更狠） |
| 1000 Hz | 0 dB（不增不减） |
| 1000 ~ 6000 Hz | 放大几个 dB |
| > 6000 Hz | 衰减 |

这也是声校准器都选 1000 Hz 发声的原因——A 计权在 1 kHz 处增益为 0，无论计权开关是否打开，校准读数都不变，杜绝了操作失误。

用 dB 表达 A 计权特别方便：计权就是**每条谱线加/减一个固定的 dB 数**。手册例子：100 Hz 处测得 80 dB，A 计权 −20 dB，结果 60 dB(A)。在对数域，滤波变成加减法——这是 dB 体系能统治声学报告的又一个实际原因。

::: warning dBA 不一定比 dB 小
直觉上 A 计权"削掉一大片"，总值应该更低。不一定。手册给了一个口哨的例子：未计权总值 84.2 dB，A 计权后反而 85.1 dB(A)——因为口哨能量集中在约 1600 Hz，恰好落在放大区，净效果是抬高。低频为主的排气噪声，A 计权后通常大幅下降；而高频啸叫，A 计权后可能更难看。评判决不能只看"有没有 A"。
:::

## 七、实测核对：在 Testlab 里自己算一遍

给一个可以动手复现的例子（出自手册）：用 SCADAS + 传声器录一段乐队调音，频谱显示 RMS 声压 1.084 Pa。声压是幅值类量，套 20 lg 公式：

20 · lg(1.084 / 20e-6) ≈ 94.7 dB

![Simcenter Testlab 中以 Amplitude 格式显示的频谱](/images/decibel-basics/db-example-spectrum.png)

在 Simcenter Testlab 里核对：右键 Y 轴 → Format → dB/Level，谱图即刻切换成 dB 显示。

![手工计算结果与 Testlab 显示一致](/images/decibel-basics/db-result-check.png)

数对上了——但前提是你选的参考值和软件一致。如果单位制里参考值被改过（或对比的是别家系统），同一个 1.084 Pa 会给出完全不同的 dB 数。这就是为什么本文反复强调：**报告里的 dB 必须带参考值才有意义**。

## 写在最后

dB 不是玄学，它就三句话：

1. **它是对数比值**，功率类 10 lg、幅值类 20 lg，系数区别来自"幅值平方是功率"；
2. **参考值决定一切**，20 µPa / 1 pW / 10⁻¹² W/m² 这些锚点把物理量拉到人的尺度上；
3. **加减在能量域做**，叠加、修正、计权、距离衰减，全都是能量域的账。

下次再看到"降 3 dB"的要求，你脑子里浮现的应该是"能量砍半"；看到"78 dB(A)"，应该条件反射地追问声压还是声功率、多远、什么环境。能到这一步，声学报告的门就进去了。
