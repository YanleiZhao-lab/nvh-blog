# ODS工作变形：不激励也能看振型

> 整车怠速轰鸣、变速箱啸叫排查，常常没有条件把车架起来敲击做模态。ODS（Operational Deflection Shape，工作变形分析）只测响应、不测激励力，直接把"运行状态下结构每个点怎么动"做成动画。它和模态振型长得像，却是两个概念——分不清它，共振判断、噪声传递路径分析都会走偏。

## 一、ODS 到底"变形"的是什么

结构运行时，每个测点都在振动。把同一频率下所有测点响应的幅值和相位集合成一个向量，在几何模型上循环动画显示出来，就是一幅 ODS——各测点之间相对运动的往复形态。

它的数学本质是强迫响应。以位移 ODS 为例，基于位移/力频响函数 H 和激振力线性谱 F，某频率 ωp 处各测点的响应向量为：

{X(ωp)} = [H(ωp)]{F(ωp)}

展开成模态叠加的形式，每一阶模态的贡献 = 振型 × 模态频响 × 该阶振型在力作用点的取值 × 力幅。这个表达式直接暴露了 ODS 的几个性质：

::: info 核心概念
- **任意频率都有 ODS**：模态振型只属于确定的固有频率，ODS 在任何测量频率处都能提取——1024 点数据块有 512 条谱线，理论上就有 512 个 ODS
- **ODS 依赖激励**：力的大小、频率成分变了，ODS 跟着变；模态振型只由结构自身（质量、刚度、阻尼）决定
- **共振点与激励谱峰点 ODS 占优**：在这两类频率上，ODS 幅值显著突出，是重点观察对象
- **无阻尼信息**：ODS 给不出阻尼比，也给不出留数、模态参与因子等模态参数
:::

为什么叫"不激励也能看振型"？因为 ODS 不需要测量输入力。发动机运转、路面激励、齿轮啮合——这些"免费"的工况激励本身就在持续激励结构，只要工况稳定，测响应谱就够了。代价是：你看到的是"这台车这个工况下的真实变形"，不是结构固有的属性。

什么时候 ODS 占优、接近某阶模态振型？两种情况：频率落在结构共振点附近，且该阶模态被显著激发；或者激励力谱在该频率有峰且以某一模态贡献为主。频率落在两阶模态之间、或多阶模态混叠时，ODS 是几阶振型的线性组合，直接当成"第 N 阶振型"解读就会出错。

## 二、测量方案：传导函数与互功率谱

ODS 测量的理想条件是：结构作简谐振动、短时间内工况稳定、信噪比高到不需要平均。实际通道数不够时要分批测量，加上工况漂移，必须设一个**参考自由度**——所有测点都相对它测量。从一批到另一批，工况变化对参考点和响应点的影响相同，相对关系（幅值比与相位差）基本被保留下来。

两种工程上常用的测量函数：

| 测量函数 | 计算方式 | 特点 | 适用场景 |
| --- | --- | --- | --- |
| **传导函数（Transmissibility）** | 响应谱 ÷ 参考点谱（复数比） | 无量纲；共振峰在分子分母间约分抵消，峰值不明显；反共振点分母趋零会产生假峰 | 分批测量、工况有漂移 |
| **互功率谱（Cross Spectrum）** | 响应谱 × 参考点谱的复共轭 | 峰值明确标示高响应频率；需要所有通道同时测量 | 多通道系统一次性测完 |
| **相位参考谱（Phase Referenced Spectrum）** | 每帧把参考通道相位归零、同相减所有通道 | 既有正确幅值又有正确相位，可安全平均 | 噪声大需要平均的场合 |

传导函数的峰要小心读：分子（互谱）和分母（参考点自谱）在同一频率都有峰时，共振峰互相约分，T 值反而不大；反倒是参考点处于反共振（分母接近零）时，T 会出现一个与高响应无关的尖峰。用互功率谱就没有这个问题——峰就是高响应级频率，但它要求所有响应在完全相同的工况下测得。

绝对标尺怎么定？传导函数乘以参考自功率谱的 RMS 值，或互功率谱按式 17-11 用参考自功率谱定标，ODS 系数就带上物理单位（位移 m、加速度 g 等）。位移、速度、加速度 ODS 之间可以靠乘 ω 或 ω² 互相换算——注意这在频域是一条谱线一个系数的换算，不是时域积分。

::: warning 工程注意
- **ODS 无阻尼**：想拿阻尼比，必须回头做模态分析；密集模态下 ODS 更难解读，几阶振型混在一幅变形里
- **滤波器会毁掉动画**：如果对部分通道加了滤波（如去趋势、带通），其他通道没加，滤波引入的相位延迟会打破通道间固定相位关系，动画直接失真
- **平均毁幅值**：普通 Spectrum 平均时相位随机，幅值会越平均越小；需要平均又要相位，用相位参考谱
- **参考点别放在节点上**：参考点恰好是关心模态的节点（响应趋零），传导函数分母失控，全盘失真
:::

## 三、ODS 与模态振型：一张表分清

| 对比项 | **ODS（工作变形）** | **模态振型** |
| --- | --- | --- |
| **所属频率** | 任意测量频率 | 固有频率（结构属性） |
| **是否依赖激励** | 是（力的量级、频率成分、作用点） | 否 |
| **物理单位** | 可定绝对标尺（m、mm/s、g） | 常归一化，无量纲 |
| **阻尼信息** | 无 | 有（模态阻尼比） |
| **获得方式** | 运行状态测响应谱即可 | 需可控激励 + FRF + 曲线拟合 |
| **典型用途** | 工况下变形定位、噪声源排查、验证 CAE | 结构动态特性描述、修改预测 |

判断一幅 ODS 是不是"某一阶振型占主导"，标准工具是 MAC（Modal Assurance Criterion，模态置信判据）：

MAC = |V1 与 V2 共轭点积|² /（V1 自点积 × V2 自点积）

两个向量线性相关（一幅是另一幅的常数倍）时 MAC 趋近 1，彼此无关时趋近 0。把实测 ODS 与各阶计算/试验模态振型逐一算 MAC，值接近 100% 的那阶就是主导模态；配合 MSF（模态比例因子，两向量的最小二乘比例常数）还能看幅值比。更进一步可以做**模态分解**：把 ODS 展开为模态振型的线性组合，看清共振现象到底由哪阶贡献。

## 四、Python 演示：同一根梁，三个频率三幅形

用一根简支梁的 9 个测点演示 ODS 与模态振型的关系：两阶模态（12 Hz、47 Hz），力作用在第 4 个测点。分别提取 12 Hz（第一阶共振）、30 Hz（两阶之间）、47 Hz（第二阶共振）三个频率的 ODS，与两阶解析振型算 MAC。

```python
import numpy as np

# 简支梁示意：9 个测点，两阶模态，模态叠加法生成各点响应
x = np.linspace(0, 1, 9)
phi1 = np.sin(np.pi * x)            # 一阶振型
phi2 = np.sin(2 * np.pi * x)        # 二阶振型
f1, f2, zeta = 12.0, 47.0, 0.02     # 固有频率与阻尼比
fp, F0 = 3, 10.0                    # 激振力作用在第 4 个测点，10 N

def ods(f):                          # 模态叠加：X(f) = Σ phi_k · H_k(f) · phi_k(fp) · F0
    w, w1, w2 = 2*np.pi*f, 2*np.pi*f1, 2*np.pi*f2
    h1 = 1 / (w1**2 - w**2 + 2j*zeta*w1*w)
    h2 = 1 / (w2**2 - w**2 + 2j*zeta*w2*w)
    return F0 * (phi1*h1*phi1[fp] + phi2*h2*phi2[fp])

def mac(a, b):                        # 模态置信判据 MAC（0~1）
    return abs(np.vdot(a, b))**2 / (np.vdot(a, a).real * np.vdot(b, b).real)

print("频率      幅值@测点2/4/6 (um)        MAC-一阶  MAC-二阶")
for f in [f1, 30.0, f2]:
    v = np.abs(ods(f)) * 1e6         # 换算成微米
    print(f"{f:5.1f} Hz   {v[2]:7.1f} / {v[4]:6.1f} / {v[6]:7.1f}"
          f"    {mac(ods(f), phi1):.3f}    {mac(ods(f), phi2):.3f}")
```

运行结果要点：47 Hz 时测点 4 幅值只有 113 μm，两侧测点是它的 18 倍——那是二阶振型的节点，节点不动是"振型指纹"；12 Hz 共振处 MAC-一阶 = 1.000，ODS 与振型完全一致；30 Hz 落在两阶之间，MAC 0.837/0.163，两阶混叠、谁都不主导，这正是 ODS 最容易误读的频区。

## 五、小结

ODS 是工况下的真实变形，不是结构属性。工程判断顺序：先看动画定位"哪里动得大、节点在哪"，再用 MAC 对照模态振型确认主导模态，需要阻尼和修改预测时回到模态分析。通道不够分批测，参考点选响应大且稳定的非节点位置，传导函数的峰先排查参考点反共振再下结论。
