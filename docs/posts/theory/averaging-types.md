# 平均技术对比：同一组数据，五种平均差出三倍

> Simcenter Testlab 稳态测量里那个不起眼的 "Averaging type" 下拉菜单，藏着五种算法：能量平均、线性平均、能量指数平均、最大值、最小值。同一组数据 3g、5g、10g，五种平均的结果从 3g 到 10g 不等——差出三倍多。这篇用手册里的经典算例，把五种平均的数学、物理含义和各自该用的场景一次讲清。

## 一、为什么"平均"不是一件事

多数人第一次打开 Simcenter Testlab Signature Acquisition 的稳态测量设置，看到平均类型下拉框里有五项，默认是 Energy average，然后就再也不改了。

问题在于：稳态测量模式下，软件把每一帧数据的自功率谱（Autopower）逐谱线平均成最终结果。平均方式不同，逐条谱线合并的规则就完全不同。手册举了个最小算例：10 Hz 谱线处，三帧数据分别测得 3g、5g、10g，五种平均算下来——

| 平均类型 | 10 Hz 谱线结果 | 一句话规则 |
| --- | --- | --- |
| **能量平均（Energy）** | 6.68 g | 平方后再平均，再开根号 |
| **线性平均（Linear）** | 6.00 g | 算术平均，逐帧等权 |
| **能量指数平均（Energy exponential）** | 7.00 g* | 新数据权重高，旧数据指数衰减 |
| **最大值（Maximum）** | 10.00 g | 逐谱线取峰值保持 |
| **最小值（Minimum）** | 3.00 g | 逐谱线取历史最低 |

\*指数平均结果依赖帧顺序，此处为 3、5、10 依次测量、EWF=50% 的结果；同样三个数按 5、10、3 的顺序测，结果变成 5.25 g。

![Simcenter Testlab 平均类型下拉菜单的五个选项](/images/averaging-types/fig1-dropdown.png)
*（图源：Simcenter Testing Knowledge Base）*

能量平均偏大不是缺陷，是设计。平方过程天然让高幅值帧拿到更多权重——这正好符合"能量叠加"的物理直觉：两台同一型号的噪声源同开，总声能量是两者相加，不是声压算术相加。声学应用几乎都指明用能量平均，比如多麦克风声功率测量里，对声压谱做能量平均合成单点等效值。

还有一条容易被忽略的副规则：能量平均的平方过程会抹掉相位。如果相位信息重要——比如要做 ODS 或传递函数分析——就得用线性平均配合 Spectrum（复谱）函数使用，而不是对 Autopower 做能量平均。

::: info 核心概念
- **帧（Block）**：一次 FFT 分析所用的数据段，稳态测量里多帧逐谱线合并成最终谱
- **能量平均**：先平方、再平均、后开方（RMS 平均），高幅值帧权重大，声学默认
- **指数平均**：递推式加权，新帧权重 (1-EWF)、旧结果权重 EWF，帧顺序影响结果
- **峰值保持（Peak hold）**：Maximum 的俗称，逐谱线保留历史最大值，不收敛
:::

## 二、逐个拆解：数学、行为与适用场景

### 能量平均：能量域的算术平均

对幅值序列 a1, a2, ..., aN，能量平均是平方求和、除以 N、再开根号。3g、5g、10g 算出 6.68 g，明显高于算术平均 6 g，因为 10 g 那帧的平方占了结果的大头。

对平稳随机信号，能量平均还有个隐藏好处：随机误差随平均次数按 1/sqrt(N) 收敛。16 帧平均把谱线幅值的随机波动压到单帧的四分之一，64 帧压到八分之一。稳态工况测背景噪声、测声功率，能量平均是统计学上最稳妥的选择之一。

### 线性平均：等权平均，保留相位

线性平均就是算术平均，每帧等权。它对幅值谱做平均时结果可预期（本例 6 g），但真正的价值在于：当测量函数是 Time 或 Spectrum 时，线性平均会把相位一起平均进去。Spectrum 直接平均时相位杂乱会导致幅值逐次塌陷（[Spectrum 与 Autopower 的区别](./spectrum-vs-autopower.html)那篇专门讲了这个现象），所以线性平均的典型搭档是自功率谱或时域平均——比如发动机逐循环角度域平均，把非同步成分平均掉只留燃烧激励。

### 能量指数平均：会"遗忘"的平均

前两种平均对时间无记忆：先测 3g 后测 10g，与先测 10g 后测 3g，结果一样。指数平均不是。它按递推式更新：

    An = EWF x A(n-1) + (1 - EWF) x an

EWF（Exponential Weighting Factor，指数加权因子）取 0 到 100%。EWF=0 时平均就等于最新一帧（完全遗忘）；EWF=100% 时等于第一帧（永不更新）；EWF=50% 时，3、5、10 的顺序得 7 g，5、10、3 的顺序得 5.25 g——**同样三个数，顺序不同结果差 1.75 g**。

这个"顺序敏感"恰是它的用途：跟踪缓慢变化的工况。定转速的稳态测量用不着它，但 run-up/run-down 里工况在漂移、或者事件后需要谱尽快反映最新状态时，指数平均能让新数据主导结果。代价是等效平均次数变少，随机误差比同等帧数的能量平均大。

### 最大值 / 最小值：不收敛的"平均"

严格说这两项不是平均，是逐谱线的极值统计。最大值俗称峰值保持（Peak hold），三帧的 3/5/10 g 它给 10 g。用途明确：worst-case 评估——通过性试验找最恶劣谱、拍击声（rattle）检测找最响事件、异响搜索中保留偶发峰。最小值反过来，常和最大值配对使用，两条曲线围出谱的包络带，展示工况波动范围。

::: warning 工程注意
峰值保持没有统计收敛性，平均次数越多只会越大或不变，切勿拿它当稳态谱报结果。另一个坑：指数平均的结果依赖测量顺序，复现试验时若帧顺序不同（比如先慢后快与先快后慢的 run-up），两轮数据没有可比性。
:::

## 三、Python 演示：五种平均一算便知

```python
import numpy as np

# 手册算例：10 Hz 谱线处三帧自功率谱幅值
v = np.array([3.0, 5.0, 10.0])

# 1) 能量平均：平方 -> 平均 -> 开方
energy = np.sqrt(np.mean(v ** 2))

# 2) 线性平均：算术平均
linear = np.mean(v)

# 3) 能量指数平均（EWF=50%）：递推 A = EWF*A + (1-EWF)*a
def exp_avg(vals, ewf=0.5):
    a = vals[0]
    for x in vals[1:]:
        a = ewf * a + (1 - ewf) * x
    return a

print(f"能量平均   = {energy:.2f} g")
print(f"线性平均   = {linear:.2f} g")
print(f"指数平均(3,5,10 顺序) = {exp_avg(v):.2f} g")
print(f"指数平均(5,10,3 顺序) = {exp_avg([5,10,3]):.2f} g  # 换个顺序就变了")
print(f"最大值     = {v.max():.2f} g")
print(f"最小值     = {v.min():.2f} g")

# 4) 能量平均的收敛性：随机误差随帧数按 1/sqrt(N) 下降
print()
print("平稳随机信号能量平均的随机误差：")
for N in (1, 4, 16, 64, 256):
    print(f"  {N:3d} 帧 -> 单帧的 {100/np.sqrt(N):5.1f}%")
```

运行结果要点：能量平均 6.68 g 明显高于线性 6 g，10 g 那帧被平方放大了话语权；指数平均两行输出最值得盯——同样三个数，顺序一换从 7.00 g 掉到 5.25 g，这就是"会遗忘的平均"的特征。最后一段 256 帧误差只剩单帧的 6.2%，解释了为什么声功率测量动辄平均上百帧。

## 四、怎么选：场景到默认项

| 测量场景 | 推荐平均类型 | 理由 |
| --- | --- | --- |
| **稳态声学/振动谱** | Energy | 能量域叠加符合物理，随机误差按 1/sqrt(N) 收敛 |
| **声功率（多麦克风）** | Energy | 声能量空间平均，标准方法要求 |
| **ODS / 需要相位** | Linear + Spectrum | 线性平均保留相位（配合相位参考） |
| **跟踪缓变工况** | Energy exponential | 新数据主导，谱随工况漂移更新 |
| **worst-case / 异响搜索** | Maximum | 峰值保持，捕捉偶发最恶劣事件 |
| **包络带展示** | Min + Max 双测 | 两条曲线围出波动范围 |

::: tip 选择原则
- 不确定时用默认的 **Energy**：稳态测量在统计意义上最稳妥的选择
- 报告里出现"平均值"字样时想一下：能量平均还是线性平均？对声学量两者差着平方再开方的距离，验收条款里写清楚
- 事件型问题（拍击、异响、放空）别用能量平均抹平偶发峰，切 Maximum 才不会漏掉最恶劣的那一帧
- 指数平均的 EWF 是等效平均次数的旋钮：EWF 越接近 100% 记忆越长、越接近 0 越像"只看最新帧"，跟踪快变工况调小，追求稳定调大
:::

## 五、小结

五种平均不是软件冗余，是五种不同的工程问题各要一个答案：能量平均回答"平均能量多大"，线性平均回答"等权平均还保不保相位"，指数平均回答"现在状态如何"，最大最小值回答"最坏最好各是什么"。同一组 3g/5g/10g，答案从 3 g 到 10 g——选错平均类型，数据本身没错，结论已经偏了三倍。
