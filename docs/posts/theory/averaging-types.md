# 平均技术对比：同一组数据，五种平均差出三倍

> Simcenter Testlab 稳态测量（stationary measurement）的 "Averaging type" 下拉菜单提供五种算法：能量平均（Energy average）、线性平均（Linear average）、能量指数平均（Energy exponential average）、最大值（Maximum value）、最小值（Minimum value）。同一组数据 3g、5g、10g，五种平均的结果从 3g 到 10g 不等——相差三倍以上。本文依据 Simcenter Testing Knowledge Base 的算例与《LMS Test.Lab 理论》第 1.4 节"平均"，逐一说明五种平均的数学定义、物理含义与适用场景。

## 一、为什么"平均"不是一件事

多数用户首次打开 Simcenter Testlab Signature Acquisition 的稳态测量设置时，看到平均类型下拉框里的五项默认值是 Energy average，此后通常不再更改。

问题在于：稳态测量模式下，软件把每一帧（Block，一次 FFT 分析所用的数据段）的自功率谱（Autopower）逐谱线平均成最终结果。平均方式不同，逐条谱线合并的规则就完全不同。手册给出的最小算例：10 Hz 谱线处，三帧数据分别测得 3g、5g、10g，五种平均的计算结果如下——

| 平均类型 | 10 Hz 谱线结果 | 一句话规则 |
| --- | --- | --- |
| **能量平均（Energy）** | 6.68 g | 平方后再平均，再开根号 |
| **线性平均（Linear）** | 6.00 g | 算术平均，逐帧等权 |
| **能量指数平均（Energy exponential）** | 7.00 g* | 新数据权重高，旧数据指数衰减 |
| **最大值（Maximum）** | 10.00 g | 逐谱线取峰值保持 |
| **最小值（Minimum）** | 3.00 g | 逐谱线取历史最低 |

\*指数平均结果依赖帧顺序，此处为 3、5、10 依次测量、EWF=50% 的结果；同样三个数按 5、10、3 的顺序测，结果变为 5.25 g。

![Simcenter Testlab 平均类型下拉菜单的五个选项](/images/averaging-types/fig1-dropdown.png)
*（图源：Simcenter Testing Knowledge Base）*

能量平均结果偏大不是缺陷，而是其数学定义的自然结果。平方过程使高幅值帧在最终结果中占据更大权重——这符合"能量叠加"的物理规律：两台同一型号的噪声源同时运行时，总声能量是两者相加，而不是声压的算术相加。声学应用普遍采用能量平均，例如多麦克风声功率测量中，对声压谱做能量平均合成单点等效值。

还有一项容易被忽略的特性：能量平均的平方过程会去除相位。如果相位信息重要——例如 ODS 或传递函数分析——应使用线性平均配合 Spectrum（复谱）函数，而不是对 Autopower 做能量平均。

::: info 核心概念
- **帧（Block）**：一次 FFT 分析所用的数据段，稳态测量里多帧逐谱线合并成最终谱
- **能量平均（Energy average）**：先平方、再平均、后开方（RMS 平均），高幅值帧权重大，声学默认
- **指数平均（Energy exponential average）**：递推式加权，新帧权重 (1−EWF)、旧结果权重 EWF，帧顺序影响结果
- **峰值保持（Peak hold）**：Maximum 的俗称，逐谱线保留历史最大值，不收敛
:::

## 二、逐项分析：数学定义、行为与适用场景

### 能量平均：能量域的算术平均

对幅值序列 $a_1, a_2, \ldots, a_N$（单位 g，即加速度幅值），能量平均定义为平方求和、除以 $N$、再开根号：

$$\bar{a}_{\text{energy}} = \sqrt{\frac{1}{N}\sum_{n=1}^{N} a_n^2}$$

物理意义：对 $a_n^2$（与能量成正比的量）做算术平均，再回到幅值域。代入算例：

$$\bar{a}_{\text{energy}} = \sqrt{\frac{3^2 + 5^2 + 10^2}{3}} = \sqrt{\frac{134}{3}} \approx 6.68\ \text{g}$$

结果明显高于算术平均 6 g，因为 10 g 那帧的平方项在求和中贡献占比最大。

对平稳随机信号，能量平均还具有明确的统计特性：功率谱（均方谱）域的谱估计随机误差（归一化标准差）随独立平均次数 $N$ 按 $1/\sqrt{N}$ 收敛；开方后的幅值谱误差约为其一半，即 $1/(2\sqrt{N})$。因此 16 帧独立平均把功率谱谱线的随机波动压到单帧的 25%，64 帧压到 12.5%（谱估计理论的标准结果，Bendat & Piersol）。稳态工况测背景噪声、测声功率时，能量平均在统计意义上是稳妥的选择之一。

### 线性平均：等权平均，保留相位

线性平均即算术平均（《LMS Test.Lab 理论》式 1-3），每帧等权：

$$\bar{a}_{\text{linear}} = \frac{1}{N}\sum_{n=1}^{N} a_n = \frac{3+5+10}{3} = 6\ \text{g}$$

物理意义：各帧对结果的贡献完全相同。它对幅值谱做平均时结果可预期（本例 6 g），但真正的价值在于：当测量函数是 Time 或 Spectrum 时，线性平均会把相位一起平均进去。Spectrum 直接平均时，随机信号相位杂乱会导致幅值逐次降低（[Spectrum 与 Autopower 的区别](./spectrum-vs-autopower.html)一篇专门分析了这个现象），所以线性平均的典型用法是配合自功率谱或时域平均——例如发动机逐循环角度域平均，把非同步成分平均掉只留燃烧激励。

### 能量指数平均：会"遗忘"的平均

前两种平均对时间无记忆：先测 3g 后测 10g，与先测 10g 后测 3g，结果一样。指数平均不是。它按递推式逐帧更新：

$$A_n = \text{EWF} \cdot A_{n-1} + (1-\text{EWF}) \cdot a_n$$

物理意义：每来一帧新数据，旧结果按 EWF 保留、新帧按 (1−EWF) 混入。EWF（Exponential Weighting Factor，指数加权因子）取 0 到 100%，无量纲。该式与《LMS Test.Lab 理论》式 1-5 的递推形式一致：$x_n = \left(1 - \frac{1}{\tau}\right) x_{n-1} + \frac{1}{\tau}\, a_n$（$\tau$ 为常数计权因子，$a_n$ 为第 $n$ 次新测量），对应关系为 $\text{EWF} = 1 - 1/\tau$，即 EWF=50% 相当于 τ=2。

EWF=0 时平均等于最新一帧（完全遗忘）；EWF=100% 时等于第一帧（永不更新）；EWF=50% 时，3、5、10 的顺序得 7 g，5、10、3 的顺序得 5.25 g——**同样三个数，顺序不同结果差 1.75 g**。

![EWF=50% 时指数平均递推计算过程（手册 Figure 2 算例）](/images/averaging-types/fig2-exponential.png)
*（图源：Simcenter Testing Knowledge Base）*

这种"顺序敏感"正是其适用场景的来源：跟踪缓慢变化的工况。定转速的稳态测量无需使用它，但升速/降速（run-up/run-down）试验中工况持续变化、或者事件发生后需要谱尽快反映最新状态时，指数平均能让新数据主导结果。代价是等效统计自由度低于同等帧数的能量平均，随机误差相应更大。

### 最大值 / 最小值：不收敛的"平均"

严格说这两项不是平均，而是逐谱线的极值统计：

$$\bar{a}_{\max} = \max_n a_n, \qquad \bar{a}_{\min} = \min_n a_n$$

物理意义：逐谱线比较各帧幅值（若数据为复数，只对幅值信息比较，见《LMS Test.Lab 理论》1.4 节"峰值电平保持"），不做任何加权合成。最大值俗称峰值保持（Peak hold），三帧的 3/5/10 g 它给 10 g。用途明确：最恶劣工况（worst-case）评估——通过性试验找最严酷谱、拍击声（rattle）检测找最响事件、异响搜索中保留偶发峰。最小值则相反，常和最大值配对使用，两条曲线围出谱的包络带（envelope），展示工况波动范围。

![同一组 3g/5g/10g 数据五种平均方法的结果对比](/images/averaging-types/fig3-comparison.png)
*（图源：Simcenter Testing Knowledge Base）*

::: warning 工程注意
峰值保持没有统计收敛性，平均次数越多结果只会越大或不变，不应将其作为稳态谱报结果。另一项注意：指数平均的结果依赖测量顺序，复现试验时若帧顺序不同（比如先慢后快与先快后慢的 run-up），两轮数据没有可比性。
:::

## 三、Python 数值验证

```python
import numpy as np

# 手册算例：10 Hz 谱线处三帧自功率谱幅值
v = np.array([3.0, 5.0, 10.0])

# 1) 能量平均：平方 -> 平均 -> 开方
energy = np.sqrt(np.mean(v ** 2))

# 2) 线性平均：算术平均
linear = np.mean(v)

# 3) 能量指数平均（EWF=50%）：递推 A = EWF*A + (1-EWF)*a
def exp_avg(vals, ewf=0.5):
    a = vals[0]
    for x in vals[1:]:
        a = ewf * a + (1 - ewf) * x
    return a

print(f"能量平均   = {energy:.2f} g")
print(f"线性平均   = {linear:.2f} g")
print(f"指数平均(3,5,10 顺序) = {exp_avg(v):.2f} g")
print(f"指数平均(5,10,3 顺序) = {exp_avg([5,10,3]):.2f} g  # 顺序不同，结果不同")
print(f"最大值     = {v.max():.2f} g")
print(f"最小值     = {v.min():.2f} g")

# 4) 平稳随机信号能量平均的收敛性
# 功率谱（均方谱）域随机误差按 1/sqrt(N) 下降；幅值谱约为其一半 1/(2*sqrt(N))
print()
print("功率谱域随机误差（幅值谱约为其一半）：")
for N in (1, 4, 16, 64, 256):
    print(f"  {N:3d} 帧 -> 功率谱域单帧的 {100/np.sqrt(N):5.1f}%"
          f"，幅值谱域 {100/(2*np.sqrt(N)):5.1f}%")
```

运行结果要点：能量平均 6.68 g 高于线性平均 6 g，10 g 那帧经平方后在结果中权重最大；指数平均两行输出最值得关注——同样三个数，顺序一换从 7.00 g 变为 5.25 g，这是指数平均顺序敏感性的直接体现。最后一段显示 256 帧平均后功率谱域误差只剩单帧的 6.3%（幅值谱域 3.1%），解释了声功率测量通常需要上百帧平均。

## 四、如何选择：场景到默认项

| 测量场景 | 推荐平均类型 | 理由 |
| --- | --- | --- |
| **稳态声学/振动谱** | Energy | 能量域叠加符合物理，功率谱误差按 1/√N 收敛 |
| **声功率（多麦克风）** | Energy | 声能量空间平均，标准方法要求 |
| **ODS / 需要相位** | Linear + Spectrum | 线性平均保留相位（配合相位参考） |
| **跟踪缓变工况** | Energy exponential | 新数据主导，谱随工况漂移更新 |
| **worst-case / 异响搜索** | Maximum | 峰值保持，捕捉偶发最恶劣事件 |
| **包络带展示** | Min + Max 双测 | 两条曲线围出波动范围 |

::: tip 选择原则
- 不确定时用默认的 **Energy**：稳态测量在统计意义上最稳妥的选择
- 报告里出现"平均值"字样时先明确：能量平均还是线性平均？对声学量两者相差"平方再开方"的距离，验收条款里应写清楚
- 事件型问题（拍击、异响、放空）不宜用能量平均抹平偶发峰，应改用 Maximum，避免漏掉最恶劣的那一帧
- EWF 直接决定指数平均的记忆长度：EWF 越接近 100% 记忆越长、越接近 0 越接近"只看最新帧"，跟踪快变工况调小，追求稳定调大
:::

## 五、小结

五种平均不是软件冗余，而是五种不同的工程问题各有对应的答案：能量平均回答"平均能量多大"，线性平均回答"等权平均还保不保相位"，指数平均回答"当前状态如何"，最大最小值回答"最坏最好各是什么"。同一组 3g/5g/10g，结果从 3 g 到 10 g——平均类型选错时，数据本身没有错误，但结论可以偏离三倍以上。
