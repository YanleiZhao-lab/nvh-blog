# 自相关函数：从噪声里捞出周期信号的时域利器

> 电机异响台架数据里，轴承特征频率的微弱周期成分完全淹没在宽带噪声中，频谱看不出来，示波器更看不出来。自相关函数（Autocorrelation）是处理这类问题的时域武器：信号与自己延时后相乘再平均，随机噪声因为"记不住自己"在非零时延处归零，周期信号却在周期整数倍处一次次亮起尖峰——不需要同步触发，不需要转速表。本文从定义推导到维纳-辛钦定理，再到 FFT 快速算法里循环缠绕的坑，最后用 numpy 把负十几个 dB 信噪比的信号捞回来。

## 一、工程问题：噪声里的周期成分怎么找

NVH 工程师常遇到一类"薛定谔的信号"：客户耳朵里有异响，数据里却找不到。可能是齿轮早期点蚀的啮合调制，可能是轴承早期损伤的冲击串，也可能是电机电磁噪声。共同点是**周期成分幅度小、背景噪声大**。

三条传统路线各有短板：

| 路线 | 前提条件 | 短板 |
| --- | --- | --- |
| **时域直接看** | 信号明显高于噪声 | 信噪比低于 0 dB 时波形一片糊 |
| **线性平均** | 有同步触发信号（转速/键相） | 没有转速表或相位漂移时平均失效 |
| **FFT 频谱** | 信号近似稳态 | 非平稳工况下谱线糊成一片 |

LMS 理论手册在第三章点明：用自相关检测湮没在噪声中的周期信号，"这种方法优于线性平均，它不要求有同步触发信号。对某些脉冲型的信号做分析时，利用自相关函数也许比利用频域函数能获得更好的结果。"

## 二、从定义出发：自相关在算什么

### 2.1 定义式的物理来路

相关（Correlation）度量两个变量的相似性。自相关取信号与**它自己延时之后的版本**做比较——直觉上是在问："这个信号记不记得 3 毫秒之前的自己？"

时域连续定义（手册式 3-2）：

$$R_{xx}(\tau) = \lim_{T\to\infty} \frac{1}{T} \int_{-T}^{+T} x(t)\, x(t+\tau)\, dt$$

拆开读：把 $x(t)$ 平移 $\tau$ 得到 $x(t+\tau)$，两者逐点相乘，在很长时间上取平均。乘积的平均就是"一致性得分"——同号相乘为正，异号相乘为负，长期平均后留下来的是两个版本真正同步变化的成分。

### 2.2 零时延是一面照妖镜

令 $\tau = 0$，定义式变成：

$$R_{xx}(0) = \lim_{T\to\infty} \frac{1}{T} \int x^2(t)\, dt = \overline{x^2}$$

这正是信号的**均方值**——总功率的时域表达。用柯西-施瓦茨不等式可以严格证明这是自相关的全局最大值（对任意时延有 $|R_{xx}(\tau)| \le R_{xx}(0)$）。物理上好理解：没有任何平移能比信号与自己完全对齐时更"像"。

### 2.3 两类信号的判决特征

**纯随机噪声**：任意两个时刻的取值互相独立，$x(t)$ 与 $x(t+\tau)$ 的乘积期望为零。所以随机噪声的自相关只在零时延处有一个窄峰（噪声的均方值），时延稍一偏离就塌到零——噪声"记不住自己"。

**周期信号** $x(t) = A\sin(2\pi f_0 t)$：代入定义式，利用积化和差：

$$R_{xx}(\tau) = \frac{A^2}{2}\cos(2\pi f_0 \tau)$$

三角函数的乘积仍是同频三角函数——周期信号的自相关是**同周期的余弦**，在时延等于 $0,\ T_0,\ 2T_0, \cdots$（周期整数倍）处反复出现峰值。信号"永远记得自己"。

::: info 核心概念
- **自相关函数 Rxx**：信号与自身延时版的相似性随时延的变化
- **零时延值 = 均方值**：自相关的上确界，总功率的时域度量
- **随机信号**：只在零时延有单峰，时延稍偏即归零
- **周期信号**：自相关为同周期函数，峰在周期整数倍处重复
:::

两条性质合起来就是检测器的判决逻辑：**噪声贡献被压扁在零时延附近，周期贡献在时延轴上一路排开等间距的峰**。只要信号里混着周期成分，等间距峰列就是它的指纹，峰间距即周期，取倒数即频率。

## 三、维纳-辛钦定理与 FFT 快速算法

### 3.1 从自谱到自相关：一步逆 FFT

按定义直接算自相关是 $O(N^2)$ 运算量，工程上没人这么干。手册式 3-3 给出频域路线：

$$R_{xx}(n) = F^{-1}\{S_{xx}(k)\}$$

其中 $F^{-1}$ 是逆傅里叶变换，$S_{xx}(k)$ 是离散自功率谱。这背后是**维纳-辛钦定理（Wiener-Khinchin Theorem）**：自相关函数与自功率谱构成一对傅里叶变换。

推导骨架分三步。第一步写出离散谱的定义：$S_{xx}(k) = X(k) X^*(k) = |X(k)|^2$，即线性谱幅值的平方。第二步对 $S_{xx}$ 做逆变换，关键一步在求和指标重排：

$$F^{-1}\{X(k)X^*(k)\} = \frac{1}{N}\sum_{m} x(m)\, x^*(m-n)$$

两个 DFT 核 $e^{j2\pi kn/N}$ 的乘积凑成一个，指标平移后正好得到"x 与自己延时 n 版本的共轭乘积对全体样点求和"——这就是自相关的离散定义乘以 N。第三步收尾：两边同除 N，得到频域计算式。

物理意义一步到位：**自谱描述功率在频率上怎么分布，自相关描述功率在时延上怎么"记忆"**——同一份信息的两种读法，FFT 在中间搬运。
### 3.2 循环缠绕：FFT 法自带的坑

用 FFT 算相关得到的是**循环相关（Circular Correlation）**——手册第九章专门画图说明：数据块的最后一个值会"绕回"接到第一个值，延时是绕圈数的。工程信号不是首尾相接的圆，直接逆 FFT 会在大时延处把数据尾巴和头错搭在一起，产生虚假相关。

![循环相关计算式](/images/autocorrelation-noise-detection/lms-circular-formulas.png)

标准解法是**补零到 2N**：信号长 N，尾部补 N 个零再做 FFT、取模方、逆 FFT，缠绕成分被推到负时延区，正时延部分就是真实自相关的无偏结果。

::: warning 工程注意
Testlab 里逆 FFT 出来的相关函数以 "AutoCorrelation" 类型挂牌（倒频谱分析也用它）。读取时两件事必做：X 轴下限设为零（双边谱负半边是镜像）；Y 轴放大——峰在零时延附近很尖，不放大看不见。补零与否决定缠绕误差大小，短数据块尤其敏感。
:::

### 3.3 马可夫回归系数：相关性的一个标量摘要

手册第九章还给出一个紧凑指标——马可夫回归系数，即相邻时延相关值之比：

$$\rho = R(1)\,/\,R(0)$$

取值 0 到 1。窄带信号相邻采样高度相似，趋近 1；宽带信号相邻采样几乎无关，趋近 0。滤波处理后看一眼这个系数，就能快速判断滤波输出大致的带宽量级——不用画谱。

## 四、Python 演示：强噪声下捞出周期

**演示一：正弦加强噪声，自相关峰列清晰可辨。** 120 Hz 正弦幅值 0.5，叠 3 倍标准差的白噪声，时域完全看不出周期：

```python
import numpy as np

fs = 4096            # 采样率 Hz
N = 32768            # 数据长度
rng = np.random.default_rng(42)
t = np.arange(N) / fs

f0 = 120.0                                   # 藏在噪声里的周期
x = 0.5*np.sin(2*np.pi*f0*t) + 1.5*rng.standard_normal(N)   # 强噪声

# FFT 法自相关: 补零到 2N 防循环缠绕
X = np.fft.fft(x, 2*N)
Rxx = np.fft.ifft(X * np.conj(X)).real / N
lags = np.arange(2*N) / fs

R0 = Rxx[0]                                  # 零时延 = 均方值
print(f"R(0) = {R0:.3f}, 均方值 = {np.mean(x**2):.3f}")   # 两者应相等
print(f"信噪比 = {10*np.log10(0.125/2.25):.1f} dB")

# 逐周期窗取最高点: 窗宽取待验证周期的猜测值
seg = Rxx[:int(0.05*fs)]
win = int(round(fs / f0))                    # 窗宽 = 猜测周期的采样数
peaks = [k + int(np.argmax(seg[k:k+win]))
         for k in range(0, len(seg)-win, win)]
print(f"峰位置 (ms): {[round(lags[p]*1000, 2) for p in peaks[1:]]}")
print(f"峰幅值: {[round(seg[p], 3) for p in peaks[1:]]}")  # 理论值 A^2/2 = 0.125
d = np.diff(peaks)
print(f"峰间距均值 = {np.mean(d)/fs*1000:.2f} ms -> 频率 = {fs/np.mean(d):.1f} Hz (真实 120 Hz)")
```

输出里最值得看的：R(0) 与信号均方值精确相等（验证零时延性质）；-12.6 dB 信噪比下峰幅值 0.128 对上理论值 A 平方除二等于 0.125，峰间距折回 120.5 Hz——时域波形一片糊，自相关峰列照样一数一个准。逐窗取最高点比全局阈值找峰稳健：噪声毛刺混不进窗内最高点的位置。

**演示二：马可夫回归系数量带宽。** 白噪声分别过低通与高通滤波，看系数怎么变：

```python
import numpy as np

N = 8192
rng = np.random.default_rng(7)
x = rng.standard_normal(N)                    # 宽带白噪声

def markov(x, lag):
    # 相邻时延相关比: R(lag)/R(0)
    R0 = np.mean(x * x)
    Rl = np.mean(x[:-lag] * x[lag:])
    return Rl / R0

# 简易一阶低通 (指数滑动平均), 高通 = 原信号 - 低通
alpha = 0.15
lowpass = np.empty(N); lowpass[0] = x[0]
for i in range(1, N):
    lowpass[i] = alpha*x[i] + (1-alpha)*lowpass[i-1]
highpass = x - lowpass

for name, sig in [("原始白噪声", x), ("低通输出", lowpass), ("高通输出", highpass)]:
    print(f"{name}: rho = {markov(sig, 1):.3f}")
```

输出里最值得看的：白噪声系数接近 0（宽带，相邻采样无关），低通输出明显抬高（窄带化，相邻采样相似），高通输出回落——一个标量就把滤波带宽的变化方向说清楚了。

## 五、自相关、互相关、倒频谱对照

| 维度 | **自相关** | **互相关** | **倒频谱** |
| --- | --- | --- | --- |
| **对象** | 一个信号 | 两个信号 | 一个信号的对数谱 |
| **回答** | 信号记得自己多久 | 两信号差多少时延最像 | 谱上周期性结构的周期 |
| **噪声表现** | 不相关噪声在非零时延归零 | 不相关噪声在平均中归零 | 同左 |
| **触发要求** | 无 | 无 | 无 |
| **典型应用** | 噪声中周期检测、带宽摘要 | 传递路径时差、声源定位 | 轴承/齿轮故障边带族 |

自相关与倒频谱是一对近亲：都是逆 FFT 出来的 "AutoCorrelation" 类型数据，自相关作用在功率谱上，倒频谱作用在对数谱上——对数把边带族的乘性结构转成加性，回声与调制族因此在倒频率轴上成峰。边界清楚的场合（单周期检测）用自相关，边带族密集的齿轮箱诊断用倒频谱。

::: tip 什么时候用自相关
- 没有转速/键相触发信号，线性平均做不了——自相关不挑这个
- 脉冲型信号（冲击、敲击）频谱平缓，频域特征不明显，时域记忆反而清楚
- 只需要快速判断"有没有周期成分、周期是多少"，不必画出精细谱
- 需要跟踪滤波效果时，马可夫回归系数是最省事的带宽标量摘要
:::

## 六、小结

判决链条就三步：算之前补零到 2N 防缠绕；算完先验 Rxx(0) 是否等于均方值；判决时在正时延区域找等间距峰列，峰间距的倒数就是藏在噪声里的频率。信噪比决定需要多长的数据——数据越长，噪声自相关峰塌得越窄，周期峰列的信噪比随数据长度提升。对整车与动力总成数据，转速波动会让"周期"本身漂移，此时先把信号重采样到角域再做自相关，峰列才不会被转速变化抹平。
