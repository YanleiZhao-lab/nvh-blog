# 自相关函数：噪声背景下周期信号的时域检测方法

> 电机异响台架数据中，轴承特征频率对应的周期成分幅度小、宽带噪声背景大，频谱上往往难以分辨。自相关函数（Autocorrelation）为此类问题提供一条时域分析路线：信号与其延时版本相乘后取时间平均，随机噪声因非零时延处取值不相关而趋于零，周期信号则在时延等于周期整数倍处重复出现峰值——既不需要同步触发信号，也不需要转速表。本文从定义出发推导自相关的基本性质，经由维纳-辛钦定理（Wiener-Khinchin Theorem）给出 FFT 快速算法，分析循环相关带来的缠绕误差与补零处理，最后用 numpy 在约 -13 dB 信噪比下验证周期检测效果。

## 一、工程问题：噪声背景下的周期成分检测

NVH 工程中常遇到一类信号：主观评价能察觉异响，数据分析时却难以定位。其来源可能是齿轮早期点蚀引起的啮合调制，可能是轴承早期损伤产生的冲击串，也可能是电机电磁噪声。共同特点是**周期成分幅度小、背景噪声大**。

三种传统路线各有适用条件与局限：

| 路线 | 前提条件 | 局限 |
| --- | --- | --- |
| **时域直接观察** | 信号幅度明显高于噪声 | 信噪比低于 0 dB 时波形难以分辨 |
| **线性平均** | 有同步触发信号（转速/键相） | 无转速表或相位漂移时平均失效 |
| **FFT 频谱** | 信号近似稳态 | 非平稳工况下谱线展宽 |

LMS 理论手册第三章指出：用自相关检测湮没在噪声中的周期信号，"这种方法优于线性平均，它不要求有同步触发信号。对某些脉冲型的信号做分析时，利用自相关函数也许比利用频域函数能获得更好的结果。"

## 二、从定义出发：自相关在计算什么

### 2.1 定义及其物理含义

相关（Correlation）度量两个变量之间的相似性。自相关取信号与**它自身的延时版本**做比较，衡量信号在不同时刻取值之间的线性依赖程度。

时域连续定义（手册式 3-2）：

$$R_{xx}(\tau) = \lim_{T\to\infty} \frac{1}{T} \int_{-T}^{+T} x(t)\, x(t+\tau)\, dt$$

其中 $x(t)$ 为信号，$\tau$ 为时延（单位 s），$R_{xx}$ 的单位为 $x$ 的平方（加速度信号即为 $(\mathrm{m/s^2})^2$）。逐项解读：把 $x(t)$ 平移 $\tau$ 得到 $x(t+\tau)$，两者逐点相乘，在很长时间上取平均。同号相乘为正、异号相乘为负，长期平均后保留下来的是两个版本同步变化的成分——乘积的时间平均即一致性度量。

### 2.2 零时延值：自相关的上界

令 $\tau = 0$，定义式变为：

$$R_{xx}(0) = \lim_{T\to\infty} \frac{1}{T} \int x^2(t)\, dt = \overline{x^2}$$

这正是信号的**均方值（Mean Square Value）**——总功率的时域表达。由柯西-施瓦茨不等式可以证明这是自相关的全局最大值：对任意时延有 $|R_{xx}(\tau)| \le R_{xx}(0)$。物理含义直观：没有任何平移能比信号与自身完全对齐时更相似。工程上也常用归一化形式——自相关系数 $\rho_{xx}(\tau) = R_{xx}(\tau)/R_{xx}(0)$，无量纲，取值范围 $[-1, 1]$，便于在不同幅度的信号之间比较。

### 2.3 随机信号与周期信号的判别特征

**纯随机噪声**：任意两个时刻的取值互相独立，$x(t)$ 与 $x(t+\tau)$ 乘积的期望为零。因此随机噪声的自相关只在零时延处有一个窄峰（峰值等于噪声均方值），时延稍一偏离即衰减到零——非零时延处随机信号不相关。

**周期信号** $x(t) = A\sin(2\pi f_0 t)$：代入定义式，先利用积化和差公式

$$\sin\alpha\,\sin\beta = \tfrac{1}{2}\big[\cos(\alpha-\beta) - \cos(\alpha+\beta)\big]$$

得到两项：差频项 $\cos(2\pi f_0 \tau)$ 与和频项 $\cos(4\pi f_0 t + 2\pi f_0 \tau)$。后者为非零频率振荡，长时间平均下趋于零，只剩差频项：

$$R_{xx}(\tau) = \frac{A^2}{2}\cos(2\pi f_0 \tau)$$

即周期信号的自相关是**同周期的余弦函数**，在时延等于 $0,\ T_0,\ 2T_0, \cdots$（周期 $T_0 = 1/f_0$ 的整数倍）处重复出现峰值——周期成分的相关性在任意时延尺度上保持。

::: info 核心概念
- **自相关函数 Rxx**：信号与自身延时版本的相似性随时延的变化
- **零时延值 = 均方值**：自相关的上界，总功率的时域度量
- **随机信号**：只在零时延有单峰，时延稍偏即归零
- **周期信号**：自相关为同周期函数，峰在周期整数倍处重复
:::

两条性质合起来构成检测依据：**噪声贡献集中在零时延附近，周期贡献在时延轴上形成等间距峰列**。只要信号中混有周期成分，等间距峰列即为判别特征，峰间距即周期，取倒数即频率。

## 三、维纳-辛钦定理与 FFT 快速算法

### 3.1 从自谱到自相关：一步逆 FFT

按定义直接计算自相关是 $O(N^2)$ 运算量，工程上一般改用频域路线，运算量降为 $O(N\log N)$。手册式 3-3 给出：

$$R_{xx}(n) = F^{-1}\{S_{xx}(k)\}$$

其中 $F^{-1}$ 是逆傅里叶变换，$S_{xx}(k)$ 是离散自功率谱（Autopower Spectrum），$n$ 为延时样点数。其理论依据是**维纳-辛钦定理**：自相关函数与自功率谱构成一对傅里叶变换。

推导分三步。第一步写出离散谱的定义：$S_{xx}(k) = X(k) X^*(k) = |X(k)|^2$，即线性谱幅值的平方。第二步对 $S_{xx}$ 做逆变换，关键一步在求和指标重排：

$$F^{-1}\{X(k)X^*(k)\} = \sum_{m=0}^{N-1} x(m)\, x^*\big((m-n)\bmod N\big)$$

两个 DFT 核 $e^{j2\pi kn/N}$ 的乘积合并为一个，指标平移后正好得到"x 与自身延时 $n$ 版本的共轭乘积对全体样点求和"——即循环自相关（未除 $N$ 的原始和式）。第三步收尾：两边同除 $N$，得到频域计算式 $R_{xx}(n) = \frac{1}{N}F^{-1}\{X(k)X^*(k)\}$。

物理意义：**自谱描述功率在频率轴上的分布，自相关描述功率在时延轴上的相关结构**——同一份信息的两种表示，FFT 在两者之间转换。

### 3.2 循环缠绕：FFT 法的固有假设

用 FFT 算相关得到的是**循环相关（Circular Correlation）**——手册第九章专门图示说明：数据块的最后一个值会绕回接到第一个值，延时按循环计数。工程信号并非首尾相接的周期序列，直接逆 FFT 会在大时延处把数据尾部与头部错搭，产生虚假相关。

标准处理方法是**补零到 2N**：信号长 N，尾部补 N 个零后再做 FFT、取模方、逆 FFT，缠绕成分被推到负时延区，正时延部分即为线性自相关的无偏结果。

::: warning 工程注意
Testlab 里逆 FFT 得到的相关函数以 "AutoCorrelation" 类型存储（倒频谱分析也使用该类型）。读取时两件事必做：X 轴下限设为零（双边谱负半边是镜像）；Y 轴放大——峰集中在零时延附近，默认量程下难以分辨。补零与否决定缠绕误差大小，短数据块尤其敏感。
:::

### 3.3 马可夫回归系数：相关性的标量摘要

手册第九章还给出一个紧凑指标——马可夫回归系数（Markov Regression Coefficient），即相邻时延相关值之比：

$$\rho = R(1)\,/\,R(0)$$

该系数无量纲，取值在 0（极低的相关性）到 1（高度相似）之间：窄带信号相邻采样高度相似，趋近 1；宽带信号相邻采样几乎无关，趋近 0。滤波处理后查看该系数，可以快速判断滤波输出的大致带宽量级，无需画谱。

## 四、Python 数值验证：强噪声下的周期检测

**验证一：正弦加白噪声，自相关峰列可分辨。** 120 Hz 正弦幅值 0.5，叠加 1.5 倍标准差的白噪声，时域波形无法分辨周期：

```python
import numpy as np

fs = 4096            # 采样率 Hz
N = 32768            # 数据长度
rng = np.random.default_rng(42)
t = np.arange(N) / fs

f0 = 120.0                                   # 藏在噪声里的周期
x = 0.5*np.sin(2*np.pi*f0*t) + 1.5*rng.standard_normal(N)   # 强噪声

# FFT 法自相关: 补零到 2N 防循环缠绕
X = np.fft.fft(x, 2*N)
Rxx = np.fft.ifft(X * np.conj(X)).real / N
lags = np.arange(2*N) / fs

R0 = Rxx[0]                                  # 零时延 = 均方值
print(f"R(0) = {R0:.3f}, 均方值 = {np.mean(x**2):.3f}")   # 两者应相等
print(f"信噪比 = {10*np.log10(0.125/2.25):.1f} dB")

# 逐周期窗取最高点: 窗宽取待验证周期的猜测值
seg = Rxx[:int(0.05*fs)]
win = int(round(fs / f0))                    # 窗宽 = 猜测周期的采样数
peaks = [k + int(np.argmax(seg[k:k+win]))
         for k in range(0, len(seg)-win, win)]
print(f"峰位置 (ms): {[round(lags[p]*1000, 2) for p in peaks[1:]]}")
print(f"峰幅值: {[round(seg[p], 3) for p in peaks[1:]]}")  # 理论值 A^2/2 = 0.125
d = np.diff(peaks)
print(f"峰间距均值 = {np.mean(d)/fs*1000:.2f} ms -> 频率 = {fs/np.mean(d):.1f} Hz (真实 120 Hz)")
```

实测输出：R(0) = 2.386，与信号均方值 2.386 一致（验证零时延性质）；信噪比 -12.6 dB；各峰幅值 0.115–0.128，对应理论值 $A^2/2 = 0.125$；峰间距均值 8.30 ms，折算频率 120.5 Hz（真实值 120 Hz）。逐窗取最高点比全局阈值找峰稳健，但个别窗内仍可能选中噪声毛刺，因此频率估计应使用峰间距均值而非单个峰位置。

**验证二：马可夫回归系数判断带宽量级。** 白噪声分别经一阶低通与高通滤波，观察系数变化：

```python
import numpy as np

N = 8192
rng = np.random.default_rng(7)
x = rng.standard_normal(N)                    # 宽带白噪声

def markov(x, lag):
    # 相邻时延相关比: R(lag)/R(0)
    R0 = np.mean(x * x)
    Rl = np.mean(x[:-lag] * x[lag:])
    return Rl / R0

# 简易一阶低通 (指数滑动平均), 高通 = 原信号 - 低通
alpha = 0.15
lowpass = np.empty(N); lowpass[0] = x[0]
for i in range(1, N):
    lowpass[i] = alpha*x[i] + (1-alpha)*lowpass[i-1]
highpass = x - lowpass

for name, sig in [("原始白噪声", x), ("低通输出", lowpass), ("高通输出", highpass)]:
    print(f"{name}: rho = {markov(sig, 1):.3f}")
```

实测输出：白噪声系数 0.001（宽带，相邻采样无关），低通输出 0.859（窄带化，相邻采样相似），高通输出 -0.080（回到零附近）。单一标量即可指示滤波带宽的变化方向。

## 五、自相关、互相关、倒频谱对照

| 维度 | **自相关** | **互相关（Cross-correlation）** | **倒频谱（Cepstrum）** |
| --- | --- | --- | --- |
| **对象** | 一个信号 | 两个信号 | 一个信号的对数谱 |
| **回答** | 信号自身周期性与相关持续时间 | 两信号在何处时延相关性最大 | 谱上周期性结构的周期 |
| **噪声表现** | 不相关噪声在非零时延归零 | 不相关噪声在平均中归零 | 同左 |
| **触发要求** | 无 | 无 | 无 |
| **典型应用** | 噪声中周期检测、带宽摘要 | 传递路径时差、声源定位 | 轴承/齿轮故障边带族 |

自相关与倒频谱联系密切：两者都由逆 FFT 得到 "AutoCorrelation" 类型数据，自相关作用于功率谱，倒频谱作用于对数谱——对数运算把边带族的乘性结构转为加性，回声与调制族因此在倒频率轴上成峰。边界清晰的场合（单一周期检测）用自相关，边带族密集的齿轮箱诊断用倒频谱。

::: tip 自相关的适用条件
- 没有转速/键相触发信号，线性平均无法进行——自相关无此要求
- 脉冲型信号（冲击、敲击）频谱平缓，频域特征不明显，时域相关结构反而清晰
- 只需判断"有无周期成分、周期是多少"，不必画出精细谱
- 需要跟踪滤波效果时，马可夫回归系数是计算代价最小的带宽标量指标
:::

## 六、小结

实施与判读分三步：计算前补零到 2N 防止循环缠绕；计算后先校验 $R_{xx}(0)$ 是否等于均方值；判读时在正时延区域寻找等间距峰列，峰间距的倒数即噪声中所含周期成分的频率。所需数据长度由信噪比决定——数据越长，噪声自相关峰越窄，周期峰列的置信度随数据长度提升。对整车与动力总成数据，转速波动会使周期本身漂移，此时应先把信号重采样到角域再做自相关，避免峰列因转速变化而展宽。
