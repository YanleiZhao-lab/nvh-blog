# PWM 开关噪声：电机啸叫的频率指纹

> 电动车 colormap 上那族"长得像阶次、但永远不穿过零频"的曲线，是逆变器 PWM 开关留下的频率指纹，幅值可能高达电机本体噪声的水平。这篇从开关边沿和占空比调制讲清指纹的成因，用 numpy 复现边带结构，给出"抬基频"与"随机化"两条整改路线的量化对比，以及测量端最容易踩的三个坑。

## 一、先认脸：那族"不落地"的斜线

分析电机工况数据，colormap（彩色图谱）上偶尔会出现一族奇怪的曲线：斜着往上走、随转速变化散开或收拢，乍看像高阶次线——但把转速往零推，它**不穿过零频**。机械阶次的频率等于"每转事件数乘以转频"，转速归零它必须落地；一族下端悬空的曲线，只能来自与转速无直接绑定关系的东西：功率电子的开关频率。

PWM（Pulse Width Modulation，脉宽调制）逆变器用功率器件的高频通断把直流电"斩"成近似正弦的交流电驱动电机。开关动作本身在极短时间内拉拽电流，di/dt 和 dv/dt 通过耦合路径变成机械振动和噪声辐射——手册明确提示：**功率电子开关产生的振动或噪声幅值，可以和电机本体相当**。基频常见 2500、5000、10000 Hz，落在人耳敏感的频段里，这就是很多电动车高速"尖啸"的来源。

![电机开关频率谐波族在 colormap 上随转速散开，始终不穿过零频](/images/pwm-switching-noise/pwm-colormap.png)

*（图源：Simcenter Testing Knowledge Base）*

::: info 指纹三要素
- **悬空**：曲线族以开关基频（及其倍频）为中心分布，下端不落在零频——这是与机械阶次的判别性特征
- **散开**：谐波族内部各线随转速升高彼此拉开距离，转速下降又收拢
- **量级**：开关噪声可达电机本体噪声的量级，不能当作"电气小事"忽略
:::

为什么转速会牵动一条"电气"曲线？用表观阶次一算就明白——同一条 5000 Hz 谱线，在不同转速下换算出的阶次数完全不同：

```python
# 表观阶次：同一条开关频率谱线在不同转速下"伪装"成的阶次
for rpm in [600, 3000, 6000, 12000]:
    f_rot = rpm / 60.0
    print(f"rpm={rpm:6d}  转频={f_rot:6.1f} Hz  "
          f"5000Hz 表观阶次 = {5000/f_rot:7.1f}")

# 对比：真正的机械 2 阶（四缸机燃烧阶次）随转速的行为
for rpm in [600, 3000, 6000]:
    print(f"rpm={rpm:6d}  机械2阶频率 = {2*rpm/60:6.1f} Hz")
```

600 rpm 时 5000 Hz 折算 500 阶，12000 rpm 时折算 25 阶——阶次数随转速连续变化，说明它不是"每转固定事件数"的机械源。机械 2 阶则严格等于 2 倍转频，转速降到底就归零。拿到 colormap 先看穿不穿零，再算表观阶次是否随转速漂移，两步就能把电气指纹和机械阶次分开。

## 二、指纹怎么来的：开关边沿与占空比调制

PWM 的载波是固定频率的三角波/锯齿波，与正弦指令比较后输出一列方波：基频 fsw 固定，**占空比**按正弦指令摆动。于是输出谱里有两样东西——开关基频及其倍频（载波族），以及调制过程搬移出来的**边带**。

数学上这是标准的调幅：开关波形可展开为载波谐波与调制函数的卷积，谱线落在 n*fsw 与 k*fe 的和差组合处，fe 是电机的电频率（指令正弦的频率）。电机升速时 fe 跟着涨，边带间距等于 fe、随之变大，整族曲线在 colormap 上就"散开"了——这就是第一节看到的悬空斜线族的物理来历。

```python
import numpy as np

fs = 200000.0                      # 采样率
t = np.arange(0, 0.02, 1/fs)       # 20 ms 数据
fsw, fe = 5000.0, 50.0             # 开关基频 5 kHz，电机电频率 50 Hz
# 正弦脉宽调制：占空比围绕 0.5 摆动正负 0.4
duty = 0.5 + 0.4*np.sin(2*np.pi*fe*t)
pwm = ((t*fsw) % 1.0 < duty).astype(float)  # 按占空比生成方波
win = 2*np.hanning(len(t)) - 1               # 手写汉宁窗压住泄漏
spec = np.abs(np.fft.rfft(pwm*win))
f = np.fft.rfftfreq(len(t), 1/fs)
band = (f > 4000) & (f < 6000)               # 只看 5 kHz 一族
idx = np.argsort(spec[band])[::-1][:6]       # 取幅值前 6 的谱线
lines = sorted(f[band][idx])
print("5 kHz 一族主要谱线 (Hz):", [int(x) for x in lines])
print("相邻谱线间距 (Hz):", [int(b-a) for a, b in zip(lines, lines[1:])])
```

谱线落在 4950/5050、4900/5100 这类位置——间距精确等于电频率 50 Hz。fe 升到 100 Hz（转速翻倍），间距就翻倍，colormap 上的曲线族随之散开。反过来，测出边带间距就能反推电频率，配合极对数还能核对转速，这是判读电机数据时很顺手的一个交叉校验。

::: warning 工程注意
- **别把边带当机械阶次**：4950/5050 Hz 的谱线对不属于任何"每转 4950 个事件"的机械部件，边带是调制产物，系统里没有对应物理特征数的零件
- **别忽略倍频族**：10、15、20 kHz 处还有一族族边带，带宽和分析上限要覆盖到，否则整改后"峰挪了个地方"都看不见
- **声学敏感度**：基频 2500 到 5000 Hz 正处人耳敏感区，单看加速度级"不大"的开关振动，听起来可能很吵
:::

## 三、整改两条路：抬基频，还是摊能量

确认指纹来自开关之后，手册给出两条整改方向。第一条动**基频**：把开关基频从 2500 Hz 提到 15000 Hz 这类听阈之外，直接降低可听度——代价是开关损耗上升，电机效率受影响。第二条动**开关方案**：放弃确定性 PWM，改用随机化开关，把集中在 fsw 附近的能量摊到宽频段上，单点峰值降下来。

| 整改路线 | 做法 | 收益 | 代价 |
| --- | --- | --- | --- |
| **抬基频** | fsw 从 2500 Hz 提到 15000 Hz 量级 | 峰值能量移出听阈，主观改善直接 | 开关损耗上升，效率下降 |
| **随机化开关** | 随机 PWM 替代确定性 PWM | 开关频率处峰值显著下降，电机本体的机械特征不受影响 | 能量摊到宽带，谱底整体抬升 |

随机化为什么有效？确定性 PWM 的开关时刻周期重复，谱能量在 fsw 及其倍频上高度集中；随机化让每个开关时刻抖动，载波族的相干性被破坏，能量从离散线扩散成连续谱底。用 numpy 对比一下 5 kHz 附近的峰值：

```python
import numpy as np

rng = np.random.default_rng(0)
fs, T = 400000.0, 0.02
t = np.arange(0, T, 1/fs)
fsw, fm = 5000.0, 100.0
ref = 0.5 + 0.45*np.sin(2*np.pi*fm*t)   # 正弦指令
win = 2*np.hanning(len(t)) - 1

def pwm_peak(jitter):
    # jitter=True 时给开关相位加随机抖动（随机 PWM 的简化模型）
    phase = t*fsw + (rng.random(len(t)) if jitter else 0)
    s = ((phase % 1.0) < ref).astype(float)
    spec = np.abs(np.fft.rfft(s*win))
    f = np.fft.rfftfreq(len(t), 1/fs)
    band = (f > 4000) & (f < 6000)      # 5 kHz 一族
    return spec[band].max(), spec[~band].sum()

p0, b0 = pwm_peak(False)   # 确定性 PWM
p1, b1 = pwm_peak(True)    # 随机化 PWM
print(f"确定性 PWM  5kHz 附近峰值: {p0:8.1f}")
print(f"随机化 PWM  5kHz 附近峰值: {p1:8.1f}  （降为 {100*p1/p0:.0f}%）")
print(f"5kHz 频带之外的谱能量: {b0:.0f} -> {b1:.0f}")
```

5 kHz 一族的峰值降到原来的百分之几量级，代价是带外谱能量翻了几倍——峰值换谱底，正对应手册里"随机化方案降低开关频率幅值"的描述。听感上尖啸的"调"消失了，换来的是更接近宽带噪声的"沙沙"声，主观上通常更易接受。注意演示里电机指令频率对应的谱结构不受影响，随机化只动开关族——这也是手册强调的要点：换开关方案时电机本身的频率特征保持不变。

## 四、测量端的三个坑

**采样带宽不够，指纹直接消失。** 开关谐波族可以延伸到 20 kHz 量级，采样率按"关心机械阶次到 2 kHz"的习惯设置，开关族整段混叠或截断，问题在数据里根本不存在。做电机 NVH，分析带宽至少留到听觉上限。

**平均会洗掉随机化 PWM 的谱线。** 随机 PWM 的能量本来就在谱底上，若测量平均方式不当，本已不高的线谱进一步被抹平，整改前后的对比就失真了。对比试验要用同一套采集设置。

**表观阶次当真阶次用。** 上一节算过，5000 Hz 在 600 到 12000 rpm 区间折算 500 到 25 阶，如果把它当机械阶次去查齿轮、轴承，方向全错。判读流程固定为：先看穿不穿零频，再算表观阶次是否随转速漂移，两者都对上电气特征，才下"开关噪声"的结论。

::: tip 判读与整改路线
- colormap 上族状曲线**下端悬空** → 电气开关频率，量边带间距反推电频率做交叉校验
- 主观抱怨集中在 2.5 到 10 kHz 的"尖啸" → 优先抬基频出听阈；效率敏感或基频不能动 → 随机化开关摊能量
- 整改验证时保持采集设置一致，带宽覆盖到开关倍频族，别让"峰挪位置"逃出视野
:::

## 五、小结

PWM 开关噪声的识别锚点就一个：不穿零频的悬空曲线族。成因是载波族的调幅边带，间距等于电频率、随转速散开。整改在"抬基频出听阈"与"随机化摊能量"之间做取舍，前者动效率、后者抬谱底。测量端把带宽留足、别把表观阶次当机械阶次，这套指纹判读法在电驱 NVH 里几乎百发百中。
