# 谱与自功率谱的区别

> Simcenter Testlab 里 Spectrum 和 Autopower 只差一个复共轭乘法，但平均之后结果天差地别：一个越平均越小，一个越平均越稳。这篇讲清两者的数学关系、相位在其中扮演的角色，以及什么场景必须用哪种函数——尤其是 ODS 分析里两者的"合体"形式：相位参考谱。

## 一、问题从哪来

在 Testlab 里新建测量，Function 一栏下拉菜单里并排躺着 Spectrum 和 Autopower。刚上手的工程师常常随手选一个，反正出来的都是"幅值-频率"曲线，看起来一模一样。

单次测量、不加平均时，两者幅值部分确实完全相同，唯一区别是 Spectrum 带相位、Autopower 相位恒为零。真正的分水岭出现在**多次平均**：同一个宽带随机信号，用 Autopower 平均 10 次、25 次、100 次，幅值波动越来越小、总量不变；用 Spectrum 平均，幅值会随平均次数**逐渐塌下去**。

这不是软件 bug，是相位在平均里互相抵消的必然结果。

::: info 核心概念
- **谱（Spectrum, Sx）**：FFT 输出的复数函数，每个频率线都有幅值和相位（a+ib 形式），只保留 0 Hz 以上单边部分
- **自功率谱（Autopower, Gxx）**：谱乘以自身的复共轭 Gxx = Sx · Sx*，相位被消掉，只剩幅值信息，单位变成原单位的平方（如 g²）
- **自功率线性（Autopower Linear）**：对 Gxx 开平方，恢复线性单位（如 g），"Linear"就指开过方
:::

## 二、相位：被丢掉的那一半信息

FFT 把时域信号分解成一组唯一的正弦波，每根正弦波除了幅值还有相位——相位相对于时间块起点计量。两个幅值相同、相位差 45° 的正弦波，在时域波形上一目了然；做 FFT 后，Spectrum 能把 45° 的差别原样保留，Autopower 则完全看不出两者有任何不同。

对纯幅值分析（比如看某阶次的转速跟踪水平、比较隔振前后振动量级），相位是冗余信息，丢掉无损。但一旦涉及**多通道联合分析**——ODS、传递路径分析、模态分析——相位就是核心数据：不知道两个测点振动的相对相位，就画不出结构的振型，也找不到抵消或叠加的根源。

## 三、数学上差一步：复共轭乘法

数字信号处理中 FFT 先得到双边谱（关于 0 Hz 镜像），折叠成单边后就是 Spectrum——复数形式，幅值与相位兼备。

Autopower 在此基础上多做一步：每个频率线上，用谱乘以它自己的复共轭：

$$G_{xx}(f) = S_x(f) \cdot S_x^*(f)$$

复数乘以自己的共轭，虚部归零，结果变成实数且恒为正——这就是为什么 Autopower 的相位处处为零。代价是单位被平方：输入单位 g，输出 g²。工程上习惯再开根号变回线性单位，即 Autopower Linear。

```python
import numpy as np

fs, N = 1024, 1024
t = np.arange(N) / fs
x = 2.5 * np.cos(2*np.pi*80*t + np.deg2rad(30))      # 80 Hz，幅值 2.5 g，初相 30°
X = np.fft.fft(x)[:N//2]                             # 单边复数谱（含相位）
Gxx = X * np.conj(X)                                 # 自功率 = 谱 × 其共轭
k = int(80 * N / fs)                                 # 80 Hz 所在谱线

print(f"谱      ：幅值 {np.abs(X)[k]*2/N:.3f} g，相位 {np.degrees(np.angle(X[k])):.0f}°")
print(f"自功率  ：{Gxx[k].real:,.0f} g²，相位 {np.degrees(np.angle(Gxx[k])):.0f}°")
print(f"自功率线性：{np.sqrt(Gxx[k].real)*2/N:.3f} g   <- 幅值回来了，相位归零")
```

运行结果要点：谱读出幅值 2.500 g、相位 30°；乘完复共轭后相位精确归零、单位变 g²；开方后幅值 2.500 g 原样回来——一步乘法，相位信息就此消失。

## 四、平均：分水岭在这里

设想两帧信号：同一个正弦波，第二帧与第一帧相位差 180°。

时域直接平均，正负抵消，结果为零。频域用 Spectrum 平均也一样——复数相加时实部虚部各自抵消。宽带随机信号没这么极端，但原理相同：每帧相位杂乱无章，复数平均下来幅值逐次衰减，平均次数越多掉得越狠。

Autopower 为什么没事？复共轭乘法等价于把信号"平方"——正弦波平方后全为正，不可能再抵消。手册里那张经典对比图：两条反相正弦波平方后完全重合，平均之后幅值分毫不差。

![反相正弦波平方后全为正，无法互相抵消](/images/spectrum-vs-autopower/fig8-square.png)
*（图源：Simcenter Testing Knowledge Base）*

实测宽带随机数据的效果：10/25/100 次平均，Autopower 谱形越来越光滑、总幅值稳定；Spectrum 幅值则持续走低。

![宽带随机信号平均 10/25/100 次：Autopower 越平均越稳，Spectrum 越平均越小](/images/spectrum-vs-autopower/fig9-averaging.png)
*（图源：Simcenter Testing Knowledge Base）*

```python
import numpy as np

fs, N = 1024, 1024
t = np.arange(N) / fs
f = 100.0                                            # 恰好落在频率线上
s1 = np.sin(2*np.pi*f*t)                             # 第1帧：相位 0°
s2 = np.sin(2*np.pi*f*t + np.pi)                     # 第2帧：相位 180°
X1, X2 = np.fft.fft(s1), np.fft.fft(s2)              # 复数谱（含相位）
k = int(N * f // fs)                                 # 峰值所在谱线

spec_avg = np.abs((X1 + X2) / 2) * 2 / N             # 复数谱先平均再取模
auto_avg = np.sqrt((np.abs(X1)**2 + np.abs(X2)**2) / 2) * 2 / N  # 自功率先平均再开方

print(f"真实幅值：1.0000 g")
print(f"复数谱平均 2 帧：{spec_avg[k]:.4f} g   <- 相位互相抵消")
print(f"平均自功率谱开方：{auto_avg[k]:.4f} g   <- 幅值不受影响")
```

运行结果要点：真实幅值 1 g 的信号，复数谱两帧平均后读数 0.0000 g——彻底抵消；自功率谱平均后开方仍是 1.0000 g。这就是"平均用错函数，幅值全军覆没"的极端演示。

::: warning 工程注意
对随机信号做谱平均时选 Spectrum，平均次数越多幅值越低——这不是测量问题，是函数选错。除非用触发保证每帧相位一致，否则 Spectrum 与平均不要同时出现。ODS/TPA 等既需要相位又需要平均的场合，用相位参考谱。
:::

## 五、既要相位又要平均：相位参考谱

ODS 分析要画结构振型，相位必不可少；现场数据又必须平均压噪。Spectrum 保相位但平均毁幅值，Autopower 平均稳定但相位没了——两头堵。

出路在于换一个相位基准。Spectrum 的相位相对于**每次采集的起点**，起点随机导致每帧相位乱跳。而振动结构上不同测点之间的**相对相位**由结构本身决定，每次采集都固定：板 13:Z 与板 15:Z 始终差 180°，不管采集何时开始。

相位参考谱（Phase Referenced Spectrum）的做法：指定一个活跃通道作参考，每次采集后、每个频率线上，把参考通道的相位减到零，其他所有通道减去同样的量。基准统一后，各帧数据变得一致，平均即可正确进行。

![Spectrum 保留相位，Autopower 相位恒为零](/images/spectrum-vs-autopower/fig2-bode.png)
*（图源：Simcenter Testing Knowledge Base）*

::: tip 参考通道选择
- 必须选**结构上振动活跃**的通道，如发动机缸体、变速箱壳体测点
- 别选振动微弱的通道（例如实验室地板上的测点）——信噪比差，参考相位本身不可靠
- 参考通道与被平均通道之间无固定相位关系的成分（如互不相关的随机振动）会在平均中被削弱，因此相位参考谱与 Autopower 的幅值未必完全一致
:::

Testlab 里的设置：Measurement Function 选 Spectrum，勾选 Phase Referenced Spectrum，在 References → Define… 里指定参考通道。

## 六、怎么选：一张表定夺

| 需求 | 推荐函数 | 原因 |
| --- | --- | --- |
| **只看幅值，需平均** | **Autopower（Linear）** | 相位消去，平均稳定收敛 |
| **幅值+相位，单次测量** | Spectrum | 无平均，幅值相位都可靠 |
| **幅值+相位，需平均（ODS/TPA）** | 相位参考谱 Spectrum | 参考通道统一相位基准 |
| **比较不同分辨率的谱** | Autopower + RMS 总量 | 谱线幅值随分辨率变化，RMS 总和不变 |

分辨率的坑单独说一句：同一信号用 1 Hz 和 2 Hz 分辨率测，Autopower 谱线幅值能差出一倍——能量分摊到的谱线数不同。横向对比时要么统一分辨率，要么看 RMS 总量。

| 特性 | Spectrum | Autopower |
| --- | --- | --- |
| 幅值 | 有 | 有 |
| 相位 | **有** | 无（恒为零） |
| 单位 | 原单位（g） | 平方单位（g²），Linear 版恢复 g |
| 多帧平均 | **幅值衰减** | 幅值稳定收敛 |
| 典型用途 | ODS、TPA、模态 | 阶次分析、水平监测、谱形对比 |

## 七、小结

只要幅值，用 Autopower——平均越多越准。要相位，用 Spectrum，但平均前必须保证相位一致，否则幅值不可信；既要相位又要平均，用相位参考谱，参考通道选结构上振动最活跃的点。分辨率不同的谱不比谱线幅值，比 RMS 总量。
