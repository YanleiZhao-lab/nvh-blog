# 吉布斯现象：为什么陡峭滤波器会振铃

> 测一个带突变的信号——过坑洞的冲击力、换挡的扭矩阶跃——时域波形边沿附近常常出现一圈"涟漪"，过冲幅度还不固定，换次测量就变。这就是吉布斯现象（Gibbs Phenomenon）。它不是传感器坏了，而是有限带宽描述不了无限陡峭的信号。本文讲清楚振铃的幅度和时长分别由什么控制，以及测试前怎么设滤波器把它压下去。

## 一、时域突变，频域无穷

傅里叶变换的基本结论：任何信号都能分解为一组唯一的正弦波之和。分解出来的频率内容，决定了信号能被"复原"得多精确。

光滑信号——正弦、三角波——频率内容有限，几个谐波就能描述得很好。但只要信号里有一个突变或阶跃，事情就变了：**时域越陡，频域越宽**。方波由基频及其全部奇次谐波（1、3、5、7……直到无穷）按 1/n 幅值递减叠加而成；理想脉冲同样需要无限带宽。没有无穷多的高次谐波，那个垂直的边沿就"砌"不出来。

![方波边沿处的吉布斯振铃：过冲与下冲围绕真实信号波动](/images/gibbs-phenomenon/fig2-ringing-square-wave.png)
*（图源：Simcenter Testing Knowledge Base）*

而任何采集系统的带宽都是有限的。用有限的频率内容去描述需要无限频率内容的信号，时域上就会在阶跃/过渡处留下振铃伪影——过冲、下冲围绕真实信号来回摆。这就是吉布斯现象。

整车测试里这类信号随处可见：悬架过减速带或坑洞的冲击力、安全带张紧器点火的爆炸脉冲、变速箱换挡瞬间的作用力阶跃、关门砰击声。它们的共同点是都含突变，都"天生"带着无限频率内容。

::: info 核心概念
- **不连续（Discontinuity）**：信号幅值的突跳。它要求无限频率内容，是吉布斯现象的源头
- **吉布斯现象**：频率内容被截断后，时域信号在突变处出现的过冲/下冲振铃伪影
- **截断（Truncation）**：测量带宽有限，高于带宽的谐波被丢掉
:::

一个重要的反面案例：**纯正弦信号不会有吉布斯现象**。给单频正弦加低通滤波，只要截止频率高于信号频率，什么都不会发生——因为没有频率内容被截断。吉布斯现象只在"信号的一部分频率内容被移除"时才出现。

## 二、振铃时长：截掉的谐波说了算

吉布斯振铃可以用两个量来描述：**幅度**（过冲/下冲多大）和**持续时间**（振铃多久衰减掉）。

时长的控制因素是频率内容的截断程度。以方波为例：把奇次谐波截到 2000 Hz，边沿变缓、振铃出现；截到 750 Hz，更多谐波被丢掉，边沿更缓、振铃持续时间更长。

![方波频谱低通截断：截掉的谐波越多，时域振铃持续越久、边沿越缓](/images/gibbs-phenomenon/fig5-truncation-duration.png)
*（图源：Simcenter Testing Knowledge Base）*

用 numpy 直接把方波"砌"出来，保留不同数量的奇次谐波，看边沿处发生了什么：

```python
import numpy as np

# 方波 = 无穷奇次谐波之和：sin(wt) + sin(3wt)/3 + sin(5wt)/5 + ...
# 只保留前 N 个奇次谐波，看边沿处会发生什么
t = np.linspace(0, 0.2, 400001, endpoint=False)
f0 = 50.0

for N in [3, 10, 100]:
    sig = np.zeros_like(t)
    for k in range(1, 2 * N, 2):          # 1,3,5,... 奇次谐波
        sig += np.sin(2 * np.pi * f0 * k * t) / k
    sig *= 4.0 / np.pi                     # 归一化：高电平 = 1.0
    fmax = f0 * (2 * N - 1)                # 保留到的最高频率
    m = (t > 0) * (t < 2.0 / fmax)         # 边沿后的振铃窗口
    overshoot = (sig[m].max() - 1.0) * 100
    seg = sig[(t >= 0) * (t < 0.005)]      # 10%~90% 上升时间
    t10 = t[np.argmax(seg > 0.1)]
    t90 = t[np.argmax(seg > 0.9)]
    print(f"保留 {N:3d} 个谐波(至{fmax:6.0f}Hz): 过冲 +{overshoot:.1f}% | "
          f"上升时间 {1000*(t90-t10):.3f} ms")
```

最值得看的是：谐波从 3 个加到 100 个，过冲几乎不变（约 +18%，即跳变高度的约 9%——数学上收敛于 8.95%，加再多谐波也压不下去），但上升时间缩短了 34 倍、振铃衰减更快。**加带宽改的是振铃时长和边沿陡度，治不了过冲幅度**；幅度要靠滤波器形状，见下一节。

::: warning 工程注意
数字采集系统里，这个振铃在信号各阶跃处的表现**不一致**——同一次测量，有的台阶振、有的不振，幅度也各不相同，原因是瞬态时刻与采样点的相对时序在变。所以别指望"用标定扣掉振铃偏置"，它不可标定。吉布斯现象的影响主要在时域，频域数据基本不受影响，判读谱时不必担心它。
:::

## 三、振铃幅度：滤波器形状说了算

幅度的主要控制因素是采集链路里低通滤波器（典型如抗混叠滤波器）的形状。**滤波器越陡，时域振铃越猛**。

为什么？对滤波器的频域形状做傅里叶反变换，得到它的时域"脉冲"响应。频域越宽的滤波器，时域脉冲越窄；时域脉冲越短促，跟信号卷积出来的振铃越突出。

极端例子是"砖墙"滤波器——通带内全 1、截止点外全 0，频域里最陡的形状。拿同一截止频率的砖墙与缓滚降高斯滤波器对比：

```python
import numpy as np

# 同一个方波，过两种同截止频率(2 kHz)的低通：砖墙(陡) vs 高斯缓滚降(缓)
fs = 51200
n = 2 ** 16
t = np.arange(n) / fs
sq = np.sign(np.sin(2 * np.pi * 100.0 * t))    # 幅值 ±1 的方波

freq = np.fft.rfftfreq(n, 1 / fs)
spec = np.fft.rfft(sq)
fc = 2000.0

wall = (freq <= fc).astype(float)               # 砖墙：截止点硬切
gauss = np.exp(-0.5 * (freq / (fc / 2.0)) ** 2) # 高斯：缓滚降

edge = round(0.01 * fs)                         # t = 10 ms 处的上升沿
for name, filt in [("砖墙(陡)", wall), ("高斯(缓)", gauss)]:
    rec = np.fft.irfft(spec * filt, n)
    after = rec[edge + 1 : edge + 300]          # 边沿之后：过冲
    before = rec[edge - 300 : edge]             # 边沿之前：前置振铃
    print(f"{name} 滤波: 边沿后过冲 +{(after.max()-1.0)*100:.1f}% | "
          f"边沿前下探 {before.min():.2f}（无振铃时应为 -1.00）")
```

同样是 2 kHz 截止：砖墙在边沿后过冲 +18%，还在边沿**之前**就提前下探到 -1.18（前置振铃，非因果形状的典型症状）；高斯缓滚降几乎干净。频域形状的"陡"直接换算成了时域的"振"。

工程里对应到两款经典滤波器：Bessel 与 Butterworth。两者可以设计成相同的 3 dB 截止点，但 Bessel 滚降更缓、Butterworth 更陡——而 Butterworth 本来就是按"固定过冲"特性设计的。

![Bessel 与 Butterworth 滤波器形状对比：3dB 点相同，滚降一缓一陡](/images/gibbs-phenomenon/fig7-bessel-vs-butterworth.png)
*（图源：Simcenter Testing Knowledge Base）*

![同一方波过两种滤波器：缓滚降的 Bessel 几乎无振铃，陡峭的 Butterworth 振铃明显](/images/gibbs-phenomenon/fig8-filter-shape-ringing.png)
*（图源：Simcenter Testing Knowledge Base）*

| 控制量 | 由什么决定 | 规律 |
| --- | --- | --- |
| **振铃时长** | 频率内容的截断程度 | 截掉的谐波越多，振铃持续越久、边沿越缓 |
| **振铃幅度** | 滤波器形状的陡峭程度 | 越陡振铃越大：高斯/Bessel < Butterworth < 砖墙 |
| **是否发生** | 信号本身 | 正弦类光滑信号不发生；含突变的信号才发生 |

| 特性 | **Bessel** | **Butterworth** |
| --- | --- | --- |
| **滚降** | 缓 | 陡 |
| **时域振铃** | 几乎无 | 固定过冲（设计特性） |
| **适用场景** | 时域波形保真、瞬态测量 | 频域选择性优先 |

::: tip 取舍原则
- 看时域波形、测瞬态（冲击、爆炸、阶跃）→ 缓滚降滤波（Bessel、低阶）
- 看频谱、对抗混叠要求高 → 陡峭滤波器没问题，吉布斯主要污染时域而非频域
- 两条都要 → 带宽留足余量（少截谐波）+ 入口加缓滚降低通，双管齐下
:::

## 四、Simcenter Testlab 里的对策

SCADAS 默认的抗混叠滤波器很陡，遇到方波类信号振铃明显。Testlab 支持在通道设置里给输入信号再追加一个低通 Bessel 滤波器，把吉布斯现象大幅压低。

开启路径：Channel Setup 工作表 → **Tools → Channel Setup Visibility**，把 `LPCutoff`、`LPFilterCharacteristics`、`LPFilterOn`、`LPFilterOrder` 四个字段 Add 进可见列。

| 参数 | 含义 | 工程建议 |
| --- | --- | --- |
| **LPCutoff** | 低通截止频率 | 经验法则：取采样率的 1/10 |
| **LPFilterCharacteristics** | 滤波器特性 | 选 Bessel（滚降缓） |
| **LPFilterOn** | 滤波开关 | ON |
| **LPFilterOrder** | 滤波器阶数 | 越低越缓，2 阶是最缓档 |

![方波信号：默认抗混叠滤波(红)振铃明显，追加二阶 Bessel(绿)后大幅收敛](/images/gibbs-phenomenon/fig12-testlab-bessel.png)
*（图源：Simcenter Testing Knowledge Base）*

注意这套低通设置依赖硬件支持——Simcenter SCADAS 的 VB8-E 与 V8-E 系列采集卡可用，其他卡型查产品资料页或咨询本地支持。

::: warning 工程注意
追加低通会压掉高频段真实内容，带宽损失是实打实的。设 LPCutoff 前先确认关心的最高频率（比如悬架冲击力谱常看到 1~2 kHz 以上仍有能量），截止频率别拍脑袋压到分析带宽以内。
:::

## 五、小结

三条判断标准带走：

1. **先看信号**：正弦类信号随便滤，不会有吉布斯；含突变/阶跃的瞬态信号（冲击、爆炸、换挡、砰击）才需要警惕。
2. **时域判读留心眼**：突变附近 9% 量级的过冲（相对跳变高度）是正常物理现象，不是传感器或安装问题；且各阶跃处表现不一致，不可标定扣除。频域数据基本不受影响。
3. **压振铃靠形状不靠带宽**：加带宽只缩短振铃时长，幅度纹丝不动；要压幅度就得用缓滚降滤波器——Testlab 里开 2 阶 Bessel，截止频率按采样率的 1/10 取，前提是硬件（VB8-E/V8-E 系列）支持。
