# IIR 原型滤波器五虎将：贝塞尔、巴特沃斯、切比雪夫与椭圆怎么选

> 在 Testlab 里点开 IIR 滤波器设计，原型下拉框里排着五个名字：贝塞尔、巴特沃斯、切比雪夫Ⅰ型、Ⅱ型、考尔（椭圆）。同一组截止频率指标，选谁都能滤，但阶次可以差一倍，通带形状和相位延迟更是各有脾气。这篇把这五种逼近的数学来历、各自拿什么特性换什么代价讲清楚，给出一张能直接抄的选型表。

## 一、为什么 IIR 设计要从"模拟原型"出发

数字 IIR 滤波器几乎从不直接设计，而是走一条"借尸还魂"的路：先在模拟域设计一个归一化低通原型（截止频率 $\omega_c=1$），再做频率变换把它变回数字域。手册第十二章给出的流程分五步：

1. **给定滤波特性**——通带边界 $\omega_p$、阻带边界 $\omega_s$、通带波纹 $\delta_1$、阻带衰减 $\delta_2$；
2. **数字频率转模拟频率**——通过双线性变换把 z 平面的数字截止频率换算到 s 平面；
3. **选原型**——在贝塞尔、巴特沃斯、切比雪夫Ⅰ/Ⅱ型、考尔五者中挑一个；
4. **频率变换**——把归一化低通原型变换成要的低通/高通/带通/带阻；
5. **双线性变换**——回到数字域，输出一组长度 n+1 的系数 a 和 b。

![IIR 滤波器的技术规格：通带波纹、阻带衰减、过渡带宽度](/images/iir-prototype-filters/iir-spec.png)

*IIR 滤波器设计第一步要交代的四个指标：通带波纹、阻带衰减、通带边界与阻带边界（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-8）*

为什么绕这道弯？因为模拟滤波器逼近理论在 1930 年代就已经成熟，巴特沃斯、切比雪夫、椭圆各有闭式解，直接拿来数字化比在数字域硬算省事得多。而"选原型"这一步，本质上是在回答一个问题：**你愿意用哪种缺陷去换阶次的降低？**

::: info 五种逼近的一句话画像
- **贝塞尔（Bessel）**：通带群延时最平，波形不失真，但阻带衰减最差
- **巴特沃斯（Butterworth）**：通带最平坦、单调下降，哪儿都不偏科，阶次需求中等
- **切比雪夫Ⅰ型（Chebyshev I）**：通带等波纹，换来的过渡带比同阶巴特沃斯窄
- **反切比雪夫Ⅱ型（Chebyshev II）**：阻带等波纹，通带平坦，含零点
- **考尔/椭圆（Cauer/Elliptic）**：通带、阻带双等波纹，同指标下阶次最低，相位最差
:::

## 二、五种原型的数学来历与代价

### 贝塞尔：用衰减换延时

贝塞尔逼近的目标不是幅值，而是**通带内的平坦群延时**。它的传递函数分母取 n 阶贝塞尔多项式 $B_n(s)$，归一化常数 $d_0 = B_n(0)$：

$$H(s) = \frac{d_0}{B_n(s)}$$

群延时平意味着各频率成分穿过滤波器的延迟一致，波形形状不失真——这对脉冲类信号、瞬态冲击是决定性优点。但代价惨重：手册直言贝塞尔的阻带衰减"甚至比巴特沃斯的还要差"，斜坡型的通带和阻带特性加上极宽的过渡带，连截止频率都难以定义。所以工程上贝塞尔的定位很窄：**保波形优先、衰减要求宽松**的场合。

### 巴特沃斯：最平坦的"老好人"

巴特沃斯的平方幅值响应是：

$$|H(j\omega)|^2 = \frac{1}{1 + (\omega/\omega_c)^{2n}}$$

"极为平坦"的数学含义是响应在原点 $\omega=0$ 处的各阶导数全部为零。代入 $\omega = \omega_c$ 验证一下截止频率处的衰减：

$$|H(j\omega_c)|^2 = \frac{1}{1+1} = \frac{1}{2}, \quad |H(j\omega_c)| = \frac{1}{\sqrt{2}}$$

幅值 $1/\sqrt{2}$ 换算成分贝是 $20\lg(1/\sqrt{2}) = -3.01\ \mathrm{dB}$——这就是"截止频率处降 3 dB"的来历，与阶数无关。

再看阻带滚降。当 $\omega \gg \omega_c$ 时分母里的 1 可以忽略，$|H| \approx (\omega/\omega_c)^{-n}$，频率翻一倍（一个倍频程）幅值就掉 $2^n$ 倍：

$$20\lg 2^n = 6n\ \mathrm{dB/倍频程}$$

4 阶巴特沃斯每倍频程衰减 24 dB，8 阶 48 dB——手册给出的"最大阻带衰减率 6×阶次 dB/倍频程"就是这么推出来的。巴特沃斯是全极点滤波器（s=∞ 处全部为零点数），通带阻带都单调下降，不产生波纹。

![巴特沃斯滤波器的特性](/images/iir-prototype-filters/butterworth-char.png)

*巴特沃斯的幅频与相频特性：通带内最大化平坦、全频段单调下降（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-10）*

### 切比雪夫Ⅰ型：通带等波纹换窄过渡带

切比雪夫Ⅰ型把巴特沃斯"通带最平坦"的执念放弃，改为**通带内等幅波纹**：

$$|H(j\omega)|^2 = \frac{1}{1 + \varepsilon^2 C_n^2(\omega)}$$

其中 $C_n(\omega)$ 是切比雪夫多项式——它在 $|\omega|\le 1$ 区间内精确地在 ±1 之间等幅振荡，这正是"等波纹"的来源。$\varepsilon$ 控制波纹深度，与通带波纹指标 $\delta_1$ 直接挂钩。

![切比雪夫Ⅰ型滤波器的等波纹通带](/images/iir-prototype-filters/chebyshev1-ripple.png)

*切比雪夫Ⅰ型：波纹全部堆在通带内，n 为奇数时从 1 起 n 为偶数时从波纹谷起（图源：Simcenter Testing Knowledge Base 中文理论手册）*

同样的衰减指标，切比雪夫Ⅰ型要求的阶次明显低于巴特沃斯，过渡带也窄得多——等波纹逼近在逼近论里就是"相同阶数下最大误差最小"的最优解。代价有二：通带有起伏（对幅值精度敏感的测量要小心），群延时不均匀、相位非线性明显。

### 反切比雪夫Ⅱ型：波纹搬去阻带

Ⅱ型把思路反过来：**通带保持平坦，波纹放到阻带**。它不再是全极点滤波器，既有极点也有零点——阻带的等波纹正是靠 s 平面上的零点把响应反复"按下去"实现的：

$$|H(j\omega)|^2 = \frac{1}{1 + \varepsilon^2 \left[C_n(\omega_r)/C_n(\omega_r/\omega)\right]^2}$$

$\omega_r$ 是阻带衰减达到规定值的最低频率。同指标下阶次同样低于巴特沃斯，代价是阻带不是单调下降而是有起伏——如果你的分析要在阻带里找低幅值成分（比如在强低频旁边找高频弱信号），阻带波纹地板会限制你能看到的深度。

![反切比雪夫Ⅱ型滤波器的等波纹阻带](/images/iir-prototype-filters/chebyshev2-ripple.png)

*反切比雪夫Ⅱ型：通带平坦、阻带等波纹，零点把阻带响应反复压回规定衰减线（图源：Simcenter Testing Knowledge Base 中文理论手册）*

### 考尔（椭圆）：两头等波纹，阶次最低

考尔滤波器通带和阻带**同时等波纹**，传递函数里的 $R_n(\omega, L)$ 是切比雪夫定额函数，涉及雅可比椭圆函数——"椭圆滤波器"由此得名：

$$|H(j\omega)|^2 = \frac{1}{1 + \varepsilon^2 R_n^2(\omega, L)}$$

在给定的阶次和波纹指标下，椭圆逼近是"感觉上最优的"——它能实现从通带到阻带**最短的过渡**。巴特沃斯和切比雪夫的阻带衰减上限是 6n dB/倍频程，椭圆可以更快，这正是手册说"要用椭圆取代低效率的前两种逼近的根本原因"。

![考尔（椭圆）滤波器的双等波纹特性](/images/iir-prototype-filters/cauer-ripple.png)

*考尔（椭圆）逼近：通带、阻带同时等波纹，过渡带最窄，代价是群延时特性最差（图源：Simcenter Testing Knowledge Base 中文理论手册）*

代价同样明确：相位/群延时特性在五种里最差。模拟椭圆滤波器在 s 平面原点有最平群延时的特征，但手册特别指出这一特征"不能一般地通过双线性变换予以保持"——数字化的椭圆滤波器延时失真照样跑不掉。

::: warning 阶次自动估计不适用于贝塞尔
用通带/阻带指标自动确定最优阶次的功能只支持巴特沃斯、切比雪夫Ⅰ/Ⅱ型和考尔四种原型。贝塞尔不行——它的特殊性质使得阶次会反过来影响截止频率，指标与阶次解耦不了。
:::

## 三、同指标下阶次差多少：算一笔账

空口说"椭圆阶次最低"没感觉，拿一组典型指标算一遍：归一化通带边界 $\omega_p=1$、阻带边界 $\omega_s=2$（过渡带一个倍频程），通带波纹 1 dB，阻带衰减 40 dB。

**巴特沃斯阶次**从定义出发推导。先由波纹指标算出鉴别因子（distinguishing factor）：

$$\eta^2 = \frac{10^{rs/10}-1}{10^{rp/10}-1}$$

巴特沃斯在阻带边界 $\omega_s$ 处的衰减为 $10\lg(1+\omega_s^{\,2n})$（归一化 $\omega_p=1$），要求它不低于 rs dB，即 $1+\omega_s^{2n} \ge \eta^2$，两边取对数解出 n：

$$n \ge \frac{\lg\eta^2}{2\,\lg(\omega_s/\omega_p)} = \frac{\lg\eta}{\lg 2}$$

代入数值：$\eta^2 = (10^4-1)/(10^{0.1}-1) \approx 38600$，$\eta \approx 196.5$，$n \ge \lg(196.5)/\lg 2 = 7.62$，取 **8 阶**。

**切比雪夫Ⅰ型**把分母里的幂函数换成双曲函数：$n \ge \mathrm{arcosh}(\eta)/\mathrm{arcosh}(\omega_s/\omega_p)$，代入得 $n \ge 4.54$，取 **5 阶**。

**椭圆**的阶次公式含第一类完全椭圆积分 $K(\cdot)$：

$$n \ge \frac{K(k)\,K(\sqrt{1-k_1^2})}{K(\sqrt{1-k^2})\,K(k_1)}, \quad k = \frac{\omega_p}{\omega_s},\ k_1 = \frac{1}{\eta}$$

代入 $k=0.5$、$k_1=1/196.5$，得 $n \ge 3.32$，取 **4 阶**。

| 原型 | 所需阶次 | 通带 | 阻带 | 相位/群延时 |
| --- | --- | --- | --- | --- |
| **贝塞尔** | （指标法不适用） | 斜坡型 | 衰减最差 | **最平，保波形** |
| **巴特沃斯** | 8 阶 | 最平坦、单调 | 单调下降 | 较好 |
| **切比雪夫Ⅰ型** | 5 阶 | 等波纹 | 单调下降 | 不均匀、非线性 |
| **切比雪夫Ⅱ型** | 5 阶 | 平坦 | 等波纹 | 不均匀 |
| **考尔（椭圆）** | **4 阶** | 等波纹 | 等波纹 | **最差** |

同样一组指标，椭圆比巴特沃斯省一半阶次。对整车 NVH 常见的实时阶次滤波、通道数多的道路谱预处理，阶次直接乘以通道数，这笔账不小。

## 四、被绕不开的双线性变换：频率翘曲

五步流程里第二步和第五步都经过双线性变换，它把 s 平面和 z 平面联系起来。当 $z=e^{j\omega_d T}$（单位圆上）且 $s=j\omega_a$ 时：

$$\omega_a = \frac{2}{T}\tan\frac{\omega_d T}{2}$$

关键性质：这个映射是**非线性**的。数字频率轴到模拟频率轴存在"翘曲"——频率越高，被压得越狠。设计时必须按上式预畸变（pre-warping），把你要的数字截止频率先换算成模拟原型频率再去设计，否则实际滤波器的截止点会偏离预期。

![由数字频率到模拟频率的转换](/images/iir-prototype-filters/freq-warping.png)

*双线性变换的频率翘曲：数字频率轴到模拟频率轴是非线性映射，高频端被压缩，设计时需预畸变补偿（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-9）*

## 五、Python 演示

### 演示一：巴特沃斯的 3 dB 截止与 6n dB/倍频程

```python
import numpy as np

w = np.array([0.5, 0.9, 1.0, 2.0, 4.0])   # 归一化频率（wc = 1）
n = 4                                      # 4 阶巴特沃斯

# |H|^2 = 1 / (1 + w^(2n))，直接从定义算幅值响应
H = 1 / np.sqrt(1 + w**(2*n))

for wi, hi in zip(w, H):
    print(f"w={wi:4.1f}  |H|={hi:.4f}  {20*np.log10(hi):+7.2f} dB")

print("\n截止频率处: %.2f dB （理论 -3.01，与阶数无关）" % (20*np.log10(H[2])))
print("2 wc 处衰减: %.1f dB （6n = 24 dB/倍频程）" % (-20*np.log10(H[3])))
print("4 wc 处衰减: %.1f dB （两个倍频程 = 48 dB）" % (-20*np.log10(H[4])))
```

输出里最值得看的两个数：$\omega=1$ 处精确落在 **-3.01 dB**，不管几阶都一样；每往上一个倍频程多衰减 **24 dB**（4 阶 × 6 dB），48.2 dB 对应两个倍频程，衰减率与阶次的乘法关系一目了然。

### 演示二：同指标下三种原型的阶次对比 + 频率翘曲

```python
import numpy as np

# 指标：wp=1, ws=2（一个倍频程过渡带），通带波纹 1 dB，阻带衰减 40 dB
wp, ws, rp, rs = 1.0, 2.0, 1.0, 40.0
eta = np.sqrt((10**(rs/10) - 1) / (10**(rp/10) - 1))   # 鉴别因子

n_bw = np.log10(eta**2) / (2*np.log10(ws/wp))          # 巴特沃斯
n_ch = np.arccosh(eta) / np.arccosh(ws/wp)             # 切比雪夫 I

def K(m):                                               # 完全椭圆积分（AGM 法）
    a, b = 1.0, np.sqrt(1 - m)
    for _ in range(60):
        a, b = 0.5*(a + b), np.sqrt(a*b)
    return np.pi / (2*a)

k, k1 = wp/ws, 1/eta                                    # 椭圆的两个参数
n_el = K(k**2)*K(1-k1**2) / (K(1-k**2)*K(k1**2))        # 椭圆阶次

print(f"鉴别因子 eta = {eta:.1f}")
print(f"巴特沃斯  n >= {n_bw:.2f} -> {int(np.ceil(n_bw))} 阶")
print(f"切比雪夫I n >= {n_ch:.2f} -> {int(np.ceil(n_ch))} 阶")
print(f"椭圆     n >= {n_el:.2f} -> {int(np.ceil(n_el))} 阶")

# 双线性变换的频率翘曲：fa = fs/pi * tan(pi*fd/fs)
fs = 1000.0
for fd in [50, 100, 200]:
    fa = fs/np.pi * np.tan(np.pi*fd/fs)
    print(f"数字 {fd:5.0f} Hz -> 模拟原型 {fa:6.1f} Hz（翘曲 {fa-fd:+.1f} Hz）")
```

最值得看的对比：同样指标下巴特沃斯要 **8 阶**、切比雪夫 5 阶、椭圆只要 **4 阶**——椭圆省一半。翘曲那一列则显示 50 Hz 几乎不动（+0.4 Hz），200 Hz 已经偏到 231 Hz：截止频率越靠近 Nyquist 的一半，预畸变越不能省。

## 六、低通原型怎么变成高通/带通/带阻

第四步的频率变换是一组对 s 的替换规则，把归一化低通原型"折"成目标滤波器，手册给出了完整的变换表：

![低通原型到其它类型滤波器的频率变换](/images/iir-prototype-filters/lp-transformations.png)

*归一化低通原型通过替换 s 变量转换为低通/高通/带通/带阻（图源：Simcenter Testing Knowledge Base 中文理论手册）*

工程上要留心的是带通/带阻变换会把原型阶次翻倍——一个 n 阶低通原型变带通后是 2n 阶。做发动机阶次跟踪的窄带带通时，先想清楚最终阶次再选原型，别在椭圆上再翻一倍还抱怨计算量大。

::: tip 选型原则
- **拿不准、通用滤波 → 巴特沃斯**：通带平坦无波纹，相位相对温和，是低风险默认项
- **过渡带窄、阶次要压 → 切比雪夫Ⅰ型**：通带幅值有 1 dB 级波纹通常可接受
- **通带幅值精度敏感、阻带要求松 → 切比雪夫Ⅱ型**：波纹藏进阻带
- **阶次预算卡死、相位无所谓 → 椭圆**：事后离线处理、只看幅值谱的场景最合适
- **保波形、看瞬态 → 贝塞尔**：冲击、脉冲信号过滤波，别用椭圆把它揉烂
- **实时在线处理 → 避开椭圆**，群延时畸变和量化敏感度都会咬人；离线批处理则可放心用
:::

## 七、小结

原型选择就是在"阶次、通带形状、阻带形状、相位"四个维度里做取舍：巴特沃斯哪一项都不极端，切比雪夫用波纹换阶次，椭圆用相位换最窄过渡带，贝塞尔用衰减换波形保真。判断标准一条就够——**先问信号后面还要不要做相位敏感的处理**。要（FRF、脉冲分析、波形回放）就退到巴特沃斯甚至贝塞尔；不要（只看幅值谱、阶次切片）就大胆用椭圆，同指标省下的阶次是实打实的。
