# IIR 原型滤波器选型：贝塞尔、巴特沃斯、切比雪夫与椭圆的特性对比

> 在 Testlab 中设计 IIR 滤波器时，原型下拉框列出五个选项：贝塞尔、巴特沃斯、切比雪夫Ⅰ型、Ⅱ型、考尔（椭圆）。同一组截止频率指标下，任一原型都能满足要求，但所需阶次可以相差一倍，通带形状与相位延迟也各不相同。本文按 Simcenter Testing 理论手册第十二章的设计流程，逐一说明五种逼近的数学定义、特性与代价，给出一组典型指标下的阶次计算和一份选型判据表。

## 一、为什么 IIR 设计要从"模拟原型"出发

数字 IIR 滤波器通常不直接在数字域设计，而是先在模拟域设计一个归一化低通原型（截止频率 $\omega_c=1$），再经频率变换和双线性变换（bilinear transform）映射回数字域。手册第十二章给出的流程分五步：

1. **给定滤波特性**——通带边界 $\omega_p$、阻带边界 $\omega_s$、通带波纹 $\delta_1$、阻带衰减 $\delta_2$；
2. **数字频率转模拟频率**——通过双线性变换把 z 平面的数字截止频率换算到 s 平面；
3. **选原型**——在贝塞尔、巴特沃斯、切比雪夫Ⅰ/Ⅱ型、考尔五者中选定一种；
4. **频率变换**——把归一化低通原型变换成目标的低通/高通/带通/带阻；
5. **双线性变换**——回到数字域，输出一组存储于长度 n+1 向量组的系数 a 和 b。

手册在这一章采用归一化频率（normalized frequency）：以采样率为单位频率，归一化频率 = 频率（Hz）/ 采样率（Hz），滤波器的工作频率范围为 0 至 0.5，单位圆上的角频率 $\omega$ = 归一化频率 $\times 2\pi$。

![IIR 滤波器的技术规格：通带波纹、阻带衰减、过渡带宽度](/images/iir-prototype-filters/iir-spec.png)

*IIR 滤波器设计第一步要交代的四个指标：通带波纹、阻带衰减、通带边界与阻带边界（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-8）*

绕这一道弯的原因：模拟滤波器逼近理论已经成熟，巴特沃斯、切比雪夫、椭圆各有闭式解，借助成熟的模拟原型设计比在数字域直接求解更为简便。而"选原型"这一步，本质上是在回答一个问题：**接受哪一种特性缺陷，以换取更低的阶次？**

::: info 五种逼近的特性概览
- **贝塞尔（Bessel）**：通带群延时最平，波形失真最小，但阻带衰减最差
- **巴特沃斯（Butterworth）**：通带最平坦、单调下降，各项特性均衡，阶次需求中等
- **切比雪夫Ⅰ型（Chebyshev I）**：通带等波纹，换来的过渡带比同阶巴特沃斯窄
- **反切比雪夫Ⅱ型（Chebyshev II）**：阻带等波纹，通带平坦，含零点
- **考尔/椭圆（Cauer/Elliptic）**：通带、阻带双等波纹，同指标下阶次最低，相位特性最差
:::

## 二、五种原型的数学定义与代价

### 贝塞尔：用阻带衰减换平坦群延时

贝塞尔逼近的目标不是幅值，而是**通带内的平坦群延时（group delay）**。它的传递函数分母取 n 阶贝塞尔多项式 $B_n(s)$，归一化常数 $d_0 = B_n(0)$：

$$H(s) = \frac{d_0}{B_n(s)}$$

群延时平坦意味着各频率成分穿过滤波器的延迟一致，波形形状不失真——这对脉冲类信号、瞬态冲击是决定性优点。但代价明显：手册指出贝塞尔的阻带衰减"甚至比巴特沃斯逼近的还要差"，斜坡型的通带和阻带特性加上极宽的过渡带，使截止频率都难以定义，手册由此评价其"没有多大实用价值"。工程上贝塞尔的适用范围很窄：**保波形优先、衰减要求宽松**的场合。

### 巴特沃斯：通带最平坦与 3 dB 截止

巴特沃斯的平方幅值响应是：

$$|H(j\omega)|^2 = \frac{1}{1 + (\omega/\omega_c)^{2n}}$$

手册所称"极为平坦"，数学含义是响应在原点 $\omega=0$ 处的各阶导数均为零。代入 $\omega = \omega_c$ 验证截止频率处的衰减：

$$|H(j\omega_c)|^2 = \frac{1}{1+1} = \frac{1}{2}, \quad |H(j\omega_c)| = \frac{1}{\sqrt{2}}$$

幅值 $1/\sqrt{2}$ 换算成分贝是 $20\lg(1/\sqrt{2}) = -3.01\ \mathrm{dB}$——这就是"截止频率处下降 3 dB"的来历，与阶数无关。

再看阻带滚降。当 $\omega \gg \omega_c$ 时分母中的 1 可以忽略，$|H| \approx (\omega/\omega_c)^{-n}$，频率每提高一个倍频程幅值下降 $2^n$ 倍：

$$20\lg 2^n = 6n\ \mathrm{dB/倍频程}$$

4 阶巴特沃斯每倍频程衰减 24 dB，8 阶 48 dB——手册给出的"最大阻带衰减率 6×阶次 dB/倍频程"即由此推出（该上限同样适用于切比雪夫逼近）。巴特沃斯是全极点滤波器（all-pole filter），全部零点位于 $s=\infty$，通带、阻带均单调下降，不产生波纹。

![巴特沃斯滤波器的特性](/images/iir-prototype-filters/butterworth-char.png)

*巴特沃斯的幅频与相频特性：通带内最大化平坦、全频段单调下降（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-10）*

### 切比雪夫Ⅰ型：通带等波纹换窄过渡带

切比雪夫Ⅰ型不再追求通带最平坦，而是允许**通带内等幅波纹**：

$$|H(j\omega)|^2 = \frac{1}{1 + \varepsilon^2 C_n^2(\omega)}$$

其中 $C_n(\omega)$ 是切比雪夫多项式——它在 $|\omega|\le 1$ 区间内精确地在 ±1 之间等幅振荡，这正是"等波纹"的来源。$\varepsilon$ 控制波纹深度，与通带波纹指标 $\delta_1$ 直接相关。

![切比雪夫Ⅰ型滤波器的等波纹通带](/images/iir-prototype-filters/chebyshev1-ripple.png)

*切比雪夫Ⅰ型：波纹全部位于通带内，n 为奇数时幅频曲线自 0 dB 起始、n 为偶数时自波纹谷起始（图源：Simcenter Testing Knowledge Base 中文理论手册）*

同样的衰减指标下，切比雪夫Ⅰ型要求的阶次低于巴特沃斯，过渡带也窄得多——等波纹逼近在逼近论中是"相同阶数下最大误差最小"的最优解。代价有二：通带有起伏（对幅值精度敏感的测量需注意），群延时不均匀、相位非线性明显。

### 反切比雪夫Ⅱ型：等波纹阻带

Ⅱ型把思路反过来：**通带保持平坦，波纹移至阻带**。它不再是全极点滤波器，既有极点也有零点——阻带的等波纹正是靠 s 平面上的零点把响应反复压回规定的衰减限值实现的：

$$|H(j\omega)|^2 = \frac{1}{1 + \varepsilon^2 \left[C_n(\omega_r)/C_n(\omega_r/\omega)\right]^2}$$

$\omega_r$ 是阻带衰减达到规定值的最低频率。同指标下阶次同样低于巴特沃斯，代价是阻带不是单调下降而是有起伏——如果分析需要在阻带内寻找低幅值成分（例如在强低频分量旁识别高频弱信号），阻带波纹的地板电平会限制可分辨的深度。

![反切比雪夫Ⅱ型滤波器的等波纹阻带](/images/iir-prototype-filters/chebyshev2-ripple.png)

*反切比雪夫Ⅱ型：通带平坦、阻带等波纹，零点把阻带响应反复压回规定衰减线（图源：Simcenter Testing Knowledge Base 中文理论手册）*

### 考尔（椭圆）：双等波纹，阶次最低

考尔滤波器通带和阻带**同时等波纹**，传递函数中的 $R_n(\omega, L)$ 是切比雪夫定额函数，参数 L 描述其波纹特性，求解涉及雅可比椭圆函数——"椭圆滤波器"由此得名：

$$|H(j\omega)|^2 = \frac{1}{1 + \varepsilon^2 R_n^2(\omega, L)}$$

手册的表述是：对给定的滤波器阶次和波纹指标，考尔逼近"从感觉上看是最优的"——它能实现从通带到阻带**最短的过渡**。巴特沃斯和切比雪夫的阻带衰减上限是 6n dB/倍频程，椭圆可以更快，这正是手册所说"要用椭圆逼近取代低效率的前两种逼近的根本原因"。

![考尔（椭圆）滤波器的双等波纹特性](/images/iir-prototype-filters/cauer-ripple.png)

*考尔（椭圆）逼近：通带、阻带同时等波纹，过渡带最窄，代价是群延时特性最差（图源：Simcenter Testing Knowledge Base 中文理论手册）*

代价同样明确：相位/群延时特性在五种中最差。模拟椭圆滤波器以在 s 平面原点有最平群延时为特征，但手册特别指出这一特征"不能一般地通过双线性变换予以保持"——数字化后的椭圆滤波器延时失真依然存在。

::: warning 阶次自动估计不适用于贝塞尔
用通带/阻带指标自动确定最优阶次的功能只支持巴特沃斯、切比雪夫Ⅰ/Ⅱ型和考尔四种原型。贝塞尔不适用：其特殊性质使阶次反过来影响截止频率，指标与阶次无法解耦。
:::

## 三、同指标下阶次差多少：定量计算

定性结论需要定量验证。取一组典型指标：归一化通带边界 $\omega_p=1$、阻带边界 $\omega_s=2$（过渡带一个倍频程），通带波纹 1 dB、阻带衰减 40 dB（即第一步中的 $\delta_1$、$\delta_2$ 以 dB 表示）。

![确定滤波器阶次需要的技术指标](/images/iir-prototype-filters/order-spec.png)

*自动确定滤波器阶次所需的输入：通带波纹、衰减、边界频率与采样频率（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-11）*

**巴特沃斯阶次**从定义出发推导。以通带边界为参考改写响应，波纹参数 $\varepsilon$ 由通带指标确定（与上节以 $\omega_c$ 为参考的写法等价，此处用 $\varepsilon$ 吸收波纹指标）：

$$|H(j\omega)|^2 = \frac{1}{1+\varepsilon^2(\omega/\omega_p)^{2n}}, \qquad \varepsilon^2 = 10^{r_p/10}-1$$

这一写法的意义：$\omega=\omega_p$ 处衰减恰为 $r_p$ dB。任意频率处相对 $\omega=0$ 的衰减为 $A(\omega) = 10\lg\left[1+\varepsilon^2(\omega/\omega_p)^{2n}\right]$ dB，在阻带边界要求 $A(\omega_s)\ge r_s$，即滚降项必须把响应压到指标以下：

$$\varepsilon^2\left(\frac{\omega_s}{\omega_p}\right)^{2n} \ge 10^{r_s/10}-1$$

定义鉴别因子（distinguishing factor）$\eta$——它度量阻带指标相对通带指标的严格程度，与原型类型无关：

$$\eta^2 = \frac{10^{r_s/10}-1}{10^{r_p/10}-1}$$

代入上式并两边取对数，解出阶次下限：

$$n \ge \frac{\lg\eta^2}{2\,\lg(\omega_s/\omega_p)} = \frac{\lg\eta}{\lg(\omega_s/\omega_p)}$$

代入数值：$\eta^2 = (10^4-1)/(10^{0.1}-1) \approx 3.86\times 10^4$，$\eta \approx 196.5$，$n \ge \lg(196.5)/\lg 2 = 7.62$，取 **8 阶**。

**切比雪夫Ⅰ型**把幂函数换成双曲函数：$n \ge \mathrm{arcosh}(\eta)/\mathrm{arcosh}(\omega_s/\omega_p)$——切比雪夫多项式在阻带区间按双曲余弦（指数律）增长，比幂律更快达到指标，代入得 $n \ge 4.54$，取 **5 阶**。

**椭圆**的阶次公式含第一类完全椭圆积分 $K(\cdot)$：

$$n \ge \frac{K(k)\,K(\sqrt{1-k_1^2})}{K(\sqrt{1-k^2})\,K(k_1)}, \quad k = \frac{\omega_p}{\omega_s},\ k_1 = \frac{1}{\eta}$$

代入 $k=0.5$、$k_1=1/196.5$，得 $n \ge 3.32$，取 **4 阶**。

| 原型 | 所需阶次 | 通带 | 阻带 | 相位/群延时 |
| --- | --- | --- | --- | --- |
| **贝塞尔** | （指标法不适用） | 斜坡型 | 衰减最差 | **最平，保波形** |
| **巴特沃斯** | 8 阶 | 最平坦、单调 | 单调下降 | 较好 |
| **切比雪夫Ⅰ型** | 5 阶 | 等波纹 | 单调下降 | 不均匀、非线性 |
| **切比雪夫Ⅱ型** | 5 阶 | 平坦 | 等波纹 | 不均匀 |
| **考尔（椭圆）** | **4 阶** | 等波纹 | 等波纹 | **最差** |

同一组指标下，椭圆所需阶次约为巴特沃斯的一半。对多通道道路谱预处理、实时阶次滤波等场合，阶次随通道数线性放大，原型选择对总计算量影响显著。

## 四、双线性变换的频率翘曲与预畸变

五步流程中的第二步和第五步都经过双线性变换，它把 s 平面和 z 平面联系起来。当 $z=e^{j\omega_d T}$（单位圆上）且 $s=j\omega_a$ 时：

$$\omega_a = \frac{2}{T}\tan\frac{\omega_d T}{2}$$

关键性质：这个映射是**非线性**的。数字频率轴到模拟频率轴存在"翘曲"（warping）——频率越高，压缩越明显。手册要求按图示方法补偿这一非线性，即设计时必须按上式预畸变（pre-warping），把目标的数字截止频率先换算成模拟原型频率再去设计，否则实际滤波器的截止点会偏离预期。

![由数字频率到模拟频率的转换](/images/iir-prototype-filters/freq-warping.png)

*双线性变换的频率翘曲：数字频率轴到模拟频率轴是非线性映射，高频端被压缩，设计时需预畸变补偿（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-9）*

## 五、Python 演示

### 演示一：巴特沃斯的 3 dB 截止与 6n dB/倍频程

```python
import numpy as np

w = np.array([0.5, 0.9, 1.0, 2.0, 4.0])   # 归一化频率（wc = 1）
n = 4                                      # 4 阶巴特沃斯

# |H|^2 = 1 / (1 + w^(2n))，直接从定义算幅值响应
H = 1 / np.sqrt(1 + w**(2*n))

for wi, hi in zip(w, H):
    print(f"w={wi:4.1f}  |H|={hi:.4f}  {20*np.log10(hi):+7.2f} dB")

print("\n截止频率处: %.2f dB （理论 -3.01，与阶数无关）" % (20*np.log10(H[2])))
print("2 wc 处衰减: %.1f dB （6n = 24 dB/倍频程）" % (-20*np.log10(H[3])))
print("4 wc 处衰减: %.1f dB （两个倍频程 = 48 dB）" % (-20*np.log10(H[4])))
```

输出中的两个关键数值：$\omega=1$ 处精确落在 **-3.01 dB**，与阶数无关；频率每提高一个倍频程衰减增加 **24 dB**（4 阶 × 6 dB），48.2 dB 对应两个倍频程，衰减率与阶次呈 $6n$ dB/倍频程的线性关系。

### 演示二：同指标下三种原型的阶次对比 + 频率翘曲

```python
import numpy as np

# 指标：wp=1, ws=2（一个倍频程过渡带），通带波纹 1 dB，阻带衰减 40 dB
wp, ws, rp, rs = 1.0, 2.0, 1.0, 40.0
eta = np.sqrt((10**(rs/10) - 1) / (10**(rp/10) - 1))   # 鉴别因子

n_bw = np.log10(eta**2) / (2*np.log10(ws/wp))          # 巴特沃斯
n_ch = np.arccosh(eta) / np.arccosh(ws/wp)             # 切比雪夫 I

def K(m):                                               # 完全椭圆积分（AGM 法）
    a, b = 1.0, np.sqrt(1 - m)
    for _ in range(60):
        a, b = 0.5*(a + b), np.sqrt(a*b)
    return np.pi / (2*a)

k, k1 = wp/ws, 1/eta                                    # 椭圆的两个参数
n_el = K(k**2)*K(1-k1**2) / (K(1-k**2)*K(k1**2))        # 椭圆阶次

print(f"鉴别因子 eta = {eta:.1f}")
print(f"巴特沃斯  n >= {n_bw:.2f} -> {int(np.ceil(n_bw))} 阶")
print(f"切比雪夫I n >= {n_ch:.2f} -> {int(np.ceil(n_ch))} 阶")
print(f"椭圆     n >= {n_el:.2f} -> {int(np.ceil(n_el))} 阶")

# 双线性变换的频率翘曲：fa = fs/pi * tan(pi*fd/fs)
fs = 1000.0
for fd in [50, 100, 200]:
    fa = fs/np.pi * np.tan(np.pi*fd/fs)
    print(f"数字 {fd:5.0f} Hz -> 模拟原型 {fa:6.1f} Hz（翘曲 {fa-fd:+.1f} Hz）")
```

关键对比：同一指标下巴特沃斯需 **8 阶**、切比雪夫Ⅰ型 5 阶、椭圆 **4 阶**，椭圆所需阶次约为巴特沃斯的一半。翘曲一列显示 50 Hz 处仅偏移 +0.4 Hz，200 Hz 处已偏移至 231 Hz：截止频率越接近 Nyquist 频率（$f_s/2$），预畸变越不可省略。

## 六、低通原型怎么变成高通/带通/带阻

第四步的频率变换是一组对 s 的替换规则，把归一化低通原型变换为目标滤波器，手册给出了完整的变换表：

![低通原型到其它类型滤波器的频率变换](/images/iir-prototype-filters/lp-transformations.png)

*归一化低通原型通过替换 s 变量转换为低通/高通/带通/带阻（图源：Simcenter Testing Knowledge Base 中文理论手册）*

需要注意带通/带阻变换会把原型阶次翻倍——一个 n 阶低通原型变带通后是 2n 阶。做发动机阶次跟踪的窄带带通时，应先核算最终阶次再选原型；若选椭圆原型，变换后阶次同样翻倍，计算量需提前评估。

::: tip 选型判据
- **通用滤波、无特殊相位要求 → 巴特沃斯**：通带平坦无波纹，相位相对温和，是低风险默认选项
- **过渡带窄、需降低阶次 → 切比雪夫Ⅰ型**：通带幅值有 1 dB 级波纹，多数场合可接受
- **通带幅值精度敏感、阻带要求宽松 → 切比雪夫Ⅱ型**：波纹位于阻带
- **阶次受限、对相位不敏感 → 椭圆**：离线处理、只看幅值谱的场景适用
- **保波形、看瞬态 → 贝塞尔**：冲击、脉冲信号滤波不应选用椭圆，其群延时畸变会改变瞬态波形
- **实时在线处理 → 避开椭圆**：群延时畸变与系数量化敏感度都会引入误差；离线批处理可正常使用
:::

## 七、小结

原型选择是在"阶次、通带形状、阻带形状、相位"四个维度内做取舍：巴特沃斯各项均衡，切比雪夫用波纹换阶次，椭圆用相位换最窄过渡带，贝塞尔用衰减换波形保真。判断的核心标准是：**滤波后的信号是否还要做相位敏感的处理**。需要（FRF、脉冲分析、波形回放）就选巴特沃斯甚至贝塞尔；不需要（只看幅值谱、阶次切片）则可选用椭圆，同指标下节省的阶次是实际收益。
