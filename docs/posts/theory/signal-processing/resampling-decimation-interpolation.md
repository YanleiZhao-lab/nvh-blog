# 重采样：降采样的折叠、升采样的镜像与任意比率的代价

> 采回来的数据经常要"换采样率"：48 kHz 录音降到 500 Hz 分析、2 kHz 降到 800 Hz 拼数据集、按转速把时间序列拧到角度轴。重采样看着只是插值取点，实际处处是坑——降采样不滤波，325 Hz 的成分会折成 75 Hz 的假峰；升采样插零，谱里会多出一串镜像；任意比率转换更要在精度和计算量之间讨价还价。这篇把固定重采样（降采样、升采样、分数比率、任意比率）和自适应重采样（角度域变换）的原理一次讲透。

## 一、为什么需要重采样

数字信号一旦采下来，采样率就焊死在数据里。但工程流程里"换采样率"的需求无处不在。

最典型的是**数据瘦身**。一台数字记录仪以 48 kHz 采样，而信号带宽只有 200 Hz——按每周期至少 2 个点的要求，500 Hz 的采样率已经绰绰有余。48 kHz 里 99% 的数据都是冗余的，白白撑大文件、拖慢后续处理。把采样率缩减下来，这个方向的处理叫**选抽（decimation）或降采样（downsampling）**。

反方向的需求也存在。已经识别出谱分量的信号，采样点数刚好够描述频率信息，但时域波形画出来毛毛糙糙——临界采样的正弦波每周期只有两个多点，频域信息是完整的，时域看着却不像回事。提高采样率让波形好看，这叫**插值（interpolation）或升采样（upsampling）**。

第三类需求来自硬件适配：D/A 重放要求数据正好是转换器支持的采样率；不同来源的数据要拼接，采样率必须先统一。

::: info 核心概念
- **降采样（Downsampling/Decimation）**：降低采样率，每 n 点取 1 点，必须先抗混叠滤波
- **升采样（Upsampling/Interpolation）**：提高采样率，采样点间插 n-1 个点，必须后置低通滤波
- **分数比率重采样**：升采样 + 降采样的组合拳，顺序不能乱
- **自适应重采样（Adaptive Resampling）**：按转速等跟踪信号把时间序列变换到角度域
:::

## 二、降采样：折叠是头号敌人

以因子 n 做整数降采样，字面操作是"保留每隔 n 点的数据"。手册里给了一个反例：降采样因子 13，而原信号每个周期有 16 个采样点——抽完后每周期只剩 1.2 个点，连耐奎斯特判据都满足不了，结果自然是错的。

正确的流程分两步。手册的算例：原始信号 1 kHz 采样，分析带宽 500 Hz，信号含 8 Hz 和 325 Hz 两个谱分量。降采样因子 5 意味着新采样率 200 Hz、新带宽 100 Hz。325 Hz 超出了新带宽，必须先用低通滤波器把它滤掉，再隔 5 取 1。

![降采样前先低通滤波保留 8 Hz 分量](/images/resampling-decimation-interpolation/downsample-filter-keep.png)
*（图源：Simcenter Testing Knowledge Base）*

不滤波直接抽会怎样？325 Hz 折叠到 100 Hz 带宽内的 75 Hz 处——谱上凭空多出一个 75 Hz 的假峰，幅值还不小。这就是混叠在重采样里的翻版：**降采样 = 数字域的第二次采样**，采样定理对它同样生效。

![不滤波的后果：325 Hz 折叠成 75 Hz 假峰](/images/resampling-decimation-interpolation/downsample-aliasing-fold.png)
*（图源：Simcenter Testing Knowledge Base）*

折叠频率的算法和初次混叠完全一样。新采样率 $f_s' = f_s/n$，折叠发生在 $f_s'/2$ 处：

$$f_{fold} = |f - k \cdot f_s'|, \quad k \in \mathbb{Z}$$

325 Hz 以 200 Hz 为模折叠：$|325 - 2 \times 200| = 75$ Hz。落在 0～100 Hz 带带内，成了以假乱真的低频成分。

::: warning 工程注意
自写脚本处理数据时，降采样前必须自己补数字低通滤波——`x[::n]` 一行代码抽完，谱上多出来的低频峰就是折叠进来的高频成分。Testlab 的重采样功能内置了抗混叠滤波，但用别的工具链时这一步没人替你做。滤掉的频率成分在降采样后永远找不回来，动手前先确认关心的频带确实在新带宽以内。
:::

## 三、升采样：插零与镜像

因子 n 的整数升采样，是在原采样点之间插入 n-1 个点。标准做法分两步：先**插零**——所有插入点取值为零；再加低通滤波器，滤除插零产生的谐波成分。

为什么插零会带来麻烦？可以从谱的角度推。设原序列 $x(m)$ 的离散傅里叶变换为 $X(e^{j\omega})$，插零后的序列 $y(m)$ 满足 $y(mn) = x(m)$、其余点为零。按定义直接展开：

$$Y(e^{j\omega}) = \sum_m y(m) e^{-j\omega m} = \sum_m x(m) e^{-j\omega nm} = X(e^{jn\omega})$$

也就是说，插零后的谱是**原谱在频率轴上压缩 n 倍后的周期重复**：0～π/n 区间是原谱的压缩版，π/n～π 区间则塞进了原谱在所有更高频率上的"镜像"。时域上看，信号像被插值削出严重毛刺；频域上看，是镜像谐波占了新腾出来的高频空间。

![因子 4 升采样：插零后时域失真、频域出现镜像](/images/resampling-decimation-interpolation/zero-stuff-mirror.png)
*（图源：Simcenter Testing Knowledge Base）*

低通滤波器的作用就是把这些镜像抹掉，只保留原带宽内的谱成分。滤波后信号保留了原有的谱，但每周期采样点数变成原来的 n 倍，时域波形顿时平滑。手册举的例子：临界采样的正弦波（每周期刚过 2 个点）做因子 10 的升采样，波形从锯齿状变成漂亮的正弦——信息没变，表达变了。

![升采样滤波后：临界采样正弦波获得平滑时域表示](/images/resampling-decimation-interpolation/upsample-filtered.png)
*（图源：Simcenter Testing Knowledge Base）*

## 四、分数比率：升在前、降在后

非整数比率的重采样靠升采样和降采样组合实现。因子 2.5 的降采样 = 先因子 2 升采样，再因子 5 降采样。**顺序至关重要**。

手册的算例：信号上限频率 300 Hz，原采样率 2 kHz，目标采样率 800 Hz（因子 2.5 降采样）。

正确步骤：
1. 先升采样至 4 kHz（分析带宽 2 kHz），用截止 1 kHz 的低通保留原谱成分；
2. 再做因子 5 的降采样，配截止 400 Hz 的低通——300 Hz 以内的成分全部保住。

![分数比率重采样的正确顺序](/images/resampling-decimation-interpolation/fractional-resample.png)
*（图源：Simcenter Testing Knowledge Base）*

如果顺序反过来，先做因子 5 的降采样，低通必须切在 200 Hz——200 到 300 Hz 之间的成分先被滤掉，后面无论怎么升采样都救不回来。**先升后降，中间的滤波器才有足够的带宽可切；先降后升，信息已经丢了。**

遇到不方便用整数组合表达的采样率，重采样软件会自动确定优化的中间采样率和运算顺序。极端情况如 8192 Hz 转 8000 Hz——理论上 125 倍升采样配 128 分之一降采样可实现，但计算代价高得离谱。实际做法是"高因子预升采样 + 线性插值"：先以较高的因子 a 做插值前升采样（LMS 软件默认值 15），再对升采样后的密集点做线性插值，直接落到目标栅格上。

![任意比率：预升采样后线性插值到目标采样点](/images/resampling-decimation-interpolation/arbitrary-rate-interp.png)
*（图源：Simcenter Testing Knowledge Base）*

插值精度有一个量化指标——**信号失真比 SDR（Signal to Distortion Ratio）**，取决于插值前升采样因子 R 和滤波器截止频率（相对耐奎斯特频率的百分比）：

$$SDR = 10 \log_{10} \left( \frac{80 R}{\pi \cdot f_c\% / 100} \right)$$

R 越大、插值点越密，线性插值的误差越小，SDR 越高。这是拿计算量换精度的明码标价。

## 五、自适应重采样：换一根轴看信号

前面四种都是"时间轴上的时间"重新分配。自适应（同步）重采样换了思路：**以转速等跟踪信号为基准，把信号从一个"域"变换到另一个"域"**。

机械领域最熟的应用是把发动机振动从时域变换到角度域。道理在频域和阶次域的互补性里：转速哪怕只波动一点，频域里低阶分量会锐变、高阶干脆糊成一片；换成阶次域，所有阶次清晰锐利，但共振现象又模糊了。两个域各看一半真相，自适应重采样让你在域之间自由切换。

变换的原料是跟踪信号——光电式、磁电式或电涡流探头给出的转速脉冲串，转换成转速-时间函数，积分得到转角-时间函数。角度域分辨率 Δα 的选取原则：**按最低转速算**。转速最低时每转的时间最长，同样的 Δα 对应的时间间隔最大，这是整个变换中最苛刻的约束。

![转速脉冲串积分成转角-时间函数](/images/resampling-decimation-interpolation/tacho-angle-domain.png)
*（图源：Simcenter Testing Knowledge Base）*

具体步骤：对按等角度栅格要求的时间间隔，在原时间序列上取样。时间采样间隔 ΔT = 1/Fs，角度间隔对应的时间随转速变化，本质上仍是一次插值——只是插值的位置由转速曲线决定，不再均匀。

![时域到角度域的转换步骤](/images/resampling-decimation-interpolation/adaptive-resample-steps.png)
*（图源：Simcenter Testing Knowledge Base）*

无论固定还是自适应，重采样的质量控制要点一以贯之：FIR 低通滤波器要有**足够的阻带抑制**（镜像和折叠压得够低）、**足够小的通带波纹**（原谱成分不被染色），同时阶次不能高到计算时间不可接受。

## 六、Python 演示：折叠与镜像的数值实验

```python
import numpy as np

fs = 1000                     # 原采样率 Hz
t = np.arange(0, 1, 1/fs)
x = np.sin(2*np.pi*8*t) + 0.7*np.sin(2*np.pi*325*t)   # 8 Hz + 325 Hz

def amp_spec(sig, fs):
    N = len(sig)
    X = np.abs(np.fft.rfft(sig)) / N * 2
    f = np.fft.rfftfreq(N, 1/fs)
    return f, X

# 错误做法：直接隔 5 取 1（不滤波）
f1, X1 = amp_spec(x[::5], fs/5)
top = np.argsort(X1)[::-1][:2]            # 幅值前二的谱峰
for k in top:
    print(f"不滤波降采样: {f1[k]:.0f} Hz 处出现 {X1[k]:.2f} 幅值峰")

# 正确做法：先低通滤波（移动平均近似 100 Hz 低通）再降采样
kernel = np.ones(5)/5
x_lp = np.convolve(x, kernel, mode='same')
f2, X2 = amp_spec(x_lp[::5], fs/5)
print(f"滤波后降采样: 最大谱峰 {f2[np.argmax(X2)]:.0f} Hz")

# 升采样插零的镜像
y = np.zeros(2*len(x)); y[::2] = x          # 因子 2 插零
f3, X3 = amp_spec(y, 2*fs)
mask = f3 > 500                             # 只在新带宽里找
print(f"插零升采样: 镜像峰 {f3[np.argmax(X3*mask)]:.0f} Hz")
```

三个数字最值得看：不滤波直接抽点，谱上 8 Hz 真峰旁边立着 0.70 幅值的 75 Hz 假峰——正是 325 Hz 折叠的结果，与手册算例完全一致；滤波后 75 Hz 假峰消失，只剩 8 Hz 真成分；插零升采样后，8 Hz 在新带宽里映出 992 Hz 的镜像（1000 - 8 = 992），印证"镜像谱周期重复"的推导。

## 七、四种重采样方式对比

| 方式 | 操作 | 必配滤波器 | 主要风险 | 典型场景 |
| --- | --- | --- | --- | --- |
| **整数降采样** | 每 n 点取 1 点 | 前置低通（截止 < 新带宽） | 高频折叠成假低频 | 数据瘦身、降文件体积 |
| **整数升采样** | 点间插 n-1 个零 | 后置低通（截止 < 原带宽） | 镜像谐波混入新带宽 | 改善时域波形、适配 D/A |
| **分数比率** | 先升后降 | 每步各配低通 | 顺序颠倒丢频带 | 统一不同来源数据采样率 |
| **自适应（角度域）** | 按转速曲线插值 | FIR 低通（阻带+波纹指标） | Δα 取太大丢高阶 | 阶次分析、同步平均 |

::: tip 工程判断
- 降采样前先问一句：新带宽罩不罩得住关心的最高频率？罩不住就别降
- 升采样不改变信息量，只为表达；别指望它"恢复"细节
- 分数比率永远先升后降，先降后升丢的频带找不回来
- 角度域分辨率按最低转速定，高速段自然富余
:::
