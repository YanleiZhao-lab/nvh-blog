# 重采样：降采样的频率折叠、升采样的镜像与任意比率的实现代价

> 实测数据在分析流程中经常需要变换采样率：48 kHz 录音降至 500 Hz 分析、2 kHz 降至 800 Hz 以便与数据集拼接、按转速把时间序列变换到角度域。重采样并非简单的插值取点：降采样若不做抗混叠滤波，325 Hz 的成分会折叠为 75 Hz 的虚假谱峰；升采样插零会在谱中引入镜像成分；任意比率转换则需在精度与计算量之间权衡。本文按测试理论手册第十一章的框架，讨论固定重采样（整数降采样、整数升采样、分数比率、任意比率）与自适应重采样（角度域变换）的原理、实施条件与质量控制要点。

## 一、为什么需要重采样

数字信号一旦完成采集，采样率就固定在数据里，而工程流程中对"变换采样率"的需求普遍存在。

最典型的是**数据缩减**。一台数字式记录仪以 48 kHz 采样，而信号带宽仅 200 Hz——按每周期至少 2 个采样点的要求，500 Hz 的采样率已经满足描述信号的需要，其余约 99% 的采样都是冗余的，只会增大文件体积、增加后续处理的计算量。把采样率缩减下来，这一处理称为**选抽（decimation）或降采样（downsampling）**。

反方向的需求同样存在。对于已经识别出谱分量的信号，采样点数刚好够描述其频率信息，但时域波形可能出现明显的锯齿状失真——临界采样的正弦波每周期只有两个多采样点，频域信息完整，时域表示却不够充分。提高采样率可以获得更好的时间波形，这一处理称为**插值（interpolation）或升采样（upsampling）**。

第三类需求来自硬件与数据格式适配：通过 D/A（数-模）转换重放信号时，要求数据具有转换器支持的特定采样率；不同来源的数据需要拼接时，采样率必须先统一。

::: info 核心概念
- **降采样（Downsampling/Decimation）**：降低采样率，每 n 点取 1 点，必须先做抗混叠低通滤波
- **升采样（Upsampling/Interpolation）**：提高采样率，采样点间插入 n-1 个零点，必须后置低通滤波
- **分数比率重采样**：升采样与降采样的级联，顺序不可颠倒
- **自适应重采样（Adaptive Resampling）**：按转速等跟踪信号把时间序列变换到角度域
:::

## 二、整数倍降采样：频率折叠

以因子 n 做整数倍降采样，字面操作是"保留每隔 n 点的数据"。手册给出了一个反例：降采样因子为 13，而原信号每个周期有 16 个采样点——抽点后每周期只剩约 1.2 个点，低于采样定理要求的每周期 2 个采样点，结果必然错误。

正确的流程分两步。手册的算例：原始信号以 1 kHz 采样，许可分析带宽 500 Hz，信号含 8 Hz 和 325 Hz 两个谱分量。降采样因子 5 意味着新采样率 200 Hz、新许可带宽 100 Hz。325 Hz 超出了新带宽，必须先用低通滤波器把数据的谱成分限制在 100 Hz 以内，再每隔 5 点取 1 点。滤波后保留的 8 Hz 分量每周期仍有 125 个采样点，描述充分。

![降采样前先低通滤波保留 8 Hz 分量](/images/resampling-decimation-interpolation/downsample-filter-keep.png)
*（图源：Simcenter Testing Knowledge Base）*

不做滤波直接抽点的后果可以定量计算。降采样等价于数字域的第二次采样，采样定理同样生效：新采样率 $f_s' = f_s / n$（单位 Hz），新许可带宽为 $f_s'/2$，任何高于 $f_s'/2$ 的成分都会折叠进带宽内：

$$f_{fold} = \left| f - k \cdot f_s' \right|, \quad k \in \mathbb{Z}$$

其中 $f$ 为原信号中的频率成分（Hz），k 为使折叠结果落在 $0 \sim f_s'/2$ 内的整数。325 Hz 以新采样率 200 Hz 为模折叠：$|325 - 2 \times 200| = 75$ Hz，正好落入 100 Hz 带宽内。手册的结论是：325 Hz 的分量折叠到 75 Hz 处，给出严重失真的结果——而且折叠不改变能量，虚假谱峰的幅值与原高频成分相当（见第六节的数值验证）。

![不滤波的后果：325 Hz 折叠成 75 Hz 虚假谱峰](/images/resampling-decimation-interpolation/downsample-aliasing-fold.png)
*（图源：Simcenter Testing Knowledge Base）*

::: warning 工程注意
自写脚本处理数据时，降采样前必须自行完成数字低通滤波——`x[::n]` 一行代码抽点后，谱上新出现的低频峰即折叠进来的高频成分。Testlab 的重采样功能内置了抗混叠滤波，但更换工具链时这一步不会自动完成。被滤除的频率成分在降采样后无法恢复，动手前应先确认关心的频带确实位于新带宽以内。
:::

## 三、整数倍升采样：插零与镜像

因子 n 的整数升采样，是在原有采样点之间插入 n-1 个数据点。标准做法分两步：先**插零**——所有插入点取值为零；再加低通滤波器，滤除插零产生的谐波成分。

插零带来的谱变化可以从定义出发推导。设原序列 $x(m)$ 的离散傅里叶变换为 $X(e^{j\omega})$，插零后的序列 $y(m)$ 满足 $y(mn) = x(m)$、其余点为零。按定义直接展开：

$$Y(e^{j\omega}) = \sum_m y(m)\, e^{-j\omega m} = \sum_m x(m)\, e^{-j\omega nm} = X(e^{jn\omega})$$

推导分三步，每步的物理意义如下：第一步是 DTFT 定义代入；第二步利用 $y(m)$ 只在 $m = kn$ 处非零，求和指标只保留这些点；第三步把 $e^{-j\omega nm}$ 识别为数字频率压缩 n 倍后的变换核。

结论：插零后的谱是**原谱在频率轴上压缩 n 倍后的周期重复**。数字频率 $\omega$ 对应的物理频率为 $f = \omega f_s' / 2\pi$（$f_s' = n f_s$ 为新采样率），代入 $Y(e^{j\omega}) = X(e^{jn\omega})$ 可得镜像成分出现的位置：

$$f_{img} = \left| k \cdot f_s \pm f \right|, \quad k = 1, 2, \dots$$

其中 $f$ 为原谱成分的频率（Hz），$f_s$ 为原采样率（Hz），取落在新带宽 $0 \sim f_s'/2$ 内的结果。时域上看，插零使波形出现严重失真；频域上看，是镜像成分占据了新腾出来的高频空间。

![因子 4 升采样：插零后时域失真、频域出现镜像](/images/resampling-decimation-interpolation/zero-stuff-mirror.png)
*（图源：Simcenter Testing Knowledge Base）*

后置低通滤波器的作用就是滤除这些镜像，只保留原带宽内的谱成分。滤波后的信号保持原有的谱成分不变，但每周期采样点数变为原来的 n 倍，时域波形随之平滑。手册的例子：临界采样（critically sampled，即采样率刚好大于每周期 2 个采样点）的正弦波做因子 10 的升采样后，时域描述明显改善——信息量没有变化，改变的只是表示方式。

![升采样滤波后：临界采样正弦波获得平滑时域表示](/images/resampling-decimation-interpolation/upsample-filtered.png)
*（图源：Simcenter Testing Knowledge Base）*

## 四、分数比率与任意比率：升在前、降在后

非整数比率的重采样通过升采样和降采样的组合实现。因子 2.5 的降采样 = 先因子 2 升采样，再因子 5 降采样。**顺序至关重要**。

手册的算例：信号上限频率 300 Hz，原采样率 2 kHz，目标采样率 800 Hz（因子 2.5 降采样）。

正确步骤：
1. 先升采样至 4 kHz（分析带宽 2 kHz），用截止 1 kHz 的低通保留原谱成分；
2. 再做因子 5 的降采样，配截止 400 Hz 的低通——300 Hz 以内的成分全部保留。

![分数比率重采样的正确顺序](/images/resampling-decimation-interpolation/fractional-resample.png)
*（图源：Simcenter Testing Knowledge Base）*

若顺序颠倒，先做因子 5 的降采样，低通必须切在 200 Hz——200 至 300 Hz 之间的成分先被滤除，后续的升采样无法恢复。判据可以概括为：**先升后降，中间的滤波器才有足够的带宽可选；先降后升，信息已经丢失。**

当要求的采样率不容易用整数升采样和降采样的组合表达时，重采样软件会自动确定优化的中间采样率和运算顺序。极端情况如 8192 Hz 转 8000 Hz（数字音频硬件重放）：理论上可通过 125 倍升采样与 128 分之一降采样的组合实现，但计算代价过高。实际做法是"高因子预升采样 + 线性插值"：先以较高的因子 a 做**插值前升采样**（LMS 软件默认值 15），再对升采样后的密集点做线性插值，直接落到目标采样栅格上；最后以整数因子 b 降采样（要求 b 低于居先的升采样因子 a），或由插值过程本身直接完成降采样。

![任意比率：预升采样后线性插值到目标采样点](/images/resampling-decimation-interpolation/arbitrary-rate-interp.png)
*（图源：Simcenter Testing Knowledge Base）*

线性插值的精度有量化指标——**信号失真比 SDR（Signal to Distortion Ratio）**，取决于插值前升采样因子 R 和滤波器截止频率（相对耐奎斯特频率的百分比 $f_c\%$）：

$$SDR = 10 \log_{10} \left( \frac{80 R}{\pi \cdot f_c\% / 100} \right) \ \mathrm{dB}$$

按默认参数 R = 15、截止 80% 计算：$SDR = 10\log_{10}(80 \times 15 / (0.8\pi)) \approx 26.8$ dB。R 越大，插值点越密，线性插值误差越小，SDR 越高——精度与计算量之间存在明确的定量权衡关系。

## 五、自适应重采样：变换分析域

前四类重采样都在时间轴上重新分配采样点。自适应（同步）重采样换了思路：**以转速等跟踪信号为基准，把信号从一个"域"变换到另一个"域"**。

机械领域最常见的应用是以某部件的转速测量为基础，从发动机振动信号中提取与"阶次"（order）相关联的现象。其依据在于频域和阶次域的互补性：转速的微小变化会使频域中低阶次的谱分量发生锐变、更高频率处模糊不清；转换到阶次域后所有阶次清晰显示，但共振现象又变得模糊。两个域各有所长，自适应重采样提供了在域之间切换的手段——例如同步平均（synchronous averaging）就要求信号先变换到现象真正重复的域内。

变换的输入是跟踪信号——光电式、磁电式或电涡流探头给出的转速脉冲串，转换为转速（rpm）-时间函数，积分后得到转角-时间函数 $\alpha(t)$。

![转速脉冲串积分成转角-时间函数](/images/resampling-decimation-interpolation/tacho-angle-domain.png)
*（图源：Simcenter Testing Knowledge Base）*

从时域转换至角度域时，要求角度域分辨率 $\Delta\alpha$ 恒定。角度间隔对应的时间间隔随转速变化，因此本质上仍是一次插值——只是插值位置由转速曲线决定，不再均匀。$\Delta\alpha$ 的选取判据是**按最低转速计算**：数据的信息损失首先发生于最低转速处。阈值公式为：

$$\Delta\alpha_{\max} = \frac{360^\circ \times \mathrm{rpm}_{\min}}{60 \, F_s}$$

其中 $\mathrm{rpm}_{\min}$ 为全程最低转速（r/min），$F_s$ 为采样率（Hz），分母 60 完成每分钟到每秒的换算。手册算例：最低转速 500 rpm、采样率 2000 Hz，则 $\Delta\alpha_{\max} = 360 \times 500/(60 \times 2000) = 1.5^\circ$。取小于阈值的角度增量只会产生更多角度域数据点而不增加信息（超量处理）；取大于阈值的增量则导致低转速段的信息损失，且转换回原域后无法恢复。

![时域到角度域的转换步骤](/images/resampling-decimation-interpolation/adaptive-resample-steps.png)
*（图源：Simcenter Testing Knowledge Base）*

无论固定还是自适应重采样，质量控制要点一致：所加的有限冲激响应（FIR）低通滤波器应有**足够的阻带抑制**（把镜像和折叠压到足够低）、**足够小的通带波纹**（原谱成分不被改变），同时滤波器阶数不能高到计算时间不可接受。

## 六、Python 演示：折叠与镜像的数值验证

```python
import numpy as np

fs = 1000                     # 原采样率 Hz
t = np.arange(0, 1, 1/fs)
x = np.sin(2*np.pi*8*t) + 0.7*np.sin(2*np.pi*325*t)   # 8 Hz + 325 Hz

def amp_spec(sig, fs):
    N = len(sig)
    X = np.abs(np.fft.rfft(sig)) / N * 2
    f = np.fft.rfftfreq(N, 1/fs)
    return f, X

# 错误做法：直接隔 5 取 1（不滤波）
f1, X1 = amp_spec(x[::5], fs/5)
top = np.argsort(X1)[::-1][:2]            # 幅值前二的谱峰
for k in sorted(top):
    print(f"不滤波降采样: {f1[k]:.0f} Hz 处出现 {X1[k]:.2f} 幅值峰")

# 正确做法：先低通滤波（移动平均近似 100 Hz 低通）再降采样
kernel = np.ones(5)/5
x_lp = np.convolve(x, kernel, mode='same')
f2, X2 = amp_spec(x_lp[::5], fs/5)
print(f"滤波后降采样: 8 Hz 峰 {X2[np.argmin(abs(f2-8))]:.2f}，"
      f"75 Hz 残留 {X2[np.argmin(abs(f2-75))]:.2f}")

# 升采样插零的镜像
y = np.zeros(2*len(x)); y[::2] = x          # 因子 2 插零
f3, X3 = amp_spec(y, 2*fs)
mask = f3 > 500                             # 只在新带宽里找
print(f"插零升采样: 镜像峰 {f3[np.argmax(X3*mask)]:.0f} Hz")
```

三组数值与理论预测一一对应：

1. **不滤波直接抽点**：8 Hz 真峰（幅值 1.00）旁边出现 75 Hz 虚假谱峰（幅值 0.70）——正是 325 Hz 按 $|325 - 2 \times 200| = 75$ 折叠的结果，且幅值与原 325 Hz 成分相当，验证了"折叠不衰减能量"；
2. **滤波后抽点**：8 Hz 峰保持 1.00，75 Hz 假峰压低至 0.15 左右——5 点移动平均只是低通的近似，阻带抑制有限；工程中应换用阶数更高的 FIR 低通以进一步压低残留；
3. **插零升采样**：8 Hz 在新带宽内映出 992 Hz 镜像（$1000 - 8 = 992$），325 Hz 映出 675 Hz 镜像，且镜像幅值恰为原谱线的一半（因子 2 插零使谱线幅值缩为 $1/n$）——与"镜像谱周期重复"的推导一致。

## 七、四种重采样方式对比

| 方式 | 操作 | 必配滤波器 | 主要风险 | 典型场景 |
| --- | --- | --- | --- | --- |
| **整数降采样** | 每 n 点取 1 点 | 前置低通（截止 < 新带宽） | 高频折叠成虚假低频 | 数据缩减、降低文件体积 |
| **整数升采样** | 点间插 n-1 个零 | 后置低通（截止 < 原带宽） | 镜像谐波混入新带宽 | 改善时域波形、适配 D/A |
| **分数比率** | 先升后降 | 每步各配低通 | 顺序颠倒丢失频带 | 统一不同来源数据采样率 |
| **自适应（角度域）** | 按转速曲线插值 | FIR 低通（阻带+波纹指标） | Δα 取太大丢失高阶信息 | 阶次分析、同步平均 |

::: tip 工程判断
- 降采样前先核对：新带宽是否覆盖关心的最高频率？不覆盖则不应降采样
- 升采样不改变信息量，只改善表示；不能指望它"恢复"细节
- 分数比率固定为先升后降，先降后升丢失的频带无法找回
- 角度域分辨率按全程最低转速确定，高速段自然富余
:::
