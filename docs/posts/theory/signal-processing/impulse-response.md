# 冲激响应函数：FRF 的时域镜像与质量验证

> 锤击模态试验的 FRF 曲线看起来完全正常——峰位清晰、相干良好，模态拟合却给出两个互相打架的极点；换一个软件重新拟合，结果又变了。问题多半不在拟合器，而在数据里藏着拟合器没被告知的缺陷。冲激响应函数（Impulse Response Function, IRF）把 FRF 从频域逆变换回时域，让缺陷以人眼直接可读的形式暴露出来：混入的周期干扰是一条不衰减的等幅正弦，延时回波是一段空白后凭空出现的第二串衰减振荡，噪声是一片抹平峰谷的毛草。本文按 Simcenter Testlab 理论手册第 3.2 节展开：IRF 与 FRF 的变换关系、它与卷积的物理联系、从衰减包络直接读阻尼的手法，以及用它给测量数据做体检的判读清单。

## 一、为什么看完频域还要回头看时域

一组锤击数据交给出差在外的同事复核，FRF 发过去，对方回了一句：“50 Hz 附近峰很干净，但 100 ms 处是不是有点东西？”——他看的不是 FRF，是把 FRF 逆变换回时域的冲激响应。频域曲线是人眼与软件共同的主战场，但它有一个先天盲区：**分辨率的账在频域算，污染的证据却在时域存**。50 Hz 附近的谱峰形状，既可能来自结构真实的 50 Hz 模态，也可能来自信号里混入的 50 Hz 电源谐波——前者在时域是一串按结构阻尼衰减的振荡，后者是一串永不衰减的等幅正弦。两条完全不同的时域曲线，投到频域可能挤在同一条谱峰附近，峰形差异不到一个谱线宽度。

反过来的需求同样常见。LSCE（最小二乘复指数法）这类时域模态拟合器，工作的第一步就是把 FRF 逆变换成冲激响应，再对它做衰减指数拟合——冲激响应不是频域分析的“附属产品”，而是一整类模态参数估计方法的直接原料。看懂它，才能看懂稳定图上的极点从哪来。

先建立一个贯穿全文的类比：**FRF 与冲激响应是同一本账的两种记法**。FRF 像“按月份汇总的年度账单”——每个月（每条谱线）一行，记录那个频率上的收益；冲激响应像“逐笔流水的原始账”——第一笔多大、隔多久来第二笔、每笔怎么缩水，一笔一笔按时序排开。年度账方便横向比较（哪个频率响应强），原始账才能回答时序问题（第一笔什么时候到、后面有没有混进别人的流水）。两种记法一本账，谁也不比谁多信息；但“有没有混进别人的流水”这种事，只在原始账上一眼可读。

具体到数字：一台 32 Hz、阻尼比 2% 的结构，其冲激响应是一串 31.25 ms 一个周期的振荡（1000/32 = 31.25），相邻同向峰值之比为 e 的负 2π×0.02 次方≈ 0.882——每过一个周期缩水约 12%。这两个数字（周期与缩水比）在频域分别变成峰的位置与峰的宽度，变换过程一行傅里叶变换就能往返，但“等幅不缩水”（混入谐波）与“缩水变慢”（阻尼估大）这类异常，在时域是肉眼可判的。
## 二、从 FRF 到冲激响应：一条逆傅里叶变换

理论手册（3.2 节）给出冲激响应函数矩阵 [h](t) 的定义：它代表线性系统输入输出之间在时域上的关系，由频响函数经一次逆傅里叶变换得到：

$$[h](t) = F^{-1}\{[H](k)\}$$

手册同时给出它参与卷积运算的形式（式 3-25）：系统对任意输入的响应，是输入与冲激响应的卷积：

$$y(t) = \int_{-\infty}^{+\infty} h(\tau)\, x(t-\tau)\, \mathrm{d}\tau$$

**这对公式回答的问题是：知道了“每本账合起来什么样”（FRF），怎么还原“逐笔流水”（IRF），以及流水账怎么用来预测任意一笔输入的后果。** 其中 F 的 -1 次幂对应数学里的逆离散傅里叶变换，[H](k) 就是上一节测得的 FRF 矩阵——在 Testlab 的实现里，这一步就是对每条 FRF 谱线做一次 IFFT；卷积式里的 h(τ) 对应物理里“结构对一记理想敲击的记忆”：敲击结束后结构如何随时间振荡衰减，这份“记忆”与未来任意输入逐点相乘积分，就得到全部响应。卷积并不好算，但变换到频域它变成乘法——这正是频域分析流行的原因，也是两种记法来回切换的全部动机。

::: info 核心概念
- **冲激响应函数（Impulse Response Function, IRF）**：系统对单位脉冲输入的响应，时域形式；与频域的 FRF 构成一对傅里叶变换。求 IRF 至少需一个参考通道（输入）与一个响应通道（输出）
- **卷积（Convolution）**：线性时不变系统“输入→输出”的普适运算，频域对应乘法 Y = H·X
- **线性时不变（LTI）**：卷积关系成立的前提——线性（叠加原理）加时不变（今天敲和明天敲结果相同）。模态分析的全部理论都建立在这个假设上，冲激响应也因此是系统完整的“指纹”
:::

*(图源：Simcenter Testing Knowledge Base，理论手册 2.2 节)*

一个必须当场验证的性质是**因果性**：真实结构的冲激响应在敲击发生前（t < 0）必须恒为零——结果不能先于原因。这句话在频域没有任何直观对应物，但在时域是一眼的事。下面的数值实验把一条双模态 FRF（32 Hz/2%、96 Hz/1%）逆变换回时域，检查 t < 0 段的数值：

```python
import numpy as np

fs, T = 4096, 4.0                      # 采样率与总时长
N = int(fs*T)
f = np.fft.rfftfreq(N, 1/fs)
H = np.zeros(len(f), complex)          # 双模态 FRF（留数取 1）
for f0, z in [(32.0, 0.02), (96.0, 0.01)]:
    wn = 2*np.pi*f0; s = 2j*np.pi*f
    H += 1/(2j*wn)*(1/(s + z*wn - 1j*wn*np.sqrt(1-z**2))
                  - 1/(s + z*wn + 1j*wn*np.sqrt(1-z**2)))

h = np.fft.irfft(H, N)                 # 逆变换得冲激响应
t = np.arange(N)/fs
print("t<0 段（取首 10 点）最大 |h| =", np.abs(h[:10]).max())
print("全局峰值 |h|max             =", np.abs(h).max())
print("峰值出现时刻 t_peak        =", t[np.argmax(np.abs(h))]*1000, "ms")
```

运行输出：t < 0 段最大幅值 9.0e-7，全局峰值 1.12e-6——因果性成立（残值是数值精度而非物理）。但注意那个“取首 10 点”：IFFT 默认把 t = 0 放在数组开头，负时间绕到数组末尾去了。如果直接把数组当时间轴画图，会看到“响应在敲击前就开始”的假象——这是循环移位问题，判读前先把后半段翻到前面。峰值出现在 3.9 ms，即两模态合成的第一个波包。
## 三、冲激响应怎么读：周期、衰减率与阻尼

冲激响应不是一条需要“看起来漂亮”的曲线，它是可以逐项读出参数的数表。对单模态主导的段落，相邻同向峰的间隔给出阻尼固有频率，峰值之比给出阻尼比。**这个关系回答的问题是：不看频域峰宽，能不能直接从“每周期缩水多少”读出阻尼？** 其中相邻峰值比对应物理里一个振荡周期内的能量耗散——衰减包络每过一个周期就乘一次这个因子，取对数后它就是阻尼比的 2π 倍：

$$\frac{A_{k+1}}{A_k} = e^{-\zeta\omega_n T_d}, \qquad \delta = \ln\frac{A_k}{A_{k+1}} = 2\pi\zeta$$

δ 称为对数衰减率（logarithmic decrement），无量纲。它的来历只有一步：包络指数 ζω_n 乘周期 T_d ≈ 2π/ω_n。对上面 32 Hz/2% 的例子：δ = 2π×0.02 = 0.126，每周期衰减 12%——与第一节给出的 0.882 缩水比是同一句话的两种说法。

![频响函数矩阵的频域输入输出关系：输出向量等于 FRF 矩阵乘以输入向量](/images/impulse-response/fig2.png)

*(图源：Simcenter Testing Knowledge Base，理论手册 3.2 节)*

用双模态冲激响应（32 Hz 分量占主导）实测一遍：
```python
import numpy as np

fs, T = 4096, 4.0
N = int(fs*T)
f = np.fft.rfftfreq(N, 1/fs)
H = np.zeros(len(f), complex)
for f0, z in [(32.0, 0.02), (96.0, 0.01)]:
    wn = 2*np.pi*f0; s = 2j*np.pi*f
    H += 1/(2j*wn)*(1/(s + z*wn - 1j*wn*np.sqrt(1-z**2))
                  - 1/(s + z*wn + 1j*wn*np.sqrt(1-z**2)))
h = np.fft.irfft(H, N); t = np.arange(N)/fs

# 按 32 Hz 周期分箱，取每箱最大值 -> 峰值序列
m = (t > 0.02) & (t < 0.4)
seg, ts = h[m], t[m]; per = 1/32.0
pk_t, pk_v = [], []
k = 0
while 0.02 + k*per < 0.4:
    mm = (ts >= 0.02+k*per) & (ts < 0.02+(k+1)*per)
    j = np.argmax(seg[mm])
    if seg[mm][j] > 0:
        pk_t.append(ts[mm][j]); pk_v.append(seg[mm][j])
    k += 1
pk_t, pk_v = np.array(pk_t), np.array(pk_v)
print("峰间隔(ms):", np.round(np.diff(pk_t[:6]*1000), 2), "理论", round(1000/32, 2))
print("相邻峰比:", np.round(pk_v[1:6]/pk_v[:5], 3), "理论", round(np.exp(-2*np.pi*0.02), 3))
sl = np.polyfit(pk_t[:10], np.log(pk_v[:10]), 1)[0]
print("回归阻尼比 zeta =", round(-sl/(2*np.pi*32), 4), "(真值 0.02)")
```

运行输出：峰间隔 31.25~31.49 ms（理论 31.25），相邻峰比 0.869~0.874（理论 0.882，略低是因为 96 Hz 分量在最初几十毫秒内还有贡献），对前 10 个峰做包络回归得 ζ = 0.0213，与真值 0.02 偏差 6.5%——在两条谱线之间读峰宽的 3dB 带宽法达不到这个精度时，时域回归是一条独立的校核路径。这也正是 LSCE 一类时域拟合器的第一步：对冲激响应（实践上常对相关函数，以压制噪声）拟合衰减复指数之和，极点从指数的复频率里读出。
## 四、冲激响应作为质量体检：三类常见病症

如果说第三节是“从健康曲线上读参数”，这一节是“从病态曲线上读病因”。频域里纠缠在一起的三类污染，到时域各自现形。

**病症一：混入周期干扰——不衰减的尾巴。** 结构自身的振荡按指数规律衰减，32 Hz/2% 的模态时间常数 τ = 1/(ζω_n) = 0.249 s，0.25 s 后只剩约 2.7%。若冲激响应在两三个时间常数之后仍有等幅振荡，那一段已经不是结构——是电源谐波、转速基频或某个没关掉的设备把自己的频率“续”在了你的数据里。判据简单：尾段包络不归零，IRF 无效；先回去处理干扰源或做谐波去除，再谈拟合。

**病症二：延时回波——空白之后卷土重来。** 敲击声经地面、墙壁或附近大质量反射回来再次激励结构，冲激响应表现为：正常衰减到接近零，几十毫秒后又冒出一串新的衰减振荡。这与第一节的“账本类比”对上：流水账里隔了一段空白出现第二组流水，频域账单上只能看到 50 Hz 峰“变宽了一点”或相干“降了一点”，原始账上却是明明白白两笔。反射路径的时延就等于第二串振荡的起始时刻，直接可量。

**病症三：噪声——整条曲线的毛草。** FRF 里的随机噪声经逆变换平摊到全部时间轴上，形成叠加在衰减振荡上的均匀毛草。它与病症一的区别在于无周期结构、幅度随机；与健康数据的区别在于尾段本应归零而它不归零。噪声大表明平均次数不足或激励能量不够——这些判断在频域需要看相干逐段核对，在时域一条曲线全看见。

![H1 估计的噪声模型：噪声 N 仅叠加在输出端，Y(k) = H(k)X(k) + N(k)](/images/impulse-response/fig3.png)

*(图源：Simcenter Testing Knowledge Base，理论手册 3.2 节)*

噪声如何进入冲激响应，可以做定量实验：对每条谱线的输出加 5% 相对噪声（对应 H1 估计的噪声模型——噪声只在输出端），做 20 次平均后逆变换：
```python
import numpy as np

fs, T = 4096, 4.0
N = int(fs*T)
f = np.fft.rfftfreq(N, 1/fs)
H = np.zeros(len(f), complex)
for f0, z in [(32.0, 0.02), (96.0, 0.01)]:
    wn = 2*np.pi*f0; s = 2j*np.pi*f
    H += 1/(2j*wn)*(1/(s + z*wn - 1j*wn*np.sqrt(1-z**2))
                  - 1/(s + z*wn + 1j*wn*np.sqrt(1-z**2)))
rng = np.random.default_rng(1); M = 20
Sxy = np.zeros(len(f), complex)
for _ in range(M):                       # 模拟 M 次平均的互谱累计
    X = rng.standard_normal(len(f)) + 1j*rng.standard_normal(len(f))
    Ns = np.sqrt(0.05)*np.abs(H*X)*(rng.standard_normal(len(f))
             + 1j*rng.standard_normal(len(f)))/np.sqrt(2)
    Sxy += np.conj(X)*(H*X + Ns)
H1 = Sxy/(M*2.0)                         # |X| 平方的期望为 2
err = np.abs(H1-H)/np.abs(H)
print("H1 相对误差: 中位 %.3f / 95分位 %.3f" % (np.median(err), np.percentile(err, 95)))
e = np.abs(np.fft.irfft(H1, N) - np.fft.irfft(H, N))
print("IRF 误差峰值 %.2e (h 峰值 %.2e)" % (e.max(), np.abs(np.fft.irfft(H, N)).max()))
```

运行输出：FRF 相对误差中位数 0.160、95 分位 0.447；逆变换后 IRF 误差峰值为 1.1e-7，约为信号峰值的 10%。两个数各有含义：频域误差分布不均（共振谱线信噪比高、反共振谷误差大），逆变换把这份不均匀摊到时域——表现为衰减后段的毛草抬高。平均次数按开方倍压噪声：20 次平均后同样的噪声水平只剩约 1/4.5 的谱线误差，尾段毛草同比例下降。
## 五、在 Simcenter Testlab 中的路径

冲激响应在 Testlab 里不是专门的工作表，而是“谱数据的时域视图”，常用三条路径：

1. **显示层直接切换**：在 Navigator 或显示窗中选中 FRF 数据块，右键纵轴 → **Processing → Inverse FFT**（与 Integrate、Section Scaling 同一组菜单），当前显示切换为冲激响应；不改变原数据，仅供判读。这也是本文“体检”用法的标准动作——FRF 看完顺手 IFFT 一眼。
2. **Time Signal Calculator**：**Tools → Add-ins** 勾选 Time Signal Calculator（26 tokens）后，在公式表用 FFT 类函数（如 FFT_INVERSE，与倒频谱文章中的用法同族）把 FRF 行变换为时域行，输出可保存为独立 trace，便于批量处理与对比。
3. **模态拟合内部**：不必手动生成——LSCE、Polymax 等时域/频域拟合器在内部完成 FRF 到 IRF（或相关函数）的转换，稳定图上的候选极点正是对这些衰减指数的拟合结果。理解第三节的意义在于：知道拟合器在拟合什么，才能判断它给出的极点可不可信。

判读时的两个操作细节：其一，冲激响应的长度由 FRF 的频率分辨率决定（T = 1/Δf），分辨率 0.25 Hz 对应 4 s 时域记录——想看清尾段衰减，先保证频域分辨率够细；其二，IFFT 的时域原点在数组首端、负时间绕到末端，画图前需做循环移位（numpy 中用 np.roll 或 fftshift，Testlab 显示已自动处理），否则会误读出“敲击前就有响应”。

## 六、小结

冲激响应与 FRF 是同一系统的两本账：频域账按频率汇总，时域账按时间逐笔。变换本身只是一次 IFFT，但换到时域视图后，三类频域纠缠的污染各自现形——等幅尾巴是周期干扰、空白后的第二串振荡是延时回波、均匀毛草是噪声；健康曲线上，峰间隔读频率、包络回归读阻尼（双模态数值实验回归 0.0213 对真值 0.02），这正是时域模态拟合器的第一步。生产流程里，FRF 测完顺手做一次 Inverse FFT 检查尾段，是成本最低的质量把关。

## 一句话记住

FRF 与冲激响应一本账两种记法：IFFT 翻回时域，等幅尾巴查干扰、空白后回声查反射、满篇毛草查平均；健康时峰距读频率、包络回归读阻尼——频域看不清的，时域一眼见分晓。
