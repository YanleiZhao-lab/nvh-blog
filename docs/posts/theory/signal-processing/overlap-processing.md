# 重叠处理：50% 重叠的数学与统计依据

> 频谱平均时相邻分析块共用一部分数据，称为重叠（Overlap）处理。重叠是否有效取决于是否加窗：不加窗时重叠不引入新的统计信息；加汉宁窗后，重叠可恢复窗端部被抑制的数据。50% 重叠是汉宁窗满足恒定重叠相加（COLA）条件的最小步距，同时相邻块功率谱相关仅 1/36，平均效果接近相互独立的平均。本文给出上述结论的推导与验证，以及随机、正弦、瞬态三类信号的重叠设置判据。

## 一、重叠的定义：相邻分析块共用数据

做 FFT 谱平均时，分析器每次取一段固定长度（帧长 T，N 个采样点）的时间记录做变换，然后前进一段步距、再取下一段。**重叠处理（Overlap Processing）**就是每次前进的步距小于帧长：相邻两块有一部分数据来自同一段波形。步距与重叠率的关系为

$$H = T\,(1 - \alpha)$$

其中 H 为步距（s），α 为重叠率（%），T 为帧长（s）。50% 重叠即第二块从第一块的中点开始，两块各有一半数据相同。

![重叠处理示意：相邻 FFT 块共用部分数据](/images/overlap-processing/overlap-diagram.png)

*（图源：Simcenter Testing Knowledge Base）*

LMS 理论手册的表述：历次 FFT 所取的时间记录并非彼此完全独立，而是取部分重叠。先做一个时间上的估算，设帧长 T = 2 s、平均 5 次：

| 设置 | 每块前进 | 5 块总时长 | 说明 |
| --- | --- | --- | --- |
| **无重叠 (0%)** | 2 s | 10 s | 相邻块数据完全独立 |
| **50% 重叠** | 1 s | 6 s | 同样 5 次平均，采集时间缩短 4 s |
| **66.7% 重叠** | 2/3 s | 4.67 s | 步距为帧长的 1/3 |
| **75% 重叠** | 0.5 s | 4 s | 每块 3/4 的数据与相邻块重复 |

对稳态随机信号的长时间监测，采集时间的缩短直接体现为测试效率。

## 二、重叠起作用的前提：窗函数的端部权重损失

不加窗时重叠没有统计意义。手册原文：如果时域数据完全没有经过加窗（加权），重叠处理并未计入任何新的数据，因而对谱估计没有任何统计上的改善。矩形窗下每块内所有采样点权重均为 1，相邻块重叠部分以相同权重被重复计入，统计信息量不变，相当于同一批数据被统计了两次。

加窗后情况不同。汉宁窗（Hanning window）两端权重为零、中心权重最大：

$$w(n) = 0.5 - 0.5\cos\left(\frac{2\pi n}{N}\right), \quad n = 0, 1, \dots, N-1$$

无重叠时，每个分析块前 20% 和后 20% 的数据被窗函数压到接近零。手册的表述是：在无重叠处理情况下，每一采样周期前 20% 和后 20% 的数据实际上大部分被舍弃掉了，它们对于平均处理而言几乎不提供任何贡献。

![汉宁窗下无重叠处理时的数据损失](/images/overlap-processing/hanning-no-overlap-loss.png)

*（图源：Simcenter Testing Knowledge Base）*

### "至少 30% 重叠"的来源

汉宁窗在起点 w(0) = 0，在 20% 帧长处幅值为

$$w(0.2N) = 0.5 - 0.5\cos(0.4\pi) \approx 0.345$$

即块首尾 20% 的数据权重不足中心值的一半，对平均的贡献很小。下一块从本块 70% 处开始（30% 重叠）时，本块尾部被压低的样本恰好落在下一块的中心高权重区，被重新利用一次。因此手册给出的判据是：施加至少 30% 的重叠，即可挽回数据的损失；这不但加快数据采集过程（对同样的平均次数而言），也使结果在统计意义上更加可信，因为所有采集数据被利用的程度更为均衡。

![施加约 30% 重叠后数据被均衡利用](/images/overlap-processing/overlap-30-percent-recover.png)

*（图源：Simcenter Testing Knowledge Base）*

30% 是恢复数据利用率的下限；50% 则是数据权重严格均匀的最小步距，依据是恒定重叠相加条件。

## 三、50% 的数学性质：COLA 恒等式

将两帧错开 N/2 的汉宁窗逐点相加。第一窗在位置 n 处取值 w(n) = 0.5 − 0.5cos(2πn/N)；同一数据点在第二窗中的坐标为 n − N/2，错开半个帧长使余弦相位增加 π。两窗之和为

$$w(n) + w\left(n + \frac{N}{2}\right) = 0.5 - 0.5\cos\frac{2\pi n}{N} + 0.5 - 0.5\cos\left(\frac{2\pi n}{N} + \pi\right)$$

代入 cos(θ + π) = −cosθ（θ = 2πn/N），两个余弦项相消：

$$w(n) + w\left(n + \frac{N}{2}\right) = 1$$

即 50% 重叠的汉宁窗逐点相加恒等于 1：每个采样点在相邻两块中的权重之和严格相等，没有任何数据点被系统性加权或抑制。这就是**恒定重叠相加（COLA, Constant Overlap-Add）条件**。

需要指出，50% 是汉宁窗满足 COLA 的**最小**步距，但不是唯一步距。对步距 N/K（K = 2, 3, 4，对应重叠率 50%、66.7%、75%），K 个错位汉宁窗的叠加和恒为 K/2：

$$\sum_{k=0}^{K-1} w\left(n + \frac{kN}{K}\right) = \frac{K}{2}$$

数值验证（N = 48000 点）：K = 2、3、4 时叠加和分别为 1.000、1.500、2.000，全区域内无起伏。因此 66.7% 与 75% 重叠同样满足权重均匀。50% 成为常用设置的原因在于统计与计算代价：在满足 COLA 的前提下，重叠率越高（步距越小），块间相关性越高（见下节），且单位数据量的 FFT 次数成比例增加。作为对比，Blackman 窗（余弦项含二次谐波）在 50% 步距不满足 COLA（叠加和在 0.68 与 1.00 之间起伏），在 75% 步距满足（叠加和恒为 1.68）。

::: info 核心概念
- **重叠率**：相邻分析块共用数据的比例，步距 = 帧长 ×（1 − 重叠率）
- **COLA 条件**：若干错位窗逐点相加为常数。汉宁窗在步距 N/K（K ≥ 2 的整数）下满足，叠加和为 K/2；矩形窗任意步距满足（但重叠无统计意义）
- **有效独立样本数**：重叠块间谱值仍相关，决定平均效果的是独立信息量而非表观块数
:::

## 四、重叠的统计代价：块间相关与方差改善

重叠并非没有代价：相邻块共用数据，两次 FFT 的谱值必然相关。衡量相关性的量是错位窗的内积与窗能量之比

$$\rho = \frac{\sum_{n} w(n)\, w(n+H)}{\sum_{n} w^2(n)}, \quad H = \text{步距（点）}$$

ρ 的物理意义是两个分析块共用数据的加权占比。对随机信号，相邻块功率谱估计的相关系数为 ρ²（幅度谱为 ρ）。对汉宁窗精确计算（N = 10000 点数值积分）：

| 重叠率 | 步距 | 相邻块窗相关 ρ | 功率谱相关 ρ² | 同数据量块数增益 | 方差改善 |
| --- | --- | --- | --- | --- | --- |
| **0%** | N | 0 | 0 | 1× | 基准 1/M |
| **25%** | 0.75N | 0.008 | <0.001 | 1.33× | 接近独立 |
| **50%** | 0.5N | 0.167 | 0.028 | 2× | 接近独立（方差约增 6%） |
| **66.7%** | N/3 | 0.471 | 0.222 | 3× | 增益明显下降 |
| **75%** | 0.25N | 0.659 | 0.434 | 4× | 增益大幅下降 |

从 0% 到 50%，块数加倍而块间功率谱相关仅 0.028，平均效果接近块数加倍后的独立平均；从 50% 提高到 75%，块数再次加倍，但 ρ² 已达 0.434，新增块中重复信息占比很高。重叠换块数的收益在 50% 之后快速衰减。

用 Monte Carlo 白噪声实验验证（M = 32 块汉宁窗平均，比较中心频段谱线方差）：

```python
import numpy as np

rng = np.random.default_rng(42)
N = 4096                       # 帧长（点）
M = 32                         # 平均块数
w = 0.5 - 0.5*np.cos(2*np.pi*np.arange(N)/N)   # 周期汉宁窗

def line_variance(overlap):
    # 白噪声下 M 块平均功率谱的中心频段方差
    hop = int(N*(1-overlap))   # 步距
    var = []
    for _ in range(300):
        x = rng.standard_normal(N + (M-1)*hop)
        pows = []
        for k in range(M):
            X = np.fft.rfft(x[k*hop:k*hop+N] * w)
            pows.append(np.abs(X)**2)
        var.append(np.mean(pows, axis=0)[600:1400].var())
    return np.mean(var)

v0, v50 = line_variance(0.0), line_variance(0.5)
print(f"无重叠   M={M} 方差: {v0:.0f}")
print(f"50%重叠  M={M} 方差: {v50:.0f}")
print(f"方差比: {v50/v0:.3f}  理论 (1+2*ρ²)/1 = {1+2/36:.3f}")
```

运行结果：方差比约 1.06，与理论值 1 + 2ρ² = 1.056 一致——在平均块数相同的条件下，50% 重叠的 32 块平均与 32 块相互独立的平均效果接近，而采集时间缩短一半。

另一个方向：固定数据总长度时，无重叠可切 32 块，50% 重叠可切 63 块（相邻块相关 ρ² = 1/36，相隔两块以上的块相互独立），两种处理的谱线方差之比为

$$\frac{\mathrm{Var}_{63}}{\mathrm{Var}_{32}} = \frac{32}{63}\left(1 + 2\rho^2 \cdot \frac{62}{63}\right) \approx 0.54$$

Monte Carlo 实测该比值约 0.54，与理论一致：同样长度的记录经 50% 重叠处理后，谱线方差约降低一半。这是重叠处理在稳态随机信号分析中的主要价值。

::: warning 工程注意
上述方差收益只属于随机信号。正弦、阶次等确定性信号做 RMS 谱平均时，重叠块间相关系数为 1：重复数据被原样平均，表观平均次数的增加不带来精度提升，只是虚增了报告中的"平均次数"。瞬态信号（冲击、起点明确的扫频）不宜使用重叠：触发同步的分段方式已保证各块独立，重叠会把同一事件重复计入。
:::

## 五、按信号类型确定重叠设置

| 信号类型 | 推荐重叠 | 依据 |
| --- | --- | --- |
| **稳态随机**（路噪、稳态工况振动） | 50%～75% | ρ² ≤ 0.43，块数换方差的收益仍为正；数据越长平均越充分 |
| **缓变工况**（升降速扫频） | 由帧长与转速变化率确定 | 帧内转速变化应足够小；重叠用于补偿汉宁窗端部损失 |
| **正弦/阶次** | 0% 或少量 | 确定性信号无统计平均需求 |
| **瞬态/触发采集** | 0% | 触发即独立，重叠会重复计入同一事件 |

::: tip 设置原则
- 默认 50%：汉宁窗 COLA 恒等式的最小步距，块间相关 ρ² = 1/36，平均效果接近独立平均，采集时间缩短一半
- 稳态随机需要更快收敛时用 66.7%～75%，接受块间相关上升的代价
- 正弦、瞬态、触发类信号设为 0%
- 方差分析只适用于功率类平均（PSD、自功率谱）；先明确要平均的量
:::

## 六、小结

50% 重叠的常用地位基于三层依据：其一，汉宁窗端部各 20% 的数据权重接近零，手册判据为至少 30% 重叠可恢复数据利用率；其二，50% 是汉宁窗满足 COLA 恒等式 w(n) + w(n+N/2) = 1 的最小步距（66.7%、75% 同样满足，叠加和分别为 1.5 与 2.0），数据权重严格均匀；其三，50% 重叠时相邻块功率谱相关仅 1/36，平均效果接近相互独立的平均，固定数据长度下谱线方差约降至无重叠的 0.54 倍。提高重叠率之前，应确认统计对象是功率类平均，并权衡更高重叠率下块间相关上升、边际收益递减的代价。
