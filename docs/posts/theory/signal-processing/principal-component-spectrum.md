# 主分量谱 PCS：多参考数据的降维视图

> 一台怠速整机摆了四个参考加速度计，软件算出四条自谱叠在一张图上，每个共振峰都出现四次——到底有几个独立振源在干活？再叠加相干函数，通道两两之间的线密密麻麻，越看越乱。本文介绍主分量谱（Principal Component Spectrum, PCS）：对每一根谱线的互谱矩阵做特征分解，把 N 个通道的响应压缩成少数几条"不相关的主分量"，奇异值突降的位置就是独立源个数的判据。像合唱排练里把混在一起的人声分声部归队——每个声部内部怎么变不重要，先数清有几个声部；主分量之间的相干恒等于零，正好对应"分声部"这件事的数学定义。本文给出分解公式、与 CMIF 的关系、虚拟相干的配合用法、Testlab 中的计算路径，以及一段复现真实传播方向的 numpy 演示。

## 一、为什么四个参考点会"数不清"振源

先看工程现场最典型的一幕。整车怠速异响排查，前后左右布了四个参考加速度计，采集、FFT、平均，一气呵成。分析时把四条自功率谱叠到同一张 colormap 上，问题来了：330 Hz 附近四条谱都有峰，340 Hz 附近又都有峰——这两个峰到底是两个独立的源（比如发动机二阶与辅泵叶频），还是同一个源被两个接近的模态放大了两次？自谱只回答"每个通道有多少能量"，通道之间谁是因谁是果、谁跟谁一回事，它一个字都不说。

把四个通道两两做相干函数呢？6 条曲线画出来，330 Hz 处通道 1-2 相干 0.98、通道 3-4 相干 0.95，但 340 Hz 处全部两两相干都高于 0.9——因为通道间相干只能逐对看，N 个通道要 N(N-1)/2 对组合，而且"都相关"既可能是"一个源传到各处"，也可能是"两个源恰好都遍布各处"。通道越多，这种两两视图越接近一团乱麻。

需要的不是更多曲线，而是一次性回答"最少几个不相关的源能解释这堆数据"的降维工具。主分量谱（Principal Component Spectrum，PCS）就是干这个的：它不新增测量，只是把已有 N 个参考通道的信息重新组织——在每一根谱线上，把互谱矩阵对角化，得到的特征值按大小排成一张谱，第 r 个特征值就是第 r 个主分量的自谱。特征值从"显著"跌到"贴地"的位置，就是独立源数目的指示。

打个生活比方：合唱团在台上齐唱，台下的录音是所有声部混在一起的波形，你听不出人数。但只要统计各段录音之间的相关性做一次"分声部"——男高、男低、女高、女低各自归队——归队之后数声部就行了：四个声部就是四个"主分量"，每个声部内部谁唱轻谁唱重是混合矩阵的事，与声部数目无关。PCS 对多参考数据做的正是这件事：**信号组里能观察到的独立源数目，等于主分量谱里"还立得起来"的条数**。

## 二、从互谱矩阵到主分量：一条谱线上的分解

### 具体数字先于符号

先看一个可复现的数值实验（完整代码见第五节）：两个独立源，38 Hz 调幅与 51 Hz 调幅，各自按不同的"传播向量"混进 4 个测点。在 38 Hz 这根谱线上对 4×4 互谱矩阵做特征分解，特征值为：

$$\lambda_1 = 4.09\times10^{5},\quad \lambda_2 = 0.72,\quad \lambda_3 = 0.43,\quad \lambda_4 = 0.30$$

第一条比第二条大近六个数量级——4 个通道的响应实际上由 1 个源主导，后面三个特征值全是噪声地平线。如果激励里有两个独立源各自显著，就会看到前两条特征值并肩立着、从第三条开始贴地。**特征值谱的"断崖"读源数，这就是 PCS 的第一用法。**

### 分解公式

**导读**：这个公式回答的问题是"N 个混在一起的通道信号，如何线性重组为一组互不相干的信号"——其中 $[U]$ 对应物理里的"分声部归队表"：每列是一个主分量在各通道上的混合比例（也就是该源传到各测点的相对大小与相位）。

对一组信号 $X_1,\dots,X_n$，假定它们可以由一组完全不相关的信号通过线性组合来描述，这后一信号组 $X'_1,\dots,X'_n$ 就称为原信号组的主分量。在每根谱线 $k$ 上，基本关系式为（LMS 理论手册 3.2 节式 3-20）：

$$
\{X'(k)\} = [U]^H\{X(k)\}, \qquad \{X(k)\} = [U]\{X'(k)\}, \qquad [U]^H[U] = [I]
$$

$$
[S'_{xx}] = [U]^H[S_{xx}][U]
$$

其中 $[S'_{xx}]$ 为以主分量自功率谱为对角元素的对角线矩阵；$\{X'(k)\}$ 为不相关的主分量信号组；$[U]$ 为转换酉矩阵（unitary matrix），上标 $H$ 表示共轭转置。

::: info 核心概念：主分量
主分量（Principal Component）是原信号组经酉变换得到的、两两之间完全不相关的新信号组。主分量之间的相干函数值精确地等于 0——因为按定义，它们之间是完全不相关的。在理念上，主分量就是信号组中能观察的主要独立机械源。矩阵 $[U]$ 的每一列给出该主分量在各原始通道上的"分布形状"，可用于动画显示对应每一主分量的工作变形（作为频率的函数）。
:::

**导读**：上面第二个式子回答的问题是"重组之后各主分量自己的谱长什么样"——其中对角矩阵 $[S'_{xx}]$ 的对角元 $\lambda_r(k)$ 对应物理里的"第 r 个独立源在这根谱线上的自谱"，把每根谱线的 $\lambda_r$ 连成曲线就是主分量谱。

推导只有两步，每步的物理意义都很直白。第一步，"不相关"翻译成数学就是互谱为零：主分量的互谱矩阵 $[U]^H[S_{xx}][U]$ 必须是对角阵，对角元依次记为 $\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_n$。第二步，什么样的 $[U]$ 能做到？线性代数给出答案：$[S_{xx}]$ 是共轭对称矩阵，其特征向量构成一个酉矩阵，用特征向量作变换恰好把矩阵对角化，特征值就是对角元。所以"求主分量"与"对互谱矩阵做特征分解（等价于奇异值分解 SVD）"是同一件事的两种说法，主分量谱就是逐谱线特征值 $\lambda_r(k)$ 的集合。

### 主分量谱回答的三个问题

1. **有几个独立源？** 看特征值谱的断崖：第 r 条之后陡降几个数量级，独立源数目就是 r（受信噪比限制，弱源可能埋在地平线下）。手册给出的主要应用正是"确定信号组中不相关机械源的数目"，熟知的例子是 MIMO 频响函数估计中多输入激励源的鉴别。
2. **每个源的空间分布什么样？** $[U]$ 的第 r 列就是第 r 个主分量的通道分布向量，可以驱动动画显示对应的工作变形。数值实验里 PCS 参考向量 $U[:,0]=[0.733,\ 0.488,\ 0.244,\ -0.407]$，与真实传播方向 $[0.732,\ 0.488,\ 0.244,\ -0.407]$ 对到千分位。
3. **每个源贡献了某通道的多大比例？** 这要配合虚拟相干（见第四节），单看特征值只能知道总量，不知道去向。

## 三、与 CMIF 的关系：同一分解的两种读法

**导读**：这个关系式回答的问题是"PCS 与模态分析里的复模态指示函数是什么关系"——其中 $[H]$ 对应物理里的"FRF 矩阵"：对 FRF 矩阵做 SVD 与对响应互谱矩阵做特征分解共享同一个数学骨架，读出的东西不同。

模态分析里的 CMIF（Complex Mode Indicator Function，复模态指示函数）对每一谱线的 FRF 矩阵 $[H](k)$ 作奇异值分解：$[H] = [U][\Sigma][V]^H$。LMS 理论手册 15.2 节指出，比较分解式可知，FRF 矩阵中的模态振型向量与模态参预因子向量由此被正则化为单位标尺向量；对任一模态而言，固有频率就发生在奇异值最大的频率点。CMIF 曲线取对数标尺绘制，清晰的峰指示出模态，与参考（输入）自由度数目相同的 CMIF 曲线可以并排画在一起。

![由 CMIF 曲线选择模态频率举例：多条奇异值曲线并排，峰指示模态](/images/principal-component-spectrum/fig_cmif_curves.png)

*（图源：LMS Test.Lab 理论手册 15.2 节）*

PCS 与 CMIF 的分工在于输入矩阵不同：PCS 对**响应互谱矩阵** $[S_{xx}]$ 分解，用于运行状态下的源数目鉴别；CMIF 对 **FRF 矩阵**分解，用于锤击/激振器试验中的模态指示。数学骨架完全一致——都是逐谱线的特征/奇异值分解，第一条曲线都挑出"最强的一个东西"（最强独立源 / 最强模态），后续曲线依次给出次强者。在模态频率选定之后，由分解式可得模态参预因子矩阵的复共轭与尚无标尺的模态振型向量，并生成对应每一模态的增强 FRF——实际上是解耦的单模态频响函数，可以再用 SDOI 法（如圆拟合）改善频率估计精度、求阻尼比。

![CMIF 及相应的增强 FRF 举例](/images/principal-component-spectrum/fig_cmif_enhanced_frf.png)

*（图源：LMS Test.Lab 理论手册 15.2 节）*

回到第一节的怠速例子：如果怀疑的不是"几个源"而是"几阶模态"，看 CMIF；如果是运行数据、没有测力，看 PCS。两者的读图习惯互通：盯住奇异值曲线的层数与断崖。

## 四、虚拟相干：给每个源算"贡献比例"

**导读**：这个公式回答的问题是"某个主分量在某通道总能量里占多大比例"——其中分子上的互谱 $S'_{ij}$ 对应物理里的"第 i 个源传到第 j 个通道的分量"，分母对应"该通道的总谱乘以该源的总谱"。

特征值谱数清了源，但 330 Hz 的峰在通道 3 里占多少、在通道 1 里占多少，PCS 本身不说。补上这个信息的标准工具是虚拟相干（Virtual Coherence）：一信号与主分量之间的常相干（LMS 理论手册 3.2 节式 3-19）：

$$
\gamma^2_{v_{ij}}(k) = \frac{|S'_{ij}(k)|^2}{S'_{ii}(k)\, S_{jj}(k)}
$$

其中 $S'_{ii}$ 为主分量 $X'_i$ 的自功率谱，$S'_{ij}$ 为信号 $X_j$ 与主分量 $X'_i$ 之间的互功率谱。虚拟相干的值总在 0 与 1 之间，且任意信号与所有主分量之间虚拟相干的和也在 [0, 1] 域内——这后一条性质使"逐源贡献占比"可以像切蛋糕一样分干净：通道 j 在谱线 k 处的总自谱，可以按各主分量的虚拟相干拆成各源贡献的份额，加起来不多不少。数值实验里，4 个通道与第一主分量的虚拟相干全部等于 1.000——因为该仿真里 38 Hz 处只有一个源，它当然是每个通道该谱线处的全部能量。

与常相干、重相干、偏相干放在一起看，四种相干函数各管一件事：常相干看两信号的线性关系，重相干看一个输出与一组输入的整体因果，偏相干在排除其余信号影响后看"净"关系，虚拟相干则把输出拆到各主分量头上。做源数目鉴别时，PCS 的特征值谱给结论，虚拟相干给分解明细，两者配套使用。

## 五、numpy 演示：从四个混合通道读回一个源

```python
import numpy as np

fs, T = 4096, 4.0
t = np.arange(0, T, 1/fs)
f1, f2 = 38.0, 51.0                      # 两个独立源频率
rng = np.random.default_rng(7)
s1 = np.sin(2*np.pi*f1*t + 0.3)*(1 + 0.25*np.sin(2*np.pi*1.5*t))   # 源1：调幅
s2 = np.sin(2*np.pi*f2*t)*(0.6 + 0.4*np.cos(2*np.pi*0.8*t + 1.1))  # 源2：调幅
A = np.array([[0.9, 0.4], [0.6, -0.7], [0.3, 0.8], [-0.5, 0.6]])  # 传播矩阵
X = A @ np.vstack([s1, s2]) + 0.02*rng.standard_normal((4, len(t)))

N = 2048; win = np.hanning(N)            # Welch 平均互谱矩阵
freqs = np.fft.rfftfreq(N, 1/fs); K = freqs.size
S = np.zeros((4, 4, K), complex); nblk = 0
for b in range(0, len(t)-N, N//2):
    Xk = np.fft.rfft(X[:, b:b+N]*win, N, axis=1)
    for kk in range(K):
        S[:, :, kk] += np.outer(Xk[:, kk], Xk[:, kk].conj())
    nblk += 1
S /= nblk

i = np.argmin(abs(freqs - f1))           # 38 Hz 谱线
lam, U = np.linalg.eigh(S[:, :, i].real)
order = np.argsort(lam)[::-1]; lam, U = lam[order], U[:, order]
print("PCS 特征值:", np.round(lam, 3))   # 断崖→1 个主导源
print("U[:,0]:    ", np.round(U[:, 0], 3))
true_dir = A @ np.array([1.0, 0.0]); true_dir /= np.linalg.norm(true_dir)
print("真实方向:   ", np.round(true_dir, 3))
cross = S[:, :, i] @ U[:, 0]             # 各通道与主分量1的互谱
Sp = (U[:, 0].conj() @ S[:, :, i] @ U[:, 0]).real
print("虚拟相干:   ", np.round(abs(cross)**2/(Sp*np.diag(S[:, :, i]).real), 3))
```

运行输出：特征值 $[4.09\times10^{5},\ 0.72,\ 0.43,\ 0.30]$——一条断崖，一个主导源；参考向量 $U[:,0]=[0.733,\ 0.488,\ 0.244,\ -0.407]$ 与真实传播方向逐位吻合（0.732/0.488/0.244/-0.407）；四个通道与第一主分量的虚拟相干全部为 1.000。三个输出恰好对应第二节列的三个问题：源数、空间分布、贡献占比。把源 2 的幅度加大再跑一遍，38 Hz 与 51 Hz 两根谱线会各自看到"前两条特征值并肩、后两条贴地"的双源结构，51 Hz 处 $U[:,0]$ 会转向 $A[:,1]$ 的方向——同一套代码，读出第二个源。

## 六、在 Simcenter Testlab 里算 PCS

手册指出，主分量可由时域抽样数据或响应的线性谱求得；相关软件把"主分量技术"用于分解多输入问题，使各子集可并行分析，并把分解后的数据组馈入动画显示程序，诠释对应每一主分量的工作变形。工程上两条常用路径：

- **Testlab Classic Spectral Testing / Signature：** 多参考通道的互谱矩阵在 throughput 后处理中逐谱线分解，主分量谱与虚拟相干在 Online Processing 或 Time Data Processing 的相关标签页里作为输出量选择；参考通道组一旦指定，特征值曲线按大小排序输出。
- **Testlab Neo Process Designer：** 互谱矩阵类方法（Cross Matrix 系）输出到 Principal Component 相关方法，逐谱线做特征分解，主分量谱、参考向量与虚拟相干作为可路由的输出；配合 Animation 显示 $[U]$ 列向量对应的工作变形。

操作要点有三个：参考通道要选在"源都能传到"的位置，通道组里漏掉某个源，该源就在分解里消失；通道数不必贪多，源数目 r 明显小于通道数 n 时特征值断崖更清晰；报告 PCS 结论时同时给出平均次数与频率分辨率，特征值的绝对数值依赖平均质量，但断崖位置稳健。

## 七、小结

- 多参考数据数不清独立源时，逐谱线对互谱矩阵做特征分解（=SVD）：特征值 $\lambda_r(k)$ 按大小排成主分量谱，断崖位置读源数，$[U]$ 列向量给空间分布。
- 主分量之间相干恒为 0，这是"分声部"定义的数学表述；PCS 不新增测量，只重组已有通道的信息。
- PCS 对响应互谱矩阵，CMIF 对 FRF 矩阵，同一分解骨架服务两类问题：运行态源鉴别与试验模态指示。
- 虚拟相干把每通道能量拆到各主分量头上，与 PCS 配套使用；特征值谱给"几个"，虚拟相干给"各占多少"。

## 一句话记住

主分量谱就是给多参考数据"分声部"：每根谱线上把互谱矩阵对角化，特征值谱的断崖数出独立源、$[U]$ 的列给出每个源的分布形状，再配虚拟相干切出各源贡献——四通道的乱麻，一次分解归队。
