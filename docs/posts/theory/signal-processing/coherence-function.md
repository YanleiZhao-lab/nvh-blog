# 相干函数：评估频响测量质量的统计指标

> 锤击模态测试完成后，频响函数（Frequency Response Function, FRF）曲线形态正常，仍需一个量化指标判断数据是否可用于模态拟合。相干函数（Coherence Function）逐频率给出：输出信号能量中有多大比例能被测到的输入经线性关系解释。Simcenter Testlab 理论手册的表述是：高值（接近 1）表明输出几乎完全由输入引起，可以充分相信频响函数的测量结果；低值（接近 0）表明存在未测量的其它输入、严重噪声、明显非线性或时延等问题。本文按手册给出常相干、重相干、偏相干、虚拟相干四种函数的定义与适用条件，推导输出端噪声与漏测输入两种典型工况下相干的解析表达式，并用 numpy 复现数值结果。

## 一、常相干函数的定义

单输入单输出系统中，激励 $x(n)$ 与响应 $y(n)$ 的**常相干（Ordinary Coherence）**定义为：

$$\gamma_{xy}^2(f) = \frac{|S_{xy}(f)|^2}{S_{xx}(f)\, S_{yy}(f)}$$

其中 $S_{xy}(f)$ 为互功率谱（Cross-spectrum）的多帧平均，$S_{xx}(f)$、$S_{yy}(f)$ 分别为输入、输出自功率谱的多帧平均；三者单位为各自信号谱单位之积（如输入为 N、输出为 m/s² 时，$S_{xy}$ 的单位与 $S_{xx}$、$S_{yy}$ 单位之积的量纲一致）。相干函数本身无量纲，取值范围 $[0, 1]$——这是数学上的必然：互谱幅值受柯西–施瓦茨不等式（Cauchy–Schwarz inequality）约束，不可能超过两个自谱的几何平均。

![常相干函数的定义式（手册式 3-16）](/images/coherence-function/eq3-16-ordinary-coherence.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册 式 3-16）*

物理意义可以读成：**输出能量中，能被测到的输入经由线性关系解释的比例**。手册进一步给出能量视角的表述：常相干反映多分量组成的输出信号中，最大能量分量与输出信号总能量之比。$\gamma^2 = 1$ 意味着输出完全由该输入通过线性系统引起；$\gamma^2 = 0.5$ 意味着一半输出能量另有来源——可能是未测到的第二个振源，可能是测量噪声，也可能是系统不再近似线性。

定义成立的前提是**谱平均**。相干函数必须建立在多帧谱平均之上：只采一帧数据时 $|S_{xy}|^2 = |X^* Y|^2 = |X|^2 |Y|^2$ 恒等于 $S_{xx} \cdot S_{yy}$，相干在所有频率上恒为 1，不含任何统计信息。单帧相干恒等于 1 这一事实，恰恰说明相干是统计量——需要足够帧数才能对"线性可解释比例"做出有方差的估计。

::: info 核心概念
- **常相干（Ordinary Coherence）**：单个输入与单个输出之间的线性相关程度，$\gamma^2 = |S_{xy}|^2/(S_{xx} S_{yy})$，无量纲，取值 $[0,1]$
- **谱平均**：相干只在多帧谱平均下有意义，单帧计算恒为 1
- **判读原则（手册）**：高值（接近 1）表明输出几乎完全由输入引起；低值（接近 0）提示未测输入、严重噪声、明显非线性或时延
- **工程门限**：工程惯例常取关心频段内 $\gamma^2 \geq 0.8$ 作为数据可用判据（具体门限应结合试验精度要求确定，非手册规定值）
:::

## 二、四种相干函数的分工

Simcenter Testlab 理论手册列出了四种相干函数：常相干、重相干、偏相干和虚拟相干，分别对应四类工程问题：

| 类型 | 输入侧 | 手册定义的用途 | 数值特征 |
| --- | --- | --- | --- |
| **常相干** | 单个参考信号 | 评估频响函数的测量质量；评估多个激振器激振力之间的相关关系 | $[0,1]$，单帧恒为 1 |
| **重相干（Multiple Coherence）** | 一组参考信号 | 检验测量中的噪声含量：所有测到的输入合起来能解释多少输出 | $[0,1]$，不低于同输出的任何常相干 |
| **偏相干（Partial Coherence）** | 排除其它信号影响后的单输入 | 多源贡献排位：在最小二乘意义上剥离其它信号后，该路径剩余的线性贡献 | $[0,1]$，条件化的常相干 |
| **虚拟相干（Virtual Coherence）** | 主分量（Principal Components） | 多参考工况下分离不相关独立源（如左右轮激励） | 与所有主分量之和不超出 $[0,1]$ |

三种非常相干的定义式如下。

**重相干**描述单一输出谱与一组参考输入谱之间的因果关系，等于多个输入引起的输出能量与输出总能量之比。单一响应谱 $Y(k)$ 与一组参考谱 $X_i(k)$ 之间的重相干按下式计算：

$$\gamma_{yx}^2(k) = 1 - \frac{S_{yy}^{! \cdot n}(k)}{S_{yy}(k)}$$

其中 $S_{yy}(k)$ 为响应信号 $y(n)$ 的自功率谱；$S_{yy}^{! \cdot n}(k)$ 为 $S_{yy}(k)$ 的条件分量，即在所有参考谱 $X_i(k)$ 的贡献均被消除之后得到的残余自谱。残余谱占比越小，重相干越接近 1。

![重相干的计算式（手册式 3-17）](/images/coherence-function/eq3-17-multiple-coherence.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册 式 3-17）*

**偏相干**是"状态信号"之间的常相干。手册对状态信号的定义是：其它信号所产生的影响已在最小二乘意义上被排除的信号。信号 $X_i$ 与 $X_j$ 的偏相干是在排除信号 $X_1, \dots, X_g$ 影响后计算的条件常相干：

$$\gamma_{pij}^2(k) = \frac{|S_{ij}^{\times g}(k)|^2}{S_{ii}^{\times g}(k)\, S_{jj}^{\times g}(k)}$$

其中 $S_{ii}^{\times g}$、$S_{jj}^{\times g}$、$S_{ij}^{\times g}$ 分别为排除 $X_1, \dots, X_g$ 影响后 $X_i$ 的自谱、$X_j$ 的自谱与两者的互谱。

![偏相干的计算式（手册式 3-18）](/images/coherence-function/eq3-18-partial-coherence.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册 式 3-18）*

**虚拟相干**是一信号与主分量之间的常相干：

$$\gamma_{vij}^2(k) = \frac{|S_{ij}'(k)|^2}{S_{ii}'(k)\, S_{jj}(k)}$$

其中 $S_{ii}'(k)$ 为主分量 $X_i'(k)$ 的自功率谱，$S_{ij}'(k)$ 为信号 $X_j$ 与主分量 $X_i'$ 之间的互功率谱。手册特别指出：主分量之间的相干函数值精确等于 0，因为按定义它们之间完全不相关；任意信号与所有主分量之间虚拟相干之和也在 $[0,1]$ 域内。

![虚拟相干的计算式（手册式 3-19）](/images/coherence-function/eq3-19-virtual-coherence.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册 式 3-19）*

选型逻辑：单输入试验看常相干；MIMO 试验看重相干，判断整组参考输入是否完整；传递路径分析（TPA, Transfer Path Analysis）中排查路径贡献用偏相干；多个不相关源混在一起且无需逐个测量时，用虚拟相干配合主分量分析分离。另有一个有用的关系：单输出情形下 $\gamma^2 = |H_1| / |H_2|$，相干直接给出了两种 FRF 估计子分离的程度（见《[H1、H2、Hv 估计子](../modal-analysis/frf-estimators.html)》）。

## 三、低相干的五类成因

相干曲线下降的原因，与手册列举的低值成因一致，可归为五类：

1. **漏测输入**。输出端混入未测量的振源——邻近工位的风机、路面激励、另一台运转设备。这是最常见也最隐蔽的原因，第二节演示二给出其定量表现。
2. **信噪比不足**。反共振区、频响函数的谷底处响应信号本身小，传感器本底噪声占比上升，相干随之下降。模态试验中反共振区相干偏低属于正常现象，模态拟合重点看共振峰。
3. **平均次数不足**。谱平均是统计估计，帧数少则估计方差大。锤击试验通常以 5～10 次平均起步。
4. **系统非线性**。螺栓连接松动、橡胶件大变形、碰撞间隙使输出中产生输入谱中没有的谐波成分，线性模型无法解释。
5. **时延与时变**。旋转机械升速工况下转速漂移，或两通道间存在采样不同步的时延，相干会被系统性拉低。

其中前两类可以做解析推导，给出可核查的定量表达式。

**输出端噪声模型。** 设真实线性输出为 $v = H \cdot x$，测量输出 $y = v + n$，噪声 $n$ 与输入 $x$ 不相关。互谱与自谱的期望为：

$$S_{xy} = S_{xv} + S_{xn} = S_{xv} \quad (\text{不相关噪声的互谱期望为零})$$

$$S_{yy} = S_{vv} + S_{nn} \quad (\text{总输出功率} = \text{真实响应功率} + \text{噪声功率})$$

代入定义式，分子 $|S_{xv}|^2 = S_{xx} S_{vv}$（$v$ 完全由 $x$ 线性生成），得到：

$$\gamma_{xy}^2(f) = \frac{S_{vv}(f)}{S_{vv}(f) + S_{nn}(f)} = \frac{1}{1 + S_{nn}(f)/S_{vv}(f)}$$

即**相干等于无噪输出功率占总输出功率的比例**——相干 0.5 对应噪声功率与真实响应功率相等。

**漏测输入模型。** 设 $y = h_1 * x_1 + h_2 * x_2$，$x_1$（已测）与 $x_2$（漏测）不相关。同理可得 $S_{x_1 y} = H_1 S_{x_1 x_1}$，$S_{yy} = |H_1|^2 S_{x_1 x_1} + |H_2|^2 S_{x_2 x_2}$，代入定义式：

$$\gamma_{x_1 y}^2(f) = \frac{|H_1(f)|^2 S_{x_1 x_1}(f)}{|H_1(f)|^2 S_{x_1 x_1}(f) + |H_2(f)|^2 S_{x_2 x_2}(f)}$$

即**已测路径的传递功率占总功率的比例**。等功率白噪声输入下简化为 $|H_1|^2/(|H_1|^2 + |H_2|^2)$——频率比、路径增益一代入，相干数值可以直接算出来（见演示二的核对）。

::: warning 工程注意
相干高不代表系统线性，只代表"输出能量能被线性关系解释"。两个不相关的信号各自经过强非线性再叠加，多帧平均后仍可能给出较高的相干。反过来，共振峰处相干偏低时，应首先排查力锤敲击一致性、传感器增益档与触发设置，其次再考虑非线性。
:::

## 四、Python 数值演示

**演示一：输出端噪声如何同时压低相干、抬高 H1 估计误差。** 构造 200 Hz 单自由度系统（阻尼比 5%），白噪声激励，输出端叠加噪声，检查三个频率点的相干与 FRF 幅值误差：

```python
import numpy as np

rng = np.random.default_rng(0)
fs, N, M = 1024, 1024, 40                  # 采样率、每帧点数、平均帧数
f = np.fft.rfftfreq(N, 1/fs)
f0, zeta = 200.0, 0.05                     # 固有频率 200 Hz、阻尼比 5%
w, w0 = 2*np.pi*f, 2*np.pi*f0
H = w0**2/(w0**2 - w**2 + 2j*zeta*w*w0)    # 单自由度频响函数
x = rng.standard_normal(M*N)               # 白噪声激励
X = np.fft.rfft(x.reshape(M, N), axis=1)
yk = np.fft.irfft(X*H, N, axis=1).ravel()  # 无噪声输出
y = yk + 0.5*rng.standard_normal(M*N)      # 输出端叠加测量噪声
Y = np.fft.rfft(y.reshape(M, N), axis=1)
Sxx = (np.abs(X)**2).mean(axis=0)          # 自谱、互谱按帧平均
Syy = (np.abs(Y)**2).mean(axis=0)
Sxy = (np.conj(X)*Y).mean(axis=0)
g2 = np.abs(Sxy)**2/(Sxx*Syy)              # 常相干
H1 = np.abs(Sxy)/Sxx                       # H1 估计
print(" 频率   |H|   相干   H1幅值误差")
for ft in [200, 350, 500]:
    k = np.argmin(np.abs(f-ft))
    print(f"{ft:>4} Hz {np.abs(H[k]):5.2f}  {g2[k]:.3f}  {(H1[k]/np.abs(H[k])-1)*100:+6.1f}%")
```

实测输出（40 帧平均，rng 种子 0）：

| 频率 | \|H\| | 相干 γ² | H1 幅值误差 |
| --- | --- | --- | --- |
| 200 Hz | 10.00 | 0.997 | −0.6% |
| 350 Hz | 0.48 | 0.541 | +3.9% |
| 500 Hz | 0.19 | 0.192 | +14.8% |

联动关系与第三节噪声模型一致：共振峰处 $\gamma^2 = 0.997$，H1 误差在 1% 以内；500 Hz 处真实响应功率与噪声功率相当，相干降到 0.19 附近，H1 幅值误差接近 15%。按工程惯例门限 $\gamma^2 \geq 0.8$ 衡量，该频段的 FRF 幅值已不适合直接用于模态拟合。

**演示二：漏测第二个振源，相干给出定量指示。** 座椅导轨响应 = 发动机经悬置路径（200 Hz 共振，$H_p$）+ 路面直接传入（频响平坦，$H_r = 2.0$，未测量）：

```python
import numpy as np

rng = np.random.default_rng(1)
fs, N, M = 1024, 1024, 40
f = np.fft.rfftfreq(N, 1/fs)
def coh(x, y):                             # 常相干估计
    X = np.fft.rfft(x.reshape(M, N), axis=1)
    Y = np.fft.rfft(y.reshape(M, N), axis=1)
    return (np.abs((np.conj(X)*Y).mean(axis=0))**2
            / ((np.abs(X)**2).mean(axis=0)*(np.abs(Y)**2).mean(axis=0)))
def through(x, H):                         # 信号经频响函数 H 输出
    return np.fft.irfft(np.fft.rfft(x.reshape(M, N), axis=1)*H, N, axis=1).ravel()
f0, zeta = 200.0, 0.05
w, w0 = 2*np.pi*f, 2*np.pi*f0
Hp = w0**2/(w0**2 - w**2 + 2j*zeta*w*w0)   # 路径1：动力总成悬置（有共振峰）
Hr = np.full_like(Hp, 2.0+0j)              # 路径2：路面激励（频响平坦）
x1 = rng.standard_normal(M*N)              # 已测输入：发动机
x2 = rng.standard_normal(M*N)              # 漏测输入：路面
y = through(x1, Hp) + through(x2, Hr)      # 座椅导轨总响应
for ft, name in [(200, "共振区  "), (400, "共振区外")]:
    k = np.argmin(np.abs(f-ft))
    g_leak = coh(x1, y)[k]                 # 只拿发动机当参考
    g_fix  = coh(x1, y - through(x2, Hr))[k]
    print(f"{ft} Hz {name}: 漏测路面 → 相干 {g_leak:.3f}，剥离后 → {g_fix:.3f}")
```

实测输出（rng 种子 1）与第三节漏测输入模型的预测对照：

| 频率 | \|Hp\| | 理论 γ² = \|Hp\|²/(\|Hp\|²+\|Hr\|²) | 实测 γ²（漏测） | 实测 γ²（剥离后） |
| --- | --- | --- | --- | --- |
| 200 Hz | 10.00 | 0.962 | 0.956 | 1.000 |
| 400 Hz | 0.33 | 0.027 | 0.032 | 1.000 |

400 Hz 处最说明问题：悬置路径在此几乎不传递能量（$|H_p| \approx 0.33$），响应主要由漏测的路面贡献，按理论式相干应为 $0.33^2/(0.33^2+2^2) \approx 0.027$，实测 0.032，与解析预测一致——尽管此时系统本身的传递特性没有任何异常。把路面贡献剥离后相干回到 1.000。低相干指向的是**测量方案**缺少输入通道，而不是结构存在缺陷。

## 五、现场判断流程

拿到一条 FRF 先看相干，按表现分类处理：

| 相干表现 | 首先怀疑 | 处置 |
| --- | --- | --- |
| **共振峰高、反共振区低** | 正常现象（信噪比随 \|H\| 变化） | 直接使用；反共振区数据不用于模态拟合 |
| **全频段普遍低** | 平均次数不足 / 通道噪声 | 增加平均次数；检查传感器与增益档 |
| **某频段突然塌陷** | 漏测输入或干扰 | 排查周边振源，补充参考通道或加窗隔离 |
| **共振峰处也低** | 锤击一致性差 / 非线性 / 双击 | 变化激励力度对比；检查连接件状态 |
| **重相干高但常相干低** | 多输入场景 | 属正常；改用 MIMO 的 H1 矩阵估计或偏相干分诊 |

::: tip 实用建议
- 单输入试验：关心频段 $\gamma^2 \geq 0.8$ 再评估数据质量（工程惯例门限），模态拟合只用共振峰附近的高相干区
- MIMO/TPA：常相干偏低先看重相干——重相干高说明参考输入组完整，问题在"分解"而非漏测
- 相干曲线逐频段对照 FRF 峰谷位置判读，仅看全频段均值会丢失局部信息
:::

相干函数不产生新的振动数据，它只对已有的谱估计做质量评估。养成"FRF 与相干同屏、先相干后 FRF"的读图习惯，可以在模态拟合前发现大部分数据质量问题，减少试验返工。
