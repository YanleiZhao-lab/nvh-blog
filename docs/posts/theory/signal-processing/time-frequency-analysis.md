# 时频分析：STFT、小波与 Wigner-Ville 分布怎么选

> 怠速抖动两秒消失、换挡瞬间"咔"一声、电机启动时啸叫扫过一段频率——这些信号的谱成分随时间剧烈变化，一帧 FFT 下来全被平均成一片糊。时频分析把信号展开成时间×频率的二元函数 P(t, ω)，专门对付非平稳信号。本文从边缘方程讲起，拆解 STFT 的固定窗折中、小波的恒百分比带宽、Wigner-Ville 的干涉项三大痛点，最后给出一张"什么信号用什么方法"的选择表。

## 一、FFT 的盲区：频率有了，时间没了

傅里叶变换建立起时域和频域之间的映射，但它回答不了"这个频率什么时候出现"。发动机升速时阶次频率在变、变速箱敲击是毫秒级的短脉冲、EV 电机启动时 PWM 啸叫扫频——对这类信号，整段 FFT 把不同时刻的能量混在一起，观察周期内"出现过什么频率"有了，"何时出现"没了。

时频分析的思路是把信号表示成二元函数 $P(t, \omega)$：时刻 $t$、每单位时间；频率 $\omega$ 处、每单位频率的能量。它不是随便画的彩色图，理论上要过两道检验——**边缘方程（marginal equations）**。

先看两个"一元"的基准。信号在时刻 $t$ 的即时功率是时域波形幅值的平方：

$$|S(t)|^2 \quad \text{——单位时间的能量（强度）}$$

每单位频率的强度则由傅里叶变换取模平方给出：

$$|S(\omega)|^2 \quad \text{——单位频率的能量（能量密度谱）}$$

一个合格的时频分布 $P(t,\omega)$，沿频率轴积分必须还原即时功率，沿时间轴积分必须还原能量密度谱：

$$\int P(t,\omega)\, d\omega = |S(t)|^2 \qquad \int P(t,\omega)\, dt = |S(\omega)|^2$$

两条边缘合起来总能量自洽：$\iint P(t,\omega)\,dt\,d\omega = E$。满足边缘方程的分布不止一种，彼此属性不同——这正是 STFT 谱图、小波尺度图、Wigner-Ville 分布分化的起点。

::: info 核心概念
- **非平稳信号（Non-stationary）**：谱成分随时间变化的信号，升速/降速过程、启停瞬态都是
- **边缘方程**：时频分布沿频率轴积分=即时功率、沿时间轴积分=能量密度谱的自洽性检验
- **干涉项（Interference term）**：二次型时频表示中两个信号分量乘积交叉产生的假能量，工程判读的头号陷阱
:::

## 二、STFT：一把窗尺量到底，折中被锁死

短时傅里叶变换（Short-Time Fourier Transform, STFT）是工程上最常用的时频方法：选一段相对短的观察周期，加窗，算这段窗内的 FFT；然后让窗沿时间轴滑动，得到一列谱。手册里画得很形象——总时间轴上竖向的一条条灰带，每条灰带出一帧谱。

定位在时间 $\tau$ 的 STFT 写作：

$$\mathrm{STFT}(\tau, \omega) = \int s(t)\, g(t-\tau)\, e^{-j\omega t}\, dt$$

信号 $s(t)$ 乘上窗函数 $g(t)$ 再做傅里叶变换，窗中心移到哪，就分析哪一段。

![图10-1 短时傅里叶变换：滑动的观察窗沿时间轴截出一段段局部谱](/images/time-frequency-analysis/stft-concept.png)
*（图源：Simcenter Testing Knowledge Base）*

STFT 可用的前提是"窗内信号近似平稳"。频率成分变化越快，要求的观察窗越短，短到难以接受时 STFT 就到头了。更根本的问题是：**同一把窗量所有时刻、所有频率**，频率分辨率 $\Delta f = 1/T$ 被窗长 $T$ 锁死——想在低频段看细一点的谱线，就得把窗拉长，而长窗又把短促事件在时间上抹开。时间分辨率和频率分辨率的乘积固定，改善一个只能牺牲另一个，这就是不确定性原理在谱分析里的具体形态。

![图10-2 时间-频率平面分格对比：(a) STFT 均匀矩形 vs (b) 小波随频率伸缩](/images/time-frequency-analysis/tf-plane-tiling.png)
*（图源：Simcenter Testing Knowledge Base）*

换个角度看 STFT 更能看清它的局限：把它理解为信号谱 $S(\omega)$ 与窗谱 $G(\omega)$ 乘积的逆傅里叶变换，窗的谱可视为一组**恒带宽带通滤波器**——所有频段用同一套宽度均匀的滤波器组去覆盖，时频平面上画出的是均匀的矩形分格（图10-2(a)）。

::: warning 工程注意
Colormap 就是 STFT 的产物。转速快变段（换挡、急加速）谱线展宽成"糊带"，往往不是测试问题，是窗长对不上信号的平稳性——要么缩短窗牺牲频率分辨率，要么改用角域重采样让阶次在窗内平稳，别在 colormap 上硬读线宽。
:::

## 三、小波变换：窗随频率伸缩，恒百分比带宽

STFT 的死结在于"窗不变"。小波变换（Wavelet Transform, WT）的解法是让分析窗随频率伸缩：不再用正弦波当基函数，改用一族在时间上更集中的"小波"基。

做法是先定义一个**原象小波** $h(t)$——定位在时间 $t_0$、频率 $\omega_0$ 的母小波，再用尺度因子 $a = \omega_0/\omega$ 去扩展或收缩它，得到分析各个频段的一族基函数。连续小波变换定义为：

$$\mathrm{CWT}(\tau, a) = \int s(t)\, \frac{1}{\sqrt{a}}\, h^*\!\left(\frac{t-\tau}{a}\right) dt$$

尺度 $a$ 大，小波被拉长——频率低、周期长，窗自然该宽；尺度 $a$ 小，小波被压缩——频率高、变化快，窗随之变窄。效果上，小波变换相当于一组**恒百分比带宽滤波器**：

$$\frac{\Delta f}{f} = \text{Const}$$

每个频段的带宽与中心频率成固定比例，时频平面上的分格不再均匀：高频处窄窗细时间分辨、低频处宽窗细频率分辨（图10-2(b)），实现多分辨率分析——回看图10-2，(a) 与 (b) 的差别一眼即知。

这套安排其实很"生理"：低频是随时间缓慢变化的现象，只需要粗的时间分辨率；高频现象时间尺度小，时间定位更重要，牺牲一点频率分辨率去换。人耳听觉就类似倍频程分析——恒百分比带宽正是耳蜗的工作方式，这也是小波分析结果与听感评价常能对上的原因。

::: tip 什么时候想到小波
- 信号里同时存在慢变的低频成分和短促的高频猝发（怠速喘振 + 齿轮敲击）——STFT 一把窗顾此失彼，小波各频段各用各的窗
- 关心阶次谐波族结构（等百分比间隔的线）时，恒百分比带宽天然匹配
- 需要与人耳听感相关联的分析（异响、音质），恒百分比带宽接近听觉滤波
:::

## 四、Wigner-Ville：能量分布的"理想型"与干涉项陷阱

STFT 和小波是线性表示，但工程上更关心的常常是**能量在时频平面怎么分布**——能量分布本身是信号的二次型。谱图（spectrogram，$|\mathrm{STFT}|^2$）和尺度图（scalogram，$|\mathrm{WT}|^2$）就是两个二次型特例。

在所有具有能量化解释的二次型表示中，Wigner-Ville 分布（WVD）满足最多的理想数学性质：

$$\mathrm{WVD}(t, \omega) = \int s\!\left(t + \frac{\tau}{2}\right) s^*\!\left(t - \frac{\tau}{2}\right) e^{-j\omega \tau}\, d\tau$$

注意这个定义的结构：算时刻 $t$ 的 WVD 值，是把 $t$ 左边的数据段翻折到 $t$ 右边数据段的前端，重叠部分相乘再积分。**双线性**——信号自己乘自己——带来理想边缘性质的同时，也带来三个工程上必须心里有数的特性。

**特性一：有限长信号的边界干净。** 信号起始时刻 $t_{start}$ 之前、末端 $t_{end}$ 之后，WVD 恒为零；限带信号超出带宽的部分同样为零。道理就在翻折相乘：边界外没有数据可与重叠，乘积为零。

![WVD 特性：有限长信号起始端之前与末端之后 WVD 值均为零](/images/time-frequency-analysis/wvd-boundary.png)
*（图源：Simcenter Testing Knowledge Base）*

**特性二：信号为零的时段，WVD 不一定为零。** 某时刻信号幅值跌到零，但把它左右两段数据翻折相乘求和，结果可以非零——能量分布"渗"进了信号本该为零的时段。

![信号电平跌落的时段 WVD 值却非零：左右段翻折相乘的产物](/images/time-frequency-analysis/wvd-zerocrossing.png)
*（图源：Simcenter Testing Knowledge Base）*

**特性三：噪声沿时间轴扩散。** 估算某无噪声时段的 WVD 值时，翻折求和会卷入信号其它区段的噪声——噪声污染的不是它的"户口所在地"，而是很宽的时间段。同理，信号同时存在多个频率分量时，各分量频率的中间位置会冒出振荡的**频率干涉项**。

![噪声的影响经 WVD 扩散到信号中很宽的时间段](/images/time-frequency-analysis/wvd-noise-spread.png)
*（图源：Simcenter Testing Knowledge Base）*

干涉项可依据其振荡属性辨认（真实能量集中项不振荡），再用平滑技术压小。WVD 的各种广义化——伪 Wigner 分布（PWD，短时 WVD）、平滑伪 Wigner 分布（SPWD，时域频域各自平滑）、Choi-Williams 分布（CWD，指数核平滑）——本质都是换不同的核函数对 WVD 做平滑，用分辨率换干涉项抑制。

::: warning 工程注意
多分量信号（旋转机械几乎全是：阶次族 + 共振带 + 背景噪声）直接看 WVD，干涉项会在阶次线之间织出一片假能量。工程判读优先用谱图或尺度图；要用 WVD 类方法，选带平滑核的变体，并把"干涉项集中在分量中间、呈振荡条纹"当作排除口诀。
:::

## 五、三种方法怎么选：一张表 + 一个演示

| 方法 | 分析窗 | 带宽类型 | 时频分格 | 干涉项 | 典型适用 |
| --- | --- | --- | --- | --- | --- |
| **STFT/谱图** | 固定窗，全程同一把 | 恒带宽 $\Delta f = 1/T$ | 均匀矩形 | 无（线性） | 缓变非平稳信号、colormap、阶次跟踪 |
| **小波/尺度图** | 随频率伸缩 | 恒百分比 $\Delta f/f$ = Const | 高频窄、低频宽 | 无（线性） | 快变+慢变混合、短促高频猝发、听感相关分析 |
| **Wigner-Ville** | 无窗，双线性 | 不受限 | 理论最优 | **有**，多分量时显著 | 单分量/少分量信号、chirp 等理论分析 |

```python
import numpy as np

# 演示：同一段"低频慢变 + 高频猝发"信号，看 STFT 固定窗的两头不讨好
fs = 4096                      # 采样率
t = np.arange(0, 2, 1/fs)      # 2 秒
# 低频缓变分量：100 Hz 连续正弦
slow = 1.0 * np.sin(2*np.pi*100*t)
# 高频猝发分量：1500 Hz，只在 1.00~1.02 s 出现 20 ms
burst_mask = (t >= 1.00) & (t < 1.02)
burst = np.where(burst_mask, 0.8*np.sin(2*np.pi*1500*t), 0.0)
x = slow + burst

def stft_peak(x, win_sec, f_target, fs):
    """给定窗长，返回目标频率处的时频能量包络（简化 STFT）"""
    n = int(win_sec * fs)
    win = np.hanning(n)
    step = n // 4
    env, times = [], []
    freqs = np.fft.rfftfreq(n, 1/fs)
    k = np.argmin(np.abs(freqs - f_target))
    for i in range(0, len(x)-n, step):
        seg = x[i:i+n] * win
        env.append(np.abs(np.fft.rfft(seg)[k]))
        times.append((i + n/2) / fs)
    return np.array(times), np.array(env)

# 长窗 0.25 s：频率上分得清 100 Hz，但 20 ms 猝发在时间上被抹宽
tl, el = stft_peak(x, 0.25, 1500, fs)
# 短窗 0.02 s：猝发定位到毫秒级，但谱线已糊
ts_, es = stft_peak(x, 0.02, 1500, fs)

print(f"长窗0.25s: 猝发能量>10%峰值的时段 = {tl[el > 0.1*el.max()].max() - tl[el > 0.1*el.max()].min():.2f} s")
print(f"短窗0.02s: 猝发能量>10%峰值的时段 = {ts_[es > 0.1*es.max()].max() - ts_[es > 0.1*es.max()].min():.3f} s")
print(f"真实猝发时长 = 0.020 s —— 长窗把 {0.25/0.020:.0f} 倍于真实的时长读成了猝发")
```

运行结果要点：长窗 0.25 s 把 20 ms 的猝发读成 0.12 s 宽的亮带——展宽 6 倍，时间定位失真；换 0.02 s 短窗读出 0.024 s，定位对了，但频率分辨率掉到 50 Hz 一格。一把窗不可能两头讨好，这正是小波"各频段各用各的窗"要解决的问题。

## 六、工程判断

- **默认 STFT**：转速缓变、信号类平稳段足够长，colormap/阶次切面那一套就是 STFT，工具链最熟
- **STFT 糊了换小波**：低频慢变与高频猝发并存、或关心等百分比间隔的谐波族，恒百分比带宽比恒带宽更贴合信号结构，还与听感对齐
- **WVD 只用于干净的单分量信号**：多分量场景干涉项织假能量，要用就选带平滑核的变体（SPWD/CWD），并牢记干涉项"位于分量中间、振荡条纹"两个辨认特征
- **别拿边缘方程苛求谱图**：谱图与尺度图不满足边缘方程，对能量定位的定性评估无伤大雅；要较真能量分布，才需要 WVD 及其平滑变体
- **转速大范围变化的旋转机械**：先想角域重采样——把"时间-频率"问题转成"转角-阶次"，比硬上时频分析更对症
