# 雨流计数：从随机载荷历程提取等幅循环的方法

> 台架上标定的 S-N 曲线对应等幅对称循环，而整车路试采集的载荷谱是大小循环叠加、均值漂移的复杂历程。雨流计数（Rainflow Counting）的作用，是把这样的历程分解为一系列具有特定值域与均值的等幅循环，分解结果可直接代入 Miner 准则计算累计损伤，进而预估构件寿命。本文从一维计数讲到雨流的四点法与残数处理，并附可复现的 numpy 演示。

![典型的载荷-时间历程](/images/rainflow-counting/load-time-history.png)
*（图源：Simcenter Testing Knowledge Base）*

## 一、疲劳分析为什么不用频谱

NVH 工程师的直觉是"看谱"：FFT、自功率谱、colormap。但频率成分对疲劳计算几乎无关——材料的损伤累积不取决于载荷每秒振荡多少次，而取决于每一次幅值反复（reversal）的大小与所处水平。手册的表述很直接：做疲劳分析时，**特殊事件的出现率比载荷的频率成分更重要**。

因此耐久数据处理走的是另一条路：浏览时间历程，找出产生疲劳的典型事件并统计其发生概率。手册图 14-2 标出了三类基本事件：

- **规定量级的峰值出现率**——峰、谷落在哪个载荷档位（峰值计数）；
- **超越规定量级的出现率**——信号向上/向下穿越某条线多少次（跨越量级计数）；
- **幅值变化超过某量级的出现率**——相邻峰谷之间的落差（值域计数）。

整个处理分两步：第一步**计数**，把时间历程压缩为事件序列；第二步**直方图**，把事件按量级分箱统计出现次数。时间波形从此退出后续流程，剩下的是一份"载荷事件记录"。

![数据迹线中的典型事件](/images/rainflow-counting/typical-events.png)
*（图源：Simcenter Testing Knowledge Base）*

::: info 核心概念
- **事件（Event）**：时间历程中一次产生疲劳损伤的基本动作，如一个峰、一次跨级、一个值域
- **计数（Counting）**：浏览历程、记录事件出现率的过程，输出峰-谷序列或矩阵
- **直方图（Histogram）**：对事件按量级分箱的统计结果，疲劳评估的输入
- **值域（Range）**：相邻峰谷之间的幅值差，升为正、降为负
:::

## 二、一维计数：峰值、跨越量级与单值域

### 峰值计数

把数据迹线的折返点分成峰（极大值）与谷（极小值），统计各载荷量级上的出现次数，可以只统计峰、只统计谷或两者都统计。

![峰-谷计数](/images/rainflow-counting/peak-valley-counting.png)
*（图源：Simcenter Testing Knowledge Base）*

### 跨越量级计数

统计信号幅值跨越不同量级线的次数，分向上（正向）跨越与向下（负向）跨越，可选择统计正向、负向或双向跨越。计数栅顶线可按纵坐标物理单位给定，也可按测量量程的百分比给定。它与峰值计数有严格的换算关系：**正向跨越某量级的次数，等于高于该量级的峰数减去高于该量级的谷数**——跨级计数可以从峰-谷计数结果导出。

![跨越量级计数](/images/rainflow-counting/level-crossing.png)
*（图源：Simcenter Testing Knowledge Base）*

### 单值域计数：对小变化敏感

统计连续峰谷之间的差值，顺序升值取正、降值取负。问题在手册图 14-9 里清楚可见：一个大循环上叠加小纹波时，单值域计数把历程拆成一串小值域，直方图堆在低值域端，大循环被"化整为零"。让信号先滤掉小变化再计数，结果完全变样。**对信号的小变化十分敏感**是这一方法的固有局限。

![单值域计数对信号的小变化十分敏感](/images/rainflow-counting/range-pair-sensitivity.png)
*（图源：Simcenter Testing Knowledge Base）*

::: warning 一维计数的局限
峰值、跨级、单值域都只记"单一事件"，丢掉了事件之间的配对关系：一个 200 MPa 的峰跟着 -50 MPa 的谷，与跟着 +150 MPa 的谷，在直方图里无法区分，损伤贡献却差别很大。二维计数法补上的正是这一维信息。
:::

### 值域对计数

单值域计数的改进是值域对计数：不把信号拆成连续的许多小值域，而是理解为一个"主体"变化（主值域）与叠加其上的小循环（值域对）；一对极值分隔的值域小于规定值域 $R$ 时，将其从值域计数中剔除。雨流计数正是这一原理与单值域计数原理相结合的产物。

![值域对计数](/images/rainflow-counting/range-pair-counting.png)
*（图源：Simcenter Testing Knowledge Base）*

## 三、二维计数：From-to、Range-mean 与雨流

### From-to 与 Range-mean：把配对关系记进矩阵

**From-to 计数**统计"j 量级的峰伴随 i 量级的谷"这类成对事件，结果放进马可夫矩阵 $A[i,j]$：元素 $a_{ij}$ 给出 j 级峰伴随 i 级谷的次数，左下三角装正向转变、右上三角装负向转变。同样是 C 到 A 的落差，谷 A 至峰 C、谷 B 至峰 D 会被记进不同的格子里——值域相同、路径不同，分别计数。

**Range-mean 计数**则把每一对极值折算成值域与均值两个数：设谷为 $A$、峰为 $C$，则

$$R = C - A, \qquad m = \frac{A + C}{2}$$

结果落进一张值域-均值二维直方图。均值这一维在疲劳评估中不可省略：平均应力拉则折寿、压则延寿，Goodman 修正以它为输入。

![Range-mean 计数直方图](/images/rainflow-counting/range-mean-counting.png)
*（图源：Simcenter Testing Knowledge Base）*

### 雨流计数：三步流程

"值域对-值域"计数在日本被独立开发为"雨流法"，两种方法得到完全相同的结果：都通过将值域对计数原理与单值域计数原理相结合，从信号中提取同样的值域对和值域。其本质，是把历程理解为一个**主体变化（主值域）与叠加其上的小循环（值域对）**，逐一剥离：信号被分解为各有特定值域与均值的循环，结果可直接代入 Miner 准则做累计损伤计数，乃至简单的裂纹扩展计算。全过程三步：

**第 1 步：压缩成峰-谷序列。** 计数只看峰谷值，先做值域滤波（设置门坎 $R$，单位与载荷一致，常按量程百分比给定）：某峰之后信号回落超过 $R$ 才算有效峰，随后的谷要回升超过 $R$ 才算有效谷。手册图 14-14 里 $e_3$ 被剔除，是因为信号降到 $e_4$ 时回落量不足——它只是主变化上的一个小纹波。

![值域滤波：载荷历程压缩为峰-谷序列](/images/rainflow-counting/range-filter.png)
*（图源：Simcenter Testing Knowledge Base）*

**第 2 步：全序列值域对扫描（四点法）。** 取连续四个极值点 $s_1, s_2, s_3, s_4$，检验中间两个极值（$s_2$、$s_3$）构成的值域是否被两端（$s_1$、$s_4$）覆盖——判据写成：

$$|s_3 - s_2| \le |s_2 - s_1| \quad \text{且} \quad |s_3 - s_2| \le |s_4 - s_3|$$

满足则中间两点构成一个**闭合的值域对**（完整循环），计数后从序列中剔除，用剔除后相邻的新四点组继续检验；不满足则窗口向前移动一个数据点。正是"剔除后回头重扫"这一步，把值域对-值域计数与一次扫描的单值域计数区别开来。

**第 3 步：残数处理。** 扫描结束剩下的峰谷叫**残数（Residue）**——形如"发散段接收敛段"的一段序列，其中包含全程最大值域（最低谷到最高峰）。残数按单值域原理计为**半循环**参与损伤。最大值域以半循环身份出现有其物理依据：若最低谷在一段超长循环的起点、最高峰在其末端，把这两点硬配成一个"完整循环"在物理上本来就缺少依据——计数结果对此保持如实。

手册给了一个六极值的例子：从 $s_1$ 开始的四点组不满足判据，移到 $s_2$、$s_3$ 仍不满足，直到 $s_3$ 到 $s_6$ 才计出第一个值域对；剩下四点再也拆不出"对"，成为残数，按 from-to 记单个半循环。

![雨流扫描示例：找出第一个值域对](/images/rainflow-counting/rainflow-example-scan.png)
*（图源：Simcenter Testing Knowledge Base）*

![雨流示例：残数按单值域计数](/images/rainflow-counting/rainflow-example-residue.png)
*（图源：Simcenter Testing Knowledge Base）*

::: tip 方法名称的由来
把载荷历程旋转 90 度（时间轴竖直向下），想象雨滴沿峰谷"屋檐"流淌：小屋顶上流下的雨滴构成小循环，能一路流过大起伏的构成大循环。雨滴的每条流径对应一个循环——名字来自 Matsuishi 与 Endo 的原始比喻，四点法判据是它的算法化。
:::

## 四、从循环结果到寿命：Miner 准则

雨流输出的是"值域、均值、次数"三列的记录。折算成损伤要走 Palmgren-Miner 线性累积：构件在等幅应力幅 $S_a$（单位 MPa）下寿命为 $N_f$ 次循环，则一个整循环耗掉 $1/N_f$ 的寿命份额；损伤线性叠加：

$$D = \sum_i \frac{n_i}{N_i}$$

$D$ 到 1 时判失效。

寿命 $N_f$ 从 Basquin 型 S-N 曲线来。从定义出发分步推导：

S-N 曲线在双对数图上是直线。设斜率倒数为 $k$（双对数图上 $\lg S_a$ 每增加 1，$\lg N_f$ 下降 $1/k$；钢在 HCF 区常取 $k \approx 8$），$N_f = 1$ 循环对应的参考强度为 $S_C$（Basquin 系数，单位 MPa）。两点定直线：

$$\lg N_f = k\,\lg\frac{S_C}{S_a}$$

两边取反对数，幂律形式即：

$$N_f = \left(\frac{S_C}{S_a}\right)^{k}$$

物理意义：应力幅每翻一倍，寿命缩到原来的 $2^{-k}$——$k=8$ 时即 $1/256$。这就是大循环主导损伤的原因：$k$ 在指数上。

对每个雨流循环取 $S_a = R/2$（值域的一半，暂不做均值修正），代入得 $N_i$，再按上式求和：完整循环记 $n_i = 1$，残数半循环记 $n_i = 0.5$。S-N 参数的取值直接决定计算结果——$k$ 相差 1，同一应力幅下寿命相差 $S_C/S_a$ 倍，应力幅越低相差倍数越大。

::: warning 残数处理的注意事项
残数里包含全程最大值域的半循环。若测段太短、最大事件未在段内"闭合"，半循环的损伤贡献会被系统性低估。工程做法：用足够长的代表性工况段；或对残数半循环做敏感性分析；跨段拼谱时让残数进入下一段继续配对，而不是每段各算各的。
:::

## 五、Python 演示：完整流程复现

### 从峰谷提取到值域滤波

```python
import numpy as np

def turning(x):
    """提取峰-谷序列：符号变化点即折返点"""
    d = np.sign(np.diff(x))
    i = np.where(d[:-1] != d[1:])[0] + 1
    return x[np.r_[0, i, len(x)-1]]

def range_filter(seq, R):
    """值域滤波：落差不足 R 的转折合并，极值保留更极端者"""
    out = [seq[0]]
    for p in seq[1:]:
        if abs(p - out[-1]) >= R:
            out.append(p)
        elif len(out) > 1 and out[-1] > out[-2]:
            out[-1] = max(out[-1], p)   # 峰候选：留更高
        else:
            out[-1] = min(out[-1], p)   # 谷候选：留更低
    return np.array(out)

rng = np.random.default_rng(3)
t = np.linspace(0, 330, 100000)
# 模拟实测应变信号：慢大循环 + 快小循环 + 噪声（单位 MPa）
sig = 300*np.sin(2*np.pi*0.02*t) + 120*np.sin(2*np.pi*0.9*t) \
      + 15*rng.standard_normal(len(t))

pv  = turning(sig)
pvf = range_filter(pv, 30.0)
print(f"原始峰谷 {len(pv)} 点 -> 值域滤波 R=30 后 {len(pvf)} 点")
```

运行结果：66350 个原始峰谷经 $R=30$ MPa 的门坎压缩为 21574 点——约 67% 的转折是噪声纹波，不滤掉它们，雨流结果会被小循环淹没。

### 四点法雨流 + Miner 损伤

```python
import numpy as np

def rainflow(pv):
    """四点法雨流：返回(完整循环, 残数半循环)，各为(值域, 均值)"""
    stack, cyc = [], []
    for p in pv:
        stack.append(p)
        while len(stack) >= 4:
            a, b, c, d = stack[-4:]
            # 中间值域被两端包含 -> 闭合小循环，剔除后回扫
            if abs(c-b) <= abs(b-a) and abs(c-b) <= abs(d-c):
                cyc.append((abs(c-b), (b+c)/2))
                del stack[-3:-1]
            else:
                break
    half = [(abs(stack[i+1]-stack[i]), (stack[i+1]+stack[i])/2)
            for i in range(len(stack)-1)]
    return cyc, half

cyc, half = rainflow(pvf)
print(f"完整循环 {len(cyc)} 个，残数半循环 {len(half)} 个")

# Basquin: S_a^8 * N = 1000^8 (MPa)，损伤 D = sum n_i / N_i
k, S_C = 8.0, 1000.0
r_full = np.array([r for r, _ in cyc])
r_half = np.array([r for r, _ in half])
D = np.sum((r_full/2/S_C)**k) + 0.5*np.sum((r_half/2/S_C)**k)
print(f"单块损伤 D = {D:.2e}，预期寿命约 {1/D:.0f} 块")
```

运行结果：21574 个峰谷拆出 10782 个完整循环加 9 个残数半循环；$k=8$ 的 S-N 下单块损伤 $D = 1.25\times 10^{-3}$，预期寿命约 802 块。值得关注的对比：本例中值域最大（约 840 MPa）的主导循环每个时间块只出现 1 次，损伤占比却高达 99.5%；其余约 1.07 万个小循环的损伤合计不足主导循环的 1%——**$k$ 在指数上，大循环主导损伤**。

## 六、工程应用要点

Testlab 里这条流程对应 Time Data Processing 的疲劳预处理：转折点检测（Peak-Valley）、值域滤波（Range Filter）到雨流矩阵（Rainflow Matrix），输出的值域-均值直方图可直接送 TecWare 做疲劳寿命预估。整车耐久应用中三个需要关注的要点：

- **量程与门坎**。值域滤波门坎 $R$ 常用量程的 1% 到 5% 起步。手册的明确结论：增大 $R$ 只是删掉小于新 $R$ 的转折点，**计数结果对 $R$ 并不敏感**——$R$ 从 $R_0$ 增至 $3R_0$ 时，From-to 矩阵里落差小于 $3R$ 的元素才清零。门坎不必反复调，量程档位更需要关注（参考量程与量化那篇）。
- **测段长度与残数**。见上文 warning，残数半循环的处理方式应在报告中写明。
- **均值漂移**。路面谱常有静载偏置，Range-mean 矩阵的均值维不应丢弃：做 Goodman/平均应力修正时它是输入，丢弃等于假设全部对称循环，结果偏保守也偏离实际。

| 计数方法 | 记录的事件 | 输出形式 | 主要用途 | 局限 |
| --- | --- | --- | --- | --- |
| **峰值计数** | 峰/谷落在各量级的次数 | 一维直方图 | 快速查看载荷分布 | 丢失配对关系 |
| **跨越量级计数** | 上/下穿越各量级次数 | 一维直方图 | 与峰值计数互相校验 | 无幅值配对 |
| **单值域计数** | 相邻峰谷落差 | 一维直方图 | 简单值域统计 | 对小变化敏感 |
| **From-to 计数** | 谷 i 至峰 j 的成对事件 | 马可夫矩阵 | 保留转变路径 | 不直接出循环 |
| **Range-mean 计数** | 值域 + 均值 | 二维直方图 | 平均应力修正输入 | 不拆嵌套循环 |
| **雨流计数** | 完整循环 + 残数半循环 | 值域-均值矩阵 | **疲劳损伤/寿命预估** | 依赖测段代表性 |

::: tip 选择原则
- 计算疲劳寿命、裂纹扩展 -> 雨流计数为首选
- 要做平均应力修正 -> 雨流或 Range-mean，保留均值维
- 快速摸底载荷分布 -> 峰值/跨级计数，计算量小
- 数据带毛刺 -> 先值域滤波再雨流；门坎按量程 1% 到 5% 起步，不必精调
:::

## 七、小结

雨流计数的价值在于把"随机"历程翻译为"等幅"循环：嵌套的大小循环分别计数，残数如实记为半循环。它是连接实测载荷谱与 S-N 曲线的桥梁，Miner 损伤和的每一项都来自这一计数结果。判断要点三条：疲劳数据处理用雨流而非一维计数；值域滤波门坎不敏感，量程和测段长度才是需要盯住的变量；均值维保留，寿命预估前的平均应力修正以它为输入。
