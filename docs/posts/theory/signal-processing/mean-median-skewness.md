# 均值、中值与偏斜度：数据中心不只一个

> 报告一份数据的统计结果时，多数工程师默认使用均值（mean）。但手册第九章明确指出：均值并非表征数据中心值的唯一参数，中值（median）同样有效，二者的选用取决于数据的偏斜度（skewness）。在偏斜度大于 1 的载荷谱、怠速抖动统计、声品质评分分布中，均值会被长尾显著抬高，而中值几乎不受少数极端点影响。本文梳理均值、中值、百分点、偏斜度这一族统计量——给出定义、从矩出发的分步推导，以及工程上何时应改用中值或百分点。

## 一、先看一族基础统计量：极值组

在讨论"中心"参数之前，手册先给出四个描述数据边界的基础量，它们是后续统计量的基础：

![最大值、最小值、幅值范围和极值示意](/images/mean-median-skewness/fig9-1-max-min-range.png)
*（图源：Simcenter Testing Knowledge Base）*

- **最大值（Maximum）**：规定测量时间段内的最大幅值；
- **最小值（Minimum）**：规定测量时间段内的最小幅值；
- **幅值范围（Range）**：最大值与最小值的差值；
- **极大值（Extremum）**：规定测量时间段内的最大绝对值——若 |max| > |min| 取 |max|，否则取 |min|。峰值因子（crest factor）的分子用的就是它。

这四个量只反映边界、不反映分布，对毛刺极其敏感。单个电磁干扰尖峰即可显著抬高最大值和幅值范围，但对中值没有影响——这正是后文选择"中心"参数时的判据依据。

::: info 核心概念
- **均值（mean）**：全部采样值的算术平均，一阶矩，数据的重心
- **中值（median）**：按大小排序后位于正中间的值，50% 数据小于它、50% 大于它
- **百分点（Percentile）**：中值的推广，第 n 百分点表示 n% 的数据小于该值
- **偏斜度（Skewness）**：分布不对称程度的无量纲度量，三次标准化矩
:::

## 二、均值与中值：两个"中心"的物理差别

### 均值是重心，中值是分界线

均值定义为：

$$\bar{x} = \frac{1}{N}\sum_{i=1}^{N} x_i$$

其中 $N$ 为采样点总数（无量纲计数），$x_i$ 为第 $i$ 个采样值（单位如加速度 g）。它是一阶矩：把每个采样值等权平均，相当于求数据的"重心"。

中值在手册中先以概率形式定义：概率密度函数 $p(x)$ 的中值 $x_{\mathrm{med}}$ 是使变量 $x$ 大于和小于该值的概率相等的点，即

$$P(x > x_{\mathrm{med}}) = P(x < x_{\mathrm{med}}) = 0.5$$

对离散数据，若所有采样值按递增或递减顺序排列，中值就是中间那个数据：$N$ 为奇数时取第 $(N+1)/2$ 个数，大于和小于中值的数据各占半数；$N$ 为偶数时取中间两个值的代数平均。中值只取决于排序位置，不取决于数值大小——把最大那个采样点从 10 g 改成 100 g，中值保持不变，均值则立即随之移动。

### 推导：为什么偏斜分布里均值被长尾拖动

设信号由一个主体分布加少量大幅值事件构成。把均值改写成加权形式：

$$\bar{x} = \frac{1}{N}\sum x_i = \sum_{k} \left( \frac{n_k}{N} \right) x_k$$

其中 $n_k/N$ 是幅值 $x_k$ 的出现频率。对对称分布，正负偏差互相抵消；一旦分布不对称——比如 95% 的点在 0.1 g 附近、5% 的点冲到 3 g——高幅值点虽然数量少，但乘以自身幅值后对总和的贡献不可忽略，重心整体向尾部一侧移动。而中值只回答"一半数据落在哪一侧"，95% 的主体数据即可确定其位置。

手册给出的判别规则：**高值数据量偏少（正偏斜）时均值 > 中值；低值数据量偏少（负偏斜）时均值 < 中值**。两者之差本身就是分布不对称的快速诊断量。

## 三、偏斜度：把不对称量化成一个数

### 从矩的定义出发推导

偏斜度（也称偏态系数）定义为三次标准化矩，表征数据在其中值上下分布的不对称程度。推导分三步：

**第一步**，中心化：每个点减去均值，得到偏差 $d_i = x_i - \bar{x}$，消除直流偏移的影响。

**第二步**，标准化：除以标准差的三次方。先看二阶矩——方差 $\sigma^2 = \frac{1}{N}\sum d_i^2$ 度量分布宽度；$\sigma^3$ 与分子 $\sum d_i^3$ 量纲一致，相除后才得到无量纲数。

**第三步**，取三次方并平均：

$$\gamma_1 = \frac{1}{N}\sum_{i=1}^{N} \left( \frac{x_i - \bar{x}}{\sigma} \right)^3 = \frac{m_3}{\sigma^3}$$

其中 $m_3 = \frac{1}{N}\sum d_i^3$ 是三阶中心矩。三次方保留符号：右侧长尾产生正的贡献，左侧长尾产生负的贡献，对称分布正负抵消归零。这就是"正偏斜/负偏斜"的数学来源。

![数据分布的对称和偏斜](/images/mean-median-skewness/fig9-2-symmetry-vs-skewness.png)
*（图源：Simcenter Testing Knowledge Base）*

### 均值和中值怎么选：手册给的决策规则

手册指出：均值比中值更常被使用，如果偏斜度保持在 −1～1 范围内，这种使用没有问题。超出该范围时按分布形态选择：

| 使用场景 | 推荐统计量 | 原因 |
| --- | --- | --- |
| **对称分布（偏斜度绝对值 < 1）** | **均值** | 与中值近似等价，且数学性质好（线性、可加） |
| **正偏斜载荷谱（偏斜度 > 1）** | **中值** | 均值被少数大载荷事件抬高，不代表典型工况 |
| **负偏斜数据（偏斜度 < −1）** | **中值** | 均值被低值尾部压低，同样失真 |
| **工况监控/异常检测** | **百分点（L10/L90）** | 对毛刺鲁棒，可自定义警戒线 |
| **法规统计（如里程分布）** | **中值/百分点** | 惯例要求，抗离群点 |

::: warning 偏斜度不是算出来就能信
手册强调两点。其一，即使偏斜度不等于零，也未必意味着数据确实偏斜：仅当三次矩的值比标准差还要大时，才可以确信偏斜度。对正态（高斯）分布的理想情况，偏斜度估计的标准差约为 $\sqrt{6/N}$——习惯上仅当估计值比该值大出几倍时，才可确认分布不对称；样本量在几千点以下、偏斜度又不大的情况下，该估计基本不可信。其二，偏斜度和峭度这类高次矩，与基于线性相加的低次矩相比鲁棒性通常较差，计算结果往往比较分散，使用时务必谨慎。
:::

## 四、Python 演示：均值怎么被尾部拖动

```python
import numpy as np

rng = np.random.default_rng(42)

# 主体：95% 的点在 0.1g 附近（对称高斯）
body = rng.normal(0.1, 0.02, 9500)
# 尾部：5% 的冲击事件冲到 3g 附近
tail = rng.normal(3.0, 0.5, 500)
x = np.concatenate([body, tail])

mean, med = x.mean(), np.median(x)
sigma = x.std()
skew = (((x - mean) / sigma) ** 3).mean()   # 偏斜度：三次标准化矩
gate = np.sqrt(6 / len(x))                  # 正态假设下的估计标准差

print(f"均值   {mean:.3f} g   中值 {med:.3f} g   差值 {mean-med:+.3f} g")
print(f"偏斜度 {skew:.2f}   门限 sqrt(6/N) = {gate:.3f}")
print(f"第90百分点 {np.percentile(x, 90):.2f} g   第99百分点 {np.percentile(x, 99):.2f} g")
```

运行结果要点：均值 0.245 g，中值 0.101 g，差 0.144 g——主体数据仅在 0.1 g 附近，5% 的冲击事件便使均值达到主体水平的两倍以上；偏斜度 4.34，是门限 0.024 的一百多倍，分布确实不对称，此时报告中值才代表主体工况。

再来一组对照——纯稳态高斯随机振动（对称分布），验证均值在对称分布下的适用性：

```python
import numpy as np

rng = np.random.default_rng(7)

# 对照组：稳态高斯随机振动（对称、无长尾）
x = rng.normal(0.0, 1.0, 10000)

mean, med = x.mean(), np.median(x)
sigma = x.std()
skew = (((x - mean) / sigma) ** 3).mean()
gate = np.sqrt(6 / len(x))                 # 估计标准差门限

print(f"均值 {mean:+.4f}   中值 {med:+.4f}   差值 {abs(mean-med):.4f}")
print(f"偏斜度 {skew:+.4f}   门限 {gate:.4f}   均值≈中值，可直接使用均值")
```

运行结果要点：偏斜度 +0.007，小于门限 0.024，均值与中值只差 0.001 量级——对称分布里两个"中心"等价，选用计算更方便的均值即可。

## 五、工程应用与注意事项

整车与动力总成测试中，这一族统计量的典型应用场景如下：

- **路噪载荷谱统计**：底盘加速度信号天然正偏斜（平稳巡航 + 过坎冲击）。以均值作为特征输入给耐久分析，等于让 5% 的坑洼事件主导 95% 正常路况的贡献；改用中值或 L90，特征才稳定。
- **怠速方向盘抖动评价**：转速波动信号峰谷不对称（压缩冲程减速快、燃烧冲程加速慢），报告中值并配合百分点带（L10–L90），比单报均值更能反映驾驶员手感。
- **声品质主观评分**：评审团打分经常出现"多数集中且伴随少数极端低分"，正偏斜分布下均值会夸大问题严重度，中值更贴近多数评审的感受。
- **数据质检**：台架跑完先看偏斜度与均值-中值差。正常随机振动应近似对称；突然出现明显正偏斜，应先排查传感器掉线后的零漂段或冲击干扰，再进行分析。

::: tip 选择原则
- 对称分布（多数稳态随机振动）→ 直接用均值
- 分布带长尾（载荷谱、冲击混合、主观评分）→ 中值 + 百分点
- 判断有没有偏：先算均值减中值的差，再算偏斜度并与 $\sqrt{6/N}$ 门限比较，超出门限几倍方可确认
:::

## 六、小结

均值是重心，中值是分界线，偏斜度给出不对称的方向和强度。偏斜度保持在 −1～1 之内用均值没有问题——超出这个范围，长尾已使重心偏离主体数据，中值或百分点才是能代表典型工况的统计量。统计一个信号之前，先看分布形状，再选中心参数，这是手册第九章给出的数据处理次序。
