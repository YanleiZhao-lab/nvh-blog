# 均值、中值与偏斜度：数据中心不只一个

> 报一份振动数据，多数工程师条件反射地写 mean。但手册第九章明确提醒：均值并非表征数据中心值的唯一参数，中值（median）同样合法，选哪个取决于偏斜度。偏斜度大于 1 的载荷谱、怠速抖动统计、声品质评分分布里，均值会被长尾巴拖着走，中值却稳如泰山。这篇把均值、中值、百分点、偏斜度这一族统计量讲透——定义、从矩出发的推导、工程上什么时候必须换掉均值。

## 一、先看一族基础统计量：极值组

在谈"中心"之前，手册先给了四个描述数据边界的基础量，它们是后续一切统计的地基：

![最大值、最小值、幅值范围和极值示意](/images/mean-median-skewness/fig9-1-max-min-range.png)
*（图源：Simcenter Testing Knowledge Base）*

- **最大值（Maximum）**：规定测量时间段内的最大幅值；
- **最小值（Minimum）**：规定测量时间段内的最小幅值；
- **幅值范围（Range）**：最大值减最小值；
- **极大值（Extremum）**：绝对值最大的那个采样点——若 |max| > |min| 取 |max|，否则取 |min|。峰值因子的分子用的就是它。

这四个量只看边界、不看分布，对毛刺极其敏感。一个电磁干扰尖峰就能把最大值和幅值范围同时抬上天，但对中值毫无影响——这正是后面选择"中心"参数时要用到的判据。

::: info 核心概念
- **均值（mean）**：全部采样值的算术平均，一阶矩，数据重心
- **中值（median）**：按大小排序后位于正中间的值，50% 数据小于它、50% 大于它
- **百分点（Percentile）**：中值的推广，第 n 百分点表示 n% 的数据小于该值
- **偏斜度（Skewness）**：分布不对称程度的无量纲度量，三次标准化矩
:::

## 二、均值与中值：两个"中心"的物理差别

### 均值是重心，中值是分界线

均值定义为：

$$\bar{x} = \frac{1}{N}\sum_{i=1}^{N} x_i$$

它是一阶矩：把每个采样值等权平均，相当于找数据的"重心"。对离散序列，若 N 为奇数，中值就是排序后第 (N+1)/2 个数；若 N 为偶数，取中间两个数的平均。中值只看排序位置，不看数值大小——把最大那个点从 10 g 改成 100 g，中值纹丝不动，均值立刻被拽走。

### 推导：为什么偏斜分布里均值被尾巴拖着走

设信号由一个主体分布加少量大幅值事件构成。把均值改写成加权形式：

$$\bar{x} = \frac{1}{N}\sum x_i = \sum_{k} \left( \frac{n_k}{N} \right) x_k$$

其中 $n_k/N$ 是幅值 $x_k$ 的出现频率。对对称分布，正负偏差互相抵消；一旦分布不对称——比如 95% 的点在 0.1 g 附近、5% 的点冲到 3 g——高幅值点虽然数量少，但乘上自身幅值后贡献不可忽略，重心整体向尾巴一侧移动。而中值只回答"一半数据在哪边"，95% 的主体直接锁死它的位置。

手册给出的判别规则：**正偏斜（高值尾巴）时均值 > 中值；负偏斜（低值尾巴）时均值 < 中值**。两者之差本身就是分布不对称的快速诊断量。

## 三、偏斜度：把不对称量化成一个数

### 从矩的定义出发推导

偏斜度定义为三次标准化矩。推导分三步：

**第一步**，中心化：每个点减去均值，得到偏差 $d_i = x_i - \bar{x}$，消除直流偏移的影响。

**第二步**，标准化：除以标准差的三次方。先看二阶矩——方差 $\sigma^2 = \frac{1}{N}\sum d_i^2$ 度量散布宽度；三次方 $\sigma^3$ 与分子 $\sum d_i^3$ 量纲一致，相除后才得到无量纲数。

**第三步**，取三次方并平均：

$$\gamma_1 = \frac{1}{N}\sum_{i=1}^{N} \left( \frac{x_i - \bar{x}}{\sigma} \right)^3 = \frac{m_3}{\sigma^3}$$

其中 $m_3 = \frac{1}{N}\sum d_i^3$ 是三阶中心矩。三次方保留符号：右侧长尾产生正的贡献，左侧长尾产生负的贡献，对称分布正负抵消归零。这就是"正偏斜/负偏斜"的数学来源。

### 均值和中值怎么选：手册给的决策规则

| 使用场景 | 推荐统计量 | 原因 |
| --- | --- | --- |
| **对称分布（偏斜度绝对值 < 1）** | **均值** | 等价于中值，且数学性质好（线性、可加） |
| **正偏斜载荷谱（偏斜度 > 1）** | **中值** | 均值被少数大载荷事件抬高，不代表典型工况 |
| **负偏斜数据（偏斜度 < -1）** | **中值** | 均值被低值尾巴压低，同样失真 |
| **工况监控/异常检测** | **百分点（L10/L90）** | 对毛刺鲁棒，可自定义警戒线 |
| **法规统计（如里程分布）** | **中值/百分点** | 惯例要求，抗离群点 |

::: warning 偏斜度不是算出来就能信
手册强调：即使偏斜度不等于零，未必意味着数据确实偏斜。对正态分布的理想情况，偏斜度估计的标准差约为 $\sqrt{6/N}$——只有当估计值比这个门限大出几倍，才能确认分布真的不对称。样本几千点以下、偏斜度又不大时，这个数基本是噪声。
:::

## 四、Python 演示：均值怎么被尾巴拖走

```python
import numpy as np

rng = np.random.default_rng(42)

# 主体：95% 的点在 0.1g 附近（对称高斯）
body = rng.normal(0.1, 0.02, 9500)
# 尾巴：5% 的冲击事件冲到 3g 附近
tail = rng.normal(3.0, 0.5, 500)
x = np.concatenate([body, tail])

mean, med = x.mean(), np.median(x)
sigma = x.std()
skew = (((x - mean) / sigma) ** 3).mean()   # 偏斜度：三次标准化矩
gate = np.sqrt(6 / len(x))                  # 正态假设下的估计标准差

print(f"均值   {mean:.3f} g   中值 {med:.3f} g   差值 {mean-med:+.3f} g")
print(f"偏斜度 {skew:.2f}   门限 sqrt(6/N) = {gate:.3f}")
print(f"第90百分点 {np.percentile(x, 90):.2f} g   第99百分点 {np.percentile(x, 99):.2f} g")
```

运行结果要点：均值 0.245 g，中值 0.101 g，差 0.144 g——本体明明只有 0.1 g，5% 的冲击就把"典型水平"报道成了它的两倍多；偏斜度 4.34，是门限 0.024 的一百多倍，分布确实不对称，此时报中值才代表主体工况。

再来一组对照——纯稳态高斯随机振动（对称分布），看均值为什么在教材里"好用"：

```python
import numpy as np

rng = np.random.default_rng(7)

# 对照组：稳态高斯随机振动（对称、无长尾）
x = rng.normal(0.0, 1.0, 10000)

mean, med = x.mean(), np.median(x)
sigma = x.std()
skew = (((x - mean) / sigma) ** 3).mean()
gate = np.sqrt(6 / len(x))                 # 估计标准差门限

print(f"均值 {mean:+.4f}   中值 {med:+.4f}   差值 {abs(mean-med):.4f}")
print(f"偏斜度 {skew:+.4f}   门限 {gate:.4f}   均值≈中值，放心用均值")
```

运行结果要点：偏斜度 +0.007，比门限 0.024 还小，均值与中值只差 0.001 量级——对称分布里两个"中心"等价，选计算更方便的均值即可。

## 五、工程上怎么用、坑在哪

整车与动力总成测试里，这一族统计量的用武之地比想象中大：

- **路噪载荷谱统计**：底盘加速度信号天然正偏斜（平稳巡航 + 过坎冲击）。拿均值做特征输入给耐久分析，等于让 5% 的坑洼事件替 95% 的好路发言；换中值或 L90，特征才稳定。
- **怠速方向盘抖动评价**：转速波动信号峰谷不对称（压缩冲程减速快、燃烧冲程加速慢），报中值配合百分点带（L10–L90），比单报均值更能反映驾驶员手感。
- **声品质主观评分**：评审团打分经常出现"一边倒加几个极端差评"，正偏斜分布下均值会夸大问题严重度，中值更贴近多数人的感受。
- **数据质检**：台架跑完先看偏斜度与均值-中值差。正常随机振动应该近似对称；突然出现明显正偏斜，先怀疑传感器掉线后的零漂段或冲击干扰，再谈分析。

::: tip 选择原则
- 对称分布（多数稳态随机振动）→ 直接用均值
- 分布带长尾（载荷谱、冲击混合、主观评分）→ 中值 + 百分点
- 判断有没有偏：先算均值减中值的差，再算偏斜度并与 $\sqrt{6/N}$ 门限比较，超几倍才算数
:::

## 六、小结

均值是重心，中值是分界线，偏斜度给出不对称的方向和强度。偏斜度保持在 −1～1 之内用均值没问题——超出这个范围，长尾巴已经把重心拖离主体，中值或百分点才是能代表典型工况的数。统计一个信号之前，先看分布形状，再选中心参数，这是手册第九章留给数据处理的次序。
