# 虚拟相干展开：多输入系统的归因工具

> 四个座位上的乘客各听到不同的响声，声源却只有一个风扇——"谁听到的响是谁发出的"，常相干答不了这个问题：两个通道相干 0.9，既可能是"同一个源传到两处"，也可能是"两个源恰好都传到这两处"，逐对看永远分不清。本文介绍虚拟相干（Virtual Coherence）：先给多通道数据做主分量分解、得到一组两两不相关的"虚拟源"，再计算每个真实通道与各虚拟源之间的常相干，把每个通道的能量逐源切分开、归因到头上。像分水管到户的水表——总表说清总量，分表说清每户用了多少，且各户读数加起来不超过总表；虚拟相干的"归因比例"正是这套分表，任意信号与所有主分量之间虚拟相干的和落在 [0, 1] 内，这是 LMS 理论手册 3.2 节明确给出的性质。本文给出虚拟相干与主分量谱的定义式、与四种相干函数的分工对比、一段把重叠频带内两个独立源正确归因的 numpy 演示，以及 Testlab 中的计算路径与操作要点。

## 一、为什么常相干在多源场合会"失灵"

先看工程现场最典型的一幕。某机型路噪排查，车内前后左右四个座位各放一个传声器，怠速+定转速两种工况各采一组数据。分析时工程师很自然地做了通道间的常相干：前排两个座位在 38 Hz 附近相干 0.42——数值不低，说明两个通道"有关系"；但这个 0.42 到底是什么意思？是同一个声源传到了两个座位，还是两个不同的源（比如动力总成刚体模态与悬架簧下模态）恰好都在这个频带有能量、又都传到了这两个座位？常相干只度量"两个信号之间线性关系的强弱"，它对"几个源"这件事保持沉默。更要命的是，N 个通道两两组合有 N(N-1)/2 对，四通道就是 6 条相干曲线，每条都既包含"同一个源的相关"也包含"不同源的叠加"，越叠越乱。

问题出在"原始通道"不是好的归因对象。两个源混在每一个通道里，无论怎么两两组合，都是在拿"混合物 A"与"混合物 B"求相关——相关系数高说明混合物里有共同成分，但拆不出成分本身。想要逐源归因，得先把混合物解开：先找到一组两两完全不相关的"虚拟源"（主分量），它们是原始通道的线性组合，能量按大小排序；然后问"某通道与第 i 个虚拟源有多相关"——这就是虚拟相干。两步合起来，就是"先分表、后读数"。

打个生活比方：老小区一根总水管进了四户人家，月底收到一张总水费单（每个座位的总声压），吵不清谁家用了多少。物业给每户装分水表——分水表读数彼此独立、加起来不超过总表（漏水部分谁也不归）；虚拟相干做的事一模一样：主分量是"分水表"，虚拟相干是"每户读数占总表的比例"。每户比例都在 0 到 1 之间，各户比例之和不超过 1——对应到信号域，就是"任意信号与所有主分量之间虚拟相干的和在 [0,1] 域内"。常相干相当于只看总表与总表的关系，永远算不清账。

## 二、主分量：先造出一组互不相关的"虚拟源"

虚拟相干的分母与分子都建立在主分量之上，所以先把主分量谱（Principal Component Spectrum, PCS）的骨架立起来。这里只列展开虚拟相干所需的最小集合，完整的推导、与 CMIF 的关系、特征值断崖读源数的用法，见《[主分量谱 PCS：多参考数据的降维视图](/posts/theory/signal-processing/principal-component-spectrum.html)》。

**导读**：这个公式回答的问题是"N 个混在一起的通道，如何线性重组为一组两两不相关的信号"——其中 $[U]$ 对应物理里的"分声部归队表"：每列是一个虚拟源在各通道上的混合比例（该源传到各测点的相对大小与相位），酉矩阵保证重组不放大也不缩小任何成分。

对一组信号 $X_1, \dots, X_n$，假定它们可以由一组完全不相关的信号通过线性组合来描述，这后一信号组 $X'_1, \dots, X'_n$ 就称为原信号组的主分量。在每根谱线 $k$ 上，基本关系式为（LMS 理论手册 3.2 节式 3-20）：

$$
\{X'(k)\} = [U]^H\{X(k)\}, \qquad \{X(k)\} = [U]\{X'(k)\}, \qquad [U]^H[U] = [I]
$$

$$
[S'_{xx}] = [U]^H[S_{xx}][U]
$$

![主分量分解的基本关系式（手册式 3-20）](/images/virtual-coherence-expanded/eq3-20.png)
*（图源：LMS Test.Lab 理论手册 3.2 节）*

其中 $[S'_{xx}]$ 为以主分量自功率谱为对角元素的对角线矩阵；$\{X'(k)\}$ 为不相关的主分量信号组；$[U]$ 为转换酉矩阵（unitary matrix），上标 $H$ 表示共轭转置。

::: info 核心概念：主分量
主分量（Principal Component）是原信号组经酉变换得到的、两两之间完全不相关的新信号组。主分量之间的相干函数值精确地等于 0——因为按定义，它们之间是完全不相关的。在理念上，主分量就是信号组中能观察的主要独立机械源。手册指出，主分量谱的主要应用是确定信号组中不相关机械源的数目。
:::

为什么"不相关"是关键？因为归因的分母必须可加。若两个"源"彼此相关（比如同一台发动机的 2 阶与 4 阶），它们在同一通道里的贡献就无法干净地分开——你归给源 1 的那份能量，源 2 也在往里添。主分量的不相关性由构造保证：$[S'_{xx}]$ 是对角阵，非对角元素（互谱）全为零，两两常相干恒为零。虚拟相干正是借用这一性质，把"归因"做成了封闭的账本：每个虚拟源只对自己名下的能量负责，各虚拟源对同一通道的贡献比例可以相加、总和有界。这也回应了第一节的比方——分水表之间不会串账，加起来才可能不超过总表。

## 三、虚拟相干：给每个通道把能量切到源头上

**导读**：这个公式回答的问题是"第 i 个虚拟源在第 j 个通道的总能量里占多大比例"——其中分子上的互谱 $S'_{ij}$ 对应物理里的"虚拟源 i 传到通道 j 的分量"，分母上的 $S'_{ii}$ 与 $S_{jj}$ 分别对应"虚拟源 i 的总谱"与"通道 j 的总谱"，结构上就是把常相干里的"信号 i"换成"虚拟源 i"。

虚拟相干是一信号与主分量之间的常相干（LMS 理论手册 3.2 节式 3-19）：

![虚拟相干的计算式（手册式 3-19）](/images/virtual-coherence-expanded/eq3-19.png)
*（图源：LMS Test.Lab 理论手册 3.2 节）*

$$
\gamma^2_{v_{ij}}(k) = \frac{|S'_{ij}(k)|^2}{S'_{ii}(k)\, S_{jj}(k)}
$$

其中 $S'_{ii}(k)$ 为主分量 $X'_i$ 的自功率谱（即对角阵 $[S'_{xx}]$ 的第 $i$ 个对角元），$S'_{ij}(k)$ 为信号 $X_j$ 与主分量 $X'_i$ 之间的互功率谱，$S_{jj}(k)$ 为信号 $X_j$ 的自功率谱。

::: info 核心概念：虚拟相干
虚拟相干（Virtual Coherence）度量"一个真实通道与一个虚拟源"之间的线性关联强度，取值总在 0 和 1 之间。它与常相干共用同一个代数结构——分子是互谱模平方，分母是两个自谱之积——只是把其中一个信号换成了主分量。手册特别给出性质：任意信号与所有主分量之间虚拟相干的和也在 [0, 1] 的域内。
:::

这个"和不超过 1"不是巧合，而是主分量正交性的直接推论。把通道 $X_j$ 用主分量展开：$X_j = \sum_r u_{jr} X'_r$（$u_{jr}$ 是 $[U]$ 第 $j$ 行第 $r$ 列元素）。由于各 $X'_r$ 互不相关，通道的自谱恰好等于各分量自谱的加权和：$S_{jj} = \sum_r |u_{jr}|^2 S'_{rr}$，而互谱 $S'_{ij} = u_{ji} S'_{ii}$（其余项因不相关而消失）。代入定义式，得

**导读**：这个展开式回答的问题是"归因比例为什么恰好构成一套封闭的账本"——其中 $|u_{ji}|^2 S'_{ii}/S_{jj}$ 对应物理里的"虚拟源 i 在通道 j 能量中的份额"，各份额之和恒为 1（无测量噪声的理想情形）。

$$
\gamma^2_{v_{ij}} = \frac{|u_{ji}|^2 S'_{ii}}{S_{jj}}, \qquad \sum_{i=1}^{n} \gamma^2_{v_{ij}} = \frac{\sum_i |u_{ji}|^2 S'_{ii}}{S_{jj}} = 1
$$

也就是说，虚拟相干把通道 $X_j$ 的能量按虚拟源切开、份额加和为 1；实测中和略小于 1，缺口正是通道里的"无主能量"——测量噪声、非线性成分、以及被平均次数压不下去的随机起伏。读图时这个缺口本身就是信息：虚拟相干和贴近 1，说明该通道的能量几乎全部能被前几个虚拟源解释；和明显小于 1，先怀疑通道噪声或非线性，再怀疑源数目估计不足。

## 四、四种相干的分工：一张账本视角的对照

把常相干、重相干、偏相干、虚拟相干放在一起，工程上容易混。用"账本"视角看会清楚很多：

- **常相干（式 3-16）**：两个"总账"之间的关系。$\gamma^2 = |S_{ij}|^2/(S_{ii} S_{jj})$，回答"这两个通道的线性关联有多强"，但两个通道各自都是混合物，拆不开成分。单输入单输出系统（锤击 FRF 的质量检查）是它的主场。
- **重相干（式 3-17）**：一个"总账"对一组"分账"的整体关系。回答"这组参考输入合计解释了输出的多大比例"，用于检验多输入 FRF 测量里输出端的噪声含量。它给的是合计，不给明细。
- **偏相干（式 3-18）**：扣除其它信号影响后的"净关系"。回答"排除干扰之后，这两个信号还剩多少线性关联"，适合已知干扰通道、想看净贡献的场合。
- **虚拟相干（式 3-19）**：真实通道对"虚拟分表"的逐源归因。回答"这个通道的能量里有百分之几来自第 i 个虚拟源"，是四者中唯一给出逐源明细的工具——前提是先做主分量分解。

一句话分工：常相干看两两、重相干看合计、偏相干看净额、虚拟相干看明细。做源数目鉴别时，PCS 特征值谱给"几个源"的结论，虚拟相干给"各占多少"的明细，两者配套使用——这也是手册把主分量谱与虚拟相干放在同一小节的原因。

## 五、numpy 演示：重叠频带内两个源的逐通道归因

光看公式不过瘾，跑一个可复现的数值实验。构造两个独立的宽带随机源，频带故意重叠（34-40 Hz 与 36-42 Hz），按不同的"传播向量"混进 4 个通道，再加 5% 噪声。在 38 Hz 这根谱线上——两源都有能量的重叠区——做主分量分解，再算各通道与两个虚拟源的虚拟相干：

```python
import numpy as np
from scipy import signal

fs, T = 4096, 8.0
t = np.arange(0, T, 1/fs)
rng = np.random.default_rng(11)
def band(lo, hi, seed):
    r = np.random.default_rng(seed)
    w = r.standard_normal(len(t))
    sos = signal.butter(4, [lo/(fs/2), hi/(fs/2)], 'bandpass', output='sos')
    return signal.sosfilt(sos, w)
s1, s2 = band(34, 40, 1), band(36, 42, 2)          # 两个独立宽带源，频带重叠
s1, s2 = 2.0*s1/np.std(s1), 1.0*s2/np.std(s2)      # 源2 幅度一半
A = np.array([[0.9, 0.4], [0.6, -0.7], [0.3, 0.8], [-0.5, 0.6]])
X = A @ np.vstack([s1, s2]) + 0.05*rng.standard_normal((4, len(t)))

N = 4096; win = np.hanning(N)
freqs = np.fft.rfftfreq(N, 1/fs); K = freqs.size
S = np.zeros((4, 4, K), complex); nblk = 0
for b in range(0, len(t)-N, N//2):                 # Welch 平均互谱矩阵
    Xk = np.fft.rfft(X[:, b:b+N]*win, N, axis=1)
    for kk in range(K):
        S[:, :, kk] += np.outer(Xk[:, kk], Xk[:, kk].conj())
    nblk += 1
S /= nblk

i = np.argmin(abs(freqs - 38.0))                    # 38 Hz 谱线：两源重叠区
lam, U = np.linalg.eigh(S[:, :, i])                 # 逐谱线特征分解
o = np.argsort(lam)[::-1]; lam, U = lam[o].real, U[:, o]
print("特征值:", np.round(lam, 1))
for j in range(4):
    vc = [abs(U[:, r].conj() @ S[:, :, i][:, j])**2/(lam[r]*S[j, j, i].real) for r in range(2)]
    print(f"ch{j+1}: γ²v(PC1)={vc[0]:.3f}  γ²v(PC2)={vc[1]:.3f}  和={sum(vc):.3f}")
g12 = abs(S[0,1,i])**2/(S[0,0,i].real*S[1,1,i].real)
print("常相干 γ²(ch1,ch2)@38Hz =", round(g12, 3))
a1 = A[:,0]/np.linalg.norm(A[:,0]); a2 = A[:,1]/np.linalg.norm(A[:,1])
print("|<PC1,a1>|=", round(abs(U[:,0].conj()@a1),3), " |<PC2,a2>|=", round(abs(U[:,1].conj()@a2),3))
```

运行输出（可逐行复现）：

```
特征值: [3421708.5 1292797.8     4.0     1.8]
ch1: γ²v(PC1)=0.897  γ²v(PC2)=0.103  和=1.000
ch2: γ²v(PC1)=0.735  γ²v(PC2)=0.265  和=1.000
ch3: γ²v(PC1)=0.251  γ²v(PC2)=0.749  和=1.000
ch4: γ²v(PC1)=0.723  γ²v(PC2)=0.277  和=1.000
常相干 γ²(ch1,ch2)@38Hz = 0.42
|<PC1,a1>|= 0.995  |<PC2,a2>|= 0.99
```

三个读数各说明一件事。**特征值**：前两条（3.4e6、1.3e6）并肩立着、后两条（4.0、1.8）贴地——断崖在第 2 条之后，独立源数目为 2，与构造一致。**虚拟相干**：通道 1 的能量 89.7% 归虚拟源 1、10.3% 归虚拟源 2；通道 3 反过来，74.9% 归虚拟源 2——四个通道逐源切分、每行加和恰为 1.000，没有无主能量。对照传播矩阵 $A$ 的列能量比例（$|a_{j1}|^2/(|a_{j1}|^2+|a_{j2}|^2)$ 依次约 0.84/0.42/0.12/0.41），归因结果与真实占比的排序与量级一致，偏差来自随机谱估计的有限平均次数。**常相干对照**：同样两个通道，常相干只有 0.42——它把"两源叠加"与"同源传播"搅在一起，读不出任何归因信息；虚拟相干把它拆成了两行明细。最后两行验证方向：PC1 与真实传播方向 $a_1$ 的内积 0.995、PC2 与 $a_2$ 内积 0.99——虚拟源不仅能量分得对，空间指向也与真实源吻合。

回到第一节的四个座位：若 38 Hz 的峰主要来自动力总成，前排两座位（离源近）的 γ²v(PC1) 会高、后排低；若悬架簧下模态是第二贡献者，靠近悬架安装点的座位 γ²v(PC2) 抬升。一张虚拟相干图，"谁听到的响是谁发出的"逐格填清。

## 六、在 Simcenter Testlab 里算虚拟相干

手册指出，主分量可由时域抽样数据或响应的线性谱求得；相关软件把主分量技术用于分解多输入问题，并把分解后的数据组馈入动画显示程序。工程上两条常用路径：

- **Testlab Classic（Spectral Testing / Signature / Time Data Processing）**：多参考通道的互谱矩阵在处理时逐谱线分解，主分量谱与虚拟相干作为输出量可选；参考通道组在通道设置里指定，特征值曲线按大小排序输出。
- **Testlab Neo Process Designer**：互谱矩阵类方法（Cross Matrix 系）输出到 Principal Component 相关方法，主分量谱、参考向量与虚拟相干作为可路由的输出，配合 Animation 显示 $[U]$ 列向量对应的工作变形。

操作要点有三个。第一，参考通道要覆盖"所有关心的源都能传到"的位置——通道组漏掉某个源，该源就在分解里消失，剩余通道的归因比例会虚高。第二，源数目 r 明显小于通道数 n 时断崖更清晰，通道数不必贪多，但至少要 ≥ 期望的最大源数。第三，报告结论时同时给出平均次数与频率分辨率——虚拟相干是有偏估计，平均次数不足时数值系统性偏低，断崖位置与归因排序却相对稳健。

## 七、小结

- 常相干在多源场合失灵的根源：原始通道是混合物，混合物之间的相关拆不出成分。
- 虚拟相干两步走：主分量分解造出两两不相关的虚拟源（式 3-20），再算真实通道与各虚拟源的常相干（式 3-19）。
- 封闭账本性质：无噪声时各虚拟源对同一通道的虚拟相干之和为 1；实测缺口即无主能量（噪声/非线性）的指示。
- 四种相干分工：常相干看两两、重相干看合计、偏相干看净额、虚拟相干看明细；PCS 特征值谱给源数，虚拟相干给各源占比。
- 数值演示验证：重叠频带内两源混合，特征值断崖正确给出源数 2，四通道归因加和为 1.000，虚拟源方向与真实传播方向内积 0.99 以上。

## 一句话记住

虚拟相干是"分水表读数"：先用主分量分解把混叠通道解成互不相关的虚拟源（分表），再算每通道对各虚拟源的常相干（读数），逐源归因、加和为 1——常相干说不清的"谁贡献了多少"，一张虚拟相干图填明。
