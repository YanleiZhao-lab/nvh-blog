# 信号过载与削波畸变：三类过载的识别与量程设置

> 过载（Overload）指输入信号电压超出传感器或数据采集系统可处理的电压范围，超出部分被削波（Clipping），数据的幅值与频率内容同时失真。本文依据 Simcenter Testing Knowledge Base 的 Overloads 专题：区分三类过载（采集系统、传感器、带外）的发生位置与处置方法；从傅里叶级数出发解释谐波畸变的产生机理，给出削波后基波幅值的解析解与数值验证；最后给出量程设置（电平指示条、自动量程、余量）的推荐做法与过载报告的定位方法。

## 一、三类过载：发生位置与识别特征

过载指输入信号电压超出传感器或数据采集系统可处理的电压范围，超出量程的数据被**削波（Clipping）**——波形顶部被限制在量程上限。

过载可能发生在测量链路的三个不同位置，识别特征与处置方法各不相同：

| 过载类型 | 发生位置 | 典型特征 | 处置方向 |
| --- | --- | --- | --- |
| **采集系统过载**（DAQ Overload） | DAQ 前端量程低于输入信号范围 | 前端红灯、过载标志置位 | 加大量程（多数 SCADAS 最大 10 V） |
| **传感器过载**（Transducer Overload） | 传感器本体超限，信号在数字化之前已被削波 | DAQ 量程富余仍出现削波 | 换低灵敏度传感器（如 100 mV/g 换 10 mV/g） |
| **带外过载**（Out-of-band Overload） | 带宽外的高幅值频率成分超出量程 | 带内数据正常，系统仍报警 | 外接低通滤波器，或换低灵敏度传感器 |

![1V 正弦被 0.5V 量程削顶](/images/overload-clipping-distortion/clip-time-domain.png)
*（图源：Simcenter Testing Knowledge Base）*

采集系统过载最容易识别：DAQ 前端量程低于输入信号范围时，超出部分被削平，前端红灯亮起并置位过载标志。

传感器过载发生在数字化之前：被测物理量超出传感器额定范围时，传感器输出在进入 DAQ 之前已经削波——即使 DAQ 量程大于信号范围也无法恢复。排查时应核对传感器数据手册给出的最大测量范围：例如额定 500g 的加速度计，若读数已接近 500g，传感器本身可能已经过载。处置方法是改用低灵敏度传感器，例如 100 mV/g 改 10 mV/g——同样振动量级下输出电压降低为原来的 1/10。

带外过载最难诊断：超出设定带宽的频率成分幅值高于系统量程上限时，带宽内显示的数据仍在范围内，系统却指示过载。两种处置方法及各自的限制：

- 换低灵敏度传感器：降低电压幅值，但信噪比随之下降；
- 外接低通滤波器：滤除引起过载的高频成分；外接滤波器自身需要比采集系统更大的量程，否则滤波器会先过载。

::: warning 带外过载同样影响全部数据
手册明确警告：即使过载发生在分析带宽之外，谐波畸变仍会出现在整个频率范围内，带外过载同样影响带内数据。抗混叠滤波器能够防止频率混叠，但不能阻止超出量程的电压在前端造成的削波。
:::

## 二、畸变机理：削波的傅里叶展开与谐波畸变

时域削波的极限情形是把正弦形状的信号切成方波形状。幅值为 C 的方波（基频 $\omega = 2\pi f$，C 单位 V）的傅里叶级数只含奇次谐波：

$$x_{\text{sq}}(t) = \frac{4C}{\pi}\left(\sin\omega t + \frac{1}{3}\sin 3\omega t + \frac{1}{5}\sin 5\omega t + \cdots\right)$$

即谐波次数 k = 1, 3, 5, …，幅值按 $A_k \propto 1/k$ 衰减，理论上延伸到无穷频率——方波的能量分布在基频及其全部奇次谐波上。

实测信号中，不同频率、不同相位的正弦分量在不同时刻被削顶，相当于在整个时间轴上产生许多周期各异的方波段；这些方波的基频各不相同，其奇次谐波相互叠加，把能量分布到整个频率范围。这一现象即**谐波畸变（Harmonic Distortion）**。

手册的对比实验：同一瞬态信号（范围 1 V）分别用 10 V 和 0.16 V 量程采集。0.16 V 量程下信号时域削顶，频域上过载信号的谱内容从低频到高频整条抬升——不只是基频幅值错误，整个测量带宽内的幅值与噪声水平都发生了变化。手册的示意图显示：即使只有三、四个不同频率的方波叠加，谐波畸变就已显著改变整条频谱。

### 削波后基波幅值的解析解

削波对频谱的影响可以定量计算。设正弦信号幅值为 A（V），量程上限为 C（V，C < A）。利用削波波形的奇对称与半波对称性（偶次谐波为零），基波系数为四分之一周期上的积分：

$$b_1 = \frac{4}{\pi}\int_0^{\pi/2} x(\theta)\sin\theta\,\mathrm{d}\theta$$

削波波形在四分之一周期内分两段：$\theta \le t_c$ 时 $x = A$ 段保持正弦、$\theta > t_c$ 段被限制在量程上限，其中削波起始角

$$t_c = \arcsin\frac{C}{A}$$

代回积分得基波幅值：

$$b_1 = \frac{4}{\pi}\left[\int_0^{t_c} A\sin^2\theta\,\mathrm{d}\theta + \int_{t_c}^{\pi/2} C\sin\theta\,\mathrm{d}\theta\right] = \frac{4}{\pi}\left[A\left(\frac{t_c}{2} - \frac{\sin 2t_c}{4}\right) + C\cos t_c\right]$$

两个极限情形可核对公式：C 大于等于 A（无削波）时 $t_c = \pi/2$，$b_1 = A$，基波不受影响；C 远小于 A（深度削波）时 $b_1 \to 4C/\pi$，退化为方波的基波幅值。A = 1 V、C = 0.16 V 时 $b_1 = 0.203$ V，基波幅值被低估 79.7%，该解析解与第三节的 FFT 数值结果一致。

衡量削波程度的常用指标是**总谐波畸变（THD, Total Harmonic Distortion）**——全部谐波与基波的幅值比：

$$\mathrm{THD} = \frac{\sqrt{A_2^2 + A_3^2 + A_4^2 + \cdots}}{A_1}$$

其中 $A_k$ 为第 k 次谐波幅值（V）。对称削波保持半波对称性，偶次谐波为零，THD 只由奇次谐波贡献。

::: info 核心概念
- **削波（Clipping）**：信号超出量程被切平顶部，时域幅值失真
- **谐波畸变（Harmonic Distortion）**：削波在频域的后果，奇次谐波分布于整个分析带宽
- **总谐波畸变（THD, Total Harmonic Distortion）**：全部谐波与基波的幅值比，衡量削波程度
:::

## 三、数值验证：削波深度与频谱损伤

复现手册实验：1 V 峰值正弦，采集量程 ±0.16 V，观察频谱失真的程度。

```python
import numpy as np

# 手册场景复现: 1V 峰值正弦, 采集量程 ±0.16V
fs = 4096; N = fs
t = np.arange(N) / fs
sig = 1.0 * np.sin(2*np.pi*50*t)      # 50 Hz 正弦, 峰值 1V
clipped = np.clip(sig, -0.16, 0.16)   # 量程 ±0.16V → 削顶

win = np.hanning(N)                   # 汉宁窗抑制泄漏
def amp(x):                           # 幅值谱(能量校正)
    return np.abs(np.fft.rfft(x*win)) * 2 / win.sum()

X, Xc = amp(sig), amp(clipped)
f = np.fft.rfftfreq(N, 1/fs)
i = lambda fc: np.argmin(np.abs(f - fc))

print(f"50Hz 基频幅值: 原始 {X[i(50)]:.3f} V | 削波后 {Xc[i(50)]:.3f} V")
print(f"150Hz 3次谐波: 原始 {X[i(150)]:.5f} V | 削波后 {Xc[i(150)]:.5f} V")
print(f"350Hz 7次谐波: 原始 {X[i(350)]:.5f} V | 削波后 {Xc[i(350)]:.5f} V")
thd = np.sqrt(sum(Xc[i(50*k)]**2 for k in range(3, 21, 2))) / Xc[i(50)]
print(f"削波信号奇次谐波 THD: {thd*100:.1f}%  (纯正弦应为 0%)")
```

运行结果：基频从 1 V 降至 0.203 V（低估 79.7%，与第二节解析解一致）；原始信号中为 0 的 3 次谐波出现 0.065 V、7 次谐波出现 0.023 V；奇次谐波 THD 为 39.9%。一次过载，幅值与频率内容同时失真。

改变削波深度，把阈值从量程富余扫到严重不足：

```python
import numpy as np

# 削波深度扫描: 阈值从 1.5V (富余) 到 0.16V (严重不足)
fs = 4096; N = fs
t = np.arange(N) / fs
sig = 1.0 * np.sin(2*np.pi*50*t)
win = np.hanning(N)
def amp(x):
    return np.abs(np.fft.rfft(x*win)) * 2 / win.sum()
f = np.fft.rfftfreq(N, 1/fs)
i = lambda fc: np.argmin(np.abs(f - fc))

print(f"{'削波阈':>7} {'基波幅值':>9} {'基波误差':>9} {'THD':>7}")
for v in [1.5, 1.05, 0.9, 0.7, 0.5, 0.16]:
    X = amp(np.clip(sig, -v, v))
    fund = X[i(50)]
    thd = np.sqrt(sum(X[i(50*k)]**2 for k in range(3, 21, 2))) / fund
    print(f"{v:>6.2f}V {fund:>8.3f}V {(fund-1)*100:>8.1f}% {thd*100:>6.1f}%")
```

运行结果（THD 计入 3–19 次奇次谐波）：

| 削波阈值 | 基波幅值 | 基波误差 | THD |
| --- | --- | --- | --- |
| 1.50 V（富余） | 1.000 V | -0.0% | 0.0% |
| 1.05 V（刚超出） | 1.000 V | -0.0% | 0.0% |
| 0.90 V | 0.963 V | -3.7% | 4.2% |
| 0.70 V | 0.812 V | -18.8% | 13.8% |
| 0.50 V | 0.609 V | -39.1% | 23.3% |
| 0.16 V | 0.203 V | -79.7% | 39.9% |

基波误差与 THD 随削波深度单调增大：阈值 0.90 V 只比信号峰值低 10%，基波误差已达 3.7%、THD 4.2%。削波对数据质量的影响在信号刚超出量程时即已出现，量程设置应保证信号峰值不触及量程上限。

## 四、量程设置：电平指示条、自动量程与余量

Simcenter Testlab 的 Acquisition Setup 界面提供电平指示条，用于判断量程设置是否合适：

| 指示条颜色 | 含义 | 动作 |
| --- | --- | --- |
| **白** | 量程过大，信噪比差 | 缩小量程 |
| **绿** | 设置合适 | 保持 |
| **橙** | 信号进入量程上限/余量（overhead）区域 | 可接受，注意瞬态尖峰 |
| **红** | 量程过低，通道过载 | 立即加大量程或更换传感器 |

自动量程（Auto-ranging）按三步操作：start ranging、hold level、set ranges，系统据此把各通道量程设到合适水平，降低过载风险。

余量（Overhead）是为数据中的尖峰预留的安全空间：自动量程按信号电平乘以余量系数设置量程。常用设置为 6 dB，对应电压安全系数为

$$10^{6/20} \approx 2$$

即量程按信号峰值的两倍设置（信号占满量程的约 50%）。路面冲击、关门、启停等瞬态成分较多的工况可适当加大余量。余量值在 Range Checking 窗口（自动量程面板的 More 按钮后）中设置，同时建议勾选 Use full range when auto-ranging。

::: tip 为什么不建议一直使用最大量程
- 一直使用最大量程（如 10 V）虽然避免了过载，但小信号只占用 ADC 的低位比特：量化步长 q = U/2^B（B 为 ADC 位数，U 为量程，单位 V）随量程增大而增大，小信号的相对量化误差增大、信噪比下降；
- 勾选 Use full range when auto-ranging 后，自动量程从满量程出发、将增益向下调整到恰好容纳信号，同时降低过载风险与量化误差；若不使用满量程，自动量程过程中发生过载时增益每次只调整一个档位，可能不足以避免下一次过载；
- 推荐做法：预采一段工况数据，自动量程 + 6 dB 余量，使信号落在量程的中上部。
:::

## 五、过载报告：通道与时刻的定位

测量结束后，Accept or reject run 对话框会提示本次 run 是否出现过载，并生成过载报告（对话框可在设置中抑制）。在 Navigator 中浏览到该 run，可见 OnlineOverloadLogging 与 OfflineOverloadLogging 两份报告；右键选择 view，在 File view 窗口双击 .txt 文件即可打开详细报告，内容为哪些通道、在哪些时刻发生过载。

依据报告结果的定位建议：

- 过载时刻与转速/工况对应 → 真实信号超出量程，处置传感器端（换低灵敏度传感器或加大量程）；
- 过载时刻随机分布 → 可能是带外高频成分或干扰，检查屏蔽与外接滤波；
- 单一通道反复过载 → 核对该通道的灵敏度设置与实际传感器是否匹配。

## 六、小结

过载的影响不限于超限的那段采样点：削波产生的奇次谐波分布于整个分析带宽，带内数据正常也可能存在带外过载。处置顺序：先查过载报告定位通道与时刻，再区分三类过载（采集系统、传感器、带外）并按对应方法处置；量程设置采用自动量程加 6 dB 余量，瞬态工况适当加大。出现过载的数据不应直接用于分析结论。
