# FIR 滤波器设计三路线：单窗、频域抽样与 Remez 交换

> 前置滤波要保相位，在 Testlab 中打开 FIR 设计界面会看到三条路线：Single Window（单窗）、Multiple Window（多重窗）、Remez（雷蒙兹）。同一组指标下，路线的选择决定了通带形态、窄带选频能力和可调节的参数范围。本文依据 Simcenter Testing Knowledge Base 中文理论手册第十二章 12.2.2 节，梳理三条路线的推导链条、性能对比与工程选型依据：单窗法从傅里叶级数截断出发，用窗函数控制级数收敛；频域抽样法在单位圆 N 等分点上直接规定频响值，经逆 DFT 得到系数；Remez 交换算法基于切比雪夫逼近理论，使最大加权误差在各频带上均匀分布且达到最小。

## 一、问题的起点：理想频响对应无限长冲激响应

FIR（Finite Impulse Response，有限冲激响应）滤波器设计的基本问题：给定期望的频率响应 $H_d(\omega)$，求有限长系数 $h(n)$（$n = 0, 1, \ldots, N-1$），使实际频响逼近它。

数学出发点是傅里叶级数展开。任何以 $2\pi$ 为周期的期望频响都可以展开为：

$$H_d(\omega) = \sum_{n=-\infty}^{+\infty} h_d(n)\, e^{-j\omega n}$$

展开系数（即傅里叶级数系数）恰好就是冲激响应：

$$h_d(n) = \frac{1}{2\pi}\int_{-\pi}^{\pi} H_d(\omega)\, e^{j\omega n}\, d\omega$$

以理想低通（截止角频率 $\omega_c$，单位 rad；对应正则化频率 $f_c = \omega_c / 2\pi$，无量纲）为例，积分可得 $h_d(n) = \sin(\omega_c n) / (\pi n)$——一个以 $n=0$ 为中心、向正负无穷缓慢衰减的 sinc 序列。

困难在此处出现：**该序列从 $-\infty$ 开始且无限长，物理上不可实现**。需要做两件事：截断（只保留有限项）与平移（使其在 $n \geq 0$ 上因果化）。简单直接的矩形截断会引发吉布斯现象（Gibbs Phenomenon）——频响在通带边沿出现过冲与波纹，级数在间断点附近不收敛。

![傅里叶级数直接截断引起的吉布斯现象：过冲与振铃](/images/fir-design-three-ways/fig12-6-gibbs.png)

*直接截断的冲激响应在频域留下约 9% 的边沿过冲和一片振铃（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-6）*

三条设计路线，是对"无限长 vs 有限长"这一矛盾的三种不同处理方式。

::: info 核心概念
- **正则化频率（Normalized Frequency）**：频率（Hz）除以采样率（Hz），无量纲，滤波器工作范围为 0 至 0.5；单位圆上角频率（rad）= 正则化频率 × 2π
- **吉布斯现象（Gibbs Phenomenon）**：矩形截断傅里叶级数时，频响间断点附近出现的固定幅度过冲与振铃
- **频域抽样设计（Frequency Sampling Design）**：在单位圆 N 等分点上直接规定期望频响值，逆 DFT 得到滤波器系数
- **等波纹逼近（Equiripple Approximation）**：Remez 交换算法的核心思想，使通带和阻带的最大加权误差相等且最小
:::

## 二、先明确一个约束：线性相位要求冲激响应对称

FIR 相对 IIR 的结构性优势是**精确线性相位**。频响写成 $H(\omega) = |H(\omega)| e^{j\theta(\omega)}$，线性相位即 $\theta(\omega) = -\alpha\omega$（$-\pi \leq \omega \leq \pi$）：所有频率成分统一延迟 $\alpha$ 个采样点，波形形状不发生色散。

推导该约束只需一步卷积论证。要求 $\theta(\omega) = -\alpha\omega$，等价于 $h(n)$ 满足对称（偶对称）条件：

$$h(n) = h(N-1-n)$$

且此时 $\alpha = (N-1)/2$。物理意义：滤波器将信号整体延迟 $(N-1)/2$ 个采样点，除此之外不引入相位失真。注意结论的细节——**对任一 N 值，只有一个 α 值能使滤波器获得精确线性相位**：延迟量由系数长度唯一确定，不可调节。

![N 为奇数与偶数时对称冲激序列的两种形态](/images/fir-design-three-ways/fig12-2-symmetry.png)

*N 为奇数时对称轴落在整数采样点上，N 为偶数时落在两个采样点之间（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-2）*

N 取奇数还是偶数有实际差别：奇数（I 型）对称轴在整数点上，可以实现低通、高通、带通任意频响；偶数（II 型）在 $\omega = \pi$ 处频响强制为零，做高通存在先天限制。选择长度时需要先确认这一点。

## 三、路线一：单窗法——用窗控制级数收敛

单窗法是对吉布斯现象的直接应对。矩形截断等价于乘矩形窗，使级数在间断点附近振荡；改用两端平滑衰减到零的窗函数去乘冲激响应，即可控制级数收敛：

$$h(n) = w(n) \cdot \hat{h}(n)$$

其中 $w(n)$ 为窗序列，$\hat{h}(n)$ 为期望的（平移因果化后的）冲激响应，均无量纲。时域相乘对应频域卷积：实际频响等于期望频响与窗谱的卷积，窗谱主瓣宽度决定过渡带宽度、旁瓣电平决定阻带衰减。手册给出窗函数的两条理想特性：**主瓣窄且涵盖尽可能多的能量；$\omega$ 趋向 π 时旁瓣能量快速衰减**。

手册列举了 LMS 产品支持的几种窗，均有闭式表达式（定义域 $-(N-1)/2 \leq n \leq (N-1)/2$）：

| 窗函数 | 表达式要点 | 特性定位 |
| --- | --- | --- |
| **矩形窗** | $W(n)=1$ | 等同直接截断，吉布斯现象的来源 |
| **汉宁窗** | $W(n) = \alpha + (1-\alpha)\cos\frac{2\pi n}{N}$，取 $\alpha = 0.5$ | 截断宽度与波纹抑制的折中 |
| **哈明窗** | 同上式取 $\alpha = 0.54$ | 旁瓣电平低于汉宁窗 |
| **凯塞窗** | $W(n) = I_0\left(\beta\sqrt{1-\left(\frac{2n}{N-1}\right)^2}\right) / I_0(\beta)$，$I_0$ 为零阶贝塞尔函数 | 限带能量泄漏最小的近似最优窗 |
| **切比雪夫窗** | 切比雪夫多项式 $T_r(x)$ 的逆 DFT | 给定频率限外谱能量最小的另一最优窗 |

两种"最优窗"需要说明。凯塞窗是长球面波函数的简化近似，其傅里叶变换接近限带函数，**溢出到选定频带外的能量最小**；切比雪夫窗利用 $T_r(\cos\theta) = \cos(r\theta)$ 的多项式递推（$T_{r+1}(x) = 2x\,T_r(x) - T_{r-1}(x)$），在给定旁瓣电平下主瓣最窄，窗序列由多项式的逆 DFT 直接计算。两者都是"可调窗"：一个参数同时决定主瓣宽度与旁瓣电平——凯塞窗的 $\beta$ 反映旁瓣波纹高度与主瓣宽度之间的折中。

::: warning 单窗法的局限
窗函数一旦选定，频响的所有特征（过渡带宽度、波纹、阻带衰减）即由窗谱整体决定——通带和阻带的波纹**不能分别指定**，过渡带宽度除改变窗长外无法独立微调。需要同时约束多个指标时，单窗法无法满足，需采用后两条路线。
:::

## 四、路线二：频域抽样——把频响直接规定在 DFT 格点上

第二条路线更换思路：FIR 滤波器的频响可由其 DFT 系数完全规定（DFT 系数即 Z 变换在单位圆 N 等分点上的抽样值），因此可以**反向操作**——先在单位圆 N 等分点上规定期望频响 $H(k)$，再逆 DFT 得到滤波器系数。

推导链条如下。滤波器冲激响应的 DFT 为：

$$H(k) = \sum_{n=0}^{N-1} h(n)\, e^{-j2\pi kn/N}$$

单位圆 N 等分点即 $z_k = e^{j2\pi k/N}$（因 $e^{j2\pi} = 1$，可由此关系证明上式的抽样性质）。设计时直接给定每个格点上的 $H(k)$（例如通带格点取 1、阻带格点取 0、过渡带格点取 0 与 1 之间的值），然后：

$$h(n) = \frac{1}{N} \sum_{k=0}^{N-1} H(k)\, e^{j2\pi kn/N}$$

手册指出该路线的适用场景：**设计具有任意滤波特性的滤波器，特别适合窄带可选择性滤波器**。原因在于格点频率上频响精确等于规定值（N 个方程 N 个未知数，精确确定），窄带滤波器只需在通带附近设置少数非零格点、其余取零，系数天然稀疏、选频性好。

手册还记载了该方法的后续步骤：连续频响由单位圆抽样值插值得到，滤波器系数由插值频响作逆 FFT 得出；**如有需要，可再用给定窗函数倍乘冲激响应，使系数端部平滑缩减至零**——频域抽样与再加窗平滑的组合，正对应 Testlab 界面中 Multiple Window（多重窗）设计的实际流程。

代价在格点之间。两个 DFT 格点中间的频响由插值得到，期望频响越陡（间断特征越尖锐），格点间的实际频响振荡越明显。缓解办法是在过渡带人为设置一到两个"过渡点"（取 0 与 1 之间的值），以通带边沿的轻微退让换取阻带衰减的改善；过渡点的取值需要与格点位置匹配，并非设置越多改善越大（第六节的数值实验可验证）。

## 五、路线三：Remez 交换——最大误差最小化的等波纹解

第三条路线是 FIR 设计中最优意义上的解：它不评价"频响像不像"，而是求解"最大偏差能压到多小"。

问题设定：期望频响表示为若干个频带组成的样板（通带、过渡带、阻带），在频带内添加密集的格子，定义加权逼近误差：

$$E(\omega) = W(\omega)\,\left[H_d(\omega) - H(\omega)\right]$$

Parks-McClellan 算法利用切比雪夫逼近理论，使该误差的**最大值在所有频带上均匀分布且达到最小**。数学上由交错定理（Alternation Theorem）保证：最优解的误差曲线在通带和阻带内等幅振荡，正负交替达到 $|\delta|$ 的极值点至少有 $(N+1)/2$ 个（N 为滤波器长度）。

![Remez 滤波器的逼近误差在通带和阻带内等波纹分布](/images/fir-design-three-ways/fig12-7-remez-error.png)

*最优解的标志：通带与阻带的逼近误差峰谷等高（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-7）*

滤波器指标涉及的三项术语（通带波纹 $\delta_1$、阻带衰减 $\delta_2$、过渡带宽度）标示于滤波特性图：

![低通滤波器的滤波特性术语](/images/fir-design-three-ways/fig12-1-filter-spec.png)

*表述低通滤波器特性的三项指标：通带波纹、阻带衰减与过渡带宽度（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-1）*

加权函数 $W(\omega)$ 是工程上的关键参数。规格化做法是阻带取 $W = 1$、通带取 $\delta_2 / \delta_1$（两个误差限之比）：

- 所有频带权取 1 → 误差在通带和阻带均匀分布，两侧波纹幅度相同
- 需要压低某个特定频带的波纹 → 给该频带相对更大的权，代价是其他频带波纹变大

对优化后的频响作一次逆 DFT，即得滤波器系数。

::: tip 与前两条路线的实质区别
单窗法的波纹由窗谱整体决定、频域抽样法的格点间行为由插值决定，Remez 是唯一能把**通带波纹、阻带衰减、过渡带宽度三项同时写进指标再解出最短长度**的方法。相同指标下 Remez 的阶次通常低于单窗法（经验上可省一至三成，视指标组合而定），代价是设计过程需迭代求解、不能手算。
:::
## 六、数值实验：同一指标，三条路线的对比

用理想低通（截止正则化频率 0.25、长度 41）做对照：单窗法取汉宁窗截断 sinc；频域抽样法在 41 个格点上规定通阻值再逆 DFT，并对比不加/加一个过渡点的结果。Remez 的等波纹解需迭代求解，超出 numpy 演示范围，前两条路线的差距已足以说明问题。

```python
import numpy as np

N = 41                 # 滤波器长度（奇数，I 型，对称轴在整数点）
fc = 0.25              # 正则化截止频率（0~0.5）
f = np.arange(8192) / 16384            # 细化频率轴（0~0.5）

def report(name, h):
    H = np.abs(np.fft.fft(h, 16384))[:8192]
    sb = H[(f > 0.32) & (f < 0.45)]    # 阻带（离开过渡带后度量）
    pb = H[(f > 0.05) & (f < 0.15)]    # 通带
    print(name, round(float(np.max(np.abs(pb - 1))), 4), round(20 * np.log10(float(np.max(sb))), 1))

# ---- 路线一：单窗法（汉宁窗截断理想 sinc）----
m = np.arange(N) - (N - 1) / 2
nz = m != 0                          # n=0 处取极限值 2*fc，避免 0/0
h_ideal = np.zeros(N)
h_ideal[nz] = np.sin(2 * np.pi * fc * m[nz]) / (np.pi * m[nz])
h_ideal[~nz] = 2 * fc
win = 0.5 - 0.5 * np.cos(2 * np.pi * np.arange(N) / (N - 1))
report("danchuang-hanning", win * h_ideal)

# ---- 路线二：频域抽样（格点钉 0/1 + 线性相位因子，逆 DFT）----
k = np.arange(N)
fg = np.minimum(k, N - k) / N            # 折叠到 0~0.5 的格点频率
phase = np.exp(-1j * np.pi * (N - 1) * k / N)   # (N-1)/2 延迟的相位因子
Hk = (fg <= fc).astype(float) * phase
report("freq-sampling", np.real(np.fft.ifft(Hk.astype(complex))))

# ---- 路线二变体：在 k=11（fg=0.268，紧邻截止）加一个 0.5 过渡点 ----
Hk_t = Hk.copy()
Hk_t[11] = 0.5 * phase[11]
report("sampling-transition", np.real(np.fft.ifft(Hk_t.astype(complex))))
```

运行输出（波纹为线性幅值，阻带为对数幅值）：

```text
danchuang-hanning     0.0008  -54.6
freq-sampling         0.0195  -23.7
sampling-transition   0.0109  -31.6
```

三个结果的分析：

- 汉宁窗把阻带压到 -55 dB 以下、通带波纹接近零；朴素频域抽样（不加过渡点）阻带只有 -24 dB 左右——**格点间靠插值，振荡能量直接泄漏进阻带**。
- 在紧邻截止频率的格点取 0.5 作为过渡点，阻带即改善约 8 dB 至 -31.6 dB，同时通带波纹反而减小。但过渡点取值需要与格点位置匹配：本例中若改设两个过渡点（0.5、0.25），实测阻带反而回落到 -25 dB 附近——过渡点并非越多越好，取值不当会抵消收益。要进一步改善，应交给 Remez。
- 一个实现细节：频域抽样的格点值必须乘上 $e^{-j\pi(N-1)k/N}$ 相位因子（对应 $(N-1)/2$ 的线性相位延迟），否则逆 DFT 得到的冲激响应不对称，阻带衰减退化到约 -3 dB，滤波器不可用。
## 七、三条路线怎么选

| 维度 | **单窗法** | **频域抽样** | **Remez 交换** |
| --- | --- | --- | --- |
| **设计自由度** | 由窗谱决定，指标不能分开设 | 格点值任意，多频带灵活 | 通带/阻带/过渡带指标独立 |
| **同指标阶次** | 最高 | 中等 | 最低（等波纹最优） |
| **窄带选频** | 一般 | **最强**（系数稀疏） | 强 |
| **设计复杂度** | 一次乘法 | 一次逆 DFT | 迭代求解 |
| **典型场景** | 快速原型、指标宽松 | 窄带滤波器组、倍频程滤波 | 指标严格的交付级滤波器 |
| **可手算性** | 可（窗有闭式） | 可（逆 DFT） | 不可 |

::: tip 选择原则
- 指标宽松、求快速实现且要求线性相位：单窗法 + 凯塞/切比雪夫可调窗，调整一个 β 参数扫描即可定稿
- 窄带选频（例如从宽带振动中提取单个阶次带）：频域抽样，通带格点数少、系数稀疏
- 通带波纹和阻带衰减都要写进验收条款：选 Remez，相同指标下其阶次最低
- 长度 N 定不下来：注意线性相位延迟 α=(N-1)/2 由长度唯一确定，实时性要求会反向约束 N
:::

一个容易忽略的工程细节：FIR 滤波器的启动瞬态为有限长时间（恰好 N-1 个采样点），而 IIR 理论上为无限长。处理瞬态冲击信号时，FIR 滤波后的前 N-1 点数据不可靠，做统计或幅值判读前应予剔除。
