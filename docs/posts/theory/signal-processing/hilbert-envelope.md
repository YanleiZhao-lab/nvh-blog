# 希尔伯特变换与包络分析：轴承故障诊断核心

> 轴承外圈剥落一处，振动信号里看到的往往不是故障频率，而是一串被结构共振"载波"的衰减冲击。希尔伯特变换（Hilbert Transform）给信号加上 90 度相移构成解析信号，其模就是包络——把高频共振解调下来，冲击的重复频率直接在包络谱上现形。Testlab 的包络分析与冲激量统计，底层都是这一套。

## 一、轴承故障信号的物理本质：冲击藏在共振里

滚道上剥落一块，滚动体每碾过一次就撞一下。撞击本身是宽带瞬态，能量很低，但它会激起轴承座、端盖这些结构件的固有频率——通常在几百 Hz 到几 kHz——形成一串周期性的衰减振荡。像钟被周期性地敲：听到的是钟的音调（共振频率），诊断要的是敲击的节拍（故障频率）。

直接对原始信号做 FFT 会得到什么？一片以共振频段为中心的毛糙隆起，故障频率及其谐波淹没在结构响应里。早期故障冲击能量小，隆起甚至都不明显。低通滤波提冲击更是走不通——冲击的重复频率（几十到几百 Hz）和齿轮啮合、轴不平衡这些低频干扰完全混在一个频段。

出路是借用通信工程的解调思路：把共振频段当成载波，把冲击序列当成调制信号，先带通滤波锁定载波，再取包络把调制信号还原。

::: info 核心概念
- **故障特征频率**：滚动体碾过缺陷产生的冲击重复率，外圈 BPFO、内圈 BPFI、滚动体 BSF、保持架 FTF，由轴承几何与转速算出
- **载波**：结构共振频段，被周期冲击激励，是故障信息的"搬运工"
- **调制**：冲击序列对共振幅值的周期性调制，解调即可还原冲击重复率
- **包络（Envelope）**：信号幅值轮廓的上边界，连接每个振荡峰值的光滑曲线
:::

## 二、希尔伯特变换：一行相移造出解析信号

包络怎么取？老办法是对信号整流加低通，缺陷是失真大、依赖手工调参。现代做法是希尔伯特变换。

时域里，希尔伯特变换把每个频率分量移相 90 度：余弦变正弦、正弦变负余弦，幅值不变。单看它没什么用，妙处在于和原信号拼在一起：z(t) = x(t) + j*H[x(t)]，构成解析信号（Analytic Signal）。原信号是实部，希尔伯特变换是虚部，两者正交，模长 |z(t)| = sqrt(x^2 + H^2) 就是瞬时幅值——包络。

![希尔伯特变换的单位样值响应](/images/hilbert-envelope/hilbert-impulse-response.png)

*希尔伯特变换的单位样值响应：逆对称序列（图源：LMS 检测理论手册）*

频域视角更直白：解析信号把负频率全部清零、正频率幅值加倍，频谱只剩"半边"。实现上就是 FFT、单边谱置零加倍、IFFT 三步，数值计算毫无障碍。

![希尔伯特变换的幅频特性](/images/hilbert-envelope/hilbert-magnitude-response.png)

*理想希尔伯特滤波器的幅频特性（图源：LMS 检测理论手册）*

理想希尔伯特变换器要求全频段幅值恒为 1、相位恒移 90 度，物理不可实现——它的单位样值响应是无限长的逆对称序列。工程实现用 FIR 滤波器逼近：限定通带下限与上限，通带内幅值逼近 1，再用窗函数截断逆对称冲激响应。这正是 FIR 滤波器设计里的一个特殊类型，LMS 手册把它和差分滤波器并列为 Remez 交换算法的两种典型应用。

::: warning 工程注意
希尔伯特变换的有效频带受 FIR 逼近精度限制，直流和奈奎斯特频率附近相移特性恶化。原始信号若含强低频成分（转速不平衡、刚体运动），包络会被这些分量扭曲，所以包络分析前必须带通滤波——通带选在共振频段上，既是选载波，也是给希尔伯特变换清理门户。
:::

## 三、包络分析全流程：带通、解调、包络谱

完整流程四步：

1. **算特征频率**。按轴承几何参数和实测转速算出 BPFO、BPFI、BSF、FTF，作为判读靶子。
2. **带通滤波**。通带罩住共振频段（从频谱或倒频谱上找那片毛糙隆起），把低频轴频干扰和无关高频清掉。
3. **希尔伯特解调**。对滤波后信号求解析信号，取模得包络，必要时再低通平滑。
4. **包络谱判读**。对包络做谱分析，峰值对准哪个特征频率，故障就在哪个部件。

第三步是全流程的灵魂。包络谱上，故障频率及其谐波成排出现，内圈故障还带着转频边带——缺陷相对传感器的位置周期变化，冲击幅值被转频调制。谐波族与边带的结构比单看一根峰线可靠得多。

| 判据 | 外圈故障 | 内圈故障 | 滚动体故障 |
| --- | --- | --- | --- |
| **包络谱主峰** | BPFO 及谐波 | BPFI 及谐波 | BSF（x2 更显）及谐波 |
| **边带特征** | 一般无（缺陷位置固定） | 正负转频边带明显 | 正负保持架转频边带 |
| **幅值稳定性** | 冲击幅值稳定 | 随缺陷转过传感器波动大 | 介于两者之间 |
| **机理** | 缺陷与负载区相对固定 | 缺陷旋转，负载区时进时出 | 滚动体自转加公转 |

::: tip 通带怎么选
- 没有现成共振信息：先看原始频谱找结构性隆起，或用 Testlab 包络分析预置频段试探
- 多个共振频段：优先选离齿轮啮合、轴频干扰远的那个
- 通带别贴着强离散谱线（如啮合频率）边缘，否则解调出虚假调制
:::

## 四、Python 演示：解调前后的天壤之别

```python
import numpy as np

# 演示：包络分析——从共振载波里解调出冲击频率
fs = 25600.0
t = np.arange(0, 1, 1/fs)
rng = np.random.default_rng(0)

# 模拟轴承外圈故障：每 5ms 撞一次（BPFO=200Hz），激起 2kHz 结构共振
f_fault, f_res = 200.0, 2000.0
sig = np.zeros_like(t)
for k in range(int(f_fault * 1.0)):      # 每个故障周期打一次冲击
    t0 = k / f_fault
    tk = t - t0
    m = (tk >= 0) & (tk < 0.01)
    sig[m] += np.sin(2*np.pi*f_res*tk[m]) * np.exp(-300*tk[m])  # 衰减振荡
sig += 0.3 * rng.standard_normal(len(t))  # 加噪声

def analytic(x):
    # 解析信号 = 原信号 + j*希尔伯特(原信号)：负频率清零、正频率加倍
    N = len(x)
    X = np.fft.fft(x)
    H = np.zeros(N); H[1:N//2] = 2.0
    return np.fft.ifft(X * H)

# 带通(1~3kHz)滤掉低频干扰 → 取包络 → 包络谱
X = np.fft.fft(sig)
ff = np.fft.fftfreq(len(t), 1/fs)
X[np.abs(ff) < 1000] = 0
X[np.abs(ff) > 3000] = 0
env = np.abs(analytic(np.fft.ifft(X).real))
E = np.abs(np.fft.rfft(env))
fe = np.fft.rfftfreq(len(t), 1/fs)
peak = fe[1:500][np.argmax(E[1:500])]
print(f"包络谱峰值频率 = {peak:.1f} Hz  (外圈故障频率 BPFO = {f_fault:.0f} Hz)")
print("2kHz 共振峰把冲击埋住，包络解调后一击一个准")
```

运行结果要点：包络谱峰值精确落在 200.0 Hz，与设定的外圈故障频率 BPFO 一致——原始频谱里这个频率根本看不见，解调后一击一个准。

```python
import numpy as np

# 演示：希尔伯特变换就是 90 度相移
fs = 1000.0
t = np.arange(0, 1, 1/fs)
x = np.cos(2*np.pi*10*t)                # 10 Hz 余弦

def hilbert_imag(x):
    # 解析信号虚部 = 希尔伯特变换：负频率清零、正频率加倍后取虚部
    N = len(x)
    X = np.fft.fft(x)
    H = np.zeros(N); H[1:N//2] = 2.0
    return np.fft.ifft(X * H).imag

h = hilbert_imag(x)
i = 25                                   # t=0.025s，即 1/4 周期处
print(f"t=1/4 周期:  x    = {x[i]:+.3f}  (cos 90度 = 0)")
print(f"            H[x] = {h[i]:+.3f}  (sin 90度 = +1)")
print(f"包络 |z| = sqrt(x^2 + H^2) = {np.hypot(x[i], h[i]):.3f} 处处为 1")
print("单频信号的包络是常数——没有调制信息")
```

运行结果要点：10 Hz 余弦的包络处处等于 1，单频信号无调制可言；包络谱的价值在幅值起伏的信号上，轴承冲击序列正是如此。

## 五、冲激量：包络的统计学延伸

包络解调出冲击，进一步的量化指标是冲激量（Impulsiveness）。LMS 检测理论手册里，冲激量基于包络分析计算：设一道阈值（综合总体 RMS、帧 RMS 与阈偏置），包络越过阈值算一次脉冲事件，统计出平均脉冲峰值电平、平均上升斜率、平均脉冲作用时间与脉冲发生率。

这套统计在柴油发动机噪声量化里是标配：燃烧冲击的强弱、疏密直接反映供油与燃烧品质。对轴承监测而言，冲激量类指标（连同峭度 Kurtosis）的价值在趋势管理——健康轴承振动接近高斯随机，峭度约 3；故障萌生时冲击占主导，峭度抬升，包络谱上特征频率从噪声地里冒头。冲击能量涨落大，单次读数别当判据，看趋势。

::: warning 工程注意
冲击传播路径复杂，传感器测到的是多重反射叠加的结果，实测包络波形远比教科书示意图凌乱。特征频率匹配要留容差——转速波动、轴承打滑都会让实际频率偏离理论值；确认故障需谐波成族、边带结构对得上，单根谱峰不立案。
:::

## 六、小结

包络分析是轴承故障诊断的标准打法：带通锁载波、希尔伯特解调、包络谱对特征频率。判读抓三条——主峰对准哪个特征频率、谐波是否成族、边带结构指向哪个部件。冲击类指标做趋势，包络谱做定位，两者配合比任何单一指标都硬。
