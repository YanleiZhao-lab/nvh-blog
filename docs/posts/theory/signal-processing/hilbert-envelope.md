# 希尔伯特变换与包络分析：轴承故障诊断

> 轴承滚道剥落产生的冲击是宽带瞬态，能量低，但会周期性激励轴承座与端盖的结构共振。直接对原始信号做 FFT，故障特征频率往往淹没在共振响应中。希尔伯特变换（Hilbert Transform）对信号各频率分量赋予 90 度相移，与原信号组合成解析信号（Analytic Signal），其模即包络（Envelope）——相当于对共振频段解调，冲击的重复频率在包络谱上直接显现。Simcenter Testlab 的包络分析与冲激量统计均以此为基础。

## 一、轴承故障信号的物理本质：冲击调制在结构共振上

滚道出现剥落缺陷后，滚动体每次碾过缺陷产生一次冲击。冲击本身是宽带瞬态，能量分散，但会激起轴承座、端盖等结构件的固有频率——通常在几百 Hz 到几 kHz——形成一串周期性衰减振荡。共振频率反映结构属性，冲击重复频率才反映缺陷位置，诊断要提取的是后者。

直接对原始信号做 FFT，得到的是以共振频段为中心的连续谱峰，故障频率及其谐波混入结构响应，难以辨认；早期故障冲击能量小，谱峰甚至不明显。低通滤波同样无法分离——冲击重复频率（几十到几百 Hz）与齿轮啮合、轴不平衡等低频干扰处于同一频段。

工程上采用通信解调的思路：把共振频段视为载波（Carrier），把冲击序列视为调制信号，先带通滤波锁定载波，再取包络还原调制信号。

::: info 核心概念
- **故障特征频率**（Fault Characteristic Frequency）：滚动体碾过缺陷产生的冲击重复率，外圈 BPFO、内圈 BPFI、滚动体 BSF、保持架 FTF，由轴承几何与转速确定
- **载波**（Carrier）：被周期冲击激励的结构共振频段，承载故障调制信息
- **调制**（Modulation）：冲击序列对共振幅值的周期性调制，解调即可还原冲击重复率
- **包络**（Envelope）：信号幅值轮廓的上边界，即连接振荡峰值的光滑曲线
:::

## 二、希尔伯特变换：由 90 度相移构造解析信号

传统包络提取采用整流加低通，失真较大且依赖手工调参；现代做法基于希尔伯特变换。

**定义与时域性质。** 希尔伯特变换是信号与 $1/(\pi t)$ 的卷积：

$$\hat{x}(t) = \mathcal{H}[x(t)] = \frac{1}{\pi}\,\mathrm{P.V.}\!\int_{-\infty}^{\infty} \frac{x(\tau)}{t - \tau}\, \mathrm{d}\tau$$

从频域看它的作用最直接。上式对应的频率响应为

$$H_{\mathcal{H}}(f) = \begin{cases} -j, & f > 0 \\ +j, & f < 0 \end{cases}$$

幅值处处为 1，相位在正、负频率处分别移 $\mp 90^\circ$：$\cos(2\pi f t)$ 变为 $\sin(2\pi f t)$，$\sin(2\pi f t)$ 变为 $-\cos(2\pi f t)$——幅值不变，每个分量只旋转 90 度。

**解析信号与包络。** 单独的 $\hat{x}(t)$ 用途有限，其价值在于与原信号构成解析信号：

$$z(t) = x(t) + j\,\hat{x}(t)$$

实部为原始信号，虚部为其希尔伯特变换，两者正交。解析信号的模即瞬时幅值——包络：

$$a(t) = |z(t)| = \sqrt{x^2(t) + \hat{x}^2(t)}$$

对单频信号 $x(t) = A\cos(2\pi f_0 t)$，有 $\hat{x}(t) = A\sin(2\pi f_0 t)$，代入上式得 $a(t) = A$：包络为常数，不含调制信息。包络分析的价值在幅值起伏的信号上，轴承冲击序列正是如此。

**频域实现。** 解析信号的频谱只保留"半边"：负频率分量置零、正频率分量加倍：

$$Z(f) = \begin{cases} 2\,X(f), & f > 0 \\ X(0), & f = 0 \\ 0, & f < 0 \end{cases}$$

数值实现即三步：FFT、按上式构造单边谱、IFFT，计算量与一次 FFT 同量级。

**工程实现。** 理想希尔伯特变换器要求全频段幅值恒为 1、相位恒移 90 度，其单位样值响应是无限长的逆对称序列，物理不可实现。工程上按 FIR 滤波器逼近：依据 LMS 检测理论手册，将期望频响规格化为在 $\omega_l < \omega < \omega_u$ 内 $|H_d(\omega)| = 1$，用 Remez 交换算法设计，并以窗函数截断冲激响应。手册将希尔伯特变换器与差分滤波器并列为 Remez 交换算法的两种典型应用。

::: warning 工程注意
希尔伯特变换的有效频带受 FIR 逼近精度限制，直流和奈奎斯特频率附近相移特性恶化。原始信号若含强低频成分（转速不平衡、刚体运动），包络会被这些分量扭曲。因此包络分析前必须带通滤波——通带选在共振频段上，既锁定载波，也保证希尔伯特变换工作在其有效频带内。
:::

## 三、包络分析流程：带通、解调、包络谱

**第一步：计算特征频率。** 设滚动体数为 $Z$，轴转频 $f_r$（Hz），滚动体直径 $d$、节圆直径 $D$（同一单位，式中只取比值），接触角 $\alpha$。外圈固定、内圈旋转时，滚动体在滚道上纯滚动，保持架转频为

$$\mathrm{FTF} = \frac{f_r}{2}\left(1 - \frac{d}{D}\cos\alpha\right)$$

滚动体随保持架公转，单位时间通过外圈任一点的次数等于保持架转频，故 $Z$ 个滚动体产生的外圈通过频率为 $\mathrm{BPFO} = Z \cdot \mathrm{FTF}$；内圈以 $f_r$ 旋转，滚动体相对内圈的通过率为 $f_r - \mathrm{FTF}$，故 $\mathrm{BPFI} = Z\,(f_r - \mathrm{FTF})$。展开即常用形式（单位均为 Hz）：

$$\mathrm{BPFO} = \frac{Z}{2}\, f_r \left(1 - \frac{d}{D}\cos\alpha\right)$$

$$\mathrm{BPFI} = \frac{Z}{2}\, f_r \left(1 + \frac{d}{D}\cos\alpha\right)$$

滚动体缺陷随自转交替撞击内、外圈，其自转频率（缺陷单侧接触）为

$$\mathrm{BSF} = \frac{D}{2d}\, f_r \left(1 - \left(\frac{d}{D}\cos\alpha\right)^{2}\right)$$

深沟球轴承 $\alpha = 0$，各式退化为常见简化形式。这四个频率是包络谱判读的基准。

**第二步：带通滤波。** 通带覆盖共振频段（从原始频谱或倒频谱上识别连续谱峰），滤除低频轴频干扰与无关高频。

**第三步：希尔伯特解调。** 对滤波后信号求解析信号，取模得包络，必要时再低通平滑。这是全流程的核心环节：包络谱上，故障频率及其谐波成族出现；内圈故障还伴随转频边带——缺陷相对传感器的位置周期变化，冲击幅值被转频调制。谐波族与边带结构比单根谱线可靠。

**第四步：包络谱判读。** 对包络做谱分析，峰值对准哪个特征频率，故障就在哪个部件。

| 判据 | 外圈故障 | 内圈故障 | 滚动体故障 |
| --- | --- | --- | --- |
| **包络谱主峰** | BPFO 及谐波 | BPFI 及谐波 | BSF（x2 更显）及谐波 |
| **边带特征** | 一般无（缺陷位置固定） | 正负转频边带明显 | 正负保持架转频边带 |
| **幅值稳定性** | 冲击幅值稳定 | 随缺陷转过传感器波动大 | 介于两者之间 |
| **机理** | 缺陷与负载区相对固定 | 缺陷旋转，负载区时进时出 | 滚动体自转加公转 |

::: tip 通带选择
- 没有现成共振信息：先看原始频谱找连续谱峰，或用 Testlab 包络分析预置频段试探
- 多个共振频段：优先选离齿轮啮合、轴频干扰远的那个
- 通带不宜贴近强离散谱线（如啮合频率）边缘，否则解调出虚假调制
:::

## 四、Python 演示：解调前后的对比

```python
import numpy as np

# 演示：包络分析——从共振载波里解调出冲击频率
fs = 25600.0
t = np.arange(0, 1, 1/fs)
rng = np.random.default_rng(0)

# 模拟轴承外圈故障：每 5ms 撞一次（BPFO=200Hz），激起 2kHz 结构共振
f_fault, f_res = 200.0, 2000.0
sig = np.zeros_like(t)
for k in range(int(f_fault * 1.0)):      # 每个故障周期打一次冲击
    t0 = k / f_fault
    tk = t - t0
    m = (tk >= 0) & (tk < 0.01)
    sig[m] += np.sin(2*np.pi*f_res*tk[m]) * np.exp(-300*tk[m])  # 衰减振荡
sig += 0.3 * rng.standard_normal(len(t))  # 加噪声

def analytic(x):
    # 解析信号 = 原信号 + j*希尔伯特(原信号)：负频率清零、正频率加倍
    N = len(x)
    X = np.fft.fft(x)
    H = np.zeros(N); H[1:N//2] = 2.0
    return np.fft.ifft(X * H)

# 带通(1~3kHz)滤掉低频干扰 → 取包络 → 包络谱
X = np.fft.fft(sig)
ff = np.fft.fftfreq(len(t), 1/fs)
X[np.abs(ff) < 1000] = 0
X[np.abs(ff) > 3000] = 0
env = np.abs(analytic(np.fft.ifft(X).real))
E = np.abs(np.fft.rfft(env))
fe = np.fft.rfftfreq(len(t), 1/fs)
peak = fe[1:500][np.argmax(E[1:500])]
print(f"包络谱峰值频率 = {peak:.1f} Hz  (外圈故障频率 BPFO = {f_fault:.0f} Hz)")
print("原始频谱中冲击重复频率被 2kHz 共振峰掩盖，包络解调后恢复")
```

运行结果：包络谱峰值频率 = 200.0 Hz，与设定的外圈故障频率 BPFO 一致——原始频谱中该频率分量被共振响应掩盖，解调后准确恢复。

```python
import numpy as np

# 演示：希尔伯特变换就是 90 度相移
fs = 1000.0
t = np.arange(0, 1, 1/fs)
x = np.cos(2*np.pi*10*t)                # 10 Hz 余弦

def hilbert_imag(x):
    # 解析信号虚部 = 希尔伯特变换：负频率清零、正频率加倍后取虚部
    N = len(x)
    X = np.fft.fft(x)
    H = np.zeros(N); H[1:N//2] = 2.0
    return np.fft.ifft(X * H).imag

h = hilbert_imag(x)
i = 25                                   # t=0.025s，即 1/4 周期处
print(f"t=1/4 周期:  x    = {x[i]:+.3f}  (cos 90度 = 0)")
print(f"            H[x] = {h[i]:+.3f}  (sin 90度 = +1)")
print(f"包络 |z| = sqrt(x^2 + H^2) = {np.hypot(x[i], h[i]):.3f} 处处为 1")
print("单频信号的包络是常数——没有调制信息")
```

运行结果：t = 1/4 周期处 $x = +0.000$、$H[x] = +1.000$，包络 $|z| = 1.000$ 处处为 1。单频信号无调制可言；包络谱的价值在幅值起伏的信号上，轴承冲击序列正是如此。

## 五、冲激量与峭度：包络的统计量化

包络解调出冲击序列后，进一步的量化指标是冲激量（Impulsiveness）。按 LMS 检测理论手册（第七章 7.10 节），冲激量基于信号的包络分析计算：设定一道阈值——由所有信号分段 RMS 的总体值、帧信号 RMS（跟踪分析情况下）与用户定义的阈偏置综合而成——包络越过阈值即记一次脉冲事件，统计输出四项参数：

![冲激量的脉冲参数定义](/images/hilbert-envelope/impulsiveness-parameters.png)

*冲激量各脉冲参数的定义：起始点、峰值电平、上升斜率与作用时间（图源：Simcenter Testing Knowledge Base）*

- **平均脉冲峰值电平**（dB）：脉冲峰值电平与阈值电平之差；峰点定义为越过阈值后达到的第一个最大值
- **平均上升斜率**：脉冲起始点与峰点之间的最大上升斜率；起始点为信号自低值上升至阈值前的极小值点
- **平均脉冲作用时间**：上升时间与下降时间之和
- **平均脉冲发生率**

这套统计常用于柴油发动机噪声量化：燃烧冲击的强弱与疏密直接反映供油与燃烧品质。对轴承监测而言，冲激量与峭度（Kurtosis）的价值在趋势管理。峭度表征概率分布相对高斯分布的尖锐程度，是四次矩的无量纲参数，手册定义式含 $-3$ 修正项（高斯分布对应零）：

$$\mathrm{Kurtosis} = \frac{1}{N\,\sigma^{4}} \sum_{i=1}^{N}\left(x_i - \bar{x}\right)^{4} - 3$$

式中 $N$ 为样本数，$\bar{x}$ 为均值，$\sigma$ 为标准差。若不加 $-3$ 修正项（部分仪器的约定），高斯分布的峭度为 3——判读趋势前应先确认所用约定。健康轴承的振动接近高斯随机过程，峭度稳定在基准值附近；故障萌生时冲击占主导，峭度抬升，包络谱上特征频率开始显露。手册同时指出：峭度与偏斜度属高次矩，鲁棒性低于低次矩，计算结果分散——单次读数不宜作判据，应以趋势为准。

::: warning 工程注意
冲击传播路径复杂，传感器测到的是多重反射叠加的结果，实测包络波形远比教科书示意图复杂。特征频率匹配要留容差——转速波动、轴承打滑都会让实际频率偏离理论值；确认故障需谐波成族、边带结构对应，单根谱峰不足以确认。
:::

## 六、小结

包络分析是轴承故障诊断的标准流程：带通锁定共振载波、希尔伯特解调取包络、包络谱对准特征频率。判读要点三条——主峰对准哪个特征频率、谐波是否成族、边带结构指向哪个部件。冲击类指标（冲激量、峭度）用于趋势监测，包络谱用于故障定位，两者配合使用。
