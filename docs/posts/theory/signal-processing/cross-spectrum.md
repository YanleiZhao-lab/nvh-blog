# 互功率谱与互相关：两个信号的因果关系

> 自功率谱只看一个信号，工程里真正值钱的问题往往是"这两个信号什么关系"：激励和响应、声源和测点、参考通道和工作数据。互相关（Cross-correlation）在时域量两个信号的相似性随时延的变化，互功率谱（Cross-power Spectrum）在频域逐频率保存两者的幅值与相位关系，两者是一对傅里叶变换。相干函数、频响函数、ODS、声强测量全建立在互谱上——它是双通道分析的地基。

## 一、从一个工程问题说起

动力总成台架上，悬置主动端和车身侧各贴一个加速度计，两条振动曲线肉眼看不出门道：频率成分相近、相位关系不明、噪声都不小。想知道"车身这份振动有多少是悬置传过去的、传了多久"，单通道的自功率谱（Autopower）给不出答案——自谱是信号与自身的乘积，相位自己乘自己消掉了，只剩能量分布。

双通道分析的核心工具就此登场。互相关回答"两个信号波形像不像、错开多少时间最像"；互功率谱回答"在每个频率上，两个信号的幅值乘积多大、相位差多少"。一个在时域，一个在频域，通过 FFT 互相转换：

Rxy(tau) = lim(T到无穷) (1/T) 积分 x(t)·y(t+tau) dt    <=>    Sxy(f) = X*(f)·Y(f)

注意共轭的位置：互谱是 X 的共轭乘 Y。这个约定决定了相位符号——Sxy 的相位等于 y 滞后 x 的角度，判读传递路径的"谁先谁后"全靠它。

::: info 核心概念
- **互相关函数 Rxy(tau)**：两信号相似性随时延 tau 的变化，峰的位置给出传播时间差
- **互功率谱 Sxy(f)**：X*(f)·Y(f)，逐频率携带两信号的幅值关系与相对相位
- **傅里叶变换对**：互谱逆变换回互相关，时域频域是同一份信息的两种读法
- **相位约定**：Sxy 相位 = y 滞后 x 的角度，判传递方向先核对软件的共轭约定
:::

## 二、互谱的物理读法：幅值与相位各管一摊

互功率谱是复数。幅值部分好理解——两个谱的乘积，谁大它就大，所以互谱高值指示"输入输出双方在该频率都占优势"。但这恰是坑所在：输出端恰好有个共振峰，幅值被放大十倍，互谱跟着高十倍，可输入端那份激励其实微不足道。**互谱高不等于因果强**，判断因果要配合相干函数，把"双方幅值都大"折算成"输出能量中能被输入线性解释的比例"。

相位部分是自谱给不了的信息。在每个频率上，Sxy 的相位角就是两个信号在该频率的相对相位：悬置主动端到车身侧某个 180 Hz 的分量相位差 90 度，说明路径上传了四分之一周期。逐频率的相位差连成曲线，能看出传递是纯延迟（相位随频率线性变化，斜率即时间差）还是经过了共振区（相位快速翻转 180 度）。

互谱的幅值类型与自谱相同，分 RMS 和 Peak 两种格式，跨数据对比时先统一格式再谈数值。

::: warning 工程注意
互功率谱的峰值可能只反映输出端共振被放大，与输入强弱无关；传导函数 T = Syx/Sxx 在反共振点还会因分母自谱趋零而冒出虚高峰。判读双通道数据，互谱必须与自谱、相干放在一起看，单看互谱幅值下结论是常见翻车点。
:::

## 三、互谱都能干什么：五大应用场景

| 应用 | 用到的函数 | 关键物理量 | 典型场景 |
| --- | --- | --- | --- |
| **频响函数估计** | H1 = Syx/Sxx | 互谱除以输入自谱 | 锤击/激振器模态试验 |
| **相干函数** | gamma2 = |Sxy|^2/(Sxx·Syy) | 互谱与自谱的组合 | FRF 质量审计 |
| **传递时差定位** | 互相关峰位置 | Rxy(tau) 峰值对应的 tau | 声源定位、路径传播时间 |
| **ODS 工作振型** | 相对参考点的互谱 | 互谱相位定各点相对运动 | 工况状态下整机振型 |
| **声强测量** | 双传声器互谱虚部 | Im(S12)/(2·pi·f·rho·d) | 声功率与声场分布 |

三个值得展开的点。

**FRF 为什么用互谱而不是直接谱相除。** 单帧数据 Y/X 固然能得到一个复数比，但噪声完全没有被抑制。H1 = Syx/Sxx 经过多帧平均后，输出端与输入不相关的噪声在互谱里被平均掉——噪声与输入不相关，乘积的期望趋于零。这是"用互谱换信噪比"的核心机制，也是一切 FRF 估计的出发点。

**H1 与 H2 的分工。** H1 = Syx/Sxx 假定输入无噪，输出噪声被最小二乘压掉，得到 FRF 的欠估计，反共振区表现更好；H2 = Syy/Syx 假定输出无噪，得到过估计，共振区表现更好。真值夹在两者之间，实测中 H2/H1 的比值就是常相干。锤击测力信号信噪比差，共振峰处看 H1；输出通道干净时 H2 对共振峰更友好。

![H1、H2、Hv 三种 FRF 估计](/images/cross-spectrum/frf.png)

*三种 FRF 估计式：对噪声位置的不同假设给出不同的估计（图源：Simcenter Testing Knowledge Base）*

**声强是把互谱虚部用到了极致。** p-p 探头两只传声器，声强 I = Im(S12)/(2·pi·f·rho·d)，互谱的虚部直接对应声能量传播——相位差里藏的是两只传声器感受到的压力梯度，乘上频率与间距就是质点速度。双通道互谱撑起了整台声强分析仪。

::: tip 实用建议
- 做传递路径或 ODS 分析，固定一个信噪比高的通道当参考，所有互谱都对它算，工况缓慢漂移的影响能被相位参考抵消
- 平均次数别抠门：互谱的噪声抑制靠平均，帧数不足时相干虚高、相位乱跳
- 声强探头间距 d 按频段选——低频要大间距保相位差分辨力，高频要小间距防相位差超过分辨范围
:::

## 四、Python 演示

**演示一：互相关峰定位传播时延，噪声再大也压不住。** 主动端是宽带随机振动，经 5 ms 传到车身侧，输出端叠加三倍于信号的强噪声，看互相关如何把 5 ms 捞出来：

```python
import numpy as np

fs = 4096                       # 采样率 Hz
N = 8192                        # 每帧点数
rng = np.random.default_rng(0)

x = rng.standard_normal(N)      # 主动端：宽带随机振动
delay = int(0.005 * fs)         # 5 ms 传播延迟对应的点数
noise = 3.0 * rng.standard_normal(N)
y = np.roll(x, delay) + noise   # 车身侧：延迟信号 + 3 倍强噪声

# 互相关：FFT 法 Rxy = IFFT( conj(X) * Y )
X, Y = np.fft.rfft(x), np.fft.rfft(y)
rxy = np.fft.irfft(np.conj(X) * Y, N)
lags = np.arange(N) / fs * 1000             # 时延轴换算成 ms

k = int(np.argmax(rxy[:N//2]))              # 正时延区找峰
snr = 10*np.log10(np.sum(x**2) / np.sum(noise**2))
print(f"输出端信噪比: {snr:.1f} dB（噪声能量是信号的 9 倍）")
print(f"互相关峰位置: {lags[k]:.2f} ms（真实延迟 5 ms，分辨率 {1000/fs:.2f} ms）")
```

输出里最值得看的：输出信噪比 -9.5 dB，噪声能量是信号的 9 倍，时域波形里信号完全看不见；互相关峰仍稳稳落在 4.88 ms——比 5 ms 差不到一个采样间隔。互相关对不相关噪声的抑制是结构性的，这正是"湮没在噪声中的信号靠相关分析救回来"的数学根据。

**演示二：互谱相位揭示共振区的相位翻转。** 200 Hz 单自由度系统受白噪声激励，做 50 帧谱平均，看互谱相位在共振频率前后如何转过约 180 度：

```python
import numpy as np

fs, N, M = 1024, 4096, 50                  # 采样率、点数、平均帧数
fn, zeta = 200.0, 0.04                     # 固有频率、阻尼比
f = np.fft.fftfreq(N, 1/fs)                # 配合 fft 的频率轴
H = 1.0 / (fn**2 - f**2 + 2j*zeta*fn*f)    # 位移型 FRF（复数）
rng = np.random.default_rng(1)

Sxy = np.zeros(N, dtype=complex)
for _ in range(M):
    x = rng.standard_normal(N)             # 白噪声激励
    y = np.fft.ifft(np.fft.fft(x) * H).real
    X, Y = np.fft.fft(x), np.fft.fft(y)
    Sxy += np.conj(X) * Y                  # 互谱累加

for fq in [150.0, 199.75, 200.75, 250.0]:  # 共振点两侧各取谱线
    k = int(round(fq * N / fs))
    print(f"{fq:6.1f} Hz  互谱相位 {np.angle(Sxy[k]/M, deg=True):+7.1f} 度")
print("跨过共振：相位从 ~0 度过 -90 度翻向 ~-180 度，响应与激励反相")
```

看四个频率的相位数字：150 Hz 处约 -8 度（位移响应跟上激励），199.75 与 200.75 Hz 分踞共振点两侧、相位分别约 -88 与 -95 度（共振区能量交换），250 Hz 处约 -170 度（位移与激励反相）。互谱相位曲线就是 FRF 相位曲线的原料，共振识别里的"相位翻转"判据从这里来。

## 五、自谱、互谱、互相关对照

| 维度 | 自功率谱 | 互功率谱 | 互相关 |
| --- | --- | --- | --- |
| **信号数** | 1 | 2 | 2 |
| **域** | 频域 | 频域 | 时域 |
| **复数性** | 实数 | 复数（含相位） | 实数 |
| **相位信息** | 无（共轭相乘消掉） | 有，逐频率相对相位 | 隐含在峰的偏移里 |
| **噪声抑制** | 平均降噪 | 不相关噪声在平均中趋于零 | 同左 |
| **典型输出** | 谱峰定位 | FRF、相干、ODS、声强 | 传播时差、源定位 |

## 六、小结

双通道问题的判断链条：先看相干确认因果成色，再读互谱相位判断传递性质，最后用互谱除自谱得到 FRF 或传导函数。互谱幅值高只说明双方能量都大，别当成因果证据；互相关的峰位置是定位声源与路径时差的利器，对不相关噪声天然免疫。所有依赖相位的分析——ODS 振型、声强、传递路径相位——精度上限都卡在通道间采样同步上，做双通道试验前先确认采集设备是同步采样而非分时扫描。
