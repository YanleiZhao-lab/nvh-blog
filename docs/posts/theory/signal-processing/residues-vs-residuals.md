# 留数与残差：模态理论里最易混的一对术语

> 模态分析报告里 Residue（留数）与 Residual（残余项）拼写只差两个字母，含义不同：留数是模态参数的正式成员，与极点（频率、阻尼）、振型并列；残余项只是窄带曲线拟合中补偿带外模态影响的修正项，不是模态参数。拟合结果表中那些"没有频率也没有阻尼的额外行"就是残余项。本文从部分分式展开分别推导两者：留数一端给出三因子式与峰拾取换算关系 $|A_{ijk}|\approx\sigma_k\,|\mathrm{Im}\,H_{ij}(\omega_{dk})|$；残余项一端给出高频侧常数（残余刚度）与低频侧 $1/\omega^2$（残余质量）两条渐近线。两个数值实验分别验证：归一化留数列还原振型（偏差 $10^{-4}\sim10^{-3}$ 量级），上下残余项把窄带拟合相对误差从 20.46% 降到 1.97%。

## 一、留数（Residue）：部分分式展开中极点前的复系数

多自由度结构的运动方程 $M\ddot{x} + C\dot{x} + Kx = f(t)$ 变换到拉普拉斯域后，频响函数是系统矩阵的逆：

$$H(s) = (s^2M + sC + K)^{-1} = \frac{\mathrm{adj}(B(s))}{\det(B(s))}$$

分母 $\det(B(s))$ 是 $s$ 的多项式，其根为系统的**极点** $\lambda_k$——每阶模态一对共轭复根 $\lambda_k = -\sigma_k + j\omega_{dk}$（$\sigma_k$ 为阻尼因子，$\omega_{dk}$ 为有阻尼固有频率，本文统一按角频率计）。有理分式的标准处理是部分分式展开：

$$H_{ij}(s) = \sum_{k=1}^{N}\left(\frac{A_{ijk}}{s-\lambda_k} + \frac{A_{ijk}^{*}}{s-\lambda_k^{*}}\right)$$

展开式中每个极点前的系数 $A_{ijk}$ 由该极点处的极限定义：

$$A_{ijk} = \lim_{s\to\lambda_k}\,(s-\lambda_k)\,H_{ij}(s)$$

复分析中这是洛朗展开的"残留部分"，**留数**（Residue）由此得名——它把 $H(s)$ 在该极点附近的全部信息压缩为一个复数。响应自由度 $i$、参考（激励）自由度 $j$、模态阶次 $k$ 三个下标缺一不可：换一对激励-响应点，留数即换一个值。

这个系数里装了什么？对比例阻尼实模态走一遍解耦：令 $B(s)=\Phi[s^2 m + sc + k]\Phi^{T}$（$\Phi$ 为实振型矩阵，$m$、$k$ 为模态质量与模态刚度矩阵），求逆后第 $k$ 项分母配方 $m_k s^2+c_k s+k_k = m_k(s-\lambda_k)(s-\lambda_k^{*})$，部分分式系数为：

$$A_{ijk} = Q_k\,\psi_{ik}\,\psi_{jk}, \qquad Q_k = \frac{1}{2j\,m_k\omega_{dk}}$$

即 LMS 理论手册式 15-5 的三因子式：**留数 = 标尺常数 × 响应点振型系数 × 参考点振型系数**。三个因子分工明确——$\psi_{ik}\psi_{jk}$ 是纯几何量（该阶模态在这两个自由度上的取值），$Q_k$ 是标尺（模态质量取多大）。若激励点落在振型节点上（$\psi_{jk}=0$），留数为零，该阶模态从这条 FRF 上整体消失——"驱动点测量"一文讨论的丢模态现象，根源就在这个乘积式上。

实模态还有一个直接推论：$Q_k$ 为纯虚数、振型系数为实数，因此**留数为纯虚数**，全部信息集中在虚部。在共振峰顶 $\omega=\omega_{dk}$ 处，单模态 FRF 的两个分式中 $j\omega_{dk}-\lambda_k=\sigma_k$，主导项为 $A/\sigma_k$，于是得到峰拾取换算关系：

$$A_{ijk} \approx j\,\sigma_k\,\mathrm{Im}\left[H_{ij}(\omega_{dk})\right], \qquad \left|A_{ijk}\right| \approx \sigma_k\,\left|\mathrm{Im}\,H_{ij}(\omega_{dk})\right|$$

手册 15.3.2 节"模态检出法"（Mode Extraction）的表述即为：模态幅值倍乘模态阻尼因子即得留数。早期的峰检索（15.3.1 节）与模态检出法据此从虚部谱峰高直接得到整列留数，除以标尺即振型。注意阻尼因子是乘数而非固定常数：同一幅值的峰，阻尼越大留数越大。该关系与圆拟合法一文中的拟合圆直径 $d=|A|/\sigma_k$ 是同一事实的两种表述——峰顶幅值恰好等于拟合圆直径。

::: info 核心概念
- **留数（Residue）$A_{ijk}$**：部分分式展开中极点前的复系数，$\lim_{s\to\lambda_k}(s-\lambda_k)H_{ij}(s)$；模态参数组成员（极点/频率、阻尼、振型、留数）
- **三因子式**：$A_{ijk} = Q_k\psi_{ik}\psi_{jk}$，$Q_k = 1/(2j\,m_k\omega_{dk})$（比例阻尼实模态、质量归一标尺）
- **量纲**：留数与 FRF 数据同量纲（柔度型 FRF 为 m/N）；振型本身无量纲，量纲由标尺常数赋予——手册第 15 章特别强调这一点
- **纯虚性与峰拾取**：比例阻尼实模态下留数纯虚；峰顶虚部乘阻尼因子即留数幅值 $|A|\approx\sigma_k|\mathrm{Im}\,H(\omega_{dk})|$
:::

::: warning 工程注意
留数是**局部量**：依赖具体的响应自由度与参考自由度，每对 $(i,j)$ 一套。极点才是**全局量**——从结构上任意一条 FRF 拟合出的频率与阻尼理论上相同。多输入分析中留数改写为"振型 × 模态参预因子"（Modal Participation Factor），两者的单位都与留数相同，本质仍是三因子式的另一种切分（手册 15.3.6.1 节）。
:::

## 二、残余项（Residual）：带外模态在窄带内的渐近贡献

曲线拟合不会使用全频段数据。分析频带通常只覆盖关心的几阶模态，但实测 FRF 是**所有**模态贡献的总和——带外模态一项不少，只是形态改变。

推导从"带外模态在窄带内如何退化"出发。单模态贡献在频率轴 $s=j\omega$ 上取值，通分：

$$\frac{A}{j\omega-\lambda} + \frac{A^{*}}{j\omega-\lambda^{*}} = \frac{2j\omega\,\mathrm{Re}(A) - 2\,\mathrm{Re}(A\lambda^{*})}{\omega_{n}^{2} - \omega^{2} + 2j\sigma\omega}$$

其中 $\omega_{n}^{2}=\sigma^{2}+\omega_{d}^{2}$ 为无阻尼固有频率的平方。通分把一对共轭分式合并为"常数分子 + 二阶多项式分母"——这正是单自由度位移导纳的结构。实模态留数 $A=j\,\mathrm{Im}(A)$ 为纯虚数，代入后分子化简为 $-2\,\omega_{d}\,\mathrm{Im}(A)$。看两个极限：

**高频带外模态**（$\omega_{n}$ 远大于分析频带上限，带内 $\omega\ll\omega_{n}$）：分母 $\approx\omega_{n}^{2}$，贡献退化为与频率无关的实常数

$$\frac{A}{j\omega-\lambda} + \frac{A^{*}}{j\omega-\lambda^{*}} \approx -\frac{2\,\omega_{d}\,\mathrm{Im}(A)}{\omega_{n}^{2}}$$

物理上，频率远高于分析频带的模态在带内表现为纯弹簧——位移与力同相、幅值近似不变，对应双对数图上斜率为零的"刚度线"。对所有高频带外模态求和，合并为一个系数 $UR_{ij}$（上残余项，残余刚度 Residual Stiffness）。

**低频带外模态**（$\omega_{n}$ 远小于分析频带下限，带内 $\omega\gg\omega_{n}$）：分母 $\approx-\omega^{2}$，贡献退化为

$$\frac{A}{j\omega-\lambda} + \frac{A^{*}}{j\omega-\lambda^{*}} \approx \frac{2\,\omega_{d}\,\mathrm{Im}(A)}{\omega^{2}}$$

物理上，频率远低于分析频带的模态在带内表现为纯质量——惯性主导，幅值随 $1/\omega^{2}$ 增长，对应斜率 -2 的"质量线"。合并为系数 $LR_{ij}$（下残余项，残余质量 Residual Mass）。于是窄带拟合的数学模型为（手册式 15-8 的位移型 FRF 版本）：

$$h_{ij}(\omega) = \sum_{k\in\text{band}}\left(\frac{A_{ijk}}{j\omega-\lambda_k} + \frac{A_{ijk}^{*}}{j\omega-\lambda_k^{*}}\right) + UR_{ij} - \frac{LR_{ij}}{\omega^2}$$

::: warning 工程注意
三个常见误用：
- **残余项不是模态**。它没有极点、没有频率、没有阻尼，不能进振型动画，不能用于计算模态质量。它只是让带内拟合更贴近数据的两个补偿系数。
- **残余项是局部量**。每对响应-参考自由度 $(i,j)$ 各有一套 $UR$、$LR$；多参考拟合时每个参考自由度各生成一项（手册 15.3.6.1 节），不存在全结构共用的"残余刚度"。
- **不能用残余项外推**。$UR$、$LR$ 只在拟合频带内有效——它们是带外模态在**这段窄带**内的渐近近似，离开这段频率，$1/\omega^{2}$ 的形态即不再成立。
:::

## 三、一张表分清两个术语

| | **留数 Residue** | **残余项 Residual** |
| --- | --- | --- |
| **身份** | 模态参数组成员 | 曲线拟合补偿项，不是模态参数 |
| **数学来源** | 部分分式极点前系数 $\lim_{s\to\lambda_k}(s-\lambda_k)H_{ij}(s)$ | 带外模态的窄带渐近：常数（刚度）+ $1/\omega^2$（质量） |
| **物理对应** | 振型系数 × 参考点振型系数 × 标尺 $Q_k$ | 高频带外模态 ≈ 残余刚度 $UR$；低频带外模态 ≈ 残余质量 $LR$ |
| **个数** | 每对 $(i,j)$、每阶模态一个复数 | 与模态阶数无关，每对 $(i,j)$ 上、下各一个 |
| **量纲** | 与 FRF 相同（m/N 等，由标尺赋予） | 与 FRF 相同 |
| **全局/局部** | 局部（依赖 $i,j$） | 局部（依赖 $i,j$，多参考时按参考点分） |
| **典型用途** | 振型、模态参预、模态质量标定、强迫响应综合 | 改善带内拟合、使综合 FRF 带外趋势正确 |

判别要点：**留数带阶次下标 $k$，残余项不带**——前者属于某阶模态，后者属于某个频带。

## 四、数值验证：留数列归一化后还原振型

两自由度系统，$M$、$K$ 已知，模态阻尼比均设 1%。验证分三步：先将广义特征问题对称化解出精确振型；再由"实测"FRF 在各共振峰顶按 $|A|\approx\sigma_k|\mathrm{Im}\,H|$ 提取留数列；最后归一化对比。这也是"锤击测一行、激振器测一列都能得到振型"的数学根据：

```python
import numpy as np

# 两自由度系统：先对称化解出精确振型，再从FRF谱峰按 |A|=sigma*|ImH| 提取留数列
M = np.array([[2.0, 0.0], [0.0, 1.0]])
K = np.array([[900.0, -400.0], [-400.0, 500.0]])
Mi = np.diag(1.0/np.sqrt(np.diag(M)))    # M^(-1/2)：把广义特征问题对称化
w2, Y = np.linalg.eigh(Mi @ K @ Mi)      # M^(-1)K非对称，直接eigh会悄悄
V = Mi @ Y                               # 取其三角部分而给出错误振型
print("固有频率:", np.round(np.sqrt(w2)/(2*np.pi), 3), "Hz")

zeta = 0.01
C = (M @ V) @ np.diag(2*zeta*np.sqrt(w2)) @ (M @ V).T   # 模态阻尼：两阶均1%
j = 0                                    # 参考自由度（激励点）
w = np.linspace(2.0, 45.0, 430001)
H = np.array([np.linalg.inv(K - M*wi**2 + 1j*wi*C)[:, j] for wi in w])

for k in (0, 1):
    wd = np.sqrt(w2[k])*np.sqrt(1 - zeta**2)
    sig = zeta*np.sqrt(w2[k])
    idx = np.where((w > wd*0.95) & (w < wd*1.05))[0]
    ipk = np.argmax(np.abs(H[idx].imag), axis=0)        # 各响应点的虚部峰
    A_col = 1j*sig*H[idx].imag[ipk, np.arange(2)]       # 峰拾取留数列
    psi = (A_col/A_col[0]).real                         # 归一化 -> 振型
    true = V[:, k]/V[j, k]
    A_th = np.abs(V[:, k]*V[j, k]/(2j*wd))              # 三因子式理论值
    print(f"模态{k+1}: 留数列 = {np.round(psi, 4)}, 振型 = {np.round(true, 4)}, "
          f"最大偏差 {np.abs(psi - true).max():.1e}")
    print(f"        |A|峰拾取 = {np.round(np.abs(A_col), 6)}, |A|理论 = {np.round(A_th, 6)}")
```

运行结果：

```text
固有频率: [2.2 4.385] Hz
模态1: 留数列 = [1. 1.2945], 振型 = [1. 1.2947], 最大偏差 2.1e-04
        |A|峰拾取 = [0.009841 0.012739], |A|理论 = [0.00984 0.01274]
模态2: 留数列 = [ 1. -1.5435], 振型 = [ 1. -1.5447], 最大偏差 1.2e-03
        |A|峰拾取 = [0.00414 0.00639], |A|理论 = [0.004138 0.006392]
```

峰拾取留数与三因子式理论值吻合到第 4~5 位有效数字；归一化留数列与振型的偏差在 $10^{-4}\sim10^{-3}$ 量级，来自峰顶定位的谱线离散化与邻模态叠加——这正是后续圆拟合、多自由度整体拟合要继续压缩的误差来源。留数列比振型多的因子（标尺 × 参考点振型系数）在归一化时被除掉：振型只给形状，留数才带绝对刻度。

代码中有一处值得注意的数值细节：广义特征问题通过对 $M^{-1/2}KM^{-1/2}$ 作对称分解求解。若直接对非对称的 $M^{-1}K$ 调用 `eigh`，numpy 只取其三角部分且不报错，本例会给出 1.37/4.71 Hz 的错误频率（正确值为 2.200/4.385 Hz）——处理实测质量、刚度阵时值得留意的陷阱。

## 五、数值验证：残余项对窄带拟合误差的补偿

三自由度系统，固有频率 31.1 / 63.8 / 95.6 Hz。分析频带取 40~90 Hz——只覆盖模态 2，模态 1 压在带下沿之外、模态 3 顶在带上沿之外。极点假设已精确估出，分别用"纯单模态模型"和"加上、下残余项的模型"作最小二乘拟合：

```python
import numpy as np

# 三自由度：只在40~90 Hz带内拟合模态2，对比纯单模态与加上、下残余项的拟合
M = np.eye(3)
K = np.diag([40000.0, 160000.0, 360000.0]) \
    - np.eye(3, k=1)*15000.0 - np.eye(3, k=-1)*15000.0
w2, V = np.linalg.eigh(np.linalg.solve(M, K))
print("三阶固有频率:", np.round(np.sqrt(w2)/(2*np.pi), 1), "Hz   分析频带: 40~90 Hz")

f = np.linspace(40, 90, 1001); s = 2*np.pi*f*1j
C = 0.5*M + 2e-4*K                                # 瑞利阻尼
H = np.array([np.linalg.inv(M*si**2 + C*si + K)[1, 0] for si in s])  # "实测"FRF

zt = (0.5/np.sqrt(w2[1]) + 2e-4*np.sqrt(w2[1])) / 2
lam = -zt*np.sqrt(w2[1]) + 1j*np.sqrt(w2[1])*np.sqrt(1-zt**2)
X0 = 1/(s-lam) + 1/(s-np.conj(lam))               # 单模态基函数（留数项）
ref = np.abs(H[np.argmax(np.abs(H))])

cA, *_ = np.linalg.lstsq(X0[:, None], H, rcond=None)              # 方案A：纯留数
errA = np.sqrt(np.mean(np.abs(H - X0*cA[0])**2)) / ref

XB = np.column_stack([X0, np.ones(f.size), -1.0/(2*np.pi*f)**2])  # 方案B：+UR -LR/w^2
cB, *_ = np.linalg.lstsq(XB, H, rcond=None)
errB = np.sqrt(np.mean(np.abs(H - XB @ cB)**2)) / ref
print(f"模态2 阻尼比 = {zt:.3f}")
print(f"纯单模态拟合     相对误差: {errA*100:5.2f} %")
print(f"加上、下残余项后 相对误差: {errB*100:5.2f} %  -> 降到原来的 {errB/errA*100:.0f}%")
print(f"  残余刚度 UR = {cB[1].real:.3e}, 残余质量 LR = {cB[2].real:.3e}")
```

运行结果：

```text
三阶固有频率: [ 31.1  63.8  95.6] Hz   分析频带: 40~90 Hz
模态2 阻尼比 = 0.041
纯单模态拟合     相对误差: 20.46 %
加上、下残余项后 相对误差:  1.97 %  -> 降到原来的 10%
残余刚度 UR = 4.188e-07, 残余质量 LR = 3.078e-01
```

20.46% 到 1.97% 这一跳说明：带外两个模态的贡献构成了纯单模态模型约五分之一的误差，两个补偿系数即将其消除。对系数本身作进一步核对：由模态 1 的渐近式计算，残余质量理论值 $LR\approx-2\omega_{d1}\,\mathrm{Im}(A_1)=0.122$，与拟合值 0.308 同号同量级、相差约 2.5 倍——带下沿 40 Hz 与模态 1（31.1 Hz）之比仅 1.3，$\omega\gg\omega_{n}$ 的渐近条件并不充分成立，最小二乘自动放大系数以跟踪真实曲线。这从数值上印证了"残余项是数学补偿项而非物理参数"：**哪个残余项大，说明哪一侧的带外模态离频带更近、影响更重**，可据此诊断分析频带的选择是否合理，但不能把 $LR$ 直接读作某个物理质量。

## 六、Testlab 中的对应设置

Simcenter Testlab 模态拟合的参数面板与这对术语直接对应：

- **Residue type**：留数按 Complex（复数）还是 Real（实数）估计。复留数适用于非比例阻尼与密频情形；实留数对应比例阻尼假定，适用于与无阻尼有限元振型对比等场景。对以实模态为主的结构，复留数的虚部应当很小——这本身可作为拟合质量的旁证。
- **Upper residuals / Lower residuals** 勾选框：即残余刚度与残余质量项，勾选后每个参考自由度各生成一项，随留数一起作最小二乘估计（LSFD 法，手册 15.3.6 节）。
- 拟合结果表中只挂数值、不带频率阻尼的行即残余项，振型动画中不会出现它们。

留数一侧的后续应用见手册第 18 章：**模态参预**（Modal Participation，18.3 节）把某阶模态对所有参考点的留数求和，留数和最大的参考点即该阶模态的最佳激励点；对所有模态作留数求和再横向比较，可定量评估参考点布置对整体试验的激励效率。

::: tip 实用建议
- 分析频带贴近强带外模态（如车身一阶刚体模态离弹性模态很近），或带内阻尼大、峰形不对称时，启用上、下残余项，拟合误差可显著下降（本例降为原来的 1/10）
- 带外模态距频带上下一两个倍频程以上时，渐近贡献已很小，残余项作用有限，可不启用
- 报告振型用留数归一化结果即可；综合 FRF、计算模态质量时须带上残余项，否则带外趋势整段偏离
- 留数是复数就按复数处理——直接把复留数读作振型幅值而丢弃相位，对密频或非比例阻尼结构会得到严重失真的振型
:::

## 七、小结

判别标准一句话：**带阶次下标的是留数，不带的是残余项**。留数是部分分式中极点前的系数、三因子式给出的带标尺振型，属于模态参数；残余项是带外模态在窄带内的渐近贡献——上残余当弹簧、下残余当质量，只服务于拟合精度。查看拟合结果表时，先看那些"没有频率的行"挂在什么位置：挂在补偿区的是残余项，挂在模态参数区且带共轭对的才是留数。
