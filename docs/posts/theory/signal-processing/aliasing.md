# 混叠：采样定理的约束与抗混叠滤波器设计

> 采样率不足时，高于带宽的频率成分不会消失，而是镜像折叠到带宽以内，以错误的频率和幅值出现在频谱中——这就是混叠（Aliasing）。本文说明镜像折叠的频率规律、抗混叠滤波器（Anti-aliasing Filter）为什么使可用分析范围只有带宽的 80%，以及测试前带宽与采样率的设置方法。

<br>

怠速振动谱上一个 24 Hz 的峰，查遍了悬置、排气管吊钩和路面激励都对不上号；把带宽从 100 Hz 提到 256 Hz 重测一遍，24 Hz 的峰消失了，176 Hz 处冒出一个真实的峰——那才是激励的本来频率。数据没换、传感器没动、算法没改，只改了一个采集设置，"鬼峰"就现了原形。这不是仪器坏了，也不是干扰来了，而是采样过程本身把高于带宽的 176 Hz"折叠"成了 24 Hz 塞进了频谱。混叠（Aliasing）就是这么一类错误：它在数据里安安静静地冒充低频成分，波形正常、谱线清晰，从采集到报告全程没有任何报警。理解它的折叠规律、知道抗混叠滤波器为什么把可用范围砍掉 20%，是每一次采样设置背后的隐形前提。

## 一、混叠的成因：高于带宽的成分以低频身份出现

ADC 按固定间隔对模拟信号取样。采样之后，信号中高于带宽的成分不会消失，而是**以低于带宽的虚假频率出现在频谱中**。这个虚假频率称为混叠频率（Alias Frequency）。

打个生活里的比方。老式电影里飞驰的马车轮子常常见到"倒转"甚至"停住"——轮辐明明向前转，银幕上却往后走。原因只有一个：摄影机每秒只拍 24 格，轮辐转得比"每格四分之一圈"更快时，相邻两格里辐条的位置会被大脑解读成反方向。胶片按固定格数取样连续的转动，混叠就此发生；你看到的"倒转轮"就是混叠频率——它不是轮子的真实转速，而是真实转速被采样率折叠出来的低频假象。采集卡每隔固定间隔采一个点，与摄影机按格拍摄在数学上是同一件事：采样率追不上信号变化，超出带宽的运动就会以另一个面目回到记录里。记住这个画面往下读——谱上每一个解释不通的"低频峰"，都可能是银幕上那只倒转的轮子。

时域上最直观：下图中红色是原始正弦信号，蓝点是采样时刻。采样率不足时，把采样点连线（蓝色曲线），得到的是一个频率低得多的正弦——采集系统记录并显示的，就是这个低频假象。

![采样率不足时，高频信号在采样后呈现为低频正弦](/images/aliasing/aliasing-time-domain.png)

*（图源：网络官方公开资料）*

混叠的风险在于它**不产生任何报警**。波形看起来正常，频谱上也有一个清晰的峰，只是频率和幅值都是错的。如果不做预防，混叠数据从采集到报告的整个流程中都可能不被发现。

### 四个必须分清的术语

| 术语 | 含义 | 数值关系 |
| --- | --- | --- |
| 采样频率 Sampling Frequency（$f_s$，Hz） | 每秒采集的数据点数 | $f_s = 2 \times$ 带宽 |
| 带宽 Bandwidth（$B$，Hz） | 系统的分析频率上限 | $B = f_s / 2$ |
| 频率范围 Span（Hz） | 无混叠且不受抗混叠滤波器影响的分析范围 | $\mathrm{Span} = 0.8\,B$ |
| Nyquist 采样率（Hz） | 不产生频率错误所需的最低采样率 | $= 2 \times$ 最高关心频率 |

根据 Nyquist 采样准则（Nyquist Sampling Criterion），采样率必须至少为最高关心频率 $f_{\max}$ 的两倍：

下面这个公式回答的问题是：采样率最低可以取多少，才保证关心的频率不被折错？其中 $f_s$ 是每秒的采样点数，$f_{max}$ 是信号中最高关心频率——采样率只要达到它的两倍，这个频率及其以下的成分在采样后仍能被唯一还原：

$$
f_s \ge 2 f_{\max}
$$

数据采集系统的采样频率取带宽的两倍（$f_s = 2B$），因此所有低于带宽的成分都能被充分采样；但若输入信号含有高于带宽的成分，采样率相对这些成分已违反 Nyquist 准则，混叠随之产生。

::: info 核心概念
- <strong>混叠（Aliasing）</strong>：高于带宽的频率成分被"折叠"到带宽以内，以低频身份出现
- <strong>镜像（Mirroring）</strong>：超出带宽 X Hz 的成分出现在带宽以下 X Hz 处
- **Span**：抗混叠滤波器保证无混叠的区间，为带宽的 80%
:::

## 二、镜像规律：混叠频率的计算

混叠的数学本质是镜像折叠：真实频率超出带宽的部分，以带宽频率为轴对称反射。带宽 1000 Hz 时，1300 Hz 的成分超出带宽 300 Hz，于是出现在 $1000 - 300 = 700$ Hz 处。

![超过带宽的频率成分以带宽频率为轴镜像折叠](/images/aliasing/alias-mirroring.png)

*（图源：网络官方公开资料）*

对于任意真实频率 $f$，采样后观测到的混叠频率 $f_{\text{alias}}$ 为

下面这个公式回答的问题是：任意一个真实频率经采样后，会以什么频率出现在频谱上？其中 $f$ 是真实频率，$B$ 是带宽，mod 是取余运算——先折算到 $[-B, B)$ 再取绝对值，一步算出任何频率（哪怕远离带宽好几倍）的最终落点：

$$
f_{\text{alias}} = \left| \left( (f + B) \bmod 2B \right) - B \right|
$$

其中 $B$ 为带宽（Hz）。该式先将频率折算到 $[-B, B)$ 区间，再取绝对值镜像到 $[0, B]$——这正是"以带宽为轴逐级折叠"的解析表达。

相关技术手册用"折叠线"描述同一件事：Nyquist 频率 $f_n$ 的各倍乘数都是折叠线。真实频率 $4f$ 以 $3f_n$ 线为基准折叠到 $3f$，$3f$ 以 $2f_n$ 线为基准折叠到 $2f$，$2f$ 又以 $f_n$ 线为基准折叠到 $1f$。因此频率为 $2f$、$3f$、$4f$ 的信号采样后看起来都是 $1f$——混叠不只是"超出一点折回来"，远离带宽的频率同样会折进分析范围。

![实际频率与采样后观测频率对照表（带宽 100 Hz）](/images/aliasing/alias-table.png)

*（图源：网络官方公开资料）*

```python
# 混叠频率计算：真实频率 vs 采样后观测频率
import numpy as np

fs = 2000                    # 采样率 Hz
bw = fs / 2                  # 带宽 = 1000 Hz

def observed(f_true, fs):
    """真实频率经采样后在 [0, fs/2) 内被观测到的混叠频率"""
    m = f_true % fs                        # 先折到 [0, fs)
    return m if m <= fs / 2 else fs - m    # 再镜像回 [0, fs/2)

for f in [400, 700, 1300, 1700, 2600]:
    obs = observed(f, fs)
    tag = "正常" if f <= bw else "混叠!"
    print(f"真实 {f:>5} Hz -> 观测 {obs:>5.0f} Hz  {tag}")

# 时域验证：1700 Hz 按 2000 Hz 采样，与 300 Hz 的序列几乎逐点相同
t = np.arange(256) / fs
err = np.max(np.abs(np.sin(2*np.pi*1700*t) - np.sin(2*np.pi*300*t + np.pi)))
print(f"1700 Hz 与 300 Hz 采样序列最大偏差: {err:.1e}")
```

运行结果：1300 Hz 折到 700 Hz（正是相关技术手册中的例子），1700 Hz 折到 300 Hz，2600 Hz 折到 600 Hz。一旦超过带宽，观测频率完全不可信。

## 三、抗混叠滤波器：Span 为何只有带宽的 80%

防止混叠的唯一办法，是在 ADC 之前用**模拟低通滤波器**把超过带宽的成分滤除——数字化之后无法补救，混叠信息已经写入数据。这就是抗混叠滤波器。

理想的抗混叠滤波器应当是"砖墙"（Brick Wall）特性：带宽以内完全通过，带宽以外完全截止。但物理上不存在砖墙滤波器。实际的抗混叠滤波器在带宽处有 -3 dB 滚降点，并在带宽以外 20% 处（即 1.2 倍带宽）才把信号衰减到零，这段过渡带的幅值已不可信。

![实际抗混叠滤波器在带宽处 -3 dB 滚降，过渡带内幅值已不可信](/images/aliasing/anti-aliasing-filter.png)

*（图源：网络官方公开资料）*

由此得到一个关键的工程结论：**从 80% 带宽到带宽之间的区间不可信**——这里的幅值已被滤波器压低，而过渡带内折回来的混叠成分也可能落在这一区间。真正无混叠的分析范围是从 0 到 80% 带宽，这个区间称为频率范围 Span：

下面这个公式回答的问题是：设定带宽之后，真正可以放心读数的频率上限在哪里？其中 $B$ 是带宽，0.8 这个系数对应物理里抗混叠滤波器过渡带的宽度——从带宽的八成到全带宽这一段，幅值已被滤波器滚降压低、折回的混叠也可能落进来，都不能算数：

$$
\mathrm{Span} = 0.8 \times B
$$

带宽 1000 Hz 时，Span 只有 800 Hz。

![镜像成分全部落在 80% 带宽与带宽之间，0 到 80% 带宽为无混叠的 Span](/images/aliasing/alias-span-mirror.png)

*（图源：网络官方公开资料）*

Simcenter SCADAS 硬件内置抗混叠滤波器，不需要额外配置；Simcenter Testlab 中可以在 Tools -> Options -> General -> Frequency 中将显示切换为 Span，让所有界面直接按可信带宽显示，避免误读 80% 到 100% 带宽之间的数据。

::: info Span 的意义
- Span 是**设定采样率后真正可用的无混叠频率范围**
- 报告中声称"分析到 8000 Hz"，意味着带宽至少要设到 10000 Hz
- 80% 这个数字来自抗混叠滤波器的过渡带宽度，由硬件特性决定
:::

## 四、测试前的带宽设置

把上述规律落成操作，只有一条主线：**带宽按最高关心频率的 1.25 倍以上设置**，等价于"带宽比最高关心频率高 20%"（考虑抗混叠滤波器后，多数采集系统对关心频率的有效采样为 2.5 倍）。

| 测试场景 | 最高关心频率 | 建议带宽 | 采样率 |
| --- | --- | --- | --- |
| 整车怠速振动 | 200 Hz | 256 Hz 以上 | 512 Hz 以上 |
| 动力总成噪声 | 2000 Hz | 2560 Hz 以上 | 5120 Hz 以上 |
| 传动系阶次 | 1000 Hz | 1280 Hz 以上 | 2560 Hz 以上 |
| 结构应变模态 | 500 Hz | 640 Hz 以上 | 1280 Hz 以上 |

两个实践要点：

1. **频域幅值正确只需 2 倍采样，时域判读波形需要 10 倍以上**。想在时域观察波形峰值（如力锤撞击测试），采样率要远高于 2 倍，否则冲击峰值会被削平。相关技术手册建议实践中取关心频率的 10 倍以上，以保证时域峰值测准。
2. **用 Span 思考，用 Bandwidth 设置**。Testlab 里可以直接按 Span 指定，系统自动换算带宽，保证到 Span 为止全部无混叠。这在通道数量多、逐个核算容易出错的场合更稳妥。

::: warning 工程注意
抗混叠滤波器只能滤除 ADC 之前的模拟高频成分。如果传感器本身在带宽以外共振、饱和或过载，产生的失真同样会折进分析频段，滤波器无法处理。传感器量程与安装谐振频率的核查，应排在采样率设置之前。
:::

## 五、混叠的三个典型现场

<strong>怠速振动的"不明 24 Hz"</strong>。某车怠速振动谱上出现一个来源不明的低频峰值，排查传递路径未找到来源。回看采集设置：带宽 100 Hz、采样率 200 Hz，而发动机舱内一台辅件的实际激励在 176 Hz——超出带宽 76 Hz，镜像到 $100 - 76 = 24$ Hz。将带宽提高到 256 Hz 重测，24 Hz 峰值消失，176 Hz 处出现真实峰值。

**敲击测试的波形削峰**。力锤测试时采样率仅为带宽的 2 倍，时域波形上冲击峰值被削掉一截。冲击信号的有效频率内容远超显示带宽，且峰值判读发生在时域——此时 2 倍采样率不够，需按关心频率的 10 倍以上设置采样率，波形峰值才能恢复真实。

**降采样处理的隐患**。对已有数据做数字降采样（减小文件、降低频率分辨率占用）时，如果降采样前没有先做数字低通滤波，高于新带宽的成分会全部折叠进新频段。降采样不是"隔点取值"，必须配合抗混叠滤波——Testlab 的重采样功能内置了这一步，自写脚本处理时需要自行补上。

::: danger 判别要点
谱上出现解释不通的低频峰、时域波形"变圆变钝"、降采样后出现新峰——应首先怀疑混叠：把带宽加倍重新测量。花十分钟重测，可避免沿错误方向的整轮排查。
:::

## 一句话记住

采样不够两倍，高频不消失、只换脸：以带宽为轴折叠成低频假峰且毫无报警；抗混叠滤波器再砍去两成过渡带，能信的只有 0.8 倍带宽的 Span——带宽按最高关心频率的 1.25 倍往上设，时域看波形还要乘 10。
