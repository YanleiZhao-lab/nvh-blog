# 模态置信判据MAC：评估振型一致性的定量指标

> 模态试验完成后，拟合出的振型是否可信？与 CAE 计算的振型是否为同一阶？两批试验数据能否对应？模态置信判据（Modal Assurance Criterion，MAC）将这些问题归结为一个 0 到 1 之间的无量纲数。本文说明 MAC 的数学定义、它对哪些因素敏感/免疫，以及影响其有效性的关键条件——测点空间布置。

## 一、MAC 在算什么：两个向量的夹角余弦平方

一个振型本质上是多维空间里的一个向量：n 个测点，振型就是 n 维复向量（各分量单位取决于传感器类型，如加速度 m/s²）。比较两个振型是否一致，就是比较两个向量是否共线。

设 $\{V_j\}$、$\{V_l\}$ 为两个等长度的振型向量（上标 $H$ 表示共轭转置），MAC 定义为（参考 Simcenter Testing 理论手册 Eqn 17-13 / 18-5）：

$$
\mathrm{MAC}_{jl} = \frac{\left|\{V_j\}^{H}\{V_l\}\right|^{2}}{\left(\{V_j\}^{H}\{V_j\}\right)\left(\{V_l\}^{H}\{V_l\}\right)}
$$

分子是两个振型内积的模平方，分母是各自模长平方的乘积。结构上它是归一化的相关系数，几何上是两向量夹角余弦的平方：

- 两向量只差一个复数比例（幅值与相位缩放均不影响），$\mathrm{MAC} = 1$
- 两向量线性无关，$\mathrm{MAC}$ 接近 0
- 其余情况落在 0 与 1 之间（软件中常以百分比显示，100% 即完全一致）

对复数比例免疫的特性是刻意设计的。试验模态的振型可以在任意复数常数下缩放（模态振型本身不唯一，质量归一化只是其中一种约定），换一批传感器灵敏度、换一个参考点，振型可能整体差一个比例因子，比较工具若对缩放敏感便无法使用。

与 MAC 搭配出现的是**模态比例因子（Modal Scale Factor，MSF）**——两个振型之间的最小二乘复数比例常数（Eqn 17-12）：

$$
\mathrm{MSF}_{jl} = \frac{\{V_j\}^{H}\{V_l\}}{\{V_j\}^{H}\{V_j\}}
$$

MSF 回答"差多少倍"，MAC 回答"这个倍数关系可信吗"。二者存在明确分工：当两向量线性相关时，MSF 即为比例常数，MAC 接近 1；当两向量线性独立时，MAC 接近零，MSF 没有意义。MAC 只有 0.3 时，MSF 虽然仍可算出一个数，但不具备工程解释力。

手册还给出 MAC 的第二个应用：检验模态振型被质量矩阵加权时的正交性（Eqn 18-7）：

$$
\{V_k\}^{T}[M]\{V_l\} = \begin{cases} m_k, & k = l \\ 0, & k \neq l \end{cases}
$$

其中 $m_k$ 为第 k 阶模态质量（kg）。在质量矩阵未知时，通常假定其为元素大致相等的对角阵；在这一前提下，两个不同模态之间 MAC 值很小，即近似等价于二者满足正交性。

::: info 核心概念
- **MAC**：两个振型共线程度的度量，1 为完全一致，0 为线性无关，对任意复数缩放不敏感（无量纲）
- **MSF**：两振型间的最小二乘复比例因子，只在 MAC 接近 1 时有意义
- **AutoMAC**：同一批振型自身计算得到的 MAC 矩阵，用于检验测点布置能否分离各阶模态
- **CrossMAC**：两批不同来源振型（试验对计算、两次试验）之间的 MAC 矩阵
:::

## 二、四种工程用法，看矩阵位置就知道

MAC 很少单独使用，一般以矩阵形式出现：行和列各放一组振型，每个元素是一对振型的 MAC。看对角线还是非对角线，结论完全不同。

| 用法 | 矩阵位置 | 想回答的问题 | 期望结果 |
| --- | --- | --- | --- |
| **试验自身检验** | AutoMAC 对角线 | 拟合出的这阶是否自身一致 | 等于 1（仅作完整性核对） |
| **测点布置检验** | AutoMAC 非对角 | 各阶振型能否被当前测点分开 | 接近 0 |
| **试验对 CAE** | CrossMAC 对角线 | 仿真模型与试验是否对应同一阶 | 接近 1（工程上 0.9 以上认为对应） |
| **两次试验对比** | CrossMAC 非对角 | 是否存在振型错位、漏阶、重根 | 接近 0 |

车身开发中最典型的场景：白车身 CAE 模型算出 45 Hz 弯曲、52 Hz 扭转，试验也测出两个峰。哪个峰对哪个峰？仅凭肉眼观察动画容易先入为主，将两条 CrossMAC 对角线元素列出——0.95 对 0.93、非对角 0.1 以下，对应关系才算闭环。车型换代沿用上一代平台时，新旧车身振型的 CrossMAC 也能定量回答结构改动的大小。

AutoMAC 非对角元素高，还有一种经典判读用途：区分真共振峰与振型交叉点。两条复模态指示函数（Complex Mode Indicator Function，CMIF）曲线在两个共振峰之间出现交叉时，高阶 CMIF 可能出现一个小的峰：

![一阶与二阶 CMIF 曲线示例：两共振峰之间的交叉点处高阶 CMIF 出现小峰](/images/modal-assurance-criterion/cmif-curves-example.png)
*（图源：Simcenter Testing Knowledge Base）*

判别方法：在交叉点两侧各取数据（如频率 a、b 处）计算 MAC 矩阵。矩阵接近幺矩阵（单位阵），说明模态未变、该峰是真实共振峰；矩阵变为反对角阵，说明模态发生了交换，该峰属于交叉点而非新模态：

![CMIF 跟踪与 MAC 矩阵判别：MAC 接近幺矩阵则为共振峰，反对角阵则为交叉点](/images/modal-assurance-criterion/cmif-cross-mac.png)
*（图源：Simcenter Testing Knowledge Base）*

::: warning 数值的陷阱
非对角 MAC 高不一定是拟合错误。两个物理上独立的模态，如果测点全布置在它们振型相似的区域（比如都集中在节点附近），算出的 MAC 照样偏高。此时应先核查测点布置，再核查算法。
:::

## 三、测点布置：MAC 数字背后的决定性因素

MAC 的分辨率受限于测点的空间分布，这与采样定理是同一类问题：时域采样太稀会混叠，空间测点太稀会发生空间混叠（spatial aliasing）。

一根简支梁，前两阶振型是半波正弦与全波正弦，理论正交。8 个测点铺满全梁，MAC 为 0；同样 8 个测点全部集中在半跨以内，一阶和二阶在这段区间里都是先升后降的单峰形状，MAC 升至 0.69。振型没变，测点变了，结论就相反。

整车试验里这个问题很具体：传感器集中在驾驶员侧和后备箱（方便布线），车顶和副驾侧空缺——弯曲和扭转模态恰恰在缺失的区域差异最大，AutoMAC 非对角就会无明显物理解释地偏高。反过来，测点过密也没有收益：超过振型最高空间频率所需的密度后，MAC 不会再改善，只是增加通道成本。

::: tip 测点布置原则
- 先用 CAE 振型做一次虚拟 AutoMAC，布点方案在仿真中把非对角压到 0.1 以下再进试验室
- 测点必须铺开覆盖节线和腹部，优先保证空间分布，不要把测点堆在方便布线的位置
- 振型对比（CrossMAC）只对共同测点计算——两批数据的测点不一致时，先取交集
:::

## 四、Python 演示：同一根梁，两种布点

```python
import numpy as np

def mac(a, b):
    # MAC：内积模平方 / 模长平方积（np.vdot 自带共轭）
    return abs(np.vdot(a, b))**2 / (np.vdot(a, a).real * np.vdot(b, b).real)

# 简支梁前两阶振型：半波正弦与全波正弦，理论正交
x_full = np.linspace(0.02, 0.98, 8)      # 8 个测点铺满全跨
x_half = np.linspace(0.02, 0.48, 8)      # 同样 8 个点挤在左半跨
m1f, m2f = np.sin(np.pi * x_full),  np.sin(2 * np.pi * x_full)
m1h, m2h = np.sin(np.pi * x_half),  np.sin(2 * np.pi * x_half)

print(f"铺满全跨   MAC(1阶,2阶) = {mac(m1f, m2f):.2f}")
print(f"挤在半跨   MAC(1阶,2阶) = {mac(m1h, m2h):.2f}")

# 复数缩放免疫性：振型整体乘 (0.5+2j)，MAC 不变
print(f"复数缩放   MAC = {mac(m1f, (0.5 + 2j) * m1f):.2f}")

# 噪声影响：振型叠加 20% 高斯噪声后与原振型比
rng = np.random.default_rng(0)
noisy = m1f + 0.2 * rng.standard_normal(m1f.size)
print(f"含噪振型   MAC = {mac(m1f, noisy):.2f}")

# AutoMAC 矩阵：全跨 15 点，前三阶
x = np.linspace(0, 1, 15)
P = np.vstack([np.sin(k * np.pi * x) for k in (1, 2, 3)]).T
print("AutoMAC 前三阶：")
for i in range(3):
    print("  " + "  ".join(f"{mac(P[:, i], P[:, j]):.2f}" for j in range(3)))
```

实测输出（numpy 2.x，随机种子 0）：

```text
铺满全跨   MAC(1阶,2阶) = 0.00
挤在半跨   MAC(1阶,2阶) = 0.69
复数缩放   MAC = 1.00
含噪振型   MAC = 0.97
AutoMAC 前三阶：
  1.00  0.00  0.00
  0.00  1.00  0.00
  0.00  0.00  1.00
```

最值得关注的是前两行：同样 8 个测点，铺满全跨 MAC 为 0.00，集中到半跨即升至 0.69——振型完全没变，变的只是测点。含噪振型的 0.97 说明 MAC 对中等噪声相当宽容，它的敏感项在空间分布。

## 五、判断标准

对角线看一致性，非对角看独立性，数值不合格先查测点再查算法。工程上可落地的验收门槛：AutoMAC 非对角小于 0.1（重根或密集模态区可放宽到 0.2），试验与 CAE 的 CrossMAC 对角大于 0.9、非对角小于 0.1。MSF 只在 MAC 高于 0.9 时引用。振型动画与 MAC 数字冲突时，以 MAC 为准——但前提是测点布置已通过虚拟 AutoMAC 的检验。

MAC 也有明确的适用边界：它不能判断一个 ODS（工作振型，Operating Deflection Shape）与某阶振型的相似是否出于巧合。手册明确提示：一个频率为 56 Hz 的 ODS 与固有频率 200 Hz 的模态振型不存在任何关联，尽管二者形状可能看起来相近：

![Simcenter 理论手册对 ODS 与振型巧合相似的提示（17.4 节）](/images/modal-assurance-criterion/ods-56hz-note.png)
*（图源：Simcenter Testing Knowledge Base）*

MAC 只比较形状；两阶模态在物理上是否相关，还必须把频率和激励条件放在一起判断。
