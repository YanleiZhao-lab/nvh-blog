# 模态置信判据MAC：振型对比的照妖镜

> 模态试验做完，拟合出的振型到底可不可信？和 CAE 计算的振型是不是同一个？两批试验数据能不能对上？模态置信判据（Modal Assurance Criterion，MAC）把这些问题压缩成一个 0 到 1 之间的数。这篇讲清 MAC 的数学本质、它对什么敏感对什么免疫，以及最容易被忽视的陷阱——测点布置。

## 一、MAC 在算什么：两个向量的夹角余弦平方

一个振型本质上是多维空间里的一个向量：15 个测点，振型就是 15 维向量。比较两个振型像不像，就是比较两个向量是否共线。

MAC 的定义：

$$MAC_{jl} = \frac{|V_{jk}^{H} V_{lk}|^2}{(V_{jk}^{H} V_{jk})(V_{lk}^{H} V_{lk})}$$

分子是两个振型内积的模平方，分母是各自模长的平方积。结构上它就是归一化的相关系数，几何上是夹角余弦的平方：

- 两向量只差一个复数比例（幅值和相位都不同也不要紧），MAC = 1
- 两向量线性无关，MAC 接近 0
- 其余情况落在 0 与 1 之间
这个对复数比例免疫的特性是刻意设计的。试验模态的振型可以在任意复数常数下缩放（模态振型本身不唯一，质量归一化只是其中一种约定），换一批传感器灵敏度、换一个参考点，振型可能整体差一个比例因子。比较工具如果对缩放敏感就没法用了。

与 MAC 搭配出现的是**模态比例因子（Modal Scale Factor，MSF）**——两个振型之间的最小二乘复数比例常数。MSF 回答差多少倍，MAC 回答这个倍数关系可信吗。MSF 有意义的前提是 MAC 接近 1；MAC 只有 0.3 时，MSF 算出来是个数，但没有任何工程含义。

::: info 核心概念
- **MAC**：两个振型共线程度的度量，1 为完全一致，0 为线性无关，对任意复数缩放不敏感
- **MSF**：两振型间的最小二乘复比例因子，只在 MAC 高时才有意义
- **AutoMAC**：同一批振型自己和自己算 MAC 得到的矩阵，用于检验测点布置是否足以分离各阶模态
- **CrossMAC**：两批不同来源振型（试验对计算、两次试验）之间的 MAC 矩阵
:::

## 二、四种工程用法，看矩阵位置就知道

MAC 很少单独出现，一般以矩阵形式使用：行和列各放一组振型，每个元素是一对振型的 MAC。看对角线还是非对角线，结论完全不同。

| 用法 | 矩阵位置 | 想回答的问题 | 期望结果 |
| --- | --- | --- | --- |
| **试验自身检验** | AutoMAC 对角线 | 拟合出的这阶是不是自己 | 接近 1（恒等于 1，仅作完整性核对） |
| **测点布置检验** | AutoMAC 非对角 | 各阶振型能否被当前测点分开 | 接近 0 |
| **试验对 CAE** | CrossMAC 对角线 | 仿真模型与试验是否对应同一阶 | 接近 1（工程上 0.9 以上认为对应） |
| **两次试验对比** | CrossMAC 非对角 | 有没有振型错位、漏阶、重根 | 接近 0 |

车身开发中最典型的场景：白车身 CAE 模型算出 45 Hz 弯曲、52 Hz 扭转，试验测出来也是两个峰。哪个峰对哪个峰？肉眼看动画容易先入为主，把两条 CrossMAC 对角线元素摆出来，0.95 对 0.93、非对角 0.1 以下，对应关系才算闭环。车型换代时沿用上一代平台，新旧车身振型的 CrossMAC 也能快速回答结构改动了多少。

AutoMAC 非对角元素高，还有一种经典判读用途：区分真共振峰与振型交叉点。两条复幂指示函数（CMIF）曲线在两个共振峰之间出现交叉时，高阶 CMIF 可能冒出一个假峰。在交叉点两侧各取数据计算 MAC——矩阵接近幺矩阵，说明模态没换、假峰是交叉效应；矩阵变成反对角阵，说明模态发生了交换，那个峰属于另一阶。

::: warning 数值的陷阱
非对角 MAC 高不一定是拟合错误。两个物理上独立的模态，如果测点全布置在它们振型相似的区域（比如都集中在节点附近），算出来的 MAC 照样虚高。先怀疑测点，再怀疑算法。
:::

## 三、测点布置：MAC 数字背后的真正主角

MAC 的分辨率受限于测点的空间分布，这和采样定理是同一类问题：时域采样太稀会混叠，空间测点太稀会空间混叠（spatial aliasing）。

一根简支梁，前两阶振型是半波正弦与全波正弦，理论上正交。8 个测点铺满全梁，MAC 算出来是 0；同样 8 个测点全部挤在半跨以内，一阶和二阶在这段区间里都是单调上升再下降的形状，MAC 冲到 0.69。振型没变，测点变了，结论就反了。

整车试验里这个坑很具体：传感器集中在驾驶员侧和后备箱（方便布线），车顶和副驾侧空着——弯曲和扭转模态在缺失的区域恰恰差异最大，AutoMAC 非对角就会不明不白地高。反过来，测点太密也没收益：超过振型最高空间频率需要的密度后，MAC 不会再变好，白花通道钱。

::: tip 测点布置原则
- 先用 CAE 振型做一次虚拟 AutoMAC，布点方案在仿真里把非对角压到 0.1 以下再进试验室
- 测点必须铺开覆盖节线和腹部，宁可用少量测点换空间分布，不要把点堆在方便布线的角落
- 振型对比（CrossMAC）只对共同测点计算——两批数据的测点不一致时，先取交集
:::
## 四、Python 演示：同一根梁，两种布点

```python
import numpy as np

def mac(a, b):
    # MAC：内积模平方 / 模长平方积（np.vdot 自带共轭）
    return abs(np.vdot(a, b))**2 / (np.vdot(a, a).real * np.vdot(b, b).real)

# 简支梁前两阶振型：半波正弦与全波正弦，理论正交
x_full = np.linspace(0.02, 0.98, 8)      # 8 个测点铺满全跨
x_half = np.linspace(0.02, 0.48, 8)      # 同样 8 个点挤在左半跨
m1f, m2f = np.sin(np.pi * x_full),  np.sin(2 * np.pi * x_full)
m1h, m2h = np.sin(np.pi * x_half),  np.sin(2 * np.pi * x_half)

print(f"铺满全跨   MAC(1阶,2阶) = {mac(m1f, m2f):.2f}")
print(f"挤在半跨   MAC(1阶,2阶) = {mac(m1h, m2h):.2f}")

# 复数缩放免疫性：振型整体乘 (0.5+2j)，MAC 不动
print(f"复数缩放   MAC = {mac(m1f, (0.5 + 2j) * m1f):.2f}")

# 噪声影响：振型叠加 20% 高斯噪声后与原振型比
rng = np.random.default_rng(0)
noisy = m1f + 0.2 * rng.standard_normal(m1f.size)
print(f"含噪振型   MAC = {mac(m1f, noisy):.2f}")

# AutoMAC 矩阵：全跨 15 点，前三阶
x = np.linspace(0, 1, 15)
P = np.vstack([np.sin(k * np.pi * x) for k in (1, 2, 3)]).T
print("AutoMAC 前三阶：")
for i in range(3):
    print("  " + "  ".join(f"{mac(P[:, i], P[:, j]):.2f}" for j in range(3)))
```

最值得看的是前两行：同样 8 个测点，铺满全跨 MAC 为 0.00，挤进半跨立刻跳到 0.69——振型完全没变，变的只是测点。含噪振型的 0.97 说明 MAC 对中等噪声相当宽容，它真正的软肋在空间分布。
## 五、判断标准

对角线看一致性，非对角看独立性，数值不合格先查测点再查算法。工程上可以落地的门槛：AutoMAC 非对角小于 0.1（重根或密集模态区放宽到 0.2），试验与 CAE 的 CrossMAC 对角大于 0.9、非对角小于 0.1。MSF 只在 MAC 高于 0.9 时引用。振型动画和 MAC 数字冲突时，以 MAC 为准——但前提是测点布置经过了虚拟 AutoMAC 的检验。

另有一件事 MAC 帮不上忙：判断一个 ODS 和某阶振型的相似是不是巧合。56 Hz 的 ODS 完全可能在形状上撞近 200 Hz 的模态——频率差着几倍，形状相似毫无意义。MAC 只管形状，物理上是否相关，还得把频率和激励条件放进来一起判断。
