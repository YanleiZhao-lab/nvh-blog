# 混叠：采样定理的工程代价与抗混叠滤波器

> 采样率不够，高频信号不会消失，而是换个"假身份"出现在低频段——这就是混叠。本文讲清楚镜像折叠的规律、抗混叠滤波器为什么把可用带宽砍掉 20%，以及测试前该怎么设带宽才能不踩坑。

## 一、高频信号是怎么"变小"的

ADC 按固定间隔对模拟信号取样。取样之后，信号里高于采样率一半的成分不会凭空消失，而是**以虚假的低频身份出现在频谱里**。这个虚假频率叫混叠频率。

时域上看最直观：下图中红色是原始正弦信号，蓝点是采样时刻。采样率太低时，把蓝点连起来（蓝色曲线），得到的是一个频率低得多的正弦——你在屏幕上看到的，就是这个低频假象。

![采样率不足时，高频信号在采样后呈现为低频正弦](/images/aliasing/aliasing-time-domain.png)

混叠的危险在于它**不产生任何报警**。波形看起来完全正常，频谱上也有一个干净的峰，只是频率和幅值都是错的。如果不做预防，一份混叠的数据从采集到出报告可以一路畅通无阻。

### 四个必须分清的术语

| 术语 | 含义 | 数值关系 |
| --- | --- | --- |
| 采样频率 Sampling frequency | 每秒采集的点数 | = 2 x 带宽 |
| 带宽 Bandwidth | 系统的分析频率上限 | = 采样频率的一半 |
| 频率范围 Span | 无混叠的可信分析范围 | = 80% 带宽 |
| Nyquist 频率 | 不产生频率错误的理论下限采样率 | = 2 x 最高关心频率 |

::: info 核心概念
- **混叠**：高于带宽的频率成分被"折叠"到带宽以内，冒充低频信号
- **镜像**：超出带宽 X Hz 的成分会出现在带宽以下 X Hz 处
- **Span**：抗混叠滤波器保证无混叠的区间，只有 80% 带宽
:::

## 二、镜像规律：一张折叠账

混叠的数学本质是镜像折叠：真实频率超出带宽的部分，会关于带宽频率对称地反射回来。带宽 1000 Hz 时，1300 Hz 的成分超出带宽 300 Hz，于是出现在 1000 - 300 = 700 Hz 处。

![超过带宽的频率成分以带宽频率为轴镜像折叠](/images/aliasing/alias-mirroring.png)

LMS 理论手册用"折叠线"描述同一件事：Nyquist 频率的各倍乘数都是折叠线，2f、3f、4f 的信号逐级折叠后，看起来全都和 f 一样。所以混叠不只是"高一点折回来"，远离带宽的频率同样会折进分析范围。

```python
# 混叠频率计算：真实频率 vs 采样后观测频率
import numpy as np

fs = 2000                    # 采样率 Hz
bw = fs / 2                  # 带宽 = 1000 Hz

def observed(f_true, fs):
    """真实频率经采样后在 [0, fs/2) 内被观测到的混叠频率"""
    m = f_true % fs                        # 先折到 [0, fs)
    return m if m <= fs / 2 else fs - m    # 再镜像回 [0, fs/2)

for f in [400, 700, 1300, 1700, 2600]:
    obs = observed(f, fs)
    tag = "正常" if f <= bw else "混叠!"
    print(f"真实 {f:>5} Hz -> 观测 {obs:>5.0f} Hz  {tag}")

# 时域验证：1700 Hz 按 2000 Hz 采样，与 300 Hz 的序列几乎逐点相同
t = np.arange(256) / fs
err = np.max(np.abs(np.sin(2*np.pi*1700*t) - np.sin(2*np.pi*300*t + np.pi)))
print(f"1700 Hz 与 300 Hz 采样序列最大偏差: {err:.1e}")
```

运行结果：1300 Hz 折到 700 Hz（正是手册中的例子），1700 Hz 折到 300 Hz，2600 Hz 折到 600 Hz。一旦超过带宽，观测频率完全不可信。

## 三、抗混叠滤波器：为什么可信带宽只有 80%

防止混叠的唯一办法，是在 ADC 之前用**模拟低通滤波器**把超过带宽的成分滤掉——数字化之后就来不及了，混叠信息已经烙进数据里。这就是抗混叠滤波器。

理想的抗混叠滤波器应该是一堵"砖墙"：带宽以内完全通过，带宽以外彻底截止。但物理世界里不存在砖墙滤波器。实际的滤波器在带宽处有 -3 dB 滚降点，之后需要一段过渡带才能把信号衰减到零，这段过渡带大约延伸到带宽的 120% 处。

![实际抗混叠滤波器在带宽处 -3 dB 滚降，过渡带内幅值已不可信](/images/aliasing/anti-aliasing-filter.png)

由此得到一个关键的工程结论：**从 80% 带宽到带宽之间的区间不可信**——这里的幅值已被滤波器压低，而过渡带里折回来的混叠成分也可能落在这一带。真正干净的分析范围是从 0 到 80% 带宽，这个区间叫频率范围 Span：

```text
Span = 0.8 x Bandwidth
带宽 1000 Hz 时，Span 只有 800 Hz
```

Simcenter SCADAS 硬件内置了抗混叠滤波器，不需要额外配置；Simcenter Testlab 里可以在 Tools -> Options -> General -> Frequency 中把显示切换为 Span，让所有界面直接按可信带宽显示，避免误读 80% 到 100% 之间的数据。

::: info Span 的意义
- Span 是**购买采样率时真正到手的可用频率范围**
- 报告里声称"分析到 8000 Hz"，意味着带宽至少要设到 10000 Hz
- 80% 这个数字来自抗混叠滤波器的过渡带宽度，是硬件设计决定的
:::

## 四、测试前的带宽设置

把上面的规律落成操作，只有一条主线：**带宽要按关心频率的 1.25 倍以上来设**，倒过来就是"带宽比最高关心频率高 20%"。

| 测试场景 | 最高关心频率 | 建议带宽 | 采样率 |
| --- | --- | --- | --- |
| 整车怠速振动 | 200 Hz | 256 Hz 以上 | 512 Hz 以上 |
| 动力总成噪声 | 2000 Hz | 2560 Hz 以上 | 5120 Hz 以上 |
| 传动系阶次 | 1000 Hz | 1280 Hz 以上 | 2560 Hz 以上 |
| 结构应变模态 | 500 Hz | 640 Hz 以上 | 1280 Hz 以上 |

两个实践细节：

1. **频域幅值正确只需 2 倍采样，时域看波形要 10 倍以上**。想在时域观察波形峰值（比如力锤撞击测试），采样率提得比 2 倍高得多才不会削峰。
2. **用 Span 思考，用 Bandwidth 设置**。Testlab 里可以直接按 Span 指定，系统自动换算带宽，保证到 Span 为止全部无混叠，这在高速通道多、逐个核算容易漏的场合更保险。

::: warning 工程注意
抗混叠滤波器只能挡住 ADC 之前的模拟高频。如果传感器本身在带宽以外共振、饱和或过载，产生的失真同样会折进分析频段，滤波器无能为力。传感器量程与安装谐振频率，永远排在采样率之前检查。
:::

## 五、混叠的三个典型现场

**怠速抖动的"神秘 24 Hz"**。某车怠速振动谱上出现一个来源不明的低频峰值，查传递路径一无所获。回看设置：带宽 100 Hz、采样率 200 Hz，而发动机舱内一台辅件的实际激励在 176 Hz——超出带宽 76 Hz，镜像到 100 - 76 = 24 Hz。把带宽提到 256 Hz 重测，"24 Hz"消失，176 Hz 处出现真实峰值。

**敲击测试的波形毛刺**。力锤测试时采样率刚好 2 倍于带宽，时域波形上冲击峰值被削掉一截。冲击信号的有效频率内容远超显示带宽，且幅值判读发生在时域——这里 2 倍不够，按 10 倍于关心频率提采样率，波形峰值才恢复真实。

**降采样处理的隐患**。对已有数据做数字降采样（减小文件、降低分辨率）时，如果降采样前没有先做数字低通滤波，高于新带宽的成分会全部折叠进新频段。降采样不是"隔点取值"，必须配合抗混叠滤波——Testlab 的重采样功能内置了这一步，自写脚本处理时要自己补上。

::: danger 判别口诀
谱上出现解释不通的低频峰、时域波形"变圆变钝"、降采样后冒出新峰——先怀疑混叠，把带宽加倍重测一遍，花十分钟省一轮错误的排查方向。
:::
