# 声品质评价指标：响度、尖锐度、粗糙度

> 两台电动车车内噪声同样是 38 dB(A)，一台听着安静顺滑，一台呜呜声让人心烦。问题不在声压级，在声品质。响度、尖锐度、粗糙度、抖动强度这组心理声学指标分别刻画"多响、多刺、多糙、多晃"，本文讲清每个指标的物理来源、参考定义、算法流派，以及整车 NVH 里什么时候必须用它们代替 dB(A)。

## 一、dB(A) 够用的时候，和不够用的时候

声压级是最基础的声信号描述，20 微帕（20e-6 Pa）是标准化听阈——正常听力的人平均能听到的 1000 Hz 最低声音。可听声压跨越十几个数量级，人耳对声刺激的反应又近似对数规律，所以工程上才普遍用分贝标尺。

但分贝只回答"多少能量"。人耳是一台复杂的非线性接收装置：外耳的耳廓绕射和耳道共振让 1 kHz 到 10 kHz 附近最敏感；内耳耳蜗的非线性让响度与声压级不成线性关系；听还涉及双耳，影响定位与感受。结果就是：**两个 dB(A) 相同的声音，主观感受可以完全不同**。

车辆噪声里最典型的例子：刮水器噪声、燃油泵噪声、电动机的呜呜声、仪表板的咔啦咔啦声——这些对总声压级贡献很小，却最让人厌烦。反过来，关车门的"砰"传递豪华感，赛车加速声传递运动感，这些"好声音"不该被一刀切地消掉。声品质分析的对象就是这些 dB(A) 照不到的角落。

::: info 核心概念
- **声品质（Sound Quality）**：声音的主观属性总和——舒适、厌烦、愉悦、信息含量，超出声压级所能表达的部分
- **心理声学指标（Psychoacoustic Metrics）**：对声信号做特殊处理、逼近听觉感受的定量指标，响度/尖锐度/粗糙度/抖动强度是四大件
- **声品质三步法**：记录（高质量/双耳）→ 评价（指标计算或主观评审）→ 修改（时域/频域/阶次域改信号做对比试听）
:::

## 二、响度：从方的对数世界到宋的线性世界

响度级以方（phon）为单位，规定某声音与多响的 1000 Hz 纯音等响即为多少方——1 kHz 处方值就等于 dB 值。等响曲线（自由场纯音与扩散场窄带噪声版本已并入 ISO 226）是它的物理基础。

方仍是对数标尺，"响一倍"没法直接读出来。宋（sone）标尺解决这个问题：**1 宋对应 40 方，两倍的响对应两倍的宋**，响度级每增加 10 方，宋值翻倍。给老板汇报"这个改进把响度从 4 宋降到 2 宋，主观感受减半"，比"降 10 dB"直观得多。

宽带声不能只看总值。内耳等效于一组衔接的带通滤波器——**临界带（Critical Band）**，以巴克（Bark）标尺刻度：500 Hz 以下各带带宽近恒定约 110 Hz，高频段则扩展为约 23% 恒百分比带宽，与耳蜗的频率—位置对数特性吻合。响度沿 Bark 轴分布成"局部响度"（specific loudness，宋/Bark），这条曲线的形状往往比总响度更能说明问题——哪个频带在"喊"，一眼看穿。

### 掩蔽：响度计算绕不开的听觉特性

同一临界带内的声能量，响度上"合在一起算"：高声级分量会把频率相近的低声级分量**掩蔽**掉。一个 50 dB、4 kHz 的纯音，在中心 1200 Hz、90 dB 的窄带背景噪声中还能听到；背景升到 100 dB 就彻底消失。掩蔽声级越高，被掩蔽的频带越宽——这就是 A 计权文章里"哨声加 A 计权反而更高"现象背后的听觉机制之一：被放大频段的响度贡献压过了低频衰减。

### 两种标准算法

| 算法 | 标准 | 输入数据 | 特点 |
| --- | --- | --- | --- |
| **斯蒂文司 Mark VI** | ISO 532A（1975）/ ANSI S3.4-1980 | 1/1 倍频程声压级 | 查图得各带响度指数 S，合成总响度时掩蔽因子 F 取 0.3（1/1 倍频程）或 0.15（1/3 倍频程）；只适用混响场中平稳宽带噪声 |
| **斯蒂文司 Mark VII** | 未入 ISO | 倍频程声压级 | 更新的计算图表，参考频率改 3150 Hz（32 dB 处定义为 1 宋），附加 PLdB 感觉响度级（约比方值低 8 dB） |
| **兹维克尔（Zwicker）** | ISO 532B | 1/3 倍频程声压级 | 自由场/扩散场各一套图组，显式计入掩蔽（含各带斜坡边缘滤波特性），支持时变信号跟踪；工程主流 |

::: tip 工程选择
- 稳态宽带噪声快速评估 → Stevens Mark VI 查表即可
- 含纯音、多分量的复杂声，或需要沿时间跟踪 → Zwicker（ISO 532B）
- 瞬态声（关门声、咔哒声）→ Zwicker 时变响度，注意帧长要覆盖约 20 ms 的听觉"积聚"时间——猝发音短于 20 ms 响度会打折扣，长于 20 ms 则几乎与时长无关
:::

## 三、尖锐度、粗糙度、抖动强度：三种"讨厌法"细分

响度解决"多响"，剩下三个指标各管一种"讨厌法"。

**尖锐度（Sharpness）**区分尖锐与沉闷，主要取决于谱形心的位置——高频成分占比越高越尖。参考声：中心频率 1 kHz、声压级 60 dB、带宽一个临界带的窄带噪声定义为 1 acum。计算上相当于对局部响度谱做一次矩，计权函数 g(z) 在 0～16 Bark 恒为 1，16 Bark 以上按 0.066·e^(0.171z) 指数抬升——在 16 Bark 处恰好衔接为 1，越往高频权重滚得越陡。限带噪声实验给出直觉：同样带宽，中心频率越高越尖。

![尖锐度与限带噪声中心频率、带宽的关系](/images/sound-quality-metrics/fig7-5-sharpness-band.png)

*限带噪声尖锐度随中心频率与带宽的变化（图源：Simcenter Testing Knowledge Base 中文理论手册）*

**粗糙度（Roughness）**针对幅值调制声。调制频率在约 15～300 Hz 区间时，人耳跟不上包络起伏，听到的是一种稳定但"糙"的声音——发动机噪声里分数谐波引起的调制就是典型。调制频率低于 15 Hz，粗糙感退化为下述的抖动感；高于 300 Hz 则能分辨出边带音。单位 asper：1 kHz、60 dB 纯音被 70 Hz、100% 幅值调制时定义为 1 asper。Zwicker 近似式 R 约等于 0.3·f_mod·ΔL，其中 ΔL 是考虑瞬态掩蔽后的掩蔽深度——不是信号包络的峰谷差，这一点常被忽视。

**抖动强度（Fluctuation Strength）**处理调制频率低于约 20 Hz 的工况，此时能直接感到音量"晃动"。同样 RMS 值下，晃动的声音比平稳声显得更响、更烦——电动车低速蜂鸣、鼓风机调速时的呜呜声常落在这个区间。单位 vacil：1 kHz、60 dB 纯音被 4 Hz、100% 调制定义为 1 vacil。近似式 F 约等于 ΔL/(f_mod/4Hz + 4Hz/f_mod)——分母在 f_mod = 4 Hz 处最小，抖动感最强，两侧对称下滑，与粗糙度对 70 Hz 附近最敏感形成呼应。

| 指标 | 感觉维度 | 参考定义 | 调制频率敏感区 | 典型整车场景 |
| --- | --- | --- | --- | --- |
| **响度 N（sone）** | 多响 | 40 方 = 1 sone | — | 车内总噪声水平对标 |
| **尖锐度 S（acum）** | 多刺 | 1 kHz/60 dB 临界带窄带噪声 = 1 acum | — | 蜂鸣、啸叫、气流声评价 |
| **粗糙度 R（asper）** | 多糙 | 1 kHz/60 dB 纯音，70 Hz/100% 调制 = 1 asper | **15～300 Hz** | 发动机燃烧噪声、齿轮啮合调制 |
| **抖动强度 F（vacil）** | 多晃 | 1 kHz/60 dB 纯音，4 Hz/100% 调制 = 1 vacil | **20 Hz 以下，4 Hz 附近** | 电驱呜呜声、鼓风机调速拍振 |

![窄带噪声掩蔽效应：4 kHz 纯音被强窄带噪声淹没的过程](/images/sound-quality-metrics/fig7-3-masking-zwicker.png)

*掩蔽效应：背景从 90 dB 升到 100 dB，4 kHz 纯音从可闻变为完全被掩蔽（图源：Simcenter Testing Knowledge Base 中文理论手册）*

::: warning 工程注意
粗糙度和抖动强度的分界是**调制频率**，不是载波频率。同一个电驱阶次噪声，包络波动 4 Hz 时是抖动问题，波动 70 Hz 时是粗糙度问题——整改方向完全不同（前者查拍频/拍振源，后者查啮合调制的边带结构）。
:::

## 四、Python 演示：响度换算与两种调制感觉的分界

```python
import numpy as np

# ---- 响度：方与宋换算（S = 2^((P-40)/10)）----
phon = np.array([40, 50, 60, 70, 80])
sone = 2 ** ((phon - 40) / 10)
for p, s in zip(phon, sone):
    print(f"{p} 方 = {s:5.1f} 宋")
print(f"60 方降到 50 方，响度比值 = {2**((50-60)/10):.2f}")

# ---- 粗糙度 R 正比 f_mod；抖动强度 F 正比 1/(f/4 + 4/f) ----
# 各自按单位定义的参考调制频率归一化（R 以 70 Hz 为 1，F 以 4 Hz 为 1）
f = np.array([2, 4, 8, 15, 20, 40, 70, 150, 300])
R = 0.3 * f                      # 掩蔽深度相同时，粗糙度随调制频率线性上升
R = R / R[np.isclose(f, 70)]
F = 1.0 / (f/4 + 4/f)            # 抖动强度的频率形状，4 Hz 处最大
F = F / F[np.isclose(f, 4)]
print("\n f_mod(Hz)   R归一(70Hz=1)   F归一(4Hz=1)")
for fi, ri, fj in zip(f, R, F):
    print(f"{fi:8.0f}        {ri:6.3f}          {fj:6.3f}")
```

输出里最值得看的两组数：响度从 60 方降到 50 方，宋值从 4.0 降到 2.0——主观响度恰好减半，这是宋标尺存在的意义；归一化后 R 曲线线性爬升、F 曲线在 4 Hz 见顶回落，15 Hz 往后 F 掉得比 R 快得多，两条线在 20～40 Hz 之间完成交叉——与听觉上"抖动"（20 Hz 以下为主）和"粗糙"（15～300 Hz）的分界带基本吻合。

## 五、Python 演示二：调制深度怎么喂给粗糙度

```python
import numpy as np

# 1 kHz 载波 + 70 Hz 幅值调制，改变调制深度 m
fs = 48000
fm = 70.0
t = np.arange(0, 0.5, 1/fs)

def env_depth_db(m):
    # 包络 = 1 + m*sin(2*pi*fm*t)，峰谷差 dB = 20*log10((1+m)/(1-m))
    env = 1 + m * np.sin(2*np.pi*fm*t)
    return 20*np.log10(env.max() / env.min())

print(" 调制深度m   包络峰谷差dB   R相对值(以m=0.5为1)")
ref = env_depth_db(0.5)
for m in [0.1, 0.25, 0.5, 0.75, 0.9]:
    dL = env_depth_db(m)
    print(f"{m:8.2f}        {dL:8.2f}            {dL/ref:6.2f}")
```

m=0.5 时峰谷差约 9.5 dB，m=0.25 时掉到 4.4 dB——调制深度砍半，包络峰谷差（粗糙度模型里正比于它的输入量）掉得比线性快。另外注意 m 趋向 1 时谷值触零、dB 差发散，而实际听觉的掩蔽深度会被瞬态掩蔽效应压住——这正是模型坚持用"掩蔽深度"而非"包络峰谷差"的原因。

## 六、小结

- 讲"多响"用响度：对标汇报用宋（线性、好沟通），谱定位用宋/Bark 局部响度（哪一带在喊）
- 讲"多刺"用尖锐度：整改高频占比，1 acum 参考声是 1 kHz/60 dB 临界带窄带噪声
- 讲"多糙/多晃"先看调制频率：15～300 Hz 归粗糙度（asper），20 Hz 以下归抖动强度（vacil），4 Hz 和 70 Hz 各自是敏感峰
- dB(A) 达标但客户抱怨"吵得烦"的项目，直接上 Zwicker 响度 + 尖锐度 + 粗糙度三件套，别在 A 计权里打转
