# 模态指示函数 MIF：从 FRF 矩阵的特征值凹陷里数模态

> 白车身锤击模态试验做完，FRF 曲线铺满一屏：哪几个峰是真模态？两个挨着的峰是密频还是重根？凭幅值谱肉眼数峰，密频对只看到一个包络，重根更是一个峰都多不出来。模态指示函数（Mode Indicator Function, MIF）把整个 FRF 矩阵压缩成一列随频率走的特征值曲线——共振区曲线塌陷成"谷"，第几条曲线一起塌，就说明这颗频率上至少有几颗模态。这篇从"共振处响应虚部主导"这个物理事实出发，推导 MIF 的特征值问题，讲清第一、第二 MIF 怎么分工，重根判据怎么用，最后用 numpy 造一根带密频对和二重根的"假车身"亲手数一遍模态。

## 一、为什么幅值谱数峰不可靠

锤击或激振器试验拿到的是一组频响函数（Frequency Response Function, FRF）：$N_o$ 个响应测点 × $N_i$ 个参考输入，组成 FRF 矩阵 $H(\omega)$，每个元素都是从某点激励、另一点响应的传递函数。大多数工程师的习惯是把几条 FRF 幅值曲线叠在一张图上数峰。这个做法有两个系统性漏洞。

第一，单条 FRF 会丢模态。激励点或响应点落在某阶振型的节点附近，该阶留数趋零，这条曲线上就没有峰——这是驱动点测量那篇讲过的问题。第二，也是更要命的：幅值谱把多阶模态的能量叠成一个包络。两阶模态频率相差不到一个共振带宽时，幅值上只表现为一个又高又胖的峰；完全重合的重根模态更是天生一个峰。数峰数出来的"模态个数"，下限都保证不了。

MIF 的思路是不看单条曲线，看整个矩阵的"姿态"。它逐条谱线地问：这个频率上，FRF 矩阵的实部占多大比重？答案打包成一组 0 到 1 之间的特征值曲线，共振信息全部写在这些曲线的凹陷里。

::: info 核心概念
- **模态指示函数（MIF）**：逐谱线求解特征值问题得到的频域函数，在固有频率处呈局域极小（凹陷）；可算出的 MIF 条数等于输入（参考）自由度数
- **重根（Repeated Root）**：两阶或多阶模态具有相同的固有频率（如对称结构的一弯一扭），靠单条 FRF 无法分辨
- **密频对（Closely Spaced Modes）**：频率间隔小于共振带宽的两阶模态，幅值谱上融成一个峰，但物理上是两颗独立的极点
- **FRF 矩阵 $H(\omega)$**：$N_o \times N_i$ 的复数矩阵，第 $ij$ 元素为 j 点激励、i 点响应的频响函数
:::

## 二、推导：从"共振处虚部主导"到特征值问题

### 第一步：共振处响应转了 90 度

单自由度系统位移导纳的频响函数，分母是 $k - \omega^2 m + j\omega c$。写成正则形式：

$$H(\omega) = \frac{1/k}{1 - \lambda^2 + 2j\zeta\lambda}, \quad \lambda = \omega/\omega_n$$

实部和虚部分别为

$$\mathrm{Re}\,H = \frac{1}{k}\cdot\frac{1-\lambda^2}{(1-\lambda^2)^2 + (2\zeta\lambda)^2}, \qquad \mathrm{Im}\,H = -\frac{1}{k}\cdot\frac{2\zeta\lambda}{(1-\lambda^2)^2 + (2\zeta\lambda)^2}$$

在共振处 $\lambda = 1$：实部分子 $1-\lambda^2 = 0$，虚部达到极值。物理意义很直白——实模态、弱阻尼条件下，结构响应在共振处恰好落后激励力 90°，能量全部写进虚部；实部只在共振两侧变号过零。这个"实部归零、虚部称王"的特性，就是 MIF 的全部出发点。

多自由度、多输入的情形，把每个测点的响应排成向量。给一组参考输入力向量 $F$，响应为 $X = [H]F$。激励力向量可以随意缩放，MIF 要找的是：**在所有可能的激励组合里，响应向量实部的"总长度"占响应总长度的最小比例是多少**。

### 第二步：比值的最小化问题

把这个比例写成二次型比值。响应实部能量为 $F^T[H_R]^T[H_R]F$，响应总能量为 $F^T([H_R]^T[H_R] + [H_I]^T[H_I])F$，其中 $[H_R]$、$[H_I]$ 是 FRF 矩阵的实部和虚部。要最小化的目标函数：

$$D^2 = \frac{F^T[H_R]^T[H_R]F}{F^T\left([H_R]^T[H_R] + [H_I]^T[H_I]\right)F} \to \min$$

$D^2 = 0$ 意味着存在一种激励组合，让响应的实部完全消失——这正是"激励找准了某阶实模态"的数学表述（手册原话：当结构上的激励找准某一模态时，响应向量实部的总长度必定变得极小）。

### 第三步：瑞利商变特征值

分母归一的二次型比值是标准的瑞利商（Rayleigh Quotient）结构，最小值在广义特征值问题的最小特征值处取到：

$$[H_R]^T[H_R]\,F = \mu\left([H_R]^T[H_R] + [H_I]^T[H_I]\right)F$$

对每一条谱线解一次这个特征值问题，把特征值按从小到大排：

- **第一 MIF** = 每条谱线的最小特征值 $\mu_1(f)$。某个频率存在实的纯模态时，$\mu_1$ 出现明显的局域极小——曲线塌出一个谷。
- **第二 MIF** = 每条谱线的第二小特征值 $\mu_2(f)$。只有当结构存在**重根模态**时，它才呈现明显的局域极小。
- 更高阶 MIF 同理：第 $n$ 条 MIF 塌陷，意味着该频率上至少有 $n$ 颗模态重合。

可组成的 MIF 阶数等于特征值个数，也等于输入（参考）自由度数。这就是手册那句结论的来历：**两条 MIF 一起塌，且塌的深度都接近零，才能宣布二重根；四重根需要四条 MIF 同时塌，也就要求至少四个独立参考输入**。

::: warning 两个容易踩的坑
- MIF 的判读前提是"实模态"。结构存在强阻尼连接、局部大阻尼时模态是复的，响应相位不再是干净的 90°，实部谷底填不满，MIF 数值偏高、凹陷变浅——METU 的教材综述明确指出 MvMIF 在非实模态系统里结果不可靠。此时改看 CMIF（复模态指示函数，对 FRF 矩阵逐谱线做 SVD，奇异值曲线的**峰**指示模态）。
- 特征值问题维数等于参考点数。两个参考点最多算出第一、第二 MIF，遇到三重根结构（轮胎的多重对称模态就是常客）直接漏判。参考点数量和位置要按预期的模态重数规划。
:::

## 三、MIF 家族与 FRF 累加：一个工具箱

MIF 不是孤军。围绕"数峰、定频、验频"这件事，工程软件里常备一组同族工具，峰谷方向和分工各不相同：

| 工具 | 数学操作 | 指示形态 | 主要用途 |
| --- | --- | --- | --- |
| **第一 MIF（MvMIF）** | $[H_R]^T[H_R]$ 的最小特征值 | 共振处**塌谷** | 找出所有被当前参考组激励到的模态频率 |
| **第 n MIF** | 同一特征值问题的第 n 小特征值 | 与前 n−1 条**同时塌谷** | 判定 n 重根，需要的独立参考数 ≥ n |
| **CMIF** | FRF 矩阵逐谱线 SVD 的奇异值 | 共振处**起峰** | 复模态也适用；密频对表现为两条奇异值曲线同时起峰 |
| **FRF 累加** | 各 FRF 的实部、虚部分别取绝对值求和 | 共振处**起峰** | 增强全部数据的共振峰，与估计频率比对 |
| **稳定图** | 递增模型阶数反复拟合极点 | 物理模态连成**竖直光柱** | 区分物理模态与计算模态（见模态拟合入门篇） |

FRF 累加值得单独一提，它是固有频率估计精度的快速体检：把所有测点 FRF 的实部和虚部分别取绝对值后逐线求和，共振峰被全体数据投票放大。拿累加曲线的峰位对照拟合出的各阶固有频率，丢失模态、有毛病的频率估计、传感器附加质量导致的共振频率偏移，一眼就能揪出来。

::: tip 怎么选
- 锤击单参考试验：先 FRF 累加数峰 + 第一 MIF 定频，稳定图选极点，两套独立证据交叉验证
- 密频疑似区（两个峰肩并肩、峰间还有反号）：上 CMIF，两条奇异值曲线是否同时起峰是密频对的直接证据
- 对称结构疑似重根：确认参考点数 ≥ 疑似重数，再看第 n MIF 是否与前 n−1 条一起塌陷
:::

## 四、Python 演示：亲手数一遍模态

构造一个 3 测点 × 2 参考输入的"试验"：30.1/30.6 Hz 一对密频模态，45.0 Hz 一组二重根（两阶正交振型分别只被两个参考激励到）。逐谱线解特征值问题，看第一、第二 MIF 怎么分工。

```python
import numpy as np

f = np.linspace(20, 55, 1401)                # 谱线
w = 2*np.pi*f
# (固有频率Hz, 阻尼比, 实振型(3测点), 参与系数(2输入))
modes = [(30.1, .01, np.array([1.0, .8, .3]), np.array([1.0, .6])),
         (30.6, .01, np.array([.4, -.9, 1.0]), np.array([.5, 1.0])),
         (45.0, .01, np.array([1.0, 0.0, -1.0]), np.array([1.0, 0.0])),   # 重根A: 输入1专激
         (45.0, .01, np.array([0.0, 1.0, 0.0]), np.array([0.0, 1.0]))]    # 重根B: 输入2专激
mif = np.zeros((len(f), 2))
for k, wi in enumerate(w):
    H = np.zeros((3, 2), dtype=complex)
    for fk, zk, psi, L in modes:             # 实模态叠加 -> FRF 矩阵
        wk = 2*np.pi*fk
        H += np.outer(psi, L) / (wk**2 - wi**2 + 2j*zk*wk*wi)
    HR, HI = H.real, H.imag
    A = HR.T @ HR                            # 实部能量矩阵
    ev = np.sort(np.linalg.eigvals(
        np.linalg.solve(A + HI.T @ HI, A)).real)   # 逐线特征值分解
    mif[k] = ev[:2]                          # 最小两个特征值 -> 第一/第二 MIF
for f0, name in [(30.35, "30.1/30.6 Hz 密频对"), (45.0, "45.0 Hz 二重根")]:
    sel = np.abs(f - f0) < 1.5
    print(f"{name}: MIF1 谷底 {mif[sel,0].min():.4f}, MIF2 谷底 {mif[sel,1].min():.4f}")
print(f"非共振区基线: MIF1 中位数 {np.median(mif[:,0]):.2f}, MIF2 中位数 {np.median(mif[:,1]):.2f}")
```

运行结果要点：密频对处 MIF1 塌到 0.0005 而 MIF2 只降到 0.40——两颗极点频率不同，各自能被"单独瞄准"，但无法同时消掉两组实部，第二特征值掉不下去；45 Hz 二重根处两条 MIF 一起塌到 0.0003/0.0046——两个独立参考输入把两阶正交振型分别激起来，两组实部可以同时清零。基线 0.99 对着谷底 0.0005，凹陷深浅两个数量级，判读毫无歧义。

## 五、参考点数与输入布局：MIF 的能力上限

演示里再做一个对照：把输入 2 拿掉，只用输入 1 重新算。45 Hz 处 MIF1 照样塌（谷底 0.0015），但特征值问题退化成 1×1，**第二 MIF 根本不存在**——重根 B 没被激励到，矩阵里没有它的信息，塌不塌都无从谈起。这不是算法缺陷，是信息论层面的缺席：$N_i$ 个参考最多撑起 $N_i$ 条 MIF，也最多"看见" $N_i$ 重复根。

工程上的推论很直接。整车车身对称模态、轮胎/制动盘的多节径模态、航空壁板的对称/反对称对，重数经常是 2 甚至 3。试验规划阶段就要把参考点布够：数量上，参考点数 ≥ 疑似最大重数；位置上，各参考点在疑似重根振型上的投影要独立（对称结构的对称点和反对称点各取一个，别把两个参考都放在对称面上）。布完再测，MIF 才有资格替你数模态；反过来，第二 MIF 全程不塌、只在个别谱线抖一下，也先检查参考点是不是布在了振型节点上，再下"无重根"的结论。

## 六、小结

- MIF 是"逐谱线特征值分解"的产物：$[H_R]^T[H_R]$ 对 $[H_R]^T[H_R]+[H_I]^T[H_I]$ 的广义特征值，从小到大排成第一、第二…条曲线
- 共振处曲线塌谷；第 n 条 MIF 与前 n−1 条同时塌，该频率上至少 n 颗模态；判重根先确认参考点数 ≥ n
- 密频对与重根的区分就一句话：MIF1 单独塌是密频（或单模态），MIF1/MIF2 一起塌才是重根；复模态场景换 CMIF
- FRF 累加全体数据投票放大峰，与拟合频率对照，丢模态、错频率、附加质量频移一查一个准
