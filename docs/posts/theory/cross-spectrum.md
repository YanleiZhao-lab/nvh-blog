# 互功率谱与互相关：双通道信号关系分析的基础函数

> 自功率谱描述单信号的能量频率分布，双通道分析处理的则是另一个问题：两个信号之间是什么关系——激励与响应、声源与测点、参考通道与工作数据。互相关（Cross-correlation）在时域度量两个信号相似性随时延的变化，互功率谱（Cross-power Spectrum）在频域逐频率保存两个信号之间的幅值与相位关系，两者构成一对傅里叶变换。相干函数、频响函数估计、ODS 分析与声强测量都以互功率谱为基础。本文按 Simcenter Testlab 理论手册第 3 章（互相关、互功率谱、相干函数）与第 5 章（声强）展开定义、计算式与工程判读方法。

## 一、工程问题与函数定义

动力总成台架上，悬置主动端和车身侧各布置一个加速度计。两条时域曲线的频率成分相近、相位关系不明确、都混有噪声，仅靠目视无法回答"车身振动有多少经由悬置传递、传递了多长时间"。单通道的自功率谱（Autopower）给不出这个答案：自谱是信号与自身共轭的乘积，$X^*(f) \cdot X(f) = |X(f)|^2$，相位在乘积中抵消，只剩下能量分布。

双通道分析需要两个函数配合。互相关回答"两个信号波形相似性在多大的时延处达到最大"；互功率谱回答"在每个频率上，两个信号的幅值乘积多大、相位差多少"。一个在时域、一个在频域，通过傅里叶变换互相转换。

**互相关的时域定义**（手册式 3-4）：滑动时延 $\tau$，把 $x(t)$ 与平移后的 $y(t+\tau)$ 逐点相乘并在全部时间上平均——乘积平均越大，说明该时延下两个波形越相似：

$$
R_{xy}(\tau) = \lim_{T \to \infty} \frac{1}{T} \int_{-T}^{+T} x(t)\, y(t+\tau)\, \mathrm{d}t
$$

其中 $x(t)$、$y(t)$ 为两通道时间信号（单位如 m/s²），$\tau$ 为时延（单位 s），$R_{xy}(\tau)$ 的单位为两信号单位之积（如 (m/s²)²）。

**互功率谱的定义**（手册式 3-15）：对 $M$ 帧记录，逐帧将 $x$ 通道即时线性谱的共轭与 $y$ 通道即时线性谱相乘，再做谱平均：

$$
S_{xy}(k) = \frac{1}{M} \sum_{m=0}^{M-1} X^*(k)_m \, Y(k)_m, \quad k = 0, 1, \dots, N-1
$$

其中 $X^*(k)_m$ 为第 $m$ 帧时间信号 $x(n)$ 即时线性谱的共轭复数，$Y(k)_m$ 为第 $m$ 帧信号 $y(n)$ 的即时线性谱，$M$ 为平均帧数。对比单帧的 $X^*(k) \cdot Y(k)$，多帧平均正是互谱抑制不相关噪声的来源。

**两者的变换关系**（手册 3.3 节）：互功率谱与互相关函数为一对傅里叶变换，离散域按下式互相转换（手册式 3-5）：

$$
R_{xy}(k) = \mathrm{IFFT}\{\, S_{xy}(k) \,\}
$$

时域频域是同一份信息的两种读法：互相关峰的横坐标给出传播时间差，互谱相位按频率逐点给出两信号的相对相位。

注意共轭的位置：互谱是 $X$ 的共轭乘 $Y$。这一约定决定了相位符号——$S_{xy}$ 的相位等于 $y$ 滞后 $x$ 的角度。判读传递路径的先后次序之前，先核对所用软件的共轭约定。

::: info 核心概念
- **互相关函数 $R_{xy}(\tau)$**：两信号相似性随时延 $\tau$ 的变化，峰的位置给出传播时间差
- **互功率谱 $S_{xy}(f)$**：$X^*(f) \cdot Y(f)$ 的多帧谱平均，逐频率携带两信号的幅值关系与相对相位
- **傅里叶变换对**：互谱逆变换回互相关，时域频域是同一份信息的两种读法
- **相位约定**：$S_{xy}$ 相位 = $y$ 滞后 $x$ 的角度；判传递方向前先核对软件的共轭约定
:::

## 二、互谱的判读：幅值与相位

互功率谱是复数，判读分幅值与相位两部分。

**幅值部分。** 互功率谱是一乘积，当两个信号的幅值都大时它的值也大，两个信号的幅值都小时它也小——因此它可以指示输入和输出二者中占优势的信号幅值。手册同时给出警示：互功率谱的高值也可能只是由于输出幅值高，而并非由输入所引起。典型情形是输出端存在共振峰：幅值被放大十倍，互谱跟着高十倍，而输入端激励在该频率的能量可能微不足道。**互谱高不等于因果强**，输入与输出的相互关系要由相干函数 $\gamma^2 = |S_{xy}|^2 / (S_{xx} S_{yy})$ 来揭示——它把"双方幅值都大"折算成"输出能量中能被输入线性解释的比例"（详见《相干函数》一文）。

**相位部分。** 互功率谱在任意频率的相位值，表示两个信号之间在该频率的相对相位，因此可用它作相位关系分析。设悬置主动端到车身侧某个 180 Hz 分量的相位差为 90°，说明该分量沿路径传播了四分之一周期。逐频率的相位差连成曲线，可以区分两类传递性质：纯延迟对应相位随频率线性变化，斜率即时间差；经过共振区则相位快速翻转约 180°。

互功率谱的幅值类型与自功率谱相同，分为 RMS 和 Peak 两种。跨数据对比前先统一幅值类型，再比较数值。

::: warning 工程注意
互功率谱的峰值可能只反映输出端共振被放大，与输入强弱无关。传导函数 $T = S_{yx}/S_{xx}$ 的峰同样要区分成因：共振峰处互谱与自谱在同一频率同时有峰，分子分母约分后 $T$ 值反而并不很大；反共振点处分母自谱接近零，会引起明显偏离实际的 $T$ 峰。判读双通道数据，互谱必须与自谱、相干函数放在一起看，单看互谱幅值下结论不可靠。
:::

## 三、五个应用场景

| 应用 | 用到的函数 | 关键物理量 | 典型场景 |
| --- | --- | --- | --- |
| **频响函数估计** | $H_1 = S_{yx}/S_{xx}$ | 互谱除以输入自谱 | 锤击/激振器模态试验 |
| **相干函数** | $\gamma^2 = |S_{xy}|^2/(S_{xx} S_{yy})$ | 互谱与自谱的组合 | FRF 质量评估 |
| **传递时差定位** | 互相关峰位置 | $R_{xy}(\tau)$ 峰值对应的 $\tau$ | 声源定位、路径传播时间 |
| **ODS 工作振型** | 相对参考点的互谱 | 互谱相位确定各点相对运动 | 工况状态下整机变形 |
| **声强测量** | 双传声器互谱虚部 | $\mathrm{Im}(S_{12})/(2\pi f \rho d)$ | 声功率与声场分布 |

三个要点展开。

**FRF 估计为什么用互谱而不用单帧谱相除。** 单帧数据 $Y/X$ 固然能得到一个复数比，但噪声完全没有被抑制。以 $H_1$ 估计（手册式 3-22）为例，它假定输入信号中不含噪声，使输出信号的噪声影响在最小二乘意义上极小化：

$$
H_1(k) = \frac{S_{yx}(k)}{S_{xx}(k)}
$$

多帧平均后，输出端与输入不相关的噪声在互谱分子中被平均掉——噪声与输入不相关，乘积的期望趋于零，而分母 $S_{xx}$ 保留输入的真实功率。这是"用互谱换信噪比"的机制，也是一切 FRF 估计的出发点。

**H1 与 H2 的适用范围。** $H_1 = S_{yx}/S_{xx}$ 假定输入无噪、输出噪声被最小二乘压掉：输入存在噪声时得到 FRF 的欠估计，反共振区的估计优于共振区。$H_2 = S_{yy}/S_{yx}$（手册式 3-23）假定输出无噪：输出存在噪声时得到过估计，对共振区的估计优于反共振区，且仅在单输出情况下才能计算。真值介于两者之间，单输出情形下 $|H_1|/|H_2|$ 的比值就是常相干 $\gamma^2$。锤击试验力信号信噪比差，共振峰判读以 $H_1$ 为准；输出通道干净时 $H_2$ 对共振峰更合适。

![H1、H2、Hv 三种 FRF 估计](/images/cross-spectrum/frf.png)

*三种 FRF 估计式：对噪声位置的不同假设给出不同的估计（图源：Simcenter Testing Knowledge Base）*

**声强测量用互谱虚部。** p-p 探头由两只间距 $d$ 的传声器组成，声强按手册式 5-1 计算：

$$
I = \frac{\mathrm{Im}(S_{1,2})}{2 \pi f \rho d}
$$

其中 $S_{1,2}$ 为两个传声器信号之间的双边互功率谱，$f$ 为信号频率（Hz），$d$ 为两传声器间距（m），$\rho$ 为空气密度（kg/m³）。互谱的虚部直接对应声能量传播：两只传声器感受到的相位差里包含压力梯度信息，经频率与间距换算即得质点速度，声压与质点速度的乘积对时间平均即声强（单位 W/m²）。声强分析仪的核心运算就是双通道互谱的虚部。

::: tip 实用建议
- 传递路径或 ODS 分析中固定一个信噪比高的通道作参考，所有互谱都对它计算：所有响应信号受到相同程度的工况变化影响，基于相对测量这些影响可以被消除，参考信号的相位同时充当所有信号的相位参考（手册 17 章）
- 平均次数要充足：互谱的噪声抑制依赖谱平均，帧数不足时相干估计不可靠、相位散布大
- 声强探头间距 $d$ 按频段选取——低频需大间距保证相位差分辨力，高频需小间距防止有限差分误差增大
:::

## 四、Python 数值演示

**演示一：互相关峰定位传播时延。** 主动端为宽带随机振动，经 5 ms 传到车身侧，输出端叠加三倍于信号的标准差噪声，检验互相关对时延的估计能力：

```python
import numpy as np

fs = 4096                       # 采样率 Hz
N = 8192                        # 每帧点数
rng = np.random.default_rng(0)

x = rng.standard_normal(N)      # 主动端：宽带随机振动
delay = int(0.005 * fs)         # 5 ms 传播延迟对应的点数
noise = 3.0 * rng.standard_normal(N)
y = np.roll(x, delay) + noise   # 车身侧：延迟信号 + 强噪声

# 互相关：FFT 法 Rxy = IFFT( conj(X) * Y )
X, Y = np.fft.rfft(x), np.fft.rfft(y)
rxy = np.fft.irfft(np.conj(X) * Y, N)
lags = np.arange(N) / fs * 1000             # 时延轴换算成 ms

k = int(np.argmax(rxy[:N//2]))              # 正时延区找峰
snr = 10*np.log10(np.sum(x**2) / np.sum(noise**2))
print(f"输出端信噪比: {snr:.1f} dB（噪声能量是信号的 9 倍）")
print(f"互相关峰位置: {lags[k]:.2f} ms（真实延迟 5 ms，分辨率 {1000/fs:.2f} ms）")
```

实测输出（rng 种子 0）：输出信噪比 −9.5 dB，噪声能量是信号的 9 倍，时域波形中信号完全不可辨；互相关峰仍落在 4.88 ms——与真实延迟 5 ms 的偏差小于一个采样间隔（0.24 ms）。互相关对不相关噪声的抑制来自乘积的平均：噪声与 $x(t)$ 不相关，乘积期望为零，只有真实延迟处的相似成分在平均中保留下来。

**演示二：互谱相位跨共振区的翻转。** 200 Hz 单自由度系统（阻尼比 4%）受白噪声激励，做 50 帧谱平均，检查互谱相位在共振频率前后的变化：

```python
import numpy as np

fs, N, M = 1024, 4096, 50                  # 采样率、点数、平均帧数
fn, zeta = 200.0, 0.04                     # 固有频率 Hz、阻尼比
f = np.fft.fftfreq(N, 1/fs)                # 配合 fft 的频率轴
H = 1.0 / (fn**2 - f**2 + 2j*zeta*fn*f)    # 位移型 FRF（复数）
rng = np.random.default_rng(1)

Sxy = np.zeros(N, dtype=complex)
for _ in range(M):
    x = rng.standard_normal(N)             # 白噪声激励
    y = np.fft.ifft(np.fft.fft(x) * H).real
    X, Y = np.fft.fft(x), np.fft.fft(y)
    Sxy += np.conj(X) * Y                  # 互谱累加

for fq in [150.0, 199.75, 200.75, 250.0]:  # 共振点两侧各取谱线
    k = int(round(fq * N / fs))
    print(f"{fq:6.1f} Hz  互谱相位 {np.angle(Sxy[k]/M, deg=True):+7.1f} 度")
print("跨过共振：相位从 ~0 度经 -90 度过渡到 ~-180 度，响应与激励反相")
```

实测输出（rng 种子 1）的四个相位值：150 Hz 处 −7.8°（位移响应基本跟随激励），199.75 Hz 与 200.75 Hz 分踞共振点两侧、相位分别约 −88.2° 与 −95.3°（共振区弹性与惯性能量交换），250 Hz 处 −169.9°（位移与激励反相）。互谱相位曲线就是 FRF 相位曲线的原料，模态识别中的"相位翻转"判据即由此而来。

## 五、自谱、互谱、互相关对照

| 维度 | 自功率谱 | 互功率谱 | 互相关 |
| --- | --- | --- | --- |
| **信号数** | 1 | 2 | 2 |
| **域** | 频域 | 频域 | 时域 |
| **复数性** | 实数 | 复数（含相位） | 实数 |
| **相位信息** | 无（共轭相乘消掉） | 有，逐频率相对相位 | 隐含在峰的偏移里 |
| **噪声抑制** | 平均降噪 | 不相关噪声在平均中趋于零 | 同左 |
| **典型输出** | 谱峰定位 | FRF、相干、ODS、声强 | 传播时差、源定位 |

## 六、小结

双通道数据的判读链条：先看相干函数确认输入输出线性关系的成立范围，再读互谱相位判断传递性质（纯延迟还是共振区），最后用互谱与自谱之比得到 FRF 或传导函数。互谱幅值高只说明双方能量都大，不构成因果证据；互相关峰的位置是定位声源与路径时差的主要手段，对不相关噪声有结构性的抑制能力。所有依赖相位的分析——ODS 变形、声强、传递路径相位——其精度上限受通道间采样同步约束，双通道试验前应确认采集设备为同步采样而非分时扫描。
