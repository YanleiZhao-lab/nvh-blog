# 声振模态分析：车身结构与车内声腔的耦合动力学

> 车内轰鸣治理到最后一公里总会撞上同一个问题：声压级峰对应的既不是结构模态也不是声腔模态，而是两者的耦合模态。LMS 理论手册 15.2.5 节给出的声振模态分析（Vibro-Acoustic Modal Analysis）把结构运动方程和声学方程拼成一个耦合二阶系统——矩阵不对称、激励可以来自结构侧也可以来自声学侧、模态振型一半是节点位移一半是声压。这篇从两个域的方程推起，讲清不对称性从哪来、互易性为什么还活着、声激励换算时要乘特征值平方，最后用 numpy 把一个"车身板+声腔"耦合模型解出来，看耦合如何把两个原本独立的模态裂变成一对。

## 一、为什么纯结构模态分析治不了车内轰鸣

做车身模态试验的工程师都熟悉这套流程：锤击或激振器扫频、拟合 FRF、得到频率阻尼振型。但把同样的流程搬到车内声学问题上，很快会对不上账：驾驶员耳侧声压的峰，频率落在结构模态表里查无此峰；反过来，声腔估算的第一阶纵向声腔模态，又和实测峰差着几赫兹。

原因不神秘。乘员舱是一个封闭空腔，空气有质量有弹性，本身就是一个"结构"——它有自己的模态（声腔模态，Cavity Modes）。地板、顶棚、行李厢隔板这些大面积钣金在振动时推拉腔内空气，声压反过来又给板面施加分布载荷。**两个动力学系统互相施加载荷，就是耦合**。耦合之后系统的模态既不属于板也不属于腔，而是两者的混合体——频率分裂、振型你中有我。只看结构侧或只看声学侧，都看不到全貌。

声振模态分析就是为这个场景准备的：同时布置加速度计（结构侧）与传声器（声学侧），用结构激励（激振器、力锤）或声激励（体积加速度源 Q-source）任选一种，把耦合系统的模态参数一次性识别出来。手册 15.2.5 节明确说：以声激励或结构激励情况下的声振测量为基础，可以实施混合的声振分析——两种激励得到的模态模型是一致的。

::: info 核心概念
- **声腔模态（Cavity Mode）**：封闭空腔内空气的固有振动模式，乘员舱第一阶纵向声腔模态通常在 50~60 Hz 量级，恰好覆盖怠速与低档位轰鸣频段
- **声振耦合（Vibro-Acoustic Coupling）**：结构振动激励声压、声压反作用于结构的双向载荷关系，耦合后的模态是结构与声腔的混合形态
- **声振模态分析**：对结构-声腔耦合系统做模态试验与参数估计，输入输出可以混合结构量（力、加速度）与声学量（体积加速度、声压）
- **Q-source**：输出已知体积加速度 Q（m³/s²）的声源，声学域里与"力"对等的激励设备
:::

## 二、耦合方程怎么拼出来：从两个域的运动方程说起

### 2.1 结构侧：多了声压载荷项

结构有限元运动方程本是老朋友：

$$M_s \ddot{u} + C_s \dot{u} + K_s u = F_s$$

$M_s$、$C_s$、$K_s$ 是结构的质量、阻尼、刚度矩阵，$F_s$ 是外力。声振耦合在右边加一项：贴着腔内空气的板面受到声压 $p$ 的作用，声压对板面的分布载荷积分后写成矩阵形式 $G\, p$——$G$ 是结构-声耦合矩阵（几何耦合矩阵），把声压场映射为节点力。结构方程变成：

$$M_s \ddot{u} + C_s \dot{u} + K_s u + G\, p = F_s$$

![声振耦合系统的结构侧运动方程（手册 15.2.5 节）](/images/vibro-acoustic-modal-analysis/eq-structure.png)

*（图源：Simcenter Testing Knowledge Base）*

### 2.2 声学侧：用"非直接"声学方程

流体侧不用声压的二阶波动方程直接写，手册用的是所谓"非直接的声学方程"——以声压 $p$ 为未知量、右端项是体积加速度 Q 的形式：

$$M_f \ddot{p} + C_f \dot{p} + K_f p = F_q$$

$M_f$、$C_f$、$K_f$ 是声腔的质量、阻尼、刚度矩阵（来自对波动方程的有限元离散），$F_q$ 是声学载荷向量——描述声压-体积加速度关系的矩阵乘上体积加速度源。板的振动排开腔内空气，等效于一个分布的体积源，这一项同样通过耦合矩阵的转置与结构挂钩：

$$M_f \ddot{p} + C_f \dot{p} + K_f p - G^T \ddot{u} = F_q$$

注意这里的 $G^T$——转置出现了，而且挂在 $\ddot{u}$（结构加速度）上。板面加速度对空气来说是体积加速度源，所以耦合项对时间求了两次导。

![声学域的非直接声学方程与声压-体积加速度矩阵（手册 15.2.5 节）](/images/vibro-acoustic-modal-analysis/eq-fluid.png)

*（图源：Simcenter Testing Knowledge Base）*

### 2.3 拼装：不对称的二阶系统

两个方程联立，未知量堆成一个向量，得到手册所说的"描述声振耦合系统特性的方程"：

$$\begin{bmatrix} M_s & 0 \\ -G^T & M_f \end{bmatrix} \begin{bmatrix} \ddot{u} \\ \ddot{p} \end{bmatrix} + \begin{bmatrix} C_s & 0 \\ 0 & C_f \end{bmatrix} \begin{bmatrix} \dot{u} \\ \dot{p} \end{bmatrix} + \begin{bmatrix} K_s & G \\ 0 & K_f \end{bmatrix} \begin{bmatrix} u \\ p \end{bmatrix} = \begin{bmatrix} F_s \\ F_q \end{bmatrix}$$

![声振耦合系统的完整二阶模型（手册 15.2.5 节）](/images/vibro-acoustic-modal-analysis/eq-coupled-full.png)

*（图源：Simcenter Testing Knowledge Base）*

盯着质量块和刚度块看：$G$ 出现在右上角，$-G^T$ 出现在左下角。两者互为转置还差一个负号——**耦合项一个挂在位移上（刚度块）、一个挂在加速度上（质量块），矩阵结构天然不对称**。这就是手册反复强调的"二阶模型明显地有不对称性"。

物理上这是两个域因果链的"错位"：板以位移推动空气（节点力正比于声压，声压在声腔方程里属刚度项），空气以惯性反作用于板（结构加速度排开体积，声压载荷正比于 $\ddot{u}$）。因果链不在同一个求导阶数上，不对称是结构性的，不是数值误差。

::: warning 工程注意
不对称不等于病态。手册明确说：多数多输入-多输出模态参数估计算法并不要求对称性，非对称的基本方程组对识别有效的模态频率、阻尼因子和模态振型没有任何问题。看到求解器报"非对称矩阵"的警告就手动对称化，反而会破坏物理模型。
:::

## 三、不对称系统的互易性：换激励域的代价是特征值平方

### 3.1 互易原理在声振系统里的形式

纯结构系统里，Maxwell-Betti 互易原理说 $H_{ij} = H_{ji}$，FRF 矩阵对称。耦合系统不对称，互易性是不是没了？没有，但换了一副面孔。手册给出声振互易的表述：结构自由度与声学自由度之间的互易关系依然成立，只是互易的两个"方向"跨越了物理域——**在结构点激励、声学点测响应，与在声学点激励、结构点测响应，两条传递函数由互易关系联系起来**。

![声振作用的互易原理（手册 15.2.5 节）](/images/vibro-acoustic-modal-analysis/eq-reciprocity.png)

*（图源：Simcenter Testing Knowledge Base）*

这正是 Q-source 声学传递函数测量的理论根基。传统 ATF（声学传递函数）测量用锤子敲悬置点、耳侧放传声器，一条路径敲一次；换成把 Q-source 放在耳侧、悬置点贴加速度计，一次测量拿到全部路径——$P/F$ 与 $A/Q$ 量纲都约化为 $1/\text{m}^2$，两者等价。

### 3.2 比例因子：差一个特征值的平方

手册接着给了一个容易被忽略的细节：**结构激励可以用声激励来代替，两种激励得到的模态模型是一致的，但每一模态的比例因子不相同**；从结构方程过渡到声学方程，要求比例因子为相应模态特征值的平方。

翻译一下。模态模型里留数带着绝对标尺，标尺由激励方式决定。用激振器在结构点激励，得到的是"力到位移/加速度"意义下的留数；用 Q-source 在声学点激励，得到的是"体积加速度到声压"意义下的留数。两者描述的是同一阶耦合模态（频率、阻尼、振型形状完全一样），但两套留数之间差一个换算系数——第 $k$ 阶模态就差 $\lambda_k^2$（该阶特征值的平方）。

工程上这意味着：拿声激励数据与结构激励数据混用、或与有限元模型对标时，**不能直接比留数幅值**，先把比例因子的换算对齐。振型形状（归一化后）可以随便比，绝对标尺必须先问"这套数据是哪个域激励出来的"。

## 四、参数估计：老工具直接复用

声振耦合系统的模态参数估计，不需要发明新算法。手册把声振分析列为"模态参数估计的特殊情况"——耦合方程虽然不对称，但仍然是标准的二阶线性系统，15.3 节的全套方法照常可用。

![模态参数的获取流程（手册图 15-1）](/images/vibro-acoustic-modal-analysis/fig15-1-modal-model.png)

*（图源：Simcenter Testing Knowledge Base）*

实测数据组织上有一个天然优势：声振试验天然就是多参考的。结构激励点、声学激励点（如果有多个 Q-source 位置）构成参考自由度组；响应侧加速度计与传声器混布。多输入整体估计方法（LSCE、FDPI、CMIF 等）在这样的数据结构里如鱼得水——密频耦合模态的解耦，靠的正是模态参与因子在多个参考点之间的独立变化。

| 维度 | 纯结构模态试验 | 声振模态试验 |
| --- | --- | --- |
| **激励设备** | 力锤、激振器 | 力锤/激振器 或 Q-source（二选一或混用） |
| **响应传感器** | 加速度计 | 加速度计 + 传声器混布 |
| **激励-响应配对** | $a/F$ | $a/F$、$P/F$、$P/Q$、$A/Q$ 混合 |
| **方程组结构** | 对称（互易结构） | 不对称二阶系统 |
| **留数标尺** | 力域统一 | 结构域与声域差 $\lambda_k^2$，逐模态换算 |
| **典型算法** | LSCE、FDPI、MLMM | 同左，多参考整体估计照常 |
| **典型场景** | 白车身、悬架部件 | 整车/内饰车身轰鸣、进排气声腔 |

## 五、Python 演示：一块板和一个声腔的耦合裂变

抽象方程看一百遍，不如把一个最小耦合模型解一遍。模型：单自由度"板"（质量-弹簧）对一个单自由度"声腔"（声压自由度，腔内空气的等效质量弹性）做耦合，耦合强度用系数 $g$ 扫一遍，看两个固有频率怎么从"各过各的"走向"裂变"。

```python
import numpy as np

# 结构侧：板的模态质量 2 kg，固有 45 Hz（典型车身板件一阶）
ms, fs = 2.0, 45.0
ks = ms * (2*np.pi*fs)**2
# 声学侧：声腔等效模态质量 1 kg，固有 50 Hz（乘员舱一阶纵向声腔量级）
mf, fc = 1.0, 50.0
kf = mf * (2*np.pi*fc)**2

def coupled_modes(g):
    # 拼不对称耦合矩阵（手册 15.2.5 形式的无阻尼版本）
    M = np.array([[ms, 0], [-g, mf]])      # 左下角 -G^T 挂在质量块
    K = np.array([[ks, g], [0, kf]])       # 右上角 +G 挂在刚度块
    lam = np.linalg.eigvals(np.linalg.solve(M, -K))  # M x'' = -K x
    w = np.sqrt(-lam.real)                 # 取共轭对的正频率部分
    return np.sort(w) / 2 / np.pi

print("耦合强度g   低频模态Hz   高频模态Hz")
for g in [0.0, 20.0, 50.0, 100.0, 150.0]:
    f1, f2 = coupled_modes(g)
    print(f"{g:8.0f}      {f1:7.2f}      {f2:7.2f}")
```

输出里最值得看的数字：$g=0$ 时两阶模态就是 45.00 与 50.00 Hz，各过各的；$g=50$ 时裂变成 43.82 与 51.35 Hz——**低于两者的往下掉、高于两者的往上抬，间距从 5.00 Hz 拉开到 7.53 Hz**。这就是耦合模态的"排斥"行为：耦合再增强到 $g=150$，间距拉到 17.61 Hz。实测轰鸣峰对不上任何一侧的"理论模态"，往往就是裂变后的耦合频率。

再补一段激励域换算的演示——结构激励与声激励的留数标尺差 $\lambda^2$：

```python
import numpy as np

for name, f in [("板侧模态", 45.0), ("腔侧模态", 50.0)]:
    lam2 = (2*np.pi*f)**2                  # 特征值平方 = (2*pi*f)^2
    print(f"{name} {f:.0f} Hz: 结构-声学留数换算系数 = {lam2:.3e}")
```

输出要点：45 Hz 模态的换算系数约 7.98e4，50 Hz 约 9.87e4——同为"特征值平方"，不同模态的系数差着 24%。混用两种激励域的数据对标留数幅值时，逐模态换算不能省；当成统一比例因子处理，高频模态的标尺直接错出两成。

::: tip 试验组织建议
- 激励方式按可行性选：台架或部件级用激振器直接结构激励最直接；整车状态下 Q-source 放耳侧做互易测量，一次拿全部 ATF 路径，省时且一致性好
- 响应侧加速度计与传声器混布是声振试验的常态，别为了"数据干净"只测结构侧——丢掉声学响应等于丢掉耦合信息的一半
- 识别算法选多参考整体估计（LSCE/FDPI 起步，重阻尼内饰上 MLMM），密频耦合模态靠模态参与因子解耦
- 结构激励与声激励数据混用时，逐模态乘 $\lambda_k^2$ 对齐标尺后再比留数
:::

## 六、小结

声振模态分析不是新学科，是模态分析在混合物理域上的自然延伸：结构方程加声压载荷项、声学方程用体积加速度源形式，拼成一个天然不对称的二阶系统——不对称来自两个域因果链的求导阶数错位，不是缺陷；互易性跨域存活，代价是留数标尺差一个特征值平方；参数估计全套沿用多参考整体方法。车内轰鸣对不上纯结构或纯声腔模态表时，先想耦合裂变：两个原本接近的模态会互相推开，实测频率落在两者外侧才是耦合系统的指纹。把它当成普通多自由度系统去试验、去拟合，工具链一行都不用改。
