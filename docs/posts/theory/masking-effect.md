# 声音的掩蔽效应：为什么电动车的提示音要抢在路噪前面

> 频谱仪上明明有一个 55 dB 的纯音, 坐进车里就是听不见——不是仪器坏了, 是它被旁边的强噪声"吃"掉了。掩蔽效应 (Masking Effect) 是人耳在临界带内的能量合成机制: 高声级分量会把频率相近的低声级分量压到听阈以下。理解它, 才能解释为什么电动车提示音 (AVAS) 的声压级要按频谱逐带设计、为什么 dB(A) 相同的两台车听起来完全不同、为什么 Zwicker 响度要先算局部响度再积分。

## 一、从一个实测怪象说起

电动车低速巡航, 车内某处有一个 4 kHz 左右的电机哨声成分, 声压级 50 dB。主观评价时没人提这个声音。把路噪隔掉 5 dB 再听, 哨声突然"冒"出来了, 抱怨接踵而至。

频谱没变多少, 听觉结论完全翻转。问题出在: 人耳不是一个全频段线性接收机。内耳的基底膜沿长度方向对不同频率共振——本质上是一排互相衔接的带通滤波器, 每个滤波器的带宽就是**临界带 (Critical Band)**。落在同一个临界带内的声能量, 响度上"合在一起算": 强分量先把带内的"响度地板"抬高, 弱分量除非高出这块地板, 否则对总响度零贡献——这就是被掩蔽。

手册给出了一个经典实验: 一个 50 dB、4 kHz 的纯音, 放在中心频率 1200 Hz、声压级 90 dB 的窄带背景噪声中仍可听到; 背景升到 100 dB, 这个纯音就彻底消失了。注意距离——掩蔽者和被掩蔽者在频率上隔了近三倍, 依然被"吃"掉, 而且掩蔽声级每提高一档, 被掩蔽的频带还在变宽。

![窄带噪声掩蔽效应：掩蔽声级越高, 被掩蔽频带越宽](/images/masking-effect/fig6-3-masking.png)

*掩蔽效应示意: 窄带噪声把邻近及高频侧纯音的听阈推高, 声级越高覆盖越宽 (图源: Simcenter Testing Knowledge Base 中文理论手册)*

::: info 核心概念
- **临界带 (Critical Band)**: 内耳等效滤波器组的单带带宽, 以巴克 (Bark) 刻度; 500 Hz 以下带宽近恒定约 110 Hz, 高频段约 23% 恒百分比带宽
- **掩蔽 (Masking)**: 一个声分量的存在使另一个分量的听阈升高; 同带内高声级分量的响度贡献吞掉低声级分量
- **掩蔽阈 (Masking Threshold)**: 被掩蔽声变得可闻所需的最低声压级, 随掩蔽声级升高、随频距减小而上升
- **局部响度 (Specific Loudness)**: 响度沿 Bark 轴的分布, 宋/Bark, 掩蔽的直接落点就是压低这条曲线
:::

## 二、掩蔽的物理根源：为什么临界带是"结算单位"

掩蔽不是玄学, 它的载体是耳蜗力学。

**第一层: 频率-位置映射。** 声波经中耳传到耳蜗后, 行波沿基底膜传播, 行波包络的峰值位置由频率决定——高频在蜗底 (入口) 达到峰值, 低频一路走到蜗顶。基底膜上某点一旦被强信号激励到位, 它的振动状态就被这个信号"占据", 邻近频率的弱信号在同一位置产生的附加位移被覆盖。这就是为什么掩蔽最强的区域总在掩蔽者频率附近: 物理上它们本来就在挤同一段基底膜。

![人耳的主要组成：外耳、中耳与耳蜗](/images/masking-effect/fig6-1-ear.png)

*声信号经外耳、中耳传入耳蜗, 基底膜上完成频率-位置映射, 掩蔽就发生在这里 (图源: Simcenter Testing Knowledge Base 中文理论手册)*

**第二层: 临界带带宽由耳蜗决定。** 基底膜的频率-距离特性是非线性的: 低频段单位长度覆盖的频率少、高频段覆盖的多。反映到等效滤波器组上, 就是 500 Hz 以下各带带宽约 110 Hz 近恒定, 高频段变成约 23% 恒百分比带宽。一组 24 个衔接的滤波器覆盖 0 至 16 kHz 以上, 即 0 至 24 Bark。掩蔽的"作用距离"以 Bark 计而不是以 Hz 计——同样差 200 Hz, 在 200 Hz 处是跨了快两个带 (各自能"各算各的"), 在 4 kHz 处还在同一个带里 (必然互相吞并)。

**第三层: 神经侧抑制展宽掩蔽区。** 基底膜上被强激励的点还会反过来抑制邻近点的神经发放 (侧抑制, lateral inhibition), 这让掩蔽的影响范围超出单个临界带——经典实验里 1200 Hz 的窄带噪声能掩蔽远在 4 kHz 的纯音, 靠的就是这种沿 Bark 轴向上蔓延的抑制, 且掩蔽声级越高蔓延越远。工程上不必细究神经机理, 记住结论: **掩蔽量沿 Bark 轴分布, 掩蔽者高频侧的扩散比低频侧更宽**, 这是后文 AVAS 频段选择的关键依据。

::: warning 工程注意
别用线性频率轴估掩蔽。在 colormap 上量"这俩分量隔了 800 Hz"没有意义——1500 Hz 和 2300 Hz 可能已跨临界带、各响各的, 4500 Hz 和 5300 Hz 大概率同带、强者通吃。掩蔽判断一律换到 Bark 域: Bark 差不小于 1 才谈得上"分开", 差值小于 1 先按同带合成处理。
:::

## 三、掩蔽三类时间形态与不对称方向

### 同时掩蔽、前掩蔽与后掩蔽

稳态问题考虑同时掩蔽 (Simultaneous Masking) 就够, 但提示音、咔嗒声这类瞬态信号必须考虑时间维度。手册给出量级:

- **前掩蔽 (Pre-masking)**: 短促声在时间上领先于强声, 其响度也会降低甚至被掩蔽掉, 作用时间大致为几十 ms;
- **后掩蔽 (Post-masking)**: 强声去掉后约 20 ms 内 (与掩蔽声级有关), 短促的猝发声仍可能被掩蔽;
- **同时掩蔽**: 连续声存在时, 声级高于它的猝发声是否"糊掉", 取决于猝发音的持续时间。

这组数字直接影响设计: 提示音如果紧跟在一次路噪冲击 (水泥路面接缝) 之后 20 ms 内到达, 感知响度会打折; 反过来, AVAS 音如果把脉冲间隔拉到大于后掩蔽窗, 每个脉冲都能全额入账。20 ms 也是"感觉响度"的积分尺度——猝发音存留时间短于 20 ms 时响度降低, 长于 20 ms 时响度几乎与时间长短无关。

### 低掩高容易, 高掩低难

掩蔽的频率不对称性是声品质整改的"免费午餐": 低频强噪声向上掩蔽高频弱信号的门槛低 (1500 Hz 的轰鸣能显著压制 3 kHz 的哨声感知), 反过来高频信号要掩蔽低频则困难得多——基底膜上高频行波在蜗底就已耗尽, 走不到低频的共振位置。

由此得到整改优先级的直觉排序: **车内同时有低频轰鸣和高频哨声时, 先压低频**——它不仅自己烦人, 还在免费掩蔽频谱上半区; 高频压掉之后低频的掩蔽格局纹丝不动。

## 四、掩蔽进入指标：响度、AI 和语音私密性的共同底座

### Zwicker 响度: 掩蔽的直接产品

ISO 532B 的 Zwicker 算法把掩蔽写进了计算流程: 1/3 倍频程声压级先转换为沿 Bark 轴的局部响度, 合成总响度时各带不是简单相加——占优频带 (掩蔽带) 会暴露其影响的频率宽度、抑制邻近带对总响度的贡献, 且要计入每个倍频程带滤波器的斜坡边缘特性。

斯蒂文司 Mark VI (ISO 532A) 用更简洁的参数化处理, 掩蔽修正是怎么进公式的值得推一遍。从"各带完全独立"的基准出发: 此时任一带的响度都全额入账, 总响度等于各带响度指数之和 $\sum S$。引入掩蔽后, 非占优带的贡献被部分压制——被占优带盖住的部分不计, 只剩下因子 F 的份额。写成公式即手册式 7-3:

$$S_t = S_m + F \left( \sum S - S_m \right)$$

其中 $S_m$ 是最大响度指数 (占优带自己的贡献, 永远全额入账), $F$ 是反映掩蔽效应的分响度贡献因子——1/1 倍频程取 0.3, 1/3 倍频程取 0.15。两个极端把 F 的角色看得很清楚: F 等于 1 时退回各带独立求和 (无掩蔽); F 等于 0 时只剩占优带 (掩蔽彻底, 强者通吃)。真实听觉在这两个极端之间, 且 1/1 倍频程的带更宽、跨带掩蔽更严重, 所以 F 取更大的 0.3。

Zwicker 法则是把这套逻辑做成沿 24 个 Bark 带的连续版本: 每个临界带先算局部响度 $N^{'}(z)$ (单位宋/Bark), 掩蔽带把低声级邻近带的图线压低甚至压平, 总响度作为局部响度曲线包围的面积算出:

$$S = \int N^{'}(z)\,dz$$

![Zwicker 响度计算举例：1/3 倍频程谱映射为局部响度曲线](/images/masking-effect/fig7-4-zwicker-example.png)

*Zwicker 法把 1/3 倍频程数据映射到 Bark 轴得局部响度图线, 曲线下面积即总响度; 掩蔽带把邻近区的图线压低 (图源: Simcenter Testing Knowledge Base 中文理论手册)*

Zwicker 分析的工程价值在于能**辨别非掩蔽区还是掩蔽区**: 局部响度曲线上被压平的一段, 对应"该分量被完全掩蔽"——整改它对总响度毫无收益, 这比在频谱上盯 dB 有用得多。

### AI 与语音私密性: 掩蔽的定量配额

掩蔽不只是"敌人"。清晰度指数 (Articulation Index) 把语言频带按重要性加权, 噪声对语言的掩蔽干扰由经过加权的 1/3 倍频程谱算出——谱压过语言信号越多, AI 越低。反过来, 办公室和电动车企划中"提供恰到好处的掩蔽"是保护交谈私密性的手段: 完全私密的门槛 AI 不超过 0.05, 半私密不超过 0.1。电动车太安静, 交谈私密性反而恶化, AVAS 和主动声浪设计里就有"用掩蔽量补回去"的思路。

![AI 图算法：谱线上方计权点数占比即清晰度指数](/images/masking-effect/fig7-7-ai-chart.png)

*AI 的图形计算法: 与语言相关的倍频程带用计权点数表示, 谱线上方的点数除以总点数即 AI (图源: Simcenter Testing Knowledge Base 中文理论手册)*

## 五、AVAS 提示音设计: 掩蔽的正面战场

电动车低速行驶太安静, 法规要求加装声学车辆警报系统 (AVAS) 提示行人。设计难点恰恰是掩蔽: 提示音必须在**环境背景噪声之上留出可闻余量**, 而背景不是白噪声, 是轮胎路噪、风噪、周围车流的谱。

三条从掩蔽理论直接导出的设计规则:

**其一, 频段避开路噪主能量区。** 路噪能量集中在数百 Hz 以下, 若提示音放在 300 至 800 Hz, 等于把自己埋进掩蔽最密集的频段。提到 1 至 3 kHz, 一方面路噪谱已滚降、掩蔽阈低, 另一方面人耳最敏感的频率范围在 1 至 10 kHz, 同样的声压级响度感知更高——双重收益。

**其二, 用窄带或音调成分, 不用宽带噪声。** 宽带提示音的能量摊薄在整个掩蔽敏感区, 每一份都单独与背景比拼。窄带成分把能量集中到少数临界带内, 带内声级可以做高, 穿透掩蔽阈更省功率——这正是倒车蜂鸣器、电动车提示音普遍采用音调式设计的原因。

**其三, 留时间余量对付瞬态掩蔽。** 提示音的重复率要考虑前/后掩蔽窗: 脉冲间隔显著大于几十 ms, 保证每个脉冲不被上一个声音事件的后掩蔽压掉。

对 NVH 工程师反向应用同样成立: 电动车的电机哨声、变速箱啸叫整改方案评审时, 必须先看**竞争声场**——传统车同一位置的高频啸叫可能一直被发动机谐波宽蔽着, 根本没人听见; 换成电动车, 发动机掩蔽消失, 同一个 55 dB 的啸叫从"不存在"变成"天天被投诉"。对标传统车频谱做电动车声品质目标时, 掩蔽格局的变化比绝对声压级变化更值得先算清楚。

::: tip 掩蔽的工程化使用
- 评审"这个纯音要不要整改": 先算它与最强邻近分量的 Bark 差, 差值小于 1 且声级差大于约 10 dB, 多半已被掩蔽, 整改优先级下调
- 改进排序: 优先压低频强分量——它同时在掩蔽高频区, 双重收益
- 汇报用 Zwicker 局部响度曲线代替频谱: 被压平的段就是"白花钱区", 领导一眼看懂
- 提示音/警报音设计: 窄带成分放 1 至 3 kHz, 重复周期大于瞬态掩蔽窗
:::

| 场景 | 掩蔽角色 | 判断/设计要点 |
| --- | --- | --- |
| **车内哨声整改** | 被低频轰鸣掩蔽 | 先查局部响度是否已压平, 是则降优先级 |
| **电动车 vs 传统车对标** | 发动机掩蔽消失 | 同级啸叫投诉突变, 重算掩蔽格局再定目标 |
| **AVAS 提示音** | 须穿透路噪掩蔽 | 窄带 + 1 至 3 kHz + 脉冲间隔大于几十 ms |
| **语言私密性** | 用掩蔽保护交谈 | AI 压回 0.05 以下 (完全私密) |
| **Zwicker 响度合成** | 带间贡献抑制 | 占优带抑制邻近带, 曲线下面积即总响度 |

## 六、Python 演示: 算一次"同带合算"的掩蔽账

```python
import numpy as np

# Hz 转 Bark 的工程近似 (Zwicker): 低频近似恒带宽, 高频近似恒百分比
def hz_to_bark(f):
    return 13.0 * np.arctan(0.75 * f / 1000.0) + 3.5 * np.arctan((f / 7500.0) ** 2)

# 车内三个声分量: (频率 Hz, 声压级 dB, 描述)
tones = [(180, 74, "路噪轰鸣"), (520, 55, "悬架嗡声"), (4200, 50, "电机哨声")]

z = [hz_to_bark(f) for f, _, _ in tones]
print(f"{'分量':<8}{'频率':>9}{'Bark':>8}{'声级':>8}")
for (f, lv, name), zi in zip(tones, z):
    print(f"{name:<8}{f:>8}Hz{zi:>8.2f}{lv:>7}dB")

# 同带判据: Bark 差小于 1 且级差大于 10 dB -> 弱者被强者掩蔽
print("\n以轰鸣(180Hz/74dB)为掩蔽源:")
for i in range(1, 3):
    dz = z[i] - z[0]
    lv_diff = tones[0][1] - tones[i][1]
    masked = dz < 1 and lv_diff > 10
    verdict = "已被掩蔽" if masked else "独立可闻"
    print(f"  {tones[i][2]}: Bark差={dz:.2f}, 级差={lv_diff}dB -> {verdict}")
```

输出里最值得看的两个数: 520 Hz 悬架嗡声与 180 Hz 轰鸣频率上只差 340 Hz, 听感上却隔了约 3 个临界带——同带掩蔽的判据 (Bark 差小于 1) 远远不满足, 55 dB 的嗡声不会被 74 dB 轰鸣按同带规则吃掉; 4 kHz 哨声的 Bark 值已到 17.5, 与低频轰鸣分处耳蜗两端, 它"听不见"的原因要另找——多半是邻近某个高频电驱啸叫在掩蔽它。一个 arctan 近似就能把"隔多远才算分开"从线性频率的直觉里拽出来。

## 七、小结

掩蔽的本质是内耳临界带内的能量合成加神经侧抑制, 一切判断以 Bark 域为准: 同带 (Bark 差小于 1) 分量强者通吃, 跨带分量各算各的。整改先压低频——它同时在掩蔽高频; 汇报用 Zwicker 局部响度曲线——被压平的段就是白花钱区; AVAS 用窄带成分放 1 至 3 kHz 并留出瞬态掩蔽窗。电动车删掉发动机不是纯赚——掩蔽格局整体重排, 原来被免费盖住的每个高频成分都要重新审一遍。
