# 声压、声功率、声强：三个量到底什么区别

> 声学报告里这三个词都挂着 dB，参考值却各不相同——把声压级当声功率级报出去，是整车噪声验收里最常见的低级错误之一。本文用一间暖房把三个量的物理本质讲透，给出换算关系和"什么场合用哪个"的判断标准。

## 一、一间暖房讲清三个量

把一台噪声源（比如电机）放进安静房间，和把一片暖气放进冷房间，是同一回事。Simcenter 知识库里的暖气类比值得反复咀嚼：

- **温度 ↔ 声压**：房间里每个位置都有一个温度值，离暖气越近温度越高。声压（Sound Pressure）也一样——空间每点一个值，单位帕斯卡（Pa），离声源越近越大。它回答的是"在这个位置声音多大"。
- **暖气功率 ↔ 声功率**：暖气每小时发出多少热量是它的固有属性，房间冷热不改变这个数。声功率（Sound Power）是声源单位时间发出的声能量，单位瓦（W），只属于声源本身，与环境无关。
- **热流 ↔ 声强**：热量在房间里有方向地流动。声强（Sound Intensity）描述声能量流过单位面积的速率，单位 W/m²，既有大小又有方向——三个量里唯一的矢量。

![暖气类比：温度对应声压、暖气功率对应声功率、热流对应声强](/images/pressure-power-intensity/fig2-heater-analogy.png)

*（图源：Simcenter Testing Knowledge Base）*

::: info 核心概念
- **声压 p**：某空间点的压力波动，标量，单位 Pa，随位置和距离变化
- **声功率 W**：声源每秒发出的声能量，声源固有属性，单位 W，与测量位置无关
- **声强 I**：声能量流过单位面积的流量，矢量，单位 W/m²，等于声功率除以包裹面积
:::

三者都能写成 dB，但参考值不同：声压用 20 µPa，声功率和声强用 1 pW（10⁻¹² W）和 1 pW/m²。数值都叫"分贝"，物理量却完全不同——报告里只写"89 dB"不写量的名字，就是在给读者埋雷。

![三个量各自有独立的参考值，都可以表达为分贝](/images/pressure-power-intensity/fig1-three-db.png)

*（图源：Simcenter Testing Knowledge Base）*

## 二、工程属性对比

| 属性 | **声压** | **声功率** | **声强** |
| --- | --- | --- | --- |
| **物理含义** | 某点的压力波动 | 声源发出的总能量速率 | 单位面积的能量流 |
| **单位** | Pa | W | W/m² |
| **是否随距离变** | 是，越远越小 | 否，固有属性 | 是，随包裹面积摊薄 |
| **是否含方向** | 否（标量） | 否（标量） | 是（矢量） |
| **dB 参考值** | 20 µPa | 1×10⁻¹² W | 1×10⁻¹² W/m² |
| **dB 公式** | 20·lg(p/pref) | 10·lg(W/Wref) | 10·lg(I/Iref) |
| **测量手段** | 单个麦克风 | 由声压或声强推算 | 双麦克风声强探头等 |
| **典型出场场合** | 车内耳位噪声、通过噪声 | 法规限值、源排序 | 声源定位、隔声量测量 |

::: warning 工程注意
同一台设备，厂商宣传"Lw = 73 dB"（声功率级），用户在半米处测到"Lp = 78 dB"（声压级），两个数都对——量不同、位置不同，根本没有可比性。混用是争议高发区：验收条款里必须写清楚是声压级还是声功率级，以及声压级的测点位置和距离。
:::

为什么法规偏爱声功率？因为它是设备的固有属性。工程机械、打印机、家电的噪声法规限值几乎都写声功率：换一个试验场地、换一个测量距离，限值依然成立，对买卖双方都公平。

## 三、三者之间的换算

三个量不是三座孤岛，特定条件下可以互相推。

**声压 × 振速 = 声强。** 声强本质是声压 p 与质点振速（Particle Velocity）u 的乘积：I = p·u。声压是标量、振速是矢量，乘出来的声强自然是矢量。自由场远场条件下 p 与 u 同相，I = p²/(ρc)，其中 ρc 是空气的特性阻抗，标准大气条件下约 415 Pa·s/m，估算常取 400。

**声强 × 面积 = 声功率。** 用一个面把声源包住，把面上各点的法向声强对面积积分，就得到声功率。这就是声强法求声功率的原理——不用消声室，在普通车间就能做，因为稳态背景噪声穿过封闭面的净流量为零。

反过来，已知声功率也能估算声场。知识库的打印机算例：一台声功率 0.02 W 的打印机，在 2 m 半径的半球面上测量：

- 半球表面积 S = 2πr² = 25 m²
- 声强 I = 0.02 / 25 ≈ 8×10⁻⁴ W/m²
- 声强级 = 10·lg(8×10⁻⁴ / 10⁻¹²) ≈ **89 dB**

![已知声功率的打印机在 2 米半球面上测量](/images/pressure-power-intensity/fig4-hemisphere.png)

*（图源：Simcenter Testing Knowledge Base）*

```python
import numpy as np

W = 0.02                      # 打印机声功率，W
W0, I0 = 1e-12, 1e-12         # 声功率、声强的参考值
Lw = 10 * np.log10(W / W0)    # 声功率级
print(f"声功率级 Lw = {Lw:.1f} dB（不随距离变化）")

rhoc = 400                    # 空气特性阻抗 Pa·s/m
for r in [1.0, 2.0, 4.0]:     # 半球测量半径
    S = 2 * np.pi * r**2      # 半球表面积
    I = W / S                 # 声强 = 声功率 / 面积
    LI = 10 * np.log10(I / I0)
    p = np.sqrt(I * rhoc)     # 自由场: I = p^2/rhoc
    Lp = 20 * np.log10(p / 20e-6)
    print(f"r={r:.0f} m: 声强级={LI:.1f} dB, 声压级={Lp:.1f} dB, 声压={p*1000:.1f} mPa")
```

最值得看的两个数字：Lw 恒为 103 dB，而 r 从 1 m 拉到 4 m，声压级从 95 dB 掉到 83 dB——声功率纹丝不动，声压随距离每翻一倍掉 6 dB。另外每个距离上 LI 与 Lp 数值相等，这不是巧合：参考值的选取恰好让 20 µPa 的声压在 400 Pa·s/m 的空气里对应 1 pW/m² 的声强。

## 四、声强比声压多出来的方向信息

同一台电机，用声强图和声压图分别画云图，幅值分布的图案完全一样，差别在方向：

![电机周围的声强图（左，含矢量箭头）与声压图（右，仅幅值）](/images/pressure-power-intensity/fig3-intensity-vs-pressure.png)

*（图源：Simcenter Testing Knowledge Base）*

声压图只告诉你"哪里红"，声强图的箭头还告诉你"声音往哪流、从哪来"。排查电机啸叫时，这一步往往就是"定位到是轴承辐射还是壳体结构辐射"的分水岭。

代价是测量复杂度：声压一只麦克风就够，声强需要两只（或以上）麦克风按已知间距排列，利用两通道之间的声压梯度算质点振速，Simcenter Soundbrush 用四面体布置的 4 只麦克风扫查网格。数据量和后处理量都上去了，所以常规监测用声压，溯源和声功率测定才动用声强。

## 五、什么场合用哪个量

先看一笔账。两台辅助水泵要并排放进机舱，A 声功率 1e-4 W，B 是 A 的两倍，估算 0.5 m 处的声压级变化：

```python
import numpy as np

W_A, W_B = 1e-4, 2e-4         # 两台泵的声功率，B 是 A 的两倍
rhoc = 400                    # 空气特性阻抗
r = 0.5                       # 评估点近似半球辐射
p = lambda W: np.sqrt(W / (2*np.pi*r**2) * rhoc)   # 声功率反推声压
LpA = 20*np.log10(p(W_A)/20e-6)
LpB = 20*np.log10(p(W_B)/20e-6)
LpAB = 20*np.log10(np.sqrt(p(W_A)**2 + p(W_B)**2)/20e-6)  # 能量叠加
print(f"单独开 A: {LpA:.1f} dB")
print(f"单独开 B: {LpB:.1f} dB（声功率翻倍只贵 3 dB）")
print(f"同时开  : {LpAB:.1f} dB（叠加只比 B 再贵 1.8 dB）")
```

功率翻倍，声压级只涨 3 dB；两台同开，也只比大的那台再多不到 2 dB——想靠"换一台安静 3 dB 的泵"显著压低总噪声，往往被能量叠加的算术劝退。这类估算只需要声功率一个数加一个距离假设，正是声功率作为"设备名片"的价值。

::: tip 场合选择
- **车内耳位、驾驶员右耳、通过噪声测点** → 声压级：法规和主观感受直接对应的就是这个量，写清测点位置
- **供应商与主机厂之间的验收、不同场地数据对比** → 声功率级：不受环境和距离摆布，对双方公平
- **声源定位、隔声量（声传递损失）测定、普通厂房里的声功率测量** → 声强：方向信息无可替代，付双麦克风以上的测量成本
:::

## 六、小结

判断标准就三条：报告里看到 dB，先问是哪个量的 dB；要和设备"本身"较劲（选型、验收、对标），拿声功率说话；要和"人听到什么"较劲（车内噪声、异响排查），拿声压说话，并把测点距离写死在报告里。需要方向、需要在现场环境直接测声功率时，再上声强。三个量的换算关系——p 乘 u 得声强、声强乘面积得声功率、自由场里声压平方除以特性阻抗一桥连通——是所有声学估算的手边工具。
