# 传递路径分析TPA入门：把整车噪声拆成一条条看得见的路

> 车内轰鸣声到底是发动机悬置传过去的、排气吊钩拽出来的，还是面板自己辐射的？传递路径分析（Transfer Path Analysis, TPA）把"源—路径—目标"拆开，逐条路径算贡献量，直接指出该改哪里。这篇文章讲清楚路径怎么定义、工况力怎么估、贡献图怎么读，以及相位抵消这个最容易踩的判读坑。

## 一、TPA 要回答什么问题

整车 NVH 排查的经典困局：目标点（驾驶员耳旁）噪声超标，但嫌疑对象一大堆——发动机四个悬置、排气吊钩、变速箱撑杆、面板辐射……每个都测过振动，每个看起来都"不小"。资源有限，先改哪个？

TPA 的思路是把系统切成三块：

- **源（Source）**：用力来表征。结构声路径用力 F（N），空气声路径用体积加速度 Q（单位 m3/s2）。
- **路径（Path）**：源与目标之间的传递函数，即频响函数 FRF，声学目标常用 P/F（Pa/N）或 P/Q。
- **目标（Target）**：人感知噪声或振动的位置，通常是声压 P 或加速度 A。

每条路径的贡献量就一个乘法：Pi = Fo,i x (P/F)i。工况力乘以传递函数，得到这条路径独立"送到"目标点的声压。把所有路径加起来，应当等于目标点实测总声压。哪条路径的 Pi 大，就改哪条——这就是 TPA 的全部逻辑。

::: info 核心概念
- **工况力（Operational Force）**：源在实际运行状态下输入结构的力，随频率（或阶次）变化
- **传递函数（Transfer Function）**：单位力激励到目标点响应的 FRF，机器停机状态下测
- **贡献量（Contribution）**：单条路径的 Fo x FRF，复数，含幅值与相位
- **计算总级（Calculated Total）**：所有路径贡献的矢量和，用来与实测总级对账
:::

注意测量顺序：传递函数必须在**源不运行**时测（锤击、激振器或仿真单位载荷），它刻画的只是"路"的特性；工况力则在源运行时测。两批数据分开采，最后在频域里相乘。

## 二、空气声与结构声：先分清力从哪里出发

"borne"指的是力**离开源的方式**，不是声音怎么到耳朵的：

- **结构声（Structureborne）**：源通过机械连接把力灌进结构——发动机经悬置把力传给车身，车身壁板振动再辐射成噪声。力的起点是机械连接。
- **空气声（Airborne）**：源直接向空气辐射声能，比如进气口噪声经空气传到车厢，或经面板透声进来。力的起点是声学辐射，用 Q 表征。

容易搞混的地方：结构声路径的终点也可能是"听到的声音"（结构振动最后辐射发声），空气声路径也可能中途与结构相互作用。判断只看起点——力是从螺栓连接出来的，还是从空气辐射出来的。

一次 TPA 可以同时包含两类路径：结构声路径用 Fo x (P/F)，空气声路径用 Qo x (P/Q)，最后一起矢量求和。

## 三、切一刀定义路径：切口决定整个模型

定义路径的办法是做一个连续的"切面"（cut）把源和结构分开，**所有跨越切面的连接就是路径**。同一辆车，切口位置不同，得到完全不同的 TPA 模型。

以一辆卡车为例。切口绕着发动机划：四个悬置 x 每个三个平动方向 = **12 条结构声路径**。

![发动机四个悬置被定义为源，跨过切口的 4 个连接点 x 3 方向 = 12 条路径](/images/transfer-path-analysis-intro/twelve_path_tpa.png)
*（图源：Simcenter Testing Knowledge Base）*

切口也可以绕着驾驶室划：发动机加车架成为"源"，跨越驾驶室悬置的连接成为路径——5 个连接点 x 3 方向 = **15 条结构声路径**。切口还能划在内饰面板上，得到 5 条**空气声路径**（每个面板一条，用 Q 和 P/Q）。

三个模型数据要求各不相同，选哪个切口，取决于你**能改什么**：

| 切口位置 | 路径数 | 需要的工况载荷 | 适用场景 |
| --- | --- | --- | --- |
| **发动机悬置（4 点 x 3 向）** | 12 条结构声 | 各悬置三向工况力 F | 悬置刚度/隔振率可调 |
| **驾驶室悬置（5 点 x 3 向）** | 15 条结构声 | 各悬置三向工况力 F | 发动机动不了、只能动驾驶室悬置 |
| **内饰面板（5 条）** | 5 条空气声 | 各面板体积加速度 Q | 怀疑声学包装泄漏/面板透声 |

::: tip 切口选择原则
- 切口划在"你有权改动的东西"上：能换悬置就切悬置，能改声学包就切面板
- 切口越靠近源，路径数越少、模型越简单，但结论只对这一层接口有效
- 每个连接点别只留一个方向——X/Y/Z 三向往往贡献悬殊，漏方向就是漏路径
:::

## 四、贡献量判读：相位抵消是最大的坑

TPA 结果最常用的展示是**贡献量图（Contribution Display）**：一排水平色条，红色贡献大、蓝色贡献小。读图顺序固定——

1. **最顶条**：目标点实测总级；
2. **第二条**：所有路径的计算总级，它应当与顶条吻合，说明重要路径没漏；
3. **其余条**：各条路径的贡献量，按大小排序。

![贡献量图：顶条为实测总级，第二条为计算总级，其余为各路径贡献](/images/transfer-path-analysis-intro/contribution_display.png)
*（图源：Simcenter Testing Knowledge Base）*

**计算总级与实测不吻合，说明有重要路径没识别到**——这是 TPA 的自带质检。吻合了才谈得上下结论。

真正的判读坑在相位。贡献量是复数，路径之间会相加也会相消。所以单条路径的贡献量**完全可能高于总声级**——比如左右悬置 Z 向几乎反相，各自贡献 0.8 Pa 和 0.75 Pa，目标总声压却只有 0.55 Pa。这时候对着幅值排序"改最大那条"，反而可能把噪声改大。

```python
import numpy as np

# 某转速下三条路径在目标点的复数声压贡献（幅值 Pa，相位 deg）
paths = {
    "mnt_L_Z": 0.80 * np.exp(1j * np.deg2rad(10)),
    "mnt_R_Z": 0.75 * np.exp(1j * np.deg2rad(170)),  # 与左侧近似反相
    "hook_X":  0.30 * np.exp(1j * np.deg2rad(45)),
}
total = sum(paths.values())
print(f"三路径幅值直接相加: {sum(abs(v) for v in paths.values()):.2f} Pa")
print(f"复数矢量求和      : {abs(total):.2f} Pa   <- 真实总声压")
residual = total - paths["mnt_L_Z"]
print(f"去掉左悬置Z后残量 : {abs(residual):.2f} Pa")
print(f"目标点声压变化    : {20*np.log10(abs(residual)/abs(total)):+.1f} dB")
```

看输出里两个数：幅值直接相加得 1.85 Pa，复数矢量和只有 0.55 Pa——左右悬置反相抵消了绝大部分；更反直觉的是，把贡献最大的左悬置 Z 拆掉，总声压反而**升 1.2 dB**，因为抵消关系被破坏了。贡献量排序必须结合相位看，孤立的大幅值不等于该改。

::: warning 判读注意
- 单路径贡献量大于总级不是错误，是相位抵消的信号
- 只看幅值贡献图会误导决策，务必同时看路径间的相位差
- 计算总级与实测对不上时，先补路径（漏方向、漏吊钩、漏空气声），再下结论
:::

## 五、工况力怎么来：两种力估计方法

传递函数好办——锤击、激振器或有限元单位载荷都能得到。难的是工况力：把悬置换成力传感器会改变系统动力学，等于测了个新结构。工程上常用两种间接估计。

### 悬置刚度法（Mount Stiffness Method）

在悬置**主动侧**（源侧）和**被动侧**（结构侧）各布加速度传感器，两组加速度双重积分成位移后相减，得到悬置相对位移 x，再乘悬置动刚度 k，即胡克定律 F = k x：

![主动侧与被动侧加速度双重积分相减得位移，乘以悬置刚度得工况力](/images/transfer-path-analysis-intro/mount_stiffness.png)
*（图源：Simcenter Testing Knowledge Base）*

前提是悬置足够"软"——两侧位移差明显，积分误差占比小。橡胶悬置、液压悬置正合适。

### FRF 矩阵求逆法（Matrix Inversion Method）

硬连接（螺栓刚性连接的变速箱撑杆、硬点）两侧位移差极小，刚度法里"小差值乘大刚度"把测量误差放大得离谱。改用在路径附近布置若干**指示点**，测指示点加速度到路径力的 FRF 矩阵，再用工况加速度反解力：Fo = [A/F] 逆阵 x Ao。

只用一条 FRF 直接相除行不通——FRF 在反共振点趋近于零，倒数趋于无穷，反演力在该频率爆炸；而且单条 FRF 忽略了路径间的交叉耦合。正确做法是把所有路径的原点 FRF、交叉 FRF 组成矩阵**整体求逆**，同一频率在所有 FRF 里同时趋零的概率大大降低。指示 FRF 数量通常要达到路径数的两倍左右，并监控每个频率点的条件数（condition number），越小越健康。

```python
import numpy as np

rng = np.random.default_rng(7)
f = np.arange(20., 401., 1.0)
def reson(f, fr, zeta, s=1.0):          # 单自由度共振峰近似
    w, wr = 2*np.pi*f, 2*np.pi*fr
    return s/(1-(w/wr)**2 + 2j*zeta*w/wr)

H1 = reson(f, 120, 0.04) + 0.2                       # 指示点1的FRF
# 指示点2的FRF：在200Hz附近有深反共振
H2 = (reson(f, 190, 0.03, 0.9) + 0.2) * (1-(f/200)**2 + 2j*0.0002*f/200)
F0 = 10.0 + 0j                                       # 真实工况力 10 N
n = 0.02                                             # 加速度测量噪声
A1 = H1*F0 + n*(rng.standard_normal(f.size)+1j*rng.standard_normal(f.size))
A2 = H2*F0 + n*(rng.standard_normal(f.size)+1j*rng.standard_normal(f.size))

Fs = A2/H2                                           # 单FRF直接相除求力
Fm = (np.conj(H1)*A1 + np.conj(H2)*A2)/(np.abs(H1)**2+np.abs(H2)**2)  # 两指示点最小二乘
i = int(np.argmin(np.abs(H2)))
print(f"反共振点 {f[i]:.0f} Hz, |H2| = {abs(H2[i]):.5f}")
print(f"真实工况力       : {abs(F0):6.2f} N")
print(f"单FRF相除        : {abs(Fs[i]):8.1f} N   <- 噪声被放大")
print(f"两指示点矩阵求逆 : {abs(Fm[i]):6.2f} N")
err = np.abs(Fm-F0)/10*100
print(f"矩阵法全频段最大误差: {err.max():.1f}%")
```

200 Hz 反共振点处 |H2| 只有 0.003，单 FRF 相除把 0.02 的加速度噪声放大成近 9 N 的力误差（18.6 N 对比真实 10 N）；两条指示 FRF 做最小二乘反演，全频段力误差压在 2.4% 以内。这就是矩阵求逆法必须"成矩阵"的原因。

| 方法 | 核心公式 | 适用连接 | 主要坑 |
| --- | --- | --- | --- |
| **悬置刚度法** | F = k(xa - xp) | 软悬置（橡胶/液压） | 刚度取值误差直接进力；双重积分低频漂移 |
| **FRF 矩阵求逆法** | F = [A/F] 逆阵 x Ao | 硬连接（螺栓/撑杆） | 反共振病态；指示点不足时条件数飙升 |

::: warning 力估计注意
- 硬连接强行用刚度法，位移差小到和噪声同量级，算出的力没有意义
- 矩阵求逆前先看条件数随频率的曲线，尖峰位置就是不可信频段
- 悬置动刚度要用实测复刚度（随频率变），别用静态刚度凑数
:::

## 六、模型搭好之后：Component Editing 虚拟试装

找到最大贡献路径只是诊断的一半，另一半是验证"改了到底降多少"。Simcenter Testlab 的 TPA Component Editing 插件允许在现成模型上做虚拟修改再重算贡献：

- **改结构灵敏度**：对 P/F 曲线的共振峰做 Remove Peak（如压低 90%），等效于给车身该处加筋/加阻尼；
- **改悬置刚度**：对 k 曲线加偏移（如整体降 6 dB），等效于换软悬置；
- 改完立即对比修改前后的计算总级与该路径贡献，量化收益。

Path Specific 视图把每条路径拆成"加速度-位移-力-FRF-贡献"链条，哪个环节占主导一眼可见。修改后的模型可另存，与原模型随时切换对比。如果所有通道是同时采集的（有时间历史），还能把各路径贡献反变换回时域**试听**——轰鸣声到底"长什么样"，耳朵有时比眼睛快。

## 七、小结

- TPA 的输出不是一张谱，而是一个决策：改哪条路径、预期降多少 dB
- 切口划在你**能改**的接口上，路径 = 跨越切面的所有连接 x 所有方向
- 计算总级对不上实测，先怀疑漏路径，别急着信排序
- 贡献量是复矢量：反相路径互相抵消时，拆掉"最大贡献"可能升噪声——任何修改决策前先看相位
- 软连接用悬置刚度法，硬连接用矩阵求逆法，后者盯住条件数
