# 调制阶次与边带：彩色图谱对称伴线的成因与判读方法

> 变速箱台架升速试验，彩色图谱（Colormap）上 62 阶啮合线两侧对称出现 60 阶和 64 阶两条伴线——这不是三个独立激励源，而是一个：阶次被调制后产生边带（Sideband），边带间距直接对应调制源的每转作用次数。偏心齿轮每转对啮合副推拉两次，边带就出现在主阶 ±2 处。本文从偏心齿轮的啮合受力机理出发推导调幅公式，说明边带间距作为故障判别依据的使用方法，以及齿轮制造商主动控制偏心量以降低峰值响应的设计考虑。

一场台架升速试验的复盘会上，两组工程师对同一张彩色图谱给出了不同结论。齿轮组坚持"多出两个激励源"：62 阶啮合线两侧对称多了 60 阶与 64 阶两条伴线，按阶次反查部件，理应存在 60 齿与 64 齿的齿轮；传动组翻遍图纸也没有这两个件——整条传动链里与 60、64 沾边的特征数一个都对不上。争论持续到有人把两条伴线的间距量出来：恰好都是 2 阶，且幅值随 62 阶同步涨落。三条线不是三个源，而是一个源被"每转推拉两次"的动作改写了能量分配。会看边带间距的人，十分钟就能把问题从"多了两个部件"改写成"某个齿轮每转被加两次载荷"；不会读的人，会在零件清单里白找一整天。本文要解决的，就是这层从图谱伴线到物理机理的翻译。

## 一、图谱上的对称伴线现象

先看一张典型的彩色图谱。62 齿齿轮啮合，若齿轮均为正圆，图谱上应只有一条 62 阶斜线（频率随 rpm 变化）。实测结果却是三条：中间 62 阶，两侧对称分布 60 阶和 64 阶。

![62阶调制阶次的彩色图谱](/images/modulated-order-sidebands/fig7_colormap.png)

*62 阶啮合阶次每转被调制两次，产生 60、64 阶边带（图源：网络官方公开资料）*

先说一个贯穿全文的类比：合唱里的领唱与回声。62 阶啮合线是领唱，音量本该恒定；偏心齿轮每转两次的推拉，就像一只手按着领唱的嘴、每拍松紧两下——歌声还是那一句（载波频率不变），但响度以固定节奏起伏（幅值被调制）。站在观众席（频谱仪）听到的不再是单一人声，而是人声两侧各多出一层"抖动"的回声：回声的节奏恰好等于按嘴的节奏，回声的强弱恰好等于按嘴的力道。读懂这两层回声，不必拆开合唱者的嘴也能知道那只手每拍动几次、用了多大力。边带之于主阶，正是回声之于领唱——**间距揭露节奏（每转几次），幅值揭露力度（调制深度）**。

初学者常见的误判，是按阶次数值反查部件——去系统里寻找"60 齿的齿轮"和"64 齿的齿轮"，而整机中并不存在这两个部件。边带不是独立的物理事件，而是主阶被调制后的数学产物：**60 阶和 64 阶的能量来自 62 齿啮合本身**。

::: info 核心概念
- <strong>调制阶次（Modulated Order）</strong>：幅值随转角周期变化的阶次，在图谱上表现为幅值沿转速方向起伏、或两侧带伴线的斜线
- <strong>边带（Sideband）</strong>：主阶两侧等间距分布的阶次分量，间距等于调制频率对应的阶次
- **边带间距 k**：主阶 ±k 处出现边带，意味着调制源每转作用 k 次
:::

## 二、偏心齿轮产生边带的机理

相关技术手册给出了直观的机理说明：一对齿轮，齿轮 1 为正圆，齿轮 2 因加工（尤其是滚齿工序中的几何偏差）呈椭圆状偏心。两齿轮啮合时，椭圆齿轮每转一圈会把齿轮 1 **推开又拉回两次**。

![偏心齿轮副](/images/modulated-order-sidebands/fig8_eccentric.png)

*齿轮 1 正圆，齿轮 2 偏心椭圆（图源：网络官方公开资料）*

![偏心导致每转两次推拉](/images/modulated-order-sidebands/fig9_pushpull.png)

*中心距每转变化两次，啮合力随之被调制（图源：网络官方公开资料）*

物理过程：齿轮 2 每转一圈，椭圆轮廓使实际中心距经历两个"远-近"循环。中心距变化引起啮合间隙变化，啮合冲击的强度每转起伏两次。若齿轮为正圆，中心距恒定，图中绿色曲线为平线，不发生调制。

### 从机理到公式

设轴频（Shaft Frequency）为 $f_{shaft}$（单位 Hz，即每秒转数），62 齿啮合频率（Gear Mesh Frequency）为 $f_m = 62 f_{shaft}$。啮合力幅值受"每转两次"的推拉调制，等价于啮合信号乘以包络 $[1 + m\cos(2\pi \cdot 2f_{shaft} t)]$，其中 $m$（无量纲，$0 \le m \le 1$）为调制深度（Modulation Depth），即幅值起伏量与平均幅值之比：

这个公式回答的问题是：一个每转被推拉两次的 62 齿啮合信号，数学上长什么样？其中方括号项 $[1 + m\cos(\cdot)]$ 就是那只"每转按两次的手"——包络（Envelope），$m$ 是按嘴的力道（起伏量与平均幅值之比），外层的余弦是领唱本身（62 阶载波）。载波频率没有被改变，被改变的只是它的幅值节奏，这正是调幅（Amplitude Modulation）的完整定义。

$$x(t) = A\,[1 + m\cos(2\pi \cdot 2f_{shaft} t)]\,\cos(2\pi \cdot 62 f_{shaft} t)$$

这一步的物理意义：啮合频率仍是 62 阶，但瞬时幅值以每转 2 次的节奏起伏，即调幅（Amplitude Modulation）。

用积化和差恒等式 $\cos\alpha\cos\beta = \tfrac{1}{2}[\cos(\alpha-\beta) + \cos(\alpha+\beta)]$ 展开乘积项：

这个公式回答的问题是：按着嘴的领唱，观众耳朵里实际听到哪几个音？积化和差恒等式把"包络×载波"的乘积展开成三个纯音之和——领唱原声 $A$ 原样保留，两侧各冒出幅值 $mA/2$ 的伴音。图谱上 60、64 阶伴线的幅值恰为 62 阶的 $m/2$ 倍，这一行就是出处；上一章"回声的强弱等于按嘴的力道"的类比，在这里落成可以量测的比例式。

$$x(t) = A\cos(2\pi \cdot 62 f_{shaft} t) + \frac{mA}{2}\cos(2\pi \cdot 60 f_{shaft} t) + \frac{mA}{2}\cos(2\pi \cdot 64 f_{shaft} t)$$

展开结果表明信号仅含三个频率分量：62 阶载波保持幅值 $A$，两侧 60、64 阶边带各为 $mA/2$。

将结论一般化：设啮合阶次为 $N$（齿数），调制源每转作用 $k$ 次，则调幅信号为

这个公式回答的问题是：换一对齿轮、换一种故障，结论还成不成立？把 62 与 2 抽象为啮合阶次 $N$ 与每转调制次数 $k$，公式对一切"载波+周期包络"结构通用——间距 $k$ 换 2 为 1 就是安装偏心，换成一根轴的转频阶次就是相邻轴载荷耦合。判读图谱伴线时套用的正是这个一般式：主阶 $N$ 定部件，间距 $k$ 定调制源。

$$x(t) = A\,[1 + m\cos(2\pi k f_{shaft} t)]\,\cos(2\pi N f_{shaft} t)$$

同样展开后，边带出现在 $N - k$ 与 $N + k$ 阶，幅值均为 $mA/2$。由此得到两个判读依据：

1. **边带定位**：边带位于主阶 $N \pm k$，间距 $k$ 等于调制源每转作用次数——间距 2 指向椭圆偏心（每转推拉两次），间距 1 指向齿轮安装偏心（每转一次）。
2. **调制深度量化**：这个公式回答的问题是——图谱量出伴线与主线的幅值后，偏心"严重到什么程度"能不能给个数？由展开式边带幅值 $mA/2$ 反解得 $m = 2A_{sideband}/A_{carrier}$，把"手按嘴的力道"从定性描述变成可跟踪的数值，用于评估偏心程度的变化趋势。

## 三、边带间距的判读对照

将常见调制源整理为对照表，读图时按"主阶 ± k"反查：

| 调制源 | 每转调制次数 k | 62 阶的边带位置 | 典型特征 |
| --- | --- | --- | --- |
| <strong>椭圆偏心齿轮（滚齿几何偏差）</strong> | 2 | 60、64 阶 | 边带成对对称，幅值相等 |
| <strong>齿轮与轴不同心（安装偏心）</strong> | 1 | 61、63 阶 | 单间距边带，常伴 1 阶升高 |
| **齿形误差/载荷波动** | 1 或多 | 61、63 阶起 | 边带族更密，需倒频谱确认 |
| **相邻轴载荷耦合** | 速比相关 | 间距=另一轴阶次 | 边带不随本轴整数阶变化（需结合传动链确认） |

::: warning 工程注意
- 边带阶次**没有对应的物理部件**：相关技术手册明确指出，62 阶对应齿轮上 62 个齿，而 60、64 阶边带在系统中没有相同特征数的部件与之对应
- 边带间距应在阶次域（而非频率域）读取——频率域上间距随转速变化，阶次域上间距恒为 $k$，这是识别调制源的关键特征
- 调制不限于幅值调制：相关技术手册指出除偏心几何外，多种物理现象都会产生调制，例如齿轮未装在轴心上导致每转一次的调制；离合器颤振、轴承缺陷、负载波动机理相同
:::

## 四、Python 验证：复现边带的形成

用 numpy 仿真一个偏心齿轮的啮合加速度信号，在**角度域**做 FFT，观察 62 阶两侧边带的出现，以及间距随调制次数的变化。

```python
import numpy as np

# 仿真参数：62 齿齿轮，轴频 20 Hz，采样率与每转点数固定（角度域均匀采样）
shaft_hz = 20.0
n_rev = 64                 # 总转数
pts_per_rev = 512          # 每转采样点数
N = n_rev * pts_per_rev
rev = np.arange(N) / pts_per_rev          # 转数坐标（角度域的"时间轴"）
t = rev / shaft_hz

# 啮合信号：62 阶载波 + 椭圆偏心导致的每转 2 次调幅
order_mesh, order_mod, m = 62.0, 2.0, 0.6
carrier = np.cos(2*np.pi*order_mesh*rev)
env = 1 + m*np.cos(2*np.pi*order_mod*rev)
x = env * carrier

# 角度域 FFT：横轴单位是"阶次"
X = np.abs(np.fft.rfft(x) * 2/N)
orders = np.arange(N//2 + 1) / n_rev

# 找主阶和边带
for target in [62.0, 60.0, 64.0]:
    i = np.argmin(np.abs(orders - target))
    print(f"{orders[i]:6.1f} 阶  幅值 {X[i]:.3f}")

# 理论对照：边带幅值应为 m/2 = 0.30
print(f"理论边带幅值 m/2 = {m/2:.3f}")
```

输出中重点核对两个数值：60、64 阶边带幅值均为 0.300，与理论值 $m/2$ 一致；62 阶载波幅值保持 1.000，不受调制影响——积化和差推导的每一项都得到数值验证。将 `order_mod` 改为 1，边带移至 61、63 阶，间距即调制次数。

## 五、设计权衡：受控偏心作为降噪手段

发现齿轮偏心后的第一反应往往是"提高加工精度"。但从噪声与振动控制角度看，这未必是降低峰值响应的最优方案。

啮合能量集中在单一 62 阶谱线时，该谱线幅值高、带宽窄——单一频率纯音，响度峰值高。能量被调制分配到三根谱线后，各谱线幅值均降低。相关技术手册的表述是：当齿轮副啮合的全部能量集中在单一阶次时，产生的振动/声幅值高于调制后的边带分布；偏心齿轮把能量分散到较宽的频率范围上，声与振动峰值随之下降。

![未调制与调制的阶次域对比](/images/modulated-order-sidebands/fig10_orderdomain.png)

*上图：正圆齿轮，能量集中单阶；下图：偏心齿轮，能量分配到边带（图源：网络官方公开资料）*

![能量集中的单阶与分散的边带](/images/modulated-order-sidebands/fig11_energy.png)

*单阶幅值高于调制后的边带族——能量分散使峰值下降（图源：网络官方公开资料）*

相关技术手册还明确指出：齿轮制造商可以出于这一目的主动控制偏心量（Gear manufacturers can control the eccentricity, just for this purpose）。这与离合器从动盘开螺旋槽、变速箱壳体加阻尼的处理思路一致——以分散能量代替单纯消减峰值。

::: tip 调制阶次的处理思路
- **先判读**：先量边带间距确定 $k$，反查调制源，再决定是否调整齿轮精度
- **间距 2 + 边带对称** → 检查齿形几何（椭圆度），评估是否在可接受范围
- **间距 1 + 1 阶同步升高** → 检查齿轮与轴的同心度（安装问题），通常需要修正
- **峰值响度为主要问题** → 可与供应商协商受控偏心量，替代追求绝对正圆
- 载波与边带族混叠难以分辨时，倒频谱（Cepstrum）可将等间距谱线族折叠为单一峰值，是进一步的分析工具
:::

## 六、小结

三条判读要点：

1. **主阶 ±k 的边带 = 调制源每转作用 k 次**。间距 2 指向椭圆偏心，间距 1 指向安装偏心——在阶次域量间距，不在频率域量。
2. **边带没有物理对应部件**。60 阶边带不意味着存在 60 齿齿轮，它是 62 阶能量被调制后重新分配的结果。
3. **调制不全是缺陷**。受控偏心把能量分散到宽频带、降低峰值响应，是齿轮制造商主动使用的设计手段；先区分问题是"峰值高"还是"存在调制"，再决定是否修正。

## 一句话记住

主阶两侧等间距的伴线不是新部件，是主阶被"每转 k 次"的调制重新分了能量：阶次域量间距 k 定调制源（2=椭圆偏心、1=安装偏心），边带幅值/主阶幅值×2 得调制深度，能量分散反能压峰值响应。
