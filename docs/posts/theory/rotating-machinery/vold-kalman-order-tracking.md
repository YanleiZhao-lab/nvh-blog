# Vold-Kalman 阶次跟踪滤波器：用加权最小二乘从噪声中提取阶次波形

> 变速箱台架升速试验中，彩色图谱（Colormap）上 21.5 阶谱线邻近常伴有 22 阶及调制边带，阶次切线在谱上难以将三者分离。Vold-Kalman 阶次跟踪滤波器（Vold-Kalman Filter, VKF）不采用"切谱线"的方式，而是建立相反的问题表述：假设待提取阶次在每一短时间段内为一根正弦波，将该结构特性作为约束，与测量数据一起构成加权最小二乘问题，直接求解阶次的时域波形，幅值与相位均为求解的副产品。本文从正弦波的二阶差分方程出发推导结构方程与数据方程，说明谐波置信因子（Harmonic Confidence, HC）如何决定滤波带宽，用 numpy 复现整套求解过程，并给出工程应用的参数选择判据。

## 一、谱线切取方法的局限与阶次求解思路

阶次分析的传统流程是角域重采样加 FFT：将时域信号按转角重采样，阶次在谱上表现为离散谱线，再从谱中提取目标阶次的谱线。该流程在转速平稳、阶次间隔较宽时效果良好，但存在两项固有限制。

其一，阶次分辨率受观察时间限制。阶次分辨率等于平均循环数的倒数——手册给出的关系为 10 个平均循环对应 0.1 阶分辨率。要将间隔 0.5 阶的两根谱线分开，平均循环数需达到 2 以上；转速快速变化时，可用于平均的循环数不足。其二，切谱线得到的是"某段平均时间内"的幅值，阶次幅值在转速瞬变过程中的起伏细节被平均过程抹平。

卡尔曼式阶次跟踪采用不同的思路：目标阶次在任意短的时间段内均近似为一根正弦波，因此可以**对每个采样时刻求解一个方程**，使解出的时域序列 $x(n)$ 既符合正弦形态（结构约束），又尽量接近测量数据 $y(n)$（数据约束）。两组约束加权折中。由此得到阶次的完整时域波形，分辨率不再受观察时间限制。知识库给出的能力清单包括：从恒采样率信号中以任意分数阶次分辨率跟踪、少量采样点即可获得良好的阶次谱分辨率、旋转速率实际上不受限制、每个采样点均产生阶次值、无相位失真。

::: info 核心概念
- **结构方程（Structural Equation）**：规定待跟踪波形形态的约束，正弦波对应二阶差分方程 $x(n) - c(n)\,x(n-1) + x(n-2) = \varepsilon(n)$，其中 $c(n) = 2\cos(2\pi f(n)/f_s)$
- **数据方程（Data Equation）**：测量信号 $y(n) = x(n) + \eta(n)$，$\eta$ 包含噪声与其它频率的周期分量
- **谐波置信因子 HC（Harmonic Confidence）**：结构方程与数据方程置信度之比，HC 高则带宽窄、频率分辨率高，HC 低则带宽宽、幅值收敛快
- **Vold-Kalman 滤波器（VKF）**：将两组方程叠成超定方程组、以加权最小二乘求解的阶次提取方法，对非平稳转速自适应
:::

## 二、推导：从正弦差分方程到加权最小二乘解

### 第一步：正弦波满足的差分方程

设目标阶次的瞬时频率为 $f$（单位 Hz，随转速变化，由转速通道逐点给出），采样率 $f_s$（单位 Hz）。一段纯净正弦 $x(t) = A\sin(2\pi f t + \varphi)$ 以间隔 $\Delta t = 1/f_s$ 采样后，相邻三个采样点之间存在精确的递推关系。利用和差化积恒等式 $\cos\alpha + \cos\beta = 2\cos\dfrac{\alpha+\beta}{2}\cos\dfrac{\alpha-\beta}{2}$，将 $x(n)$ 与 $x(n-2)$ 的和式重新组合，可消去幅值 $A$ 与初相 $\varphi$，得到

$$x(n) - c \cdot x(n-1) + x(n-2) = 0, \quad c = 2\cos(2\pi f/f_s)$$

物理意义：已知一根正弦最近两个采样点，第三个点即被完全确定，无需幅值与相位信息。这就是"结构"的含义：无论这根正弦幅值大小、相位如何，只要频率为 $f$，该三点递推关系严格成立。频率 $f$ 逐点随转速变化，因此系数也是逐点的 $c(n)$。

### 第二步：引入非齐次项

实测信号的频率、幅值、相位均会缓慢漂移，严格等式约束过强。引入一个确定但未知的偏离项 $\varepsilon(n)$，方程变为 $x(n) - c(n)\,x(n-1) + x(n-2) = \varepsilon(n)$，其标准差 $S_\varepsilon$（单位与被测信号一致，如 m/s²）刻画"允许波形偏离理想正弦的程度"。测量端写成 $y(n) = x(n) + \eta(n)$，$\eta$ 为噪声与其它周期分量之和，标准差 $S_\eta$（同单位）。

### 第三步：叠加为超定方程组，加权求解

对每个时刻 $n$，两个方程均只涉及 $x(n)$、$x(n-1)$、$x(n-2)$ 三个未知数。将全部时刻的方程竖向叠加，得到一个超定方程组：结构方程约束"波形形态为正弦"，数据方程约束"数值接近测量"。两组误差的量纲与置信度不同，不能直接相加，因此用标准差之比定义计权因子 $r(n) = S_\varepsilon / S_\eta$（无量纲），将方程统一为加权形式，对所有时间观察点列方程后以标准最小二乘求解。

*（图源：Simcenter Testing Knowledge Base）*

矩阵形式可以写得更直观。设 $L$ 为二阶差分算子矩阵（每行仅含三个非零元素 $1$、$-c(n)$、$1$），则整个问题等价于最小化目标函数

$$J = \frac{1}{r^2}\,\|Lx\|^2 + \|x - y\|^2$$

第一项是结构误差（偏离正弦形态的程度），第二项是数据误差（偏离测量的程度），$1/r^2$ 是两者的权重比。对 $x$ 求导并置零，得到正规方程的解

$$x = \left(I + \frac{1}{r^2}\,L^T L\right)^{-1} y$$

记结构计权 $\lambda = 1/r^2$（即谐波置信因子的平方度量，$\lambda$ 大等价于 HC 高），则 $x = (I + \lambda L^T L)^{-1} y$。一次线性代数求解即得到阶次的时域波形：幅值包络用滑动 RMS 或 Hilbert 变换从 $x$ 中提取，相位即 $x$ 的瞬时相位。这也是"无相位失真"的来源——求解的对象是波形本身，而非谱线幅值。

::: warning 两项前提条件
- 被跟踪信号的结构必须精确已知：频率对应阶次、采样率恒定，转速时迹必须准确。转速通道不准时 $c(n)$ 即为错误系数，滤波器将跟踪错误的目标。知识库强调转速通道与振动通道应以相同采样率记录，必要时先做重采样平滑
- 结构方程假定频率在三个连续采样点内近似不变。转速变化小于滤波器带宽即满足条件；带宽下限为观察时间 $T$（单位 s）的倒数，旋转速率上限为 $F_s/2T$。按知识库算例，变化率 75 Hz/s 的燃气轮机 5 秒降速过程仅需 750 Hz 采样率，实际工程中该条件一般不构成限制
:::

## 三、谐波置信因子的选择：带宽与收敛时间的权衡

计权因子 $r$ 的倒数即谐波置信因子 HC。HC 高，相当于认定"结构方程可信、测量数据噪声大"，滤波器带宽变窄、频率分辨能力提高，代价是幅值估计收敛变慢；HC 低则相反，带宽宽、收敛快，但相邻阶次之间会产生渗透。

![三种谐波置信因子下的滤波器带宽特性对比](/images/vold-kalman-order-tracking/hc-bandwidth.png)

*（图源：Simcenter Testing Knowledge Base）*

另一个值得注意的细节：计权因子逐点可变，意味着**带宽可以定义为频率或阶次的函数**。若按频率定义带宽，低转速时同一 Hz 带宽会覆盖多个阶次；按阶次定义带宽，各转速下的滤波范围相对阶次轴恒定。知识库的带宽特性图直观展示了两种定义的差别。

![滤波带宽按频率与按阶次定义时的行为差异](/images/vold-kalman-order-tracking/bandwidth-vs-order.png)

*（图源：Simcenter Testing Knowledge Base）*

用 numpy 复现整套求解，观察结构计权 $\lambda$ 对带宽与收敛的实际影响。目标为 40 Hz 正弦，干扰为 55 Hz 邻频。先考察带宽：对每个候选频率的复指数求滤波器增益，等效于扫频测量滤波器的频率响应。

```python
import numpy as np

fs, N = 1000.0, 4000                    # 采样率（Hz）与数据长度
f0 = 40.0                               # 目标频率（对应某阶次）
c = 2*np.cos(2*np.pi*f0/fs)             # 结构方程系数
L = np.zeros((N-2, N))                  # 二阶差分算子：每行 1, -c, 1
L[:, 2:]   += np.eye(N-2)
L[:, 1:-1] -= c*np.eye(N-2)
L[:, :-2]  += np.eye(N-2)
A = L.T @ L

for lam in [30, 300, 3000]:             # 结构计权 λ = 1/r²
    M = np.linalg.inv(np.eye(N) + lam*A)  # 滤波器矩阵 (I + λL'L)^-1
    gains = []
    for f in [40, 45, 50, 55]:          # 扫频：考察邻频抑制
        n = np.arange(N)
        y = np.exp(2j*np.pi*f*n/fs)     # 复指数激励
        g = np.abs(M @ y)[N//2:].mean() # 稳态增益
        gains.append(f"{f}Hz:{g:.2f}")
    print(f"λ={lam:5d}  增益 " + "  ".join(gains))
```

运行结果：λ=30 时 55 Hz 增益 0.92，邻频几乎原样通过；λ=300 时降至 0.52；λ=3000 时降至 0.10。带宽随结构计权增大而收窄的效果明确：λ 每增大一个量级，阻带抑制相应提高一档。

再考察收敛速度。目标正弦幅值在 3 s 处从 1.0 阶跃至 0.2，测量提取出的包络跟随该阶跃所需的时间。

```python
import numpy as np

fs, N = 1000.0, 6000
f0 = 40.0
c = 2*np.cos(2*np.pi*f0/fs)
L = np.zeros((N-2, N))
L[:, 2:]   += np.eye(N-2)
L[:, 1:-1] -= c*np.eye(N-2)
L[:, :-2]  += np.eye(N-2)
A = L.T @ L

n = np.arange(N)/fs
amp = np.where(n < 3.0, 1.0, 0.2)               # 幅值阶跃
target = amp*np.sin(2*np.pi*f0*n)
y = target + 0.05*np.random.default_rng(3).standard_normal(N)

for lam in [30, 300, 3000]:
    x = np.linalg.solve(np.eye(N) + lam*A, y)   # VKF 求解
    e = np.convolve(np.abs(x), np.ones(20)/20, 'same')  # 20ms 包络
    idx = np.where((n > 3.0)*(np.abs(e-0.2) < 0.04))[0]
    print(f"λ={lam:5d}  包络收敛耗时 {(idx[0]/fs-3.0)*1000:.0f} ms")
```

运行结果：λ=30 收敛 6 ms，λ=300 收敛 7 ms，λ=3000 延长至 19 ms。带宽收窄后阶跃响应变慢，正对应知识库所述"高 HC 以幅值收敛时间为代价"。

两组演示结果汇总为参数选择对照表：

| 场景 | HC 取向 | 带宽 | 依据 |
| --- | --- | --- | --- |
| **邻阶密集**（变速箱多对齿轮啮合阶次间距小） | 高 | 窄 | 优先保证相邻阶次分离，稳态工况下幅值最终收敛 |
| **转速快变**（电机快速升降速、tip-in 载荷突变） | 中低 | 宽 | 阶次幅值本身瞬变，带宽过窄会将真实起伏平滑掉 |
| **阶次幅值突变**（离合器接合瞬间的冲击） | 低 | 宽 | 关注事件发生时刻的幅值，允许一定邻频渗透以换取跟踪速度 |
| **稳态精测**（定转速下与 CAE 幅值对标） | 高 | 窄 | 时间充足，分辨率优先，将邻频泄漏压至最低后读数 |

::: tip 参数选择起步建议
- HC 先按"目标阶次与最近邻阶的间隔"反推带宽：知识库指出对两个间隔密集正弦波的分辨能力与总观察时间成反比，观察时间应取最小频率间隔的倒数
- 不确定时先以中等 HC 计算一版，检查提取波形与原始数据的残差：残差中仍含目标阶次成分，说明带宽过窄、结构约束过强；残差中邻频成分明显，说明带宽过宽
- 带宽定义优先按阶次而非频率，以保证全转速范围内滤波行为一致
:::

## 四、与重采样 FFT 法的适用划分

Vold-Kalman 滤波与角域重采样 FFT 不是替代关系，而是分工关系。

| 维度 | 重采样 + FFT | Vold-Kalman |
| --- | --- | --- |
| **输出** | 阶次谱、切线（平均结果） | 阶次时域波形（逐点） |
| **分辨率** | 1/平均循环数 | 不受观察时间限制，可达分数阶次 |
| **瞬变跟踪** | 快速升降速时平均造成模糊 | 逐点自适应，无相位失真 |
| **计算代价** | 低，一遍重采样加 FFT | 高，逐阶次求解大型方程组 |
| **多阶次** | 一次计算得到全部阶次 | 一次求解一个阶次，需几条线则解几次 |
| **前提** | 转速通道质量决定结果 | 同样依赖转速通道，且要求频率模型精确 |

选择规律：需要全谱概览、彩色图谱、观察数十条阶次线时，用重采样 FFT；只需其中一两条关键阶次、需要其在瞬态过程中的幅值相位细节时，用 Vold-Kalman。实际项目中常见的组合是：用重采样法的彩色图谱定位问题阶次，锁定后再用 VKF 求解该阶次做幅值定量与源识别；配合声阵列做阶次域波束成形（beamforming）也是其典型应用。

## 五、小结

阶次提取的本质，是在"波形应具有的形态"与"实际测量数据"之间做加权折中。结构方程将正弦形态写成三点递推，数据方程约束解不偏离测量，HC 决定两者的相对权重。工程判断三条：邻阶间隔决定带宽下限，幅值瞬变剧烈程度决定带宽上限，两者冲突时优先保证分辨率。幅值收敛慢尚可等待；邻阶渗透进入结果后，读出的数值即是错误的。
