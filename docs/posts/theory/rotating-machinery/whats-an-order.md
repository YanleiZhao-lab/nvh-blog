# 阶次：转频与振动频率的桥梁

> 转速一变，频谱上的峰就跟着跑，怎么追踪"哪个零件"的贡献？答案是阶次（Order）——每转事件数与参考轴之比。本文从单轴升速讲到位形图判读，再到阶次与频率的换算、六缸机 3 阶 combustion 的来历，读完你能在 colormap 上直接认出阶次线与共振线。

## 一、为什么需要阶次

一台运转的机器，每个旋转部件（齿轮、轴、活塞、泵、轮胎……）都在往总噪声、总振动里添自己的份。升速过程中转速连续变化，频谱上同一个峰的位置不停移动——固定频率轴根本没法回答"这是谁贡献的"。

阶次分析解决的就是这个归属问题：把响应幅值表示成**每转事件数**的函数，事件的"主人"便锁定了。皮带轮上一颗不平衡质量每转打一次，是 1 阶；啮合的 86 齿齿轮每转打 86 次，是 86 阶。转速怎么扫，阶次不变。

先看单根轴怎么生成 1 阶数据。轴从 600 rpm 转到 6000 rpm：600 rpm 对应转频 10 Hz，6000 rpm 对应 100 Hz。每个转速下测一个幅值，把"频率—幅值—RPM"画进三维图：

![单轴升速：频率-幅值-RPM 三维图](/images/whats-an-order/first-order-3d.png)

*(图源：Simcenter Testing Knowledge Base)*

沿 RPM 方向把数据补满（连续扫频、小步进计算），得到的就是 1 阶的完整轨迹。转速与频率之间是严格的比例关系，所以这条轨迹在频率-RPM 平面上是一条从原点出发的直线。

## 二、阶次数怎么算

### 基准轴与阶次比

阶次数本质是**相对 1 阶（参考轴）的每转事件数之比**。

两根轴经皮带轮连接，A 轴直径是 B 轴的 3 倍。A 转 1 圈，B 转 3 圈。以 A 为参考轴扫 600→6000 rpm 时，B 的响应始终出现在 3 倍转频处：A 在 600 rpm（10 Hz）时 B 是 30 Hz，A 在 6000 rpm（100 Hz）时 B 是 300 Hz。B 的响应就是 **3 阶**。

![皮带传动的两轴系统：直径比即转速比](/images/whats-an-order/two-shafts.png)

*(图源：Simcenter Testing Knowledge Base)*

反过来，若 tacho 装在 B 轴上，B 成了参考轴，A 的响应就是 1/3 阶。**阶次的数值取决于参考轴选谁**——这一点工程上由转速计（tacho）的位置决定：Simcenter Testlab 自动把 tacho 所追踪的那个部件设为 1 阶。tacho 装曲轴，曲轴是 1 阶；装发电机，发电机是 1 阶，其余所有阶次都相对它重新计算。对比两份阶次数据前，先确认参考轴一致，否则数字对不上。

::: info 核心概念
- **阶次（Order）**：每转事件数相对参考轴（1 阶）之比
- **参考轴**：tacho 追踪的旋转部件，其每转 1 次的事件定义为 1 阶
- **阶次切（Order cut）**：沿某一阶次的轨迹在 colormap/瀑布图上做的剖面，跟踪该阶次随 RPM 的幅值
:::

### 阶次不一定是整数

两齿轮啮合，蓝轴（主动）转 60 rpm，绿轴（从动）的转动相对蓝轴是 **1.625 阶**——传动比不是整数，阶次就不是整数。半阶、分数阶在发动机和变速器里非常常见，别见到 0.5 阶、1.5 阶就怀疑数据。

最经典的分数阶来自四冲程：曲轴每 **2 转**才完成一次完整循环（进气、压缩、做功、排气各占 1 转），所以单缸四冲程机的燃烧事件是 **1/2 阶**。六缸机每圈有 3 个缸点火，combustion order = 6 × (1/2) = **3 阶**。这个 3 阶与转速无关——不管怠速还是红线，点火阶次始终是 3。

```python
import numpy as np

# 四冲程发动机的燃烧阶次
n_cyl = 6                          # 缸数
events_per_2rev = n_cyl            # 2 转内每缸各点火 1 次
order_comb = events_per_2rev / 2   # 阶次 = 每转事件数（相对曲轴）
print(f"六缸四冲程机 combustion order = {order_comb:.0f} 阶")

# 同一台发动机 3 阶在不同转速下的频率
for rpm in [800, 2000, 4000]:
    f = order_comb * rpm / 60
    print(f"  {rpm:5d} rpm -> {f:6.1f} Hz")
```

怠速 800 rpm 时 3 阶是 40 Hz，4000 rpm 时爬到 200 Hz——阶次不变，频率随转速线性走。这就是"同一个问题"在两种坐标下的样子。

## 三、阶次与频率的换算

频率和阶次其实是同一个东西的两种记法，都是"观测帧内的事件数"：

- 频率：每秒事件数（观测帧 = 1 秒）
- 阶次：每转事件数（观测帧 = 1 圈）

知道 rpm 就能在两者之间换算：

**频率（Hz） = 阶次 × RPM ÷ 60**

反过来，阶次 = 事件频率 ÷ 转频。手册里两个例子值得记住：

| 对象 | 转速 | 事件频率 | 阶次 |
| --- | --- | --- | --- |
| **6 叶风扇叶片通过** | 6000 rpm | 轴 100 Hz，叶片通过 600 Hz | 100 Hz 处 **6 阶** |
| **86 齿齿轮啮合** | 600 rpm | 轴 10 Hz，啮合 860 Hz | 10 Hz 处 **86 阶** |
| **六缸四冲程燃烧** | 任意 | — | **3 阶**（与转速无关） |
| **皮带从动轮（速比 3）** | 主动轮扫速 | — | **3 阶** |
| **齿轮从动轴（速比 1.625）** | 主动轮 60 rpm | — | **1.625 阶** |

风扇的例子还有个捷径：不必先算频率——主轴每转 1 圈必然发生 6 次叶片通过，叶片通过就是 6 阶。数事件数比算频率更快，也更不容易错。

```python
import numpy as np

# 阶次 <-> 频率双向换算
def order_to_hz(order, rpm):
    return order * rpm / 60          # Hz = 阶次 * rpm / 60

def hz_to_order(freq, rpm):
    return freq / (rpm / 60)         # 阶次 = 事件频率 / 转频

# 86 齿齿轮 @ 1200 rpm
rpm = 1200
mesh_hz = order_to_hz(86, rpm)
print(f"86 阶 @ {rpm} rpm -> 啮合频率 {mesh_hz:.0f} Hz")

# 变速器里一个 1720 Hz 的峰，输入轴 2400 rpm，是几阶？
peak = 1720
print(f"1720 Hz @ 2400 rpm -> {hz_to_order(peak, 2400):.2f} 阶")

# 常用发动机阶次速查（曲轴参考）
print("曲轴参考下：怠速发火 0.5 阶，L4 发火 2 阶，L6 发火 3 阶，V8 发火 4 阶")
```

1720 Hz 的峰落在 43 阶上——正好是主减齿轮副常见的齿数区间，下一步就该去查传动系统齿轮参数了。

::: warning 工程注意
colormap 上把 dB 显示打开再找阶次线。线性幅值下颜色被少数大峰 dominate，暗部的阶次线几乎看不见；dB 格式提亮暗部，阶次线（斜线）与共振线（竖线）的分界立刻清晰。另外频率-阶次换算只在"事件频率与转频严格成比例"时成立——液力变矩器打滑、皮带打滑会让阶次线弯曲，看到弯的"阶次线"先查打滑再怀疑算法。
:::

## 四、阶次数据怎么显示：瀑布图与彩色图

阶次数据的标准显示是**瀑布图（waterfall）与彩色图（colormap）**：按小 RPM 步进逐帧计算自功率谱（autopower），沿 RPM 轴堆叠起来。瀑布图保留三维视角，每条沿频率轴的曲线就是一个 RPM 切片的 autopower。

![瀑布图：逐转速切片的自功率谱堆叠](/images/whats-an-order/waterfall.png)

*(图源：Simcenter Testing Knowledge Base)*

把瀑布图"压扁"——幅值轴转向纸外、用颜色深浅表示——就是 colormap。冷色低幅值，暖色高幅值，一眼看全局。

![彩色图：颜色即幅值](/images/whats-an-order/colormap.png)

*(图源：Simcenter Testing Knowledge Base)*

判读 colormap 只认两类特征：

| 特征 | 形状 | 含义 |
| --- | --- | --- |
| **阶次线** | 从原点出发的斜线 | 某部件每转 N 次事件的轨迹，频率 ∝ RPM |
| **共振线** | 沿频率轴的竖直亮带 | 结构固有频率，转速无关、阶次扫过时被激励 |

斜线与竖线的交点最值得关注：阶次扫过共振频率的转速，正是"问题转速"——轰鸣、啸叫、抖动通常在这里冒头。定位到交点后，用阶次切（order cut）沿该斜线取剖面，拿到这条阶次随 RPM 的幅值曲线，与整车主观评价的转速点对齐，整改就有了靶子。

::: tip 实用建议
- 判读顺序：先 dB 显示 → 找斜线（阶次）与竖线（共振）→ 锁定交点转速 → 对交点阶次做 order cut
- 阶次线弯曲、不过原点：查打滑（变矩器、离合器、皮带）或参考轴选错
- 对比两份数据前，先核对 tacho 装在哪根轴上，参考轴不同阶次数完全不同
:::

## 五、小结

阶次是"每转事件数"的归一化，把随转速漂移的频率峰锚定到具体部件上。频率 = 阶次 × rpm/60，四冲程发动机燃烧阶次 = 缸数/2（六缸即 3 阶），齿轮啮合阶次 = 齿数，传动链里每级速比都直接写进阶次数。拿到 colormap 先开 dB、找斜线竖线交点，那就是下一步整改的目标转速。
