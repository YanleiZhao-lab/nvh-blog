# 阶次：旋转机械响应的每转事件数表征

> 升速过程中转速连续变化，频谱峰的位置随转速移动，固定频率轴的谱分析难以回答"各旋转部件分别贡献了多少"。阶次（Order）把响应幅值表示为每转事件数（events per revolution）的函数，使响应可以归属到具体部件。本文给出阶次的定义与计算方法、阶次与频率的换算式，以及瀑布图与彩色图的判读要点：斜线为阶次线，竖直亮带为共振频率线，两者的交点对应需要关注的转速。

## 一、为什么需要阶次

一台运转的机器中，每个旋转部件（齿轮、轴、活塞、泵、轮胎等）都对系统的噪声与振动总量有贡献。升速过程中转速连续变化，频谱上同一个峰的位置随转速持续移动——仅按固定频率轴分析，无法确定某个响应来自哪个部件。

阶次分析解决这一归属问题：把响应幅值表示成**每转事件数**的函数，响应与激励部件的对应关系即可确定。皮带轮上一处不平衡质量每转产生 1 次激励，为 1 阶；86 齿齿轮每转发生 86 次啮合事件，为 86 阶。无论转速如何变化，阶次数保持不变。

先看单根轴如何生成 1 阶数据。轴转速从 600 rpm 增至 6000 rpm：600 rpm 对应转频 10 Hz，6000 rpm 对应 100 Hz。在每个转速下测量一次幅值，将"频率—幅值—转速"关系绘入三维图：

![单轴升速：频率-幅值-RPM 三维图](/images/whats-an-order/first-order-3d.png)

*(图源：Simcenter Testing Knowledge Base)*

沿 RPM 方向以小步进补全数据（连续升速、逐转速计算频谱），即得 1 阶的完整轨迹。转速与频率之间为严格的比例关系，因此该轨迹在频率-RPM 平面上是一条过原点的直线。

## 二、阶次数的计算

### 基准轴与阶次比

手册给出的定义：**阶次数是每转事件数相对 1 阶（参考轴）之比**。

两根轴经皮带轮连接，A 轴直径为 B 轴的 3 倍：A 转 1 圈，B 转 3 圈。皮带传动无打滑时两轮线速度相等，直径与转速成反比，从动轴相对参考轴的阶次数为

$$
O_B = \frac{n_B}{n_A} = \frac{D_A}{D_B} = 3
$$

其中 $n_A$、$n_B$ 为两轴转速（rpm），$D_A$、$D_B$ 为两皮带轮直径（mm）。以 A 为参考轴扫 600→6000 rpm 时，B 的响应始终出现在参考轴转频的 3 倍处：A 在 600 rpm（转频 10 Hz）时 B 为 30 Hz，A 在 6000 rpm（100 Hz）时 B 为 300 Hz。B 的响应即 **3 阶**。

![皮带传动的两轴系统：直径比即转速比](/images/whats-an-order/two-shafts.png)

*(图源：Simcenter Testing Knowledge Base)*

反之，若转速计（tacho）装在 B 轴上，B 成为参考轴，A 的响应为 1/3 阶。参考轴互换时，阶次数互为倒数：

$$
O_{A|B} = \frac{1}{O_{B|A}}
$$

**阶次数的取值取决于参考轴的选择**——工程上由转速计的安装位置决定：Simcenter Testlab 自动把 tacho 所追踪的旋转部件设为 1 阶。tacho 装曲轴，曲轴为 1 阶；装发电机，发电机为 1 阶，其余所有阶次均相对它重新计算。对比两份阶次数据前，应先确认参考轴一致，否则阶次数不可比。

::: info 核心概念
- **阶次（Order）**：每转事件数相对参考轴（1 阶）之比
- **参考轴**：tacho 追踪的旋转部件，其每转 1 次的事件定义为 1 阶
- **阶次切（Order cut）**：沿某一阶次轨迹在 colormap/瀑布图上做的剖面，跟踪该阶次随 RPM 的幅值
:::

### 阶次不一定是整数

两级齿轮传动中，主动轴（蓝）转 60 rpm 时，从动齿轮（绿）的转动相对主动轴为 **1.625 阶**——传动比不是整数，阶次就不是整数。半阶与分数阶在发动机、变速器中常见，0.5 阶、1.5 阶属于正常数据。

四冲程发动机是分数阶的典型来源：曲轴每 **2 转**完成一个完整循环（进气、压缩、做功、排气各占 1 转），单缸四冲程机的燃烧事件为 1/2 阶。设缸数为 $N_{\mathrm{cyl}}$，每缸在 2 转内各点火 1 次，燃烧阶次为

$$
O_{\mathrm{comb}} = \frac{N_{\mathrm{cyl}}}{2}
$$

六缸机 $N_{\mathrm{cyl}} = 6$，$O_{\mathrm{comb}} = 3$ 阶。该阶次与转速无关——从怠速到最高转速，点火阶次始终为 3。

```python
import numpy as np

# 四冲程发动机的燃烧阶次
n_cyl = 6                          # 缸数
events_per_2rev = n_cyl            # 2 转内每缸各点火 1 次
order_comb = events_per_2rev / 2   # 阶次 = 每转事件数（相对曲轴）
print(f"六缸四冲程机 combustion order = {order_comb:.0f} 阶")

# 同一台发动机 3 阶在不同转速下的频率
for rpm in [800, 2000, 4000]:
    f = order_comb * rpm / 60
    print(f"  {rpm:5d} rpm -> {f:6.1f} Hz")
```

怠速 800 rpm 时 3 阶对应 40 Hz，4000 rpm 时对应 200 Hz——阶次不变，频率随转速线性变化。这是同一现象在两种坐标系下的表示。

## 三、阶次与频率的换算

频率和阶次是同一现象的两种度量，都是"观测帧内的事件数"：

- 频率：每秒事件数（观测帧 = 1 秒）
- 阶次：每转事件数（观测帧 = 1 转）

换算从定义出发分三步。

**第一步：转速换算为转频。** 每分钟转数除以每分钟的秒数（60），得到每秒转数，即转频：

$$
f_{\mathrm{rot}} = \frac{n}{60}
$$

其中 $n$ 为转速（rpm），$f_{\mathrm{rot}}$ 为转频（Hz）。600 rpm 的轴转频为 10 Hz，即每秒旋转 10 圈。

**第二步：阶次定义为事件频率与转频之比。** 比值即每转发生的事件次数：

$$
O = \frac{f_{\mathrm{event}}}{f_{\mathrm{rot}}}
$$

**第三步：两式合并**，得到由阶次和转速计算事件频率的换算式：

$$
f_{\mathrm{event}} = O \cdot \frac{n}{60}
$$

手册算例：600 rpm 处的 2 阶振动，$f = 2 \times 600 / 60 = 20\ \mathrm{Hz}$。

反过来，已知事件频率与转速可求阶次：$O = 60 f_{\mathrm{event}} / n$。手册中的几个算例汇总如下：

| 对象 | 转速 | 事件频率 | 阶次 |
| --- | --- | --- | --- |
| **6 叶风扇叶片通过** | 6000 rpm | 转频 100 Hz，叶片通过 600 Hz | $600/100 =$ **6 阶** |
| **86 齿齿轮啮合** | 600 rpm | 转频 10 Hz，啮合 860 Hz | $860/10 =$ **86 阶** |
| **六缸四冲程燃烧** | 任意 | — | **3 阶**（缸数/2，与转速无关） |
| **皮带从动轮（速比 3）** | 主动轮扫速 | — | **3 阶** |
| **齿轮从动轴（速比 1.625）** | 主动轮 60 rpm | — | **1.625 阶** |

风扇一例也可不经频率计算直接得出：主轴每转 1 圈必然发生 6 次叶片通过事件，叶片通过即为 6 阶。按事件计数与按频率计算的结果一致，前者步骤更少。

```python
import numpy as np

# 阶次 <-> 频率双向换算
def order_to_hz(order, rpm):
    return order * rpm / 60          # Hz = 阶次 * rpm / 60

def hz_to_order(freq, rpm):
    return freq / (rpm / 60)         # 阶次 = 事件频率 / 转频

# 86 齿齿轮 @ 1200 rpm
rpm = 1200
mesh_hz = order_to_hz(86, rpm)
print(f"86 阶 @ {rpm} rpm -> 啮合频率 {mesh_hz:.0f} Hz")

# 变速器里一个 1720 Hz 的峰，输入轴 2400 rpm，是几阶？
peak = 1720
print(f"1720 Hz @ 2400 rpm -> {hz_to_order(peak, 2400):.2f} 阶")

# 常用发动机阶次速查（曲轴参考）
print("曲轴参考下：怠速发火 0.5 阶，L4 发火 2 阶，L6 发火 3 阶，V8 发火 4 阶")
```

1720 Hz 的峰落在 43 阶上——处于主减齿轮副常见的齿数区间，下一步应核对传动系统齿轮参数。

::: warning 工程注意
colormap 建议切换为 dB 格式后再判读。线性幅值下，颜色动态范围被少数大峰占据，低幅值区域的阶次线难以分辨；dB 格式压缩动态范围后，阶次线（斜线）与共振线（竖线）的分界更清晰。此外，频率-阶次换算以"事件频率与转频严格成比例"为前提——液力变矩器打滑、皮带打滑都会使阶次线弯曲。发现弯曲的"阶次线"时，应优先排查打滑因素，再检查算法设置。
:::

## 四、阶次数据的显示：瀑布图与彩色图

阶次数据的标准显示是**瀑布图（waterfall）与彩色图（colormap）**：按小 RPM 步进逐帧计算自功率谱（autopower），沿 RPM 轴堆叠。瀑布图保留三维视角，每条沿频率轴的曲线即一个 RPM 切片的 autopower。

![瀑布图：逐转速切片的自功率谱堆叠](/images/whats-an-order/waterfall.png)

*(图源：Simcenter Testing Knowledge Base)*

将瀑布图的幅值轴转向纸面外、用颜色深浅表示幅值，即得 colormap：冷色对应低幅值，暖色对应高幅值，便于观察全局分布。

![彩色图：颜色即幅值](/images/whats-an-order/colormap.png)

*(图源：Simcenter Testing Knowledge Base)*

判读 colormap 只认两类特征：

| 特征 | 形状 | 含义 |
| --- | --- | --- |
| **阶次线** | 从原点出发的斜线 | 某部件每转 N 次事件的轨迹，频率 ∝ RPM |
| **共振线** | 沿频率轴的竖直亮带 | 结构固有频率，转速无关、阶次扫过时被激励 |

斜线与竖线的交点最值得关注：阶次扫过共振频率的转速即"问题转速"，轰鸣、啸叫、抖动等主观问题通常出现在该转速附近。定位交点后，用阶次切沿该斜线取剖面，得到该阶次随 RPM 的幅值曲线，再与整车主观评价的转速点对齐，即可为整改提供依据。

![阶次切：沿某阶次轨迹的剖面，跟踪其随 RPM 的幅值](/images/whats-an-order/order-cut.png)

*(图源：Simcenter Testing Knowledge Base)*

::: tip 实用建议
- 判读顺序：切换 dB 显示 → 找斜线（阶次）与竖线（共振）→ 锁定交点转速 → 对交点阶次做 order cut
- 阶次线弯曲、不过原点：排查打滑（变矩器、离合器、皮带）或参考轴选择错误
- 对比两份数据前，先核对 tacho 装在哪根轴上；参考轴不同，阶次数完全不同
:::

## 五、小结

阶次是对每转事件数的归一化，把随转速漂移的频率峰对应到具体部件上。核心换算式 $f = O \cdot n / 60$；四冲程发动机燃烧阶次为缸数/2（六缸即 3 阶）；齿轮啮合阶次等于齿数；传动链中每级速比直接进入阶次数。判读 colormap 时先切换 dB 显示，再找斜线（阶次线）与竖线（共振线）的交点，交点对应的转速即后续分析与整改的目标。
