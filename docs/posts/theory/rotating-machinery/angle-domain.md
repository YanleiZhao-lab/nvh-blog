# 角度域：把时间轴换成转轴看信号

> 变转速工况里，同一根轴的振动周期随 rpm 漂移，时域 FFT 只能得到一个展宽的峰。角度域（Angle Domain）把横轴从时间换成转角，让"每转发生一次"的事件重新变成严格周期——阶次接替频率成为新的坐标，循环平均接替谱平均成为新的滤波器。本文说明换轴的物理逻辑、时域与角域的对偶关系，以及这项变换的代价与收益。

## 一、时间轴为什么失灵

发动机从 600 rpm 升到 6000 rpm，曲轴转频从 10 Hz 涨到 100 Hz。曲轴上那颗不平衡质量每转激励一次，在时间轴上看，相邻两个振动峰的间隔从 100 ms 一路缩短到 10 ms——信号本身不再是周期函数，FFT 的前提（帧内平稳）被打破。

结果是频谱上出现一条被拖宽的"斜坡"：升速扫过的每个频率都贡献一点能量，1 阶成分展宽到 10~100 Hz 的整条频带上，幅值无法准确估计，各阶次之间也难以区分。

从另一个角度看：这些事件在**轴上**的位置从未改变。反光贴片每转都经过光学探头同一个位置，缸压峰值永远出现在压缩上止点附近。变的不是事件，是观察事件的时钟。

![升速工况下每转一次的事件：时域脉冲间隔越转越密，换到角域后严格等间距](/images/angle-domain/time-vs-angle-pulses.png)

*(图源：Simcenter Testing Knowledge Base)*

把横轴从时间换成转角，"每转一次"的事件立刻回到等间距排列。这就是角度域的全部动机：**用事件自身的周期性基准（转角）替代外部基准（时钟）**。设转速为 $n(t)$（单位 rpm），对转速积分得到累计转数：

$$\theta(t)=\int_{0}^{t}\frac{n(\tau)}{60}\,\mathrm{d}\tau \quad [\text{转}]$$

物理意义：转角是转速的时间积分，只要 $n(t)$ 已知（来自转速计通道），任一时刻的轴位置便唯一确定。转速波动被吸收进这层坐标变换里，信号重新变成周期函数，各类周期分析工具重新适用。等角度重采样在等角度栅格

$$\Delta\theta=\frac{1}{N_{spr}}\ \text{转}=\frac{360}{N_{spr}}\ \text{度}$$

上取值：反解 $\theta(t_m)=m\,\Delta\theta$ 得到各栅格点对应的时刻 $t_m$，再对信号插值 $x_a[m]=x(t_m)$。$N_{spr}$ 即每转采样数（samples per revolution），相当于角域里的"采样率"。

::: info 核心概念
- **角度域（Angle Domain）**：横轴为转角（度或转数）而非时间的数据表示，一转 360 度，四冲程发动机一个完整循环 720 度
- **时间域到角度域变换**：按转速-时间曲线积分出转角-时间映射，再把信号重采样到等角度栅格上
- **每转采样数（samples per revolution）**：角域栅格的角度增量，相当于角域里的"采样率"
- **同步/非同步成分**：与参考轴转速成整数倍关系的成分是同步的，换轴后对齐；其他成分在角域里逐转漂移
:::

## 二、换一根轴，整个分析体系跟着换

角度域不是时域的"另一种画法"，它是一套完整的对偶体系。频率轴上每个概念，在角域里都有对应物：

| 概念 | **时域/频域** | **角域/阶次域** |
| --- | --- | --- |
| 横轴 | 时间（秒） | 转角（度或转） |
| 周期性的基准 | 时钟：事件每 T 秒重复 | 转轴：事件每转重复 |
| 谱的横轴 | 频率 f（Hz，每秒周期数） | 阶次 O（每转周期数） |
| 采样栅格 | 等时间间隔，采样率 fs | 等角度间隔，每转 $N_{spr}$ 点 |
| Nyquist 限制 | fs/2 以上的频率混叠 | spr/2 以上的阶次混叠 |
| 变速的影响 | 谱峰随 rpm 滑动、拖宽 | 阶次位置不变，谱峰锁定 |
| 非同步干扰 | 固定频率，谱线不动 | 逐转漂移，能量发散 |
| 典型工具 | FFT、谱平均、频响函数 | 阶次谱、循环平均、谐波去除 |

表中信息量最大的一行是"变速的影响"。时域里转速一变，同一个物理成分在频谱上搬家；角域里它原地不动。反过来，与轴不同步的固定频率干扰（50 Hz 电力谐波、结构共振残留）在角域里成了"逐转漂移"的成分——位置关系整个翻转。

频率与阶次的换算关系连接两个域。从定义出发：阶次 $O$ 是每转的事件次数，转速 $n$（rpm）换算为每秒转数 $n/60$，两者相乘即每秒事件数，也就是频率：

$$f = O \cdot \frac{n}{60} \quad [\mathrm{Hz}]$$

600 rpm 下的 2 阶对应 20 Hz（Simcenter 手册算例：600 除以 60 得 10 Hz，再乘 2）；反过来，6000 rpm 下 6 叶风扇的叶片通过频率为 600 Hz，相对 100 Hz 的主轴转频是 6 阶。阶次与频率本质是同一现象的两种计数方式——一个按每转数，一个按每秒数。

采样栅格一行的对偶同样有公式可依：角域的 Nyquist 准则是

$$O_{\max}=\frac{N_{spr}}{2}$$

每转 $N_{spr}$ 个采样点，$N_{spr}/2$ 以上的阶次将发生混叠——这与时域 $f_s/2$ 的限制在形式上完全一致。

## 三、Python 演示：换轴前后的频谱对比

模拟一台从 900 rpm 匀加速到 12900 rpm 的机器，信号里含 1 阶（不平衡）与 4 阶（每转激励 4 次，如八缸四冲程发动机的点火）两个成分。先在时域做 FFT，再重采样到等角度栅格上做"阶次谱"：

```python
import numpy as np

fs = 20000                                # 定采样率
t = np.arange(0, 4.0, 1/fs)
rpm = 900 + 3000*t                        # 匀加速：900 -> 12900 rpm
f_rot = rpm/60
phase = 2*np.pi*np.cumsum(f_rot)/fs       # 累计转角
sig = np.sin(phase) + 0.5*np.sin(4*phase) # 1阶(不平衡) + 4阶(每转4次激励)

# --- 时域 FFT：变转速把阶次拖成宽峰 ---
N = 8192; win = np.hanning(N)
S_t = np.abs(np.fft.rfft(sig[:N]*win)); fr = np.fft.rfftfreq(N, 1/fs)
band = fr[S_t > 0.2*S_t.max()]
print(f"时域FFT：>20%max 谱线散布 {band.min():.0f}~{band.max():.0f} Hz（宽 {band.max()-band.min():.0f} Hz）")

# --- 等角度重采样（每转128点）再做"阶次谱" ---
spr = 128
n_rev = int(phase[-1]/(2*np.pi))
ang = np.arange(n_rev*spr)*(2*np.pi/spr)
sig_ad = np.interp(np.interp(ang, phase, t), t, sig)

S_a = np.abs(np.fft.rfft(sig_ad[2048:2048+N]*win)); ordr = np.fft.rfftfreq(N, 1/spr)
k = np.where((S_a[1:-1] > S_a[:-2]) * (S_a[1:-1] > S_a[2:]) * (S_a[1:-1] > 0.3*S_a.max()))[0] + 1
print("角域FFT：峰位置", "、".join(f"{ordr[i]:.2f} 阶" for i in k))
```

运行结果要点：时域 FFT 的谱线散布 17~112 Hz、拖成 95 Hz 宽的斜坡，幅值无从谈起；换到每转 128 点的角域栅格后，峰精准落在 1.00 阶和 4.00 阶。同一份数据，只换了横轴，成分归属问题随之解决。

重采样的实现也值得注意：转速曲线积分出累计转角 phase(t)，它单调递增，反查出每个等角度栅格点对应的时刻，再对信号做插值——工程软件中的角度域变换，核心即是这一步（对应第一节中 $\theta(t)$ 与 $x_a[m]=x(t_m)$ 两式）。

## 四、换轴的代价：三项工程注意

::: warning 工程注意
- **转速通道质量决定角域精度。** 角度栅格完全由转速通道反推而来，转速计漏脉冲、毛刺、量化过粗，误差直接写进角域数据的相位里。换轴前先清洗 RPM 曲线。
- **每转点数封顶最大阶次。** 角域的 Nyquist 准则是 $N_{spr}/2$：每转 128 点，64 阶以上开始混叠。Simcenter 手册中谐波去除的最大可去除阶次同样取 samples_per_rev 的一半。若需分析齿轮啮合等上百阶成分，应相应增大每转采样数。
- **四冲程循环为两转（720 度）。** 一转 360 度，一个完整工作循环却是两转。循环定义（cycle_definition）填错，逐循环平均会把相邻循环错位相加，缸压对不齐、相位统计失效。
:::

还有一个不那么直观的事实：非整数阶在角域里并不"锁定"。2.3 阶每转发生 2.3 次，转与转之间相位持续漂移——它对 1 阶轴是非同步成分。这既是限制，也提供了分离手段。

## 五、角域的收益：循环平均的同步滤波效应

同步成分（整数阶）在角域里逐转对齐，非同步成分逐转漂移。把多个循环按转折叠、逐角度点求平均，对齐的留下、漂移的互相抵消。这个效应可以定量推导。设角域中某成分的阶次为 $O=k+\delta$（$k$ 为整数部分，$0<\delta<1$ 为小数部分），以转为单位的角度变量为 $\theta$：

$$x(\theta)=\hat{x}\,\sin\!\left(2\pi\left(k+\delta\right)\theta\right)$$

第 $j$ 转带来的相移为 $2\pi\left(k+\delta\right)j$，其中整数部分 $2\pi k j$ 是 $2\pi$ 的整倍数、不影响相位，有效相移仅剩 $2\pi\delta j$——非同步性完全由小数部分 $\delta$ 决定。对 $N$ 转求循环平均（cycle averaging），相当于对 $N$ 个等相位步长 $2\pi\delta$ 的正弦分量求和：

$$\bar{x}(\theta)=\frac{\hat{x}}{N}\sum_{j=0}^{N-1}\sin\!\left(2\pi\left(k+\delta\right)\theta+2\pi\delta j\right)$$

用相量（几何级数）求和并取模，得到平均后与平均前的幅值比：

$$\frac{\left|\bar{x}\right|}{\hat{x}}=\frac{\left|\sin\!\left(N\pi\delta\right)\right|}{N\,\left|\sin\!\left(\pi\delta\right)\right|}\;\le\;\frac{1}{N\,\left|\sin\left(\pi\delta\right)\right|}$$

物理意义：$\delta=0$（整数阶，同步成分）时分式极限为 1，$N$ 个相量同相相加，幅值原样保留；$\delta\neq 0$ 时幅值按 $1/N$ 量级衰减。**循环平均在角域中的作用等价于一组以参考轴为基准的梳状滤波器：整数阶通过，非整数阶按上式衰减。**

Simcenter Testing 知识库中的示例：信号含 1 阶和 2.3 阶，滑动窗口取 10 个循环做平均，1 阶稳稳留在平均循环里，2.3 阶被平均掉；把平均循环逐转扣除，剩下的就是干净的 2.3 阶。

![滑动循环平均：与轴同步的 1 阶留在平均里，2.3 阶被平均掉](/images/angle-domain/sync-average.png)

*(图源：Simcenter Testing Knowledge Base)*

![平均循环逐转扣除后，时域里只剩 2.3 阶](/images/angle-domain/nonsync-remains.png)

*(图源：Simcenter Testing Knowledge Base)*

用 numpy 复现这套"平均—扣除"流程：

```python
import numpy as np

spr, n_rev = 32, 103                      # 每转32点，共103转
ang = np.repeat(np.arange(n_rev), spr)*360 + np.tile(np.arange(spr)*360/spr, n_rev)
sig = np.sin(np.deg2rad(2*ang)) + 0.6*np.sin(np.deg2rad(2.3*ang))  # 2阶+2.3阶

# 循环平均：按转折叠成矩阵，逐角度求平均
avg = sig.reshape(n_rev, spr).mean(axis=0)
resid = sig - np.tile(avg, n_rev)

# 单频 DFT 量各阶幅值：角域里阶次就是"每转周期数"
amp = lambda x, o: 2*abs(np.mean(x*np.exp(-1j*np.deg2rad(o*ang))))
print(f"平均循环：2阶 {amp(np.tile(avg,n_rev),2):.3f}（设计 1.000）| 2.3阶泄漏 {amp(np.tile(avg,n_rev),2.3):.4f}")
print(f"残差：2.3阶 {amp(resid,2.3):.3f}（设计 0.600）| 2阶残留 {amp(resid,2):.4f}")
```

运行结果要点：103 个循环平均后，同步的 2 阶幅值 0.998（设计值 1.000），非同步的 2.3 阶泄漏只剩 0.003——与上式的预估一致（本例 $N=103$、$\delta=0.3$，理论幅值比 0.0037，对应 0.6 幅值成分残留约 0.002，实测 0.003，同一量级）；扣除平均后，残差里 2.3 阶 0.600 与设计值一致、2 阶残留 0.0000。这就是 Simcenter Testlab 里 HARMONIC_FILTER 谐波去除（harmonic removal）功能的数学内核——具体的软件操作路径，见《[谐波去除：从信号中剥离已知干扰](../../practice/data-processing/harmonic-removal.html)》。

平均用的循环数还有一层分辨率含义。对长度为 $N_{cyc}$ 转的记录做阶次谱分析，谱线间隔即最小可分辨的阶次差：

$$\Delta O=\frac{1}{N_{cyc}}\quad[\text{阶}]$$

Simcenter 手册对谐波去除的 nr_of_cycles_for_avg 参数同样给出该定义：10 个循环的平均对应 0.1 阶分辨率——循环越多分得越细，但窗口拉长后对转速突变的跟踪能力下降，两者按数据长度权衡。

## 六、什么时候该切到角域

::: tip 使用判断
- 变转速工况 + 关心"哪根轴/哪个部件"的贡献：角域是默认选择，colormap 上的阶次线分析全建立在这根轴上
- 稳态工况、关心结构共振与定频干扰：时域/频域更直接，没必要绕一道重采样
- 需要逐循环统计（缸压峰值、燃烧变差、每循环最大抖动）：必须进角域，详见《[逐循环平均：发动机工况数据处理](../../practice/data-processing/cycle-cycle-averaging.html)》
- 剥离已知轴系的整数阶干扰：角域循环平均 + 扣除，即谐波去除
- 定采样与同步采样两条进阶路线的取舍，另见《[阶次跟踪两种采样：定采样 vs 同步采样](./order-tracking-sampling.html)》
:::

## 七、小结

角度域的本质是一次基准切换：把"每秒发生几次"换成"每转发生几次"，转速波动从信号里搬进坐标变换里。换轴的代价是重采样插值和对转速通道的完全依赖，收益是阶次锁定、循环对齐、循环平均构成同步梳状滤波器。判断准则只有一条——激励事件随转轴重复，就应在转轴坐标系下分析它。
