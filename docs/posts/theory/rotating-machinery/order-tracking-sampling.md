# 阶次跟踪两种采样：定采样 vs 同步采样

> 变转速工况下要获得准确的阶次幅值，先要回答：数据是等时间间隔采集的，还是等角度间隔采集的？定采样配合转速重采样是当前主流方案，同步采样在扭振高阶测量中仍不可替代。本文给出两种路线的原理差异、最大阶次上限的计算方法与选型判据。

## 一、问题的根源：转一转，到底采几个点

一台发动机从 1000 rpm 升到 4000 rpm，曲轴转频（rotational frequency）从 16.7 Hz 升至 66.7 Hz。同一个 2 阶成分，频率从 33 Hz 滑到 133 Hz——在频谱上这是一条斜线，不是一个定点。阶次与频率、转速的关系为

$$f = k \cdot \frac{n}{60} \quad [\mathrm{Hz}]$$

其中 $n$ 为转速（rpm），$k$ 为阶次（无量纲，定义为每转周期数）。

采样时钟却与转速无关。ADC 按固定采样率（如 10 kHz）等间隔取样，一转之内的采样点数完全由当时转速决定：1000 rpm 时一转 600 个点，4000 rpm 时只剩 150 个。若要在「角度均匀」的栅格上分析（如逐循环平均、角度域统计），定采样数据必须先经过一道**重采样**：从时间域换算到角度域。

同步采样把这件事反过来做：让采样时钟跟随转轴。编码器每转给出固定的脉冲数（PPR），每来一个脉冲采一个点，采样栅格天然按角度均匀。阶次在这个栅格里就是「每转周期数」，与转速解耦。

::: info 核心概念
- **定采样（fixed sampling）**：等时间间隔采集，采样率恒定；后续靠转速计曲线插值重采样到角度域
- **同步采样（synchronous sampling）**：等角度间隔采集，每转采样点数恒定；阶次即「每转周期数」
- **PPR（pulses per revolution，每转脉冲数）**：转速计或编码器每转输出的脉冲数，决定角度域栅格密度
- **重采样（resampling）**：按转速-时间曲线把定采样数据插值到等角度栅格，Simcenter Testlab 中由 Order Tracking 模块完成
:::

## 二、定采样的局限与同步采样的阶次上限

### 定采样靠重采样进入角度域

重采样的原理：转速计脉冲给出转速-时间函数 $n(t)$（单位 rpm），积分得到转角-时间函数；在角度域按固定步长 $\Delta\alpha$ 取参考点 $\alpha_i$，反查出对应时刻 $t_i = \alpha^{-1}(\alpha_i)$，再用插值取出该时刻的信号值：

$$\alpha(t) = 2\pi \int_0^t \frac{n(\tau)}{60}\, \mathrm{d}\tau \quad [\mathrm{rad}]$$

其中 $\tau$ 为积分哑变量（s）。

代价在插值环节。Simcenter 的实现是先升采样（插值前升采样因子默认 $R = 15$）再做线性插值、最后降采样，插值误差由**信号失真比 SDR（Signal to Distortion Ratio，单位 dB）**刻画（LMS 理论手册 11.1.4 节）：

$$SDR = 10 \log_{10} \left( \frac{80\, R}{\pi \cdot f_c\% / 100} \right) \quad [\mathrm{dB}]$$

其中 $R$ 为插值前升采样因子（无量纲，默认 15），$f_c\%$ 为滤波器截止频率相对于奈奎斯特频率的百分比（%）。$R$ 越大、$f_c\%$ 越低，失真越小——这是用计算量换取精度的定量关系。

另一条约束来自最低转速：角度分辨率必须按全程最低转速设计。手册给出的判据——设最低转速 500 rpm、采样率 $f_s = 2000$ Hz，则角度增量阈值

$$\Delta\alpha_{\max} = \frac{360^\circ \times 500/60}{2000} = 1.5^\circ$$

对应每转 240 点。采用小于阈值的角度增量只增加数据量而不增加信息；采用大于阈值的增量，最低转速段的信息即告损失，且转回时间域也无法恢复。最低转速处的「每转采样点数」最先不足，信息损失从那里开始。

### 同步采样的上限由 PPR 决定

编码器直接采样时，角度域的奈奎斯特（Nyquist）准则是：**最大可分析阶次 = PPR / 2**。手册的算例：要测量 60 阶扭振，至少需要 120 PPR。

![120 PPR 采样下，60 阶以上区域（深蓝）已无任何阶次信息](/images/order-tracking-sampling/max-order-ppr.png)

*(图源：Simcenter Testing Knowledge Base)*

PPR 通道**没有抗混叠保护**——它不经过模拟抗混叠滤波器，阶次超出 PPR/2 的成分同样会折叠进来混充低阶。因此实际选型普遍再乘 10 倍安全系数：测 60 阶，选 600 PPR 的编码器或斑马带。

![同一次 RPM 升速测量：1 PPR（黑）未捕捉到扭振，120 PPR（红）捕捉到每转之内的转速波动](/images/order-tracking-sampling/torsional-ppr-compare.png)

*(图源：Simcenter Testing Knowledge Base)*

上图说明 PPR 不足的直接后果：扭振是每转之内的转速波动，1 PPR 每转只给一个转速样本，转内波动完全丢失；120 PPR 才能还原转内波动。高 PPR 的实现通常靠光电传感器配合斑马带或斑马盘——每条白线对应一个脉冲，PPR 由条纹密度决定：

![斑马盘：40 刻度与 100 刻度两种规格](/images/order-tracking-sampling/zebra-disk-ppr.png)

*(图源：Simcenter Testing Knowledge Base)*

::: warning 工程注意
同步采样最易被忽略的风险在低速段。每转点数固定，转速升高时等效时间采样率同步升高，高频信息只会更充裕；真正的损失在低速，若角度分辨率按最低转速设计过粗，角度域信息在低速段已经丢失，转回时间域也无法恢复。选 PPR 前先计算：关心的最高阶次乘 2，再乘安全系数。
:::

## 三、两条路线怎么选

| 维度 | **定采样 + 重采样** | **同步采样（编码器直采）** |
| --- | --- | --- |
| 采样栅格 | 等时间间隔 | 等角度间隔 |
| 硬件门槛 | 普通转速计（1 PPR 即可） | 高 PPR 编码器或斑马带 + tacho 通道 |
| 最大阶次 | 受采样率与插值质量限制，一般到几百阶 | PPR/2（无混叠保护，实际留 10 倍余量） |
| 幅值精度 | 依赖重采样插值，SDR 可量化 | 栅格原生对齐，无插值损失 |
| 扭振与高阶 | 可用但需高采样率支撑 | **首选**，齿轮啮合、传动系扭振标准做法 |
| 灵活性 | 一次采集，时间域角度域可反复切换 | 数据天然在角度域，回时间域需再插值 |
| 适用场景 | 整车路试、通用 NVH 扫描 | 变速箱台架、扭振专项、逐循环分析 |

::: tip 选择原则
- 默认路线：定采样加 Order Tracking 重采样，硬件要求低、数据可逆，覆盖绝大多数整车与动力总成 NVH 场景
- 扭振专项、齿轮啮合高阶（大于 20 阶）专项：上同步采样，PPR 至少为目标阶次的 20 倍（奈奎斯特下限 2 倍再乘安全系数 10 倍）
- 转速波动剧烈的工况（急加减档、瞬态），重采样插值误差被放大，优先考虑同步直采
- 已有数据要补充角度域分析：先确认转速计质量与全程最低转速，再确定角度分辨率
:::

## 四、Python 演示：重采样改变了什么

```python
import numpy as np
np.random.seed(0)

# 模拟一段变速工况：转频 1 Hz -> 3 Hz 线性上升
fs = 100.0                      # 定采样率 Hz
t = np.arange(0, 4.0, 1/fs)     # 4 秒
# 累计转角(rad) = 转频的积分，再乘 2*pi
angle = 2*np.pi*(1.0*t + 0.5*t**2)

# 振动信号 = 3 阶成分（每转 3 次）+ 少量噪声
sig = np.sin(3*angle) + 0.05*np.random.randn(len(t))

# --- 重采样到角度域：每转固定 32 个点 ---
N_ppr = 32
angle_grid = np.arange(0, angle[-1], 2*np.pi/N_ppr)
sig_angle = np.interp(angle_grid, angle, sig)

# 在角度域提取 3 阶：取 3 整转做单频相关解调
seg = sig_angle[:3*N_ppr]
k = np.arange(len(seg))
est = 2*np.sum(seg*np.exp(-1j*2*np.pi*3*k/N_ppr))/len(seg)
print("总转数: %.1f, 角度域点数: %d" % (angle[-1]/(2*np.pi), len(sig_angle)))
print("每转点数恒为 %d, 与转速无关" % N_ppr)
print("3 阶幅值: |A| = %.3f (理论值 1.000)" % abs(est))
```

运行结果：总转数 12.0、角度域点数 383，每转点数恒为 32（与转速无关）；3 阶幅值恢复为 0.997（理论值 1.000，含噪声与插值误差）。在角度域栅格里，变速工况下的阶次成分被「冻结」为固定频率的周期信号——这就是阶次分析在角度域进行的原因。

## 五、小结

判断标准两条：一是最高关心阶次，二是转速波动烈度。阶次高、波动大、要求精确幅值时采用同步采样，PPR 按目标阶次的 20 倍选取（奈奎斯特下限 2 倍乘安全系数 10 倍）；其余场景定采样加重采样即可满足，硬件预算优先投在转速计信号质量上。
