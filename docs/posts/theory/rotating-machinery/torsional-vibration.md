# 扭转振动：旋转机械角速度波动的基本概念、测量判据与阶次诊断

> 扭转振动（Torsional Vibration）是旋转部件角速度围绕稳态转速的交变波动，叠加在平均转速之上。本文依据 Simcenter Testing Knowledge Base 的表述给出其定义与危害、PPR（Pulses Per Revolution，每转脉冲数）与最高可分辨阶次的定量关系、点火阶次与曲轴扭振共振的判读方法，以及 Simcenter Testlab 的四项数据处理要点。

## 一、转速曲线中的角速度波动

考察一条四缸机从 1000 RPM 升至 3500 RPM 的转速曲线，总体趋势为单调上升；将时间轴放大到单个旋转周期内部，可见转速并非恒定值，而是在一个转角周期内反复波动，波动量可达 100 RPM 量级。

这就是扭转振动（Torsional Vibration）的定义：**旋转部件角速度围绕稳态转速的交变波动**，这些波动叠加在稳定运行转速之上。它是旋转系统中除横向振动、轴向振动之外的第三个运动自由度，也最容易被遗漏：常规加速度传感器安装在轴承座上，其敏感方向对扭转运动不敏感，横向振动测量不能替代扭振测量。

设瞬时角速度为 $\omega(t)$（单位 rad/s），平均角速度为 $\bar{\omega}$（rad/s），角速度波动量为 $\Delta\omega(t)$（rad/s），则扭转振动的定义为

$$\omega(t) = \bar{\omega} + \Delta\omega(t), \qquad \bar{\omega} = \frac{1}{T}\int_0^T \omega(t)\,\mathrm{d}t$$

式中 $T$（s）为取平均的时间窗。扭振分析的对象即波动项 $\Delta\omega(t)$。

车速表指针看似平稳的原因在于：仪表大约每转才刷新一次，恰好将一转之内的波动全部平均掉。若仪表采样更快，转速波动将直接显现，用户可能据此认为"发动机运行不稳"而送修——平稳的观感部分来自采样率的限制，而非角速度恒定。

用一段模拟程序验证"每转采样次数"如何决定扭振能否被观测：

```python
import numpy as np

rpm0 = 2000.0                          # 稳态转速
f_rot = rpm0 / 60                      # 转频 Hz
# 四缸机 2 阶点火激励，叠加正负 25 RPM 的转速波动
wave = lambda t: rpm0 + 25.0*np.sin(2*np.pi*2*f_rot*t)

for ppr in [1, 10, 120]:
    # 每转 ppr 个脉冲 = 每秒 ppr*f_rot 个采样点
    fs = ppr * f_rot
    tp = np.arange(0, 0.2, 1/fs)
    rpm_s = wave(tp)
    print(f"PPR={ppr:>3} | 采样点数={rpm_s.size:>4} | 测得波动峰峰值={rpm_s.max()-rpm_s.min():5.1f} RPM")
```

PPR=1 时每个采样点都落在同一转角相位上，测得波动峰峰值为 0——真实存在的正负 25 RPM 扭振完全未被记录。PPR=10 起波动才被完整还原。扭振测量的前提由此确定：**一转之内有信息，一转只采一次则无信息**。

## 二、激励来源与危害

几乎所有旋转机械的角速度都不是绝对恒定的，激励来源随机型而异：

| 机械类型 | 扭振机理 | 阶次特征 |
| --- | --- | --- |
| **内燃机** | 各缸燃烧爆发推动曲轴加速，两次燃烧之间惯性使其减速 | 点火阶次主导（四缸机为 2 阶） |
| **电机** | 磁极离散，每转经过固定数目的磁极产生转速脉动 | 与极数相关的低阶次 |
| **液压泵/马达** | 液体以不均匀的速率进出各工作腔，转速随之脉动 | 与柱塞/齿轮/叶片数相关的高阶次 |

危害横跨四个维度：

- **耐久性**：弹性联轴器磨损、齿轮磨损、曲轴与传动系提前疲劳——燃烧引起的转速交变构成轴系上的循环疲劳载荷；
- **舒适性**：扭振经传动系传至方向盘、座椅、踏板，表现为低速抖动；
- **噪声**：齿轮啸叫（gear whine）、离合器颤振（chatter）；
- **同步性能**：同步类机构工作质量下降、油耗恶化。

低速段抖动投诉、找不到振源的齿轮啸叫、台架上提前磨损的联轴器——遇到此类问题，扭振阶次分析应列入排查项目。

## 三、测量方法：PPR 是关键设置

扭振测量的本质不是"测振动"，而是**高频响地测转速**：对每转 N 个脉冲的转速信号做分析，扭振信息记录在脉冲间隔的微小变化中。两类常用传感器：

| 方案 | PPR 上限 | 优点 | 限制 |
| --- | --- | --- | --- |
| **磁电传感器（magnetic pickup）+ 齿轮** | 齿数 | 坚固、便宜、对环境粉尘不敏感 | PPR 被齿数锁定，无法加密 |
| **光学传感器 + 斑马带/斑马盘（zebra tape/disk）** | 条纹数（可自选） | PPR 可按需要设置得很高 | 接缝（butt joint）会引入假波动 |

同一台四缸机的同一条升速曲线，120 PPR 测得的红色曲线完整记录了一转之内的转速波动，1 PPR 的黑色曲线只剩一条平滑斜线——低 PPR 造成的不是"精度差一点"，而是整个扭振频段的信息缺失。

![1 PPR 与 120 PPR 测同一条升速曲线的对比](/images/torsional-vibration/ppr-compare.png)

*低 PPR（黑色）未记录到扭振，高 PPR（红色）记录到旋转周期内的转速波动（图源：Simcenter Testing Knowledge Base）*

PPR 的取值判据：**每转脉冲数必须至少是最高关心阶次的 2 倍**——测 60 阶扭振至少 120 PPR。实践中常再乘 10 倍安全系数，原因是阶次域的"采样"没有抗混叠滤波器，欠采样不会使高阶变模糊，而是直接折叠出假阶次。定量表述如下：设每转脉冲数为 $N_{PPR}$（无量纲），转频为 $f_{rot}$（Hz），则等效采样率为

$$f_s = N_{PPR}\, f_{rot}$$

可分辨的奈奎斯特阶次（Nyquist Order）$O_{max}$ 为

$$O_{max} = \frac{N_{PPR}}{2}$$

真实阶次 $O$ 超过 $O_{max}$ 时，观测阶次按取模与镜像折叠计算：先取余数 $r = O \bmod N_{PPR}$，当 $r \le N_{PPR}/2$ 时观测阶次即 $r$，当 $r > N_{PPR}/2$ 时观测阶次为镜像值 $N_{PPR} - r$。用程序验证折叠行为：

```python
import numpy as np

ppr = 120.0            # 每转 120 个脉冲，可分辨上限 = 60 阶
for order in [2, 30, 60, 61, 90, 119]:
    fold = order % ppr
    if fold > ppr/2:                # 超过奈奎斯特阶次，镜像折叠
        fold = ppr - fold
    print(f"真实 {order:>3.0f} 阶  ->  观测为 {fold:>4.0f} 阶")
```

90 阶一行给出典型后果：PPR=120 时它不消失，而是表现为一条 30 阶线。若正在排查 30 阶齿轮啸叫，这条折叠出的假阶次线会将排查方向带偏。PPR 不足时的图谱特征是：colormap 高阶区无数据，阶次切片在奈奎斯特阶次处截止——观察到该特征应检查 PPR 设置。

::: warning 工程注意
高 PPR 带来高数据率：每转 120 脉冲、6000 RPM 时脉冲频率达 12 kHz，转速通道的采集带宽与记录吞吐需按此量级配置；普通转速通道按常规 tacho 信号处理会丢失信息。Simcenter SCADAS 前端的专用高性能 tacho 输入（含直流或 ICP 供电；RV4 模块可同时接入四路高脉冲率转速流，支持离线或实时处理）即为此场景设计。
:::

## 四、扭振阶次：从转速数据到 NVH 诊断

获得高 PPR 转速数据后，对转速波动量做阶次分析（与对振动信号做 colormap 的流程相同），得到扭振阶次。四缸机升速的扭振 colormap 上，2 阶及其谐波占主导——2 阶正是该四缸机的点火阶次（Firing Order）：曲轴每转经历两次燃烧事件，在"被推动—惯性减速"之间循环。点火阶次通常是发动机扭振的主导阶次。

![四缸机扭振 colormap（左）与 2 阶扭振随转速的切片（右）](/images/torsional-vibration/torsional-colormap.png)

*2 阶及其谐波为主导阶次；右侧切片中扭振随转速升高而减小，仅在曲轴共振（约 2600 RPM）附近出现峰值（图源：Simcenter Testing Knowledge Base）*

右侧阶次切片包含两条规律。

**其一，转速越低扭振越大。** 转速低意味着两次燃烧之间的时间间隔长，曲轴在间隔内减速得更深，波动幅度更大。对应的推论：缸数越少，每转燃烧事件越少、间隔越长，扭振越大——三缸机大于四缸机，单缸机最严重。

**其二，约 2600 RPM 处有一个突出的峰。** 低转速段扭振随转速升高整体下降，2600 RPM 附近出现逆势凸起的共振包。共振频率与转速的关系为：2 阶激励频率 $f_2 = 2 \times rpm/60$ 随转速线性扫过曲轴扭振固有频率 $f_n$，在 $f_2 = f_n$ 处响应放大。单自由度系统的无量纲放大因子为

$$H(f) = \frac{1}{\sqrt{\left[1 - \left(\dfrac{f}{f_n}\right)^2\right]^2 + \left[2\zeta\,\dfrac{f}{f_n}\right]^2}}$$

式中 $\zeta$（无量纲）为阻尼比，$f_n$（Hz）为扭振固有频率。用该模型复现阶次切片形状：

```python
import numpy as np

rpm  = np.linspace(1000, 3500, 51)        # 转速点
f2   = 2 * rpm / 60.0                     # 2 阶激励频率 Hz
fn, zeta = 86.7, 0.05                     # 扭振固有频率(对应约2600RPM)与阻尼比
mag  = 1.0/np.sqrt((1-(f2/fn)**2)**2 + (2*zeta*f2/fn)**2)
base = 6000.0 / rpm                       # 低速段更大：燃烧间隔长，减速深
tors = base + 8.0*mag/mag.max()           # 两种机理叠加

for r, f, a in zip(rpm[::10], f2[::10], tors[::10]):
    print(f"转速 {r:>5.0f} RPM | 2阶激励 {f:5.1f} Hz | 扭振幅值 {a:5.2f} RPM")
print(f"扭振峰值出现在 {rpm[tors.argmax()]:.0f} RPM")
```

输出中 1000 RPM 处约 6.9 RPM，随转速升高在 1800 RPM 左右降到谷值，2600 RPM 处回升至约 10.3 RPM 的峰值，之后再次回落——实测曲线即该形状：整体下降叠加一处共振包。

**诊断流程**：在司机右耳（DRE，Driver Right Ear）布置话筒，2 阶声压切片在 2600 RPM 附近同样存在 dB 峰。仅看噪声数据，该峰的来源存在多种可能；将 2 阶扭振曲线叠加到同一坐标系，两峰转速对齐——噪声峰的来源即曲轴扭振共振。

![DRE 处 2 阶噪声与 2 阶扭振叠图，2600 RPM 处两峰对齐](/images/torsional-vibration/dre-overlay.png)

*两峰对齐表明 DRE 处 2 阶声压峰由曲轴扭振共振贡献（图源：Simcenter Testing Knowledge Base）*

这就是扭振阶次的核心用途：**判定扭振是否驱动了产品的噪声/振动水平**。叠图对齐，应检查轴系扭振模态；对不齐，扭振排除，转查其他传递路径，避免在错误方向上投入。

::: tip 判读要点
- 扭振 colormap 上先找点火阶次及其谐波：点火阶次是发动机扭振的主导阶次；
- 阶次切片上逆着"随转速下降"趋势凸起的包，对应轴系扭振共振，记下转速换算成频率；
- 噪声/振动的阶次峰与扭振峰转速对齐，即可确认因果关系的存在。
:::

## 五、Testlab 实操要点

**通道设置一通道两用。** Channel Setup 里把转速通道的 ChannelGroupId 从 Tacho 改成 Vibration，同一通道同时产出转速数据与"振动"数据——无需物理分路接两个通道，即可直接对 throughput 数据做 colormap 和阶次切片。

**纵轴量纲可切换。** 右键纵轴、Processing、Integrate (Single)，转速波动积分成扭振角位移（角度）；评估轴系疲劳与联轴器变形时，角位移是更直接的量纲。同一菜单的 Section Scaling 里可切换 RMS / Peak / Peak-Peak 格式。

**扭振可做 ODS 动画。** Geometry 工作表的 Torsional node 子工作表里 Add Disc 添加旋转件圆盘节点（输入节点名、半径与朝向），之后扭振的谱、阶次、时域数据都能像普通几何一样做 ODS 动画，用于观察各圆盘之间的相对扭转。

**斑马带接缝需修正。** 斑马带缠轴收尾处的搭接缝（butt joint）每转产生一次假的转速骤降或尖峰，属于系统性伪影；Testlab Time Signal Calculator 的 ZEBRA_MOMENTS_TO_RPM 函数（Tacho 函数组，需填入 Pulses_per_rev 字段）可以扣除，16A 版本起支持多接缝。接缝与脉冲毛刺的完整清洗流程，另见《[RPM 信号去毛刺：转速信号的清洗](../../practice/data-processing/rpm-spike-removal.html)》。

## 六、小结

扭振是角速度的交变波动，叠加在平均转速之上，横向振动测量不能替代。工程判断三条线：测——PPR 至少取最高关心阶次的 2 倍，实际留 10 倍余量，PPR 不足时高阶折叠成假阶次而非消失；看——发动机扭振以点火阶次为主导，低转速段幅值更大，切片上逆势凸起的包对应轴系扭振共振；断——把扭振阶次与车内噪声阶次叠图，峰转速对齐才能确认因果关系。
