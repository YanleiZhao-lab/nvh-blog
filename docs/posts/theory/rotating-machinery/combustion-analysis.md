# 燃烧分析：缸压与放热率的测量链路

> 缸内压力是发动机唯一同时携带"载荷、燃烧进程、做功能力"三条信息的测量量：它既是结构强度与 NVH 的激励源，又通过热力学第一定律换算出放热率与燃烧相位。本文从四冲程循环与曲轴转角基准讲起，推导气缸容积、多变压缩、Rassweiler-Withrow 放热分析与 CA50 等燃烧相位指标，最后落到 Simcenter Testlab 角域采集与逐循环统计的完整测量链路。

## 一、为什么缸压是燃烧分析的起点

发动机 NVH 工程师关心燃烧，不是转行去做热力学，而是因为**燃烧是发动机里最"猛烈"的事件**（Simcenter 手册原话：Combustion is the most "violent" event in an engine）。混合气在几毫秒内完成点火与火焰传播，缸内压力从几十 bar 的压缩压力冲到 50~100 bar 的峰值，再通过活塞、连杆、曲轴一路传出去——整车怠速抖动、加速轰鸣、变速箱敲击，源头多半要追到这里。

先看一张整车层面的证据。下图是 Simcenter 手册中一辆四缸车驾驶员耳旁噪声的 colormap（彩色图谱）：横轴转速、纵轴频率、颜色幅值。最亮的斜带是 **2 阶（2nd order）**——一条随转速成正比移动的线，在 3000~3500 rpm 和 4800 rpm 以上两片区域幅值最高。

![四缸车驾驶员耳旁噪声 colormap：2 阶成分幅值最高，3000~3500 rpm 与 4800 rpm 以上两片区域突出](/images/combustion-analysis/fig1-order-colormap.png)

*(图源：Simcenter Testing Knowledge Base)*
**阶次（Order）** 的定义：与转轴每转事件次数挂钩的振动频率计数，$f = O \cdot n/60$（$n$ 为 rpm）。四冲程发动机每缸每 2 转燃烧一次，四缸机每转完成 $4/2 = 2$ 次燃烧，因此燃烧激励天然落在 **2 阶**——3000 rpm 时对应 $2 \times 3000/60 = 100\ \mathrm{Hz}$。上图里那条最亮的斜线，就是四个气缸轮流打点的合力。

![四缸四冲程发动机：曲轴每转发生 2 次燃烧事件（红色爆炸标记），对应 2 阶激励](/images/combustion-analysis/fig2-combustion-events.png)

*(图源：Simcenter Testing Knowledge Base)*

要注意"每转 2 次燃烧"不等于"四个缸每转都烧"。四冲程机一个完整循环要 2 转：某缸这一转压缩-燃烧，下一转就排气-进气，四个缸错开半程轮换。手册的示意图给出了活塞在 720 度里走完进气、压缩、做功、排气四个行程的全过程。

![四冲程循环：活塞 2 转完成进气-压缩-做功-排气，黑色矩形指示活塞位置](/images/combustion-analysis/fig3-fourstroke.png)

*(图源：Simcenter Testing Knowledge Base)*

::: info 核心概念
- **四冲程循环（Four-stroke Cycle）**：活塞往复 2 次、曲轴旋转 720 度完成进气-压缩-做功-排气一个完整工作循环
- **曲轴转角（Crank Angle, CA）**：以曲轴转角而非时间定位事件的坐标，压缩上止点（TDC）为 0 度，常用 ATDC（上止点后）/BTDC（上止点前）标注
- **燃烧阶次（Combustion Order）**：每转燃烧事件数 = 缸数/2（四冲程），四缸机为 2 阶、六缸机为 3 阶，与转速无关
- **缸压（Cylinder Pressure）**：缸内气体绝对压力随曲轴转角的变化 $p(\theta)$，燃烧分析的核心测量量
:::
## 二、测量链路第一环：角域采集——把时钟换成曲轴

缸压分析的第一条纪律：**缸压是转角的函数，不是时间的函数**。同一个 720 度循环，转速波动会让它的时间长度逐循环变化——按时间切片，第 N 循环与第 N+1 循环的燃烧事件对不上位置；按转角切片，压缩上止点永远在同一个角度，逐循环对齐才有意义。

这就要求数据从等时间采样变换到**等角度采样（angle domain）**。角域里相当于"采样率"的参数是**每转采样数（samples per revolution, spr）**，对应的角度增量 $\Delta\theta = 360/N_{spr}$。它与时域采样率的换算：

$$f_s = \frac{n}{60} \cdot N_{spr} \quad [\mathrm{Hz}]$$

物理意义：转速 $n$ rpm 即每秒 $n/60$ 转，每转采 $N_{spr}$ 点，两者相乘即每秒样本数。反过来看更直观——想要 0.1 度的角分辨率（燃烧分析常规要求），6000 rpm 时需要

$$f_s = \frac{6000}{60} \times \frac{360}{0.1} = 360\ \mathrm{kHz}$$

即每样本时间间隔只有 2.78 微秒。反过来，一台 100 kHz 的采集系统在 6000 rpm 下能达到的角度分辨率只有 $100000/(100 \times 360) \approx 0.36$ 度/样本。这就是缸压通道通常要求独立高采样率、且必须配曲轴角标信号（每转 360 个脉冲以上的编码器或飞轮齿盘信号）的原因。

| 参数 | **时域采集** | **角域采集** |
| --- | --- | --- |
| 采样栅格 | 等时间间隔 $\Delta t = 1/f_s$ | 等角度间隔 $\Delta\theta = 360/N_{spr}$ |
| 分辨率指标 | 频率分辨率 $\Delta f$（Hz） | 角度分辨率 $\Delta\theta$（度） |
| 转速波动的影响 | 循环事件位置逐循环漂移 | 事件锁定在固定角度 |
| 硬件需求 | 时基 + 抗混叠滤波 | 角标通道（编码器/齿盘）+ 转速跟踪 |
| 典型设置（缸压） | 50~100 kHz 固定采样 | 0.1~0.5 度分辨率，1 循环 = 720 度 |

Simcenter Testlab 中这条链路是：曲轴角标接转速通道，缸压/振动通道按 Tracked 模式跟踪角标，**Tracking Method 选 Free Run (angle)**，按循环数截取数据；**AD Acquisition 标签页设每循环 2 转**——这样每个循环由完整 720 度组成。手册特别提醒：四冲程机若按默认 1 转切，缸压曲线会被切成两半，压缩行程与排气行程错位对叠，后续统计全部失效。

![Testlab Time Data Processing 的角域采集设置：Tracked + Free Run (angle)，按循环数升序截取](/images/combustion-analysis/fig4-ad-settings.png)

*(图源：Simcenter Testing Knowledge Base)*

::: warning 工程注意
角标信号的每转脉冲数（PPR）决定了角域的角度分辨率上限——0.1 度分辨率意味着每转 3600 个脉冲（或由插值重采样补足）。飞轮齿盘 60-2 齿的信号直接重采样只能到 6 度，粗到无法定位 CA50；缸压分析必须上高分辨率编码器，或确认采集系统支持脉冲插值。转速通道的缺脉冲、毛刺、接缝误差会直接污染角域栅格，先清洗转速再谈燃烧指标。

## 三、缸压曲线的读法：从多变压缩到峰值相位

拿到一条干净的 $p(\theta)$，先学会读三个特征段。

**压缩段（BTDC 30 度到着火前）**：进气门关闭后气体被压缩，压力升高遵循多变过程（polytropic process）：

$$p V^{n} = \mathrm{const}$$

其中 $n$ 是**多变指数（polytropic exponent）**，等温过程 $n=1$、绝热过程 $n=\gamma$（比热比，约 1.3~1.35），真实压缩带传热与漏气，$n$ 介于两者之间。对上式取对数得 $\ln p = -n \ln V + C$——在双对数图上压缩段是一条直线，**斜率的负值就是 n**。压缩比 10.6 时，$n$ 从 1.32 变到 1.34，压缩压比 $CR^{\,n}$ 从 22.6 变到 23.7——这就是后面"压力基准修正"要对 $n$ 较真的原因。

**燃烧段**：着火后压力急剧抬升。两个硬指标：

- **峰值压力 $p_{max}$ 及其相位**：自然吸气机典型 50~80 bar，出现在 TDC 后 5~15 度。峰值太靠近 TDC 说明燃烧太早，机械负荷与噪声都恶化；
- **最大压力升高率** $(\mathrm{d}p/\mathrm{d}\theta)_{max}$：燃烧"猛烈程度"的直接度量，决定了燃烧噪声与活塞敲击的激励强度。汽油机通常几个 bar/度，爆震时显著升高。

**膨胀段**：燃气膨胀做功，同样近似多变过程，指数略高于压缩段（燃气温度更高、传热方向相反）。

单看一条曲线没有工程意义——**循环变差（cycle-to-cycle variation）才是常态**。同一工况下相邻循环的着火时刻、火焰速度都有随机差异，缸压峰值逐循环波动。下图是 Testlab 切出的 5 个连续循环的缸压曲线（左）与同一时段的振动曲线（右），横轴均为 720 度：每个循环形态相似、细节各异。

![Navigator 中的 5 个连续循环：左侧缸压、右侧振动，横轴均为 720 度曲轴转角](/images/combustion-analysis/fig5-five-cycles.png)

*(图源：Simcenter Testing Knowledge Base)*

对 300 个循环做逐点统计，得到**平均循环**（典型工作状态）与 **max/min 包络**（稳定程度）：包络在燃烧段撑得越开，循环变差越大——怠速不稳、加速抖动的数据证据就在这里。

::: tip 测量要点
- 缸压传感器安装位置避开进排气门与喷油器锥角，通道尽量短——长的测压通道会形成亥姆霍兹共振，压力高频成分被放大污染压力升高率
- 绝对压力基准（pegging）：压电传感器只能测动态变化，逐循环用进气管压力（进气门关闭前）或膨胀段多变外推校准绝对零点，n 值取压缩段拟合结果
- 每循环的相位对齐以压缩 TDC 为基准，TDC 标定误差 1 度可引起放热率相位整体漂移——热力学 TDC 与上止点传感器 TDC 的差值必须标定
:::

## 四、从缸压到放热率：Rassweiler-Withrow 分析

压力曲线只告诉你"多猛"，不直接告诉你"烧了多少、烧得快慢"。把缸压换算成**放热率（heat release rate）**，才算进入燃烧分析的腹地。

### 4.1 从热力学第一定律出发

把缸内气体当成一个忽略开口流动、忽略动能位能的控制体，热力学第一定律：

$$\delta Q = \mathrm{d}U + p\,\mathrm{d}V$$

读法：燃烧放出的热量 $\delta Q$，一部分变成气体内能 $\mathrm{d}U$（压力温度升高），一部分推动活塞做功 $p\,\mathrm{d}V$。理想气体 $U = m c_v T$，结合状态方程 $pV = mRT$ 与 $R = c_p - c_v$、$\gamma = c_p/c_v$，可得内能增量的压力-容积表达：

$$\mathrm{d}U = \frac{1}{\gamma - 1}\left(V\,\mathrm{d}p + p\,\mathrm{d}V\right)$$

代回第一定律，**放热率的完整表达式**：

$$\delta Q = \frac{1}{\gamma - 1}V\,\mathrm{d}p + \frac{\gamma}{\gamma - 1}p\,\mathrm{d}V$$

每一项的物理意义：$V\,\mathrm{d}p/(\gamma-1)$ 是"憋在缸内的能量"（压力升高），$\gamma\,p\,\mathrm{d}V/(\gamma-1)$ 是"送出去的功"（容积膨胀），两者之和才是燃烧释放的总能量。

### 4.2 Rassweiler-Withrow 方法：工程近似

上式直接用需要知道 $\gamma$ 随温度的变化，1930 年代 Rassweiler 与 Withrow 提出的做法把放热拆成两段分别近似：

- **压缩/膨胀段（无燃烧）**：压力变化服从多变过程 $pV^{n} = \mathrm{const}$，微分得 $\mathrm{d}p = -n\,p\,\mathrm{d}V/V$。这段"该有的"压力变化可以预测；
- **燃烧段**：实际压力减去"若不燃烧会有的压力"，差值折算成放热。

把第 $i$ 个曲轴转角步长的压力增量分成两部分：

$$\Delta p_i = \underbrace{\left(\Delta p_i\right)_{\mathrm{V}}}_{\text{多变容积项}} + \underbrace{\left(\Delta p_i\right)_{\mathrm{comb}}}_{\text{燃烧放热项}}$$

容积项由多变关系给出 $\left(\Delta p_i\right)_{\mathrm{V}} = -n\,p_i\,\Delta V_i / V_i$，燃烧项就是实测压力增量扣除容积项后的剩余。由于压力增量正比于放热量（气缸容积变化不大时），把逐角度的燃烧项归一化累加，即得**质量已燃分数（Mass Fraction Burned, MFB）**曲线：

$$\mathrm{MFB}(\theta) = \frac{\sum_{i \le \theta} \left(\Delta p_i\right)_{\mathrm{comb}}}{\sum_{\text{all } i} \left(\Delta p_i\right)_{\mathrm{comb}}}$$

MFB 从 0 涨到 1 的过程就是燃烧进程本身。三个标准刻度：

| 刻度 | **定义** | **物理含义** | **典型值（汽油机）** |
| --- | --- | --- | --- |
| CA10 | MFB = 10% 的曲轴转角 | 火焰发展期结束、急燃开始 | TDC 前 10 度 ~ TDC 后 5 度 |
| CA50 | MFB = 50% 的曲轴转角 | 燃烧重心（combustion center） | TDC 后 5~10 度附近热效率最优 |
| CA90 | MFB = 90% 的曲轴转角 | 主燃期结束 | TDC 后 25~40 度 |

**CA50 是燃烧相位最常用的单一指标**：CA50 过早（TDC 之前），压缩负功增大、峰值压力逼近机械限值；CA50 过晚，燃烧在膨胀行程里"追着活塞跑"，有效膨胀比缩水、排温升高。经验上 CA50 落在 TDC 后 6~10 度附近热效率较好，具体随机型与工况而变，工程上以台架扫点火角找油耗最低点（MBT，最小点火提前角 for 最佳扭矩）标定。

::: info 核心概念
- **放热率（Heat Release Rate）**：单位曲轴转角（或单位时间）燃烧释放的能量，由缸压经热力学第一定律换算
- **质量已燃分数（MFB）**：累计放热量占总放热量的比例，从 0 到 1 描述燃烧进程
- **CA10/CA50/CA90**：MFB 达到 10%/50%/90% 的曲轴转角位置，燃烧相位的三个标准刻度
- **Rassweiler-Withrow 方法**：把压力增量分解为多变容积项与燃烧项、以燃烧项累加构造 MFB 的工程近似，无需壁温传热模型
:::

### 4.3 气缸容积：曲柄连杆几何

上述所有公式都用到 $V(\theta)$，它由曲柄连杆机构几何决定。设排量 $V_d$、压缩比 $CR = (V_c + V_d)/V_c$、曲柄连杆比 $\lambda = r/l$（曲柄半径/连杆长度），气缸容积：

$$V(\theta) = V_c + \frac{V_d}{2}\left[1 - \cos\theta + \frac{1}{\lambda}\left(1 - \sqrt{1 - \lambda^{2}\sin^{2}\theta}\right)\right]$$

推导要点：活塞位移 = 曲柄销投影 + 连杆摆角修正，$\lambda$ 项就是连杆有限长带来的偏离简谐运动的修正。$\theta = 0$（TDC）时 $V = V_c$ 最小，$\theta = 180$ 度（BDC）时 $V = V_c + V_d$ 最大。
### 4.4 数值演示：从压力反算放热与 CA50

下面这段 numpy 演示完整走一遍链路：按曲柄连杆几何生成容积曲线，用多变压缩造一条"拖动缸压"，叠加 Wiebe 函数模拟燃烧放热并按热力学第一定律正向积分出压力，再用 Rassweiler-Withrow 逆运算反算 MFB 与 CA10/50/90——正反两条路径对得上，方法才算真懂。

```python
import numpy as np

# 单缸参数：压缩比10.6、排量0.5L、曲柄连杆比0.3、比热比1.32
CR, Vd, lam, k = 10.6, 0.5e-3, 0.3, 1.32
Vc = Vd/(CR-1)
th = np.radians(np.arange(-180.0, 180.0, 0.1))   # 0 度=压缩上止点
V = Vc + Vd/2*(1-np.cos(th) + (1-np.sqrt(1-(lam*np.sin(th))**2))/lam)

# 压缩段多变过程 n=1.32，从下止点 0.9 bar 出发
p = 0.9e5*(V[0]/V)**1.32

# Wiebe 燃烧：-15 度着火、持续 50 度、a=5、m=2，总放热 900 J
x = np.clip((np.degrees(th)+15)/50, 0, 1)
xb = 1 - np.exp(-5*x**2)
dQ = 900*np.diff(xb, prepend=0)

# 热力学第一定律正向积分出缸压
dV = np.diff(V, prepend=V[0])
for i in range(1, len(th)):
    p[i] = p[i-1] + (k-1)/V[i]*dQ[i] - k*p[i-1]/V[i]*dV[i]

# Rassweiler-Withrow 逆运算：由压力反算放热与 MFB
Qrw = np.cumsum(V/(k-1)*np.diff(p, prepend=p[0]) + k/(k-1)*p*dV)
mfb = (Qrw-Qrw.min())/Qrw.max()
deg = np.degrees(th)
ca = lambda f: deg[np.argmax(mfb >= f)]
print('p_max = %.1f bar @ %.1f deg ATDC' % (p.max()/1e5, deg[p.argmax()]))
dp = np.diff(p, prepend=p[0])/1e5
print('dp/dtheta_max = %.2f bar/deg @ %.1f deg' % (dp.max(), deg[dp.argmax()]))
print('CA10=%.1f, CA50=%.1f, CA90=%.1f deg ATDC' % (ca(.10), ca(.50), ca(.90)))
# 压缩段(-35~-20度)双对数拟合多变指数，检验 pegging 用
seg = (deg > -35) & (deg < -20)
n_fit = -np.polyfit(np.log(V[seg]), np.log(p[seg]), 1)[0]
print('polytropic n = %.3f (true 1.320)' % n_fit)
```

运行结果（真实输出）：

```
p_max = 53.5 bar @ 11.1 deg ATDC
dp/dtheta_max = 0.22 bar/deg @ -2.5 deg
CA10=-7.7, CA50=3.6, CA90=18.4 deg ATDC
polytropic n = 1.319 (true 1.320)
```

三个数字值得细看：峰值压力 53.5 bar 落在 TDC 后 11.1 度，CA50 在 TDC 后 3.6 度——相位关系自洽（CA50 必然晚于着火点 -15 度、早于或接近峰值相位）；反算的多变指数 1.319 与正向设定的 1.320 只差 0.001，说明容积函数与能量方程的一致性。把 Wiebe 着火角从 -15 度提前到 -25 度，CA50 随之前移、峰值压力抬高并向 TDC 靠拢——点火角标定扫的就是这条链路。

## 五、Testlab 逐循环统计与门区指标

放热分析之外，Testlab 的角域工具链直接面向"每循环一个数"的统计需求——发动机标定与耐久评估喜欢的口径。

**逐循环对齐与多缸平均**：不同气缸的着火相位互差 720 度/缸数，跨缸比较或求"平均缸"前先用 **Angle Domain Validation 工作表的 Cyl Offset** 字段逐通道设置角度偏移，把各缸曲线对齐到同一相位基准，再在 Channel Processing 的 DerivedAD 里用 LINAVG 函数求平均。手册明确：缸压曲线在角域是 720 度周期函数，角度域上的线性平均才有物理意义。

**门区统计（Gated Statistics）**：关心"每循环峰值压力及其出现角度"这类逐循环指标时，在 Frame Statistics AD 标签页定义角度门区——例如峰值预期出现在 10~30 度 ATDC，就把门设在那里——系统对每个循环在门内取最大值及其角度位置，输出随循环数排列的序列。300 个循环的峰值压力序列可以直接算均值、标准差、极差，**循环变差的量化数字**（如峰值压力的变异系数 CoV）就出自这里。若要压力升高率，对缸压曲线在 DerivedAD 里定义 DIFFERENTIATE 函数做角域微分，最大压力升高率同样可用门区逐循环提取。

::: tip 链路检查单
- 角标 PPR 与目标角度分辨率匹配（0.1 度对应每转 3600 脉冲或插值）
- AD Acquisition 每循环 revolutions = 2（四冲程），切完抽查首循环相位
- 转速信号先清洗（缺脉冲/毛刺/接缝）再进角域重采样
- 传感器灵敏度、pegging 基准、TDC 标定三项记录在案——放热分析的误差预算大头
- 报告燃烧指标时注明口径：MFB 方法（R-W 或其他）、$\gamma$ 或 $n$ 取值、平均循环还是逐循环分布
:::

## 六、小结

燃烧分析的测量链路一句话概括：**角标定时钟、角域切循环、缸压算放热、相位定好坏**。判据与数字直接给出：

- 燃烧激励阶次 = 缸数/2（四冲程），四缸机 2 阶、六缸机 3 阶，与 rpm 无关；2 阶突出先查燃烧相位与压力升高率，不要急着换悬置
- 缸压通道角分辨率 0.1 度是常规要求：6000 rpm 下等效采样率 360 kHz，角标 PPR 必须跟上
- 峰值压力相位在 TDC 后 5~15 度、CA50 在 TDC 后 6~10 度附近是汽油机健康的相位窗口；CA50 早于 TDC 说明点火过早，机械载荷与燃烧噪声同时恶化
- 最大压力升高率是燃烧噪声与活塞敲击激励强度的第一指标，逐循环分布比单值重要
- 循环变差用 300 循环包络宽度或峰值压力变异系数量化，怠速稳定性问题从这里找证据
- Rassweiler-Withrow 是工程近似：$\gamma$ 取常数、忽略传热与余隙，绝对放热量有百分之几的偏差，但 CA10/50/90 相位对参数不敏感，用于相位判断足够可靠
