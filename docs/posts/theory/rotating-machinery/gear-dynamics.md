# 齿轮动力学：啮合阶次、边带与故障特征

> 一台电动车减速器出厂检验合格，装车后却有细高频啸叫，而另一台边带明显的样机听感反而更安静——齿轮 NVH 的三张面孔常让新手困惑。本文以相关公开技术资料的齿轮内容为纲：啮合阶次是齿轮的身份码（齿数即阶次、与转速无关），边带是健康状况的体检单（间距 k 指向每转 k 次的调制源），敲击是载荷与间隙的报警器（不随转速移动的宽带）。一条判读链路串起三张面孔，落到 Testlab 的阶次光标与角域工具。

## 一、为什么齿轮是旋转机械 NVH 的高频主角

先看一个工程现场常见的问题：减速器台架跑升速，人耳听到一段细细的哨音，转速越高音调越高。频谱上看，峰的频率严格跟着转速走——3000 rpm 时 860 Hz，6000 rpm 时 1720 Hz。这不是结构共振（共振频率不随转速变），而是齿轮啮合：每一对齿进入和脱离接触各产生一次冲击，冲击的重复率乘上齿数、再乘上转速，就是这条斜线的频率。齿轮之所以是旋转机械 NVH 的高频主角，正是因为齿数这个倍率因子把激励频率推到了人耳最敏感的频段——一根 3000 rpm 的轴转频不过 50 Hz，装上 86 齿齿轮后啮合激励立刻跳到 4300 Hz。

打一个贯穿全文的比方：齿轮副像两排互相咬合的邮票打孔器。主动轮每转过一个齿，从动轮也被点一下——完美齿轮的打孔等间隔、等力度，听感是一条纯音；如果其中一个轮子做得略扁（偏心），或者装到轴上时略偏（不同心），打孔的力度就周期性地时轻时重，纯音开始晃动——这份晃动在频域里就是主阶两侧的边带；如果打孔器之间留了缝隙（齿侧间隙）而负载又在波动，孔就打不实、时打时不打，声音变成一片沙沙的宽带——这就是敲击（rattle）。记住打孔器这个比方，后文的每个公式都能在它上面找到对应。

相关公开技术资料把旋转机械问题归纳为彩色图谱上的五大特征：阶次、共振、调制阶次、瞬态、电气开关。其中直接由齿轮引起的有三类——啮合阶次（健康齿轮也有）、调制边带（几何或安装缺陷的指纹）、齿面敲击（间隙与载荷波动共同作用）。三类特征的计算与判读，就是本文的主线。

## 二、啮合阶次：齿轮的身份码

### 从一个具体算例开始

相关技术手册的经典例题：一根轴上装着 86 齿的齿轮，轴转速 600 rpm。三个问题依次是——轴频率是多少？啮合频率是多少？啮合阶次是多少？

第一步，轴频率：600 rpm 意味着每秒转 10 圈，轴频率 10 Hz。第二步，啮合频率：齿轮每转一圈，86 个齿各啮合一次，啮合频率 860 Hz。第三步，啮合阶次：相关技术手册强调，其实不必先算频率——每转一圈发生 86 次啮合事件，啮合就是 86 阶，一步到位。

![86 齿齿轮啮合例题：600 rpm 轴上的啮合频率与阶次](/images/gear-dynamics/fig1-gear-mesh-86.png)

*（图源：网络官方公开资料）*

这个例题揭示了齿轮阶次的最重要性质：齿数即阶次，与转速无关。600 rpm 时啮合频率 860 Hz，6000 rpm 时变成 8600 Hz——频率随转速线性增长，但阶次始终是 86。这就是彩色图谱（colormap）上齿轮啮合表现为一条过原点高阶斜线的原因：斜率越陡，齿数越多。

这个公式回答的问题是：已知齿数与转速，啮合激励的频率落在哪里？其中 $N$ 对应物理里的齿数（每转啮合事件数），$n$ 对应轴转速（rpm），60 把每分钟换算成每秒：

$$
f_{\mathrm{mesh}} = N \cdot \frac{n}{60} \quad \mathrm{Hz}
$$

::: info 核心概念
- <strong>啮合频率（Gear Mesh Frequency）</strong>：单位时间内齿对进入啮合的次数，等于齿数乘轴频
- <strong>啮合阶次（Gear Mesh Order）</strong>：相对参考轴每转的啮合事件数，数值上等于齿数 $N$（齿轮直接装在参考轴上时）
- **阶次不变性**：转速变化只改变啮合频率，不改变啮合阶次——这是把齿轮激励从频谱中认出来的依据
:::

### 传动链里的分数阶

啮合阶次等于齿数，前提是齿轮就装在被选为参考轴的那根轴上。实际传动链里，转速计（tacho）只能装在一根轴上，其他轴上的齿轮阶次都要按传动比换算——于是出现了分数阶。

相关技术手册的第二个例题：蓝轴（主动）60 rpm，绿齿轮（从动）相对蓝轴的转动阶次是多少？答案是 1.625 阶——一个彻头彻尾的分数。传动比不是整数，阶次就不是整数；0.5 阶、1.5 阶、1.625 阶在发动机与变速箱数据里都属于正常值，看到分数阶不必怀疑数据出了问题。

![两级齿轮传动：从动齿轮相对主动轴呈 1.625 阶](/images/gear-dynamics/fig2-two-gears.png)

*（图源：网络官方公开资料）*

![从动齿轮相对主动轴为 1.625 阶的答案图示](/images/gear-dynamics/fig3-gear-ratio-1625.png)

*（图源：网络官方公开资料）*

这个公式回答的问题是：从动轴上的齿轮啮合，相对装转速计的参考轴是多少阶？其中 $N_2$ 对应从动齿轮齿数，$n_2/n_1$ 对应物理里从动轴与参考轴的转速比（传动比 $i$）：

$$
O_{\mathrm{mesh}} = N_2 \cdot i = N_2 \cdot \frac{n_2}{n_1}
$$

回到打孔器的比方：参考轴上的打孔器每圈打 86 孔是 86 阶；如果这套打孔器装在由 1.625 倍速轮带动的从动轴上，相对参考轴每圈打的孔数就变成 $86 \times 1.625 = 139.75$ 个——分数阶出现了。判读传动链数据时，先把每根轴的转速比对清楚，再对号入座各条斜线；两份数据若转速计装的位置不同，阶次数不可直接比较。

## 三、边带：齿轮健康状况的指纹

### 图谱上的对称伴线

相关技术手册给出的标志性案例：62 齿齿轮啮合，理论上图谱上只有一条 62 阶斜线，实测却多出两条——60 阶与 64 阶，对称分布在主阶两侧。初学者最常见的误判是按阶次反查部件：去系统里找 60 齿的齿轮和 64 齿的齿轮，而整机里根本不存在这两个零件。相关技术手册明确指出：边带阶次没有对应的物理特征数——60、64 阶的能量来自 62 齿啮合本身。

![62 阶调制后的彩色图谱：主阶两侧对称出现 60、64 阶边带](/images/gear-dynamics/fig4-sideband-colormap.png)

*（图源：网络官方公开资料）*

### 偏心齿轮怎么晃出边带

机理仍用打孔器讲：一对齿轮，齿轮 1 是正圆，齿轮 2 因为滚齿工序的几何偏差呈略扁的椭圆。椭圆轮廓使两齿轮的中心距每转经历两次推近—拉远循环——啮合力度每转被调制两次。

![偏心齿轮副：齿轮 2 椭圆轮廓使中心距每转变化两次](/images/gear-dynamics/fig5-eccentric-pushpull.png)

*（图源：网络官方公开资料）*

如果齿轮都是正圆，中心距恒定，啮合力度平稳，不发生调制；椭圆齿轮则让啮合冲击的强度以每转 2 次的节奏起伏。时域上这是幅值被周期性揉搓的啮合信号，频域上等价于把单根 62 阶谱线分裂成三根。

这个公式回答的问题是：啮合信号被每转 k 次的力度起伏调制后，频谱变成什么样？其中 $N$ 对应物理里的啮合阶次（载波），$k$ 对应调制源每转作用次数，$m$ 对应调制深度——方括号里的包络项就是打孔器时轻时重的定量描述：

$$
x(t) = A\,\bigl[1 + m\cos(2\pi k f_{\mathrm{shaft}} t)\bigr]\cos(2\pi N f_{\mathrm{shaft}} t)
$$

用积化和差恒等式展开乘积项，三根谱线现出原形：

$$
x(t) = A\cos(2\pi N f_{\mathrm{shaft}} t) + \frac{mA}{2}\cos\bigl(2\pi (N-k) f_{\mathrm{shaft}} t\bigr) + \frac{mA}{2}\cos\bigl(2\pi (N+k) f_{\mathrm{shaft}} t\bigr)
$$

物理意义分三层：载波仍是 $N$ 阶、幅值 $A$ 不变；两条边带出现在 $N-k$ 与 $N+k$ 阶，幅值各为 $mA/2$；能量被重新分配而不是凭空多出两个激励源。由此得到边带判读的两条铁律：

1. **边带间距 $k$ = 调制源每转作用次数**。间距 2 指向椭圆偏心（每转推拉两次，滚齿几何偏差）；间距 1 指向安装偏心（齿轮与轴不同心，每转一次）。
2. **边带间距在阶次域量，不在频率域量**。频率域上边带间距随转速变化，阶次域上恒为 $k$——这是确认伴线是边带而不是别的阶次的关键一步。

相关技术手册特别提醒调制不限于偏心一种：齿轮未装在轴心上的不同心每转调制一次，负载波动、轴承缺陷、离合器颤振都遵循同一套数学。边带间距是指纹，反查调制源要结合传动链结构。

### 反直觉的一条：偏心不一定要修

发现齿轮偏心，直觉反应是提高加工精度、把齿轮磨圆。相关技术手册给出反直觉的工程答案：从噪声角度看，能量集中在单阶未必是好事。全部啮合能量集中在一条 62 阶谱线时，该谱线幅值高——单一频率的纯音哨叫，响度刺耳；被调制分散到三根谱线后，每根的幅值都下降，峰值响应随之降低。齿轮制造商甚至会出于这个目的主动控制偏心量，把集中的能量摊到宽频带上。这与离合器从动盘开螺旋槽、壳体贴阻尼的思路同源：以分散能量替代单纯追求单指标。

当然，前提是分清问题性质：如果边带间距 1 且 1 阶同步升高，指向安装不同心，通常需要修正；如果是间距 2 的对称边带且峰值达标，未必动刀。判读顺序永远是先量间距、再反查机理、最后谈处理。

## 四、敲击与宽带：间隙与载荷的报警器

第三类齿轮特征不集中在任何一条阶次线上。相关技术手册的图谱案例：频段 1000~3000 Hz 出现一片幅值抬升的宽带区域，不随转速移动成斜线。这不是啮合，而是瞬态冲击——两个零件短暂撞击，每次撞击激发结构的宽频响应，在图谱上叠加成片状亮区。

齿轮箱里最典型的瞬态是齿面敲击（gear rattle/clatter）：变速箱里有若干常啮合齿轮副，同一时刻只有一对传递载荷，其余空载漂浮；发动机转速的扭振波动通过轴系传成扭矩脉冲，空载齿轮副在齿侧间隙里来回撞——每次撞击都是一次宽带激励。

![齿面敲击：空载齿轮副在扭矩脉冲下往复撞击产生宽带响应](/images/gear-dynamics/fig6-gear-rattle.png)

*（图源：网络官方公开资料）*

敲击与边带的图谱判读对比鲜明：边带是离散的对称伴线，跟随主阶斜线移动；敲击是连续的宽带竖纹，基本不随转速移动。机理也不同——边带来自确定性的调制（周期性的力度起伏），敲击来自随机性的撞击（间隙内的往复碰撞），因此对策也不一样：相关技术手册给出的方向是消除撞击条件，给空载齿轮副施加微小载荷让它不再漂浮，或修整齿面微观几何改善接触。这与发动机活塞敲缸同属一类问题，处理思路可以互相借鉴。

## 五、numpy 验证：从健康齿轮到偏心齿轮的频谱演化

用一段自包含代码在角度域复现第二、三节的核心结论：健康齿轮只有单阶谱线；偏心调制后出现对称边带、幅值 m/2；边带间距等于调制次数。

```python
import numpy as np

n_rev, pts_per_rev = 64, 512          # 64 转，每转 512 点（角度域采样）
rev = np.arange(n_rev * pts_per_rev) / pts_per_rev

def order_spectrum(order_mesh, order_mod=0.0, m=0.0):
    # 啮合载波 + 可选的每转 order_mod 次调幅
    x = (1 + m*np.cos(2*np.pi*order_mod*rev)) * np.cos(2*np.pi*order_mesh*rev)
    X = np.abs(np.fft.rfft(x)) * 2 / len(x)
    orders = np.arange(len(X)) / n_rev
    peak = lambda o: X[np.argmin(np.abs(orders - o))]
    targets = [order_mesh] + ([order_mesh-order_mod, order_mesh+order_mod] if order_mod else [])
    return {round(o, 1): round(peak(o), 3) for o in targets}

print('健康 62 齿: ', order_spectrum(62.0))                 # 仅 62 阶
print('椭圆偏心 k=2:', order_spectrum(62.0, 2.0, m=0.6))   # 60/62/64 阶
print('安装偏心 k=1:', order_spectrum(62.0, 1.0, m=0.6))   # 61/62/63 阶
```

预期输出：健康齿轮在 62 阶幅值 1.0、别处为 0；k=2 时 60 与 64 阶幅值均为 0.300（理论值 m/2 = 0.3）；k=1 时边带移到 61、63 阶。把 order_mod 换成任意整数，边带跟着移动而间距不变——第二条判读铁律的数值化。

## 六、Testlab 落地：从数据到判读

- **彩色图谱与阶次光标**：Simcenter Testlab 的 Throughput Processing 工作表生成 colormap 后，用交互式阶次光标（Interactive Order Cursor）沿斜线拖动，即可读出任意阶次随转速的幅值曲线；对齿轮数据先拉主阶（齿数阶），再检查主阶 ±1、±2 处有无伴线。
- **边带间距在阶次域确认**：伴线疑似边带时，切换到阶次轴（角度域重采样后做 FFT）量间距——频率域间距随转速变、阶次域恒为 k，一次对比即可定性。
- **啮合阶次对传动链对账**：转速计装在哪根轴上，那根轴就是 1 阶；其余齿轮按传动比换算阶次（含分数阶）。对不上账先查参考轴，再查传动比。

::: tip 齿轮 NVH 排查的顺序
1. 图谱上锁定高阶斜线，按齿数与传动比对号入座（啮合阶次）
2. 主阶两侧找对称伴线，阶次域量间距：2 查椭圆度、1 查安装同心度（边带）
3. 宽带竖纹、不随转速走，查空载齿轮副与齿侧间隙（敲击）
4. 峰值纯音刺耳但结构健康，考虑受控偏心分散能量，而非一味提高精度
:::

## 七、小结

齿轮在旋转机械图谱上留下三类特征，各有各的算法与对策：啮合阶次是身份码——齿数即阶次、与转速无关，传动链里按传动比换算出分数阶；边带是健康指纹——主阶 ±k 的对称伴线来自调幅，间距 k 等于调制源每转作用次数，且必须在阶次域量取；敲击是间隙报警——空载齿轮副在扭矩脉冲下的往复撞击产生不随转速移动的宽带，消除撞击条件比削减峰值更对症。

## 一句话记住

齿数即阶次（传动链按速比折算出分数阶），主阶 ±k 的对称伴线是每转 k 次调幅的指纹（阶次域量间距：2 查椭圆、1 查同心），宽带竖纹是间隙敲击——先认线、再量边、后查间隙。
