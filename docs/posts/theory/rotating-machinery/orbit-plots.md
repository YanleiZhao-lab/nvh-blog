# 轴心轨迹图 Orbit Plot：从波形到轴心运动

> 转轴在轴承里到底怎么运动，一根探头波形回答不了：把互相垂直的两路位移波形“对着画”，轴心在一个响应平面内的完整运动轨迹——轴心轨迹图（Orbit Plot）——就浮现出来。轨迹的形状直接对应故障类型：圆对不平衡、椭圆对径向受限/不对中、内“8”字对流体动压失稳。本文从位移探头原理讲起，分步说明 AC/DC 分量、双探头正交合成、键相标记与滤波/未滤波两种视图，最后落到三种典型故障的判读判据与 Simcenter Testlab 的操作链路。

## 一、为什么需要轴心轨迹图

旋转机械（Rotating Machinery）——发动机、涡轮机、压缩机、泵——的振动诊断里，最基础的问题是：**转轴的中心线在轴承间隙内怎样运动**。理想状态下，轴绕自身几何中心旋转，中心线一动不动；现实里，不平衡、不对中、轴承油膜力等因素会把轴心推离平衡位置，轴心一边自转一边绕平衡位置公转，这个复合运动称为**涡动（Whirl）**。

用单轴加速度传感器在轴承座上测，得到的是轴承座受迫振动的波形——它经过了轴-油膜-轴承座这条传递路径的“过滤”，包含转子响应、支座共振、基础振动等全部成分的混合。工程上需要一种**直接观察轴本身运动**的工具，把传递路径的干扰剥掉。这就是轴心轨迹图的定位：**用非接触位移探头直接测轴的表面运动，还原轴心在轴承平面内的二维轨迹**。

![理想与实际：轴应绕中心旋转（左），偏心运转时轴心画出轨道（右）](/images/orbit-plots/fig1.png)

*（图源：Simcenter Testing Knowledge Base）*

上图给出概念对比：左侧理想状态，轴截面（红色）绕自身中心旋转，蓝色实线轨迹缩成一个点；右侧轴心偏离中心公转，蓝色虚线画出的闭合曲线就是轴心轨迹。**轨迹的形状与幅值携带故障源信息**——这是后文全部判读的物理基础。

::: info 核心概念
- **轴心轨迹图（Orbit Plot）**：轴心线在垂直于转轴的平面内运动轨迹的可视化图形，由两个互相垂直的位移测量合成
- **涡动（Whirl）**：轴心绕平衡位置的回转运动，与轴的自转叠加构成实际运动
- **响应平面（Response Plane）/传感器响应平面（Transducer Response Plane）**：两只位移探头所在的、垂直于轴线的测量平面，通常取轴承位置
:::

## 二、测量链路：探头、平面与键相

### 2.1 测点布置与响应平面

一套完整的轴心轨迹测量布置如图所示。单跨转子由两只轴承支撑，每只轴承处沿轴向各布置两只互相垂直的位移探头（图中绿 X、蓝 Y），该截面即响应平面（图中白色透明圆盘）。两只轴承各出一个响应平面，两个平面的轨迹拼起来，就能看到整根轴的运动全貌——例如判断涡动是平移型（两平面轨迹同相位）还是摆动型（反相位）。

![测点布置：两只轴承处各设 X/Y 探头，构成两个响应平面](/images/orbit-plots/fig2.png)

*（图源：Simcenter Testing Knowledge Base）*
### 2.2 电涡流位移探头

轴心轨迹用**位移（Displacement）**量构造，不是加速度。位移测量的标准传感器是**趋近式探头（Proximity Probe）**，本质是非接触电涡流（Eddy Current）位移传感器：探头线圈通高频电流产生交变磁场，轴表面感应涡流，涡流的反磁场削弱线圈电感，输出电压与探头-轴表面间距成比例。轴表面无需粘贴任何东西，特别适合旋转部件的连续监测。

![趋近式探头实物：非接触电涡流位移传感器](/images/orbit-plots/fig3.png)

*（图源：Simcenter Testing Knowledge Base）*

### 2.3 AC 与 DC：一个信号里的两种信息

探头电压与间距成比例，意味着输出信号可以拆成两部分：

- **DC 分量（直流/均值）**：轴心平均位置到探头的距离。它给出**轴心在轴承间隙内的绝对位置**——轴心是否偏在间隙一侧、偏多少，直接反映静态预载与油膜厚度分布
- **AC 分量（交变部分）**：轴涡动引起的周期波动。它就是轴心轨迹的形状信息

两者的关系用一行公式表达。设探头输出为 $$d(t)$$，则：

$$d(t)=\underbrace{d_0}_{\text{DC：轴心平均位置}}+\underbrace{a\cos(\omega t+\varphi)}_{\text{AC：涡动轨迹}}$$

物理意义：DC 分量定位轨迹圆心在轴承里的位置，AC 分量描绘轨迹本身的形状。**只看 AC（轨迹图），知道轴怎么晃；加上 DC（平均中心位置图，Centerline Plot），才知道轴在哪儿晃**。两者合起来才是完整的诊断。

![探头-轴间距产生 DC 偏置：间距不同，直流电平不同](/images/orbit-plots/fig5.png)

*（图源：Simcenter Testing Knowledge Base）*

上图的两组工况说明 DC 的来源：探头安装位置相对轴承中心存在固定偏差，该偏差线性映射为输出电压的直流电平。轨迹形状（AC）相同时，DC 告诉你轴心整体偏向哪一侧——例如立式泵推力轴承磨损后轴心下沉，正是靠 DC 位置图的趋势监测捕捉的。

![轴涡动产生交变信号：绿色波动叠加在红色虚线 DC 电平上](/images/orbit-plots/fig6.png)

*（图源：Simcenter Testing Knowledge Base）*

上图是轴开始涡动后的完整信号：交变的 AC 波形骑在 DC 电平上。注意一个要点——**两幅图的轨迹形状完全相同，仅 DC（圆心位置）不同**。这解释了为什么轨迹图（只用 AC）与中心位置图（只用 DC）必须成对使用。
### 2.4 双探头正交合成：轨迹的数学构造

一只探头只给出一维信息（轴在该方向的位移）。在同一平面内加第二只探头、彼此成 90 度，就得到 $x(t)$、$y(t)$ 两路正交分量：

$$\begin{cases}x(t)=X_0+A_x\cos(\Omega t+\varphi_x)\\[4pt]y(t)=Y_0+A_y\cos(\Omega t+\varphi_y)\end{cases}$$

其中 $\Omega$ 为转频（rad/s），$X_0$、$Y_0$ 为 DC 分量，$A_x$、$A_y$、$\varphi_x$、$\varphi_y$ 为两方向涡动幅值与相位。以 $x$ 为横轴、$y$ 为纵轴逐点作图，消去时间参数 $t$ 即得轨迹方程。分三种情形看形状：

**情形一：相位差 90 度且两方向幅值相等**。令 $\varphi_x=0$、$\varphi_y=90^\circ$，则 $x=A\cos\Omega t$，$y=A\cos(\Omega t+90^\circ)=-A\sin\Omega t$，两式平方相加：

$$x^2+y^2=A^2$$

正圆。这就是**纯不平衡**主导的轨迹：同步涡动幅值各向均匀。

**情形二：$A_x \neq A_y$、相位差仍 90 度**。$x=A_x\cos\Omega t$，$y=-A_y\sin\Omega t$，消元得：

$$\frac{x^2}{A_x^2}+\frac{y^2}{A_y^2}=1$$

椭圆，长轴沿刚度低（幅值大）的方向。轴承**各向异性刚度**或**不对中预载**压扁了其中一个方向。

**情形三：相位差不是 90 度**（叠加了非同步成分或多频成分）。轨迹不再闭合为规则椭圆，出现内环、花瓣或乱线——判读信息恰恰藏在这里（见第四节油膜失稳的“8”字轨迹）。

![两路正交波形对画成轨迹：X/Y 波形（左）、合成过程（中）、紫色轨迹（右）](/images/orbit-plots/fig7.png)

*（图源：Simcenter Testing Knowledge Base）*

上图把合成过程动画化：左图两只探头各自的波形，中图同步采样序列，右图逐点对画出的紫色闭合轨迹。**轨迹的绘制方向（顺/逆时针）也有物理含义**——它由相位关系决定，正常同步涡动的方向与轴自转方向一致（前向涡动），碰摩等故障会出现反向涡动段。

### 2.5 键相器：给轨迹装上“零刻度”

**键相器（Keyphasor）**是第三只传感器：轴上做一个标记（键槽或反光片），每转经过探头时产生一个电压脉冲。它提供两个不可替代的信息：

1. **转频/转速**：脉冲间隔的倒数即瞬时转速，也是角度域重采样的基准
2. **相位基准**：轨迹上的脉冲点告诉分析者“轴转到哪个角度时轴心在这个位置”——两平面轨迹的相位对比、轨迹起点/终点的判断全靠它

![键相脉冲（黑）叠加在两路探头波形（绿/蓝）上，每转一个尖峰](/images/orbit-plots/fig8.png)

*（图源：Simcenter Testing Knowledge Base）*

键相点在轨迹图上画成一个亮点缺口。下图中红、蓝两条曲线分别是两转的轨迹，键相点（黑圈）重合良好说明运动稳定、轨迹逐转可重复；若键相点逐转漂移，说明存在显著的非同步成分或转速不稳。

![两转轨迹（红/蓝）与键相标记点（黑圈）：点重合代表运动可重复](/images/orbit-plots/fig9.png)

*（图源：Simcenter Testing Knowledge Base）*

::: warning 工程注意
键相标记必须安装在被测轴上（与探头同一根轴），不能取自减速箱另一根轴再折算——扭振与转差会让折算相位失真。四冲程发动机一个工作循环 720 度，若关注燃烧阶次（0.5 阶整数倍），键相与角度域循环定义都要按 720 度配置，否则相位逐循环翻转。
:::

### 2.6 滤波与未滤波：同一份数据的两种视图

- **未滤波轨迹（Unfiltered / Direct Orbit）**：X/Y 原始波形直接对画，包含全部阶次与频率成分。它最“真实”，但多种成分叠在一起时轨迹杂乱，难以归因
- **滤波轨迹（Filtered Orbit）**：先用阶次跟踪或带通滤波提取指定阶次（如 1X，即转频一阶）的复数幅值，再用两方向该阶次的幅值与相位重构轨迹。只看目标成分，形状干净，用于把某一疑点（如不平衡的 1X）单独拎出来验证

![未滤波（左）与 1X 滤波（右）轨迹的对比](/images/orbit-plots/fig10.png)

*（图源：Simcenter Testing Knowledge Base）*

上图左：未滤波轨迹叠加了多种频率成分，环线杂乱；右：仅保留 1X 成分后轨迹成为干净的椭圆。工程流程通常是**先看未滤波找异常，再滤波定位到具体阶次验证假设**——滤波后若 1X 轨迹是规则椭圆而未滤波轨迹杂乱，说明杂乱来自非同步成分（如油膜涡动、碰摩），问题不止不平衡一项。

::: tip 视图选择原则
- 日常趋势监测：未滤波轨迹 + 总体位移幅值
- 不平衡量评估与动平衡配重计算：1X 滤波轨迹（幅值相位直接进影响系数法）
- 疑似油膜失稳（次同步成分）：看未滤波轨迹上是否叠加内环，并用全谱瀑布图确认约 0.42~0.48X 分量
:::
## 三、用 Python 从波形合成轨迹

数值演示最直观。下面构造一台 3000 rpm（转频 50 Hz）转子，X/Y 各含 1X 涡动幅值 40/25 µm（相位差 90 度，模拟水平刚度低），叠加少量噪声与一个 0.45X 次同步分量模拟油膜涡动。逐点对画，直接得到轨迹及键相点。

```python
import numpy as np

fs = 12800                      # sampling rate, Hz
rpm = 3000.0
f1 = rpm / 60                   # shaft frequency 50 Hz
t = np.arange(0, 0.1, 1/fs)     # 0.1 s = 5 revs
rot = 2*np.pi*f1*t

# 1X synchronous whirl: X amp 40 um, Y amp 25 um, phase 90 deg
X = 40.0*np.cos(rot)
Y = 25.0*np.sin(rot)
# add 0.45X subsynchronous (oil whirl) plus noise
sub = 2*np.pi*0.45*f1*t
X += 10.0*np.cos(sub + 0.3); Y += 8.0*np.sin(sub + 0.3)
rng = np.random.default_rng(1)
X += rng.normal(0, 1.0, X.size); Y += rng.normal(0, 1.0, Y.size)

# keyphasor: one mark per revolution, at zero-crossing of shaft angle
key_idx = np.where(np.diff(np.signbit(np.mod(rot, 2*np.pi))))[0]
print("max displacement pp: %.1f um" % (2*np.sqrt(X**2+Y**2).max()))
print("1X ellipse axes: %.0f x %.0f um" % (2*40, 2*25))
print("keyphasor marks: %d in 0.1 s (%d revs)" % (key_idx.size, round(0.1*f1)))
```

运行结果要点：最大位移峰峰值明显大于 1X 椭圆的两倍长轴（80 µm），因为 0.45X 分量与 1X 分量的幅值最大点随时间缓慢错相、叠加出更深的开合；键相点数应恰为 5，即 0.1 秒内 5 转、转频 50 Hz。把 `sub` 项幅值改为零重跑，轨迹立即回到干净椭圆——这就是滤波前后的数值版本。
## 四、从轨迹形状读故障：三类典型判据

轨迹形状是旋转机械故障的指纹。三类最常见故障的判读判据汇总如下（对应图自上而下：圆、椭圆、双环）：

![三种典型轨迹：圆形-不平衡（上）、椭圆-受限制力（中）、双环-流体失稳（下）](/images/orbit-plots/fig_faults.png)

*（图源：Simcenter Testing Knowledge Base）*

### 4.1 圆形轨迹：不平衡

不平衡（Unbalance）时轴的重心不在旋转轴线上，离心力随转速平方增长，轴心做纯同步（1X）前向涡动。各向刚度近似相同时轨迹为**正圆**，直径直接正比于不平衡量。判据：

| 特征 | 圆形轨迹（不平衡） |
| --- | --- |
| **形状** | 正圆，未滤波与 1X 滤波基本一致 |
| **频率成分** | 能量几乎全部在 1X |
| **键相点** | 每转一点、逐转重合，轨迹起点稳定 |
| **随转速** | 幅值按离心力规律（正比转速平方）向临界转速放大 |

圆的直径越大不平衡越重，配重计算直接用 1X 滤波轨迹的幅值与相位（配合影响系数或模态平衡法，参见动平衡专题）。

### 4.2 椭圆轨迹：径向受限与不对中

椭圆说明**某一个方向的运动被限制**了。长轴是自由方向，短轴是受限方向。两种最常见成因：

- **轴承刚度各向异性**：例如水平方向支撑刚度低于垂直方向（油膜刚度、支座刚度不一致），水平幅值大、竖直幅值小，椭圆长轴躺平
- **轴系不对中（Misalignment）预载**：联轴器强制把轴拉向一侧，产生定向恒力（预载荷），压缩该方向涡动空间，轨迹被压扁，且常伴随 2X 成分增强

判据：椭圆扁度（短轴/长轴比）量化受限程度；DC 中心位置图配合看轴心是否被压向间隙一侧；2X 分量显著（未滤波轨迹出现扁平香蕉形或双线）指向不对中而非单纯刚度差。
### 4.3 双环/内8字轨迹：流体动压失稳

滑动轴承（Fluid Film Bearing / 油膜轴承）依赖轴与轴承之间的一层油膜支撑转轴。轴旋转带动油膜流动，油膜平均流速约为轴表面速度的一半（约 0.5X）。油膜对轴的作用力可分解为径向与切向分量：**径向分量支撑转轴，切向分量推动轴心沿切向涡动**。

转速升高到某阈值后，切向力超过阻尼力，系统失稳——轴心以接近油膜平均流速的频率（约 0.42~0.48X）做大振幅涡动，称为**油膜涡动（Oil Whirl）**；严重时油膜频率锁定到转轴一阶临界转速频率上，振幅急剧增大，称为**油膜振荡（Oil Whip）**。轨迹特征：

| 特征 | 油膜涡动/振荡 |
| --- | --- |
| **形状** | 未滤波轨迹出现内环（双环/8字），1X 环内再套次同步环 |
| **频率成分** | 显著次同步峰，约 0.42~0.48X（涡动）；whip 时锁定在一阶临界频率 |
| **随转速** | 涡动频率跟随转速的约 0.45 倍上移；whip 后转速继续升、频率不再变 |
| **危害** | 振幅大且不稳定，属于必须立即停机处理的失稳故障 |

内环的成因一句话：**1X 同步涡动与 0.45X 次同步涡动两个不同频率的椭圆运动叠加**，逐点合成即出现环内套环——正如第三节数值演示里叠加 0.45 倍频分量后的轨迹。

::: info 三类故障对照速查
- **圆** 指向不平衡：1X 主导，直径正比于不平衡量，键相点稳定
- **椭圆** 指向刚度各向异性/不对中：长短轴比量化受限方向，2X 增强指向不对中
- **双环** 指向油膜涡动/振荡：约 0.45X 次同步，内环出现即查油膜，whip 锁频立即停机
:::
## 五、在 Simcenter Testlab 中生成轴心轨迹

Simcenter Testlab Revision 2021.2 及以上版本内置轴心轨迹处理，链路如下：

1. **开插件**：Tools 菜单 Add-ins 勾选 Rotor Dynamics，同时启用 Signature Throughput Processing、Angle Domain Analysis 与 Customized Metrics Calculator（共需 88 tokens：Angle Domain Processing 42 + Signature Throughput Processing 26 + Rotor Dynamics 20）
2. **装入数据**：Navigator 中右键 X/Y 探头与键相的时域数据选 Replace in Input Basket；Time Data Selection 工作表确认数据源为 Input Basket 并点 Replace
3. **设置四大参数区**（Rotor Dynamics 工作表）：
   - **Rotor Parameters**：选键相信号；探头方向信息正确时可 Auto select X-Y pairs；设定旋转方向与探头角位置用于轨迹标注
   - **AD Resampling Parameters**：角度域重采样的转速通道与每转点数
   - **Acquisition Parameters**：计算轨迹的转数（如 20 转）
   - **Processing**：勾选 Orbit，可同时输出 Centerline、Polar、Full Spectrum 瀑布图；支持慢转补偿（Slow Roll Compensation，扣除低速下的原始晃动）
4. **出图**：计算结果存入当前 section；Navigator 里 Create a Picture 选 Orbit，把数据拖入显示区即得未滤波轨迹，滤波轨迹在显示属性中切换

::: warning 工程注意
X/Y 两通道的尺度（灵敏度）与滤波带宽必须一致，否则轨迹形状失真，圆会被画扁。探头角位置（如 45 度/135 度安装）要如实填入软件，坐标旋转不对会错判涡动方向。两通道存在增益/相位失配时，先做通道匹配标定再采轨迹数据。
:::

## 六、小结

轴心轨迹图的判读可以直接给出一组工程判断标准：

- 轨迹图由**两路正交位移波形的 AC 分量对画**而成，DC 分量另给中心位置图，两者成对使用
- **正圆 = 不平衡**，直径给不平衡量级，1X 滤波轨迹的幅值相位直接进动平衡计算
- **椭圆 = 单向受限**，先查轴承刚度各向异性，再查不对中（2X 增强是关键佐证）
- **内环/双环 = 次同步失稳**，先确认约 0.45X 油膜涡动，一旦频率锁定一阶临界（whip）立即停机
- 键相点是轨迹的时间刻度：点漂移量直接量化非同步成分占比
- Testlab 的 Rotor Dynamics 插件（2021.2 以上，88 tokens）从时域数据一键出轨迹、中心位置、全谱瀑布与极坐标图，慢转补偿功能可剔除轴本身的不圆度干扰
