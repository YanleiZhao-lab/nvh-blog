# 声功率测量：半球包络法与K1/K2修正

> 一台设备"多吵"用声压级说不清：麦克风放 1 m 还是 2 m、放正面还是背面，读数能差出好几个 dB，验收条款里没写距离就等于给人留了操作空间。声功率把距离和方位两个变量一起消掉，靠的是"包络面能量平均 + 表面积补偿"这套构造。本文从半球阵列的公式推起，讲清 K1 背景修正与 K2 反射修正各自的物理账，以及什么时候该放弃修正直接换场地。

## 一、为什么声压级回答不了"这设备多吵"

拿麦克风对着声源读一个 dB 值，是最直觉的操作，也是最不靠谱的操作。问题出在两个自由度上：

**距离**。自由场里距离每翻一倍，声压级掉 6 dB。1 m 处测 78 dB 的音箱，2 m 处就只剩 72 dB。如果验收条款写"不得超过 50 dB"却没规定测点距离，把麦克风往后挪几米就能"合格"——数字游戏而已。

![距离不同，同一声源的声压级读数不同](/images/sound-power-measurement/mic-1m2m.png)

*（图源：Simcenter Testing Knowledge Base）*

**方位**。就算距离锁死，绕着设备转一圈读数也不一样：音箱正面的麦克风和背面的麦克风，看到的声辐射强度完全不同。

![同一距离不同方位的麦克风，读数各不相同](/images/sound-power-measurement/mic-positions.png)

*（图源：Simcenter Testing Knowledge Base）*

声功率（Sound Power，单位瓦特）的设计目标就是把这两个变量同时消掉：**量化声源本身的辐射强度，与测点距离、方位无关**。这也是为什么法规认证、供应商与主机厂之间的对赌条款，用的都是声功率级而不是声压级。

::: info 核心概念
- **声功率 W**：声源每秒辐射的总声能，单位 W，是声源的固有属性
- **声功率级 Lw**：Lw = 10·lg(W/W₀)，参考功率 W₀ = 1 pW（10⁻¹² W）
- **包络面**：假想把声源包起来的闭合面（半球面、箱形面），声功率 = 声强在面上的积分
:::

## 二、半球包络法：公式是怎么构造出来的

### 2.1 测量布置

工程上最常见的做法：把设备放在硬质反射地面上，用一圈麦克风在半球面上把它围起来。

![半球形麦克风阵列包络被测设备：左为测点布置图，右为实际测试系统](/images/sound-power-measurement/hemisphere-array.png)

*（图源：Simcenter Testing Knowledge Base）*

半球法的完整公式（手册 Equation 1）拆成两块看：

$$L_W = \overline{L_P} + 10\lg\frac{S}{S_0}$$

- $\overline{L_P}$：所有麦克风声压级的**能量平均**（不是算术平均）
- $S$：测量面面积，半球面 $S = 2\pi r^2$；参考面积 $S_0 = 1\ \mathrm{m^2}$

### 2.2 能量平均：为什么不能直接加起来除以个数

声压级是对数量，平均必须在能量域做。设 $N$ 个测点声压级为 $L_{P,i}$，各点声压平方 $p_i^2 = p_0^2 \cdot 10^{L_{P,i}/10}$（其中 $p_0 = 20\ \mu\mathrm{Pa}$），则：

$$\overline{L_P} = 10\lg\left(\frac{1}{N}\sum_{i=1}^{N} 10^{L_{P,i}/10}\right)$$

推导的物理依据是能量守恒：通过包络面的总功率等于各测点局部声功率之和，而功率正比于声压**平方**，所以必须先把 dB 还原成 $p^2$ 平均，再取对数回去。算术平均会系统性偏低——十个测点里有一个 80 dB 的热点，算术平均把它当"80"看待，能量平均把它当"10 倍于 70 dB 的能量"看待，后者才是真相。

### 2.3 表面积补偿：小半球大声压、大半球小声压，乘积不变

公式第二项 $10\lg(S/S_0)$ 是距离无关性的关键。看手册的打印机算例：声功率 0.02 W 的设备，声功率级 $L_W = 10\lg(0.02/10^{-12}) = 103$ dB。在三个半径的半球面上分别测：

| 半球半径 r | 面积 S = 2πr² | 声压级 Lp | Lp + 10lg(S) |
| --- | --- | --- | --- |
| **1 m** | 6.28 m² | 95.0 dB | **103.0 dB** |
| **2 m** | 25.13 m² | 89.0 dB | **103.0 dB** |
| **4 m** | 100.53 m² | 83.0 dB | **103.0 dB** |

半径从 1 m 拉到 4 m，声压级掉了 12 dB，但面积项 $10\lg(S)$ 恰好补回来 12 dB，Lw 纹丝不动。这就是公式的构造逻辑：

![半球剖面：麦克风离源近则声压高但面积小，离源远则声压低但面积大，两者乘积恒定](/images/sound-power-measurement/hemisphere-cross-section.png)

*（图源：Simcenter Testing Knowledge Base）*

![手册中声功率基本公式的构成](/images/sound-power-measurement/equation1-sound-power.png)

*（图源：Simcenter Testing Knowledge Base）*

::: warning 工程注意
能量平均 + 表面积补偿的前提是"除地面反射外无其他反射、无其他声源"。这个理想条件在 CAE 仿真里天然成立，在普通厂房里几乎从来不成立——所以需要第三、四节的修正项。测点数量与布置阵列必须按标准（如 ISO 3744）执行，随意减点省时间，能量平均的空间采样误差直接进结果。
:::

## 三、K1 背景修正：能量域做减法

公式假设环境里只有被测设备在响。现实中厂房有通风、有邻位设备，麦克风收到的是"设备 + 背景"的总声级。K1 的做法：设备不开机先测一遍背景，再把背景贡献从总声级里扣掉。

能量域的减法推导：设某倍频程带测得总声压平方 $p_{tot}^2$，背景声压平方 $p_{bg}^2$，设备自身贡献 $p_{src}^2 = p_{tot}^2 - p_{bg}^2$。取 10lg：

$$L_{src} = 10\lg\left(10^{L_{tot}/10} - 10^{L_{bg}/10}\right) = L_{tot} + K_1,\quad K_1 = 10\lg\left(1 - 10^{-\Delta/10}\right)$$

其中 $\Delta = L_{tot} - L_{bg}$ 是级差。级差越大，K1 越接近 0（无需修正）；级差越小，修正越猛、结果越不可信。手册给出的三条判据：

| 级差 Δ（总级−背景级） | K1 修正量 | 处理方式 |
| --- | --- | --- |
| **Δ < 0** | 无意义 | 背景比设备还响，**整个测试作废** |
| **Δ ≥ 15 dB** | −0.14 dB 以内 | 修正量可忽略，**不再修正** |
| **6 dB ≤ Δ < 15 dB** | −1.3 ~ −0.1 dB | 按公式逐倍频程带修正 |
| **Δ < 6 dB** | 超过 −1.3 dB | 结果存疑，标准通常不允许 |

注意 K1 全部按**倍频程带**逐带进行——某个带背景安静不代表所有带都安静，中频设备放在高频风机旁边，总级差 10 dB 掩盖了高频带级差只有 3 dB 的事实。

## 四、K2 反射修正：用标准声源给场地"体检"

公式的另一个隐含假设是墙面吸收完美（除地面反射面外）。普通测试间的墙面反射会把声压级整体抬高，算出来的 Lw 偏大。K2 的思路很巧：**用一个声功率已知、且可复现的标准声源（Reference Sound Source）在同一场地测一遍**。

推导逻辑：标准源标称某倍频程带声功率 90 dB，在该场地实测 91 dB。多出来的 1 dB 不是标准源变了，而是场地反射的贡献。假设被测设备与标准源受到同样的反射"加成"，把这部分从被测结果里扣掉：

$$L_W = \overline{L_P} + 10\lg\frac{S}{S_0} - K_1 - K_2$$

![虚拟 CAE 仿真中的声功率测试：没有多余背景噪声与反射的理想环境](/images/sound-power-measurement/cae-virtual-test.png)

*（图源：Simcenter Testing Knowledge Base）*

K2 与 K1 一样逐倍频程带操作。反射对低频带的影响往往比高频大（低频波长与房间尺寸可比，驻波效应显著），一刀切的 K2 会漏掉频带间的差异。

::: warning 工程注意
K1/K2 是"限值内的补救"不是无限信用卡。背景贴近被测源、或 K2 修正量大到离谱，说明场地根本不适合声压法声功率测试——正确动作是换消声室/半消声室，或改用声强法（ISO 9614 系列，可在普通现场测）。硬修出来的数，认证复测对不上，责任在测试方。
:::

## 五、Python 演示

### 5.1 半球法的不变性

```python
import numpy as np

W = 0.02                      # 声功率 0.02 W（手册打印机算例）
W0, p0, rho_c = 1e-12, 20e-6, 400.0   # 参考功率、参考声压、空气特性阻抗

print(f"声功率级 Lw = {10*np.log10(W/W0):.1f} dB（理论值，与距离无关）")
for r in [1.0, 2.0, 4.0]:     # 三个不同半径的半球测量面
    S = 2 * np.pi * r**2      # 半球表面积
    I = W / S                 # 面上平均声强 = 功率/面积
    Lp = 10*np.log10(I * rho_c / p0**2)   # 换算成声压级
    Lw = Lp + 10*np.log10(S / 1.0)        # 加回表面积项
    print(f"r={r} m: S={S:6.2f} m2  Lp={Lp:.1f} dB  Lp+10lg(S)={Lw:.1f} dB")
```

半径 1 m 处声压级 95.0 dB、4 m 处掉到 83.0 dB，但三行末列全部回到 103.0 dB——距离变化被面积项精确吞掉，这就是声功率"与测点距离无关"的数值体现。

### 5.2 能量平均 vs 算术平均

```python
import numpy as np

p0 = 20e-6                                  # 参考声压
Lp = np.array([72, 75, 68, 80, 77, 73, 79, 71, 74, 76.])  # 10 个测点声压级

p2 = p0**2 * 10**(Lp/10)                    # dB 还原到声压平方（能量域）
Lp_energy = 10*np.log10(p2.mean() / p0**2)  # 能量平均再取对数
Lp_arith  = Lp.mean()                       # 错误做法：直接平均 dB

print(f"能量平均 Lp = {Lp_energy:.2f} dB")
print(f"算术平均 Lp = {Lp_arith:.2f} dB（偏低 {Lp_energy - Lp_arith:.2f} dB）")
```

最值得看的数字：能量平均 75.81 dB，算术平均 74.50 dB，差 1.31 dB——十个测点里那几个 80 dB 上下的热点主导了能量账本，直接平均 dB 会把它们的权重悄悄抹平。报告里写错平均方式，等于给结果埋了一个系统偏低项。

### 5.3 K1 修正量表

```python
import numpy as np

print(f"{'级差 Δ(dB)':>10} {'K1(dB)':>8} {'修正后误差若忽略':>14}")
for d in [15, 10, 6, 4, 3]:                  # 总声级与背景级的差
    k1 = 10*np.log10(1 - 10**(-d/10))        # K1 = 10lg(1-10^(-Δ/10))
    print(f"{d:>10} {k1:>8.2f} {-k1:>13.2f} dB")
```

级差 15 dB 时 K1 只有 −0.14 dB（忽略不计，标准据此免修正）；级差 6 dB 时已到 −1.26 dB；级差 3 dB 时 K1 高达 −3.02 dB——背景和设备一样响，能量域里两者各占一半，再修就是在两个大数里抠一个小数，任何测量波动都被放大。

## 六、结果长什么样，以及怎么用

声功率测试的最终交付物通常是 **A 计权倍频程谱**——横轴倍频程带、纵轴以 1 pW 为参考的 dB 值：

![声功率测试结果：A 计权倍频程谱](/images/sound-power-measurement/octave-spectrum.png)

*（图源：Simcenter Testing Knowledge Base）*

拿到谱之后的典型用法：

- **对标限值**：法规或验收条款逐倍频程带给限值，超带即不合格，总 A 计权值只是汇总指标
- **对比迭代**：同一产品降噪改款前后，逐带对比谱形，比单看总值信息量大得多
- **跨场地可比**：正因为 K1/K2 把环境差异剥离掉，不同实验室的数据才有可比性

| 应用场景 | 用声功率级的原因 |
| --- | --- |
| **出口认证（如欧盟指令）** | 法规限值挂在声功率上，与安装位置无关 |
| **供应商验收条款** | 双方不在一个场地测，声功率是唯一公平基准 |
| **产品对标与改款评估** | 消除测量距离/方位的变量，谱形可直接比 |
| **声源排序（排查）** | 多台设备各自的声功率相加即总贡献，声压级不能直接加 |

::: tip 实用建议
- 手里有消声室/半消声室 → 声压法半球阵列（ISO 3744 系），精度最高、认证认可度最高
- 只有普通现场 → 声强法（ISO 9614 系列），对稳态背景不敏感，还能顺手拿声强云图定位源
- 测前必做背景噪声预查：先算各倍频程带级差，Δ 不足 6 dB 的带提前预警，别等测完才发现作废
:::

## 七、小结

声功率公式的两个构件各管一个变量：能量平均消方位，表面积补偿消距离，K1/K2 再把背景与反射这两个环境变量扣掉——四件事做完，剩下的数才真正属于设备本身。判断一个声功率测试可不可信，顺序是：先查背景级差够不够 6 dB、再查 K2 修正量是否离谱、最后核对测点阵列是否符合标准——三关全过，数据才拿得出手。
