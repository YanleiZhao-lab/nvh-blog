# 调制阶次与边带：彩色图谱上对称亮线的病灶读法

> 变速箱台架升速扫频，彩色图谱（Colormap）上 62 阶啮合线两侧对称地长出 60 阶和 64 阶两条"伴线"——这不是三个故障源，而是一个。阶次被调制后产生边带（Sideband），边带的间距直接指向病灶：偏心齿轮每转推拉两次，边带就出现在主阶 ±2 处。这篇从偏心齿轮的受力机理推到调幅公式，讲清边带间距怎么当"诊断书"用，以及为什么齿轮厂会故意把齿轮做偏一点。

## 一、图谱上的"一拖二"现象

先看一张典型的彩色图谱。62 齿齿轮啮合，正常情况下图谱上应该只有一条 62 阶斜线（频率随 rpm 走），实际测到的却是三条：中间 62 阶，上下对称挂着 60 阶和 64 阶。

![62阶调制阶次的彩色图谱](/images/modulated-order-sidebands/fig7_colormap.png)

*62 阶啮合阶次每转被调制两次，长出 60、64 阶边带（图源：Simcenter Testing Knowledge Base）*

初学者最容易犯的错误，是拿着阶次计算器去找"60 齿的齿轮"和"64 齿的齿轮"——整机里根本没有这两个件。边带不是独立的物理事件，它是主阶被调制后的数学产物：**60 阶和 64 阶的能量，来自 62 齿啮合本身**。

::: info 核心概念
- **调制阶次（Modulated Order）**：幅值随转角周期变化的阶次，在图谱上表现为一条"串珠状"或两侧带伴线的斜线
- **边带（Sideband）**：主阶两侧等间距分布的阶次分量，间距等于调制频率对应的阶次
- **边带间距 k**：主阶 ±k 处出现边带，意味着调制源每转动作 k 次
:::

## 二、偏心齿轮怎么制造边带

手册里给了一个直观的机理：一对齿轮，齿轮 1 是正圆，齿轮 2 加工时滚齿偏差导致椭圆化（偏心）。两齿轮啮合时，椭圆齿轮每转一圈会把齿轮 1 **推开又拉回两次**。

![偏心齿轮副](/images/modulated-order-sidebands/fig8_eccentric.png)

*齿轮 1 正圆，齿轮 2 偏心椭圆（图源：Simcenter Testing Knowledge Base）*

![偏心导致每转两次推拉](/images/modulated-order-sidebands/fig9_pushpull.png)

*中心距每转变化两次，啮合力随之被调制（图源：Simcenter Testing Knowledge Base）*

物理图景是这样的：齿轮 2 每转一圈，其椭圆轮廓让实际中心距经历两个"远-近"循环。中心距变化 → 啮合间隙变化 → 啮合冲击的强度每转起伏两次。如果齿轮是正圆，中心距恒定，绿色曲线是一条平线，什么调制都不会发生。

### 从机理到公式

设轴频为 $f_{shaft}$（每秒转数），62 齿啮合频率 $f_m = 62 f_{shaft}$。啮合力幅值被"每转两次"的推拉调制，相当于啮合信号乘上一个 $[1 + m\cos(2\pi \cdot 2f_{shaft} t)]$ 的包络，$m$ 是调制深度：

$$x(t) = A\,[1 + m\cos(2\pi \cdot 2f_{shaft} t)]\cos(2\pi \cdot 62 f_{shaft} t)$$

用积化和差 $\cos\alpha\cos\beta = \tfrac{1}{2}[\cos(\alpha-\beta) + \cos(\alpha+\beta)]$ 展开第二项：

$$x(t) = A\cos(2\pi \cdot 62 f_{shaft} t) + \frac{mA}{2}\cos(2\pi \cdot 60 f_{shaft} t) + \frac{mA}{2}\cos(2\pi \cdot 64 f_{shaft} t)$$

三根谱线就此现身：62 阶载波保持幅值 $A$，两侧 60、64 阶边带各分得 $mA/2$。**推导直接给出诊断逻辑：边带出现在主阶 ±k 处，k 就是调制源每转的动作次数。** 反过来读图谱：边带间距 2 → 疑似椭圆偏心；间距 1 → 疑似齿轮安装偏心（每转一次）。

## 三、边带间距就是诊断书

把常见的调制源整理成对照表，读图谱时按"主阶 ± k"反查：

| 调制源 | 每转调制次数 k | 62 阶的边带位置 | 典型特征 |
| --- | --- | --- | --- |
| **椭圆偏心齿轮（滚齿偏差）** | 2 | 60、64 阶 | 边带成对对称，幅值相等 |
| **齿轮与轴不同心（安装偏摆）** | 1 | 61、63 阶 | 单间距边带，常伴 1 阶升高 |
| **齿形误差/载荷波动** | 1 或多 | 61、63 阶起 | 边带族更密，需倒频谱确认 |
| **相邻轴载荷耦合** | 速比相关 | 间距=另一轴阶次 | 边带不随本轴整数阶变化 |

::: warning 工程注意
- 边带阶次**没有对应的物理部件**：图谱上看到 60 阶就去找 60 齿齿轮，是南辕北辙
- 边带间距要用阶次域（不是频率域）读——频率域上间距随转速变，阶次域上间距恒为 k，这才是调制源的指纹
- 调制不只发生在幅值上：离合器颤振、轴承缺陷、负载波动都会调制，机理同源
:::

## 四、Python 演示：复现边带的诞生

用 numpy 仿真一个偏心齿轮的啮合加速度信号，在**角度域**做 FFT，看 62 阶两侧的边带如何出现，以及间距怎么随调制次数变化。

```python
import numpy as np

# 仿真参数：62 齿齿轮，轴频 20 Hz，采样率与每转点数固定（角度域均匀采样）
shaft_hz = 20.0
n_rev = 64                 # 总转数
pts_per_rev = 512          # 每转采样点数
N = n_rev * pts_per_rev
rev = np.arange(N) / pts_per_rev          # 转数坐标（角度域的"时间轴"）
t = rev / shaft_hz

# 啮合信号：62 阶载波 + 椭圆偏心导致的每转 2 次调幅
order_mesh, order_mod, m = 62.0, 2.0, 0.6
carrier = np.cos(2*np.pi*order_mesh*rev)
env = 1 + m*np.cos(2*np.pi*order_mod*rev)
x = env * carrier

# 角度域 FFT：横轴单位是"阶次"
X = np.abs(np.fft.rfft(x) * 2/N)
orders = np.arange(N//2 + 1) / n_rev

# 找主阶和边带
for target in [62.0, 60.0, 64.0]:
    i = np.argmin(np.abs(orders - target))
    print(f"{orders[i]:6.1f} 阶  幅值 {X[i]:.3f}")

# 理论对照：边带幅值应为 m/2 = 0.30
print(f"理论边带幅值 m/2 = {m/2:.3f}")
```

输出里最值得看的两个数：60、64 阶边带幅值都是 0.300，正好落在理论值 $m/2$ 上；而 62 阶载波幅值保持 1.000 不受调制影响——积化和差推导的每一项都被数值验证了一遍。把 `order_mod` 改成 1，边带就跳到 61、63 阶，间距即指纹。

## 五、反直觉的权衡：偏心反而是设计特性

发现齿轮偏心，第一反应往往是"提高加工精度，做圆它"。从噪声控制角度看，这未必是对的。

啮合能量集中在一根 62 阶谱线时，那根线又高又细——单一频率的纯音，听感刺耳，响度峰值也高。能量被调制摊到三根谱线后，每根线的幅值都降了：载波旁边多了两根 $mA/2$ 的伴线，但主体能量被"稀释"。

![未调制与调制的阶次域对比](/images/modulated-order-sidebands/fig10_orderdomain.png)

*上图：正圆齿轮，能量集中单阶；下图：偏心齿轮，能量摊到边带（图源：Simcenter Testing Knowledge Base）*

![能量集中的单阶与分散的边带](/images/modulated-order-sidebands/fig11_energy.png)

*单阶幅值反而高于调制后的边带族——分散即衰减（图源：Simcenter Testing Knowledge Base）*

手册里说得直接：齿轮制造商**可以故意控制偏心量**，把啮合能量摊宽到频率范围上，让声音和振动峰值都降下来。这跟离合器从动盘上开螺旋槽、变速箱壳体加阻尼的处理思路同源——与其硬碰硬消峰值，不如把能量散掉。

::: tip 处理调制阶次的思路
- **判读优先**：先量边带间距定 k，反查调制源，别急着动齿轮精度
- **间距 2 + 边带对称** → 查齿形几何（椭圆度），评估是否在可接受范围
- **间距 1 + 1 阶同步升高** → 查齿轮与轴的同心度（安装问题），这个通常必须修
- **峰值响度是痛点** → 与其追求绝对圆，不如与供应商协商一个受控偏心量
- 载波、边带搅在一起分不开时，倒频谱（Cepstrum）能把等间距族折叠成单峰，是下一层的工具
:::

## 六、小结

三条判断标准带走：

1. **主阶 ±k 的边带 = 调制源每转动作 k 次**。间距 2 指向椭圆偏心，间距 1 指向安装偏心——在阶次域量间距，不要在频率域量。
2. **边带没有物理对应物**。60 阶边带不意味着 60 齿齿轮，它只是 62 阶能量被重新分配后的样子。
3. **调制不全是坏事**。受控偏心把能量摊宽、峰值摊低，是齿轮厂主动使用的设计手段；先判断痛点是"峰值高"还是"有调制"，再决定要不要修。
