# H1、H2、Hv：频响函数估计子，噪声在哪答案就偏在哪

> 模态测试拿到的频响函数（FRF）不是“测”出来的，是从带噪声的互谱、自谱里“估”出来的。H1、H2、Hv 是三种估计子：假设噪声全在输出端，H1 在反共振谷不会塌；假设噪声全在输入端，H2 在共振峰不会缩；两头都有噪声时 Hv 兜底。选错估计子，反共振谷深浅能差出 6 倍，这种数据拿去拟合模态，极点直接漂。

## 一、FRF 为什么需要“估计子”

理想线性系统里，输出谱等于输入谱乘频响函数：Y(f) = H(f)·X(f)，两边一除就是 H。问题在于实测的 x(t)、y(t) 永远混着噪声：力锤敲上去，测到的力除了真实激励还有锤头压电传感器的电噪声；加速度计信号里除了结构响应还有背景振动。直接拿两帧带噪谱一除，除出来的不是 H，是“H 被噪声污染后的混合物”。

三种估计子的差别，就在你假设噪声藏在哪一端：

- **H1 估计**：假设输入无噪声、噪声全在输出端，最小化输出噪声的影响，H1 = Syx/Sxx；
- **H2 估计**：假设输出无噪声、噪声全在输入端，最小化输入噪声的影响，H2 = Syy/Syx；
- **Hv 估计**：两头都认账，对输入输出同时做总体最小二乘。

::: info 核心概念
- **频响函数（FRF）**：输出谱与输入谱之比，一个响应自由度（DOF，分子）对一个参考自由度（分母），复数，含幅值与相位
- **H1 估计**：Syx/Sxx，噪声模型在输出端；若噪声实际在输入端，得到 FRF 的欠估计（幅值偏低）
- **H2 估计**：Syy/Syx，噪声模型在输入端；若噪声实际在输出端，得到 FRF 的过估计（幅值偏高）
- **Hv 估计**：取谱矩阵 [Sxx Sxy; Syx Syy] 最小特征值对应的特征向量为解，共振区接近 H2、反共振区接近 H1
- **相干函数**：γ² = |Syx|²/(Sxx·Syy)，恰好等于 |H1|/|H2|，两端噪声总量的照妖镜
- **反共振谷**：两阶模态相消处结构几乎不响应，输出信号极小、输出端噪声占比飙升
:::

## 二、欠估计与过估计的物理直觉

H1 假设噪声全在输出端。它拿 Syx/Sxx 做最小二乘：分子 Syx 里输出噪声与输入不相关，多帧平均后趋零，分母 Sxx 全是真实激励功率——所以 H1 对输出噪声天生免疫。但如果噪声其实混在输入端（力传感器漂移、吃锤不实），分母 Sxx 被噪声功率抬高，H1 被系统性压低，这就是**欠估计**。

H2 反过来。它假设输出干净、噪声全在输入端，拿 Syy/Syx：输出里的全部能量——包括没被力传感器看到的那部分——都被记在分子上，分母 Syx 又被输入噪声稀释，两头一起把幅值顶高，**过估计**。注意 H2 只在单输出情况下可直接计算，多输入多输出（MIMO）要用广义逆。

一条硬关系把三者锁死：|H1| = γ²·|H2|。相干低的地方，H1 与 H2 分道扬镳；相干接近 1 的地方，三者几乎重合。

### 共振区 vs 反共振区，谁信谁

共振峰处，结构把激励放大几十倍，输出端的电噪声相对可忽略，主要误差源换成输入端——吃锤不实、力通道信噪比低，该信 H2。反共振谷处正相反：结构几乎不响应，加速度信号本身就快和背景振动一个量级，噪声格局翻成“偏输出端”，该信 H1。Hv 在共振区贴近 H2、反共振区贴近 H1，两头都占住，代价是每个频率点都要做谱矩阵特征分解，计算时间比 H1/H2 长。

| 场景 | 噪声格局 | 推荐估计子 | 选错的代价 |
| --- | --- | --- | --- |
| **共振峰** | 输出被结构放大，噪声占比自动下降；输入端是主要误差源 | **H2**（或 Hv） | 用 H1，峰值压低，拟合阻尼偏大 |
| **反共振谷** | 输出几乎为零，输出端噪声占比飙升 | **H1**（或 Hv） | 用 H2，谷被填平甚至翻起假峰 |
| **频带整体判读** | 两端都有噪声 | **Hv** | 只用 H1，全带幅值系统性偏低 |
| **MIMO 多输入** | 输入间相关时 Sxx 病态 | Hv，或 H1 加主分量鉴别 | 直接对 Sxx 求逆，矩阵接近奇异、FRF 出毛刺 |
| **锤击测试** | 力窗保证输入干净，输出端两次敲击之间全是背景 | **H1** | 用 H2，反共振区虚高数倍（见下文演示） |
| **激振器随机激励** | 力谱平坦，两端信噪比都不差 | **Hv** | — |

## 三、Python 演示：同一组数据，三个估计子在峰谷处各偏多少

双自由度系统（约 16 Hz 与 27.5 Hz 两阶模态、22.5 Hz 反共振），均匀谱随机激励、30 帧平均，输入输出两端各加 5% 噪声：

```python
import numpy as np

np.random.seed(7)
fs, T, nb = 200, 4.0, 30                          # 采样率/帧长/平均帧数
N = int(fs*T); f = np.fft.rfftfreq(N, 1/fs)
M = np.eye(2); K = np.array([[2e4,-1e4],[-1e4,2e4]]); C = 1.5e-4*K
H = np.array([0j] + [np.linalg.solve(K + 2j*np.pi*fi*C - (2*np.pi*fi)**2*M,
                                     np.eye(2))[0,0] for fi in f[1:]])
H = H/np.abs(H).max()                             # 真值 FRF，归一化便于读数
Sxx = np.zeros(len(f)); Syy = np.zeros(len(f)); Sxy = np.zeros(len(f), complex)
for _ in range(nb):                               # 30 帧谱平均
    XF = np.random.randn(len(f))                  # 均匀谱随机激励
    x = np.fft.irfft(XF); y = np.fft.irfft(H*XF)
    xm = np.fft.rfft(x + 0.05*x.std()*np.random.randn(N))   # 输入端 5% 噪声
    ym = np.fft.rfft(y + 0.05*y.std()*np.random.randn(N))   # 输出端 5% 噪声
    Sxx += abs(xm)**2; Syy += abs(ym)**2; Sxy += xm*np.conj(ym)
Sxx /= nb; Syy /= nb; Sxy /= nb
H1 = np.conj(Sxy)/Sxx                             # H1 = Syx/Sxx
H2 = Syy/Sxy                                      # H2 = Syy/Syx
gam = abs(Sxy)**2/(Sxx*Syy)                       # 相干 = |H1|/|H2|
Hv = np.zeros(len(f), complex)
for i in range(len(f)):                           # Hv：谱矩阵最小特征向量
    _, V = np.linalg.eigh([[Sxx[i], Sxy[i]], [np.conj(Sxy[i]), Syy[i]]])
    Hv[i] = -np.conj(V[0,0]/V[1,0])
mag = np.abs(H)
pk = sorted((i for i in range(1, len(f)-1) if mag[i-1] < mag[i] > mag[i+1]),
            key=lambda i: -mag[i])[:2]
lo, hi = sorted(pk); anti = lo + int(np.argmin(mag[lo:hi]))   # 定位两峰一谷
print("位置      频率Hz   真值    H1     H2     Hv    相干")
for tag, i in [("共振峰1", lo), ("反共振谷", anti), ("共振峰2", hi)]:
    print(f"{tag}  {f[i]:5.1f}  {mag[i]:.3f}  {np.abs(H1[i]):.3f}  "
          f"{np.abs(H2[i]):.3f}  {np.abs(Hv[i]):.3f}  {gam[i]:.3f}")
```

运行结果要点：共振峰上三个估计子几乎重合（真值 1.000，三者 0.985/0.988/0.987，偏差都在 1.5% 以内），相干 0.997——峰顶不需要挑估计子，谁都准。分水岭在反共振谷：真值 0.002，H1 与 Hv 老老实实贴着 0.002，H2 却报 0.010，虚高 6 倍，同一频率的相干跌到 0.159。低相干与 H2 虚高是同一个噪声的两种症状：谷越深、输出信噪比越差，H2 抬得越高。想保住谷形，要么换 H1/Hv，要么在谷区提高激励量级把输出从噪声里捞出来。

## 四、MIMO 的坑：H1 不只是除法

多台激振器同时激励时，H1 矩阵 Syx·Sxx 的逆要对输入谱矩阵求逆——输入信号彼此相关（比如由同一随机源移相生成）时 Sxx 接近奇异，求逆把噪声放大，FRF 到处长毛刺。手册给的解法是主分量分析：对 Sxx 做特征分解，不相关主分量的个数就是真正独立的激励源数，先把相关源鉴别出来再估计。这也是 lms-theory 手册强调“主分量谱的主要应用是确定信号组中不相关机械源的数目”的原因，MIMO 频响估计里它是前置步骤而非可选项。

::: warning 工程注意
锤击测试用 H2 有个隐藏陷阱：力窗把窗外的输入噪声抹掉，看起来“输入很干净”，但反共振谷里被填平的假响应其实来自输出端背景振动，H2 把这笔账全记到输入头上，谷底翻起假峰——锤击默认 H1 是有道理的。另一个极端是激振器测试只看 H1：共振峰被压低 (1-γ²) 的比例，小阻尼结构上拟合出的阻尼比能偏出两三成。判据始终是相干：峰区 γ² 上不去，先怀疑输入端；谷区 γ² 跌是物理必然，别急着扔数据。
:::

## 五、小结

拿到 FRF 先叠相干：共振峰 γ²>0.95 数据才可用；反共振谷 γ² 允许跌，但 H1 与 Hv 应保持谷形。选估计子三条判断标准：锤击用 H1（噪声偏输出端），激振器随机激励用 Hv（两端噪声都认账），只关心共振区极点且输入信噪比可疑时补一条 H2 交叉验证。|H1|/|H2| 就是 γ²，一条曲线同时读出噪声总量与估计子分裂程度——比单看任何一条 FRF 都诚实。
