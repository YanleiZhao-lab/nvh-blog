# 耐久与疲劳：从载荷历程到损伤累积的工程框架

> 静力计算合格的支架，装车跑完强化路试却在第 6 万公里出现裂纹——应力从没超过材料屈服强度，它为什么断了？答案是疲劳：损伤不由"这一次载荷有多大"决定，而由"循环了多少次、每次多大"悄悄累积。本文从 1842 年凡尔赛火车事故讲起，沿 S-N 曲线、Miner 线性损伤累积、雨流计数这条主线，把"载荷时间历程 → 循环计数 → 损伤累积"的耐久分析框架一次讲清。

裂纹不会因为静强度合格就绕道走。某车型后视镜支架，静力校核安全系数 2.5，装车跑强化坏路到第 6 万公里，支架根部出现贯穿裂纹。回查实测应变：全程应力峰值不到材料屈服限的一半，按静强度思路"永远不该坏"。断口的真实机制是疲劳（fatigue）——每一次循环载荷都在裂纹尖端留下一点不可逆的损伤，单次微不足道，几十万次累积起来就是断裂。工程师面对的核心问题因此不是"这根杆能承受多大力"，而是"这串载荷历程吃掉了多少寿命、还剩多少"。本文沿一条完整链条展开：载荷历程怎么变成循环计数（雨流计数），循环怎么折算成损伤（S-N 曲线 + Miner 法则），以及这套框架的历史由来与工程边界。

## 一、为什么"没超强度"也会断：疲劳的三个反常识

第一个反常识：**疲劳寿命与应力幅的关系是"指数级"的**。1910 年 Baskin 用 Wöhler 的试验数据拟合出 S-N 曲线的双对数（log-log）线性关系——应力幅降一点，寿命翻许多倍。数量级感受：钢在 ±200 MPa 下可能 $10^5$ 次循环致断，把幅值降到 ±100 MPa，寿命可以跳到 $10^7$ 次以上；反过来说，幅值算错 10%，寿命预测可能差一个数量级。这就是耐久分析对载荷测量精度"斤斤计较"的根源。

第二个反常识：**均值应力不可忽略**。同样的 ±100 MPa 循环，围绕 0 MPa 波动和围绕 +300 MPa 波动，寿命完全不同——拉均值把裂纹"掰开"，让每次循环的有效驱动力更大。1899 年提出的 Goodman-Haigh 图就是量化均值/交变应力交互作用、圈定无限寿命安全包络的工具。

![Goodman-Haigh 图：浅蓝区域为给定材料的无限寿命安全工作应力包络](/images/durability-fatigue-intro/fig-goodman.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

第三个反常识：**损伤会"记账"**。每级应力水平用掉的寿命份额可以线性相加，与加载顺序无关——这是 1945 年 Miner 推广的线性损伤假设，也是整个耐久试验编排的理论地基。

先建立一个贯穿全文的类比：**把零件的疲劳寿命想成一块电池**。新零件 = 满电（损伤 D=0）；出现工程意义上的裂纹 = 电量耗尽（D=1）。S-N 曲线是"放电倍率表"——大电流（高应力幅）放几圈就没电，小电流（低应力幅）能撑很久；Miner 法则是电量计：每种电流各用了多久，按比例扣减，加起来就是总消耗。后文的雨流计数，则相当于从混乱的用电记录里把"每一次完整的放电循环"挑出来记账。电池类比有一个明确边界要预先声明：真实电池可以充电（愈合），金属疲劳损伤在工程模型里不可逆——这正是 Miner 假设"线性累加、不管顺序"的物理背景。

::: info 核心概念
- **疲劳（Fatigue）**：材料在循环载荷下于低于静强度极限的应力水平处萌生并扩展裂纹的过程；"疲劳"一词 1839 年由 Poncelet 首次正式使用——他推测车轴"用久了会累"
- **S-N 曲线（Wöhler 曲线）**：恒幅循环应力水平 S 与致断循环次数 N 的关系曲线，由不同应力水平的成组试件试验获得
- **损伤 D（Damage）**：寿命消耗份额的无量纲度量，新件 D=0，工程定义的失效（表面萌生可见裂纹）时 D=1
- **Miner 法则（Palmgren-Miner 线性损伤假设）**：各级应力水平造成的损伤独立线性累加，D=Σn_i/N_i
- **雨流计数（Rainflow Counting）**：把随机载荷历程分解为一系列等效恒幅循环的算法，1968 年由 Endo 提出，1986 年纳入 ASTM E1049-85
:::

## 二、S-N 曲线：用"放电倍率表"给材料做体检

S-N 曲线的原料是疲劳试验机上的恒幅循环试验。把一批材料试件（coupon）装上轴向疲劳试验机，每组固定一个应力幅，循环到试件出现裂纹，记录致断次数；换一个应力幅再来一组，把 (S, N) 点对画到双对数坐标上，就是 S-N 曲线。

![S-N 曲线：循环应力水平对致断循环次数，应力越高寿命越短](/images/durability-fatigue-intro/fig-sn-curve.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

![对材料试件施加恒幅循环载荷的轴向疲劳试验机](/images/durability-fatigue-intro/fig-coupon-machine.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

这条曲线的历史本身就是被事故逼出来的。1842 年凡尔赛火车事故中机车车轴意外断裂、五十余人遇难，当时没人理解"许多次小应力循环的累积能导致金属零件突然失效"；Wöhler 为调查此事故开发了反复加载试验装置，系统绘制载荷水平与致断循环数的关系，1867 年在巴黎博览会上发表——这就是 S-N 曲线也叫 Wöhler 曲线的原因。

![1842 年凡尔赛火车事故：疲劳研究的历史起点](/images/durability-fatigue-intro/fig-versailles.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

在双对数坐标上，钢的 S-N 曲线中段近似一条直线，Baskin 1910 年将其表达为幂律形式。这个公式回答的问题是：给定应力水平，这种材料的试件平均能扛多少次循环？其中 S 是循环应力幅，N(S) 是该水平下的致断循环次数，m 是双对数斜率（钢典型 3~10，由材料与应力类型决定），C 是由试验数据拟合的常数——m 越大，曲线越陡，应力的小变化被放大成寿命的巨大变化：

$$N(S) = C \cdot S^{-m}$$

许多钢材在约 $10^6 \sim 10^7$ 次循环处曲线趋平，该水平以下的应力理论上"无限寿命"，称为疲劳极限（fatigue limit / endurance limit）。注意两点工程现实：其一，铝合金多数没有明显的疲劳极限，曲线持续下行；其二，一旦零件经历过塑性载荷，疲劳极限的"保险"即告失效——这正是后文 Miner 法则顺序盲区的伏笔。

## 三、Miner 法则：给损伤记账

有了"放电倍率表"（S-N 曲线），下一问是：幅值上上下下的真实载荷历程，寿命怎么算？Miner 法则给出工程上最常用的答案：**每一级幅值单独记账，按寿命份额线性扣减，总和到 1 判失效**。

这个公式回答的问题是：一串包含 k 个不同幅值水平的载荷历程，总共消耗了多少寿命份额？其中 n_i 对应物理里第 i 级幅值实际作用的循环次数（实测/试验统计得到），N_i 对应该幅值下材料能承受的总循环次数（S-N 曲线查得），D 是无量纲损伤总量：

$$D = \sum_{i=1}^{k} \frac{n_i}{N_i}, \qquad D \ge 1 \ \text{视为失效}$$

用一个可以直接手算的例子建立直觉（数值取自 Simcenter Knowledge Base 的教学示例）：某零件先受 2 个循环的幅值 A——该幅值下 S-N 曲线给出寿命 6 次，损伤 2/6 = 0.33，寿命用掉三分之一；再来 2 个循环更高的幅值 B——该水平寿命 4 次，损伤 2/4 = 0.50，累计 0.83，还没断；接着第 3 个幅值 B 循环到来，累计 0.83 + 0.25 = 1.08 ≥ 1，出现裂纹。三步记账的全过程如下三图。

![损伤记账第 1 步：2 个循环 ÷ 6 次寿命 = 损伤 0.33](/images/durability-fatigue-intro/fig-damage-33.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

![损伤记账第 2 步：再 2 个循环 ÷ 4 次寿命 = 0.50，累计 0.83](/images/durability-fatigue-intro/fig-damage-83.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

![损伤记账第 3 步：再 1 个循环，累计 1.08 ≥ 1，失效发生](/images/durability-fatigue-intro/fig-damage-108.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

回到电池类比：幅值 A 是 1C 放电倍率、总容量 6 份，放 2 次用掉 33%；幅值 B 是 2C 倍率、总容量 4 份，放 2 次再用 50%——电量计只认"倍率 × 时长"，不问放电顺序。Miner 法则 1945 年由 Miner 推广流行，但最早可溯至 Palmgren 1924 年的研究，故常合称 Palmgren-Miner 线性损伤假设。

线性假设的价值在于简单可加，边界也必须说清：

- **顺序盲区**：Miner 法则不区分"先高后低"与"先低后高"。实测中若先经历塑性区载荷，构件的疲劳极限此后即告失效，后续低幅循环照样贡献损伤——线性累加对此无能为力；
- **分散性**：疲劳寿命数据天生分散（Weibull 1951 年提出含形状参数的分布正是为了描述它，经典高斯分布拟合不了螺栓与铝试件的断裂概率），D=1 只是统计意义上的中位参考，工程上常留损伤安全系数。

## 四、真实载荷不是正弦波：雨流计数

Miner 记账的前提是"知道每一级幅值各有多少次循环"，但用户手里的载荷历程从来不是干净的恒幅正弦——它是烂路、刹车、过坎叠加出的杂乱时间曲线。把杂乱历程分解成一个个等效恒幅循环的算法，就是 1968 年 Endo 开发的雨流计数（rainflow counting），名字据说来自宝塔式屋顶的雨水流泻路径。

![真实产品的载荷历程：杂乱、变幅、绝非正弦](/images/durability-fatigue-intro/fig-complex-load.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

![Miner 法则配套的损伤记账流程：时间历程 + S-N 曲线 → 损伤累计](/images/durability-fatigue-intro/fig-miner-tally.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

雨流计数的核心思想，是在峰谷序列里识别"封闭的滞回环"：一个完整的循环对应应力-应变平面上一个闭合环，大环套小环，逐层剥出。算法上分三步（与 LMS 理论手册"值域对-值域"计数一节一致）：

1. **压缩为峰谷序列**：丢弃非转折点，并施加值域滤波器（门槛 R）剔除微小波动——只有当信号从峰回落超过 R，该峰才算有效峰；
2. **值域对扫描**：取四个连续峰谷点，若中间一对构成的值域被外侧一对包住，即提取一个完整循环并从序列中删除，窗口回退重组，继续扫描；
3. **残差处理**：扫描结束剩余的峰谷残数按单值域（半个循环）计入。

计数的输出是"幅值-均值-次数"三维直方图（Range-Mean 矩阵），正是 Miner 记账需要的 n_i。

![雨流计数把复杂历程分解为一个个等效恒幅循环](/images/durability-fatigue-intro/fig-rainflow.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

这一步在整条链路里的角色，用电池类比说就是：从混乱的电流记录里把"一次完整充放"挑出来，才能算清每个倍率各用了多久。

值得工程注意的三点：值域滤波器尺寸在合理范围内对疲劳结果不敏感（增大门槛只是去掉小转折点，手册明确指出这证明了滤波的稳健性）；均值应力信息保留在 Range-Mean 矩阵里，配合 Goodman-Haigh 一类的均值修正再查 S-N 曲线；计数前通常先做带通或低通预处理，极高频小波纹对损伤贡献可忽略。

## 五、十行 numpy：Miner 记账全流程演示

下面用一段自包含代码演示"载荷历程 → 雨流式循环提取 → Miner 损伤"的完整流程。为了不依赖 rainflow 库，用简化的三点半循环雨流实现；S-N 曲线取 m=5、参考点 (S_ref=200 MPa, N_ref=1e5)：

```python
import numpy as np

# S-N 幂律: N = C * S^-m, 由参考点 (200 MPa, 1e5 次) 定出 C
m, S_ref, N_ref = 5.0, 200.0, 1e5
C = N_ref * S_ref**m
life = lambda S: C * S**-m if S > 0 else np.inf

def turns(x, gate=5.0):                 # 1) 压缩为峰谷序列 + 值域滤波
    t = [float(x[0])]
    for v in x[1:]:
        v = float(v)
        if len(t) < 2 or (v - t[-1]) * (t[-1] - t[-2]) <= 0:
            t.append(v)                 # 方向反转 -> 新转折点
        else:
            t[-1] = v                   # 同向 -> 保留更极端值
    return [v for i, v in enumerate(t) if i == 0 or abs(v - t[i-1]) >= gate]

def rainflow(peaks):                    # 2) 四点法提取完整循环（ASTM E1049 思路）
    stack, cycles = [], []
    for p in peaks:
        stack.append(p)
        while len(stack) >= 4:
            r1 = abs(stack[-2] - stack[-3]); r2 = abs(stack[-1] - stack[-2])
            r3 = abs(stack[-3] - stack[-4])
            if r2 >= r1 and r2 >= r3:   # 中间值域被外侧包含 -> 完整循环
                cycles.append(r1)
                del stack[-3:-1]
            else:
                break
    cycles += [abs(stack[i+1] - stack[i]) for i in range(len(stack)-1)]  # 3) 残差
    return cycles

rng = np.random.default_rng(3)
t = np.arange(20000)
load = (240*np.sin(2*np.pi*t/37) + 120*np.sin(2*np.pi*t/7.3)
        + 80*rng.standard_normal(t.size))    # 变幅+噪声的模拟载荷历程(MPa)
cyc = rainflow(turns(load, gate=5.0))
amp = np.array(cyc)/2.0                      # 值域/2 = 应力幅
D = sum(1/life(a) for a in amp if a > 10)    # Miner: Σ n_i/N_i（每循环 n=1）
print(f"循环总数 {len(cyc)}, 损伤 D = {D:.4f}, 寿命占比 {D*100:.1f}%")
```

实测一次输出：`循环总数 5130, 损伤 D = 0.0314, 寿命占比 3.1%`——两万点历程用掉约 3% 寿命，而损伤的主要贡献来自少数大幅值循环：m=5 幂律下，一次 180 MPa 循环的"杀伤力"等于 7.6 次 120 MPa 循环（$(180/120)^5 = 7.59$，实测逐项核验一致）、约 97 次 60 MPa 循环。这解释了耐久试验为何执着于"截断小幅值、保留大事件"：小循环数量再多，在幂律面前常常无足轻重。

## 七、小结

耐久分析是一条三段式流水线：**载荷历程（实测）→ 雨流计数（变幅历程拆成等效恒幅循环）→ Miner 记账（各级损伤 Σn_i/N_i 线性累加，D=1 判失效）**，其中 S-N 曲线是材料级别的"放电倍率表"，Goodman-Haigh 图处理均值应力的修正。框架的每个环节都有 100 多年的历史沉淀——从凡尔赛事故到 Wöhler 曲线（1867），从 Miner 法则（1945）到 ASTM E1049 雨流标准（1986）。使用时记住两条边界：线性假设不管加载顺序（塑性预载后疲劳极限失效），寿命数据本身有分散性（Weibull 分布、留安全系数）。

## 一句话记住

疲劳损伤靠记账：S-N 曲线给出每级应力幅的"总寿命"，雨流计数把乱波形拆成一笔笔循环，Miner 法则按 n_i/N_i 逐级扣减——D 到 1 就断，顺序不管、分散要防。
