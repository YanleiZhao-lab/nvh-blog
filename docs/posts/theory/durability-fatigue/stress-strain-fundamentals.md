# 应力与应变：从载荷到材料内部受力的完整图景

> 同一根钢棒，载荷 15 kN 不变，直径从 20 mm 加粗到 28 mm，内部应力从 47.7 MPa 掉到 24.4 MPa——降了一半，代价是质量增加 96%。耐久工程师每天做的决定，几乎都压在这两个量上：应力（Stress）问"材料内部单位面积扛了多大力"，应变（Strain）问"材料被拉长了多少比例"。它们像一枚硬币的两面：应力看不见摸不着，必须靠载荷除以面积算出来或靠应变换算；应变小到肉眼全瞎——0.000227 这种数没法读，工程师把它放大一百万倍写成 227 微应变（microstrain）。本文用"体重秤与身高尺"这对类比把应力应变的定义、胡克定律、屈服与颈缩、工程应力与真实应力的分岔一次讲透，配 9 张公开资料插图与 numpy 数值演示，为 S-N 曲线、Neuber 法则、应变寿命法打底。

## 一、为什么要分清应力与应变

耐久试验室里最常见的一类对不上账，源于把载荷、应力、应变三个量混着用。载荷组的报告写"悬挂硬点载荷 15 kN"，材料手册写"屈服强度 350 MPa"，仿真输出却是"孔边应变 8500 微应变"——三个数看起来都在描述"这个件受力有多大"，单位却分别牛、兆帕、无量纲。它们之间的换算桥梁只有两条公式：载荷除以面积得应力，长度变化除以原长得应变。搞不清这两步，后面所有的疲劳寿命预测都是空中楼阁：S-N 曲线的纵轴是应力幅、应变寿命法的横轴是应变幅、Neuber 法则在应力应变之间搭桥，任何一处量纲口径不齐，寿命预测可以差出一个数量级。

先把两个量各自的"分工"说清楚，用一个贯穿全文的类比：**把零件想成一个人，应力是体重秤读数，应变是身高尺读数**。体重秤（应力）告诉你"此刻承受了多少"——同样 70 kg 的人踩不同的秤，读数一样，但一个踩的是双足站立的整块大秤面、另一个踩的是只容单脚尖的小秤面，秤面材料受的压强完全不同——应力把"力"按"承受面积"摊开，单位面积上的力才是材料真实感受到的强度。身高尺（应变）告诉你"被拉长了多少比例"——1.8 m 的人长高 1 mm 和 0.3 m 的孩子长高 1 mm，绝对量相同、相对变形差 6 倍，材料只关心相对量。体重秤坏了可以换一台再称，身高尺量完人回不到原高——这就是应力是"状态量"、应变里藏着"是否回得去"的信息的区别，也是弹性与塑性的分水岭。

::: info 核心概念
- **应力（Stress，σ）**：力除以受力面积，描述材料内部单位面积上传递的力，单位 MPa（N/mm²）
- **应变（Strain，ε）**：长度变化量除以原始长度，无量纲，工程上常用微应变（microstrain，με）= 10⁻⁶ 应变
- **工程应力（Engineering Stress）**：载荷除以**原始**截面积的应力，试验报告默认口径
- **真实应力（True Stress）**：载荷除以**当前实际**截面积的应力，塑性大变形分析用
:::

## 二、应力：把力摊到面积上

### 2.1 一根试棒受拉时内部发生什么

金属试棒（coupon）两端受拉力 F，任取一个横截面，截面两侧的材料互相拽着——这个"内部拽力"除以截面面积就是应力。相关技术资料用一根受拉圆柱给出定义图示：

![图1：金属试棒拉伸试验：左为原始试样、中为颈缩阶段、右为断裂（图源：网络官方公开资料）](/images/stress-strain-fundamentals/f1.png)

*（图源：网络官方公开资料）*

![图2：力施加在金属圆柱（试棒）上（图源：网络官方公开资料）](/images/stress-strain-fundamentals/f2.png)

*（图源：网络官方公开资料）*

具体数字先于符号：直径 20 mm 的钢棒（截面积 314.2 mm²）受拉力 15 kN 时，内部应力 47.7 MPa——数值上等于每平方毫米的材料扛着 4.77 kg 的重物。这个数离普通结构钢 350 MPa 的屈服强度还很远，但如果隔壁零件开了个孔、截面积掉到 100 mm²，同样的力下应力跳到 150 MPa，离屈服只剩一步。

这个公式回答的问题是：把看不见的"内部受力"换算成可与材料强度对比的数，怎么算？其中 F 是外载荷（N），A₀ 是原始横截面积（mm²），商的单位是 N/mm² 即 MPa：

$$\sigma = \frac{F}{A_0}$$

### 2.2 降应力只有两条路，每条都有代价

从公式看，要降应力只能减 F 或增 A₀。工程上真正的问题从来不是"会不会算"，而是两条路各要付出什么：

**加粗截面**。直径 20 mm 加到 28 mm，应力从 47.7 降到 24.4 MPa（降 49%），质量却增加 96%——接近翻倍。汽车、航空行业今天的"轻量化（lightweighting）"浪潮正是被这笔账逼出来的：每一个为疲劳寿命加粗的截面都在吃能耗指标。反过来说，**把真实载荷环境摸准，是省重量的第一杠杆**——如果实际载荷比设计假设小一圈，零件就在为一个不存在的严苛环境多背 96% 的质量。

**几何陷阱**。设计部门把直圆柱改成"可乐瓶"造型，中段收窄，有效截面积骤减：

![图3：截面积从 A 变为 A1，试棒上的应力随之降低（图源：网络官方公开资料）](/images/stress-strain-fundamentals/f3.png)

*（图源：网络官方公开资料）*

![图4：几何变化减小有效截面积并产生应力集中（图源：网络官方公开资料）](/images/stress-strain-fundamentals/f4.png)

*（图源：网络官方公开资料）*

更隐蔽的坑在"应力集中（Stress Concentration）"：截面突变处应力不是均匀分布，局部峰值可以是名义应力的好几倍（缺口系数 Kt 的由来）。疲劳裂纹几乎总从这类位置萌生——孔边、圆角、键槽根部。这也是后续 Neuber 法则（把名义应力换算成缺口根部真实应力应变）要解决的核心问题。

::: warning 工程注意
载荷组的"kN"、材料相关技术手册的"MPa"、有限元的"με"三本账要对齐，先统一到应力或应变的同一口径再比较。任何一处混用单位，寿命预测的偏差不是百分之几，是倍数级。
:::

## 三、应变：被拉长了多少比例

### 3.1 一个小到必须"放大一百万倍"的量

试棒受拉后变长一点点。应变定义为长度变化量与原始长度之比：

![图5：应变定义为长度变化量除以原始长度（图源：网络官方公开资料）](/images/stress-strain-fundamentals/f5.png)

*（图源：网络官方公开资料）*

这个公式回答的问题是：材料被拉伸的"程度"有多大，与试棒原始长短无关怎么表达？其中 L 是变形后长度，L₀ 是原始长度，分子分母都是长度、相除后无量纲：

$$\varepsilon = \frac{\Delta L}{L_0} = \frac{L - L_0}{L_0}$$

数值有多小：前述 15 kN 载荷下 47.7 MPa 的应力，除以钢 210 GPa 的弹性模量，应变为 0.000227。这种小数读写都费劲，工程惯例是乘 10⁶ 换成**微应变（microstrain，με）**：0.000227 → 227 με。应变片、采集软件（如 Testlab 应变通道）读数给出的就是微应变。

### 3.2 体重秤与身高尺的对应关系

回到贯穿类比：应力是体重秤读数（承受了多少），应变是身高尺读数（变形了多少）。两把尺子各自量一个维度，胡克定律是它们之间的"汇率"。理解这个对应关系后，很多工程做法变得自然：应变片贴在零件上量的是身高尺（应变），但校准系数（灵敏度系数）让你直接换算出体重秤读数（应力）——因为弹性范围内两者严格成正比。这解释了为什么实测应变是疲劳分析最可靠的输入：它绕过了载荷路径、截面积、应力集中系数的所有估算，直接量到材料"被拉长了多少"。

numpy 演示把两把尺子串起来（20 mm 钢棒、15 kN 载荷，含加粗方案与颈缩处的应力对比）：

```python
import numpy as np

E = 210000.0          # 弹性模量 MPa
F = 15000.0           # 载荷 N
d0 = 20.0             # 原始直径 mm
A0 = np.pi * d0**2 / 4
sigma = F / A0                    # 工程应力 MPa
eps = sigma / E                   # 弹性应变
print(f"A0={A0:.1f} mm^2, sigma={sigma:.1f} MPa, eps={eps*1e6:.0f} muE")

d1 = 28.0                          # 加粗方案
print(f"d {d0:.0f}->{d1:.0f} mm: sigma {F/(np.pi*d1**2/4):.1f} MPa, "
      f"mass +{((d1/d0)**2-1)*100:.0f}%")

dneck = 14.0                       # 颈缩后直径
print(f"neck {dneck:.0f} mm: eng sigma {F/A0:.1f} vs "
      f"true sigma {F/(np.pi*dneck**2/4):.1f} MPa")

# 应变片读数换算：灵敏度系数 GF=2，dR/R=0.0009
GF, dR_R = 2.0, 0.0009
eps_g = dR_R / GF
print(f"gauge dR/R={dR_R} -> {eps_g*1e6:.0f} muE -> {eps_g*E:.1f} MPa")
```

运行输出：

```text
A0=314.2 mm^2, sigma=47.7 MPa, eps=227 muE
d 20->28 mm: sigma 24.4 MPa, mass +96%
neck 14 mm: eng sigma 47.7 vs true sigma 97.4 MPa
gauge dR/R=0.0009 -> 450 muE -> 94.5 MPa
```

值得看的数字：加粗 40% 换来应力减半但质量近乎翻倍；同一根试棒颈缩到 14 mm 时真实应力已是工程应力的两倍——下一节解释为什么两本账要分开记。

## 四、胡克定律：弹性区的汇率

载荷从小往上加，最初应力与应变成严格正比——这段叫**弹性区（elastic region）**：卸载后零件完全回到原状，身高尺量完人还能缩回去。

![图6：材料弹性区内应力与应变的关系（图源：网络官方公开资料）](/images/stress-strain-fundamentals/f6.png)

*（图源：网络官方公开资料）*

这个公式回答的问题是：弹性范围内"体重秤读数"与"身高尺读数"按什么汇率换算？其中 E 是**弹性模量（Young's Modulus / 杨氏模量）**，即应力-应变曲线弹性段的斜率，钢约 210 GPa、铝约 70 GPa：

$$\sigma = E \, \varepsilon$$

这条 1660 年由 Robert Hooke 提出的定律是耐久分析的地基：S-N 曲线高周端的应力幅可以和实测应变幅互相换算；有限元线弹性分析输出应力，本质上用的也是这条汇率。E 是材料"出生就带"的属性——钢不管怎么热处理，E 都在 210 GPa 附近，变的只是屈服强度那些"后天"参数。

::: tip 换算要点
应变片实测 227 με 的钢构件，应力即时算出 227×10⁻⁶×210000 = 47.7 MPa。实测应变换应力这条路只在弹性区有效——一旦进入塑性，汇率本身失效，须换弹塑性关系（Ramberg-Osgood）处理。
:::

## 五、塑性与屈服：汇率失效的地方

### 5.1 曲线弯了意味着什么

载荷继续加，应力-应变关系从直线变弯——进入**塑性区（plastic region）**：卸载后零件不再回到原状，身高尺量完人回不去了，"变长"被永久记住。

![图7：材料弹性区与塑性区内的应力-应变关系全貌（图源：网络官方公开资料）](/images/stress-strain-fundamentals/f7.png)

*（图源：网络官方公开资料）*

直线到曲线的转折点叫**屈服强度（yield strength）**。现实里这个转折不是一刀切，而是有一小段过渡区，因此标准做法是画一条从 0.2% 应变处平行于弹性段的偏移线，取它与应力-应变曲线的交点定义为屈服强度（0.2% offset method）。越过屈服继续加载，某处开始**颈缩（necking）**——对应**强度极限（ultimate strength）**；再往后试棒断裂。

![图8：试棒应力逐级升高时截面积的变化：从左到右（图源：网络官方公开资料）](/images/stress-strain-fundamentals/f8.png)

*（图源：网络官方公开资料）*

### 5.2 弹塑性交界：耐久方法的分水岭

弹性还是塑性，直接决定该用哪套寿命预测方法：全部循环都在弹性区，用应力寿命法（S-N 曲线）；局部进入塑性（孔边、缺口根部常见），换应变寿命法（E-N），必要时用 Neuber 法则把弹性应力换算成弹塑性应力应变。本站已有专文展开，此处只强调判断依据——就是应力-应变曲线上那个 0.2% 偏移交点。

## 六、工程应力与真实应力：两本账的分岔

试棒拉长时横截面积在缩（弹性阶段泊松效应缩得极慢，塑性阶段越缩越快）。前面所有应力都除以**原始**面积 A₀——这是**工程应力**口径，试验报告默认用它。若改用**当前实际**面积，得到**真实应力**：

![图9：工程应力曲线（红）与真实应力曲线（蓝）的对比：试棒载荷逐级升高（图源：网络官方公开资料）](/images/stress-strain-fundamentals/f9.png)

*（图源：网络官方公开资料）*

两条曲线在弹性段几乎重合（前述 numpy 演示里 2000 με 轴向拉伸下面积只缩 0.03%），分岔发生在塑性区：真实应力持续上升，而工程应力在颈缩后反而"下降"——那不是材料变弱，是分母还固执地用原始面积、而真实承载面积已急剧缩小的假象。所以：**看强度极限找工程应力曲线**（颈缩点一目了然），**做塑性大变形分析用真实应力应变**（材料本构的真实行为）。

两本账之间的换算在塑性区有严格关系，这个公式回答的问题是：工程口径的应力应变如何无损换到真实口径？其中 σ、ε 为工程应力应变，换算基于体积不可压缩假设：

$$\sigma_{\text{true}} = \sigma_{\text{eng}} (1 + \varepsilon_{\text{eng}}), \qquad \varepsilon_{\text{true}} = \ln(1 + \varepsilon_{\text{eng}})$$

弹性区两者差可忽略（227 με 时真实应变 227.3 με，差 0.13%）；塑性区必须换算——应变寿命法用的正是真实应力应变回线。

## 七、在链条中的位置

应力与应变是耐久分析的第一环，后续每一步都建立在本文的口径上：载荷除以面积得应力（或应变片直接测应变）→ 判断弹性/塑性选方法 → S-N 或 E-N 曲线查寿命 → Miner 法则累积损伤 → 雨流计数拆循环。反过来，评审时对不上账的寿命预测，第一件事就是回头查口径：载荷是峰值还是幅值？应力是名义的还是局部的？应变是工程的还是真实的？——三问下去，多数"差一个数量级"的悬案当场破案。

Testlab 中应变测量（Strain Gauges）与 Tecware 载荷处理把本文的量直接接进数据链：应变片通道按灵敏度系数标定输出微应变，弹性范围内按 σ=Eε 换算应力；进入塑性的局部评估则交给应变寿命法流程（可参阅本站《S-N 曲线与疲劳极限》《Neuber 法则》《应变寿命法》诸文的完整演练）。

## 一句话记住

应力是体重秤（力摊到面积上）、应变是身高尺（伸长除以原长），胡克定律是弹性区的汇率；屈服之后汇率失效、要换 E-N 方法，颈缩之后工程应力是"原始面积"造出的假象——对账先对口径。
