# 疲劳损伤谱 FDS：把载荷谱转成频域损伤指标

> 同一条试验路上，A 组司机跑出来的 PSD 比 B 组高 2 dB，但装在同一台设备上做耐久试验，B 组的载荷反而先让样品开裂——RMS 高不代表更伤，因为疲劳损伤对幅值是幂律敏感、对频率位置也敏感，一张 PSD 图回答不了"哪个更伤、伤在哪个频率"。疲劳损伤谱（Fatigue Damage Spectrum, FDS）就是回答这个问题的指标：把实测振动喂给一排调到不同固有频率的虚拟单自由度振子，对每个振子的响应做循环计数、换算成损伤，逐频率累加，得到"每个频率上攒了多少损伤势"的一张谱。它像给不同食谱标注"每样的含糖量"——不看菜名（振动长什么样），只看对血糖（损伤）的贡献；有了它，比较不同工况、加速试验都变成同一张账本上的算术。

## 一、为什么 RMS 与 PSD 排不出"谁更伤"

现场耐久数据拿回来，工程师的第一个问题往往是：碎石路 200 秒和高速 600 秒，哪段更伤？直觉做法是比 RMS 或看 PSD 包络——碎石路量级高，那就碎石路凶。这个直觉经常出错，原因藏在疲劳的两个非线性里。

第一个非线性是**幅值幂律**。材料的 S-N 曲线画在双对数坐标上是一条往下斜的直线：应力幅抬 25%，致断循环数不是跟着降 25%，而是按斜率的幂次塌下去——对钢（斜率 5）意味着寿命只剩一半，对铝（斜率 8）只剩四分之一。所以两段信号即使 RMS 相近，幅值分布"尾巴"更长的那段（偶尔来一下的大冲击）损伤可以大出一个量级，而 RMS 只算均方根、看不见尾巴的长短。

具体数字感受一下这个反差。假设两段各 10 分钟的基座振动，RMS 都是 0.5 g：A 段是干净的窄带随机，幅值分布规整；B 段一样但每隔几十秒叠一个 1.8 g 的冲击。按 RMS 与 PSD 包络评判，两段"一样严酷"；但损伤按幅值的幂次记账，B 段那几十次大冲击记下的账，可以比 A 段几十万次小循环的总和还多。台架试验如果只照着 PSD 包络去复现，就会把 B 段真正致命的部分漏掉——试出来的"合格"，到现场变成保修期内的开裂。

第二个非线性是**频率选择性**。被测设备的每一个共振峰都像一个窄带滤波器：激励能量落在共振频率附近的才被放大，其余频率再大也激不起响应。两段路谱总量级一样、但一段的能量集中在设备第一阶共振附近、另一段在别处——对这台设备而言，两段载荷的"破坏势"天差地别。PSD 只描述激励本身，不包含"设备会在哪些频率上放大"的信息。

换一个更贴近现场的问法：供应商交付试验报告，附了三种路面各一小时的 PSD；你的设备第一阶共振在 80 Hz 附近，你要决定台架谱在哪个频段重点加码。三张 PSD 图叠在一起看，谁也回答不了"80 Hz 这个峰对我的零件意味着多少损伤"——因为缺的不是激励数据，而是把激励换算成"我的零件的响应再换算成损伤"的那把钥匙。

FDS 的做法是把这两个非线性都装进计算流程：不是对原始加速度计数，而是先让信号过一遍"通用替身"——一排调到不同固有频率的虚拟振子，每个振子只对自己频率附近的能量起响应；再对每个振子的响应做循环计数与损伤换算。这样得到的谱横轴是频率（哪个共振峰最受伤）、纵轴是损伤（攒了多少破坏势），激励的频率分布与材料的幂律敏感一次性都进了账。

![FDS 计算流程：从加速度时程到疲劳损伤谱的完整链路](/images/fatigue-damage-spectrum/fig1.png)

*（图源：网络官方公开资料）*

::: info 核心概念
- <strong>FDS（Fatigue Damage Spectrum，疲劳损伤谱）</strong>：把振动时程换算成"逐频率累积损伤"的谱，用于比较不同载荷的破坏势与推导加速试验谱
- <strong>伪损伤（Pseudo damage）</strong>：FDS 的纵轴通常是相对损伤而非绝对寿命——参数不必标定到真材料，只作同一把尺子下的比较
- <strong>DUT（Device Under Test，被试件）</strong>：将来要经历这些振动、最终可能疲劳失效的产品或部件
:::

## 二、计算链路：一排振子、一次计数、一笔损伤账

FDS 的完整计算链只有四步：振子响应 → 循环计数 → 位移换应力 → Miner 记账。逐个拆开看，每一步都是前面章节讲过的老朋友，新意只在"给每个频率各算一套"。

### 2.1 一排虚拟振子：激励的"通用替身"

第一步把实测加速度时程作为基座激励，喂给一组单自由度（SDOF）质量-弹簧-阻尼振子，每个振子调到不同的固有频率，覆盖整个分析频段。任何真实结构在某个共振峰附近的行为都可以用对应调谐的 SDOF 近似——所以这排振子不是针对某台具体设备的模型，而是"任何设备"的通用替身：设备第一阶共振 180 Hz，就看 180 Hz 那个振子的账。

![实测加速度时程施加到一排虚拟 SDOF 振子上，得到各自的相对位移响应](/images/fatigue-damage-spectrum/fig3.png)

*（图源：网络官方公开资料）*

振子的输出取**相对位移** $z$（质量相对基座的位移），不是绝对加速度。这个选择有讲究：位移正比于应变与应力，正是疲劳关心的量；加速度则是冲击响应谱（SRS）取的量。同一排振子，取相对位移去算损伤就是 FDS，取绝对加速度的最大值就是 SRS/MRS——两条谱线共用一套响应计算，回答两个不同的问题（"攒了多少损伤"与"峰值多大"）。

加速度到位移的转换在频域里就是除以 $(j\omega)^2$：积分两次。时域里做完这步，每个振子手里都有一段以自身固有频率为主的位移时程。

### 2.2 循环计数：把波形拆成一笔笔循环

第二步对每个振子的位移时程做循环计数，得到"循环次数 $n$ 对幅值 $z$"的直方图。可直接计数（range-pair 取相邻转向点幅值、zero-max 取过零间隔内的最大值），也可以用雨流计数把嵌套的闭环一个个拆出来——三种方法软件里都可选，雨流最通用。

![Range-Pair 直接计数示例：位移时程拆成幅值直方图](/images/fatigue-damage-spectrum/fig4.png)

*（图源：网络官方公开资料）*

![雨流计数：把时程中的闭环循环逐个识别出来](/images/fatigue-damage-spectrum/fig5.png)

*（图源：网络官方公开资料）*

### 2.3 从位移到应力再到损伤

第三步把位移幅值乘上应力/位移常数 $K$ 换算成应力幅——这就是把"振子位移账"翻译成"材料应力账"的汇率。第四步用材料的 Woehler 曲线（S-N 曲线）参数把每个应力幅对应的允许循环数 $N$ 查出来，Miner 法则逐级记账：

$$D = \sum_{i} \frac{n_i}{N_i} = \frac{K^b}{A} \sum_{i} n_i\, z_i^{\,b}$$

这个公式回答的问题是：一个振子的响应时程总共攒了多少疲劳损伤——其中 $n_i$ 对应物理里的第 $i$ 级幅值上数出来的循环次数，$z_i$ 是该级位移幅值，$K^b$ 把位移账换算成应力账（$b$ 次幂来自幂律），$A$ 是 Woehler 曲线的截距常数，除以它等于按材料的"价目表"折价。逐级 $n_i/N_i$ 求和就是 Miner 线性累积损伤：账记到 $D=1$，裂纹出现。

![单个 SDOF 振子的损伤计算公式](/images/fatigue-damage-spectrum/fig7.png)

*（图源：网络官方公开资料）*

![应力循环经 Woehler 曲线用 Miner 法则累加成总损伤](/images/fatigue-damage-spectrum/fig8.png)

*（图源：网络官方公开资料）*

### 2.4 把每个频率的账并排画出来

四个步骤对每个振子各跑一遍，把每个固有频率上的损伤总数并排画出来，就是疲劳损伤谱：

![三个输入时程（上）与各自算出的 FDS（下）：碎石路损伤全面高于加速制动](/images/fatigue-damage-spectrum/fig2.png)

*（图源：网络官方公开资料）*

官方这张对比图最能说明 FDS 的用途：三段实测载荷（Belgian block 石块路、Saw tooth 锯齿路、Accelerate-brake 加速制动）各算一条 FDS，一眼看出<strong>加速制动（红）在所有频率上的损伤都低于石块路（绿）与锯齿路（蓝）</strong>，且三条谱都是低频段损伤高于高频段——如果要在台架上复现这种损伤，重点得放在低频。这正是"同一张账本上比较不同食谱的含糖量"：不比菜名、不比总热量（RMS），只比对血糖的实际贡献。

还要强调一遍 FDS 的定位：**相对指标而非绝对指标**。纵轴的绝对数值依赖 $K$、$A$、$Q$、$b$ 一整套参数——参数没标定到真材料，"FDS=1 就失效"这种解读不成立；但只要整条计算链用同一套参数，不同载荷的 FDS 之间的比值就是有效的相对比较。这也是它叫"伪损伤"的原因。

## 三、四个参数：谁影响形状、谁只改刻度

打开软件的参数设置页，要填的东西不少，但真正需要花心思的是下面四个。先给结论：<strong>Q 与 b 改变谱的形状，A 与 K 大多只改刻度。</strong>

### 3.1 Q 因子：振子放大量

Q 因子（品质因数）设定虚拟振子的阻尼：$Q=10$ 对应 5% 阻尼，$Q=5$ 对应 10% 阻尼，两者在软件里联动。阻尼小（Q 高），振子对共振频率附近的激励放得越大，响应位移越大，损伤越高——同一激励下高 Q 算出的 FDS 整体更高。官方建议选定一个 Q 之后全程沿用，保证所有谱在同一把尺下可比。

![Q=10 与 Q=2 的 SDOF 响应对比：高 Q 峰更尖更高](/images/fatigue-damage-spectrum/fig13.png)

*（图源：网络官方公开资料）*

打个比方：Q 是这排"替身振子"的铃铛属性——钢铃（高 Q）敲一下响很久，橡胶铃（低 Q）声音马上闷掉。同一记敲击，钢铃攒的"振次账"自然多。真实结构的阻尼 Unknown 时，Q=10（5% 阻尼）是常用默认。

### 3.2 Woehler 指数 b：唯一必须较真的参数

指数 $b$ 是 S-N 曲线双对数斜率，它同时改变 FDS 的**幅值与形状**：$b$ 越大，小幅值循环的损伤贡献被压得越狠，谱形整体变形而不只是缩放。所以哪怕只做相对比较，$b$ 也不能随手填——不同 $b$ 下两段载荷"谁更伤"的结论都可能翻转。

![同一信号不同 b 值算出的 FDS：小 b 损伤更高且谱形改变](/images/fatigue-damage-spectrum/fig15.png)

*（图源：网络官方公开资料）*

工程取值：钢 $b=5$（Testlab 默认）、铝 $b=8$、电子产品常用 5（NATO AECTP-200），常见范围 3~12；多材料组件取**最小的 b** 最保守——小 b 算出的损伤最高，等于按最娇气的材料记账。有的文献把斜率记作 $k$，与本文的 $b$ 是同一个量。

::: warning 工程注意
为什么 $b$ 大反而损伤低？评论区有个常见困惑：公式里 $\sum n_i z_i^b$，$b$ 越大幂越高、和不该越大吗？Siemens 工程师的回答一针见血：振动信号的位移幅值用 SI 单位表示时远小于 1（$z \ll 1$，米量级的千分之几），一个小于 1 的数取更高次幂只会更小。直觉被"大于 1 的数"带偏了。
:::

### 3.3 A 与 K：一对经常互相抵消的刻度

Woehler 截距 $A$ 定曲线高低（单位是应力），应力/位移常数 $K$ 定位移换应力的汇率。注意两者在损伤公式里一个在分母、一个在分子且同取 $b$ 次幂：**只要做相对比较，把 A 和 K 都设成 1，两者直接对消**，算出的谱照样有效。需要绝对损伤数值（估算寿命）时才必须按材料认真标定。

![A 与 K 同增时 FDS 不变：两者在分子分母互相抵消](/images/fatigue-damage-spectrum/fig18.png)

*（图源：网络官方公开资料）*

| 参数 | 物理含义 | 对 FDS 的影响 | 常用值 |
|---|---|---|---|
| **Q 因子** | 振子阻尼（Q=10 即 5% 阻尼） | 整体抬高/压低，峰形变尖 | 10 |
| **b 指数** | S-N 双对数斜率 | **幅值与形状都变**，最敏感 | 钢 5 / 铝 8 |
| **A 常数** | Woehler 截距（应力单位） | 幅值缩放，形状不变 | 比较用可设 1 |
| **K 常数** | 位移→应力汇率 | 与 A 对消，比较用可设 1 | 比较用可设 1 |

## 四、numpy 演示：同一条谱，参数怎么改结论

用 20 行 numpy 复现核心逻辑：构造一段窄带随机"碎石路"与一段"高速"激励（同 RMS），各算一条 FDS（窄带近似），看 b 与频率位置如何决定"谁更伤"：

```python
import numpy as np

rng = np.random.default_rng(7)
fs = 2048.0                                  # 采样率 Hz
t = np.arange(int(fs*20))/fs                 # 20 s
f_res = 80.0                                 # "设备"第一阶共振 80 Hz

def band_signal(fc, bw, amp):
    """中心 fc、带宽 bw 的窄带随机加速度 (g)"""
    n = (len(t),)
    x = rng.standard_normal(n)
    freqs = np.fft.rfftfreq(len(t), 1/fs)
    X = np.fft.rfft(x)
    X[(freqs < fc-bw/2) | (freqs > fc+bw/2)] = 0
    s = np.fft.irfft(X, len(t))
    return amp*s/np.std(s)                   # 归一化到目标 RMS

a_cobble = band_signal(80, 30, 1.0)          # 碎石路: 能量压在共振上
a_highway = band_signal(400, 30, 1.0)        # 高速: 同 RMS, 能量在别处

def pseudo_damage(acc, fn, Q=10, b=5.0, K=1.0, A=1.0):
    """单振子伪损伤: 基座激励->相对位移->峰值计数->Miner 记账"""
    wn, z = 2*np.pi*fn, 1/(2*Q)              # 固有角频率与阻尼比
    w = 2*np.pi*np.fft.rfftfreq(len(acc), 1/fs)
    H = -1.0/(wn**2 - w**2 + 2j*z*wn*w)      # 基座加速度->相对位移频响 (s^2)
    disp = np.fft.irfft(np.fft.rfft(acc*9.81)*H, len(acc))  # g->m/s^2 再变位移
    mid = disp[1:-1]
    pk = mid[(disp[1:-1] < disp[:-2]) * (disp[1:-1] < disp[2:])]  # 局部峰值
    return (K**b/A)*np.sum((2*np.abs(pk))**b)  # 峰-谷幅值的 b 次幂求和

for b in (5.0, 8.0):
    r = pseudo_damage(a_cobble, f_res, b=b)/pseudo_damage(a_highway, f_res, b=b)
    print(f"b={b:.0f}: 碎石路/高速伪损伤比 = {r:.2e} ({np.log10(r):.1f} 个量级)")
```

运行结果：两段激励 RMS 完全相同，能量压在 80 Hz 共振上的"碎石路"算出的伪损伤是"高速"的 <strong>1.7e10 倍（约 10 个量级）</strong>；把 b 从 5 换成 8，倍数再放大到 <strong>6.6e16（约 17 个量级）</strong>——幂律把离共振频小循环的损伤贡献压得更死。这两个数字就是第一节两个非线性的直接注脚：<strong>RMS 相同的载荷，破坏势可以差出十个量级；b 填错，"谁更伤"的结论整个翻转。</strong>（具体倍数随随机种子与带宽参数变化，量级稳定；演示用峰值计数代替雨流，不影响结论方向。）

## 五、Testlab 操作：Classic 界面与 Neo 方法库

**Simcenter Testlab Classic**：启动目录的 Testlab Environmental 文件夹里双击 Mission Synthesis 图标（token 许可下占用 24 个），界面分三块——Data Selection 选数据、Calculator 计算区、Display 显示区。流程：在 Navigator 里高亮通道 → 选定标识属性（如 Point ID "Left Front"）→ 点文件夹图标送入 Calculator → 每个事件填重复次数（2 小时实录填 20，等效于同一环境跑 40 小时；不填默认 1）→ 高亮事件按 **Excitation → MRS/FDS**，在设置页填 Q/阻尼、Woehler A 与 b、K、计数方法（range-pair / zero-max / rainflow）与频率轴 → 算完事件表 FDS 列打 V。结果显示要选中行后按红色信号按钮，不会自动刷新；结果存进当前工程的 "Mission Synthesis Data" 文件夹（按环境名分子目录）。

- 只比较载荷、不推绝对寿命：A=K=1、Q=10 固定、b 按主导材料选（钢 5/铝 8，多材料取最小）
- 要推绝对寿命：A、K 必须按材料标定，且 Q 要贴真实结构阻尼
- 两环境都要经历用 Sum、只经历其一用 Env；重复次数别忘了乘
:::

## 六、小结

FDS 把"振动有多伤"从一句直觉变成一张可比较、可合成、可反演的谱：一排调谐 SDOF 振子当通用替身，响应做循环计数，位移换应力，Miner 记账，逐频率画出损伤势。它解决 RMS 排序失灵的两个根源——幅值幂律与频率选择性；它是相对指标，A、K 比较时可设 1 对消，Q 定尺子，b 定形状也定结论。比较载荷用它，加速试验的等损伤换算（E^b 汇率）靠它，任务合成反演台架谱的目标函数还是它。

## 一句话记住

FDS 是振动的"含糖量表"：一排虚拟振子试吃激励、逐频率记损伤账——RMS 相同破坏势差百万倍，比较时 A=K=1 对消、Q 固定当尺子，b 最较真（钢 5 铝 8 取小保守），谱形变了结论就变。
