# Miner 线性累积损伤：等效应损怎么算

> 台架报告最后一行写着"损伤 D = 0.87，未失效"，评审会上有人追问：这个 0.87 是怎么算出来的？为什么不是数裂纹、不是量变形，而是一个无量纲的小数？答案是一套记账规则：每一次循环载荷按幅值查表折算成"寿命份额"，用掉多少记多少，账本加到 1 判失效。本文把这本账从单级恒幅载荷记到多级程序块，再到 0.33 + 0.50 + 0.25 = 1.08 的完整手算示例，并用 numpy 复算一条真实量级的载荷谱——你会看到损伤的大头永远来自少数几个大幅值循环。

台架报告最后一行写着"损伤 D = 0.87，未失效"。这个数没有单位、不对应任何可以直接测量的物理量，评审会上却要拿它决定一套悬架方案的去留。它是怎么来的？疲劳失效不像屈服——没有一条可以盯住的应力线；裂纹萌生的时刻在单个试件上也几乎不可预测，同批试件同幅值加载，致断次数能差出一倍。工程师需要一个能把"用过多少寿命"写成数字的办法，Miner 线性累积损伤（Miner's Rule，Palmgren-Miner 线性损伤假设）就是工程上通用的答案：把每一种幅值的循环按 S-N 曲线折算成寿命份额，记账、加总，账到 1 判失效。这本账好算，但每一笔怎么折算、账本的两条边界在哪，值得从头走一遍。

## 一、为什么"损伤"必须是一个记账出来的数

先看失败的思路。第一种：数裂纹。等到表面能看到裂纹，零件已经处在失效边缘，这个"测量"对设计毫无前瞻性。第二种：算塑性变形。高周疲劳的应力全程在屈服强度以下，材料宏观上一直是弹性的，变形量里读不出任何"快坏了"的信号。

问题出在疲劳损伤的物理本质上：它藏在裂纹尖端的微观尺度里，每一次循环载荷都让裂纹向前挪一点点，单次挪动无法测量，几十万次累积起来才是断裂。既然单次不可测、只有累积到失效的"总量"可标定，那么合理的做法就是反过来定义：<strong>给一批相同试件施加恒幅循环，数出裂纹出现时的循环次数，把这个次数定义为"损伤总量 = 1"</strong>。损伤从此不是测出来的，是一个以失效为 1 的寿命份额。

这里给出贯穿全文的类比：**Miner 记账像一张预付储值卡**。新卡面值固定（损伤 D=0，全部寿命可用）；每种消费单价不同——小额消费（低幅值循环）次数多也花不完，大额消费（高幅值循环）几笔就见底；不管先买贵的还是先买便宜的，卡里剩多少钱只看"单价 × 笔数"的总账。后文的 S-N 曲线就是价目表，Miner 公式就是消费小票的加总，而这张卡有一条与真实储值卡不同的铁律——**只能扣、不能充**，金属疲劳损伤在工程模型里不可逆。

::: info 核心概念
- <strong>失效（Failure）</strong>：工程上取保守定义——零件表面萌生可见裂纹即为失效，不必等到裂纹贯穿分离；本文全文沿用此定义
- <strong>损伤 D（Damage）</strong>：无量纲寿命份额。全新未受载零件 D=0；恒幅试验中裂纹出现时 D=1
- <strong>循环（Cycle）</strong>：应力从某值出发，经上方与下方（或先下后上）再回到初值，为一个完整循环
- <strong>S-N 曲线（SN-Curve）</strong>：恒幅循环应力水平与致断循环次数的关系曲线，由成组疲劳试验获得，是损伤记账的"价目表"
:::

一个完整循环长什么样，值得先看图——起于零、上、下、回零，是一个闭环；半个循环（只走单边）在计数里只是残差，后文雨流一节会再遇到它：

*（图源：网络官方公开资料）*

## 二、价目表：S-N 曲线怎么读出"每一笔的单价"

Miner 记账的第一步是拿到价目表。把一批材料试件（coupon）装上疲劳试验机，每组固定一个恒定应力幅循环加载，直到裂纹出现，记下致断循环次数；换一个应力幅再来一组。应力水平越高、致断次数越少，点对连起来就是一条向下倾斜的 S-N 曲线——"S" 是应力（Stress），"N" 是循环次数（Number of Cycles）。

![S-N 曲线：循环应力水平对致断循环次数，应力越高寿命越短](/images/miners-rule-damage/fig-sn-curve.png)

*（图源：网络官方公开资料）*

![对材料试件施加恒幅循环载荷的轴向疲劳试验机](/images/miners-rule-damage/fig-coupon-machine.png)

*（图源：网络官方公开资料）*

价目表上每一行就是一条"单价"：某应力幅下试件能扛 N 次，那么每次这样的循环花掉 1/N 的寿命。加载方式可以是轴向、扭转、弯曲，S-N 曲线随材料和载荷类型不同——本文重点是记账规则本身，S-N 曲线的三区间、疲劳极限与双对数幂律详见 S-N 曲线专文。

## 三、手算一遍：0.33 + 0.50 + 0.25 = 1.08

现在把账本打开。公开技术资料中的教学示例只有三笔，足够手算，也足够把规则讲透。

<strong>第一笔：2 个中等幅值循环。</strong> 零件先经历 2 个循环的某应力幅。查 S-N 曲线：该幅值下材料能承受 6 次循环。这一步记的账是 2/6 = 0.33——零件三分之一的寿命已经用掉。

![记账第 1 笔：左侧载荷历程、中间 S-N 曲线、右侧损伤累计 2/6 = 0.33](/images/miners-rule-damage/fig-damage-33.png)

*（图源：网络官方公开资料）*

<strong>第二笔：2 个更高幅值循环。</strong> 换到更高的应力幅再来 2 个循环。查表：这个幅值下 4 次循环致断。记账 2/4 = 0.50，账本累计 0.33 + 0.50 = 0.83。还没到 1，按 Miner 法则零件完好。

![记账第 2 笔：再 2 个高幅值循环，2/4 = 0.50，累计 0.83，未失效](/images/miners-rule-damage/fig-damage-83.png)

*（图源：网络官方公开资料）*

<strong>第三笔：再来 1 个高幅值循环。</strong> 同幅值第 3 个循环到来，记账 1/4 = 0.25，累计 0.83 + 0.25 = 1.08 ≥ 1。失效发生——裂纹出现在零件表面。

![记账第 3 笔：再 1 个循环，累计 1.08 ≥ 1，失效发生](/images/miners-rule-damage/fig-damage-108.png)

*（图源：网络官方公开资料）*

三笔账并列放在一张图里，就是完整的记账流程：载荷时间历程（左）→ S-N 曲线查寿命（中）→ 损伤逐笔累加（右）。

![完整记账流程：时间历程 + S-N 曲线 → 损伤累计表](/images/miners-rule-damage/fig-tally-summary.png)

*（图源：网络官方公开资料）*

回到储值卡类比：第一笔是中等单价刷了 2 次，第二笔是高单价刷了 2 次，第三笔再刷 1 次，卡余额归负——储值卡没有"透支即停机"的保护，Miner 账本同样只认总额，不问刷卡顺序。

## 四、公式与它的适用边界

三笔账的规则写成通用形式。这个公式回答的问题是：一串包含 k 个不同幅值水平的载荷历程，总共用掉多少寿命份额？其中 n 是零件在服役中实际承受的某幅值循环次数（来自实测载荷或试验编排），N 是该幅值下材料的致断循环次数（实验室 S-N 曲线查得），k 是幅值水平数，D 是总损伤：

$$D = \sum_{i=1}^{k} \frac{n_i}{N_i}$$

判据就一条：**D = 1 时失效**。

![Miner 法则公式：D = Σ n/N，D 等于 1 时失效](/images/miners-rule-damage/fig-formula.png)

*（图源：网络官方公开资料）*

::: info 历史注记
1945 年 M. A. Miner 推广了这条法则，故称 Miner's Rule；更早的提出者是 1924 年的 A. Palmgren，因此规范名称是 Palmgren-Miner 线性损伤假设（linear damage hypothesis）。
:::

公式只有一行，但两条"真实世界"的边界必须同时交底，否则账本的精度会被误读：

<strong>边界一：不管循环顺序。</strong> 公式只对 n/N 求和，先大后小与先小后大算出的 D 完全相同。真实材料不是这样：一旦先经历塑性区载荷，疲劳极限从此失效——后面的低幅循环按原价目表"免费"，实际上照样扣费。储值卡的类比在这里也要修正：真卡在哪家店刷的确实无所谓，材料的"卡"被大额消费刷过一次之后，小额消费的单价会偷偷上涨。

<strong>边界二：真实载荷不是恒幅正弦。</strong> 示例里每笔账都是干净的恒幅循环，用户手里的载荷历程却是杂乱无章的——这正是为什么需要雨流计数（rainflow analysis）把复杂历程拆解成一笔笔等效恒幅循环，才能逐笔查表记账。

![真实产品的服役载荷历程：杂乱变幅，绝非恒幅正弦](/images/miners-rule-damage/fig-complex-load.png)

*（图源：网络官方公开资料）*

还有一条量级提醒：真实金属的 S-N 曲线是双对数曲线，寿命动辄数百万次循环，多级程序块与实测谱的记账项数远多于教学示例的三笔——但规则一条不变。

## 五、numpy 复算：多级程序块的完整账本

教学示例只有三笔，下面把量级放大到工程常用的多级程序块：8 个应力水平、钢典型幂律（指数 k=5，即 Basquin 形式 N = C·S^-k，由锚点 300 MPa 对应 1e5 次标定），模拟一段程序块谱并逐笔记账：

```python
import numpy as np

# S-N 幂律价目表：N = C * S^-k，锚点 300 MPa 对应 1e5 次
k = 5.0
C = 1e5 * 300.0**k
N = lambda S: C * np.asarray(S, float)**-k    # 查表：幅值 -> 致断次数

# 多级程序块：8 个应力水平各循环若干次（模拟谱）
levels = np.array([120, 150, 180, 210, 240, 270, 300, 330])   # MPa
counts = np.array([9500, 4200, 1500, 520, 180, 60, 15, 4])    # 次

# 逐笔记账：每级损伤 = n/N，总损伤 D = Σ n/N
dmg = counts / N(levels)
D = dmg.sum()
print(f"总损伤 D = {D:.4f}（{'失效' if D >= 1 else '未失效'}）")
print(f"最大单级贡献：{dmg.max():.4f}（占 {dmg.max()/D*100:.0f}%）")

# 哪一级最"贵"：按幅值排序看损伤分布
for S, n, d in sorted(zip(levels, counts, dmg), key=lambda x: -x[2])[:3]:
    print(f"  {S:3.0f} MPa x {n:5.0f} 次 -> 损伤 {d:.4f} ({d/D*100:4.1f}%)")
```

实测一次输出：

```
总损伤 D = 0.4918（未失效）
最大单级贡献：0.1905（占 39%）
  330 MPa x    4 次 -> 损伤 0.1905 (38.7%)
  300 MPa x   15 次 -> 损伤 0.1097 (22.3%)
  270 MPa x   60 次 -> 损伤 0.0545 (11.1%)
```

账本里最值得看的对比：330 MPa 只有 4 个循环，却花掉总寿命的 38.7%；而 120 MPa 的 9500 个循环加起来不到 1%（输出前三名里根本没有它）。幂律价目表下，单价随幅值五次方上涨，**少数大额消费主导整本账**——这正是耐久试验谱"截断小幅值、保留大事件"的算术依据，也是载荷测量必须死保大幅值精度的原因。

## 六、Testlab 落地：账本在软件里怎么翻

Simcenter 体系里，从载荷到损伤的记账链每个环节都有对应位置：

- **载荷采集**：SCADAS 硬件 + Testlab Signature 采集时间历程，应变通道见应变测量系列专文
- **循环计数**：雨流计数把复杂历程折算成"幅值-均值-次数"，Testlab Neo Process Designer 的雨流计数功能块输出 Range-Mean 矩阵
- **S-N 曲线管理**：Tecware 中可设置零件级 S-N 曲线（Setting up a SN-Curve in Simcenter Tecware）
- **损伤计算**：Tecware Process Builder 的 "Calculating Damage" 流程直接挂 S-N 曲线输出 Miner 损伤
- **低周塑性场景**：S-N + Miner 的适用区在高周弹性段；塑性主导时换 Testlab Neo 的 Strain Life（应变寿命）方法

::: warning 工程注意
D=1 是统计中位参考而非精确开关：疲劳试验数据天然分散，同批试件致断次数可差一倍。安全相关件常把判据收紧到 D < 0.3～0.5，或对载荷侧、寿命侧分别留安全系数——账本算出 0.87 "未失效"，离失效其实只有一次大载荷的距离。
:::

## 七、小结

Miner 损伤是一个记账出来的数：S-N 曲线是价目表（每一级幅值一个单价 1/N），载荷历程拆成的每个循环是一笔消费（n/N），账本加总到 1 判失效。规则本身一行公式，工程价值全在三条腿上——价目表要准（S-N 曲线随材料、载荷类型、均值应力修正）、账目要清（雨流计数决定每笔记多少）、边界要认（顺序盲区与寿命分散性）。三笔账 0.33 + 0.50 + 0.25 = 1.08 的示例小到可以手算，numpy 程序块谱的复算大到百万次循环，规则一条不变：损伤的大头永远来自少数大幅值循环。

## 一句话记住

Miner 记账三件事：S-N 曲线查单价（1/N）、每个循环记一笔（n/N）、账到 1 就失效——顺序不管、分散要防、大头永远在大幅值循环。
