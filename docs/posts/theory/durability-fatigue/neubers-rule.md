# Neuber 法则：从名义应力到局部缺口应力的换算

> 同一个悬置支架，装在车上的那件两万公里就在圆角处裂了，台架上按名义应力评估却显示"远低于屈服、无限寿命"。裂纹偏偏从圆角起。缺口根部的真实应力早就不止名义值乘应力集中系数那么简单——材料一旦局部屈服，应力集中会被塑性"缓和"，而应变集中反而被放大，真正驱动低周疲劳的是后者。本文讲 公开技术资料的 Neuber 法则（Neuber's Rule）：只用一条弹性应力时间历程加一条 Ramberg-Osgood 材料曲线，把每一个时间点上的弹性应力换算成对应的弹塑性应变，让线性有限元的输出也能喂给应变寿命法算疲劳。就像用一张信用卡账单（弹性应力）反推出你实际花了多少现金（弹塑性应变）——账单是线性的，现金流不是，中间靠一条"等面积"规则对账。

悬挂支架台架复现不了裂纹，是耐久评审上常见的僵局。线性有限元给出的应力时间历程永远是"弹性"的——载荷翻倍应力翻倍，300 MPa 就是 300 MPa，材料屈服这件事在模型里根本不存在。可缺口根部的真实材料早就局部屈服了：真实应力比弹性预测的低（塑性形变替它"扛"了一部分载荷），真实应变比弹性预测的大（塑性形变是额外的、不可恢复的形变量）。低周疲劳恰恰由应变驱动——S-N 曲线那套应力记账在这里失灵，必须换应变寿命（Strain Life）法，而应变寿命法的输入是弹塑性应变时间历程。一边只有弹性应力，一边要弹塑性应变，中间缺的那座桥就是 Neuber 法则。公开技术资料对它的定位一句话讲清：**它让线性模型预测非线性行为**（Neuber's Rule allows a linear model to predict non-linear behavior）。

## 一、为什么需要 Neuber 法则：缺的是哪一块

先把材料的两副面孔摆出来。低载荷下，材料像一根线性弹簧：应力与应变成正比，比例系数是弹性模量（Young's Modulus），卸载后形变完全恢复——这是<strong>弹性行为（Elastic behavior）</strong>。载荷升高、局部应力越过屈服强度后，材料开始永久变形，应力-应变关系变成一条弯向应变轴的曲线，卸载后留下残余形变——这是<strong>塑性行为（Plastic behavior)</strong>。真实构件的缺口根部往往是两者并存：周围大部分材料还弹性工作，根部一小块已经塑性流动，称为<strong>弹塑性（Elastic-plastic）</strong>状态。

一个直观的类比：**把缺口根部想成一根橡皮筋和一团橡皮泥串联的小元件**。小载荷下橡皮筋拉伸、橡皮泥不动，整体是线性的（弹性）；载荷大了橡皮泥开始永久变形，再卸载，橡皮筋缩回去、橡皮泥却停在拉长状态（塑性留下残余）。线性有限元只会算橡皮筋的伸长，永远不知道橡皮泥贡献了多少形变；而驱动疲劳裂纹的，恰恰是橡皮泥那部分每一次循环的永久形变。Neuber 法则的职责，就是从"橡皮筋伸长量"（弹性应力/应变）反推出"橡皮筋加橡皮泥的总形变"（弹塑性应变）。

站在测试现场看这件事的两条来路会更清楚。第一条路：直接贴应变片。应变片测到的形变天然包含弹性与塑性两部分，单位是微应变（με），直接就是应变寿命法要的弹塑性应变——不需要任何换算。第二条路：仿真。用线性有限元施加单位载荷得到力-应力灵敏度，再叠上实测的载荷时间历程，得到的是弹性应力时间历程——塑性完全缺席。相关技术资料文章明确画出这条岔路：应变片直测弹塑性应变，线性有限元只出弹性应力，后者必须经过 Neuber 法则才能进入应变寿命计算。

*（图源：网络 侵删）*

*（图源：网络 侵删）*

两条路怎么选？有条件贴片的位置优先贴片——实测永远优先；但当危险点在型腔内壁、装配缝隙深处，或者一个项目要筛几十个候选方案时，"有限元灵敏度 + 实测载荷 + Neuber 换算"就是唯一现实的组合。这也正是 Simcenter Testlab Neo 应变寿命方法为"载荷"和"应力"输入都内置 Neuber 换算的原因。

::: info 核心概念
- <strong>弹性行为（Elastic behavior）</strong>：应力与应变成正比（斜率为弹性模量 E），卸载后形变完全恢复；线性有限元的全部世界
- <strong>塑性行为（Plastic behavior）</strong>：应力超过屈服后发生不可恢复的永久变形，应力-应变关系非线性
- <strong>弹塑性应变（Elastic-plastic strain）</strong>：总应变 = 弹性部分 + 塑性部分，应变寿命法计算疲劳损伤所需的输入
- <strong>Neuber 法则（Neuber's Rule）</strong>：对弹性应力时间历程的每个点，按"弹性应变能 = 弹塑性应变能"的等面积条件，在 Ramberg-Osgood 曲线上求出对应的真实应力与总应变
- <strong>Ramberg-Osgood 关系（Ramberg-Osgood relationship）</strong>：描述材料弹塑性应力-应变关系的经验公式，是 Neuber 换算的目标曲线
:::

## 二、等面积规则：Neuber 法则在坐标纸上做什么

铺垫够了，现在把 Neuber 法则放到应力-应变坐标纸上讲。它的表述出奇地短：<strong>对弹性应力时间历程中的任一应力值，它所对应的弹塑性真实点满足"弹性虚应变能与弹塑性真应变能相等"</strong>——在应力-应变图上，就是"弹性点下方矩形面积 = 弹塑性点下方矩形面积"。

用前面的橡皮筋-橡皮泥类比说一遍：线性模型算出橡皮筋伸长到某个长度（弹性应变 $\varepsilon_e$）、弹力多大（弹性应力 $\sigma_e$），两者乘积是它"储存的功"。真实的缺口根部，橡皮筋加橡皮泥一起变形，真实应力比 $\sigma_e$ 低、真实总应变比 $\varepsilon_e$ 大。Neuber 的主张是：找那个"真实应力 × 真实总应变恰好等于 $\sigma_e \varepsilon_e$"的组合——塑性缓和掉多少应力，就用等量的应变放大补回来，能量总量守恒。

先看数字再上公式。一块 RQ355 级钢材（弹性模量 E = 210 GPa，循环强度系数 K′ = 660 MPa，循环硬化指数 n′ = 0.08），缺口弹性应力 450 MPa（名义 150 MPa、应力集中系数 3）：按弹性算应变是 450/210000 = 2.14×10⁻³（2140 微应变）；按 Neuber 换算，真实应力降到 373 MPa，总应变升到 2.58×10⁻³（2580 微应变）——应力被塑性缓和了 17%，应变被放大了 21%。弹性应力涨到 750 MPa（名义 250 MPa）时差距拉开：真实应力停在 426 MPa（缓和 43%），总应变却冲到 6.28×10⁻³，是弹性估计的 1.76 倍。名义应力越高，弹性假设错得越离谱，这正是缺口件疲劳评估必须换算的原因。

现在正式给公式。这条式子回答的问题是：<strong>弹性模型算出的应力与应变，跟缺口根部真实的应力与应变之间，靠什么量联系起来？</strong>其中 $\sigma_e$、$\varepsilon_e$ 是线性模型的弹性应力与弹性应变（$\varepsilon_e = \sigma_e / E$，两者由弹性模量锁死在一条直线上）；$\sigma$、$\varepsilon$ 是缺口根部的真实应力与真实总应变——它们不再成比例，塑性让它们分家。等号两边都是"应力 × 应变"的量纲，物理意义是单位体积的应变能：

$$\sigma \,\cdot\, \varepsilon \;=\; \frac{\sigma_e^{\,2}}{E}$$

右边 $\sigma_e^2 / E$ 全部由弹性模型决定——一条已知的数；左边是待求的两个未知数的积。一个方程两个未知数，还需要第二条关系才能解出唯一的点，这条关系就是材料的弹塑性骨架曲线：

$$\varepsilon \;=\; \frac{\sigma}{E} \;+\; \left(\frac{\sigma}{K'}\right)^{1/n'}$$

这条 Ramberg-Osgood 公式回答的问题是：<strong>这种材料在任意应力水平下，总应变里弹性与塑性各占多少？</strong>第一项 $\sigma/E$ 是弹性部分——线性世界里的老朋友；第二项 $(\sigma/K')^{1/n'}$ 是塑性部分——$K'$（循环强度系数，MPa）与 $n'$（循环硬化指数，无量纲）由材料循环试验拟合得到。应力低时第二项趋近零，曲线贴着弹性直线走；应力升高，塑性项以幂律速度抬头，曲线弯向应变轴。

两条关系一联立，几何图像立刻清楚：在应力-应变图上过原点画"弹性直线"（斜率 E）与"Ramberg-Osgood 曲线"；弹性应力 $\sigma_e$ 在弹性直线上定出蓝点，蓝点下方的矩形面积就是 $\sigma_e^2/E$；沿 Ramberg-Osgood 曲线找一点（红点），使其下方矩形面积恰好等于同一块面积——红点的坐标就是缺口根部的真实应力与真实总应变。相关技术资料文章正是用这张图定义 Neuber 法则：蓝点（弹性）与红点（弹塑性）的虚线双曲线就是"等面积双曲线"（面积 $\sigma\varepsilon$ 为常数的点集），两条材料线各截一次，交点即答案。

![Neuber 法则图解：弹性点（蓝）在杨氏模量直线上，等面积的弹塑性点（红）在 Ramberg-Osgood 曲线上](/images/neubers-rule/fig3-neuber-ramberg-osgood.png)

*（图源：网络 侵删）*

::: info 核心概念
- **等面积条件**：弹性应变能密度（$\sigma_e^2/E$）= 弹塑性应变能密度（$\sigma\varepsilon$），Neuber 法则的核心假设，1961 年由 Heinz Neuber 提出
- **应力集中缓和**：塑性变形使缺口根部真实应力低于弹性预测（弹性 $\sigma_e$ > 真实 $\sigma$）
- **应变集中放大**：塑性变形使缺口根部真实应变高于弹性预测（真实 $\varepsilon$ > $\varepsilon_e$），低周疲劳的真正推手
:::

值得强调的是这个换算逐点进行：弹性应力时间历程上每个采样点各自做一次"等面积求解"，得到一条完整弹塑性应变时间历程，再交给雨流计数与应变寿命法。它不是只对峰值做一次修正的粗办法，而是全历程的非线性映射——这也意味着计算量可控（每点一次一维求根），Simcenter Testlab Neo 在后台自动完成。

## 三、numpy 演示：一条弹性应力历程的 Neuber 换算

二十行自包含代码把第二节的两条关系解出来。设一件 RQ355 级钢材缺口件（E = 210 GPa、K′ = 660 MPa、n′ = 0.08、屈服 355 MPa、理论应力集中系数 $K_t$ = 3），名义应力历程取四个水平，看每个水平换算前后的应力与应变：

```python
import numpy as np

E, Kp, npn, Sy, Kt = 210e3, 660., 0.08, 355., 3.0   # MPa 系

def eps_total(s):                       # Ramberg-Osgood 总应变
    return s/E + (s/Kp)**(1/npn)        # 弹性项 + 塑性项

def neuber(se):                         # 解 sigma*eps(sigma)=se^2/E
    tgt = se*se/E                       # 等面积目标（能量密度）
    lo, hi = 1e-9, 10*Kp                # 二分求根区间
    for _ in range(200):
        mid = 0.5*(lo+hi)
        if mid*eps_total(mid) < tgt: lo = mid
        else: hi = mid
    s = 0.5*(lo+hi)
    return s, eps_total(s)

print("名义S  弹性3S  真实sigma  弹性eps   Neuber eps  应变放大  真Kt(应力)")
for S in [100, 150, 200, 250, 300]:
    se = Kt*S                           # 线性有限元的弹性局部应力
    s, e = neuber(se)
    print(f"{S:5.0f}  {se:6.0f}  {s:8.0f}  {se/E*1e3:6.2f}me  {e*1e3:7.2f}me"
          f"   {e/(se/E):5.2f}x   {s/S:5.2f}")
```

运行结果（实测输出）：

```
名义S  弹性3S  真实sigma  弹性eps   Neuber eps  应变放大  真Kt(应力)
  100     300       295    1.43me    1.45me   1.02x   2.95
  150     450       373    2.14me    2.58me   1.21x   2.49
  200     600       406    2.86me    4.22me   1.48x   2.03
  250     750       426    3.57me    6.28me   1.76x   1.71
  300     900       442    4.29me    8.73me   2.04x   1.47
```

三个读数值得停下看。第一，名义 100 MPa 时换算几乎没有变化（应变放大 1.02 倍）——弹性应力 300 MPa 低于屈服，材料整体还在弹性区，Neuber 点贴着弹性点，换算自动"退化"为不修正，不需要人为判断是否进入塑性。第二，名义应力升到 200 MPa，真实应力只有 406 MPa 而不是弹性的 600 MPa：有效应力集中系数从 3.0 掉到 2.03，应力集中确实被塑性缓和了。第三，缓和掉的应力没有消失，全部变成了应变——真实应变 4.22×10⁻³ 是弹性估计的 1.48 倍，且名义应力越高放大越猛（250 MPa 时 1.76 倍、300 MPa 时 2.04 倍）。如果拿弹性应变直接进应变寿命法，等于系统性地少算塑性损伤，缺口件的寿命会被明显高估。

再补一条"载荷链路"的算例，对应官方文章里有限元单位载荷的用法：线性有限元在单位载荷下给出某单元的力-应力灵敏度 5.03983 MPa/N（官方文章实测数值），实测载荷历程的峰值从 50 N 到 135 N 扫一遍，同样的五行函数给出：

```
 F(N)  弹性应力(MPa)  Neuber真实应力(MPa)  Neuber总应变
   50          252.0                  251          1.20me
   80          403.2                  357          2.17me
  100          504.0                  387          3.12me
  120          604.8                  407          4.28me
  135          680.4                  418          5.28me
```

135 N 时弹性应力 680 MPa 是屈服的两倍，真实应力却收敛在 420 MPa 附近缓涨——塑性把缺口根部的应力"钳"在了材料循环骨架曲线的水平上，多余的外载全部由塑性形变吸收。这也是为什么弹塑性分析里"应力集中"这个概念会淡化，而"应变集中"才是主角。

## 四、Testlab Neo 落地：三种输入类型怎么填

Simcenter Testlab Neo 的应变寿命（Strain Life）方法接受三种输入时间历程：载荷（力）、应力、应变。无论哪种，进入损伤计算前都必须变成弹塑性应变——区别只在谁来换算。

![应变寿命方法的三种可能输入：载荷（上红）、应力（中绿）、应变（下蓝）](/images/neubers-rule/fig4-input-types.png)

*（图源：网络 侵删）*

方法属性里的 **Input Type** 字段只有两个选项，对应两条换算路线：

- <strong>Load（载荷）</strong>：输入是力或应力时间历程时选它。软件内部先经影响系数换算，再用 Neuber 法则（配合 Ramberg-Osgood 材料数据）导出弹塑性应变；
- <strong>Elastic-plastic strain（弹塑性应变）</strong>：输入已经是应变片实测的应变时选它，不需要任何换算。

![Strain Life 方法属性中的 Input Type 设置（右下）](/images/neubers-rule/fig5-input-type-setting.png)

*（图源：网络 侵删）*

选了 Load 之后，还有一步"载荷如何变成应力"要交代，即 **Load Influence** 字段的两个选项：<strong>Manual（手工）</strong>与 <strong>Input Base Unit -> Material Data Base Unit（输入基准单位换算到材料基准单位）</strong>。

<strong>Manual（手工）</strong>：已知换算系数时用。典型来路是线性有限元——单位载荷加在有限元模型上，读出危险单元的应力，得到力-应力灵敏度。官方文章的算例：单位载荷下某单元灵敏度为 5.03983 MPa/N，则 Stress Influence 填 5.03983（单位 MPa），Load Influence 填 1 N，载荷历程乘上这对系数就得到弹性应力历程，再走 Neuber 换算。这正是本文第三节第二个算表的软件实现。

![依据有限元模型设置 Stress Influence 与 Load Influence（5.03983 MPa/N）](/images/neubers-rule/fig7-fe-stress-influence.png)

*（图源：网络 侵删）*

**Input Base Unit -> Material Data Base Unit**：换算系数未知时的兜底——把输入历程的数值直接按材料数据库的单位重新标注（例如 2,000,000 N 的历程读作 2,000,000 Pa = 2 MPa）。官方文章明确提示：这样得到的绝对结果不正确（not correct in absolute terms），只能用于相对比较——几条载荷历程谁更伤可以比，绝对寿命不能报。

如果输入已经是弹性应力时间历程（单位 MPa），同样选 Load + Manual，把两个影响系数都设为 1——应力原样通过，直接进 Neuber 换算。注意 Testlab Neo 的材料数据以 MPa 为基准，输入应力必须是 MPa 才对得上。

::: warning 工程注意
- <strong>Neuber 换算的前提是"有缺口、会局部屈服"</strong>：光滑试棒远低于屈服的工况，换算前后几乎没有差别；它解决的是缺口件局部塑性问题，不是万能修正器
- **Ramberg-Osgood 参数必须是循环参数**：$K'$、$n'$ 来自循环稳定化后的试验拟合，用单调拉伸参数替代会系统性偏差
- **单位兜底档只做相对比较**：绝对寿命结论必须建立在真实的影响系数（有限元灵敏度或实测标定）上
- **与平均应力修正的关系**：Neuber 换算输出的是真实局部应力/应变循环， Goodman 等平均应力修正处理的是应力循环的静态分量——两者在流程上是串联的两步，不互相替代
:::

## 五、小结

Neuber 法则的输入输出关系一句话可以说完：弹性应力历程进，弹塑性应变历程出，中间是"等面积"两个字。它在应力-应变图上把线性模型的弹性点沿等能量双曲线搬到材料的 Ramberg-Osgood 曲线上，用能量的等价交换，让不包含任何塑性知识的线性结果，获得塑性材料行为的修正。缺口件低周疲劳评估的完整链条因此闭合：有限元灵敏度把载荷换成弹性应力，Neuber 把弹性应力换成弹塑性应变，雨流计数拆循环，应变寿命法出损伤。链条上每一步的物理含义，比软件界面上那几个下拉框重要得多。

## 一句话记住

Neuber 法则用"应力乘应变能量守恒"把弹性点搬到 Ramberg-Osgood 曲线上：塑性缓和应力、放大应变，缺口件疲劳由应变主导——线性有限元加 Neuber 换算，就能喂饱应变寿命法。
