# S-N 曲线与疲劳极限：材料抗疲劳能力的标尺

> 两个载荷历程，一个 300 MPa 循环 1000 次，另一个 600 MPa 循环 1000 次——幅值只翻了一倍，损伤却翻了二十倍。这个反直觉的结果背后，是 S-N 曲线的双对数本质：它是一张“查询表”，横轴是循环次数、纵轴是交变应力幅值，告诉你某种材料在给定应力下平均能扛多少次循环。本文把这把标尺的来历（Wöhler 与 1842 年凡尔赛火车事故）、三个寿命区间（塑性/弹性/无限寿命）、双对数规律的工程含义一次讲清，并给出 k 因子、平均应力修正与载荷类型修正的使用要点。

## 一、为什么需要一把“寿命标尺”

零件强度校核回答的是“这一次载荷能不能扛住”，疲劳分析回答的是“重复多少次之后会断”。两个问题的答数之间没有直接换算关系：钢制车轴在远低于屈服强度的应力下反复加载，几十万次后依然断裂。要预测这种失效，必须知道每一级应力幅值对应多少次循环寿命——这张对照表就是 S-N 曲线（S-N Curve，又称 Wöhler 曲线）。

这把标尺的历史本身就是被事故逼出来的。1842 年法国凡尔赛，机车车轴在日常行驶的低应力循环下意外断裂，五十余人遇难。德国工程师 August Wöhler（1819～1914）为调查此事故开发了反复加载试验装置，系统绘制载荷水平与致断循环次数的关系——他发现裂纹在轴表面缓慢萌生、长大，到临界尺寸后突然快速扩展导致断裂，而这些载荷水平远低于材料的强度极限和屈服强度。对当时的观察者而言，车轴什么时候突然断裂看似无法预测；直到 S-N 曲线出现，循环应力与寿命的关系才可以被一致地预估。

![图1：August Wöhler（1819～1914）因调查铁路车轴失效开发了 S-N 曲线（Siemens Simcenter Testing Knowledge Base）](/images/sn-curve-basics/fig1-wohler.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

::: info 核心概念
- <strong>S-N 曲线（S-N Curve / Wöhler 曲线）</strong>：交变应力幅值与致断循环次数的关系曲线，通常横纵轴均取对数刻度，是疲劳寿命预测的查询表
- <strong>疲劳极限（Endurance Limit / Fatigue Limit）</strong>：存在于钢等铁基材料的一个应力幅值门槛——全部循环低于此幅值时理论上可承受无限次循环
- <strong>k 因子（k-factor）</strong>：双对数 S-N 曲线弹性段的斜率，描述应力水平变化被放大成寿命变化的倍率
:::

## 二、曲线怎么来：从试棒到查询表

S-N 曲线的原料是金属试棒（coupon）的成组恒幅循环试验：把一批同材料、同工艺的小试棒装上轴向疲劳试验机，每组固定一个应力幅值循环加载直到裂纹或断裂，记录致断次数；换一个应力级再来一组，把 (S, N) 点对画到双对数坐标上。工程上通常要求至少 5 个应力水平、每级 3 次重复，才能拟合出一条可用的曲线。

![图2：用金属试棒循环试验机生成 S-N 曲线（Siemens Simcenter Testing Knowledge Base）](/images/sn-curve-basics/fig2-coupon-machine.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

![图3：典型 S-N 曲线：应力幅值越高、致断循环次数越少（Siemens Simcenter Testing Knowledge Base）](/images/sn-curve-basics/fig3-sn-curve.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

曲线的功能就是一张查询表：知道应力幅值，顺着虚线查到对应的致断次数。绝大多数 S-N 曲线从左上向右下倾斜——幅值高的循环寿命短，幅值低的循环寿命长。有一个容易忽略的细节：疲劳试验里循环的频率本身不进入结果——决定寿命的只有循环次数，不是加载快慢。但在真实结构上频率会间接起作用：当载荷频率与结构固有频率重合时，谐振放大应力幅值，寿命随之缩短——这是 NVH 与耐久交叉的地方：共振区的振动放大等于把载荷谱向高应力段搬运。

## 三、三个寿命区间与三个关键应力

一条完整的 S-N 曲线可以划出塑性、弹性、无限寿命三个区间，分界由三个关键应力值给出：

![图4：S-N 曲线上的强度极限、屈服强度与疲劳极限（Siemens Simcenter Testing Knowledge Base）](/images/sn-curve-basics/fig4-regions.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

- <strong>强度极限（Ultimate Strength）</strong>：一个循环就失效的应力水平，对应曲线最左上端
- <strong>屈服强度（Yield Strength）</strong>：塑性区与弹性区的分界，这两个值都可以由静态拉伸试验直接得到
- <strong>疲劳极限（Endurance Limit）</strong>：若全部循环幅值低于此门槛，不发生疲劳失效

<strong>塑性区（低周疲劳）</strong>：应力超过屈服强度，材料每个循环都产生不可恢复的形变，少量高幅循环即失效。塑性与几何形状主导寿命，用 S-N 曲线算塑性区寿命并不合适——工程上应改用应变-寿命（E-N）方法，它还能计入载荷顺序的影响。

<strong>弹性区（高周疲劳）</strong>：应力-应变保持线性，循环卸载后材料恢复原状。失效需要大量低幅循环，故称高周疲劳。残余应力与几何细部（如尖角、小圆孔）是这个区间的主导因素——缓和的几何过渡比陡变几何更难萌生裂纹。S-N 曲线的主流应用就在这个区间。

**无限寿命区**：钢等铁基材料在疲劳极限以下出现明显的斜率拐点，之后曲线趋平——幅值低于此门槛时理论上可承受无限次循环（工程上百万次以上的试验即视为验证）。发动机曲轴、连杆这类循环累积极快的关键件通常按无限寿命设计：把全部工况应力幅值压在疲劳极限之下。

但无限寿命有两个前提必须牢记：第一，它只针对循环应力本身，假设腐蚀等其他机制不存在；第二，只要任一个循环进入弹性或塑性区，疲劳极限即告失效——偶发一次过载就能把“永远不坏”的零件拖回有限寿命世界。

还要注意：铝合金、镁合金、铜合金等多数非铁基合金没有明确的疲劳极限——钢的曲线在极限处有明显斜率拐点，铝的曲线则持续下倾，只能按指定循环次数（如 $10^7$ 次）对应的应力作为设计门槛。给铝件定“疲劳极限”是常见的工程错误。判断零件是否处于无限寿命区，通常用 Goodman-Haigh 图：它在幅值之外还计入了平均应力的影响。

## 四、双对数的代价：幅值翻倍、损伤翻二十倍

回到开头的例子。两段历程：300 MPa × 1000 次，以及 600 MPa × 1000 次。按 Miner 法则，同幅值下循环次数翻倍，损伤翻倍（300 MPa × 2000 次的损伤是 300 MPa × 1000 次的两倍）——这符合常识。但幅值翻倍、次数不变，损伤却是二十倍（Simcenter 手册中的对比算例）。为什么？

因为 S-N 曲线实际上是双对数图。在线性坐标上看同一条曲线，才能意识到应力与寿命的关系有多么陡峭：线性坐标里“看起来还行”的幅值余量，在寿命轴上是几个数量级的压缩。

![图5：同一条 S-N 曲线在线性（左）与双对数（右）坐标上的样貌（Siemens Simcenter Testing Knowledge Base）](/images/sn-curve-basics/fig5-log-vs-linear.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

用具体数字感受这种敏感性。这个公式回答的问题是：弹性区内给定应力幅值 S，平均能循环多少次？其中 N(S) 对应物理里该幅值下的平均致断循环次数，k 对应双对数曲线的斜率（注：本文 k 为寿命对应力的斜率指数，与 Basquin 形式中的幅值指数 m 互为倒数，k=1/m），C 是由试验拟合的常数：

$$N(S) = C \cdot S^{-k}$$

两边取对数即得直线形式。这个公式回答的问题是：双对数坐标上斜率是多少、拐点在哪里？它把幅值与寿命的幂律关系写成一条直线，便于拟合与查表：

$$\lg N = \lg C - k \cdot \lg S$$

k 越大，曲线越陡，幅值的小变化被放大成寿命的巨大变化。按 Simcenter 手册的经验值，k=5（钢的典型值）时，载荷变化 15%，损伤/寿命变化约为 2 倍；常用材料的经验 k 值：焊缝约 3、钢约 5、铝约 7。这个公式回答的问题是：幅值变化一个比例 r，寿命放大多少倍？答案是 r 的 k 次方——幅值翻倍、k=4.3 时损伤正好翻二十倍（$2^{4.3}\approx 20$）：

$$\frac{N(S_1)}{N(S_2)} = \left(\frac{S_2}{S_1}\right)^{k}$$

![图6：k 因子与应力水平、疲劳寿命的换算表（Siemens Simcenter Testing Knowledge Base）](/images/sn-curve-basics/fig6-kfactor-table.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

这个换算关系直接支撑了加速耐久试验的合理性：把载荷提高一小截（保证失效模式不变），寿命就能大幅缩短，从而把试验时间压缩到工程可接受的范围。反过来它也是精度警报：载荷测量差 15%，寿命预测差一倍——这就是耐久载荷谱测量对量程与标定精度“锻而不舍”的根源。

```python
import numpy as np

# 钢的典型 S-N 参数（弹性区幂律段，示意值）：300 MPa 对应 1e5 次，k=5
k = 5.0
C = 1e5 * 300.0**k          # 由锚点 (300 MPa, 1e5 cycles) 反算 C
N = lambda S: C * S**(-k)   # 幂律式 S-N 关系

for S in (300.0, 345.0, 600.0):   # 基准 / +15% / 翻倍
    print(f"S={S:6.0f} MPa -> N = {N(S):.3g} cycles")

# 幅值 +15% 的寿命变化（应为 2 倍左右）
print("life ratio (+15% load):", round(N(300)/N(345), 2))
# 幅值翻倍、要达到同样损伤的损伤倍数（k=4.3 时约 20 倍）
k2 = 4.3
print("damage ratio (2x stress, k=4.3):", round(2.0**k2, 1))
```

运行结果：300 MPa 对应 $10^5$ 次；幅值提高 15%（345 MPa）寿命降至 $4.98\times10^4$ 次，比值恰为 2.01；幅值翻倍时若取 k=4.3，同次数循环的损伤倍数为 $2^{4.3}\approx 19.9$，即开头“二十倍”的由来。一个幅值误差就能把寿命预测拖离一个数量级，这就是双对数规律的工程分量。

## 五、曲线的两类修正：平均应力与载荷类型

标准试棒试验给出的 S-N 曲线通常对应平均应力为零的对称循环（应力比 R = −1）。真实零件很少这么“干净”：悬架系统要扛住车重（静态拉伸平均应力），路面起伏叠加在上面。这时需要对曲线修正。

平均应力的方向决定修正的方向：**拉伸平均应力为正**，相当于在循环之外始终有一股力把裂纹拉开，寿命缩短——相当于把 S-N 曲线整体下移；**压缩平均应力为负**，裂纹在部分循环中被压闭，寿命延长——曲线上移。这个公式回答的问题是：循环载荷的平均水平在哪里？其中 R 对应物理里循环中最小应力与最大应力之比，是标记试验条件的便捷方式：

$$R = \frac{\sigma_{\min}}{\sigma_{\max}}$$

完全对称循环（平均应力为零）R = −1；静态载荷 R = 1；航空工业常用 R = 0.1 保证净拉伸。报告 S-N 数据时必须同时报 R 值，否则无法判断平均应力修正的方向。

另一类修正来自载荷方式：同一材料在弯曲、扭转、轴向加载下的 S-N 曲线不同，需用载荷比例修正系数 $C_f$ 把应力上下缩放（如手册给的算例中弯曲与扭转之间调整 40%）。此外零件尺寸、表面粗糙度、缺口与圆孔等几何特征也都要求对材料曲线修正后才能用于具体零件——材料曲线不等于零件曲线。

## 六、曲线的统计本质与选用要点

S-N 曲线不是一条“确定的线”，而是对一片散布数据的拟合：同一应力水平下各试棒的致断次数天然分散，理想情况下应由置信区间代替单值曲线。试验成本限制了样本量，工程上常见的做法是从 FKM 《Analytical Strength Assessment》（德国机械设备制造商协会 VDMA 出版）等手册查成熟材料的曲线；新合金则必须自己投入试验。

选用与使用中的三个检查点：

::: tip 工程要点
- **先判区间再选方法**：幅值进入塑性区就换 E-N 应变-寿命方法，不要用 S-N 硬算
- **铝件没有疲劳极限**：只能按指定循环次数的对应应力设计，“永远不坏”对铝不成立
- **数据口径齐全再比较**：应力比 R、载荷类型、表面与尺寸修正、置信度，任一项不同，两条曲线就不可直接比较
:::

## 一句话记住

S-N 曲线是材料的“寿命查询表”：幅值越低寿命越长，钢在疲劳极限以下趋于无限寿命而铝没有；双对数规律下幅值翻倍损伤翻二十倍——用前先查 R 比、载荷类型与修正口径。
