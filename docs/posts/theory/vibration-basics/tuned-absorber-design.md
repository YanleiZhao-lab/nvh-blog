# 调谐式动力吸振器：用模态模型直接算出质量、刚度与阻尼

> 排气吊钩 38 Hz 共振、顶棚 45 Hz 轰鸣，加筋错频改动的是结构模态，影响面大。Simcenter 模态设计模块提供一种附加式整改手段：调谐式消振器（Tuned Absorber），不修改原结构，只在共振点附近附加一个单自由度质量-弹簧-阻尼系统，把响应峰值压低。本文按 LMS 理论手册第二十章 20.3.3.8 的公式链，从消振器运动方程推导到等效质量反算，给出 m、k、c 三个参数的完整设计流程，并用 numpy 数值实验复现 5% 质量比把 42 Hz 共振峰压低 13 dB、单峰分裂为等高双峰的全过程。

## 一、吸振器在共振整改方法中的位置

共振整改通常优先考虑"错频"：增加刚度或减小质量，把固有频率移出激励频段。但对动力总成悬置架、排气吊钩这类附件，结构改动牵涉面广：吊钩加粗可能把模态能量耦合进车身，悬置架加筋改动的是整车 NVH 标定。此时可以把整改目标从"移走峰"改为"压低峰"，吸振器即属于这一类方法。

其物理原理：在共振结构的振幅最大点附加一个小的单自由度系统，调谐到原共振频率附近。原结构振动时，吸振器质量块被反向加速，其惯性力通过弹簧和阻尼器反作用回附着点，抵消原结构在该频率处的运动。激励频率不变、结构不改，只在共振点附近抑制响应。

![调谐式消振器：刚性质量经弹簧与阻尼器连接到结构](/images/tuned-absorber-design/fig-tuned-absorber.png)

*（图源：Simcenter Testing Knowledge Base）*

三条整改路线的取舍：

| 整改路线 | 对固有频率 | 对峰高 | 附加质量 | 适用场景 |
| --- | --- | --- | --- | --- |
| **加筋/错频** | 上移 | 基本不变 | 小 | 激励频段窄、结构改动自由 |
| **加阻尼** | 不变 | 压低、带宽变宽 | 很小 | 阻尼原本低、宽频激励 |
| **调谐吸振器** | 单峰裂双峰 | 大幅压低 | 中（质量比 2%~10%） | 频率改不动、定点频率激励 |

::: tip 选择原则
- 定速定频的共振（如怠速转速对应的发动机阶次、附件阶次），吸振器收益最大
- 宽频随机激励下吸振器只保住调谐点附近，应先分析激励谱再作决定
- 质量比不足 2% 时压峰效果有限，需考虑其他整改路线
:::

## 二、从运动方程到三个设计公式

### 附着点受力：一个频率相关的等效质量

设附着点沿消振器方向的运动为 $x(t)$，消振器质量块位移 $x_2(t)$，两者相对位移 $\delta = x_2 - x$。质量块上只受弹簧力和阻尼力，其运动方程为（手册式 20-72）：

$$m\,\ddot{x}_2 + c\,\dot{\delta} + k\,\delta = 0$$

物理意义：质量块的惯性力全部由弹簧和阻尼器传回附着点。设谐波激励下各量为复幅值 $\bar{x}$、$\bar{\delta}$（省略 $e^{j\omega t}$ 因子），解出相对位移（式 20-73）：

$$\bar{\delta} = \frac{m\,\omega^{2}}{-m\,\omega^{2} + j\,\omega\,c + k}\,\bar{x}$$

物理意义：相对位移与附着点运动之比是频率的函数，在消振器固有频率 $\omega_a=\sqrt{k/m}$ 附近急剧增大。再看质量块对结构的作用力：由牛顿第三定律，结构受到的反作用力等于 $k\delta + c\dot{\delta}$，而由运动方程它恰好等于 $-m\ddot{x}_2$。把式 20-73 代入，手册得到（式 20-75）：

![作用在消振器附着点的力](/images/tuned-absorber-design/eq20-76.png)

*（图源：Simcenter Testing Knowledge Base）*

写成解析形式：

$$F = \frac{(k + j\,\omega\,c)\,m}{-m\,\omega^{2} + j\,\omega\,c + k}\,\omega^{2}\,\bar{x}$$

这个力可以视作一个**等效质量**的惯性力 $F = m_{\mathrm{eff}}(\omega)\cdot\ddot{x}$（式 20-76），等效质量为（式 20-77）：

$$m_{\mathrm{eff}}(\omega) = \frac{(k + j\,\omega\,c)\,m}{-m\,\omega^{2} + j\,\omega\,c + k}$$

关键在于 $m_{\mathrm{eff}}$ 是频率的函数：分母 $k - m\omega^{2} + j\omega c$ 在 $\omega_a$ 附近趋于零，等效质量急剧增大；极限情况 $c=0$ 且 $\omega = \omega_a$ 时分母为零，附着点如同被无限大质量约束，振动**完全消除**。这就是调谐的数学本质：不是吸收能量，而是让结构在该频率点上"推不动"。

![吸振器等效质量的频率特性](/images/tuned-absorber-design/fig-mass-curve.png)

*（图示：按式 20-77 计算的等效质量幅值。低频趋于吸振器质量 237 g，在调谐频率 40 Hz 附近急剧增大，高频后反号衰减。按本文第三节算例参数绘制）*

### 最佳调谐频率与最佳阻尼

完全消除只在无阻尼、单频、频率不漂移时成立。实际工程要对付的是**结构共振峰**：峰有宽度、频率会漂移，消振器自身也需要阻尼限幅。手册给出共振缩减场景下的两个最优公式（Den Hartog 经典解）。

最佳调谐频率（式 20-78）：

![消振器最佳调谐频率](/images/tuned-absorber-design/eq20-78.png)

*（图源：Simcenter Testing Knowledge Base）*

即 $\omega_a = \omega_n/(1+\mu)$，**有意调低于**结构固有频率 $\omega_n$，不是正好调到共振频率。原因：装上吸振器后单峰分裂为双峰，$\mu$ 越小双峰越拢，$\mu$ 越大双峰越开；按上式调谐能让两个新峰恰好等高。

最佳阻尼比（式 20-80）：

![消振器最佳阻尼比](/images/tuned-absorber-design/eq20-80.png)

*（图源：Simcenter Testing Knowledge Base）*

手册形式为 $\zeta_a = \sqrt{3\mu/\left(8(1+\mu)^{3}\right)}$（Den Hartog 原式，阻尼比以结构固有频率 $\omega_n$ 为参考）；若以消振器自身调谐频率 $\omega_a$ 为参考，同一阻尼系数对应 $\zeta_a = \sqrt{3\mu/\left(8(1+\mu)\right)}$，两种写法等价。阻尼太小，双峰尖锐且调谐点外响应被放大；阻尼太大，等效质量的增大效应被削弱，压峰能力下降。最优值使双峰等高且最小，这是优化问题"最坏点最小化"（minimax）的解析解。

其中质量比 $\mu = m_a / m_{\mathrm{eq}}$（式 20-79），$m_a$ 为消振器质量，$m_{\mathrm{eq}}$ 是**结构在附着点、对被调谐模态的等效质量**。

### 等效质量：模态模型提供的输入

前两个公式代入即可，关键输入是 $m_{\mathrm{eq}}$。手册式 20-81：

![结构等效质量计算式](/images/tuned-absorber-design/eq20-81.png)

*（图源：Simcenter Testing Knowledge Base）*

写成解析形式：

$$m_{\mathrm{eq}} = \frac{1}{\psi_j^{2}\cdot 2\,j\,\omega_{d}}$$

它需要两个模态模型产物：被调谐模态在附着点的**带标尺模态振型系数** $\psi_j$（按质量归一，即模态质量取 1 kg），以及该模态的**有阻尼固有频率** $\omega_d$（rad/s；所得 $m_{\mathrm{eq}}$ 单位 kg）。对驱动点（Driving Point，激励与响应同点）FRF，位移留数与等效质量的关系是 $A_{jj} = -j/(2\,\omega_d\,m_{\mathrm{eq}})$，反算即：

$$m_{\mathrm{eq}} = \frac{-1}{2\,\omega_d\,\mathrm{Im}(A_{jj})}$$

驱动点留数恒为负虚部（相位落后），所以分母恒正。这也解释了手册反复强调的**驱动点系数**要求：没有驱动点测量，模态振型只有任意比例，标尺无从谈起，等效质量和吸振器参数全都算不出绝对值。这也是悬置吸振器设计必须补测悬置主/被动侧驱动点 FRF 的原因。

::: info 核心概念
- **调谐式消振器（Tuned Absorber）**：附加在结构上的单自由度质量-弹簧-阻尼系统，调谐到目标频率以压低该处响应
- **等效质量（Equivalent Mass）**：结构在附着点对某一模态表现的单自由度等效质量，由带标尺振型系数或驱动点留数反算
- **质量比（Mass Ratio）**：消振器质量与结构等效质量之比，决定压峰上限
- **minimax 最优**：式 20-78/20-80 使分裂后的双峰等高且最小，而非反共振点最深
:::

## 三、Python 演示：设计一台 42 Hz 吸振器

场景：某支架一阶模态 42 Hz、阻尼比 2%，驱动点拟合得位移留数（m/N，位移 FRF）虚部为 -4.0e-4。质量比取 5%，走完"留数反算等效质量、三参数设计、装上验证"全流程。

```python
import numpy as np

# --- 输入：模态模型产物 ---
A_jj, fn, zeta_s = -4.0e-4j, 42.0, 0.02          # 驱动点留数(m/N)、固有频率、结构阻尼比
wd = 2*np.pi*fn
m_eq = -1/(2*wd*A_jj.imag)                        # 反算等效质量
m1, k1 = m_eq, m_eq*wd**2                         # 主结构 SDOF 参数
c1 = 2*m1*zeta_s*wd

# --- 设计：式 20-78 / 20-80 ---
mu = 0.05                                         # 质量比 5%
m2 = mu*m_eq
f2 = fn/(1+mu)                                    # 故意调低到 40 Hz
z2 = np.sqrt(3*mu/(8*(1+mu)))                     # 最佳阻尼比
k2, c2 = m2*(2*np.pi*f2)**2, 2*m2*z2*(2*np.pi*f2)
print(f"等效质量 {m_eq:.2f} kg -> 吸振器 {m2*1e3:.0f} g, "
      f"{k2:.0f} N/m, {c2:.1f} N.s/m (f_a={f2:.1f} Hz, zeta={z2:.3f})")

# --- 验证：装上后的耦合 FRF ---
f = np.linspace(30, 56, 5201); w = 2*np.pi*f; j = 1j
a11 = k1+k2 - m1*w**2 + j*w*(c1+c2)               # 2x2 动刚度矩阵组装
a12 = -k2 - j*w*c2
a22 = k2 - m2*w**2 + j*w*c2
H_new = np.abs(a22/(a11*a22 - a12**2))            # 附着点位移/力
H_old = 1/np.abs(k1 - m1*w**2 + j*w*c1)
pk = np.where((H_new[1:-1] > H_new[:-2]) & (H_new[1:-1] > H_new[2:]))[0] + 1
print(f"原峰 {H_old.max()*1e3:.3f} mm/N -> 新峰 {H_new.max()*1e3:.3f} mm/N, "
      f"降 {20*np.log10(H_old.max()/H_new.max()):.1f} dB")
print("分裂双峰: " + ", ".join(f"{f[i]:.1f} Hz" for i in pk))
```

运行结果要点：等效质量 4.74 kg，吸振器参数 237 g / 14960 N/m / 15.9 N.s/m（阻尼比 0.134，明显高于常用结构阻尼比量级）；原峰 0.076 mm/N 压到 0.016 mm/N，**降 13.3 dB**；单峰分裂为 37.4 Hz 与 44.4 Hz 两个新峰，幅值差仅 0.5 dB，式 20-78 的调低正是为了让它们等高。

![装吸振器前后的附着点驱动点 FRF 对比](/images/tuned-absorber-design/fig-frf-before-after.png)

*（图示：原结构单峰 0.076 mm/N，装吸振器后分裂为 37.4 Hz / 44.4 Hz 近等高双峰，峰值降至 0.016 mm/N。按本节代码输出绘制）*

再对比两组方案（同样流程换参数重算）：直接调到 42 Hz 而非 40 Hz，新峰回升约 2.1 dB 且两峰不等高；质量比减半到 2.5%，峰高回到 0.0215 mm/N，与调谐不当方案的水平相当。质量比 5% 且调谐正确时的收益约等于把质量加倍，调谐精度和质量比的收益在同一量级。

## 四、工程落地清单与常见问题

设计流程四步：模态试验拟合出极点与驱动点留数，反算附着点等效质量，按式 20-78/20-80 算出吸振器三参数，用修改预测验证装上后的耦合模态。输入与来源对照：

| 设计输入 | 来源 | 缺失后果 |
| --- | --- | --- |
| **有阻尼固有频率、阻尼因子** | 模态拟合（极点） | 调谐频率失准，压峰变推峰 |
| **带标尺振型系数** | 需驱动点测量定标 | 等效质量无绝对值，质量比失真 |
| **质量比** | 工程权衡（2%~10%） | 过小压不动，过大附加质量影响原模态 |
| **附着点与方向** | 振型动画确认 | 附加在节点附近，激励不起来 |

::: warning 工程注意
- **模态模型频带要够宽**：手册要求至少包含感兴趣频带上下各一个模态，带外模态靠残余项补偿，而残余项无法参与振型标尺，等效质量会算错
- **修改量别越界**：装吸振器属小修改，预测出的新模态若超出原试验频带，结果不可信
- **失谐敏感**：温度、工况让结构频率漂移 2~3 Hz，吸振器就偏出最优窗；质量比 5% 时约 0.13 的最佳阻尼比正是抗失谐的余量，不应为追求极限压峰把阻尼做小
- **高频慎用**：吸振器带宽正比于质量比，齿轮啸叫这类 1 kHz 以上、频率又漂移的目标，先算带宽再动手
:::

::: tip 实用建议
- 附着点选被调谐模态振型系数最大处（驱动点 FRF 峰最高点附近），等效质量小、同样吸振器质量下质量比更大
- 先用修改预测把"结构 + 吸振器"的耦合模型算一遍再开模，37.4 Hz/44.4 Hz 两个新峰若与其他阶次重叠，整改无效
- 双方向都有问题时装两台单方向吸振器，不做斜向一体式，两个目标的最佳参数不同
:::

## 五、小结

调谐式吸振器是模态模型少有的直接输出设计参数的场景：驱动点留数给出等效质量，两个闭式公式给出全部三参数，前后不到十分钟计算量。判断标准明确：定点频率激励、频率错不开、能给 2%~10% 质量比，就按式 20-78/20-80 设计并预留阻尼调整空间；宽频或频率漂移大的问题，应走加阻尼或隔振路线，吸振器并非通用方案。
