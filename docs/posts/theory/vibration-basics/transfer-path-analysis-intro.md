# 传递路径分析TPA入门：把整车噪声拆成一条条可量化的传递路径

> 车内噪声超标时，工程上需要回答的问题是：贡献来自发动机悬置、排气吊钩，还是面板辐射？传递路径分析（Transfer Path Analysis, TPA）将系统分解为"源—路径—目标"三要素，逐条路径计算贡献量，为整改决策提供排序依据。本文说明路径的定义方法、工况力的两种估计途径、贡献量图的判读流程，以及相位抵消现象对排序结论的影响。

## 一、TPA 要回答什么问题

整车 NVH 排查的典型情形：目标点（驾驶员耳旁）噪声超标，但候选声源众多—发动机四个悬置、排气吊钩、变速箱撑杆、面板辐射…每个都测过振动，幅值都不小。资源有限，先改哪个？

TPA 的思路是把系统分解为三要素：

- **源（Source）**：以输入量表征。结构声（structure-borne）路径用力 $F$（单位 N）；空气声（airborne）路径用体积加速度 $Q$（volume acceleration，单位 $\mathrm{m^3/s^2}$）。
- **路径（Path）**：源与目标之间的传递函数，即频响函数 FRF（Frequency Response Function）。声学目标常用 $P/F$（单位 Pa/N）或 $P/Q$。
- **目标（Target）**：人员感知噪声或振动的位置，响应量为声压 $P$（Pa）或加速度 $A$（$\mathrm{m/s^2}$）。

每条路径对目标的贡献量是一个频域乘法：

$$P_i(f) = F_{o,i}(f) \cdot \left(\frac{P}{F}\right)_i(f)$$

即工况力（operational force）乘以传递函数，得到该路径单独传递到目标点的声压。式中三项均为随频率 $f$ 变化的复数，含幅值与相位信息。将所有路径贡献矢量求和，应等于目标点实测总声压—这一对账关系是 TPA 结果可信度的基础校验。哪条路径的 $|P_i|$ 大，整改优先级就高，这就是 TPA 的基本逻辑。

::: info 核心概念
- **工况力（Operational Force）**：源在实际运行状态下输入结构的力，随频率（或阶次）变化
- **传递函数（Transfer Function）**：单位力激励到目标点响应的 FRF，在源停机状态下测量
- **贡献量（Contribution）**：单条路径的 $F_o \times$ FRF，复数，含幅值与相位
- **计算总级（Calculated Total）**：所有路径贡献的矢量和，用来与实测总级对账
:::

注意测量顺序：传递函数必须在**源不运行**时测量（力锤激励、激振器激励或有限元单位载荷），它反映的只是"路径"的特性；工况力则在源运行时测量。两批数据分开采集，最后在频域相乘。

## 二、结构声与空气声：按力的输入方式分类

"传递方式"（borne）指的是力**离开源的方式**，不是声音到达人耳的最终方式：

- **结构声（Structure-borne）**：源通过机械连接向结构输入力—发动机经悬置把力传入车身，车身壁板振动再辐射为噪声。力的起点是机械连接点。
- **空气声（Airborne）**：源直接向空气辐射声能，例如进气口噪声经空气传播到车厢，或经面板透射进入。输入量以体积加速度 $Q$ 表征。

容易混淆之处在于：结构声路径的终点也可能是"听到的声音"（结构振动最终辐射发声），空气声路径也可能中途与结构发生相互作用。分类只依据输入侧—力是从螺栓连接传入的，还是从空气辐射传入的。

一次完整的 TPA 可以同时包含两类路径：结构声路径用 $F_o \cdot (P/F)$，空气声路径用 $Q_o \cdot (P/Q)$，最后一起矢量求和。

两类传递函数之间存在互易关系。根据声学互易定理，把校准声源（Q-source）置于目标点发声、在路径点测加速度，得到的 $A/Q$ 与敲击路径点、在目标点测声压得到的 $P/F$ 数值相等，可由单位导出：

$$\frac{P}{F} = \frac{\mathrm{Pa}}{\mathrm{N}} = \frac{\mathrm{N/m^2}}{\mathrm{N}} = \frac{1}{\mathrm{m^2}}, \qquad \frac{A}{Q} = \frac{\mathrm{m/s^2}}{\mathrm{m^3/s^2}} = \frac{1}{\mathrm{m^2}}$$

两者都化为 $1/\mathrm{m^2}$。据此，传统上需要对 4 个悬置 × 3 个方向逐一敲击得到的 12 条 $P/F$，可以用一个 Q-source 放在声学响应点、悬置点贴加速度计，**一次测量**同时获得全部 12 条传递函数（Simcenter Testing Knowledge Base 对此有专门论述）。

## 三、切一刀定义路径：切口位置决定模型结构

定义路径的做法是构造一个连续的"切面"（cut）把源与结构分离，**所有跨越切面的连接即为路径**。同一辆车，切口位置不同，得到的 TPA 模型完全不同。

以一辆卡车为例。切口绕发动机划：四个悬置 × 每个三个平动方向 = **12 条结构声路径**。

![发动机四个悬置被定义为源，跨过切口的 4 个连接点 × 3 方向 = 12 条路径](/images/transfer-path-analysis-intro/twelve_path_tpa.png)
*（图源：Simcenter Testing Knowledge Base）*

切口也可以绕驾驶室划：发动机连同车架成为"源"，跨越驾驶室悬置的连接成为路径—5 个连接点 × 3 方向 = **15 条结构声路径**。切口还可以划在内饰面板上，得到 5 条**空气声路径**（每个面板一条，用 $Q$ 和 $P/Q$）。

三个模型的数据要求各不相同，选择哪个切口，取决于整改权限—**你能改什么**：

| 切口位置 | 路径数 | 需要的工况载荷 | 适用场景 |
| --- | --- | --- | --- |
| **发动机悬置（4 点 × 3 向）** | 12 条结构声 | 各悬置三向工况力 $F_o$ | 悬置刚度/隔振率可调 |
| **驾驶室悬置（5 点 × 3 向）** | 15 条结构声 | 各悬置三向工况力 $F_o$ | 发动机不可改动、仅可动驾驶室悬置 |
| **内饰面板（5 条）** | 5 条空气声 | 各面板体积加速度 $Q_o$ | 怀疑声学包装泄漏/面板透声 |

::: tip 切口选择原则
- 切口划在"有权限改动"的接口上：能换悬置就切悬置，能改声学包就切面板
- 切口越靠近源，路径数越少、模型越简单，但结论只对这一层接口有效
- 每个连接点不能只保留一个方向—X/Y/Z 三向的贡献往往相差悬殊，漏掉方向就是漏掉路径
:::

## 四、贡献量判读：相位抵消对排序结论的影响

TPA 结果最常用的展示是**贡献量图（Contribution Display）**：一排水平色条，红色贡献大、蓝色贡献小。读图顺序固定—

1. **最顶条**：目标点实测总级；
2. **第二条**：所有路径的计算总级，它应当与顶条吻合，说明重要路径没有遗漏；
3. **其余条**：各条路径的贡献量，按大小排序。

![贡献量图：顶条为实测总级，第二条为计算总级，其余为各路径贡献](/images/transfer-path-analysis-intro/contribution_display.png)
*（图源：Simcenter Testing Knowledge Base）*

**计算总级与实测不吻合，说明存在未识别到的重要路径**—这是 TPA 自带的质量校验。对账吻合之后，路径排序才有意义。

判读的关键在相位。贡献量是复数，路径之间既可能相加也可能相消。单条路径的贡献量幅值**完全可能高于总声级**—设左右悬置 Z 向贡献分别为 $P_L = 0.80\,e^{j10^\circ}$ Pa 与 $P_R = 0.75\,e^{j170^\circ}$ Pa，二者近似反相：

$$P_{\mathrm{total}} = \left| P_L + P_R + P_{\mathrm{hook}} \right| = \left| 0.80\,e^{j10^\circ} + 0.75\,e^{j170^\circ} + 0.30\,e^{j45^\circ} \right| \approx 0.55\ \mathrm{Pa}$$

三个幅值之和为 $0.80 + 0.75 + 0.30 = 1.85$ Pa，矢量求和结果却只有 0.55 Pa—左右悬置反相抵消了大部分。此时若按幅值排序处理"最大贡献路径"，结果可能背离预期。

```python
import numpy as np

# 某转速下三条路径在目标点的复数声压贡献（幅值 Pa，相位 deg）
paths = {
    "mnt_L_Z": 0.80 * np.exp(1j * np.deg2rad(10)),
    "mnt_R_Z": 0.75 * np.exp(1j * np.deg2rad(170)),  # 与左侧近似反相
    "hook_X":  0.30 * np.exp(1j * np.deg2rad(45)),
}
total = sum(paths.values())
print(f"三路径幅值直接相加: {sum(abs(v) for v in paths.values()):.2f} Pa")
print(f"复数矢量求和      : {abs(total):.2f} Pa   <- 真实总声压")
residual = total - paths["mnt_L_Z"]
print(f"去掉左悬置Z后残量 : {abs(residual):.2f} Pa")
print(f"目标点声压变化    : {20*np.log10(abs(residual)/abs(total)):+.1f} dB")
```

输出中两个数值值得注意：幅值直接相加得 1.85 Pa，复数矢量和只有 0.55 Pa—左右悬置反相抵消了绝大部分；进一步计算表明，把贡献幅值最大的左悬置 Z 拆除后，总声压反而**上升约 1.2 dB**（0.55 Pa → 0.63 Pa），因为原有的抵消关系被破坏。贡献量排序必须结合相位判读，孤立的大幅值并不构成整改依据。

::: warning 判读注意
- 单路径贡献量大于总级不是计算错误，而是相位抵消的标志
- 仅看幅值贡献图可能导致误判，须同时核查路径间的相位差
- 计算总级与实测不吻合时，先补充路径（漏方向、漏吊钩、漏空气声），再下结论
:::

## 五、工况力怎么来：两种力估计方法

传递函数的获取相对直接—力锤、激振器或有限元单位载荷均可。难点在工况力：把悬置换成力传感器会改变系统动力学，相当于测量了一个新结构。工程上常用两种间接估计方法。

### 悬置刚度法（Mount Stiffness Method）

在悬置**主动侧**（源侧）与**被动侧**（结构侧）各布置加速度传感器，两组加速度双重积分成位移后相减，得到悬置相对位移 $x$，再乘以悬置动刚度 $k$，即胡克定律：

$$F_o(f) = k(f) \cdot x(f) = k(f) \cdot \left( \frac{a_a(f)}{(j2\pi f)^2} - \frac{a_p(f)}{(j2\pi f)^2} \right)$$

其中 $a_a$、$a_p$ 分别为主动侧、被动侧加速度（$\mathrm{m/s^2}$），$j$ 为虚数单位；频域双重积分等价于除以 $(j2\pi f)^2$，因此 $x$ 的单位为 m，动刚度 $k$ 的单位为 N/m。注意 $k$ 应使用随频率变化的**复动刚度**（含阻尼相位滞后），而非静态刚度。

![主动侧与被动侧加速度双重积分相减得位移，乘以悬置刚度得工况力](/images/transfer-path-analysis-intro/mount_stiffness.png)
*（图源：Simcenter Testing Knowledge Base）*

该方法的适用前提是悬置足够"软"—两侧位移差明显，积分误差在差值中占比小。橡胶悬置、液压悬置满足此条件。

### FRF 矩阵求逆法（Matrix Inversion Method）

硬连接（螺栓刚性连接的变速箱撑杆、硬点）两侧位移差极小，刚度法中"小差值乘大刚度"会将测量误差放大到不可接受。改用在路径附近布置若干**指示点**（indicator points），测量指示点加速度到路径力的 FRF 矩阵，再用工况加速度反解力：

$$\{A_o\} = \left[\frac{A}{F}\right] \{F_o\} \quad \Longrightarrow \quad \{F_o\} = \left[\frac{A}{F}\right]^{-1} \{A_o\}$$

其中 $\{A_o\}$ 为工况加速度列向量（指示点数 × 1），$[A/F]$ 为指示点对路径力的 FRF 矩阵（指示点数 × 路径数）。指示点数多于路径数时矩阵不可直接求逆，采用最小二乘解：

$$\{F_o\} = \left( [H]^{\mathrm{T}} [H] \right)^{-1} [H]^{\mathrm{T}} \{A_o\}, \qquad [H] = \left[\frac{A}{F}\right]$$

![指示点加速度与路径力构成 FRF 矩阵，工况加速度反解工况力](/images/transfer-path-analysis-intro/matrix_force2.png)
*（图源：Simcenter Testing Knowledge Base）*

只用一条 FRF 直接相除不可行—FRF 在反共振点趋近于零，其倒数趋于无穷，反演力在该频率发散；而且单条 FRF 忽略了路径间的交叉耦合。正确做法是把所有路径的原点 FRF、交叉 FRF 组成矩阵**整体求解**：同一频率在所有 FRF 中同时趋零的概率大幅降低。指示 FRF 的数量通常取路径数的两倍左右，并监控每个频率点的条件数（condition number）—条件数越小，解越稳定。

```python
import numpy as np

rng = np.random.default_rng(7)
f = np.arange(20., 401., 1.0)
def reson(f, fr, zeta, s=1.0):          # 单自由度共振峰近似
    w, wr = 2*np.pi*f, 2*np.pi*fr
    return s/(1-(w/wr)**2 + 2j*zeta*w/wr)

H1 = reson(f, 120, 0.04) + 0.2                       # 指示点1的FRF
# 指示点2的FRF：在200Hz附近有深反共振
H2 = (reson(f, 190, 0.03, 0.9) + 0.2) * (1-(f/200)**2 + 2j*0.0002*f/200)
F0 = 10.0 + 0j                                       # 真实工况力 10 N
n = 0.02                                             # 加速度测量噪声
A1 = H1*F0 + n*(rng.standard_normal(f.size)+1j*rng.standard_normal(f.size))
A2 = H2*F0 + n*(rng.standard_normal(f.size)+1j*rng.standard_normal(f.size))

Fs = A2/H2                                           # 单FRF直接相除求力
Fm = (np.conj(H1)*A1 + np.conj(H2)*A2)/(np.abs(H1)**2+np.abs(H2)**2)  # 两指示点最小二乘
i = int(np.argmin(np.abs(H2)))
print(f"反共振点 {f[i]:.0f} Hz, |H2| = {abs(H2[i]):.5f}")
print(f"真实工况力       : {abs(F0):6.2f} N")
print(f"单FRF相除        : {abs(Fs[i]):8.1f} N   <- 噪声被放大")
print(f"两指示点矩阵求逆 : {abs(Fm[i]):6.2f} N")
err = np.abs(Fm-F0)/10*100
print(f"矩阵法全频段最大误差: {err.max():.1f}%")
```

200 Hz 反共振点处 $|H_2| = 0.003$，单 FRF 相除将 0.02 的加速度噪声放大成 18.6 N 的力估计（真实值 10 N，偏差 86%）；两条指示 FRF 做最小二乘反演，全频段力误差控制在 2.4% 以内。这就是矩阵求逆法必须"成矩阵"的原因。

| 方法 | 核心公式 | 适用连接 | 主要误差来源 |
| --- | --- | --- | --- |
| **悬置刚度法** | $F_o = k\,(x_a - x_p)$ | 软悬置（橡胶/液压） | 刚度取值误差直接进入力；双重积分低频漂移 |
| **FRF 矩阵求逆法** | $\{F_o\} = [A/F]^{-1}\{A_o\}$ | 硬连接（螺栓/撑杆） | 反共振点病态；指示点不足时条件数增大 |

::: warning 力估计注意
- 硬连接强行使用刚度法，位移差小到与噪声同量级，解出的力没有意义
- 矩阵求逆前先检查条件数随频率的曲线，尖峰位置即不可信频段
- 悬置动刚度应使用实测复刚度（随频率变化），不应以静态刚度代替
:::

## 六、模型搭好之后：Component Editing 虚拟修改

找到最大贡献路径只是诊断的一半，另一半是验证"修改后能降多少"。Simcenter Testlab 的 TPA Component Editing 功能允许在现成模型上做虚拟修改再重算贡献量：

- **修改结构灵敏度**：对 $P/F$ 曲线的共振峰执行 Remove Peak（例如压低 90%），等效于给车身该处加筋/加阻尼；
- **修改悬置刚度**：对 $k$ 曲线施加偏移（例如整体降低 6 dB），等效于更换软悬置；
- 修改后立即对比修改前后的计算总级与该路径贡献，量化收益。

Path Specific 视图把每条路径分解为"加速度—位移—力—FRF—贡献"链条，主导环节一目了然。修改后的模型可另存，与原模型随时切换对比。如果所有通道为同时采集（含时间历史），还可将各路径贡献反变换回时域**试听**—试听不是判读手段，但有助于建立对路径声音特征的直观认识。

## 七、小结

- TPA 的输出不是一张谱，而是一个整改决策：改哪条路径、预期降多少 dB
- 切口划在**可以改动**的接口上，路径 = 跨越切面的所有连接 × 所有方向
- 计算总级对不上实测，先怀疑漏路径，再参考排序结论
- 贡献量是复矢量：反相路径互相抵消时，拆除"最大贡献"路径可能反而升高噪声—任何修改决策前先核查相位
- 软连接用悬置刚度法，硬连接用矩阵求逆法，后者须监控条件数
