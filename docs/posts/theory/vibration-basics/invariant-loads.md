# 不变载荷：与装配无关的载荷提取

> 同一台电驱、同一个转速，装在刚性台架上测到的悬置力是 120 N，装回白车身里再测只剩 40 N——两次都是认真测的，仪器都校过准，哪个数才能写进交付给整车厂的载荷谱？答案是：都不能，因为这两个数都是“配合演出来的”接触力，它随搭档（接收端阻抗）而变。本文讲怎么把源组件的“出场特性”从搭档里剥离出来：用阻断力、自由速度、体积加速度这三类不变载荷（invariant loads）描述源，使同一份载荷数据能预测它与任何接收端的装配表现——先讲直接测量与间接估计两条路线的适用条件（弱耦合 vs 强耦合），再用电驱、路噪、HVAC 压缩机、雨刷电机四个工程案例演示接口位置与耦合类型怎么定方法。

## 一、为什么同一个源，换个“搭档”力就全变了

先把工程现场的困境说具体。零部件供应商往往在自家试验台上测了源组件（电驱、空调压缩机、雨刷电机）的悬置力载荷谱交给整车厂；整车厂拿到后装到另一套车身上做预测，结果和实测差得离谱。问题不在仪器：悬置处的接触力本来就不只取决于源，它是源的激励特性与接收端阻抗共同“合演”出来的界面量——这正是《阻断力 vs 接触力》一文讨论过的结论。源装在刚性台上，台架“端得住”，源把全部动力都传出来；源装在弱悬置上，界面“跟着动”，传出的力就小。台架一换、力就变，这份载荷谱只能描述“这个源+那个台架”的组合，换个车身就得重测。

生活里有一个准确的类比：锅炖肉。同一口锅、同一个火候，锅盖放上和不放，锅里的压力和水位完全不同——锅盖盘太重压不住（类比刚性接收端），蒸汽顶着盖子全部顶出来；锅盖轻轻浮着（类比柔软接收端），蒸汽就把盖子顶开、自己跑掉一部分。“火候”是源的固有特性（对应源的内部激励），“锅里的压力”却是源与接收端的合成结果。如果你要向别人描述这口锅多厉害，合理的做法不是报“锅里 5 个大气压”（换个盖子就变），而是报“盖死压住时会顶出多少蒸汽”——这个数不随盖子变，就是锅的“不变载荷”。整个组件基 TPA（Component-based TPA，C-TPA）的目标就是把每个组件都描述成“盖死压住时顶多少蒸汽”的形式，然后用频响函数基子结构合成（FRF Based Substructuring，FBS）在电脑里把任意组合装起来算表现，不用造物理样件。

下图是 C-TPA 的数据地图：源（A）、接收端（B）、悬置（K）各自需要哪些数据——源要不变载荷 $F_{2,A}$ 和源阻抗 $H_{22,A}$，接收端要界面阻抗 $H_{33,B}$ 和到目标点的传递灵敏度 $H_{35,B}$，悬置要动刚度 K。注意编号 2 的位置：不变载荷定义在连接界面上，而源内部激励 $F_1$（如发动机的电磁力）往往根本无法精确定位和测量——所以才要把它“折算”到界面上。

*（图源：网络 侵删）*

把这些组件数据用 FBS 拼装成整机并预测目标点响应，就是 C-TPA 的全部流程：

![用 FBS 对源-接收端系统做虚拟装配并预测目标点响应](/images/invariant-loads/fig6.png)

但 C-TPA 的精度对输入数据质量极其敏感，小误差会在最终预测里被放大；而所有输入数据中最难获取、也最容易出错的，就是源的不变载荷。本文剩下的内容都围绕一个问题：怎么拿到高质量的不变载荷。

## 二、三类不变载荷：把接收端推向两个极端

回到锅的类比：要让锅的“出场特性”与盖子无关，只有两个极端可选——盖子无限重（刚性接收端）或盖子完全拿掉（自由悬浮）。把这两个极端情形下的载荷记录下来，它们就与任何具体接收端无关：

::: info 核心概念
- <strong>阻断力（Blocked Forces）</strong>：结构声传递载荷，源连接到理论无穷大阻抗（刚性接收端）时界面上的力，单位 N
- <strong>自由速度（Free Velocities）</strong>：结构声传递载荷，源处于理论零阻抗（自由悬浮）时界面上的速度，单位 m/s（常用加速度计 m/s² 测量后积分）
- <strong>体积加速度（Volume Accelerations，声学力 Q）</strong>：空气声传递载荷，因空气阻抗远低于结构材料可自动视为自由悬浮，单位 m³/s²（其积分为体积速度 m³/s）
- <strong>C-TPA（Component-based Transfer Path Analysis）</strong>：组件基传递路径分析，用不变载荷+组件 FRF 在模型里虚拟装配预测系统 NVH 表现
- <strong>弱耦合/强耦合（Weak/Strong Coupling）</strong>：源与接收端界面阻抗差异是否显著（经验分界 >10 dB）；弱耦合时一方近似刚性、另一方近似自由，强耦合时两边行为相互牵连
:::

三类载荷之间可以换算：自由速度乘上源阻抗即得阻断力，这是源特性描述的常用等价形式。先看一个具体数字例子再说换算关系：某电驱在其悬置固有频率附近的界面机械阻抗模长为 2×10⁵ N·s/m，同频率下自由悬浮状态测得界面速度 4 mm/s，则阻断力约为 2×10⁵ × 0.004 = 800 N——这个数不随车身改变。若换上一个阻抗只有 5×10⁴ N·s/m 的柔软车身，同样的源传出的接触力会完全不同，但 800 N 的阻断力不变——这就是“不变”二字的含金量。

这个换算关系写成通式：它回答的问题是——已知自由速度描述的源，它的阻断力是多少？其中 $Y_A$ 对应物理里的源机械阻抗（机械导纳，单位 m/(N·s)，是刚度的倒数除以 jω），$v_{\mathrm{free}}$ 对应自由悬浮时界面上的速度：

$$F_{\mathrm{blocked}} = \frac{v_{\mathrm{free}}}{Y_A}$$

分母上的源机械阻抗 $Y_A$ 正是“源自己的脉搏”：同样的自由速度，源越“杆”（阻抗越小）顶出的阻断力越大。上一节的数字例子就是这条式子的一次代入：0.004 ÷ (1/(2×10⁵)) = 800 N。

## 三、怎么拿到：先判耦合强弱，再选直接测或间接估

两条获取路线的选择只看一件事：源与接收端在关心频段内是弱耦合还是强耦合。经验法则：界面两侧阻抗差异超过 10 dB 才能当弱耦合处理，否则一律按强耦合处理。

### 3.1 弱耦合：直接测量

弱耦合的物理图景可以用两个质量-弹簧小系统看清楚：右边那根弹簧远比左边的硬，于是左边的质量动起来时，右边的质量几乎不动——硬的那一侧就像被焊死在地上（近似刚性接收端），软的那一侧就像自由悬浮（近似零阻抗接收端）。此时理论极端边界可以用真实结构近似，不变载荷直接用传感器就能测到：

![弱耦合两组件的互动：右侧弹簧刚度远大于左侧，一侧近似刚性、另一侧近似自由](/images/invariant-loads/fig2.png)

*（图源：网络 侵删）*

- **直接测阻断力**：把源连到一个比它硬得多的接收端上，在连接界面用测力计抄电阻断力。限制在低频：再硬的结构到高频也会出现共振，“刚性”假设在共振之后失效。
- **直接测自由速度**：把源连到一个比它软得多的支撑上，用加速度计在界面测速度再积分。限制在高频：再软的悬浮到低频也会变硬（悬浮弹簧刚度随频率下降而减小），“自由”假设在低频失效。

![直接测量阻断力的布置示意：刚性接收端+界面测力计](/images/invariant-loads/fig3.png)

*（图源：网络 侵删）*

换算关系 $F_{\mathrm{blocked}} = v_{\mathrm{free}}/Y_A$ 意味着两条直接法可以互补：低频用刚性台测阻断力，高频用柔软支撑测自由速度，中间通过源阻抗换算拼接。

### 3.2 强耦合：间接估计（in-situ TPA 与 ASQ）

强耦合就是回到了真实装配：界面两侧的弹簧刚度、质量都相当，一个质量的运动会牵着另一个一起动，任何侧都不能简化成刚性或自由：

![强耦合两组件的互动：各弹簧刚度与质量相近，运动相互牵连](/images/invariant-loads/fig4.png)

*（图源：网络 侵删）*

此时用 in-situ TPA（在位传递路径分析）间接估计阻断力：不拆装配，在耦合状态下测接收端上若干指示点的响应 $a_4$ 和传递函数 $H_{24}$，用矩阵求逆反演阻断力：

![用 in-situ TPA 估计阻断力的布置示意：耦合状态下测指示点响应与传递函数，矩阵求逆反演](/images/invariant-loads/fig5.png)

*（图源：网络 侵删）*

这个矩阵求逆公式回答的问题是：已知接收端指示点的响应和激励到指示点的传递函数，界面上作用了多大的力？其中 $a_4$ 对应物理里的指示点响应向量（加速度），$H_{24}$ 对应每个界面力到每个指示点的传递函数矩阵，乘上伪逆矩阵就是最小二乘意义下的阻断力估计：

$$F_{\mathrm{blocked}} = \left(H_{24}^{T} H_{24}\right)^{-1} H_{24}^{T} \, a_{4}$$

值得注意的是一个反直觉结果：这个估计的精度随耦合变强而提高——因为耦合越强，激励到指示点的传递函数 $H_{24}$ 信噪比越好。这也是 in-situ TPA 的工程纯力所在：不必造专用刚性/柔性台，现有台架甚至真实装配直接就能用。空气声传递路径的体积加速度同样可以间接估计：虽然空气与结构阻抗天然失配（弱耦合），但体积加速度只有在简单平面几何上才能直接测，一般用 ASQ（Airborne Source Quantification）矩阵反演得到——结构上与 in-situ TPA 同构，只是把力换成了声学源强 Q、指示点换成了传声器。关于 Q 的定义与量纲可参考《声学参量 Q：声源的“力”与声辐射的“速度”》一文。

## 四、四个工程案例：接口在哪儿划、方法就跟着定了

选方法前先回答两个问题：**连接界面划在哪里**（取决于想把哪些部件当成可独立替换的组件）？**这个界面上是强耦合还是弱耦合**（决定直接测还是间接估）？下面四个案例都是这个决策树的展开。

### 4.1 电驱 EDU：同一个源，三种合理泻法

软悬置安装的电驱单元（EDU）是最典型的复杂场景，同一个源有三条可行路线，各有得失：

| 方案 | 接口位置与方法 | 优点 | 代价 |
| --- | --- | --- | --- |
| ① 主动侧悬置面 + in-situ TPA | 界面划在 EDU 与悬置之间 | EDU 与悬置、车身彼此独立，后续可分别替换 | 悬置太软时能量传不到车身指示点，$H_{24}$ 信噪比受损 |
| ② 被动侧悬置面 + in-situ TPA | 界面划在悬置与车身之间 | 与车身强耦合，$H_{24}$ 测得准，估计精度高 | 悬置影响混入 EDU 特性，无法独立改悬置 |
| ③ 主动侧悬置面直接测自由速度 | 界面同①，但按弱耦合处理 | 分离同样彻底，只需加速度计 | 要求悬置在关心频段内足够软 |

空气传递路径则统一用 ASQ 估体积加速度，任何台架或装配上都能做，不挑边界条件。这张表的实质是：把接口往源一侧划，组件分离彻底、可替换性强，但对测量条件苛刻；把接口往接收端一侧划，测量质量高，但源的描述里混进了别的部件。工程上没有免费的午餐，只有和产品开发节奏对得上的权衡。

### 4.2 路噪：轮心的三个频段三种拿法

结构声路噪沿“轮→悬架→车身”传入，接口可以划在不同位置，对应不同的可用频段：轮心直接用车轮力传感器在刚性台上测阻断力，但只限低频（台架刚性假设的上限）；同样在轮心，把 4〜8 个螺栓连接简化成一个虚拟点（Virtual Point Transformation，VPT）再用 in-situ TPA 估阻断力，局部刚性假设比刚性台架撑得更高，还附带得到转动自由度，频段上限提高到低中频；要更高频段，就把接口划到悬架与车身的被动侧悬置面——那里与车身强耦合，in-situ TPA 精度好，代价是轮、悬架、悬置全部混进路噪特性、无法独立替换。注意一个实操细节：直接对 4〜8 个螺栓逐个估三向力会造成矩阵条件数恶化，VPT 把它们压缩成单个虚拟点的 6 个自由度才能算得动——这是几何密度带来的数值问题，不是物理问题。

### 4.3 HVAC 压缩机：小件用重心伪力或绷带吊浮

刚性连接到发动机的空调压缩机是小尺度组件的代表：2〜3 个螺栓密集连接，几何密度比 EDU 更高。两条路都通：用 VPT 把压缩机简化成重心处的虚拟点源，in-situ TPA 估出的称为“伪力”（pseudo forces），分离彻底但受局部刚性限制在低中频；或者利用它小轻的特点，用绷带吊起来直接测自由速度，低频段上限由绷带杆软程度决定。同样的思路适用于液压泵等其它小型附件。

### 4.4 雨刷电机：不变载荷的“反例”——接触力有时反而够用

最后一个案例反过来讲：如果台架就是目标车身的前半段，它的阻抗与最终车身几乎相同，那么这个“配合演”出来的接触力也几乎就是未来车上的接触力——此时未必追求不变载荷，直接估接触力反而更省事：传递函数 $H_{34}$ 可以提前在不装源的车身上测好，装上源之后只需快速采一次指示点响应就能反演。代价是这份接触力只对这个车身有效，车身一改就全作废。它提醒我们：不变载荷是为“换搭档、早期虚拟装配”准备的；如果设计已冻结、只服务于这一台车，接触力的“不可移植”就不是缺点。

## 五、numpy 验证：接触力随搭档变、阻断力不变

用一个最小的物理模型把全文核心命题验证一遍：源是被内部激励 F1 驱动的质量 mS，经界面弹簧 kA 连向接收端。先写出源在界面处的等效阻抗（弹簧串联质量），再按定义求自由速度与阻断力，最后把同一个源接到三个阻抗不同的接收端上看接触力。分析频率取 200 rad/s，远离界面弹簧-质量的反共振点（ω=√(kA/mS)≈100 rad/s 处 Zsrc 趋零），避开数值上的特殊点。

```python
import numpy as np

F1 = 100.0        # N   源内部激励（固定不变）
mS = 20.0         # kg  源质量
kA = 2e5          # N/m 界面弹簧（源侧）
w  = 200.0        # rad/s 分析频率

Zsrc = kA/(1j*w) + 1j*w*mS    # 从界面往源看进去的等效阻抗（弹簧+质量）
v_free = F1/(1j*w*mS)         # 自由速度：拿掉接收端，界面弹簧不出力
F_bl = v_free * Zsrc          # 阻断力：自由速度 × 源等效阻抗（正文公式的代入）
print(f"|Zsrc| = {abs(Zsrc):.0f} N*s/m, v_free = {abs(v_free)*1000:.2f} mm/s")
print(f"阻断力 = {abs(F_bl):.1f} N")

# 同一个源接到三个阻抗不同的接收端：接触力 = F_bl · ZR/(Zsrc+ZR)
for name, ZR in [("柔软 k=2e4", 2e4/(1j*w)),
                 ("质量 20 kg", 1j*w*20.0),
                 ("刚硬 k=2e7", 2e7/(1j*w))]:
    Fc = F_bl * ZR/(Zsrc + ZR)
    print(f"{name:12s}: 接触力 = {abs(Fc):6.1f} N   阻断力 = {abs(F_bl):.1f} N")
```

实测输出（numpy 2.x）：

```text
|Zsrc| = 3000 N*s/m, v_free = 25.00 mm/s
阻断力 = 75.0 N
柔软 k=2e4 : 接触力 =    2.6 N   阻断力 = 75.0 N
质量 20 kg  : 接触力 =   42.9 N   阻断力 = 75.0 N
刚硬 k=2e7 : 接触力 =   77.3 N   阻断力 = 75.0 N
```

三行输出把全文逻辑浓缩成了一张表：接收端从柔软变刚硬，同一个源传出的接触力从 2.6 N 升到 77 N，变了近 30 倍；而阻断力始终是 75 N——这就是“与装配无关”的字面证据。代码里的关键两行正是文中的公式：自由速度取“拿掉接收端”的情形，阻断力按换算关系（自由速度 × 源等效阻抗）求得，两者一旦拿到，配任何接收端的接触力都只是一次串联分压。还可以注意到刚硬接收端那一行：接收端阻抗远大于源时接触力趋近阻断力（接收端越“端得住”，接触力越接近源的极限输出），而柔软接收端上接触力被大幅分压——文章开头“刚性台上 120 N、车身里 40 N”的现象，就是这个分压关系的真实版本。

这套工作流在 Simcenter Testlab 里有完整的对应：想预测虚拟装配的系统表现，用 Virtual Prototype Assembly 创建源/接收端/悬置组件库并做 FBS 拼装；在位阻断力估计的矩阵求逆在 Transfer Path Analysis 相关功能中完成；体积加速度（声学源强 Q）的估计属于 ASQ 工具集；轮心/重心的虚拟点变换是 VPT 功能。文中案例的完整工程实施可参考 公开技术资料文章《Obtaining Invariant Loads: Practical Examples》（KB000073710）。

## 一句话记住

接触力随搭档变、阻断力/自由速度/体积加速度不随搭档变：先定连接界面、再判强弱耦合，弱耦合直接测（刚性台测阻断力、柔软吊测自由速度）、强耦合 in-situ TPA 反演；接口往源划分离彻底、往接收端划精度高，权衡完写进载荷谱。
