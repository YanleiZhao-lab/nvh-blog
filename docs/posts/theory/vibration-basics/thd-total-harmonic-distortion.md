# 总谐波失真 THD：一句话里的失真全貌

> 给一个系统输入单频正弦，理想情况下输出应该还是同一频率的正弦——只是幅值与相位有所改变。实际系统输出里往往混进了输入中并不存在的 2 倍、3 倍、4 倍频成分，这就是谐波失真。总谐波失真（Total Harmonic Distortion, THD）把全部谐波能量与基频能量之比压缩成一个数字，随频率逐点画出，就能回答"这套系统在哪些频段会把试验做得走样"。本文以 Simcenter Testing Knowledge Base 的 THD 专题为底本：从 RMS 与正交性出发分步推导 THD 定义式，澄清 THD 与 THD+N 的口径差异，给出振动台系统的典型量级（功放 0.01、裸台 2%、带试件可超 50%）与五类失真来源，解释 THD 高的频段为什么难控，最后给出 Simcenter Testlab 的在线与离线测量入口。

## 一、THD 是什么：输出像不像输入，一个数字说了算

**总谐波失真（Total Harmonic Distortion, THD）**是一个随频率变化的函数，用来量化"系统输出复制输入的能力"：THD 越低，输出中的噪声与失真越少。它的测量方法很直接——向系统输入单一频率的正弦信号，测量输出；输出中除了与输入同频的成分外，还可能出现输入频率的整数倍成分（**谐波，Harmonics**）。例如输入 100 Hz 正弦，输出里可能出现 200、300、400 Hz。

闭环振动控制试验正是这样一个系统。SCADAS 输出的驱动电压经功率放大器（**功放，Amplifier**）驱动振动台（**Shaker**），台面经试验夹具（**Test Fixture**）带动试件，控制加速度计装在台面或试件上反馈实际振动。链条上每个环节都可能产生谐波：

![正弦振动控制系统的组成：SCADAS 输出经功放驱动振动台，夹具与试件在台面上，控制加速度计反馈](/images/thd-total-harmonic-distortion/fig1.png)
*（图源：Simcenter Testing Knowledge Base）*

上图是正弦振动控制系统的组成：信号发生与闭环控制、功放、振动台、夹具、试件、控制加速度计各为一环。每一环的 THD 低，整条链路的 THD 才低；而**THD 低的系统更容易控制**——正弦试验中 THD 随频率逐点不同，有的频段好控、有的频段难控，根源就在这里。

谐波失真的直观图景：

![谐波失真：输入单频正弦，输出中出现输入中没有的谐波成分](/images/thd-total-harmonic-distortion/fig2.png)
*（图源：Simcenter Testing Knowledge Base）*

上图中输入是干净的单频正弦，输出频谱里除基频外冒出了一串等间距的谱线——基频的整数倍。这些谱线在输入中完全不存在，是系统自己"制造"出来的。

::: info 核心概念
- **谐波失真（Harmonic Distortion）**：系统输出中出现输入中不存在的、输入频率整数倍频率成分的现象
- **基频（Fundamental Frequency）**：与输入正弦同频的输出成分，记作 $f_0$
- **THD（Total Harmonic Distortion）**：全部谐波能量与基频能量之比的平方根，取值 0 到 1（或 0 到 100%）
- **THD+N**：把谐波之间的噪声也计入分子的一种口径，N 即 Noise
:::
## 二、THD 定义式：从 RMS 与正交性分步推出来

Knowledge Base 给出的定义：**THD 等于输出信号中与输入正弦无关的能量，除以输出信号的总能量（或基频能量）**。这个"能量"用 **RMS（Root Mean Square，均方根）**度量。公式不是凭空来的，从大学物理的三个基本事实推起。

### 第一步：正弦的 RMS 等于峰值除以根号 2

RMS 的定义是对信号平方取时间平均再开根号。对幅值 $A$、周期 $T$ 的正弦 $x(t) = A\sin(2\pi f_0 t)$：

$$x_{\mathrm{rms}} = \sqrt{\frac{1}{T}\int_0^T A^2 \sin^2(2\pi f_0 t)\, dt}$$

利用半角公式 $\sin^2\theta = (1-\cos 2\theta)/2$，余弦项在整周期上积分为零，剩下 $\frac{1}{T}\cdot\frac{A^2 T}{2} = \frac{A^2}{2}$，开根号：

$$x_{\mathrm{rms}} = \frac{A}{\sqrt{2}} \approx 0.707\,A$$

物理意义：RMS 正比于信号的功率（能量流），1 g 峰值正弦的 RMS 是 0.707 g——这也是热效应与疲劳损伤关心的量。

### 第二步：谐波叠加时能量直接相加

设输出是基频与若干谐波的叠加：

$$y(t) = \sum_{k=1}^{\infty} A_k \sin(2\pi k f_0 t + \varphi_k)$$

计算 $y^2$ 的周期平均时，交叉项形如 $A_j A_k \sin(j\cdot)\sin(k\cdot)$，$j \ne k$ 时利用积化和差化为两个余弦之差，在整周期上积分恒为零——这就是三角函数的**正交性（Orthogonality）**。于是总均方值等于各分量均方值之和：

$$y_{\mathrm{rms}}^2 = \sum_{k=1}^{\infty} \frac{A_k^2}{2}$$

物理意义：不同频率成分之间不交换能量，各自独立贡献功率；相位 $\varphi_k$ 对能量毫无影响——这也是 THD 只看幅值谱就能算的原因。

### 第三步：非基频能量与基频能量之比

把 $k \ge 2$ 的谐波能量归到分子，基频留在分母，各开根号即比值：

$$\mathrm{THD}(f_0) = \frac{\sqrt{\dfrac{1}{2}\sum_{k=2}^{\infty} A_k^2}}{\sqrt{\dfrac{A_1^2}{2}}} = \frac{\sqrt{A_2^2 + A_3^2 + A_4^2 + \cdots}}{A_1}$$

公共因子 $1/\sqrt{2}$ 在分子分母间约掉，THD 最终等于**全部谐波幅值的方和根与基频幅值之比**。取值范围 0 到 1：接近 0 表示输出频谱与输入几乎一样干净；接近 1 表示输出的频率内容大部分不在输入频率上。工程上更常用百分比，100% 对应 1。

数字手感：基频 1 g 峰值，2/3/4 次谐波分别 0.20/0.10/0.05 g 峰值，则

$$\mathrm{THD} = \sqrt{0.20^2 + 0.10^2 + 0.05^2} = \sqrt{0.0525} \approx 0.229 = 22.9\%$$

### 扫频测量与谱域实现

THD 通常在一个频率范围（例如 20 到 2000 Hz）上逐点计算：输入正弦扫过整个范围，每个频率记录一个 THD 值。数字谱测量中，"能量"通过对某频带或主谐波附近求 RMS 得到。测完连成曲线：

![某系统的 THD 随频率变化曲线](/images/thd-total-harmonic-distortion/fig3.png)
*（图源：Simcenter Testing Knowledge Base）*

上图中 THD 不是一条水平线：某些频段失真大、某些频段干净。做正弦试验时遇到的"这段频率死活控不平"，先看 THD 曲线——十有八九在难控频段 THD 正冲着峰值。

### THD 与 THD+N：口径差异

实践中的 THD 计算存在不同口径，对比数据前必须先对齐：

| 口径 | 分子包含 | 典型用途 | 特点 |
| --- | --- | --- | --- |
| **仅前 5 次谐波** | $k=2\ldots6$ 的谐波线 | 音频功放规格书 | 高次谐波被忽略，数值偏小 |
| **仅前 10 次谐波** | $k=2\ldots11$ 的谐波线 | 电声器件 | 覆盖更宽，数值略大 |
| **THD+N** | 谐波 + 谐波之间的全部噪声 | 振动控制系统 | 最严格，宽带失真全计入 |

振动控制语境下常用 THD+N 式的口径：把输出总 RMS 平方减去基频 RMS 平方再开根号作为分子，因为夹具碰撞、摩擦这类宽带失真与谐波同样危害控制。两种口径的差值本身就是信息——THD+N 明显大于 THD 时，说明失真主体不是谐波而是宽带噪声。

::: warning 工程注意
对比两份 THD 数据前先核对三件事：谐波取到第几次、是否含噪声（THD 还是 THD+N）、分母是基频还是总能量。口径不同，同一系统的 THD 能差出数倍。
:::
## 三、振动台系统的 THD 量级与失真来源

### 量级：从功放到整机差三个数量级

Knowledge Base 给出的典型数字，按链条逐级叠加：

| 环节 | 典型 THD | 说明 |
| --- | --- | --- |
| **功率放大器** | 0.01 量级（1% 以下） | 电子环节接近线性，规格书常给 0.01 以下 |
| **功放 + 振动台（无试件）** | 低于 2%，个别尖峰约 10% | 机械环节引入失真 |
| **功放 + 振动台 + 夹具 + 试件** | 可超 50% | 局部频段显著抬高 |

![振动台带试件（金色曲线）的 THD 高于裸台（蓝色曲线）](/images/thd-total-harmonic-distortion/fig4.png)
*（图源：Simcenter Testing Knowledge Base）*

上图两条曲线对比同一振动台：蓝色是功放加裸台的 THD，大部分频段低于 2%、少数尖峰约 10%；金色是加上夹具与试件后的整机 THD，多个频段显著抬升。测量口径：输入取 SCADAS 输出 DAC 电压（V），输出取控制加速度计振动（g），系统传递量为 g/V。

机械系统的 THD 天然高于电子系统——这不是缺陷，而是机理不同：功放的失真来自晶体管非线性，可以做得很小；振动台的失真来自机械运动学，几乎无法根除。

### 失真从哪里来：五类物理来源

明明只输入了一个受控频率，谐波从哪来？Knowledge Base 列出的来源：

1. **导向与轴承摩擦**：振动台动圈导向机构、轴承内的摩擦使运动不再纯净正弦；
2. **动圈共振**（Armature Resonance）：动圈的弯曲共振产生主激励平面之外的运动——垂直激励激起横向摆动；
3. **动圈不直**：动圈略有弓弯时，直线运动附加出垂直于激励方向的力矩；
4. **夹具/试件局部共振**：高频局部共振使试件两侧能量不均，经台面反馈回控制回路；
5. **偏心安装**：试件质心不在台面中心正上方时，激振力对质心产生附加力矩——传递路径分析里源-路径思维同样适用于此。

其中偏心一项最容易被忽视：两个看似都能做的安装方案，偏心的那个 THD 全频段偏高，因为偏心力矩激励出横向模态，横向响应再耦合回轴向控制通道。

另一个常见来源是**过载削波**：信号超出量程被削顶，正弦被切成近似方波，奇次谐波铺满全带宽——机理与量级分析见[信号过载与削波畸变](../signal-processing/overload-clipping-distortion.html)一文：1 V 峰值正弦配 0.16 V 量程时基波被低估 79.7%、奇次谐波 THD 达 39.9%。

### Python 演示：同一输入，两套系统的 THD

```python
import numpy as np

# 两个系统同一 1 g 峰值正弦输入, 对比输出 THD
fs, N = 8192, 8192
t = np.arange(N) / fs
f0 = 100.0
x_in = np.sin(2*np.pi*f0*t)              # 输入: 1 g 峰值纯正弦

y_A = 1.0 * x_in                         # 系统 A: 功放级, 近似线性
y_B = (1.0 * x_in + 0.20*np.sin(2*np.pi*2*f0*t)   # 系统 B: 台+夹具+试件
                  + 0.10*np.sin(2*np.pi*3*f0*t)   # 输出带 2/3/4 次谐波
                  + 0.05*np.sin(2*np.pi*4*f0*t))

def thd(y):                              # 基频外全部能量 / 基频能量
    Y = np.abs(np.fft.rfft(y)) / (N/2)
    f = np.fft.rfftfreq(N, 1/fs)
    k1 = np.argmin(np.abs(f - f0))
    rest = np.sum(Y**2) - Y[k1]**2
    return (rest / Y[k1]**2) ** 0.5

print("输入  THD = %.4f" % thd(x_in))
print("系统A THD = %.4f  (功放级)" % thd(y_A))
print("系统B THD = %.3f   (台+夹具+试件)" % thd(y_B))
```

运行结果：输入与系统 A 的 THD 都是 0.0000（纯数字信号无失真），系统 B 为 0.229（22.9%）——与第二节手算的方和根 0.2291 完全一致。频域实现正是第二节的定义式：基频谱线能量留在分母，其余谱线能量全部进分子（THD+N 口径）。

## 四、THD 与系统 FRF：一个管失真、一个管增益

评估一套动态系统，THD 之外还要看**频响函数（FRF, Frequency Response Function）**。振动控制系统的 FRF 单位是 g/V：1 V 驱动电压换来多少 g 振动响应。控制理论里它叫**系统增益（System Gain）**——闭环控制靠它预测"要达到目标振动量级，驱动电压该给多少"。

THD 与 FRF 通常反相：

![振动控制系统的 THD（蓝色，左轴）与 FRF（绿色，右轴，g/V）叠加：增益高处 THD 低](/images/thd-total-harmonic-distortion/fig5.png)
*（图源：Simcenter Testing Knowledge Base）*

上图把同一系统的 THD 与 FRF 叠画：**系统增益高的频段 THD 低**——基频响应幅度大，谐波被"淹没"在高幅值输出里；反过来，**THD 高的频段增益低**——振动响应本身小，谐波占比就显眼。物理上这是一体两面：低增益频段往往对应结构反共振或隔离区，此时残余的摩擦、偏心力矩产生的谐波在输出中占比升高。

### THD 高为什么难控

闭环控制只盯着一个频率：驱动电压按控制谱目标调节幅值。谐波失真意味着试件上出现了**不受控频率的振动**——控制回路对它们既不设目标也不调输出，振动量级以不可预测的方式叠加在试件上。后果有两层：

- 控制谱显示"达标"，试件实际承受的宽带振动超标——试验严酷度失真；
- 谐波能量混入控制加速度计的测量，反馈回路被污染，控制参数怎么调都震荡。

遇到难控系统时的排查路径：先画 THD 曲线确认哪些频段失真高，再对照失真来源清单——消掉一个夹具共振、把偏心试件重新对中，往往比调控制参数有效得多。定期测 THD 还能评估功放与振动台是否工作正常，是设备健康监测的廉价手段。

## 六、小结

THD 把"输出像不像输入"压缩成一条随频率变化的曲线，判读直接给数字：

- **功放级** THD 在 0.01 量级为正常；**裸台**低于 2%、尖峰约 10%；**带试件整机**局部频段可超 50%——高失真频段大概率难控；
- 定义式 THD 等于全部谐波幅值的方和根与基频幅值之比，由 RMS 定义与三角正交性两步推出，相位不参与、幅值谱即可算；
- 口径先行：谐波取几次、是否含噪声（THD 还是 THD+N）、分母是什么，三件事对齐再比较数值；
- THD 与 FRF 反相：低增益频段失真占比高；治理顺序是先消物理来源（夹具共振、偏心、摩擦），再调控制参数；
- Testlab 里在线勾选、离线用 Offline Sine Data Reduction，THD 曲线是难控频段诊断与设备健康监测的第一手证据。
