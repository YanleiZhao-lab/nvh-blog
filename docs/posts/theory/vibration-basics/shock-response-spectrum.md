# 冲击响应谱 SRS：以单自由度振子序列量化冲击严酷度

> 火工品解锁、变速箱换挡冲击、电池包跌落、路面坑洞——这些瞬态事件的时域波形形态各异，仅用峰值加速度一两个数字难以客观比较其严酷程度。冲击响应谱（Shock Response Spectrum，SRS）的标准做法是：将冲击施加到一组不同固有频率的单自由度振子上，记录每个振子的最大响应，连成一条随频率变化的包络曲线。它不是频谱，而是"破坏势"的频率分布——哪个频段的设备会被该冲击损坏，从谱值即可直接判断。

## 一、为什么峰值加速度不够用

整车与零部件试验中常见这样的问题：跌落台给出 500 g / 1 ms 的半正弦（half-sine）脉冲，实车路面坑洞测得 80 g / 20 ms，哪个环境更严酷？按峰值判断是前者，但 1 ms 脉冲的能量集中在高频，无法激起一个 100 Hz 支架的共振；20 ms 的 80 g 脉冲却能把低阶模态激励到大振幅振荡。

问题的物理本质：冲击对结构的破坏不取决于输入峰值本身，而取决于**冲击能量与结构固有频率的匹配程度**。结构只在自己的共振频带内对激励产生显著响应——脉宽过短的脉冲，对低频结构等效于一次速度突变；脉宽接近结构半周期时，脉冲前半段与后半段做功同向叠加，响应被共振放大；固有频率远高于脉冲频谱上限的振子则基本跟随基座运动，响应趋近输入峰值。

SRS 把这套逻辑标准化：用一组线性单自由度（Single Degree of Freedom，SDOF）振子作为标准参考系统，横轴是振子固有频率，纵轴是振子的最大响应加速度。读取 SRS 时无需再凭经验估计——所关心组件的固有频率落在谱的哪个位置，该处谱值就是它将承受的等效冲击。

![多自由度系统模型：基座上安装一排不同固有频率的单自由度振子，各自输出最大响应构成 SRS](/images/shock-response-spectrum/mdof-model.png)

*（图源：Simcenter Testing Knowledge Base）*

::: info 核心概念
- **SRS（冲击响应谱）**：一组同阻尼、不同固有频率的线性单自由度振子对同一基座冲击输入的最大响应，随固有频率画出的曲线
- **基座激励（Base Excitation）**：冲击从安装基座传入，振子被动响应，这是大多数运输/火工冲击的传入方式
- **品质因子 Q**：$Q = 1/(2\zeta)$，即共振放大倍数；SRS 惯例取 Q=10（阻尼比 5%）
- **Maximax 谱**：每个振子取绝对值最大的响应（不分正负），工程上最常用的 SRS 类型
:::

## 二、从运动方程到谱值：SRS 的计算方法

### 相对坐标下的基座激励方程

设振子质量块绝对位移为 $y(t)$（m），基座绝对位移为 $x(t)$（m），弹簧与阻尼器只感受两者之差。定义相对位移 $z(t) = y(t) - x(t)$，牛顿定律 $m\ddot{y} + c\dot{z} + kz = 0$ 展开为：

$$\ddot{z} + 2\zeta\omega_n\dot{z} + \omega_n^2 z = -\ddot{x}(t)$$

其中 $\omega_n = \sqrt{k/m}$ 是无阻尼固有频率（rad/s），$\zeta = c/(2\sqrt{mk})$ 是阻尼比（无量纲）。该方程的物理意义明确：**质量块感知到的激励是基座加速度取负号**，而响应量用相对位移表示——相对位移乘以 $\omega_n^2$ 正比于弹簧力，正是疲劳与碰撞损伤的驱动量。

### 卷积积分：响应的解析解

零初始条件下，方程的解是输入与单位脉冲响应的卷积：

$$z(t) = \frac{-1}{\omega_d}\int_0^t \ddot{x}(\tau)\, e^{-\zeta\omega_n (t-\tau)} \sin\left[\omega_d (t-\tau)\right] d\tau$$

其中 $\omega_d = \omega_n\sqrt{1-\zeta^2}$ 是阻尼固有频率（rad/s）。被积函数中的衰减正弦反映了振子对历史激励的有限记忆：冲击结束后，振子响应按 $e^{-\zeta\omega_n t}$ 的速率衰减。

工程上最关心的是质量块的**绝对加速度** $\ddot{y}(t)$（单位与输入一致，工程上常用 g）。将原方程改写为 $m\ddot{y} = -c\dot{z} - kz$，得到：

$$\ddot{y}(t) = -2\zeta\omega_n \dot{z}(t) - \omega_n^2 z(t)$$

对每个固有频率完成时域响应计算后，取绝对值的最大值 $S(f_n) = \max_t |\ddot{y}(t; f_n)|$，在 1/6 倍频程的频率序列上逐点计算，连成曲线即 maximax SRS。频域实现更直接——基座激励下绝对加速度对基座加速度的传递函数：

$$H(\omega) = \frac{\omega_n^2 + 2j\zeta\omega_n\omega}{\omega_n^2 - \omega^2 + 2j\zeta\omega_n\omega}$$

输入谱乘 $H$ 再逆变换回时域取峰值，与卷积结果一致（下文的 Python 演示即采用此方法）。

### 三段渐近行为：谱形的判读依据

推导整条曲线不必逐点计算，三个极限特性即可确定谱形的主体特征：

**低频端（软振子，$f_n \ll 1/T_0$）**：脉冲对软振子等效于速度突变。速度增量 $\Delta v = \int \ddot{x}\, dt$ （m/s）固定后，振子响应峰值加速度 $S \approx 2\pi f_n \Delta v$，谱线随频率线性上升（log-log 图上 +6 dB/倍频程斜率）。半正弦脉冲 $\Delta v = 2aT_0/\pi$，代入得 $S \approx 4 f_n a T_0$——低频段斜率只由速度增量决定，与脉冲形状无关。

**平台段（$f_n \sim 1/(2T_0)$ 附近）**：振子半周期与脉宽同量级，脉冲前半段加速、后半段继续做同向功，响应共振放大。半正弦脉冲理论放大系数约 1.65 倍（Q=10 时），谱在此处到达峰值。

**高频端（硬振子，$f_n \gg 1/T_0$）**：振子相对运动趋于零，质量块近似随基座平动，$\ddot{y} \to \ddot{x}$，谱值渐近于输入峰值 $a$。

![倍频程滤波器组：SRS 计算中振子固有频率按分数倍频程分布，相邻振子响应拼接成谱](/images/shock-response-spectrum/octave-filter-bank.png)

*（图源：Simcenter Testing Knowledge Base）*

::: warning 工程注意
低频段谱值对**记录长度**高度敏感。振子周期长、衰减慢（Q=10 时自由衰减需几十个周期才可忽略），如果采集记录在响应尚未衰减完时截止，FFT 法会在记录尾部截断残余振荡，低频谱值严重失真。经验法则：记录时长至少取最低分析频率对应周期的 10 倍以上，让每个振子的残余响应自然衰减到峰值以下。
:::

## 三、三种谱类型与参数选择

SRS 按取峰方式分三种。同一冲击、同一组振子，只是"取哪个最大值"的规则不同：

![SRS 三种类型：正最大谱、负最大谱与 Maximax 谱的关系](/images/shock-response-spectrum/srs-three-types.png)

*（图源：Simcenter Testing Knowledge Base）*

| 谱类型 | 取值规则 | 特点 | 适用场景 |
| --- | --- | --- | --- |
| **正最大谱（Max Positive）** | 每个振子取最大正向响应 | 波形不对称时与负谱差异大 | 关心单向过冲（如弹性吸合限位） |
| **负最大谱（Max Negative）** | 每个振子取最大负向响应 | 同上，方向相反 | 同上，与正谱对照判不对称性 |
| **Maximax 谱** | 取正负响应绝对值最大者 | 两条谱的包络，最保守 | 通用默认，规范几乎都指定它 |

maximax 是包络，永远不低于正/负谱，作为设计输入最保守，所以 MIL-STD-810、ECSS 等规范与 Simcenter Testlab 默认输出都用它。log-log 格式的 maximax 谱是行业通用呈报格式——低频斜率、膝点（knee frequency）、平台高度三个特征量可直接读出。

| 参数 | 惯例值 | 含义与影响 |
| --- | --- | --- |
| **Q 值** | 10（$\zeta$=5%） | 共振放大倍数；Q 越大谱峰越尖，规范间对比必须同 Q |
| **频率间隔** | 1/6 倍频程 | 谱线密度；1/3 偏粗、1/12 计算量大，1/6 是平衡点 |
| **频率范围** | 覆盖组件主要模态 | 上限不超过 fs/10，下限受记录时长限制 |
| **分析起点** | 低于最低模态一个倍频程 | 保证低频上升段完整可见 |

![Simcenter Testlab 中 SRS 分析参数设置界面：谱类型、倍频程数、Q 值与频率范围](/images/shock-response-spectrum/srs-params.png)

*（图源：Simcenter Testing Knowledge Base）*

::: tip 选择原则
- 对比两条 SRS 曲线，**先核对 Q 值和频率间隔是否一致**——Q=10 对 Q=50 的比较没有意义
- 转台/跌落类低频冲击关注 10–500 Hz，火工冲击关注 100 Hz–10 kHz，先明确被测设备的模态频带再定分析带宽
- 需要从 SRS 反推时域波形做台架复现时，用小波综合（wavelet synthesis），Simcenter Testlab 的 SRS Synthesis 提供现成流程
:::

## 四、Python 演示：计算一条半正弦脉冲的 SRS

### 演示 1：三个振子的响应差异

```python
import numpy as np

# 半正弦冲击：峰值 50 g、脉宽 10 ms，速度增量 dv = 2aT0/pi（单位 g·s）
fs = 50000.0
T0, a = 0.01, 50.0
t = np.arange(0, 0.5, 1/fs)                     # 记录 0.5 s，让低频响应衰减完
x = np.where(t <= T0, a*np.sin(np.pi*t/T0), 0.0)
zeta = 0.05                                     # Q = 10

# 频域法：基座激励下绝对加速度传递函数 H，逆变换回时域取峰值
N = len(t)
omega = 2*np.pi*np.fft.rfftfreq(N, 1/fs)
X = np.fft.rfft(x)

print(f"输入: 半正弦峰值 {a:g} g、脉宽 {T0*1e3:g} ms")
for fn in (40.0, 80.0, 400.0):
    wn = 2*np.pi*fn
    H = (wn**2 + 2j*zeta*wn*omega) / (wn**2 - omega**2 + 2j*zeta*wn*omega)
    yacc = np.fft.irfft(X*H, N)                 # 质量块绝对加速度响应
    print(f"fn={fn:5.0f} Hz 振子 -> 响应峰值 {np.abs(yacc).max():5.1f} g")
```

同样的 50 g 输入：40 Hz 振子响应 64 g（仍在放大区）、80 Hz 振子响应 82.6 g（正落在膝点附近，放大 1.65 倍）、400 Hz 振子为 53.6 g（已进入跟随区，接近输入峰值）。一条 SRS 曲线就是把这三个数对连续的频率序列各计算一遍。

### 演示 2：完整 maximax 谱与三段渐近行为

```python
import numpy as np

fs = 50000.0
T0, a = 0.01, 50.0
t = np.arange(0, 0.5, 1/fs)
x = np.where(t <= T0, a*np.sin(np.pi*t/T0), 0.0)
freqs = 20.0 * (2.0**(1/6))**np.arange(0, 40)   # 1/6 倍频程频率序列，20 Hz 起
zeta = 0.05

N, omega = len(t), 2*np.pi*np.fft.rfftfreq(len(t), 1/fs)
X = np.fft.rfft(x)
srs = np.array([
    np.abs(np.fft.irfft(
        X * ((2*np.pi*fn)**2 + 2j*zeta*2*np.pi*fn*omega) /
            ((2*np.pi*fn)**2 - omega**2 + 2j*zeta*2*np.pi*fn*omega), N
    )).max()
    for fn in freqs
])

peak_i = srs.argmax()
print(f"谱峰值 {srs[peak_i]:.1f} g @ {freqs[peak_i]:.0f} Hz (输入的 {srs[peak_i]/a:.2f} 倍)")
print(f"平台值(高频端) {srs[-1]:.1f} g，输入峰值 {a:g} g，两者应接近")
print(f"膝点经验值 f_knee = 1/(2*T0) = {1/(2*T0):.0f} Hz")
print(f"低频段 20 Hz 谱值 {srs[0]:.1f} g，按 S~4*fn*a*T0 估算 {4*freqs[0]*a*T0:.1f} g")
```

输出中重点核对三个数值：谱峰 82.6 g 出现在 80 Hz，落在膝点经验值 $1/(2T_0)=$ 50 Hz 之上的放大区（数值法含阻尼相位滞后，峰位略高于无阻尼估计）；高频平台 50.1 g 与输入峰值 50 g 几乎重合，验证"硬振子跟随基座"的渐近行为；低频端 20 Hz 谱值 37.5 g 与渐近式 $S \approx 4 f_n a T_0$ 的估计值 40 g 同量级——记录更长、分析频率更低时，两条曲线将进一步接近。

## 五、SRS 与 FFT 频谱的区别

初学者常见的混淆点：SRS 横轴也是频率，它与功率谱有何区别？区别在于纵轴的量纲与物理含义——FFT 谱回答"输入中包含哪些频率成分"，SRS 回答"这些成分能把一个共振在该处的结构激励到多高"。前者是激励的描述，后者是响应的包络。

| 对比维度 | FFT 频谱 / PSD | SRS |
| --- | --- | --- |
| **物理含义** | 信号本身的频率分解 | 一组 SDOF 振子的峰值响应包络 |
| **纵轴量纲** | g 或 g²/Hz（PSD） | g（响应加速度） |
| **阻尼参与** | 无阻尼概念 | 显式依赖 Q 值 |
| **相位信息** | 保留（复谱） | 完全丢弃，只留峰值 |
| **对波形敏感性** | 不同脉冲波形谱不同 | 不同波形可以有相近的 SRS（损伤等效） |
| **典型用途** | 频率成分诊断、声学分析 | 冲击严酷度评级、试验规范制定 |

最后一行是 SRS 存在的理由：试验规范要的是"等效损伤"，不是"相同波形"。跌落台、振动台、谐振板产生的波形与实车实测完全不同，但只要 SRS 包络住实测谱，对设备就是保守的损伤等效——这正是 SRS 作为损伤等效评估方法的工程价值。

::: warning 工程注意
SRS 隐含线性假设。大冲击下结构进入非线性（连接件松动、材料屈服、减振器触底）时，振子模型失效，SRS 会高估或低估真实响应。跌落缓冲设计的评估尤其要注意：缓冲材料压缩硬化后传递的波形已经改变，对应的 SRS 也会随之变化，不能将线性阶段标定的谱长期沿用。
:::

## 六、小结

拿到一条 SRS，按顺序检查四件事：低频上升段斜率是否合理（速度增量守恒的对数斜率）、膝点频率在哪（约 $1/(2T_0)$，决定哪些模态被放大）、平台高度多少（渐近输入峰值）、有没有异常尖峰（很可能是记录过短或传感器过载的伪影）。制定试验规范时，用实测 SRS 加安全余量做包络，Q 统一取 10、1/6 倍频程、maximax 类型，规范间才有可比性。波形成分不是判据，损伤等效才是——这是 SRS 区别于直接波形比较方法的本质特征。
