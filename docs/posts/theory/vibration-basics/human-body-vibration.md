# 人体振动测量：ISO 2631 与全身/手臂暴露评价

> 同一台工程机械，驾驶员座垫上测得 0.3 m/s²，方向盘上却测到 3 m/s²——相差十倍的两个数，谁更危险？答案是：看哪个部位在承受。人体对振动不是一台均匀的仪器：躯干最怕 4~8 Hz 的低频摇晃，手掌手臂却对 8~16 Hz 甚至更高频的振动最敏感。人体振动测量因此不是"把加速度计贴上去读数"，而是一套"用人体敏感度给振动重新记账"的方法——计权滤波、轴合成、时间折算、VDV 补账，一步都不能省。这篇把 ISO 2631（全身）与 ISO 5349（手臂）两条评价链从物理直觉讲到公式与标准限值，配 numpy 实算：为什么冲击型振动的 RMS 会"漏记"七成伤害。

一台 40 吨矿用卡车在碎石路面上跑一个班次，驾驶座椅面上放个座垫式加速度计，读出加权加速度 0.31 m/s²，低于 0.5 的行动限值，看似合格；可同一路线上的手电钻操作工，握柄处测到 3.2 m/s²——手传振动的日常暴露限值以 m/s² 的 A(8) 计，3 m/s² 上下已经是必须管控的水平。同一个人体，座垫 0.3 判"还好"、握柄 3 判"超标"，两件事并不矛盾：**人体不同部位有不同的"痛觉频段"，不同组织有不同的"记账规则"**。把物理加速度翻译成生理负担，中间隔着一整套滤波器、系数与积分公式——这就是 ISO 2631 与 ISO 5349 两个标准族要干的事。

## 一、为什么不能直接拿 m/s² 读数评价人体

打个贯穿全文的比方：人体振动评价像**用体重秤给行李称重收托运费**。航空公司不会拿物理重量直接收钱——经济舱 23 kg、公务舱 32 kg，同一件行李在不同"接收端"（舱位等级）对应不同费用规则；超规的额外一公斤罚款翻着倍涨，不是线性加价。人体振动同理：同样 1 m/s² 的物理加速度，落在 5 Hz 上，坐姿躯干"照单全收"（计权因子接近 1）；挪到 50 Hz，躯干几乎无感（计权因子 0.25），但握在掌心的手却还在全权重记账（手臂计权在 50 Hz 处反而超过 1）。评价人体振动，第一步永远是问三个问题：**作用在哪个部位？沿哪个方向？什么频率成分？**——部位定标准（2631 还是 5349），方向定系数（横向 1.4 倍于纵向），频率定滤波（计权曲线）。三者都没问就报一个 m/s²，等于不问舱位直接报行李物理重量，账就没法算。

这背后是几十年生物动力学实验的结论：把振动台上的受试者从 1 Hz 扫到 100 Hz，测量主观舒适度与生理响应，人体俨然一个带通滤波器组。坐姿人体躯干在 4~8 Hz 有明确的共振峰——内脏与躯干作为一个质量-弹簧系统在这一频段被最有效激发，胸腹脏器相对脊柱的相对运动最大；1 Hz 以下换运动病（晕车）说了算；到了 16 Hz 以上，躯干整体跟不动了，振动集中在接触点附近——座椅传给臀部的不多，方向盘传给手掌的却很足。手部最敏感频段在 8~16 Hz，正对应凿岩机、角磨机、链锯这类工具的主要能量集中区，血管与神经的损伤（振动白指病）恰恰在几十到几百 Hz 的频段积累。

::: info 核心概念
- <strong>全身振动（Whole-Body Vibration, WBV）</strong>：通过座面、脚底或靠背传入人体的振动，评价健康与舒适，标准为 ISO 2631-1
- <strong>手传振动/手臂振动（Hand-Arm Vibration, HAV）</strong>：经手掌传入手臂系统的振动，评价血管、神经与肌肉骨骼损伤风险，标准为 ISO 5349-1
- <strong>频率计权（Frequency Weighting）</strong>：按人体部位敏感度对加速度频谱逐频加权的滤波曲线；全身坐姿垂直方向用 Wk，手臂用 Wh
- <strong>轴振动系数（Axis Factor / k 因子）</strong>：横向振动比纵向更伤人的经验系数，坐姿横向 k=1.4、纵向 k=1.0
- <strong>A(8)（Daily Exposure）</strong>：把一天内各段暴露按能量等效折算成"8 小时等效暴露值"，欧洲指令 2002/44/EC 的法定量
:::

## 二、全身振动：Wk 计权与四条评价链

### 2.1 频率计权：人体敏感度写成滤波器

ISO 2631-1 对每一种"部位 × 方向 × 姿势"组合给一条计权曲线。最常用的一条是 **Wk**——坐姿或立姿沿脊柱方向（z 轴）的健康评价计权：4~8 Hz 处权重接近 1，频率往两边跑权重迅速衰减，1 Hz 只剩 0.48 左右，80 Hz 只剩 0.13。手臂系统用的是另一条曲线 **Wh**：8 Hz 以下权重极小，8~16 Hz 爬升到 1 附近，并在 16~63 Hz 保持一个略高于 1 的宽平台，直到 1 kHz 才衰减到底——掌心对高频振动的"包容度"远大于躯干。

![全身 Wk 与手臂 Wh 计权曲线：两条带通形状对应人体两个部位的敏感频段](/images/human-body-vibration/fig1-weighting-curves.png)

*（图源：网络官方公开资料）*

工程上计权在频域逐谱线完成：对每个频率分量乘计权因子后按能量求和。这个公式回答的问题是：**一条计权曲线怎么压缩成一个数？**其中 $w(f_i)$ 对应物理里该频率处人体的相对敏感度（无量纲，峰值约 1），$a_i$ 是该谱线的加速度幅值——加权后按平方求和，因为人体对宽带振动的响应近似能量叠加：

$$
a_w = \sqrt{\sum_i \left( w(f_i)\, a_i \right)^2}
$$

其中 $a_w$ 是计权加速度（weighted acceleration，m/s²）。它在时域有等价形式：让原始信号通过一个传递函数等于 $w(f)$ 的滤波器，再取 RMS——现代采集系统（如 SCADAS 前端）走的都是这条路，计权作为实时滤波器挂在通道上，原始信号照存。

### 2.2 轴合成与总振动值

这个公式回答的问题是：**三个方向的计权加速度怎么合成单一评价值？**其中 $k_x$、$k_y$、$k_z$ 对应物理里"横向比纵向更伤人"的经验放大率——坐姿下人体左右摇晃（x、y 向）比垂直颠簸（z 向）更不舒适，故横向取 1.4、纵向取 1.0，靠背方向用座面坐标系（绕 y 轴旋转 −90°）后同样取 1.4：

$$
a_v = \sqrt{ (k_x a_{wx})^2 + (k_y a_{wy})^2 + (k_z a_{wz})^2 }
$$

$a_v$ 就是标准里的**总振动值（Total Value）**，舒适评价（ISO 2631-1 第 7 章）与部分整车厂座椅验收都用它。

![轴振动系数 k：同样 0.40 m/s² 的计权加速度，横向计入 0.56、纵向计入 0.40](/images/human-body-vibration/fig4-axis-factors.png)

*（图源：网络官方公开资料）*

::: warning 工程注意
健康评价（2631-1 第 6 章）与舒适评价（第 7 章）对多轴的用法不同：健康评价通常只取 12 个坐标（座面 6 + 靠背 3 + 脚 3）中计权值最大的一个方向做判定，舒适评价才做总振动值合成。拿到一份报告先看它引用的是哪一章——同一个三向数据，两种算法给出的是两个不同用途的数。
:::

### 2.3 时间折算：A(8) 的平方根律

振动对人体的伤害按能量积累，而暴露时间正是能量里的积分变量。这个公式回答的问题是：**一天里几段不同时长的暴露，怎么折成一个可以与限值比较的数？**其中 $T_0 = 8\ \mathrm{h}$ 是参考时长，$a_{wi}$ 与 $T_i$ 是第 $i$ 段暴露的计权加速度与时长——各段按"能量 × 时长"记账后统一折算到 8 小时口径：

$$
A(8) = \sqrt{ \frac{1}{T_0} \sum_i a_{wi}^2 \, T_i } = a_w \sqrt{ \frac{T}{T_0} } \quad (\text{单一工况时})
$$

单一工况的化简式暴露了一条重要的物理律：**平方根律**。暴露时长减半，A(8) 只降 $\sqrt{2} \approx 1.41$ 倍——"让司机每天少开一半时间"的管控效果，远不如直觉里的一半。反过来，峰值工况短时间也有大贡献：aw = 0.6 m/s² 的恶劣路段哪怕每天只跑 1 小时，折算 A(8) 已是 $0.6\times\sqrt{8} \approx 1.70$ m/s²，一步越过 0.8 的暴露限值。

![同一波形下暴露时长与 A(8) 的关系：时长减半，A(8) 只降 1.41 倍](/images/human-body-vibration/fig3-a8-duration.png)

*（图源：网络官方公开资料）*

### 2.4 VDV：给冲击型振动补账

RMS 类指标（$a_w$、A(8)）按幅值平方记账，偶发的强冲击在能量里只占很小的份额——但人体对冲击的耐受恰恰不是能量问题。ISO 2631-1 为冲击型振动准备了**四次方剂量（VDV, Vibration Dose Value）**：

这个公式回答的问题是：**冲击很稀但很强的振动，按什么口径记伤害账？**其中四次方对应物理里"痛感与损伤随幅值超线性增长"的实验规律——峰值翻倍，贡献翻十六倍，冲击被大幅放大记账；单位是 m/s^1.75（四次方开四次根的量纲遗产）：

$$
\mathrm{VDV} = \left( \int_0^T a_w^4(t)\, \mathrm{d}t \right)^{1/4} \quad [\mathrm{m/s}^{1.75}]
$$

VDV 是累积量、不随时间平均，一天一记、单位是 m/s^1.75；英国等标准体系以 VDV 8 小时参考值 9.1 m/s^1.75 作为健康风险分界。

![同一基础波形叠加 12 次强冲击：aw 只升 1.5 倍，VDV 升 6 倍](/images/human-body-vibration/fig2-vdv-vs-rms.png)

*（图源：网络官方公开资料）*

当测得的波峰因数（crest factor，峰值与加权 RMS 之比）不超过 9 时，$a_w$ 与 A(8) 足够；超过 9 就必须补 VDV（或用 MTVV 短时窗峰值）佐证——这是标准写明的判据，也是"数据没超限、司机却腰疼"这类现场纠纷最常见的解释：RMS 把冲击摊薄了。

## 三、手传振动：ISO 5349 的评价链

手臂系统尺寸小、频段高，评价链与全身振动同构但参数全换：计权曲线换 Wh（8~16 Hz 敏感峰，高频平台延伸到 1 kHz）；测量位置换"握持点三向"（手柄坐标系：握轴 z、水平垂直 x/y）；轴合成对三向等权（不再乘 1.4）；频率范围通常 8~1250 Hz。

日暴露量 $A(8)$ 沿用平方根律：

$$
A(8) = a_{hv} \sqrt{ \frac{T}{T_0} }, \qquad a_{hv} = \sqrt{ a_{hwx}^2 + a_{hwy}^2 + a_{hwz}^2 }
$$

其中 $a_{hv}$ 是三向计权加速度的方和根值（frequency-weighted acceleration sum）。欧洲指令 2002/44/EC 给手臂振动的暴露限值为 A(8) = 5 m/s²、行动限值为 2.5 m/s²——注意这两个数比全身振动的 0.8/0.5 大一个数量级，正是"部位不同、账本不同"的直接体现。

振动白指病（Vibration-Induced White Finger, VWF）的剂量-响应关系是 ISO 5349-1 附录里的经验公式：暴露人群 10% 出现白指的年数 $\approx 31.8\,(C / A(8))^2 \times 11.8$ 年（$C$ 为常数），只作群体风险参考，个体差异极大，不用于个案判定。

## 四、numpy 实算：RMS 怎么"漏记"冲击的账

一段 120 秒的仿真数据：基础是 0.25 m/s² 的 5 Hz 正弦加噪声（计权已视作完成），叠加 12 次 4 m/s²、50 ms 宽的 20 Hz 冲击——模拟"平整路面上偶尔过坎"的座垫信号。分别按 RMS 与 VDV 记账，再看标准允许的近似式 eVDV = 1.4·aw 偏差多少：

```python
import numpy as np

fs, T = 1000, 120.0                    # 采样率 / 时长
t = np.arange(0, T, 1/fs)
rng = np.random.default_rng(7)
base = 0.25*np.sin(2*np.pi*5*t) + 0.05*rng.standard_normal(len(t))

x = base.copy()
for i0 in np.linspace(0.05, T-0.2, 12).astype(int):   # 12 次过坎
    seg = int(0.05*fs)
    x[i0:i0+seg] += 4.0*np.sin(2*np.pi*20*t[i0:i0+seg]) * np.hanning(seg*2)[:seg]

aw  = np.sqrt(np.mean(x**2))           # 计权 RMS（m/s2）
vdv = (np.sum(x**4)/fs / T) ** 0.25    # 四次方剂量（m/s^1.75）
cf  = np.max(np.abs(x)) / aw           # 波峰因数
A8  = aw*np.sqrt(8*3600/T/3600)        # 折 8 小时口径
print(f"aw = {aw:.3f} m/s2,  A(8) = {A8:.3f} m/s2   <- 均低于 0.5 行动限值")
print(f"VDV(120s) = {vdv:.2f} m/s^1.75,  crest = {cf:.1f}  <- 远超 9，必须看 VDV")
print(f"折 8h VDV ≈ {vdv*(8*3600/T)**0.25:.1f}  <- 越过 9.1 风险分界")
print(f"近似式 eVDV = 1.4*aw = {1.4*aw:.2f}  比真值低 {1-1.4*aw/vdv:.0%}")
```

运行输出：

```text
aw = 0.275 m/s2,  A(8) = 0.275 m/s2   <- 均低于 0.5 行动限值
VDV(120s) = 1.26 m/s^1.75,  crest = 40.0  <- 远超 9，必须看 VDV
折 8h VDV ≈ 3.2  <- 越过 9.1 风险分界
eVDV = 1.4*aw = 0.39  比真值低 69%
```

三笔账摆在一起就是全文的核心结论：同一份数据，RMS 口径说"完全合格"（0.28 对 0.5），VDV 口径按 8 小时外推已经触及风险区，而标准允许的近似式在这个波峰因数下直接失效——**冲击型振动不看 VDV，等于没测**。（注：8 小时外推假定全天工况与这 120 秒同分布，实际报告应对每段工况分别积分。）

## 五、标准限值与法规一页对表

| 口径 | 量 | 行动限值 | 暴露限值 | 出处 |
| --- | --- | --- | --- | --- |
| 全身振动 | A(8)（Wk 计权） | 0.5 m/s² | 0.8 m/s² | EU 2002/44/EC |
| 全身振动（冲击） | VDV（8h 参考） | 9.1 m/s^1.75 为风险分界 | — | ISO 2631-1 / BS 6841 |
| 手臂振动 | A(8)（Wh 计权） | 2.5 m/s² | 5 m/s² | EU 2002/44/EC |
| 舒适评价 | 总振动值 av | < 0.315 m/s² "无不舒适" | > 2 m/s² "极其不舒适" | ISO 2631-1 第 7 章 |

ISO 2631-1 本身是"评价方法"标准，不设强制限值；各国把 A(8) 的限值写进职业健康法规（欧洲 2002/44/EC 指令最具影响力，中国 GBZ 系列职业卫生标准同构）。做出口设备或海外项目验收时，先核对合同引用的是哪套限值。

## 六、测量的工程要点：座垫加速度计与测点布置

**全身振动**的标准测位：座面（座垫式三向加速度计，SEAT 计权传感器，人坐下后垫在臀部与椅面之间）、靠背、脚部地板，必要时加靠背测点；测量期间记录实际坐姿与暴露时段。座垫加速度计内藏的半刚性盘使传感器贴合人体-椅面界面，三向分别对准座面坐标系。**手传振动**的测位在握持点：小型三向加速度计用适配夹具贴到手柄上，坐标系以手握持方向定义，测量时保持典型握力与姿势——握力改变手掌阻抗，直接改写传入手臂的振动量。

::: tip 实操清单
- 座垫传感器装好后让驾驶员真实坐上去再采数，空椅面数据不能代表人群暴露
- 每段工况（直线/过坎/装卸）分别记录时段与 A(8)，不要只报全天一个均值
- 波峰因数超 9 必补 VDV；越野、矿区、农林机械几乎必然超
- 手臂测量报告必须写明握力、姿势与测点坐标定义，否则 A(8) 不可复核
:::

## 七、Testlab 落点

在 Simcenter Testlab 里，人体振动计权是一条挂在通道上的滤波器：Channel Setup 里为座垫/手柄通道选择对应计权函数（Wk、Wc、Wd、Wh 等），采集时实时输出计权时域信号；离线在 Time Data Processing 或 Neo Process Designer 中对吞吐数据补算计权通道，再按工况段做 RMS/VDV/A(8) 统计。对既有三向原始数据，事后补计权永远可行——原始信号照存是前提。

## 一句话记住

人体振动评价是给物理加速度"换账本"：部位定标准（全身 Wk / 手臂 Wh）、方向定系数（横向 1.4）、频率定滤波、时长按平方根折 A(8)、冲击超波峰因数 9 必补 VDV——五步走完，m/s² 才变成可以跟限值比、跟健康挂钩的数。
