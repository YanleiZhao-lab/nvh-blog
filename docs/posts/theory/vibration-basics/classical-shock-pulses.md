# 经典冲击脉冲：半正弦/梯形/锯齿的规范谱

> 同样是"50 g 冲击"，为什么有的试验件安然无恙，有的却焊点开裂？规范里的经典冲击脉冲就像菜谱里的"标准辣度"——半正弦、梯形、锯齿各自对应一种固定的"辣法"，不追求复现真实撞击波形，而是用可复现的标准形状把冲击环境规定清楚。本文从"为什么标准脉冲长这样"讲起：形状决定频率含量（半正弦偏低频、矩形偏宽带）、脉宽决定低频强弱、前后脉冲（pre/post pulses）替振动台"腾出行程"，最后给出 Simcenter Testlab Shock Control 的完整操作链。

## 一、为什么需要"标准形状"的冲击

运输跌落、火工品爆炸、铁路挂钩碰撞——真实世界的冲击波形千奇百怪：有一次快速的正负振荡，有长时间的复杂衰减，也有带多次回弹的脉冲串。实验室要复现某个冲击环境，最直接的想法是把现场实测波形原样回放。Simcenter Testlab 里的 TWR（Time Waveform Replication，时间波形复现）就是干这件事的：它能多轴、多点地在试验件上复现实测波形，是技术上最"保真"的实验室冲击手段。

但保真是要付代价的。做 TWR 需要：拿到那件具体产品在真实环境中的实测数据（很多项目根本测不到）、占用样机做迭代学习、多通道设备与试验准备时间。对一个"给电路板验证抗冲击能力"的例行试验来说，这套成本常常不划算。

于是标准脉冲登场：MIL-STD 810H 等规范直接定义了若干**经典冲击脉冲（Classical Shock Pulses）**——半正弦（half-sine）、三角形/锯齿（terminal peak sawtooth）、矩形（rectangle/梯形 trapezoid）等。它们有预先规定的形状、幅值、方向和持续时间，任何实验室、任何振动台都能以高度一致的方式复现。换句话说，经典脉冲牺牲了"像真实波形"，换来了**可重复、可对比、可写进规范**。

## 二、形状决定频率含量：同幅同宽，谱却不同

三个脉冲：半正弦、后峰锯齿、矩形，幅值都是 10 g、脉宽都是 11 ms。它们激起的频率成分一样吗？

不一样，而且差别巨大。直觉的钥匙是**波形里的"突变"**：波形的角落越尖锐，高频成分越多。半正弦从零平滑爬升、再平滑回落到零，没有尖锐角落，所以它的能量集中在低频段；后峰锯齿有一个急速回落沿，高频含量显著高于半正弦；矩形脉冲干脆处处是直角（起点阶跃、终点阶跃），在三个形状里高频含量最高、带宽最宽。

![三种经典脉冲对比：后峰锯齿（品红）、半正弦（蓝）、矩形（绿），左为时域波形、右为冲击响应谱，均为 10 g / 11 ms](/images/classical-shock-pulses/fig3.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

官方文章对这组对比的结论是：半正弦"低频段量级高于高频段"（得益于平滑过渡）；后峰锯齿"尖峰过渡在高频段产生比半正弦更高的量级"；矩形"因多个非常尖锐的过渡而拥有最高的整体频率含量"。用 numpy 对这三种 10 g / 11 ms 脉冲做冲击响应谱（SRS，Q=10）计算，可以量化验证：

```python
import numpy as np

fs = 20000.0
t = np.arange(0, 0.5, 1/fs)

def half_sine(t, a=10.0, T=0.011):
    x = np.zeros_like(t); m = t < T
    x[m] = a*np.sin(np.pi*t[m]/T); return x

def rectangle(t, a=10.0, T=0.011):
    x = np.zeros_like(t); m = t < T
    x[m] = a; return x

def sawtooth(t, a=10.0, T=0.011):        # 后峰锯齿：线性上升、瞬时跌落
    x = np.zeros_like(t); m = t < T
    x[m] = a*t[m]/T; return x

def srs(x, fs, Q=10):                    # 频域法 SRS（绝对加速度，maximax）
    zeta = 1/(2*Q)
    fn = 5*2**(np.arange(0, 157)/24)     # 5~2000 Hz，1/24 倍频程
    X = np.fft.rfft(x); f = np.fft.rfftfreq(len(x), 1/fs); w = 2*np.pi*f
    out = np.zeros_like(fn)
    for i, f0 in enumerate(fn):
        wn = 2*np.pi*f0
        H = 1 + w**2/(wn**2 - w**2 + 2j*zeta*wn*w)   # 基座激励绝对加速度传递
        out[i] = np.max(np.abs(np.fft.irfft(X*H, len(x))))
    return fn, out

for name, sig in [("半正弦", half_sine(t)), ("后峰锯齿", sawtooth(t)), ("矩形", rectangle(t))]:
    fn, v = srs(sig, fs)
    lv = lambda fr: np.interp(np.log(fr), np.log(fn), np.log(v))
    print(f"{name}   50Hz:{np.exp(lv(50)):5.1f}  500Hz:{np.exp(lv(500)):5.1f}  2000Hz:{np.exp(lv(2000)):5.1f} g")
```

运行结果（实测输出）：

```text
半正弦   50Hz: 15.3  500Hz: 10.5  2000Hz: 10.0 g
后峰锯齿  50Hz: 17.8  500Hz: 18.2  2000Hz: 18.3 g
矩形     50Hz: 18.6  500Hz: 18.6  2000Hz: 18.4 g
```

数字背后的物理：半正弦在 500 Hz 以上谱值快速跌向输入峰值附近再走低，锯齿与矩形却几乎全频段保持在 18 g 上下的平台。这组数字直接指导选型——关心低频大变形（结构机架、安装支架）选半正弦；关心高频脆性失效（电子组件焊点、继电器触点）选后峰锯齿；规范若要求全频段覆盖，可能需要组合两种脉冲各打一遍。

代价也随之而来：矩形脉冲虽然频谱最宽，但它的阶跃沿对振动台是严苛考验——高频要求大推力、突变要求大电流，同时位移需求也大。工程上矩形脉冲用得比半正弦、后峰锯齿少得多。

## 三、脉宽决定低频强弱：11 ms 与 22 ms 的差别

形状之外，脉宽是第二个旋钮。固定形状（半正弦）与幅值（10 g），把脉宽从 10 ms 加长到 22 ms，SRS 会怎么变？

官方文章的对比（10 / 18 / 22 ms，同形状同幅值）结论：**主脉冲越长，低频段的谱值越高**。这有清晰的物理图像：脉宽越长，加速度对时间的积分（速度增量 $\Delta V$）越大，而低频结构对冲击的响应本质上由速度增量驱动——就像推秋千，同一力但推的作用时间越长，秋千摆得越高。

上节代码改一行参数即可复现（SRS@20 Hz）：

```text
脉宽 10 ms: SRS@20Hz =  7.5 g
脉宽 18 ms: SRS@20Hz = 12.4 g
脉宽 22 ms: SRS@20Hz = 14.2 g
```

低频谱值接近翻倍。反过来读这张表：如果规范写"50 g / 0.5 ms"这种极窄脉冲，它对低于 1 kHz 左右的结构几乎没考核意义——窄脉冲的全部能量都在高频。

![SRS 对比：10 ms（绿）、18 ms（黑）、22 ms（红）经典脉冲，同形状同幅值，脉宽越长低频越高](/images/classical-shock-pulses/fig6.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

顺带一个量级感受：10 g / 11 ms 半正弦的速度增量 $\Delta V = \frac{2}{\pi} \cdot aT \approx 0.69$ m/s（数值积分验证 0.687 m/s）。速度增量与脉宽成正比——这就是"长脉冲低频强"的定量注脚。

## 四、前后脉冲：替振动台"腾行程"

到这里都是"纸面脉冲"。真上振动台跑，立刻撞上现实：**振动台的位移和速度是有限资源**。一个 10 g / 11 ms 的半正弦，台面要先获得约 0.69 m/s 的速度再回到静止，若从零速硬起跳，台面在脉冲期间的行程就吃掉了大半额定行程，而且脉冲结束后的残余速度会把台面狠狠甩向行程端点。

单看主脉冲的账：速度增量 $\Delta V$ 之后再匀减速停下来，需要的位移约 $d \approx \Delta V^2/(2a) \approx 0.69^2/20 \approx 2.4$ cm 量级（以 10 g 减速计），远超中小型电动台 ±12.5~25 mm 的行程。这就是为什么规范里的"裸脉冲"在振动台上根本跑不了。

解法是在主脉冲**前后各加一段反向的补偿脉冲**：前置脉冲（pre pulse）先把台面压到行程下端、并积攒一个尽量负的速度；主脉冲到来时台面从"低位、负速"出发，全速向上穿越行程中点；后置脉冲（post pulse）再把台面柔和地拉回零位、零速。前后脉冲要满足三件事：起止条件全零（加速度、速度、位移都回到零）、补偿足够让主脉冲在台面能力内实施、以及**尽量少引入额外损伤**——所以补偿脉冲的幅值被限制在主脉冲的约 22% 以内，形状平缓，避免自己变成一次额外冲击。

![同一个半正弦主脉冲带前后脉冲的加速度、速度、位移三通道视图](/images/classical-shock-pulses/fig4.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

官方对比了同一半正弦脉冲"不带/带"前后脉冲的伪速度冲击响应谱（PVSS）：带前后脉冲后，所需位移与速度显著降低，而**最大加速度考核量保持不变**——即损伤等效性没被破坏，只在"台面资源账"上做了优化。PVSS 三段读法：左渐近线定最大位移、中平台定最大速度、右渐近线定最大加速度。

前后脉冲的排布还有四种方案可选：单边（适合行程不对称的液压台）、双边（充分利用双极性行程）、优化式（前后不对称，高峰值配小行程）、最小化（总位移需求最小）。控制软件会根据台的行程/速度/加速度限制自动推荐。

![四种前后脉冲方案示意：单边、双边、优化式、最小化](/images/classical-shock-pulses/fig5.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

::: info 核心概念
- **经典冲击脉冲（Classical Shock Pulse）**：规范预定义形状/幅值/脉宽的标准脉冲（半正弦、锯齿、矩形等），用于替代实测波形的可复现实验室冲击
- **前后脉冲（Pre/Post Pulses）**：主脉冲前后的补偿脉冲，使起止加速度/速度/位移全零，并优化振动台行程与速度资源
- **伪速度冲击响应谱（PVSS，Pseudo Velocity SRS）**：以伪速度（相对位移 × 固有角频率）表示的 SRS，左/中/右三段分别对应位移、速度、加速度限制
- **速度增量（ΔV）**：加速度脉冲的时间积分，决定低频响应强度：$\Delta V = \int a\,dt$
:::

## 五、在 Simcenter Testlab 里定义一个冲击试验

Simcenter Testlab 的振动控制冲击试验流程（Shock Control 工作簿）：

1. **启动与建项**：开始菜单 → Simcenter Testlab → Shock Control，新建工程
2. **配置振动台**：Tools → Options → Shaker 标签 → Configure…，在向导里定义台的推力/行程/速度限制
3. **通道设置（Channel Setup）**：激活控制通道（ChannelGroupID 设为 Control），设传感器方向、测量量（加速度）、ICP/Charge 输入模式与灵敏度
4. **Shock Setup 定义参考脉冲**：选择经典脉冲类型，打开 Profile Editor——左侧定义主脉冲（类型、幅值、脉宽、极性），中间定义前后脉冲，右侧设报警/中止限
5. **检查台面资源**：关闭 Profile Editor 后软件立即给出试验中的最大加速度、速度、位移、推力预估值，与台规格逐一对比，指示灯全绿再往下走
6. **Self Check**：低量级宽带激励估计传递函数，外推到试验量级并推荐各通道量程（Range/Threshold → Apply suggested）
7. **Shock Control 运行**：Arm → Ready → Start，运行中可分级回退、中断/继续、开关环

其中第 5 步是前后脉冲设计的"验收关"：预估值一旦亮黄/红灯，回到 Profile Editor 调整前后脉冲方案（单边/双边/优化/最小化）或降低脉宽，再查资源账。

## 六、小结

经典冲击脉冲用"标准形状"换取冲击试验的可复现性与规范可比性。选脉冲的三步逻辑：先看失效模式（低频大变形 → 半正弦；高频脆性 → 后峰锯齿）→ 再定脉宽（越长低频越强，$\Delta V$ 与脉宽成正比）→ 最后在振动台上用前后脉冲解决位移/速度资源问题，同时保持最大加速度考核量不变。纸面上的规范值与台面上的资源账，是冲击试验设计的两端，缺一不可。

## 一句话记住

形状定带宽（半正弦低频、锯齿高频、矩形最宽）、脉宽定低频（$\Delta V$ 与时长成正比）、前后脉冲定台面可行性——经典冲击 = 规范形状 × 台面资源账。
