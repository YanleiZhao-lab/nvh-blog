# 阻断力 vs 接触力：TPA 两种力的本质区别

> 同一台电机，装在台架夹具上测出一组"力"，换到整车车身上这组力竟然全变了数——不是测量漂了，是"力"这个字本来就指两种不同的东西。接触力（contact force）是源与接收端"合演"出来的界面力，换了搭档就换数值；阻断力（blocked force）则是源"一个人的戏"，不管接谁都不变，所以又叫不变载荷（invariant load）。本文用公开技术资料 KB000044211 的四质量解析模型把两种力的来龙去脉算给读者看：接触力只能配着原接收端用、阻断力必须连同源一起用，配错了对象，预测曲线与真值南辕北辙；最后给出换接收端预测、台架先行开发这两类场景的选型判据与 Testlab 锚点。

电机供应商在台架上测完某型号电机的界面力，交付给主机厂一份"载荷谱"。主机厂把它直接加到整车车身模型上预测内饰噪声，结果与实车实测差出一截——双方都坚持自己的测量与模型没有错，问题出在哪？答案几乎总是同一个：供应商交付的是**接触力**，它在台架夹具上测得时已经把"电机+夹具"这对组合的动力特性揉了进去；而接触力换了接收端就不再成立，把它套到车身这个"新搭档"上，等于拿着为上一任搭档量身定制的剧本让新演员照演。要交付"换谁都好用"的载荷，得测的是**阻断力**——只属于源本身、与接收端无关的不变载荷。这两种力在 TPA（Transfer Path Analysis，传递路径分析）里都会被叫作"工况力"，单位都是牛顿，谱图看起来也差不多，但物理含义与使用规则截然不同。本文把这条最容易踩的界线讲清楚。

在动公式之前，先把一笔"对账"的数字摆上桌。把这台"电机"简化成四个质量、三根弹簧的链式模型（第 5 节给出全部参数与可复跑的代码）：质量 9/4/5/7 kg 依次相连，界面弹簧刚度 10⁷ N/m，源端施加 1 N 扫频力。在"电机+台架"的完整组合上算界面弹簧的内力——即接触力——在 1～300 Hz 分析频段内几乎恒定为 0.48 N；把界面右侧换成刚性墙、只留源单独计算——即阻断力——恰好是 1.00 N。同一个源、同一份激励，两个数都对：0.48 N 是界面真实传过去的力，它只需要推动界面以后的 12 kg 质量，恰占系统总质量 25 kg 的 12/25；1.00 N 是源"想"输出而被刚性墙全额接住的力。两者之比 25/12 不是巧合，而是惯性账单的分配——接触力天生记着搭档的份额，阻断力只记源自己的账，这笔账第 5 节可以逐行复跑核对。

为什么"力"这种听起来属于源的东西，会跟着搭档变？直觉上容易把力想成源的属性——如同水温属于水；但界面力更像"成交价"：由买卖双方共同决定，同一件货换个买家，价格就变。源在界面上输出的是"想要的运动趋势"，究竟能换成多大的力，取决于对面"接不接得住"：接收端越刚硬（阻抗越大），同样的运动趋势换成的力越大；接收端越柔软，力越小。这不是测量误差，而是界面力的定义使然——它本来就是两个子系统在界面上"谈判"成交的结果。所以"哪个数才对"本身就问错了问题，正确的问题是：这个数是在哪对组合上测的？以后要配哪对组合用？把这两个问题回答清楚之前，任何一份"载荷谱"都不敢直接往别的模型上套。

本文按"现象—定义—测法—对账—落地"的顺序展开：先在 TPA 框架里看清两种力的定义如何分岔（第一章），再分别讲接触力与阻断力的获取方法与使用铁律（第二、三章），用换接收端的对照实验与 numpy 复现把两条铁律算成误差数字（第四、五章），最后给出 Testlab 落地位置与选型判据（第六章）。

## 一、为什么同一次测量会得到两种"力"

这一章先把舞台搭好：TPA 怎么切分源与接收端、"力"为什么必须从间接量反推、两条反推路线如何分岔出两种力。第一个出场的算式是 TPA 的基本账法。这个公式回答的问题是：已知界面上的工况力和接收端的传递函数，目标点的响应有多大、哪条路径贡献最多？其中 $F_o$ 对应物理里界面上实际作用的工况力（下标 o 为 operational），FRF 对应接收端从界面到目标点的频响函数——"力×路径"的乘积就是每条路径的贡献份额，也是后文一切反推的出发点。

先从 TPA 的框架说起。一个"源—接收端"系统（source–receiver）：源（S）是产生振动的部件——电机、发动机、水泵；接收端（R）是承受振动并把它变成噪声或振动的部分——车身、支架、壳体。TPA 的基本算式是"力乘传递函数"：界面上的工况力 $F_o$（下标 o 为 operational，工况）乘以接收端从界面到目标点的频响函数（FRF），得到目标点的响应。哪个界面的"力×路径"乘积大，哪条传递路径就是主犯——这套逻辑在[传递路径分析 TPA 入门](transfer-path-analysis-intro.html)一文里已展开，此处不赘述。

麻烦在"力"从哪来。CAE 仿真里常用单位载荷代替真实载荷，因为真实工况力很难直接测量——在悬置内部、在螺栓连接面上串一个力传感器，多数产品根本做不到。工程上的办法是从加速度这类容易测的间接量"反推"力。而反推的时候，在哪个子系统上定义这个力、用哪套 FRF 做逆运算，就分出了两条路：

- 一条路把力定义在**接收端的输入端**，用接收端自身的 FRF 做矩阵求逆，得到的是**接触力** $F_c$——界面处真实传递的力；
- 另一条路把力定义在**源的输出端**，反问"源在界面处想输出多大的力"，得到的是**阻断力** $F_b$——源独自具有的特性，与接收端是否存在无关。

::: info 核心概念
- <strong>接触力（Contact Force，$F_c$）</strong>：源-接收端界面上实际传递的力，是源与接收端动力交互的共同产物；定义在接收端输入位置，随接收端改变而改变
- <strong>阻断力（Blocked Force，$F_b$）</strong>：源输出端"被刚性阻断时"输出的力，只取决于源自身，又称源的不变载荷（invariant load）；与任何接收端组合都保持不变
- <strong>源/接收端（Source/Receiver）</strong>：TPA 对系统的切分——发出振动的是源，承受并放大振动的是接收端，界面（interface）是两者连接处
- <strong>指示点（Indicator）</strong>：接收端上便于布置传感器的响应测点，不处于界面输入/输出位置，用于间接反推界面力
:::

一个贯穿全文的类比：把源想成一位**歌手**，接收端想成**录音棚**。接触力是"歌手在这个棚里实际录出的效果"——棚的混响、吸声、驻波全都揉进了成品，换个棚就得重录；阻断力则是歌手"清唱水平"本身——不管进哪个棚都带着的那份功底，配上新棚的传递特性（棚的 FRF），就能预测在新棚里的录音效果。注意物理对应关系要严丝合缝：接触力 = 界面处实际发生的力（已含双方动力特性的耦合），阻断力 = 源单独的激励特性（需再乘以任意接收端的路径才能得到响应）。这个"配搭档还是配全体"的规则，正是两种力最核心的使用铁律，下文解析模型会把它算成曲线。

先给出数量级层面的感受，再进入公式。公开技术资料（KB000044211，作者 Peter Schaldenbrand）用一个四质量-弹簧-阻尼解析模型把两种力的行为算得明明白白：质量 9/4/5/7 kg，刚度 4×10⁷/10⁷/5×10⁶ N/m，阻尼 40/20/50 kg/s，源端输入 1000 N 扫频力，观察接收端末端的响应速度。同一套参数下，接触力加在"接收端单独模型"上预测完美、加在"源+接收端组合模型"上预测失效；阻断力恰好相反。分野不在力的大小，而在力"认不认"它所施加的那个模型。

## 二、接触力：界面处实际传递的力

### 2.1 悬置刚度法

最直观的估计方法利用胡克定律：力 = 刚度 × 位移。在悬置（mount）这类"软"连接两侧各贴一个加速度计，工况加速度双重积分得位移，两侧位移相减即悬置的相对变形，再乘以悬置的动刚度曲线 $K$，就得到悬置内部传递的力。

这个公式回答的问题是：已知悬置两端各自的运动，悬置里传递了多大的力？其中 $K$ 对应物理里的悬置复动刚度（随频率变化，通常由供货商给出或专门测得），$x_2 - x_3$ 对应物理里的跨悬置相对位移（源侧与接收端侧位移之差）：

$$F_c = K \, (x_2 - x_3)$$

刚度法的前提是"力只经悬置传递、且悬置两端近似刚性连接于各自结构"。车身悬置、发动机悬置这类软连接场景是它的主场；对螺栓刚性连接，相对位移小到接近积分噪声，刚度法就力不从心了。

*（图源：网络官方公开资料）*

### 2.2 FRF 矩阵求逆法

更通用的路线是矩阵求逆（matrix inversion）：拆掉源，只在接收端上测得界面输入点之间的驱动点 FRF 矩阵 $H_{33}$（A/F 形式，含互易的交叉项），再测工况下这些界面点的加速度 $A_3$，解一个线性方程组反演出界面力。

这个公式回答的问题是：什么样的界面力作用在接收端上，会产生实测到的界面加速度？其中 $H_{33}^{-1}$ 对应物理里接收端界面 FRF 矩阵的逆（单位 F/A），$A_3$ 对应物理里工况下接收端界面点的加速度响应——两者相乘就是把"果"反解回"因"：

$$\{F_{3c}\} = [H_{33}]^{-1} \{A_3\}$$

矩阵求逆的工程要点全在**条件数**上：界面点之间的交叉 FRF 必须测全（多悬置即多输入），常需补充"界面到指示点"的额外 FRF 行来改善方程组的良态性；在接收端模态的反共振区，$H_{33}$ 接近奇异，反演会把测量噪声放大成虚假的力峰。这些坑在[传递路径分析 TPA 入门](transfer-path-analysis-intro.html)的矩阵求逆一节有数值演示（反共振点单 FRF 相除噪声放大近 9 N）。

![矩阵求逆法：接收端单独测界面驱动点 FRF 矩阵 H33，与工况加速度 A3 相除反演出接触力](/images/blocked-vs-contact-forces/fig3.png)

*（图源：网络官方公开资料）*

### 2.3 接触力的使用铁律

接触力在定义上就"住在接收端的输入端"，它已经把源的动力特性吸收在内。因此它的适用边界非常清晰：**只能施加在接收端单独模型上**。上述解析模型给出的对账结果：把接触力施加到接收端（R）单独模型，预测的末端速度与全模型真值严丝合缝（图 1 绿线）；施加到"源+接收端"（SR）组合模型，预测立即跑偏（红线）——因为组合模型里源的动力特性被算了两遍，一遍藏在接触力里，一遍又在结构里。

![接触力对账：施加在接收端(R)单独模型上预测速度与真值吻合（右绿），施加在源-接收端(SR)组合模型上不吻合（中红）](/images/blocked-vs-contact-forces/fig4.png)

*（图源：网络官方公开资料）*

由此直接推出接触力的适用场景与禁区：**场景**——整车厂在自己车身不变的前提下排查"哪个悬置传递的力大"，接触力就是正确工具，它直接回答"界面上实际传了多少力、从哪个位置进来"；**禁区**——接收端一旦改变（换车身、改支架、上新车型），旧接触力全部作废。回看开头的故事：供应商在台架夹具上测的接触力，本质上是"电机×台架"的组合产物，交付给主机厂用于"电机×车身"的组合，必然失真。

## 三、阻断力：源自己的"清唱水平"

### 3.1 从定义到三种测法

阻断力的定义是"把源的输出端连接到无限刚硬的边界时，边界上的反作用力"。想象把电机的输出轴顶死在一堵无限刚性的墙上，电机内部该有多大的力想输出，墙就感受到多大的反作用——这份力只由源的内部激励与自身动力特性决定，墙（接收端）怎么变都与之无关，所以它又叫**不变载荷**。歌手的清唱功底就是这份力：进任何录音棚都不变。

三种获取途径对应三种边界条件：

1. **刚性边界法**：真的把源顶死在刚性夹具上直接测。工程上"无限刚性"造不出来——相关技术文档给了一个轮胎刚性夹具的尝试照片，实物夹具在动态视角下永远有限刚度，测到的只是"源×这个夹具"的接触力近似。
2. **自由边界法**：数学上可证明，把源用软绳悬吊成自由-自由状态（free-free，即"自由加速度/自由速度"状态），测输出端的 FRF 与工况响应，也能反演出阻断力。物理图像：自由状态下源输出端的运动，与刚性阻断状态下源输出端的力，通过源自身的动态特性一一对应。难点同样直白——让一台运转中的发动机悬在半空，工程上近乎做不到。
3. <strong>在位法（in-situ）</strong>：这是工程实践的主流。源与接收端正常装配、正常运行，利用"源输出端到接收端指示点"的 FRF（整机在场、含悬置）结合工况指示点响应做 FRF 反演，把接收端的影响"反着抠掉"，得到源的阻断力。

### 3.2 在位法与矩阵求逆的镜像关系

在位法的数学结构与接触力的矩阵求逆法几乎同构，差别只在两处"在哪里测、拆不拆源"：

| 维度 | 接触力（矩阵求逆） | 阻断力（在位法） |
| --- | --- | --- |
| 力定义位置 | 接收端输入端 | 源输出端 |
| FRF 测量时源的状态 | **拆除源**，只留接收端 | **源在场**，整机装配状态 |
| FRF 路径 | 接收端界面驱动点（含交叉） | 源输出端 → 接收端指示点 |
| 工况数据 | 接收端界面点加速度 | 接收端（或整机）指示点加速度 |
| 结果属性 | 随接收端改变 | 不随接收端改变 |

在位法的独特困难：装配状态下悬置点、螺栓孔的可接近性差，"源输出端"的 FRF 激励与响应测量都比自由状态麻烦得多。Simcenter 生态的对策是用 Q-source 校准体积声源配合互易定理批量获取传递函数，相关展开见[声学量 Q：体积加速度的物理意义](../acoustics-basics/acoustic-quantity-q.html)；对更复杂的装配场景，相关技术文档另有 Obtaining Invariant Loads: Practical Examples 专文。

### 3.3 阻断力的使用铁律

与接触力恰好镜像：阻断力**必须施加在"源+接收端"组合模型上**。因为阻断力只是源的激励特性，预测响应时必须把接收端（以及源到界面的传递）一并放进模型。上述解析模型的对账：阻断力施加到 SR 组合模型，预测速度与真值吻合（图 2 绿线）；施加到接收端 R 单独模型，预测跑偏（红线）。这与接触力的规则正好相反，一句话记：<strong>接触力配"半个系统"（接收端），阻断力配"整个系统"（源+接收端）</strong>。

![阻断力对账：施加在源-接收端(SR)组合模型上预测速度与真值吻合（中绿），施加在接收端(R)单独模型上不吻合（右红）](/images/blocked-vs-contact-forces/fig5.png)

*（图源：网络官方公开资料）*

## 四、换接收端：阻断力的"独门优势"

两种力的真正分水岭在"换接收端"的场景。解析模型在源不变的前提下引入新接收端 T（新质量 8/3 kg、刚度 5×10⁷ N/m、阻尼 20 kg/s）：从旧组合 SR 算出的接触力施加到新组合 ST 上，预测完全失效——接触力是旧车身参与演出的产物，换了车身就换了数值；而从源单独算出的阻断力施加到新组合 ST 上，预测的新末端速度与真值吻合。歌手换棚重录的类比在此回收：清唱功底（阻断力）配上任何新棚的传递特性（新接收端 FRF），都能预测新录音效果；上一间棚里录好的成品（接触力）带不进新棚。

![换新接收端(T)：阻断力施加在新组合(ST)上预测吻合（左蓝/绿），旧接触力施加在新接收端上预测失效（右红）](/images/blocked-vs-contact-forces/fig6.png)

*（图源：网络官方公开资料）*

这就解释了工业界两类高频场景为什么必须用阻断力：

- **供应商交付载荷谱**：电机/油泵/空压机厂商在台架上表征产品振动特性，交付给不同主机厂、不同车身。载荷必须"不变"，否则每换一家就重测。
- **前期虚拟开发**：源（电机、泵、发动机）在台架上先于整车可用，配合 CAE 的整车 FRF 模型，可在样车存在之前预测装配后的振动噪声。公开技术资料中的案例用同一源分别在试验夹具与应用夹具上验证：台架阻断力 + 应用结构 FRF 的预测与实测紧密吻合，而台架接触力 + 应用结构的预测明显跑偏。

公开技术资料中的实验还给出一个值得注意的工程细节：试验台架上用电动激振器给源施加已知激励，从而把"力的真值"掌握在手里——阻断力的预测精度是在这种可控条件下对账出来的。这也提示，阻断力标定试验的价值随"源被复用的次数"增长：同一个源要接三个不同接收端，阻断力一次测量三处受用。

进一步，阻断力是**组件级 TPA（Component TPA）与虚拟样机装配的货币**：源库与接收端库都以阻断力/界面 FRF 为共同语言，任意组合即可拼出虚拟 TPA 模型，不必每次都造物理样机。当组合系统的 FRF 也拿不到时，可用[基于 FRF 的子结构耦合 FBS](../modal-analysis/frf-based-substructuring.html)逐谱线合成，Simcenter Testlab 的 Virtual Prototype Assembly 即为此设计。

## 五、numpy 复现：两种力的对账实验

先说清这段程序要回答什么。这个模型回答的问题是：两种力各自配上"对的模型"时，预测能否精确复现真值？其中全系统 SR 的响应是真值基准，接触力施加在接收端 R 单独模型上、阻断力施加在 SR 组合模型上，逐谱线对账相对误差——判据是误差落在浮点舍入量级（恒等关系成立）还是有限量级（定义用错了对象）。

这套四质量解析模型（m1=9、m2=4、m3=5、m4=7 kg，k12=4×10⁷、k23=10⁷、k34=5×10⁶ N/m，c=40/20/50 kg/s，界面取 m2–m3 之间的弹簧）可以在 40 行内复现，且能把两种力的使用铁律逐条对账。模型约定：源 S 为 m1+m2（含内部弹簧 k12），接收端 R 为 m3+k34+m4，界面是 k23 这根"悬置"：

```python
import numpy as np

m = np.array([9.0, 4.0, 5.0, 7.0])            # 质量 kg
k = np.array([4e7, 1e7, 5e6])                 # 刚度 N/m
c = np.array([40.0, 20.0, 50.0])              # 阻尼 kg/s
f  = np.linspace(1, 300, 600)                 # 频率 Hz
w  = 2*np.pi*f
F1 = np.ones_like(w)                          # 源端 m1 单位扫频力

def chain_Y(masses, springs, dampers):
    """链式质量-弹簧-阻尼系统的导纳矩阵，逐频率求逆"""
    n = len(masses)
    Y = np.zeros((len(w), n, n), complex)
    for i, s in enumerate(w):
        Z = np.diag(1j*s*masses)
        for j, (kj, cj) in enumerate(zip(springs, dampers)):
            zg = kj + 1j*s*cj
            Z[j, j] += zg; Z[j+1, j+1] += zg
            Z[j, j+1] -= zg; Z[j+1, j] -= zg
        Y[i] = np.linalg.inv(Z)
    return Y

Y_SR = chain_Y(m, k, c)                       # 全系统 SR（真值基准）
v4_ref = Y_SR[:, 3, 0] * F1                   # 真值：m1 加力 -> m4 速度

# --- 接触力：界面弹簧 k23 的内力 = k23*(v2 - v3) ---
zg23 = k[1] + 1j*w*c[1]
Fc = zg23 * (Y_SR[:, 1, 0] - Y_SR[:, 2, 0]) * F1
Y_R = chain_Y(m[2:], k[2:], c[2:])            # 接收端 R 单独（m3-k34-m4）
v4_contact = Y_R[:, 1, 0] * Fc                # Fc 只施加在 R 上

# --- 阻断力：源单独（m1-k12-m2），输出端 m2 被刚性阻断 ---
Y_S = chain_Y(m[:2], k[:1], c[:1])            # 源单独、输出端自由
Fb = (Y_S[:, 1, 0] / Y_S[:, 1, 1]) * F1       # 使 v2=0 所需的反力即阻断力
v4_blocked = Y_SR[:, 3, 1] * Fb               # Fb 施加在 SR 组合的界面源侧

def rel_err(pred, ref):
    return np.mean(np.abs(pred - ref) / np.abs(ref))

print("接触力 -> R 单独模型   相对误差: %.1e" % rel_err(v4_contact, v4_ref))
print("阻断力 -> SR 组合模型  相对误差: %.1e" % rel_err(v4_blocked, v4_ref))
```

运行结果（作者本机实跑）：

```
接触力 -> R 单独模型   相对误差: 3.0e-13
阻断力 -> SR 组合模型  相对误差: 1.1e-16
```

两条铁律都是数值意义上的"精确成立"（误差在浮点舍入量级）：接触力只认接收端单独模型，阻断力只认源+接收端组合模型——这不是近似方法的好坏之分，而是两种力的定义决定的恒等关系。`Fb = (Y_S[:,1,0]/Y_S[:,1,1]) * F1` 这一行值得盯一眼：阻断力等于"源输出端自由导纳之比乘输入力"，它只含源自身的矩阵元素，接收端的信息一个都没有——不变载荷的"不变"就写在这个结构里。

第二段代码回答的问题是：换了接收端之后，旧接触力与阻断力各自还能不能预测新组合的响应？其中新接收端 T 换掉了界面以后的全部结构，预测对象是新组合的末端速度——看点是旧接触力的误差从舍入量级跌到百分位量级，而阻断力的误差纹丝不动。

再把第四节"换接收端"的对照实验跑完：保持源与 F1 不变，把接收端换成新系统 T（m3=8 kg、m4=3 kg、连接刚度 5×10⁷ N/m、阻尼 20 kg/s），分别用旧接触力和阻断力预测新组合的末端速度——

```python
# 新接收端 T：m3=8, m4=3, 界面刚度 5e7, 阻尼 20
kT = np.array([4e7, 5e7, 5e7]); cT = np.array([40.0, 20.0, 20.0])
YT_SR = chain_Y(np.array([9.0, 4.0, 8.0, 3.0]), kT, cT)
v6_ref = YT_SR[:, 3, 0] * F1                  # 新组合真值

Y_T = chain_Y(np.array([8.0, 3.0]), kT[2:], cT[2:])   # 新接收端单独
v6_contact = Y_T[:, 1, 0] * Fc                # 旧接触力硬套新接收端
v6_blocked = YT_SR[:, 3, 1] * Fb              # 阻断力配新组合 ST

print("旧接触力 -> 新接收端 T  相对误差: %.1e" % rel_err(v6_contact, v6_ref))
print("阻断力   -> 新组合 ST   相对误差: %.1e" % rel_err(v6_blocked, v6_ref))
```

运行结果（作者本机实跑）：

```
旧接触力 -> 新接收端 T  相对误差: 4.7e-02
阻断力   -> 新组合 ST   相对误差: 1.1e-16
```

分水岭出现了：旧接触力硬套新接收端，全频段平均相对误差 4.7%（个别频段更大），预测失效；阻断力配新组合，依然精确复现。这正是公开技术资料图 17、18 的结论在自家机器上的复现——回看开头的交付纠纷，供应商若交付的是阻断力（配"源+新接收端"的使用说明），主机厂的预测就会像第三行输出一样贴合实测。

## 六、Testlab 落地位置

- **力的估计**：Simcenter Testlab Transfer Path Analysis 工作簿中，工况力反演（矩阵求逆/悬置刚度法）在 Operating Data 阶段选择力估计方法；阻断力在位反演对应 Source Contribution Analysis / Component TPA 相关插件
- **组件库与虚拟装配**：Virtual Prototype Assembly（VPA）把台架测得的源阻断力与新接收端 FRF 组合，直接预测装配响应（详见[虚拟样机装配 VPA](../modal-analysis/virtual-prototype-assembly.html)）
- **子结构合成**：组合系统 FRF 拿不到时，用 FRF Based Substructuring 逐谱线合成（Testlab 中 Tools → Add-ins → FRF Based Substructuring）
- **时域试听**：阻断力驱动的虚拟 TPA 模型可经 Time Domain TPA 回放每条路径的"声音"，见[时域 TPA](../../practice/data-processing/time-domain-tpa.html)

## 七、小结

接触力与阻断力不是两种测法，而是同一个界面处两种物理含义的力：接触力是源-接收端交互的产物，定义在接收端输入端，只能配接收端单独模型用，换接收端即作废，适合"车身不变、排查路径"的整车场景；阻断力是源自身的不变载荷，必须配源+接收端组合模型用，换接收端依然成立，适合"载荷交付、前期虚拟开发、组件库"的场景。测法上，接触力走悬置刚度法或"拆源测 R 的 FRF + 矩阵求逆"；阻断力走刚性边界（难）、自由边界（难）或在位法（主流）。选型只问一句：这个力以后要不要跟新的接收端组合？要，就测阻断力。

## 一句话记住

接触力是"二人转"：源与接收端合演的界面力，只配原接收端、换搭档作废；阻断力是"清唱"：源的不变载荷，必须连同源一起上车，却换任何接收端都不改口——排查现车用接触力，交付载荷与虚拟装配用阻断力。
