# 随机振动控制入门：闭环与均衡

> 同一台振动台、同一个试件、同一份参考谱，不做闭环直接开环推，控制加速度计读回的谱在试件共振处堆成尖峰、在反共振处塌成深谷——台子没坏，功放没坏，是"开环"这个做法本身错了。随机振动试验里，控制器该输出什么波形由试件与夹具的传递特性决定，而这条特性恰恰是试验前不知道、试验中还会漂移的。本文回答随机控制的三个基本问题：为什么必须闭环、控制谱为什么用 PSD 表示、驱动信号如何被"均衡"出来。把振动台系统想象成一套**扩声系统加调音师**：功放推音箱、话筒拾音、调音师按听到的声音调推子——闭环均衡做的事与调音师完全同构。全文给出从参考谱算总均方根值、均衡初值一步到位与闭环迭代收敛的 numpy 演示，并对应 Simcenter Testlab Random Control 的操作位置。

## 一、为什么随机试验不能"开环推"

现场场景：一个新的支架试件上振动台，规范要求 80~350 Hz 平直谱 0.04 g2/Hz。工程师图省事，直接生成一份 PSD 符合要求的随机波形送给功放——不闭环、不反馈。结果控制加速度计读回来的谱完全变了形：180 Hz 附近（试件一阶共振）能量堆积成峰，350 Hz 附近又塌了下去。规范判据 ±3 dB，实测超差近 10 dB，试验无效。


原因不复杂。控制点加速度 $C(f)$ 与驱动电压 $D(f)$ 之间隔着一整条链路：功放增益、动圈机电转换、台面与夹具的动力学、试件反作用。这条链路合起来是一个频率响应 $H(f)$，在共振处放大十余倍、在反共振处几乎断路。开环送"标准波形"，等于假设 $H(f)$ 全频段恒等于 1——现实中不存在这样的系统。

再看一个量级感：试件共振频率 180 Hz、阻尼比 5% 时，品质因数 $Q = 1/(2\zeta) = 10$。同一个 1 V 驱动，在 100 Hz 产生 1.44 g、在 180 Hz 产生 10 g、在 500 Hz 只剩 0.15 g（本文第五节 numpy 复算）。要让控制点谱平直，驱动谱必须**倒着**这条曲线走：180 Hz 处压低 20 dB（放大 10 倍的倒数），350 Hz 处抬升约 9 dB。这份"倒着的驱动谱"正是控制器要算的东西。

::: info 核心概念
- **随机控制（Random Control）**：以参考 PSD 为目标、以控制加速度计实测 PSD 为反馈，逐帧修正驱动信号幅值谱的闭环试验模式
- **参考谱（Reference/Profile PSD）**：规范规定的控制目标，单位 g2/Hz，通常为折线（断点谱）
- **控制通道（Control Channel）**：装在台面或夹具上、其谱被闭环"盯着"的加速度计；其余为监测通道（Monitor）
- **均衡（Equalization）**：按系统传递函数的倒数修正驱动谱，使控制谱贴合参考谱的过程
- **驱动信号（Drive Signal）**：控制器输出给功放的电压时域波形，由驱动谱乘随机相位经 IFFT 合成
:::

## 二、贯穿类比：调音师的耳朵闭环

把系统想成一套扩声系统：功放推音箱（振动台），话筒拾音（控制加速度计），调音师听声音调推子（控制器闭环）。调音师从不问"推子推到多少格"——他只问"话筒里听到的对不对"，不对就反着调。三个细节一一对应：

1. **目标在"听到的"一侧，不在"送出"的一侧**：观众区声压（控制谱）达标才算数，音箱馈入电压（驱动电压）多大无人关心；
2. **房间的频率响应必须被补偿**：会议室某频率轰鸣、某频率发闷（共振放大与反共振衰减），调音师先把推子拉出一条"倒着的"均衡曲线（均衡），之后放任何音乐都平了；
3. **一次调不准，反复微调**：调音师每次只动一点，听、再动（闭环迭代），一次拧到底会来回振荡（过冲、发散）。

随机控制器的全部行为——闭环、均衡、限幅、渐进升量级——都能在这位调音师身上找到原型。后文每一节都会回到这个类比。

## 三、控制目标为什么是 PSD：随机信号的密度语言

随机振动的时域波形本身没有可复现性——它每一秒都不一样，峰值、周期都不可重复。可复现的只有它的**统计属性**：频率成分的功率分布。这就是《[功率谱密度 PSD](../signal-processing/psd-explained.html)》里说清的事实：宽带随机数据的自功率谱幅值随频率分辨率变化，除以分辨率归一化成 PSD 后才能与分辨率无关地比较——所以随机试验规范里写的都是 g2/Hz，控制环里流的也都是 PSD。

![三份相同宽带随机数据的自功率谱：只改频率分辨率，幅值却差数倍——随机数据的谱幅值必须按密度口径比较](/images/random-control-basics/fig58.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

参考谱是断点折线，读懂它要会的第一件事是算**总均方根值 Grms**。这个公式回答的问题是：这条规范谱折算到时域，控制加速度计的 RMS 该读到多少。其中 $W_i$ 是第 i 段的 PSD 幅值（g2/Hz）、$f_i$ 到 $f_{i+1}$ 是该段起止频率——每一段的 PSD 乘带宽得均方值，全段求和开方：

$$
\mathrm{Grms} = \sqrt{\sum_i W_i \,(f_{i+1}-f_i)}
$$


![放大到狭频段看三条曲线：1 Hz 分辨率的谱线密而低、8 Hz 的精而高，但各自围成的面积相同](/images/random-control-basics/fig60.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

代进本文的例子：0.04 g2/Hz、80~350 Hz，Grms 等于 0.04 乘 270 的平方根，即 3.29 g。这个数是整个试验的总能量锚点：升量级表按它折算，试验结束判 RMS 是否达标也按它对表。

![块状显示下的同一组数据：分辨率越粗单根谱线越高、线数越少，总量不变](/images/random-control-basics/fig62.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

斜线段的通式是梯形面积法，原理同功率等于密度乘带宽，试验规范手册均有现成表格。

控制谱这一侧，PSD 用周期图平均估计：几十帧的谱平均把随机估计的方差压到工程可用范围。这也是闭环必须逐帧更新、却不能帧帧大动的统计原因——单帧谱估计本身就有正负 3 dB 量级的随机起伏，把它当真去修正驱动，系统永远在抖。

还要清楚 PSD 只锁定频率成分与 RMS 总级，不锁定时域峰值分布——峭度 3 的高斯驱动与峭度 8 的冲击密集驱动可以有几乎相同的 PSD。路谱复现类试验要补这一维控制，见《[峭度](../signal-processing/kurtosis-signal-statistics.html)》：Testlab Random Control 的 Kurtosis Control 直接填目标峭度（高斯=3，可设 3~12），Sigma Clipping 限制峰值/RMS 比保护功放与试件。

![派对类比：同一壶饮料分给不同数量的杯子，每杯水位随杯数变化、总量不变——谱线与分辨率的关系同理](/images/random-control-basics/fig63.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

## 四、闭环均衡：误差怎么变成驱动修正

闭环每一帧做四件事：估计控制谱、算误差、修正驱动谱、重合成驱动波形。核心是中间两步。

第一步，误差用 dB 表达。这个公式回答的问题是：每个频率上控制谱偏离目标多少。其中 $C_k$ 是第 k 条谱线的控制 PSD 估计、$R_k$ 是参考 PSD——取对数乘 10，正数超差、负数欠差，上下偏差对称：

$$
E_k = 10\,\lg\!\frac{C_k}{R_k}\quad(\mathrm{dB})
$$

第二步，按误差的反方向修正驱动谱。这个公式回答的问题是：驱动谱该乘多大一个因子才能把误差抵消。其中 $\alpha$ 是收敛因子（0 到 1），指数上的 $\alpha/2$ 里的 1/2 来自谱是幅值的平方——控制谱差 6 dB 时驱动**幅值**只需改 3 dB：

$$
D_k \leftarrow D_k \cdot \left(\frac{R_k}{C_k}\right)^{\alpha/2}
$$

$\alpha=1$ 是全修正，一帧到位但极易过冲振荡；$\alpha$ 取一半左右是常用工程值，误差每帧减半、两三帧收敛——调音师每次只动一点的数学形式。再叠一道保险：单帧驱动修正被钳位在正负 2~3 dB 内（限幅），防止共振辨识不准时驱动剧烈跳变损伤试件。收敛因子定脾气，限幅定底线。

**均衡的解析形式**：正式试验前的系统辨识（Testlab 的 System Identification，2206 版之前叫 SelfCheck）用低量级随机信号测功放输出到控制通道的传递函数 $H(f)$（典型单位 g/V），直接算出驱动谱初值。这个公式回答的问题是：不经迭代，驱动谱的解析初值长什么样。其中 $S_D$ 是驱动电压谱密度、$S_R$ 是参考加速度 PSD、$|H|$ 是辨识出的系统幅频特性——**均衡就是把参考谱除以传递函数的平方**，共振处自动深陷、反共振处自动高耸：

$$
S_D(f) = \frac{S_R(f)}{|H(f)|^2}
$$

辨识给出的初值越准，闭环起步误差越小；试验中每帧仍继续小幅修正，吸收辨识之后系统随温度、试件松弛产生的缓慢漂移。均衡与闭环的分工：**均衡给骨架，闭环续呼吸**。

## 五、numpy 演示：均衡初值一步到位，闭环迭代收敛

复现第四节的两条路线：给定 180 Hz 共振（阻尼比 5%、峰值放大 10 倍）的系统，先用 $S_R/|H|^2$ 算均衡初值，再看无初值时纯闭环迭代怎么收敛：

```python
import numpy as np

fs, N = 2048, 4096
f = np.fft.rfftfreq(N, 1/fs)
psd, f1, f2 = 0.04, 80.0, 350.0          # 参考谱：平直 0.04 g2/Hz

def S_ref(fr):                            # 断点参考谱
    return np.where((fr >= f1) * (fr <= f2), psd, 0.0)

def Hmag(fr):                             # 系统：180 Hz 共振、zeta=5%
    r = fr/180.0
    return 1.0/np.sqrt((1-r**2)**2 + (2*0.05*r)**2)

band = S_ref(f) > 0
print(f"Grms = {np.sqrt(psd*(f2-f1)):.2f} g")
print(f"|H|: 100 Hz {Hmag(np.array([100.]))[0]:.2f} | "
      f"180 Hz {Hmag(np.array([180.]))[0]:.2f} | "
      f"500 Hz {Hmag(np.array([500.]))[0]:.2f}")

D_eq = S_ref(f)/Hmag(f)**2 + 1e-12        # 路线一：均衡初值
err = 10*np.log10((D_eq*Hmag(f)**2)[band]/S_ref(f)[band])
print(f"eq-init max|err| = {np.max(np.abs(err)):.1f} dB")

D = np.sqrt(S_ref(f)) + 1e-12             # 路线二：天真驱动直接送
for it in range(5):
    C = D*Hmag(f)                         # 控制谱 = 驱动 x 系统响应
    e = 10*np.log10(C[band]**2/S_ref(f)[band])
    print(f"iter {it}: max|err| = {np.max(np.abs(e)):5.1f} dB")
    D = D*(S_ref(f)/(C**2 + 1e-12))**0.25 # alpha/2 = 0.5 的一半
```

实测输出：

```
Grms = 3.29 g
|H|: 100 Hz 1.44 | 180 Hz 10.00 | 500 Hz 0.15
eq-init max|err| = 0.0 dB
iter 0: max|err| =  20.0 dB
iter 1: max|err| =  10.0 dB
iter 2: max|err| =  5.0 dB
iter 3: max|err| =  2.5 dB
iter 4: max|err| =  1.3 dB
```

三个结论。其一，**均衡初值一步到位**（0.0 dB）：$S_R/|H|^2$ 的解析修正完全抵消系统响应，这正是 System Identification 存在的理由；其二，纯闭环从 20 dB 起步，误差每帧**减半**——修正后误差是修正前的 $1-\alpha$ 倍，几何级数收敛；其三，收敛因子是速度与稳定的交换：$\alpha=1$ 一帧收敛，但辨识稍有偏差就过冲振荡；$\alpha$ 小则平滑，代价是起步阶段试件已在承受超差。工程默认值取在中间，配限幅兜底。

回到调音师：均衡初值是他进场前按房间已知特性拉好的推子曲线；闭环迭代是演出中随温度与人流变化做的持续微调。

## 六、升量级：能量百分比与平方根折算

控制谱贴合参考后，最后一步是从低量级爬到全量级。通行做法是**能量百分比升量表**：先 10%、再 25%、50%、100%，每级停留数分钟检查控制谱与监测点。量级按能量百分比的**平方根**折算——功率谱与均方值成正比，RMS 与能量的平方根成正比，10% 能量对应 32% 的 Grms、50% 对应 71%：

| 能量百分比 | Grms（全量级 3.29 g） | 工程含义 |
| --- | --- | --- |
| 10% | 1.04 g | 首次验证控制谱形状，试件热身 |
| 25% | 1.65 g | 检查夹具预紧、监测点响应趋势 |
| 50% | 2.33 g | 确认无异常发热与异响 |
| 100% | 3.29 g | 正式考核量级 |

为什么不能一步到全量级？把第一节的数字接回来：若均衡有残差、系统又在爬量级中因温升漂移（铜阻每 100 摄氏度上涨约 40%，见《[振动台选型与使用](../../practice/test-setup/shaker-table-considerations.html)》），全量级下的残差会被 Q=10 的共振放大成显著的局部超差。渐进升量级把发现问题的成本压到最低：在 1.04 g 一级发现问题，试件尚无损伤；直接打到 3.29 g 才发现，试件可能已经在错误量级下过了一遍考核。

Testlab Random Control 的对应位置：Output Level Schedule 表逐级填能量百分比与保持时间；abort 限（通道极限）与 alarm 限（超差分贝数）在 Setup 中逐通道设置；控制加速度计不止一只时，平均控制、最大/最小控制在同一面板选策略——《振动台选型与使用》一文里平均控制救夹具不均匀，用的就是这里的入口。

## 七、判读控制屏：三张图与报警处置

试验运行中，工程师盯三张图：参考谱与控制谱的叠加、误差谱（逐谱线 dB）、驱动谱。判读要点：

1. **控制谱在容差带内**：正负 3 dB 是常见验收带，共振陡峭处标准允许窄带内出带（宽度按规范执行）；
2. **误差谱的形态比数值更有诊断价值**：整体抬升指向功放或台子系统问题；单点尖峰多因辨识过期（结构漂移）；正负 1 dB 内的随机波动属谱估计方差，不是异常；
3. **驱动谱是均衡的成绩单**：它应当是参考谱除以系统响应的倒影，共振处深陷。若驱动谱已顶到功放满输出仍追不上参考谱，是《[振动台选型与使用](../../practice/test-setup/shaker-table-considerations.html)》里那笔推力账没算够——物理极限面前，任何闭环算法都无解。

一个常见疑问：监测点谱超出容差带要不要停？不要——容差带只对控制通道生效。监测点超差说明试件某些位置响应高于预期，记录在案、试验后评估；只有控制点失控（闭环持续追不上参考）才触发 abort。

## 八、小结

随机控制的完整逻辑链：规范给 PSD 参考（PSD 是随机信号唯一可复现的语言，Grms 是它的能量锚点）→ System Identification 辨识系统传递函数，按 $S_R/|H|^2$ 均衡出驱动初值 → 闭环每帧估计控制谱、算 dB 误差、按收敛因子修正驱动谱、限幅 → 能量百分比渐进升量级，控制谱始终锁在容差带内。开环必然失败，因为系统传递函数在共振处放大十倍；闭环能够稳定，因为修正量被收敛因子与限幅双重约束；驱动谱的倒影形态，是均衡正常工作的肉眼判据。

## 一句话记住

规范给 PSD、控制点测 PSD、驱动谱等于参考谱除以系统响应平方；均衡给初值、闭环每帧半量修正、能量百分比爬量级——台面谱平了，试验才算数。
