# FIR 滤波器设计三路线：单窗、频域抽样与 Remez 交换

> 前置滤波要保相位，Testlab 里点开 FIR 设计却看到三条路：Single Window、Multiple Window、Remez。同一组指标，走哪条路决定了你的通带长什么样、窄带选频性能差多少、调试哪个旋钮。手册第十二章 12.2.2 把这三条路线的数学来历讲得很清楚：单窗法从傅里叶级数截断出发、频域抽样法拿 DFT 点直接钉住频响、Remez 交换算法把最大误差均匀摊到每个频带。这篇把三者的推导链条、优劣对比和工程选型一次讲透。

## 一、问题的起点：理想频响是个无限长冲激响应

FIR 滤波器设计面对的是一个看似简单的等式：给定期望的频率响应 $H_d(\omega)$，找到有限长的系数 $h(n)$（$n = 0, 1, \ldots, N-1$），让实际频响尽量贴近它。

数学出发点是傅里叶级数展开。任何以 $2\pi$ 为周期的期望频响都可以展开为：

$$H_d(\omega) = \sum_{n=-\infty}^{+\infty} h_d(n)\, e^{-j\omega n}$$

展开系数（傅里叶级数系数）恰好就是冲激响应：$h_d(n) = \frac{1}{2\pi}\int_{-\pi}^{\pi} H_d(\omega) e^{j\omega n} d\omega$。以理想低通为例，积分可以徒手算出 $h_d(n) = \frac{\sin(\omega_c n)}{\pi n}$——一个以 n=0 为中心、向正负无穷缓慢衰减的 sinc 序列。

麻烦就在这里：**这个序列从 $-\infty$ 开始且无限长，物理上不可实现**。必须做两件事：截断（只留有限项）和平移（让它在 $n \geq 0$ 上因果化）。而简单直接的矩形截断会触发吉布斯现象——频响在通带边沿出现过冲和波纹，级数在间断点附近永不收敛。

![傅里叶级数直接截断引起的吉布斯现象：过冲与振铃](/images/fir-design-three-ways/fig12-6-gibbs.png)

*直接截断的冲激响应在频域留下约 9% 的边沿过冲和一片振铃（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-6）*

三条设计路线，本质上是对这个"无限长 vs 有限长"矛盾的三种不同回答。

::: info 核心概念
- **正则化频率（Normalized Frequency）**：频率除以采样率，工作范围 0 至 0.5，单位圆上角频率 = 正则化频率 × 2π
- **吉布斯现象（Gibbs Phenomenon）**：矩形截断傅里叶级数时，频响间断点附近出现的固定幅度过冲与振铃
- **频域抽样设计（Frequency Sampling Design）**：在单位圆 N 等分点上直接规定期望频响值，逆 DFT 得到滤波器系数
- **等波纹逼近（Equiripple Approximation）**：Remez 交换算法的核心思想，让通带和阻带的最大加权误差相等且最小
:::

## 二、先交代一个硬约束：线性相位要求冲激响应对称

FIR 相对 IIR 的王牌是**精确线性相位**。频响写成 $H(\omega) = |H(\omega)| e^{j\theta(\omega)}$，线性相位即 $\theta(\omega) = -\alpha\omega$：所有频率成分统一延迟 $\alpha$ 个采样点，波形形状不发生色散。

推导这个约束只需要一步卷积论证。要 $\theta(\omega) = -\alpha\omega$，等价于 $h(n)$ 满足对称条件：

$$h(n) = h(N-1-n)$$

且此时 $\alpha = (N-1)/2$。物理意义：滤波器就是把信号整体推迟 $(N-1)/2$ 个采样点，除此之外不引入任何相位失真。注意结论里的细节——**对任一 N 值，只有一个 α 值能使滤波器获得精确线性相位**，延迟量被系数长度锁死，不能调。

![N 为奇数与偶数时对称冲激序列的两种形态](/images/fir-design-three-ways/fig12-2-symmetry.png)

*N 为奇数时对称轴落在整数采样点上，N 为偶数时落在两个采样点之间（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-2）*

N 取奇数还是偶数有实际差别：奇数（I 型）对称轴在整数点上，可以实现低通、高通、带通任意频响；偶数（II 型）在 $\omega = \pi$ 处频响强制为零，做高通会先天残缺。选长度时这是个隐性前提。

## 三、路线一：单窗法——用窗控制级数收敛

单窗法是对吉布斯现象的直接回应。既然矩形截断（等价于乘矩形窗）让级数在间断点附近振荡，那就换一个两端平滑衰减到零的窗函数去乘冲激响应：

$$h(n) = w(n) \cdot \hat{h}(n)$$

其中 $w(n)$ 是窗序列，$\hat{h}(n)$ 是期望的（平移因果化后的）冲激响应。时域相乘对应频域卷积：实际频响等于期望频响与窗谱的卷积，窗谱的主瓣宽度决定过渡带宽度、旁瓣电平决定阻带衰减。手册给出窗函数的两条理想特性：**主瓣窄且涵盖尽可能多的能量；$\omega$ 趋向 π 时旁瓣能量快速衰减**。

手册列举了 LMS 产品支持的几种窗，全部有闭式表达式：

| 窗函数 | 表达式要点 | 特性定位 |
| --- | --- | --- |
| **矩形窗** | $W(n)=1$ | 直接截断，吉布斯现象的源头 |
| **汉宁窗** | $W(n) = \alpha + (1-\alpha)\cos\frac{2\pi n}{N}$，取 $\alpha = 0.5$ | 截断宽度与波纹抑制的折中 |
| **哈明窗** | 同上式取 $\alpha = 0.54$ | 旁瓣比汉宁更低 |
| **凯塞窗** | $I_0$ 贝塞尔函数族，参数 $\beta$ 可调 | 限带能量泄漏最小的近似最优窗 |
| **切比雪夫窗** | 切比雪夫多项式 $T_r(x)$ 的逆 DFT | 给定频率限外谱能量最小的另一最优窗 |

两条"最优窗"值得多说一句。凯塞窗是长球面波函数（时限函数里能量最集中的那个）的简化近似，它的傅里叶变换接近限带函数，**溢出到选定频带外的能量最小**；切比雪夫窗走另一条路——利用 $T_r(\cos\theta) = \cos(r\theta)$ 的多项式递推，在给定旁瓣电平下主瓣最窄，由多项式的逆 DFT 直接算出窗序列。两者都是"可调窗"：一个参数同时换主瓣宽度和旁瓣电平。

::: warning 单窗法的软肋
窗函数一旦选定，频响的所有特征（过渡带、波纹、阻带衰减）就被窗谱整体决定——通带和阻带的波纹 **不能分开指定**，过渡带宽度也不能独立于窗长之外微调。想同时卡死多个指标，单窗法做不到，得往下走。
:::

## 四、路线二：频域抽样——把频响直接钉在 DFT 格点上

第二条路线换了思路：既然 FIR 的频响可以由 DFT 系数完全规定（DFT 系数就是 Z 变换在单位圆 N 等分点上的抽样值），那干脆**反过来**——先在单位圆 N 等分点上规定期望频响 $H(k)$，再逆 DFT 得到滤波器系数。

推导链条很短。滤波器冲激响应的 DFT 为：

$$H(k) = \sum_{n=0}^{N-1} h(n)\, e^{-j2\pi kn/N}$$

单位圆 N 等分点即 $z_k = e^{j2\pi k/N}$。在频率抽样设计里，你直接给定每个格点上的 $H(k)$（比如通带格点取 1、阻带格点取 0、过渡带格点取中间值），然后：

$$h(n) = \frac{1}{N} \sum_{k=0}^{N-1} H(k)\, e^{j2\pi kn/N}$$

手册特别指出这条路线的适用场景：**设计具有任意滤波特性的滤波器，尤其适合窄带高选择性滤波器**。道理在于格点频率上频响精确等于规定值（N 个方程 N 个未知数，精确钉死），窄带滤波器只需要在通带附近放几个非零格点、其余全取零，系数天然稀疏、选频性极好。

代价在格点之间。两个 DFT 格点中间的频响靠插值得到，期望频响越陡（间断特征越尖锐），格点间的实际频响振荡越明显。缓解办法是在过渡带人为加插一到两个"过渡点"（取 0 与 1 之间的值），用通带边沿的轻微失守换阻带衰减的大幅改善——这正是"多重窗"名称的来历：不同频带区域可以指定不同的逼近方式。

## 五、路线三：Remez 交换——最大误差最小化的等波纹解

第三条路线是 FIR 设计的"最优解"。它不问"频响像不像"，问"最大偏差能压到多小"。

问题设定：期望频响表示为若干个频带组成的样板（通带、过渡带、阻带），在频带上添加密集的格子，定义加权逼近误差：

$$E(\omega) = W(\omega)\,[H_d(\omega) - H(\omega)]$$

Parks-McClellan 算法利用切比雪夫逼近理论，让这个误差的**最大值在所有频带上均匀分布且达到最小**。数学上由交错定理保证：最优解的误差曲线在通带和阻带内等幅振荡，振荡次数等于滤波器长度的一半左右。

![Remez 滤波器的逼近误差在通带和阻带内等波纹分布](/images/fir-design-three-ways/fig12-7-remez-error.png)

*最优解的标志：通带与阻带的逼近误差峰谷等高（图源：Simcenter Testing Knowledge Base 中文理论手册 图12-7）*

加权函数 $W(\omega)$ 是工程上的关键旋钮。规格化做法是阻带取 $W=1$、通带取 $\delta_2/\delta_1$（两个误差限之比）：

- 所有频带权取 1 → 误差在通带和阻带均匀分布，两边波纹一样大
- 想压小某个特定频带的波纹 → 给该频带相对更大的权，代价是别的频带波纹变大

算出最优频响后做一次逆 DFT，滤波器系数直接落地。

::: tip 与前两条路线的实质区别
单窗法的波纹由窗谱"批发"决定、频域抽样法的格点间行为"听天由命"，Remez 是唯一能把**通带波纹、阻带衰减、过渡带宽度三者同时写进指标再解出最短长度**的方法。同指标下 Remez 阶次通常比单窗法低 20%~30%，代价是设计过程迭代求解、不能手算。
:::

## 六、Python 演示：同一指标，三条路线各长什么样

用理想低通（截止 0.25 正则化频率、长度 41）做对照：单窗法取汉宁窗截断 sinc，频域抽样法在 41 个格点上规定通阻值再逆 DFT。Remez 的等波纹解需要迭代求解，超出 numpy 演示的范围，但前两条路线的差距已经足够说明问题。

```python
import numpy as np

N = 41                 # 滤波器长度（奇数 -> I 型，对称轴在整数点）
fc = 0.25              # 正则化截止频率（0~0.5）
f = np.arange(8192) / 16384            # 细化频率轴（0~0.5）

def report(name, h):
    H = np.abs(np.fft.fft(h, 16384))[:8192]
    sb = H[(f > 0.32) & (f < 0.45)]    # 阻带（离开过渡带后量）
    pb = H[(f > 0.05) & (f < 0.15)]    # 通带
    print(f"{name:<14} 通带波纹 ±{np.max(np.abs(pb - 1)):.4f}   "
          f"阻带最大泄露 {20 * np.log10(np.max(sb)):.1f} dB")

# ---- 路线一：单窗法（汉宁窗截断理想 sinc）----
m = np.arange(N) - (N - 1) / 2
h_ideal = np.where(m == 0, 2 * fc, np.sin(2 * np.pi * fc * m) / (np.pi * m))
win = 0.5 - 0.5 * np.cos(2 * np.pi * np.arange(N) / (N - 1))
report("单窗-汉宁", win * h_ideal)

# ---- 路线二：频域抽样（格点钉 0/1 + 线性相位因子，逆 DFT）----
k = np.arange(N)
fg = np.minimum(k, N - k) / N            # 折叠到 0~0.5 的格点频率
phase = np.exp(-1j * np.pi * (N - 1) * k / N)   # (N-1)/2 延迟的相位因子
Hk = (fg <= fc).astype(float) * phase
report("频域抽样", np.real(np.fft.ifft(Hk.astype(complex))))
```

运行输出：

```text
单窗-汉宁     通带波纹 ±0.0008   阻带最大泄露 -54.6 dB
频域抽样      通带波纹 ±0.0190   阻带最大泄露 -23.7 dB
```

最值得看的两个数：汉宁窗把阻带压到 -55 dB 以下、通带波纹几乎为零；朴素频域抽样（不加过渡点）阻带只有 -24 dB 左右——**格点间靠插值，振荡能量直接漏进阻带**。给过渡带加两个中间值格点（0.5、0.25），阻带能追到 -32 dB 附近，代价是通带边沿略钝；要再往上就得交给 Remez。另一个细节：频域抽样的格点值必须乘上 $e^{-j\pi(N-1)k/N}$ 相位因子（对应 $(N-1)/2$ 的线性相位延迟），否则逆 DFT 出来的冲激响应不对称，阻带直接塌到 -4 dB。

## 七、三条路线怎么选

| 维度 | **单窗法** | **频域抽样** | **Remez 交换** |
| --- | --- | --- | --- |
| **设计自由度** | 窗谱决定，指标不能分开设 | 格点值任意，多频带灵活 | 通带/阻带/过渡带指标独立 |
| **同指标阶次** | 最高 | 中等 | 最低（等波纹最优） |
| **窄带选频** | 一般 | **最强**（系数稀疏） | 强 |
| **设计复杂度** | 一次乘法 | 一次逆 DFT | 迭代求解 |
| **典型场景** | 快速原型、指标宽松 | 窄带滤波器组、倍频程滤波 | 指标卡死的交付级滤波器 |
| **可手算性** | 可（窗有闭式） | 可（逆 DFT） | 不可 |

::: tip 选择原则
- 指标宽松、赶时间、要保线性相位：单窗法 + 凯塞/切比雪夫可调窗，一个 β 参数扫一遍就收工
- 窄带选频（比如从宽带振动里抠出单个阶次带）：频域抽样，通带格点数少、系数稀疏
- 通带波纹和阻带衰减都要写进验收条款：Remez，别犹豫——同指标下它给你的阶次最低
- 长度 N 定不下来：记住线性相位延迟 α=(N-1)/2 被长度锁死，实时性要求反过来卡 N
:::

一个容易忽略的工程细节收尾：FIR 滤波器的启动瞬态是有限长时间（恰好 N-1 个采样点），而 IIR 理论上无限长。处理瞬态冲击信号时，FIR 滤波后的前 N-1 点数据是不可信的，做统计或幅值判读前要先掐头。
