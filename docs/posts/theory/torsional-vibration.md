# 扭转振动：旋转机械的隐藏自由度

> 转速表指针平滑上升的背后，曲轴其实一直在"加速—减速"地抖动——这就是扭转振动。本文讲清它的物理本质、为什么 1 PPR 测不到它、PPR 与最高可分辨阶次的定量关系，以及如何用扭振阶次把车内噪声峰定位到曲轴共振。

## 一、藏在转速曲线里的波动

看一条四缸机从 1000 升到 3500 RPM 的转速曲线，第一印象是单调上升。放大每一转内部：转速并不是稳定值，而是在一个转角周期内反复波动，波动量可以到 100 RPM 的量级。

这就是扭转振动（Torsional Vibration）的定义：**旋转部件角速度围绕稳态转速的交变波动**。它叠加在平均转速之上，是旋转系统里除了横向振动、轴向振动之外的第三个自由度——也是最容易被忽略的那个，因为常规的加速度传感器贴在轴承座上，测到的横向振动对扭振并不敏感。

转速表为什么看起来那么稳？因为仪表大约每转才刷新一次——恰好把一转之内的波动全部平均掉了。仪表采样再快一点，用户反而会以为"发动机跑得不稳"往 4S 店跑。这不是玩笑：稳，有时候只是采样率不够。

用一段模拟感受一下"每转采样多少次"如何决定你能不能看到扭振：

```python
import numpy as np

rpm0 = 2000.0                          # 稳态转速
f_rot = rpm0 / 60                      # 转频 Hz
# 四缸机 2 阶点火激励，叠加 ±25 RPM 的转速波动
wave = lambda t: rpm0 + 25.0*np.sin(2*np.pi*2*f_rot*t)

for ppr in [1, 10, 120]:
    # 每转 ppr 个脉冲 = 每秒 ppr*f_rot 个采样点
    fs = ppr * f_rot
    tp = np.arange(0, 0.2, 1/fs)
    rpm_s = wave(tp)
    print(f"PPR={ppr:>3} | 采样点数={rpm_s.size:>4} | 测得波动峰峰值={rpm_s.max()-rpm_s.min():5.1f} RPM")
```

PPR=1 时每个采样点都落在同一转角相位上，测到的波动峰峰值是 0——真实存在 ±25 RPM 的扭振，仪器完全看不见。PPR=10 起波动才被完整还原。这就是扭振测量的第一定律：**一转之内有信息，一转只采一次就什么都没有**。

## 二、扭振从哪来：三类机械，四种危害

几乎没有旋转机械的角速度是绝对恒定的，激励来源各不相同：

| 机械类型 | 扭振机理 | 阶次特征 |
| --- | --- | --- |
| **内燃机** | 各缸燃烧爆发推动曲轴加速，两次燃烧之间惯性又使其减速 | 点火阶次主导（四缸机为 2 阶） |
| **电机** | 磁极离散，每转经过固定数目的磁极产生转速脉动 | 与极数相关的低阶次 |
| **液压泵/马达** | 液体以不均匀的速率进出各工作腔，转速随之脉动 | 与柱塞/齿轮/叶片数相关的高阶次 |

危害横跨四个维度：

- **耐久**：弹性联轴器磨损、齿轮磨损，曲轴与传动系提前疲劳——燃烧引起的转速交变每天都在给轴系上疲劳载荷；
- **舒适**：扭振经传动系传到方向盘、座椅、踏板，表现为低速抖动；
- **噪声**：齿轮啸叫（gear whine）、离合器颤振（chatter）；
- **性能**：同步类机构工作质量下降，油耗恶化。

低速段抖动抱怨、找不到振源的齿轮啸叫、台架上莫名早衰的联轴器——遇到这类问题，查一下扭振阶次往往有意外收获。

## 三、怎么测：PPR 是成败的关键

扭振测量本质上不是"测振动"，而是**高频响地测转速**：对每转 N 个脉冲的转速信号做分析，扭振信息就藏在脉冲间隔的微小变化里。传感器两大主流路线：

| 方案 | PPR 上限 | 优点 | 限制 |
| --- | --- | --- | --- |
| **磁电传感器 + 齿轮** | 齿数 | 坚固、便宜、抗粉尘 | PPR 被齿数锁死，加不了密 |
| **光学传感器 + 斑马带/斑马盘** | 条纹数（可自选） | PPR 想多高有多高 | 接缝（butt joint）会引入假波动 |

真实案例里同一条 4 缸机升速曲线，120 PPR 的红色曲线把一转之内的转速波动完整记录，1 PPR 的黑色曲线只剩一条平滑斜线——低 PPR 不是"精度差一点"，是整个扭振频段直接消失。

![1 PPR 与 120 PPR 测同一条升速曲线的对比](/images/torsional-vibration/ppr-compare.png)
*（图源：Simcenter Testing Knowledge Base）*

PPR 选多少？定量判据：**每转脉冲数必须至少是最高关心阶次的 2 倍**——测 60 阶扭振至少 120 PPR。而且实践中常再乘 10 倍安全系数，原因是阶次域的"采样"没有抗混叠滤波器兜底，欠采样不会变模糊，而是直接折叠出假阶次：

```python
import numpy as np

ppr = 120.0            # 每转 120 个脉冲，可分辨上限 = 60 阶
for order in [2, 30, 60, 61, 90, 119]:
    fold = order % ppr
    if fold > ppr/2:                # 超过奈奎斯特阶次，镜像折叠
        fold = ppr - fold
    print(f"真实 {order:>3.0f} 阶  ->  观测为 {fold:>4.0f} 阶")
```

看 90 阶那一行：PPR=120 时它不消失，而是冒充成一条 30 阶线。如果你正好在追 30 阶的齿轮啸叫，这条假线能把你带偏一整个排查方向。PPR 不够时，colormap 上高阶区一片空白，阶次切片在"理论上限阶次"处戛然而止——看到这个特征就该检查 PPR 设置了。

::: warning 工程注意
高 PPR 带来高数据率：每转 120 脉冲、6000 RPM 时脉冲频率 12 kHz，转速通道的采集带宽和记录吞吐都要按这个量级准备，普通转速通道设置会把脉冲当普通 tacho 信号处理而丢信息。Simcenter SCADAS 的专用高性能 tacho 输入（RV4 模块可同时接 4 路）就是为此设计的。
:::

## 四、扭振阶次：从转速数据到 NVH 诊断

拿到高 PPR 转速数据后，对它做阶次分析（跟对振动信号做 colormap 一样），得到的就是扭振阶次。四缸机升速的扭振 colormap 上，2 阶及其谐波是绝对主角——2 阶正是四缸机的点火阶次（Firing Order）：每转两次燃烧事件，曲轴在"被推动—惯性滑行"之间循环。

![四缸机扭振 colormap（左）与 2 阶扭振随转速的切片（右）](/images/torsional-vibration/torsional-colormap.png)
*（图源：Simcenter Testing Knowledge Base）*

右侧的阶次切片藏着两条规律：

**其一，转速越低扭振越大。** 转速低意味着两次燃烧之间的时间间隔长，曲轴减速得更深，波动幅度自然更大。推论同样重要：缸数越少，每转燃烧事件越少，间隔越长，扭振越严重——三缸机比四缸机糟，单缸最糟。

**其二，约 2600 RPM 处有一个突出的峰。** 低转速段扭振随转速升高一路下降，到 2600 RPM 附近却逆势鼓起一个包——这是 2 阶激励频率扫过曲轴扭振固有频率时的共振。用单自由度系统复现这条曲线：

```python
import numpy as np

rpm  = np.linspace(1000, 3500, 51)        # 转速点
f2   = 2 * rpm / 60.0                     # 2 阶激励频率 Hz
fn, zeta = 86.7, 0.05                     # 扭振固有频率(对应~2600RPM)与阻尼比
mag  = 1.0/np.sqrt((1-(f2/fn)**2)**2 + (2*zeta*f2/fn)**2)
base = 6000.0 / rpm                       # 低速段更大：燃烧间隔长，减速深
tors = base + 8.0*mag/mag.max()           # 两种机理叠加

for r, f, a in zip(rpm[::10], f2[::10], tors[::10]):
    print(f"转速 {r:>5.0f} RPM | 2阶激励 {f:5.1f} Hz | 扭振幅值 {a:5.2f} RPM")
print(f"\n扭振峰值出现在 {rpm[tors.argmax()]:.0f} RPM")
```

输出里 1000 RPM 处约 6.9 RPM，随转速升到 1800 RPM 左右降到谷底，2600 RPM 处反弹到约 10.3 RPM 的峰值，之后再次回落——实测曲线正是这个形状：整体下降 + 一处共振包。

**诊断闭环**：在司机右耳（DRE）布置话筒，2 阶声压切片在 2600 RPM 附近同样有个 dB 峰。单看噪声数据，这个峰的来源可以有十种猜测；把 2 阶扭振曲线叠上去，两峰转速对齐——噪声峰的来源就是曲轴扭振共振。

![DRE 处 2 阶噪声与 2 阶扭振叠图，2600 RPM 处两峰对齐](/images/torsional-vibration/dre-overlay.png)
*（图源：Simcenter Testing Knowledge Base）*

这是扭振阶次最大的价值：**回答"扭振到底有没有驱动整车的噪声/振动"**。叠图对齐，去查轴系扭振模态；对不齐，扭振出局，去查别的路径，避免在错误的攻关方向上耗时间。

::: tip 判读要点
- 扭振 colormap 上找点火阶次及其谐波：那是发动机的指纹；
- 阶次切片上逆着"随转速下降"趋势鼓起的包，对应轴系扭振共振，记下转速换算成频率；
- 噪声/振动的阶次峰与扭振峰转速对齐，即可锁定因果。
:::

## 五、Testlab 实操要点

**通道设置一鱼两吃。** Channel Setup 里把转速通道的 ChannelGroupId 从 Tacho 改成 Vibration，一个通道同时产出转速数据与"振动"数据——不必物理分路接两通道，就能直接对 throughput 数据做 colormap 和阶次切片。

**纵轴不只是 RPM。** 右键纵轴 → Processing → Integrate (Single)，转速波动积分成扭振角位移（角度），工程上评估轴系疲劳与联轴器变形时看角位移更直接。同一菜单的 Section Scaling 里可切换 RMS / Peak / Peak-Peak 格式。

**扭振也能做动画。** Geometry 工作表的 Torsional node 子工作表里 Add Disc 添加旋转件圆盘节点（输入节点名与半径），之后扭振的谱、阶次、时域都能像普通几何一样做 ODS 动画，直观看各圆盘间的相对扭转。

**斑马带接缝要修正。** 斑马带缠轴收尾处的搭接缝每转会制造一次假的转速骤降或尖峰，属于系统性伪影，Testlab Time Signal Calculator 的 ZEBRA_MOMENTS_TO_RPM 函数（Tacho 函数组）可以扣除，16A 版本起支持多接缝。接缝与脉冲毛刺的完整清洗流程，另见《[RPM 信号去毛刺：转速信号的清洗](../practice/rpm-spike-removal.html)》。

## 六、小结

扭振是角速度的波动，不是"转速不稳的错觉"。工程判断三条线：测——PPR 至少取最高关心阶次的 2 倍，实际留 10 倍余量，PPR 不够时高阶折叠成假阶次而非消失；看——发动机扭振以点火阶次为主导，低转速段幅值更大，切片上逆势凸起的包是轴系扭振共振；断——把扭振阶次与车内噪声阶次叠图，峰对得上才有因果，别让横向振动的排查思路先入为主。
