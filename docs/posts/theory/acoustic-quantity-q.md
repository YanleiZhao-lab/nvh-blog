# 声学量Q：体积加速度的物理意义

> 声学传递路径分析和声源识别文献里经常出现符号 Q，单位 m³/s²——它就是体积加速度（Volume Acceleration），声学系统里与"力"对等的输入量。理解 Q，才能理解为什么一只 Q-source 能把 12 次敲击实验压缩成 1 次测量，以及 Testlab 里 P/F 和 A/Q 两条传递函数为什么会是同一条曲线。

## 一、从 F=ma 到 Q→P：声学系统的对偶

结构 NVH 分析的基本框架是牛顿第二定律：力 F 输入系统，加速度 a 是响应输出，中间由质量、刚度、阻尼决定的传递函数连接。锤击法测模态、TPA 测悬置传递率，都是在测这个"输入力 → 输出响应"的关系。

声学系统完全可以套用同一套思路，只是输入输出的量换了：

| 对偶项 | 机械系统 | 声学系统 |
| --- | --- | --- |
| **输入量** | 力 F（N） | 体积加速度 Q（m³/s²） |
| **输出量** | 加速度 a（m/s²） | 声压 P（Pa） |
| **传递函数** | a/F（加速度导纳） | P/Q（Pa·s²/m³） |
| **典型激励设备** | 力锤、激振器 | Q-source |

::: info 核心概念
- **体积加速度（Volume Acceleration，Q）**：声源表面法向加速度沿面积的积分，单位 m³/s²，声学系统中与力 F 对等的输入量
- **体积速度（Volume Velocity，U）**：声源表面积分得到的体积流量，单位 m³/s；谐和振动时 Q = jωU，两者差一个 ω 因子
- **互易性（Reciprocity）**：线性系统中，A 点输入 B 点响应，等于 B 点同样输入 A 点响应——Q-source 高效测量的物理基础
:::

为什么不直接用声压当输入？因为声压是"果"不是"因"：同一声源在小房间和开阔消声室里产生的声压完全不同，而它输出的 Q 是固有属性，不受环境声学条件摆布。就像描述激振器我们说输出力多少牛顿，而不是说"它能把某块铁板振到多少 g"。

## 二、体积加速度 = 面积 × 加速度：从扬声器说起

Q 这个名字乍看费解——"体积"怎么会有"加速度"？最直观的拆法是把它看成**面积 × 加速度**。

想象一个扬声器纸盆。把它的表面切成一小块一小块的面积元，每个面积元中心贴一枚加速度计。声源总的 Q 就是所有"面积 × 各自法向加速度"的和：

Q = Σ Ai · ai

纸盆上每一点都同相位、同幅值振动时，Q 就等于纸盆总面积乘以加速度。这与低频"活塞式"辐射的图景一致。

![扬声器表面分区示意](/images/acoustic-quantity-q/speaker-areas.png)
*（图源：Simcenter Testing Knowledge Base）*

关键在高频。结构上弯曲波的波长随频率升高而变短，相邻两块面积元可能一个向上拱、一个向下凹——加速度相位相反。面积乘加速度是带符号的求和，相位相反的区块贡献互相抵消，总 Q 迅速缩水。

所以用加速度计阵列测 Q 时，**分析的频率越高，面积元必须切得越小**，否则大区块内部的相位抵消会让积分结果严重偏小。手册里那张仪表板分区图就是这个意思：想在高频段还原准确的 Q，板面要切成上百个小块，逐块布置加速度计。

![仪表板分区测量 Q](/images/acoustic-quantity-q/dash-panel-areas.png)
*（图源：Simcenter Testing Knowledge Base）*

下面用一段 numpy 演示"相位抵消"到底多致命——两块等面积的板，加速度幅值完全相同，只改相位关系：

```python
import numpy as np

# 一块隔板分成两个 0.02 m2 的补丁，加速度幅值都是 1 m/s2
area = np.array([0.02, 0.02])          # 面积，m2
amp  = np.array([1.0, 1.0])            # 加速度幅值，m/s2

# 低频：结构波长远大于补丁尺寸，两块近似同相
phase_low  = np.deg2rad([0, 5])
# 高频：结构波长与补丁尺寸相当，相邻补丁接近反相
phase_high = np.deg2rad([0, 170])

def q_of(area, amp, phase):
    # 复数加速度按相位合成，Q = sum(面积 × 加速度)（复数求和）
    a = amp * np.exp(1j * phase)
    return np.sum(area * a)

Q_low, Q_high = q_of(area, amp, phase_low), q_of(area, amp, phase_high)

print(f"同相振动: |Q| = {abs(Q_low):.4f} m3/s2  （两块贡献几乎直接相加）")
print(f"反相振动: |Q| = {abs(Q_high):.4f} m3/s2  （大面积元内部自我抵消）")
print(f"幅值损失: {20*np.log10(abs(Q_high)/abs(Q_low)):.1f} dB")
```

输出里最值得看的是最后一行：加速度幅值一点没变，仅仅因为相邻补丁相位差从 5 度变到 170 度，Q 就掉了约 21 dB。这就是高频必须细分区积分的原因——不是测量精度问题，是物理上的相消。

## 三、Q-source 与互易法：12 次敲击变 1 次测量

Q 真正的威力在测试效率上。

传统测结构声传递路径的做法：用力锤在悬置安装点逐点敲击，麦克风放在驾驶员耳位接收声压，得到 P/F 传递函数。一台电机通过四个悬置安装在结构上，每个悬置三个方向都要敲，就是 4 × 3 = 12 次敲击测量。悬置更多、方向更全，工作量线性增长。

Q-source 把这件事反过来做（互易法）。把 Q-source 放在响应点——驾驶员耳位，让它发出标定过的体积加速度；同时在各悬置安装点贴上加速度计。激励一次，12 个通道同时采到 A/Q 传递函数。

![中高频 Q-source，喷嘴尖端产生标定 Q](/images/acoustic-quantity-q/qsource-nozzle.png)
*（图源：Simcenter Testing Knowledge Base）*

为什么 A/Q 能替代 P/F？看量纲：

- P/F = (N/m²) / N = 1/m²
- A/Q = (m/s²) / (m³/s²) = 1/m²

两个比值都约化成 1/m²，量纲完全一致。这不是巧合——对满足互易性的线性声振系统，"悬置点加力、耳位产生声压"与"耳位注入 Q、悬置点产生加速度"这两条路径的传递函数严格相等。手册中的对比实验也确认：Q-source 互易法测出的 FRF 与力锤逐点敲击的结果一致，但时间大幅缩短。

| 对比项 | 力锤直接法（P/F） | Q-source 互易法（A/Q） |
| --- | --- | --- |
| **激励位置** | 悬置安装点（结构侧） | 声学响应点（如耳位） |
| **激励量** | 力 F（N） | 体积加速度 Q（m³/s²） |
| **测量响应** | 声压 P（麦克风） | 加速度 A（加速度计） |
| **4 悬置 × 3 向** | 12 次独立敲击 | 1 次激励，12 通道并行 |
| **适用场景** | 少数关键路径 | 多路径 TPA、批量排查 |

再用一段代码把两件事串起来：给定 Q 之后，自由场里声压大概什么量级——感受一下 Q 与熟悉的 dB 数之间的距离：

```python
import numpy as np

# 自由场单极子近似：从 Q 估算距离 r 处的声压级
rho0  = 1.204                     # 空气密度，kg/m3
Q     = 1.0                       # Q 幅值，m3/s2（Q-source 典型量级）
p_ref = 20e-6                     # 声压参考值，Pa

for r in [1.0, 0.1]:              # 距离源 1 m 与 0.1 m
    p   = rho0 * Q / (4 * np.pi * r)     # |p| 近似为 rho0*Q/(4*pi*r)
    spl = 20 * np.log10(p / p_ref)
    print(f"r = {r:>4} m: |p| = {p:.3f} Pa, SPL ≈ {spl:.1f} dB")

# 对比：Q 减半（比如标定填错一档），声压级掉多少
spl_half = 20 * np.log10(0.5)
print(f"\nQ 若减半: SPL 下降 {spl_half:.1f} dB —— 灵敏度填错直接体现在每一根谱线上")
```

两个看点：1 m³/s² 的点源在自由场 1 m 处约 75 dB，距离缩到 0.1 m 就涨 20 dB——反比衰减意味着用 Q-source 测 FRF 时，源到响应点的距离是第一敏感参数；Q 减半声压级正好掉 6 dB，标定灵敏度填错一档，整条传递函数就整体平移。（注：单极子公式是自由场近似，车内混响场实际值会偏离，但量级判断够用。）

## 四、Testlab 里配置 Q-source 的要点

硬件连接：SCADAS 的源输出经内置功放电缆接 Q-source，Q-source 上的 BNC 输出端回接到一个数据通道，采回实际发出的 Q 信号。软件设置按标定单逐项填：

1. **Channel Setup**：Measured Quantity 选 VolumeAcceleration；Input Mode 按 Q-source 类型选 ICP 或 Voltage（标定单上写明）；Actual Sensitivity 填标定单给的灵敏度，单位 mV/(m³/s²)
2. **Spectral Acquisition 的 Scope**：源设为 Random
3. **Test Setup**：勾选 FRF 的 Measure + Save
4. 测完后在显示页右键 Y 轴选 Unit，可以把 A/Q 切换成 P/F 直接按力传递函数读数

::: warning 工程注意
- 灵敏度、Input Mode 一律以 Q-source 随附的**标定单**为准，不要沿用上一个项目的通道设置——不同型号 Q-source 供电方式（ICP/Voltage）不同，填错会导致 Q 幅值整体偏差 6 dB 量级
- 市面上常把这类声源叫 Volume Velocity source，但它输出的测量量是 Volume Acceleration——名字混用，认单位 m³/s² 才不会接错通道
:::

## 五、小结

记住三条就够用：

- Q（体积加速度，m³/s²）= 面积 × 加速度的面积分，是声学系统里与力 F 对等的输入量；P/Q 之于声学，如同 a/F 之于结构
- 用加速度计阵列积分求 Q 时，频率越高分区要越细——相邻区块相位反转带来的相消是 dB 级的损失，不是小误差
- 多路径结构声 TPA 优先考虑 Q-source 互易法：耳位放源、悬置点放加速度计，一次激励并行拿全所有 P/F（即 A/Q）传递函数；力锤逐点敲击留给少数路径的复核
