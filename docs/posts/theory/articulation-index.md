# 清晰度指数与语言干扰级：语言频带内的可懂度评价

> 两台车车内噪声分别为 67 dB(A) 与 56 dB(A)，总级较高、低频轰鸣明显的那台反而更易交谈——决定语音可懂度的不是总声级，而是 500 Hz～4 kHz 语言频带内信号高于背景的余量。清晰度指数（AI）与语言干扰级（SIL/PSIL）是针对这一频带的两个评价指标：前者按各频带对可懂度的重要程度加权求和，后者取几个带级的算术平均对通话环境分级。本文按 Simcenter Testing 理论手册 7.8、7.9 节整理二者的定义、算法口径与适用条件。

## 一、dB(A) 与通话可懂度的脱节

整车 NVH 汇报惯用 dB(A)，但 A 计权在低频衰减显著：100 Hz 处修正值为 $-19.1$ dB（IEC 61672 的 1/3 倍频程中心频率标称值）。于是"低频轰鸣、高频干净"的车与"中高频沙沙作响"的车可以合成相同的总级。而语言能量集中在 500 Hz～4 kHz，辅音辨别尤其依赖 2 kHz 以上——正是 A 计权几乎不衰减的频段。

总级由各带级在能量域合成：

$$L_{p\mathrm{A}} = 10\,\lg\!\left(\sum_{i} 10^{(L_i + \Delta A_i)/10}\right)\ \mathrm{dB}$$

其中 $L_i$ 为第 $i$ 个 1/3 倍频程带声压级（dB），$\Delta A_i$ 为该中心频率的 A 计权修正值（dB）。物理意义：计权修正作用于声压平方（能量）域，低频分量在求和前已被大幅压低——同一总级之下，频谱形状仍有很大的自由度。

结果是总级与通话质量脱钩：高速风噪主导的车 dB(A) 不高，乘员却需提高声级交谈；粗糙路面低频轰鸣的车 dB(A) 很高，面对面说话仍可正常听清。评价通话、免提、语音助手唤醒率这类场景，需要只针对语言频带的指标。

::: info 核心概念
- **清晰度指数（Articulation Index，AI）**：对噪声频谱（1/3 倍频程）按各频带对语言可懂度的重要程度加权后归一求和，0～100%，回答"背景中语言信息还剩多少"
- **语言干扰级（Speech Interference Level，SIL/PSIL）**：语言频带内几个倍频程带声压级的算术平均，数值越低越容易交谈
- **语言频带**：语言能量与辨别信息集中的约 500 Hz～4 kHz 区间，是这组指标与 A 计权出现分歧的地方
:::

## 二、AI：按频带重要性加权的可懂度指标

AI 最初是为**通话私密性**提出的参数——办公室、开放式工位里，背景噪声把相邻谈话掩蔽到什么程度。视角与干扰评价相反：噪声在此不是干扰，而是提供掩蔽、保护私密的资源。

算法骨架出自 Beranek 1947 年的《语音通讯系统的设计》（The design of speech communication system，Proceedings of the IRE, Vol.45, 880-884, 1947）：把 1/3 倍频程声压级谱画在专用图版上，图版按各频带对语言可懂度的贡献印有数目不等的计权圆点（语言核心频带点密，带外点稀），**谱线以上的点数除以总点数就是 AI**。点位于谱线上方，代表该处语言能量未被噪声掩蔽；谱越高，被盖住的点越多，AI 越低。

![AI 的图形计算法：1/3 倍频程谱画在计权图版上，谱线上方的计权点数占比即 AI](/images/articulation-index/fig7-7-ai-nomogram.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册 图7-7）*

图算法的解析表述可分三步写出。

**第 1 步，逐带信噪比。** 设第 $i$ 个 1/3 倍频程带的语言带级为 $L_{V,i}$（dB）、背景噪声带级为 $L_{N,i}$（dB），该带的语音余量为

$$\mathrm{SNR}_i = L_{V,i} - L_{N,i}\ \mathrm{dB}$$

物理意义：可懂度由每个频带内信号高于背景多少决定，而非全频段总级。

**第 2 步，限幅归一。** 余量接近零的带不贡献可懂度，余量很高的带也不会线性兑换更多可懂度，经典处理是把每带 SNR 夹紧后线性映射到 0～1：

$$g(\mathrm{SNR})=\min\!\left(1,\ \max\!\left(0,\ \frac{\mathrm{SNR}-\mathrm{SNR}_{\min}}{\mathrm{SNR}_{\max}-\mathrm{SNR}_{\min}}\right)\right)$$

即 $\mathrm{SNR}\le \mathrm{SNR}_{\min}$ 时 $g=0$（完全掩蔽），$\mathrm{SNR}\ge \mathrm{SNR}_{\max}$ 时 $g=1$（充分可懂），中间线性过渡。Beranek 原始方法取线性区间 0～30 dB，ANSI S3.5-1969 修订为 $-12$～$+18$ dB。物理意义：低于下限的带被完全掩蔽，高于上限的带已充分可懂，两端饱和。

**第 3 步，按重要性加权求和：**

$$\mathrm{AI}=\sum_{i} W_i\, g(\mathrm{SNR}_i), \qquad \sum_{i} W_i = 1$$

$W_i$ 为第 $i$ 个频带对可懂度的重要度计权，语言核心频带取值大、带外取值小——图版上圆点的疏密就是 $W_i$ 的图形化。AI 的物理意义即背景中未被掩蔽的语言信息比例，值域 0～100%。

AI 与可懂度的换算有实测曲线支撑。工程上的锚点：**完全私密要求 AI 不超过 0.05；半私密（商谈非保密事务）AI 取 0.1 以内**。

![句子可懂度随清晰度指数的变化曲线](/images/articulation-index/fig7-8-intelligibility.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册 图7-8）*

::: warning 两种算法结果不可直接对比
- **标准方法**（Beranek 路线）：AI 值域 0～100%
- **改良方法**（AIM 路线）：在 20～100 dB 固定 80 dB 量程上再上下浮动 30 dB，算出的 AI 可达 107%～约 160%
对比两份报告前先确认算法口径，超 100% 不是数据有误，而是改良法量程未封顶。
:::

电动车低噪声环境催生了 AI 的反向应用：缺少发动机掩蔽后，车厢内轻声交谈几乎不受掩蔽，语音私密性下降——电动车主动声浪、AVAS 提示音设计中，"把 AI 压回 0.05 以下"是掩蔽量的设计目标之一。

## 三、SIL/PSIL：语言频带带级的算术平均

AI 需逐带加权，工程现场有时只需要一个能快速分级的数。语言干扰级即取语言频带内几个倍频程带声压级的算术平均，不引入其他处理。三个历史版本：

$$\mathrm{SIL}_{\mathrm{Beranek}}=\frac{L_{600\text{-}1200}+L_{1200\text{-}2400}+L_{2400\text{-}4800}}{3}\ \mathrm{dB}$$

$$\mathrm{PSIL}=\frac{L_{500}+L_{1000}+L_{2000}}{3}\ \mathrm{dB}$$

$$\mathrm{SIL}_{\mathrm{ANSI}}=\frac{L_{500}+L_{1000}+L_{2000}+L_{4000}}{4}\ \mathrm{dB}$$

| 版本 | 取带 | 来源 |
| --- | --- | --- |
| **SIL（原始）** | 600~1200、1200~2400、2400~4800 Hz 三带平均 | Beranek 原始定义 |
| **PSIL（优先）** | 500、1000、2000 Hz 三个倍频程带平均 | 优先倍频程带规定后的改名 |
| **ANSI-SIL** | 500、1000、2000、4000 Hz 四带平均 | ANSI S3.14-1977（R-1986），与 ISO TR3352-1974 一致 |

三个口径同源不同标尺，手册给出的换算关系：**ANSI-SIL 大致比 Beranek 原始 SIL 高 1 dB，比 PSIL 低约 2.5 dB**。报告数据必须写明口径，相差两三个 dB 的"语言干扰级"没有可比性。

PSIL 的经典用途是查图回答"该噪声环境下，面对面交谈需要多近"。PSIL 越高，能正常交谈的距离越短——乘员舱布置、公交车驾驶区、开放式办公室的通话评估都用这套图。

## 四、Python 数值演示：相同总级、不同频谱

两组典型谱形的车内噪声：高速风噪（中高频平直）与粗糙路面轰鸣（低频滚降）。1/3 倍频程带级为手工设定的典型值，A 计权取 IEC 61672 标准值，总级按第一节的能量合成公式计算。

```python
import numpy as np

# 1/3 倍频程中心频率与 A 计权（IEC 61672 标准值，dB）
fc = np.array([100,125,160,200,250,315,400,500,630,800,1000,1250,1600,2000,2500,3150,4000,5000])
Aw = np.array([-19.1,-16.1,-13.4,-10.9,-8.6,-6.6,-4.8,-3.2,-1.9,-0.8,0,0.6,1.0,1.2,1.3,1.2,1.0,0.5])
idx = {c: k for k, c in enumerate(fc)}

# 两组典型车内噪声带级（dB）：风噪中高频平直；路面轰鸣低频滚降
wind   = np.array([30,32,34,36,38,40,42,44,45,46,46,46,46,46,46,46,45,44.])
rumble = np.array([78,76,74,70,66,62,58,54,50,46,43,41,39,38,37,36,35,34.])

dBA  = lambda L: 10*np.log10(np.sum(10**((L+Aw)/10)))                                # A 计权能量合成
psil = lambda L: (L[idx[500]] + L[idx[1000]] + L[idx[2000]]) / 3                     # PSIL 三带平均
sil4 = lambda L: (L[idx[500]] + L[idx[1000]] + L[idx[2000]] + L[idx[4000]]) / 4      # ANSI 四带平均

print(f"风噪车:  dBA = {dBA(wind):5.1f}   PSIL = {psil(wind):5.1f}   ANSI-SIL = {sil4(wind):5.1f}")
print(f"轰鸣车:  dBA = {dBA(rumble):5.1f}   PSIL = {psil(rumble):5.1f}   ANSI-SIL = {sil4(rumble):5.1f}")
print(f"轰鸣车 dBA 高 {dBA(rumble)-dBA(wind):.1f} dB，PSIL 反而低 {psil(wind)-psil(rumble):.1f} dB")
```

运行结果：风噪车 56.4 dB(A)、PSIL 45.3 dB；轰鸣车 67.1 dB(A)、PSIL 45.0 dB。轰鸣车总级高出 10.7 dB(A)，PSIL 基本持平——总级差距全部位于 500 Hz 以下，语言频带内两车相当。按总级评价轰鸣车"更吵"，按语言频带评价两车属于同一等级。

再看 AI 的物理依据：语言频带内的逐带信噪比。正常交谈 1 m 处的典型语言带级取示意值：

```python
import numpy as np

# 语言关键倍频程带：1 m 处正常交谈的典型带级（示意值）
band  = np.array([250, 500, 1000, 2000, 4000], float)
voice = np.array([53, 60, 58, 52, 46.])
# 上一组数据中与风噪同 dBA 口径的两种背景（取对应倍频程带）
wind_bg   = np.array([36, 44, 46, 46, 45.])
rumble_bg = np.array([70, 54, 43, 38, 35.])

snr_w, snr_r = voice - wind_bg, voice - rumble_bg
print(f"{'带 (Hz)':>8} {'250':>6} {'500':>6} {'1000':>6} {'2000':>6} {'4000':>6} {'平均':>7}")
print(f"{'风噪 SNR':>8} " + " ".join(f"{v:6.1f}" for v in snr_w) + f" {snr_w.mean():7.1f}")
print(f"{'轰鸣 SNR':>8} " + " ".join(f"{v:6.1f}" for v in snr_r) + f" {snr_r.mean():7.1f}")
```

运行结果：风噪车 500 Hz 带语言信噪比为 16 dB，2 kHz 带降至 6 dB、4 kHz 带仅 1 dB；轰鸣车 1 k～4 kHz 三个带均有 11～15 dB 余量，250 Hz 带则被轰鸣反超（−17 dB）。可懂度由语言频带逐带 SNR 决定——这正是 AI 逐带加权求和的物理出发点，也解释了"总级不高却需提高声级交谈"的现象。

## 五、指标选型与工程注意事项

| 指标 | 输入 | 输出 | 适用 | 局限 |
| --- | --- | --- | --- | --- |
| **AI** | 1/3 倍频程谱 | 0～100%（改良法可超 100%） | 逐带计权、与可懂度有实测曲线 | 算法口径多，结果不可直接横比 |
| **PSIL** | 500/1k/2k 三带 | dB，算术平均 | 一个数快速分级，可查通话距离图 | 只覆盖中频，4 kHz 以上不计 |
| **ANSI-SIL** | 四带含 4 kHz | dB | 计入辅音辨别关键的 4 kHz | 与 PSIL 差约 2.5 dB，口径易混 |
| **dB(A)** | 全频段计权 | dB | 法规与验收通用 | 低频被压制，与可懂度脱钩 |

::: tip 选择原则
- 免提通话、语音助手唤醒率问题 → 首选 AI 或 ANSI-SIL，把 4 kHz 带纳入
- 现场快速评估"能不能交谈"、乘员舱布局 → PSIL 查图最快
- 对外验收、法规汇报 → 仍然 dB(A)，但内部诊断要配语言频带指标交叉核对
:::

::: warning 三个常见误用
- **把 AI 当"安静度"指标**：AI 高只说明语言信息可传递，高频嘶声可以把 dB(A) 推得很高而 AI 几乎不变
- **口径不写明导致数据失效**：标准法/改良法、PSIL/ANSI-SIL、1/3 倍频程还是倍频程，任何一项不同，两个数值即不可比
- **稳态谱指标不覆盖混响和瞬态**：车内反射声、公交车到站报站的瞬态语音，都要在实际声场中复核，指标只针对背景谱
:::

## 六、小结

语言类指标和 dB(A) 是分工关系而非替代关系：dB(A) 回答"车里多吵"，AI 与 SIL 回答"话还能不能说清"。判别路径很直接——涉及语音交互的问题，先查 500 Hz～4 kHz 语言频带的带级和逐带 SNR；轰鸣问题不受总级误导，风噪问题不被总级掩盖。报告里 AI 必须注明算法口径，SIL 必须注明取带版本，否则数值没有可比性。
