# 留数与残差：模态理论里最易混的一对术语


> 模态分析报告里 Residue 和 Residual 只差两个字母，含义却是两码事：留数是模态参数家族的正式成员（频率、阻尼、振型、留数并列），残余项只是曲线拟合时补偿带外模态的修正项。把两者混为一谈的人，常在看到拟合结果表里那些"没有频率也没有阻尼的额外行"时彻底糊涂。这篇从部分分式展开把两者的来历各推一遍，再用两个数值实验分别展示"留数列就是带标尺的振型"和"残余项把窄带拟合误差从 20% 压到 2%"。

## 一、Residue 留数：每个极点前面挂着的那个复系数

多自由度结构的运动方程 $M\ddot{x} + C\dot{x} + Kx = f(t)$ 变换到拉普拉斯域后，频响函数是系统矩阵的逆：

$$H(s) = (s^2M + sC + K)^{-1} = \frac{\mathrm{adj}(B(s))}{\det(B(s))}$$

分母 $\det(B(s))$ 是 $s$ 的多项式，它的根就是系统的**极点** $\lambda_k$——每阶模态一对共轭复根 $\lambda_k = -\sigma_k + j\omega_{dk}$（$\sigma_k$ 阻尼因子，$\omega_{dk}$ 有阻尼固有频率）。有理分式的标准操作是部分分式展开：

$$H_{ij}(s) = \sum_{k=1}^{N}\left(\frac{A_{ijk}}{s-\lambda_k} + \frac{A_{ijk}^*}{s-\lambda_k^*}\right)$$

展开式里每个极点前面挂着的系数 $A_{ijk}$，数学上定义为该极点处的极限：

$$A_{ijk} = \lim_{s\to\lambda_k}\,(s-\lambda_k)\,H_{ij}(s)$$

复分析里这是洛朗展开的"残留部分"，**留数**（Residue）由此得名——它是把 $H(s)$ 在极点附近的全部信息压缩下来的那个数。响应自由度 $i$、参考（激励）自由度 $j$、模态阶次 $k$ 三个下标缺一不可：换一对激励响应点，留数就换一个值。

这个系数里装了什么？对比例阻尼的实模态走一遍解耦：令 $B(s)=\Phi[s^2 m + sc + k]\Phi^T$（$\Phi$ 为实振型矩阵，$m$、$k$ 为模态质量刚度矩阵），求逆后第 $k$ 项分母配方 $m_k s^2+c_k s+k_k = m_k(s-\lambda_k)(s-\lambda_k^*)$，部分分式系数立刻出来：

$$A_{ijk} = Q_k\,\psi_{ik}\,\psi_{jk}, \qquad Q_k = \frac{1}{2j\,m_k\omega_{dk}}$$

这就是 LMS 理论手册式 15-5 的三因子式：**留数 = 标尺常数 × 响应点振型系数 × 参考点振型系数**。三个因子各有分工——$\psi_{ik}\psi_{jk}$ 是纯几何（这阶模态在这两点上长什么样），$Q_k$ 是标尺（模态质量定多大）。激励点落在振型节点上（$\psi_{jk}=0$），留数归零，这阶模态从该 FRF 上整体消失——驱动点测量一文讲过的"丢模态"，根源就在这个乘积式上。

实模态还有个方便的副产品：$Q_k$ 是纯虚数、振型系数是实数，所以**留数是纯虚数**，全部信息集中在虚部。于是有了工程上最常用的近似——共振峰顶处留数与 FRF 虚部峰值的直接换算：

$$A_{ijk} \approx 2\,H_{ij}^{\mathrm{Im}}(\omega_{dk})$$

早期的峰拾取法（Peak Picking）就是靠这条关系，量一把虚部谱的峰高就得到整列留数，除以标尺就是振型。

::: info 核心概念
- **留数（Residue）$A_{ijk}$**：部分分式展开中极点前的复系数，$\lim_{s\to\lambda_k}(s-\lambda_k)H_{ij}(s)$；模态参数四件套（极点/频率、阻尼、振型、留数）之一
- **三因子式**：$A_{ijk} = Q_k\psi_{ik}\psi_{jk}$，$Q_k = 1/(2j\,m_k\omega_{dk})$（比例阻尼实模态、质量归一标尺）
- **量纲**：留数与 FRF 数据同量纲（柔度型 FRF 为 m/N）；振型本身无量纲，量纲由标尺常数赋予——手册特别强调这一点
- **纯虚性**：比例阻尼实模态下留数纯虚，峰顶虚部乘 2 即留数
:::

::: warning 工程注意
留数是**局部量**：依赖具体的响应自由度和参考自由度，每对 $(i,j)$ 一套。极点才是**全局量**——从结构上任意一条 FRF 拟合出来的频率和阻尼理论上相同。多输入分析里留数改写为"振型 × 模态参预因子"（Modal Participation Factor），两者单位都与留数相同，本质仍是三因子式的另一种切分。
:::

## 二、Residual 残余项：带外模态留在窄带里的影子

曲线拟合永远不会拿全频段的数据。分析频带通常只圈住关心的几阶模态，但实测 FRF 是**所有**模态贡献的总和——带外的模态一个都没缺席，只是姿态变了。

推导从"带外模态在窄带内如何退化"出发。单模态贡献写作 $A/(j\omega-\lambda) + A^*/(j\omega-\lambda^*)$，对带外**高频**模态（$\omega_k$ 远大于带上限），$j\omega$ 与阻尼项相对 $\omega_k$ 都是小量，两个分式相加后频率项相消：

$$\frac{A}{j\omega-\lambda_k} + \frac{A^*}{j\omega-\lambda_k^*} \approx -\frac{A+A^*}{\omega_k^2} = -\frac{2\,\mathrm{Re}(A)}{\omega_k^2}$$

整个分式退化成与频率无关的**常数**——高频模态在低频段表现为纯弹簧，这就是双对数图里那条斜率为零的"刚度线"。对所有高频带外模态求和，合并成一个系数 $UR$（上残余项，残余刚度 Residual Stiffness）。

带外**低频**模态（$\omega_k$ 远小于带下限）则相反，惯性项主导，贡献随 $1/\omega^2$ 走——低频段那个模态整体当刚体运动，表现为纯质量，对应斜率 -2 的"质量线"：

$$\frac{A}{j\omega-\lambda_k} + \frac{A^*}{j\omega-\lambda_k^*} \approx -\frac{A+A^*}{\omega^2} = -\frac{2\,\mathrm{Re}(A)}{\omega^2}$$

对所有低频带外模态求和合并成 $LR$（下残余项，残余质量 Residual Mass）。于是窄带拟合用的数学模型变成（LMS 手册式 15-8 的位移型 FRF 版本）：

$$h_{ij}(\omega) = \sum_{k\in\text{band}}\left(\frac{A_{ijk}}{j\omega-\lambda_k} + \frac{A_{ijk}^*}{j\omega-\lambda_k^*}\right) + UR_{ij} - \frac{LR_{ij}}{\omega^2}$$

上图是手册图 15-3 的示意：分析频带上下两侧各有一群"够不着"的模态，上残余项用一根弹簧等效它们（残余刚度），下残余项用一个质量等效它们（残余质量）。名字里的"残"指的是**带外模态残留在带内的贡献**——它是完整 FRF 减去带内模态后剩下的部分，不是拟合残差（fit residual），更不是留数的另一种写法。

::: warning 工程注意
三个常踩的坑：
- **残余项不是模态**。它没有极点、没有频率、没有阻尼，不能进振型动画，不能拿来算模态质量。它只是让带内拟合更贴数据的两个补偿系数。
- **残余项是局部量**。每对响应-参考自由度 $(i,j)$ 各有一套 $UR$、$LR$；多参考拟合时每个参考自由度生成一项（Testlab 手册 8.13.3 节），别指望全结构共用一个"残余刚度"。
- **别拿残余项外推**。$UR$、$LR$ 只在拟合频带内有效——它们是带外模态在**这段窄带**的泰勒近似，离开这段频率，$1/\omega^2$ 的形状立刻对不上。
:::

## 三、一张表分清两个术语

| | **留数 Residue** | **残余项 Residual** |
| --- | --- | --- |
| **身份** | 模态参数四件套成员 | 曲线拟合补偿项，不是模态参数 |
| **数学来源** | 部分分式极点前系数 $\lim_{s\to\lambda_k}(s-\lambda_k)H_{ij}(s)$ | 带外模态的窄带近似：常数（刚度）+ $1/\omega^2$（质量） |
| **物理对应** | 振型系数 × 参考点振型系数 × 标尺 $Q_k$ | 高频带外模态 ≈ 残余刚度 $UR$；低频带外模态 ≈ 残余质量 $LR$ |
| **每阶模态个数** | 每对 $(i,j)$ 每阶一个复数 | 与模态阶数无关，每对 $(i,j)$ 上、下各一 |
| **量纲** | 与 FRF 相同（m/N 等，由标尺赋予） | 与 FRF 相同 |
| **全局/局部** | 局部（依赖 $i,j$） | 局部（依赖 $i,j$，多参考时按参考点分） |
| **典型用途** | 振型、模态参预、模态质量标定、强迫响应综合 | 改善带内拟合、让综合 FRF 在带外趋势正确 |

一个记忆钩子：**留数带阶次下标 $k$，残余项不带**——前者属于某阶模态，后者属于某个频带。

## 四、Python 演示：留数列就是带标尺的振型

两自由度系统，$M$、$K$ 已知。质量归一化后模态质量为 1，留数矩阵有闭式解 $A_k = \psi_k\psi_k^T/(2j\omega_{dk})$。把留数矩阵的一列（固定参考点）按参考点归一化，应当精确还原振型向量——这正是"锤击测一行、激振器测一列都能得到振型"的数学根据：

```python
import numpy as np

# 两自由度系统：留数列按参考点归一后应严格还原振型（留数=带标尺的振型）
M = np.array([[2.0, 0.0], [0.0, 1.0]])
K = np.array([[900.0, -400.0], [-400.0, 500.0]])
w2, V = np.linalg.eigh(np.linalg.solve(M, K))     # 固有频率平方与振型
V = V / np.sqrt(np.diag(V.T @ M @ V))            # 质量归一：模态质量=1
print("固有频率:", np.round(np.sqrt(w2)/(2*np.pi), 2), "Hz")

zeta = 0.01
for k in (0, 1):
    wd = np.sqrt(w2[k]) * np.sqrt(1 - zeta**2)
    Ak = np.outer(V[:, k], V[:, k]) / (2j * wd)   # 第k阶留数矩阵
    col = (Ak[:, 0] / Ak[0, 0]).real              # 留数列，按参考点0归一
    shape = V[:, k] / V[0, k]                     # 理论振型，同样归一
    print(f"模态{k+1}: 留数列 = {np.round(col, 4)}, 振型 = {np.round(shape, 4)}, "
          f"最大偏差 {np.abs(col - shape).max():.2e}")
```

运行结果：

```text
固有频率: [1.37 4.71] Hz
模态1: 留数列 = [ 1.      0.9395], 振型 = [ 1.      0.9395], 最大偏差 0.00e+00
模态2: 留数列 = [ 1.     -1.0645], 振型 = [ 1.     -1.0645], 最大偏差 0.00e+00
```

两阶模态的留数列归一化后与振型**一位不差**（偏差在机器精度量级以下）。留数列比振型多的那个因子——标尺乘以参考点振型系数——在归一化时被除掉了：振型只能给"形状"，留数才带"绝对刻度"。顺带一提，把列换成行（按参考点归一化留数行）结果相同，留数矩阵对称就是 FRF 互易性的直接体现。

## 五、Python 演示：残余项如何拯救窄带拟合

三自由度系统，固有频率 31.1 / 63.8 / 95.6 Hz。分析频带取 40~90 Hz——只圈住模态 2，模态 1 压在带下沿之外、模态 3 顶在带上沿之外。极点假设已精确估出，分别用"纯单模态模型"和"加上下残余项的模型"做最小二乘：

```python
import numpy as np

# 三自由度：只在 40~90 Hz 带内拟合模态 2，看带外模态 1、3 的"残余"影响及补偿
M = np.eye(3)
K = np.diag([40000.0, 160000.0, 360000.0]) \
    - np.eye(3, k=1)*15000.0 - np.eye(3, k=-1)*15000.0
w2, V = np.linalg.eigh(np.linalg.solve(M, K))
print("三阶固有频率:", np.round(np.sqrt(w2)/(2*np.pi), 1), "Hz   分析频带: 40~90 Hz")

f = np.linspace(40, 90, 1001); s = 2*np.pi*f*1j
C = 0.5*M + 2e-4*K                                # 瑞利阻尼
H = np.array([np.linalg.inv(M*si**2 + C*si + K)[1, 0] for si in s])  # "实测"FRF

zt = (0.5/np.sqrt(w2[1]) + 2e-4*np.sqrt(w2[1])) / 2
lam = -zt*np.sqrt(w2[1]) + 1j*np.sqrt(w2[1])*np.sqrt(1-zt**2)
X0 = 1/(s-lam) + 1/(s-np.conj(lam))               # 单模态基函数（留数项）
ref = np.abs(H[np.argmax(np.abs(H))])

cA, *_ = np.linalg.lstsq(X0[:, None], H, rcond=None)             # 方案A：纯留数
errA = np.sqrt(np.mean(np.abs(H - X0*cA[0])**2)) / ref

XB = np.column_stack([X0, np.ones(f.size), -1.0/(2*np.pi*f)**2]) # 方案B：+UR -LR/w^2
cB, *_ = np.linalg.lstsq(XB, H, rcond=None)
errB = np.sqrt(np.mean(np.abs(H - XB @ cB)**2)) / ref
print(f"模态2 阻尼比 = {zt:.3f}")
print(f"纯单模态拟合     相对误差: {errA*100:5.2f} %")
print(f"加上、下残余项后 相对误差: {errB*100:5.2f} %  -> 降到原来的 {errB/errA*100:.0f}%")
print(f"  残余刚度 UR = {cB[1].real:.3e}, 残余质量 LR = {cB[2].real:.3e}")
```

运行结果：

```text
三阶固有频率: [ 31.1  63.8  95.6] Hz   分析频带: 40~90 Hz
模态2 阻尼比 = 0.041
纯单模态拟合     相对误差: 20.46 %
加上、下残余项后 相对误差:  1.97 %  -> 降到原来的 10%
残余刚度 UR = 4.188e-07, 残余质量 LR = 3.078e-01
```

最值得看的是 20.46% 到 1.97% 这一跳：带外两个模态的"影子"贡献了纯单模态模型五分之一的误差，两个补偿系数就把它吃掉了。再看系数本身——$LR=0.31$ 远大于 $UR=4\times10^{-7}$：模态 1（31.1 Hz）离带下沿只有 9 Hz，质量线尾巴拖得重；模态 3（95.6 Hz）离上沿稍远且刚度线本身平坦，所以残余刚度小。**哪个残余项大，就说明哪一侧的带外模态离得更近、影响更重**——这也是判断分析频带选得好不好的一个诊断信号。

## 六、Testlab 里的对应位置

Simcenter Testlab 模态拟合的参数面板把这对术语直接摆在你面前：

- **Residue type**：留数取 Complex 还是 Real。手册建议默认 Complex——真实机械结构理应拟出接近实数的模态，若 Complex 拟合结果虚部很小，这本身就是拟合质量的旁证；Real 选项留给与无阻尼有限元振型对比这类特定场景。
- **Upper residuals / Lower residuals** 勾选框：即残余刚度与残余质量项，勾上后每个参考自由度各生成一项，随留数一起最小二乘解出（LSFD 法，手册 15.3.6 节）。
- 拟合结果表里那些只挂数值、没有频率阻尼的行就是残余项，振型动画里不会出现它们。

留数一侧的工具更值钱：第 18 章的**模态参预**分析把某阶模态对所有参考点的留数求和，留数和最大的参考点就是这阶模态的最佳激励点；对全部模态做留数求和再横向比较，就能定量评估一套参考点布置对整体试验的激励效率——比"凭经验挪激振器"有依据得多。

::: tip 实用建议
- 分析频带贴近强带外模态（比如车身一阶刚体模态离弹性模态很近）、或带内阻尼大峰形不对称时，勾上上下残余项，拟合误差常能降一个量级
- 带外模态离得很远（上下一两个倍频程开外）时残余项基本失效，勾不勾差别不大，不必执着
- 报告里报振型用留数归一化结果没问题；但综合 FRF、算模态质量时，务必带上残余项，否则带外趋势整段错
- 留数是复数就让它复着——直接把复留数"读成"振型幅值而丢掉相位，密频或非比例阻尼结构会得到面目全非的振型
:::

## 七、小结

判断标准一句话就够：**带阶次下标的是留数，不带的是残余项**。留数是部分分式里极点前的系数、三因子式给出的带标尺振型，属于模态参数；残余项是带外模态在窄带内的影子——上残余当弹簧、下残余当质量，只服务于拟合精度。下次打开拟合结果表，先看那些"没有频率的行"挂在哪个位置：挂在残差补偿区的是残余项，挂在模态参数区还带共轭对的，才是留数。
