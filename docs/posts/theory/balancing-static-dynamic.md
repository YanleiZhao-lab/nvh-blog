# 动平衡：静平衡、耦合平衡与动平衡

> 传动轴异响、电机转子电磁噪声、飞轮抖动，背后常常是同一个物理原因：质量分布绕旋转轴不均。静平衡、耦合平衡、动平衡不是三套独立技术，而是质量轴与旋转轴三种不同的空间错位关系——关系不同，校正平面的数量就不同。读懂这个几何关系，平衡机两端配重"既不同相也不反相"的数据就不再神秘。

## 一、不平衡从哪来：质量轴与旋转轴的错位

一个转子绕轴旋转时，如果质量绕轴分布不均匀，质心（COG）就会偏离旋转中心。旋转时偏心质量产生离心力，作用在轴承和支承结构上——这就是不平衡（Unbalance）。

更本质的说法：每个转子都有一条**主质量轴**（principal mass axis），绕它旋转时不产生净离心力。平衡的目标，就是让这条质量轴与实际旋转轴重合。

不平衡不是只有"制造粗糙"一条路，实际工程里的成因五花八门：

| 成因 | 机理 | 典型场景 |
| --- | --- | --- |
| **质量不对称** | 结构本身绕轴不均匀 | 法兰、键槽、铸造缩孔 |
| **轴不直** | 制造弯曲，或使用中弹性变形 | 长传动轴、曾经磕碰的半轴 |
| **配合间隙** | 万向节、花键、轴承游隙让轴偏离中心 | 磨损后逐渐加剧的抖动 |
| **弯曲共振** | 工作转速激起弯曲模态，轴在旋转中变形 | 运行在临界转速附近的转子 |

不平衡的后果不只是"抖"：振动带来的噪声、轴承寿命衰减、传动效率损失，最终还会演变成安全隐患。振动烈度压不下来的整改，平衡往往是最先该查的一项。

::: info 核心概念
- **不平衡量 U**：U = M·e = m·r，转子总质量×质心偏距 = 不平衡质量×其半径，单位是 [质量]×[距离]，常用克·厘米（gm·cm）与盎司·英寸（oz·in）
- **离心力 F**：F = U·w²，w 为角速度（rad/s）——力与不平衡量成正比，与转速平方成正比
- **主质量轴**：转子绕之旋转不产生净离心力的惯性轴，平衡即让质量轴与旋转轴重合
:::

## 二、三种不平衡：质量轴与旋转轴的三种几何关系

### 静不平衡（Static，单面）

质量轴与旋转轴**平行错开**。相当于整个转子的质心整体偏向一侧，旋转时各截面的离心力指向同一个方向，合成一个作用于质心平面的合力。

![静不平衡：质量轴与旋转轴平行错开](/images/balancing-static-dynamic/fig5-static-unbalance.png)
*（图源：Simcenter Testing Knowledge Base）*

![不平衡公式各项的几何含义：轴截面上的不平衡质量与偏心距](/images/balancing-static-dynamic/fig6-unbalance-terms.png)
*（图源：Simcenter Testing Knowledge Base）*

静不平衡最直观：转子架起来不转，重的一侧自然转向下方——不启动就能"静态"发现，这也是名字的由来。校正只需在**一个平面**上加去重或配重，把质心拉回旋转轴，使偏心距 e 归零。

### 耦合不平衡（Coupled，双面）

两个平面上各有一个**等量的不平衡质量，相位相差 180 度**。合成质心仍然落在旋转轴上（静不平衡为零），但旋转时两个等大反向的离心力组成一对力偶，让转子在旋转中不断"点头"摆动。

![耦合不平衡：两个质量位于不同平面、相位相差180度](/images/balancing-static-dynamic/fig8-coupled-unbalance.png)
*（图源：Simcenter Testing Knowledge Base）*

耦合不平衡的隐蔽性比静不平衡强：静止时没有任何征兆，低速时力偶也不明显，转速升高后摆动才显形。校正必须在**两个平面**上配重，单面无解——力偶无法靠一个平面上的合力抵消。

### 动不平衡（Dynamic，双面）

实际转子最常见的不平衡形态，是静不平衡与耦合不平衡的**叠加**：质量轴与旋转轴既不平行，也不相交。

![动不平衡是静不平衡与耦合不平衡的组合](/images/balancing-static-dynamic/fig9-dynamic-unbalance.png)
*（图源：Simcenter Testing Knowledge Base）*

表现上，转子一边承受合成离心力，一边承受力偶矩，运行时整体倾摆（tilt / wobble）。校正同样需要两个平面。

| 类型 | 质量轴 vs 旋转轴 | 离心力合成 | 校正平面 |
| --- | --- | --- | --- |
| **静不平衡** | 平行错开 | 单平面合力 | 1 个 |
| **耦合不平衡** | 相交于质心 | 纯力偶、合力为零 | 2 个 |
| **动不平衡** | 既不平行也不相交 | 合力 + 力偶 | 2 个 |

::: warning 工程注意
平衡机打出的两面配重，角度往往既不同相也不反相——那是静分量与耦合分量矢量叠加的结果，不是数据乱了。反过来，只做单面平衡等于默认耦合分量为零，对传动轴、电机转子这类长转子是致命简化；而且低速下平衡合格的转子，高速下离心力按平方放大，耦合分量照样把振动顶起来。
:::

## 三、离心力：转速才是主变量

不平衡的危害程度由离心力 F = U·w² 决定。两个规律值得刻在脑子里：不平衡量翻倍，离心力翻倍；**转速翻倍，离心力翻四倍**。

![不平衡量与转速增大时离心力的变化](/images/balancing-static-dynamic/fig7-force-vs-rpm.png)
*（图源：Simcenter Testing Knowledge Base）*

```python
import numpy as np

# 不平衡量 U = 10 gm·cm，换算成国际单位 kg·m
U = 10.0 * 1e-5              # 1 gm·cm = 1e-5 kg·m

# 不平衡质量本身的重力：10 gm 放在 1 cm 半径处
gravity = 10e-3 * 9.81

print(f"不平衡质量自身重力: {gravity:.3f} N")
print(f"{'转速(rpm)':>10} {'离心力(N)':>10} {'重力倍数':>8}")
for rpm in [1500, 3000, 6000, 12000]:
    w = rpm * 2 * np.pi / 60     # 角速度 rad/s
    F = U * w**2                 # F = U*w^2
    print(f"{rpm:>10} {F:>10.1f} {F/gravity:>8.0f}")
```

输出里最该看的数字：转速从 3000 提到 6000，离心力从 9.9 N 涨到 39.5 N，正好四倍；到 12000 rpm 时，10 克质量偏置产生的离心力已达到它自身重力的 1600 倍左右。几克的偏置在高转速下足以主导轴承载荷——这就是电动车驱动电机转子对平衡精度远比传统件苛刻的物理原因。

## 四、两面配重怎么算：动不平衡的分解

平衡机双面测量拿到的是两个平面上的不平衡相量（幅值+相位）。任意两面的不平衡，都可以唯一分解为一对**同相的静不平衡分量**和一对**反相的耦合不平衡分量**：

```python
import numpy as np

# 两个校正平面测得的不平衡相量 (gm·cm)，角度单位为度
U1 = 20.0 * np.exp(1j * np.deg2rad(0))
U2 = 12.0 * np.exp(1j * np.deg2rad(150))

# 分解：静分量两平面同相，耦合分量两平面反相
U_static = (U1 + U2) / 2      # 静不平衡分量
U_couple = (U1 - U2) / 2      # 耦合不平衡分量（平面1处）

print(f"{'分量':<10} {'幅值(gm·cm)':>10} {'相位(deg)':>10}")
for name, U in [("平面1实测", U1), ("平面2实测", U2),
                ("静不平衡", U_static), ("耦合不平衡", U_couple)]:
    print(f"{name:<10} {abs(U):>10.2f} {np.rad2deg(np.angle(U)):>10.1f}")

# 校验：两个分量重新合成，应还原平面1的实测值
print(f"还原校验: 静+耦合 = {abs(U_static + U_couple):.2f} 应等于 {abs(U1):.2f}")
```

这组数据值得注意的一点：两端实测 20 和 12 gm·cm 看着都不大，分解后耦合分量约 15.5 gm·cm，远大于静分量的约 5.7 gm·cm——这个转子的问题主要出在力偶上。这也解释了为什么双面平衡"缺一不可"：抽掉任何一个校正平面，耦合分量就无处安放。

## 五、单面校正还是双面校正

校正平面（correction plane）是转子上加/去重的具体截面位置。选单面还是双面，取决于不平衡的形态：

![单校正平面与双校正平面在轴上的位置](/images/balancing-static-dynamic/fig10-single-dual-plane.png)
*（图源：Simcenter Testing Knowledge Base）*

**单面平衡**只在转子的一个平面上加配重，原理上只能消除静不平衡——它对力偶无能为力。适合轴向尺寸短、不平衡基本集中在单个截面的盘类零件：飞轮、离合器压盘总成、冷却风扇叶轮。

**双面平衡**在转子的两个平面上各加一组配重，静不平衡、耦合不平衡、动不平衡都能覆盖，适用于传动轴、曲轴总成、驱动电机转子这类长转子。两种平衡的操作流程差别不大，Simcenter Testlab 的平衡应用同时提供单面与双面方案。

::: tip 选择原则
- 盘类短转子、只在端面有配重条件 → 单面平衡
- 长转子（传动轴、电机转子、曲轴）→ 一律双面
- 拿不准时选双面：静不平衡只是动不平衡的特例（两平面不平衡同相等量），双面方案天然覆盖
:::

## 六、小结

不平衡量 U = M·e，单位 [质量]×[距离]；离心力 F = U·w²，转速翻倍力翻四倍——转速越高的转子，对平衡精度越敏感。判断校正平面数量只需看质量轴与旋转轴的关系：平行错开是静不平衡，单面可解；相交是耦合不平衡，必须双面；既不平行又不相交是最常见的动不平衡，同样双面。平衡机两端配重角度"不伦不类"，是静分量与耦合分量矢量叠加的正常结果，别当成坏数据修掉。
