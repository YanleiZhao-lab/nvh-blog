# 模态试验与 CAE 对标怎样组织验证记录

> 有限元（Finite Element Analysis，FEA）模型能否反映结构的动力学特性，必须通过模态试验对标来回答。一套可追溯、可复用的验证记录，既是模型可信度的证据，也是后续设计迭代和问题排查的基础。本文整理 CAE 模型验证的完整流程、关键参数、相关性指标的计算和报告结构，表述对齐 Simcenter Testing 理论手册第十八章"模态验证"。

## 一、验证流程总览

CAE 模型验证不是"算完对一下频率"就结束，而是一个闭环流程：

```text
试验规划 → 测点布置 → 模态试验 → 参数提取
    ↕
模型构建 → 边界/材料 → 求解 → 频率/振型提取
    ↘___________________________↙
         相关性分析 (MAC / 频率对比)
              ↕
        偏差定位 → 模型修正 → 复核
```

::: tip 核心原则
验证记录的目标是"让别人能复现你的结论"。每一步的输入、参数、输出都要落地为文件，而不是存在分析师的脑子里。
:::

## 二、边界条件与材料参数

边界条件和材料参数是 CAE 结果偏离试验最常见的原因，必须显式记录。

| 类别 | 需记录字段 | 典型问题 |
| --- | --- | --- |
| **约束边界** | 自由/固支/弹性支撑、约束位置 | 自由边界用悬挂，弹性支撑需测刚度 |
| **连接** | 焊点、螺栓、胶接、铰链的等效方式 | 螺栓刚度简化过度导致局部模态偏移 |
| **材料** | 密度 ρ、弹性模量 E、泊松比 ν、阻尼 | E 取名义值而未用实测，频率整体偏移 |
| **网格** | 单元类型、尺寸、质量指标 | 网格过粗使高阶模态漏掉 |
| **求解** | 特征值方法（Lanczos/Subspace）、频率范围 | 截断频率不足，遗漏目标模态 |

自由—自由（free-free）边界是模态试验最常用的支承方式。理论手册第十九章指出，柔性支承结构的频响函数在低频段呈现"质量线"，反映结构的惯性制约力，据此可反算质量、质心与转动惯量等刚体属性；反过来，悬挂是否足够"软"，可用刚体模态频率来核对——刚体六阶模态应集中在接近 0 Hz 的频段内，且与第一阶弹性模态之间留出足够间隔（工程上至少一个数量级），否则悬挂刚度会污染低阶弹性模态。

![由测量的 FRF 推算刚体属性的流程：质量线反映惯性制约力，可反算质量、质心与转动惯量（图源：Simcenter Testing 理论手册 图 19-1）](/images/cae-validation/rigid-body-from-frf.png)

::: warning 常见陷阱
阻尼参数在模态分析阶段通常不输入（求无阻尼特征值），但在频响（FRF）验证时必须给出。阻尼来源（材料/连接/声辐射）不同，等效方式也不同，不能一概用 0.5%。
:::

## 三、模态试验与参数提取

试验侧需记录的关键信息：

```python
# 模态试验记录数据结构示例
modal_test_record = {
    "test_date": "2026-08-05",
    "specimen": "前副车架焊接总成",
    "boundary": "自由-自由（橡皮绳悬挂）",
    "excitation": "力锤（8 kHz 采样，硬塑料锤头）",
    "reference_points": ["P03", "P07"],   # 至少 2 个参考点
    "response_points": 42,                 # 总测点数
    "bandwidth_hz": 2000,
    "lines": 3200,
    "averages": 8,
    "window": "force/exponential",
    "extracted_modes": [
        {"mode": 1, "freq_hz": 86.3,  "damping_pct": 0.42},
        {"mode": 2, "freq_hz": 134.7, "damping_pct": 0.61},
        {"mode": 3, "freq_hz": 212.5, "damping_pct": 0.88},
    ],
}
```

::: tip 参考点选择
参考点必须避开目标模态的节点位置。建议先用两个不同位置的参考点预试验，确认各阶模态在两个参考点下都能被激发，避免"漏模"。
:::

模态数与重根（多重根）的核对，可用模态指示函数（Modal Indicator Function，MIF）辅助：对每一参考自由度可算出一条 MIF，第一 MIF 在每个固有频率处都出现局部极小，第二 MIF 仅在存在重根时才出现局部极小；若存在四重根，则第一至四阶 MIF 都会在重根频率处呈现局部极小（理论手册 18.9 节）。测点数量是否足以分离各阶模态，则用 AutoMAC 非对角元素检验（见下节）。

![模态指示函数 MIF：第一 MIF 在每个固有频率处局部极小，高阶 MIF 仅在重根处出现极小，可据此判断重根阶数（图源：Simcenter Testing 理论手册 18.9 节）](/images/cae-validation/mif-repeated-roots.png)

## 四、相关性分析：MAC 与频率对比

### 4.1 MAC（模态置信判据）的定义与推导

模态置信判据（Modal Assurance Criterion，MAC）是衡量试验振型与计算振型一致性的核心指标。它可以从向量几何关系分三步导出。

**第一步：振型即复向量。** n 个测点拟合出的振型是一个 n 维复向量 $\boldsymbol{\varphi} \in \mathbb{C}^{n}$，上标 $H$ 表示复共轭转置。物理意义：振型描述各测点同频运动的幅值与相位分布。

**第二步：以内积度量逐点吻合。** 两个振型 $\boldsymbol{\varphi}_t$（试验）与 $\boldsymbol{\varphi}_c$（计算）的复内积为 $\boldsymbol{\varphi}_t^{H}\boldsymbol{\varphi}_c$，它对每个测点的幅值与相位差异同时敏感。若两振型只差一个复数比例常数（模态振型本身的标尺不唯一，这是模态理论的固有性质），则内积的模达到最大。

**第三步：用各自模长归一化。** 分子除以两个向量各自模长的乘积并取模平方，得到 MAC：

$$
\mathrm{MAC}_{tc} = \frac{\left|\boldsymbol{\varphi}_{t}^{H}\boldsymbol{\varphi}_{c}\right|^{2}}{\left(\boldsymbol{\varphi}_{t}^{H}\boldsymbol{\varphi}_{t}\right)\left(\boldsymbol{\varphi}_{c}^{H}\boldsymbol{\varphi}_{c}\right)}
$$

几何意义：MAC 等于两向量夹角余弦的平方，取值范围 $[0,1]$，且对任意复数缩放不敏感——试验换一组传感器灵敏度、换一个参考点导致振型整体差一个比例因子，不影响 MAC 取值。这正是它适合作对标指标的原因（理论手册 18.2 节，Eqn 18-5）。

与 MAC 搭配的模态比例因子（Modal Scale Factor，MSF）给出两振型间的最小二乘复比例常数（Eqn 17-12）：

$$
\mathrm{MSF}_{tc} = \frac{\boldsymbol{\varphi}_{t}^{H}\boldsymbol{\varphi}_{c}}{\boldsymbol{\varphi}_{t}^{H}\boldsymbol{\varphi}_{t}}
$$

MSF 回答"差多少倍"，MAC 回答"这个倍数关系是否成立"：两向量线性相关时 MSF 即比例常数、MAC 接近 1；线性独立时 MAC 接近零、MSF 无工程意义。

理论手册还给出 MAC 的第二个应用：检验振型对质量矩阵的加权正交性（Eqn 18-7）——

$$
\boldsymbol{\varphi}_{k}^{T} M \boldsymbol{\varphi}_{l} = m_{k} \;\; (k = l), \qquad \boldsymbol{\varphi}_{k}^{T} M \boldsymbol{\varphi}_{l} = 0 \;\; (k \neq l)
$$

其中 $m_k$ 为第 k 阶模态质量。将试验振型扩展到有限元自由度（或将有限元模型缩聚到测点自由度）后，可用有限元质量矩阵检验试验振型之间的正交性；质量矩阵未知时，若近似取元素大致相等的对角阵，不同模态间 MAC 值很小即近似等价于正交性成立。

工程判读（手册指出对应模态的 MAC 应接近 100%，以下为常用分档）：

- **MAC > 0.9**：振型一致性好，认为试验与计算对应同一阶模态
- **0.7 < MAC < 0.9**：基本一致，需检查局部测点与振型细节
- **MAC < 0.7**：振型不一致，可能模态顺序错乱或模型有误

对角线元素确认"哪阶对哪阶"，非对角元素检验"各阶能否分开"。区分真共振峰与振型交叉点也是 MAC 的经典用法：两条复模态指示函数（Complex Mode Indicator Function，CMIF）曲线在两个共振峰之间交叉时，高阶 CMIF 会出现小峰——用交叉频率两侧数据计算 MAC 矩阵，接近幺矩阵（单位阵）说明是共振峰、模态未变；反对角形式则说明是交叉点、模态发生交换（理论手册 15.3.4 节，图 15-10）。

![跟踪一阶与二阶 CMIF：MAC 矩阵接近幺阵表明 CMIF2 的峰为共振峰，反对角形式则表明为振型交叉点（图源：Simcenter Testing 理论手册 图 15-10）](/images/cae-validation/cmif-tracking.png)

### 4.2 频率偏差

$$
\Delta f\% = \frac{f_{\mathrm{CAE}} - f_{\mathrm{test}}}{f_{\mathrm{test}}} \times 100\%
$$

$\Delta f\%$ 为正说明计算频率偏高，通常指向刚度偏大或质量偏小；为负则相反。频率对比与 MAC 必须同时给出：

| 模态 | 试验频率 (Hz) | CAE 频率 (Hz) | Δf% | MAC | 判定 |
| --- | --- | --- | --- | --- | --- |
| 1 | 86.3 | 88.1 | +2.1% | 0.95 | 通过 |
| 2 | 134.7 | 131.2 | -2.6% | 0.88 | 关注 |
| 3 | 212.5 | 198.4 | -6.6% | 0.52 | 不通过 |

::: warning MAC 高 ≠ 频率对
MAC 只反映振型形状的相似度，不含频率信息。可能出现 MAC=0.95 但频率偏 15% 的情况，说明刚度或质量分布有系统偏差。必须频率和 MAC 同时看。
:::

### 4.3 频响函数（FRF）对比

除了模态参数，直接对比频响曲线能发现局部动力学问题。理论手册 18.10/18.11 节给出两个配套工具：**FRF 累加**——将各测点 FRF 的实部与虚部分别取绝对值求和再合成，用于核对拟合频率与实测共振峰是否吻合、发现丢失模态或传感器附加质量引起的频率偏移；**FRF 综合**——由模态模型（含标尺的振型与模态参预因子）反算 FRF，再与实测 FRF 逐谱线计算相关性与误差。

```python
# FRF 对比的简化记录
frf_comparison = {
    "driving_point": "P07+Z",
    "f_test":  "frf_test_P07z.txt",    # 试验 FRF
    "f_cae":   "frf_cae_P07z.txt",     # 计算 FRF
    "freq_range": [0, 2000],           # Hz
    "metrics": {
        "peak_freq_error_pct": 2.3,
        "peak_amp_error_db": 1.8,
        "freq_domain_assurance_criterion": 0.87,  # FDAC
    },
}
```

## 五、验证报告结构

一份可追溯的 CAE 验证报告应包含以下章节：

1. **试验概述** — 对象、日期、设备、环境
2. **测点布置图** — 坐标、编号、参考点标注
3. **CAE 模型说明** — 软件/版本、网格统计、材料、边界、单元类型
4. **频率与振型对比表** — 含 Δf% 与 MAC
5. **FRF 曲线对比** — 关键测点，含峰值与相位
6. **偏差分析** — 不通过项的原因定位（连接？材料？边界？）
7. **模型修正记录** — 改了什么、为什么改、改后结果
8. **结论与置信度** — 模型在哪个频段可信、可用于哪类分析
9. **附件** — 原始数据文件、求解输入文件、脚本

按理论手册第十八章的验证工具清单，报告中还应纳入试验自身的质量证据：驱动点 FRF 的互易性（Reciprocity）检查、模态相位共线性（Modal Phase Collinearity，MPC）与平均相位偏差（Mean Phase Deviation，MPD）——实正则模态的 MPC 应接近 100%、MPD 接近 0°，数值异常提示局部阻尼元件或不良测量，应在与 CAE 对标之前先行处理。

::: tip 沉淀为模板
建议把上述结构固化成报告模板（Word 或 Markdown），每次验证直接填充。长期下来，模型修正经验和常见偏差原因也会积累成知识库，新人能快速上手。
:::

## 六、工程意义

CAE 模型一旦通过验证，其价值远超单次分析：

- **设计阶段** 预测结构动态特性，减少物理样机
- **问题排查** 基于可信模型做灵敏度分析，定位优化方向
- **传递路径分析（TPA）** 用验证过的模型生成逆矩阵
- **优化迭代** 在可信频段内做拓扑/尺寸优化

::: warning 范围声明
模型验证结论有**频段适用范围**。在 0–500 Hz 验证通过的模型，不代表 2000 Hz 的局部模态可信。每次使用都要声明模型的验证频段。
:::
