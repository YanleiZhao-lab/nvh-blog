# NVH指标体系与工程解释

> NVH（Noise、Vibration、Harshness）是汽车、机械、消费电子等领域衡量产品声振品质的核心工程体系。本文整理常用 NVH 指标的定义、计算方法和工程含义，数值与判据以心理声学理论手册（LMS 声学理论篇）及 SimCenter 手册为准，供日常分析参考。

## 一、客观指标 vs 主观指标

NVH 评价分为几类互补的层次：

| 类别 | 指标示例 | 特点 |
| --- | --- | --- |
| **客观指标** | 声压级 SPL、阶次、频谱 | 可仪器测量，数值可复现 |
| **心理声学指标** | 响度、尖锐度、粗糙度 | 基于人耳感知模型，半客观 |
| **主观评价** | 烦扰度、偏好评分 | jury test，统计学分析 |

::: tip 工程建议
单一指标无法完整描述 NVH 问题。建议以客观指标定位问题频率/来源，以心理声学指标评估感知严重度，以主观评价验证最终效果。
:::

## 二、声学基础指标

### 2.1 声压级（Sound Pressure Level, SPL）

声压级分两步从声压定义导出。

**第一步：取有效值。** 传声器测得的是时域声压信号 $p(t)$（媒质压强相对静压的偏离，单位 Pa）。评价稳态强弱用的是与信号能量对应的有效值（RMS）：

$$p_{\mathrm{rms}} = \sqrt{\frac{1}{T}\int_0^T p^2(t)\,\mathrm{d}t}$$

物理意义：均方根对应平均声能量，是稳态声强弱的度量。

**第二步：取对数。** 人耳可听声压跨越约 6 个数量级，正常听力者在 1 kHz 的平均听阈为 $p_0 = 20\ \mu\mathrm{Pa}$（标准化额定听阈）。听感强度近似随刺激量的比值变化，故按对数标尺定义声压级：

$$L_p = 20\,\lg\frac{p_{\mathrm{rms}}}{p_0}\quad(\mathrm{dB})$$

系数取 20 而非 10，是因为声压是场量，其平方才正比于声能量；$20\lg(p/p_0)$ 等价于对声压平方之比取 $10\lg$。

```python
import numpy as np

# 计算声压级
def calc_spl(rms_pressure, ref_pressure=20e-6):
    """计算声压级 SPL (dB)
    rms_pressure: 声压有效值 (Pa)
    ref_pressure: 参考声压 20 μPa (空气中)
    """
    spl = 20 * np.log10(rms_pressure / ref_pressure)
    return spl

# 示例：1 Pa 的声压对应 94 dB
p_rms = 1.0
print(f"SPL = {calc_spl(p_rms):.1f} dB")
# 输出: SPL = 94.0 dB
```

A 计权声压级在实践中与主观反应相关性好：按理论手册，A 计权曲线近似为 40 方等响曲线的倒置，B、C 计权则分别相当于 70 方与 100 方等响曲线的倒置。

### 2.2 倍频程（Octave）分析

将宽带噪声按倍频程或 1/3 倍频程划分，是噪声标准限值常用的表达方式。相邻频带中心频率按固定比值规定（理论手册 §4.3）：

$$f_{c,\,i+1} = 2^{x}\,f_{c,\,i}\,,\quad x \in \{1,\,1/3,\,1/12,\,1/24,\dots\}$$

每个 $1/x$ 倍频程带的下限、上限频率以中心频率表示为：

$$f_{l} = f_c\,2^{-1/(2x)}\,,\qquad f_{u} = f_c\,2^{+1/(2x)}$$

由此算得的称为自然（natural）频率，用于计算；工程标注采用标准化中心频率（如 31.5、63、125 Hz 等），两者可能略有出入。

| 倍频程中心频率 (Hz) | 范围 | 典型关注场景 |
| --- | --- | --- |
| 31.5 | 22-44 | 低频轰鸣 |
| 125 | 89-141 | 发动机怠速 |
| 500 | 354-707 | 路面噪声主能量 |
| 2000 | 1414-2828 | 高频啸叫 |

## 三、心理声学指标

### 3.1 响度（Loudness, sone）

**响度级（Loudness Level, phon）。** 等响曲线（ISO 226）由大量心理声学试验得出，描述纯音响度感觉随频率和声压级的变化。给定频率、给定声压级的纯音与 1 kHz 参考纯音比较得到的值称为响度级，单位为方（phon）：对 1 kHz 纯音，phon 数值就等于 SPL 的 dB 值。

![等响曲线：同一响度级下各频率所需声压级连成的曲线簇](/images/nvh-metrics/fig6-2-equal-loudness.png)

**响度（线性标尺）。** phon 是对数标尺，由它导出的线性感知标尺为响度，单位为宋（sone）。理论手册给出换算式（式 7-2）：

$$S = 2^{(P-40)/10}\quad(\mathrm{sone})$$

物理意义：1 sone 对应 40 phon；响度级每升高 10 phon，sone 值加倍，主观感受约成"两倍响"。

**特定响度（Specific Loudness）。** 对宽带声或多音声，响度按临界频带（Critical Band）分布表示，临界频带率以巴克（Bark）计，此时采用"特定响度/局部响度"，单位为 sone/Bark。

**标准算法。** 稳态声的响度计算有 ISO 承认的两种经典方法：

- **Stevens 法**（ISO 532A）：以倍频程带声压级为起点，将各频带声压级转换为响度指数，再计及掩蔽效应综合为总响度（式 7-3）：

$$S_t = S_m + F\left(\sum_i S_i - S_m\right)$$

其中 $S_m$ 为最大响度指数，$F$ 为反映掩蔽效应的贡献因子：1/1 倍频程取 0.3，1/3 倍频程取 0.15。该法仅适用于扩散场中相对平稳的宽带噪声。

- **Zwicker 法**（ISO 532B，现行 ISO 532-1）：以 1/3 倍频程声压级为基础，可用于自由场或扩散场中的复杂宽带噪声，充分计及各临界带间的掩蔽效应：高声级的分量可掩蔽频率相近的低声级分量。

![窄带噪声掩蔽效应：4 kHz、50 dB 纯音在中心 1.2 kHz、90 dB 窄带背景中仍可闻，背景升到 100 dB 后被掩蔽](/images/nvh-metrics/fig7-3-masking-zwicker.png)

::: info 算法标准
响度计算的现行标准为 **ISO 532-1**（Zwicker 方法，对应旧版 ISO 532B）与 **ISO 532-2**（Moore-Glasberg 方法）。工程中以 Zwicker 方法最常用；Stevens Mark VI 对应旧版 ISO 532A-1975。
:::

### 3.2 尖锐度（Sharpness, acum）

尖锐度（Sharpness）描述声音"尖锐（sharp）"或"沉闷（dull）"的听感属性，主要取决于谱成分与中心频率，而不依赖于响度级细节。量化单位为 acum：**1 acum 的参考声是中心频率 1 kHz、声压级 60 dB、带宽等于一个临界带的窄带噪声**（1 kHz 处一个临界带宽约 160 Hz）。

按理论手册（第 7.4 节），尖锐度相当于强化高频成分后的特定响度谱的一次矩：先定义计权函数 $g(z)$，16 Bark 以下恒为 1，高于 16 Bark 按指数规律上升（式 7-5）：

$$g(z)=\begin{cases}1, & z \le 16\ \mathrm{Bark}\\ 0.066\,e^{0.171 z}, & z > 16\ \mathrm{Bark}\end{cases}$$

总尖锐度由特定响度 $N'(z)$（sone/Bark）加权积分得到（式 7-4/7-6）：

$$S = 0.11\,\frac{\displaystyle\int_0^{24} g(z)\,N'(z)\,z\;\mathrm{d}z}{N}\quad(\mathrm{acum})$$

其中 $N=\int_0^{24} N'(z)\,\mathrm{d}z$ 为总响度。物理意义：$z$ 的一次矩使高频（高 Bark）成分按指数计权放大，因此越是高频能量突出，尖锐度越高。

![尖锐度与限带噪声中心频率、带宽的关系：噪声频率越高，尖锐度越高](/images/nvh-metrics/fig7-5-sharpness-band.png)

![计算尖锐度的计权函数 g(z)：16 Bark 以下恒为 1，以上按指数规律增长](/images/nvh-metrics/fig7-6-sharpness-weighting.png)

```python
import numpy as np

def sharpness_zwicker(specific_loudness, z):
    """Zwicker 尖锐度 (acum) 简化实现
    specific_loudness: 特定响度 N' (sone/Bark)
    z: 临界频带率 (Bark)，0~24
    """
    N = np.trapz(specific_loudness, z)      # 总响度 N = 积分 N'dz
    g = np.where(z <= 16, 1.0, 0.066 * np.exp(0.171 * z))  # 计权函数 g(z)
    return 0.11 * np.trapz(g * specific_loudness * z, z) / N
```

### 3.3 粗糙度（Roughness, asper）

粗糙度（Roughness）是声音受幅值调制（AM）时的声品质评价指数，感觉与调制深度、调制频率有关，对载波（基本）频率并不敏感。单位为 asper：**1 asper 规定为 1 kHz、60 dB 纯音被 70 Hz、100% 幅值调制时的粗糙度**。

按理论手册（第 7.5 节）：调制频率低于约 15 Hz 时，直接感受到时变的响度抖动（抖动强度，单位 vacil；1 kHz、60 dB 纯音被 4 Hz、100% 调制规定为 1 vacil）；调制频率高至 150-300 Hz 时可分辨出不同音调；在中间的调制频率区间（约 **15-300 Hz**）感觉到的是稳定然而粗糙的声音，发动机噪声中的分数谐波常引起这类调制。幅值调制声的粗糙度可近似表示为（式 7-7）：

$$R \approx f_{\mathrm{mod}}\cdot\Delta L$$

其中 $f_{\mathrm{mod}}$ 为调制频率（Hz），$\Delta L$ 为瞬时掩蔽深度，即实际感觉到的时变响度样本的最大值与最小值之差。

::: warning 注意
粗糙度的计算尚未有 ISO 统一标准，不同软件（HEAD acoustics、Siemens）算法有差异，跨工具数值不可直接对比。
:::

## 四、振动指标

### 4.1 振动总量级（Overall Vibration Level）

振动速度有效值由时域信号定义：

$$v_{\mathrm{rms}} = \sqrt{\frac{1}{T}\int_0^T v^2(t)\,\mathrm{d}t}$$

与声压级同理（速度亦为场量，平方对应能量），振动级取：

$$L_v = 20\,\lg\frac{v_{\mathrm{rms}}}{v_0}\,,\qquad v_0 = 10^{-9}\ \mathrm{m/s}$$

### 4.2 阶次分析（Order Analysis）

阶次（Order）定义为每转事件数相对于参考轴 1 阶的比值：1 阶即 tacho 所跟踪参考轴每转一次的事件，其余阶次按每转事件数与参考轴之比确定。阶次与频率通过转速换算（SimCenter 阶次手册）：

$$f = O\cdot\frac{n}{60}\quad(\mathrm{Hz})$$

其中 $O$ 为阶次，$n$ 为转速（rpm）。例：600 rpm 下的 2 阶振动，$f = 2\times600/60 = 20\ \mathrm{Hz}$。

| 阶次 | 典型来源 | 工程含义 |
| --- | --- | --- |
| 1x | 不平衡、偏心 | 基频同步振动 |
| 2x | 不对中、联轴器 | 2 倍频 |
| 齿数x | 齿轮啮合 | 高频啮合冲击 |
| 叶片数x | 风扇/泵 | 流体脉动 |

::: danger 常见错误
阶次分析必须基于准确的转速信号（tacho / 编码器）。若用估计转速（free-run），阶次线会展宽、模糊，导致误判来源。
:::

## 五、指标关联性速查

::: tip 经验对照（供初步判断）
- 响度级每升高 10 phon，响度（sone）加倍，主观感受约成"两倍响"（式 7-2）
- 强声级分量会掩蔽频率相近的弱分量（Zwicker 掩蔽），因此纯音突出时即使总声压级不高也容易被察觉、引起烦扰
- 调制频率处于约 15-300 Hz 区间时产生粗糙感；低于约 15 Hz 时感知转为响度抖动（vacil）
:::
