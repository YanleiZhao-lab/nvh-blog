# 论文复现实验记录模板

> 阅读一篇 NVH 论文，到自己能复现其方法并应用到工程问题，中间有大量细节需要沉淀。本文提供一个结构化的复现记录模板，确保关键信息不遗漏，复现过程可追溯。文中判据与术语按 Simcenter 数字信号处理理论手册对齐。

## 一、为什么需要复现模板

论文给出的"方法"与实际可运行的代码之间，往往存在差距：未公开的数据、隐含假设、软件版本差异、参数取值的工程经验。如果不系统记录，复现过程难以推进，且难以排查问题出在方法本身还是具体实现。

::: info 复现的价值
复现不是为了证明论文对错，而是为了**把方法变成自己可用的工具**。能复现的方法才是真正理解了的方法。
:::

## 三、关键记录要点

### 3.1 数据差异是最常见的偏差来源

论文通常用干净数据（公开数据集或仿真），工程现场数据带噪声、缺通道、采样率不一致。必须显式记录差异：

- 论文是消声室数据，你是半消声室 → 需考虑反射修正
- 论文是稳态工况，你是瞬态 → 方法可能不适用
- 论文采样率 51.2 kHz，你是 8 kHz → 抗混叠和分辨率都变了

采样率差异的影响可以用奈奎斯特（Nyquist）采样准则定量评估。带宽（Bandwidth, $F_{max}$）是傅里叶变换能分析的最高频率，等于采样率的一半：

$$F_{max} = \frac{F_s}{2}$$

其物理意义：采样后的频谱以 $F_s/2$ 为轴折叠，高于该频率的能量会混叠进分析频带。工程实践中，数据采集系统的抗混叠滤波器（anti-aliasing filter）从带宽的 80% 处就开始压低信号幅值，因此实际可用带宽低于理论值；为保证频域幅值正确，实践中采样率通常取关注频率的 2.5 倍以上，若还需保证时域波形幅值，则应达到 10 倍以上。复现数据与论文采样率不同时，这些边界条件都会改变，必须逐一记录。

::: info 数据先行
开始复现前，先把"我有没有等价数据"这个问题答清楚。没有合适数据，复现只能停在算法演示阶段。
:::

### 3.2 参数取值的工程经验

论文里写"Hann 窗，频率范围 0–4000 Hz"，但不写为什么。复现时把这些隐含判断补上：

- 为什么选 Hann 而非平顶窗 Flattop？（权衡泄漏与幅值）
- 为什么上限 4000 Hz？（目标信号特征 / 设备限制）
- 平均次数为什么是 8？（稳态？噪声水平？）

频率上限与频率分辨率并非独立参数。按数字信号处理的定义分步推导：

第一步，帧长（Frame Size, $T$）是采集一个数据块所需的时间，等于数据块大小（Block Size, $N$）除以采样率：

$$T = \frac{N}{F_s}$$

物理意义：每采一个样本耗时 $1/F_s$，采满 $N$ 个样本即构成一帧。

第二步，带宽 $F_{max} = F_s/2$，FFT 后的有效谱线数（Spectral Lines, $SL$）为 $N/2$。

第三步，频率分辨率（Frequency Resolution, $\Delta f$）等于带宽除以谱线数：

$$\Delta f = \frac{F_{max}}{SL} = \frac{F_s/2}{N/2} = \frac{F_s}{N} = \frac{1}{T}$$

这就是数字信号处理的"黄金方程"：频率分辨率由帧长唯一决定——分辨率越细，要求的采集时间越长；帧长越短，分辨率越粗。论文给出频率范围与 FFT 点数时，应据此核算其隐含的帧长是否与工况时长匹配。

![数字信号处理的黄金方程：频率分辨率与帧长互为倒数（图源：Simcenter DSP 理论手册 图 15）](/images/paper-template/dsp-golden-equation.png)

![频率分辨率对谱分析的影响：1.0 Hz 分辨率下 100 Hz 与 101 Hz 两个正弦分量合并为一个峰，0.5 Hz 分辨率下可分开（图源：Simcenter DSP 理论手册 图 16）](/images/paper-template/dsp-frequency-resolution.png)

窗函数的取舍同样有定量判据。汉宁窗（Hanning）用于一般随机数据分析，在频率分辨率与幅值精度之间折中：最大幅值误差为 15%（即使施加窗修正因子后仍如此），泄漏通常限制在原信号两侧各 1.5 条谱线内；若信号在帧内周期截断，则误差为 0。平顶窗（Flattop）幅值精度高，常用于校准。瞬态事件宜用 Tukey 窗，锤击模态试验用指数窗（需注意引入人工阻尼）。

![对随机数据施加汉宁窗：窗函数（中）使数据帧两端平滑过渡到零，抑制截断突变（图源：Simcenter DSP 理论手册 图 4）](/images/paper-template/dsp-hanning-random-data.png)

![汉宁窗的时域形状（左）及其对周期/非周期截断正弦信号的频域影响（右）（图源：Simcenter DSP 理论手册 图 5）](/images/paper-template/dsp-hanning-shape-leakage.png)

::: info 记录"为什么"
参数表里最有价值的不是数值，而是"理由"那一列。这些工程经验是论文不会写、但复现必须搞清楚的。
:::

## 四、结果对比与偏差分析

复现结果与论文有偏差是常态，关键是区分偏差来源：

| 偏差类型 | 可能原因 | 处理方式 |
| --- | --- | --- |
| **数值小偏差** | 软件版本/数值精度 | 可接受 |
| **趋势一致，幅值偏** | 数据差异/单位/加权 | 逐一排查 |
| **趋势不同** | 方法实现错误/前提不符 | 重点核查 |
| **完全无法复现** | 论文描述不完整/数据缺失 | 联系作者/放弃复现 |

## 五、从复现到工程应用

复现完成后，记录的"工程价值"部分决定这篇论文对你的实际意义：

- **直接可用** — 方法和数据条件都匹配，纳入工具链
- **需适配** — 方法对，但要改参数/输入格式
- **仅供参考** — 方法思路有价值，但工程上不可直接用

::: info 闭环
一篇论文的复现记录，最终要回答一个问题："这个东西我下次遇到类似问题时，能拿出来用吗？"如果能，复现就成功了。
:::
