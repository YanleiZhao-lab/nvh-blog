# 论文复现实验记录模板

> 阅读一篇 NVH 论文，到自己能复现其方法并应用到工程问题，中间有大量细节需要沉淀。本文提供一个结构化的复现记录模板，确保关键信息不遗漏，复现过程可追溯。

## 一、为什么需要复现模板

论文里写的"方法"和实际能跑通的代码之间，往往隔着：未公开的数据、隐含假设、软件版本差异、参数取值的工程经验。如果不系统记录，复现到一半就会卡住，且难以排查是方法问题还是实现问题。

::: info 复现的价值
复现不是为了证明论文对错，而是为了**把方法变成自己可用的工具**。能复现的方法才是真正理解了的方法。
:::

## 二、复现记录模板

以下模板可直接复制为每篇论文的复现笔记：

## 三、关键记录要点

### 3.1 数据差异是最常见的坑

论文通常用干净数据（公开数据集或仿真），工程现场数据带噪声、缺通道、采样率不一致。必须显式记录差异：

- 论文是消声室数据，你是半消声室 → 需考虑反射修正
- 论文是稳态工况，你是瞬态 → 方法可能不适用
- 论文采样率 51.2 kHz，你是 8 kHz → 抗混叠和分辨率都变了

::: info 数据先行
开始复现前，先把"我有没有等价数据"这个问题答清楚。没有合适数据，复现只能停在算法演示阶段。
:::

### 3.2 参数取值的工程经验

论文里写"Hann 窗，频率范围 0–4000 Hz"，但不写为什么。复现时把这些隐含判断补上：

- 为什么选 Hann 而非平顶？（权衡泄漏与幅值）
- 为什么上限 4000 Hz？（目标信号特征 / 设备限制）
- 平均次数为什么是 8？（稳态？噪声水平？）

::: info 记录"为什么"
参数表里最值钱的不是数值，而是"理由"那一列。这些工程经验是论文不会写、但复现必须搞清楚的。
:::

## 四、结果对比与偏差分析

复现结果与论文有偏差是常态，关键是区分偏差来源：

| 偏差类型 | 可能原因 | 处理方式 |
| --- | --- | --- |
| **数值小偏差** | 软件版本/数值精度 | 可接受 |
| **趋势一致，幅值偏** | 数据差异/单位/加权 | 逐一排查 |
| **趋势不同** | 方法实现错误/前提不符 | 重点核查 |
| **完全无法复现** | 论文描述不完整/数据缺失 | 联系作者/放弃复现 |

## 五、从复现到工程应用

复现完成后，记录的"工程价值"部分决定这篇论文对你的实际意义：

- **直接可用** — 方法和数据条件都匹配，纳入工具链
- **需适配** — 方法对，但要改参数/输入格式
- **仅供参考** — 方法思路有价值，但工程上不可直接用

::: info 闭环
一篇论文的复现记录，最终要回答一个问题："这个东西我下次遇到类似问题时，能拿出来用吗？"如果能，复现就成功了。
:::

```text
│   ├── code/
│   ├── data/
│   └── results/
```
