# 几何骨架：试验模型的测点线面组织

> 40 个测点的平板模态做完了，振型动画里结构却缺了一角——三个点的数据明明采到了，动画上就是不动。查半天发现是几何里两个结点坐标敲错了一位小数，点被画到了离结构十米之外的位置，数据挂不上正确的结点，动画自然缺角。这类事故的根源不在测量，而在试验前搭的**几何骨架**。本文把几何模型比作城市的**公交线网图**——结点是站台、连线是线路、着色面是街区，乘客（振型动画）只在线网上行走——讲清结点的位置与方位、坐标系选择、欧拉角与自由度这四个构件怎么搭，以及搭错一处会在后面的模态分析里以什么面目出现。

## 一、为什么数据都对、动画却瘸了：几何骨架在模态试验里的角色

先看一个更普遍的现象。某车架子结构模态试验，60 个测点、数据质量良好（相干普遍 0.95 以上、稳定图光柱清晰），拟合出的频率阻尼也正常。但一到振型动画，前两阶整体弯曲振型看起来扭曲得不合理，几个点的相位明明应该是同向，动画里却跳来跳去。最后定位到的原因：三向加速度计装在了结构背面，测量方向与几何模型的坐标轴正方向相反，而几何定义时没有处理这个方向差异——振型系数的正负号全乱了。数据一个都没错，错的是几何模型里的**方位**信息。

这不是孤例。试验模态分析的产出是一组复数振型系数，每个系数挂在一个自由度（测点加方向）上；几何模型就是这批系数的地址簿——动画显示、MAC 比较、与有限元模型对标、后来的设计修改，全都按地址簿来取数。地址写错（坐标错）、门牌朝向写错（方位错）、楼层写错（自由度方向错），数据本身再好也取不出来或取反。LMS 理论手册第二十一章把这套地址系统归结为四个构件：**结点**（node）、**参考坐标系**、**方位与欧拉角**、**自由度**（DOF）。下面逐个展开。

::: info 核心概念
- **几何骨架（geometry skeleton）**：由结点、结点间连线（edge）与可选着色面构成的试验结构简化表示，服务于振型动画与设计修改
- **结点（node）**：规定要在结构上测量的点，也是要计算模态振型信息的点，由位置与方位共同给定
- **自由度（DOF, Degree of Freedom）**：结点可自由移动的方向，每结点最多有 3 个线位移、3 个角位移和 1 个标尺自由度，共 7 个
- **欧拉角（Euler angles）**：三个一组的转角，描述结点坐标系相对参考坐标系的方位差异
:::

## 二、结点：站台在线网里的位置

几何模型里最重要的是结点。规定的结点就是要在结构上进行测量的点，也是之后要计算模态振型信息的点——数据采集时通道表里填的 Point ID，指向的正是几何里的某个结点。通常还要在特定结点之间加上连接线或筋条（edge），构成结构的骨架模型；再通过着色表示某些表面，帮助观察所代表的结构。这正像公交线网图：站台（结点）是乘客上下车的实体，线路（连线）只是把站台串起来让人看得出这一带的结构长什么样，街区着色（表面）进一步给出整体轮廓——线路本身没有力学意义，删掉重画不改变任何测量数据。

结点由它的**位置**和**方位**给定，这是两个关键词。先看位置。

在三维空间，结点的位置由一组三个实数（坐标值）确定，坐标值都是相对于某参考坐标系的值。参考坐标系可以是直角坐标系，也可以是柱坐标系或球坐标系——同一个点在不同坐标系下有三套写法，但指的是同一个位置。手册给了一个例子：某结点在直角坐标系中坐标为 $(x, y, z)$，在柱坐标系中写为 $(r, \theta, z)$，在球坐标系中写为 $(R, \theta, \varphi)$，三种写法经坐标换算完全等价。选择哪种，看结构形状：回转体（制动鼓、轮胎、筒形件）用柱坐标布点往往更省事，多数板类与框架结构用直角坐标最直观。

*（图源：Simcenter Testing Knowledge Base 中文理论手册 图21-1）*

![直角、柱、球三种参考坐标系：同一结点位置的三种写法](/images/geometry-skeleton/fig21-2-coordinate-systems.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册 图21-2）*

参考坐标系应当和结构的骨架模型在显示窗内一起表示出来。**总坐标系的原点**即包含试验结构的三维空间的原点；当结构存在总体上的对称点时，应考虑将总坐标系的原点选在该对称点。这样做的实际好处：对称结构（自由梁、自由板）的刚体模态与弹性模态在坐标原点居于对称中心时更容易解读，振型动画的正弦分布一目了然；对标有限元模型时，两边坐标原点一致，点对点映射省去一次坐标变换。

## 三、方位与欧拉角：站台的朝向

位置只回答在哪，方位回答朝哪。结点的方位用直角坐标表示，在大多数应用中，结点的方位规定与测量方向一致——结点坐标系的原点与结点位置重合，坐标轴跟着测量的方向走。

![结点坐标系：原点与结点重合、坐标轴与测量方向对齐](/images/geometry-skeleton/fig21-3-node-triad.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册 图21-3）*

如果结点坐标系的坐标轴与测量方向不一致——包括正负指向不一致——那么它们之间的区别必须用**欧拉角**来给定。这是几何定义里最容易被跳过、又最容易出第一节那种动画跳变事故的一步。

三个欧拉角用来确定一个坐标系相对于有相同原点的参考坐标系的方位，本质是绕轴转三次的分解：

- **第一欧拉角**：坐标系绕参考坐标系 z 轴的转角（正向转角从 x 轴转向 y 轴），这一旋转产生的第一个中间坐标系在坐标轴标号上加撇表示；
- **第二欧拉角**：绕第一中间坐标系 x 撇轴的旋转（正向从 y 撇转向 z 撇），产生第二中间坐标系；
- **第三欧拉角**：绕第二中间坐标系 z 双撇轴的旋转（正向从 x 双撇转向 y 双撇），得到最终方位。

下面这个公式回答的问题是：结点坐标系的测量向量，怎么换算到总坐标系里去参与动画与对标——三次旋转各对应一个旋转矩阵，按次序相乘就是坐标变换。其中三个转角对应物理里的三个欧拉角，v-local 是结点坐标系里写出的向量，v-global 是总坐标系下的同一向量：

$$
v_{\mathrm{global}} = R_z(\theta_1)\, R_{x'}(\theta_2)\, R_{z''}(\theta_3)\; v_{\mathrm{local}}
$$

两个旋转矩阵的显式形式（Rz 管绕 z 轴、Rx 管绕 x 轴）：

$$
R_z(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta & 0 \\ \sin\theta & \cos\theta & 0 \\ 0 & 0 & 1 \end{bmatrix},\quad R_{x'}(\theta) = \begin{bmatrix} 1 & 0 & 0 \\ 0 & \cos\theta & -\sin\theta \\ 0 & \sin\theta & \cos\theta \end{bmatrix}
$$

注意旋转**次序不可交换**：先绕 z 转直角再绕新 x 轴转直角，与先绕 x 转再绕新 z 轴转，结局不同。这正是欧拉角必须一步一步、带着撇号书写的原因——每次旋转都是绕上一步产生的新轴转，而不是绕原始轴。举例：加速度计装在结构背面、其敏感轴与模型正 X 方向反向，等价于结点坐标系绕 z 轴转了平角（180 度），换算矩阵把该通道振型系数的 X 分量取反——第一节事故里缺的就是这一句定义。

::: warning 常见误区
欧拉角的三个角是链式旋转（每次绕上一旋转产生的新轴），不是绕固定原始轴的三个独立转角。写对时忘了撇号、按固定轴理解，转出来的是另一个方位——多数动画朝向不对的几何问题源出于此。
:::

## 四、自由度：站台能往哪些方向走

结点的自由度表示结点自由地移动的方向。每一结点最多可有**七个**自由度：三个线位移自由度、三个角位移自由度和一个标尺（scalar）自由度。

![结点的自由度：三个线位移、三个角位移与一个标尺自由度](/images/geometry-skeleton/fig21-4-dof.png)

*（图源：Simcenter Testing Knowledge Base 中文理论手册 图21-4）*

为什么线位移之外还要角位移？因为模态试验里的点不只携带平动信息。用三向加速度计测的是三个线位移 DOF；而应变、声学测量或某些特殊传感器给出的是别种量。标尺自由度则用于那些只有大小、没有方向的量——最典型的是声学测试中的声压：传声器测的是标量，挂在标尺 DOF 上（声学测量中定义的结点和网格在手册声学部分另有叙述）。

用公交线网的话说：站台（结点）建好了，还得声明它能发哪几个方向的车（自由度）。大多数振动测点只发三班平动车（X、Y、Z 线位移），角位移与标尺是特殊线路，不开就不填。通道表里 Point ID 加 Direction 合起来才指定一个完整的 DOF——这也是为什么布点文档里只写 103 号点不够，方向必须同时写清。

## 五、numpy 演示：方位错误的振型动画长什么样

几何方位错的代价可以定量演示。取一块简支平板的一阶振型（解析形式），其中第 24 号结点因传感器装反、几何未定义 180 度欧拉角，其振型系数符号与真实相反。比较正确几何与错误几何下的动画向量：

```python
import numpy as np

# 简支板 (0<=x<=1, 0<=y<=1) 一阶振型（解析解，系数任意）
def mode_shape(m, n, X, Y):
    return np.sin(m*np.pi*X) * np.sin(n*np.pi*Y)

# 均匀 6x6 布点
g = np.linspace(0.02, 0.98, 6)
X, Y = np.meshgrid(g, g)
phi_true = mode_shape(1, 2, X, Y).ravel()   # 真实振型 (1,2)

# 26 号点（振型幅值最大处）：传感器装反、几何未定义 180 度欧拉角
phi_wrong = phi_true.copy()
phi_wrong[26] = -phi_wrong[26]

# 归一化后量化动画扭曲程度：与真实形态的自相关（单模态自 MAC）
a = phi_true/np.linalg.norm(phi_true)
b = phi_wrong/np.linalg.norm(phi_wrong)
mac = (a @ b)**2
print(f"装反一个点的自 MAC = {mac:.4f}")
print(f"该点符号翻转能量占比 = {phi_true[26]**2/(phi_true**2).sum():.1%}")

# 对照：装反的是振型幅值接近零的角点，MAC 几乎不受影响
phi_w2 = phi_true.copy()
phi_w2[35] = -phi_w2[35]
b2 = phi_w2/np.linalg.norm(phi_w2)
print(f"装反振型节点处的自 MAC = {(a @ b2)**2:.4f}")

# 修复：给该结点定义 180 度欧拉角，坐标变换等价于该方向分量取反
th = np.pi
Rz = np.array([[np.cos(th), -np.sin(th), 0],
               [np.sin(th),  np.cos(th), 0],
               [0, 0, 1]])
print("Rz(180 度) 作用后该方向分量符号自动纠正")
```

运行输出：装反一个点的自 MAC = 0.5493，该点符号翻转能量占比 12.9%；而装反振型节点（幅值近零的角点）时自 MAC = 1.0000，几乎无感。两个数对照出一条工程规律：方位错误的破坏力取决于该点在振型里的权重——振型腹点装反，36 个测点里只错 1 个，动画自相关就掉到 0.55、肉眼明显扭曲；振型节点装反则几乎看不出。这解释了为什么方位事故总是"部分模态动画怪、部分正常"：不同阶振型的腹点位置不同，中招的只有腹点装反的那几阶。修正只需要在几何里给该结点补一个 180 度的欧拉角定义（或按第四节的通道规则在 Direction 上取负），一行改动换回整条振型的可信度。

## 六、Testlab 中的几何骨架操作

Simcenter Testlab 里几何骨架在 **Testlab Modal Analysis** 工作簿的 Geometry 组（或 MIMO FRF Testing 等采集工作簿内的 Geometry 标签页）中创建：

- **结点与坐标**：Geometry 的 Components/Points 表格中逐点输入坐标；回转类结构可在坐标系下拉中切换柱坐标，软件内部自动换算存储
- **连线与面**：Lines/Polygons 页选结点序号连线；给表面着色在 Display 中设置，仅影响显示不参与计算
- **方向定义**：通道表（Channel Setup）中 Point ID 加 Direction 与几何结点绑定，Direction 的正方向即结点坐标系的轴正方向
- **振型动画**：Modal Analysis 的 Mode Shapes 页直接调用几何做动画；着色面让整体振型（如板的一阶弯曲）一眼可辨

经验做法：布点图（测点编号、方向、坐标表）在搭几何之前定稿并双人核对；几何搭完先做一次空跑——不加试件，把各通道指到几何上播放一遍，确认每个通道都挂对了结点与方向，再开始正式测量。第一节的两类事故（坐标错位、方位缺转角）在这一步都能拦下。

## 七、小结

- **几何骨架是地址簿不是画**：结点、连线、着色面服务于振型动画、MAC 对标与设计修改；连线与面只有显示意义，删改不影响测量数据
- **结点 = 位置 + 方位**：位置由参考坐标系（直角、柱、球）下三个坐标给定，总坐标原点优先放在结构对称点；方位由结点坐标系给定，与测量方向不一致时必须用欧拉角定义
- **欧拉角是链式旋转**：绕 z、绕新 x、绕新 z，三次转角次序不可交换；传感器装反这类 180 度情形，缺了这步定义振型系数就整体反号
- **自由度最多七个**：3 线位移、3 角位移、1 标尺；Point ID 加 Direction 才是完整 DOF，声压等标量挂标尺自由度
- **先空跑再测量**：几何搭完将通道逐一挂点核对，坐标错位与方位缺转角在动画空跑阶段即可拦截

## 一句话记住

几何骨架是振型数据的地址簿：结点是站台（位置加方位）、连线是线路、自由度是发车方向，欧拉角管朝向对不上时的转角——地址写对一个不错，动画与对标才取得出正确的数据；先空跑核对，再正式开测。
