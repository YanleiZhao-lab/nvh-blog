# 单端 vs 差分输入：噪声抑制的电路差异

> 两只应变计贴在同一根梁上、接进同一台 SCADAS，旁边有人拿 110 V 电源适配器一靠近，屏幕上一条时域曲线立刻"长草"，另一条纹丝不动——传感器没坏、采集卡没坏，差别只在接线模式：一条走单端（single-ended），一条走差分（differential）。本文用"两人三脚赛跑"的类比说清两种输入的本质差异、共模噪声为什么会被相减抵消，以及 Simcenter Testlab 里耦合方式如何随 InputMode 自动切换。

同一台设备、同一个夜晚、同一个测点，两份数据却吵起来了。应变小组用四分之一桥应变计测吊车梁的静载应变，采集了一整夜；第二天发现时域曲线上密密麻麻全是毛刺，FFT 一看，60 Hz 及其谐波（120 Hz、180 Hz）一根不少——50 Hz 供电的车间怎么会有 60 Hz？排查三天，最后发现毛刺最强的时段恰是厂房照明与电焊机工作的时间：旁边的动力电缆在信号线上感应出了电磁噪声。而隔壁小组的全桥应变计就布在同一根梁上、同样距离电缆，数据却干净得多。同样的现场、同样的噪声环境，一条曲线"长草"、一条干净，分水岭不在传感器精度，而在采集前端那一栏常被一路点"下一步"的设置——输入到底是单端还是差分。

要理解这个差别，先看数字。一根与 110 V 动力电缆平行走线的信号线，感应出几十毫伏的 60 Hz 电磁噪声毫不费力；而四分之一桥应变计满量程输出往往只有 10 mV 量级——噪声与信号同量级，信噪比接近 0 dB，时域上毛刺比信号还高。对比同一只全桥应变计：满量程输出约 20 mV，看起来也没好多少，但它走差分输入，感应噪声在相减中被抵消掉绝大部分，剩下的 60 Hz 分量比单端低了约一个数量级。这就是本文要展开的核心：**单端输入把"信号 + 噪声"一起放大，差分输入先相减再放大，共模噪声在减法里湮灭**。

## 一、为什么一根导线天然"收集"噪声

任何一根有一定长度的导线，都是一个环形天线。变化的电磁场（动力电缆里的 50/60 Hz 电流、变频器开关噪声、电焊机弧光）穿过导线与地构成的回路时，按法拉第电磁感应定律在导线两端感应出电动势——这不需要接触，只需要"靠近"。

![图1：SCADAS Mobile 前端与安装在气罐上的加速度计，一根电源线正搭在传感器电缆上](/images/single-ended-vs-differential/fig1.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

Simcenter 知识库的实验现场正是这样布置的：加速度计电缆接到 SCADAS Mobile 前端，一根电源线直接压在传感器电缆上方。此时电缆里传的已不只是传感器的信号，还有电源线感应进来的 EMF（Electric and Magnetic Field，电场与磁场）噪声分量。

**单端输入**测量的是一根信号线与地之间的电压差，然后放大这个差值：

$$V_{\mathrm{out}} = G \cdot (V_{\mathrm{sig}} + V_{\mathrm{noise}} - 0)$$

这个公式回答的问题是：**单端输入最终放大的是什么？**其中 $G$ 对应物理里前端的放大倍数，$V_{\mathrm{sig}}$ 对应物理里传感器真正测到的信号电压，$V_{\mathrm{noise}}$ 对应物理里电缆全程收集的感应噪声——括号里两者是"和"，放大器一视同仁地放大，噪声与信号同增益，谁也甩不掉谁。信号线走过的地方越长、与动力线并行越远，$V_{\mathrm{noise}}$ 越大；因为参考端是地，地环路上两点间的电位差也会混进结果。

![图2：灰盒代表换能器到 SCADAS 的电缆，紫色为期望信号，红色为 EMF 噪声；右侧输出 = 信号 + 噪声](/images/single-ended-vs-differential/fig2.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

而且噪声的危害是**相对的**：同样 10 mV 感应噪声，落在 5 V 满量程输出的 IEPE 加速度计通道上是零头（信噪比 54 dB），落在 10 mV 满量程的四分之一桥应变通道上就是灭顶之灾（信噪比 0 dB）。所以"单端到底能不能用"从来不是绝对命题，而是信号电平与噪声电平的比例问题——这也是为什么加速度计日常用单端毫无问题，而应变测量对差分近乎刚需。

## 二、差分输入：两人三脚，先对暗号再出发

**差分输入**不参考地。信号走在两根线上——(+) 信号线与 (−) 信号线，输出取两者之差：

$$V_{\mathrm{out}} = G \cdot \left[(V_{\mathrm{sig}} + V_{\mathrm{noise}}) - (-V_{\mathrm{sig}} + V_{\mathrm{noise}})\right] = G \cdot 2 V_{\mathrm{sig}}$$

这个公式回答的问题是：**差分输入凭什么既消噪又加倍信号？**其中两根线上的 $+V_{\mathrm{sig}}$ 与 $-V_{\mathrm{sig}}$ 对应物理里传感器（如全桥应变计）在两根输出端子上输出的反相信号，两个 $V_{\mathrm{noise}}$ 对应物理里同一条电缆护套内两根芯线几乎相同位置上感应出的**共模噪声（common-mode noise）**——因为两根线绞在一起、紧挨着走，外界的电磁场在两根线上感应出的噪声几乎完全相同。相减时：信号因反相而相加（$2V_{\mathrm{sig}}$），噪声因同相而相消（$V_{\mathrm{noise}} - V_{\mathrm{noise}} = 0$）。

![图3：电缆内的 (+) 与 (−) 两根信号线，紫色为期望信号、红色为 EMF 噪声；右侧为两线相减后的输出——噪声消除、信号加倍](/images/single-ended-vs-differential/fig3.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

一个贯穿全文的类比：**差分输入像一场"两人三脚"赛跑**。单端输入是一个人独自跑——路上每块石头（噪声）都结结实实踢到自己脚上；差分输入是两个人绑着相邻的腿跑——要求两人事先对好暗号（信号反相：你抬腿我落腿，步幅相同方向相反），路面上的颠簸（共模噪声）两个人同时经历、相减时彼此抵消，而两人对暗号的"相对动作"（差模信号）被完整保留还翻了一倍。这个类比里每个要素都对应电路实体：两个人是两根芯线，暗号是传感器的反相输出，路面颠簸是共模 EMF，绑腿是双绞线——绞距越密，两根线经历的噪声越"同步"，相减越干净。

::: info 核心概念
- **单端输入（Single-ended input）**：测一根信号线对地的电压差并放大，结构简单，但感应噪声与地环电位差全部进入结果
- **差分输入（Differential input）**：信号走 (+)/(−) 两根线，取两线电压之差再放大；反相的差模信号相加、同相的共模噪声相消
- **共模噪声（Common-mode noise）**：同时、等幅、同相出现在两根线上的噪声分量，主要来自电磁感应；差分结构对其有天然抑制力
- **共模抑制比 CMRR（Common-Mode Rejection Ratio）**：差分放大器抑制共模分量的能力指标，实际器件不为无穷大，两线不完全对称时残余共模仍会漏过一部分
:::

实际工程中差分不是无条件的：两根线的阻抗路径要对称，电缆要双绞，否则"几乎相同的噪声"就不再几乎相同，相减后留残差。双绞线的意义正在于此——每半个绞距交叉一次，两根线对干扰源的相对位置不断互换，感应噪声的平均值被强制拉平。

## 三、实验对照：全桥 vs 四分之一桥

知识库的演示实验把两种输入放在同一现场对比：同一根梁上贴两只应变计，一只全桥（差分输入），一只四分之一桥（单端输入），同时接入 SCADAS Mobile。

![图4：同一根梁上的全桥与四分之一桥应变计，同时接入 SCADAS Mobile 前端](/images/single-ended-vs-differential/fig4.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

两个问题可以先自问再往下看：其一，没有外部干扰时，哪只应变计的时域读数噪声更大？其二，把 110 V、60 Hz 的电源适配器拿到导线附近，哪只信号受影响更大？

结果分两层。**时域层面**：四分之一桥（单端）的读数明显更"毛"，因为它的信号电平低（满量程 10 mV 量级），而环境电磁噪声直接叠加在单端通路上，相对危害大；全桥（差分）时域平滑得多。**频域层面**：把电源适配器靠近导线后做 FFT，两种信号的谱上 60 Hz 及其谐波都出现了，但幅值差距显著——单端通道的 60 Hz 分量远高于差分通道，差分对 EMF 的抑制直接写在谱线高度上。

![图5：两种应变信号的 FFT——60 Hz EMF 及其谐波同时出现，但幅值差距显著](/images/single-ended-vs-differential/fig5.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

![图6：放大细看——60 Hz 电源噪声在全桥（差分）上的幅值远小于四分之一桥（单端）](/images/single-ended-vs-differential/fig6.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

值得强调的是差分不是魔法：谱里 60 Hz 只是"低了很多"而非"完全消失"。原因回到第二节的概念框——CMRR 有限，两线不对称、绞距不匀、接线端子阻抗差异都会让共模噪声漏过一小部分。工程正确姿势是把差分当成噪声抑制的第一道闸门，而不是唯一闸门：布线远离动力线、信号线双绞屏蔽、必要时缩短电缆，与差分输入叠加使用。

## 四、Testlab 通道设置：耦合方式随 InputMode 联动

在 Simcenter Testlab 里，判断与设置入口都在通道设置（Channel Setup）：

- **加 Coupling 列**：Tools → Channel Setup Visibility，把 Coupling 列调出来。设置 InputMode 后，耦合方式会自动应用
- **自动单端的场景**：InputMode 设为 Voltage AC、Voltage DC 或 Active sensor（IEPE/ICP 传感器走这条）时，耦合自动设为单端
- **需要手动改差分的场景**：使用差分传感器（如全桥应变计）时，必须把耦合改为差分

![图7：Channel Setup 中增加 Coupling 列后可查看与修改各通道的耦合方式](/images/single-ended-vs-differential/fig7.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

对应关系可以直接记：**全桥应变计是差分，半桥、四分之一桥与 ICP 传感器是单端**。这就是为什么应变试验前查一遍 Coupling 列是值得养成的习惯——四分之一桥被迫单端没法改，但全桥没改成差分，等于把第二道闸门白白关掉了。

```python
import numpy as np

# 演示：同一噪声环境下，单端与差分通道里 60Hz 噪声线与信号线的比值
fs = 2048.0
t = np.arange(0, 2, 1/fs)
sig = 0.005 * np.sin(2*np.pi*7*t)            # 5 mV 应变信号（差模，两线反相）
emf = 0.004 * np.sin(2*np.pi*60*t)           # 4 mV 60Hz 感应噪声（共模，两线同相）
mismatch = 0.03                              # 两线噪声耦合不对称度 3%（CMRR 有限）

plus  =  sig + emf * (1 + mismatch/2)        # (+) 线：信号 + 噪声(略大)
minus = -sig + emf * (1 - mismatch/2)        # (−) 线：反相信号 + 噪声(略小)

se   = plus                                  # 单端：取 (+) 线对地
diff = plus - minus                          # 差分：两线相减

def line_amp(x, f0):
    """汉宁窗 FFT 后 f0 频率处的谱线幅值"""
    X = np.abs(np.fft.rfft(x * np.hanning(len(x))))
    f = np.fft.rfftfreq(len(x), 1/fs)
    return X[np.argmin(np.abs(f - f0))]

for name, x in [("单端", se), ("差分", diff)]:
    ratio = 20*np.log10(line_amp(x, 60) / line_amp(x, 7))
    print(f"{name}: 60Hz噪声线比7Hz信号线 {ratio:+.1f} dB")
```

运行结果：单端通道里 60 Hz 噪声线只比信号线低 1.8 dB——4 mV 感应噪声几乎与 5 mV 信号等高，时域自然"长草"；差分通道同一根噪声线低 38.4 dB——两个数字差 36.6 dB，正是相减把 97% 的共模噪声抵消、只留 3% 不对称残差的直接体现。一栏设置差出 30 dB 以上，这就是通道表里那一列"耦合方式"的含金量。

## 五、工程判断

- **默认规则**：ICP/IEPE 加速度计、麦克风走单端即可——输出电平高（伏级），感应噪声相对可忽略；应变测量（尤其四分之一桥）优先创造差分条件
- **低电平传感器是差分的主战场**：应变计、热电偶、桥式传感器，满量程输出毫伏级，与感应噪声同量级，单端的信噪比先天不足
- **差分不是免死金牌**：CMRR 有限，双绞与屏蔽、远离动力线、缩短电缆永远排在"改耦合方式"之前或之后同时做
- **排查 50/60 Hz 毛刺先看接线模式**：时域毛刺 + FFT 出现工频及谐波，第一反应不是换传感器，而是查该通道是单端还是差分、电缆是否与动力线并行
- **Testlab 联动规则**：Voltage AC/DC、Active sensor 自动单端；差分传感器记得手动把 Coupling 改为差分，全桥差分、半桥/四分之一桥/ICP 单端

## 一句话记住

单端量"线对地"、噪声信号一起放大；差分量"线对线"、反相信号相加减掉共模噪声——低电平传感器配差分，Testlab 里 Coupling 随 InputMode 联动，全桥差分、ICP 单端。
