# SCADAS RS 维护与校准：周期、项目与现场可执行项

> 一台高防护等级的采集设备三年没做过任何"保养"，是不是失职？恰恰相反——它几乎没有用户可维护的零件，真正要做的只有三件事：按规程清洗、按年度送检校准、按状态灯与电池规则做日常检查。很多团队的困惑在于"那我们平时到底要做什么"：清洗能不能上高压水枪？校准为什么必须每年一次、自己能不能做？本文用**体检类比**贯穿：SCADAS RS 像一位常年跑马拉松的运动员——身体底子好（IP67、无内部运动部件），不需要"开胸手术"式的维修，但需要每年一次"三甲体检"（工厂校准）、赛后正确"冲澡"（清洗规范）、日常"看脸色吃饭"（状态灯与电池管理）。本文把相关技术手册第 14 章的全部可执行项逐条展开，并补充周边章节的电池、固件与报废规则，最后给出一张可直接抄进 SOP 的年检-月检-测前检查清单。

## 一、为什么"免维护"的设备反而最需要讲维护

先看一个真实场景。某车队路试项目做了两个雨季，一套 SCADAS RS 堆叠在皮卡货箱里经历了泥水、盐雾与冲洗站的反复冲刷。第三个雨季开始前，工程师想给它做"保养"，翻遍相关技术手册第 14 章只找到两页纸：清洗与校准。第一反应是"就这？"——没有润滑点、没有易损件清单、没有扭矩复查表，与旋转机械的维护手册完全不是一个体量。

这不是相关技术手册偷懒，而是设计哲学的不同。SCADAS RS 是面向恶劣环境的模块化采集前端：整机防护等级 IP66/IP67（可承受 100% 相对湿度）、无风扇等强迫运动部件、内部没有任何用户可维修的零件。**"没有用户可维修的零件"这句话本身就是维护策略**——它把传统设备的"定期拆检"彻底排除，把用户的维护责任收缩到三件可以外部完成的事：

- **清洗**：外部的污垢与油脂必须清除，且方式有明确限制；
- **校准**：信号调节单元出厂已校准，年度复检由客户支持团队执行；
- **状态监测**：指示灯、电源缓冲器（电池）、固件版本这三项日常可观察量。

打个贯穿全文的比方：SCADAS RS 像一位**常年跑马拉松的运动员**。体检报告一切正常（工厂校准合格）、没有旧伤（无运动部件磨损），你不需要给他做手术；但三件事必须做对——赛后要按正确方式冲澡（清洗有水量/压力/距离限制，不是随便冲）、每年要做一次权威体检（年度校准，且要溯源到国际标准）、日常要看脸色（状态灯的颜色与闪烁频率就是他的"脸色"）。运动员的"免手术"不等于"免管理"，采集设备的"免维护"同样不等于"什么都不用做"。

::: info 核心概念
- **工厂校准（Factory Calibration）**：每台信号调节单元出厂前完成的校准，随附校准报告，是设备量值溯源的起点
- **认可校准（Accredited Calibration）**：由符合 ISO 17025:2017 的认可校准实验室执行、可正式溯源至国际测量标准的校准
- **电源缓冲器（Power Buffer）**：UPS 单元内置的锂离子电池组，容量 58.4 Wh，断电时维持系统供电直至数据安全保存
- **防护等级 IP66/IP67**：按 IEC 60529 评定的外壳防护能力，IP67 表示短时浸水也无有害影响
:::

## 二、清洗：可以冲洗，但有三条硬限制

SCADAS RS 常年跟着车辆跑，脏是常态。相关技术手册的态度很明确：**必须清除单元外部的任何污垢或油脂**——泥污不是美观问题，它覆盖连接器标识、藏住盐分加速腐蚀、堵住通风口的压力平衡通道。但"怎么清"分两种情况，限制各不相同。

### 装在车辆上清洗：参数化限制

设备还装在车上、整车进清洗工位时，允许用高压清洗机，但参数绝不能超：

![在车辆上清洁单元的限制：水量 100 l/min、压力 100 kPa、距离 3 m——三项上限同时满足](/images/rs-maintenance-calibration/fig3-vehicle-wash.png)

*（图源：网络官方公开资料）*

注意单位里的陷阱：**100 kPa 约 1 bar**，只是民用高压清洗机起始档位的一小部分——常见清洗机额定压力 10~15 MPa，是上限的一百多倍。换句话说，"用高压清洗机"在相关技术手册语境里实际意味着"用它的最低压力档、最远距离、最大散开的水雾"。三项参数（水量 100 l/min、压力 100 kPa、距离 3 m）必须**同时**满足，任何一项超标都可能把水压进通风口结构或连接器密封面。

### 单个单元的清洁：先拆分、再手洗

单元从车上拆下来单独清洁时，流程反而更严格——**禁止高压清洗机近距离冲洗**。正确步骤：

![单个单元的清洁步骤：拆分堆叠、拆卸背靠背与背板安装、密封所有连接器后再清洁](/images/rs-maintenance-calibration/fig4-single-unit-clean.png)

*（图源：网络官方公开资料）*

1. 拆分堆叠的单元；
2. 拆卸背靠背安装的单元；
3. 拆卸安装在背板上的所有单元；
4. **确保所有连接器都用盖子密封**，防止灰尘、水和清洁剂进入。

清洁动作本身很温和：用刷子擦去污垢，必要时用温热的自来水，油脂可用温和的清洁剂，最后用温热自来水彻底冲洗、用不起毛的布擦干。整套动作与"给精密仪器洗澡"的直觉一致——刷子与流水是主力，化学强度与水压都要克制。

回到运动员类比：车上冲洗像是"赛后站在淋浴房门口远远冲一下"，单件清洁像是"回家自己仔细搓澡"——后者反而更讲究，因为离得近、水更容易灌进耳朵（连接器）。

::: warning 工程注意
清洁前先断电、盖好所有连接器盖，是单件清洁流程里最容易省略、后果最重的一步。相关技术手册在操作章节反复强调：使用系统后先关闭电源再断开电缆，每断开一根电缆先盖上盖子再清洁——顺序颠倒，清洁剂与水就获得了直通通道。
:::

## 三、校准：工厂校准、年度校准与认可溯源的层级

清洗解决"外部状态"，校准解决"量值是否还可信"。相关技术手册 Calibration 一节把校准组织成三个层级：

![校准的三个层级：出厂工厂校准附报告；建议每年由客户支持团队校准；需正式溯源时使用符合 ISO 17025:2017 的认可实验室](/images/rs-maintenance-calibration/fig2-calibration.png)

*（图源：网络官方公开资料）*

**第一层：出厂工厂校准。** 每台信号调节单元出厂时都经过工厂校准并附校准报告。这份报告是设备的"出生证"，记录了出厂时的量值状态，也是后续所有校准的比对基准。

**第二层：年度校准。** 建议**每年**由客户支持团队通过维护或校准合同执行一次校准。为什么是一年？采集设备的模拟前端（滤波、放大、ADC 基准）随温度循环与器件老化存在缓慢漂移，一年是行业通行的时间尺度——传感器标定证书的有效期普遍也是一年，两者对齐便于统一管理。

**第三层：认可校准。** 如果组织需要**正式溯源至国际测量标准**的校准（例如试验报告要通过审核、数据要进法律程序、或质量体系有明确要求），就要走认可工厂校准实验室：完全符合 **ISO 17025:2017** 要求，并在荷兰认可委员会（RVA）的 **K159 范围**下注册。这一层给出的校准证书带有认可标志，量值链条可以一路追到国际单位制。

三层的结构用体检类比来看很直白：工厂校准是"出生时的全面体检"，年度校准是"每年单位组织的例行体检"，认可校准是"三甲医院的权威体检报告"——平时例行体检就够，要办保险、打比赛（报告送审）时必须拿权威报告。

### 校准之外：测前的验证手段

年度校准解决"设备级"的量值，但一场具体试验开始前还有通道级的验证可做，这些不替代校准、却是日常质量控制的一部分：

- **调零/清零（Zeroing）**：应变类通道采集前清零，消除安装预载与零漂——Recorder App 的 Auto zeroing 可自动化这一步；
- **分流校准（Shunt Calibration）**：电桥通道并接精密电阻制造一个可计算的标准应变，核对整条调理链的灵敏度；
- **TEDS 电子数据表**：传感器端存储灵敏度等标识信息（当前硬件已具备、软件支持尚未开放）；
- **指示灯状态**：REC 单元状态灯出现"正在进行校准"等状态时，说明系统自身在做内部校准动作，等它完成再开始采集。

::: info 核心概念
**溯源性（Traceability）**：测量结果通过一条不间断的校准链与国际单位制联系起来的性质。工厂校准报告给出的是"出厂可信"，认可校准给出的是"法律意义上可信"——层级差异在报告用途，不在设备好坏。
:::

## 四、状态监测：指示灯、电池与固件

"免维护"不等于"不观察"。相关技术手册在操作与故障排除章节给出了三个日常可观察的窗口，它们是年检周期之间的连续监测手段。

### 指示灯：设备的"脸色"

所有单元正面的状态指示灯用**闪烁频率 + 颜色**编码状态，位置统一、跨单元一致：

![所有单元状态指示灯的常规状态：启动初始化（Normal 白）、升级固件（Normal 青）、识别（快 品红）、内部错误（固体 红）、空闲（慢 绿）](/images/rs-maintenance-calibration/fig5-led-states.png)

*（图源：网络官方公开资料）*

日常最该记住两条：**慢闪绿色 = 空闲**（健康待命），**固体红色 = 内部/意外错误**（立即处理）。识别功能（快闪品红）用于在多台设备里"点名"——通过 GUI 触发某台设备闪灯，确认你操作的到底是哪一台，这个功能在多台 REC 同场时非常实用。

### 电源缓冲器：58.4 Wh 的电池规则

UPS 单元内置锂离子电池组作为电源缓冲器，容量 **58.4 Wh**。断电时它接续供电，耗尽前系统会先让 REC 保存数据再安全关机——这是"数据不丢"的最后一道防线。日常规则有几条：

- **首次使用前充满电**；直流电源接入且电量足够时，UPS 会视当前负载自动充电；
- **充电窗口**：负载高于 **82 W** 时停止充电、降到 **75 W** 以下才恢复——大负载工况下别指望边采边充；
- **低温放电限制**：–25 °C 以下满载、–30 °C 以下 3/4 负载、–35 °C 以下 1/2 负载时缓冲器不可用；低温启动前按相关技术手册做快速放电（如 –20 °C 以下满载先快放至少 20 s，–15 °C 以下满载先快放至少 2 分钟）；
- **电池安全**：单元损坏、变形、受挤压应立即停用；损坏的电池**切勿运输、当地处置**，处理时保护眼睛与皮肤、远离易燃物。

### 固件更新：软件也是维护项

固件（含嵌入式 Recorder 应用程序）与 Testlab Neo 的更新包从官方支持门户下载，通过 Recorder 应用程序经 **SCRSA-CABN02**（REC 到 PC）电缆上传到 REC 单元；要更新其他单元还需 **SCRSA-CABN01**（菊花链连接至 PC）电缆。固件是签名的——防篡改，更新后 Web 应用行为异常先清浏览器缓存（Windows: Ctrl+F5）再排查。

## 五、年度之外：一张可抄进 SOP 的分层清单

把上述内容按执行频率分层，就是一套完整的维护计划。数字全部来自相关技术手册的规定值：

| 频次 | 项目 | 要点 |
| --- | --- | --- |
| **每次测前** | 连接器密封检查 | 未用连接器盖好盖子；清洁后确认干燥 |
| **每次测前** | 通道级验证 | 应变通道调零；电桥通道分流校准抽查 |
| **每次测前** | 指示灯巡检 | 空闲应为慢闪绿；红光立即排查 |
| **每次用车后** | 外观清洁 | 刷洗 + 温水；装车状态下冲洗不超 100 l/min、100 kPa、3 m |
| **每月** | 电池状态 | 缓冲器充满存放；82 W 停充/75 W 恢复的窗口内合理排负载 |
| **每季** | 固件版本核对 | 官方门户查更新；更新后清缓存验证 Web 应用 |
| **每年** | 校准送检 | 客户支持团队执行；需正式溯源走 ISO 17025 认可实验室 |
| **报废时** | 合规处置 | 按当地法规处置、回收可回收件；**电池切勿运输、当地处置** |

这张表的关键结构是"**高频轻动作、低频重动作**"：测前的检查都是几十秒级的小事，年度校准是唯一需要外部资源的大动作。把高频项做扎实，年度校准拿到手的就是"没有意外"的报告——这正是运动员类比的全貌：日常看脸色、赛后正确冲澡、每年一次权威体检，三者缺一不可，但没有一件需要"开胸手术"。

::: tip 实用建议
- 恶劣环境（盐雾/泥水）项目结束后当天清洗，盐分干燥后对连接器密封面的侵蚀远大于湿态；
- 多台 RS 同场时，先用"识别"闪灯功能点名再操作，避免配置写错设备；
- 校准合同谈判时确认量值溯源层级：普通年度校准与 ISO 17025 认可校准的证书用途不同，按报告需求选。
:::

## 六、小结

- "内部没有用户可维修的零件"是设计宣言也是维护边界：用户侧的全部维护收缩为清洗、校准、状态监测三类外部动作；
- 清洗分装车与单件两套规程：装车可冲洗但三参数（100 l/min、100 kPa、3 m）同时受限，单件禁止近距离高压、必须先密封所有连接器；
- 校准三层级：出厂工厂校准附报告、建议每年由客户支持团队校准、需正式溯源走 ISO 17025:2017 认可实验室（RVA K159 范围）；
- 日常三窗口：指示灯（频率+颜色编码状态）、58.4 Wh 电源缓冲器（82 W/75 W 充电窗口与低温放电限制）、签名固件（官方渠道更新）；
- 维护计划按频率分层：测前秒级检查、每月电池、每季固件、每年校准——高频轻动作 + 低频重动作。

## 一句话记住

SCADAS RS 像常年马拉松的运动员：免手术不等于免管理——赛后按参数冲澡（100 l/min、100 kPa、3 m 或单件手洗盖好盖）、每年一次权威体检（年度校准/ISO 17025 溯源）、日常看脸色（灯色与电池规则），三件事做对就是全部。
