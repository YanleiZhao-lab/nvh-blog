# 振动台选型与使用：推力、位移、承载

> 要跑一个 2700 N（600 lbf）推力的试验，照着样本册买一台"2700 N 振动台"回来，装上试件第一天就推不到位——这不是段子，是振动试验室最贵的选型错误之一。额定推力是"裸台"的出厂成绩单，夹具、试件、水平滑台的每一公斤都要从这份成绩单里扣钱。本文把电动振动台比作一名**举重运动员**：杠铃片（试件+夹具）多重、动作幅度（位移）多大、爆发速度（速度）多快、肌肉极限（推力）多少，四个数字共同决定他能不能完成你的"比赛动作"；沿着这条主线讲清性能曲线的三段受限区、推力公式 F=B·L·I 的力从哪里来、选型为什么要留 15%~20% 余量、平均控制什么时候救场，以及用裸台传递函数给振动台做"体检"的完整 Testlab 流程。

## 一、为什么"额定推力够"不等于"试验能跑"

先看工程现场最常见的一幕。某零部件按规范要做峰值 20 g 的正弦振动，试件 10 kg、夹具 8 kg。工程师翻样本册，看中一台额定正弦推力 356 N（80 lbf）的小台——20 g × 10 kg = 196 N，还剩 160 N 余量，"绰绰有余"。装机开跑，低频段还没问题，一到高频控制仪就报警，怎么都推不到 20 g。

账错在哪里？他只算了试件的重量，没算**全部运动质量**：动圈（armature）本身、夹具、螺栓、线束，全部要被同一台"运动员"举着做同样的加速度。牛顿第二定律一步见分晓——假设动圈运动质量 2 kg，总运动质量是 2+8+10 = 20 kg，需要的推力是 20 kg × 20 g ≈ 3924 N，比 356 N 大了一个数量级。这就是"照额定推力买台子"必然翻车的原因：**额定推力是台子自己的极限，不是你试验的可用推力**。

::: info 核心概念
- **动圈（Armature）**：振动台的运动部件，试件通过夹具装在它上面，连同动圈一起振动
- **额定推力（Force Rating）**：制造商在裸台条件下给出的正弦峰值推力上限，不含试件与夹具质量
- **运动质量（Moving Mass）**：动圈 + 头扩展台/滑台 + 夹具 + 紧固件 + 线缆 + 试件的总和，全部消耗推力
- **性能曲线（Performance Curve）**：裸台加速度对驱动电压的传递函数（g/V）随频率的变化，是振动台的"体检基线"
:::

厂商描述振动台能力时习惯给三个极限，本文沿用"举重运动员"的比喻贯穿全文：**举得多重**（力极限）、**蹲得多深**（位移极限）、**起身多快**（速度极限）。一名运动员挺举极限 200 kg，不代表他能以任意速度、任意幅度举起 200 kg——杠铃行程大了举不快、动作快了举不起最大重量。振动台同理，下一节把这三个极限放进同一张图。

## 二、性能曲线：一条曲线上的三段"体能极限"

振动台对单位驱动电压的响应并非在全频段一致，低频段尤其受最大位移与最大速度的限制。工作频率范围的上限，国际标准 ISO 5344 规定为动圈一阶固有频率的 1.5 倍——动圈自己也是一个弹性结构，越过这条线，"运动员"的动作开始变形。

大多数制造商发货前会提供性能曲线。做法是：裸台（只装一只测量加速度计，无夹具无试件）上做激励，把加速度谱除以功放驱动电压谱，得到以 g/V 为单位的传递函数。取传递函数而非直接取加速度响应的好处是：无论驱动电压是 50、100 还是 500 mV，得到的曲线都一致（图 3 上下两图的对比正说明这一点——下图中三条不同电压的响应谱幅度不同，上图中三条传递函数完全重合），因此可以与历史数据直接比对。

![不同驱动电压下的响应谱（下）与归一化后的传递函数（上）：传递函数与电压无关](/images/shaker-table-considerations/fig3.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

性能曲线全貌如下：

![振动台性能曲线：低频位移限制、中频速度限制、高频力限制三段](/images/shaker-table-considerations/fig4.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

三段受限区对应运动员的三种"体能瓶颈"：

| 区段 | 受限量 | 运动员类比 | 物理原因 |
| --- | --- | --- | --- |
| A 低频 | 最大位移（行程） | 蹲到最深处举不动更重 | 动圈悬挂与挠性件行程有限，低频大位移先顶到机械限位 |
| B 中频 | 最大速度 | 起身速度有上限 | 功放电压/电流与磁路决定的极限速度 |
| C 高频 | 最大力（加速度） | 挺举极限重量 | 电磁推力上限，对应空载最大加速度 |
| D 频率上限 | 动圈一阶共振 ×1.5 | 心率爆表 | ISO 5344 规定的工作频率上限 |

先用一组数字把"三段瓶颈"的切换看清（示意数量级：峰值位移 25 mm、峰值速度 1.6 m/s、空载 50 g）。位移、速度、加速度对正弦振动各有各的换算关系：给定频率，位移幅值对应加速度按平方律放大、速度幅值按线性放大，实际可达加速度取三者最小值。5 Hz 时位移率先顶死（约 2.5 g），20 Hz 换速度顶死，50 Hz 以上力顶死在 50 g。**同一台台子，5 Hz 和 500 Hz 的"能力"差 20 倍——读性能曲线时看的不是一条水平线，而是一道峡谷的轮廓。**

## 三、推力从哪里来：磁场里的安培力

电动振动台（electrodynamic shaker）的结构剖视如下：

![振动台剖视图：动圈、励磁线圈、挠性件、导向轴承、气动支撑等](/images/shaker-table-considerations/fig2.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

主要部件：**动圈**（黑色，运动部件，试件装于此）、**音圈**（橙色，绕在动圈上的铜线/铜管，通电后产生交变磁场）、**台体**（蓝色，铁磁材料）、**励磁线圈**（浅橙，通电产生静磁场；小台用永磁体）、**挠性件**（品红，连接动圈与台体的 J 形弹性件）、**导向轴承**（紫色，中间立柱，防止动圈倾转）、**气动支撑**（深蓝，承担试件重量、保持动圈居中）、**隔离支座**（绿色，通常为气袋，隔离台子对试验大厅的振动传递）。

运行时，功放给励磁线圈加恒定电压建立静磁场；给音圈加时变电压，音圈电流在静磁场中受力，拖着动圈往复运动。这个力就是载流导线在磁场中受的安培力（洛伦兹力的宏观形式）。

这个公式回答的问题是：一台振动台到底能输出多大的力。其中 $B$ 对应物理里的磁通密度（气隙中的静磁场强度）、$L$ 是磁场中铜线的有效总长度、$I$ 是音圈电流——三者的乘积就是可用推力。

$$F = B \, L \, I$$

可用推力由音圈绕线长度、通过音圈的电流、磁场强度三者共同决定。三个因子对应三条工程约束：$L$ 长（绕组多）则电阻与电感大、需要更高电压驱动；$I$ 大则发热严重（铜损与电流平方成正比）；$B$ 强则磁路体积重量上升。**"运动员的肌肉"是三者的折中产物，这也是同等推力下不同厂家的台子体积差异很大的原因。**

### 温升：肌肉会"热软"

铜的电阻温度特性不可忽视：**每升高 100 摄氏度，铜线电阻增大约 40%**。电压不变时电流按欧姆定律同比下降，推力随之降到原来的约 71%——高温下的运动员举不起常温下的杠铃。这就是大型振动台必须配备冷却（风冷、水冷或厂家各自的方案）的原因：不是保护性点缀，而是保住推力额定值的物理前提。

## 四、选型三笔账：运动质量、激励类型、频带

### 第一笔账：全部运动质量都要"吃"推力

计划试验时，运动质量必须按全系统计算：不只试件（DUT，Device Under Test），还有全部夹具、紧固件、线束等。这个公式回答的问题是：这台台子带着我的试件，最多能给出多大加速度。其中 $F$ 对应物理里的台子可用推力（应按扣除余量后的值取），$m$ 是包括动圈、夹具、试件在内的总运动质量——牛顿第二定律直接给出上限：

$$a_{\max} = \frac{F}{m}$$

推力一定时，试件越重可达加速度越低，两者成反比。举一个量级感清晰的算例（第七节附 numpy 复算）：额定正弦推力 400 N、动圈 2 kg、夹具 8 kg 的台子，试件 2 kg 时总运动质量 12 kg，可跑 3.4 g；试件加重到 20 kg，总质量 30 kg，只剩 1.4 g——试件重了 10 倍，可用加速度掉到四成以下，因为夹具与动圈的"死重"也在分推力。

### 第二笔账：激励类型改变推力口径

同一台振动台，正弦试验与随机试验的力限额不同——随机推力额定值通常规定在有限频带上（典型到 2000 Hz），在更窄频带内做随机试验时可用推力按能量比例折减。原文给出的折减公式以图片形式呈现：

![窄带试验时可用推力的折减公式](/images/shaker-table-considerations/eq2.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

折减规律是可用推力按频带宽度的平方根缩放：2000 Hz 全带宽额定 400 N 的台子，在 500 Hz 带宽内只剩 200 N（50%）、200 Hz 带宽内只剩 126 N（32%）——频带砍掉四分之三，推力掉到不足三分之一。规划窄带随机试验前必须先算这笔账。

### 第三笔账：15%~20% 余量

需要 6000 lbf 推力的试验，不要买 6000 lbf 额定的台子——制造商普遍建议选型时留 **15%~20% 推力余量**，理由至少有四条：

1. 额定推力不含试件与夹具质量（第一笔账）；
2. 振动试验是动态过程，共振/反共振会瞬时抬高推力需求（试件在共振点"顶"台子，反共振点"吸"推力）；
3. 正弦与随机的力限额口径不同（第二笔账）；
4. 温升吃掉推力（第三节）。

### 水平滑台与多台型式

大试件多方向试验常用水平滑台（slip table）或双台并激，此时滑台油膜、连接牛鼻（bullnose/driver bar）的质量与摩擦也要进第一笔账的"运动质量"里。

![多轴（左）、垂直（中）、水平（右）三类振动台](/images/shaker-table-considerations/fig1.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

商用电动振动台的推力覆盖从 9 N（2 lbf）到 356 kN（80000 lbf），液压台还能做得更大。本文讨论以 450 N（100 lbf）以上的环境试验（耐久）台为主；模态激振器、传递路径用小激振器不在范围内。

## 五、平均控制：夹具不完美时的补救

标准做法不建议把试件直接装在动圈上，而是先在动圈上加装刚性头扩展台（head expander），再把试件装在扩展台上——目的是在试件接口处形成一个输入均匀的台面。但**任何夹具都有固有模态**，台面上各点的振动并不完全一致。当输入不均匀影响到试验质量时，平均控制（average control）是可行的补救。

水平滑台的一种典型情况：台面边缘各点振动量级不一致（图 5），此时沿边缘布置两只或更多控制加速度计做平均。

![滑台边缘多点平均控制](/images/shaker-table-considerations/fig5.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

另一种情况：靠近牛鼻（驱动杆接口，"前"侧）的振动量级高于远端（"后"侧）。假设力沿前后线性滚降，前后各放一只控制加速度计做平均（图 6），即可在两只表之间复现参考量级。

![前/后控制点平均：在两表之间得到参考量级](/images/shaker-table-considerations/fig6.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

最常见的一种：试件有多个安装接口（图 7），在每个接口处各放一只控制加速度计取平均，垂直/水平方向都适用。

![试件多点接口的平均控制](/images/shaker-table-considerations/fig7.png)

*（图源：Siemens Simcenter Testing Knowledge Base）*

注意：是否需要平均控制取决于具体设置。稳妥的做法是先在台面多放几只加速度计摸一遍数据，确认确有明显不均匀再用平均控制或其他手段处理。

## 六、振动台"体检"：裸台传递函数监测

造得好的振动台能服役几十年，但和汽车一样需要定期保养，也可能被推到能力极限的高量级试验损伤：导向轴承磨损、动圈变形或开裂、音圈绕组脱层、挠性件疲劳……部件疲劳会改变振动台的性能。**监测方法：定期测一次"裸台传递函数"，与历史数据比对。** 传递函数由裸台加速度谱除以控制器输出给功放的驱动电压谱得到，一台健康台子的这条曲线终生不应变化——变了，就说明台子或功放出了问题。

回到运动员的比喻：体检不是让他再举一次最重的杠铃，而是用同一根固定的"标准杠"（恒定电压扫频）看他每个动作速度下的响应——今天和五年前举同一根杠的反应应当一模一样。

测量流程五步（Simcenter SCADAS + Testlab Tracked Sine Dwell）：

1. **物理连接**：SCADAS 信号源输出的驱动电压用 T 头分一路进采集输入通道（设为控制/参考通道），功放输出接台子；裸台动圈上装一只测量加速度计（图 8）。
2. **软件配置**：Testlab Tracked Sine Dwell 模块，通道设置见图 9。
3. **功放"标定"**：功放增益先归零（保持通电），在单一频率（典型 100 Hz）上驻留，缓慢增大增益直到加速度计读到预设量级（典型 1~2 g，拿不准时咨询台子厂商）。
4. **扫频**：转入 Sine 控制模块做扫频，得到全频段传递函数（图 10~11）。
5. **比对**：Navigator 中把新曲线与历史曲线叠加，应当重合（图 12，两条不同年代的曲线重叠）。

## 七、numpy 对账：三笔账一起算

```python
import numpy as np

F_rated, arm, fixture = 400.0, 2.0, 8.0   # N, kg, kg

# 第一笔账：总运动质量吃掉多少加速度
for m_dut in (2.0, 10.0, 20.0):
    m = arm + fixture + m_dut
    print(f"DUT {m_dut:>4.0f} kg -> 总运动质量 {m:>4.0f} kg, "
          f"可达峰值 {F_rated/m/9.81:.1f} g")

# 第二笔账：窄带随机推力折减（额定带宽 2000 Hz）
for band in (2000, 1000, 500, 200):
    print(f"带宽 {band:>5} Hz -> 可用推力 {F_rated*np.sqrt(band/2000):>5.0f} N "
          f"({np.sqrt(band/2000)*100:>3.0f}%)")

# 第三笔账：温升吃掉推力（铜阻每 100 摄氏度涨 40%，电压不变）
R = np.array([1.0, 1.4])                  # 常温 / +100 度
F_drop = R[0]/R[1]
print(f"电压不变时 +100 度: 推力降至 {F_drop*100:.0f}%")
```

实测输出（numpy 2.x）：

```text
DUT    2 kg -> 总运动质量   12 kg, 可达峰值 3.4 g
DUT   10 kg -> 总运动质量   20 kg, 可达峰值 2.0 g
DUT   20 kg -> 总运动质量   30 kg, 可达峰值 1.4 g
带宽  2000 Hz -> 可用推力   400 N (100%)
带宽  1000 Hz -> 可用推力   283 N ( 71%)
带宽   500 Hz -> 可用推力   200 N ( 50%)
带宽   200 Hz -> 可用推力   126 N ( 32%)
电压不变时 +100 度: 推力降至 71%
```

三笔账叠加的含义很直白：标称 400 N 的台子，做一个 20 kg 试件、200 Hz 带宽、功放偏热的随机试验，推力口径先折到 126 N、温升再打七折只剩约 90 N——不到铭牌的四分之一。选型留 15%~20% 余量不是保守，是把这三笔账一次算清后的下限。

## 一句话记住

振动台是一名举重运动员：低频比蹲深（位移）、中频比起身速度、高频比挺举极限（F=B·L·I）；运动质量全算、窄带按平方根折减、温升再打七折，最后留 15%~20% 余量，并用裸台 g/V 传递函数定期体检。
