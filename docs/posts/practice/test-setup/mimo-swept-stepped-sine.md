# 扫频与步进正弦 MIMO：另一种激励路线

> 同一台白车身，随机激励 MIMO 半小时测完的 FRF 在某阶轻阻尼模态处峰值比仿真低了一截，改用步进正弦重新测，峰值"长"回来 30%——是结构变了，还是激励方式在说谎？答案往往是后者：随机激励把能量摊到全频段，每个频率分到的功率有限；正弦激励把全部能量逐个频率投放，共振峰处的信噪比天然更高。这就像用喷淋花洒和聚焦水枪冲洗同一块污渍：花洒覆盖快、单点冲力弱，水枪单点冲力强、但要一寸一寸挪。Simcenter Testlab 的 MIMO Swept and Stepped Sine 软件包走的就是"水枪"路线：多台激振器输出受控正弦，频率连续扫过（扫频）或逐级步进（步进），把每个频率上的激励能量和响应幅值钉在目标谱上。本文说明扫频与步进的物理差别、扫速为什么必须慢过共振建立时间、闭环控制与系统辨识怎么做，以及 Testlab 里从通道设置到采集的完整操作路径。

一个真实的对比试验很能说明问题：某航天器部件模态试验先用 burst random MIMO 完成，阻尼比 0.4% 的一阶模态拟合出的阻尼比明显偏高、峰值偏低；同一状态改用步进正弦复测，共振区 0.05 Hz 步距加密，拟合阻尼比回落 20%，与有限元仿真终于对上。两次试验结构没变、传感器没动，变的只是激励把能量"喂"给每个频率的方式。

## 一、为什么需要正弦激励：随机 MIMO 之外的第二条路线

《[MIMO 多输入多输出测试](mimo-testing.html)》里分析的 MIMO 随机激励把宽带能量一次性洒向全频段，测 FRF 靠谱平均统计。多数模态试验这就够了，但有两类工况例外。

第一类是**轻阻尼、高信噪比要求**的试验。阻尼比 0.5% 的模态，半功率带宽只有约 1 Hz（带宽等于两倍阻尼比乘固有频率），随机激励在这个 1 Hz 里分到的能量很少，峰值处信噪比不足，FRF 峰值被低估。第二类是**幅值必须严格受控**的试验：脆性试件、带非线性连接的部件，或者验收规范直接写了"指定频率、指定加速度级"（如典型的 1 g 定频检测）——开环激励的幅值随结构阻抗起伏，根本无法保证。

正弦激励的答案很直接：任何时刻只激励一个频率，全部激励功率集中在这一条谱线上。Simcenter 官方知识库的总结一针见血：扫频测试耗时更短，但激励能量是"摊开"的；步进正弦耗时更长，但每个频率都被充分激励（Figure 1）。

![扫频与步进正弦对比：扫频省时间，步进在每个频率上能量更集中](/images/mimo-swept-stepped-sine/fig1.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

两类正弦的具体差别：

- **扫频正弦（Swept Sine）**：单一正弦波的频率随时间连续变化。扫过每个频率只停留一小段，测试总时间短；代价是共振"来不及完全建立"，峰值略有损失（第二节定量演示）。
- **步进正弦（Stepped Sine）**：频率逐级跳变，在每个频率上停留若干整周期、等响应稳定后再测量，然后跳下一级。每个频率激励充分、估计精度高；代价是总时间长。

| 维度 | **扫频正弦** | **步进正弦** | **随机 MIMO** |
| --- | --- | --- | --- |
| 单频率激励能量 | 中（扫过时集中） | 高（逐点驻留） | 低（摊到全带） |
| 测试总时间 | 中 | 长 | 短 |
| 峰值估计精度 | 受扫速限制 | 高（稳态后测量） | 受平均次数限制 |
| 幅值闭环控制 | 可（跟踪目标谱） | 可（每步收敛） | 可（均衡） |
| 频率步距 | 连续 | 可变（共振区加密） | 固定谱线间隔 |

先把量级摆出来：同样 1 N 的激励能力，随机激励在 0～2000 Hz 带宽内把功率摊给约 800 条谱线，每条谱线分到的有效幅值只有约 0.035 N（1 除以根号 800）；正弦激励则把整个 1 N 都押在当前频率上——单频激励能量相差近 30 倍，这就是轻阻尼模态在随机激励下峰值总是"矮一截"的算术根源。也是"花洒与水枪"类比里两种水流的物理对应：花洒的总水量可以更大，但单位面积冲力取决于聚不聚焦。

时间账同样直观：扫频正弦以 2 Hz/s 扫过 20～200 Hz 需要 90 秒；步进正弦若以 1 Hz 步距、每点驻留 2 秒，需要约 360 秒；同样的带宽若共振区加密到 0.1 Hz、驻留 4 秒，时间涨到半小时以上。精度的代价就是时间，没有免费的午餐。

## 二、扫与步的物理账：为什么共振区必须慢下来

回到"水枪冲污渍"的类比：水枪冲力再强，一扫而过也只能洗掉浮灰——顽固污渍需要停留。结构共振也一样：共振幅值的建立需要时间，阻尼越小、需要的建立时间越长。扫频正弦经过共振峰时若扫得太快，响应来不及爬到稳态值，测到的峰值就偏低，而且峰值出现的时刻被"拖"到频率已经扫过共振点之后。

这个建立时间可以定量写出。这个公式回答的问题是：**共振幅值爬到稳态需要多久？**其中 τ 对应物理里的"包络时间常数"——共振包络按指数逼近稳态，每过一个 τ 衰减剩余差距的 63%，爬到 98% 需要 4 个 τ：

$$\tau = \frac{1}{2\pi \zeta f_0}$$

其中 ζ 是阻尼比，f0 固有频率。100 Hz、阻尼比 2% 的模态，τ 约 80 ms；阻尼比 0.5% 时 τ 约 318 ms。

第二个约束是**驻留时间要覆盖半功率带宽**。这个不等式回答的问题是：**扫过一个共振峰至少要花多少时间？**其中 T_res 对应物理里的"扫过半功率带宽 2*ζ*f0 的耗时"——它应不短于数个建立时间常数 τ：

$$T_{res} = \frac{2 \zeta f_0}{R} \geq 4 \tau = \frac{2}{\pi \zeta f_0}$$

其中 R 是扫速（Hz/s）。移项即得扫速上限的量级估计：

$$R \leq \pi \zeta^2 f_0^2$$

100 Hz、阻尼比 0.5% 的模态代入：R 上限约 0.79 Hz/s。也就是说，要让这阶模态的峰值爬满 98%，扫过它附近必须慢于约 0.8 Hz/s——快一个量级的 10 Hz/s 快扫意味着什么，下面用仿真定量回答。

用 100 Hz、阻尼比 0.5% 的单自由度系统做线性扫频仿真（20-200 Hz，扫速 0.5-10 Hz/s），峰值达到稳态值的比例与峰值位置漂移如下（第五节给出可复现代码）：

| 扫速 | 峰值/稳态值 | 峰值处瞬时频率 | 停留半功率带内时间 |
| --- | --- | --- | --- |
| 0.5 Hz/s | 97.3% | 100.3 Hz | 2.0 s（约 6.3 个 τ） |
| 1 Hz/s | 93.7% | 100.5 Hz | 1.0 s（约 3.1 个 τ） |
| 2 Hz/s | 87.6% | 100.7 Hz | 0.5 s（约 1.6 个 τ） |
| 5 Hz/s | 75.5% | 101.4 Hz | 0.2 s（约 0.6 个 τ） |
| 10 Hz/s | 64.4% | 102.1 Hz | 0.1 s（约 0.3 个 τ） |

10 Hz/s 的"快扫"把峰值削掉了 35.6%，峰值位置被拖后 2.1 Hz——如果拿这条 FRF 去拟合模态频率和阻尼，系统误差就吃掉了工程容差。这正是 Testlab 提供 Tabulated 扫速的原因：共振区慢扫、共振区外快扫，总时间与精度两头兼顾。

步进正弦从机制上回避了这个问题：每个频率点上激励保持到响应稳定（软件按设置的周期数估计幅值），测完再跳到下一个点，测到的就是稳态响应。代价是时间——共振区要加密步距（如 0.1 Hz）、每点又要驻留若干周期，一段 1 Hz 带宽可能就要几十分钟。

::: info 核心概念
- **扫频正弦（Swept Sine）**：正弦频率随时间连续变化的激励方式，测试快，峰值精度受扫速限制
- **步进正弦（Stepped Sine）**：频率逐级步进、每点驻留至稳态的激励方式，精度高、耗时长
- **扫速上限**：由模态建立时间 τ = 1/(2*pi*ζ*f0) 与半功率带宽共同决定，量级为 pi*ζ^2*f0^2，共振区必须慢扫
- **驻留周期数（Number of Periods）**：每频率点用于幅值估计的周期数，越多估计越稳、时间越长
:::

## 三、Testlab 里的正弦 MIMO：从通道到采集

Simcenter Testlab 的 MIMO Swept and Stepped Sine 是 Structure Acquisition 目录下的独立软件包，与 SCADAS 硬件配合完成多输入正弦激励与 FRF 测量。硬件连接与随机 MIMO 一致：力传感器与加速度计布点、多台激振器经功放接 SCADAS 输出通道、以太网连接测试机（Figure 2）。

![双激振器扫频/步进正弦试验布置示例](/images/mimo-swept-stepped-sine/fig2.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

启动入口在 Testlab Structure Acquisition 文件夹的"MIMO Swept and Stepped Sine Testing"图标。通道设置（Channel Setup）工作表里，除了常规的传感器标定与测点信息，要做闭环正弦测试至少定义一个**控制通道（Control）**与一个**参考通道（Reference）**。控制通道选力或加速度，两种组合测出的传递特性含义不同：

- 控制选加速度、测量也选加速度：得到的是**传递率（Transmissibility）**——两个结构响应之比；
- 控制选力、测量选加速度：得到的是**真正意义上的 FRF**——加速度响应除以激振力。

### 关键参数一：模式与控制策略

MIMO Sine Setup 工作表右上角的控制面板集中了主要试验参数（Figure 3）。

![MIMO Sine Setup 工作表的控制面板：模式、控制策略、扫速、频率范围、扫数](/images/mimo-swept-stepped-sine/fig4.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

- **MIMO sine mode**：Stepped 或 Swept，对应步进/扫频；
- **Control strategy**：No Control（开环，输出不随响应调整）、Amplitude/Phase（幅值相位双控）、Amplitude（仅幅值控制）。闭环控制根据控制通道的实测与目标谱的偏差实时修正输出；
- **Sweep Rate / Number of Periods**（扫频）：扫速可设为固定值，或 Tabulated 分频段设置——共振区慢扫就在这里做；
- **Frequency Ranges**（步进）：设定最低/最高频率与步距，同样支持分频段不同步距；
- **Sweep Mode**：Linear（线性等步距）或 Log（低频细、高频粗）；
- **Number of Sweeps**：扫程重复次数。

扫速 Tabulated 编辑器里可以按频段分别设置周期数与扫速（Figure 4）。官方给出的操作要点是：降低扫速有助于更好地跟踪目标幅值，尤其在共振频率附近放慢扫速；增加周期数提高幅值估计质量，但拉长试验时间。

![Tabulated 扫速编辑器：按频段分别设置周期数与扫速](/images/mimo-swept-stepped-sine/fig5.png)

步进正弦的 Frequency Ranges 菜单（Figure 5）定义各频段的步距——共振区 0.1 Hz、其它区域 1 Hz 这样的非均匀布置是标准做法。值得注意的是，Polymax 模态拟合器支持非等间隔频率分辨率的 FRF，步进正弦的变步距数据可以直接进拟合流程。

### 关键参数二：扫数与相干

Number of Sweeps 设为 2 及以上时，每次扫程用**不同的激振器相位组合**重复。这一点和随机 MIMO 用多次平均估计 FRF 的逻辑一致：多次扫程平均之后才能算出有统计意义的 FRF 与相干。官方文档特别提醒：只扫一次时没有平均，相干在每个频率上都完美等于 1——这个 1 不含任何信息，与《[相干函数](../theory/signal-processing/coherence-function.html)》里"单帧相干恒为 1"是同一回事。相干此时衡量的是多次扫程的**重复性**：越接近 1，系统越接近线性时不变、激励越稳定。

### 关键参数三：参考谱与安全

Source Parameters 面板打开各输出通道后，在 MIMO Sine Setup 底部的 Edit Reference Profile 里逐激振器输入目标幅值谱（频率-幅值表，Figure 6）。表中只填幅值与对应频段，相位与频率步距/扫速在其它菜单设置，且频率范围必须覆盖 Frequency Ranges 设定的区间。

![Edit Reference Profile：逐激振器输入频率-幅值目标谱](/images/mimo-swept-stepped-sine/fig7.png)

Safety 区的 Advanced 设置里，OverloadAction 建议改为 Increase Range：扫到共振峰时响应可能突增，软件自动升量程避免试验中断，比默认的停机更稳妥。

## 四、系统辨识：正式试验前的彩排

System Identification（2206 版之前叫 SelfCheck）是正式试验前的强制步骤：向激振器发送低量级宽带随机信号，逐级加量直到达到设定的信噪比，测量功放输出到控制通道的系统传递函数（典型单位 g/V），并外推全量级下各测点的预测响应。这一步回答三个问题：闭环控制在设定参数下能不能跑得起来、有没有通道会过载、驱动到控制的相干好不好。

低相干、过载预测、开路通道是最常见的三类问题：控制加速度计安装不牢或位置不当会造成驱动-控制相干跌落；满量级过载提示换更钝的传感器（如 100 mV/g 换 10 mV/g）或向量程；传感器响应低于本底噪声则提示断线或传感器故障（Figure 7）。

![System Identification 工作表：低量级随机信号辨识系统传递特性](/images/mimo-swept-stepped-sine/fig8.png)

*(图源：Siemens Simcenter Testing Knowledge Base)*

对正弦 MIMO 有个实用技巧：如果该试件已经做过一次正弦采集，System Verification 工作表左上角可选 Load Last MIMO Acquisition，直接用上一次试验的实测数据代替低量级随机辨识。前次实测的响应特性比低量级宽带辨识更接近真实，目标谱的跟踪也更准。

正式采集在 MIMO Sine Acquisition 工作表：Arm 后 Start。进行中可 Hold/Release 暂停（两种模式都支持），扫频模式还能在试验中实时 Speed Up / Speed Down，共振附近临时放慢、过了共振再提速，是应对未知密集模态的常用手法（Figure 8）。

![试验进行中的操作按钮：Hold/Release 暂停，扫频中可实时调速](/images/mimo-swept-stepped-sine/fig9.png)

## 五、数值演示：扫速吃掉了多少峰值

下面这段自包含 numpy 代码复现第二节的表格：100 Hz、阻尼比 0.5% 的单自由度系统，20-200 Hz 线性扫频，比较不同扫速下的峰值与峰值位置。离散化用增广矩阵指数（零阶保持），不需要微分方程数值库：

```python
import numpy as np

def disc_sys(f0, zeta, fs=20000.0):
    w0 = 2*np.pi*f0                  # 状态 [y, v], y'' + 2*z*w0*y' + w0^2*y = x
    M = np.zeros((3, 3))
    M[0, 1] = 1.0
    M[1, 0] = -w0*w0
    M[1, 1] = -2*zeta*w0
    M[1, 2] = 1.0
    dt = 1/fs
    E = np.eye(3); P = np.eye(3).copy()   # 矩阵指数级数 (A*dt)^n / n!
    for n in range(1, 60):
        P = (P @ (M*dt)) / n
        E = E + P
    return E[:2, :2], E[:2, 2]           # Ad, bd（零阶保持）

def sweep(f0, zeta, rate, f1=20.0, f2=200.0):
    T = (f2-f1)/rate                     # 线性扫频总时长
    t = np.arange(int(T*20000))/20000
    x = np.sin(2*np.pi*(f1*t + 0.5*rate*t**2))
    Ad, bd = disc_sys(f0, zeta)
    state = np.zeros(2); y = np.empty(len(t))
    for k in range(len(t)):
        state = Ad @ state + bd*x[k]
        y[k] = state[0]
    kf = f1 + rate*t                     # 瞬时频率
    i = int(np.argmax(np.abs(y)))
    return np.abs(y).max(), kf[i]

f0, zeta = 100.0, 0.005                  # 100 Hz, 阻尼比 0.5%
w0 = 2*np.pi*f0
steady = 1/w0**2/(2*zeta)                # 稳态共振幅值（解析）
tau = 1/(2*np.pi*zeta*f0)
print(f"稳态峰值 {steady:.3e}, 建立时间常数 {tau*1000:.0f} ms")
for r in [0.5, 1, 2, 5, 10]:
    pk, pf = sweep(f0, zeta, r)
    print(f"{r:>4} Hz/s: 峰值 {pk/steady*100:5.1f}% 稳态值, 峰值处 {pf:6.1f} Hz")
```

运行输出（阻尼比 0.5%，τ 约 318 ms，半功率带宽 1 Hz）：

| 扫速 | 峰值/稳态值 | 峰值处瞬时频率 |
| --- | --- | --- |
| 0.5 Hz/s | 97.3% | 100.3 Hz |
| 1 Hz/s | 93.7% | 100.5 Hz |
| 2 Hz/s | 87.6% | 100.7 Hz |
| 5 Hz/s | 75.5% | 101.4 Hz |
| 10 Hz/s | 64.4% | 102.1 Hz |

两个规律值得记下：**峰值损失随扫速单调加剧**，10 Hz/s 时只剩 64.4%；**峰值位置系统性后移**，惯性使响应峰值滞后于扫过的频率，快扫时漂移超过 2 Hz，直接进拟合器会同时污染频率与阻尼估计。反过来讲，若试验目的是识别轻阻尼模态的精确阻尼比，要么用足够慢的扫速，要么干脆用步进正弦。

同样的代码把 zeta 改为 0.02（2% 阻尼）再跑一遍：带宽展宽到 4 Hz、τ 缩短到 80 ms，10 Hz/s 快扫下峰值仍有 96.2%，阻尼越大，对扫速越不敏感。这也解释了为什么同一套扫速参数在汽车车身（阻尼 1%-3%）上没事，搬到阻尼 0.2% 的航空复合材料壁板（如 GVT 试验）上就出问题：试件阻尼越低，越需要慢扫或步进。

## 六、选型指南：什么时候用哪种

| 试验场景 | 推荐激励 | 理由 |
| --- | --- | --- |
| 通用模态测试，阻尼大于 2% | 随机 MIMO / 锤击 | 覆盖快，统计平均够用 |
| 轻阻尼结构精确阻尼识别（小于 1%） | 步进正弦 | 稳态测量，峰值不失真 |
| 大频率范围快速摸底 | 扫频正弦（Tabulated 慢扫共振区） | 兼顾时间与关键频段精度 |
| 指定频率定幅值检测（如 1 g 定频） | 步进正弦 + 闭环 | 幅值严格收敛到目标 |
| 强非线性部件（连接松动、间隙） | 步进正弦变幅值多轮 | 每个频率点可做幅值扫描查非线性 |
| GVT / 航空复合材料 | 步进正弦为主 | 阻尼极低，带宽极窄 |

一句话原则：**先把"要什么"说清楚，要快还是要准、要宽带覆盖还是要单点能量、结构阻尼多高，激励方式自然就定了。**花洒与水枪从来不是谁替代谁，而是各有各的污渍。

## 一句话记住

正弦 MIMO 把全部激励能量逐频率投放：扫频快但峰值受扫速限制（共振区必须慢扫，快扫削峰、拖峰），步进准但耗时；建立时间 τ = 1/(2*pi*ζ*f0) 决定扫速上限，闭环控制靠系统辨识彩排，多次扫程才能算出有意义的相干。
