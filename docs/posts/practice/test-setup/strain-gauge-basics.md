# 应变片原理与选型：金属箔式、阻值、温度补偿

> 同一根拉杆，贴 120 Ω 片的通道数据"干净"，贴 350 Ω 片的通道却在高温车间里慢慢漂移——片都没坏，差别的账要算到焦耳热上。应力没法直接测，工程上的办法是测应变再乘弹性模量"换算"回去，而应变本身小到 10⁻⁶ 量级，只能靠"一根电阻丝被拉长变细、电阻随之变化"这个朴素效应放大出来。本文用"橡皮筋通电"类比讲清应变片从形变到电阻再到电压的完整链条：电阻定律、灵敏系数、惠斯通电桥三种接法，以及阻值选择、温度补偿、供桥电压这些选型现场必须对表的项目。

## 一、为什么疲劳试验台上贴的都是"小电阻片"

耐久试验室的日常：同一根车桥拉杆，仿真给出危险截面，试验工程师带着应变片和胶水上去，贴片、固化、焊线、组桥、标定，然后台架一开就是几百小时。为什么传感器家族里有加速度计、传声器、位移计，疲劳载荷谱却几乎清一色靠应变片？因为疲劳损伤的驱动量是**应力（Stress）**——应力超标才萌生裂纹，而应力几乎无法直接测量（混凝土应力计、土压力计是少数特例），常规路线是间接测量：先测**应变（Strain）**，再乘材料的弹性模量换算成应力。

这条路线在弹性范围内成立。一根金属圆柱受拉力 $F$，内部产生应力，同时沿轴向伸长：长度从 $l$ 变为 $l+\Delta l$。应力与应变的定义都是"强度除以基准"：应力是力除以横截面积，应变是伸长量除以原长。两者的比值在弹性段是常数，就是杨氏模量——这是胡克定律的内容，也是"测应变知应力"的合法性来源。

数值上感受一下这个量级：钢的屈服应力约 350 MPa、弹性模量 210 GPa，屈服前的应变只有 350/210000 ≈ 0.00167，写成微应变（με，10⁻⁶ m/m）是 1670 με。也就是说，1 米长的杆件屈服前只伸长 1.67 毫米；而疲劳高风险点的应变常常只有几百微应变，对应的长度变化是"米级杆件上零点几毫米"。把这么小的形变测准，还要在振动、温度变化的环境里跟踪它的时域历程——这就是应变片要解决的问题。

## 二、应变片：把形变翻译成电阻的"敏感橡皮筋"

先建立贯穿全文的类比：**应变片的核心是一根"通电的橡皮筋"**。取一根导电的细丝，它既有橡皮筋的力学属性——被拉长时变长又变细，又有电阻的电磁属性——越长越细电阻越大。把这样的细丝折成栅状、贴到零件表面，零件伸长它就跟着伸长，零件缩短它就跟着缩短；于是"零件的形变"被翻译成"细丝的尺寸变化"，再被翻译成"细丝的电阻变化"。整条测量链里，橡皮筋的"电阻读数"是唯一被测量的量，前面发生的力学传递全靠"贴得牢"来保证——这也是贴片工艺（表面打磨、清洗、胶层厚度、固化）直接决定数据质量的原因。

现代应变片不是绕线而是蚀刻的金属箔栅，但物理完全一样。解剖一枚应变片，有四个特征部位要认识：

![应变片的构造：敏感栅、 active length、横向段与基底](/images/strain-gauge-basics/fig4.png)
*（图源：Siemens Simcenter Testing Knowledge Base）*

- **敏感栅（薄电阻丝/箔栅）**：感知应变的元件，来回折弯成矩形栅格，使大部分丝长沿测量方向排布；
- **标距（Active Length）**：应变片是单轴传感器，测量方向就是标距方向。应变场方向已知时应沿最大主应变方向贴；方向未知时用应变花（三片定角集成，详见[应变花 Rosette](/posts/practice/durability-testing/rosette-strain-gauges.html)）；
- **栅格面积**：应变片测的是栅格面积内的平均应变——栅面积越小测点越局部，但小栅片散热差，会影响性能；
- **横向段**：垂直于测量方向的栅段对横向应变也有响应（横向灵敏度），是测量误差来源之一。

1938 年，加州理工的 Edward Simmons 与 MIT 的 Arthur Ruge 各自独立发明了粘贴式电阻应变片；MIT 当时放弃了 Ruge 的专利权，理由是这东西"虽然有趣，但看不出多大前景"——如今全世界的疲劳试验台上贴的仍是它的直系后代。

## 三、两条物理定律：从形变到电阻

应变片站在两条物理定律上。第一条回答"电阻从哪来"：一段导体的电阻由它的几何尺寸与材料电阻率共同决定。这个公式回答的问题是**"一根丝的电阻由什么决定"**——其中 $L$ 对应物理里栅丝的有效长度（拉长时增大）、$A$ 对应横截面积（拉长时按泊松比收缩）、$\rho$ 是材料电阻率（随温度变化，后面温度补偿的伏笔）：

$$R = \frac{\rho\, L}{A}$$

零件受拉时栅丝变长变细，两方面的变化都让电阻升高；受压则相反。第二条定律回答"电阻变化折算成应变怎么折"：定义**灵敏系数（Gauge Factor, GF）**为电阻相对变化与应变之比。这个公式回答的问题是**"电阻变化了多少，对应多大应变"**——其中 $\Delta R/R$ 是桥路直接读到的相对电阻变化，$GF$ 是厂家标定的比例系数（金属箔片典型值 2 左右），把它除过去就是应变：

$$\varepsilon = \frac{\Delta R / R}{GF}$$

两个数字对一下量级：350 Ω 的应变片受 100 με 应变、GF=2 时，电阻变化仅 $\Delta R = 350 \times 2 \times 100\times10^{-6} = 0.07$ Ω——相对变化万分之二。直接用万用表量这个变化几乎不可能（温漂、接触电阻都在同一量级），必须依赖下一节的电桥电路把它变成可测的电压差。

::: info 核心概念
- **应力（Stress）**：力除以横截面积（Pa），零件内部对载荷的响应，疲劳分析的驱动量
- **应变（Strain）**：长度相对变化 $\Delta l / l$，无量纲，常用微应变 με（10⁻⁶）计
- **灵敏系数（Gauge Factor, GF）**：电阻相对变化与应变之比，金属箔片典型约 2
- **比率为输出（Ratiometric）**：应变片输出的是电压比 Vout/Vsupply 而非电压本身，单位 mV/V，与激励电压涨落天然免疫
:::

## 四、惠斯通电桥：把 0.07 Ω 变成电压

把"电阻的微小变化"变成"电压的微小变化"的电路是**惠斯通电桥（Wheatstone Bridge）**：四个电阻围成菱形，对角供电压、另一对角量输出。它本质是两个分压器背靠背——右边的画法就是为非电专业准备的等价形式。

![惠斯通电桥的两种等价画法：经典菱形与双分压器](/images/strain-gauge-basics/fig10.png)
*（图源：Siemens Simcenter Testing Knowledge Base）*

四个电阻相等时，两个分压器中点电位相同，输出为零——**平衡电桥**。把 R1 换成应变片 G1（初始阻值与另三个相等），无载荷时输出仍为零；载荷一来，G1 阻值偏离，平衡被打破，输出端出现电压。这个公式回答的问题是**"不平衡量与输出电压的定量关系"**——其中 $R_1 \cdots R_4$ 是四臂电阻（含应变片的实测阻值），$V_{supply}$ 是供桥电压，分子里"对臂乘积之差"对应物理里两条分压路径的电位差：

$$V_{out} = V_{supply} \cdot \frac{R_1 R_3 - R_2 R_4}{(R_1 + R_2)(R_3 + R_4)}$$

注意到输出天然是"差值"：温度引起的阻值漂移若四臂同步，分子里相减抵消大半——这就是电桥"会做减法"的天赋，也是温度补偿能用电桥实现的原因。从电压比回到应变，还要把灵敏系数和工作臂数目考虑进来。这个公式回答的问题是**"电压比读数折算应变的总公式"**——其中 $N$ 是桥中参与工作的应变片数（四分之一桥 N=1、半桥 N=2、全桥 N=4），$GF$ 是灵敏系数：

$$\varepsilon = \frac{4\,(V_{out}/V_{supply})}{GF \cdot N}$$

::: info 核心概念
- **惠斯通电桥（Wheatstone Bridge）**：四电阻双分压器电路，平衡时输出为零，微小电阻变化转化为输出电压
- **平衡电桥（Balanced Bridge）**：四臂相等、输出为零的状态，所有测量的起点
:::

## 五、一笔算到底的实例

官方手册的例子值得亲手算一遍：四分之一桥，一枚 350 Ω 应变片接在 G1 位，R2=R3=R4=350 Ω 精密电阻，供桥 5 V，GF=2。加载后应变片阻值变化 +0.07 Ω。

代入输出电压公式（附录 numpy 逐步复算）：

$$V_{out} = 5 \cdot \frac{350.07 \times 350 - 350 \times 350}{(350.07+350)(350+350)} = 2.5 \times 10^{-4}\ \mathrm{V} = 250\ \mu\mathrm{V}$$

250 微伏——这就是"小水管里的小水流"：万用表交流档的噪声都比它大，所以后级必须有高增益差分放大与良好屏蔽（长导线场景的对策见[长导线应变测量](/posts/practice/test-setup/strain-long-cables.html)）。再折算应变：

$$\varepsilon = \frac{4 \times (250\times10^{-6}/5)}{2 \times 1} = 100 \times 10^{-6} = 100\ \mu\varepsilon$$

反推验证一致：0.07 Ω / 350 Ω = 200×10⁻⁶，除以 GF=2 正是 100 με。这个例子还说明工程上为什么用微应变作单位——应变的原始数值太小，乘 10⁶ 读起来才是"整数"。

![四分之一桥实例：350 Ω 桥、5 V 供桥、ΔR=+0.07 Ω](/images/strain-gauge-basics/fig14.png)
*（图源：Siemens Simcenter Testing Knowledge Base）*

## 六、四分之一桥、半桥、全桥：花几倍的功夫换什么

电桥四臂不必都由采集系统补精密电阻——把更多臂换成贴在零件上的应变片，输出、抗干扰能力、可测的应变类型都随之变化。三种基本接法：

**四分之一桥（Quarter Bridge）**：1 片工作 + 3 个精密电阻（电阻在采集卡内补齐）。最省事的接法，也是最常见的：只需贴一枚片。代价是灵敏度最低、不能温度补偿、只能测叠加应变（弯拉合成，分不开）。

![四分之一桥：一枚工作片，SCADAS 卡内补三枚精密电阻](/images/strain-gauge-basics/fig20.png)
*（图源：Siemens Simcenter Testing Knowledge Base）*

**半桥（Half Bridge）**：2 片工作 + 2 个电阻。贴片翻倍，换来灵敏度提高与温度补偿的可能（取决于两片的布置方向）；典型用法是弯曲梁上下表面各贴一片——一片受拉一片受压，两臂反向变化，输出翻倍，轴向应变（两片同向同量）则在相减中抵消，实现"弯拉分离"。

![半桥：两枚工作片，可温度补偿、可分离弯曲与轴向](/images/strain-gauge-basics/fig21.png)
*（图源：Siemens Simcenter Testing Knowledge Base）*

**全桥（Full Bridge）**：4 片全部工作。贴片工作量最大，但灵敏度最高、温度自补偿、共模抑制抗电磁干扰，配置得当时可专测弯曲或轴向、甚至测轴上扭矩。市售的测力传感器、压力传感器内部就是封装好的全桥——"传感器化的应变片"。

![全桥：四枚工作片，测力传感器与压力传感器的内芯](/images/strain-gauge-basics/fig22.png)
*（图源：Siemens Simcenter Testing Knowledge Base）*

用第五节的实例把三者的账摆在一起最直观：同样是"每个工作臂感受 100 με"的情形，四分之一桥输出 250 μV、半桥（两臂等量反向）输出 500 μV、全桥（四臂配对反向）输出 1000 μV——工作臂数翻一倍，输出翻一倍，而折算公式里的 N 同步翻倍，最终应变读数一致、信噪比逐级改善。这笔账在恶劣电磁环境或长导线现场决定成败。

::: info 核心概念
- **四分之一桥**：1 工作片+3 电阻，最常用、灵敏度最低、无温度补偿
- **半桥**：2 工作片，灵敏度翻倍，方向布置得当时可温度补偿、弯拉分离
- **全桥**：4 工作片，灵敏度最高、温度自补偿、共模抑制，测力/压力传感器内芯
:::

## 七、方向性：贴错 90 度，测到的是泊松应变

应变片只沿标距方向"看"应变。同一根受压圆柱：左边的片沿压缩方向贴，读到的就是压缩应变；右边的片横过来贴，压缩应变几乎测不到——测到的是垂直方向上的泊松膨胀加上横向灵敏度的少量串扰。载荷方向未知的场，用应变花三片定角一次解出主应变大小与方向。

## 八、选型三张对表：阻值、温度、供桥电压

**阻值：120 Ω 还是 350 Ω？** 标称阻值最常见的两档，选择的核心账是焦耳热：同样的供桥电压下，$P = V^2/R$，120 Ω 片的发热是 350 Ω 片的近三倍（5 V 下分别约 208 mW 与 71 mW）。热量散不掉，片自身温度升高、阻值漂移，直接伪装成"应变"——所以**低导热基体（塑料、复合材料）或散热差的小构件优先 350 Ω 甚至 1000 Ω**；金属大构件导热好，120 Ω 也可用。此外阻值越高、同样长导线电阻占比越小，长导线场合高阻片占优。

**温度补偿：漂移的三道防线。** 电阻率随温度变、零件热胀冷缩、胶层性能漂移——温度是应变测量的头号系统误差源。第一道防线是**自补偿片**：选栅材热输出与被测材料热膨胀匹配的型号（按材料膨胀系数订片），把热输出压到可接受范围。第二道是**电桥补偿**：半桥/全桥里在相邻臂放一枚"哑片"——贴在同一材料上、不受力（比如贴在旁边的小凸台或专门的补偿块上），温度变化时工作片与哑片阻值同步漂移，在电桥的减法里抵消。第三道是**数值补偿**：用温度通道记录历程，按厂家热输出曲线事后扣除——精度要求越高越需要多道防线叠加。

**供桥电压：越大越好吗？** 输出电压正比于 $V_{supply}$，提高供桥电压是最直接的放大手段；但焦耳热也正比于 $V^2$。过高的供桥电压让片自热过度、热应变误差上升，厂家按栅面积与基体材料给出最大值——小栅片、低导热基体必须降额使用。官方配套文章"Strain Gauges: Selecting an Excitation Voltage"专门讨论这个权衡。

## 九、Testlab 锚点与 numpy 对账

在 Simcenter Testlab 中测量应变片：SCADAS 的 VB8 应变采集卡在卡内补齐电桥缺臂（四分之一桥时三枚精密电阻在卡里），Channel Setup 中设置桥型、灵敏系数 GF、标称阻值与供桥电压；Channel Setup 的隐藏字段（Tools → Channel Setup Visibility 可调出）里有 Bridge Lead Resistance 等长线补偿项。实时计算应变花 Derived 量用 Channel Setup 右上角下拉的 Virtual Channels（f(x) → Strain gauges 函数组）；离线重算走 Time Signal Calculator。

最后用 numpy 把第五节的实例与三种桥型的输出账一次算清（自包含，可直接运行）：

```python
import numpy as np

R, Vs, GF = 350.0, 5.0, 2.0          # 标称阻值 / 供桥电压 / 灵敏系数
dR = 0.07                            # 加载后的阻值变化 (ohm)

def vout(r1, r2, r3, r4):            # 惠斯通电桥输出
    return Vs * (r1*r3 - r2*r4) / ((r1+r2)*(r3+r4))

def strain(v, n):                    # 电压比 -> 应变, n 为工作臂数
    return 4 * (v / Vs) / (GF * n)

# 四分之一桥: G1=R+dR, 其余为精密电阻
q = vout(R+dR, R, R, R)
# 半桥: 弯曲梁上下两片, 等量反向 (+dR 与 -dR 各占一臂)
h = vout(R+dR, R, R, R-dR)
# 全桥: 四片配对反向
f = vout(R+dR, R-dR, R+dR, R-dR)

for name, v, n in [("quarter", q, 1), ("half", h, 2), ("full", f, 4)]:
    print(f"{name:8s} Vout={v*1e6:7.1f} uV  strain={strain(v, n)*1e6:6.1f} ue")

# 焦耳热: 同一供桥电压下 120 与 350 ohm 的发热对比
for Rn in (120.0, 350.0):
    print(f"R={Rn:5.0f} ohm @ {Vs}V: P = {Vs**2/Rn*1e3:5.0f} mW")
```

运行结果（与手算第五节一致）：

```text
quarter  Vout=  250.0 uV  strain= 100.0 ue
half     Vout=  500.0 uV  strain= 100.0 ue
full     Vout= 1000.0 uV  strain= 100.0 ue
R=  120 ohm @ 5V: P =   208 mW
R=  350 ohm @ 5V: P =    71 mW
```

三行输出串起全文逻辑：同样 100 με，工作臂数从 1 到 4，输出电压从 250 μV 翻到 1000 μV 而应变读数不变——多贴片买的是信噪比，不是更大的应变。最后两行是选型那张表的数值版：120 Ω 与 350 Ω 在 5 V 下的自热差近三倍，低导热构件上的选型依据就在这里。

## 一句话记住

应力测不了就测应变、乘模量换回去：应变片把形变翻译成电阻变化（GF≈2），电桥把它翻译成电压（比率为输出、差分天然抗共模），四分之一/半桥/全桥按工作臂数翻倍买信噪比，阻值、温度补偿、供桥电压三张表决定数据漂不漂。
