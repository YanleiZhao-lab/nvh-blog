# 三向加速度计通道设置技巧

> 一个三向头占三个通道，整车路试十几个三向头就是四五十行通道表——PointId、Direction、灵敏度逐格手填，填错一格，幅值看起来一切正常，问题要等到模态动画里才以飞点形式出现。本文给出 Simcenter Testlab 通道设置（Channel Setup）的三个官方技巧，外加评论区提出的一个易被忽视的问题：Direction 标签不等于极性。

## 一、通道设置：工作量不小，错误当场看不出

通道设置是每次测试的第一屏，也是最容易被当成简单重复劳动的一步。三向加速度计（Triaxial Accelerometer）每个占用三个采集通道，三行的 PointId 要一致、Direction 要构成合法组合、灵敏度（Sensitivity）要各填各的——这些字段之间没有任何默认校验，全靠人工核对。

填错的后果有个共同特征：**当场看不出来**。振动幅值、频谱、A 计权（A-weighting）总级全部正常，因为单通道数据本身没有损坏。问题要到模态分析（Modal Analysis）或工作变形（ODS, Operational Deflection Shape）动画里才出现——某个点的三个方向不合拍，模型上出现一个别的点都不跟着动的"飞点"（flyer point），或者整个振型方向反常。到那时候，试验早结束了。

常见错误和它们的症状归类：

| 错误类型 | 幅值谱 | 动画/相位类结果 | 典型发现时机 |
| --- | --- | --- | --- |
| **X/Y 接线对调** | 正常（两轴幅值互换） | 振型旋转 90° | 动画播放时 |
| **Direction 填错（如 -Z）** | 正常 | 该点方向反向，出现飞点 | 模态拟合后 |
| **三方向不构成右手系** | 正常 | 相位关系错乱，动画不一致 | ODS/模态动画时 |
| **PointId 不一致** | 正常 | 几何上三点分开，本是一点 | 几何挂接时 |
| **灵敏度张冠李戴** | 幅值整体偏差 | 动画正常但量级错 | 数据对比时 |

::: info 字段速查
- **PointId（测点号）**：三向头的三个通道必须共用同一个测点号，几何模型靠它把数据挂到节点上
- **Direction（方向）**：通道的物理方向标签，如 +X、+Y、+Z，只作描述、不做校验
- **MultiChannel（多通道属性）**：隐藏列，设为 Triax-RH 后可强制三个方向构成右手系
:::

## 二、技巧一：Auto Fill 拖拽，三行变三十行

第一个技巧解决的是重复劳动。在 Channel Setup 工作表里，把一个三向头的三行 **PointId 和 Direction 列一起选中**，鼠标移到选区**右下角**，等光标变成**双向白色箭头**，按住往上或往下拖——PointId 自动递增，Direction 按原来那组三向组合自动循环填充。

![选中 PointId 与 Direction 后在右下角等待双向箭头](/images/triaxial-channel-tricks/autofill-drag.png)
*（图源：Simcenter Testing Knowledge Base）*

拖完检查一眼：每个测点三行，PointId 相同、方向依次 +X/+Y/+Z，下一个测点编号自动加一。

![拖拽后其余三向头的通道自动填好](/images/triaxial-channel-tricks/autofill-result.png)
*（图源：Simcenter Testing Knowledge Base）*

四十个三向头一百二十行通道，手敲至少半小时，且个别笔误难以完全避免；拖拽填充把这件事变成十秒钟的鼠标动作，而且 Direction 不会出现"+X、+Y、+Z、+X、+Y、+Y"这类连续笔误。

::: warning 范围边界
Auto Fill 只填 PointId 和 Direction。灵敏度、量程这些每通道各不相同（同一只三向头三个方向的灵敏度标定值也常有百分之零点几的差异），还得逐通道照着标定单填写，无法靠拖拽生成。
:::

## 三、技巧二：单线三向，从结构上杜绝接错线

传统接法是一只三向头拖三根 BNC，分别插到采集卡三个通道上。三根线外观一样、插孔排成一排，现场光线差、赶进度，X 插到 Y 的孔里并不罕见——而且插错了**没有任何提示**，三路信号都完好，只是身份对调了。

如果采集硬件是 **SCADAS V-24 卡或 SCADAS XS**，可以改用单线方案：三向加速度计的四芯插头（PCB 4-pin 或 mini 4-pin）通过一根 Lemo 线直连采集卡，三个方向在 connector 内部分好，**结构上不可能交叉接线**。

![SCADAS XS 与单线三向加速度计](/images/triaxial-channel-tricks/single-cable.png)
*（图源：Simcenter Testing Knowledge Base）*

以 PCB 三向头为例，官方给出的线缆型号：

- **PCB 010M136/M003**：SCADAS Lemo 转 4-pin 插头，末尾 003 代表 3 米
- **PCB 034M59/M003**：SCADAS Lemo 转 mini 4-pin 插头

末尾的长度代码可以按需替换成 005（5 米）、010（10 米），其余型号定义不变。

| 接线方式 | 通道占用 | 交叉接线风险 | 现场布线 | 适用硬件 |
| --- | --- | --- | --- | --- |
| **三根 BNC** | 任意三通道 | 高，插错无提示 | 三根线捆着走 | 所有 SCADAS 卡 |
| **单线 Lemo** | 卡内固定三通道 | **结构上不可能** | 一根线，布线简单 | V-24 卡 / SCADAS XS |

::: tip 怎么选
有 V-24 卡或 XS 就用单线，尤其是测点分散、需要长距离拉线的整车路试。老硬件只有三根 BNC 时，接线后用"轻敲传感器某个面、看哪一路响应"的方法当场验证三方向身份，确认无误再开测。
:::

## 四、技巧三：MultiChannel 设 Triax-RH，强制右手系

默认状态下，每个通道的 Direction 是独立填写的，软件**不检查**三个方向是否构成右手坐标系。+X、+Y、-Z 这种组合完全填得进去——数据处理一切正常，但模态振型和 ODS 动画里三个方向的相位关系是错的。

三个方向构成右手系（right-handed triad）的判定准则，从定义出发分三步得到：

1. 每个方向标签对应一个单位向量：+X 对应 $\mathbf{a}=(1,0,0)$，+Y 对应 $\mathbf{b}=(0,1,0)$，-Z 对应 $(0,0,-1)$。物理意义：方向标签是测量坐标系的约定，不是数据本身的属性。

2. 按右手定则，前两个轴的叉积 $\mathbf{a}\times\mathbf{b}$ 必须与第三个方向 $\mathbf{c}$ 位于同一半空间。物理意义：第三根轴要在前两轴张成平面的法向一侧。

3. "同一半空间"量化为点积大于零，得到三重积（scalar triple product）判据：

$$
(\mathbf{a}\times\mathbf{b})\cdot\mathbf{c} > 0
$$

物理意义：该值大于零为右手系（Triax-RH 合法），小于零为左手系；判据由三轴组合整体决定，与某一根轴带不带负号无关。

落实方法在一个默认不可见的列里：

1. 菜单 **Tools -> Channel Setup Visibility**，把 **MultiChannel** 字段加进 Channel Setup 工作表；
2. 对每个三向头的三行，把 MultiChannel 设为 **Triax-RH**。

此后这三个通道的 Direction 下拉框只会给出**合法的右手系组合**，左手组合无法选到，方向组合填错导致的飞点问题在源头被阻断。

![默认行为：三个方向独立设置，互不校验](/images/triaxial-channel-tricks/independent-directions.png)
*（图源：Simcenter Testing Knowledge Base）*

![MultiChannel 设为 Triax-RH 后，方向只剩合法右手系组合](/images/triaxial-channel-tricks/triax-rh.png)
*（图源：Simcenter Testing Knowledge Base）*

顺带一提，下拉里还有个 Triax-LH（左手系），官方原文说明它"为南半球用户准备"，这个幽默的说法反映的实际情况是：不同厂家、不同批次传感器的坐标定义确有差异。遇到左手定义的三向头，选 LH 即可，关键是**同一批测点用同一套规则**。

## 五、标签不等于极性：标注 -X 的完整做法

前三个技巧来自官方文章，第四个问题来自同一篇文章的评论区，一句话概括：**Direction 只是一个标签，改变它不会翻转数据的符号**。

先写出通道的物理量换算关系。采集系统按灵敏度把电压信号换算成工程量：

$$
a = \frac{U}{S}
$$

其中 $U$ 为采集到的电压（V），$S$ 为灵敏度（V/g 或 pC/g）。物理意义：$S$ 的正负号直接决定工程量的符号——这是通道设置里唯一能翻转数据极性的量。

现场经常遇到：传感器安装位置受限，只能"倒装"，工程师想把方向标成 -X 来表达"这个轴反了"。光改标签是不够的——数据还是正 X 的符号，标签却说它是 -X。要让工程量符号随标签一起翻转，需满足：

$$
a' = \frac{U}{S'} = \frac{U}{-S} = -a
$$

即 $S' = -S$：**同时把该通道灵敏度写成负值**（或把极性设为反），标签、灵敏度符号与实际安装方向三者一致，缺一步都不成立。

这个错误难以察觉的原因在于症状分布：自功率谱（Auto Power Spectrum）、总级、A 计权这些只看幅值的量**全部正常**（符号翻转不改变幅值），错误只出现在相位敏感的场合——FRF（Frequency Response Function，频响函数）相位、模态振型、ODS 动画、多通道矢量投影。幅值报表看起来越正常，越不容易有人怀疑到通道设置。

## 六、Python 验证：右手系判定与极性标注错误

两个十行左右的演示，把第四、五节的道理变成看得见的数字。

第一个是 Triax-RH 的数学实质：三重积（先叉乘再点乘）大于零即为合法右手系，判据见第四节。

第二个复现极性问题。先说明幅值类指标为何对极性不敏感。RMS（Root Mean Square，均方根）定义为：

$$
x_{\mathrm{RMS}} = \sqrt{\frac{1}{N}\sum_{n=0}^{N-1} x_n^2}
$$

把符号翻转 $x_n \to -x_n$ 代入，$x_n^2$ 不变，故 RMS 对极性完全不敏感。与之对照，信号向量向任一方向 $\mathbf{u}$（$\|\mathbf{u}\|=1$）的投影：

$$
p = \mathbf{x}^{\mathrm{T}}\mathbf{u}
$$

是各分量的线性组合，右端任一分量变号都会直接改变投影值。两类指标对极性的敏感性差异，就是下面演示的数学依据。

```python
import numpy as np

# 一、右手系判定：三重积 (a x b) 再点乘 c，大于 0 即合法，Triax-RH 的幕后校验就是它
cases = {"+X +Y +Z": [(1,0,0),(0,1,0),(0,0,1)],
         "+X +Y -Z": [(1,0,0),(0,1,0),(0,0,-1)],
         "+X -Z +Y": [(1,0,0),(0,0,-1),(0,1,0)]}
for name, (a, b, c) in cases.items():
    tri = np.dot(np.cross(np.array(a), np.array(b)), np.array(c))
    print(f"方向组合 {name}: 三重积 = {tri:+.0f} -> {'右手系 合法' if tri > 0 else '左手系 会被 Triax-RH 拦下'}")

# 二、极性坑：传感器倒装，通道标 -X。正确做法是灵敏度取负（数据翻到整车坐标），
#    错误做法是只改标签——数据仍是传感器原始符号
t = np.linspace(0, 0.5, 1024, endpoint=False)
veh = np.array([np.sin(2*np.pi*40*t), 0.3*np.ones_like(t), 0.1*np.ones_like(t)])  # 正确：整车坐标 XYZ
raw = veh.copy(); raw[0] = -veh[0]     # 错误：只有标签没有负灵敏度，X 数据符号是反的
u = np.array([1, 1, 0]) / np.sqrt(2)   # 整车坐标 45 度方向的单位向量
i = int(np.argmax(veh[0]))             # X 正峰到来的采样时刻
print(f"\n总级 RMS: 正确 {np.sqrt((veh**2).mean()):.4f} g | 只改标签 {np.sqrt((raw**2).mean()):.4f} g  <- 幅值完全查不出")
print(f"X 正峰时刻的 45 度投影: 正确 {veh.T[i] @ u:+.3f} g | 只改标签 {raw.T[i] @ u:+.3f} g")
print(f"两路 X 信号的相关系数: {np.corrcoef(veh[0], raw[0])[0,1]:+.1f}  <- 相位敏感的量一测就露馅")
```

运行结果要点：三组方向组合的三重积分别是 +1、-1、+1——第三组带着 -Z 却换了个顺序，仍是合法右手系，可见 Triax-RH 校验的是三轴组合，不是有没有负号。极性问题更直接：总级 RMS 两种标法完全相同（都是 0.4472 g），但 X 正峰时刻沿 45 度方向的投影，正确标法 +0.919 g，只改标签的 -0.495 g，两路 X 信号的相关系数（correlation coefficient）为 -1.0——幅值类指标查不出这类错误，方向投影与相关类指标一测便知。

## 七、小结

通道设置的验收标准，按优先级排：

- **方向身份**：单线硬件天然免疫；三 BNC 接线必须现场敲击验证
- **方向合法性**：MultiChannel 列设 Triax-RH，所有三向头统一右手系（左手定义的传感器统一 Triax-LH）
- **负方向**：标 -X 的通道，灵敏度同步取负，两步必须一起做
- **PointId**：同一只三向头三行共用一个测点号，Auto Fill 拖拽生成后抽查两三个点
- **灵敏度**：逐通道照标定单填，三个方向不相等是常态而非异常

这五条全过，再去处理采集参数、量程等设置。方向错了而幅值正常的数据，比量程错了、数据明显异常的数据更具误导性。
