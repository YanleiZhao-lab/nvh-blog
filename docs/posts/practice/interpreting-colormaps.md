# 彩色图谱判读：colormap 的正确打开方式

> colormap（彩色图谱，也叫声谱图、Campbell 图）是旋转机械 NVH 诊断的第一现场：升速过程连续算 FFT，把"频率—转速—幅值"压成一张彩色图。但同样的图，有人三分钟锁定病根，有人盯半天只看到一团彩云。差别不在软件操作，在线型判读——斜线、水平线、边带、竖条带，每种形状背后是不同的物理机制和不同的整改方向。

## 一、colormap 是怎么来的

理解判读规则，得先知道这团颜色是什么。测试时让机器做 run-up（升速），从 800 rpm 拉到 6000 rpm，转速每走一小步，对振动或声学信号做一次傅里叶变换（FFT）。几百片频谱按转速排开，就得到一个三维数据体：横轴 RPM 或时间，纵轴频率，第三维幅值用颜色表示——这就是 colormap。Simcenter Testlab 里通过 Throughput Processing 对转速通道加数据块处理即可生成。

判读的总纲一句话：**看线的形状，别只看哪里最亮**。因为线的斜率暴露了激励的来源，亮暗只说明幅值大小。五类典型线索如下表，后文逐一展开。

| 线型 | 形状特征 | 物理机制 | 典型场景 |
| --- | --- | --- | --- |
| **阶次线** | 从原点出发的斜线，频率随转速成比例移动 | 每转固定次数的事件（燃烧、啮合、不平衡） | 四缸机 2 阶怠速轰鸣 |
| **共振线** | 水平线（或竖线，取决于轴向布置），频率不随转速变 | 结构固有频率被工作激励扫过 | 台架工装 450/750 Hz 共振 |
| **边带** | 主阶次两侧等间隔对称的弱线 | 幅值调制：偏心齿轮每转推拉 N 次 | 62 齿偏心齿轮的 60/64 阶 |
| **敲击条带** | 突然出现又消失的竖条宽带，频率范围宽 | 短暂冲击激起的宽带响应 | 活塞敲缸、变速箱齿轮拍击 |
| **开关频率族** | 形似阶次但永远不穿过零频的曲线族，随转速散开 | 电机控制器 PWM 开关及其谐波 | 电动车 5 kHz 开关噪声 |

::: info 基础概念
- **colormap（彩色图谱）**：多个转速（或时刻）的 FFT 按顺序排列成的三视图，也称 spectrogram、Campbell 图
- **阶次（Order）**：每转事件次数，频率 = 阶次 × rpm / 60；转速扫描时阶次线是过原点直线
- **边带（Sideband）**：调幅在主阶次两侧产生的对称谱线，间隔等于调制频率对应的阶次
:::

## 二、斜线：阶次线的三步判读法

阶次线是 colormap 上最常见的线。判读分三步：认出它、算出阶次数、定位源头。

第一步靠形状：频率随转速成比例增长，图上是从原点附近出发的斜线，转速归零它也归零——这一点是它和开关频率族的本质区别。第二步算阶次：在图上任取一点，用"频率 ÷ (rpm/60)"得到阶次数。第三步对号入座：阶次数指向每转发生那么多次事件的部件，皮带轮上一块不平衡质量是 1 阶，86 齿齿轮啮合是 86 阶，四缸四冲程发动机每转两次燃烧，是 2 阶。

![四缸机驾驶员耳旁噪声 colormap，2 阶占主导](/images/interpreting-colormaps/order-colormap.png)

*(图源：Simcenter Testing Knowledge Base)*

上图是一辆四缸车驾驶员人耳处噪声的 colormap，2 阶线在 3000–3500 rpm 和 4800 rpm 以上两个区间特别亮。四冲程发动机每个汽缸要两转才完成一个循环，四缸机每转恰好两次燃烧事件——燃烧是发动机里最"暴烈"的激励，2 阶自然成了内饰声学的主旋律。整改手段沿着激励路径排：源头上调点火提前角让缸压上升更平缓、加双质量飞轮或离心摆吸振器削掉脉动；路径上换悬置刚度隔振、仪表台和内饰做声学封堵，切断传到驾驶员耳朵的路线。

::: warning 工程注意
算阶次时别忘了检查基准轴。皮带传动、多级变速箱里被测轴与转速参考轴之间有速比，直接用 rpm 算出来的"阶次"是相对基准轴的——86 齿齿轮若在速比 1.5 的从动轴上，它相对曲轴是 129 阶。基准搞错，部件指认全盘皆错。
:::

## 三、水平线：共振与阶次的相遇

colormap 上不随转速移动的水平亮带，是结构共振——固有频率是结构自身属性（刚度、质量决定），跟激励转速无关，所以激励扫过去时它在原地发光。

![机械设备振动 colormap，450 Hz 与 750 Hz 处两条共振亮带](/images/interpreting-colormaps/resonance-colormap.png)

*(图源：Simcenter Testing Knowledge Base)*

这台设备的工装在 450 Hz 和 750 Hz 各有一个共振，升速时工作激励扫过这两条线，图上留下两条水平亮带。危害不在共振本身，而在**相遇**：阶次斜线扫过共振线的那个转速上，激励频率与固有频率重合，响应被急剧放大。colormap 上看交点，交点对应的转速就是"问题转速"。

```python
import numpy as np

# 演示：阶次线（斜线）扫过结构共振（水平线），交点 = 问题转速
rpm = np.arange(1000, 6001, 50)            # 升速 1000→6000 rpm
freq = np.arange(0, 301, 1)                # 频率轴 0~300 Hz
f2 = 2 * rpm / 60.0                        # 2 阶线（四缸机燃烧）

# 结构共振：固有频率 90 Hz，放大倍数 10 倍（峰值为本底的 10 倍）
H = 1 + 9 * np.exp(-((freq - 90) / 6.0)**2)

# 2 阶激励能量沿阶次线分布（每片 FFT 里是一条窄峰），乘上共振放大
Z = 0.3 * np.exp(-((freq[None,:] - f2[:,None]) / 3.0)**2) * H[None,:]

# 沿 2 阶线取每个转速的峰值 —— 这就是 2 阶切片
cut = Z.max(axis=1)
worst = rpm[np.argmax(cut)]
print(f"共振带中心频率: 90 Hz")
print(f"2 阶扫到 90 Hz 的转速 = 90*60/2 = {90*60//2} rpm")
for r in [2300, 2500, 2700, 2900, 3100]:
    print(f"  {r} rpm   2 阶幅值 {cut[np.argmin(np.abs(rpm-r))]:.2f}")
print(f"切片峰值自动定位的问题转速: {worst} rpm")
```

运行结果要点：2700 rpm 处 2 阶幅值 3.00，是 2300/3100 rpm 处（0.32）的近 10 倍——这就是"放大倍数 10"的共振带被 2 阶线扫中的效果。问题转速不靠肉眼在云图上找，一条 2 阶切片曲线的峰值直接给出 2700 rpm。

共振的整改思路按优先级排：首选错开——加刚度或减质量把固有频率顶出工作转速对应的激励频段，或者干脆限制设备运行转速避开共振区；错不开就压幅——加阻尼、加调谐吸振器（tuned absorber）在关键转速吃掉响应峰值。

## 四、边带：主阶次两侧的"影子"暴露调幅

主阶次线两侧出现等间隔的对称弱线，是调制（modulation）的指纹。机理：某个每转 N 次的周期性扰动给啮合信号做了幅度调制，频域上就在载波两侧搬移出 N 阶间隔的边带。

![62 阶被每转 2 次调制，产生 60/64 阶边带](/images/interpreting-colormaps/sideband-colormap.png)

*(图源：Simcenter Testing Knowledge Base)*

这张图里 62 齿齿轮的啮合线（62 阶）两侧各有一条弱线：60 阶和 64 阶。来源是那个齿轮不圆——滚齿加工控制不好会留下椭圆度（偏心），偏心齿轮每转把啮合副"推开—拉近"两次，啮合力幅值随之每转起伏两次，62 阶被 2 阶调制，边带就落在 ±2 阶处。偏心量不变、调制源固定，边带间隔就是判读线索：间隔几阶，扰动就每转发生几次。

```python
import numpy as np

# 演示：调幅产生边带 —— 62 阶被每转 2 次调制
rpm = 3000.0
f_shaft = rpm / 60.0              # 转频 50 Hz
f_mesh = 62 * f_shaft             # 62 齿啮合频率 3100 Hz
t = np.arange(0, 0.5, 1/20000.0)
# 啮合信号幅值被"每转 2 次"的周期推拉调制，深度 0.4
sig = (1 + 0.4*np.cos(2*np.pi*2*f_shaft*t)) * np.sin(2*np.pi*f_mesh*t)

N = len(t)
spec = np.abs(np.fft.rfft(sig * np.hanning(N))) * 4 / N     # 手写 hann 窗 + 幅值校正
faxis = np.fft.rfftfreq(N, 1/20000.0)

def amp_at(f):                     # 取最邻近谱线的幅值
    return spec[np.argmin(np.abs(faxis - f))]

for f, name in [(f_mesh, "载波(62阶)"), (f_mesh-2*f_shaft, "下边带(60阶)"), (f_mesh+2*f_shaft, "上边带(64阶)")]:
    print(f"{f:6.0f} Hz  {amp_at(f):.2f}   {name}")
print(f"边带间隔 = 2×转频 = {2*f_shaft:.0f Hz}，即阶次域上偏 62 阶整整 2 阶")
```

运行结果要点：载波幅值 1.00，两侧 60/64 阶各 0.20——正好是调制深度 0.4 的一半，边带对称出现。数边带间隔就能反推调制源的"每转次数"，不必拆开齿轮箱猜。

有个反直觉的工程结论值得记下：发现偏心齿轮，直接把它车圆未必更好。所有啮合能量集中在单一 62 阶时，那条线的峰值反而更高；偏心把能量摊到边带族上，总声级常常更低。齿轮制造商有时故意保留可控的几何偏差来"摊薄"啸叫，判断要不要整改，得看总和而不是单线。

::: warning 工程注意
边带阶次没有对应的物理部件。62 齿齿轮有 62 个齿，但系统里不存在 60 齿或 64 齿的零件——边带是调制的数学产物，别按"阶次数找部件"的思路去指认源头，要找的是那个"每转 N 次"的扰动（偏心、不对中、负载波动）。
:::

## 五、竖条带与不穿零的曲线：冲击与开关频率

**敲击条带。** 两个零件间隙配合，每转到某个角度碰一下，每次碰击是短脉冲，激起宽带响应——colormap 上呈现为突然出现、又随转速移动消失的竖直条带，覆盖很宽的频段（比如 1000–3000 Hz 整段变亮）。活塞敲缸（活塞每转在缸壁上蹭一下，磨损后加剧）和变速箱齿轮拍击（未啮合齿轮副浮动，被发动机扭振脉冲来回打）是两个高频元凶。整改方向是消除冲击本身：活塞销偏置、给浮动齿轮副预载、修齿形微观几何改善接触。

![冲击产生的宽带响应](/images/interpreting-colormaps/impact-colormap.png)

*(图源：Simcenter Testing Knowledge Base)*

**开关频率族。** 电机驱动器用 PWM（脉宽调制）把直流电变成交流电，开关动作本身产生振动噪声，幅值可能与电机本体相当。判别特征很特别：形似阶次曲线，但**永远不穿过零频**，以开关频率（常见 2500/5000/10000 Hz）为中心随转速变化散开或收拢。看到一族"下端不落地"的曲线，基本可以断定来自功率电子开关而非机械啮合。整改两条路：提高基频到听阈之外（如 15 kHz，但牺牲效率），或改用随机 PWM 把开关能量摊宽摊低。

![电机开关频率谐波族，随转速散开，不穿过零频](/images/interpreting-colormaps/pwm-colormap.png)

*(图源：Simcenter Testing Knowledge Base)*

## 六、判读流程小结

拿到一张 colormap，按这个顺序过一遍，两分钟内给初诊：

| 步骤 | 看什么 | 判什么 |
| --- | --- | --- |
| **1 扫形状** | 斜线/水平线/竖条带/边带/不穿零曲线 | 先分类，不急着算数 |
| **2 验阶次** | 任取斜线上一点算 频率÷(rpm/60)，核对速比 | 指认每转 N 次的部件 |
| **3 找交点** | 阶次线与水平共振线的交叉 | 交点转速 = 问题转速，验证与主观抱怨转速是否一致 |
| **4 数边带** | 主阶次两侧间隔几阶 | 反推每转 N 次的调制扰动 |
| **5 查全程** | 条带是否只在个别转速段出现 | 冲击类问题，锁定间隙配合部位 |

最后一条经验：colormap 用 dB 显示往往比线性幅值好看——dB 压缩了动态范围，弱线索（边带、高阶线）才能从大片强色里浮出来。Testlab 里右键 Y 轴改格式即可。判读是定位，不是定量；锁定了线和转速，下一步用阶次切片、阶次跟踪把幅值随转速的曲线拉出来，才是整改决策的定量依据。
