# 彩色图谱判读：colormap 五类线型的识别与整改

> colormap（彩色图谱，又称 spectrogram、Campbell 图）是旋转机械 NVH 诊断的基础分析工具：升速过程中按转速逐步计算 FFT，把"频率—转速—幅值"三维信息压缩成一张彩色图。同一张图，判读结论的差别往往不在软件操作，而在线型识别——斜线、水平线、边带、竖条带、不穿零的曲线族，每类形状对应不同的物理机制和不同的整改方向。本文对齐 Simcenter Testing 知识库文章《Interpreting Colormaps》，逐类给出成因、判读步骤与整改思路。

## 一、colormap 是怎么来的

理解判读规则，先要知道这团颜色是什么。测试时让机器做 run-up（升速），从 800 rpm 拉到 6000 rpm，转速每走一小步，对振动或声学信号做一次快速傅里叶变换（Fast Fourier Transform, FFT）。几百片频谱按转速排开，就得到一个三维数据体：横轴 RPM 或时间，纵轴频率，第三维幅值用颜色表示——这就是 colormap。Simcenter Testlab 里通过 Throughput Processing 对转速通道做数据块处理即可生成。

判读的总原则一句话：**看线的形状，而不是只看哪里最亮**。线的斜率暴露激励的来源，亮暗只说明幅值大小。五类典型线索如下表，后文逐一展开。

| 线型 | 形状特征 | 物理机制 | 典型场景 |
| --- | --- | --- | --- |
| **阶次线** | 从原点出发的斜线，频率随转速成比例移动 | 每转固定次数的事件（燃烧、啮合、不平衡） | 四缸机 2 阶怠速轰鸣 |
| **共振线** | 水平线（或竖线，取决于轴向布置），频率不随转速变 | 结构固有频率被工作激励扫过 | 台架工装 450/750 Hz 共振 |
| **边带** | 主阶次两侧等间隔对称的弱线 | 幅值调制：偏心齿轮每转推拉 N 次 | 62 齿偏心齿轮的 60/64 阶 |
| **敲击条带** | 突然出现又消失的竖条宽带，频率范围宽 | 短暂冲击激起的宽带响应 | 活塞敲缸、变速箱齿轮拍击 |
| **开关频率族** | 形似阶次但永远不穿过零频的曲线族，随转速散开 | 电机控制器 PWM 开关及其谐波 | 电动车 5 kHz 开关噪声 |

::: info 基础概念
- **colormap（彩色图谱）**：多个转速（或时刻）的 FFT 按顺序排列成的三视图，也称 spectrogram、Campbell 图
- **阶次（Order）**：每转事件次数，频率 = 阶次 × rpm / 60；转速扫描时阶次线是过原点直线
- **边带（Sideband）**：调幅在主阶次两侧产生的对称谱线，间隔等于调制频率对应的阶次
:::

## 二、斜线：阶次线的三步判读法

阶次线是 colormap 上最常见的线。判读分三步：认出它、算出阶次数、定位源头。

判读的算术基础是阶次—频率关系，从定义出发分两步推导。第一步，转速换转频：转速 $n$（单位 rpm）是每分钟转数，除以 60 得到转频 $f_{rot}$（单位 Hz），即每秒转数：

$$f_{rot} = \frac{n}{60}$$

第二步，乘上每转事件次数：每转发生 $O$ 次的周期事件，其重复频率等于事件次数乘转频：

$$f = O \cdot f_{rot} = \frac{O \, n}{60}$$

这条式子说明事件频率与转速成正比，比例系数就是阶次。在以转速为横轴、频率为纵轴的 colormap 上，$f = \frac{O}{60} n$ 是一条过原点、斜率为 $O/60$ 的直线——阶次线是斜线、转速归零频率也归零，原因在此，这也是它与后文开关频率族的本质区别。

第一步认形状即核对这条比例关系；第二步算阶次是上式的反向使用——在图上任取斜线上一点 $(n, f)$，反算阶次数：

$$O = \frac{60 \, f}{n}$$

第三步对号入座：阶次数指向每转发生那么多次事件的部件——皮带轮上一块不平衡质量是 1 阶，86 齿齿轮啮合是 86 阶，四缸四冲程发动机每转两次燃烧，是 2 阶。

![四缸机驾驶员耳旁噪声 colormap，2 阶占主导](/images/interpreting-colormaps/order-colormap.png)

*(图源：Simcenter Testing Knowledge Base)*

上图是一辆四缸车驾驶员人耳处噪声的 colormap，2 阶线在 3000–3500 rpm 和 4800 rpm 以上两个区间幅值最高（知识库原图中以红色标出）。四冲程发动机每个汽缸要两转才完成一个循环，四缸机每转恰好两次燃烧事件；燃烧是发动机中最剧烈的激励，2 阶因此常成为车内声级的主要贡献分量。整改手段沿激励路径排：源头上调整点火提前角使缸压上升更平缓、加装双质量飞轮（dual-mass flywheel）或离心摆吸振器（centrifugal pendulum absorber）削减脉动；路径上更换悬置刚度隔振、对仪表台和内饰做声学封堵，切断传到驾驶员耳朵的路线。

::: warning 工程注意
算阶次时先检查基准轴。皮带传动、多级变速箱里被测轴与转速参考轴之间有速比，直接用 rpm 算出来的"阶次"是相对基准轴的——86 齿齿轮若在速比 1.5 的从动轴上，它相对曲轴是 129 阶。基准搞错，部件指认全盘皆错。
:::

## 三、水平线：共振与阶次的相遇

colormap 上不随转速移动的水平亮带，是结构共振——固有频率是结构自身属性（由刚度、质量分布决定），与激励转速无关，所以激励扫过时它在原地保持常频。

![机械设备振动 colormap，450 Hz 与 750 Hz 处两条共振亮带](/images/interpreting-colormaps/resonance-colormap.png)

*(图源：Simcenter Testing Knowledge Base)*

这台设备的工装在 450 Hz 和 750 Hz 各有一个共振（知识库给出的模态振型分别为右侧前后弯曲与两侧弯曲），升速时工作激励扫过这两条线，图上留下两条水平亮带。危害不在共振本身，而在**相遇**：阶次斜线扫过共振线的那个转速上，激励频率与固有频率重合，响应被急剧放大。令阶次—频率关系式中的激励频率等于固有频率 $f_n$，即得问题转速的解析式：

$$\frac{O \, n}{60} = f_n \quad \Longrightarrow \quad n_{crit} = \frac{60 \, f_n}{O}$$

物理意义：$O$ 阶激励线升到 $f_n$ 高度时对应的转速。colormap 上直接看阶次线与水平共振线的交点，交点转速就是"问题转速"。

```python
import numpy as np

# 演示：阶次线（斜线）扫过结构共振（水平线），交点 = 问题转速
rpm = np.arange(1000, 6001, 50)            # 升速 1000→6000 rpm
freq = np.arange(0, 301, 1)                # 频率轴 0~300 Hz
f2 = 2 * rpm / 60.0                        # 2 阶线（四缸机燃烧）

# 结构共振：固有频率 90 Hz，放大倍数 10 倍（峰值为本底的 10 倍）
H = 1 + 9 * np.exp(-((freq - 90) / 6.0)**2)

# 2 阶激励能量沿阶次线分布（每片 FFT 里是一条窄峰），乘上共振放大
Z = 0.3 * np.exp(-((freq[None,:] - f2[:,None]) / 3.0)**2) * H[None,:]

# 沿 2 阶线取每个转速的峰值 —— 这就是 2 阶切片
cut = Z.max(axis=1)
worst = rpm[np.argmax(cut)]
print(f"共振带中心频率: 90 Hz")
print(f"2 阶扫到 90 Hz 的转速 = 90*60/2 = {90*60//2} rpm")
for r in [2300, 2500, 2700, 2900, 3100]:
    print(f"  {r} rpm   2 阶幅值 {cut[np.argmin(np.abs(rpm-r))]:.2f}")
print(f"切片峰值自动定位的问题转速: {worst} rpm")
```

运行结果要点：2700 rpm 处 2 阶幅值 3.00，是 2300/3100 rpm 处（0.32）的近 10 倍，与解析式 $n_{crit} = 60 \times 90 / 2 = 2700$ rpm 的预测一致。问题转速不靠肉眼在云图上找，一条 2 阶切片曲线的峰值直接给出 2700 rpm。

共振的整改思路按优先级排：首选错开——加刚度或减质量把固有频率顶出工作转速对应的激励频段，或者限制设备运行转速避开共振区（知识库示例：把上限转速限制在 2200 rpm 以下）；错不开就压幅——加阻尼，或加装调谐吸振器（tuned absorber）在关键转速降低响应峰值。

## 四、边带：主阶次两侧的对称伴线与调幅

主阶次线两侧出现等间隔的对称弱线，是幅值调制（Amplitude Modulation）的特征。从调幅的定义出发分三步推导边带的位置与幅值，每步的物理意义如下。

第一步，写出调幅信号。62 齿啮合产生频率 $f_m = 62 f_{rot}$ 的载波 $A\cos(2\pi f_m t)$；偏心使啮合幅值每转起伏 $k$ 次，等价于载波乘上包络 $[1 + m\cos(2\pi k f_{rot} t)]$，其中 $m$（$0 \le m \le 1$）是调制深度，即幅值起伏量与平均幅值之比：

$$x(t) = A\left[1 + m\cos(2\pi k f_{rot}\, t)\right]\cos(2\pi f_m t)$$

第二步，积化和差展开，把余弦乘积改写为频率搬移的和差形式：

$$\cos\alpha \cdot \cos\beta = \tfrac{1}{2}\left[\cos(\alpha - \beta) + \cos(\alpha + \beta)\right]$$

第三步，得到三个频率分量：

$$x(t) = A\cos(2\pi f_m t) + \frac{mA}{2}\cos\!\left(2\pi (f_m - k f_{rot})\, t\right) + \frac{mA}{2}\cos\!\left(2\pi (f_m + k f_{rot})\, t\right)$$

载波保持 $f_m$，两侧各出现一条幅值 $mA/2$ 的边带，位于 $f_m \pm k f_{rot}$；频率除以 $f_{rot}$ 回到阶次域，就是主阶次 $N$ 两侧的 $N \pm k$ 阶。**边带间距 $k$ 等于调制源每转作用次数**——这是判读的关键量。

![62 阶被每转 2 次调制，产生 60/64 阶边带](/images/interpreting-colormaps/sideband-colormap.png)

*(图源：Simcenter Testing Knowledge Base)*

这张图里 62 齿齿轮的啮合线（62 阶）两侧各有一条弱线：60 阶和 64 阶，对应上式中 $N=62$、$k=2$。来源是那个齿轮不圆——滚齿加工几何控制不良会留下椭圆度（偏心），偏心齿轮每转把啮合副"推开—拉近"两次，啮合力幅值随之每转起伏两次，62 阶被 2 阶调制，边带落在 $\pm 2$ 阶处。调制源不止椭圆偏心一种：齿轮与轴不同心（安装偏心）产生间距 1 的边带，载荷波动、相邻轴耦合也都会调制啮合信号。

```python
import numpy as np

# 演示：调幅产生边带 —— 62 阶被每转 2 次调制
rpm = 3000.0
f_rot = rpm / 60.0                 # 转频 50 Hz
f_mesh = 62 * f_rot                # 62 齿啮合频率 3100 Hz
t = np.arange(0, 0.5, 1/20000.0)
# 啮合信号幅值被"每转 2 次"的周期推拉调制，调制深度 m = 0.4
sig = (1 + 0.4*np.cos(2*np.pi*2*f_rot*t)) * np.sin(2*np.pi*f_mesh*t)

N = len(t)
spec = np.abs(np.fft.rfft(sig * np.hanning(N))) * 4 / N     # hann 窗 + 幅值校正
faxis = np.fft.rfftfreq(N, 1/20000.0)

def amp_at(f):                     # 取最邻近谱线的幅值
    return spec[np.argmin(np.abs(faxis - f))]

for f, name in [(f_mesh, "载波(62阶)"), (f_mesh-2*f_rot, "下边带(60阶)"), (f_mesh+2*f_rot, "上边带(64阶)")]:
    print(f"{f:6.0f} Hz  {amp_at(f):.2f}   {name}")
print(f"边带间隔 = 2×转频 = {2*f_rot:.0f} Hz，即阶次域上偏离 62 阶整整 2 阶")
```

运行结果要点：载波幅值 1.00，两侧 60/64 阶各 0.20——与推导中边带幅值 $mA/2 = 0.4/2 = 0.20$ 的理论值一致，边带对称出现。数边带间隔就能反推调制源的每转次数，不必拆开齿轮箱逐件排查。

一个与直觉相反的工程结论：发现偏心齿轮，直接把它车圆未必更好。当所有啮合能量集中在单一 62 阶时，那条线的峰值反而更高；偏心把能量摊到边带族上，总声级常常更低。齿轮制造商有时故意保留可控的几何偏差来分散啸叫能量，判断要不要整改，得看总和而不是单线峰值。

::: warning 工程注意
边带阶次没有对应的物理部件。62 齿齿轮有 62 个齿，但系统里不存在 60 齿或 64 齿的零件——边带是调制的数学产物，别按"阶次数找部件"的思路指认源头，要找的是那个"每转 N 次"的扰动（偏心、不对中、负载波动）。
:::

## 五、竖条带与不穿零的曲线：冲击与开关频率

**敲击条带。** 两个零件间隙配合，每转到某个角度碰一下，每次碰击是短脉冲，激起宽带响应——colormap 上呈现为突然出现、又随转速移动消失的竖直条带，覆盖很宽的频段（比如 1000–3000 Hz 整段变亮）。活塞敲缸（piston clatter，活塞每转在缸壁上蹭一下，磨损后加剧）和变速箱齿轮拍击（gear rattle，未啮合齿轮副浮动，被发动机扭振脉冲来回打）是两类常见来源。整改方向是消除冲击本身：活塞销偏置、给浮动齿轮副预载、修正齿形微观几何改善接触。

![冲击产生的宽带响应](/images/interpreting-colormaps/impact-colormap.png)

*(图源：Simcenter Testing Knowledge Base)*

**开关频率族。** 电机驱动器用脉宽调制（Pulse Width Modulation, PWM）把直流电变成交流电，开关动作本身产生振动噪声，幅值可能与电机本体相当。其谱线族分布在开关基频及其谐波的两侧：

$$f = l \, f_{sw} \pm j \, f_e, \qquad l = 1, 2, 3, \ldots; \;\; j = 0, 1, 2, \ldots$$

其中 $f_{sw}$ 为开关基频（常见 2500/5000/10000 Hz），$f_e$ 为电机电频率。判别特征由这条式子直接给出：曲线族以 $l f_{sw}$ 为中心、相邻谱线间隔等于 $f_e$，随转速升高而散开；整族曲线不经过零频，而机械阶次线 $f = O f_{rot}$ 必然汇聚于原点——这是两者的本质区别。看到一族"下端不落地"的曲线，可判断来自功率电子开关而非机械啮合。整改两条路：提高开关基频到听阈之外（如 15000 Hz，代价是开关损耗与效率），或改用随机 PWM 把开关能量在频域摊宽摊低。

![电机开关频率谐波族，随转速散开，不穿过零频](/images/interpreting-colormaps/pwm-colormap.png)

## 六、判读流程小结

拿到一张 colormap，按这个顺序过一遍，可以快速形成初步判断：

| 步骤 | 看什么 | 判什么 |
| --- | --- | --- |
| **1 扫形状** | 斜线/水平线/竖条带/边带/不穿零曲线 | 先分类，不急着算数 |
| **2 验阶次** | 任取斜线上一点算 频率÷(rpm/60)，核对速比 | 指认每转 N 次的部件 |
| **3 找交点** | 阶次线与水平共振线的交叉 | 交点转速 = 问题转速，验证与主观抱怨转速是否一致 |
| **4 数边带** | 主阶次两侧间隔几阶 | 反推每转 N 次的调制扰动 |
| **5 查全程** | 条带是否只在个别转速段出现 | 冲击类问题，锁定间隙配合部位 |

最后一条经验：colormap 用 dB 显示往往比线性幅值更容易判读——dB 压缩了动态范围，弱线索（边带、高阶线）才能从大片强色里显现。Testlab 里右键 Y 轴改格式即可。判读是定位，不是定量；锁定了线和转速，下一步用阶次切片（order cut）、阶次跟踪（order tracking）把幅值随转速的曲线拉出来，才是整改决策的定量依据。
