# 切片分析三件套：频率切片、阶次切片与倍频程切片

> 一台设备升速试验做完，colormap 上 2700 rpm 附近明显一片泛红，可报告里三条曲线各说各话：总级曲线说全程平稳、频率切片说 90 Hz 处有峰、阶次切片说 2 阶在 2700 rpm 被放大——到底哪条在说实话？其实三条都在说实话，只是它们戴的"有色眼镜"不同。本文依据 LMS 检测理论手册 3.3 节"复合函数"，把频率切片、阶次切片、倍频程切片这三种从瀑布图里切取二维曲线的方法一次讲清：积分带怎么定义、带宽跟着谁走、三种切片各自能把哪类问题照出来，以及为什么"总级说平稳"和"频率切片说有峰"并不矛盾。

同一组升速数据，三条曲线给出三个说法，评审会上谁也说服不了谁——这个局面在很多测试部门都出现过。要害不在数据，在于没有分清：**从三维数据体（转速—频率—幅值）里沿不同的方向切，得到的二维曲线回答的是不同的问题**。把切法搞混，就像体检报告拿错了页：血常规再正常，也回答不了心电图的问题。

## 一、为什么有了瀑布图还需要切片：从一团颜色到一条曲线

先看一个典型场景。某设备升速过程中 2700 rpm 附近出现轰鸣，工程师拿到一整幅 colormap：横轴转速、纵轴频率、颜色代表幅值。图上信息量很大，但"很大"本身就是问题——几百片频谱摞在一起，红一块黄一片，想在评审会上说清楚"哪个成分、在哪个转速、涨了多少"，靠指着一团颜色比划是不行的。决策需要的是**一条随转速变化的曲线**：横轴转速，纵轴幅值，峰在哪、多高、多宽，一眼读出。

这就是切片分析（Section Analysis）的用武之地。手册 3.3 节把这族功能称为<strong>复合函数（Section Functions）</strong>——之所以"复合"，是因为它们不是新的测量，而是从已有测量函数（频谱、自功率谱等）进一步**导出**的二维曲线：沿着某种规则，把每个转速增量上的一段频谱积分为一个数，再把这一串数对转速作图。LMS 手册原文的表述是：这类分析考察信号随环境（rpm、时间……）变化的演变，需要能反映这种演变的功能。

生活里有个贴切的类比：CT 影像与病理切片。colormap 是 CT 三维影像——信息全，但层次叠在一起；切片分析是病理切片——大夫怀疑哪里，就从哪里切一片出来单独放在显微镜下看。**切哪个方向，取决于怀疑什么病**：怀疑固定频率的结构共振，沿水平方向切（频率切片）；怀疑随转速走的阶次成分，沿斜线方向切（阶次切片）；要按人耳的频带习惯看能量分布，按倍频程网格切（倍频程切片）。切法本身不产生新信息，它只是把三维数据体里你关心的那条"通道"单独拉出来。

三种切片加上不分频带的总级（Overall Level, OA），构成一套完整的"取线"工具。先把三者的分工列在下面，后文逐一展开。

| 切片 | 积分带的中心 | 积分带的宽度 | 回答的问题 |
| --- | --- | --- | --- |
| **总级 OA** | 不分频带（全带） | — | 总能量随转速怎么变 |
| **频率切片** | 固定中心频率 | 固定带宽（频率） | 某个定频成分（如共振）何时被激起、多强 |
| **阶次切片** | 阶次 × 转速（随转速移动） | 按 4 种模式定义 | 某阶次成分全程的幅值履历 |
| **倍频程切片** | 标准倍频程中心频率 | 倍频程带宽 | 某倍频程带内能量总和的变化 |

::: info 核心概念
- <strong>复合函数（Section Function）</strong>：从基本测量函数导出的、直接相对跟踪参数（转速/时间）的二维函数，LMS 手册 3.3 节
- <strong>跟踪参数（Tracking Parameter）</strong>：表征信号变化的控制参数，如转速、时间；切片曲线的横轴
- <strong>切片（Section）</strong>：对每个跟踪参数增量，在规定频带内做能量积分（RMS）得到的单一数值
- <strong>瀑布图/地形图（Waterfall/Map）</strong>：多个转速下的频谱按顺序排列成的阵列图，切片的母体
:::

## 二、总级（OA）：切片家族的基准线

在谈三种切片之前，先把基准线立起来——**总级**。它描述测量信号的**总能量**随环境（转速、时间……）的演变，手册指出它总是表示为<strong>谱的总有效值（RMS）</strong>：对每个转速增量，把该频谱全部谱线（或规定频带内全部谱线）的平方和开根号，得到一个数。总级不区分频率成分，是"不戴有色眼镜"的一条线。

时域上也有对应的量：手册介绍 ANSI 1.4 规定的时基 OA 级计算，用指数平均把时间信号在特定带宽内的 OA 级算出来，加权因子为 $\mathrm{e}^{-\Delta t/\tau}$——这个公式回答的问题是"新的采样点以多快的速度取代旧信息"，其中 $\Delta t$ 对应采样间隔、$\tau$ 对应时间常数（平均的"记忆长度"）。标准给出三挡：

$$\tau = \begin{cases} 35~\mathrm{ms} & \text{脉冲（尖峰）信号} \\ 125~\mathrm{ms} & \text{快变信号} \\ 1000~\mathrm{ms} & \text{缓变信号} \end{cases}$$

三挡时间常数的分工有明确的物理逻辑：信号变得越快，平均的"记忆"就要越短，否则真实起伏被自己抹平。对含尖峰的信号，手册规定按"脉冲"挡处理并附加峰值检测——首次平均取 35 ms，此后以 1500 ms 的延迟率做峰值保持。

总级的问题也同样明确：它只记账总数，不记账明细。总能量涨了 3 dB，可能是 2 阶涨了，也可能是共振带被扫过——总级分不出来。明细，要靠下面三种切片去查。

## 三、频率切片：守住一个定频窗口

频率切片（Frequency Section）描述**规定频带内**测量信号的能量随转速的变化。手册说得很直接：频率切片的计算，是**围绕一中心频率邻近一定带宽上的积分运算**；切片的中心频率由中心参数给定，带宽的上下限取决于中心频率 ±（带宽 ÷ 2）。

![频率切片：围绕中心频率的带宽积分](/images/section-analysis-trio/freq-section-bands.png)

*(图源：LMS 检测理论手册 3.3 节)*

它回答的典型问题是：<strong>"90 Hz 处发生了什么？"</strong>——90 Hz 若是结构固有频率，频率切片就是这台设备共振响应的全程履历：曲线的峰对应的转速，正是工作激励扫过该固有频率的问题转速。

频率切片的关键参数是中心频率与带宽，带宽有三种指定办法（固定频率区间、固定谱线数、中心频率的百分比），三者的几何含义见下图：

![频率切片带宽的三种指定方式](/images/section-analysis-trio/freq-section-modes.png)

*(图源：LMS 检测理论手册 3.3 节)*

要理解的第一个要害是：**窗口守在频率轴上不动，内容物却在换**。还是用病理切片打比方：固定在 90 Hz 开一个 6 Hz 宽的窗口，低转速时窗口里"住着"的是本底噪声；转速升到 2700 rpm 附近、2 阶线爬进窗口（$2 \times 2700/60 = 90$ Hz），窗口里的能量骤增；转速继续升、2 阶线爬出窗口，能量又落回本底。窗口没动，住户换了一轮——频率切片的曲线因此有清晰的"进窗—峰值—出窗"结构。

第二个要害是**窗口必须对准、且够宽**。用数字感受一下量级：设 2700 rpm 时 90 Hz 处有一条宽度约 6 Hz 的共振亮带，以 87–93 Hz（±3 Hz）开窗，积分值 3.30；窗口中心挪偏 2 Hz（85–91 Hz），积分值掉到 2.37；挪偏 6 Hz（81–87 Hz），只剩 1.51——中心偏 6 Hz，读数少了一半多。带宽过窄同样吃亏：共振的能量经窗函数涂抹后分布在中心两侧，窗口只盖住峰值附近一两根谱线时，切出来的幅值对带宽极其敏感，复测换个分辨率就对不上账。

第三个要害回到开头的"三个说法"：总级说平稳、频率切片说有峰，矛盾吗？不矛盾——总级是全频带的能量总数，共振带只占其中一小格；总数被几百根谱线摊平，小窗口里的住户换人不足以撼动总数。<strong>查"定频的局部"，必须用频率切片，不能用总级。</strong>

## 四、阶次切片：跟着斜线走的移动窗口

阶次切片（Order Section）描述**规定阶次内**测量信号的能量变化。手册强调："次"指这样一种特殊频带——**其中心频率随测量环境或跟踪参数改变**；阶次本身不过是基本跟踪参数（rpm）的倍乘系数。也就是说，阶次切片的积分窗口不是钉死在频率轴上的，而是**跟着一条过原点的斜线走**：窗口中心 = 阶次 × rpm/60，转速升、窗口沿频率轴上移。

![阶次切片积分带的定义方式](/images/section-analysis-trio/order-section-modes.png)

*(图源：LMS 检测理论手册 3.3 节)*

它回答的典型问题是：<strong>"2 阶全程表现如何？"</strong>——不平衡、燃烧这类每转固定次数的激励，其频率与转速严格成正比，只有这种会移动的窗口才能全程咬住它。固定的频率窗口要么在低转速咬住、高转速跟丢，要么反过来。

阶次切片积分带的定义办法比频率切片更多，手册列出四种：固定的频率区间、固定的谱线数（谱线吻合精确的频率值或阶次值）、固定的阶次带宽、选定阶次值的百分比。四种办法的本质区别是**带宽跟着谁走**：固定频率区间时，窗口宽度在频率轴上不变，折算到阶次轴随转速收窄——低转速"够宽"、高转速"偏窄"；固定阶次带宽时，频率宽度随转速线性增大，全程对同一阶次的"包裹松紧"一致；百分比则让高阶自动拿到更宽的绝对带宽。

用数字把"窗口跟不跟"的差别算出来。仍用 2 阶成分加 90 Hz 共振的谱阵：以固定 ±0.1 阶的阶次带宽切 2 阶，600 rpm 处切线幅值 0.87、2700 rpm 处 3.48——2 阶线爬到 90 Hz 共振带内时被放大到 4 倍，峰的位置准确落在问题转速上；换成固定 ±3 Hz 的频率带宽去追同一条 2 阶线，600 rpm 处 1.13、6000 rpm 处 1.17，全程近乎平直——不是 2 阶真的平稳，而是 ±3 Hz 在低转速对应的阶次宽度近 0.6 阶（把邻近成分一起算进来抬高读数），在高转速只对应 0.06 阶（切丢了大半能量），带宽的意义在高转速端被稀释，共振放大被窗口误差抵消了。**同一份数据、追同一条线，窗口规则不同，结论可以完全相反**——这是阶次切片最需要警惕的地方。

手册还提到一个后处理的自由度：阶次切片通常以 rpm 为横轴，但通过后处理，考察阶次切片**随测量时间或频率**的变化也是可能的——积分带沿"时间—阶次"或"频率—阶次"的方向去取，用于需要把阶次能量放到另一个坐标系里审视的场合。

## 五、倍频程切片：按人耳的频带习惯记账

倍频程切片（Octave Section）表示**一个倍频程带内能量总和的变化**，倍频程带的中心频率按 ISO 150266 标准规定。手册指出 LMS 的倍频程分析覆盖 1/1、1/2、1/3、1/12 与 1/24 倍频程。

它与频率切片的机制完全相同——中心频率固定、带宽固定、窗口钉在频率轴上——唯一的区别是**窗口的位置和宽度按倍频程标准取**：中心频率按 $10^{3N/10}$（N 为整数或其分数）的规定序列取值，带宽与中心频率保持恒定比例（1/1 倍频程的带宽为中心频率的约 71%，1/3 倍频程约 23%）。这样取窗口的结果是**频率轴上按对数刻度均匀分格**：20–80–315–1250 Hz 一路排下来，低频格子窄、高频格子宽，每格对应恒定的相对带宽。

为什么要按这种"低频窄、高频宽"的网格记账？因为这是**人耳的频带习惯**：听觉对频率的分辨近似对数式，600 Hz 到 700 Hz 的音高差，听感上约等于 1200 Hz 到 1400 Hz 的差。声学标准（声级限值、声品质指标）几乎全部落在倍频程网格上，因此**当切片的结果要和声学指标、法规限值对标时，倍频程切片是对接口**。用病理切片的话说：前面两种切法是大夫按病灶选切面，倍频程切片是按体检表的固定项目切——项目是标准定的，全国可比。

数字例子：对上文同一谱阵取 125 Hz 一倍频程带（88.4–176.8 Hz），600 rpm 处切线值 0.20（2 阶线还在 20 Hz，窗外）、2700 rpm 处 3.11（共振带在窗内）、4500 rpm 处 1.26、6000 rpm 处 0.36——2 阶线从窗外爬进窗内再爬出去，加上共振带被扫过的放大，一条曲线把两个事件都记下了。值得注意的是，这条曲线既不是纯"定频窗口"（带宽不是几个赫兹而是 88 Hz），也不是纯"阶次窗口"（窗口不随转速移动）；它以对数宽度覆盖一段频率区间，记录的是**这段区间内所有能量的总和**——宽带、慢变、与人耳口径对齐。

## 六、numpy 演示：同一谱阵，四种切法四种说法

把第二至五节的机制用一段自包含代码演示：构造 600→6000 rpm 升速谱阵（2 阶高斯脊 + 90 Hz 共振带 + 随转速抬升的本底），分别算总级、两种频率切片、2 阶阶次切片（两种带宽规则）与 125 Hz 倍频程切片，看四种切法各自的"说法"。

```python
import numpy as np

rpm  = np.arange(600, 6001, 60)             # 升速 600→6000 rpm
freq = np.arange(1.0, 2001.0, 1.0)          # 频率轴，1 Hz 分辨率
f2   = 2 * rpm / 60.0                       # 2 阶线：20→200 Hz

# 谱阵 = 2 阶脊（幅值0.5）+ 90Hz共振带（2700rpm最强）+ 抬升的本底
ridge = 0.5*np.exp(-((freq[None,:]-f2[:,None])/4.0)**2)
reson = 0.9*np.exp(-((freq-90.0)/6.0)**2)[None,:] \
        * np.exp(-((rpm-2700.0)/700.0)**2)[:,None]
floor = (0.02 + 0.018*rpm/6000.0)[:,None]*np.ones_like(freq)[None,:]
Z = ridge + reson + floor

def band_rms(row, f, lo, hi):               # 切片 = 带内能量 RMS
    m = (f >= lo) * (f <= hi)
    return np.sqrt((row[m]**2).sum())

at = lambda a, r: a[np.argmin(np.abs(rpm-r))]

OA    = np.sqrt((Z**2).sum(axis=1))                                   # 总级
sec90 = [band_rms(Z[i], freq, 87, 93) for i in range(len(rpm))]       # 频率切片:守90Hz
sec20 = [band_rms(Z[i], freq, 17, 23) for i in range(len(rpm))]       # 频率切片:守20Hz
ord_track = [band_rms(Z[i], freq, f2[i]-0.1*rpm[i]/60,                # 2阶±0.1阶
                            f2[i]+0.1*rpm[i]/60) for i in range(len(rpm))]
ord_fixed = [band_rms(Z[i], freq, f2[i]-3, f2[i]+3)                   # 固定±3Hz追2阶
                      for i in range(len(rpm))]
oct125 = [band_rms(Z[i], freq, 88.4, 176.8) for i in range(len(rpm))] # 125Hz一倍频程

print(f"总级OA:      600rpm {at(OA,600):.2f}  2700rpm {at(OA,2700):.2f}  6000rpm {at(OA,6000):.2f}")
print(f"频率切片90Hz: 峰值 {max(sec90):.2f} @ {rpm[np.argmax(sec90)]} rpm")
print(f"频率切片20Hz: 600rpm {at(sec20,600):.2f}  3000rpm {at(sec20,3000):.2f}  6000rpm {at(sec20,6000):.2f}")
print(f"2阶±0.1阶:    600rpm {at(ord_track,600):.2f}  2700rpm {at(ord_track,2700):.2f}  6000rpm {at(ord_track,6000):.2f}")
print(f"2阶固定±3Hz:  600rpm {at(ord_fixed,600):.2f}  6000rpm {at(ord_fixed,6000):.2f}")
print(f"125Hz倍频程:  600rpm {at(oct125,600):.2f}  2700rpm {at(oct125,2700):.2f}  6000rpm {at(oct125,6000):.2f}")
```

运行输出：

```text
总级OA:      600rpm 1.54  2700rpm 3.87  6000rpm 2.10
频率切片90Hz: 峰值 3.30 @ 2700 rpm
频率切片20Hz: 600rpm 1.13  3000rpm 0.08  6000rpm 0.10
2阶±0.1阶:    600rpm 0.87  2700rpm 3.48  6000rpm 1.25
2阶固定±3Hz:  600rpm 1.13  6000rpm 1.17
125Hz倍频程:  600rpm 0.20  2700rpm 3.11  6000rpm 0.36
```

四种切法、四种说法，逐条对账：

- **总级** 2700 rpm 处 3.87，比两端高，但"峰"不陡——全带能量把局部事件摊薄了；
- **频率切片守 90 Hz** 峰值 3.30 恰在 2700 rpm——共振事件的准确定位；**守 20 Hz**（低转速时 2 阶在窗外、600 rpm 时 2 阶恰在 20 Hz 附近）则只有 600 rpm 处 1.13 一个孤峰——窗口定在哪，就只能看见哪里的住户；
- <strong>2 阶阶次切片（±0.1 阶）</strong> 在 2700 rpm 处 3.48——移动窗口全程咬住 2 阶线，共振放大无处遁形；同一条线用**固定 ±3 Hz** 去追，两端读数 1.13、1.17，共振峰消失——带宽规则不当，事件被窗口误差抹掉；
- **125 Hz 倍频程切片** 峰值 3.11 也在 2700 rpm，但峰更宽、量级口径与声学标准一致——适合与限值对标，不适合精确定位。

同一段数据、同一个事件（2 阶扫过 90 Hz 共振），每条曲线都说出了自己口径下的真相。切片分析的功力，就在于**先想清楚要回答什么问题，再选切法**。

## 七、Testlab 里的切片：Section Settings

Simcenter Testlab 中切片功能的落点在 Time Data Processing 工作簿：Acquisition Parameters 区点 **Change Settings**，进入 **Section Settings** 对话框。按切片类型走不同的标签页：总级在 **Overall Level** 页勾选；频率切片在 **Frequency Sections** 页给中心频率与带宽；阶次切片在 **Order Sections** 页——先填阶次号（多个用分号隔开，可非整数），再选带宽模式（Order / % / Frequency / Lines）与带宽数值，软件按设置自动算出上下限；倍频程切片在倍频程相关页选择 1/1、1/3 等分析规格。测量模式设为 Tracked（跟踪转速），切片结果存入 Sections 目录。若只想交互式地快速切一条：在 Navigator 的 colormap 上右键 → Add Processing Cursor → Order（或 Frequency），把光标块拖进显示窗，带宽参数实时可调——边看图谱边调窗口，是最不容易切错的工作方式。

::: warning 工程注意
- 切片幅值对带宽敏感：切线报告必须同时注明积分带定义（中心、模式、带宽），否则数值不可复现
- 追阶次成分用阶次切片，别用固定频率带宽去追——高转速端带宽折算成阶次过窄，会切丢能量
- 频率切片的窗口要对准再够宽：中心偏一个带宽，读数可以少一半
- 与声学限值对标时用倍频程切片，与标准口径对齐，不同来源的数据才可比
:::

## 八、判断标准

拿到一幅 colormap 要"取线"时，按怀疑对象选切法：怀疑定频共振 → 频率切片，窗口对准固有频率、带宽盖住涂抹带；怀疑旋转阶次 → 阶次切片，带宽模式选 Order 并全程对照图谱；要与声学指标对标 → 倍频程切片；先看总级定基调，再用切片查明细。带宽与中心频率是切片的两个生命参数，报告里与数值并列给出。切法选错或带宽失当，得到的不是数据的信息，而是参数设置的回声。

## 一句话记住

切片是从三维谱阵里取二维证据：总级记总数、频率切片守定频、阶次切片追斜线、倍频程切片对耳口径——先想清楚要回答什么问题，再决定往哪个方向切、切多宽。
