# 谐波跟踪：转速瞬变中锁定单根阶次的实操链

> 同一份升速数据，两位工程师算出的 4 阶幅值差了 4 倍——一位 0.98 g，一位 0.24 g。数据没变、阶次没变，差别只在处理链路：一位用了干净的转速迹线做谐波跟踪（Harmonic Tracking，手册十三章的卡尔曼式跟踪滤波），一位的转速迹线带着每转固定角度的量化锯齿。转速通道的误差如何被阶次跟踪放大、跟踪滤波的带宽（谐波置信因子）该拧到哪一挡、它与谐波去除怎样配合使用，本文沿一条实操链把这些决策点串起来：转速迹线是地基、结构/数据方程是方法、HC 是唯一的旋钮、与谐波去除构成加减互补的一对工具。

## 一、为什么切谱线会丢幅值：三个现场场景

先看三个工程现场反复出现的场景，它们指向同一个根源。

**场景一：快速降速。** 燃气轮机 5 秒内从工作转速降到怠速，降速率 75 Hz/s。要做 4 阶的幅值曲线，传统做法是角域重采样加 FFT：阶次分辨率等于平均循环数的倒数，要把间隔 0.5 阶的两根线分开需要至少 2 个循环的平均，而转速掉得如此之快，每个"平均窗"内转速已跨过一大段——切出来的谱线是多个转速状态的平均值，幅值瞬变细节全被抹平。

**场景二：噪声淹没。** 变速箱台架的 21.5 阶啸叫线埋在宽带的齿轮箱本体噪声里，谱线上看只是一条勉强高出本底的窄峰。带通滤波想把它滤出来，但滤波器带宽一窄，转速稍变频率就滑出通带；带宽一宽，邻阶和噪声一起进来。

**场景三：转速迹线先天不足。** 用 60 条纹斑马带测 3000 rpm：每转 60 个脉冲，2000 Hz 采样下每个脉冲间隔只有约 2.2 个采样点，取整量化让换算出的转速迹线带每转固定角度的锯齿。这张"不干净的地图"进入任何阶次跟踪算法，都会让解调相位漂移——幅值误差不是百分之几，而是数倍。

三个场景的共同点：**需要的不是更好的滤波器，而是换一种问题表述**。手册第十三章的答案是卡尔曼式谐波跟踪：不假设信号由固定的频率分量组成，而是逐采样点自适应地跟踪一个结构已知的分量。本文按实操顺序展开：先把转速迹线处理干净（场景三的对策），再理解跟踪方程在做什么（场景一、二的对策），最后落到参数选择与工具配合。

::: info 核心概念
- **谐波跟踪（Harmonic Tracking）**：用卡尔曼滤波式方法从恒采样率信号中跟踪单一阶次成分的算法，输出该阶次的时域波形、逐点幅值与相位
- **结构方程（Structural Equation）**：规定被跟踪波形形态的约束——正弦波对应三点递推差分方程，频率逐点随转速变化
- **数据方程（Data Equation）**：测量信号等于目标成分加噪声与其他成分的表述
- **谐波置信因子 HC（Harmonic Confidence）**：两组方程置信度之比，是决定跟踪带宽与收敛速度的唯一旋钮
:::

## 二、转速迹线是地基：量化锯齿如何变成相位漂移

谐波跟踪的全部方程都依赖一个输入：逐采样点的瞬时转速。手册在 13.2.1 节说得直接——Rpm 信息不精确，"可能会跟踪错误的分量"。转速迹线的误差如何量化地伤害结果？关键在**相位是转速的积分**这一事实。

先用具体数字建立直觉。目标 4 阶、转速 900 rpm：瞬时频率 $4 \times 900/60 = 60$ Hz。若转速迹线整体偏差 15 rpm——只有 1.7%——4 阶频率被高估 $4 \times 15/60 = 1$ Hz。看起来微不足道，但解调相位按积分累积：每秒多转 $2\pi \times 1$ rad，2 秒数据末尾相位偏差 720 度——整整两圈。相干解调的窗口内相位扩散超过一周时，幅值几乎归零。

这个公式回答的问题是：转速迹线的误差经过"阶次×换算×积分"之后，到底变成多大的相位偏差？其中 $n(t)$ 对应物理里的瞬时转速（rpm），$e(t)$ 是转速迹线误差，$k$ 是阶次，相位偏差 $\varphi_e$ 是误差频率对时间的累积。

$$\varphi_e(t) = 2\pi \int_0^t \frac{k\, e(\tau)}{60}\, d\tau \quad [\mathrm{rad}]$$

由此直接读出三类转速误差的危害等级：**零均值随机误差**在积分中互相抵消，危害最小；**单点尖峰毛刺**只贡献一个相位台阶，若毛刺幅值不大可容忍；**系统性偏差（恒偏、比例误差、每转固定角度的锯齿）**线性累积，是幅值误差的主凶。这解释了一个反直觉现象：工程师往往最警惕转速毛刺，但对跟踪精度而言，小而恒定的偏差更致命。

用 numpy 把这三类误差的后果算出来。升速数据 900→1400 rpm、4 阶、信噪比适中的信号，分别用带不同误差的转速迹线做两路相干解调：

```python
import numpy as np

fs = 2000.0                              # 采样率 Hz
t = np.arange(4000)/fs                   # 2 s 升速数据
rpm_true = 900 + 500*t/2                 # 900 -> 1400 rpm
k = 4                                    # 目标阶次
phase = 2*np.pi*np.cumsum(k*rpm_true/60)/fs
sig = np.sin(phase) + 0.3*np.random.default_rng(3).standard_normal(len(t))

def demod_amp(rpm_est, avg=200):
    """两路相干解调取 4 阶幅值：相干本底对消噪声"""
    ph = 2*np.pi*np.cumsum(k*rpm_est/60)/fs
    ai = np.convolve(sig*np.cos(ph), np.ones(avg)/avg, 'same')[2000:]
    bi = np.convolve(sig*np.sin(ph), np.ones(avg)/avg, 'same')[2000:]
    return 2*np.hypot(ai.mean(), bi.mean())

cases = [("准确迹线",            rpm_true.copy()),
         ("恒定偏差 +5 rpm",     rpm_true + 5),
         ("恒定偏差 +15 rpm",    rpm_true + 15),
         ("比例误差 1%",         rpm_true*1.01)]
rpm_spiky = rpm_true.copy()               # 5 处单点毛刺 ±150 rpm
for pos in [400, 900, 1500, 2600, 3400]:
    rpm_spiky[pos] += 150 if pos % 2 == 0 else -150
cases.append(("5 处单点毛刺 ±150 rpm", rpm_spiky))

for name, est in cases:
    pe = np.degrees(2*np.pi*np.cumsum(k*(est-rpm_true)/60)/fs)
    print(f"{name:22s}: 末段相位误差 {pe[-1]:7.0f} 度 | 4 阶幅值 {demod_amp(est):.3f}")
```

运行结果：

```
准确迹线            : 末段相位误差       0 度 | 4 阶幅值 0.991
恒定偏差 +5 rpm     : 末段相位误差     240 度 | 4 阶幅值 0.815
恒定偏差 +15 rpm    : 末段相位误差     720 度 | 4 阶幅值 0.033
比例误差 1%        : 末段相位误差     552 度 | 4 阶幅值 0.171
5 处单点毛刺 ±150 rpm: 末段相位误差       9 度 | 4 阶幅值 0.991
```

结论定量而残酷：+15 rpm 恒定偏差（相对误差 1.7%）让 4 阶幅值从 0.99 崩到 0.03——误差不是被平均掉，而是被阶次和积分**放大**；相比之下 5 处 150 rpm 的单点毛刺几乎无影响。阶次越高、数据越长，同样的转速偏差影响越大。

这就是为什么手册把转速迹线处理列为跟踪前的两个独立步骤：第一步把脉冲串转换为 rpm-时间函数（TACHO_PULSE_TO_RPM 一族函数处理缺脉冲、毛刺、斑马带接缝三类问题，各有专文）；第二步做"采样再采样"的平滑——因为机械系统有惯性，转速物理上不可能突变，所以用逼近边界条件的三次样条把量化锯齿拉成光滑曲线。样条平滑压的正是"每转固定角度的系统性锯齿"这类积分不抵消的误差。

一个贯穿全文的类比在这里引入：**转速迹线是地图，跟踪算法是按图索骥的导航**。地图上每条街道（每个采样点的转速）标错一点，单看无妨；但导航是积分式的——走过的每一步误差都累进里程，几公里后你已经站在完全错误的路口。系统性的地图偏差（每条街都偏北 1 度）让终点偏出几公里；一次看错路标（单点毛刺）只是走了一小段冤枉路，回到正道即可。后面选 HC 参数时这张地图还要再用一次。

## 三、跟踪方程在做什么：结构约束与数据约束的折中

转速迹线干净之后，跟踪本身是两组约束的折中。原理在[上一篇理论文](../../theory/rotating-machinery/vold-kalman-order-tracking.html)中已完整推导，这里只复述实操者需要的骨架，重点放在"每一步在工程上意味着什么"。

第一组是**结构方程**：一段频率为 $f$ 的正弦，相邻三个等间隔采样点满足精确的递推关系。这个方程回答的问题是：已知一根正弦最近两个点，第三个点是否被完全确定？答案是肯定的——无需幅值相位信息，这就是"结构"二字的含义。

$$x(n) - c(n)\,x(n-1) + x(n-2) = \varepsilon(n), \quad c(n) = 2\cos\!\left(\frac{2\pi f(n)}{f_s}\right)$$

其中 $x(n)$ 是目标阶次的理想波形，系数 $c(n)$ 逐点由瞬时频率 $f(n) = k \cdot n(t)/60$ 算出（这里转速迹线的质量直接进入方程），$\varepsilon(n)$ 是允许波形偏离理想正弦的松量——幅值缓变、频率微漂都靠它容纳。

第二组是**数据方程**：测量信号就是目标波形加干扰。

$$y(n) = x(n) + \eta(n)$$

$\eta(n)$ 包含噪声与其他频率成分。两组方程都对全部采样点列出，叠成超定方程组，以加权最小二乘一次求解。加权因子 $r(n)$ 是两组方程置信度之比，其倒数就是谐波置信因子 HC——整个算法对使用者暴露的唯一旋钮。

矩阵形式一行写完（$\lambda = 1/r^2$，即 HC 的平方度量；$L$ 为逐点系数的二阶差分算子）。这个公式回答的问题是：全部结构约束与数据约束折中之后，目标阶次的时域波形一步怎么求出？其中 $I+\lambda L^T L$ 对应物理里"数据项+加权结构项"的组合矩阵，右乘 $y$ 即得逐点波形解：

$$x = \left(I + \lambda\, L^T L\right)^{-1} y$$

一次线性代数求解同时得到全部采样点的波形值——不是"某段平均时间内"的谱线幅值，而是逐点的时域波形 $x(n)$。幅值包络用滑动 RMS 或两路解调从 $x$ 中提取，相位即 $x$ 的瞬时相位。手册给出的能力清单由此而来：任意分数阶次分辨率、不足一个循环的数据也能给出良好分辨率、旋转速率实际不受限制、无相位失真——后一条尤其值钱：求解对象是波形本身，相位不是估计出来的副产品假设，而是解的一部分。代价同样明确：一次求解一个阶次，方程组规模与数据长度同阶，要几十条阶次就得解几十次。

## 四、HC 怎么选：带宽与收敛的定量权衡

HC 高低对应滤波器带宽宽窄，手册的表述是：HC 高意味着谐波（结构数据）可信、测量数据误差大，滤波器呈窄带性质、频率分辨能力高，代价是幅值估计收敛慢；HC 低则带宽宽、收敛快、邻阶渗透。落到实操，两个问题必须定量回答：邻阶隔多近需要多高的 HC？瞬变工况最多能容忍多窄的带宽？

用 numpy 直接做这两个实验。转速 3000±300 rpm 波动，目标 4.0 阶（幅值 2 s 处从 1.0 阶跃到 0.2，模拟离合器接合后的幅值跌落），邻阶 4.5 阶幅值 0.4 模拟邻对齿轮啮合干扰。3000 rpm 下两阶间隔 $0.5 \times 3000/60 = 25$ Hz：

```python
import numpy as np

fs = 2000.0
t = np.arange(6000)/fs
rpm = 3000 + 300*np.sin(2*np.pi*0.5*t)   # 转速波动 ±300 rpm
def inst(o):                             # o 阶的瞬时频率 Hz
    return o*rpm/60
N = len(t)

amp = np.where(t < 2.0, 1.0, 0.2)        # 2 s 处幅值阶跃 1.0 -> 0.2
sig = amp*np.sin(2*np.pi*np.cumsum(inst(4.0))/fs) \
    + 0.4*np.sin(2*np.pi*np.cumsum(inst(4.5))/fs) \
    + 0.3*np.random.default_rng(5).standard_normal(N)

c_full = 2*np.cos(2*np.pi*inst(4.0)/fs)  # 结构方程逐点系数
rows = np.arange(N-2)
L = np.zeros((N-2, N))                   # 二阶差分算子：每行 1, -c(n), 1
L[rows, np.arange(2, N)]   = 1.0
L[rows, np.arange(1, N-1)] = -c_full[2:N]
L[rows, np.arange(0, N-2)] = 1.0
A = L.T @ L

def envelope(x, avg=100):                # 两路解调取包络
    ph = 2*np.pi*np.cumsum(inst(4.0))/fs
    ai = np.convolve(x*np.cos(ph), np.ones(avg)/avg, 'same')
    bi = np.convolve(x*np.sin(ph), np.ones(avg)/avg, 'same')
    return 2*np.hypot(ai, bi)

sig45 = np.sin(2*np.pi*np.cumsum(inst(4.5))/fs)
for lam in [30, 300, 3000]:              # lam = 1/r^2, HC 的平方度量
    M = np.eye(N) + lam*A
    x   = np.linalg.solve(M, sig)
    res = np.linalg.solve(M, sig45)      # 邻阶 4.5 的通过量
    env = envelope(x)
    sel = (t > 2.05) * (np.abs(env - 0.2) < 0.04)
    conv = (np.where(sel)[0][0]/fs - 2.0)*1000
    print(f"lam={lam:5d}: 邻阶4.5污染 {res.std()/x.std()*100:5.1f}% | 阶跃收敛 {conv:4.0f} ms")
```

运行结果：

```
lam=   30: 邻阶4.5污染  86.5% | 阶跃收敛   50 ms
lam=  300: 邻阶4.5污染  31.1% | 阶跃收敛   50 ms
lam= 3000: 邻阶4.5污染   4.9% | 阶跃收敛   76 ms
```

两组数字把权衡摆上台面：$\lambda$ 从 30 提到 3000，邻阶污染从 86.5% 压到 4.9%，代价是幅值阶跃的收敛时间从 50 ms 拖到 76 ms。带宽还有一个容易被忽略的维度——手册 13.3 节指出计权因子逐点可变，**带宽可以定义为频率或阶次的函数**。按频率定义带宽时，低转速下同一个 Hz 带宽会罩住好几个阶次；按阶次定义时，滤波范围相对阶次轴恒定，全转速范围行为一致。实操建议：除极低速工况外，一律按阶次定义。

手册还给出一条先验判据：对间隔密集的两个正弦波，分辨能力与总观察时间成反比——**观察时间应取最小频率间隔的倒数**。25 Hz 间隔对应 40 ms 观察时间，远短于实际数据长度，所以本例在 $\lambda=3000$ 下仍能获得 4.9% 的干净分离。反过来，若两阶在全程最低转速下的频率间隔缩到 2 Hz，观察时间需 0.5 s——瞬变幅值在 0.5 s 内早已变化，此时分辨率与瞬变跟踪物理上不可兼得，只能分段处理或换更密的转速迹线（回到第二节：更密的 PPR 让地图更准，量化锯齿更小）。

## 五、与谐波去除的配合：一加一减的工具对

谐波跟踪与[谐波去除](./harmonic-removal.html)共享同一套"结构已知的离散成分"世界观，方向相反：跟踪是**把目标阶次提取出来看**（加法思维——我只要这一根），去除是**把干扰阶次减出去扔**（减法思维——我只要除这一根以外的）。实操中二者常在同一批数据上先后使用。

典型链路：做运行模态分析（OMA）或扭振分析时，先用谐波去除剥掉污染数据的发动机阶次族得到"干净的本底"，再用谐波跟踪从原始数据中提取关键阶次的时域波形做幅值定量与源识别——一个保证背景可用，一个保证目标可读。顺序上先去除后跟踪还有个好处：跟踪的数据方程中 $\eta(n)$ 的"其他周期分量"被预先剥掉了大部分，同样的 HC 下跟踪结果更干净。

两个工具对转速迹线的依赖也同源：谐波去除的角域重采样需要 rpm-时间函数，谐波跟踪的结构方程系数 $c(n)$ 逐点需要瞬时频率。第二节结论通用——**任何一条链路开工前，先把转速迹线按三类误差的判据过一遍**：每转固定次数的向下突降是缺脉冲（填标称 PPR 与缺齿数修正）、无固定位置的随机尖峰是毛刺（滑窗 MAD 剔除或直线替换）、固定角度的阶跃是斑马带接缝（角度全局重排）。处理完再上样条平滑，压掉量化锯齿这张"系统性偏差的地图"。

::: tip 实用路线
先以中等 HC 跑一版，检查两个残差：提取波形对原始数据的残差里若仍含目标阶次成分，说明带宽过窄（结构约束过强）；残差里若邻阶成分明显，说明带宽过宽。据此微调一档再看。稳态精测（对标 CAE 幅值）最终用高 HC；瞬变工况（tip-in、离合器接合）宁可用中低 HC 容忍少量邻阶渗透，换取幅值的时间细节。
:::

## 六、小结

谐波跟踪的实操链五步：**转速迹线体检**（三类误差判据 + 样条平滑，警惕系统性偏差——它是被阶次和积分放大的那个）→ **确认结构模型**（阶次数、采样率恒定、转速迹线与振动通道同采样率）→ **选 HC**（邻阶间隔定带宽下限、幅值瞬变剧烈程度定上限，带宽按阶次定义）→ **求解与包络提取**（一次线性求解得到逐点波形，幅值相位都是解的一部分）→ **与谐波去除配合**（先去除保背景、后跟踪读目标）。回到开头的两个数字：0.98 与 0.24 的差距不在算法，在链路——地图干净了，导航才可信。

## 一句话记住

谐波跟踪 = 干净转速迹线（系统性偏差被阶次×积分放大，样条平滑压锯齿）+ 结构/数据方程加权最小二乘逐点解出阶次波形；HC 定带宽：邻阶间隔定下限、瞬变速度定上限，与谐波去除一取一舍构成工具对。
