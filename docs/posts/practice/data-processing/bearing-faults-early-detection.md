# 轴承故障早期检测：从包络谱到冲激量的实操链

> 滚动轴承从出现首个剥落点到整机报故障，中间有一段宝贵的窗口期——这段时间里 RMS 几乎不变、频谱上只有一片若隐若现的共振带，常规总级趋势管理看不见它。早期检测要做两件事：用包络分析（Envelope Analysis）从结构共振里解调出故障特征频率，回答"哪个部件坏了"；用冲激量（Impulsiveness）、峭度（Kurtosis）、峰值因子（Crest Factor）这类统计量量化冲击强度，回答"发展到哪一步了"。本文把这条实操链从公式推到判据：特征频率怎么算、包络谱怎么读、统计量口径怎么对、Testlab 里怎么落地，并给出可直接运行的 numpy 演示。

## 一、为什么常规监测抓不住早期轴承故障

状态监测（Condition Monitoring）的常规抓手是总级趋势：RMS、峰值随时间画曲线，超限报警。这套办法对不平衡、不对中等连续激励型故障有效，对轴承剥落却天生迟钝，原因藏在故障信号的物理结构里。

**冲击太短，能量太小。** 滚动体碾过滚道上一处剥落缺陷，接触时间通常在微秒到亚毫秒量级。一个幅值很高但持续时间极短的脉冲，其能量（幅值平方对时间积分）仍然很小，混进整段记录的 RMS 里几乎不露头。等 RMS 明显抬升时，剥落往往已经扩展到多个滚动体、故障进入中晚期。

**冲击是宽带的，谱上不聚焦。** 时域越窄的信号，频域越宽——这是傅里叶变换的对偶性质。单次冲击的频谱是一条平坦的连续谱，能量摊在整个分析带宽上，不形成任何可辨认的谱峰。周期性重复的冲击会在谱上留下"梳齿"，但梳齿被结构共振调制后，肉眼很难直接数出来。

![短瞬态事件在频域产生宽频响应](/images/bearing-faults-early-detection/fig7-transient-broadband.png)

*短时瞬态事件在时域只占几毫秒，在频域却铺开成宽频响应（图源：Simcenter Testing Knowledge Base）*

上图是 Simcenter 知识库对瞬态冲击的经典示意：时域上一个短促的事件，对应频域上一条宽阔的响应带。轴承早期故障正是无数个这样的短事件按特征频率重复出现——每个事件都把自己的能量涂抹到宽频带上，任何单一谱线都只分到极小的一份。

**周期性冲击在彩色图谱上留痕。** 把升速或稳态运行的数据画成 colormap（彩色图谱），周期性冲击表现为贯穿全频段的竖条纹——每个冲击事件瞬间激励所有频率。Simcenter 知识库把这类竖条带列为彩色图谱五类特征线型之一（斜线是阶次、水平线是共振、竖条带是冲击）。

![周期性冲击在彩色图谱上形成竖条带](/images/bearing-faults-early-detection/fig6-impacts-colormap.png)

*周期性冲击在彩色图谱上呈现为竖条带，图中 1000～3000 Hz 的抬升带由反复撞击产生（图源：Simcenter Testing Knowledge Base）*

看到竖条带只能判断"有冲击源"，还不知道是轴承、齿轮拍击还是活塞敲缸。定位到具体部件，需要下一节的包络分析。

::: info 核心概念
- **包络分析（Envelope Analysis）**：对共振频段带通滤波后取幅值包络，再做谱分析，从载波里解调出冲击重复频率的诊断方法
- **故障特征频率（Fault Characteristic Frequency）**：滚动体碾过缺陷的冲击重复率，由轴承几何与转速决定，外圈 BPFO、内圈 BPFI、滚动体 BSF、保持架 FTF 四个量各对应一个部件
- **冲激量（Impulsiveness）**：基于包络分析量化信号冲击性质的统计输出组，含平均脉冲峰值电平、上升斜率、作用时间与脉冲发生率
- **峭度（Kurtosis）**：信号四阶标准化矩，幅值分布尾部长度的度量，含冲击成分的信号显著高于高斯基准
:::

## 二、第一步：算准四个特征频率

包络谱判读的前提是手里有一张"频率对照表"。设滚动体数 $Z$，轴转频 $f_r$（Hz，等于 rpm/60），滚动体直径 $d$、节圆直径 $D$（同一单位，式中只出现比值），接触角 $\alpha$（深沟球轴承 $\alpha=0$）。

外圈固定、内圈随轴旋转时，保持架（Cage）相对外圈的转动频率是整条推导链的起点。滚动体在滚道上纯滚动，保持架转速是内圈转速与滚动体公转的折中：

$$\mathrm{FTF} = \frac{f_r}{2}\left(1 - \frac{d}{D}\cos\alpha\right)$$

$Z$ 个滚动体跟着保持架公转，单位时间内滚过外圈任一固定点的次数是 $Z \cdot \mathrm{FTF}$，这就是外圈通过频率；内圈以 $f_r$ 旋转，滚道上的点相对保持架以 $f_r - \mathrm{FTF}$ 通过滚动体，得到内圈通过频率：

$$\mathrm{BPFO} = \frac{Z}{2}\, f_r \left(1 - \frac{d}{D}\cos\alpha\right)$$

$$\mathrm{BPFI} = \frac{Z}{2}\, f_r \left(1 + \frac{d}{D}\cos\alpha\right)$$

滚动体自转缺陷交替撞击内外圈，其自转频率为：

$$\mathrm{BSF} = \frac{D}{2d}\, f_r \left(1 - \left(\frac{d}{D}\cos\alpha\right)^{2}\right)$$

四个频率都在 $f_r$ 的整数倍与分数倍之间分布：$\mathrm{BPFO} < Z f_r / 2 < \mathrm{BPFI}$，FTF 恒小于 $f_r/2$。拿一个典型深沟球轴承算数值：$Z=9$，$d/D=0.18$，$\alpha=0$，轴转速 3000 rpm（$f_r = 50$ Hz）时：

| 频率 | 公式代入 | 数值 | 相当于几阶 |
| --- | --- | --- | --- |
| **FTF 保持架** | $0.5 \times 50 \times (1-0.18)$ | 20.5 Hz | 0.41 X |
| **BPFO 外圈** | $4.5 \times 50 \times 0.82$ | 184.5 Hz | 3.69 X |
| **BPFI 内圈** | $4.5 \times 50 \times 1.18$ | 265.5 Hz | 5.31 X |
| **BSF 滚动体** | $(1/0.36) \times 50 \times (1-0.0324)$ | 134.5 Hz | 2.69 X |

这张表说明两件事：其一，特征频率都不是整数阶，不会与不平衡（1X）、不对中（2X）等轴频谐波族混淆；其二，四者彼此间距有限，包络谱分辨率必须足够细才能分开——184.5 与 20.5 Hz 的间距要求包络谱有效分辨率优于 10 Hz 量级，记录长度至少 0.1 s，工程上通常取 1 s 或更长。

::: warning 工程注意
特征频率公式假设纯滚动。实际轴承存在滑动，载荷、转速、游隙都会让实测频率偏离理论值 1%～2%。判读时在理论频率附近开一个小搜索窗（如正负 2%），找窗内最高峰对表，不要拿游标死钉在理论值上。
:::

## 三、第二步：包络分析——从共振载波里解调出故障频率

### 3.1 冲击调制的物理图像

剥落缺陷激起的是轴承座、端盖的结构共振——通常落在几百 Hz 到几 kHz。把这段共振看成通信系统里的载波（Carrier），冲击序列就是对载波的调制（Modulation）：有冲击时共振被激起、幅值大，无冲击时共振衰减、幅值小。包络（Envelope）就是这条幅值轮廓线。

提取包络的现代做法基于希尔伯特变换（Hilbert Transform）——对信号每个频率分量赋予 90 度相移，与原信号组成解析信号（Analytic Signal），其模即包络。完整的推导与 Testlab 实现在本站《希尔伯特变换与包络分析》一文已有展开，此处只回顾工程链路：带通滤波锁定共振段，希尔伯特取包络，包络谱判读。

![希尔伯特滤波器幅频特性的规格化定义](/images/bearing-faults-early-detection/fig5-hilbert-mag-spec.png)

*希尔伯特变换器的幅频特性：只在 $\omega_l < \omega < \omega_u$ 内要求 $|H_d(\omega)|=1$，工程上按 FIR 逼近（图源：LMS 检测理论手册）*

LMS 检测理论手册特别指出：理想的希尔伯特变换器（全频段幅值恒 1、相位恒移 90 度）物理不可实现，工程实现只在有限通带内逼近。这从数学上坐实了带通滤波的必要性——原始信号里的低频轴频分量和直流漂移落在逼近频带之外，不解调会直接扭曲包络。

### 3.2 包络谱的判读表

对包络信号做 FFT，得到的谱上，冲击重复频率及其谐波成族出现——谐波族比单根谱线可靠得多，因为谐波族结构很难被偶然噪声伪造。四个部件的"指纹"各有差异：

| 判据 | 外圈故障 | 内圈故障 | 滚动体故障 | 保持架故障 |
| --- | --- | --- | --- | --- |
| **包络谱主峰** | BPFO 及谐波 | BPFI 及谐波 | BSF（x2 更显）及谐波 | FTF（很低且弱） |
| **边带特征** | 一般无转频边带 | 正负 $f_r$ 边带明显 | 正负 FTF 边带 | 伴生成分复杂 |
| **幅值稳定性** | 冲击幅值稳定 | 随缺陷位置波动大 | 介于两者之间 | 幅值微弱 |

| **物理机理** | 缺陷相对载荷区固定 | 缺陷随内圈旋转、时进时出载荷区 | 滚动体自转加公转 | 保持架碰外圈 |

边带的物理来源值得多说一句：内圈缺陷随轴旋转，缺陷转进载荷区时冲击强、转出时冲击弱，冲击幅值被转频调制，包络谱上 BPFI 两侧就出现间距为 $f_r$ 的边带族。滚动体缺陷撞的是相对保持架位置固定的接触点，调制源换成保持架转频，边带间距变成 FTF。外圈缺陷位置固定、载荷区固定，无调制。边带间距是仅次于主峰频率的第二判据。

::: tip 通带选择原则
- 没有共振信息：先看原始频谱找连续谱峰带，或直接用宽通带（如 1～10 kHz）试解调
- 多个共振带：优先选离齿轮啮合频率、轴频谐波远的那个，避免解调出虚假调制
- 通带别贴着强离散谱线（如啮合频率）的边缘——谱线滚降进通带会变成假载波
:::

## 四、第三步：冲激量——给冲击强度定标尺

包络谱回答"哪个部件"，趋势管理还需要"严重程度"的量化指标。RMS 在早期阶段不敏感（第一节的原因），工程上换用直接针对冲击形态设计的统计量。LMS 检测理论手册第 7.10 节给出的冲激量（Impulsiveness）是其中信息最完整的一组。

### 4.1 冲激量的输出参数

冲激量的算法基于包络分析——这与第三节的诊断链天然衔接。手册明确其输出包含四组量：**平均脉冲峰值电平**、**平均脉冲上升斜率**、**平均脉冲作用时间**、**平均脉冲发生率**。判定"什么算一次脉冲"依赖阈值（Threshold）：综合所有信号分段的 RMS（总体求得）、帧信号 RMS（跟踪分析情况下）与用户定义的阈偏置。手册对脉冲事件的定义链为：

- **脉冲起始点**：信号从低值上升至阈值时的极小值点
- **脉冲上升时间**：起始点至达到脉冲峰值电平的时间间隔
- **峰值电平**：以 dB 表示，取脉冲峰值电平与阈值电平之差
- **峰点**：越过阈值后达到的第一个最大值
- **脉冲作用时间**：上升时间与下降时间之和
- **上升斜率**：起始点与峰点之间的最大上升斜率

![冲激量输出参数的定义](/images/bearing-faults-early-detection/fig1-impulsiveness-params.png)

*冲激量的参数定义：阈值之上识别脉冲，输出平均峰值电平、上升斜率与作用时间（图源：LMS 检测理论手册）*

这组参数的价值在于把"冲击"从定性描述变成可趋势管理的数字序列：故障扩展时，剥落边缘增大、单次冲击变宽变强——峰值电平与作用时间上升；缺陷数量增多时，脉冲发生率上升。四条曲线合起来就是故障发展的台账。手册还注明其典型应用是量化柴油发动机噪声的冲击性质，轴承监测沿用同一套算法。

### 4.2 峰值因子与峭度：两个轻量替代

冲激量需要设阈值、分段计算，实现较重。日常监测更常用两个开箱即得的统计量。

**峰值因子（Crest Factor）** 定义为峰值与 RMS 之比：

$$C = \frac{x_{\mathrm{peak}}}{x_{\mathrm{rms}}}$$

LMS 手册给出基准数值：正弦波 $C = 1.41$（即 $\sqrt{2}$），随机信号大致 3～4，短促尖脉冲可以很大。峰值因子提供数据的"峰态"测量，纯 RMS 趋势看不出形态变化时它先动。

**峭度（Kurtosis）** 是四阶标准化矩，手册定义（高斯基准归零的"峭度超值"口径）：

$$k = \frac{1}{N}\sum_{i=1}^{N}\left(\frac{x_i - \bar{x}}{\sigma}\right)^4 - 3$$

减 3 这一项让高斯分布对应 0：正值表示实际分布比高斯有更长的尾部，负值表示尾部更短。含冲击的信号绝大多数采样点安静地待在零附近、少数冲击点伸到远处，分布呈"中部尖峰+长尾"，峭度显著为正。

![正负峭度分布与正态分布的比较](/images/bearing-faults-early-detection/fig4-kurtosis-dist.png)

*峭度对分布形态的区分：长尾分布峭度为正，短尾为负（图源：LMS 检测理论手册，原书注：图中正负峭度两图形疑应互换）*

![数据分布的对称和偏斜](/images/bearing-faults-early-detection/fig2-skewness-dist.png)

*偏斜度与峭度互补：偏斜度看分布左右不对称性，峭度看尾部长短（图源：LMS 检测理论手册）*

轴承故障进程与峭度的关系有明确的物理对应：早期单点缺陷，冲击稀疏而尖锐，峭度高；故障扩展到多个剥落点，冲击密集化，幅值分布趋近均匀，峭度反而回落、RMS 接手上升。所以趋势管理里峭度适合"早期报警"，RMS 适合"晚期确认"，两者接力。

手册同时给出两点告诫。其一，峭度对高斯分布的标准差为 $\sqrt{24/N}$，高次矩对离群点极度敏感，实际分布的标准差往往无法确定。其二，原文强调："偏斜度和峭度这种高次矩，与基于线性相加的低次矩相比较，其鲁棒性通常较差，计算结果往往比较分散，在使用它时务必谨慎。"工程对策：峭度要配合滑动帧统计（对信号分帧、每帧算一个峭度，看随时间变化的曲线）使用，单帧孤值不作为判据。

::: warning 口径必须核对
不同软件的"峭度"定义不一致：有的口径不减 3（高斯 = 3），有的减 3 成"峭度超值"（高斯 = 0）。Simcenter Testlab 不同模块之间口径也有差异，对比两套系统的数值前必须先确认。跨系统对比趋势数据，口径差 3 直接让基线错位。
:::

### 4.3 统计量的分工总表

| 指标 | 数学本质 | 早期单点缺陷 | 中晚期多点剥落 | 何时失效 |
| --- | --- | --- | --- | --- |
| **RMS** | 二阶矩，能量 | 几乎不变 | 明显上升 | 冲击能量小于背景振动时（早期） |
| **峰值因子** | 峰值/RMS | 升高 | 回落（RMS 涨得比峰值快） | 有单个毛刺干扰时失真 |
| **峭度** | 四阶矩，尾部长度 | 显著为正 | 回落趋近高斯 | 样本短、离群点主导时分散 |
| **冲激量** | 包络加阈值事件统计 | 峰值电平、发生率上升 | 作用时间变宽 | 阈值设置不当漏计或过计 |

## 五、实操链串联：一次完整的早期检测

把前四节组装成可执行的作业流程。场景设定：台架上一台电机驱动齿轮箱，输出端轴承型号已知，3000 rpm 稳态运行，测点布置在轴承座径向。

**测量准备。** 采样率至少覆盖到轴承座结构共振的上限——通带若选 1～10 kHz，采样率 25.6 kHz 起步；记录长度按包络谱分辨率需求定，要分开 FTF 与 $f_r$ 边带（本例 20.5 与 50 Hz），记录至少 1 s，建议 10 s 以上取平均。加速度计磁吸或胶粘在轴承座载荷区方向（径向指向载荷方向，传递路径最短）。

**在线筛查。** Testlab Signature 等常规采集下先看 colormap：全频段竖条带是冲击源的标志。竖条带出现即转入包络分析，没有竖条带也要按周期做统计量趋势。

**离线包络分析。** Time Signal Calculator 里 FILTER_BP 带通锁定共振段，接希尔伯特类解调函数取包络，再对包络做 FFT。判读按第三节的表：主峰对上哪个特征频率，故障就在哪个部件；边带间距复核调制源。谐波族至少看到 2～3 阶才算坐实，单根谱线不足为凭。

**趋势台账。** 定期（如每天或每工况段）计算冲激量四参数与峭度、峰值因子、RMS，画在同一时间轴上。报警逻辑不是单指标越限，而是组合判据：峭度持续为正 + 包络谱出现 BPFO 谐波族 = 早期外圈缺陷，列入观察；冲激量峰值电平单调上升 + 作用时间变宽 = 缺陷在扩展，安排更换窗口。

**降速复核。** 特征频率正比于 $f_r$，降低转速时真实的轴承故障峰会跟着 $f_r$ 挪动，结构共振峰不动。降速复测一次，峰跟着走的才是故障，留在原地的只是共振带内的定频干扰——这是区分调制成分与固有成分的零成本手段。

## 六、Python 演示：早期故障在四个统计量上的不同表现

```python
import numpy as np
from numpy.fft import rfft, irfft

fs = 25600.0
t = np.arange(0, 2, 1/fs)
rng = np.random.default_rng(1)
f_res, decay = 3200.0, 900.0     # 结构共振 3.2 kHz，衰减率 900/s

def synth(f_fault, n_fault, depth):
    # 按故障频率叠加 n_fault 次冲击，depth 控制冲击强度（早期小、晚期大）
    sig = np.zeros_like(t)
    for k in range(n_fault):
        t0 = k / f_fault + rng.normal(0, 2e-5)   # 微小抖动模拟轴承滑动
        tau = np.clip(t - t0, 0, None)
        sig += depth * np.exp(-decay*tau) * np.sin(2*np.pi*f_res*tau)
    return sig + rng.normal(0, 0.15, t.size)      # 背景振动

def stats(x):
    k4 = np.mean(((x - x.mean())/x.std())**4)     # 峭度，不减3口径，高斯=3
    return x.std(), np.abs(x).max()/x.std(), k4   # RMS、峰值因子、峭度

print("state     RMS    Crest  Kurtosis")
for name, ff, dep in [("healthy", 0, 0.0), ("early", 184.5, 0.8), ("mid", 184.5, 3.0)]:
    r, c, k = stats(synth(ff, int(ff*2), dep))
    print(f"{name:<8}{r:8.3f}{c:8.2f}{k:10.2f}")

# 带通-希尔伯特取包络再谱分析：第三节的解调链
x = synth(184.5, 369, 0.8)
X = rfft(x)
freq = np.fft.rfftfreq(x.size, 1/fs)
X[(freq < 2000) | (freq > 6000)] = 0             # 2-6 kHz 带通锁定共振段
xh = irfft(X)                                    # 带通后的实信号
Xa = rfft(xh) * 2.0                              # 单边谱加倍=解析信号谱
Xa[0] /= 2.0
an = np.concatenate([Xa, Xa[-2:0:-1].conj()])    # 拼成全谱
env = np.abs(irfft(an, n=x.size))                # 解析信号取模=包络
E = np.abs(rfft(env - env.mean()))               # 包络谱
ef = np.fft.rfftfreq(env.size, 1/fs)
band = np.logical_and(ef > 10, ef < 500)         # 特征频率搜索频段
peak = ef[np.argmax(np.where(band, E, 0.0))]
print(f"envelope spectrum peak: {peak:.1f} Hz (theory BPFO = 184.5 Hz)")
```

运行结果要点：健康件峭度 3.05、峰值因子 4.42，正落在本节手册给的高斯随机 3～4 区间附近；早期故障（冲击深度 0.8）叠加后 RMS 只从 0.149 涨到 0.234（+57%），峭度已升到 4.49、峰值因子 5.25——形态类指标先动；中期（深度 3.0）RMS 涨到 0.692（近 5 倍），此时 RMS 才成为最显眼的指示。解调链的包络谱最高峰精确落在 184.5 Hz，正对外圈特征频率，且 369.0 Hz 二次谐波同步在列——谐波族坐实诊断。

## 七、小结

早期检测的判据链，按优先级直接给：

- 包络谱出现某特征频率的 2 阶以上谐波族——部件定位，主峰对表、边带复核，内圈看 $f_r$ 边带、滚动体看 FTF 边带
- 峭度（口径核对清楚）持续高于高斯基准——早期报警，配合滑动帧看随时间变化的曲线，单帧孤值不作数
- 冲激量的平均脉冲峰值电平与作用时间同时上升——缺陷扩展的直接证据，比 RMS 早动
- RMS 明显抬升——中晚期确认，配合安排更换窗口
- 降速复测峰随 $f_r$ 移动——区分真故障与定频干扰的零成本手段

监测节奏上，包络分析按周或按工况做离线复盘即可，统计量趋势要高频做——峭度与峰值因子的计算成本极低，适合每次采集后自动跑一遍。特征频率表是整条链的地基，轴承型号一换表就得重算，型号录入错误是这条实操链里最常见的低级事故。
