# 谐波去除：从信号中剥离已知干扰

> 数据里总有一些"你已经知道是谁、但就是不想要"的成分：zebra 盘偏心造出的假 1 阶、50 Hz 电力谐波一族、OMA 数据里斜穿的发动机阶次线。Simcenter Testlab 的 Harmonic Removal 不走滤波路线，而是把角域循环平均得到的同步成分从原信号里减掉——这篇讲清四步算法、六个参数和三个典型用法。

## 一、滤波器干不了的活

先看三个真实场景：

- 扭振测试，zebra 盘装偏了一点。每转一圈条纹先密后疏，转速通道里混进一个假的"每转一次"波动。它和真实的 1 阶扭振在**同一个频段**，带通滤波根本无法区分；
- 做运行模态分析（OMA），激励本该是宽带随机，结果 colormap 上发动机阶次斜线一片，模态识别直接被淹；
- 台架数据被 8 Hz 及其倍频污染（电力谐波 50/60 Hz 同理），竖条带贯穿整张 colormap。

三件事的共同点：干扰是**某个已知转速（或已知频率）的整数倍离散成分**——即谐波。而普通滤波器对付不了它们，原因有二。

第一，阶次是随转速斜着走的，定频滤波器追不上；就算用跟踪滤波，一次也只能处理一条阶次线，而谐波是一整族（1、2、3…阶）。第二，也是更根本的：需要去掉的成分和想保留的信号常常**共用同一频段**——偏心 runout 的假 1 阶叠在真扭振上，阶次线压在共振峰上。频域里分不开的东西，得换到别的域里找判据。

::: info 核心概念
- **谐波（Harmonics）**：与参考转速成整数倍关系的离散频率成分，由旋转部件产生
- **角域（Angle Domain）**：横轴从时间换成转角的表示法，转速波动时同步成分在角域严格周期重复
- **同步平均（Synchronous Averaging）**：按循环对齐后平均，只保留与参考轴同步的成分，非同步成分被平均掉
:::

## 二、四步算法：不滤，而是"估计出来再减"

Harmonic Removal 的思路不是滤掉谐波，是**先把谐波估计准，再从原信号里逐点减去**。整个流程四步，一次 HARMONIC_FILTER 操作内部全部完成：

**1. 时域变角域。** 用转速通道把数据按转角重采样。转速波动时，每转一次的事件在时域里间隔不均匀，到了角域全部均匀对齐——这是后续"按循环对齐"的前提。

**2. 角域循环平均。** 取滑动窗口（窗长 = nr_of_cycles_for_avg 个循环），把窗口内的循环逐点平均成一个"平均循环"。与参考轴整数倍同步的成分每循环严格重复，原样留在平均里；不同步的成分循环间相位漂移，越平均越趋近于零。

**3. 逐循环相减。** 把平均循环从每个实际循环里减掉——同步的谐波族被剥走，剩下的就是"其他一切"。

**4. 角域变回时域。** 变回时域继续用，或直接输出角域数据。

*（图源：Simcenter Testing Knowledge Base）*

手册里的经典例子：信号含 1 阶和 2.3 阶两个成分。平均循环里只剩 1 阶（及 1 阶的整数倍，如果有的话），2.3 阶因为不同步被平均掉；原信号减去平均循环，剩下的恰好是干净的 2.3 阶。一进一出，两个成分干净分家。

## 三、Testlab 操作：六个参数定生死

入口在 Time Signal Calculator：主菜单 Tools -> Add-ins 勾选 **Harmonic Removal**（15 tokens）和 **Time Signal Calculator**（26 tokens），然后在 Time Data Selection 界面按 f(x) 找到 **HARMONIC_FILTER** 函数。

![HARMONIC_FILTER 在 Time Signal Calculator 的函数列表里](/images/harmonic-removal/tsc-harmonic-filter.png)

*（图源：Simcenter Testing Knowledge Base）*

设置一共六项，每一项都有工程含义：

| 参数 | 含义 | 工程要点 |
| --- | --- | --- |
| **function1** | 要去谐波的数据通道 | 处理对象 |
| **tacho** | 参考转速通道 | 与它同步的谐波族会被去除 |
| **samples_per_rev** | 角域每转采样点数 | 可去除的最大阶次 = 其一半 |
| **cycle_definition** | 每循环转数 | 四冲程发动机 = 2 转/循环 |
| **nr_of_cycles_for_avg** | 滑动平均的循环数 | 阶次分辨率 = 1/循环数 |
| **mode** | 输出域 | 时域或角域 |

![Harmonic Filter 的六个设置项](/images/harmonic-removal/harmonic-filter-settings.png)

*（图源：Simcenter Testing Knowledge Base）*

两个参数最容易被坑：

::: warning 参数坑
- **cycle_definition 忘改 2**：四冲程机一个完整循环是 2 转（720 度），按默认 1 转去平均，进气行程和做功行程被错位对叠，燃烧相关的 0.5 阶族信息直接被搅乱；
- **nr_of_cycles_for_avg 是把双刃剑**：10 个循环平均得到 0.1 阶分辨率，不同步成分分得更干净；但窗口越长，对瞬态变化的跟踪越迟钝。稳态数据取长些，快变的瞬态（tip-in/out）别超过信号实际平稳的长度。
:::

## 四、Python 演示：为什么 1 阶留下、2.3 阶消失

循环平均的分离机制一句话就能说清：k 阶分量相邻循环的相位差等于 360 度乘以 k 的小数部分。整数阶相位差为零，循环间严格对齐，平均原样保留；非整数阶相位漂移，平均后趋于抵消。下面用 numpy 复现这套分离：

```python
import numpy as np

spr, ncyc = 64, 40                       # 每转采样数、总循环数
angle = np.arange(ncyc * spr) / spr * 2 * np.pi
sig = 1.0*np.sin(1*angle) + 0.5*np.sin(2.3*angle)   # 1 阶 + 2.3 阶

# 相邻循环相位差 = 360 度 * 阶次的小数部分
for k in (1.0, 2.0, 2.3, 2.5):
    d = (k % 1) * 360
    tag = "对齐留在平均里" if min(d, 360-d) < 1 else "漂移被平均掉"
    print(f"{k:>4} 阶: 相位差 {d:5.1f} 度  {tag}")

cyc = sig.reshape(ncyc, spr)             # 按循环切齐（角域对齐的等价形式）
avg = cyc.mean(axis=0)                   # 平均循环：只剩同步的 1 阶
resid = cyc - avg                        # 相减：只剩 2.3 阶

rms = lambda x: np.sqrt(np.mean(x**2))
print(f"平均循环 RMS = {rms(avg):.3f}  (1 阶理论值 {1/np.sqrt(2):.3f})")
print(f"残差 RMS    = {rms(resid):.3f}  (2.3 阶理论值 {0.5/np.sqrt(2):.3f})")
```

看两个数：平均循环 RMS 0.707 精确等于 1 阶理论值——同步成分毫发无损；残差 RMS 0.354 精确等于 2.3 阶理论值——40 个循环足以把非同步分量平均到零。顺带注意 2.5 阶：相位差 180 度，只需两个循环就完全抵消；而 2.02 阶相位差仅 7.2 度，短窗内近似对齐，会往平均里泄漏——这正是 nr_of_cycles_for_avg 决定阶次分辨率的定量原因。

## 五、三个典型应用

### 修正 zebra 盘偏心的 runout

zebra 盘装偏心，条纹间距每转一次密一次疏，转速估计里出现假的每转一次波动。它以 1 阶及整数谐波的形式污染扭振数据。用 HARMONIC_FILTER 以该转速通道自身为参考，把假 1 阶族剥掉，剩下的才是真实扭振。注意这里 tacho 和 function1 是同一个通道——自己洗自己。

### 分离多个旋转部件的贡献

整车或台架上液压泵、发电机、压缩机各转各的，colormap 里阶次线混作一团。对每个部件的转速分别做谐波去除，就能给每条阶次线找到主人。**前提是各部件转速比不能是整数倍**——泵转速恰是发电机 2 倍的话，相对发电机它们全是整数阶，在循环平均里不分彼此；2.3、1.4、4.6 这类非整数比才分得开。

### 扣掉定频污染：没有转速通道就造一个

8 Hz、50/60 Hz 电力谐波是定频干扰，手头往往没有对应的"转速通道"。办法是在 Time Signal Calculator 里造一个：生成 8 Hz 方波再转成 RPM 通道，把它当 tacho 喂给 HARMONIC_FILTER（具体造法在[上一篇 TSC 技巧](./time-signal-calculator-tips.html)里写过）。定频谐波相对这个虚拟转速永远是整数阶，照剥不误：

![8 Hz 谐波族去除前（上）后（下）的 colormap 对比](/images/harmonic-removal/colormap-8hz-removed.png)

*（图源：Simcenter Testing Knowledge Base）*

::: tip 使用判断
- 干扰与某根轴（或某个定频）严格整数倍同步：HARMONIC_FILTER 是首选
- 想保留的成分恰好也是该轴整数阶（比如就是想分析 2 阶本身）：别用它，会连同目标一起剥掉
- 没有物理转速通道：定频干扰用虚拟 RPM，转速未知的旋转件先想办法提取 RPM 再说
:::

## 六、小结

谐波去除的本质是把"频域分不开、角域分得开"的判据用足：同步成分循环间对齐、非同步成分循环间漂移，一次循环平均就能把两类成分拆开，再加一步减法各取所需。参数上盯死两处——四冲程 cycle_definition 记得填 2，平均循环数在分辨率与跟踪能力之间按数据平稳长度取舍；多部件分离前先确认转速比不是整数。数据被已知干扰污染时，先想这个工具，再想重测。
