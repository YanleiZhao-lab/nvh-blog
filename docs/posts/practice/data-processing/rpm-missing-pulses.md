# 转速信号缺脉冲：识别与修复

> 转速测量普遍采用磁电传感器对齿轮、光电传感器对斑马带的脉冲计数方式：脉冲间隔的倒数乘以换算系数即得转速。一旦圆周上有一条条纹或一个齿缺失，缺齿处的脉冲间隔被拉长约一倍，换算出的转速在该处骤降——每转一次、形状可重复。本文从脉冲计数测速原理出发，推导缺脉冲误差的定量公式，说明它与随机毛刺、斑马带接缝两类误差的区分判据，并给出 Simcenter Testlab 离线（TACHO_PULSE_TO_RPM）与在线（Tracking Setup）两条修正路径的全部参数设置。

## 一、脉冲计数测速：缺脉冲从哪里来

测旋转机械转速，最常用的手段不是"直接测速度"，而是**数脉冲**：在旋转部件圆周上均匀布置条纹或齿，传感器每感测到一条就输出一个脉冲，数据采集系统记录每个脉冲的到达时刻 $t_k$（$k=0,1,2,\dots$）。设每转脉冲数（Pulses Per Revolution, PPR）为 $P$，相邻两个脉冲的间隔 $\Delta t_k = t_{k+1}-t_k$ 对应的角度增量为 $360^\circ/P$，则该角度区间内的平均转速为

$$
n_k = \frac{60}{P\,\Delta t_k}\ \mathrm{rpm}
$$

推导只有两步：一转被 $P$ 个脉冲均分为 $P$ 个角度格，一个格子耗时 $\Delta t_k$，一转就耗时 $P\,\Delta t_k$；取倒数得每秒转数，乘 60 换算到每分钟。转速与脉冲间隔是严格的倒数关系——**间隔被拉长多少，转速就被等比例压低**，这是后文一切误差分析的出发点。

![编码器信号缺一脉冲时的转速曲线](/images/rpm-missing-pulses/rpm-downturns.png)

*图 1 每转缺一个脉冲的编码器信号：转速-时间曲线上出现周期性的向下尖坑，坑的重复频率严格等于转频（图源：Simcenter Testing Knowledge Base）*

图 1 是缺脉冲最典型的指纹：转速曲线主体平滑，但每隔一转出现一次骤降。坑的深度远超真实转速波动，且每次形状一致——这不是机器真的在减速，是算法被缺齿"骗"了。

为什么每转脉冲数要多？因为分辨率。PPR 越高，一转之内可分辨的转速变化越细，扭振（torsional vibration）、角域分析这类需要看清"一转之内速度怎么波动"的应用就依赖高 PPR。反过来，这些分析也要求脉冲**严格等间隔**——任何固定的间距偏差都会被换算成假的转速变化，进而被误读为扭振、不平衡或其他故障。

::: info 核心概念
- **每转脉冲数（Pulses Per Revolution, PPR）**：旋转一周传感器输出的脉冲个数，决定角向分辨率
- **脉冲计数测速**：由相邻脉冲到达时刻的间隔按倒数关系换算转速的方法
- **缺脉冲（missing pulse）**：圆周上本应有脉冲的位置（齿、条纹）缺失，导致该处间隔异常拉长
:::

## 二、磁电传感器与缺齿齿轮：一个完整案例

转速传感器有很多种，工程上最常见的一类是**磁电转速传感器**（magnetic pickup）：输出电压与到金属表面的距离成正比，对准金属齿轮的齿顶安装，齿与齿槽交替经过即输出一串电压脉冲。它的好处是皮实、便宜、抗灰尘，且 PPR 直接等于齿轮齿数——36 齿齿轮每转自动给出 36 个脉冲，不用额外贴条带。

代价是齿轮本身可能缺齿。有些齿轮设计上就故意去掉一个齿（如发动机曲轴信号齿轮，缺齿用于指示曲轴绝对角位置）；有些是断齿、油泥遮蔽、传感器安装偏斜导致某个齿的信号幅值低到检测门限以下。无论哪种，结果一致：**那一圈的脉冲序列里少了一个**。

设齿轮标称 $P$ 齿、缺 1 齿，缺齿处的脉冲间隔从理论值 $\Delta t$ 拉长到约 $2\Delta t$（跨过空缺的下一个脉冲晚到约一个齿距）。代入转速公式，该处反算转速为

$$
\hat{n} = \frac{60}{P\cdot 2\Delta t} = \frac{n}{2}
$$

即**瞬时转速被低估到一半左右**。推导就一步：间隔翻倍进入分母，倒数关系让转速减半。若轴实际稳定在 3000 rpm，缺齿处就会算出约 1500 rpm 的深坑——每转一次。

![缺脉冲造成的转速骤降](/images/rpm-missing-pulses/rpm-3000-drop.png)

*图 2 五转数据中缺脉冲的影响：真实转速约恒定 3000 rpm，每转一次因脉冲间隔拉长而测得显著的转速下降（图源：Simcenter Testing Knowledge Base）*

图 2 中轴的真实转速恒定在 3000 rpm 附近，但每转一次的深坑把曲线切出五个锯齿。这个假信号的频率位置尤其麻烦：**每转一次 = 1 阶**，恰好落在扭振分析最关心的低阶段；幅值又远超真实扭振（跌掉约 1500 rpm，而真实扭振通常只有几到几十 rpm），在 colormap 上会拉出一条明亮的假 1 阶线（含其谐波），把真信号淹没。

::: warning 工程注意
曲轴信号齿轮的缺齿是**设计特性**，不是故障——但若在通道设置里按实际齿数（如 35）而非标称齿数（36）填 PPR，或根本不做缺脉冲修正，扭振与角域分析全部作废。拿到齿轮图纸第一件事：确认标称齿数与缺齿数。
:::

## 三、识别：与随机毛刺、接缝误差的区分

缺脉冲不是转速通道里唯一的误差，修正前必须先分清是哪一类，因为三类误差对应三套完全不同的修正工具：

| 对比项 | 缺脉冲 | 随机毛刺（油污/偶发丢脉冲） | 斑马带接缝 |
|---|---|---|---|
| **出现规律** | 每转固定次数（缺几个齿就几次） | 随机、无固定位置 | 每转一次、固定角度 |
| **形状** | 深度一致的骤降坑 | 幅值不一的尖刺，双向 | 骤降或尖峰，形状可重复 |
| **方向** | 几乎总是转速骤降（间隔拉长） | 升降皆有 | 豁口降、挤压升 |
| **成因** | 齿/条纹物理缺失或低于门限 | 油污、电磁干扰、偶发漏检 | 缠带收尾搭接的几何误差 |
| **修正工具** | TACHO_PULSE_TO_RPM 缺脉冲修正 | TACHO_MOMENTS_SPIKEREMOVAL_TO_RPM | ZEBRA_MOMENTS_TO_RPM |
| **修正思路** | 已知缺几个：跨过空缺按标称几何换算 | 滑窗中位数（MAD）统计剔除离群 | 全部脉冲按理论角度全局重排 |

识别判据抓三条：**每转固定次数、深度一致、几乎只向下**。满足这三条的坑，先数一转内有几个——缺几个齿就有几个坑；坑的间距就是缺齿在圆周上的相对位置。随机毛刺没有固定位置且双向；接缝虽然也每转一次，但它只出现在缠带测量中、且总在同一个角度位置，形态还可能是尖峰（挤压型搭接）。

更进一步的佐证在原始电压信号上：放大脉冲序列，直接看缺齿处的空缺，以及紧邻脉冲的畸变——缺脉冲后面的第一个脉冲往往幅值和时刻都不对，这是磁电传感器在齿缺失后信号重新建立的暂态表现，修正时它也要一并处理（见第四节）。

## 四、离线修正：TACHO_PULSE_TO_RPM 的六个参数

Simcenter Testlab 的离线修正在 **Time Signal Calculator**（需先在 Tools → Add-ins 中勾选 Time Signal Calculator 插件，令牌授权下占用 26 个令牌）里完成：Time Data Selection 工作表中调用 **TACHO_PULSE_TO_RPM** 函数，把原始脉冲电压信号直接换算为转速，菜单里一组参数专门服务缺脉冲修正。

![TACHO_PULSE_TO_RPM 菜单](/images/rpm-missing-pulses/tacho-menu.png)

*图 3 TACHO_PULSE_TO_RPM 菜单，缺脉冲修正相关参数以黄色高亮标出（图源：Simcenter Testing Knowledge Base）*

以 36 齿缺 1 齿的齿轮信号为例，逐个说明。

**（1）Pulses_per_rev（每转脉冲数）**：填**标称**齿数 36，不是实际存在的 35。算法需要知道"满编"时一转应该有多少脉冲，才能识别出"这一圈只来了 35 个、跨过了一个空缺"。这与接缝修正的思路一致：以理论几何为基准。

**（2）Number of missing teeth（缺齿数）**：填缺失的齿数。齿与齿的空缺可以相当于 1、2 甚至更多个齿位，软件最多支持修正 4 个缺失脉冲。本例填 1。

**（3）Cross level（交叉电平）**：信号必须穿越这个电平才被计为一个脉冲。磁电传感器信号围绕 0 V 波动，交叉电平取 0；若是 0 到 5 V 的 TTL 信号，取 2.5 V。电平选得不合适会把噪声当脉冲、或把真脉冲漏掉。

**（4）Slope（斜率方向）**：信号穿越检测电平时可以是上升沿（positive）或下降沿（negative），对应齿的前沿或后沿。这不是随意的选项：同一信号用不同沿触发，换算出的转速曲线质量不同，磁电信号往往负斜率更平稳——设置时两种都试，看哪条曲线毛刺小。

**（5）Missing pulse correction（缺脉冲修正范围）**：修正只处理缺失脉冲本身，还是连同相邻脉冲一起。缺齿之后紧跟的第一个脉冲常常幅值畸变、时刻偏移（信号重新建立的暂态），只修缺的那个、不动邻居，转速曲线上的坑压不平。

![缺脉冲后相邻脉冲的畸变](/images/rpm-missing-pulses/distorted-pulse.png)

*图 4 缺齿处不仅少一个脉冲，紧随其后的脉冲在幅值与时刻上都发生畸变（图源：Simcenter Testing Knowledge Base）*

图 5 的对比给出了量化结论：只修缺脉冲（绿）残留明显波动；把缺脉冲后一个也纳入修正（蓝），曲线才真正压平。

![不同修正范围的效果对比](/images/rpm-missing-pulses/correction-compare.png)

*图 5 只修正缺失脉冲（绿）不足以压平曲线，连同其后脉冲一起修正（蓝）效果才完整；红色为未修正的转速（下）（图源：Simcenter Testing Knowledge Base）*

**（6）Pulse correction factor（脉冲修正因子）**：判定"脉冲缺失"的灵敏度，取整数 1 到 4。算法逻辑：比较当前一对穿越的时间间隔 $T_n$ 与前一对的 $T_{n-1}$——若 $T_n > T_{n-1}$，可能是缺脉冲，也可能只是轴真的在减速。修正因子规定：**若在 $T_{n-1}$ 的指定百分比时间内没有新脉冲到来，才判定缺失并触发修正**。因子 1 最灵敏（百分比阈值最低），4 最迟钝。

![脉冲修正因子设置对照表](/images/rpm-missing-pulses/correction-factor-chart.png)

*图 6 四种 Pulse Correction Factor 设置对应的判定阈值：在上一间隔的指定百分比内无新脉冲即判为缺失（图源：Simcenter Testing Knowledge Base）*

因子选小了，正常的急剧减速（如换挡丢油门）会被误判为缺脉冲而错误"修正"；选大了，真缺脉冲漏判、坑留下来。经验起点：匀速或缓变工况用较灵敏档，急加速/急减速工况（转速本身快速变化）适当调迟钝，并始终用修正前后的转速曲线对比来验收。

::: tip 参数设置顺序
1. 先看原始电压信号，确定 Cross level 与 Slope——这是脉冲检测的地基，地基错后面全错
2. 数齿：Pulses_per_rev 填标称值，Number of missing teeth 填缺齿数
3. Missing pulse correction 先从"缺脉冲+后一个"试起，看曲线是否压平，不够再加前一个
4. Pulse correction factor 从默认起步，只在出现误判/漏判时再调
:::

## 五、在线修正：采集时就地修复

若等到试验做完才发现缺脉冲，离线修正是救场手段；更好的做法是采集时在线修正。Simcenter Testlab Signature Acquisition 的 **Tracking Setup** 工作表中，在每转脉冲数设置旁点击 **More...**，即进入与离线功能等价的 tacho 设置菜单：脉冲修正因子、缺脉冲数、斜率、平滑系数等参数都在这里填写，采集的同时完成修正，直接输出干净的 RPM 通道。

在线修正的参数含义与第四节完全一致，唯一区别是时机。它省掉了后处理环节，代价是参数错误当场不易发现——所以官方建议同时保存原始脉冲电压通道：在线设置若有偏差，事后仍可用 TACHO_PULSE_TO_RPM 离线重算，原始脉冲序列就是留底。

## 六、Python 演示：缺脉冲误差的定量复现

```python
import numpy as np

# 模拟 36 齿缺 1 齿的齿轮：轴稳定 3000 rpm
P = 36                      # 标称每转脉冲数（齿数）
n_true = 3000.0             # 真实转速 rpm
n_rev = 5                   # 模拟 5 转
dt = 60.0 / (n_true * P)    # 理论脉冲间隔 (s)

dt_ok = np.full(n_rev * P, dt)   # 健康齿轮的间隔序列
dt_bad = dt_ok.copy()
dt_bad[::P] = 2.0 * dt           # 缺 1 齿：每转第 0 个间隔跨过空缺，长度约翻倍

rpm_ok  = 60.0 / (dt_ok  * P)   # 倒数关系反算转速
rpm_bad = 60.0 / (dt_bad * P)

print(f"真实转速: {n_true:.0f} rpm")
print(f"健康齿轮瞬时转速: {rpm_ok.min():.1f} ~ {rpm_ok.max():.1f} rpm")
print(f"缺齿处反算转速: {rpm_bad[::P][0]:.1f} rpm (每转 1 次)")
print(f"转速低估比例: {1 - rpm_bad[::P][0]/n_true:.1%}")
print(f"假 1 阶波动峰峰值: {n_true - rpm_bad[::P][0]:.0f} rpm")

# 修正：跨过空缺的间隔实际对应 2 个齿距，按 2 齿换算即恢复
fixed = np.where(dt_bad > 1.5*dt, 60.0/(dt_bad/2 * P), 60.0/(dt_bad * P))
print(f"修正后缺齿处转速: {fixed[::P][0]:.1f} rpm")
```

运行结果：缺齿处反算转速 1500.0 rpm，低估恰好 50%——与第二节 $\hat{n}=n/2$ 的推导一致；这个每转一次、深度 1500 rpm 的坑等效于峰峰值 1500 rpm 的假 1 阶波动，而同一台机器的真实扭振通常只有几 rpm 到几十 rpm，信噪比完全失衡。按"跨缺口的间隔记 2 个齿距"修正后，该处转速回到 3000.0 rpm。这正是 TACHO_PULSE_TO_RPM 内部做的事：识别超长间隔，按标称几何（P 与缺齿数）重新解释它，用理论齿距换算转速。

## 七、小结

缺脉冲的识别三要素：每转固定次数、深度一致、几乎只向下。修正的关键参数只有两个——标称 PPR 与缺齿数，前者填"满编"值而非实际值，后者决定算法跨空缺的方式；边缘参数里 Cross level 与 Slope 决定脉冲检测本身是否可靠，Missing pulse correction 与 Pulse correction factor 决定修正的完整性与灵敏度。能在线修就在 Tracking Setup 里修，但原始脉冲通道永远留底。缺脉冲（本篇）、随机毛刺（滑窗 MAD 剔除）、接缝误差（角度全局重排）是转速通道三类常见误差，判据与工具各不相同，混用必错。
