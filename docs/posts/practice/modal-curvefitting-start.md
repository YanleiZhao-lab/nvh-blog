# 模态拟合入门：稳定图与极点选择

> 锤击法测完一组 FRF 之后，怎么从曲线里"榨"出固有频率、阻尼比和振型？答案是把曲线拟合问题转化为极点估计问题。这篇讲清楚拟合器到底在解什么方程、稳定图（Stabilization Diagram）上那些符号为什么忽明忽暗，以及挑选物理极点时最常用的判据和陷阱。

## 一、拟合器在解什么：从 FRF 到极点

实验模态分析的核心关系式很直接——测得的频响函数（FRF）可以写成一组模态的叠加：

$$H_{ij}(\omega) = \sum_{k=1}^{N} \left( \frac{A_{ijk}}{j\omega - \lambda_k} + \frac{A^*_{ijk}}{j\omega - \lambda^*_k} \right)$$

每个模态贡献一对共轭极点 $\lambda_k = -\sigma_k + j\omega_{d,k}$ 和一对留数 $A_{ijk}$。极点是全局量——同一阶模态，从结构上任何一个 FRF 里估出来的频率、阻尼都应该一样；留数则随响应点和激励点位置变化，按 $A_{ijk} = \psi_{ik}\psi_{jk}/(2j m_k \omega_{d,k})$ 分解后就是模态振型。

所以拟合这件事分两步走：先把所有 FRF 放在一起，统一估出全套极点（整体估计）；再把每条 FRF 的留数解出来，得到振型。最小二乘复指数法（LSCE）就是这么干的——它把脉冲响应表示为衰减复指数的和，构造协方差矩阵后求解一个线性方程组，一次算出所有模态的频率和阻尼。

但有个绕不开的问题：**数据里到底有几阶模态？** 拟合器不知道。它只会按你设定的阶数解方程。

::: info 核心概念
- **极点（Pole）**：$\lambda_k = -\sigma_k + j\omega_{d,k}$，包含阻尼因子和有阻尼固有频率，是结构的全局特性
- **留数（Residue）**：复数幅值系数，随测点/激励点变化，分解后得到模态振型；注意它是有量纲的
- **整体估计（Global Estimate）**：所有 FRF 同时参与拟合，极点结果对所有测点一致，LSCE、PolyMAX 类方法都属此类
- **单自由度（SDOF）法**：峰值拾取、模态圆拟合等，只适用于频带内模态明显解耦的情形
:::

## 二、稳定图：让物理模态自己"站"出来

拟合前要先设定模型阶数 N。真实系统若有 4 阶模态，理论上 N=4 误差最小——最小二乘误差图会在这个阶数处出现明显拐点。但实测数据带噪声，噪声让误差曲线一直往下走，拐点变钝，光看误差图不够。

于是换一个思路：让阶数从低到高逐步增加，把每一步估出的所有极点都画到同一张频率轴上。物理模态的极点由结构决定，阶数增加不会让它移动——它在图上连成一条竖直的"光柱"；计算模态（Computational Modes）是拟合器拿来吸收噪声的数学摆设，阶数一变它就漂。这就是稳定图。

软件里每个极点符号的明暗还有讲究：同一频率处，与上一阶数相比频率、阻尼、振型都稳定，符号最亮；只满足一两项判据就暗一些。真正可信的物理模态，应该是一根从头亮到尾的竖直光柱，而不是孤零零一个亮点。

::: warning 工程注意
不要看到 FRF 曲线有几个峰就选几个极点。峰可能来自带外模态的残余影响、泄漏伪峰或结构非线性，而密布的极点列里也可能藏着两阶靠得很近的耦合模态。稳定图给出的信息比幅值谱峰丰富得多——先看光柱，再看谱峰。
:::

## 三、极点取舍判据：三稳才可信

判别物理极点通常用三条标准，频率、阻尼、振型各自与相邻阶数的结果比对：

| 判据 | 典型容差 | 物理含义 |
| --- | --- | --- |
| **频率稳定** | 相邻阶数间变化 < 2% | 极点位置由结构决定，不随模型阶数漂移 |
| **阻尼稳定** | 相邻阶数间变化 < 5% | 阻尼对噪声敏感，容差放宽些 |
| **振型稳定** | 与相邻阶数振型的 MAC > 90% | 不仅频率吻合，空间形态也要一致 |
| **模态参与（MPC）** | > 0.9（密模态场景） | 多参考点下该极点在各参考点处都显著 |

阻尼容差比频率宽，因为阻尼本身就是对噪声最敏感的参数——这和锤击试验里指数窗会人为增大阻尼是同一类问题：凡是影响衰减速率的因素，都会先反映到阻尼估计上。

::: tip 选择原则
- 默认做法：先在稳定图上找"三稳"光柱，频率与 FRF 峰值对得上的才是物理模态
- 阶数宁多勿少——多出来的计算模态在稳定图上会自己漂走，不会干扰判断
- 密集模态或重根情形，必须用多参考点数据，靠模态参与因子解耦，单参考点数据无从谈起
- 极点选定后，务必看拟合的 FRF 综合曲线与实测曲线的覆盖程度，峰谷都要对得上才算收工
:::

## 四、Python 演示：亲眼看计算模态漂移

下面用 LSCE 的思路做一个最小实现：构造两个模态（32 Hz/2.5%、87 Hz/1.0%）的脉冲响应加噪声，对相关函数做 Prony 拟合（相关函数噪声自相关近似为零，拟合更稳），阶数从 2 逐步加到 10，看哪些极点站得住。

```python
import numpy as np

# 含两个物理模态的脉冲响应（32 Hz/2.5%，87 Hz/1.0%），叠加噪声模拟实测
fs = 2048; dt = 1/fs
n = np.arange(1024)
h = 4*np.exp(-2*np.pi*32*0.025*n*dt)*np.cos(2*np.pi*32*n*dt) \
  + 2*np.exp(-2*np.pi*87*0.010*n*dt)*np.cos(2*np.pi*87*n*dt)
rng = np.random.default_rng(0)
h = h + 0.05*rng.standard_normal(h.size)

# LSCE 思路: 对相关函数做 Prony（噪声的相关近似为零，极点与原信号相同）
full = np.correlate(h, h, 'full') / h.size
r = full[h.size-1:]                    # 正滞后部分的相关函数

def prony_poles(x, order):
    M = 150                            # 用 150 个相关滞后值，方程强超定
    A = np.column_stack([x[order-i:M+order-i] for i in range(1, order+1)])
    b, *_ = np.linalg.lstsq(A, x[order:M+order], rcond=None)
    z = np.roots(np.concatenate(([1], -b)))
    s = np.log(z.astype(complex))/dt   # 离散根换算回连续极点
    f = np.abs(s.imag)/2/np.pi
    zeta = -s.real/np.abs(s)
    ok1 = np.logical_and(f > 5, f < 500)
    ok2 = np.logical_and(zeta > 0, zeta < 0.2)
    keep = np.logical_and(np.logical_and(ok1, ok2), s.imag > 0)
    return f[keep], zeta[keep]

print("真实极点: 32.0Hz/2.5%   87.0Hz/1.0%")
for N in (2, 4, 6, 8, 10):
    f, z = prony_poles(r, N)
    pairs = "  ".join(f"{fi:6.1f}Hz/{zi*100:4.1f}%" for fi, zi in zip(f, z))
    print(f"order {N:3d}: {pairs}")
```

运行结果要点：阶数 6、8、10 时，32 Hz 和 87 Hz 两个极点几乎纹丝不动（31.9→31.9→32.0 Hz，阻尼 3.1%→2.7%→2.6%），这就是稳定图上的"光柱"；而 order 10 冒出来的 450.3Hz/11.1% 在低阶数时根本不存在，阶数一变它就漂——典型的计算模态。挑极点时，看的就是这份"镇定"。

## 五、小结

选极点不是玄学，判断标准很具体：物理模态 = 稳定图上频率、阻尼、振型三稳的竖直光柱 + 与 FRF 峰位对应 + 综合曲线回代吻合。阶数设高一点没关系，让计算模态去漂；阻尼对噪声和窗函数敏感，交叉验证时多留 5% 余量；密集模态别指望单参考点，多参考数据的模态参与因子才是解耦的正道。
