# 阻断力表征为什么从几天缩到几分钟？——AutoCMX 与 ISO 20270 组件模型提取

> 电动化车型的内饰声目标要提前到没有可驾驶样车的阶段兑现，靠的是把各个部件先单独"体检"、再在虚拟空间里拼成整车预测——预测的数学（C-TPA、FBS、VPA）早已成熟，真正卡脖子的是喂给它的部件数据：描述一个结构声源"出厂特性"的阻断力（blocked force），传统在位法表征要资深工程师守着台架做几个小时到几天，换个站点换个工程师，结果还未必能对上。Simcenter Testlab 2606 推出的 AutoCMX（Automated Component Model Extraction，自动化组件模型提取）把整套 ISO 20270 表征流程固化进"自测量夹具"硬件与自动化软件：换件只需螺栓装卸，技师按流程操作，组件模型从"专家手艺"变成"几分钟下线的产品"。本文讲清阻断力为什么是不变量、两步法在位测量的数学结构、六根可靠性支柱各挡住哪类误差，并用电动助力转向 EPS 的实测账本回答标题：24 组指示器 FRF 从 4 小时 48 分压到 16 分钟。医院自动化验流水线的类比贯穿全文。

::: tip 30 秒速览
- **一句话**：给电动车预测车内噪声要先有每个部件的"体检报告"，这份报告以前为什么又慢又难复制，现在怎么变成几分钟一条流水线？
- **类比**：医院的自动化验流水线——采血口、试管、分析仪全部固定并标准化，护士按流程放血样就行，化验单指标不随医院与操作员变化；部件表征的"血样"就是阻断力
- **关键数字**：同一批 24 组指示器 FRF，手动移动激振器做要 4 小时 48 分，夹具内置激振器自动接力只要 16 分钟——快 18 倍，且整件模型从几天缩到约 20 分钟
- **结论**：阻断力是部件的不变"出厂特性"，换接收端不变；把它测准靠的不是老师傅的手感，而是固定激振器、刚性虚拟点、在板校验这三件硬事——可以固化，所以可以自动化
:::

## 一、虚拟开发卡在哪：数学成熟了，数据没有

每个电动化车型项目都有一个时刻：管理层要求 NVH 团队在第一辆可驾驶样车存在之前，承诺这台车听起来什么样。答案是虚拟样机（Virtual Prototype）：把动力总成、悬架、压缩机等部件各自单独表征成模型，在数字空间装配到整车模型上，用基于部件的传递路径分析（C-TPA）、基于频响函数的子结构耦合（FBS）、虚拟样机装配（VPA）预测驾驶员耳旁声压与关键位置振动。这套预测数学经过多年验证已经成熟；不成熟的是喂数据的一侧——部件级表征。

困难集中在描述结构声源的那个量上。发动机退场后，电驱的阶次啸叫、齿轮阶次、结构传声输入失去了宽频掩蔽，变得清晰可闻；整车厂越来越把阻断力限值写进供应商的合同 NVH 接口——表征不再是学术练习，而是交付物。而传统在位法 TPA 表征要资深工程师全程操盘：试验误差沿着逆问题直接灌进结果，发表的研究通常只基于一两件样本，做一次占住台架几个小时到几天。结果就是四个慢性病：跨工程师跨站点重复性差、精度存疑、台架吞吐低、一两件样本根本分不清"零件间真实差异"与"测量散布"。规模化阻断力测试至今不是行业常态——测试太慢，质量太不可靠。

::: info 核心概念
- **阻断力（Blocked Force）**：把源与接收端的连接界面"刚性锁死"时，界面上传给刚性墙的力。它只取决于源部件本身，与接到什么接收端上无关，因此可以"表征一次、装配到任何整车模型"；又称不变载荷（invariant load）
- **ISO 20270:2019**：在位法（in-situ）测量结构声源阻断力的国际标准：部件装在真实或代表性接收端上运行，同时测界面附近频响，反演出界面阻断力
- **AutoCMX（Automated Component Model Extraction）**：Simcenter Testlab 2606 推出的自动化组件模型提取方案：自测量夹具（内置激振器与加速度计的刚性虚拟点适配器）+ 自动化软件，端到端执行 ISO 20270 流程
- **虚拟点变换（VPT, Virtual Point Transformation）**：把分布在连接点周围的若干锤击/激振与响应测点，变换到几何上不可达的界面"虚拟点"六自由度上的数学方法
:::

## 二、阻断力：部件的出厂说明

先说清要测的量为什么偏偏是它。给医院验血的类比在这里最贴切：一份化验单要能跟着人走——同一个人在三甲医院和体检中心测出的血糖应当一致，指标描述的是人，不是医院。部件的"化验单"也必须只描述部件本身：同一台电动压缩机装到 A 车与 B 车上，界面上实际测到的接触力完全不同（那是源与接收端"合演"的结果），唯独阻断力不变。虚拟装配要的正是这种可携带的量：在供应商台架上表征一次，装进任何整车模型都能用。关于接触力与阻断力这对概念的身份之辨，本站[《同一台电机测的力，换了车身为什么全变数？——阻断力与接触力》](../../theory/vibration-basics/blocked-vs-contact-forces.html)有专门推导，此处只取结论。

这个公式回答的问题是：**部件在真实接收端上运行时，它"出厂"的界面载荷怎么从可测的响应里反解出来？**左边是界面各自由度上的阻断力，右边只有两样可测的东西——若干指示器加速度 $a_4$（装在接收端上敏感位置的加速度计），以及在位测得的耦合加速度导纳矩阵的 Moore–Penrose 伪逆 $H_{42}^{AB+}$：

$$f_{2,\mathrm{bl}} = H_{42}^{AB+} \, a_{4}$$

结构一目了然：运行响应乘上"逆传递特性"等于界面载荷。它就是 AutoCMX 第二步执行的运算，也是"试验误差沿逆问题直接灌进结果"这句话的数学出处——$H_{42}^{AB}$ 里任何一点测量噪声，经过伪逆的放大都会直接写在 $f_{2,\mathrm{bl}}$ 上。传统方法对资深工程师的依赖、AutoCMX 对测量质量的系统设计，全都围绕让这个伪逆"吃到干净的数据"展开。顺带一提，整车预测端的装配数学（FBS 把部件模型拼成整机）见[《两个部件隔着半个地球，装配体的频响凭什么提前算出来？——基于 FRF 的子结构耦合 FBS》](../../theory/modal-analysis/frf-based-substructuring.html)。

## 三、两步走的 ISO 20270 流程

标准给出的在位法分两步，AutoCMX 把两步都自动化。

**第一步：自动测量耦合 FRF 矩阵并做虚拟点变换。**夹具上永久固定的若干激振器顺序点火，逐个测出连接点附近的耦合指示器 FRF 矩阵，再用虚拟点变换（VPT）把测点上的 FRF 投影到源与接收端界面上那个几何不可达的"虚拟点"——每个连接点得到完整的六自由度描述。这一步的关键是激振路径的**几何精确与刚性**：力沿一条已知力线打进连接点，虚拟点变换才良态。

![AutoCMX 自测量夹具：刚性虚拟点适配器内置激振器与加速度计](/images/autocmx-iso20270-component-models/fig3.png)

*（图源：网络 侵删）*

**第二步：运行工况下反演阻断力。**装上被测部件让它运行，记录指示器响应 $a_4$，代入上一节的伪逆式即得界面阻断力。另做一次性台架标定，配合 FBS 解耦恢复未耦合的阻抗 FRF，部件的不变模型就此完整——直接可投入虚拟样机装配做 KPI 预测，最终进 NVH Simulator 做声学彩虹化试听。

![AutoCMX 与虚拟样机开发流程的衔接](/images/autocmx-iso20270-component-models/fig2.png)

*（图源：网络 侵删）*

值得强调的是整个过程**不往被测件上贴任何东西**：所有传感器与激振器都在夹具上。换件只是"卸一套螺栓、装一套螺栓"，这让批量吞吐第一次成为可能。

## 四、六根可靠性支柱：快的前提是准

速度若牺牲精度就一文不值。AutoCMX 的可重复性立在六根支柱上，每一根挡住一类具体误差：虚拟点变换的**刚性**（激振经几何精确的刚性路径引入，重构界面表现为真实刚体，实测与变换后数据的相干在全部六个自由度上都达 0.9 以上）；台架的**在板校验**（一个被排除在力计算之外的目标加速度计，用来对比预测响应与实测响应，每次测量自带客观置信检查）；**高信噪比**（运行响应在关心频段内高出传感器本底 10 dB 以上）；**相干质量控制**（总体与逐条 FRF 两级相干门槛，FRF 矩阵干净到伪逆可直接作用于实测数据、无需滤波或正则化）；**指示器 FRF 的一致性**（激振器一旦装定不再移动，逐次实验的 FRF 标定天然一致——这是固定激振器相对移动激振器的本质优势）；**测量条件一致**（温度、预紧、工况复现）。

这里有一处容易被忽略的细节：保证刚性所需的任何局部加强，都加在**接收端夹具**上，绝不加在源部件上——一旦给源件加筋，阻断力就不再是"出厂特性"。另外，整次测量只要几分钟，可疑的设置当场重测改进即可，不需要用后处理假设去"补"，那些假设本来还要写文档、上评审去辩护。

## 五、两本账：速度账与一致性账

### 5.1 速度账：18 倍从哪来

公开发表的电动助力转向（EPS）实测（SAE 技术论文 2026-01-0704）给出第一本账：EPS 系统三个悬置点、阻断力计算所需的 24 组指示器 FRF，AutoCMX 用 16 分钟完成；手动移动激振器方式约 4 小时 48 分；移动锤约 4 小时。落到组件级，以前要专家数天数周的表征，现在实验室技师约 20 分钟做完一件。

快 18 倍的机制不神秘：激振器全部内置、顺序点火，省掉的是"拆装、移位、重新标定"的纯手工时间；换件只动螺栓，省掉的是"重新布置传感器"的时间。速度账直接换算成吞吐账：供应商一年表征十个以上样本审计生产波动、与整车厂在 ISO 20270 口径上谈阻断力目标，才成为排得进日程的事。

### 5.2 一致性账：伪逆的"干净输入"值多少

第二本账回答"固定激振器到底值多少精度"。下面的数值实验用两自由度耦合模型复现两种实验组织方式的差别：固定式——每次实验用同一套 FRF 标定，只有传感器噪声；移动式——每次重新安装让界面连接刚度漂移 5%，实验人员却仍拿旧标定矩阵去反演。结论先摆在这：同样的 0.5% 传感器噪声下，固定式 200 次重复的阻断力散布 0.2%，移动式 0.6%，散布放大 3.6 倍（点击展开）：

<details>
<summary>数值实验：固定激振器与移动激振器的阻断力重复性对比（25 行）</summary>

```python
import numpy as np

rng = np.random.default_rng(11)
w = 2 * np.pi * 120.0                       # 关心频点 120 Hz
M = np.diag([2.0, 3.0])                     # 两自由度耦合模型
K0 = np.array([[8e4+5e4, -5e4], [-5e4, 1.2e5+5e4]])
C = np.array([[30., -10.], [-10., 35.]])
H0 = -w**2 * np.linalg.inv(K0 + 1j*w*C - w**2*M)   # 加速度导纳（基准标定）
f_bl = np.array([40.0, 25.0])               # 真实阻断力 N
a = H0 @ f_bl

def est(Hm, am):
    return np.linalg.pinv(Hm) @ am          # ISO 20270 第二步：伪逆反演

fixed_f1, rov_f1 = [], []
for _ in range(200):
    am = a + 0.005*a.std()*rng.standard_normal(2)          # 固定式：同标定
    fixed_f1.append(abs(est(H0, am)[0]))
    Kj = K0 * (1 + 0.05*rng.standard_normal())             # 移动式：重装漂移 5%
    Hj = -w**2 * np.linalg.inv(Kj + 1j*w*C - w**2*M)
    rov_f1.append(abs(est(H0, Hj @ f_bl
                          + 0.005*a.std()*rng.standard_normal(2))[0]))
fx, rv = np.array(fixed_f1), np.array(rov_f1)
print("fixed shakers : f1 mean %.2f N  std %.2f N (%.1f%%)"
      % (fx.mean(), fx.std(), 100*fx.std()/fx.mean()))
print("roving 5 pct  : f1 mean %.2f N  std %.2f N (%.1f%%)"
      % (rv.mean(), rv.std(), 100*rv.std()/rv.mean()))
print("spread ratio roving/fixed: %.1fx" % (rv.std()/fx.std()))
```

</details>

运行结果：固定式 $f_1$ 均值 40.00 N、散布 0.06 N（0.2%）；移动式均值 40.03 N、散布 0.23 N（0.6%），散布比 3.6 倍。两个均值几乎不差——系统性误差在均值里被伪逆部分抵消——但**散布**差 3.6 倍：批量表征要靠散布分辨零件间真实差异，散布每大一分，"生产波动"与"测量噪声"就多糊一分。这就是第四根支柱（指示器 FRF 一致性）在账面上的分量。

### 5.3 反演本身有多稳

第三本小账验证伪逆吃干净数据的鲁棒性：同一个两自由度基准，指示器加 1% 噪声，阻断力反演误差多大？

<details>
<summary>数值实验：1% 指示器噪声下阻断力反演误差（20 行）</summary>

```python
import numpy as np

rng = np.random.default_rng(3)
w = 2 * np.pi * 120.0
M = np.diag([2.0, 3.0])
K = np.array([[8e4+5e4, -5e4], [-5e4, 1.2e5+5e4]])
C = np.array([[30., -10.], [-10., 35.]])
H = -w**2 * np.linalg.inv(K + 1j*w*C - w**2*M)
f_true = np.array([40.0, 25.0])
a = H @ f_true

a_meas = a + 0.01*a.std()*rng.standard_normal(2)     # 单次：1% 指示器噪声
f_est = np.linalg.pinv(H) @ a_meas
print("true:", f_true)
print("est :", np.round(f_est.real, 3))
print("single-run rel error: %.2f%%" %
      (100*np.linalg.norm(f_est-f_true)/np.linalg.norm(f_true)))
errs = [np.linalg.norm(np.linalg.pinv(H) @
        (a + 0.01*a.std()*rng.standard_normal(2)) - f_true)
        / np.linalg.norm(f_true) for _ in range(500)]
print("500-run mean: %.2f%%  std: %.2f%%" %
      (100*np.mean(errs), 100*np.std(errs)))
```

</details>

运行结果：单次反演相对误差约 1.1%，500 次重复均值约 0.4%、标准差约 0.2%。指示器噪声被伪逆"按比例透传"而不放大——前提是 $H$ 本身干净。AutoCMX 相干门槛保证的"FRF 矩阵无需滤波直接伪逆"，正是让这条鲁棒性成立的前提条件。

## 六、EPS 实战：不变，而又敏锐

速度之外是保真。同一项 EPS 研究测了三台转向机：基线原型、改进后的量产件、一件故意制造成缺陷的离群件。AutoCMX 给出的阻断力同时做到两件看似矛盾的事：**不变**——三件好件之间的散布小到足以让人信任模型本身；**敏锐**——缺陷件与好件的阻断力清楚分开。换句话说，测到的是真实的生产波动，不是测量散布。把实测阻断力传播过相容的整车模型，驾驶员耳旁噪声与副车架振动的预测与实车测量吻合良好；同一套设置还支持快速假设检验——刚性、60 邵氏、50 邵氏三种悬置隔离方案直接在悬置点对比。

## 七、工程要点清单

1. **表征量选阻断力而非接触力**：接触力随接收端变化，虚拟装配不可携带；合同接口、模型交付一律用阻断力（ISO 20270 口径）
2. **刚性加强只加接收端**：任何为保刚性做的局部加强加在夹具侧，给源件加筋等于亲手改掉被测对象的出厂特性
3. **关注散布而不只是均值**：批量表征的价值在分辨零件间差异，固定激振器的一致标定把测量散布压低数倍
4. **信噪比与相干是硬门槛**：运行响应高出本底 10 dB、逐条 FRF 相干达标，伪逆才有资格直接吃实测数据
5. **用在板校验收口**：每次测量的预测响应与实测响应对比（排除在力计算外的目标加速度计）是自带的质量闸门
6. **吞吐换能力**：每件 20 分钟的量级让"多件样本审计生产波动"成为例行公事，而不是研究项目

## 一句话记住

阻断力是部件随身的"化验单"：换医院不换数值；AutoCMX 用内置激振器的自测量夹具把开单流程标准化——16 分钟拿下的不是将就的近似，而是相干达标、散布压低、带在板校验的干净数据，因此组件模型才能从专家手艺变成分钟级下线的产品。
