# 同一条路为什么既决定舒适性又决定耐久？——IRI 路面粗糙度与载荷关联

> 路谱采集回来，舒适性组看的是"颠不颠"，耐久组看的是"伤不伤车"，两边各用各的指标，路数据却始终是同一份。有没有一个数，既能让道路工程师给路面分级、又能让耐久工程师预判载荷严酷度？有——国际粗糙度指数 IRI（International Roughness Index）。它用一辆完全标准化的"金车"（Golden Car）四分之一车模型，以 80 km/h 匀速碾过路面高程剖面，把悬架相对位移的累计行程折算成每公里多少米，单位 m/km。新高速 2~4、老国道 4~6、破损路 6~8、未铺装路 8 以上——一个数就把路面从"丝绸"到"搓板"排成了队。本文讲清 IRI 的物理含义与分级、它为何天然关联整车耐久载荷、同一剖面不同车速读数为何不同，以及用 Testlab 把实测路谱算成 IRI 并自动分级打标的完整流程。路政的体检秤类比贯穿全文：同一条路，秤称的是"乘起来多颠"，耐久组借用的是"载荷有多大"。

::: tip 30 秒速览
- **一句话**：同一条路，为什么舒适性报告和耐久报告都能用它说话？
- **类比**：路政部门的一台标准化"体检秤"——不是称车重，而是让一辆参数完全固定的标准小车以 80 km/h 碾过路面，看它的悬架每公里累积"喘"了多少米
- **关键数字**：新高速约 2~4 m/km，未铺装路可超 8 m/km，新兴市场常见路面能到 12 m/km 以上——同一个车型，从"温和"直接跳到"严酷"
- **结论**：IRI 一头连着舒适性分级（路面管理的语言），一头连着悬架行程与车身加速度（耐久载荷的源头）；一个数，两个学科都用，因为它们本就出自同一次碾压
:::

## 一、同一条路，两份报告

一辆为中欧市场开发的 SUV，路谱车队在新兴市场跑完耐久强化路回来，两份报告先后摆上桌面。舒适性组的结论是"粗糙路比例偏高，建议悬架阻尼重新匹配"；耐久组的结论是"台架谱欠严酷，按当前谱试车的样件在用户路上撑不到设计寿命"。有意思的是，两份报告引用的是同一段路、同一批数据——舒适性组看的是乘起来颠不颠，耐久组看的是载荷循环伤不伤车。评审会上自然有人问：能不能用一个统一的数，把"这条路有多糟"说清楚，让两个组、甚至让道路部门与整车厂说同一种语言？

这个数已经存在了四十多年。上世纪 80 年代世界银行组织的一项道路成本研究中，为了把各地五花八门的路面平整度测量统一成可比的指标，提出了国际粗糙度指数 IRI。它的定义完全标准化：一辆参数固定到小数点后的"金车"四分之一车模型（簧上 250 kg、簧下 35 kg、悬架刚度 16 kN/m、阻尼 3 k·s/m、轮胎刚度 160 kN/m），以 80 km/h 匀速碾过实测的路面高程剖面，把簧上与簧下之间相对位移的绝对值一路累加，再除以行驶距离。累加的结果单位是"米每公里"（m/km）：悬架每公里"喘"了几米。数字越大路越糙——这就是路政部门的体检秤：不管被评价的是豪华车还是面包车，秤本身永远用同一辆标准车、同一个速度称路。

![不同路面条件下的车辆](/images/iri-road-roughness-durability/fig1.png)

*（图源：网络 侵删）*

对耐久工程师，这台秤的价值在于：载荷不是凭空来的。路面高程剖面是输入，悬架相对行程、车轮载荷、车身加速度是响应——IRI 累加的恰恰是悬架行程这个耐久关心的核心响应量。路越糙，悬架行程越大、循环次数越多，底盘件、车身接头、悬置、支架的疲劳损伤都随之上涨。舒适性看的是响应的"感受"侧，耐久看的是响应的"损伤"侧，输入同一次碾压——这就是标题的答案。

## 二、IRI 是怎样算出来的

### 2.1 金车：一台参数不许改的仪器

IRI 的核心思想是**用一个标准响应器代替人来评价路面**。人的主观评价因车而异、因人而异，没法跨项目比较；把评价器换成一辆参数完全固定的四分之一车，任何人在任何路上测，得到的数都能直接比。这就是"金车"（Golden Car）名字的由来——它不是某款真车，而是一组写进标准的动力学参数：

::: info 核心概念
- **IRI（International Roughness Index，国际粗糙度指数）**：金车以 80 km/h 碾过路面剖面，悬架相对位移绝对值累计行程除以距离，单位 m/km
- **金车（Golden Car）**：参数标准化的四分之一车模型——簧上质量 250 kg、簧下质量 35 kg、悬架刚度 16000 N/m、悬架阻尼 3000 ·s/m、轮胎刚度 160000 N/m，采样间距 0.25 m
- **路面剖面（Road Profile）**：沿里程方向逐点采样的路面高程序列，是 IRI 的唯一输入
:::

这台"仪器"的妙处在于它有频率选择性。金车的簧上共振约 1.2 Hz、簧下共振约 10 Hz，对波长 10~30 m 的长波起伏和 1~3 m 的短波不平整都敏感，而极长波（桥头沉降那种几秒才颠一下的）和极短波（路面纹理）都被动力学滤掉。所以 IRI 度量的是"会影响悬架与车轮载荷的那部分路面不平整"——恰好也是耐久最关心的频段。

### 2.2 从高程序列到一个数

这个公式回答的问题是：**路面高程逐点已知，一个数怎么把"悬架一路喘了多少"折算出来？**分子是对簧上、簧下相对位移的绝对值沿里程积分——只累计幅度、不问方向，上跳下窜都算磨损；分母是区间长度，把绝对量折成"每公里"的强度。

$$\mathrm{IRI} = \frac{1}{L} \int_0^L \left| z_s(x) - z_u(x) \right| \, \mathrm{d}x \quad \left[ \mathrm{m/km} \right]$$

其中 $z_s$、$z_u$ 分别是金车簧上、簧下的垂向位移，$L$ 是计算区间的里程长度。位移差的绝对值沿里程积分量纲刚好得到米，除以公里即得 m/km——0 是物理上不存在的完美平路，20 以上是能颠坏车的极端烂路。

### 2.3 分级表：一个数排队全部路面

有了统一刻度，路面就能按区间分级。公开技术资料中广泛使用的分级如下：

| 路况分级 | IRI 区间 | 乘坐感受 | 典型路段 | 典型车速 |
| --- | --- | --- | --- | --- |
| 很平滑（Very smooth） | < 2 m/km | 完美 | 新高速、机场跑道 | 120 km/h |
| 平滑（Smooth） | 2~4 m/km | 良好 | 维护良好的高速、新市政路 | 80~120 km/h |
| 一般（Fair） | 4~6 m/km | 可接受 | 老高速、普通市政路 | 60~80 km/h |
| 粗糙（Rough） | 6~8 m/km | 明显下降 | 破损路、维护良好的砾石路 | 40~60 km/h |
| 极粗糙（Extremely rough） | > 8 m/km | 差 | 未铺装路、破损市政路 | < 40 km/h |

这张表有两层用法。对道路管理者，它是养护优先级排序；对耐久工程师，它是**用户路面矩阵的分层框架**——目标市场里各级路面各占多少比例，直接决定耐久载荷谱的构成。新兴市场车型常见的情况是：相当比例的里程落在 IRI>12 m/km 的路面上，而按欧洲路网（多为 2~4）标定的试验谱，欠严酷是系统性的。

## 三、为什么粗糙度直接写进载荷

### 3.1 行李箱里的衣服：舒适性指标看不见的事

IRI 与悬架行程成正比、与车身加速度正相关，这好理解。但"舒适性差"与"耐久出问题"之间隔着什么？打个比方：舒适性指标像看行李箱外观有没有磨破，耐久分析像数行李箱里每件衣服被揉了多少次。路面把悬架反复拉压，每一下都是底盘结构件的一次应力循环——衣服外观看着还行，里面的衬衫早就皱透了。这就是为什么只看舒适性指标会漏掉耐久问题：两个学科统计的是同一次碾压的不同侧面。

粗糙度对整车的作用还有级联效应。路面的振动不只磨悬架：它经结构传到动力总成悬置、传到车身接头、传到支架与线束接插件；装在车身上的电子件（传感器、摄像头支架）在平滑路标定的安装点，在持续高幅振动下可能出现可靠性问题。载荷路径是全车的，所以路谱的严酷度评估必须**按整车对待，而不是只当作悬架的事**。

### 3.2 数量级账：粗糙度翻倍意味着什么

把分级表换算成载荷语言。用金车参数在合成剖面上做数值实验（下一节给出可复现的代码），控制其他条件不变、只逐步加大剖面粗糙度，悬架相对行程与车身加速度的统计量大致随 IRI 线性放大：

| 路况 | IRI（m/km） | 车身加速度 RMS（m/s²） | 相对很平滑路 |
| --- | --- | --- | --- |
| 很平滑 | 0.65 | 0.004 | ×1 |
| 平滑 | 0.95 | 0.006 | ×1.4 |
| 一般 | 1.68 | 0.011 | ×2.6 |
| 粗糙 | 3.13 | 0.020 | ×4.8 |
| 极粗糙 | 6.23 | 0.039 | ×9.4 |

从新高速换到未铺装路，车身加速度 RMS 放大近十倍；而疲劳损伤对应力幅的高次幂敏感（钢的大多数疲劳场合常用四次幂估计），响应线性放大十倍意味着循环载荷的"伤害潜力"按幂次跳几个数量级。这就是"每公里路都在记账"的工程含义：路谱里粗糙路段的比例，是耐久严酷度的一等变量，不是二等变量。

### 3.3 数值实验：金车五档剖面复算

下面的 numpy/scipy 演示把金车状态方程搭起来，在同一个基底剖面上叠加五档幅值，复算 IRI 与车身加速度——数值即上表的来源。

<details>
<summary>数值实验：金车模型复算五档路况的 IRI 与车身加速度（25 行）</summary>

```python
import numpy as np
from scipy.signal import lsim

# 金车参数（标准化，不许改）
ms, mu, cs, ku, kt = 250.0, 35.0, 3000.0, 16000.0, 160000.0
L, v = 0.25, 80/3.6                       # 采样间距 m，标准车速 m/s
np.random.seed(7); n = 40001              # 10 km 剖面
rng = np.random.default_rng(7)
base = rng.normal(0, 0.0006, n)           # 公共基底不平整

A = np.array([[0,1,0,0],[-ku/ms,-cs/ms,ku/ms,cs/ms],
              [0,0,0,1],[ku/mu,cs/mu,-(ku+kt)/mu,-cs/mu]])
B = np.array([[0,0],[0,0],[0,0],[0,kt/mu]])
ts = np.arange(n) * L / v

for label, extra in [("very smooth",0.0002),("smooth",0.0007),
                     ("fair",0.0015),("rough",0.0030),("extreme",0.0060)]:
    road = base + rng.normal(0, extra, n) # 逐档加糙
    u = np.column_stack([np.zeros(n), road])
    _, y, _ = lsim((A, B, np.eye(4), np.zeros((4,2))), u, ts)
    iri = np.abs(y[:,1] - y[:,3]).mean() / v * 1000   # m/km
    ax  = y[4000:,1].std()                            # 车身加速度 RMS
    print("%-12s IRI=%5.2f m/km  ax_rms=%.3f m/s2" % (label, iri, ax))
```

运行结果：

```text
very smooth  IRI= 0.65 m/km  ax_rms=0.004 m/s2
smooth       IRI= 0.95 m/km  ax_rms=0.006 m/s2
fair         IRI= 1.68 m/km  ax_rms=0.011 m/s2
rough        IRI= 3.13 m/km  ax_rms=0.020 m/s2
extreme      IRI= 6.23 m/km  ax_rms=0.039 m/s2
```

从很平滑到极粗糙，IRI 放大 9.6 倍，车身加速度 RMS 同步放大 9.4 倍——粗糙度与响应统计量近似同比例增长，这正是"一个数两头用"的数值基础。

</details>

## 四、速度账：同一条路，跑得越慢读数越高

工程师常问：IRI 是不是路的固有属性，跟车速无关？不是。金车以 80 km/h 定义，同一剖面换个车速碾，激励的频率成分就变了——剖面波长除以车速等于激励频率，速度一变，同样的波长落在不同的频段上，与金车两个共振（约 1.2 Hz 与 10 Hz）的关系随之改变。用 3.3 节同一模型对同一条粗糙剖面扫五档车速：

| 车速 | IRI（m/km） |
| --- | --- |
| 40 km/h | 7.15 |
| 60 km/h | 4.48 |
| 80 km/h | 3.16 |
| 100 km/h | 2.38 |
| 120 km/h | 1.87 |

同一条路，40 km/h 碾出的 IRI 是 120 km/h 的 3.8 倍——因为慢速把长波激励挪到簧上共振附近，悬架"喘"得更起劲；快速反而滤掉了最伤悬架的低频激励。这提醒两件事：其一，IRI 数值只在 80 km/h 标准速度下可比，报告中引用分级必须遵守这个前提；其二，用户实际车速分布与标准车速不同，从 IRI 折算载荷时要经过车速修正，不能拿分级表直接当载荷等级。

## 五、用 Testlab 把实测路谱算成 IRI

### 5.1 一条流程算到底

理论落到桌面。路谱采集（SCADAS RS 等记录设备）带回来的典型通道包括车身高度（路面高程代理）、行驶距离等；在 Testlab 中可以把 IRI 的全部计算与分级串成一条流程，一次执行完成打标：

- 由 GPS/车轮信息计算行驶距离通道；
- 用实测路面高程驱动四分之一车模型——系统级仿真模型（如 Amesim 搭建）可直接导入 Testlab 作为计算单元；
- 由模型响应合成车身位移与悬架位移，并修正尖峰、漂移、偏置等异常；
- 按定义计算 IRI：簧上/簧下位移差绝对值累计除以距离；
- 按分级标准自动给录痕打标：very smooth / smooth / fair / rough / extremely rough。

## 六、工程要点清单

1. **口径统一**：IRI 只在 80 km/h 标准速度下可比，跨车速引用必须换算；
2. **载荷折算要过车速修正**：用户实际车速分布与标准速度不同，分级表不等于载荷等级表；
3. **按整车对待粗糙度**：载荷路径穿过悬置、支架、电子件安装点，不止悬架一家的事；
4. **用 IRI 分层组织用户路面矩阵**：目标市场路网的 IRI 分布，是决定耐久谱构成的一等输入；
5. **自动化打标进数据库**：录痕级 IRI 标签让"按路况筛选数据"成为一条查询语句的事。

## 七、一句话记住

IRI 是路政的体检秤，称的是悬架每公里"喘"几米；舒适性听它的读数判颠簸，耐久借它的读数估载荷——同一个数服务两个学科，因为载荷与感受本就出自同一次碾压。
