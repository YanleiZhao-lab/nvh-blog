# RPM 信号去毛刺：转速信号的清洗

> 转速通道没你想的那么干净：毛刺、丢脉冲、接缝跳变会让阶次分析全盘失真。本文给出 RPM 信号常见故障模式与清洗方法。

## 一、转速通道没你想的那么干净

做阶次分析的人都有一个惯性思维：振动通道才是"脏"的，要担心传感器安装、量程、接地干扰；转速通道嘛，贴个反射片、打束激光，出来的 RPM 曲线天然就是准的。

实际干过几个 Run-up 项目就会知道，恰恰相反——**RPM 曲线上的毛刺（spike/dropout）几乎是常态**。一个偶发尖峰、一段掉线、或者每转固定角度上冒出来的小鼓包，都能让 colormap 上拉出一条条假的阶次线，或者让阶次切片在某个转速点上突然跳变。数据处理阶段如果不把转速通道洗一遍，后面的阶次分析基本是在垃圾上盖楼。

这篇就讲两件事：毛刺从哪来，以及在 Simcenter Testlab（原 LMS Test.Lab）里怎么把它们洗掉。

## 毛刺的三种典型面孔

先学会"看诊"，再谈"开药"。转速信号里的异常基本分三类。

**第一类：偶发的尖峰或掉线。** 转速曲线整体平滑，但某一两个时间点上 RPM 突然飙高（spike）或者掉到零附近（dropout）。多半是测试现场的"敌对环境"造成的——轴上有油污、粉尘，激光打过去反射信号时好时坏，计数就出错了。台架上有切削液雾、飞溅金属屑的场合尤其常见。

![现场环境](/images/rpm-spike-removal/rpm-anomalies.png)

**第二类：每转固定位置上的规律毛刺。** RPM 曲线放大看，每一转的同一个角度位置都冒一个小尖。这不是环境问题，是斑马带（zebra tape）或码盘上某一条条纹的间距、宽度做得不完美——每转到这个角度，脉冲间隔就错一次，转速计算跟着错一次。这种毛刺的危害更大：它是严格周期性的，会在频谱上生成真实的阶次成分，跟你的被测信号搅在一起。

**第三类：斑马带接缝（butt joint）造成的假扭振。** 斑马带缠到轴上总有个收尾，两头搭接的地方如果处理不好——留了缝、或者两条纹挤在一起——轴每转一圈，接缝处就会出现一次"假的"减速或加速。这本质上是每转一次的系统性误差，跟第二类同源，但成因在搭接处而非单条条纹。

三类问题的机理一句话概括：**转速不是直接测的，是靠"相邻条纹到达的时间差"算出来的**。时间差倒数乘以每转条纹数就是转速。所以任何影响"单个脉冲到达时刻"的因素——油污遮住一条纹、条纹印刷间距偏差、接缝搭接——都会一对一地翻译成转速曲线上的毛刺。


![斑马带与激光](/images/rpm-spike-removal/zebra-tape-laser.png)

::: info
为什么斑马带高 PPR（每转脉冲数）测扭振时毛刺更显眼？因为扭振分析本来就要靠每转几十上百个脉冲去分辨一转之内的转速波动，脉冲用得越密，单个脉冲的误差对曲线的影响越直接。
:::

## 洗法一：偶发毛刺，手动替换

偶发的尖峰和掉线，用 Simcenter Testlab 的 **Time Data Editor** 处理，思路很直接：把坏的那一小段圈出来，用直线替换掉。

操作路径：
1. 菜单 **Tools -> Add-ins**，勾选 **Time Data Editor - Standard**。之后 Time Data Selection 工作表上方会多出一排编辑工具按钮。
2. 在左侧数据集中点亮要处理的转速时域 trace。
3. 在 Overview 显示区**按住鼠标拖拽**，框住毛刺前后的一小段。
4. 按 **[R]** 键执行替换，选中的段被一条直线取代，毛刺消失。

![毛刺替换效果](/images/rpm-spike-removal/spike-before-after.png)

几个实操细节值得记住：

- 工具栏右上角有个**设置开关**。开着的时候，每次按编辑键会弹出对话框，可以把"替换为直线"改成"替换为曲线"；关掉则沿用上次设置直接执行。精细操作时开着，批量处理时关掉省事。
- **Undo/Redo 按钮就在旁边**。框选范围手一抖框大了，别慌，撤销重来。
- 改完之后左侧有 **Save**（直接覆盖原数据）和 **Save As**（另存）两个选择。做清洗操作强烈建议另存，原始转速数据是没法重测的，覆盖了就没了。

::: warning
直线替换有一个不能忽视的副作用：**被替换那段的扭振信息，也就是一转之内的转速波动，也被直线抹掉了**。所以这个方法适合的场景是"保住整体转速曲线做阶次跟踪"；如果你的目标是扭振分析本身，一转之内的转速波动正是你要的信号，不能用直线替换去洗，得用下面第二个方法。
:::

## 洗法二：每转固定毛刺，用统计剔除函数

每转同一位置都出现的规律毛刺，手动替换不现实——转速扫到 6000 RPM、采几十秒数据，毛刺成千上万个，一个一个框选能把人框到下班。这时候用 Time Signal Calculator 里的专用函数 **TACHO_MOMENTS_SPIKEREMOVAL_TO_RPM**。

路径：**Tools -> Add-ins** 打开 **Time Signal Calculator**，在界面里点 **f(x)** 按钮，左侧函数组选 **Tacho**，找到这个函数。

![函数设置对话框](/images/rpm-spike-removal/spike-removal-dialog.png)

### 算法逻辑

这个函数不是简单的滑动平均平滑，它的判别基准是统计学的：

1. 取一个**滑动窗口**（默认长度等于一转的脉冲数），计算窗口内各脉冲间平均转速；
2. 对窗口内数据计算**中位数绝对偏差 MAD（Median Absolute Deviation）**；
3. 偏差超过门槛的脉冲判定为离群点，也就是毛刺，剔除后由剩余脉冲重新生成 RPM trace。

用中位数而不是均值做基准是有讲究的：毛刺本身就是极端值，用均值做基准会被毛刺自己带偏，中位数则稳得多。这也是为什么这个算法对"每转固定的规律毛刺"特别有效——规律毛刺在窗口里永远是少数离群点。

### 参数怎么给

| 参数 | 默认值 | 说明 |
|---|---|---|
| Function1 | 无 | 输入转速通道，填通道号 CH1 或通道名 Tacho |
| Pulses_per_rev | 0 | 每转脉冲数；0 表示沿用采集时的 tacho 定义，基本不用改 |
| Spike_detection_window | 0 | 毛刺检测滑动窗口大小，单位为脉冲数；0 表示一转 |
| Spike_detection_threshold | 3.5 | 毛刺判定门槛，即相对滑动平均的最小幅度；常用范围 2 至 100，越低越灵敏 |
| Pulse_rejection_mode | 0 | 0 为优化算法，尽量保留原有频率和扭振内容；1 为激进算法，超门槛的脉冲全删 |
| Additional_pulse_rejection | 0 | 剔除坏脉冲时是否连带：0 只删坏脉冲本身；1 连同前一个；2 连同后一个；3 前后都删 |
| Function2 | DEFAULT | 输出采样率；默认与输入一致 |

实际调参的经验顺序：**先用默认值跑一遍**，前后对比看毛刺是否清除、正常波动是否被误伤。默认门槛 3.5 对绝大多数情况够用。如果毛刺很小清不干净，把 threshold 往 2 的方向降；如果正常转速波动被误删、曲线被过度平滑，往大调。Additional_pulse_rejection 在毛刺成对出现、一个尖峰紧跟一个凹陷时用 3 效果更好。

::: warning
这个函数**不做斑马带接缝校正**，两者别混。接缝校正用的是 ZEBRA_MOMENTS_TO_RPM 函数，把所有脉冲按理论均匀角度重新分布，属于全局修正；毛刺剔除是只动出错的少数脉冲，属于局部修正。如果数据里既有接缝误差又有随机毛刺，两个函数都要用，先剔除毛刺再做接缝校正。
:::

## 两种方法怎么选

| 对比项 | 手动替换 Time Data Editor | 统计剔除 TACHO 函数 |
|---|---|---|
| 适用毛刺类型 | 偶发尖峰、掉线 | 每转固定位置的规律毛刺 |
| 毛刺数量 | 少量，几个到几十个 | 大量，每转一次，成百上千 |
| 扭振信息 | 被替换段直接抹平 | 统计剔除，最大限度保留 |
| 工作量 | 逐个框选，费时 | 设好参数一键跑 |
| 适用后续分析 | 阶次跟踪、colormap | 阶次加扭振分析都行 |

一个常见的完整清洗流程是：先跑一遍 spike removal 函数把规律毛刺批量清掉，再目检一遍残余的偶发尖峰，个别顽固的用 Time Data Editor 手动点杀。

## 采集阶段能预防多少

后处理能救数据，但最好还是在源头少出错：

- 斑马带贴完后**转一圈目检接缝**，搭接处宁可整齐压一条，也别留豁口；贴之前把轴面油污擦干净。
- 激光探头角度尽量垂直于轴面，偏角大时条纹反光强度不均，边缘脉冲容易丢。
- 测扭振用高 PPR 时记住采样定律：**每转脉冲数至少是关心最高扭振阶次的 2 倍**，比如关心 60 阶扭振，至少 120 PPR。而且 PPR 本身没有抗混叠保护，工程上常乘个 10 倍安全系数。
- 现场粉尘油雾大的，定期检查探头镜头——很多"数据变脏"其实是镜头脏了。

## 小结

转速通道的毛刺不是玄学，是"脉冲到达时刻被干扰"的必然结果。偶发毛刺用 Time Data Editor 手动替换，规律毛刺用 TACHO_MOMENTS_SPIKEREMOVAL_TO_RPM 统计剔除，接缝误差用 ZEBRA_MOMENTS_TO_RPM 全局重排——三件套各管一段。洗数据的底线只有一条：动任何修正之前先另存原始数据，转速是整场试验的基准轴，覆盖了没有后悔药。
