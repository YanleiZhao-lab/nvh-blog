# MIMO 多输入多输出测试：多激振器协同激励的收益与代价

> 一个激振器敲不出来的模态，两个激振器一起上。多输入多输出（MIMO）测试用几台激振器同时激励、一组加速度计同步测量，一次试验填出 FRF 矩阵的整行整列，密集模态和重根模态靠多参考数据解耦。代价是输入之间不能相关——否则输入谱矩阵病态，求逆时 FRF 满屏毛刺。这篇讲清 MIMO 的收益从哪来、相关性为什么是死穴、激振器怎么摆，以及 Testlab 里 MIMO FRF 估计的操作路径。

## 一、从 SIMO 到 MIMO：多台激振器买来什么

单输入多输出（SIMO）试验里，一台激振器固定在一个点，加速度计遍历所有测点。这套流程有两个软肋。一是模态理论层面的：单个参考点若恰好落在某阶模态的节点附近，那阶模态在整组 FRF 里都激不出来，或者激得很弱。二是数据完整性层面的：每换一次参考点，结构状态都要重新安装，试验一致性随时间漂移，白车身这种大结构尤其明显。

MIMO 的做法是一次挂多台激振器，同时激励、同步测量。按 LMS 理论手册的定义：如果系统受多个输入激励，同时在多个响应 DOF 测量响应，则 FRF 分析方法属于多输入多输出（MIMO）方法。

![FRF 与自由度：一个 FRF 连接响应 DOF 与参考 DOF](/images/mimo-testing/frf-definition.png)

*（图源：Simcenter Testing Knowledge Base）*

一个 FRF 总是涉及两个 DOF——响应 DOF（分子）和参考 DOF（分母）。SIMO 试验只能填出 FRF 矩阵的一列；MIMO 试验一次填出若干列，激振器数少于测点数时，靠分批移动加速度计补齐其余行。

| 维度 | **SIMO（单激振器）** | **MIMO（多激振器）** |
| --- | --- | --- |
| **参考点落在模态节点** | 该阶模态整列丢失 | 其它参考点补位，模态仍在 |
| **密集/重根模态** | 单参考数据无法解耦 | 多参考模态参与因子解耦 |
| **FRF 矩阵完整性** | 一列，互易性没法自检 | 整行整列，互易性可当场验证 |
| **试验一致性** | 换参考点=重新安装 | 一组状态测完全部数据 |
| **激励能量** | 单点输入，大结构激不动 | 多点分摊，总能量成倍提高 |
| **系统代价** | 一台功放一套力传感 | 每通道一套功放/力传感，通道数翻倍 |

::: info 核心概念
- **MIMO（Multi Input Multi Output）**：多个输入激励与多个响应测量同时进行的 FRF 分析方法，一次试验填出 FRF 矩阵的多个列
- **参考 DOF**：激振器（或力锤）作用的自由度，FRF 的分母；几台激振器就是几个参考 DOF
- **模态参与因子（Modal Participation Factor）**：第 k 阶模态在各输入自由度上的参与系数行向量，互易性成立时正比于参考点的模态振型系数——多参考解耦密集模态的钥匙
- **输入谱矩阵**：所有输入通道两两之间的自谱与互谱组成的矩阵，MIMO FRF 估计的分母，要求可逆（满秩）
:::

## 二、FRF 矩阵方程：H1 估计推广到多输入

单输入时 FRF 是一个数：$H = S_{yx}/S_{xx}$。多输入时它变成矩阵方程。设系统有 $N_i$ 个输入、$N_o$ 个输出，对每条谱线，输入向量 {X}、输出向量 {Y} 与频响函数矩阵 [H] 满足：

$$\{Y\} = [H]\{X\}$$

[H] 的维度是 $N_o \times N_i$——每个输出对每个输入都有一个 FRF。理想无噪声情况下两边同乘输入的逆就得到 [H]；实际测量必含噪声，于是仿照单输入的思路做最小二乘估计。

### 从 SISO 到矩阵 H1：推导分三步

**第一步，写误差方程。** 设输出端有噪声 {N}，实测关系是 $\{Y\} = [H]\{X\} + \{N\}$，误差 {N} 是输出中不能被输入解释的部分。

**第二步，构造最小二乘目标并推出正规方程。** 让误差能量 $E[\{N\}^H\{N\}]$ 最小，对 [H] 求导置零，得到正规方程 $[H][S_{xx}] = [S_{yx}]$。其中 $[S_{xx}] = E[\{X\}\{X\}^H]$ 是输入谱矩阵（上标 H 表示共轭转置），$[S_{yx}] = E[\{Y\}\{X\}^H]$ 是输出对输入的互谱矩阵。对每条谱线，$[S_{xx}]$ 是 $N_i \times N_i$ 方阵，$[S_{yx}]$ 是 $N_o \times N_i$ 矩阵。

**第三步，右乘逆矩阵。** 正规方程两边右乘 $[S_{xx}]^{-1}$：

$$[\hat{H}_1] = [S_{yx}][S_{xx}]^{-1}$$

物理意义：每条谱线上解一个小线性方程组，把每台激振器对每个响应点的贡献从混叠的响应里拆开。单输入公式 $H_1 = S_{yx}/S_{xx}$ 就是它 $N_i=1$ 时的特例。手册明确指出：在各输入信号之间**不相关**的情况下，H1 估计得到最佳的结果；如果输入信号中存在噪声，H1 得到的是 FRF 的欠估计——这两句合起来就是 MIMO 的命门所在。

### 密集模态为什么靠多参考解耦

MIMO 的深层收益在参数估计。留数矩阵按模态分解后，第 k 阶模态贡献可写成响应点振型与模态参与因子行向量的外积。手册特别讨论了两个彼此非常密集的极点的情形：相对于单一输入自由度，两个密集模态的响应看起来是耦合的线性组合而非独立模态——单参考数据在数学上无法把它们分开。而模态参与因子是随参考自由度变化的向量：两个参考点上参与因子比例不同，多参考数据就提供了把密集模态乃至重根模态拆开的额外信息量。

![密集模态的耦合与解耦：模态参与因子随参考自由度变化](/images/mimo-testing/close-modes-mpf.png)

*（图源：Simcenter Testing Knowledge Base）*

手册表 15.2 给了个反直觉的关系：模型阶次 p、模态数 N 与参考自由度数之间是非线性关系——8 阶模型在同时分析 3 个输入时，足以描述 11~12 个模态。参考自由度越多，同阶模型罩住的物理模态越多，稳态图上的光柱越干净。

## 三、相关激励：MIMO 的死穴

$[\hat{H}_1] = [S_{yx}][S_{xx}]^{-1}$ 成立的前提是 $[S_{xx}]$ 可逆。如果两台激振器输出完全相同的信号（相关系数为 1），$[S_{xx}]$ 的两行成比例，矩阵奇异，逆不存在。相关系数介于 0 和 1 之间时矩阵可逆但**病态**：条件数飙升，求逆把互谱里的测量噪声放大成 FRF 上成片的毛刺。极端情形等价于把一台激振器的力分给两个通道去"冒充"两台——力是真力，方程却已经瞎了。

这就是 MIMO 信号设计的核心约束：**各输入信号彼此不相关**。激振器数量翻上去，信号源就必须为每通道产生独立的随机序列。手册在主分量谱一节给出判别工具：对输入组做分解得到互不相关的主分量，"主分量之间的相干函数值精确地等于 0"；主分量谱的主要应用之一就是 MIMO 频响函数估计中多输入激励源的鉴别——若某个输入信号组实际只含一个独立源（比如两台激振器被误接成同一信号），主分量分析当场暴露。

| 病灶 | 表现 | 诊断手段 |
| --- | --- | --- |
| **两输入完全相关** | $[S_{xx}]$ 奇异，FRF 求逆报错或发散 | 输入互谱矩阵秩亏；主分量只剩 1 个非零 |
| **输入高度相关** | FRF 共振峰两侧成片毛刺 | 输入常相干接近 1；条件数检查 |
| **参考点落在模态节点** | 该列 FRF 该阶模态峰值缺失 | 与其他列对比；模态参与因子近零 |
| **激振器互相"拉扯"** | 力谱出现谐振掉坑，结构被制动 | 检查激振器安装刚度与推力杆 |
| **信号源通道共享** | 多通道输出同一序列 | 信号发生器配置逐通道核对 |

::: warning 相关不等于同步
"多台激振器同时开动"是同步，不是相关。MIMO 要求的是互不相关的独立驱动信号同时输出——纯随机、猝发随机天然满足；扫频正弦多台一起扫同一频带时若不加相位/频率错开设计，相关性会随扫描过程漂移，稳态图跟着花。
:::

## 四、Python 演示：输入相关性怎样摧毁 FRF 估计

用两台"激振器"驱动一个 2 输入 2 输出系统，逐步提高第二路输入与第一路的相关系数，看输入谱矩阵的条件数和 FRF 估计误差怎样联动爆炸。每帧独立采样、40 帧平均，输出端加同样的噪声：

```python
import numpy as np

rng = np.random.default_rng(42)
fs, T = 2048, 2.0                       # 采样率与每帧时长
N = int(fs * T)
f = np.fft.rfftfreq(N, 1/fs)

# 2x2 FRF 矩阵：每个元素是一个单自由度系统（固有频率/阻尼比/刚度）
H = np.zeros((2, 2, len(f)), complex)
params = [[(40, 0.02, 1.0), (55, 0.03, 0.3)],
          [(48, 0.025, 0.5), (62, 0.035, 1.0)]]
for o in range(2):
    for i in range(2):
        fn, zeta, K = params[o][i]
        H[o, i] = K / (1 - (f/fn)**2 + 2j*zeta*(f/fn))

frames = 40
for gamma in (0.0, 0.7, 0.95, 0.999):   # 第二路输入与第一路的相关系数
    Sxx = np.zeros((2, 2, len(f)), complex)
    Syx = np.zeros((2, 2, len(f)), complex)
    for _ in range(frames):             # 逐帧累积谱矩阵
        x1 = rng.standard_normal(N)
        x2 = gamma*x1 + np.sqrt(1-gamma**2)*rng.standard_normal(N)
        X = np.fft.rfft(np.stack([x1, x2]), axis=-1)        # 输入谱
        Y = np.einsum('oif,if->of', H, X) + 0.05*rng.standard_normal((2, len(f)))
        Sxx += (X[:, None, :]*X.conj()[None, :, :])/frames  # 输入谱矩阵
        Syx += (Y[:, None, :]*X.conj()[None, :, :])/frames  # 互谱矩阵
    band = np.logical_and(f > 5, f < 200)
    cond = np.mean([np.linalg.cond(Sxx[:, :, k]) for k in np.where(band)[0]])
    Hest = np.linalg.solve(Sxx[:, :, band].transpose(2, 0, 1),
                           Syx[:, :, band].transpose(2, 0, 1)).transpose(1, 2, 0)
    err = np.abs(Hest[0, 1] - H[0, 1, band]).max()
    print(f"gamma = {gamma:5.3f} | cond(Sxx) = {cond:8.1f} | H12 峰值误差 = {err:8.2e}")
```

运行结果（40 帧平均、输出噪声 0.05）：

```text
gamma = 0.000 | cond(Sxx) =      1.4 | H12 峰值误差 = 5.75e+00
gamma = 0.700 | cond(Sxx) =      5.9 | H12 峰值误差 = 4.00e+01
gamma = 0.950 | cond(Sxx) =     41.1 | H12 峰值误差 = 2.12e+02
gamma = 0.999 | cond(Sxx) =   2117.7 | H12 峰值误差 = 1.49e+04
```

相关系数从 0 拉到 0.999，条件数涨三个数量级，H12 的估计误差跟着涨近四个数量级——$[S_{xx}]^{-1}$ 就是噪声放大器，相关激励等于亲手把增益旋到最大。更阴险的是常相干的变化趋势：同一组数据里输入-输出常相干均值随相关性升高反而从 0.71 爬到 0.999——两路输入相关时，输出几乎能被任一路输入"解释"，单看相干曲线一片大好，FRF 早就烂了。相干救不了 MIMO，条件数和输入互相干才是该盯的指标：输入互相干超过 0.8 警觉，超过 0.9 这组数据基本可以重测。

::: tip 信号选择建议
- **默认纯随机或猝发随机**：各通道独立序列，天然不相关，汉宁窗（随机）或矩形窗（猝发）按常规
- **伪随机慎用于 MIMO**：单输入时伪随机是高质量选择；多输入时若各通道相位谱设计不当，帧内相关性可能异常，逐通道核对输入互相干
- **通道数宁少勿滥**：2~4 台激振器覆盖大多数车身与部件试验；输入通道翻倍，$[S_{xx}]$ 尺寸平方增长，病态风险随之上升
:::

## 五、试验组织与 Testlab 操作路径

MIMO 试验的准备工作量比 SIMO 大一截，但换来的数据完整性和解耦能力不可替代。

**激振器布置。** 参考点要避开主要模态的节点（用 CAE 模态或前次试验数据预判），几个参考点之间拉开结构上的距离、方向错开——两个挨在一起的激振器对全局模态提供几乎相同的信息，等于白白浪费一个参考自由度。激振器通过推力杆与结构连接，安装刚度和对中直接影响力谱质量。

**信号与采集。** 每台激振器一套独立信号源通道、功放与力传感器；Testlab 中各输入通道设为 Reference 类型，输出通道为 Response，MIMO FRF 计算自动按参考通道组组织。随机激励加汉宁窗、多帧平均；谱矩阵按帧累积，平均次数几十帧起步。

**估计子选择。** 多输入下 H1 依旧是最常用的估计子；H2 在多输出情形无法直接计算（手册注明需 Moore-Penrose 广义逆）；Hv 对输入输出噪声总体最小化，共振区贴近 H2、反共振区贴近 H1，代价是每条谱线做谱矩阵特征分解，计算更慢。输入相关性存疑时先做主分量分析鉴别独立源，再进曲线拟合。

**曲线拟合。** 多参考 FRF 直接喂给整体估计器：多输入 LSCE 同时估计频率、阻尼与模态参与因子，密集模态乃至重根模态可以被识别；CMIF（复模态指示函数）以多参考 FRF 为基础，每条谱线对 FRF 矩阵做奇异值分解，第一奇异值曲线的峰快速锁定模态数、检索重根，为 LSCE/FDPI 定阶提供先验。

![多输入 LSCE 的数据模型：极点与模态参与因子同输出自由度无关](/images/mimo-testing/mimo-lsce-model.png)

*（图源：Simcenter Testing Knowledge Base）*

模型阶次与参考自由度的关系也值得留个心眼。手册表 15.2 的数字说明参考自由度越多，同一阶模型能描述的模态数越多——多参考不只解耦，还顺带压低了稳态图里计算模态的存活空间。

## 六、小结

MIMO 不是"多接几台激振器"，是用多参考数据结构换模态解耦能力与试验一致性：参考点避开节点靠冗余保住每阶模态、模态参与因子拆开密集与重根模态、FRF 矩阵整行整列支撑互易性自检。前提只有一条——输入信号互不相关，$[S_{xx}]$ 满秩且良态；相关系数逼近 1 时条件数就是噪声放大倍数，FRF 满屏毛刺是数学病态不是结构特性，而且常相干会虚高掩盖病情。试验前用主分量分析鉴别独立源，试验中盯输入互相干与条件数，拟合时 LSCE/CMIF 吃多参考数据，2~4 台激振器是大多数试验的甜点区。
