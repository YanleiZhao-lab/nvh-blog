# 任务合成 Mission Synthesis：从用户载荷到台架谱

> 同一个电子产品按通用规范谱做振动试验一次通过，装到客户的新车型上却在保修期内批量开裂——问题多半不在产品，而在那张"祖传"的试验谱。规范谱是几十年前从旧车型、旧路面数据归纳出来的默认曲线：对新一代平台，它可能过于严酷（逼着产品过设计），也可能过于温和（现场提前失效），风险是双向的。本文用一台需要经受铁路运输、三个地区路面使用的设备作例子，把 相关技术资料的任务合成（Mission Synthesis）流程走一遍：定义任务剖面、采集基座现场数据、用疲劳损伤谱 FDS 与最大响应谱 MRS 量化每个环境的"破坏势"、按串并行规则合成全寿命总损伤、反演出等损伤的台架 PSD 谱，并用夸大因子判断加速度试验有没有"加过头"。

## 一、为什么"祖传谱"越来越靠不住

振动台架试验的默认做法是从标准里翻出一条通用谱——比如某些电子设备规范里那张经典的平直加陡降曲线——按给定量级与时长扫完交差。这种做法的前提假设是：规范制定时参考的载荷环境与你产品将来经历的环境足够接近。

这个假设正在变得越来越脆弱。产品装在哪台车上、跑哪些地区、客户是高速通勤还是矿区重载，谱形差别巨大；规范谱的默认曲线来自多年前特定条件下的存量数据，对"装在新环境里的具体设备"可能完全不代表。手册把风险讲得很直白：规范谱**过于严酷**的后果是潜在过设计（重量与成本白白加上去），**过于温和**的后果是潜在现场失效（保修与口碑买单）。

任务合成给出的替代路线是不依赖默认曲线，而是**从产品真实寿命剖面出发**：先定义任务（运输+使用的全部环境），逐环境实测基座输入加速度，把每个环境的损伤势算出来加在一起，最后反演出一条"等损伤、短时长"的台架 PSD 谱。整个流程像给产品定制体检方案——不是套用所有人的平均体检套餐，而是按你这台设备将来要经历的每一段路，分别开检查项目，再合并成一张处方。

![任务合成流程：从现场实测振动数据到加速振动台架谱](/images/mission-synthesis/fig2-process.png)

*（图源：网络 侵删）*

值得先说清楚一条边界：任务合成的目标是推导**对组件等疲劳损伤的输入**，而不是复现组件上每个位置的精确损伤。这个取舍带来两个直接好处——不需要组件的详细模型；不同设计方案的组件可以对着同一条输入谱做对比试验。

## 二、任务剖面：把"一辈子"画成流程图

任务合成的第一步不是接传感器，而是回答一个问题：这台产品在寿命期内会经历哪些振动环境？官方例子是一台既要用在亚太、欧盟、美国三个地区，又有高速与越野工况的设备，出厂还要先经铁路运输。把这些环境画成流程图：

![产品寿命期环境流程图：铁路运输必经，三个地区按实际销售使用其一](/images/mission-synthesis/fig7-mission.png)

*（图源：网络 侵删）*

这张图上每一格，将来都对应一段实测数据、一张 FDS 谱和一个重复次数。图里还藏着后面合成时要用的关键区分：**有些环境是"或"的关系**（产品只会卖到三个地区之一，亚太/欧盟/美国的坏路它只经历其中一种），**有些是"且"的关系**（铁路运输加上使用地的高速与越野，每台产品都要经历）。这个区分决定了合成时取最大还是求和，第三节会展开。

数据采集本身有两条硬要求。第一，测点放在**基座（安装界面）上**——也就是组件与主机结构连接的地方，因为任务合成推导的是输入振动，将来台架试验的控制加速度计也应放在同一位置；第二，尽量用三向加速度计，先弄清哪个方向量级最大，单向台架要按 X/Y/Z 分别分析与试验。现场数据可以用坚固型采集设备（如 Simcenter SCADAS RS）记录，输入软件的可以是时间历程（LDSF、UF 等格式）或直接是 PSD。

## 三、损伤势怎么算：一行 SDOF 振子，两张谱

现场数据拿到手，下一个问题是：怎么比较"碎石路 200 秒"与"高速 600 秒"哪个更伤？直接比 RMS 不行——疲劳损伤对幅值是幂律敏感的，对频率分布也敏感。任务合成的做法是把测量振动喂给一排虚拟的单自由度（SDOF）质量-弹簧-阻尼振子，每个振子调到不同的固有频率：

![一系列调到不同固有频率的 SDOF 振子承受实测振动，各自产生以自身固有频率为主的响应](/images/mission-synthesis/fig14-sdof.png)

*（图源：网络 侵删）*

这排振子不是物理装置，而是"待测设备的通用替身"：任何真实结构在某个频率附近的响应行为，都可以用对应调谐的 SDOF 近似。输入加速度经过每个振子相当于经过一个窄带滤波器，输出一段以该振子固有频率为主的响应时程。对这段响应做不同的后处理，就得到两张谱：

- <strong>疲劳损伤谱 FDS（Fatigue Damage Spectrum）</strong>：对每个振子的响应时程做循环计数（雨流等），再用材料曲线把循环换算成损伤，逐频率累加——它回答"这个环境在每个频率上攒了多少疲劳损伤"
- <strong>最大/冲击响应谱 MRS/SRS（Maximum/Shock Response Spectrum）</strong>：取每个振子响应时程的绝对最大加速度——它回答"这个环境在每个频率上出现的峰值有多大"。MRS 通常来自随机振动数据，SRS 通常来自瞬态冲击数据，算法相同、输入类型不同

![FDS 计算链：加速度测量经 SDOF 组产生各频率响应时程，循环计数加材料曲线换算成逐频率累积损伤](/images/mission-synthesis/fig15-fds.png)

*（图源：网络 侵删）*

::: info 核心概念
- <strong>FDS（Fatigue Damage Spectrum，疲劳损伤谱）</strong>：逐频率累积疲劳损伤的谱，台架 PSD 反演的目标函数
- <strong>MRS/SRS（Maximum/Shock Response Spectrum，最大/冲击响应谱）</strong>：逐频率峰值响应包络，判定加速试验是否过头的红线
- <strong>每倍频程点数（Points per Octave）</strong>：虚拟振子的数量，决定谱沿频率轴的疏密，可线性或对数分布
- <strong>Q 因子（Q-Factor）</strong>：虚拟振子的品质因数，Q=10 对应阻尼 5%，所有振子取同一 Q
:::

FDS 计算需要一组材料参数：Q 因子或阻尼、应力/位移常数 K、Woehler 常数 A 与指数 b。这里有个初学时容易迷路、官方特意点破的性质：**加速试验时真正起作用的只有 Woehler 指数 b**。因为 K、Q、A 这些参数在"算 FDS"和"从 FDS 反推 PSD"两步中都出现，同进同出、互相抵消；只有 b 掌握着"幅值抬高多少能换时长缩短多少"的兑换率。常用参考值：钢 b=5（Testlab 默认值）、铝 b=8、电子产品 b=5；多材料组件取最小的 b 更安全。若只有 PSD 数据（比如要拿现场数据与规范谱或现有台架谱比对），用"PSD to FDS & MRS"方法即可，随机输入按高斯假设处理。

## 四、合成总损伤：并行取最大、顺序做累加

每个环境的 FDS 算好后，要回答"全寿命总损伤是多少"。这一步的物理规则只有两条，都来自疲劳损伤的累积本性：

- <strong>并行（Parallel）</strong>：几个环境产品只会经历其一（三个地区的坏路只走一种）——取每个频率上的**最大**损伤
- <strong>顺序（Sequential）</strong>：几个环境每台产品都要经历（运输、坏路、高速一样不落）——损伤是累积量，直接**求和**

再乘上每个环境的重复次数。官方例子：200 秒的时程重复 4200 次，意味着零件要挺过 840000 秒（14000 小时）的该环境；代表 14000 小时的 FDS 算出来后，还可以继续与其他环境求和。重复次数在 Testlab Neo 2506 之后可以放进 Excel 表用过程变量管理，改方案不用重搭流程。

合成结束时得到一条代表"产品整个寿命累积损伤"的 FDS——它就是台架谱反演的目标。

## 五、反演台架谱：等损伤的 PSD 与时长

最后一步是把目标 FDS 变成能上台架的东西：一条 PSD 谱加一个试验时长。Testlab Neo 里用"FDS & MRS to PSD"方法，关键参数两个：

- <strong>总时长（Total Time）</strong>：台架试验运行的秒数或小时数，应短于产品实际寿命（否则谈不上加速）
- <strong>材料定义（Automatic/Manual）</strong>：Automatic 直接沿用前面算 FDS 的材料参数（默认，且除 b 以外的参数会互相抵消）；Manual 手选材料时不能与算 FDS 时不同，否则当量关系失效

这一步回答的核心问题是：<strong>时长缩短多少，量级要抬高多少，损伤才刚好相等？</strong> 设台架与现场的量级比为 E（夸大因子，Exaggeration Factor）、时长比为 1/E^b（时间缩减因子，Time Reduction Factor），等损伤条件给出两者的兑换关系：

$$D_{\text{bench}} = D_{\text{field}} \;\Longleftrightarrow\; \left(\frac{A_{\text{bench}}}{A_{\text{field}}}\right)^{b} \cdot \frac{T_{\text{bench}}}{T_{\text{field}}} = 1 \;\Longleftrightarrow\; E^{b} = \frac{T_{\text{field}}}{T_{\text{bench}}}$$

这个公式回答的问题是：幅值与时长怎么换算才不亏欠损伤——其中 E 对应物理里的振动量级放大倍数（PSD 是幅值的平方，故 PSD 放大 $E^2$），b 是材料 Woehler 曲线斜率（钢 5、铝 8），$E^b$ 就是"花 1.25 倍量级买 3.05 倍时长"的汇率。b 越大，同样幅值增量能兑换的时长压缩越多——铝（b=8）比钢（b=5）更"吃"加速。

具体数字感受一下这张汇率表：量级抬 10%，时长压到 1/1.61；抬 15%，压到 1/2.01；抬 25%，压到 1/3.05；抬 50%，压到 1/7.59；翻倍则压到 1/32。官方表格给了同一组对照：

![夸大因子、材料曲线斜率 b 与时间缩减因子对照表](/images/mission-synthesis/fig28-exagg.png)

## 六、加速的边界：三条红线

任何时长都可以填进"Total Time"——软件会自动把 PSD 台阶抬高来补偿。**能填不等于该填**。判断加速有没有过头，手册给了三条检查线。

<strong>红线一：台架能力。</strong> 每台振动台对给定负载有最大加速度、最大速度、最大位移的限制（Testlab 环境类产品里在 Tools -> Options -> Shakers 设置）。反演出的谱如果台架推不动，只能加长试验时长。

<strong>红线二：材料区域。</strong> 钢的疲劳极限与抗拉强度之比约为 2：量级抬高到 2 倍意味着弹性区的循环被推到接近极限强度的区域，失效机理从高周疲劳变味成低周塑性——现场根本不会出现的失效模式会在台架上冒出来。所以 E=1.5~2 的加速一般要避免；**15%~25% 的量级增量**是工程上常用的稳妥区间（对应时长压到 1/2 到 1/3），但仍应对照实际载荷水平与材料核实。

<strong>红线三：MRS 对 SRS。</strong> 加速后的台架谱要和现场数据的 MRS、冲击试验的 SRS 放在一起比：加速试验的 MRS 低于最严酷冲击事件的 SRS，说明峰值没越界，时长不必再加；反之 MRS 超过 SRS，要么加长试验时间把量级降下来，要么按某些耐久规范的逻辑，振动已覆盖冲击、冲击试验可以免做。Testlab Neo 的透视表（Pivot Table）做这种多方向谱叠加对比很顺手——点表头即可整行整列叠加：

## 七、numpy 数值演示：233 小时压到 76 小时，损伤一分不少

下面用 20 行 numpy 走一遍核心当量关系：构造一个双峰现场 PSD（低频高速峰 + 宽带坏路峰），重复 4200 次 200 秒（233.3 小时）；按 E=1.25、b=5 反演台架条件（PSD 放大 $E^2$、时长压到 $1/E^b$），用窄带近似 FDS 校验损伤是否严格相等：

```python
import numpy as np

f = np.logspace(np.log10(5), np.log10(2000), 400)      # 频率轴 Hz
psd_field = (0.005*np.exp(-0.5*(np.log(f/60))**2)      # 高速低频峰 (g^2/Hz)
           + 0.080*np.exp(-0.5*(np.log(f/250))**2))    # 坏路宽带峰 (g^2/Hz)

def fds(psd, f, T, b=5.0, Q=10):
    """窄带近似 FDS：D(fn) ~ fn*T*sigma^b, sigma 为 SDOF 响应 RMS"""
    out = np.empty_like(f)
    for i, fn in enumerate(f):
        z = 1/(2*Q); r = f/fn                          # 阻尼比与频率比
        H2 = (1+(2*z*r)**2)/((1-r**2)**2+(2*z*r)**2)   # 基座激励绝对加速度传递函数 |H|^2
        out[i] = fn*T*np.trapezoid(psd*H2, f)**(b/2)   # 响应方差开 b/2 次方
    return out

T1 = 200*4200/3600.0                                   # 现场: 200s x 4200 次 = 233.3 h
D_field = fds(psd_field, f, T1)                        # 目标 FDS

E, b = 1.25, 5.0                                       # 夸大因子 / 钢的 Woehler 斜率
T2 = T1/E**b                                           # 台架时长 = 现场 / E^b
D_bench = fds(psd_field*E**2, f, T2, b=b)              # PSD 放大 E^2 的台架谱
print(f"现场 {T1:.1f} h -> 台架 {T2:.1f} h（压缩 {T1/T2:.2f} 倍）")
print("损伤当量校验 max|D_bench/D_field-1| =",
      np.max(np.abs(D_bench/D_field-1)))
for E2 in (1.10, 1.15, 1.25, 1.50, 2.00):
    print(f"E={E2:.2f}: 时长压缩 E^b = {E2**5:5.2f}x -> 台架 {T1/E2**5:6.1f} h")
```

运行结果：现场 233.3 小时压到台架 76.5 小时（压缩 3.05 倍），FDS 当量校验最大相对偏差 $1.2\times10^{-15}$——机器精度内损伤一分不少。汇率表同时可见加速的诱惑与边界：E=2 能把 233 小时压到 7.3 小时，但第六节的材料红线告诉我们，钢制件量级翻倍已经把弹性区循环推进接近极限强度的区域，台架失效模式会失真；E=1.15~1.25 才是既省时又不骗人的工程区间。

注意演示里 PSD 放大 $E^2$ 而不是 E：PSD 的量纲是幅值的平方，"量级抬 25%"指 RMS 加速度抬 25%，对应 PSD 抬高 $1.25^2=1.5625$ 倍。这也是初上手时最常见的单位坑之一。

## 八、Testlab Neo 操作锚点

- **插件**：File -> Add-ins 打开 Process Designer（19 tokens）与 Mission Synthesis（24 tokens），共需至少 43 tokens
- **界面**：左下角 Processing 标签页 = 数据选择区 + 方法库 + 流程区 + 显示区
- **流程搭建**：右键现场数据 Replace in Input Basket -> 拖入 FDS & MRS 方法（材料参数在其属性页设置）-> Combine FDS & MRS（Combination 属性里选并行/顺序、填重复次数，2506 起支持 Excel 过程变量）-> FDS & MRS to PSD（Total Time 定时长、Define Material 用 Automatic）
- **红线检查**：Tools -> Options -> Shakers 查台架极限；Pivot Table 点表头叠加 MRS/SRS 对比

## 一句话记住

规范谱是别人的病历，任务合成是给自己的设备写处方：实测基座载荷算 FDS、串行累加并行取大合成全寿命损伤，反演等损伤 PSD 台架谱——幅值换时长的汇率是 $E^b$，量级只加 15%~25%，别把弹性区循环推进塑性区。
