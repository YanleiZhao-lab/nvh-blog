# Community Guidelines

NVH Test Forum is for engineering research, academic discussion, and practical NVH problem solving.

## Posting Rules

- Use a clear title that names the problem, method, or topic.
- Include enough context: equipment, sampling settings, operating condition, expected result, and observed result.
- Do not publish customer data, confidential project names, license keys, API keys, private endpoints, payment information, or personal information.
- When sharing data, anonymize files and explain how the data was collected.
- When discussing papers, include the paper title, authors, year, and source link when available.

## Engineering Question Template

Use this structure for troubleshooting posts:

1. Problem description
2. Test object and operating condition
3. Sensors and acquisition settings
4. Processing method and parameters
5. Expected result
6. Observed result
7. What has already been tried
8. Safe-to-share data, plots, or screenshots

## Moderation Principles

- Prefer editing and coaching over deleting when a post is useful but poorly structured.
- Remove sensitive data immediately and ask the author to repost a sanitized version.
- Move posts to better categories when that improves discoverability.
- Mark high-quality solved discussions as references for channel and blog summaries.

## API And Tool Discussions

The forum may discuss public API plans, MCP workflows, Skill examples, and client scripts. It must not host backend secrets, paid-account credentials, or production configuration.
