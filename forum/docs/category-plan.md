# Forum Category Plan

`forum.nvhtest.cn` should be a focused NVH engineering and academic forum. The production runtime should be Discourse; this file is the planning reference for manual setup or future import scripts.

## Categories

| Category | Purpose | First Permissions |
| --- | --- | --- |
| 公告 | Official announcements, maintenance, events, and roadmap updates. | Staff create, everyone read |
| NVH 测试 | Measurement setup, sensors, operating conditions, data quality, and reports. | Members create/read |
| 信号处理 | FFT, order tracking, filters, envelope analysis, time-frequency methods. | Members create/read |
| CAE 与仿真 | Modal analysis, structural acoustics, acoustic cavities, materials, validation. | Members create/read |
| 声学材料 | Absorption, insulation, damping, porous materials, test standards. | Members create/read |
| 论文与学术 | Paper notes, method discussion, reproducibility, academic resources. | Members create/read |
| 工具开发 | Scripts, MCP, Skill, API clients, automation, report generation. | Members create/read |
| 问题求助 | Troubleshooting questions with data context and expected output. | Members create/read |
| 数据与资源 | Public datasets, templates, links, and reusable examples. | Trust level gated when needed |

## Tag Groups

- Domain: `vehicle-nvh`, `e-drive`, `acoustics`, `vibration`, `modal`, `psychoacoustics`
- Method: `fft`, `order-tracking`, `filtering`, `stft`, `fea`, `test-design`
- Resource: `paper`, `dataset`, `template`, `script`, `case-study`, `checklist`
- Service: `api`, `ai-api`, `mcp`, `skill`, `reporting`

## Moderation Defaults

- Posts involving customer data must be removed or edited until fully anonymized.
- Tool/API posts may discuss usage and public examples, but must not include keys, tokens, credentials, private endpoints, or payment data.
- Academic discussions should include citation links where possible and distinguish facts from personal interpretation.
